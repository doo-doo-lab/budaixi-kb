# 杀无生

================================================================================

庄子·逍遥游剧《东离剑游纪》中的虚拟人物杀无生是霹雳布袋戏《东离剑游纪》系列中的冷血杀手，称号“鸣凤决杀”，由桧山修之（日语版）配音。

他以双剑为武器，精通音律与自创“杀劫”系列剑术，将凛雪鸦视为宿敌，在凛雪鸦许诺交出项上人头之后加入队伍，代替廉耆使用回灵笛。

角色性格孤傲偏执，追求绝对剑道，名言“汝之命运，已掌握在吾杀无生手中”凸显其掌控欲。

他多次执行秒杀任务，于第九集挑战蔑天骸被其所杀。

外传揭示其幼年被视作不祥弃于剑圣铁笛仙门下，养成扭曲价值观，与凛雪鸦的羁绊贯穿其悲剧生涯。

杀无生以极端方式践行剑道，短暂生涯充斥杀戮执念与宿命抗争，其武学设计与身世悲剧为角色赋予复杂层次，最终成为剧情关键转折点。

## 角色能力

武器凤啼双声（双剑）武学杀劫·百鸟朝凤：射出无数发精练的气劲，并将其外型伪装成短剑的模样。

这时用迅捷的手法将真正的暗器混入其中投掷，扰乱对手的应对方式，制造出致命的破绽也就是说这招只是破防，真正的杀招是最后那一剑。

杀无生 江湖游记写真杀劫·黑禽夜哭：吸收他人释放的气息，使自己剑招加成的秘招。

在两军交战之类的多人乱战场合可以发挥奇效。

只有平素惯于与他人杀意相对的修罗方能做到。

仙歌·玄琅天音：“剑圣”铁笛仙之剑法。

双足离地、将身子投入空中，借由回旋之势就此将敌方一刀两断，犹如天降神罚的落雷一般。

仙歌·神籁无响：“剑圣”铁笛仙之剑法，也是其奥义之一。

看似突刺的动作，凝聚真气化作势可贯穿白日的不详黑雷。‘神籁无响’，最响亮的有声即为无声，将此矛盾之意蕴含其中，化作有形的奥义。

以“大音希声”之理凝凝而成的一式，意在让对手误以为这是足以致命的一击，进而造成失策误算。

（注：关于‘仙歌’详细信息来自于东离剑游纪官方小说外传《生死一剑·杀无生篇》）

## 官方外传

东离剑游纪外传之杀无生篇，由江波光则写作，虚渊玄监修。

官方外传小说封面外传设定杀无生原本出生于权贵之家，但因出生之时乌鸦啼叫、母亲难产而死、产婆推责互杀，从而被父亲视为不祥之人，丢弃在剑圣铁笛仙的道馆门前请求诛杀。

后被铁笛仙收养，成为其徒弟。

但是外传中的角色人设均与动画差异极大，且有诸如狩云霄、残凶类的出场不太合理。

最大的问题在于，外传将凛雪鸦塑造成了缺乏底线、心理扭曲的纯恶人，他跟杀无生当了三年朋友，支持其参加剑道大赛，一度让杀无生产生了就此洗白名声、开道场过日子的想法，但凛雪鸦最终目的依然是彻彻底底毁掉杀无生的自尊和未来。

在剑道大赛，杀无生杀掉曾经的师父铁笛仙和一众高手，最后关头才醒悟被凛雪鸦算计，身负重伤仍突破重围，却无法手刃凛雪鸦，从此走上了更为极端的剑道。

这番剧情在发布后曾引发粉丝间强烈争议，刑亥外传小说里，凛雪鸦又是另一番表现，富有人情味，均对应不上原本人设。

据说虚渊玄本人读过《生死一剑》后，都觉得剧情很悲剧。

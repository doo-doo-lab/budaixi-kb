# Thunderbolt Fantasy 东离剑游纪

**东离剑游纪 · 霹雳 × 虚渊玄** · 2016 — 至今 · 收录 **51** 位角色

霹雳与日本编剧虚渊玄（Nitroplus / Type-Moon 系作家）合作的国际化布袋戏。
故事架构为虚渊玄、世界设定带有日式奇幻色彩，以"西幽"为虚构背景。
目前已推出三季正篇（2016 / 2018 / 2021）+ 剧场版《西幽玹歌》《生死一剑》。

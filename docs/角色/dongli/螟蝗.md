# 螟蝗

================================================================================

汉语词语螟蝗是汉语复合词，由螟虫与蝗虫两类农业害虫名称组合而成，读音为míng huáng。现代汉语词典将其定义为并列关系的双音节词，强调二者作为农业害物的共同属性。泛指对粮食作物具有显著破坏作用的鳞翅目与直翅目害虫。在古典文献如《吕氏春秋》中常以异序词“蝗螟”形式出现，在正史中被记载为介虫之孽或臝虫之孽。中文名螟蝗拼 音míng huáng注 音ㄇㄧㄥˊㄏㄨㄤˊ类 别汉语词语结构类型并列复合词出处典籍《吕氏春秋》词语属性农业术语近义词蝗螟

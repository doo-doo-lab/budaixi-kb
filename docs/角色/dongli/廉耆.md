# 廉耆

布袋戏《东离剑游纪》及其衍生作品中的角色廉耆是《东离剑游纪》中的人物，由黄汇峰（闽南语）、山路 和弘（日语）配音。

**中文名**：廉耆

**外文名**：れんき

**配音**：黄汇峰、山路和弘

**性别**：男

**登场作品**：东离剑游纪

**称号**：无人物设计三杜シノヴ（Shinovu Mimori）（Nitroplus）

## 角色设定

廉耆凛雪鸦的盟友，术法之器“回灵笛”的原主。柄也为蔑天骸所夺。

## 出场集数

初登场：东离剑游纪第4集退场：东离剑游纪第4

## 集交战记录

VS杀无生：败

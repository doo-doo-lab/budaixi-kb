# 廉耆

================================================================================

布袋戏《东离剑游纪》及其衍生作品中的角色廉耆是《东离剑游纪》中的人物，由黄汇峰（闽南语）、山路 和弘（日语）配音。中文名廉耆外文名れんき配 音黄汇峰、山路和弘性 别男登场作品东离剑游纪称 号无人物设计三杜シノヴ（Shinovu Mimori）（Nitroplus）

## 角色设定

廉耆凛雪鸦的盟友，术法之器「回灵笛」的原主。柄也为蔑天骸所夺。

## 出场集数

初登场：东离剑游纪第4集退场：东离剑游纪第4

## 集交战记录

VS杀无生：败

**廉耆**（レンキ）是《東離劍遊紀》中的角色。

- **配音員**: 山路和弘（日語）／黃滙峰（臺語）

兩鬢飛霜的老者。

因持有攻克迷宮所需的「迴靈笛」而受凜雪鴉請託，但半途卻遇上殺無生並被他殺害，身上的「迴靈笛」也被取走。
- **分類**: 東離劍遊紀角色

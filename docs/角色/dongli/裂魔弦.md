# 裂魔弦 (裂魔弦)
- **季度**: season4
================================================================================

Character
キャラクター

裂魔弦
レツマゲン

CV：小西克幸
キャラクターデザイン：三杜シノヴ(ニトロプラス)
浪巫謠が愛用する琵琶にして相棒の聆牙が、魔界の霊気で完全覚醒を遂げた姿。片目を覆う仮面にのみ楽器であった頃の名残が残る。手の甲から刀身を生み出して切り裂く、指先からは弦を伸ばして緊縛するなど、自らを武器と成して戦う。浪巫謠の魔力を浴びて生まれた存在であるため、その結びつきは血よりも濃い。

念白
「為友情，捨人性，兇殘何妨？化鬼神，奏殺曲，戰遍四方。」
友のためならば、人の道を外れた凶行に何の躊躇があろうか？　鬼神と化して死の曲を奏で、どこまでも戦い抜くのみだ。

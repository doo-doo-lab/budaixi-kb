# 东离剑游纪3

2021年黄强华执导的电视剧《东离剑游纪3》是由日本剧作家虚渊玄担任总编剧、黄强华执导，霹雳国际多媒体联合Nitroplus等公司制作的奇幻武侠布袋戏电视剧，于2021年4月3日在中国台湾和日本首播，共13集。该剧延续前作设定，讲述了殇不患携魔剑目录与同伴在魔界搜寻娄震戒及七杀天凌时，遭遇魔女刑亥与西幽邪教神蝗盟联手阻挠的冒险故事。作品延续泽野弘之负责音乐制作，主要配音包括鸟海浩辅、诹访部顺一等声优。剧情围绕洞窟奇景、魔神复活计划等元素展开，呈现角色在多方势力对抗中的命运纠葛。

# 天命（汉语词语）

================================================================================

订阅0有用+10天命是汉语词语，原指天道的意志，后衍生出自然规律、寿命定数及政权合法性依据等多重含义，最早见于《尚书·盘庚上》。其内涵包含三重维度：一为天道对人类命运的主宰；二指自然法则；三被引申为君主统治的理论依据。该概念萌芽于商周时期，甲骨卜辞已显雏形。《礼记·中庸》将其与人性论结合，提出“天命之谓性”。汉代后既用于解释个人寿命，也作为王朝构建合法性的理论基石。至宋明理学发展为“天命之性”的心性学说，融入传统伦理体系。中文名天命外文名Mandate of Heaven拼 音tiān mìng近义词定数 定命 天意反义词造化注 音ㄊㄧㄢ ㄇㄧㄥˋ出 处《书·盘庚上》释 义天道的意志，天道主宰众生命运别 名天魂

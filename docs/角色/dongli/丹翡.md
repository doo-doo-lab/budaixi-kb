# 丹翡（日本布袋戏《东离剑游纪》角色）

================================================================================

丹翡是日本奇幻武侠布袋戏《东离剑游纪》及其衍生作品中的虚构角色，由中原麻衣配音。作为世代守护圣剑“天刑剑”的护印师一族后裔，她性格认真固执且纯朴天真，职责是看守供奉天刑剑的锻剑祠。因玄鬼宗宗主蔑天骸夺剑灭族，她在兄长牺牲后与殇不患、凛雪鸦结盟，踏上夺回圣剑的旅程。途中多次以丹辉剑诀对抗敌人，并在牢狱中为救卷残云主动舍弃剑格，粉碎蔑天骸的野心。最终魔神复苏时，见证殇不患以劫荒剑完成封印，自身则继承守护新圣剑的使命。结局与卷残云成婚后，她重建锻剑祠，从恪守传统的护印师蜕变为肩负新责的守护者。

## 角色设定

代代相传的护印师一族后裔，负责看守祀奉着圣剑“天刑剑”的“锻剑祠”。自小便背负着传统及责任，因此自尊心高、相当认真固执，却也有不知人情世故、天真纯朴的一面。遭受觊觎天刑剑的蔑天骸所袭击， 因缘际会受到凛雪鸦与殇不患的帮助， 此后与他们一起踏上了旅途……丹翡

## 角色能力

总体评价实力强大的护印师，不过由于初登场时便遭遇更为强大的蔑天骸，故而为部分观众认为实力不足。

武学丹辉剑诀：锻剑祠丹家的家传剑术，剑式中蕴含有祓除、克魔的效用。

- 烈华诛夜护印师的基础剑技。
- 就算于夜晚及瘴气弥漫的不洁环境，也能释放出完全清净的剑气。
- 圣芒辟邪此招是用翠辉剑的灵力放出清净的剑气，对上不净的眷属可造成巨大损伤。
- 流阳陵日由“飞霞行月”所衍生出的大量饱和攻击。
- 可同时操作的剑气数量因修为而异，亦可说是护印师等级判断的依据。
- 驭彗灼虹将周身全部真气尽会于一式的必杀之剑。
- 既是最强、也是作为决定胜负的最后一招：只因为施展完此招后，会造成剑者严重的气空力竭的状态，无法再持续战斗。——但丹翡并未将这招用于决胜，而是击向周围作为掩护：对于重视传统、尊严的护印师而言，这是一个罕见的决定。

术法辟邪圣印属于护印师必修课的防御结界术，具有将不净的眷属阻隔在领域外的效力。

- 原本的作用是单独保护施术者，其缺点是使用时无法做出其他行为。
- 另外，为了扩大领域的效果范围，需要助手持有媒质（剧中为缎带）拉开范围。

操纵灵脉之术对灵脉做出祷告，达到穿梭至各个灵脉节点的效用。

- 所谓“灵脉”者，乃循环流转的大地力量所形成、如洪流一般的存在（剧中的案例之一为树龄极老的古树）。
- 自古以来寺院皆是沿灵脉而建造，丹翡、卷残云凭此迅速自魔脊山沿途抵达无垠寺。
- 值得一提的是，“操作灵脉”并非为护印师独有，死灵使同样能可施展。

咒言：（台语版）“敢问钧天，雷师之馗；

经巳至酉，龙途何在？” （日译版）“询问圣天雷公之式，路经太乙到达从魁的龙之路在何处？” 武器翠辉剑：用带有灵力的翠晶铁锻造而成的剑。

- 只允许护印师随身佩戴，在市面上极为罕见。
- 据传在收藏家之间会以令人难以想象的高价转手交易。

## 角色经历
逃亡本与兄长丹衡以及丹家众人守护着代代守护的的圣剑“天刑剑”，但被欲抢夺天刑剑的玄鬼宗攻击，丹家被破，不得已与兄长携封印天刑剑的剑格、剑柄逃出圣地。

但又遭到玄鬼宗的追杀，混战中，兄长丹衡为掩护丹翡逃走与玄鬼宗激战，为玄鬼宗宗主蔑天骸所杀。

丹翡跳崖逃脱，但依然遭到玄鬼宗追杀，重伤疲惫昏倒后，被途径的殇不患救下，并在凛雪鸦的策划下为向玄鬼宗前进，一同寻找能助自己的同伴。

同伴之行在凛雪鸦的策划下，一行人前往夜魔丛林寻找魔族的死灵师刑亥，虽极其反感厌恶刑亥，但由于顾全大局，依然强忍了下来。

在寻找刑亥的途中，使用了丹辉剑诀，展现出了不辱其身份的实力。

之后因回灵笛与杀无升的争斗中，直言愿帮卷残云迎战，认真固执的性格的显露无疑。

玄鬼宗之行在众人的陪同下，丹翡一行人经水路前往魔脊山，在水边与玄鬼宗激战，玄鬼宗猎魅在激战中被杀无生所杀.之后一行人进入魔脊山，一行人中除丹翡、卷残云外的人暗中设计使殇不患独自一人迎战前两道关卡。

使得殇不患愤而独自前行。

得知众人算计殇不患的真相后愤怒的离开前去追殇不患。

却遭到凛雪鸦的算计出卖与殇不患一起被玄鬼宗所擒。

之后殇不患破开牢笼独自一人前往欲夺回天刑剑，而丹翡被赶来的卷残云所救出，两人前往被殇不患告知的藏匿真正剑格的地方。

却遭到尾随而来的刑亥、狩云霄的攻击，卷残云也在和决裂的义兄的交手中被射伤眼睛。

丹翡遂抛出剑格，救走卷残云。

新的使命得到剑格剑柄的蔑天骸打开封印取走天刑剑，发现天刑剑下封印着魔神。

丝毫不在意的蔑天骸持天刑剑离开，与祠堂外的凛雪鸦激战后将天刑剑毁去。

强大的魔神自封印中苏醒，正当丹翡等人绝望时，殇不患展现真正的实力，持收集自西幽36柄邪、魔、圣剑之一的须弥天幻·劫荒剑施展了洪荒禁穹狱将不死不灭的魔神封印在了宇宙的彼端时空的狭缝之中，并留下须弥天幻·劫荒剑镇压裂缝。

之后丹翡与卷残云两人成亲，卷残云在第13集入赘丹家成为护印师，重建丹家“锻剑祠”，接受新的使命守护劫荒剑。

## 人际关系

殇不患殇不患（友人）：自称来自西幽的的神秘高手，手持木剑。

实际是为减少因神器而产生的战乱而安置从西幽收集的36柄神剑而踏上征程的超级强者。

重诺/重义的强者，是丹翡极其信任的同伴。

因一把雨伞的情义救下被玄鬼宗追杀的丹翡，从而引发全篇故事。

诗号：狂风骤雨催纸伞，游人浪迹步不休。

天地滂沱如何渡，蓑衣褪尽任浊流。

卷残云卷残云（丈夫）：狩云霄收的义弟，追被凛雪鸦所邀请的大哥而来，武器是长枪。

天真单纯，热血急躁的年青人。

对丹翡一见钟情，正努力博得与自己武艺相应的名声。

膜拜狩云霄，随后狩云霄亲口告知其是伪装的大侠，后与狩云霄决裂。

为了保护剑格而被狩云霄射瞎右眼。

在殇不患打倒魔神后，与丹翡成亲，重建丹家锻剑祠守护殇不患留下的封印。

诗号：人笑良图若华胥，吾志凌云意坚行。

不与浮荣竞朝夕，无憾黄沙染身时。

## 人物影响

在《东离剑游纪》手游中，丹翡定位为辅助型角色，技能可为队友持续恢复生命并免疫减气力效果，拥有“圣芒辟邪·护”、“兄妹情深”、“圣芒治愈”、“战无不怠”等秘术。丹翡攻击速度快、续航与能量回复能力强，在PVP及后期推图中具有重要作用。在游戏《东离剑游纪之生死一剑》中，其基础属性为攻击3、防御4、生命3、辅助5、控制0，站位为中排。此外，在角色视觉设计上，丹翡采用了萌化的大圆眼睛、肉嘟嘟脸蛋的日漫风格，以提高观众接受度。

**丹翡**（タンヒ）是《东离剑游纪》中的主要角色。操偶师：廖嘉升 

- **配音员**: 中原麻衣（日语）／邓玮德（台语）

- **诗号**: “膺怀丹心承天命，身负恩仇江湖行。裂弃柔丝绮罗绢，付尽情梦仗寒兵。”

称号“圣辉丹心”

因应第一女主角必须可爱的需求，她的眼睛比起一般的戏偶要来得大。

代代相传的护印师一族后裔，负责看守祀奉著圣剑“天刑剑”的“锻剑祠”，以及天刑剑的剑锷。

兵器为“翠辉剑”。

自小便背负着传统及责任，因此自尊心高、相当认真固执，却也有不知人情世故、天真纯朴的一面。

善使多种术法，例如能架起防止敌人进入的结界，或透过灵脉进行瞬间移动。

遭受觊觎天刑剑的蔑天骸所袭击， 因缘际会受到凛雪鸦与殇不患的帮助， 此后与他们一起踏上了旅途。

事件结束后与卷残云结为连理一同守护“劫荒剑”，严厉地指导他学习丹家剑诀。

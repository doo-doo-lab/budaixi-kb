# 邪剑仙（单机游戏《仙剑奇侠传三》人物）

================================================================================

订阅0有用+10邪剑仙，单机游戏《仙剑奇侠传三》角色之一。主线大BOSS（注：花楹结局线和紫萱结局线中为最终BOSS），为蜀山五长老的邪念所化。在人界中有较强的实力。曾经勾结霹雳堂堂主罗如烈祸害人界、假扮蜀山派掌门清微血洗蓬莱御剑堂、蜀山派无极阁前抢夺镇妖剑并同时杀害唐雪见和蜀山派掌门清微、重创景天致其濒死。最终被景天等人消灭。中文名邪剑仙别 名老邪、杂碎（重楼专用特称）饰 演刘家辉（电视剧《仙剑奇侠传三》）性 别男登场作品《仙剑奇侠传三》身 份蜀山五长老邪气所化邪灵特 长邪灵幻身种 族不明（降妖谱中被归为仙族）

## 角色设定

背景设定邪剑仙是蜀山五长老所有邪念的集合体。当年五长老偷偷修炼门中所禁仙术，将体内邪念排出，并将其封印入锁妖塔中，不料邪念却在锁妖塔中修炼成形，并趁混乱之机从锁妖塔中逃脱。它是六界之外的生命，没有实体，可以变化成为五长老中任何一位的样子，借以迷惑众人。因为它是邪念的化身，所以恶的欲望就成为它强大力量的源泉。邪剑仙---降妖谱邪剑仙真身---降妖谱邪灵是邪剑仙的本体，是由多种邪念混合仙气修炼而成的邪仙。它能够进入任何人体内，通过侵蚀人类的元神，破坏人类修为，还能激发出人类心中的为恶欲望，使心智受到它的控制，即使能够将它逐出体外，也无法挽救被附身者的生命。它没有固定的形态，可以自由的变幻和分解，只有攻击它的正体才能对它造成伤害。性格特点残忍奸诈，为达目的不择手段。为了报复蜀山五长老，并想成为天下的统治者，用尽各种心机提升自己的力量，培养势力。

## 主题诗词

求道难成抛俗念，锁妖塔中聚邪仙。神锋魔刃炉内锻，为祸天地乱人间。

## 角色关系

邪剑仙是蜀山五长老所有邪念的集合体，可以说，蜀山五长老是邪剑仙的本源。人物关系曾伪装成蜀山掌门清微血洗蓬莱派，并也蛊惑过徐长卿等弟子想利用他们达到目的。邪剑仙与霹雳堂副堂主罗如烈狼狈为奸，把霹雳堂弟子尽数妖魔化，使唐门衰亡。在景天等人从锁妖塔中取回镇妖剑凯旋而归时，邪剑仙夺走了镇妖剑同时杀害唐雪见和蜀山派掌门清微。邪剑仙在重楼出现时都会被吓退。在剑冢铸剑成功之后，邪剑仙将镇妖剑插进了景天的胸膛，杀了景天。邪剑仙赶往蜀山企图血洗蜀山派，利用剑冢所铸造邪剑再次攻击锁妖塔，却被蜀山四长老与长卿合力打断邪剑，邪剑仙受挫，四长老却也因此受伤。与景天等人交战不敌后控制受伤的蜀山四长老与景天、徐长卿、紫萱、龙葵（或唐雪见）等人战斗，但还是不敌，最后吸尽四长老修为变成邪灵完全体，景天等人一番苦战后将其消灭。（根据游戏数值来看，邪灵状态邪剑仙战斗力甚至远超普通状态重楼，只比魔尊状态重楼略差一点。）

## 主要剧情

当年蜀山五长老运用了被祖师禁用的蜀山密术，将自身的邪念从体内排出，封印入锁妖塔，令自身修为大进。但邪念竟然修成一体，趁蜀山派混乱之际破坏封印逃出。邪剑仙2D头像后邪剑仙记恨蜀山五长老，无时无刻不想着找到五长老报仇，但是他也很想知道当年蜀山五长老将邪念从体内排出的事情到底是怎么一回事。由于蜀山与蓬莱交厚，邪剑仙先行扰乱蓬莱，逼问蓬莱掌门商风子关于蜀山八十年前的旧事。由于其法力高深，商风子不能看出他并非真正的蜀山派掌门清微。正被逼问无奈之际，紫萱看出了邪剑仙的破绽，此时重楼出现，邪剑仙见事迹败露，又斗不过重楼，于是逃跑。随后，邪剑仙不甘失败，他再次化身清微掌门，并成功骗到了徐长卿并带上他上蜀山企图去迷惑蜀山弟子。结果紫萱带领景天等人赶到蜀山，邪剑仙的阴谋再次被阻止。邪剑仙把景天等人打成重伤后撤离。为了自己的实验，他和霹雳堂罗如烈合作，把霹雳堂弟子变成妖物，使其攻击力大大增强，令唐门日渐式微。邪剑仙觉得这些对付人来讲很强，但对付其他五界就不行了，于是打算夺取镇妖剑。当景天等人取回镇妖剑时，邪剑仙出现，并将拿着镇妖剑的雪见一击毙命，还杀死了清微掌门。因为雪见是神树化成，所以躯体是神界神物，所以邪剑仙偷走她的肉身准备合体。经过景天等人的努力，终于使雪见脱离鬼界，到冰风谷。在邪剑仙阴谋占用雪见肉身之前，雪见已还魂成功。怒火中烧的邪剑仙于景天等人初次正面交锋，本占据上风的他最终被赶来搭救景天等人的重楼再次吓退。邪剑仙恨阴谋未成，打算炼成一炳邪剑，来助自己报仇。景天等人来到剑冢，进入姜国原来的铸剑厅，正遇邪剑仙。邪剑仙为夺魔剑，使用姜国秘传毒药，将众人毒倒，夺取景天手中魔剑，然后将镇妖剑与魔剑同入铸剑炉，邪剑铸成。剑铸成之后，邪剑仙将镇妖剑插进了景天的胸膛，杀了景天以后前往蜀山。而景天，因雪见和龙葵其中一人跳炉被救活，并修复其中一把剑（这与游戏进程以及好感度等各方面有关，雪见跳炉则修复魔剑，龙葵跳炉则修复镇妖剑）。仙剑奇侠传游戏中邪剑仙图片邪剑仙正面对抗蜀山四长老以及徐长卿等人，在这过程中，景天等人御剑赶来。邪剑仙见此，于是发挥邪剑威力，将锁妖塔损坏，而四长老和长卿合成五灵法阵限制了邪剑仙的法力。邪剑仙与景天等人战斗，却被打败。战败之后，邪剑仙分出四个邪灵，侵入四长老身体，继续对抗景天等人，没想到还是败下阵。最后，邪剑仙真身出现，景天等人顽强抗争，邪剑仙不敌身死。

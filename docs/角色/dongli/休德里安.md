## 来自百度百科的补充

休德里安是魔宫次席贵族，表面效忠魔王且认同魔界现状，实则兼具智谋与冷酷特质。其能力远超其他贵族，既担任魔王核心参谋，又作为刽子手以无锋断头剑暗中肃清政敌 。

他明面以温和派姿态维持魔界稳定，暗地通过血腥清洗巩固统治地位。在魔界，休德里安被击败 。

这种矛盾性构建起其权力根基——以温和表象掩盖铁腕手段，成为魔界权力更迭的关键推手。

在《Thunderbolt Fantasy 东离剑游纪4》第10话“託された心”中，休德里安被击败 。

根据2024年12月6日发布的剧情信息，在《Thunderbolt Fantasy 东离剑游纪4》第10话中，休德里安在魔界被打倒，随后再次陷入沉睡的浪巫谣被悍狡袭击。

休德里安的形象被收录于官方周边产品《Thunderbolt Fantasy Project 缶バッジコレクション Vol.6 東離劍遊紀4》徽章收藏系列中，该系列共有22种，于2025年1月24日发布。

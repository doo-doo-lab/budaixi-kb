# 猎魅

================================================================================

动画《东离剑游纪》中的角色猎魅是《东离剑游纪》中的女性角色，玄鬼宗中的强者，同时也是蔑天骸的得力手下。其中文（闽南语）配音为郭馨雅，日文配音为户松遥，人物设计由源觉负责。猎魅对蔑天骸非常痴迷。作为蔑天骸的部下，曾带手下追杀殇不患，并为报残凶被杀伤害宗主名誉之仇而追杀殇不患。猎魅在与凋命围堵凛雪鸦一行的船时被杀无生所杀。

**中文名**：猎魅

**外文名**：りょうみ

**配音**：郭馨雅（闽南语）、户松遥（日语）

**性别**：女

**登场作品**：东离剑游纪人物设计源觉（Nitroplus）

**招式**：枯骨·碎腑

**武器**：魅月弧

## 角色背景

猎魅是玄鬼宗中的强者，同时也是蔑天骸的得力部下，对蔑天骸非常痴迷。其中文（闽南语）配音为郭馨雅，日文配音为户松遥，人物设计者为Nitro+社的源觉。

## 创作背景

猎魅的人物设计由Nitro+社的源觉负责。源觉在设计时花费了许多心思，例如其胸部服饰的设计。原稿中大腿髋关节部分本是裸露的，但在实际制作成人偶时用布遮盖了。源觉曾想将猎魅的眉毛设计为平安时代贵族流行的‘麻吕眉’，但因文化差异需额外说明而作罢。猎魅是源觉在该作品中负责的唯一女性角色，也是她最喜欢画的角色。

## 形象设定

猎魅的武器为魅月弧，招式名为枯骨·碎腑，并拥有标志性台词：“呵呵呵，好呀，就帮你画第二张，当做遗照。”据人物设计师源觉透露，猎魅的胸部服饰设计耗费了不少心思；其眉毛原设计为平安时代贵族流行的麻吕眉（まろ眉）。在人设原稿中，其大腿髋关节部分为部分裸露，但在实际制作成人偶后均用布料遮盖。源觉表示猎魅是她负责的唯一一名女性角色，也是她最喜欢画的角色。

## 经历
猎魅是玄鬼宗宗主蔑天骸的部下，对其非常痴迷，并曾为报同僚残凶被杀、损害宗主名誉之仇而带领手下追杀殇不患。最终，她与凋命一同围堵凛雪鸦一行时，被剑客杀无生所杀。

## 人物关系

猎魅是玄鬼宗中的强者，作为蔑天骸的得力手下，对蔑天骸非常痴迷，她为报残凶被杀伤害宗主名誉之仇追杀殇不患，并与凋命围堵凛雪鸦一行的船时被杀无生所杀。

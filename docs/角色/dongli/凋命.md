# 凋命

================================================================================

日本动漫《东离剑游纪》角色凋命是日本动漫《东离剑游纪》中的虚拟角色，来自玄鬼宗，是蔑天骸的部下。其日语配音为大川透，中文配音为黄汇峰，角色设计由Nitroplus的源覚负责。武器为“寒獠钩”。性格冷静，擅长局势分析，决不允许任何人让玄鬼宗蒙羞。起初认为殇不患仅是凛雪鸦的替身小丑，在殇不患展现出压倒性实力后仍执意挑战，最终不敌身亡。

## 角色设定

“别让他脱逃！给他见识侮辱玄鬼宗之下场！”凋命蔑天骸的部下。凋命（ちょうめい/チョウメイ）是玄鬼宗成员，武器为寒獠钩，人物设计由源覚（Nitroplus）负责。角色配音为黄汇峰（台语）和大川透（日语），个性冷静，擅长局势分析，不允许任何人让玄鬼宗蒙羞。

## 经历
凋命初登场于《东离剑游纪》。起初认为殇不患只是凛雪鸦拿来当替身的小丑，在殇不患表现出压倒性的实力后，仍选择挑战殇不患。凋命于第12话与殇不患的战斗中落败而亡。亦登场于剧场版《Thunderbolt Fantasy 生死一剑》。

## 人物关系

凋命是邪恶组织“玄鬼宗”的成员，直接听命于其首领蔑天骸。他最终在与殇不患的对决中落败身亡。首领：蔑天骸。对手：殇不患。

## 相关作品

凋命在《Thunderbolt Fantasy 东离剑游纪》中作为蔑天骸的部下登场，由大川透（日语）和黄汇峰（台语）配音。凋命也在《Thunderbolt Fantasy 生死一剑》中作为蔑天骸的部下登场，由大川透配音。

## 人物影响

凋命是《东离剑游纪》中的玄鬼宗强者，听命于蔑天骸，使用武器寒獠钩，人物设计由源覚负责。

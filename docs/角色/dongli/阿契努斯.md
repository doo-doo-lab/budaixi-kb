# 阿契努斯

阿契努斯，《Thunderbolt Fantasy 东离剑游纪最终章》中的角色。 作品于2025年2月21日公开上映，阿契努斯由梅原裕一郎配音。 在相关活动中，阿契努斯被列为冲官英雄之一。

## 角色背景

《Thunderbolt Fantasy 东离剑游纪 最终章》于2025年2月21日起在日本全国影院上映，阿契努斯由声优梅原裕一郎配音。

阿契努斯的衍生商品包括在《Thunderbolt Fantasy 东离剑游纪 最终章》Blu-ray和DVD的Nitro在线商店特典中，附有由“三杜シノヴ”绘制的“阿契努斯”迷你色纸（单色印刷），于2025年5月28日发售 ；此外还有商品“東離偶用配件-枯髏(阿契努斯煙斗)” 。在官方活动方面，阿契努斯于2026年的Pilifan活动中作为“冲官英雄”角色之一加入 。

在《Thunderbolt Fantasy 东离剑游纪 最终章》Blu-ray&DVD发售时，附带有“三杜シノヴ”描き下ろし「阿契努ス」ミニ色紙作为特典。 角色相关的“东离偶用配件-枯髏（阿契努斯烟斗）”曾开放预购。 在2026年霹雳粉丝活动中，阿契努斯作为冲官英雄之一出现。

# Thunderbolt Fantasy 东离剑游纪2

中国台湾，日本虚渊玄编剧的布袋戏电视剧《Thunderbolt Fantasy 东离剑游纪2》是霹雳国际多媒体、Nitroplus、Good Smile Company出品，大霹雳国际整合营销、Aniplex发行，由虚渊玄编剧，鸟海浩辅、诹访部顺一等主演的布袋戏电视剧，共13集，该剧于2018年10月1日由优酷独家播出。该剧讲述了流浪剑士殇不患携危险秘宝“魔剑目录”避难于东离，却遭仇敌“祸世螟蝗”及西幽异能刺客追击，危机之际，红莲之衣的谜样吟游诗人突现相助。

# 諦空 (谛空)
(百度百科无对应条目,Fandom 东离剑游纪角色分类收录)
================================================================================

**諦空**（テイクウ）俗名**婁震戒**，是《Thunderbolt Fantasy 東離劍遊紀2》中的角色。

==基本資訊==
為一苦行僧，練有氣功，雖不能幫人解毒，但能用氣功助入吸出毒素至自身再灌入陽氣而救治人。

==經歷==
初登場時，曾救助了伯陽候。

之後在廟中遇上蠍瓔珞，蠍瓔珞想殺他不成，反被他教訓，說她不了解自身的意義。其實他自身也一直在尋找自身的意義，但始終無法尋得，後來他在殤不患和浪巫謠的追擊下救了蠍瓔珞，並與他們兩個就意義展開對話，浪巫謠認為他十分危險因此想殺他，而為殤不患所阻。

之後他再次與蠍瓔珞在廟中對話，讓她了解真正的忠義之道，不應該拘於自身的表現和想獲得稱讚。如果真能這樣就不會再迷惘。

之後他在廟中獲得七殺天凌，反而認為自身找到了生存的意義--戰鬥掠奪開殺，殺死了蠍瓔珞，侍奉七殺天凌。

# 狩云霄

电视剧《东离剑游纪》中登场的虚拟人物霹雳布袋戏衍生剧《东离剑游纪》中登场的虚拟人物。以神射手身份闻名东离的侠客，兵器为弓箭。认卷残云为其义弟。为了攻克蔑天骸的城堡，受凛雪鸦邀请成为队伍一员……曾经受凛雪鸦之托杀害剑圣大赛半数以上参赛者，并在关键时刻暗算铁笛仙，使其被杀无生失手杀害，走之前射伤杀无生的腿，使其无法追击凛雪鸦。本人是一个利益之徒，锐眼穿杨只是行走江湖的招牌，追求个人利益最大化的伪大侠。

**狩云霄**（シュウンショウ）是《东离剑游纪》中的角色。

- **配音员**: 小山力也（日语）／黄汇峰（台语）

- **诗号**: “双目不能视物，只眼能望千里。凝吾眸光成箭，夺人不避之命。”

称号“锐眼穿杨（エイガンセンヨウ）”。

兵器为弓箭“银牙”。

侠名威震东离的独眼神射手，认卷残云为其义弟。 

为了攻克蔑天骸的城堡，受凛雪鸦邀请成为队伍一员。

表面上看似重情义，但实际上相当现实，为维护自己的利益及名声，在不为人知之处甚至可以背弃同伴。

认为真正的荣耀要用生命换取，而享有名誉却又还活着的人，绝对都和他一样有着不可告人的心机。

得知魔神将要苏醒，便威吓蔑天骸将天刑剑放回，却被身后的刑亥偷袭绞杀，尸体落入封印魔神的坑中。

# 狩云霄

================================================================================

电视剧《东离剑游纪》中登场的虚拟人物霹雳布袋戏衍生剧《东离剑游纪》中登场的虚拟人物。以神射手身分闻名东离的侠客，兵器为弓箭。认卷残云为其义弟。为了攻克蔑天骸的城堡，受凛雪鸦邀请成为队伍一员……曾经受凛雪鸦之托杀害剑圣大赛半数以上参赛者，并在关键时刻暗算铁笛仙，使其被杀无生失手杀害，走之前射伤杀无生的腿，使其无法追击凛雪鸦。本人是一个利益之徒，锐眼穿杨只是行走江湖的招牌，追求个人利益最大化的伪大侠。中文名狩云霄外文名しゅうんしょう别 名锐眼穿杨配 音黄汇峰、小山力也性 别男登场作品东离剑游纪

**狩雲霄**（シュウンショウ）是《東離劍遊紀》中的角色。

- **配音員**: 小山力也（日語）／黃滙峰（臺語）

- **詩號**: 「雙目不能視物，隻眼能望千里。凝吾眸光成箭，奪人不避之命。」

稱號「鋭眼穿楊（エイガンセンヨウ）」。

兵器為弓箭「銀牙」。

俠名威震東離的獨眼神射手，認捲殘雲為其義弟。 

為了攻克蔑天骸的城堡，受凜雪鴉邀請成為隊伍一員。

表面上看似重情義，但實際上相當現實，為維護自己的利益及名聲，在不為人知之處甚至可以背棄同伴。

認為真正的榮耀要用生命換取，而享有名譽卻又還活著的人，絕對都和他一樣有著不可告人的心機。

得知魔神將要甦醒，便威嚇蔑天骸將天刑劍放回，卻被身後的刑亥偷襲絞殺，屍體落入封印魔神的坑中。
- **分類**: 東離劍遊紀角色

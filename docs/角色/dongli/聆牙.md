# 聆牙

剧场版《西幽玹歌》及其衍生作品的角色聆牙是剧场版《Thunderbolt Fantasy西幽玹歌》及其衍生作品中的角色，为浪巫谣所爱用的魔性琵琶，由小西克幸配音。
它原为浪巫谣之母爱用的琵琶，被浪巫谣带出后相伴；长期沐浴在浪巫谣的言灵下发展出自我意识，可与人沟通，并常替不爱说话的浪巫谣交谈。
在特典广播剧CD等衍生作品中，聆牙出现，为异飘渺取别名“黑眼圈鬼”，并有周边商品如亚克力杯垫、橡胶挂饰和亚克力立牌。

**中文名**：聆牙

**配音**：小西克幸

## 人物关系

聆牙是浪巫谣所爱用的魔性琵琶，长期沐浴在浪巫谣充满魔力的言灵之下发展出自我意识并可与人沟通，并经常替不太爱说话的浪巫谣与其他人交谈沟通。

## 相关作品

在特典广播剧CD《Thunderbolt Fantasy 东离音游纪》中，聆牙由小西克幸配音。官方曾推出包含聆牙形象的周边商品，如浪巫谣与聆牙的亚克力杯垫、橡胶挂饰。官方在AnimeJapan 2024现场限量发售了“浪巫谣&聆牙”亚克力立牌。琵琶

**聆牙**（リョウガ）是《Thunderbolt Fantasy 东离剑游纪2》中的角色。

来自西幽，为浪巫谣所爱用的魔性琵琶。长期沐浴在浪巫谣充满魔力的言灵之下发展出自我意识并可与人沟通。
聆牙经常替不太爱说话的浪巫谣与其他人交谈沟通，有时会讲出浪巫谣不想讲的真心话，但也因为讲话太直有时会让浪巫谣不快而处罚他。
- **分类**: 东离剑游纪角色

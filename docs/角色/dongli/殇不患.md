# 殇不患

================================================================================

东离剑游纪系列作品中的虚拟人物殇不患是日本剧作家虚渊玄与霹雳布袋戏合作作品《Thunderbolt Fantasy Project》中的虚拟角色，日文名ショウフカン，别名刃无锋、啖剑太岁，由诹访部顺一、黄汇峰配音，角色设计为源觉，本尊雕偶师为洪剑山。

角色首次登场于《东离剑游纪》系列，在外传《生死一剑》中作为核心人物展开后传故事。

生日为9月23日，持有武器包括拙剑及封印三十六把神魔兵器的魔剑目录。

原为西幽流浪剑客的殇不患因携带魔剑目录辗转至东离，表面讽世嫉俗却重情重义。

他本是西幽皇族护卫，因目睹照君临的阴谋而携魔剑叛逃。

诗号“狂风骤雨催纸伞”象征其浪迹天涯的生存哲学。

在系列剧情中先后对抗蔑天骸七人同舟、玄鬼宗及西幽军队，并在《东离剑游纪3》使用苍黎剑击败照君临。

随着剧情发展，其未来人的身份在第四季被揭示，《最终章》揭开其伏笔，殇不患是睦天命和浪巫谣的儿子。

其最终目标是处理魔剑目录内的武器，拒绝使用它们对抗追兵。

殇不患以木剑注气为武学特色，战斗中曾使用魔剑目录中的灼晶剑、八阵断鬼刀等兵器。

人际关系涵盖盟友丹翡、凛雪鸦，敌对势力包括祸世螟蝗、七杀天凌。

## 经历
殇不患首次登场于《东离剑游纪》第一季，是一名来自西幽的流浪剑客，因凛雪鸦的计谋而被蔑天骸手下盯上，为帮助丹翡而踏上旅程。在电影《生死一剑》中，其篇章承接第一季之后、第二季之前的故事。在《东离剑游纪》第二季中，因持有魔剑目录而被仇敌祸世螟蝗得知消息，再次陷入危机，他与浪巫谣结伴护送魔剑目录，途中揭露其过去——曾为西幽皇族护卫，因目睹照君临的阴谋而携魔剑叛逃，最终在七罪塔与娄震戒、七杀天凌展开决战。在后续作品中，其身世被揭示为浪巫谣与睦天命所生。

原为仙镇城所收藏，在《东离剑游纪2》中受托保管并收入目录。

武学《东离剑游纪》部分剧照内功超凡，看似是使用剑术攻击，实则是向木剑中注入气劲以达到普通金属兵器的效果。

在拙剑离手时，也常常随手拾取木棍竹子等当做武器。

自称：“若注入沛足的气劲，连纸和布这类，都能够割裂皮肉、斩断人骨。”但使用木剑与真剑交锋并不轻松，相反是极耗体力的方式，这样做的原因是：“杀人这种事，困难是理所当然。”《东离剑游纪2》部分剧照《西幽玹歌》部分剧照东离剑游纪3部分剧照拙剑无式・八方气至（せっけんむしき・はっぽうきし）：在千钧一发避开敌方攻势的同时释出气力来打乱敌方架式。

尽管看似简单，但却是需要看透对手攻势的高难度招式。

拙剑无式・鬼神辟易（せっけんむしき・きしんへきえき）：精准刺中躯干经络、强制停止对手真气运行，藉此让对手无处运行的真气爆体而出的招式。

此招对擅于运气的对手有绝大功效。

拙剑无式・黄尘万丈（せっけんむしき・こうじんばんじょう）：若是将注入极致气劲的剑从手中放开，剑便会毫无轨迹可循地旋动。

然而，若剑上灌注的气劲乃是高手自己能巧妙驾驭的，他便能操纵剑运行的方向。

黄尘万丈此招，比起让剑能运行出复杂的轨迹，更着重在剑的力势，利用猛烈回旋的剑身所产生的风压，连飞来的箭矢都能够挡开。

拙剑无式・电掣星驰（セッケンムシキ・デンセイセイチ）：将气劲集中在下半身，瞬间逼近对方，全力突刺之招数。

此招式步法极为迅速，令出招者自身也暴露于危险之中，但此招式很适合当做决胜招式，以一招击中敌人后立即脱身。

殤不患（ショウフカン）是《東離劍遊紀》中的角色。因為發音近似，有因本觀眾稱之為「娼婦館」

- **操偶師**: 洪嘉章

- **配音員**: 諏訪部順一（日語）／黃滙峰（台語）

- **詩號**: 「狂風驟雨催紙傘，遊人浪跡步不休。天地滂沱如何渡，蓑衣褪盡任濁流。」

稱號「刃無鋒（ジンムホウ）」，是捲殘雲戲謔他武器無鋒而起的，此後便以此自稱。

謎樣的流浪劍客，常用兵器為木劍。

表現得一副諷世嫉俗的模樣，常以令人不悅的方式說話，但本性其實相當重義氣又有人情味。

因為凜雪鴉的計謀，而與玄鬼宗結仇，殺死了殘凶，為了幫助丹翡，不情願地與眾人一齊踏上旅途。

想法單純，害怕麻煩，面對問題習慣用最簡單直接的方式應對。

流浪的理由是因為身上藏有各式劍的「三十六劍・藏劍錄」被惡人覬覦，為了將藏劍放置到一個安全的地方而不斷流浪，結果不知不覺地來到東離。

所持武器只是一柄上了銀漆的木刀「拙劍」，連殺無生等高手都錯認為鈍鐵而輕視；但實際上帶有深厚精純的內力，即使用枯枝也能殺敵。

不以高強武功自持而隨意動武殺人，足見其自律及謙遜：如為凡人般自己擔心若是持有利劍會太容易殺人，但時時告誡自己卻又麻煩，於是乾脆配把難以使用的木刀，以此方式來約束自己。

魔神妖荼黎復甦後，以藏劍錄中的「須彌天幻·劫荒劍」一招「洪荒禁窮獄」將妖荼黎傳送到異空間禁閉。

由於空間閉合需要一百年的時間，於是將此劍交由身為護印師的丹翡守護。

故事最後為了尋找安全的地方放置「藏劍錄」中剩下的三十五劍而再度踏上旅程。

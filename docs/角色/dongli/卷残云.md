# 卷残云

================================================================================

霹雳布袋戏《东离剑游纪》中的主要角色卷残云是《东离剑游纪》系列中的青年角色，称号“寒赫”，人物设计由源覚（Nitroplus）负责。

使用长枪作为武器，擅长家传枪术“腾雷枪法”。

其日语配音由铃村健一担任。

卷残云性格天真单纯、热血急躁，专注于通过武艺获取名声。

作为狩云霄的义弟，因崇拜其武艺而追随加入讨伐魔神队伍。

在魔神讨伐行动中，因狩云霄为名利背叛团队而与之决裂。

在魔神苏醒的危机中，与丹翡共同经历生死考验，最终在魔神之祸平定后（2016年）与丹翡成婚并入赘丹家。

在第三季（2022年）中卷入凛雪鸦的计谋，误杀异飘渺后与殇不患共同斥责凛雪鸦的行径。

卷残云的角色诗号为“人笑良图若华胥， 吾志凌云意坚行； 不与浮荣竞朝夕， 无憾黄沙染身时”。

## 角色背景

卷残云是狩云霄的义弟，因崇拜其武艺而追随加入讨伐魔神队伍。他称号为“寒赫”。性格天真热血，专注于通过武艺获取名声，使用家传枪术"腾雷枪法"。在魔神讨伐行动中（2016年），因队伍分裂与狩云霄决裂。

## 形象设定

卷残云称号为“寒赫”，人物设计由源覚（Nitroplus）负责，日语配音由铃村健一担任。卷残云性格天真单纯、热血急躁，对丹翡一见钟情，并正努力博得与自己武艺相应的名声。其配枪为“腾雷”，枪法包括“疾风回旋”、“蛟龙盘云”和“赫雷撼天”，并修习“丹辉剑诀”剑法。其经典台词为“名震东离的无双大丈夫，人称寒赫之卷残云，***在此！”。角色诗号为“人笑良圖若華婿，吾誌淩雲意堅行；不與浮榮競朝夕，無憾黃沙染身時”（繁体）或“人笑良图若华胥，吾志凌云意坚行；不与浮荣竞朝夕，无憾黄沙染身时”（简体）。

## 角色经历
魔脊山战役（2016年）：卷残云是一位天真单纯、热血急躁的年轻人，正努力博得与自己武艺相应的名声。

他因崇拜狩云霄而跟随其成为义弟，并半强行地跟着被凛雪鸦所邀请的狩云霄而来。

在行动期间，面对强敌杀无生，卷残云曾打算独自与之作战，拼上性命以搏取扬名天下的机会，但此提议遭到团队众人的否决。

刑亥甚至提出可利用一种将死人血液化为硫酸并引爆的术法，让卷残云与杀无生同归于尽。

参与封印魔神的行动过程中，因狩云霄为名利背叛团队而与之决裂。

在魔神苏醒的危机中，与丹翡共同经历生死考验，最终平定魔神之祸后结为夫妻并入赘丹家。

七杀天凌事件（2022年）：第三季中被凛雪鸦易容假扮，遭七杀天凌操控误杀异飘渺。

事件结束后与殇不患共同谴责凛雪鸦的计谋。

**捲殘雲**（ケンサンウン）是《東離劍遊紀》中的角色。

- **配音員**: 鈴村健一（日語）／黃滙峰（臺語）

- **詩號**: 「人笑良圖若華胥，吾志凌雲意堅行。不與浮榮競朝夕，無憾黃沙染身時。」

自號「寒赫（カンカク）」。

兵器為長槍「騰雷槍」。

重傷後繼承兵器「穆輝劍」。

是年輕的武術家，對於「英雄」一詞抱有想像而跟隨狩雲霄，並自稱其義弟。

使槍高手。

正努力博得與自己武藝相應的名聲。

半強行地跟著被凜雪鴉所邀請的狩雲霄而來。

在得知狩雲霄的真面目後，一番掙扎之後決定與其決裂，之後遭其傷了右眼。

事件結束後入贅丹家，與丹翡共同守護「劫荒劍」。
- **分類**: 東離劍遊紀角色

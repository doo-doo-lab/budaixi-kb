# 阿尔贝卢法

================================================================================

东离剑游纪系列作品中的虚拟人物阿尔贝卢法，霹雳布袋戏与虚渊玄合作拍摄制作的系列作品“Thunderbolt Fantasy Project”中的虚拟人物，TV版《Thunderbolt Fantasy 东离剑游纪3》中首次登场。精通操控时间与空间的法术，可以自由往来魔界与人界、魔宫排名第八位的魔族。经常隐藏真实目的策划谋略的神秘人物。 其真实身份是浪巫谣的生父。

**中文名**：阿尔贝卢法

**外文名**：アジベルファ

**配音**：三木真一郎

**性别**：男

**登场作品**：东离剑游纪3

**角色编剧**：虚渊玄人物设计三杜シノヴ（Shinovu Mimori）

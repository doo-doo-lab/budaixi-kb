# 阿尔贝卢法

================================================================================

东离剑游纪系列作品中的虚拟人物阿尔贝卢法，霹雳布袋戏与虚渊玄合作拍摄制作的系列作品“Thunderbolt Fantasy Project”中的虚拟人物，TV版《Thunderbolt Fantasy 东离剑游纪3》中首次登场。精通操控时间与空间的法术，可以自由往来魔界与人界、魔宫排名第八位的魔族。经常隐藏真实目的策划谋略的神秘人物。 其真实身份是浪巫谣的生父。中文名阿尔贝卢法外文名アジベルファ配 音三木真一郎性 别男登场作品东离剑游纪3角色编剧虚渊玄人物设计三杜シノヴ（Shinovu Mimori）

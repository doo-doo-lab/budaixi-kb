# 七杀天凌（布袋戏《Thunderbolt Fantasy 东离剑游纪2》中的角色）

================================================================================

七杀天凌是布袋戏《Thunderbolt Fantasy 东离剑游纪2》中的角色，由悠木碧配音，为娄震戒所持有的一把寄宿着剑灵的魔剑。七杀天凌具有自我意识。其能力包括散发诡异光芒以魅惑人类，被魅惑者会以夺取魔剑为最优先目标。剑身可通过吸血夺取并储备魔力，持剑者能获得体力、招式威力等加成，但自我意识会逐渐崩塌，产生嗜血欲与幻觉。在剧情中，七杀天凌于第二季第二集登场，其魅惑能力连眼镜和幻惑香都难以防御。

**中文名**：七杀天凌

**别名**：天凌公主

**配音**：悠木碧

**性别**：女

**登场作品**：布袋戏《Thunderbolt Fantasy 东离剑游纪2》

## 角色形象

官方未设定其明确的人形姿态。其配音由悠木碧担任。天凌公主与天凌王子的剑身不大一样。都是黑红金配色的剑身，公主是细剑，王子是宽剑。原画负责smdrr，每次出现都会有些不同，在东离之中与红龙之中也不大一致。

## 角色能力

七杀天凌并非单纯的道具，它具有意识，比起剑更像是猛兽，或许更应该被称为魔物。七杀天凌通过散发诡异光芒，魅惑一切光芒入眼的人类，被魅惑者会以夺取七杀天凌为最优先目标，被激发出困兽般斗志。剑身砍中人后，可通过吸血夺取、储备魔力，效率极高，轻轻一划便可夺走三日精气，剑的魔力流入持剑者体内，可作为后备内力、治愈伤口以及分享嗜血欲。嗜血欲具有成瘾性，严重时会产生幻觉，即便离开七杀天凌，短时间内也无法消除。七杀天凌极其锋利，能穿透无视普通攻击的龙鳞。作为魔物，七杀天凌拥有完整的记忆，丰富的知识，充分的理性，以及语言能力，其邪恶的意志以杀光所有人类为目标。

## 角色经历
蝎璎珞从剑谱中取出天凌公主反派蝎璎珞抢走了男主殇不患所有的剑谱之中的两把魔剑。其中一把便是七杀天凌，蝎璎珞差点被天凌公主控制，扛住魅惑后用布条将天凌公主缠住藏在破庙之中……后来，这把剑被僧人娄震戒捡到并持有。

## 登场记录

其实东离第一季殇不患打开剑谱就能看到七杀天凌的名字和形象。2018年10月8日播出的《东离剑游纪2》第二集之中，正式再次登场，由悠木碧配音。

## 相关作品

七杀天凌登场于作品《Thunderbolt Fantasy 东离剑游纪2》。该作品于2018年10月1日开播，已完结，全13话。角色七杀天凌由悠木碧配音。

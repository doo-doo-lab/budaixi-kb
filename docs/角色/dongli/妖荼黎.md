# 东离剑游纪（奇幻武侠布袋戏偶电视剧集作品）

================================================================================

中国台湾、日本13 集订阅0有用+10《东离剑游纪》是由台湾霹雳国际多媒体股份有限公司、日本Nitro 、Good Smile Company合作制作，黄强华、王嘉祥执导，虚渊玄编剧的奇幻武侠布袋戏作品。该剧起源于虚渊玄2014年接触霹雳布袋戏后提出的合作构想，Nitro+负责角色设计，Good Smile Company担任人偶造型顾问。故事围绕“神诲魔械”最强兵器天刑剑展开，护印师丹翡为夺回被蔑天骸夺取的圣剑，与凛雪鸦、殇不患等同伴踏上征程。作品融合日式角色设计与传统布袋戏技艺，采用台湾声优先行配音、日本声优二次配音的双轨模式，主题曲由西川贵教演唱。台湾版首章于2016年7月8日随《霹雳狼烟之古原争霸》DVD发行，7月13日独立发行第1章，7月15日起每周五发行最新章，全13章；2017年3月25日-26日在东森电影台首播。日本版于2016年7月8日起每周五在TOKYO MX首播，中国大陆由bilibili独家正版发布。剧场版《生死一剑》于2017年12月在台湾、日本上映，续作《东离剑游纪2》《东离剑游纪3》分别于2018年10月、2021年4月播出。剧场版第2弹《西幽玹歌》2019年10月25日上映。第四季《东离剑游纪4》于2024年10月5日首播，系列完结篇《东离剑游纪 最终章》定档2025年2月21日。导演黄强华（总）、王嘉祥、郑保品（助）首播时间2016年7月8日中文名东离剑游纪外文名Thunderbolt Fantasy、東離劍遊紀主要演员鸟海浩辅诹访部顺一中原麻衣小山力也图集

# 蔑天骸

================================================================================

布袋戏剧《东离剑游纪》中的虚拟人物蔑天骸是霹雳布袋戏《东离剑游纪》中的虚拟角色，由黄汇峰（闽南语）和关智一（日语）配音。

作为玄鬼宗首领，其以天然要害环守的山城七罪塔为据点，精通剑术与死灵法术，能通过读取亡者记忆获取情报，被定位为剧中主要反派。

原为七罪塔护卫的蔑天骸，在塔内原主身亡后自立为首领。

为夺取丹氏兄妹守护的天刑剑，率部攻入丹氏圣地并将丹衡杀害，随后持续追杀逃亡的丹翡。

在与凛雪鸦、殇不患等人组建的对抗队伍周旋过程中，最终在七罪塔决战败于凛雪鸦的"天霜·烟月无痕"招式，折断天刑剑自尽身亡。

蔑天骸持有武器渎世与天刑剑，掌握役魔阵·万象尽灭等武学。

其诗号"万物之生，死亡之序，奉吾则功上枯骨，逆我则剑下亡魂，寒刃之前，唯此二道"集中体现了武力至上的信念，名言"世上只有剑，才能证明力量、才是不可动摇的至高真理所在之处"进一步凸显角色核心特质。

- **组织门派**: 玄鬼宗部署：残凶、猎魅、凋命、玄鬼宗众兵士其他：凛雪鸦（感兴趣的对象）发出便当：丹衡、杀无生

## 角色能力

武器渎世、天刑剑武学蔑天骸（べつ てんがい）称号：森罗枯役魔阵·万象尽灭：不仅将剑气，还将咒法与灵压同时放出的必杀技。即使防御住了剑气，寿命也会被削减，就连生命力本身都会被剥夺。役魔阵·暴乱黄泉：这招秘剑是以传说中的魔神为假想敌所创的。是役魔阵中最强的奥义，“没有人类能够凌驾于这招之上”正是这份确信给了蔑天骸绝对的自信。

**蔑天骸**（ベツテンガイ）是《东离剑游纪》中的角色。因发音相近而被观众称为“每天嗨”。

- **操偶师**: 廖嘉升

- **配音员**: 关智一（日语）／黄汇峰（台语）

- **诗号**: “万物之生，死亡之序，奉吾则功上枯骨，逆吾则剑下亡魂。寒刃之前，唯此二道。”

绰号“森罗枯骨（シンラココツ）”

武器为“渎世”

以天然要害环守的山城七罪塔为根据地的“玄鬼宗”首领。

高超、并具备有操纵死灵的法术，为故事中的强敌。

迷恋剑，认为剑是力量及区隔生与死之间所具现之物，并以此为真理，因此疯狂搜罗世间所有至强名剑，予以收藏。

为了满足自己的真理及收藏欲望，而夺取丹氏兄妹所守护的“天刑剑”，用尽一切手段攻入丹氏圣地。

被凛雪鸦击败后，难受屈辱而破坏天刑剑，要让魔神毁灭世界来给予凛雪鸦绝望。

最后被天刑剑的刀刃穿透身体而死，临死前仍嘲笑着凛雪鸦。
* **招式“役魔阵‧万象尽灭”**
- **分类**: 东离剑游纪角色

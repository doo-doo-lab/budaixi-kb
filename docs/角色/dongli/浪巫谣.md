# 浪巫谣

================================================================================

东离剑游纪系列作品中的虚拟人物浪巫谣是霹雳布袋戏与虚渊玄合作《Thunderbolt Fantasy Project》系列的核心虚拟人物，首次登场于剧场版《生死一剑》，后在《东离剑游纪2》《西幽玹歌》中担任主角，并于TV版《东离剑游纪3》继续作为主角之一登场。

别名"弦歌断邪""天籁吟者"（由西幽皇女嘲风亲授此号），由西川贵教配音，诗号"筋为弦，脉为鼓，息如笙歌；

以吾命，谱乐章，邪音不容"贯穿其核心特质。

出身西幽的浪巫谣自幼随母亲咒旬喑修炼歌唱与刀法，魔性嗓音引发诸多风波，故寡言少语，以魔性琵琶"聆牙"表达情感。

其绝对音感与武器"聆牙"在战斗中屡建奇功，身世揭示为魔界伯爵阿尔贝卢法之子，与殇不患、睦天命结为伙伴后，为追寻殇不患足迹曾穿越被诅咒的荒野"鬼殁之地"。

童年创伤导致其通过琵琶交流，性格从孤僻吟游诗人转变为团队核心战力。

浪巫谣的歌声与琵琶技艺成为串联多部作品的关键叙事符号，经历身世揭秘与情感纠葛后，完成从工具化存在到自我命运掌控者的蜕变。

**浪巫谣**（ロウフヨウ）是《Thunderbolt Fantasy 东离剑游纪2》中的角色。

==基本资讯==
来自西幽，背着一把会说话的琵琶聆牙，与殇不患是原搭档。沉默寡言，但聆牙刚好和他相反，非常多话，会使用琵琶的音波作武器。

==经历==

小时在雪山成长，由母亲咒旬喑(聆莫言)教导歌唱及武功，因日夜操顿加上变声成长，身为曾经在凤西宫生活成长的大小姐自然是不知男孩变声期，将变声的巫谣视为妖怪，追逐中发生意外，母亲跌落山谷而死

母亲死后，伤心之余收拾遗物带走聆牙，放一把火烧了全部，下山在一间酒楼吃食，没有钱，身无分文下

被店小二提出拿东西抵债，两人僵持不下拉扯之际，酒店老板提出唱的好就收留，一唱便一鸣惊人，也在酒楼生活卖唱长大成帅气的男子。 某天，过着如同死水日子的他在郊外夜晚散心，遇到一位美丽的女子-睦天命。

天命的歌声撼动了他的灵魂，使他打开封闭的心灵，两人至此相谈甚欢，在月亮绽放亮圆的夜晚，一同交流歌唱弹奏心得那期间感情也逐渐慢慢升华...

一段时日后，睦天命好心告知他早早离开酒楼才好，他起初不在意，后来啸狂娟带着官员抄店后才得知

酒店老板利用自己魔声歌喉，加上鸦片酒谋取暴利价格，促使酒客为了来店内听歌而犯罪，罪名是蛊惑人心

啸狂娟这时也和他做一个交易，只要成功就不用问罪，失败便是死。

之后参加了皇女-嘲风规划的残忍游戏，成功生还也取得一个称号“天赖吟者”

在皇宫生活的日子宛如死水过的很闷，从小到大段练的歌与武学，变成与别的乐师互相躲开刀剑杀戮的竞赛，使的他非常迷惘

某天，要争夺天赖吟者的挑战者出现，竟然是许久不见的-睦天命

他不解为何她要这么做，为何她要与自己拔刀相向，在一阵天昏地暗的歌唱比武对决后，睦天命知晓计划成功便逃跑了

处在原地的他被背叛什么都没搞清楚也跟着愤而追出去，在啖剑太岁和睦天命说明盗剑和看见南方景像后，无法融入人群的他直接回雪山上，

再也不想跟任何人扯上关系。

睦天命放心不下他，以过往谈天内容寻找判断，没多久便找到他的位置，睦天命对他提点虽然歌声有魔性，但将那些垂练成歌声的是拥有灵魂的自己

只要有灵魂，就有办法和人共生，说完便离去。

在睦天命的教诲指导和自己思考下，决定将不理世俗眼光，由自己眼耳判断是非，掌握自己的剑柄，将力量注入到聆牙内

爆出火焰与染了一身红莲造型，像只死去的凤凰在火里浴火重生。

横渡诅咒的荒野-鬼殁之地到东离，对于殇不患不告而别颇伤感。

见到殇不患后，协助他对付蝎璎珞，之后并和凛雪鸦一起为救殇不患的毒患而进入鬼殁之地，取得之后认为凛雪鸦的存在对殇不患不利而想杀他，但未能成功。

后来追杀受伤的蝎璎珞时，遇上谛空，与之后话时又直觉他很危险而想杀他，为殇不患所阻止。

后来对上手持七杀天凌，靠着过人的听力，闭着眼睛打败了对手。

因为拯救自己的大半人生，心里对睦天命抱有着爱慕之情，教导失明的她过生活，在螟蝗战争无力保护好她，造成悲剧而不断愧疚懊悔著，并不断寻找弥补方法。

# 浪巫谣

================================================================================

东离剑游纪系列作品中的虚拟人物浪巫谣是霹雳布袋戏与虚渊玄合作《Thunderbolt Fantasy Project》系列的核心虚拟人物，首次登场于剧场版《生死一剑》，后在《东离剑游纪2》《西幽玹歌》中担任主角，并于TV版《东离剑游纪3》继续作为主角之一登场。

别名"弦歌断邪""天籁吟者"（由西幽皇女嘲风亲授此号），由西川贵教配音，诗号"筋为弦，脉为鼓，息如笙歌；

以吾命，谱乐章，邪音不容"贯穿其核心特质。

出身西幽的浪巫谣自幼随母亲咒旬瘖修炼歌唱与刀法，魔性嗓音引发诸多风波，故寡言少语，以魔性琵琶"聆牙"表达情感。

其绝对音感与武器"聆牙"在战斗中屡建奇功，身世揭示为魔界伯爵阿尔贝卢法之子，与殇不患、睦天命结为伙伴后，为追寻殇不患足迹曾穿越被诅咒的荒野"鬼殁之地"。

童年创伤导致其通过琵琶交流，性格从孤僻吟游诗人转变为团队核心战力。

浪巫谣的歌声与琵琶技艺成为串联多部作品的关键叙事符号，经历身世揭秘与情感纠葛后，完成从工具化存在到自我命运掌控者的蜕变。

**浪巫謠**（ロウフヨウ）是《Thunderbolt Fantasy 東離劍遊紀2》中的角色。

==基本資訊==
來自西幽，背著一把會說話的琵琶聆牙，與殤不患是原搭檔。沉默寡言，但聆牙剛好和他相反，非常多話，會使用琵琶的音波作武器。

==經歷==

小時在雪山成長，由母親咒旬瘖(聆莫言)教導歌唱及武功，因日夜操頓加上變聲成長，身為曾經在鳳西宮生活成長的大小姐自然是不知男孩變聲期，將變聲的巫謠視為妖怪，追逐中發生意外，母親跌落山谷而死

母親死後，傷心之餘收拾遺物帶走聆牙，放一把火燒了全部，下山在一間酒樓吃食，沒有錢，身無分文下

被店小二提出拿東西抵債，兩人僵持不下拉扯之際，酒店老闆提出唱的好就收留，一唱便一鳴驚人，也在酒樓生活賣唱長大成帥氣的男子。 某天，過著如同死水日子的他在郊外夜晚散心，遇到一位美麗的女子-睦天命。

天命的歌聲撼動了他的靈魂，使他打開封閉的心靈，兩人至此相談甚歡，在月亮綻放亮圓的夜晚，一同交流歌唱彈奏心得那期間感情也逐漸慢慢昇華...

一段時日後，睦天命好心告知他早早離開酒樓才好，他起初不在意，後來嘯狂娟帶著官員抄店後才得知

酒店老闆利用自己魔聲歌喉，加上鴉片酒謀取暴利價格，促使酒客為了來店內聽歌而犯罪，罪名是蠱惑人心

嘯狂娟這時也和他做一個交易，只要成功就不用問罪，失敗便是死。

之後參加了皇女-嘲風規劃的殘忍遊戲，成功生還也取得一個稱號「天賴吟者」

在皇宮生活的日子宛如死水過的很悶，從小到大段練的歌與武學，變成與別的樂師互相躲開刀劍殺戮的競賽，使的他非常迷惘

某天，要爭奪天賴吟者的挑戰者出現，竟然是許久不見的-睦天命

他不解為何她要這麼做，為何她要與自己拔刀相向，在一陣天昏地暗的歌唱比武對決後，睦天命知曉計畫成功便逃跑了

處在原地的他被背叛什麼都沒搞清楚也跟著憤而追出去，在啖劍太歲和睦天命說明盜劍和看見南方景像後，無法融入人群的他直接回雪山上，

再也不想跟任何人扯上關係。

睦天命放心不下他，以過往談天內容尋找判斷，沒多久便找到他的位置，睦天命對他提點雖然歌聲有魔性，但將那些垂練成歌聲的是擁有靈魂的自己

只要有靈魂，就有辦法和人共生，說完便離去。

在睦天命的教誨指導和自己思考下，決定將不理世俗眼光，由自己眼耳判斷是非，掌握自己的劍柄，將力量注入到聆牙內

爆出火焰與染了一身紅蓮造型，像隻死去的鳳凰在火裡浴火重生。

橫渡詛咒的荒野-鬼歿之地到東離，對於殤不患不告而別頗傷感。

見到殤不患後，協助他對付蠍瓔珞，之後並和凜雪鴉一起為救殤不患的毒患而進入鬼歿之地，取得之後認為凜雪鴉的存在對殤不患不利而想殺他，但未能成功。

後來追殺受傷的蠍瓔珞時，遇上諦空，與之後話時又直覺他很危險而想殺他，為殤不患所阻止。

後來對上手持七殺天凌，靠著過人的聽力，閉著眼睛打敗了對手。

因為拯救自己的大半人生，心裡對睦天命抱有著愛慕之情，教導失明的她過生活，在螟蝗戰爭無力保護好她，造成悲劇而不斷愧疚懊悔著，並不斷尋找彌補方法。

後來追殺受傷的蠍瓔珞時，遇上諦空，與之後話時又直覺他很危險而想殺他，為殤不患所阻止。

後來對上手持七殺天凌，靠著過人的聽力，閉著眼睛打敗了對手。

因為拯救自己的大半人生，心裡對睦天命抱有著愛慕之情，教導失明的她過生活，在螟蝗戰爭無力保護好她，造成悲劇而不斷愧疚懊悔著，並不斷尋找彌補方法。

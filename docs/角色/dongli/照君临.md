# 照君临

================================================================================

霹雳布袋戏《东离剑游纪3》中登场的虚拟人物照君临是霹雳布袋戏衍生剧《东离剑游记3》中的虚拟角色，由悠木碧配音，角色设计由なまにくATK（Nitroplus）担任，登场于《东离剑游记3》。照君临出身魔界，是魔界第一术士，亦为泣宵·刑亥的姐姐，持有武器“倾天下”。大约200多年前，照君临混入西幽皇室成为宠妃，通过谗言诛杀忠良，引发诅咒导致西幽皇族频出暴君。被识破真身后遭圣剑击杀，灵魂依附于七杀天凌魔剑，后被殇不患封印。复活后与刑亥等开启魔界大门，最终被娄震戒刺穿并重新封入七杀天凌，随逢魔漏消失于时空缝隙。其诅咒影响贯穿西幽历史，灵魂依附与复活过程均围绕七杀天凌展开，最终在第三季被再度封印。

## 角色经历
来自魔界拥有倾国美貌的绝世美女。

泣宵·刑亥的亲姐姐，魔界第一术士。

在穹幕之战终结后约200多年前混入西幽，为了从内部扰乱人间暗中活动化身婢女卖艺。

利用其美貌成为了当时西幽皇帝的宠妃。

通过向夫君皇帝献上谗言，诛杀了许多勇将贤臣，使国家濒临奔溃，在其戏耍下所流出的鲜血与怨念都成了渗透凤曦宫（西幽皇宫）根基的诅咒，导致哪怕如今的西幽皇帝一脉中，仍出现痴迷于鲜血的暴君昏君。

但由于得意忘形疏忽大意而被识破，作为迷惑皇室的妖姬，被人算计踏入布有净化之力的结界中暴露了真身。

被护印师们围攻，遭受了圣剑的一击葬身大海。

然而，在她生前，凭借她在皇宫中准备的一道魔术（万一肉体毁灭，灵魂便会依附在沾染她鲜血的器物上）依附在刺杀她的圣剑上。

在妖姬·照君临从人们的记忆中淡化的150年后，作为魔剑“妖姬·七杀天凌”再度开始扰乱世界的活动。

但是，其过于张扬的活动引起了啖剑太岁·殇不患的注意，被其封印在魔剑目录之中。

另外，西幽灵皇族的血统由于受到了照君临的诅咒，国家之所以会因嗜血的暴君而混乱，正是因为还弥漫着浓厚的诅咒。

作为大妖术师在魔界似乎也有着备受瞩目的地位，以阿尔贝卢法为首，高位魔界贵族也备受厚待。

在刑亥的帮助下穿越时空来到过去。

使死后不久的肉体再生，再通过将七杀天凌中的灵魂转移到肉体上实现了复活。

但是，由于七杀天凌失去了其魅力的灵气，娄震戒非常激动，为了让他得到谅解而笼络，但一束手无策就将其抛弃至过去的世界。

回到现代后，在无界阁与刑亥、阿尔贝卢法打开魔界大门，准备对人界发起进攻。

万军破舍命阻拦不敌，被赶到的殇不患压制后使用妖术魅惑，却被孤注一掷使用灼晶剑的万军破协助阻拦，后找准时机找到了仅存的能在无界阁等各个时空中转移的道具逢魔漏。

在危急关头，熟练运用逢魔漏的凛雪鸦带着被照君临抛弃至过去时空的娄震戒赶到。

娄震戒为恢复七杀天凌的灵气，一剑刺穿照君临并将其重新封入七杀天凌中。

得到凛雪鸦分的逢魔漏后，娄震戒便与他的君王、公主——七杀天凌（照君临）一起消失在时空缝隙的彼岸。

（截止第三季结尾）

# 丹衡

霹雳布袋戏之《东离剑游纪》中的人物霹雳布袋戏之《东离剑游纪》虚拟人物。“森罗枯骨‧蔑天骸……在丹氏圣地，岂容你如此亵渎！”丹翡的哥哥，与妹妹同为护印师后裔。丹衡随身保管天刑剑剑柄、而丹翡保管剑锷。遭受蔑天骸袭击时陷入了苦战的穷途末路。

**中文名**：丹衡

**外文名**：たんこう、尼桑（道友爱称）

**身份**：护印师后裔

**配音**：平川大辅（日）设计者三杜シノヴ登场时间2016年保管物天刑剑剑柄妹 妹丹翡

## 角色设定

## 角色能力

武器穆辉剑武学丹辉剑诀·飞霞行月：丹衡的必杀技，运用气功驱使刀剑在空中自由飞旋。丹辉剑诀·流阳凌日：比飞霞行月更加饱和的攻击招式，也可以说能同时操纵数道气功，威力根据护印师的等级而定。

## 【补充来源:Fandom 布袋戏资料库】
- **来源**: https://palmardrama.fandom.com/zh/wiki/丹衡

**丹衡**（タンコウ）是《东离剑游纪》中的角色。

- **配音员**: 平川大辅（日语）／黄汇峰（台语）

丹翡的哥哥，与妹妹同为护印师后裔。

丹衡随身保管天刑剑剑柄、而丹翡保管剑锷。

武功高强，丹翡自认实力只有兄长的一半。

在玄鬼宗入侵圣地后，为了替妹妹断后而遭蔑天骸杀死。

在故事最后，其兵器“穆辉剑”被卷残云继承。

* **招式“丹辉剑诀‧飞霞行月”**
*: 丹衡的必杀技，运用气功驱使刀剑在空中自由飞旋。
* **招式“丹辉剑诀‧流阳凌日”**
*: 比飞霞行月更加饱和的攻击招式，也可以说能同时操纵数道气功，威力根据护印师的等级而定。

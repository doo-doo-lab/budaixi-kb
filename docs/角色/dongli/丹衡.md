# 丹衡

================================================================================

霹雳布袋戏之《东离剑游纪》中的人物霹雳布袋戏之《东离剑游纪》虚拟人物。“森罗枯骨‧蔑天骸……在丹氏圣地，岂容你如此亵渎！”丹翡的哥哥，与妹妹同为护印师后裔。丹衡随身保管天刑剑剑柄、而丹翡保管剑锷。遭受蔑天骸袭击时陷入了苦战的穷途末路。

**中文名**：丹衡

**外文名**：たんこう、尼桑（道友爱称）

**身份**：护印师后裔

**配音**：平川大辅（日）设计者三杜シノヴ登场时间2016年保管物天刑剑剑柄妹 妹丹翡

## 角色设定

名称：丹衡（たんこう）角色丹衡的设定图称号：无角色配音：黄汇峰（闽）、平川大辅（日）、角色设计：三杜シノヴ（Shinovu Mimori）（Nitroplus）初登场：东离剑游纪第1集退场：东离剑游纪第1集（死于蔑天骸）妹妹：丹翡根据地：丹家锻剑祠

## 角色能力

武器穆辉剑武学丹辉剑诀·飞霞行月：丹衡的必杀技，运用气功驱使刀剑在空中自由飞旋。丹辉剑诀·流阳凌日：比飞霞行月更加饱和的攻击招式，也可以说能同时操纵数道气功，威力根据护印师的等级而定。

## 交战记录

VS玄鬼宗成员：胜(击败多名追杀的士兵。)丹衡VS残凶：胜(与残凶对决时以丹辉剑诀·飞霞行月击败对方)VS蔑天骸：败（死于蔑天骸，天刑剑剑柄被夺）

**丹衡**（タンコウ）是《東離劍遊紀》中的角色。

- **配音員**: 平川大輔（日語）／黃滙峰（台語）

丹翡的哥哥，與妹妹同為護印師後裔。

丹衡隨身保管天刑劍劍柄、而丹翡保管劍鍔。

武功高強，丹翡自認實力只有兄長的一半。

在玄鬼宗入侵聖地後，為了替妹妹斷後而遭蔑天骸殺死。

在故事最後，其兵器「穆輝劍」被捲殘雲繼承。

* **招式「丹輝劍訣‧飛霞行月」**
*: 丹衡的必殺技，運用氣功驅使刀劍在空中自由飛旋。
* **招式「丹輝劍訣‧流陽凌日」**
*: 比飛霞行月更加飽和的攻擊招式，也可以說能同時操縱數道氣功，威力根據護印師的等級而定。
- **分類**: 東離劍遊紀角色

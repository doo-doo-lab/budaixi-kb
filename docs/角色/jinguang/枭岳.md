# 枭岳

金光布袋戏虚拟人物古辰雅彦（其父金敖所取本名），别名枭岳（自称更满意此名），金光布袋戏虚拟人物。半妖血统，父亲为妖族金敖（古辰雅久），初登场于《金光御九界之魆妖纪》第21集，归属东瀛、妖界、苗疆多地域。枭岳因阴阳师迫害导致神智癫狂化身山神，后被安倍博雅等人解救恢复真身。因怨恨父亲离家投靠胧三郎，凭借读心术与变形能力成为妖族战将。酒吞童子战败后，不愿退隐，随剑无极赴中原后拜师岳灵休习得金仙大罗掌，因白比丘暗算丧失读心异能，现已加入苗疆阵营。

## 人际关系

师徒亲友父亲：金敖（古辰雅久）朋友：安倍博雅、剑无极、岳灵休、步清云老大：黑白郎君（与安倍博雅被黑白郎君教训后，看到黑白郎君就叫老大）师傅：岳灵休（传授武艺，因为妖族身份，年纪大过岳灵休很多，称呼其为岳仔）朋友：叉猡（金光御九界之齐神箓第03集对话）妖族主战派上司：胧三郎（酒吞童子）同僚：木魅、红翎、薄寒君人族同伙：柴田道末、望月咲、

## 上杉恒矢角色设计

酒吞童子几个主要妖族部下的名字与能力依照金木水火土五行属性进行取名：金（金敖）、木（木魅）、水（薄寒君）、火（红翎）、土（枭岳）

## 角色经历

金敖之子，原名“枭岳”，后金敖以“古辰雅久”之名隐居东瀛，所以将其取名“古辰雅彦”，但他依然以枭岳自居。

多年前，阴阳师利用术法控制枭岳，逼迫金敖将魔之甲重铸为八刀八剑，才放枭岳回到金敖身边，然而因为身中术法，枭岳失去一只手臂，同时神智疯癫，时常出现在蒙陀山上，被称为“山神”。

后来因为一次机缘巧合，枭岳无意间以自身异能变换成雪山银燕的模样。

因为雪山银燕也曾因为元邪皇而失去一条手臂，所以枭岳被剑无极误认为是雪山银燕，悉心照料。

而安倍博雅和出云能火也在寻找恢复其神智的方法。

期间安倍博雅发现枭岳的真正身份，而找金敖对质，金敖承认他的确不是雪山银燕，而安倍和出云也用术法将其回复 。

在回复神智后，枭岳打伤了安倍博雅，又因为父亲曾对其生母不忠，心怀怨恨，离家出走。

适逢酒吞童子转世胧三郎在东瀛征战天下，枭岳为创出一番事业，而投靠麾下，展现其读心术和变换异能，从而被胧三郎收编。

其父金敖（古辰雅久）不希望其走上这条不归路，于是假意重回酒吞麾下。

经过一连串事件后，酒吞童子战败，古辰父子全身而退。

金敖（古辰雅久）希望枭岳（古辰雅彦）随他退隐，但枭岳却希望去看一看这江湖，于是同剑无极、安倍博雅前往中原。

在中原之行中，结识岳灵休，并得其指点，开始修炼。

其读心能力，因遭白比丘暗算已无法使用。

在学会岳灵休的招式“金仙大罗掌”之后，又勤加练习武功，终于实力大增，击败殷若微。

后来找到殷若微尸体时，却发现殷若微早已被人用乱棍打死，死状骇人，吓得当场呕吐。

## 对战记录

与剑无极等人前往中原途中，在船上被黑白郎君整治。配合俏如来等人在尚同会迎战阎王鬼途，因提醒众人而被偷袭，幸得岳灵休相助。与药神鸩罂粟被神志不清的安倍博雅攻击，第一次使用岳灵休所传授的武学：金仙大罗掌。绝命司战败后，追杀殷若微，以岳灵休传授的金仙大罗掌，击败殷若微。在《金光御九界之齐神箛》第29集中，于天允山风云之巅对战任孤沉，使用招式“荒神拳·破天关”，与风逍遥、忆无心、铁骕求衣等人配合攻击，但最终不敌任孤沉。

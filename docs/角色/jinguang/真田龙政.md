# 真田龙政

霹雳布袋戏经典虚拟人物东瀛望族真田一族之主，家族拥有雄厚的资本。才德兼具，稳重深沉，温文尔雅，足智多谋，关怀众生。官拜太宰，长谋善政。为弭平东瀛乱象而支持岩堂大一统，扫荡鬼祭将军势力，曾远渡重洋至中土取回金龙文召，以正天皇之实名。

**身份**：背景真田龙政乃是东瀛第一智者，官拜太宰，才德兼具，对天皇存着绝对忠诚，于霹雳雷霆第14集登场，但仅出现短短四集，直到时隔多年后的霹雳神州方又再度现身。角色经历雷霆时期真田龙政乃是东瀛望族之后，在多场内战中均选择明哲保身，但私下对鬼祭将军嚣张跋扈压制天皇的做法不满已久，趁着素还真与莫召奴刻意诈败让伪造的金龙文诏回归东瀛本土时，说服岩堂将军起兵反抗鬼祭政权，打出改革五代天皇的萎靡，开创新的朝政为口号。真田龙政为对付兵力强大许多的鬼祭政权，真田龙政同时从刀劈怒江等武魁神迹，调查出神遗一族的所在位置以维护天皇血统拜托，借由族中长老的斡旋顺利请得武魁·神无月出山，改名为军神·源武藏，协助击溃鬼祭军，同时真田龙政在战场上活用兵法制造津平大撤退的沙场奇迹，摧毁鬼祭军主力，建立岩堂幕府。为建立岩堂幕府的正当性，真田龙政率领当年被他解除冰封的中原女子九千宵及八魂刀前往中原向莫召奴讨回真正的金龙文诏，并留下八魂刀斩草除根将赤鬼、夜卫两名鬼祭将领斩杀，也向九千宵表示她已报答完恩情，放她归乡，独自一人回转中原。神州时期回到东瀛的真田龙政为保鬼祭专政的事件不会重演，跟源武藏一文一武架空了岩堂将军的权力，所以岩堂将军装作忠臣模样不断向天皇进谗，诬赖真田龙政跟源武藏，将自己包装成同样被架空权利的受害者，因而获得天皇的绝对信赖，更借由天皇命令真田龙政策划开疆大纪侵略中土，所以才有夜摩市潜伏中原搜罗武经神兵的布局。而在军神败北于跟一页书的八山柱之战时，岩堂将军说动天皇罢免真田龙政太宰一职，但真田龙政早料到他有此一著，不但在派军前往中原时故意将岩堂旧部京极鬼彦调去中原，使岩堂将军无法轻易掌握神风营，更早从三个月前便由犬若丸手中借取夜狐百赦瓦解，同时用上调虎离山之计利用自己的行踪吸引岩堂将军，令他无法在京都阻止其他朝臣在天皇面前替自己缓颊。由于军神战败被天皇解职，真田龙政遂转与拳皇·长宗我部神权合作，用国家需要恶人的理由说服他，表示要将他推上权力巅峰，成为神风营大将，并唆使他杀入神风营击毙伊藤源二立威，但在实际上却让他背上一条罪名为伏笔，使他日后无法轻易进入朝堂。同时暗中有合作关系的良峰贞义也顺利被岩堂将军网罗为麾下。所以在决定继任的神风营大将时，岩堂将军接受良峰贞义提议推出剑圣·柳生剑影，双方以决战，岩堂将军为确保不失，让罗观大僧正率众偷袭六道轮回，结果反中拳皇陷阱，罗观大僧正遭长曾我部神权击毙惨死。但拳皇与柳生剑影为大将宝座决战时，表面保持平手，但实际上却无法完全接下万神劫第二式，据剑圣所言拳皇若全力防守能挡下第三式，但仍无法印证万神劫的第四式，所以剑圣在战中弃战，擅自离去，此战被无限期押后。真田龙政而在决斗当日，岩堂将军莫名收到一封书信，上面是真田龙政冒其书法，写着自愿把权位交由良峰贞义等内容，而插画中军神所留的气功同时发出，当场把岩堂将军打成瘫痪重伤，这封手信也被天皇当成其遗愿，同意晋升良峰贞义代理岩堂将军的职权。长曾我部神权于战后惊觉，此战结果根本是真田龙政与良峰贞义所设计，真田龙政也不吝啬告知拳皇计谋真相，同时以放任拳皇统一武道作为安抚，尽管拳皇放话将会有反噬的一日，但真田龙政也接下拳皇一击，展现不俗

**武功**：更大方表示出有杀虎之能，不惧拳皇半分。登场记录一、东瀛第一次的内战：诸侯不满鬼祭将军而遭到血腥镇压。鬼祭将军为证明自己代替天皇领导东瀛的正当性，需要请出文诏。莫召奴窃文诏出走，导致各诸侯更有借口反抗鬼祭将军。真田太宰帮助反抗诸侯中最有力的岩堂，以求尽早结束内战。二、军神跟真田龙政如何结识：真田太宰为对抗鬼祭势大军，寻找不败传说的武魁。借由昔日卖刀小童的描述画出刀劈怒江图，乃寻得武魁。得知或推测出神遗族与天皇的关系，说动族中长老同意帮助推翻鬼祭政权。神遗族决定由族中最精英的源武藏出战。源武藏轻取三十七场战役，斩首三万，创下军神无敌神话。三、莫召奴跟真田的关系：莫召奴是绝对和平主义。真田太宰相对倾向务实跟东瀛。为了维系东瀛的安定，真田太宰是可以勉强接受移祸中原的手段。所以两人虽然可以互相了解，但立场并不完全一致。致于“良峰贞义最适合领导东瀛”一辞，未曾闻也。四、真田跟岩堂及鬼祭的关系：谁能实现东瀛的安定，真田太宰就支持谁。所以岩堂及鬼祭都不视其为自己人。真田太宰也从未真正将自己完全投入哪方。五、东瀛的势力分布：绝对不容侵犯的天皇势：已经被彻底架空了许多代并持续被架空中。一度合法代替天皇行使领导东瀛权力的鬼祭势：因领导出问题，被“敌在本能寺”。孤臣遗子藏身的落日故乡被无敌神话完全拆除。将遗产鬼之瞳典当给莫召奴请来的“百万大军”，从此跟太阳之海无缘。挥别东瀛，现正藏身海外小岛。推翻鬼祭势的岩堂势：狼将被外派中原战场远离权力核心，最后战死异乡。岩堂太政大臣，打开军神的死亡书法，亡。政权移交良峰贞义。
阪良城：城主良峰贞义病死，由其妹良峰秀泷假扮，现已接收岩堂势政权。真田势：当主真田龙政虽被降级，仍是身处权力核心。继鬼祭之后，岩堂也被其以谋除去。今，或与阪良的恶魔观雪与月；或坐着大轿巡视。曾经是东瀛菁英集中的神风营：在源武藏解除神风营大将一职后，失去领导，任人欺负中。神遗族：取得天皇血脉后，已解决早夭问题。六、天皇误认岩堂及白狐国对他有救命之恩：因为表面上把天皇从鬼祭将军的不敬中解救出来的，仍还是岩堂。白狐国应该是数代前赐下的夜狐百赦，从未有何救命之恩。七、莫召奴通缉犯

# 真田龍政 (真田龙政)
================================================================================

真田龍政

霹靂布袋戲經典虛擬人物東瀛望族真田一族之主，家族擁有雄厚的資本。才德兼具，穩重深沉，溫文爾雅，足智多謀，關懷眾生。官拜太宰，長謀善政。為弭平東瀛亂象而支持岩堂大一統，掃蕩鬼祭將軍勢力，曾遠渡重洋至中土取回金龍文召，以正天皇之實名。

安定，真田太宰就支持誰。所以岩堂及鬼祭都不視其為自己人。真田太宰也從未真正將自己完全投入哪方。五、東瀛的勢力分布：絕對不容侵犯的天皇勢：已經被徹底架空了許多代並持續被架空中。一度合法代替天皇行使領導東瀛權力的鬼祭勢：因領導出問題，被“敵在本能寺”。孤臣遺子藏身的落日故鄉被無敵神話完全拆除。將遺產鬼之瞳典當給莫召奴請來的“百萬大軍”，從此跟太陽之海無緣。揮別東瀛，現正藏身海外小島。推翻鬼祭勢的岩堂勢：狼將被外派中原戰場遠離權力核心，最後戰死異鄉。岩堂太政大臣，打開軍神的死亡書法，亡。政權移交良峰貞義。
阪良城：城主良峰貞義病死，由其妹良峰秀瀧假扮，現已接收岩堂勢政權。真田勢：當主真田龍政雖被降級，仍是身處權力核心。繼鬼祭之後，岩堂也被其以謀除去。今，或與阪良的惡魔觀雪與月；或坐著大轎巡視。曾經是東瀛菁英集中的神風營：在源武藏解除神風營大將一職後，失去領導，任人欺負中。神遺族：取得天皇血脈後，已解決早夭問題。六、天皇誤認岩堂及白狐國對他有救命之恩：因為表面上把天皇從鬼祭將軍的不敬中解救出來的，仍還是岩堂。白狐國應該是數代前賜下的夜狐百赦，從未有何救命之恩。七、莫召奴通緝犯身份未被撤銷：莫召奴是因竊取文詔而遭鬼祭將軍通緝。但此行為並非與岩堂合謀。鬼祭勢潰後，莫召奴也並未作出任何支持岩堂勢的行為。故而雖不在積極追捕，但亦不需刻意平反。角色歌曲◎真田龍政（真田龍政角色曲）曲/編曲：阿輪 收錄於《霹靂英雄音樂精選十五》作者用法國號吹奏出真田龍政完美布局的序曲，弦樂層疊出權勢謀略環環相扣窒息氣氛，配器中音提琴急促拉出緊張的氣氛，三味線輕撥點出東瀛風味，偶而穿梭笛音高亢，詮釋絕代智者真田龍政，城府至深、行事沉穩，帶領東瀛侵略中原正道的神秘風範。

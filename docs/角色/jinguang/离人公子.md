# 离人公子

霹雳布袋戏虚拟人物离人公子，霹雳布袋戏虚拟人物。隐居极北之处，浮舟流川尽头，烟航归处的主人。举止高雅，谈吐清冷，喜爱恬静，有着银红眸与月牙耳，不知从何方而来的恶魔。性情孤僻，行事随心而定，对人性洞察透彻，总是一副事不关己，看透尘世的模样。拥有掌控记忆的奇能，人们为记忆真相前来，凡勾起离人公子的兴趣，并通过考验者，便能一诉祈愿，签订契约，随着秉烛指引，进入心海，探看自身过往经历的事实。随着剧情演出，揭露其身份为前任沅海玄渊的共主，恶魔真名“零之北溟”，如今寻得故人线索，前往异域镜界。

# 非凡公子

霹雳布袋戏 经典虚拟人物。身具三教主与魔族的正邪血统，造就非凡公子亦正亦邪的特殊性格。聪明、自负，以初生之犊不畏虎的气势及傲人的智慧武功，居于猜心园中运筹帷幄。之后因刚愎自用，行事尖锐而树敌众多落难流离。尔后因负有五方主星之“北玄武”的身份而东山再起。

## 角色经历

非凡公子为报养父七色龙之仇，追杀杀父仇人，黑流派首领神鹤佐木（普生大师）而渡海来到中土，自此在猜心园里运筹帷幄。

甫一出场，就令天残武祖闻风丧胆，与素还真斗智，以神秘、高深之姿首领各方势力组成黑道大联盟与素还真、和修会形成鼎足之势，打击素还真之势力；

由于目中无人的性格和极其狠毒的手段导致得罪很多武林正道，最终被擒拿囚于菩提学院。

直至三教之子的下落在武林风波大起，在素还真的牵引下，非凡公子脚底的五芒星揭示了其三教之主的身份，在素还真的推波助澜下创立霹雳王朝登上王座。

在任期间，对外多次派兵征伐魔域，对内则对三教采取高压分化政策，终导致了王朝颠灭，非凡势落被其母魔魁之女所救。

后非凡公子及魔魁之女又被玉天玑及血道天宫宫主潇湘子的追杀，魔魁之女亡，非凡公子在回东瀛的海上突遭海盗强袭给去势，漂流在荒岛上被海上浮尸（欧阳上智）所救，后非凡以破世阴字再现江湖入主无极殿，表面上辅佐金小开，自己则重建猜心园，决策在手。

后来找到外祖父魔魁的下落，为帮助其复活四处奔波，在东瀛与魔界之间非凡公子选择追随祖父，换血成为魔族的一分子，也因此惹上其师权门宗矩并中东瀛独门之毒，魔魁为救非凡公子广招天下医者，命在旦夕之时靠着富贵乞丐花爵百炼生（素还真）的千里悬丝诊脉而解除毒患，其与魔魁祖孙间不弃不离的感情令人动容。

之后龙阁梭罗复辟玄都，建立龙马帝国入主魔域，在万钧势的围杀下魔魁下落不明，非凡公子被抓依旧誓死追随祖父，后因万钧势也感染了透体鬼火之症，斩海只好破除天魔录封印，寻求天魔医治之道，却造成天魔录封印众魔现身武林，自此魔界风波不断。

直至五方星主与七星传说沸腾整个武林，白无垢在追击其师九鬿老进入竹林中遇上玄武石像，后非凡公子以北玄武的身份再现江湖。

为让天魔救出被非善类绑走的魔魁，非凡公子答应白无垢之请托辅佐天魔，天魔和魔魁一战中魔魁落败，非凡公子和魔魁居于天魔麾下力扶魔界进逼中原，智斗素还真、莫召奴等人。

而后为报指魔被杀之仇，与莫召奴在心筑情巢决战导致两败俱伤，得素还真以中麒麟川之力而复原。

在天魔闭关后，魔界遭魔剑道各个击破危如累卵；

魔魁死后，非凡公子以调查凶手为条件，和素还真等手联手对抗天策真龙，为了不让天策真龙获得五方地气，非凡公子前往猜心园欲毁地气之时天策真龙来到，武力不敌被断去一臂，最终趁隙跳上玄武石像，一毁地气爆体身亡。

比较初登场时的刚愎自用与毒辣手段，经历颠沛流离后的非凡公子，除了狂傲，更是多了一份谨慎与稳重。

与亡命之花的主仆之情和魔魁的祖孙之情至今令人深刻难忘。

## 角色语录

1、思故国：水流花谢两无情，送尽东风过楚城，蝴蝶梦中家万里，杜鹃枝上月三更；故园书动经年绝，华发春摧两鬓生，自是不归归便是，五湖烟景有谁争。

2、葡萄美酒夜光杯，欲饮琵琶马上催，醉卧沙场君莫笑，古来征战几人回。

3、被禁于菩提学院之感叹：江北秋阴一半开，晓云含雨却低回，青山缭绕疑无路，忽见千帆隐映来。

4、河进已无擎雨盖，菊残犹有傲霜枝，一年好景君须记，最是橙黄橘绿时。

5、子生而母危，镪积而盗窥，何喜非忧也；贫可以节用，病可以保身，何忧非喜也。故达人当顺逆一视，而欣戚两忘。

6、感伤诗：时难年荒事业空，弟兄羁旅各西东，田园寥落干戈后，骨肉流离道路中；吊影分为千里雁，碎根散作九秋蓬，共看明月应垂泪，一夜乡心五处同。

7、吊非常女：坠雨已辞云，流水难归消，遗恨几时休，心抵秋莲苦，忍泪不能歌，试托哀弦语，弦语愿相逢，知有相逢否。（霹雳英雄榜22）

8、论行走武林禁忌：气忌全盛，人忌全满，才忌全露。

9、忧魔魁锋芒太露而欲劝阻所吟之古训：能柔能刚，其国弥光，能弱能强，其国弥彰；纯柔纯弱，其国必削；纯刚纯强，其国必亡。

10、收七诀迷阵口诀：七诀运化，天罗旋转，缠绵乾坤，锁仙伏魔。

11、战神秘剑客旁白：将才战高手，魔气斗剑光。

12、评论秦始皇：行仁道者未必能治世；治世者方能行仁道。

13、登高壮观天地间，大江茫茫去不返；黄云万里动风色，白波九道流云山。

14、世路如冥，风波肆恶；人情若梦，矛盾相残。

15、语天残武祖：居逆境中，周身皆针砭药石，砥节励行而不觉；处顺境内，满前尽兵刃戈矛，销膏靡骨而不知。

16、语白无垢：风霜之威，天之杀物，正以成物也，祸患之降，天之困人，正以成人也。

17、驾凌玄武九天翔，智谋非凡名声扬，尘世浊浪不沾足，心倾竹音识长才。

18、会莫召奴：一双冷眼看世人，满腔热血酬知己，恨我相见今犹迟，湘江倾盖缔兰芝。

19、语半缘君雄鸡和蛤蟆不同之处：蛤蟆日夜鸣而人厌之，雄鸡一鸣而天下振动。

20、战天策真龙旁白：手扬吞天玄武风，怒啸破世狂龙暴，力卷风云万里泣，气震山河千丈波。

21、吊非凡：一生傲骨，绝世非凡，历经无数苦劫的三教之子，却也逃不过命运无情的捉弄。今日所留的是悲风，还是风悲呢。

23、语天残武祖：人有礼则安，无礼则危。

24、处世之道：害人之心不可有，防人之心不可无，此戒疏于虑也；宁受人之欺，毋逆人之诈，此警惕于察也。二语并存，精明而浑厚矣。

25、处世之道：处治世宜方，处乱世宜圆，处叔季之世，当方圆并用；待善人宜宽，待恶人宜严，待庸众之人，当宽严互存。

## 角色评价

非凡公子，集傲然于一身，生平数度大起大落，纵然挫折不断，仍斩不断他的雄心壮志，他是英雄，更是枭雄。

甫一出场，即以神秘、高深之姿首领各方势力组成黑道大联盟以打击素还真的势力；其勇气与作风令人敬佩，更令人刮目相看。

直至三教之子一事，在素还真的推波助澜下登上王座，创立霹雳王朝。在任期间，不断用计打压三教，并且趁机削弱三教与魔界等势力，以便能够完全掌控，其智慧与野心在此又是独树一格。

王朝颠灭，非凡势落，欧阳上智伸出援手，非凡以破世阴字再现江湖，重建猜心园，入主无极殿，表面上辅佐金小开，但是决策在手，金小开除了自身任性，亦奈他何？

魔魁再现，非凡选择追随祖父，不断用计助魔魁夺得霸业，打击正道、覆灭金魔、正式统治当时的魔界，直至魔魁还原兽形，其与魔魁祖孙间不弃不离的感情令人动容。

天魔录现世，魔界风波不断，五方星主纷纷出笼，非凡挟玄武之力再现江湖，掌控继白无垢之后的魔界所有计划，智斗素还真、莫召奴等人之际，更是力扶魔界，再现武林的他除了狂傲，历经风霜的他更是多了一份谨慎与稳重。

天策真龙为祸武林，非凡公子为毁地气自爆而亡。即使身死身灭，但是傲骨的北玄武，依旧以非凡之姿活在每个人的心中。

## 附注说明

注1：诗文典出清代诗人通州诗丐《绝命诗》：赋性生来是野流，手执竹杖过通州；饭篮向晓迎残月，歌板临风唱晚秋。两脚踏翻尘世浪，一肩担起古今愁；而今不爱嗟来食，村犬何须吠未休？

注2：非凡公子为其外祖父魔魁为了颠复三教，而利用魔魁之女取得三教元祖（圣夫子、老佛、道尊）的精元孕化而成，故而非凡公子之亲生父亲可被认为是圣夫子、老佛、道尊三人；但在之后三教的攻势下，魔魁于荒龙道受三教及七重冥王的围杀而亡，魔魁之女趁乱逃至东瀛，被伊贺派首领七色龙所救，并下嫁七色龙，又因此来说，七色龙成为非凡公子的养父。

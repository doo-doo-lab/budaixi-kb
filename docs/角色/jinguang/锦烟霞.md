# 锦烟霞

================================================================================

金光布袋戏虚拟人物锦烟霞，金光布袋戏虚拟人物，别称白练飞踪、白蛟，配音黄立纲。女性魔族，属蛟龙血脉，2014年7月16日登场于《天地风云录之魔戮血战》，退场于《墨邪录》第8集。身为魔世帝女精国王室遗脉，因遭青奚宣背叛被法海封印于金雷村百余年，破除封印后与转世者一步禅空、欲星移再续前缘。其破除封印时，魔门世家宗家门主以击杀凶兽雾饕取心口鳞为条件提供救援。经历一步禅空牺牲自身镇守龙涎口后释怀，最终为阻止元邪皇破坏龙脉施展萨埵十二恶皆空身亡。锦烟霞身负古岳剑法·残雪封桥等武学，持伞柄所制古箫。角色经历与《蛟腾兮怨狂》《镇龙涎兮别离怅》等配乐关联，诗号“三千白发三千恨”映照命运轨迹，由编剧季电与雕偶师萧佟兴共同塑造。中文名锦烟霞别 名白练飞踪、白蛟、凶神、白娘子、白娘娘、锦妈妈配 音黄立纲性 别女登场作品天地风云录之魔戮血战金光御九界之墨武侠锋金光御九界之墨世佛劫登场作品金光御九界之墨邪录生 日2014年7月16日年 龄百年之上编 剧季电种 族魔族血 脉蛟龙归 属祖籍魔世 生长于中原雕偶师萧佟兴

## 角色经历

蛟族遗孤，被镇压在金雷村长达百年的凶神，由於经过背叛的过往，破封之後个性已趋极端，原本想摧毁金雷村，却因常欣的善良与俏如来的劝说而罢手，却又受到族人早已绝迹的打击，开始以屠杀僧侣作为活下去的动力，岂料先後遇见一步禅空、欲星移，竟因此重启百年前的因果。在一步禅空牺牲自我封印龙涎口，逐渐解开心结，最终为守护一步禅空所重视之天门，对抗地门。为守护青奚宣所出生之海境，牺牲自我引爆龙涎口，对抗元邪皇。为阻邪皇再进一步攻入海境，锦烟霞引爆龙涎口，欲用龙涎口水流的冲击力结合自身蛟龙御水天赋，结合一步禅空的功力所使出的萨埵十二恶皆空，与元邪皇同归于尽。绵延百里的超强水流猛冲而出，金雷村的方圆百里尽是魔兵的尸骸。然而此举并未能成功击杀元邪皇，锦烟霞不幸牺牲。

## 相关作品

锦烟霞在《金光布袋戏》系列中登场于《墨武侠锋》。在《墨邪录》中，有经典台词“你能牺牲别人，不能牺牲自己？”。在《墨世佛劫》中，有“锦烟霞退场又复出”的剧情记录。

## 侠锋封底拓展阅读

金光布袋戏，实际通称为黄俊雄布袋戏。金光布袋戏由黄俊雄，西卿，黄凤仪（长女）和黄立纲（幼子）共同经营；黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。以声音道具等奇关变景吸引观众的表演形态，被称之为“金光戏”，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，后于1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的“金光戏变革”，故把自己旗下的布袋戏事业，称为金光布袋戏。如今经营公司的是黄立纲的天地多媒体。主要剧集《千禧版云州大儒侠》至《金光御九界之战血天道》。金光布袋戏，黑白龙狼传，天地风云录之决战时刻，天地风云录之九龙变，天地风云录之剑影魔踪，天地风云录之魔戮血战，金光御九界之墨武侠锋，金光御九界之墨世佛劫，金光御九界之墨邪录，金光御九界之东皇战影，金光御九界之魆妖纪，金光御九界之鬼途奇行录，金光御九界之齐神箓，金光御九界之战血天道

# 忘今焉

================================================================================

金光布袋戏虚拟人物金光布袋戏虚拟人物。隐居于月凝湾的神秘老者，甫登场便为身陷两难困境的苍越孤鸣剖析局势，以引导思考的方式，对苍狼给予适当的指导，后帮助苍越孤鸣夺回苗疆王位，被封苗疆国师，深受其的尊崇。其真实身份是九算之一，忘今焉精谋略，善算计，智慧通达，修为教养不落凡俗，乃是九算中的最长者。只可惜狼子野心，手段狠毒，在道域布局夺权，杀害一百六十六名学童，面对利益时，对同为九算的玄之玄亦下杀手，导致众叛亲离。后在赤羽信之介和苍越孤鸣布下的狼王爪之局中，被风月二人联手诛杀，终结了其罪恶的一生。中文名忘今焉别 名琅函天配 音黄立纲性 别男登场作品天地风云录之魔戮血战登场作品金光御九界之墨武侠锋身 份(前)苗疆国师、墨家九算·老大登场日期2014-01-29退场日期2015-04-01出场集数63集

## 人物经历

掀起道域大乱，与玉千城、荻花题叶等在道域造成一连串血案。因和钜子理念不同，墨家九算九人曾联手对抗钜子默苍离，被墨家钜子揭破阴谋，结果最终九算四死二重伤惨败而远遁苗疆。密谋让风花雪月四人分裂。于月凝湾乘竹筏飘然而来。忘今焉官方桌布助苍越孤鸣取得解药。教苍越孤鸣面对当前局势的计策。陪伴苍越孤鸣签订三境盟约。假意提供赤羽黑瞳名单，实则与玄之玄联手算计了赤羽和俏如来二人。为洗清过往罪恶，与俏如来合作，嫁祸玄之玄，却反被俏如来将军，利用雪早已布下的咒命七罡字脱身。为谋夺狼王爪以增加对付苍越孤鸣的筹码，上千雪孤峰，反被算计，被早已守候在此的风与月联手杀死。

## 墨武战韬

兵者，国之爪也。兵法运用，皆在棋上。正邪黑白要分明，其子纵横布满坪。试问何来先一著，回首慕然纵云清。正与邪之分，何为正，何为邪，正，乃行之善。邪，乃行之恶。何谓非邪亦正，何谓非正亦邪，非邪亦正，行不为恶，非正亦邪，行不为善。善与恶之别，何为善，何为恶，何谓行善，何谓行恶。善，行之处世圆融，谈有理之言，乐有道之举，以有理之言，有道之举，行有义之事,不求代价，不求回报，只求心足意满矣，意谓行善。恶，行之霸道横野，喜无理之言，乐无道之举，以无理无道之行为，而乱无义之事，只问代价，只待回报，欲心不足贪矣，意谓行恶。

## 相关配乐

1、终南捷算 - 忘今焉角色曲　◎作曲：Lawrence Yeh收录于《魔戮血战原声带一》迷离幽微的前奏，带出之后细密的管弦合奏。主旋律中充满细碎的各式敲击、弹拨，间或穿插遥远的唢呐，令人联想起剧中忘今焉隐居之处——湖面波光粼粼、周遭却充斥瘴毒的月凝湾，也让人不禁好奇他隐居在此的目的。2、乃九算，谁云真-九算场景曲◎编曲：Matt Smith收录于《魔戮血战剧集原声带二》温润弹拨的乐器，清脆的敲击叮当，仿佛缓缓运行的钟表，赋予全曲充满岁月感的开头。其后的胡琴悠悠而奏，肩负起全曲主要旋律，则更增添了古往今来，人世几度沧桑的说书韵味。此曲不仅摩写出尚贤宫年岁久远的气息，也传达了墨家隐世千年的神秘色彩。3、务非命兮墨乱 -九算气势曲◎编曲：Kenneth Yang收录于《墨武侠锋剧集原声带》迅捷强劲的鼓声，带着恢弘的铜管出场，挑起全曲的大梁。胡琴，笛声与琵琶交替出现，营造出典型的中国风。声势浩大、层次丰富的主旋律，则表现出南征北讨的气势。本曲的风格，和1986年港剧《秦始皇》的同名主题曲和配乐略有异曲同工之妙。

## 相关扩展

金光布袋戏，实际通称为黄俊雄布袋戏。金光布袋戏由黄俊雄，西卿，黄凤仪(长女)和黄立纲(幼子)共同经营；黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。以声音道具等奇关变景吸引观众的表演形态，被称之为「金光戏」，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，後於1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的「金光戏变革」，故把自己旗下的布袋戏事业，称为金光布袋戏。主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。金光布袋戏，黑白龙狼传，天地风云录之决战时刻，天地风云录之九龙变，天地风云录之剑影魔踪，天地风云录之魔戮血战，金光御九界之墨武侠锋，金光御九界之墨世佛劫，金光御九界之墨邪录

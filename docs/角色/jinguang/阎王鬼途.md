# 阎王鬼途

金光布袋戏虚拟势力阎王鬼途是金光布袋戏虚拟势力。由绝命司、恪命司在内的阎途十部众所操控的秘密组织。阎王鬼途为秘密组织，主要活动在苗疆、中原境内，根据地为十殿阴曹。组织目的为研究长生不老药（亡命水），垄断药物流通等。在与中苗混战中，阎途十部众连番折损，绝命司夺舍安倍博雅肉身后，意识遭胧三郎击杀，肉身死于剑无极，阎王翎被毁，阎王鬼途至此覆灭！中文名阎王鬼途所在地中原登场作品金光布袋戏

## 角色背景

组织历史鬼谷一脉师承玄微子，玄微子有徒名唤徐福，徐福为助始帝得长生药，带三千童男童女远渡东瀛，他明白此生再难踏上中原故土，所以在离开前预先为徐氏后人做好安排，数百年后，中原群雄并起，后人徐氏曾以谋士出山，一鸣惊人，无奈时势所逼，终是化明为暗，成立了一个秘密组织，表面是为救其病母，但背后的实际目的无人可知，这便是阎王鬼途的前生，这个组织经历过数度的覆灭和复生，终成了现今的阎王鬼途。

注：徐氏曾以谋士出山，这个徐氏谋士很有可能就是三国时期的徐庶首先：救其病母，和徐庶与其母亲的故事几乎如出一辙二：徐庶本名徐福三：《胡氏世说》：灵山东北海中有鼓子洋。

岛上有白耐冬花，大可拱把。

好事者泛海致之，遇老人驾小舟至，芒履道服，貌甚古。

问：“小子何往？”以实对。

叱曰：“此非世俗间物，可留伴耐冬人耳。”又云：“即墨有道学先生胡峄阳，为吾通一问讯。”言已不见。

其人惊疑，遂反登筏。

大风忽起，弃其所获乃已。

后访胡峄阳，具道其事。

胡怃然曰：此三国时徐庶也，隐居鼓子洋久矣。

根据《胡氏世说》这一段所记载，其内容性质和阎王鬼途追求长生不老药有某种程度的相关。

## 人物关系

组织人员首领：绝命司（徐福及其受其记忆影响转化的其他人的新人格）、恪命司历届恪命司：幽冥君（卧底）、鸩罂粟（卧底且已经脱离）注：阎王翎是徐福记忆意识的载体，受其影响因载体本身记忆和天赋的不同新衍生的人格亦有所不同。

记忆载体对所附身之人的肉身有一定的要求，玄冥和钓烟波都曾表示为其奉献成为下一任的绝命司，但是被绝命司本人回绝，称“体质不符”*（阎王翎的特点是药物瓦解记忆，蛊毒重塑人格，术法维持徐福的主导权，所以理论上只要大脑完好就可以成为绝命司载体，但是因为会融入载体的记忆与人格，更多是出于对玄冥、钓烟波奴性的鄙视称其体质不符）。

其他：白比丘（徐福的另一个意识体，已死）

## 角色配乐

组织配乐◎阎王开途（阎王鬼途情境曲）管风琴响奏，沉闷的鼓点与低音BASS凝重的开场，迅疾跳跃的弦乐有如晃动的搏浪鼓，密林中，魈毒童子稚颜上满是阴鸷，遍地行尸随着鼓声缓缓前行，声声童笑回荡其中，彷若骇人地狱图重现。

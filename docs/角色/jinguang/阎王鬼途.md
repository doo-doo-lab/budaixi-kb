# 阎王鬼途

================================================================================

金光布袋戏虚拟势力阎王鬼途是金光布袋戏虚拟势力。由绝命司、恪命司在内的阎途十部众所操控的秘密组织。阎王鬼途为秘密组织，主要活动在苗疆、中原境内，根据地为十殿阴曹。组织目的为研究长生不老药（亡命水），垄断药物流通等。在与中苗混战中，阎途十部众连番折损，绝命司夺舍安倍博雅肉身后，意识遭胧三郎击杀，肉身死于剑无极，阎王翎被毁，阎王鬼途至此覆灭！中文名阎王鬼途所在地中原登场作品金光布袋戏

組織歷史鬼谷一脈師承玄微子，玄微子有徒名喚徐福，徐福為助始帝得長生藥，帶三千童男童女遠渡東瀛，他明白此生再難踏上中原故土，所以在離開前預先為徐氏後人做好安排，數百年後，中原群雄並起，後人徐氏曾以謀士出山，一鳴驚人，無奈時勢所逼，終是化明為暗，成立了一個秘密組織，表面是為救其病母，但背後的實際目的無人可知，這便是閻王鬼途的前生，這個組織經歷過數度的覆滅和復生，終成了現今的閻王鬼途。

註：徐氏曾以謀士出山，這個徐氏謀士很有可能就是三國時期的徐庶首先：救其病母，和徐庶與其母親的故事幾乎如出一轍二：徐庶本名徐福三：《胡氏世說》：靈山東北海中有鼓子洋。

島上有白耐冬花，大可拱把。

好事者泛海致之，遇老人駕小舟至，芒履道服，貌甚古。

問：“小子何往？”以實對。

叱曰：“此非世俗間物，可留伴耐冬人耳。”又云：“即墨有道學先生胡嶧陽，為吾通一問訊。”言已不見。

其人驚疑，遂反登筏。

大風忽起，棄其所獲乃已。

後訪胡嶧陽，具道其事。

胡憮然曰：此三國時徐庶也，隱居鼓子洋久矣。

根據《胡氏世說》這一段所記載，其內容性質和閻王鬼途追求長生不老藥有某種程度的相關。

組織人員首領：絕命司（徐福及其受其記憶影響轉化的其他人的新人格）、恪命司歷屆恪命司：幽冥君（臥底）、鴆罌粟（臥底且已經脫離）註：閻王翎是徐福記憶意識的載體，受其影響因載體本身記憶和天賦的不同新衍生的人格亦有所不同。

記憶載體對所附身之人的肉身有一定的要求，玄冥和釣煙波都曾表示為其奉獻成為下一任的絕命司，但是被絕命司本人回絕，稱“體質不符”*（閻王翎的特點是藥物瓦解記憶，蠱毒重塑人格，術法維持徐福的主導權，所以理論上只要大腦完好就可以成為絕命司載體，但是因為會融入載體的記憶與人格，更多是出於對玄冥、釣煙波奴性的鄙視稱其體質不符）。

其他：白比丘（徐福的另一個意識體，已死）組織配樂◎閻王開途（閻王鬼途情境曲）管風琴響奏，沉悶的鼓點與低音BASS凝重的開場，迅疾跳躍的弦樂有如晃動的搏浪鼓，密林中，魈毒童子稚顏上滿是陰鷙，遍地行屍隨著鼓聲緩緩前行，聲聲童笑迴蕩其中，彷若駭人地獄圖重現。

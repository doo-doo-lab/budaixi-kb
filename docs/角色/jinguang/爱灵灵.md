# 爱灵灵（金光布袋戏《黑白龙狼传》及其衍生作品中的角色）

爱灵灵是金光布袋戏《黑白龙狼传》及其衍生作品中的虚拟角色，由黄立纲配音。作为灵界之主灵尊泣幽冥之孙女，她兼具灵界小师妹与西剑流成员双重身份，初登场于《黑白龙狼传》第10集，后活跃于《决战时刻》《九龙变》等剧情中。性格天真烂漫、活泼外向却不通世事，是灵界中出了名的惹祸精，始终保有纯净善心。因对内心挣扎的月牙岚产生兴趣，她主动接近并试图感化对方，两人情感纠葛贯穿多部作品。在梁皇无忌协助下，她曾与月牙岚退隐东瀛并育有一子月牙诚，但灵尊之死使其深受打击。为挽回月牙岚性命，爱灵灵最终牺牲自我，其人生轨迹展现了纯真与残酷世界的激烈碰撞，成为作品中命运跌宕的典型角色。

## 官方简介

灵界的惹祸精，灵尊孙女，个性天真浪漫，活泼外向，但不通世事，保有一颗纯净的善良之心。

在接触人界时，对身受内心痛苦折磨的月牙岚产生兴趣，不断主动接近对方，试图感化具有善良本性的月牙岚。——（决战时刻：英雄扉页）灵界之主，灵尊泣幽冥之孙，心地善良，天真无邪，坚信人性本善，在与月牙岚接触后，决心感化月牙岚，两人互相影响，不料月牙岚却因她而亡，对此十分自责。——（决战时刻：桌布）灵界之主，灵尊泣幽冥之孙，心地善良，天真无邪，坚信人性本善，在与月牙岚接触后，决心感化月牙岚，两人互相影响，不料月牙岚却因此被西剑流赐死，使爱灵灵十分自责。——（决战时刻：甲子名人帖）灵尊孙女，天真烂漫并纠缠着月牙岚，而后因月牙岚之死而牺牲自己换回对方。——（金光风云录）灵界之主，灵尊泣幽冥之孙，心地善良，天真无邪，坚信人性本善，在与月牙岚接触后，决心感化月牙岚，两人互相影响，不料月牙岚却因她而亡，对此十分自责。

在西剑流之战结束后，于梁皇无忌的帮助下与月牙岚回东瀛退隐。——（金光群侠传）【精灵巧慧】灵界之主灵尊的孙女，父母于之前的灵界大战里身亡。

个性天真烂漫，活泼外向，思考跳跃，乐善好施，保有一颗纯净的善良之心。

在接触人界时，对身受内心痛苦折磨的月牙岚产生兴趣，不断主动接近对方，甚至不惜以自身的性命感化具有善良本性的月牙岚。

后来在梁皇无忌的支持下，爱灵灵和月牙岚至东瀛退隐。

历经西剑流洗心革面的过程，两人拥有短暂的幸福时光，育有一子，名为月牙诚，一改过去天真的个性，成为一名相夫教子的少妇。——（东皇战影：桌布）

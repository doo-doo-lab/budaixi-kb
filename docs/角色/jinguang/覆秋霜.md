# 覆秋霜

================================================================================

金光布袋戏虚拟人物覆秋霜是金光布袋戏系列《金光御九界之魆妖记》《金光御九界之鬼途奇行录》中的虚拟角色，由黄立纲配音。其身份为鳞族鲛人、太虚海境卸任丞相，别号雨相，隐藏身份为纵横家鬼谷一脉传人，曾先后归属海境朝堂、纵横家及阎王鬼途等多方势力。覆秋霜在海境内战期间周旋于各方势力谋取利益，阴谋败露后逃离至中原加入阎王鬼途（实为俏如来驱虎吞狼之计），成为十部众之一并负责药材采购事务。在十部众与泷玉的药材交易中，覆秋霜通过抬高两成价格促成首笔订单，使得阎王鬼途资金大量流向泷玉。其以“彻底解决阎王鬼途”为由假意与海境决裂，实则试图通过扰乱资金链牵制对方行动。后联合慕容胜雪试图铲除前任绝命司方之墨，反遭徐福意志通过阎王翎侵占肉身成为绝命司载体。覆秋霜持有九锡冠节、黄琥刀币等特殊物品，初登场于《魆妖记》第3集，暂退场于《鬼途奇行录》第11集，最终以绝命司身份在同系列第17集被岳灵休击杀。中文名覆秋霜别 名雨相、老狐狸、绝命司配 音黄立纲性 别男登场作品金光御九界之魆妖记登场作品金光御九界之鬼途奇行录种 族鳞族血 脉鲛人归 属海境组 织海境朝堂、纵横家、阎王鬼途

## 人物设定

覆秋霜官方桌布姓名：覆秋霜称呼：雨相、老狐狸、绝命司（被徐福意志侵占肉身之后）诗号：残声凭烛捻韶光，半掩孤帏远庙堂，满树凋零无寄处，独吟萧索覆秋霜。（与狷螭狂诗号只差六字）身份：海境卸任丞相、纵横家鬼谷一脉传人、鬼谷四慧之一、绝命司载体种族：鳞族血脉：鲛人归属：海境组织：海境朝堂、纵横家、阎王鬼途初登场：金光御九界之魆妖记 第3集暂退场：金光御九界之鬼途奇行录 11集（肉体被徐福侵占成为绝命司）正式退场：金光御九界之鬼途奇行录 17集（以绝命司身份，死于岳灵休之手）武器：潮汐瑰瑕（原为纵横派传人李剑诗的佩剑，现已归还）、无名宝剑（在归还潮汐瑰暇后所用之剑，在最后一战时被岳灵休一掌击断）所有物：九锡冠节【海境先王御赐，丞相、使节合于一人之身的最高象征】、黄琥刀币、冰晶玉【天河至宝，每次只产十粒，每粒价值一百两银，在与军长铁骕求衣河上争夺药材之时被顺手摸走，装在锦囊之中，一共七十二粒，事后骂铁骕求衣（土匪）】、阎王翎【遭到绝命司附身后随身所携带】

## 角色能力

古岳剑法「钟响南屏、平湖秋光、曲眠春晓、夕照古峰、岳擎北云、残雪封桥」（利用狷螭狂的感情让他教剑）徐福能力被徐福意识入侵后，能够发挥徐福部分所学剑法：画河点星术法：阴符七术·「鸷鸟散势、腾邪实意」（被绝命司附体时使用）

## 角色经历

九锡冠节先王在位，边关各大独立部族不受皇室统治，一人手持栉节为使，游走各部辩战众人，分剖利害深中肯綮，不费一兵一卒为海境拓疆百里。海境卸任丞相，离开朝堂后表面专心培育新一代人才，实为培植自己的势力。覆秋霜欲星移出海境游历时，和纵横家鬼谷一脉的逍遥游推波助澜，引发三王之乱、更在之后埋下了海境内战的种子。海境内战时，周旋于各方势力之间，妄图谋取最大利益。阴谋败露后，逃离海境。进入中原，寻访同为纵横家鬼谷一脉的传人李剑诗，归还佩剑潮汐瑰瑕，并希望能够联合所有纵横家对抗墨家，遭到拒绝。无法联合纵横势力，覆秋霜只能另寻合作伙伴，于是开始与阎王鬼途接触。在帮助阎王鬼途处死叛徒真眉后，加入阎王鬼途，成为继任神华，并成为十部众之一，负责药材采购事务，联合慕容胜雪铲除绝命司计划失败，此次计划旨在铲除前任绝命司方之墨，但失败后反遭徐福意志通过阎王翎侵占肉身，成为绝命司载体，遭遇十部众围杀。在十部众与泷玉的药材交易中，通过抬高两成价格促成首笔订单，使得阎王鬼途资金大量流向泷玉。后以“彻底解决阎王鬼途”为由假意与海境决裂，实则试图通过扰乱资金链牵制对方行动。剑法以及内功皆是宗师修为，在重伤中毒的情况下，面对魈毒童子、无患开膛以及殷若微三人联手还能稳占上风，剑气逼住三丈的距离。被阎王鬼途擒拿后，绝命司占据其肉体，直至败亡于岳灵休之手，于《鬼途奇行录》第17集被击杀。

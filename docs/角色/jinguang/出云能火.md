# 出云能火

================================================================================

日本布袋戏《金光布袋戏》角色金光布袋戏虚拟人物。出云能火是东瀛西剑流六部之咒部。原为安倍流阴阳师，后加入西剑流。擅长咒术与阴阳之术，个性阴笃邪气，喜欢阴沉沉的笑，能取生灵与死灵，与鬼部的夜叉瞳为好友，擅长召唤术，最强一技为与夜叉瞳合招的阴阳并流术。中文名出云能火配 音黄立纲性 别男登场作品金光布袋戏身 份西剑流六部之咒部种 族人族归 属东瀛组 织安倍流、西剑流

## 人物设定

名称：出云能火出云能火身份：西剑流六部之咒部归属：东瀛组织：安倍流（原师承之处）、西剑流初登场：天地风云录之决战时刻第6集退隐：天地风云录之九龙变第3集 （返回东瀛）再登场：金光御九界之东皇战影第19集再退隐：金光御九界之鬼途奇行录第1集武学：幻阴诀·封界化实幻阴诀·雪鬼寒霜式神召唤·赤狻猊式神召唤·鬼角阴行·封灵七回冥道(与夜叉瞳合招)阴阳并流‧荒妖血河(与夜叉瞳合招)幻阴诀·幽冥妖火五星照五方·五行化五气·五方开天路·五气借神通·五鬼搬运·偷天换日（与安倍博雅合招，窃取地气）

## 官方简介

（西剑流六部咒部，擅长多种术法）西剑流咒部，擅长阴阳之术，个性怪异无法猜透。但亦对西剑流忠心耿耿。——（金光风云录）西剑流六部咒部之长，擅咒术与阴阳之术，个性阴笃邪气又嗜血，能取生灵与死灵，其技能包括与夜叉瞳合招的阴阳并流术。——（决战金光：史艳文传奇）西剑流六部之咒部。擅长咒术与阴阳之术，个性阴笃邪气，喜欢阴沉沉的笑，颇为嗜血，能取生灵与死灵，与鬼部的夜叉瞳为好友，擅长召唤术，其技能包括与夜叉瞳合招的阴阳并流术。——（决战时刻：桌布）出云能火原为安倍流阴阳师，后加入西剑流。

## 人际关系

安倍流师弟：安倍博雅西剑流上司流主：炎魔幻十郎、天宫伊织（继任）祭司：桐山守（桐山薰）军师：赤羽信之介四天王：天宫伊织（青龙）、月牙泪（白虎）、宫本总司（玄武）、赤羽信之介（朱雀）同级六部：神田京一（暗部）、衣川紫（医部）、邪马台笑（兵部）、天海光流（道部）、出云能火（咒部）、夜叉瞳（鬼部）下属八门：雨音霜（休门）、真田隆三（生门）、丑孔明（伤门）、月牙岚（杜门）、千鸟胜（景门）、柳生鬼哭（死门）、鬼夜丸（惊门）、天满道隆（开门）、风间始（继任景门）四组：雨音焱（云组）、石皮阎罗（破组）、八刀痕（分组）、云十方（森组）其他：真田勇次郎、青木诚归降：天恒君、三清道长、武上君对手仇敌对手：叹悲欢、柴田道末其他信息桃子姐

## 角色经历

西剑流入侵中原后，六部大将相继前来处理尚未归附的中原势力。出云能火与夜叉瞳受命对付灵界，在与灵界的斗争中，使灵界复出沉重代价。后西剑流主炎魔幻十郎于天允山战败，以纳灵大法吸收西剑流全体能量，鬼部夜叉瞳惨死，众人无奈反叛，导致西剑流最终战败。西剑流战败后，出云能火随军师赤羽信之介等人退回东瀛，休养生息。

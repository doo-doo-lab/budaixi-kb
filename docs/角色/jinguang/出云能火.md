# 出云能火

日本布袋戏《金光布袋戏》角色金光布袋戏虚拟人物。出云能火是东瀛西剑流六部之咒部。原为安倍流阴阳师，后加入西剑流。擅长咒术与阴阳之术，个性阴笃邪气，喜欢阴沉沉的笑，能取生灵与死灵，与鬼部的夜叉瞳为好友，擅长召唤术，最强一技为与夜叉瞳合招的阴阳并流术。

## 官方简介

（西剑流六部咒部，擅长多种术法）西剑流咒部，擅长阴阳之术，个性怪异无法猜透。但亦对西剑流忠心耿耿。——（金光风云录）西剑流六部咒部之长，擅咒术与阴阳之术，个性阴笃邪气又嗜血，能取生灵与死灵，其技能包括与夜叉瞳合招的阴阳并流术。——（决战金光：史艳文传奇）西剑流六部之咒部。擅长咒术与阴阳之术，个性阴笃邪气，喜欢阴沉沉的笑，颇为嗜血，能取生灵与死灵，与鬼部的夜叉瞳为好友，擅长召唤术，其技能包括与夜叉瞳合招的阴阳并流术。——（决战时刻：桌布）出云能火原为安倍流阴阳师，后加入西剑流。

## 角色经历

西剑流入侵中原后，六部大将相继前来处理尚未归附的中原势力。出云能火与夜叉瞳受命对付灵界，在与灵界的斗争中，使灵界复出沉重代价。后西剑流主炎魔幻十郎于天允山战败，以纳灵大法吸收西剑流全体能量，鬼部夜叉瞳惨死，众人无奈反叛，导致西剑流最终战败。西剑流战败后，出云能火随军师赤羽信之介等人退回东瀛，休养生息。

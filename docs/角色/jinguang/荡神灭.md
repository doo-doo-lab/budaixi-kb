# 荡神灭

================================================================================

金光布袋戏虚拟人物荡神灭是台湾金光布袋戏系列中魔世修罗国度灭世三尊之一的虚拟人物，由黄立纲配音。其性格强势刚硬，奉行强者为尊，却对人类女子恋红梅情深意重。为护恋人周全，他多次违背帝尊戮世摩罗之命，与同僚炽阎天、曼邪音冲突，甚至独战魔世联军。经典战役包括以“神摧意灭”突破重围却遭恋红梅背刺重伤，相关剧情集中于《魔戮血战》第5、8、9、16-19集。荡神灭以魔族身份展现复杂人性，高傲外表下隐含深情，其刚硬与柔情并存的特质构成角色核心戏剧张力。

**中文名**：荡神灭

**别名**：阿鼻尊、牛头尊、好男人

**配音**：黄立纲

**登场作品**：金光御九界之墨武侠锋

**身份**：灭世三尊之一

**种族**：虺族血 脉虺族归 属魔世

**组织**：修罗国度

## 扩展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

金光布袋戏，黑白龙狼传，天地风云录之决战时刻，天地风云录之九龙变，天地风云录之剑影魔踪，天地风云录之魔戮血战，金光御九界之墨武侠锋，金光御九界之墨世佛劫，金光御九界之墨邪录

# 诛天 (诛天)
================================================================================

诛天(霹雳布袋戏虚拟人物)

霹雳布袋戏虚拟人物。是图展霸业的魔皇，源自魔界，因不容于天魔而未封于天魔录之内，出走魔界另组魔剑道。诛天性格阴沈奸险，为了完成自己霸业无所不用其极，率领座下魔魇大军，与天策真龙一争中原导致生灵涂炭；虽如此，对内却颇能接纳建议。对爱子黑衣剑少也极为宠溺，但感情绝不形于外。在诛天眼中一直秉持着‘非我族类，其心必异’的观念，故对人类毫无同情之心，但对内却极重情义，对好友风之痕真心相对，对养子白衣剑少视如己出，同时亦及其爱护魔剑道下属，虽于正道群侠立场不同，但也不失为一代不世枭雄。

**兄弟**：二人双双出现，一举杀死魔魁、龙王鱽两大高手而震撼中原武林。而后随着天策真龙的出现，诛天知道天策真龙若吸收星灵将会力量大增，便改以天策真龙为目标，不仅阻止天策真龙逼杀不二刀，更要众人协助中原武林对付天策真龙。诛天在天策真龙统一中原后，正式揭开了“魔剑道”与“天策王朝”之间的征战。诛天仗着十七万魔魇大军认为稳操胜券，但却被沙舟一字师设下的圣灵界线所组挡。使得魔魇无法长驱直入进入中原，诛天缓慢的让魔魇不断冲击圣灵界线，希望突破圣灵界线能直捣中原，但黑衣剑少两次私自前往腾龙殿刺杀天策真龙，导致白衣剑少被擒，迫不得已下，诛天答应以不二刀在九九登天台与天策真龙交换人质，但其实诛天事先让部分魔魇大军潜入地底而突破圣灵界线，就在九九登天台一役，魔魇大军猛然出现地面让天策大军溃不成军。就在一路追击天策大军时，因魔魇怕水而被暂时阻挡在万里江边，此时诛天让白衣剑少担任先锋武将统领大军，岂料在燃灯大师牺牲下，竟使三传人同时杀死控制魔魇大军的三阴巫姥，致使魔魇大军失去控制而消失，而后白衣剑少将功赎罪，在天绝峡谷设计全套，让天策真龙被孤立而遭到魔剑道大军围剿，就在诛天将要杀死天策真龙时，化星星灵出现，致使天策真龙六星入体而扭转战局，双方也因死伤惨重而各自退兵，后因天策真龙主张和谈，诛天便与天策真龙在寒月江立下和平条约，双方互不侵犯。半年后，诛天为争夺爱子黑衣剑少而被妖后、策谋略偷袭而死，人头被挂在中原公开亭，魔剑道众将群情激愤要找出杀死诛天的凶手，最后独孤遗恨承认自己便是凶手后被风之痕所杀，而后妖后让黑衣剑少回到魔剑道继承魔皇之位，也间接把魔剑道并入妖刀界，其部属将领也在追查诛天死亡之谜时，纷纷亡故，魔剑道也形同走向了灭亡。人物配乐诛天（角色曲） 收录于《沧海遗珠 剧集原声带》旭日东升（情境曲） 收录于《龙图霸业 壹 剧集原声带》

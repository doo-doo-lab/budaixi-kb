# 誅天 (诛天)
================================================================================

誅天(霹靂布袋戲虛擬人物)

霹靂布袋戲虛擬人物。是圖展霸業的魔皇，源自魔界，因不容於天魔而未封於天魔錄之內，出走魔界另組魔劍道。誅天性格陰沈奸險，為了完成自己霸業無所不用其極，率領座下魔魘大軍，與天策真龍一爭中原導致生靈塗炭；雖如此，對內卻頗能接納建議。對愛子黑衣劍少也極為寵溺，但感情絕不形於外。在誅天眼中一直秉持著『非我族類，其心必異』的觀念，故對人類毫無同情之心，但對內卻極重情義，對好友風之痕真心相對，對養子白衣劍少視如己出，同時亦及其愛護魔劍道下屬，雖於正道群俠立場不同，但也不失為一代不世梟雄。

人物設定姓名：誅天稱號：魔皇誅天退場：霹靂異數之龍圖霸業 第15集（死於妖后）來自/種族：魔界/魔族身份：魔劍道之主根據地：西漠所有物：魔界寶玉人際關係主要人際關係兒子 ·黑衣劍少魔劍道皇太子，師承魔流劍風之痕，劍法霸氣、剛強，相較於皇兄白衣劍少的冷靜、快意，黑衣則表現出不同的任性、狂野，以及不服輸的個性。天性聰穎機靈，雖年少但在武學上有不可小覷的成就，繼承妖刀界與魔劍道的霸業。平日被誅天寵壞，對誅天說話沒大沒小，儘管對誅天器重白衣有一定的不滿，但心中對父親和兄長仍是親情敬重。養子 ·白衣劍少魔劍道皇少主，師承魔流劍風之痕，個性冷靜穩重、重情重義，特異的體質不畏一般劇毒。被魔劍道之主誅天所收養，成為魔劍道少主，有著複雜的身世，另一身分為西疆皇朝王太子。尚在襁褓時期的白衣曾被誅天收養，感念誅天的養育之恩，為魔劍道大業盡心盡力，父子二人雖無血緣關係，但感情極為深厚。摯友 ·魔流劍風之痕魔界傳說中的絕代劍者，無人能出其右，平生追求劍術極致，崇尚自由不受拘束，對權力等武林鬥爭毫無興趣，創造出【風之痕】與【魔流劍】二種完全截然不同的劍法，一為冷靜快意，一為狠野瘋狂。魔界武者的決鬥試煉中與年輕氣盛的誅天巧遇，不打不相識地結為生死摯友，於誅天背後默默支持好友的霸業發展。妻子 ·妖后容貌嬌艷，體態姣好，深沉冷靜，智勇雙全；狠辣強悍且城府極深的女性君王角色，對事情皆觀察入微。非常疼愛自己的兒子黑衣劍少，除了關於兒子的事外，對其他任何事絕不留情，連自己的丈夫也不例外。野心勃勃的同時，還能冷靜分析局勢，從而能夠掌握武林的局勢，令中原正道人心惶惶，具有與眾武林英雄好漢逐鹿天下的王者風範。次要人際關係人物能力武學狂魔槍法、怒極魔威、萬魔鎖關、魔槍滅世、毀天滅地、狂槍滅世武器狂魔槍誅天 武器·狂魔槍◎外形特徵：以雙頭利刃交錯而成的雙叉戟，適合旋轉攪碎攻擊，柄長而鈍重，兼走輕靈與剛猛，完全視使用者特性發揮。原為橫千秋所有，後傳給誅天。◎長度：九尺◎重量：九十斤◎登場劇集：霹靂異數之龍圖霸業 第5集人物經歷魔劍道·大事紀要誅天出走魔界後，在西疆所創立的組織，在滅了西疆王朝後，積極進軍中原武林，以十七萬魔魘大軍為力量，與統一中原武林的「天策王朝」對戰，曾在九九登天台與天絕峽谷大敗天策真龍大軍，因天策真龍六星入體而被扭轉戰局，在誅天意外身亡後，魔劍道被黑衣劍少接管而遭併入妖刀界。魔劍道初次展現實力為中原的神劍爭奪戰，區區一名無名者的劍法修為便讓人為之訝異，而後惡魔岩、魔閻殿等相繼出現，以搶奪西疆王朝的神劍為目標，就在悲鳴殿出現後，以七大靈首為主，展開侵略中原武林的野心，同時皇少主白衣劍少、黑衣劍少兄弟二人雙雙出現，一舉殺死魔魁、龍王魛兩大高手而震撼中原武林。而後隨著天策真龍的出現，誅天知道天策真龍若吸收星靈將會力量大增，便改以天策真龍為目標，不僅阻止天策真龍逼殺不二刀，更要眾人協助中原武林對付天策真龍。誅天在天策真龍統一中原後，正式揭開了「魔劍道」與「天策王朝」之間的征戰。誅天仗著十七萬魔魘大軍認為穩操勝券，但卻被沙舟一字師設下的聖靈界線所組擋。使得魔魘無法長驅直入進入中原，誅天緩慢的讓魔魘不斷衝擊聖靈界線，希望突破聖靈界線能直搗中原，但黑衣劍少兩次私自前往騰龍殿刺殺天策真龍，導致白衣劍少被擒，迫不得已下，誅天答應以不二刀在九九登天台與天策真龍交換人質，但其實誅天事先讓部份魔魘大軍潛入地底而突破聖靈界線，就在九九登天台一役，魔魘大軍猛然出現地面讓天策大軍潰不成軍。就在一路追擊天策大軍時，因魔魘怕水而被暫時阻擋在萬里江邊，此時誅天讓白衣劍少擔任先鋒武將統領大軍，豈料在燃燈大師犧牲下，竟使三傳人同時殺死控制魔魘大軍的三陰巫姥，致使魔魘大軍失去控制而消失，而後白衣劍少將功贖罪，在天絕峽谷設計全套，讓天策真龍被孤立而遭到魔劍道大軍圍剿，就在誅天將要殺死天策真龍時，化星星靈出現，致使天策真龍六星入體而扭轉戰局，雙方也因死傷慘重而各自退兵，後因天策真龍主張和談，誅天便與天策真龍在寒月江立下和平條約，雙方互不侵犯。半年後，誅天為爭奪愛子黑衣劍少而被妖后、策謀略偷襲而死，人頭被掛在中原公開亭，魔劍道眾將群情激憤要找出殺死誅天的兇手，最後獨孤遺恨承認自己便是兇手後被風之痕所殺，而後妖后讓黑衣劍少回到魔劍道繼承魔皇之位，也間接把魔劍道併入妖刀界，其部屬將領也在追查誅天死亡之謎時，紛紛亡故，魔劍道也形同走向了滅亡。人物配樂誅天（角色曲） 收錄於《滄海遺珠 劇集原聲帶》旭日東升（情境曲） 收錄於《龍圖霸業 壹 劇集原聲帶》

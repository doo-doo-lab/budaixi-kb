# 苦海女神龍 (苦海女神龙)
(百度百科无对应条目,newton.com.tw 收录)
================================================================================

人物名稱苦海女神龍人物概況苦海女神龍，本名「波娜娜」，原是韃靼國三公主，自幼即仰慕中原文化，飽讀詩書，並且習得高超功夫，文武全才。韃靼大公主與沙陀族聯姻後意欲進犯中原，波娜娜不能贊同大姊作法，並洞悉沙陀陰謀，卻苦於孤立無援，只能遠赴中原，向中原皇帝尋求幫助。離開祖國後，波娜娜化名為「苦海女神龍」，在她的手刀之下，惡棍妖道鮮少能夠全身而退，強勢的作風讓歹人膽寒，然而，她在剛強的外表和武技下，卻有著溫柔仁慈的心腸，對敵時從不取人性命，就算對手是無可救藥的壞蛋，最多不過癈其武功，使之無法再為非作歹。苦海女神龍與史艷文相識後，成了無不談的好友，也發展出一段刻骨銘心、 生死與共的戀情。女神龍初入中原之際，正是女暴君稱霸武林之時，擅長吸取元陽的女暴君一直對史艷文的純陽功體很有「興趣」，女神龍自然與她勢不兩立，一正一邪的武林英雌展開大鬥法，女暴君武功與邪功高超，女神龍拿她沒辦法，但太陰星宿轉世的女神龍卻也不是姚明月邪功能夠克制的對象。在聞世先生獻計之下，史艷文與女神龍終於大破女暴君的邪功，隨後再大戰紫玄觀和藏鏡人於南陽城。最後，中原群俠在兩人帶領下返回韃靼，此時，篡位的大公主已遭殺害，韃靼已被沙陀控制，眾人協助韃靼三公主復國後，紛爭才告一段落。史艷文在大明皇帝、母親和元配同意下，與苦海女神龍成親，史艷文回到中原後，卻心灰意冷，落髮出家。女神龍曾經遣女兒史菁菁遠赴中原找尋父親，但史艷文已經化身為逃名客，真假莫辨，而後，女神龍亦曾再進中原，但卻再未與史艷文碰過面了……。

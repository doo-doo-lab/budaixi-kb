# 苦海女神龙
(百度百科无对应条目,newton.com.tw 收录)

人物名称苦海女神龙人物概况苦海女神龙，本名“波娜娜”，原是鞑靼国三公主，自幼即仰慕中原文化，饱读诗书，并且习得高超功夫，文武全才。

鞑靼大公主与沙陀族联姻后意欲进犯中原，波娜娜不能赞同大姐作法，并洞悉沙陀阴谋，却苦于孤立无援，只能远赴中原，向中原皇帝寻求帮助。

离开祖国后，波娜娜化名为“苦海女神龙”，在她的手刀之下，恶棍妖道鲜少能够全身而退，强势的作风让歹人胆寒，然而，她在刚强的外表和武技下，却有着温柔仁慈的心肠，对敌时从不取人性命，就算对手是无可救药的坏蛋，最多不过废其武功，使之无法再为非作歹。

苦海女神龙与史艳文相识后，成了无不谈的好友，也发展出一段刻骨铭心、 生死与共的恋情。

女神龙初入中原之际，正是女暴君称霸武林之时，擅长吸取元阳的女暴君一直对史艳文的纯阳功体很有“兴趣”，女神龙自然与她势不两立，一正一邪的武林英雌展开大斗法，女暴君武功与邪功高超，女神龙拿她没办法，但太阴星宿转世的女神龙却也不是姚明月邪功能够克制的对象。

在闻世先生献计之下，史艳文与女神龙终于大破女暴君的邪功，随后再大战紫玄观和藏镜人于南阳城。

最后，中原群侠在两人带领下返回鞑靼，此时，篡位的大公主已遭杀害，鞑靼已被沙陀控制，众人协助鞑靼三公主复国后，纷争才告一段落。

史艳文在大明皇帝、母亲和元配同意下，与苦海女神龙成亲，史艳文回到中原后，却心灰意冷，落发出家。

女神龙曾经遣女儿史菁菁远赴中原找寻父亲，但史艳文已经化身为逃名客，真假莫辨，而后，女神龙亦曾再进中原，但却再未与史艳文碰过面了……。

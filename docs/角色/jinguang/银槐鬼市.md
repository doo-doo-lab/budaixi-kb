# 银槐鬼市

金光布袋戏虚拟组织银槐鬼市是金光布袋戏中隐于古朝东都遗迹附近的神秘组织，以经营江湖黑暗买卖闻名，遵循“夜冥开市、天明即散”的运作规则。

该组织由鬼尊、天首、地宿、老爷、偃师五位当家共同领导，下设偃师司匠、不夜长河、落花随缘庄、巧木宫四大分支，分别掌管偃甲术、赌坊、暗杀及黑市交易。

内部施行禁武令、血印立契等特殊机制，交易需凭黄琥刀币准入或推荐人担保。

该组织曾派遣诸葛穷渗透苗疆未果，后由涉入银槐深处的忆无心和随风起揭露其真实面目。

早年因魔军入侵被迫迁移，天首以天魔舞歼灭七百魔军护卫转移。

后遭仙岛势力冲击核心封闭，主要成员隐遁待机并持续布局中苗战略。

在苗疆动乱期间，老爷与阎王鬼途合作囤积药材，通过结缘酒机制操纵竞价，计划在药神回归时高价抛售。

银槐鬼市通过刀币流通与契约体系维持运作，涵盖暗杀、情报、黑市等多领域交易。

## 能力

偃甲之术偃甲人（机关傀儡人）、机关术、铸造术、火器、仿造，银槐鬼市技术储备和后勤中心。不夜长河逍遥天赌坊、酒楼、妓院、竞技场、旅店、当铺、钱庄、商会，掌管酒色财气，银槐鬼市最大的娱乐中心。枯魂斗技场因为地宿打赌输了，后划给了巧木宫。落花随缘庄暗杀、刺杀、虐杀、定制杀人法，接各类杀手生意。巧木宫买卖毒品、盗窃物品、消息情报、武功秘籍、神兵利器、物资、医药、奇珍异宝的黑市，在老爷易主以后放弃了人口和奴隶买卖。鬼尊银槐鬼市执法者，银槐鬼市负责协调四大家矛盾的仲裁者，监督四大势力，维持鬼市的稳定和法度。

## 险遇亡祀组织环境

天首辖区无漓鬼河介绍：搭上由刀币启动的轻筏，殷红灯笼引领渡河，外界进入银槐的路径之一，过河后竹筏会自动消失。

特点：幽暗如黄泉冥河，阴森鬼音绕耳不断，扰人心神。

落花随缘庄介绍：三姑娘居住的地方特点：种满天首亲手栽培打理的故乡花草幽荧，被忆无心评价是很美丽的地方。

深渊之境介绍：签订血契者，未能完成契约的去处。

巧木宫辖区巧木宫介绍：老爷居住和招待宾客的地方。

阴司街介绍：鬼市里对普通宾客进行买卖交易的地方，种类繁杂细琐，小到吃穿用度，大到情报人命。

特点：大多见不得光，卖家隐于暗处，买家要全凭自己的眼力，手气和直觉而确定是否交易。

交易规则：不论价格高低，只要双方同意，订立契约，交易即成。

买卖：臭豆腐香包枯魂斗技场介绍：欠债者在庄家的安排下，以斗技的方式偿还债务。

监牢收押欠债难还者的地方。

客房介绍：来银槐交易的宾客进行留宿，以及斗技场常胜斗士休息的地方。

医庄介绍：医治枯魂斗技场伤员的地方。

血暗深渊让欠债者做苦力偿还债务的地方。

葬书宿收藏银槐鬼市从各地网罗来的武功秘籍和各项情报纪录之处。

地宿辖区不夜长河介绍：赌坊、酒楼、妓院、竞技场、旅店、当铺、钱庄、商会，掌管酒色财气，银槐鬼市最大的娱乐中心。

逍遥天介绍：不夜长河里最热闹的赌坊，主要收入来源。

## 组织交易

客户黄琥刀币：御兵韬、覆秋霜、慕容胜雪、泰玥皇锦朱瑚刀币：忆无心、四仙宫荷仪宫主欠债诸葛穷（已经还清）拍卖骆子枫的碧血银芒神弓鹊血饮羽介绍：射杀开朝名将陈氏将军的神弓，经过巧匠炮制，常年不朽，陈将军怨气栖宿其上，邪厉异常经历：十六年前鬼市拍卖，因来历非凡备受关注，以千两黄金天价售出，得标者鸿鹄壮志向云飞（实际上是接天岚设计），最后被铁骕求衣斩断。

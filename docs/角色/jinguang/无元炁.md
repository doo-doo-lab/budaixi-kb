# 无元炁

================================================================================

布袋戏剧《金光布袋戏》中的角色无元炁，金光布袋戏《金光御九界之鬼途奇行录》中的虚拟角色，由黄立纲配音。

作为阎王鬼途组织阎途十部众之‘玄冥’（绝命司惯以‘无’称之），其身躯经绝命司无数次精密实验改造，仅剩头部保留原身，融合七名高手特性形成组合体，擅长掌法与借气之术冥海归元劲。

因改造后已非常人身躯，无元气聚集之处而需向万物借气，被称为阎途十部众第一高手。

最终携阎王翎遭遇御兵韬时选择逆行兵解，导致阎王鬼途彻底瓦解。

阎途十部众之名皆取自十殿阎王所居之宫殿，玄冥对应秦广王之玄冥宫。

无元炁作为绝命司最忠诚的部下，其躯体兵解标志着徐福千年计划的终结。

角色退场于《鬼途奇行录》第32集，以衣帽遗落、阎王翎折断收场。

**中文名**：无元炁

**别名**：玄冥

**配音**：黄立纲

**性别**：男

**登场作品**：金光御九界之鬼途奇行录

**身份**：阎途十部众之一

**种族**：人族归 属道域·阴阳学宗（已脱离）中原

**组织**：阎王鬼途

## 人际关系

阎王鬼途上司：绝命司根据地：十殿阴曹（内部有多个据点，如第七处）十部众：无元炁（玄冥，已死）、魈毒童子（普明，已死）、无患开膛（纣绝，已死）、殷若微（太和，已死）、丁凌霜（纠伦，已脱离）、慕容胜雪（明晨，已除名）、识龙影（神华，已死）、方之墨（七非，已死）、真眉（碧真，已死）、钓烟波（肃英，已死）、覆秋霜（继任神华，已死）杀手：百雪踪（已死）下级：柳君老（已死）、傅人美（已死）、司徒虹日（已死）叛徒：幽冥君、鸩罂粟（相继成为恪命司，夺取阎王鬼途实权，与岳灵休里应外合瓦解过一次阎王鬼途）对手仇敌对手：幽冥君、鸩罂粟、岳灵休

## 角色经历
阎王鬼途为贩卖药物的地下组织，通过一手施毒，一手贩药的手段敛财，用于研究亡命水（长生不老药）。

曾经被幽冥君、鸩罂粟、岳灵休捣毁过一次，如今死灰复燃。

在阎王鬼途中，玄冥无元炁的身份最为神秘，其身份甚至比绝命司更晚曝光。

在整个阎王鬼途之中，除了绝命司外，属他的实力最强，曾多次解除组织危难，掌力非凡，带有阴邪奇寒玄霜，刀枪不入之躯，李剑诗、丁凌霜对战时，都不能伤及分毫。

在绝命司下令命其处理丁凌霜时曾说，【事成之后，他一双用剑的快手归你了】，与肃英钓烟波为绝命司最忠诚的部下，甚至愿意献出肉身成为下一任绝命司，却因并非真正意义上的活人，而无法成就此愿。

阴阳学宗当世七雅之一【花（荻花题叶）、酒（叱酒当歌·浪飘萍）、诗（行诗乐苦·咏天涯/无元炁）、琴（休琴忘谱/逍遥游）、棋（云棋水镜/黓龙君）、书（临书玉笔/旭长辉）、画（如画江山/碧松影）】风逍遥评价：笑世俗庸人，行颓废篇章，这就是我印象中的咏天涯！

其实，无元炁为了让肉身不死，利用阴阳学宗的禁术，使自己成为行尸，所以得以更换躯体部位，实力也更强，能够存活更长时间。

无元炁沉默寡言，在阎王鬼途多次会议当中，一言不发，只以掌气进行投票，期间从未现身，直到绝命司被岳灵休打死之后，出现救了在场众人。

然后，为了得到药神所研发的向天抢时，与药神之徒榕桂菲交易，意图以治好药神的内伤来换取向天抢时。

得知交易被人监视，而只派一名手下，用假的解药交换假的向天抢时，事后，早就料到向天抢时乃假物的绝命司用力捏碎了药丸。

无元炁又参与围杀遥星旻月，任务失败后，绝命司命令其杀死临阵弃战的丁凌霜。

在唤魂桥，无元炁阻击丁凌霜，一度将其打败，然而丁凌霜却被慕容宁所救，无元炁只得回到绝命司身边。

后在涳溟沄渊，无元炁以一人之力对战狼主等人，因为狼主等人害怕涳溟沄渊收到冲击而崩塌，不敢使出全力，而被无元炁压制。

最后，大祭司牺牲性命，使用术法封印涳溟沄渊，而无元炁被术法击中逃走。

之后，又随绝命司来到阴阳分垒，击败剑无极，夺取安倍博雅。

在黑白郎君到来后，无元炁携带安倍博雅回到十殿阴曹。

而经过一段时间，绝命司迟迟未归，无元炁判断以岳灵休作为载体的绝命司无法回来，于是将阎王翎贯入安倍脑中，让绝命司得到了安倍的躯体，绝命司谋划千年的计划得以实现！

然而，随着绝命司的再次身亡，携带阎王翎准备前往涳溟沄渊的无元炁又遇上苗疆军师御兵韬。

一番交谈之后，无元炁拿出了阎王翎，却没有交给御兵韬，而是将阎王翎刺中自己身体。

瞬间，无元炁的禁术解除，躯体兵解，只留下衣帽等物，而阎王翎也被折断，从此，阎王鬼途彻底覆灭，历经千年岁月的徐福也彻底死去。

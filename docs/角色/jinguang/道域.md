# 道域（金光布袋戏虚拟势力）

道域是金光布袋戏中的虚构势力，属中土九龙地界之一，由龙虎天师张道陵创立，崇尚无为而治。其划分为神啸刀宗、阴阳学宗、紫微星宗、仙舞剑宗四大宗派，以天师云杖为统治权象征，通过十二年一届的天元抡魁比武选拔执掌者，由四宗年轻弟子比试决胜。因内战与血神事件，道域废除修真院制度，将天元抡魁改为两年一届并允许18岁以下弟子参与，天师云杖转为四宗共管、十年交接。传承物品包括天师云杖、三不名锋等，其中血染不绝由持之不败与血不染融合而成，用于封印血神。四宗各具镇宗法宝，如泽国战图、三垣卷轴等，地界特性载于《九龙天书》。

## 地界概述

道域为龙虎天师张道陵所创立之势力，亦为九龙地界之一，崇尚无为而治。

道域势力划分为四大宗派：神啸刀宗、阴阳学宗、紫微星宗、仙舞剑宗。

道域传统，每十二年召开一次天元抡魁，由道域四宗年轻弟子参与，获胜的一派，其宗主将成为新一任的神君，执掌天师云杖，统治道域。

天师遗训，修道者重天份，道域不看现在，注重未来，纵有遗珠之憾，也是天意。

在经历道域内战、覆舟虚怀、血神复活等等影响后，末代神君千金少和四宗高层决议，废除修真院制度，天元抡魁改为二年一次举办，十八岁以下弟子皆可参加。而天师云杖四宗共同保管，每十年进行交接。

## 特殊物品

天师云杖：龙虎天师所留王骨，能够缩短咒命七罡字生效时间、加成术法威力、也可当兵器使用加成道域武学。

解金貂：道域稀贵之酒，一年一酿，难得十斤。

铁松核：生于保含金铁的环境，蕴含特殊磁能，有提升术法的功效。

血不染：道域三不名锋之一，为无情葬月所有。已被血神吸收。

持之不败：道域三不名锋之一，为莫离骚所有。已被血神吸收。

随心不欲：道域三不名锋之一，为飞渊所有。为防血神窥探，暂由莫离骚使用兼保管。现由飞渊持有，无剑鞘。

血染不绝：由持之不败与血不染融合而成，实为血神之武器。

封印剑鞘：秘密藏于随心不欲的剑鞘之内的鞘中鞘，乃龙虎天师所留封印血染不绝的剑鞘，重新封印血神的关键。

神逸刀：神啸刀宗镇宗双器之一，由千金少赠予风逍遥。

天市镜：三垣法宝之一，传说可照人心魔障，万妖伏灭，现为苍苍所有。

阴阳学宗

### 阴阳学宗

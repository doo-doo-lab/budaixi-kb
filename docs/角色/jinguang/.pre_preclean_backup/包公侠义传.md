# 包公侠义传

黄立纲执导的电视剧中国台湾52 集《包公侠义传》是由黄立纲执导并编剧的台湾布袋戏电视剧，由天地国际多媒体公司于2007年制作，改编自古典小说《三侠五义》。

该剧以北宋仁宗年间为背景，讲述清官包拯在开封府任职期间，联合北侠欧阳春、南侠展昭、丁氏双侠等江湖侠士侦破悬案的故事，首播于公视主频道。

剧集通过“大破黑狼山”“狸猫换太子”等案件，展现包拯铁面无私的形象，融合公案传奇与侠义精神，刻画众侠士协助包拯破除贪腐、为民伸冤的历程。

全剧共52集，以布袋戏形式呈现，突出忠义主题与江湖豪情，塑造了白玉堂、卢方等五鼠兄弟的侠客群像。

导演黄立纲首播时间2007年09月13日中文名包公侠义传外文名baogongxiayizhuan图集

### 剧集介绍

2007年天地国际多媒体公司 推出 根据古典名著《三侠五义》改编的布袋戏《包公侠义传》，叙述北宋仁宗年间北侠欧阳春、南侠展昭、丁氏双侠与卢方韩彰徐庆蒋平白玉堂等众侠义协助清官包拯为国除害为民伸冤办理了无数疑难案件的故事。

配音和编导由黄俊雄之幼子黄立纲担纲，西卿和黄凤仪则担任幕後主唱，首播频道为公视主频道。

### 剧情介绍

故事内容主要叙述北宋仁宗年间出了一位著名清官包拯曾封龙图阁直学士后世称之为“包龙图”主开封府能夜治阴间昼断阳间断案如神公正廉明忠于宋廷铁面无私专惩贪官污吏先后办理了无数疑难案件深得百姓拥戴慕包拯英名以北侠欧阳春、南侠展昭、丁氏双侠、小侠艾虎、智化、沉仲元等七位侠客与卢方等五位义士前往开封府为国效力……

# 默苍离

金光布袋戏虚拟人物默苍离是金光布袋戏系列中的虚拟人物，墨家巨子，曾化名策天凤、黓龙君等身份活跃于九界。

初次登场于《天地风云录之决战时刻》，在血色琉璃树下收俏如来为徒传授止戈流剑阵，后通过铸心之局完成墨家传承。

曾平定羽国内乱并收雁王为徒，设计破除北竞王篡位阴谋，挫败墨家九算叛乱。

默苍离手持墨狂剑与琉璃串，以擦拭铜镜的形象著称。

在《天地风云录之剑影魔踪》第19集中死于俏如来剑下完成血继传承。

退场后通过回忆片段影响后续剧情，曾在《墨世佛劫》中附身俏如来对抗玄之玄，《战血天道》以亡灵形态现身道域破除血神之力。

剧中通过九龙天书局破解、灵界十九错分析等战役展现智谋，黄立纲配音赋予其冷漠声线特征。

角色设定包含与冥医探讨心病的对话，强调决策责任自负的师徒关系，曾将叶青视为变数分析魔之甲线索。

九算老五凰后与雁王联手终结玄之玄篡权，元邪皇之乱期间俏如来正式继承巨子职责。

## 无情葬月主要剧情

苗疆弈棋化名神弈子参加苗疆金碑开局，与苗疆第一棋手北竞王对弈。

北竞王先手落子，和棋收场。

用名默苍离时期再见小王，自称是自己不想赢，不然再让三子亦可败北竞王到无地自容。

默苍离图片道域平乱化名黓龙君巡回道域时，察觉并挫败忘今焉（九算老大）的阴谋。

以一敌九察觉九算阴谋，以一敌九。

造成四死二重伤。

重伤二人为欲星移、凰后，死者为老四、老六、老八、老九。

实际上老八与默苍离合作，当年诈死回到仙岛。

远赴羽国墨家内斗爆发后，赴羽国阻止凰后（九算老五）的阴谋。

化名策天凤，收雁王为徒，为平羽国内乱，教导雁王三年。

欲雁王为传人，设下铸心之局，上官鸿信因不肯弑师而铸心失败，策天凤离开羽国。

至此，化另一名，孤鸿寄语默苍离。

十年一局从羽国归来后，与冥医救下无情葬月，布下揭开道域惨案真相之局。

三问俏如来引俏如来至血色琉璃树，三问“为何你还没死”，点破迷津。

三粒药丸请好友冥医准备三颗药丸，分别用于施救俏如来、史艳文、藏镜人的性命。

三个考验以三道试题考察俏如来是否具备成为其传人的资格。

书中智计灵魔大战前夕，送无字书于俏如来，让他参悟书中计。

再讲一次宫本总司死于九脉峰决战，再三命俏如来回忆描述宫本师尊死亡经过，逼迫其将悲愤感情宣泄出来。

十九次错误指出灵界大战中，俏如来所犯下的十九次错误。

少思错一 没想到各种可能涉险错二 没腹案就进攻莽攻错三 不该用一字长蛇阵无谋错四 没想到找外援寡断错五 没有牺牲的决心轻言错六 让苗王知道自身兵力空虚易信错七 对苗王动机怀疑不足少算错八 没安排退路误判错九 错算网中人实力失察错十 情报掌握不足以上是天地风云录之九龙变第19集里提到的错误，剩下的在编辑座谈会上放出。

怠机十一 没预料到梁皇的损耗而使他陷入险境。

失守十二 没提防到网中人的反扑，中军空虚，以至于二师兄尸体被夺，让梁皇见到二师兄的尸体而入魔（幸好苗王也没趁机偷袭）。

错置十三 北方防线的布置太弱，不但差点让天恒君打掉（幸好有万大刀帮忙），还放入魑鬼（害藏镜人功亏一篑）。

拙变十四 临场反应不足（如：尸体被夺走后也没猜到对方的目的，并且做好及早的应对，像是转向北方想办法通知里头的人之类的）。

失统十五 统御失调，扰敌躁进（银燕扰敌变成冲冲冲）。

妄动十六 整个战局几乎由苗王和网中人控制，成败的关键几乎受制于两人，半路竟然因为忆无心被抓而离开中央，完全没有发现战局变化。

失机十七 错上加错：没有早点领悟无字书用途。

寡智十八 使用方法不够漂亮。

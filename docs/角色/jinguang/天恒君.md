# 天恒君

================================================================================

金光布袋戏虚拟人物天恒君是金光布袋戏中的虚拟角色，中文名天恒君，别名天兵君，由黄立纲配音，初登场于《黑白龙狼传》第4集。身份从天部成员逐步转变为西剑流卧底、修罗国度魔将，经帝鬼改造后获得杀生鬼言称号。天恒君以贪生怕死、见风使舵著称，曾出卖天部情报导致组织全灭。假意替剑无极挡招骗取信任后暗算云十方致其牺牲。被俏如来击败后投靠魔世，先后效忠帝鬼、戮世摩罗，参与围剿史家行动。魔戮血战败退后逃往东瀛，最终循印记重归戮世摩罗麾下。该角色贯穿多部剧情，凭借反复倒戈的生存策略周旋于各方势力，其标志性口头禅"消灭"与墙头草形象形成鲜明特征。中文名天恒君别 名天兵君饰 演典型的小人，自私自利，心中有恶配 音黄立纲性 别男登场作品金光布袋戏身 份俏如来宿敌种 族魔族（由人族转变）归 属中原、魔世组 织天部、西剑流、修罗国度化 身杀生鬼言

## 官方简介

典型墙头草，奸险狡诈的双面人，贪生怕死之不义之徒。——（金光风云录：天恒君）原为中原地部的分部首领，厌倦当反抗组织而向西剑流输诚。典型拍马奉承之人，运气极佳，总是能获得各方的采纳包容。——（决战金光：史艳文传奇）西剑流在中原的卧底，机灵狡猾，请求炎魔为其入灵，魔化后短时间内能拥有不亚于八门的能力。——（金光风云录：魔化天恒君）擅使言灵之术，于魔世入侵后现身正气山庄的神秘魔将，透露给帝鬼相当多的中原情报，其真实身份究竟是……——（决战金光：史艳文传奇：杀生鬼言）魔世军队成员，谋略平庸嘴上功夫却不饶人。——（金光群侠传：天兵君）原中原背叛者天恒君，在被吸入魔世后由帝鬼拾得，改造成为「杀生鬼言」，可将单字化为具杀伤力的术法。本性除作战之外也很多话，经常被帝鬼下令禁言，由煞魔子管辖。戮世摩罗接手修罗国度后，成为调侃打趣的对象，意外地处得不错。——（金光群侠传：天恒君）【杀生鬼言：赤口白舌】帝鬼率领七先锋侵略人世时，现身正气山庄狙杀燕陀龙、脚仔王的神祕魔将，对中原情报所知不少，致使帝鬼快速掌握人世状况，攻略百武会，造成许多武林人士惨亡。其真实身分为意外被魔世封印裂缝吸入的天恒君，经帝鬼改造后，外貌丕变，更习有化用文字攻击的言灵术，在帝鬼身亡之后，成为戮世摩罗麾下，与煞魔子、三尊共事。——（魔戮血战：桌布）

## 云十方出场集数

黑白龙狼传天恒君身为西剑流卧底中原的天部成员，他出卖消息使得天部除他之外的人全灭，他也因此被剑无极怀疑。在多番试探之下的拙劣表现使得剑无极对他更不放心，最后却因为替剑无极挡刀而获得信任。天地风云录之决战时刻天恒君二版造型受西剑流收买而卧底中原，黑白龙郎传时期的甘草角色。本档受炎魔入灵，能短暂拥有超越八门实力的魔化之能，但被俏如来设计而魔化失败，被一箭射入江中，之后被网中人捡起吸收身上残留的炎魔魔气，生死未卜。天地风云录之九龙变投入妖神将网中人麾下，在网中人大战灵界一役中被撕裂的模式封印吸入内中，生死不明。天地风云录之剑影魔踪天恒君三版造型魔世先锋魔将之一的杀生鬼言首现，天恒君变身杀生鬼言，欲除史家人而后快。习得禁言之术的天恒君实力更上一层，在围剿独眼龙俏如来一役中是唯一的幸存者。天地风云录之魔戮血战小空篡权后跟在小空后面当跟班，在中苗鳞佛联军的攻势下，修罗国度在人世的驻军溃败，小空被网中人用魔茧包覆丢入海中，而再次失去靠山的杀生鬼言开始躲避玄之玄尚同会的追杀。金光御九界之魆妖记战败之后逃亡至东瀛，隐姓埋名，后发现修罗国度的印记，得知是戮世摩罗所留，重归麾下。

# 銀羽風少 (银羽风少)
================================================================================

銀羽風少

銀羽風少，。邪尊道妖誕四少之一，性格冷峻高傲，率性且精明幹練，相較於他人多了點心眼，說話尖酸、捉摸不定，但對組織和妖后相當忠心。善於狙擊，以一口猛禽展翅的天弓為武器，用途廣泛，不但能拆成雙刀，亦可御弓飛行。命格屬水，是使用天工八月泉水弦誅殺號天窮的人選。

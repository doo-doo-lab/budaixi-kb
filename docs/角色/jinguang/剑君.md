# 剑君

================================================================================

乃创作的网络小说《剑君》是中国网络作家乃创作的幻想言情类网络小说，连载于网络平台。作品以修仙世界为背景，融合转世重修、剑道修行等元素。小说讲述女主洛紫为寻回身体重踏仙途，发现前世佩剑化形成人，由此展开人与剑灵共修的故事。主线围绕其修炼历程，展现冷面女主与神秘剑灵男子的互动，融合修仙进阶与情感羁绊。作品以“暖甜宠”“苏爽”为基调，通过剑心历练等情节，塑造男女主1V1双向成长关系，并逐步揭开剑灵身世之谜。目录章节以意象化标题串联剧情，暗示修行关卡与情感转折。中文名剑君作 者乃小说类型幻想言情连载平台书香云集

==生平==
劍君十二恨，亦有人稱呼為**劍君**，以劍為名、仗劍天涯，致力追求劍的真意。

為人重情義、富正義感，自然率真而不造作，為傲骨桀然的劍界奇俠。

因過往的家中變故，而與胞弟驚虹留恨失去聯繫，而對親情極為重視，常有因此被騙的情況發生。

劍術師承**仇天**，為追求天下第一而步入江湖，背後劍架隨時帶有數把劍，視敵人強弱取用。

初時，因當時盛傳葉小釵為**天下第一快劍**而前往尋釁，但為素還真所勸，而改以特殊的**以筆論劍**決勝負，但其後，葉小釵因**元神出竅**走火入魔時為**劍君**所助而放水，是論戰被劍君十二恨以無效論。

驚虹留恨因故受創於葉小釵後，**劍君**因愛弟心切而受白雲驕霜指點，但其弟仍因白雲驕霜為與魔界交易，而被魔魁吸收。

敗於素還真所化身的神秘女郎**靈嘯月**後，一度意志消沉，但也受其推薦，成為儒教教主聖夫子閉門徒弟，而使雲本冷傲的性格漸趨圓融、睿智。

魔魁復生時，為素還真等人商請，與亂世狂刀、葉小釵等三傳人共同誅魔，但因為弟復仇之心過盛，反而使得實力無法發揮而敗於魔魁之手。

而後，拜入**八風吹不動**病劍叟門下，以求再創頂峰。

**七星之亂**時，病劍叟因為**劍王星**之身分而被紫星眉所殺，**越劍人**與**馴刀者**為求四刀四劍誅龍，而向當時身在病劍叟故居的**劍君**告知其師死訊。

**三先座**之一的策衍先座因當初不允四方無君襄助晚輩四無君一事而被其陷害，失去雙腳，憤恨欲報仇的**策衍**以**地凌劍**、**武馳劍**和**無玹劍**及**武痴絕式**向**劍君**交易，換取北無君、四無君等人之命。

其後，為追查嗜血者之事，而與段忍等人前往**嗜血者要地**，但不敵冰爵禔摩，段忍當場喪命，**劍君**亦為其嗜血。

因不甘成為**嗜血者**，在血液尚未被毒素侵占前，劍君再度踏上**玄空島**，最後雖因失血過多身亡，但其最後領悟的劍意也使得葉口月人及其首領九幽震撼，更引發後來傲笑紅塵的報復行動。

==武器==
#**寇心劍**:原本是劍君的師父天下第一關仇天所有，後來仇天的師兄司徒無憂滅門奪劍，劍君逃出，苦學三年後報了滅門之仇，並奪回寇心劍，此劍具有靈性，每逢九月初九，必感懷故主而泣血。

劍君曾把此劍插在琉璃仙境，並言劍泣血之日便是決戰之時，但被業途靈拔出化解。

#**十二無敵**:為劍君十二恨初出江湖所揹之劍架最上一層寶劍，外型十分特殊，劍鞘與劍身連在一起，狀似為兩柄夾扇，可用之夾住敵人之兵器，後為斷邪的復仇之手所斷。

#**霹靂無鋒長白劍**：拒生郎贈與劍君一把削鐵如泥，能斷絲巾，待開鋒之白色寶劍。

#**諸凰劍**:儒教鎮教之寶，原為夫子隱丘所收藏，後贈與其徒劍君十二恨，配合「四時江雨」劍招威力無窮，最後劍君又將此劍歸還給當時的掌教百里抱信，待百里抱信身亡此劍亦不知所終。

#**玉冰劍**:此劍劍刃乃是萬年不化之冰所鑄，鑄劍之人已不可考，但應是絕世的高人，並將自己的畢生的功力灌注劍中，所以劍上冷冽劍氣，一送即發，擋者血液凝結，而劍身絕不沾血，玉潔冰清故名玉冰劍。玉冰劍乃當年歐陽世家盟邦「南黑鳶」所有，門主委託特使歐陽勝天送至「北雪鷲」，做為訂親之聘禮，孰料歐陽勝天李代桃僵，騙了美人與寶劍，東窗事發後攜劍潛逃隱遁，後歐陽世家東山再起，歐陽勝天趁勢復出。後來骨董為報好友白羽長風客夫婦之仇，挑戰歐陽勝天，歐陽勝天不敵反死於玉冰劍下，玉冰劍遂為骨董所有，最後在天外方界陰謀下與劍君決鬥，死在劍君劍下，而玉冰劍也被劍君拿走，此劍最後出現於兵家堡。

#**巽風劍**:上古屠龍四劍之一，為八風吹不動病劍叟收藏於劍塚，後贈與劍君，對抗天策真龍屠龍八卦陣時配合使用，卦位乾屬天。是對付天策真龍所需的四刀四劍。

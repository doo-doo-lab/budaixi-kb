# 剑君

乃创作的网络小说《剑君》是中国网络作家乃创作的幻想言情类网络小说，连载于网络平台。作品以修仙世界为背景，融合转世重修、剑道修行等元素。小说讲述女主洛紫为寻回身体重踏仙途，发现前世佩剑化形成人，由此展开人与剑灵共修的故事。主线围绕其修炼历程，展现冷面女主与神秘剑灵男子的互动，融合修仙进阶与情感羁绊。作品以“暖甜宠”“苏爽”为基调，通过剑心历练等情节，塑造男女主1V1双向成长关系，并逐步揭开剑灵身世之谜。目录章节以意象化标题串联剧情，暗示修行关卡与情感转折。中文名剑君作 者乃小说类型幻想言情连载平台书香云集

## 角色背景 / 角色设定 / 形象设定

此为霹雳布袋戏人物，登场：**霹雳狂刀**第58集，退场：**霹雳劫之阇城血印**第21集于**玄空岛**上力战身亡。

剑君十二恨，亦有人称呼为**剑君**，以剑为名、仗剑天涯，致力追求剑的真意。

为人重情义、富正义感，自然率真而不造作，为傲骨桀然的剑界奇侠。

因过往的家中变故，而与胞弟惊虹留恨失去联系，而对亲情极为重视，常有因此被骗的情况发生。

剑术师承**仇天**，为追求天下第一而步入江湖，背后剑架随时带有数把剑，视敌人强弱取用。

## 角色经历 / 人物经历

初时，因当时盛传叶小钗为**天下第一快剑**而前往寻衅，但为素还真所劝，而改以特殊的**以笔论剑**决胜负，但其后，叶小钗因**元神出窍**走火入魔时为**剑君**所助而放水，是论战被剑君十二恨以无效论。

惊虹留恨因故受创于叶小钗后，**剑君**因爱弟心切而受白云骄霜指点，但其弟仍因白云骄霜为与魔界交易，而被魔魁吸收。

败于素还真所化身的神秘女郎**灵啸月**后，一度意志消沉，但也受其推荐，成为儒教教主圣夫子闭门徒弟，而使云本冷傲的性格渐趋圆融、睿智。

魔魁复生时，为素还真等人商请，与乱世狂刀、叶小钗等三传人共同诛魔，但因为弟复仇之心过盛，反而使得实力无法发挥而败于魔魁之手。

而后，拜入**八风吹不动**病剑叟门下，以求再创顶峰。

**七星之乱**时，病剑叟因为**剑王星**之身份而被紫星眉所杀，**越剑人**与**驯刀者**为求四刀四剑诛龙，而向当时身在病剑叟故居的**剑君**告知其师死讯。

**三先座**之一的策衍先座因当初不允四方无君襄助晚辈四无君一事而被其陷害，失去双脚，愤恨欲报仇的**策衍**以**地凌剑**、**武驰剑**和**无玹剑**及**武痴绝式**向**剑君**交易，换取北无君、四无君等人之命。

其后，为追查嗜血者之事，而与段忍等人前往**嗜血者要地**，但不敌冰爵禔摩，段忍当场丧命，**剑君**亦为其嗜血。

因不甘成为**嗜血者**，在血液尚未被毒素侵占前，剑君再度踏上**玄空岛**，最后虽因失血过多身亡，但其最后领悟的剑意也使得叶口月人及其首领九幽震撼，更引发后来傲笑红尘的报复行动。

==武器==
#**寇心剑**:原本是剑君的师父天下第一关仇天所有，后来仇天的师兄司徒无忧灭门夺剑，剑君逃出，苦学三年后报了灭门之仇，并夺回寇心剑，此剑具有灵性，每逢九月初九，必感怀故主而泣血。

剑君曾把此剑插在琉璃仙境，并言剑泣血之日便是决战之时，但被业途灵拔出化解。

#**十二无敌**:为剑君十二恨初出江湖所背之剑架最上一层宝剑，外型十分特殊，剑鞘与剑身连在一起，状似为两柄夹扇，可用之夹住敌人之兵器，后为断邪的复仇之手所断。

#**霹雳无锋长白剑**：拒生郎赠与剑君一把削铁如泥，能断丝巾，待开锋之白色宝剑。

#**诸凰剑**:儒教镇教之宝，原为夫子隐丘所收藏，后赠与其徒剑君十二恨，配合“四时江雨”剑招威力无穷，最后剑君又将此剑归还给当时的掌教百里抱信，待百里抱信身亡此剑亦不知所终。

#**玉冰剑**:此剑剑刃乃是万年不化之冰所铸，铸剑之人已不可考，但应是绝世的高人，并将自己的毕生的功力灌注剑中，所以剑上冷冽剑气，一送即发，挡者血液凝结，而剑身绝不沾血，玉洁冰清故名玉冰剑。玉冰剑乃当年欧阳世家盟邦“南黑鸢”所有，门主委托特使欧阳胜天送至“北雪鹫”，做为订亲之聘礼，孰料欧阳胜天李代桃僵，骗了美人与宝剑，东窗事发后携剑潜逃隐遁，后欧阳世家东山再起，欧阳胜天趁势复出。后来骨董为报好友白羽长风客夫妇之仇，挑战欧阳胜天，欧阳胜天不敌反死于玉冰剑下，玉冰剑遂为骨董所有，最后在天外方界阴谋下与剑君决斗，死在剑君剑下，而玉冰剑也被剑君拿走，此剑最后出现于兵家堡。

#**巽风剑**:上古屠龙四剑之一，为八风吹不动病剑叟收藏于剑冢，后赠与剑君，对抗天策真龙屠龙八卦阵时配合使用，卦位干属天。是对付天策真龙所需的四刀四剑。

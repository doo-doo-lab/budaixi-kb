# 醉弥勒

================================================================================

电影《三剑奇缘》角色醉弥勒是电影《三剑奇缘》中的人物，由中国台湾演员赵自强饰演。醉弥勒是天下三奇之一，身为得道高僧却也是酒肉和尚，修心不休口。性格爽朗率直、嫉恶如仇、笑看人间、深藏不露，武功为醉拳，武器是酒葫芦。中文名醉弥勒饰 演赵自强性 别男登场作品电视剧《三剑奇缘》、电影《三剑奇缘》

## 角色背景

醉弥勒是天下三奇之一，是一位得道高僧同时却也是酒肉和尚，其修心不休口，是个看破红尘俗事、游戏人间的智者与异人；个性爽朗率直、嫉恶如仇、笑看人间、深藏不露，武功为醉拳，武器是酒葫芦。

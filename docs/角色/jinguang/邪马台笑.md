# 邪马台笑

================================================================================

金光布袋戏虚拟人物邪马台笑，金光布袋戏虚拟人物，西剑流六部之兵部首领，不老族后代，实际年龄过百岁，东瀛出身，由黄立纲配音。初登场于《天地风云录之决战时刻》第8集，退场于《魔戮血战》第1集。身为西剑流铸将，性格豪爽嗜酒，与柳生鬼哭为多年好友，后与天海光流结成忘年交。因西剑流之乱留驻中原赎罪，成为中原对抗魔世的重要助力。帝鬼入侵时被天悬红练斩断右手，经默苍离指引前往黑水城重铸兵器。最终在天擎峡战役中为掩护群侠撤退，与天海光流联手对抗炽阎天，力战而亡。角色经历贯穿赎罪与义气主题，以断臂重铸、血战殉友为关键转折点，体现江湖情义与自我救赎的特质。

## 角色背景

西剑流兵部，不老族，个性爽朗，嗜酒，亦是典型江湖性情中人，会欣赏对手但仍坚持西剑流的立场。——（金光风云录）西剑流六部之兵部。

西剑流的铸将，是东瀛忍派血统【不老族】的族人，实际年龄已经有100多岁，力气极大，喜欢四处云游与喝酒，和柳生鬼哭为好友，在柳生鬼哭来到中原后，将一同聊天喝酒的目标转到天海光流身上，两人不知不觉间成了好友。——（决战时刻：桌布）西剑流“兵部”之首，不老族后代，年过百岁，为人豪爽，力大无穷，与柳生鬼哭是多年好友。

自从柳生鬼哭被调至中原后，改邀天海光流喝酒，因此与天海也成为出生入死、无话不说的好伙伴。

由于目睹忆无心的遭遇，勾起自己悲惨身世的回忆，不禁油然产生怜悯之心，逐渐与忆无心结为忘年之交。——（决战时刻：英雄扉页）西剑流六部兵部之长，为人豪爽，当至交柳生鬼哭调至中原时，与天海光流成为忘年之交，后为了赎罪而成为中原助力。——（决战金光：史艳文传奇）东瀛西剑流六部之一兵部之长，为东瀛不老族人，实际年龄已过百岁，为人豪爽、重义气、嗜酒，与柳生鬼哭是好友，到中原后常与天海光流一起行动，与其成为忘年之交。

也是忆无心认可的至交好友，在西剑流之乱后，为了替西剑流赎罪而留下成为中原助力。——（金光群侠传）东瀛西剑流兵部之长，为不老族人，实际年龄已过百岁，豪爽、重义气、嗜酒，与柳生鬼哭是好友。

到中原后常与天海光流一起行动，与其为忘年之交，也是忆无心的至交好友。

在西剑流之乱后，为了替西剑流赎罪而留下成为中原助力。

在魔世入侵时，与天海光流联手对抗炼狱尊炽阎天，奋战不敌，被落石所埋，绝迹至今。——（金光特展：180228）

# 常欣（中国国家画院美术馆副馆长）

================================================================================

本词条由百度百科艺术计划 参与编辑并审核，经艺术家本人认证 。百科已开放本人编辑服务，若您为词条本人可免费认领词条，解锁低门槛编辑特权立即前往常欣，1982年出生于河北省张家口市，中国国家画院美术馆副馆长、青年画院画家、一级美术师，文化和旅游部青年联合会委员，中国美术家协会会员，中国女画家协会理事。2004年、2007年、2010年先后毕业于西安美术学院国画系，分获学士、硕士、博士学位，2023年完成该校美术学博士后科研流动站出站考核。其参与国家社会科学基金重点项目《中国画院史》及一般项目《写意论》撰稿工作，创作《圪梁梁》获第四届中国西部大地情画展银奖。山水作品《云顶雪中飞》入选2020年度国家艺术基金青年创作人才项目。以副馆长身份参与策划“黄河文化主题中国画作品巡展”“大庆人画大庆——美术精品工程作品展”等国家级展览，2016年获“文化部青年拔尖人才”称号。中文名常欣外文名Chang Xin国 籍中国民 族汉出生地河北省张家口市出生日期1982年毕业院校西安美术学院职 业画家代表作品《圪梁梁》《赶牲灵》《印象陕北》《春雨贵如油》《戴月归》主要成就一级美术师，美术学博士  中国美术家协会会员 西安美术学院博士后文化和旅游部青年联合会委员艺术风格中国画、当代水墨

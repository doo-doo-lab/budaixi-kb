# 常欣

常欣，金光布袋戏虚拟角色，别名欣儿，由黄立纲配音。金雷村现任安龙祭巫女，性格天真乐观，常以独特视角解读世事，具有牺牲奉献精神。

## 称呼

- **欣儿**：长老称呼
- **巫女**：村民称呼
- **常欣**：锦烟霞、玄狐称呼
- **常欣姑娘**：俏如来等人称呼

## 角色简介

常欣身为金雷村现任安龙祭巫女，性格天真乐观，常以独特视角解读世事，具有牺牲奉献精神。

## 相关剧情

- 初登场时，常欣与俏如来谈论《白娘子传奇》的看法
- 常欣入魔被俏如来压制
- 常欣接纳锦烟霞回到金雷村
- 收容过负伤回来的锦烟霞和一步禅空
- 常欣感应锦烟霞不测
- 玄狐为常欣带回锦烟霞
- 常欣与玄狐谈论梁山伯与祝英台故事
- 常欣被玄狐告白
- 常欣命危得见俏如来

## 相关配乐

- **青石愿**：墨世佛劫第二片尾曲，玄狐与常欣主场
- **悟**：常欣、玄狐抒情曲，收录于《墨世佛劫原声带上》。魔世铁精玄狐，为了创造出属于自己的剑招，想要学会人类的感情。常欣费尽心思想要开导他，但玄狐却是执迷不悟，让常欣觉得很苦恼。
- **芳冢诉馀哀**：锦烟霞偕俏如来吊祭常欣，收录于《墨世佛劫原声带下》

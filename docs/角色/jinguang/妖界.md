# 妖界（金光布袋戏虚拟势力）

妖界是金光布袋戏虚构的九龙地界势力之一，由散布于劫海万洲的岛屿群构成。千年前与人界共生共存，后因通道封闭分裂为主战、主和两派，主战派首领酒吞童子战败后流亡东瀛，自称第六天魔王。后借云外镜重开通道，率旧部重返人世。月凝湾地脉被毁后，意外打开了妖界通道。妖界内部长期因资源与人妖对立引发纷争，半妖群体处境艰难。徐福挑拨导致内乱激化，仙岛入侵后地脉损毁，势力分化为祆灵漈国、晖煌鬼市、莱乡圣界三大核心，分别以夜宁宫据点、鬼市联通、人族科技为特征。妖界之中三大势力彼此争斗多年，神秘幽灵船与戮世摩罗亦涉入其中。妖界力量源自母晶能源与子晶锻造技术，夜煌废墟记载着妖族早期历史与“九龙吐珠”地脉传说。

## 势力概述

妖界为九龙地界之一，因大小岛屿遍布，又被称为劫海万洲。

千年前，妖界与人界相连，人妖共处，时有纷争。后两界通道断开，妖界内部分为主战主和两派，发生内乱。主战派战败，首领酒吞童子与部分部署被流放东瀛。

千年后，酒吞童子借助云外镜之力，打通妖界通道，召唤昔日旧部进入人世。

妖界内部封闭千年，人妖二族相互敌视冲突不断，而二者所生的半妖更是被二族歧视，直接或是间接的否定血统，内部势力为资源为生存爆发大战争斗不休，十年前劫海大战终结，各方势力得以喘息，直到仙岛入侵，毁地脉、立天柱，引发劫海动荡，封印破裂，妖界各大势力将再度冲突。

仙岛之乱解决后，月凝湾地脉被毁意外打开妖界通道，俏如来等人进入妖界。妖界之中三大势力彼此争斗多年，神秘幽灵船在劫海区域活动。

重要场景

### 重要场景

夜宁宫：妖界三大势力之一祆灵傈国妖王之根据地。

夜煌：始朝之前妖族的故乡，当时人族妖族比邻而居，后妖族内乱分裂，如今环境沙化，已为废墟。

晖煌鬼市：妖界三大势力之一，也是中原银槐鬼市的总部。

莱乡圣界：妖界三大势力之一，妖界中专属人族的圣地，以科技机关立国。

特殊物品

### 特殊物品

云外镜：能够打通妖界通道，开启空间之门。

离尘石：妖族可通过离尘石汲取能量。离尘石亦可用于打造灵器、兵器，如藏镜人的墨邪盾、忆无心的七彩云珞。实为妖界子晶，可感应妖界母晶的所在地。

妖界母晶：可吸收力量，攻击造成的冲击，甚至术法也能吸收的铸材，为妖族子民力量的供应来源。

# 妖界（金光布袋戏虚拟势力）

================================================================================

妖界是金光布袋戏虚构的九龙地界势力之一，由散布于劫海万洲的岛屿群构成。千年前与人界共生共存，后因通道封闭分裂为主战、主和两派，主战派首领酒吞童子战败后流亡东瀛，自称第六天魔王。后借云外镜重开通道，率旧部重返人世。月凝湾地脉被毁后，意外打开了妖界通道。妖界内部长期因资源与人妖对立引发纷争，半妖群体处境艰难。徐福挑拨导致内乱激化，仙岛入侵后地脉损毁，势力分化为祆灵漈国、晖煌鬼市、莱乡圣界三大核心，分别以夜宁宫据点、鬼市联通、人族科技为特征。妖界之中三大势力彼此争斗多年，神秘幽灵船与戮世摩罗亦涉入其中。妖界力量源自母晶能源与子晶锻造技术，夜煌废墟记载着妖族早期历史与“九龙吐珠”地脉传说。

**中文名**：妖界

**别名**：劫海万洲定 位中土九龙地界之一

**登场作品**：金光布袋戏

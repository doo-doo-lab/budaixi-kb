# 羽国

金光布袋戏虚拟势力羽国是金光布袋戏中的虚拟势力，为九界之一。羽国曾发生九羽内乱，雁王在化名盗才生、策天凤者辅佐下平定内乱，驱逐潜伏在羽国的九算老五凰后。凰后在羽国内乱时著作《羽国志异》。

## 来自百度百科的补充

地界概述 羽国为九界之一（九界分别为：中原、苗疆、海境、佛国、魔世、羽国、道域、妖界），全名平旭羽国，为信仰太阳的国度，羽国先祖开国君王大羿平定九个欲兴动乱部族继承者，创立羽国后流传于世成为羿射九日的传说。后大羿设下羿畿，由九地齐奉为主，诸侯不服，九地共讨，选贤与能，禁家天下。十几年前羽国九羽内乱，其时，墨家九算中的老五凰后潜伏于羽国，著作《羽国志异》，并与其他九算成员散播孛星之说，意图引出墨家钜子。墨家钜子万军无兵策天凤（默苍离，化名盗才生）辅佐雁王上官鸿信平定了羽国持续三年的内战，一统羽国。期间雁王之父翊地鹤王、妹妹霓裳公主牺牲，战后默苍离离开羽国。而王骨彤弓弽下落不明，翟地大将翁翼生、鴊王之子也莫名失踪。羽国和平数年后，雁王禅位于鹭王，离开羽国。

### 势力设定

组织结构：羽国朝堂（正常）—— 君主：大羿（开国君王）、上官鸿信（雁王）、鹭王（现）；诸侯：翩地鹞王、翎地鹰王、翟地鴊王、翊地鹤王；其他：比鹏将军、霓裳公主、翁翼生(翟地大将)；流放：扁鹊、鸩罂粟。墨家羽国分部（正常）—— 首领：凰后；成员：墨无书、擎掠鹰、别离燕。其他正常：羿鬼晨。

### 代表人物

雁王：姓名上官鸿信。本名上官鸿信，前任羽国之主。个性阴沉而稳健，心计深远而可怕，修习羽国镇国神功寰羽诏空神卷，武功高绝。甫一入世便接连布局拔除墨家九算，却又与九算之一的凰后维持合作上的平衡，与新任钜子俏如来关系微妙。以动乱九界为行事准则，所作所为无不挑战着对手的信念与人性，被视为黑暗、浑沌的存在。称号：雁王。身份：羽国前任国主。性别：男。种族：羽族。组织：羽国朝堂（已禅位）。武器：断云石。

凰后：姓名凰后。当世九算排行第五，姿态妖娆，风情万种，在收服人心方面甚有天赋。长期蛰伏于尚贤宫，暗中观察局势，并掌握墨家使徒名册，与雁王联手收揽墨家成员，并接连算计玄之玄、铁骕求衣，以取得止戈流、继承钜子为目标，意图完整墨家，并回归黑暗，让自己成为黑暗界的王者。擅长以虚实相参的流言带动风向，操纵舆论，使局面导向自己所想要的状态。身份：墨家九算之一。性别：女。种族：人族。组织：墨家。武器：断云石、裂羽铳。诗号：封侯盛世灯宵，权衡天下，百代风骚。功名不过传谣，回眸一笑，举步烟硝。

### 重要场景

羿畿：羽国首都，中央政权所在地。翩地、翎地、翟地、翏地、羿地、翁地、翾地、翔地、翊地：羽国九大地域封地，九地各有一方诸侯坐镇，其奉君王为尊。云天关：进入羽国所经之地。彩虹桥：进入羽国所经之地。星河之阶：进入羽国所经之地。霓霞关：羽国战乱霓霞之战之地。

### 特殊物品

断云石：羽国特产，可产生奇特战能，能够操纵越多断云石，则其实力越强。通常能够操纵三颗断云石，即为绝顶高手，而使用羽国镇国神功寰羽诏空神卷可以突破操纵超过三颗断云石的限制，且能够心随意发，任意变化断云石的形态。裂羽铳：鲁缺按雁王要求所造，能充分发挥断云石特性的武器。结合断云石的结晶，可融合使用者自身内力，既能单点狙击，亦能散发退敌。羽国志异：记录墨家钜子在羽国平定祸乱的故事，为凰后所著，其中内容有虚有实。寰羽诏空神卷：唯有羽国王族血脉才能修炼的羽国镇国神功，心随意发，任意变化断云石的形态(神物任化)，更能突破三颗断云石的界限。彤弓弽：羽国开国君王大羿所留传世王骨，可不由寰羽诏空神卷变化断云石的形态，变化后甚至接近断云石的本质不受任何影响，九羽之战后下落不明，现为羿鬼晨的兵器。

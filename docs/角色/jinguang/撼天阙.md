# 天阙孤鸣

================================================================================

金光布袋戏虚拟人物天阙孤鸣，别称撼天阙，是金光布袋戏中的虚拟角色，由黄立纲配音。身为苗疆前代大王子及颢穹孤鸣与千雪孤鸣的异母长兄，曾率军为苗疆开拓半数疆土，因王室夺嫡之争遭颢穹孤鸣与老苗王陷害，背负刺杀苗太祖罪名被囚于罪海七恶牢三十年。天阙孤鸣性格嚣张跋扈，因王位继承权及与挚爱希妲的恋情引发宿怨，最终被命运拆散。苍越孤鸣为对抗北竞王，以自残方式求其协助复仇。鱼龙穴决战中，天阙孤鸣将毕生功力传予苍狼后身亡，临终前立誓来生追随副将战兵卫。苗疆祭鼓节期间，苍越孤鸣颁布诏令恢复其皇室身份，终结其罪囚之名。

## 人际关系

师徒亲友皇祖父：祖苗王父皇：前任苗王（当时还是太子）皇弟：颢穹孤鸣（苗王）、千雪孤鸣（狼主）皇叔：竞日孤鸣（北竞王）皇侄：苍越孤鸣（苍狼）挚爱：希妲挚友：夙（战兵卫）苗疆朝堂（祖苗王主政时期）君主：祖苗王皇室：竞日孤鸣（小皇子）、天阙孤鸣（大皇孙）、颢穹孤鸣（二皇孙）、千雪孤鸣（小皇孙）部下：战兵卫（夙）西苗联军扶持：苍越孤鸣（苍狼）王族亲卫：冽风涛、岁无偿、叉猡、司空知命、慕云追逸、月荒凉部下：嚓哈雷、孟赫、奉天对手仇敌对手：颢穹孤鸣（苗王）、竞日孤鸣（北竞王）

## 角色经历
天阙孤鸣出身正统而且天资过人，深得当时苗王即其祖父重用，因嚣张狂傲，被身为王子的自己父亲所不容，于是被父亲及异母弟弟颢穹设计陷害而被囚罪海七恶牢三十年。

后苍狼被北竞王追杀，逃至罪海七恶牢，以自我牺牲换取了撼天阙的帮助。

撼天阙对苍狼极尽凌辱折磨，以报复苍狼之父，自己的异母弟弟，颢穹孤鸣。

但又因苍狼是一生挚爱希妲之子，对其心生不忍。

后来撼天阙杀死战兵卫，见到北竞王送上的希妲遗物，明白当年战兵卫与希妲的苦心，又听见苍狼的月下独白，终于醒悟，决定全力帮助苍狼夺回王位。

在鱼龙穴陷入绝境时，慨叹自己一生，承认是自己性格造成自己一生悲剧。

在传功给苍狼之后说出希望苍狼是自己的儿子的话语。

临终恍惚，似又见战兵卫，说出来世将换自己一生追随战兵卫的誓言后死去。

结束坎坷又悲壮的一生。

苗疆祭鼓节时，苍狼下诏恢复皇室身份。

# 慕容清（金光布袋戏虚拟人物）

================================================================================

慕容清是金光布袋戏虚拟人物。天剑慕容府之主慕容烟雨之九妹，现已离世，保管慕容十三器之一的神兵磐龙刃。慕容清死后，礊龙刃成为墨家九算老二铁骕求衣之兵刃，慕容宁曾言，慕容府剑法万千，慕容清擅长以刀行剑并且是此道的佼佼者。曾化名冰心无垢沐雪清行走江湖，与名为向云飞（铁骕求衣）、凌风歌（接天岚）之人一同惩恶除奸，留有侠名。表面上得知凌风歌与其相恋只是为了骗取慕容家的武学，产子托孤后羞愤自杀，但这一切都是铁骕求衣所安排的假象，实际上慕容清乃是为了配合铁骕求衣计划而自愿牺牲名节，冷秋颜之父亦并非凌风歌。

**中文名**：慕容清

**别名**：小清

**配音**：黄立纲

**性别**：女

**登场作品**：金光布袋戏化 身冰心无垢·沐雪清

**种族**：人族归 属中原

**组织**：天剑慕容府

慕容清(通天狄仁杰虚拟人物)

慕容清是电视剧《通天狄仁杰》中的虚拟人物，由阚清子饰演。慕容清从小受龙潜训练，后被濮王李泰派到狄仁杰身边卧底，她一方面深爱狄仁杰，却不得不受制与濮王，成了名副其实的双面伊人。

# 慕容清（金光布袋戏虚拟人物）

================================================================================

慕容清是金光布袋戏虚拟人物。天剑慕容府之主慕容烟雨之九妹，现已离世，保管慕容十三器之一的神兵磐龙刃。慕容清死后，礊龙刃成为墨家九算老二铁骕求衣之兵刃，慕容宁曾言，慕容府剑法万千，慕容清擅长以刀行剑并且是此道的佼佼者。曾化名冰心无垢沐雪清行走江湖，与名为向云飞（铁骕求衣）、凌风歌（接天岚）之人一同惩恶除奸，留有侠名。表面上得知凌风歌与其相恋只是为了骗取慕容家的武学，产子托孤后羞愤自杀，但这一切都是铁骕求衣所安排的假象，实际上慕容清乃是为了配合铁骕求衣计划而自愿牺牲名节，冷秋颜之父亦并非凌风歌。中文名慕容清别 名小清配 音黄立纲性 别女登场作品金光布袋戏化 身冰心无垢·沐雪清种 族人族归 属中原组 织天剑慕容府

慕容清(通天狄仁傑虛擬人物)

慕容清是電視劇《通天狄仁傑》中的虛擬人物，由闞清子飾演。慕容清從小受龍潛訓練，後被濮王李泰派到狄仁傑身邊臥底，她一方面深愛狄仁傑，卻不得不受制與濮王，成了名副其實的雙面伊人。

基本介紹
- **中文名**: 慕容清飾演：闞清子登場作品：電視劇《通天狄仁傑》性別：女
 劇集介紹,人物介紹, 劇集劇情介紹《通天狄仁傑》由李文龍、葉昭儀執導、任嘉倫、闞清子、焦俊艷、繆俊傑、陳奕、郭曉冬、王雨、白冰、曹馨月等主演古裝劇。該劇已於2014年7月5日在橫店影視城開機，10月29日全劇殺青。人物介紹慕容清經歷坎坷，她與狄仁傑從一場陰謀政變相識，兩人經歷了歡喜冤家浪漫初戀，經歷了很多事情之後，性情大變。之後慕容清又受到濮王要挾，到狄仁傑身邊臥底。慕容清開始用冷漠來武裝自己，變成了一個外表冷漠，但卻不泯真誠善良的本性的冰塊臉。

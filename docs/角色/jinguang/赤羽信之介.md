# 赤羽信之介

金光布袋戏虚拟人物赤羽信之介，金光布袋戏虚拟人物，西剑流军师，同时亦为四天王之一。曾协助祭司侵略中原。后为报恩，来到中原，在《魔戮血战》中得悉中原与俏如来遭受魔世大军威胁，便从东瀛返回中原帮助俏如来。在《墨世佛劫》时期，赤羽信之介协助俏如来对抗魔世，与北竞王谈判，联手铁骕求衣和欲星移击溃妖魔海，但遭玄之玄陷害而重伤，与俏如来一同被中苗两界追杀，后与铁骕求衣定计破坏忘今焉的阴谋。为人恩仇分明，严于律己，极重情义，治理西剑流在严厉中仍保有一分情分，使得部下能够信服，堪称维系西剑流团队的核心灵魂。

## 经历

魔世入侵后，赤羽信之介带着神田京一立即动身前往中原，最终与胜邪封盾汇合，助胜邪封盾发起反攻的号角。与北竞王谈判得其出兵相助中原抗击魔世的承诺，代价是帮其驻守万里边城。同时以为网中人创造机会杀戮世摩罗为条件，挑拨其袖手边关战事。与苗疆军长铁啸裘衣、鳞族师相欲星移联手射出十里之箭，击溃魔世的强力军妖魔海，一解魔世兵围黑水城之危。对魔之战胜利后，原本代替中原主持大局的俏如来与赤羽将功劳拱手让给玄之玄。赤羽欲劝说玄狐，结果落入玄之玄陷阱，玄之玄与玄狐协议，以杀赤羽换取看飘渺剑法的机会，赤羽重伤。最终导致俏如来和赤羽信之介遭至中苗两界追杀。

## 竞日孤鸣角色赏析

为西剑流军师，武功亦属西剑流四大天王之一，火属性的溘钨鐁威力强大（代表武学有：赤洪飞羽、朱雀天火、朱凰蚀炎等，随身兵器为凤凰刀），心思细腻，思维缜密，容貌威严俊美，协助祭司侵略中原，与以中原为主的各方势力展开争斗，行事风格上，果断而不失情理，使同侪与部下皆对他心服。

其后受俏如来之恩，使西剑流免于在炎魔幻十郎手中全军覆没。

赤羽因此感念在心，因此在收到了欲星移伪造的神蛊温皇信件，得知魔世之乱后，协神田京一再返中原，有恩报恩，有仇报仇。

赤羽在个人情感方面多得剧中女性青昧。

雨音霜和衣川紫曾倾慕于他。

在与神蛊温皇对战中，赤羽救了雨音霜，霜逐渐萌生少女情怀，倾心于赤羽（后转为雪山银燕）。

其为人情深义重又甚为自律，与同为西剑流四天王的月牙泪，宫本总司以兄弟相称。

曾因感念兄弟之情而放走叛逃的月牙泪亲弟月牙岚，自请受三鞭戒灵鞭之刑，强撑着退回后吐血昏迷。

被宫本总司所瞒叛逃西剑流后，也十分痛心和怀念。

在流主炎魔幻十郎复活后采取的各种偏激政策下，赤羽带领西剑流谋求出路。

曾派邪马台笑和天海光流绑架扣留忆无心，利用女暴君的情报，设计史艳文藏镜人在天允山暴露兄弟关系，使其二人被天下人追杀，中原群龙无首（后由俏如来接管）。

天允山最后一战中破温皇三道杀局，却被俏如来入局于外功亏一篑。

为避免西剑流全军覆没于炎魔幻十郎之手，带领西剑流众人当场倒戈，与史藏等人合作，祭出凤凰刃于柳生鬼哭之手，完成诛杀炎魔的最后一击。

九龙变中与神蛊温皇会面于还珠楼，揭开任飘渺四人真假之谜，随着西剑流第一次退场。

魔世入侵后，接到假冒书信（后证实为欲星移所做）协神田京一再返并相助中原。

与北竞王谈判得其出兵相助中原抗击魔世的承诺，代价是帮其驻守万里边城。

同时以为网中人创造机会杀戮世摩罗为条件，挑拨其袖手边关战事。

与苗疆军长铁骕求衣、鳞族师相欲星移联手射出十里之箭，击溃魔世的强力军【妖魔海】。

黑水城被围时，与铁欲两人合谋，说服黑白郎君对战戮世摩罗，釜底抽薪解黑水城之围。

并亲自投入战斗，在黑水城外围决战炼狱尊，以朱凰蚀焰重创炼狱尊后，欲杀之为邪马台笑和天海光流报仇，最终因欲星移故意拖延缺少支援使得炽焰天被曼邪音所救。

四方山一战中，在忆无心的帮助下，带领士兵从地下转移潜入至战场，成功围困修罗国度。

赤羽与神田京一返回中原后，最终与胜邪封盾汇合，并立即协助发起反攻。

魔世之乱结束后协助俏如来对抗墨家九算，过程中两人因情报缺失导致误判陷入困境，被尚同会以及九算追杀至重伤。

此困境实为墨家九算之一玄之玄的阴谋。

玄之玄与玄狐达成协议，以杀赤羽换取观看飘渺剑法的机会，导致赤羽重伤，救援受阻。

逃至苗疆后因掩护俏如来而被俘，九算忘今焉阴谋被揭破后恢复自由之身，并提点苗王苍狼对付忘今焉之法。

为保证苗疆利益，铁骕求衣违抗王命，将赤羽与神田京一暗中送回中原，并委托赤羽前往月凝湾救助风逍遥。

其后协助俏如来交锋雁王，布三道防线保护俏如来决战玄狐后平安撤退，彼时与西剑流众人约定的一年之期已至，与俏如来道别并对瘫痪的温皇言语相激后，与神田返回东瀛，却在海上遭残忍联盟大军拦截，两人在千人大军的围攻和残联的人质要挟下赤羽被擒，被关在残忍联盟本部牢房内遭受酷刑，被望月咲的七窍水银针封住功体。

被西剑流残留人员救出后，功体尽失的情况下单独约见竹龙众之主上杉龙矢，与之谈判达成合作，成功取得西剑流喘息空隙，在上杉龙矢的协助下拔出水银针后，与对方以及剑无极的协助下成功引导残忍联盟局势，一抗酒吞童子胧三郎。

充满和风的鼓声、琵琶与能管，依据日式五声音阶奏出了悠扬的旋律。
清新的曲风、轻快的节拍，勾勒出赤羽信之介身为西剑流军师，胸有成竹、运筹帷幄的智者身姿。
衬底的各式打击音效细碎而绵密，则反映其思虑周密、务求面面俱到的个性。
6、赤凤舞天流（赤羽信之介武戏曲）收录于《魔戮血战原声带贰》
坚决的鼓点，以快板呈现，背景的拍击，则以更为紧凑的急板疾行，令人冒汗屏息。
尺八的吹奏跟着分进合击，交代角色的东瀛背景，也营造风声鹤唳的气氛。
打击的声势在乐曲后段持续加强，进一步加入了狂放的电吉他和高亢的笛声，更显热血激昂。
7、宿敌扶桑犹抱信（西剑流再入中原）收录于《魔戮血战原声带贰》
雍容的钢琴音符在胡琴伴奏下，犹如雨后阳光温煦洒落凡尘。
雄壮的鼓声与铜管随后出现，节奏渐快、力道渐烈，搭配深具电影风格的旋律，营造出天地般的磅礴感。
其后出现的电音则将听者引领向另一个情绪的高峰，期盼故事新章的来临。
8、朱雀啸空（赤羽信之介气势曲）收录于《魆妖纪剧集原声带》
何处击鼓声，伴随萧声渐出，快节奏的三味线描绘出赤羽信之介运筹帷幄时的不凡自信的神态。
再回东瀛的他面对全新局势，为保西剑流周旋在残忍联盟诸门派间，更与风间烈一同力抗胧三郎带来的灾殃。
9、朱凰烨舞（新赤羽信之介角色曲）收录于《魆妖纪剧集原声带》
悠远的乐声若凤凰昂首唳鸣，自苍穹旋飞来临，节奏错落有致的三味线，是焰华中的凤凰翩然起舞，赤色华羽漫天纷落，行云流水的曲风，是浴火重生后的西剑流首席军师赤羽信之介，惊鸿再现。

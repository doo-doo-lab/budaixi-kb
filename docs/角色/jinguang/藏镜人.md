# 藏镜人（金光布袋戏虚拟人物）

================================================================================

藏镜人，金光布袋戏虚拟人物，因布袋戏的风行，“藏镜人”一词成为台湾俚语中“幕后黑手”的代称。苗疆战神，甲子名人帖上，与史艳文并列天下第一掌，

**本名**：罗碧，豪气万千、我行我素，唯我独尊，长年以面具遮掩面容，因国仇家恨而视史艳文为毕生宿敌。在女暴君刻意透漏讯息、西剑流胁持忆无心的双重压迫下，藏镜人被迫在众人面前摘下面罩，揭露其为史艳文孪生

**兄弟**：秘辛，因此遭到追杀，其后历经许多心境转折，更于史艳文重伤昏迷的当下，藉其身份领导中原，安定人心，然而颢穹孤鸣却因预言而穷追不舍，藏镜人遂愤怒反扑。

## 角色经历
决战时刻2012年的《天地风云录之决战时刻》中因为好友神蛊温皇与东瀛西剑流军师赤羽信之介等人的策画下（主要因为与女暴君所生之女忆无心被东瀛西剑流绑架），被迫在众目睽睽下披露真面目，导致史艳文及藏镜人两人因其兄弟身份分别招致中原及苗疆之追杀，并且在种种因素下与史艳文在山洞中决斗，被史艳文打昏互换身份而逃出生天，并且于之后兄弟二人处于心和口不和的状态，一般是藏镜人怒呛史艳文而史艳文挖苦藏镜人的情况，但无论如何不满，过往藏镜人叱骂史艳文的“史狗子”却不会再说出口，同时揭露史家老奶奶(史艳文及藏镜人的母亲)尚在人世。

在《天地风云录之九龙变》，与史艳文次子小空被入灵夺舍，而复活的东瀛西剑流流主炎魔幻十郎的一战中，史艳文为救藏镜人而挡下炎魔幻十郎意图同归于尽之杀招，身负重伤而昏迷不醒。

藏镜人便伪装史艳文的身份，方便四处奔走于武林中，寻求医治藏镜人（即史艳文）的方法。

第12集时，在藏镜人（即史艳文）清醒后，两人对谈中说明了兄弟互换的真相，为了偿还受伤时而服下史艳文给予的‘阎王低头’（疑似决战炎魔重伤所致）之恩情，加上史艳文虽病愈却脚部残废的后遗症，使藏镜人自愿承担继续暂代胞兄身份成为中原指标性领袖，辅助史的两个儿子俏如来和雪山银燕成长，而史的用意更是为了让藏镜人获得中原众人谅解，成为正气之人。

及至《九龙变》后期藏镜人假扮史艳文之身份，被女暴君识破并招来苗疆大军之追杀。

藏镜人为保其爱女忆无心之安危而暂避苗疆北竞王王府，但北竞王收留藏镜人之目的实为引导藏镜人于九龙天书之局中刺杀苗王。

苗王死于藏镜人之手后，北竞王告知其事实真相。

伤疲之下，藏镜人及其义兄弟千雪孤鸣合力也无法击败北竞王，二人于坠落地底深渊后遭佛国八大支脉之一的“地门”救起并以术法控制记忆为地门效力。

在《墨邪录》中，藏镜人为了行走江湖方便而身穿黑甲金装，化名天地不容客，从元邪皇手下援救史艳文等人，而后袭击雪山银燕，并指导雪山银燕武学和战斗理论，雪山银燕认真遵守师父宫本总司教导止杀的思想，但藏镜人却道破若你不够强而不能杀(亦即并非不想做，而是能力上做不到)，又如何止杀的概念，同时要求他在几日内击杀数百魔兵。

有别于史艳文的温良作法，藏镜人虽模仿兄长的口吻和态度维妙维肖，但不免几次透漏出强硬以及不拘泥手段的原有性格来处理危机，反而令戏迷感到新鲜和有趣。

然而随着剧情发展，常可见史艳文在为人处世之上并非不知变通或有其他较为极端的手段，却只是不选择这种处理方式，于战斗中大多也是强压弱的方式取胜。

反观藏镜人渴望亲情、不怕强敌、不断重伤又不断突破自我而战胜对手，除了引起戏迷内心代入感外，也成为剧中能以个人的出场就可逆转局势的少数人之一。

两人差异最大的或许不是为人处世，迥然有别的更是对家庭、亲情的态度，特别在于对儿女的教育(溺爱)上，以“谁敢伤害忆无心(藏镜人女)”一句话足可证明藏镜人对女儿的宠爱，然而，或许因为忆无心是女性且几乎不会武功(必须受人保护)，加上早年两人分离的缘故，所以让藏镜人成为金光剧中女儿控的代表性人物。

## 角色评价

藏镜人为什么称之为藏镜人？

闯荡江湖之初，藏镜人因缘际会取得一面魔镜，行走江湖之际，隐身在一道光之后，向敌人发动攻击。

藏镜人可以说是台湾电视布袋戏史上第一位大魔头，即使在新角色层出不穷，其形象仍是十分鲜明，在许多戏迷心中始终仍占有一席之地，黄俊雄塑造这个角色可以说相当成功。

布袋戏中经常可以看见以光芒掩身的高手或先觉，藏镜人正是第一位以这种方式出场而让观众印象深刻的角色，让人觉得神莫测，就算他现身时也是将面貌覆上，鲜少亮出真面目，也就因为如此，“藏镜人”成为台湾社会中一个代名词(或形容词)，用以形容幕后黑手或是神秘莫测的人物。

藏镜人虽是黑道大魔头，但性格独特，恩怨分明，史艳文虽是他的死对头，却也曾是报恩的对象，而藏镜人固然狠辣、擅使阴谋，但对敌时从不倚多为胜，不使小人伎俩。

藏镜人亦甚有智慧，对敌时固是威风八面，运筹帷幄时也是气派非凡，他也不是莽夫，有时候也会忍口气、退一步，所以藏镜人一生中虽非无往不利，但始终不至一败涂地，能够保住性命。

比起金庸笔下几个最突出的反派人物，诸如欧阳峰、东方不败和任我行等，藏镜人毫不逊色，甚至有过之而无不及。

藏镜人之仇史艳文可以说是藏镜人最大的仇人, 因为史艳文之父史丰洲生死不明, 虽然一度传闻正义英雄中国强是史丰洲所化, 但父仇子还的心态使得藏镜人认定史艳文是世仇, 从一开始要看到史艳文的孤立无援。

到后来的要史艳文成为废人，再到要想亲手杀死史艳文, 当中的复杂交错已经超越父仇，可见已转化成个人仇恨。

藏镜人在霹雳城中, 藏镜人曾被感化，惭愧自己的所作所为， 并弃暗投明, 帮助史艳文。

但再度被邪恶化，内心的邪恶仇恨再度被引出, 到了欲罢不能的地步…… 一直到了黑白龙狼传时期，藏镜人终于逼得史艳文与他单独终极一战，数十年仇恨终该了解, 可是黑白郎君的介入, 无法完成战役...在史艳文被东瀛组织西剑流所擒, 藏镜人不但设法救之, 还帮助中原群侠对抗西剑流, 为的就是不让史艳文死在他人手上... 史艳文与藏镜人的恩怨情仇, 持续了将近半个世纪的对抗, 终于在天地风云录之决战时刻上演真真正正的了结。

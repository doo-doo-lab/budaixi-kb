# 北冥华

金光布袋戏虚拟人物北冥华，金光布袋戏虚拟人物海境二皇子，性格昭如朗月，心直口快，重视亲情，因前皇后之子的身份卷入夺嫡纷争，虽一度被立为太子，终因未贵妃阴谋败露而位废，以脚上功夫武学闻名，最终不幸于乱世中殒命。

## 人物设定

以之教授北冥华，为两兄弟之间的羁绊。

北冥觞亡故后，转由北冥华所拥有。）名字含义：鳞王为其取名为华，期望他一生荣华富贵，衣食无忧太虚海境二皇子，为人昭如朗月，心直口快，毫无心机，喜饮酒作乐。

同前太子北冥觞一样乃是鳞王（北冥封宇）一生挚爱的前皇后·贝璇玑之子。

在一众皇子中是开朗大方之人，任何东西都会献出和众兄弟分享，极为重视亲情。

在鳞王昏迷后现身参与夺嫡乱局，更有雨相之子卧寅（实则是狷螭狂顶替身份）暗中献策。

而在未贵妃执政期间受封的太子之位也因未贵妃阴谋败露而被鳞王收回作废。

## 角色经历
京王陨落北冥华为海境已故太子北冥觞一母同胞的兄弟，两人感情甚笃，在北冥觞死后，积极夺取太子位。狷螭狂假借卧寅身份，辅佐北冥华，与北冥缜、北冥异争斗。海境内乱，北冥华与北冥异坐镇后方，但因雨相覆秋霜之阴谋，导致北冥华被杀，死前希望北冥异能够放过其父皇北冥封宇。

## 人物评价

心直口快，刚愎自用，不识大体，好大喜功，自大傲慢，做事不考虑别人感受。但又善良单纯，尤其对血亲有情有义，不仅为霄王押下群臣奏折，更在误认为霄王仍图谋不轨的情况下拼死救霄王出死局，临死将奏折交给霄王，希望他“放过”父王。是一个相当复杂，可恨可悲但又可爱的角色。

## 拓展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之战血天道》。

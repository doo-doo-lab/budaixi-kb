# 狼主（金光布袋戏虚拟人物）

================================================================================

狼主是金光布袋戏虚拟人物。

苗疆狼主，系前苗王颢穹孤鸣之弟，现任苗王苍越孤鸣之皇叔。

与藏镜人、神蛊温皇并称“苗疆三杰”。

性格爽朗，不喜约束，刀法绝伦，并精通药理与奇门遁甲之术。

曾经施展过皇世经天武典打败黑白郎君分身——白狼。

性格极重感情，视藏镜人如亲兄弟，在剧中多次帮忙藏镜人和其女儿忆无心。

曾对神蛊温皇的漠然感到不谅解，但心里还是希望苗疆三杰的友情能够一如往昔，对苗王来说是个不乖的王弟，但是感情很好。

有时会扔到其克星——北竞王处管教，修习皇世经天宝典中的“星辰变”。

被竞日孤鸣（北竞王）无情追杀后，与藏镜人进入“地门”，被洗记忆，和银娥成亲，是有名无实的夫妻。

并成为了大智慧座下的四大天护之一，在念荼罗的领导下，攻下天门。

后因俏如来说服大智慧，大智慧将记忆归还众人，回归苗疆，辅佐苍越孤鸣。

昨颜非胜身陷海境王权斗争，狼主与玄玉府将领昨颜非交战，并将其击毙。

樱吹雪平为抢夺王骨，樱吹雪与狼主相斗，最终平局收场藏镜人平十年前，狼主与藏镜人以招式切磋，点到为止，平手。

## 医治记录

伤病类型对象结果详情心病北竞王无果北竞王天生体弱，疾病缠身，为治愈他，狼主开始学习医药之术。

但其实北竞王实为装病，身体无恙，病在心中。

内伤藏镜人治愈藏镜人以纯阳之体，逆练极阴之功，虽功成，但自身重创。

狼主与温皇一同为其治疗，历经千辛，方将其治愈。

中毒地门众天护治愈神蛊温皇闯地门之时，对身陷地门的四大天护施以蛊毒，狼主虽能解此蛊毒，但是众人仍需调息。

战伤北冥封宇压制北冥封宇与元邪皇一战，身受重创，狼主与修儒皆前往为其诊治，无奈只能为其稳住伤势，并不能令鳞王苏醒，最后虽然将鳞王治愈，但最主要之功，无关狼主。

战伤藏镜人治愈藏镜人与黑白郎君于海境洄森岗交战，战后藏镜人受到内伤，狼主给予丹药，助其疗养。

中毒苗疆众人治愈苗疆民众与部分重臣受到阎王鬼途阴谋设计，身中亡命水控制，在以药神为首的医者最终将苗疆众人治愈。

战伤李剑诗缓解李剑诗、别小楼受计遭围，阎王鬼途与鬼市人马将李剑诗打成重伤，苗疆等人前来救援，狼主以丹药暂缓李剑诗伤势，但其伤势过重，无法凭借丹药治愈。

# 仙岛（金光布袋戏虚拟势力）

仙岛是金光布袋戏中的虚拟势力，属于中土九龙地界之一。空间变异、九界逆乱后，仙岛侵略随即而来，率先拿下中苗地界。仙岛居民拥有坚定信念，但信念会整体转变。反抗司马王朝的六大势力以南斗六星为代号。仙岛七王意欲一统九界，其中“天璇巨门”实则为太叔雨，是侵略的重要推手之一。七王对应七星法阵，辅助剑之盾、冰之壁的守护之招。

## 来自百度百科的补充

九龙地界之一，九界中最神秘的一界，根据九龙天书的记载，中土九界，人族共居五处，中苗佛道仙，也是金光布袋戏剧情中最后登场的九界势力。欲往仙界，必须渡清圣桥，但四百年前随着清圣桥消失，以无人知晓仙界消息。直到九龙地脉破损，血神之力、王骨天师云杖等极招共鸣，引爆空间动乱，清圣桥的指向不再是单一境界，仙岛势力彻底出世。随后，空间变异、九界逆乱，破碎的清圣桥传来警告，仙岛侵略随即而来，率先拿下中苗地界。 六甲子以来，仙岛由玄朝皇室司马一族后代统治，陈腐以现，后内部争斗，七王并立，各大势力纷纷崛起，最终因天璇巨门（实则为「舞啸笔狂」太叔雨的另一个身份，兼具「仙岛七王」、「鬼谷四慧」、「墨家九算」三重身份，是仙岛侵略其他地界的重要推手之一） 在关键时刻提供历史文本，仙岛七王再度团结，以一统九界为目标前进。仙岛居民和一般人族无二，却十分团结，拥有坚定信念，做为战士，可以一挡百、做为谋士，可无惧牺牲。但仙岛居民无法用常理讨论，信念随时都在转变，但却非个人的转变，而是整体的转变，不会产生矛盾，反而觉得理所当然，信念却会变得更加坚定，即使牺牲生命也不会放弃信念。

### 重要场景

- 清圣桥：进入仙岛所经空间通道，乃特殊的移动地形，十分难寻。
- 无雪圣岳：仙岛八脉之一，也是八脉之中的最高峰。
- 一线天：修罗缝的核心，是一处正在分裂的地形，但因修罗缝为仙岛阴气和阳气最盛的交界处，一线天底下有一阴一阳力量悬浮，相互吸引排斥形成了一线天奇景。
- 仙岛洪祸：仙岛远古时的灾难，实为和仙岛邻近的妖界劫海动荡导致，每次仙岛洪祸的发生都为仙岛居民带来难以想象的灾害。
- 七星法阵：仙岛七王对应的法阵，用于辅助仙岛剑之盾、冰之壁的守护之招，仙岛洪祸的守护之阵。

### 特殊物品

- 金缕封隙：仙岛第一奇毒。
- 挪天仪：可通过清圣桥出仙岛的特殊之物，在仙岛只有三个，珍贵稀少。
- 司南车：玄兵识机记录所载，太古三朝时期王骨，目前由司马王朝保管。
- 玄刀幽冥：原为佛国谛听须弥藏创建者无色昙华所持戒刀，因不明原因失踪四百多年。后得知目前为仙岛七王之一的十雪天子所持配刀。
- 摆渡一念：如同佛国地门的无我梵音，可控制记忆思能，仙岛入侵一统九界的重要关键，仙岛七王各有不同版本的摆渡一念，在仙岛七王团结后，打造最强版本的摆渡一念广泛传达九界，创造一个以仙岛为尊的九界。曾在仙岛的历史上造就不少血腥的一页，许多人因为摆渡一念的控制无法保持自我，成为各大摆渡一念持有者的工具，多年前更捉拿玄思族实验，造就玄思族一万两千多名族人惨死，使其灭族。
- 天柱锻神锋：以上古不周山为原型，锻神锋和蔺幽兰以九大王骨合铸，已被毁。
- 剑之盾、冰之壁：仙岛远古时，常有洪祸发生，因而仙岛祖先创设一套「剑之盾、冰之壁」的武功保护仙岛，冰之壁用以冻结洪水，剑之盾可守护居民。而今只有十雪天子和君子宿联合才能顺利施展这套守护之招。

因空间变异、九界逆乱，破碎的清圣桥指向变化，仙岛势力彻底出世，随即对中苗地界发动侵略，俏如来等人遭遇空前危机。 仙岛七王意欲一统九界，其中天璇巨门（实为太叔雨的另一身份）作为重要推手，长期潜伏于正道阵营之中，并在关键时刻提供了号称完整的历史文本，促使七王再度团结，共同推进侵略计划。

《金光御九界之仙古狂涛》于2021年1月7日开播，讲述了空间变异、九界逆乱和仙岛侵略其他地界的故事。 剧中第17集于2021年8月19日上线，第29集于2022年2月3日上线，重点描绘了仙岛七王的行动与动机。

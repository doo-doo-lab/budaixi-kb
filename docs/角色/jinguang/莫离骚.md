# 莫离骚（金光布袋戏中的虚拟人物）

莫离骚，金光布袋戏虚拟人物天剑慕容府二当家，说话直接但无厘头，常在不自知情况下得罪人。行事随兴，看似慵懒嗜睡，却又剑艺超绝。真实身份为道域剑界传说“天之道”。曾以八岁之龄横扫天元抡魁，替剑宗夺下神君之位，却在锋芒最盛之时，悄然离开，直到道域遣人偷取持之不败，才重新踏上故土。

个性慵懒淡泊，不染红尘，因道域的身份似有私事隐瞒，倒也不曾耽误府上正经事。脾气古怪，不好相处，看似什么都不在乎，其实总是默默关心别人。记不住没有逻辑的事情，比如别人的姓名。

## 经历
仙舞剑宗的天才少年三十几年前，莫离骚乃是出身道域的天才少年，名唤天之道。

道域分四宗，道统乃以十八岁以下，当代天分最高的少年，入修真院接受四宗交流的修炼，最后各自派人参加十二年举办一次的天元抡魁，夺取神君之位。

剑宗派了一名学童入修真院，作为迷惑其他三宗的手段，而老宗主将天之道留在自己的身边，亲授技艺，其目的便是不让他宗之人，透析其武学剑路。

天之道以八岁之姿，一剑横扫全道域的少年高手，技惊四宗，在天元抡魁中替剑宗夺得神君之位。

他年少聪颖，深得老宗主厚爱，让大师兄玉千城深感压力。

老宗主年岁已高，不愿天之道被自己的大徒弟所害，秘密将天之道送出道域，并将剑宗三剑之一的持之不败，交于天之道。

带艺拜师慕容府在天之道被老宗主秘密送往中原的那一年，慕容烟雨又一次打败李沉渊，因心情不好，四处散心，在一处名唤桃源渡口的地方，遇上天之道。

两人互相看不顺眼，莫离骚主动向他挑战，结果败于慕容烟雨，被强行带回慕容府收留为徒。

因为身世秘密，有一些与众不同的习惯，慕容烟雨曾经放话，只要不让慕容府被灭，莫离骚要做什么，不受慕容府束缚。

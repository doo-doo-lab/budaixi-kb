# 误芭蕉

金光布袋戏虚拟人物金光布袋戏虚拟人物。冷檐知雨·误芭蕉，师承雨相覆秋霜，向北冥缜毛遂自荐，并成为其手下的第一谋士。说服无心皇位的锋王北冥缜参与王储之争，并替其谋划诸事。雨相赐“冷檐知雨”之号，在短短两年便有所作为，有意与梦虬孙竞争相位。

## 角色经历
北冥缜身旁策士，出身鲛人一脉，砚寒清的表妹，师承卸任丞相覆秋霜，与辅佐北冥异的伴风宵为同门师兄妹，是少数几个了解北冥缜脾气，并敢加以亲近的辅佐人才，略通朝堂人情世故，弥补北冥缜过于刚硬的一面，因而深受信任，并建言北冥缜积极参与夺嫡。一心想证明自己的能力，认为女性亦可担任相位。

## 拓展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之仙古狂涛》。

# 煞魔子

================================================================================

电视剧《金光布袋戏》中的登场角色煞魔子是金光布袋戏系列剧集《天地风云录之剑影魔踪》《魔戮血战》中的虚拟角色，由黄立纲配音，身份为魔世修罗国度七先锋之一、暗之军势首领，擅长咒术与侦查术法，负责维持魔世通道及镇魔龙脉调查。身为梁皇无忌的师弟，因沉沦海之战受其救命之恩而誓死追随。在帝鬼入侵人界期间，暗中囚禁叛离魔世的梁皇无忌企图劝说其夺取象征修罗国度统治权的鬼玺，以此促成两界和平。帝鬼战败后潜伏于新任帝尊戮世摩罗身边担任卧底，最终为掩护梁皇无忌身亡。角色以智谋布局与忠义执念为核心特质，曾以天地逆轮术法推动魔世迁移，在阵营抉择中始终以报恩为行动准则。结局以生命践行对师兄的承诺，其牺牲情节贯穿魔世剧情线，成为推动故事发展的关键人物。中文名煞魔子别 名暗之军势配 音黄立纲性 别男登场作品天地风云录之剑影魔踪登场作品天地风云录之魔戮血战身 份七先锋之一种 族魔族归 属魔世组 织修罗国度 胜邪封盾

## 角色经历

暗之军势首领，帝鬼身边的军师、策师，是七先锋当中少数的智将，擅长术法，曾以天地逆轮术法推动魔世迁移，为梁皇无忌在魔世时的师弟，因沉沦海之战受其救命之恩而誓死追随，同时也颇重情义，为保住梁皇无忌而暗中将其囚禁，并劝其夺取鬼玺以统治修罗国度，换来人界和魔世和平，在帝鬼败亡后，仍留在戮世摩罗身边，成为梁皇无忌在魔世中的卧底，最终为掩护梁皇无忌身亡。

## 人际关系

师徒亲友师兄：梁皇无忌修罗国度（33-34代帝尊在位时期）上司帝尊：帝鬼（33代）、戮世摩罗（34代）左右手：网中人、梁皇无忌（叛离，后升任帝尊）、戮世摩罗（继任梁皇无忌之位，后升任帝尊）策君：公子开明三尊：炽阎天（炼狱尊）、曼邪音（闼婆尊）、荡神灭（阿鼻尊）同僚七军势：七重峦（山）、天悬红练（水）、焱饕餮（火）、殁神翼（空）、玄影（幻）、角龙（雷）、煞魔子（暗）其他魔将：魔司令、杀生鬼言（天恒君）、弑坤月、怒千绛、火穷奇、炎梼杌、燚混沌、夔阴师、应童律、钟山鼓、鹗钦丕、雷妖、闪鬼、魇将、日唱寡魄对手仇敌击杀：阳九昊

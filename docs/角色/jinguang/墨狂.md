# 墨狂

================================================================================

金光布袋戏虚拟物品墨狂是金光布袋戏中的虚构神兵，由鲁家应墨家要求铸造，与血之禁印、渡世大愿并称“诛魔之利”，专门克制魔世并由历代墨家巨子传承。

该兵器初登场于《天地风云录之决战时刻》，正式登场于《天地风云录之九龙变》，需配合止戈流阵法使用，并由巨子通过杀师血继仪式继承力量。

墨狂铸造历时两千年，废苍生通过与锻神锋交流获取王骨铸术，将始帝鳞融入墨狂并用不灭火冶炼，使其首次完整现世。

元邪皇战役中，玄狐在不灭火中主动将自身力量融入墨狂强化其破坏王骨的能力，最终俏如来在伏羲深渊与元邪皇对决时斩断幽灵魔刀。

俏如来凭借渡世大愿成功开启真阵，先后击杀帝鬼、玄狐及玄之玄。

该兵器源于始帝融合阴阳术与咒术所创的诛魔计划，其血咒通过巨子代际传承。

鲁家初期锻造的墨狂无法承受真阵威力，直至废苍生改进铸术才形成“超越的墨狂”。

中文名墨狂出 自金光布袋戏系列持有者默苍离、皇甫佚名、俏如来等

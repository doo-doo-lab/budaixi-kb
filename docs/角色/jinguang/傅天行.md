# 傅天行

================================================================================

金光布袋戏虚拟人物傅天行是金光布袋戏系列《金光御九界之齐神箓》中的虚拟人物，称号“神笔状元”，初登场于第2集，退场于第18集。其身份为仙笔峰行云山庄庄主，擅用书法与枪法融合的独门武学“行云流帖”，以笔枪为武器，退隐江湖后加入玄武真道担任导师。原为笔海三豪之一，与太叔雨等人以墨、纸、砚相结交。秉持仁义原则参与天下第一枪之争，只败不杀，曾挫败为祸中原的羚罕，但败于落拓子。受命寻回风铃一刀声时遭其偷袭，以双手能书之技反制未果，终被断臂杀害，尸体悬挂天允山示众。性格宽厚，视玄武真道同僚为友，却因组织内斗殒命，尸身由友人送回玄武真道。其生平以文武双全著称，结局凸显江湖争斗的残酷性。中文名傅天行别 名神笔状元、傅老、天行兄、状元兄配 音黄立纲性 别男登场作品金光布袋戏身 份行云山庄庄主、玄武真道导师种 族人族归 属中原组 织行云山庄、玄武真道

## 人物能力

- **擅长**: 书法、双手能书武学：行云流帖武器：笔枪

## 人际关系

组织门派：行云山庄、玄武真道师徒亲友侄子：傅人美朋友：别小楼、落拓子、旭长辉（楷模全赋）、舞啸笔狂‧太叔雨（草乱无章）【笔锋论交，并称笔海三豪】玄武真道（靳铅华担任教宗时期）教宗：靳铅华圣导：接天岚导师：祝武娘、傅天行、司马魁宗、风铃一刀声教众：步清云、恋红梅、魏长卿、释非瘟、乐铭觞对手仇敌对手：羚罕

## 人物经历

在鬼途奇行路中第一次被遥星公子别小楼提起，为行云山庄之主。风云碑开启之际，留名天下第一枪，与对手对战时，只败不杀，十分讲究仁义道德。其真实身份为玄武真道导师之一，平时为人和善，视众导师（包括少言寡语不合群的风铃一刀声）为朋友。本是一名武者，因为喜欢临摹名帖，逐渐练成一套书法和枪法结合的武功，成为一名文武双全的侠客，善用一杆毛笔为武器，当成枪用，于是号称“神笔状元”。在羚罕为祸中原时，以争夺天下第一枪的名义将其打败，却被其偷袭受伤。之后，落拓子留名天下第一枪，两人一见如故，并进行对决，最后落败。后来，风铃一刀声被祝武娘等人围杀远遁，傅天行受接天岚之托，前往寻找风铃一刀声，却遭其攻击，废掉一臂。傅天行展现双手能书的实力，击败风铃一刀声，却又遭其背后偷袭，断去双臂，又被数刀残杀而死。尸体被挂在天允山上被人发现，后落拓子将其尸身送回玄武真道。

## 评价

逍遥游：遥想当年，临书玉笔楷模全赋，披靡道域，神笔状元行云流帖，技惊中原，加上舞啸笔狂所使草乱无章，三人笔锋论交，各以墨、纸、砚相济，惊艳武道。别小楼：天行兄向来不好繁杂

金光布袋戲虛擬人物。仙筆峰流水塘畔行雲山莊莊主，神筆狀元傅天行。仁心俠舉，退隱江湖多時，後加入玄武真道，天下風雲碑再開之時，參與天下第一槍之爭。

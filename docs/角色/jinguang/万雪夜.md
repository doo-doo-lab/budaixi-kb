# 万朔夜

金光布袋戏虚拟人物万朔夜，本名万雪夜，是金光布袋戏中的虚拟角色。以背负曤日刀的少年形象行走武林，出场时总伴随着无尽风雪，因义父万曙天败于独眼龙，执着挑战以夺回天下第一刀之名。恋人聆秋露自尽后分裂为男性人格万朔夜与女性人格聆秋露，后经独眼龙和冥医杏花君相助而接受事实。万朔夜师承万曙天，刀法蕴含冻气，招式包含曤日九耀等。曾进入佛国地门寻找独眼龙，受地门影响失忆后结识缺舟一帆渡，经其引导恢复记忆并选择离开。与独眼龙重逢时遭遇大智慧渡化，缺舟阻拦后将其带回无水汪洋。最终继承义父遗志，以仁刀之名行侠仗义，常驻根据地梅香坞，与义母恋红梅存有深刻羁绊。

诗号：冷眼识世路，朔夜逐日痕。深恩不可负，尽付霜刀魂。

## 人物关系

万朔夜的亲属包括义父万曙天和义母恋红梅。其恋人暨至亲为聆秋露，两人关系匪浅。仇人为独眼龙。与其他角色如冥医曾有冲突互动，与笑不老、苍狼有剧情互动。

## 角色能力

万朔夜万朔夜师承前任‘天下第一刀&仁刀’万曙天，刀招带有强烈冻气、能透过交手入侵对手体内；此举不只是增加招式威力，更会让对方被冻气入侵而失去反抗能力，作到不杀而战胜的结果。同时在战斗结束后，冻气也有冰封伤口止血的作用。但若是对方强行逼出冻气，就会让伤口流血不止进而丧命，现今对方如果运功就会被冻气完全冻住随即碎裂。暮雪沉影残月凝雪霜星坠地(疑似是万曙天过往最强一招，却败给独眼龙导致失去天下第一刀名号；曾打败神田京一、血求道)流雪回空(在跟对方交手时可钻入对方招式变化的空隙，一击取胜；苍狼便是因此落败)曤日九耀(大范围攻击刀气)飞鳞破甲(简单明快，兼具力量与速度的一击)雪流凝刃雪夜曙光(万曙天为了万雪夜而创的一招，代表万曙天在万雪夜身上得到的救赎)暴雪封关(凝结地下水脉化作冰墙，具有防御跟掩护撤走的效用)一夕飞霜，三丈雪封(把冻气缩小在三丈以内，借此提高密度与威力、使炽阎天的广范围火力难以发挥。)

## 来自百度百科的补充

"万朔夜是西剑流败退后忽然在江湖上出现的少年刀客，白发披肩、冷漠寡言，出现时总伴随着无尽的风雪，是一位身背大刀的神秘少年侠客"。

"万朔夜身揹昔日仁刀万曙天的佩刀『曤日』，甫出场便先后挑战神田京一、白狼等等曾与独眼龙交手过的人，对独眼龙有异常的执着，三番两次向其约战，誓言为父夺回天下第一刀之名"。

"万朔夜的真实性别为女，原名万雪夜，因为执着于向义父万曙天报恩，而化身男性万朔夜，成为仁刀传人"。

"万朔夜初登场于《天地风云录之九龙变》第2集"。

"为替义母恋红梅寻仇，万朔夜中途截杀冥医杏花君"。

"在梅香坞外河面对战独眼龙，并意外夺得九龙天书，后经聆秋露劝说，将九龙天书送离梅香坞"。

"为替笑不老报仇，万朔夜找上苍狼王子，并限制其十五日内找出真凶"。

"根据编剧三弦于2013年8月1日发布的创作杂谈，万朔夜（万雪夜）是其相当喜欢的一个故事，并偏爱该故事中的影子主角万曙天"。"编剧反思了该角色故事线在《九龙变》剧集中的问题，认为大纲给予的事件太少、进度拖沓"。

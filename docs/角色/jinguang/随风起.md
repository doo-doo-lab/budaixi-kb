# 随风起

金光布袋戏虚拟人物随风起，金光布袋戏虚拟男性角色，由黄立纲配音，登场于《金光御九界之鬼途奇行录》《齐神箓》《仙古狂涛》系列剧集。

原属苗疆阵营，历任还珠楼蓝带杀手、银槐鬼市成员，作为还珠楼自创立以来首位提出辞呈的成员，与流光一剑、一剑随风合称“流光一剑随风起”。

作为还珠楼顶尖杀手，随风起因收入问题离职后受雇协助忆无心进入银槐鬼市，最终加入天首势力。

性格风趣自恋，曾与丁凌霜因往事产生矛盾，在鬼市大会中观察局势并评价白丑生“阴阳怪气”、冷总管“能让老爷屡次拉拢”。

常以撕信、扯花瓣等行为展现跳脱个性，最终在《仙古狂涛》第14集与殊天九决斗身亡。

随风起掌握驰风一势、天外飞仙等武学，持有天外飞仙剑谱及朱瑚刀币，诗号“流光一剑随风起，命绝飞霜更不疑”作为角色标识。

## 角色能力

身法：以趾风行武学：回风落影、天外飞仙、搏风归翔、斗风飘痕、驰风一势、随风剑起命不留、雁风横飒、飓风旋杀、剑走风行路武器：长剑、血芒(借用)

## 人物性格

经验丰富的老江湖，风趣幽默爱吐槽，传闻里是个有趣的人，喜欢结交朋友，重情义。自恋，非常厚脸皮，有欺良压善的不好习惯，根据凤蝶描述，个性难以与人相处。爱钱如命，但是很讲究杀手的原则和职业操守，收钱办事，做到最好。

## 角色经历
随风起是还珠楼的顶尖杀手，与流光一剑、一剑随风齐名，并称“流光一剑随风起”，还珠楼主神蛊温皇称其实力远在另外两人之上，不在副楼主酆都月和代楼主百里潇湘之下。因为还珠楼久未做杀手生意，忧心没薪水会被饿死，决定另谋高就。应天首之邀，在往银槐鬼市赴任的路上，路遇苗疆待职的忆无心，以短期雇佣身份帮助她进入银槐，寻找诸葛穷。与诸葛穷一起待命于天首三姑娘麾下。

# 东方鼎立 (东方鼎立)
================================================================================

人物设定东方鼎立名称：东方鼎立称号：不落狂阳性别： 男诗号：天无二日，惟吾旷照，东方不落，鼎立不摇。

初登场：霹雳剑踪 第3集（霹雳皇朝之龙城圣影39集声音已经出现）角色能力武学：归阳不复、恨舞悔阳、刀为穷·剑有尽·狂照无垠东方鼎立 长日狂阳武器：长日狂阳◎外形特征：阔身平直的方头大刀，刀身有一圆形缺口，护柄设计仿造古剑夫差，刀鞘与刀身能组合成为斩马长刀，带有无限的灼热炎气。◎登场剧集：霹雳王朝之龙城圣影 第39集◎原形：阎魔荒神斩（圆形缺口装上荒神宝石恢复原形）人际关系恩人/仇人：僰医人（蛊皇）角色经历东方鼎立，号称不落狂阳，阳年阳月阳日阳时出生，和阎魔旱魃八字一样，所以可以操纵魔刀阎魔荒神斩，但因为魔刀失去宝石神荒，型态变化而被东方鼎立改称长日狂阳。

多年前曾经斩杀北极天宗赫颜姑苏，导致北极天朝瓦解，雪山崩解成红雪江，他还在赫颜姑苏头颅上留字：“天无二日，惟吾旷照，东方不落，鼎立不摇。”后与地理司（老大）、邓九五（老二）、公孙月（老四）、章袤君（老五）四人结拜，排行老三。

出登场前便焚杀名家三百口，只为夺取名家剑法最后一式，并驱使名战前去叶小钗拜师以窥叶小钗刀剑之术的奥秘，并且指点情杀以一个“尽”字破解令狐神逸的刀法，在令狐神逸受伤时趁隙杀死令狐神逸。

东方鼎立 官方桌布在名战学会叶小钗的武学后，看穿他复仇之意，遂不顾原先放他一马的承诺将名战杀死，并学成名家剑法最后一式，补全狂照无垠之招，于叶小钗前来报仇时将他打败。

后为探查吞佛童子下落，冒充他屠灭佛寺，为协助二哥邓九五消灭心腹之患与剑邪对上。

在叶小钗伤愈复出后，两人又战一场，东方鼎立不敌心剑落败，同时因为杀害令狐神逸之事曝光，引来巨锋里高手天险刀藏报复，导致章袤君亡于天险刀藏之手，后来回响大哥地理司的行动参与攻打北辰皇朝，斩杀北辰胤。

后于琉璃仙境决战时对上傲笑红尘，但被复仇心切的北辰元凰以苍龙弓暗算，身受飞箭重创，摔入山谷。

濒死之时被蛊皇所救，但也沦为其尸蛊操控，暗算四妹公孙月，使她失去常性杀害忠烈王笏君卿，期间曾与天险刀藏对垒，以不死之身重创之，后与羽人非獍交手时被他取出身上尸蛊，发现这短暂的重生竟落为他人傀儡，心有不甘下捏死尸蛊而亡，虽为反派角色，但其义气和一身傲骨仍颇令人欣赏。

# 東方鼎立 (东方鼎立)
================================================================================

人物設定東方鼎立名稱：東方鼎立稱號：不落狂陽性別： 男詩號：天無二日，惟吾曠照，東方不落，鼎立不搖。初登場：霹靂劍蹤 第3集（霹靂皇朝之龍城聖影39集聲音已經出現）角色能力武學：歸陽不復、恨舞悔陽、刀為窮·劍有盡·狂照無垠東方鼎立 長日狂陽武器：長日狂陽◎外形特徵：闊身平直的方頭大刀，刀身有一圓形缺口，護柄設計仿造古劍夫差，刀鞘與刀身能組合成為斬馬長刀，帶有無限的灼熱炎氣。◎登場劇集：霹靂王朝之龍城聖影 第39集◎原形：閻魔荒神斬（圓形缺口裝上荒神寶石恢復原形）人際關係恩人/仇人：僰醫人（蠱皇）角色經歷東方鼎立，號稱不落狂陽，陽年陽月陽日陽時出生，和閻魔旱魃八字一樣，所以可以操縱魔刀閻魔荒神斬，但因為魔刀失去寶石神荒，型態變化而被東方鼎立改稱長日狂陽。多年前曾經斬殺北極天宗赫顏姑蘇，導致北極天朝瓦解，雪山崩解成紅雪江，他還在赫顏姑蘇頭顱上留字：“天無二日，惟吾曠照，東方不落，鼎立不搖。”後與地理司（老大）、鄧九五（老二）、公孫月（老四）、章袤君（老五）四人結拜，排行老三。出登場前便焚殺名家三百口，只為奪取名家劍法最後一式，並驅使名戰前去葉小釵拜師以窺葉小釵刀劍之術的奧秘，並且指點情殺以一個“盡”字破解令狐神逸的刀法，在令狐神逸受傷時趁隙殺死令狐神逸。東方鼎立 官方桌布在名戰學會葉小釵的武學後，看穿他復仇之意，遂不顧原先放他一馬的承諾將名戰殺死，並學成名家劍法最後一式，補全狂照無垠之招，於葉小釵前來報仇時將他打敗。後為探查吞佛童子下落，冒充他屠滅佛寺，為協助二哥鄧九五消滅心腹之患與劍邪對上。在葉小釵傷愈復出後，兩人又戰一場，東方鼎立不敵心劍落敗，同時因為殺害令狐神逸之事曝光，引來巨鋒里高手天險刀藏報復，導致章袤君亡於天險刀藏之手，後來回響大哥地理司的行動參與攻打北辰皇朝，斬殺北辰胤。後於琉璃仙境決戰時對上傲笑紅塵，但被復仇心切的北辰元凰以蒼龍弓暗算，身受飛箭重創，摔入山谷。瀕死之時被蠱皇所救，但也淪為其屍蠱操控，暗算四妹公孫月，使她失去常性殺害忠烈王笏君卿，期間曾與天險刀藏對壘，以不死之身重創之，後與羽人非獍交手時被他取出身上屍蠱，發現這短暫的重生竟落為他人傀儡，心有不甘下捏死屍蠱而亡，雖為反派角色，但其義氣和一身傲骨仍頗令人欣賞。角色配樂不落狂陽·東方鼎立（角色曲）收錄於《霹靂英雄音樂精選五》射日（羽人非獍戰東方鼎立） 收錄於《霹靂英雄音樂精選八》

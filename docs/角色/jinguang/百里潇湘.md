# 百里潇湘

金光布袋戏虚拟人物百里潇湘，金光布袋戏虚拟人物因楼主任飘渺长期隐退，代掌还珠楼期间与副楼主酆都月因立场分歧屡生冲突。性格豪放孤郁，常借酒抒怀，试图掌控实权却受制于任飘渺布局。最终被化身神蛊温皇的任飘渺所杀，应验诗号“潇湘夜雨寄魂舟”的预言。

## 官方简介

还珠楼代楼主，性喜饮酒，豪气中带着几分郁郁寡欢的孤独感，对于消失已久的楼主心有忌惮，对此更与酆都月有所不合。——（决战时刻：桌布、决战时刻：甲子名人帖）还珠楼代楼主，性喜饮酒，豪气中带着郁郁寡欢的孤独感，对于已消失的楼主仍有忌惮，对此更与副楼主酆都月有所不合。——（决战金光：史艳文传奇）（还珠楼代理楼主，个性多疑）还珠楼代理楼主，个性猜忌多疑，想找出任飘渺行踪并取而代之。——（金光风云录）

# 西经无缺

================================================================================

## 人物设定

西经无缺官方桌布姓名：尸称号：西经无缺、死老头（剑无极称）、西经前辈（俏如来称）、老仔（剑无极称）身份：暗盟第一剑手登场：金光御九界之墨邪录第1集退场：金光御九界之墨邪录第22集（与元邪皇同归于尽，可元邪皇本体在幽灵魔刀里）组织门派：魔世「幽暗联盟」知己：长琴无焰齐名：玄狐，鬼飘伶武学：尸神七诡（多年前曾经使用，如今已至空无之境，剑法玄妙，无招无式无可名状）武学传承者：剑无极兵器：犁灵剑犁灵氏《东荒经》有犁灵之尸,犁灵氏之尸也,以不坏。

## 人物口白

【墨邪录02】长琴无焰：玄狐的状况西经无缺：他，开始在乎了。不是对剑的执着，那份守护，我很明白，一种剑，一种痴。【墨邪录12】西经无缺：吾，亦非吾。长琴无焰：对无焰来说，尸，仍是尸。西经无缺：那个远久前的尸吗？长琴无焰：远久后的现在，亦同。————————————————————长琴无焰：以不变应万变，毕竟，江湖还在。西经无缺：却是沸腾。长琴无焰：既已沸腾，何不一品。————————————————————西经无缺：烫手的江湖。长琴无焰：那就等待吧。在茶热散尽之后，那冷却烟硝的淡然。届时，希望你与无焰共饮。

## 人物剧情

登场时和胜弦主在竹林对话，然后来到佛国找回玄狐。剑无极突然闯入暗盟阵中，西经无缺出面阻拦，并将其擒住，教授其空无之境。期间和任飘渺对战不分胜负，却自认占得一先，故略占上风。后元邪皇目的被众人知晓，与玄狐、胜弦主一同对阵元邪皇未果，三人分散。之后找到被应龙师围困的胜弦主和墨雪，利用其能够吸收死尸灵力增强功力的特性击退应龙师。最后，在无极山和胜弦主对阵元邪皇，因为事先暗盟众人牺牲，而让西经无缺吸收灵力，而实力大增。本来意图消耗元邪皇体力，却在战斗中发现有机会将其格杀，而果断牺牲自己和元邪皇同归于尽。

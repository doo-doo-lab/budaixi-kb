# 燕驼龙
================================================================================

燕驼龙

金光布袋戏虚拟人物。中原魔门世家传人，传闻其实力不在史艳文、藏镜人之下，后受史艳文感化，为守护史家人而成为中原一方的中流砥柱，抗击入侵的东瀛西剑流。

**武功**：秘笈两三千本，一百万字的魔经（旧金光系列）毒药：五毒化血丸，魔门世家秘传毒药，可以以毒攻毒，暂时缓解西剑流的奇毒。官方简介中原魔门世家传人，原为夺取中原霸权无恶不作的恶人，在被史艳文感化后，转为守护并支援史家人的得力助手。——（黑白龙狼传：英雄扉页）中原魔门世家之主，受史艳文感化而尽心尽力帮助中原，帮助史家。——（金光风云录）史艳文挚友，魔门世家家主，精术法与部分医术。后受史艳文感化，守护史家人成为中原的中流砥柱，抗击入侵的西剑流。——（决战金光：史艳文传奇）魔门世家之主，现今魔门世家唯一成员，同时也是史艳文的挚友，为俏如来等人的长辈，虽是魔门之人，但倾向中原，个性诙谐逗趣，是位十分关心后辈的好好先生，对于协助史家不遗余力。——（决战时刻：桌布）魔门世家之主，曾率魔门侵略中原而对战史艳文，被感化成为挚友，变成史家长辈。个性诙谐逗趣，是位十分关心后辈的好好先生，对于协助史家不遗余力，并多次以精湛的医术救援史家人。——（决战时刻：甲子名人帖）人际关系师徒亲友指导：忆无心（指导其术法，无师徒名分）盟派：天部、地部、灵界部署跟班跟班：脚仔王、地狱尊王（旧金光系列）、悾气剑王（旧金光系列）部属：魔斧千恶僧（旧金光系列）魔门世家对手仇敌主要设定中原有着800历史的魔门世家的传人， 其目的是为了称霸中原，一统天下。后受史艳文感化，为守护史家人而成为中原一方的中流砥柱，抗击入侵的东瀛西剑流。根据魔门世家灵字分支门主步霄霆所言，是魔族后裔，新剧设定中，魔门世家乃是魔世留在中原的一批后人。世人皆认为燕驼龙是魔门世家一脉单传，然而除他之外，另有一批“灵字辈”的旁支，家主乃步霄霆。人物经历旧版金光的燕驼龙非常怕死而且很搞笑，一心想做万教至尊，最怕对剑只影万君愁（苦海女神龙），被微服私访的万历皇帝封为“万教至蠢”还乐得下跪山呼谢万岁。《黑白龙狼传》时期，为换取能救治云十方的解药“金刚不死丹”，将《万毒必解》下册交予千雪孤鸣。《九龙变》时期步入女暴君的圈套，如北竞王所愿将九龙天书相关的信息送至俏如来身边。随后受俏如来安排，化身“汲水先生”燕云初，带出第三本九龙天书并追查识龙影的真实

# 燕駝龍 (燕驼龙)
================================================================================

燕駝龍

金光布袋戲虛擬人物。中原魔門世家傳人，傳聞其實力不在史艷文、藏鏡人之下，後受史艷文感化，為守護史家人而成為中原一方的中流砥柱，抗擊入侵的東瀛西劍流。

**武功**：秘笈兩三千本，一百萬字的魔經（舊金光系列）毒藥：五毒化血丸，魔門世家秘傳毒藥，可以以毒攻毒，暫時緩解西劍流的奇毒。官方簡介中原魔門世家傳人，原為奪取中原霸權無惡不作的惡人，在被史艷文感化後，轉為守護並支援史家人的得力助手。——（黑白龍狼傳：英雄扉頁）中原魔門世家之主，受史艷文感化而盡心盡力幫助中原，幫助史家。——（金光風雲錄）史艷文摯友，魔門世家家主，精術法與部分醫術。後受史艷文感化，守護史家人成為中原的中流砥柱，抗擊入侵的西劍流。——（決戰金光：史艷文傳奇）魔門世家之主，現今魔門世家唯一成員，同時也是史豔文的摯友，為俏如來等人的長輩，雖是魔門之人，但傾向中原，個性詼諧逗趣，是位十分關心後輩的好好先生，對於協助史家不遺餘力。——（決戰時刻：桌布）魔門世家之主，曾率魔門侵略中原而對戰史艷文，被感化成為摯友，變成史家長輩。個性詼諧逗趣，是位十分關心後輩的好好先生，對於協助史家不遺餘力，並多次以精湛的醫術救援史家人。——（決戰時刻：甲子名人帖）人際關係師徒親友指導：憶無心（指導其術法，無師徒名分）盟派：天部、地部、靈界部署跟班跟班：腳仔王、地獄尊王（舊金光系列）、悾氣劍王（舊金光系列）部屬：魔斧千惡僧（舊金光系列）魔門世家對手仇敵主要設定中原有著800歷史的魔門世家的傳人， 其目的是為了稱霸中原，一統天下。後受史艷文感化，為守護史家人而成為中原一方的中流砥柱，抗擊入侵的東瀛西劍流。根據魔門世家靈字分支門主步霄霆所言，是魔族後裔，新劇設定中，魔門世家乃是魔世留在中原的一批後人。世人皆認為燕駝龍是魔門世家一脈單傳，然而除他之外，另有一批“靈字輩”的旁支，家主乃步霄霆。人物經歷舊版金光的燕駝龍非常怕死而且很搞笑，一心想做萬教至尊，最怕對劍隻影萬君愁（苦海女神龍），被微服私訪的萬曆皇帝封為“萬教至蠢”還樂得下跪山呼謝萬歲。《黑白龍狼傳》時期，為換取能救治雲十方的解藥“金剛不死丹”，將《萬毒必解》下冊交予千雪孤鳴。《九龍變》時期步入女暴君的圈套，如北競王所願將九龍天書相關的信息送至俏如來身邊。隨後受俏如來安排，化身“汲水先生”燕雲初，帶出第三本九龍天書並追查識龍影的真實

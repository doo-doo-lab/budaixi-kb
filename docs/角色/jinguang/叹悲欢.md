# 叹悲欢（金光布袋戏虚拟人物）

================================================================================

《叹悲欢》是金光布袋戏中的虚拟人物。

**中文名**：叹悲欢

**别名**：哀灵道者

**配音**：黄立纲

**性别**：男

**登场作品**：黑白龙狼传

**登场作品**：天地风云录之决战时刻

**身份**：灵界三师兄、灵界导师归 属中原

**组织**：灵界配 乐灵凡之门

## 人物设定

名称：叹悲欢叹悲欢图片称号：哀灵道者、灵长性别：男诗号：哭诉三世冤，叹无人情暖，悲中寻情理，灵界一线牵。术法：大地之风、木海之潮初登场：黑白龙狼传第4集退场：天地风云录之决战时刻第11集 （为梁皇无忌挡招重伤，后死于出云能火的式神召唤）为人稳重正派，对爱灵灵有兄长般的情谊。初次离开灵界，是为了找回爱灵灵和调查灵气失衡事件。在制服附灵者的过程中，察觉了灵气失衡与西剑流有关。后灵界对上西剑流，成为了中原正道的助力。

## 官方简介

灵界灵员之一，为灵尊的得力助手。燕驼龙戏称(爱哭脸A)。——（黑白龙狼传：英雄扉页）灵界三师弟，也是灵界导师，忆无心的养父，负责教导爱灵灵与忆无心，为人正直，为了灵界四处奔波。——（决战时刻：桌布、决战时刻：甲子名人帖、决战时刻：英雄扉页）叹悲欢图片梁皇无忌三师弟，个性啰嗦爱操心，收养忆无心，后来为保护梁皇无忌而死。——（金光风云录）

## 人际关系

- **组织**: 灵界身份：灵界三师兄、灵界导师师父：灵尊泣幽冥师兄：大师兄梁皇无忌、二师兄莫前尘同伴：爱灵灵、哀世间收养：忆无心朋友：燕驼龙、神蛊温皇、独眼龙

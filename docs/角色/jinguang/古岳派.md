# 古岳派

================================================================================

金光布袋戏虚拟势力古岳派是金光布袋戏中的虚构势力，为中原抗魔组织，末代掌门李沉渊率众抵御修罗国度入侵而覆灭。其核心武学古岳剑法源自诗仙李白的诗仙剑序残招，曾为武林剑界代表。该派由北冥清涟次子李颇黎创立，因传承残缺逐渐式微。百余年前李氏重组残招创古岳剑法，经慕兰城事件后得蛟龙锦烟霞与青奚宣协助完善“残雪封桥”终式。李沉渊幼时得锦烟霞赐名，成年后将其剑法推至巅峰，门派一度鼎盛。鼎盛后因内部分裂衰落，李沉渊晚年难阻门人离散。魔世入侵时遭荡神灭率军围剿，李沉渊战死后门派覆灭，核心传承断绝。后虽有其传人李剑诗现世，但古岳派已为历史陈迹。中文名古岳剑派外文名guyuejianpai所属势力中原所处位置中原古岳峰掌 门李沉渊绝 学诗仙剑序、古岳剑法祖 师李颇黎门 人李真岩、李玄苏、李修儒等门派信物锦烟霞一缕断发（内含剑意）

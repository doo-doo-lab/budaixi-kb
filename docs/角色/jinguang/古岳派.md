# 古岳派

金光布袋戏虚拟势力古岳派是金光布袋戏中的虚构势力，为中原抗魔组织，末代掌门李沉渊率众抵御修罗国度入侵而覆灭。其核心武学古岳剑法源自诗仙李白的诗仙剑序残招，曾为武林剑界代表。该派由北冥清涟次子李颇黎创立，因传承残缺逐渐式微。百余年前李氏重组残招创古岳剑法，经慕兰城事件后得蛟龙锦烟霞与青奚宣协助完善“残雪封桥”终式。李沉渊幼时得锦烟霞赐名，成年后将其剑法推至巅峰，门派一度鼎盛。鼎盛后因内部分裂衰落，李沉渊晚年难阻门人离散。魔世入侵时遭荡神灭率军围剿，李沉渊战死后门派覆灭，核心传承断绝。后虽有其传人李剑诗现世，但古岳派已为历史陈迹。

## 组织概况

中原正道组织，出场时已灭亡。掌门为李沉渊，源自于盛朝李太白，门派绝学为古岳剑法。

## 势力设定

海境鳞族八百年前的王者北冥清涟，在中原游历时留下次子李颇黎（北冥颇黎）。李颇黎以其父的『诗仙剑序』起家，着手建立古岳派。但是，李颇黎并未传下诗仙剑序的剑谱，仅以剑意相传领悟。李颇黎神秘失踪后，因古岳派内部各方对剑意的理解不同，使得诗仙剑序逐渐失传，古岳派由此式微。

百余年前，古岳派一李氏门人收集古岳派内流传的『诗仙剑序』残招断章，进行整理再造后开创『古岳剑法』。一百零八年前，天下风云碑提前开碑，比试结束后李氏夫妻与当时的天下第一剑漱冰濯雪慕兰城谈武论道。李氏夫妻在理论上破解了慕兰城的剑法，因此被慕兰城记恨而遭到追杀，逃亡期间幸被江湖侠侣锦烟霞青奚宣二人所救。在锦烟霞青奚宣二人的帮助下，李氏夫妻完成古岳剑法最后一招"残雪封桥"。期间李氏得一子，锦烟霞侠侣为其起名"沉渊"。李氏感念锦烟霞与青奚宣的恩情，遂于古岳派设立祭锦仪式以为纪念。

李沉渊将其父所创的古岳剑法练至极致，成为一代宗师，由此带领古岳派走向鼎盛时期。据御兵韬所说，在武林剑界曾有三十年是属于古岳派的时代。然而在李沉渊的晚年，古岳派因门户之争而内斗不断。李剑诗曾言，那时的古岳派已经分崩离析、名存实亡，若非李沉渊在世镇压，古岳派早已没落。李剑诗、李真岩等人皆在此时出走，李沉渊实则无力阻止古岳派走向衰落。

魔世之乱时期，古岳派遭到荡神灭带领的魔世大军围剿，仅有少数门人逃生。李沉渊为众人断后，力战而死，古岳派自此灭亡。

## 组织结构

起源：李颇黎（李太白之子）

太祖父辈：李沉渊之父（古岳剑法创造者）

曾祖父辈：李沉渊（李剑诗祖父）

祖父辈：李剑诗之父

父辈：李剑诗、狷螭狂、李玄苏

小辈：李修儒

门徒：岳寒笙

## 代表人物

李剑诗：古岳派当世传人，同时也隶属纵横家·鬼谷一脉。李剑诗年少时机缘巧合，练成了古岳派失传已久的『诗仙剑序』，但也由此不容于众，被迫出走。剑术天赋极高，因长年隐居而不显于世，成为只有少数人知道的传说。古岳派覆灭后其重出江湖，收修儒为传承弟子，立志重振古岳门楣。称号：旻月。种族：人族。武器：潮汐瑰瑕。诗号：星耀自古晦明时，不持太阿误剑诗。

李修儒：李玄苏之子，武学方面的资质较差，对于古岳剑法的领悟有限。但古岳派覆灭后，他跟在冥医身旁做学徒，于医术一途展露出了极高的领悟天赋。冥医去世后，修儒辗转于中原、苗疆、海境等地，医术日臻精进，虽是年少，但阅历颇多。曾在古岳峰遇险，被李剑诗救下。被其正式收为徒弟，学习古岳剑法。性别：男。种族：人族。所有物：生生草、朔望之果、蓝血蟾蜍、织命金刀（未完成）、织命针、覆口锦囊、古岳剑谱。

狷螭狂：太虚海境罪者，原纹绣罪·狷螭狂。手持锦囊，面有螭龙纹。在北冥觞游历海境腹地时与其相遇，并传授其武艺，元邪皇攻打海境之时，应北冥觞之请而出。为螭龙案卷翻案与未珊瑚合谋，以卧寅的身份操控北冥华，主导了一系列阴谋。称号：原纹绣罪。化身：卧寅。身份：海境罪者。性别：男。种族：鳞族·螭龙。武器：混天拐、潮汐瑰瑕。所有物：覆口锦囊、古岳剑谱（死后按其遗愿将锦囊与剑谱赠与修儒）。诗号：残声凭烛捻韶光，半掩孤帏悬锦囊，满树凋零无寄处，独吟萧索倦痴狂。

## 组织绝学

古岳剑法：李沉渊之父以古岳派流传的诗仙剑序残招断章为基础，整理改造而创立的剑法。是古岳派的门派绝学，但在江湖中亦多有流传。

内部流传剑法（古岳剑法）：碧潭印月（取自西湖十景之三潭印月）、夕照古峰（取自西湖十景之雷峰夕照）、曲眠春晓（取自西湖十景之苏堤春晓）、岳擎北云（取自西湖十景之双峰插云）、钟响南屏（取自西湖十景之南屏晚钟）、平湖秋光（取自西湖十景之平湖秋月）、残雪封桥（取自西湖十景之断桥残雪）、沉鱼羞花（取自西湖十景之花港观鱼）、莺啼柳浪（取自西湖十景之柳浪闻莺）、荷满风华（取自西湖十景之曲苑风荷）。

外部流传：墨改·古岳剑法（玄之玄根据古岳剑法改良）——碧潭映月、夕照古峰、潮信双涛、流萤逐月、飞星穿月。魔变·古岳剑法（玄狐根据玄之玄墨改·古岳剑法领悟）——碧潭映月、夕照古峰。太白行（根据古岳剑法补完诗仙剑序）：苍榛蔽层丘、清辉照海月、明断自天启（未珊瑚）；飞剑决浮云、横绝历四海、披云卧松雪、白骨横千霜（李剑诗，纵横家·鬼谷一脉完整的诗仙剑序）。

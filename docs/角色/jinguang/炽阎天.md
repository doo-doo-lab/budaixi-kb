# 炽阎天

================================================================================

金光布袋戏虚拟人物炽阎天是台湾金光布袋戏中的虚拟角色，

**本名**：炼狱尊，由黄立纲

**身份**：为魔世修罗国度灭世三尊之一。其初次登场于《天地风云录之剑影魔踪》第20集，属魔族并执掌火属性

**武器**：为重黎，绝招包含烈焰掌、十方炼狱等。作为三尊之一，炽阎天曾随修罗国度征战沉沦海，参与魔世与人世的多场战役。在魔戮血战时期，多次协调闼婆尊曼邪音与阿鼻尊荡神灭的矛盾。后因魔世通道封印一度回归，于《墨邪录》中为诱杀应龙师与雁王合作，最终在愧疚中发动自毁

**招式**：“八荒焰·十方狱·劫变狼烟”牺牲。该角色结局以被应龙师逼至精神崩溃，自爆身亡收场，标志着修罗国度战力的重大折损。

## 经历
炽阎天，本名炼狱尊，是魔世修罗国度灭世三尊之一，初次登场于《天地风云录之剑影魔踪》第20集。其经历贯穿《魔戮血战》、《墨武侠锋》、《墨世佛劫》等剧集。在《墨武侠锋》第1集中，曾发生“雪夜再战炽阎天”的情节。作为三尊之一，炽阎天在魔戮血战时期曾多次协调闼婆尊曼邪音与阿鼻尊荡神灭的矛盾。最终，其在《墨邪录》中为诱杀应龙师与雁王合作，发动自毁招式牺牲。

# 沐摇光

================================================================================

金光布袋戏虚拟人物沐摇光是金光布袋戏《金光御九界之墨武侠锋》《墨世佛劫》中的虚拟男性角色，由黄立纲配音，称号“武林绝剑北杓三耀”，代管沧海珍珑。

作为北杓三耀之首，原为海境师相欲星移培养的墨家精英，负责保管沧海珍珑。

天门之战后随三耀转投玄之玄麾下，后暗中效忠凰后并出卖玄之玄情报，因计划败露被玄之玄夺取面容杀害，于《墨世佛劫》第4集退场。

沐摇光曾协助凰后围杀玄之玄替身，并参与追杀魔族锦烟霞。

玄之玄伪装其身份后，沐摇光在尚同会内以“执行盟主遗愿”为由推动火化玄之玄尸体，实际所焚为替身。

留守尚同会期间，俏如来通过沐摇光收到蒙昧始觉的邀约。

玄之玄利用沐摇光传递虚假情报。

沐摇光所属的北杓三耀名称取自北斗七星柄部三星，其名对应第七星摇光（破军星）。

最终因背叛玄之玄被其夺面杀害，成为玄之玄伪装身份的工具。

**中文名**：沐摇光

**配音**：黄立纲

**性别**：男

**登场作品**：金光御九界之墨武侠锋

**称号**：武林绝剑北杓三耀

**佩剑**：沧海珍珑（后归还欲星移）

## 角色设定

佩剑：沧海珍珑（金光御九界之墨武侠锋第28集在玄之玄的命令下归还欲星移）登场集数：金光御九界之墨武侠锋第17集退场：墨世佛劫第1集（被玄之玄杀害并以影形的办法取代）正式退场：金光御九界之墨世佛劫第4集（玄之玄再出，并说明沐摇光已经被杀害）

## 人际关系

上司（真实）：老五凰后上司（曾经）：封鳞非冕欲星移上司（卧底）：蒙昧始觉玄之玄同修：高玉衡、令开阳姐姐：沐媛轸（六弓禁道成员，已逝）

## 北杓三耀

斗杓北杓三耀为师相欲星移亲自训练出的精英，名称取自北斗七星。杓（biāo）亦称“斗柄”，是古代对北斗七星柄部的三颗星，即第五、第六、第七颗星，玉衡、开阳和摇光的称呼。沐摇光即对应北斗七星中的第七星摇光星，位于斗柄的最末端，也称破军星。

人物

## 经历
北杓三耀之首，被授予海境师相欲星移之佩剑——沧海珍珑。师相放弃协助九算阴谋后，将北杓三耀留给玄之玄作为手下使派，以表自己无敌对之心。欲星移杀人，让沐摇光帮助自己。因为一次意外，沐摇光手中的沧海珍珑被师相的表弟梦虬孙看见，梦虬孙步下天门之计，高玉衡与令开阳被梵海惊鸿所杀，沐摇光赶去天门时，却见天门已被封闭。再火葬玄之玄替身，湮灭证据，又以尚同会成员身份，追杀身为魔族的锦烟霞，中途为飞渊所阻。最后，玄之玄伪装成师相的模样，找上沐摇光，口中说要沐摇光帮助自己“对付俏如来”，实则杀死沐摇光，自己取而代之，伪装成他的模样，以此对付俏如来。

## 扩展阅读

金光布袋戏，实际通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪(长女)和黄立纲(幼子)共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。

以声音道具等奇关变景吸引观众的表演形态，被称之为「金光戏」，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，後於1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的「金光戏变革」，故把自己旗下的布袋戏事业，称为金光布袋戏。

如今经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之仙古狂涛》。

金光布袋戏，黑白龙狼传，天地风云录之决战时刻，天地风云录之九龙变，天地风云录之剑影魔踪，天地风云录之魔戮血战，金光御九界之墨武侠锋，金光御九界之墨世佛劫，金光御九界之墨邪录，金光御九界之东皇战影，金光御九界之魆妖纪，金光御九界之鬼途奇行录，金光御九界之齐神箓，金光御九界之战血天道，金光御九界之仙古狂涛

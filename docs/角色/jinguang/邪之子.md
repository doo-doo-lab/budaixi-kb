# 邪之子 (邪之子)
================================================================================

邪之子

霹靂布袋戲虛擬人物。邪之子融合惡鬼與聖女血統、加上嗜血族異變而生，象徵邪惡與黑暗，身具解碼嗜血族封印寧暗血辯之能。工於心計、狡詐善謀，能窺知他人心思及弱點並加以運用，集邪兵衛、嗜血族、邪帝絕學三大暗邪之力於一身。

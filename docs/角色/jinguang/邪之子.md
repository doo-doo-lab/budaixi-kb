# 邪之子

霹雳布袋戏虚拟人物。邪之子融合恶鬼与圣女血统、加上嗜血族异变而生，象征邪恶与黑暗，身具解码嗜血族封印宁暗血辩之能。工于心计、狡诈善谋，能窥知他人心思及弱点并加以运用，集邪兵卫、嗜血族、邪帝绝学三大暗邪之力于一身。

## 人物设定

**星座**：牡羊座（会刊第149期）种族：嗜血者（吸血鬼）所有物：邪兵卫

## 人物能力

武学：阇皇之力、冰邪千峰、九阴汇邪、暗日邪红、黄泉引途判、追源锁念、邪魅摘雷手

## 来自百度百科的补充

邪之子是西蒙与柳湘音之子。

邪之子曾引发争端，在鎏法天宫、圣殿之上掀起战云。

后被佛剑分说吸收，其影响导致佛剑分说精神错乱。吸收邪之子后，佛剑分说不仅乱开杀戒，还破了色戒生下一子，但散尽舍利后仍未成功驱散其影响。

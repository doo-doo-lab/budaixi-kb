# 天地不容客

================================================================================

金光布袋戏虚拟人物天地不容客是金光布袋戏中的虚拟角色，

**本名**：罗碧，又称史罗碧，由黄立纲

**配音**：。其真实

**身份**：为蜕变后的藏镜人

**初登场**：于《金光御九界之墨邪录》第14集，暂退于《东皇战影》第11集，后于《魆妖纪》第3集

**再登场**：。天地不容客身披暗金宝甲，手持离尘石盾，曾于元邪皇攻破黑水城时救下史艳文等人，自称“天地不容，无亲无故”。角色

**诗号**：为“踏烽火，折兵锋，正邪无用；斩敌颅，杀魍魉，天地不容”，擅长飞瀑掌、纯阳掌及阴阳合招，配乐包括武戏曲《天地莫容》与气势曲《踏折兵锋》，均由李穆作曲。该角色

**武器**：为离尘石盾

**武学**：融合阴阳双流

**招式**：包含暴雷狂涛、纯阳贯地等，合招形式多样。人物经历佛劫后重塑

**身份**：以新姿态活跃于墨邪录至魆妖纪剧情线。

**中文名**：天地不容客

**别名**：罗碧

**配音**：黄立纲

**性别**：男

**登场作品**：金光御九界之墨邪录金光御九界之东皇战影

**登场作品**：金光御九界之魆妖纪金光布袋戏

**生日**：3月2日

**年龄**：50真实

**身份**：藏镜人

**初登场**：金光御九界之墨邪录第14集

武器天地不容客的真面目离尘石盾——战骁（因为是由离尘石打造防御力可化消攻击力道还可借用王骨灵能特性，出自锻神锋之手首次提到盾名为仙古狂涛19集）武学飞瀑掌飞瀑怒潮、暴雷狂涛、暴流灭境、狂潮辟野、怒潮袭天、雷光炽爁、恶潮袭境，飞瀑怒扬，怒潮灭天。纯阳掌纯阳一气、辟邪烈日、纯阳贯地阴阳合招：纯阳行左·飞瀑走右·阴行阳招·阳行阴招·阴阳交融·贯天袭地（天地不容客时使用）纯阳行左·飞瀑走右·阴行阳招·阳行阴招·阴阳融合·袭地贯天（藏镜人时使用）啸问岁月·天狼影（与任飘渺，狼主千雪孤鸣合招）

天地不容客

天地不容客，金光布袋戏虚拟人物。一身暗金宝甲，手持烽火神兵，威势不凡，霸气雄沉，在元邪皇大破黑水城之时威凛现身，硬接元邪皇全力数击，并全身而退，救下了史艳文等人。自称天地不容，无亲无故，其真实身份为经历了地门佛劫，蜕变再出的藏镜人。

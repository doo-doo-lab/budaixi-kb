# 天海光流

金光布袋戏虚拟人物天海光流，金光布袋戏虚拟人物，由黄立纲配音。天海光流，西剑流六部之道部部长，擅长暗器，十分喜欢喝酒，不喜与别人交际，为六部中的怪人，平时深居他自己的修行地，闭不出户，自柳生鬼哭被调去中原后，就被邪马台笑一天到晚缠着一起喝酒，所说的话只有邪马台笑能懂。西剑流败退后，与邪马台笑留在中原照顾其伤势，为赎罪而尽一份心力。

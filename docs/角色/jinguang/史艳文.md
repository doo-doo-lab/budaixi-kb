# 史艳文（金光布袋戏虚拟人物）

================================================================================

史艳文，金光布袋戏虚拟人物，是金光系列里的第一主角，是台湾布袋戏的灵魂人物。太阳星转世，背部刻有四字“纯忠报国”。人称云州大儒侠、玉圣人，中原武林的中流砥柱。甲子名人帖上，与藏镜人并列天下第一掌，其纯阳功体独霸武林。史艳文乃是温文儒雅，饱读诗书的儒家君子。虽多情但不滥情，风雅而不风流，个性内敛持重、气质出众、风度翩翩。因其品行高洁、君子端方，世称“史君子”、“史贤人”。修养与包容力过人，仁德处世，对于一些“尚可救药”的歹人，往往会网开一面。为此，史艳文甚至不惜牺牲自身利益，无怨无悔地奔走跋涉。但若忍无可忍，则会一反和平处事的理念，以暴制暴。长年带领群侠抵御苗疆的入侵，与世仇苗疆战神藏镜人作战多年。被西剑流囚禁五年期间，酷刑加身仍不屈不挠。后联手藏镜人三战炎魔幻十郎，协助默苍离抵挡魔世入侵中原。与次子戮世摩罗一战，被其丢入魔世后失踪。。数年后从魔世归来，救下元邪皇刀下的长子俏如来以及众人，成为对抗元邪皇不可或缺的战力。诗号1：回忆迷惘杀戮多，往事情仇待如何。绢写黑诗无限恨，夙兴夜寐枉徒劳。诗号2：乾坤乙定不休功，卦卜将来绝对空。蹙额连思兼叹息，徒然命运不亨通。中文名史艳文外文名Shi Yen-WenSu Young Man别 名云州大儒侠、史贤人、史君子、五皮君子（山、医、卜、文、武）配 音黄俊雄、黄立纲（黑白龙狼传起）性 别男登场作品云州大儒侠史艳文（1970年）云州大儒侠续集新云州大儒侠（1983年）史艳文与女神龙新云州大儒侠（1994年）登场作品云州大儒侠史艳文（1970年）云州大儒侠续集新云州大儒侠（1983年）史艳文与女神龙新云州大儒侠（1994年）金光霹雳菩萨藏万教大革杀金光十八龙金光九天盘千禧云州大儒侠第一侠苦海女神龙第一侠苦海女神龙之霹雳城第一侠苦海女神龙之鹰燕龙虎榜黑白龙狼传天地风云录之决战时刻天地风云录之九龙变天地风云录之剑影魔踪金光御九界之墨邪录金光御九界之东皇战影金光御九界之魆妖纪金光御九界之鬼途奇行录金光御九界之仙古狂涛金光御九界之妖祸天劫生 日03月02日年 龄50原 型文素臣官 位兵部侍郎、太子少师爵 位一字并肩王功 体纯阳体佩 剑龙泉剑宝 物天地人三卷天书著 作数返真经根据地正气山庄代表势力中原人物原创编剧黄海岱、黄俊雄人物接手编剧三弦本尊偶雕偶师陈文龙接手雕偶偶师洪有聪

## 角色形象

从1970年的《云州大儒侠》起，史艳文的造型随着时间的流逝和剧集的发展，有着不同的变化，整体气质越来越贴近人物形象，显示出史艳文这一角色因40年历史而沉淀出的风华和底蕴。为了塑造世代为官的世家子形象，史艳文的服饰、造型都偏向于华丽，颜色艳丽且面料多为绸缎，头上还戴着纶巾。这个时候史艳文的形象更偏重于儒侠当中的“儒”，即举仕入朝的读书人形象。（图中）史艳文往期各种形象成为将军后，造型也随之改变，身着黄底镶红边的战袍，身背龙泉剑，头发也简单的用发带束起，整个人显得神采飞扬、精神奕奕。（图右二）千禧版首出场：《千禧年云州大儒侠》第一集造型越见朴素，衣服面料转为布，款式也更见朴拙大方，已经逐渐偏重于儒侠的“侠”的部分。大概这也与史艳文个人经历更多、阅历更深，从而心境更加平和有关。（图右一）清圣版（千禧二版）首出场：《千禧年云州大儒侠》第四十一集造型古朴，简单大方，儒雅又不失潇洒。头发束起扎成一个马尾，干脆利落。整个偶头的眉眼部分十分具有神采，眼神清亮，正气凌然。脸型饱满偏圆，眉毛直直斜飞入鬓，墨色浓密；眼睛是黑白分明的杏仁眼。服装由于年代及条件所限，较为朴素，白色外衫外还罩了一件纱衣，在袖子、肩膀处均有精致的绣花，其宽袍广袖的样式和低调稳重的颜色明确了儒侠之“儒”。《天地风云录之决战时刻》的先导片中，在保持原先的造型之外，还使用了抹额装饰。抹额主体为银色，上面用黑色丝线绣出祥云纹路，中间镶嵌一颗颇有分量的红宝石。注：被西剑流囚禁五年，酷刑甚多，并不能保持衣冠整齐，因此有黑白散发版造型。史艳文旧剧偶新剧（黑白龙狼传起）中，史艳文的造型因时而变，去粗取精，堪称新金光布袋戏中最为经典的人物造型之一。造型开始简约，乍看朴实无华，细品韵味十足。决战版首出场：《黑白龙狼传》第二十六集雕偶师：陈文龙整个偶头集温润的君子气质和威严的正道领袖风范于一体。从偶的面目来说，这版偶头在脸型上延续了一直以来的偏圆脸。眉毛变成了有圆润的曲线，仅在眉尾上扬勾勒气质，眼睛则保持了杏仁眼的眼形，瞳孔由之前的黑色变成了蓝灰色，这两处改动使得史艳文变得柔和温润，而抿紧的嘴唇又带有几分威严。白色的衣衫出尘绝世，虽无华丽的装饰，但是袖口及衣领处精致的绣花暗纹彰显了低调的优雅；如墨的长发用玉冠束起，干练简洁，白色的发带垂在脑后，与黑色的头发依偎在一起，简单的色彩交织出了一种动人心魄的美。身上唯一的装饰品——额饰，主体为白玉，中间镶嵌有银片和玉珠，给原本略嫌朴素的造型增添了一份贵气，很符合史艳文世家子的身份。决战版九龙版首出场：《天地风云录之九龙变》第十二集雕偶师：洪有聪在九龙变中，史艳文因重伤昏迷，醒来后却因卧床时间太长暂时不良于行，只能坐轮椅。而这套造型衣着简朴，颜色低调，十分不起眼，头上还戴着罩有黑纱的斗笠掩盖面容，很适合史艳文目前所扮演的“藏镜人”的尴尬处境。另外，造型整体偏向暗色，有些阴沉，和这一段剧情中史艳文无奈牺牲儿子的心情相得益彰，体现了人物气质的沉郁。注：此版衣服即清圣版，与此同时也暗示了其真正的身份。九龙版剑影版首出场：《天地风云录之九龙变》第三十五集雕偶师：洪有聪与决战版比较，剑影版整体造型没有变化，主要的变化在偶头，此版偶头是洪有聪仿照陈文龙所雕。眼睛颜色由蓝灰色变成了湖蓝色，眼形从杏仁眼变成丹凤眼，鼻头更有棱角。脸型较之前稍尖，不似之前那么圆润。注：在《天地风云录之决战时刻》第十三集中，被炎魔幻十郎一掌重伤时散发，因此有决战散发版造型。此造型开始由洪有聪接手。剑影版墨邪版首出场：《金光御九界之墨邪录》第六集雕偶师：洪有聪墨邪版偶头可以说是彻底的改头换面。脸型削尖，眼睛变得狭长且更为上挑，眼珠颜色由湖蓝变为天蓝，丹凤眼的眼形更为明显，眉眼间距较近。墨邪版全身造型一改原本的素衣白袍、简单马尾，而是更为华丽。衣服布料不是以前飘逸的纱质，绣花变成了显眼的黑线与银线交织而成的花纹；衣服样式由简单一件儒衫变成了好几件，还增加了立领的外杉，领口的贴花和腰间、袖口的盘扣都说明了新偶的服装复杂程度明显提高；发型也不再是原本随意束起的马尾，而是在马尾之下还有各种发辫、盘发等穿插，鬓发和刘海上都加了些许白发；头上所戴的抹额由素雅的玉环穿银片变得更精美华丽。墨邪版天人版首次出场：《金光御九界之妖祸天劫》第三十二集雕偶师：暂不知为了改变不应该存在的未来，接受了可承载十重纯阳体的天羽神裳。天人版

## 角色能力

官方评价布袋戏传统文化的延续（黄俊雄）自从史艳文当年（1970年）在台视亮相以来至今（2000年），已历经了三十个寒暑，如果再溯及早年“全省走透透”的野台戏年代，史艳文更已年过半百。这么多年来，我看到那么多台湾人为他疯狂、着迷，时至今日，仍有许许多多的群众对他印象深刻、挚情不忘，显然史艳文已蔚为台湾社会文化的一部份。不可否认，史艳文为掌中戏找出一条活路，使得这项传统技艺不致凋零，强华、文择和文耀的“霹雳系列”与“天宇系列”，更为布袋戏带来新的契机和方向。我之所以选择在此时让史艳文“复出”，最大的目的还是在于让传统艺术得以存续，布袋戏要不断随着时代创新、改变，让更多的新新人类去接受他，自然会有人去主动接触、甚至去研究那些古早的、传统的、必须恒久保存下去的事物，那么也就不必担心会被遗忘在历史的洪流里了。台湾布袋戏的同义词云州大儒侠史艳文，是多数台湾人的集体记忆。三十年来，黄俊雄演出的史艳文早已深植人心，并在台湾社会文化中泛起一波波的涟漪。没有史艳文，就不会有现在的素还真、红云，或是冰山冷燕；没有史艳文，恐怕也极少人会注意到传统的掌中戏。因此我们大胆地将“史艳文”视为布袋戏的同义词。史艳文也可以是七十年代台湾社会忠孝节义的代名词，其大无畏、知其不可而为之的精神，在现在的观点来看，似乎显得愚昧。但事实上，史艳文也会用权谋，只是他“算计”对象都是一些足以颠覆江湖安危或是侵害国家社稷的恶人或组织，而且从来不牺牲朋友亲人，为了这些人，他甚至可以不惜生命。即使如此，史艳文依然可以好好地活着，这才是真正的智者。从各种角度来看，史艳文都可以说是个近乎完美无缺的角色，但也是个有血有泪的角色。忍的哲学（钟千琪）史艳文的行为，像佛陀本生经故事“舍身饲虎”之类的忍辱，或可视为舍离“人相”、“我相”的菩萨行为，故称之“禅师”还尚可。有些特殊的是在此选择“五月五日端午节”为决斗日，因屈原是为国尽忠而死谏，而史艳文却没有特别交代“死谏”之事，虽在“云州大儒侠”与“大儒侠”中，史艳文为国立下汗马功劳，但“朝内奸臣恐其权旁落，说史有叛国通贼之行为，由于路远难以查证，便软禁萱姑为人质，派两名钦差前去调查”或“明皇宠妃商妃对史心存妒意，故向明皇进言恶语，遂使史再度陷入万劫重围之中”或“当今明朝皇上建文帝，听信了兵部尚书齐泰的谗言，说你在边疆，非但没有平定干戈，反而煽惑乌斯藏的臣民和苗族人联台起来图谋不轨，圣上已下旨，要捉拿你的夫人和公子史献忠”这类奸臣在皇帝身旁谗言并陷之于不义罪名的情节，屡见不鲜。因此，在此巧合“端午节”的日子，或许是以屈原为类比的隐喻。因此整个来说，黄俊雄把他的道德哲学或人生观简化为”忍“， 虽很通俗，可是还是可以借着实际的情节或人物，来表达这样抽象的观念，包括忍辱、牺牲小我等，总之就是存着一颗不动的赤子之心或良知，而且在环境无论如何恶劣或艰难的情况下，都可以坚持下去或熬下去。他人评价藏镜人/天地不容客：你（雪山银燕）的父亲二十岁就以纯阳掌威震天下，而你，连你父亲当年一半的本事都没。我若是你，早就自尽了。宫本总司虽在剑上绝逸群伦，论掌法，能赢过你（雪山银燕）的父亲史艳文吗？用掌，史艳文犹然在上。你的父亲史艳文，我不曾见过第二个人，有他这等对武学的见识与分析。你（雪山银燕）父亲史艳文是我见过在武学上悟性最高的人，简单的功夫被他应用也能发挥极大的威力，困难的功夫他可以轻易学得。面对对手能很快想出克敌的方略。不接受人质威胁，才能永远免除平民遭受人质威胁。就算用平民百姓为饵，史艳文也未必会中计。西剑流忍者：忍者甲：这到底是第几次的失败了？忍者乙：算不清了。忍者甲：若不是亲眼看见他是怎样被祭司刑的，我还想在祭司是对他手下留情，还是功力退步，这个中原人，实在有够硬骨。连分筋挫骨那些方式都用了，要让他分神，无法度抗拒祭司改造，谁知道他连哀也不哀一声，硬跟祭司对抗。结果，人都昏去了，还是无法度入灵，祭司的缚灵之术从来没失败过呢。默苍离：不是俏如来没有变成第二个史艳文，而是在这个世上，只有史艳文能成为史艳文。保全小空是自私；袖手旁观，是将史家人的祸患交给别人处理，也是自私；纵然大义灭亲，仍是将史家人的责任，加强于小空的身上，这也是自私。不管怎样做，也是摆脱不了受人质疑的恶名，这就是你史艳文的悲哀。帝鬼：神逸俊扬，这番的气度，这番的姿态，你是史艳文。佯退假攻，各个击破，以一战四，你本不能赢得如此轻可，朕赞赏你的战斗智慧，你叫……史艳文。你的聪明反应，再度让朕赞叹了，朕不在乎你怎样试探魔世，在此地杀了你，就能让整个中原震动。

处事与遭遇：
黄俊雄原剧
明朝中叶，嘉靖君钦命将军史丰洲（史艳文之父）亲征交阯，以定边陲。此次战役两军互有伤亡，交阯将军罗天从（藏镜人之父）虽战败身殒，史丰洲亦于战火中下落不明。当时史艳文年幼不谙世事、未解恩仇，藏镜人却因此将丧父亡国之痛归咎史艳文、有如宿敌，誓不两立…。十数年后，史艳文方逾弱冠之年，便因素行侠义而获“云州大儒侠”之美誉，因崇仰岳飞一生精忠，史艳文乃别母离家、携书僮庸儿前往杭州祭拜之，不料从此步上江湖险路……。 史艳文行至杭州境内之后因投宿刘家店而与店主刘三相识（后与刘三之妹刘萱姑缔结姻缘），结为挚友，孰知于一擂台赛中得罪提督安天祥（奸相安基谋之弟），虽藉洪长卿举荐得以面圣，却遭奸相诬陷入罪，幸有公主谢红豆说情，发配辽东充军三年。然安基谋并未因此善罢干休，又埋兵百万于西河驿馆、欲诛杀史艳文，幸史艳文以孝心感动杀手高云、获赠龙泉宝剑，复有赛关公等人相助，方化险为夷。一路上被史艳文的为人所感化的江湖人士众多，因而渐渐形成了一群追随他的志士团体，简称中原群侠。
期后史艳文被宰相诬陷，被判死刑，可史艳文并无反抗，只因皇令不可有违，史艳文的同伴得悉后赶往刑场欲将之劫走，史艳文生怕要连累同伴，在行刑前对侍机而行的同伴说：“……咱们的国法，其一是杀人偿命，咱们的礼教忠孝礼节义，绝对不是用在犯法，如果有人为我不满想劫犯，就是要使我生而不安，死而不宁！”，从此点也可见他刚烈耿直的性格，以及不忍同伴受牵连的仁善之心。
此时匿身中原之藏镜人见安基谋百般算计之下仍是成事不足，便告知嘉靖君将于八月中秋前往相国寺礼佛之事，安基谋立刻策划叛变，幸事发之时，史艳文赶至解围，乃受封为兵部侍郎兼太子少师，同时得知按察陈文炳落难之事。史艳文随即赶往太华山，凭着机警、顺利营救陈文炳安然而退。
然一波未平、一波又起，史艳文为擒国犯，欲破困龙岛，真假仙极思拉拢困龙岛主雷英，乃与藏镜人密谋七星破太阳之计划，顺利击败史艳文。史艳文负伤而逃之余又为藏镜人以飞瀑怒潮击中，万死一生之中为康城公主沙玉琳所救，藏镜人因此设计假史艳文（巴士克）毁沙玉琳之名誉，导致沙玉琳化名恨世生欲杀史艳文。史艳文未知康城生变，致力于玉玺遭窃、国犯未擒之事，同时江湖中神秘角色相继出现，暗凶不断为恶肆虐……
新剧（天地风云录、金光御九界系列）
史艳文虽得世人称许，剧中人物多以“史贤人”、“史君子”称之，但其三子“雪山银燕”史存孝却因为父亲屡次牺牲史仗义而与他关系紧张，甚至否认父子关系；史艳文无奈以强硬方法回应，但他仍相信，尽管长子精忠与三子银燕选择不同道路，但仍会朝正确的方向成长。
虽然史艳文至仁至善，但若被逼入绝境，亦会采取极端，以暴制暴，于天地风云录之决战时刻中，史艳文与藏镜人联手欲破坏儿子小空入灵成为炎魔幻十郎，并夹攻初复活的炎魔。
藏镜人虽然追杀史艳文多年，但史从没打算要杀掉他，而是希望他能觉悟；后来藏镜人因战败而要拿下面罩，史艳文终确定藏镜人为失散多年的胞弟，结果两人被指同谋多年，分别受中原及苗疆人士追杀，期间巧合躲进九脉峰山洞内。在洞内藏镜人讲述其身世，并要与史艳文最终一战，实际上是希望让史艳文杀死自己，惟史艳文看穿了胞弟的用意，在交手一刻将其点穴，趁他晕倒时与他互换衣服，后离开洞穴，愿代藏镜人而死。（天地风云录之决战时刻）
事实上，此时史艳文已经对行走江湖多年感到无奈：“人生确实处处无奈，步步悲哀，我恨我不能做一个尽责的父亲，我恨我不能改变过去，我恨我自己是史艳文，如同你一样，我也只是活在别人期待之下、别人的眼光之中。这世间战火不断，谁能称正，又能定谁为邪？就像你我一样，正邪，只不过在那一线之间。命运所造成的遗憾，我们只能承受，而人生，就由我们自己决定。我会先引起追杀你的苗兵，只要藏镜人一死，苗兵对你的追杀将会到此为止...... 我的胞弟，别再为他人而活，为自己活下去吧。”
史艳文亦是大义之人，欲阻止魔世入侵中原，他牺牲二子史仗义（小空）以堵住魔世入口，后来史仗义受魔世修罗国度君主（修罗国度内部尊称帝尊）的帝鬼控制，成为猛将“戮世摩罗”。史艳文与三子雪山银燕史存孝、剑无极联手，欲唤醒史仗义，但计划失败。（天地风云录之九龙变）
在墨家钜子默苍离问史艳文能否下手杀亲生儿子时，史艳文并没正面回应，但借“没有带（三子）银燕前来已表明立场”。（天地风云录之剑影魔踪）
长子史精忠决战帝鬼时，史艳文负责阻止戮世摩罗支援帝鬼；在史精忠处下风之际，史艳文情急欲下重手杀掉戮世摩罗、救史精忠，但此时戮世摩罗一声“父亲”，令史艳文被自身功力反冲，重伤之际被捅一刀，失踪至今。
云海过客表示，史艳文现在过得很好。（金光御九界之墨世佛劫）
在俏如来和元邪皇决战重伤撤退之时，和鬼飘伶现身挡下元邪皇脚步，协助俏如来逃走。之后和中原正道及苗疆将士共同抵御元邪皇，阻止始界回归，造成九界动乱。为阻止元邪皇，找上化名天地不容客的藏镜人，希望能以两人联手，道法自然的阴阳合招，对抗元邪皇的烛龙自然之力。（金光御九界之墨邪录）
而后来到了历来不为中原所知晓的“仙界”的主要地带“仙岛”。因清圣桥封印意外被破、驰突孤燕（雪山银燕）闯入“修罗缝”并大肆屠戮，因而与修罗缝双尊灵龟万寿公、腾邪千岁爷合力、欲制伏驰突孤燕。但因史艳文心软反受重创、并引来正在附近的天权文曲（鹰尊十雪天子）、天玑禄存（金蹄战马）、开阳武曲（司马幻魂）三王而失败。后因清圣桥封印意外被破、造成空间震荡缘故，“修罗缝”可能崩毁，史艳文因此答应双尊两人的要求，以自身功体拉住“修罗缝”的重要地带“一线天”。（金光御九界之仙古狂涛）

刘萱姑，云州大儒侠史艳文之妻，温柔贤惠，蕙质兰心。在兄长刘三的撮合下与史艳文结成夫妻，但史艳文明言，要在自己功成名就之后再与刘萱姑洞房，实则是拖延之计。与史艳文聚少离多，却毫无怨言，尽心尽力的照顾婆婆与三个儿子。因史艳文在朝中的变故，刘萱姑与婆婆三子从此离散，后在尼姑庵中出家。因被苦海女神龙的诚心所打动，还俗后与女神龙、鹰女一同前往鞑靼国居住。
苦海女神龙（波娜娜），遇中毒受伤的史艳文，史艳文乃太阳星下凡，与苦海女神龙的太阴星身份阴阳相引，为替史艳文解毒，两人有一夜夫妻之情。后来苦海女神龙诞下女儿史菁菁（鹰女）再度来到中原，助史艳文除恶扬善。

在剧中，史艳文其最大的敌人是总是蒙着颜面的藏镜人，史艳文为保护中原、消灭藏镜人入侵的野心，而与藏镜人展开一连串的斗智斗法。后来史艳文遭藏镜人打落万丈深渊，生死不明。
在2009年的黄俊雄布袋戏全国巡演中延续了之后的故事，原来史艳文和藏镜人乃因兵乱而失散的亲兄弟，身上有相同的胎记，而两人的父亲为剧中另一神秘角色中国强（即先前在战乱中失踪的史丰洲所化装）。
2011年国家戏剧院版本，演出史、藏两人原为双胞胎兄弟，襁褓时故居被罗天从所灭，水氏情急之下只带走史艳文。罗天从便想出毒计，扶养藏镜人长大成人，再用他对付史丰洲。也因此造成史艳文与藏镜人无止尽的争斗。

史艳文曾于1971年前后代理主持台视《田边俱乐部——周末剧场》。
史艳文被戏迷称为“史爸”，因而得“Spa”这称号。

# 庸儿

《云州大儒侠》系列作品中的虚构人物庸儿是古典文学作品《云州大儒侠》及其衍生作品中的核心配角，作为主角史艳文的贴身书童登场。该角色最早见于1983年电视剧版《云州大儒侠》的剧情设定，随史艳文赴杭州途中开启江湖历险。其古怪可爱的性格特征通过作弄他人等剧情得以展现，并在后续发展中经历拜师六骨和尚等重要转折。截至相关作品时间线，庸儿保持着年近三十仍服务于史家的设定，见证史艳文从功成名就到江湖沉浮的全过程。在衍生剧情中，该角色曾因水怪袭击失踪，后以操控黑金刚作战的反派形象再现，成为推动故事矛盾的关键要素。

## 角色背景

作为云州大儒侠史艳文的贴身侍从，庸儿自嘉靖年间便伴随左右。明中叶时期跟随史艳文别母离乡，开启杭州祭拜之旅，由此卷入江湖纷争。该设定在1983年电视剧版中得到首次确立，并通过后续衍生作品形成完整人物脉络。

## 性格特点

角色塑造突出其"古怪可爱"的核心特质，具体表现为：日常行为中带有作弄他人的顽皮倾向处理事务时保持机敏灵活的特点长期侍奉中展现忠心耿耿的品质

人物

## 经历
早期侍从阶段在史艳文取得功名返乡途中，史艳文带着书僮庸儿前往杭州西湖参拜岳飞帝君，途中经过桃花山与范应龙、李彪结拜为生死兄弟，并投宿于杭州城刘家店。

庸儿全程参与杭州境内的重要事件。

包括：协助史艳文结识侠士刘三见证史艳文与刘萱姑定亲过程处理日常文书事务与行程安排身份转变事件据衍生作品记载，庸儿曾于某年在杭州西湖遭遇水怪袭击后失踪（据《霹雳城》剧情记载，庸儿被灵鹫山三宝寺的倒头僧救起并传授武功。）。

再现时已掌握精妙刀法，并具备操控黑金刚作战的能力，该转变引发史艳文对其失忆可能性的医学求证。

后续经历庸儿受其师倒头僧指示，携带破功钉与化容水前往帮助白阳生。

在刘三与蒙面人交手并揭开头巾后，庸儿以化容水揭露了假史母的真面目，随后先行离去，刘三见状紧追在后。

此后，庸儿随史艳文一同随玉小保回见其祖父，并在此过程中认识了鲁氏兄弟。

在另一次行动中，庸儿曾与铁乞者、高云、五爪、六骨僧等人在山下随时准备接应史艳文。

## 人际关系

与史氏家族保持跨越代际的主仆关系：作为史艳文早年随从见证其功成名就持续服务至史艳文四十余岁时期与史家后人俏如来保持主仆互动模式师承脉络庸儿曾落水遇险，被灵鹫山三宝寺的倒头僧救起。倒头僧认为与庸儿有师徒之缘，将其度回灵鹫山传授武功，以期其日后能助主人史艳文完成大事。此后，倒头僧曾千里传音吩咐庸儿速往帮助白阳生，并令其携带破功钉与化容水。

## 形象演变

在不同艺术载体中呈现多样化特征：电视剧版着重刻画其书童身份的憨直文学衍生作品强化其成年后的沉稳特质及身份转变同人创作扩展其黑化反派的

戏剧冲突

## 相关作品
庸儿作为史艳文的书僮，在《霹雳城》中登场。剧中，史艳文带着庸儿前往杭州西湖参拜岳飞帝君，途中在桃花山与范应龙、李彪结拜。后在西湖游览时遭遇水怪，庸儿落水后被灵鹫山倒头僧所救并传授武功。之后受命携带破功钉、化容水帮助白阳生，并曾以化容水揭穿假史母的真面目。在电视剧《云州大儒侠》中，庸儿亦有出场。例如在第12集中，他与铁乞者、高云、五爪、六骨僧等人在山下准备接应史艳文。在第26集中，他随史艳文和玉小保去见玉小保的祖父，并结识了鲁氏兄弟。

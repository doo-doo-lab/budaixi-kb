# 狷螭狂

金光布袋戏虚拟人物金光布袋戏虚拟人物。太虚海境罪者，‘原纹绣罪’狷螭狂，也是四龙中‘螭龙’的代表。手持锦囊，面有螭龙纹。在北冥觞游历海境腹地时与其相遇，并传授其武艺，元邪皇攻打海境之时，应北冥觞之请而出。为螭龙案卷翻案与未珊瑚合谋，以卧寅的身份操控北冥华，主导了一系列阴谋。

## 角色能力

武器混天拐八纮稣浥所铸镔铁六器之一，赠予狷螭狂，最早由北冥觞使用，后放置浮情道归还狷螭狂。

双拐湛若蓝玉，雕琢涩铁金纹；

更能并合化为一口剑器，圆镡方铗，黄青一同，方圆兼具。

混天拐成对的意义，是谓：‘纵使世道浑浊，双持亦可开天’。

而镔铁所铸之器，乃鲲帝死克，若以龙之力催动，倍添其威。

狷螭狂凭借螭龙之力催动浑天拐，成功小破鳌千岁鲲鳞战甲，却也因此丧命。

潮汐瑰瑕覆秋霜发妻佩剑，剑镡琦蓝瑕英，剑刃汐朝剔透，瑰丽不可方物。

曾被狷螭狂央托借予未珊瑚，后由鳞王归还；

之后雨相再度借予狷螭狂，并赠言：‘剑，有去有回；

人，有去有回。’（惜叹之后人情世变，不可谓讽刺至极）实则此剑乃覆秋霜鬼谷同门‘旻月才女’李剑诗碧海兼容琴中佩剑，多年前因故借予覆秋霜，今已物归其主、海容潮瑕。

武学古岳剑法·“夕照古峰、曲眠春晓、岳擎北云、钟响南屏、平湖秋光、残雪封桥、沉鱼羞花、莺啼柳浪、荷满风华”◎武学概述：狷螭狂以拐为武，双拐运化战绩精妙，恪守方寸，旋甩世道，混天忽捶，括囊不咎——但双拐实则守势偃武，掩盖自身真正底牌：“古岳剑法”。

当守势走尽，即抛双拐，一剑惊尘。“古岳剑法”系出中原古岳派，狷螭狂习自亡父遗留剑谱，剑气文华煊章，意境深远。

狷螭狂与未珊瑚合作时，便以手中剑谱助其补全宝躯未氏所遗‘诗仙剑序’残篇。

当中所录最后一式‘残雪封桥’，虽让整套剑法更为周全，但练法却与入手总诀有所差异，使得狷螭狂经络受损。

在修儒提点诊治后，改以绵劲催运，剑芒宛如雪光反射，剑柔似针穿引，劲力无孔不入。

狷螭狂对覆秋霜视之如亲，此情却遭覆秋霜利用，传授覆秋霜剑法。

注释：古岳剑法招式名该取自现实〖西湖十景〗。

碧潭印月=三潭印月夕照古峰=雷峰夕照曲眠春晓=苏堤春晓岳擎北云=双峰插云钟响南屏=南屏晚钟平湖秋光=平湖秋月残雪封桥=断桥残雪沉鱼羞花=花港观鱼莺啼柳浪=柳浪闻莺荷满风华=曲苑风荷能力〖螭龙之力〗狷螭狂为宝躯与人族（先祖是鲲帝一脉的北冥清涟）混血，面生螭龙纹，为四龙之‘螭龙’（鲲帝与宝躯混血），亦是《螭龙案卷》的一切起点——但龙力远弱于觉醒的梦虬孙，发挥不出梦虬孙那般的镔铁死克。

所有物反口锦囊狷螭狂手中所握，习惯谋划思考时抚摸锦囊，是狷螭狂智者的象征、螭龙翻案的冀望，亦是其凄凉一生的缩影。

锦囊之名有如其主立场摇摆不定，看似翻覆趋炎，实乃命蹇时乖、终不得已，恰映狷螭狂秉烛自述：‘反口锦囊，虽有妙策，无处不反，真是讽刺。’狷螭狂临终一刻，将演图关地形图以及排布的暗线放入锦囊，被砚寒清接下。

时过势变，螭龙案卷翻案无望，其父因忠而反，其己藉反尽忠，当中辛酸苦楚，俱负反口锦囊，谁人能知？《古岳剑谱》其父李真岩所遗，狷螭狂身亡后按其遗愿将剑谱转赠修儒。

## 角色经历
其父李真岩为中原古岳派弟子，因斗争失败而进入海境。然而在海境中仍受政党斗争影响，被诬为乱臣，史称螭龙案卷。狷螭狂为人族与宝躯混血而生的螭龙，螭龙为远古四龙之一，他的存在影响了海境皇室鲲帝一脉的政权，故遭到统治阶级的封杀。在元邪皇入侵时，应海境太子北冥觞之邀请，进入朝堂，其目的是为父亲翻案。但这个目的却会影响到统治阶级，所以备受阻挠。在海境内乱时，狷螭狂假意归顺鳍鳞会，作为内应瓦解鳍鳞会攻势，并在与叛臣北冥皇渊的战斗中，舍身破其鲲鳞战甲。

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

# 十九爺 (十九爷)
================================================================================

十九爺

霹靂布袋戲虛擬人物。富貴山莊之主，身軀高大肥胖，手持一把金色小扇不停扇動，是莫召奴在東瀛的朋友與暗樁之一，個性好客爽朗，多年來以天儀四柱鎖囚禁八岐太歲，欲套出鬼之瞳的下落，卻始終不得其法。

 人物設定,人物能力,人際關係,人物經歷, 人物設定名稱：十九爺十九爺性別：男退場：霹靂開疆紀 第27集（死於草一色）

**身份**：富貴山莊之主根據地：富貴山莊人物能力武學：天羅掌、破山手所有物：扇子、天儀四柱鎖鑰匙、天衣有縫人際關係人物經歷十九爺，乃是東瀛最大賭坊富貴山莊的大莊家，姓名取自賭徒十賭九輸，他開賭場當莊家必十賭九贏，故稱十九爺。以換取鬼之瞳十分之一財寶的條件答應和莫召奴合作，多年來以天儀四柱鎖囚禁八岐太歲。但十九爺是個深藏不露的陰謀家，不滿足於十分之一的財寶進而為謀奪鬼之瞳，一手策劃櫻千代臥底在幻雲齋身邊，更刻意讓幻雲齋派來富貴山莊臥底的藤一郎偷襲得手後，使他們救出順利救出八岐太歲。十九爺本人佯裝受傷，由神秘劍客保護，讓櫻千代從八岐太歲口中得知鬼之瞳收藏在東瀛知名機關師荻少將建造的棧冥鬼屋這項重要情報。十九爺後來因為事情敗露而與莫召奴反目，被草一色所殺。

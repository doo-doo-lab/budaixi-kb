# 十九爷

霹雳布袋戏虚拟人物。富贵山庄之主，身躯高大肥胖，手持一把金色小扇不停扇动，是莫召奴在东瀛的朋友与暗桩之一，个性好客爽朗，多年来以天仪四柱锁囚禁八岐太岁，欲套出鬼之瞳的下落，却始终不得其法。

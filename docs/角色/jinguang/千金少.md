# 千金少

================================================================================

金光布袋戏虚拟人物千金少，金光布袋戏虚拟人物，出自《战血天道》第8集，初登场于《金光御九界之战血天道》第一集。诗号为“美女多如狗，宝刀最妖娇。人命值一笑，买醉千金少”。神啸刀宗现任宗主，西江横棹师弟，风逍遥师兄。当年刀宗身陷道域大战，前任宗主遭设计身亡，危急存亡之际，千金少挺身而出，力挽狂澜护宗门不倒。为人爽朗，个性豁达，十分重情义，相当重视与西江横棹、风逍遥间的师兄弟感情，与其徒戚寒雨亦有着深厚情谊。武器为神啸双器之一的啸穹刀，武学包括拟形八法、龙形刀步、醉生梦死。性格爽朗豁达，重情重义。

## 人物能力

武学小碎刀步“纵步杀·虚影、掠步杀·疏狂”拟形八法“虎啸空山、雁鸣长空、猿啼孤月、凤舞狂花、鱼跃大川、狼奔万里、龙卷黄沙、马驰残阳”龙形刀步“双龙腾·步虚影、双龙转·步寸芒、双龙舞·步迷尘、双龙啸九天”醉生梦死（刀宗禁招）PS：千金少虽为年轻一代，却是出类拔萃：手握双锋之一，刀宗三艺兼成，对比道域前代杰出人物亦毫不逊色。

在十几年前道域内战、刀宗凋零之际挺身而出，为了活下去无所不用其极，更修炼此刀宗禁招《醉生梦死》——用他本人的话说：‘为了刀宗，甘愿一辈子做酒鬼。’武器啸穹神啸刀宗镇宗双器之一，似汉代斩马刀制式，镡长尺余，首为大环，并系有一串驼铃；

刀鞘则呈广漠包缠的异域风格，并有数条金缕赭绫飘荡。

刀镡为虎首王纹，譬喻刀宗“神啸”之喻；

刀身笔直锋锐，玄面金镂，于一寸处有一缺角：乃三十三年前西风横笑于天元抡魁，惨败天之道、遭持之不败所斫。

西风横笑由此半生蹉跎，易名弃刀，后由千金少持有，亦成为“笑残锋”名号的由来。

持有2019年端午节羊皮酒囊（铁枫零制，后被西风横笑转赠千金少）、啸穹项链（托人将啸穹碎角制成项链，赠与徒弟戚寒雨）、神逸（刀宗镇宗双器之一，赠与风逍遥）、天师云杖（交予颢天玄宿保管）

## 配乐

【笑啸残锋】千金少角色曲曲：哲浩起始的短箫声画龙点睛地呼应角色的小名，令人莞尔。鼓声节奏伴随着主旋律，彷若能看见千金少扛着啸穹快意潇洒地行走在道域。中段独奏的箫声，带着孤独但温柔，像自诩一生卑鄙的千金少，却带着一颗柔软的心，对刀宗及师兄弟，能倾付一切在所不辞。

# 帝鬼

金光布袋戏虚拟人物金光布袋戏虚拟人物，魔世修罗国度第三十三代帝尊。在魔世通道大开之际，亲率七先锋与其三千精锐部队侵略中原，拓展领土，以此扩充战力，来日一统魔世。其武器为沉黑的奇形大戟“征伐”。帝鬼出身畸眼族，与千年前的元邪皇同族，拥有“邪眼缚神”的瞳术。在战斗中曾自毁真元使出禁招“修罗夜炼·化元归无”，亦曾施展“修罗夜炼·万鬼同悲”之招。最终在《剑影魔踪》第20集中败亡。任才适用，驭下厉仁兼具，失败时，会检讨各方面的失误，甚至自己的方针，是英明的领导者。其亦被评价为“智将”与“战修罗”，实力不俗并且智勇兼备，爱护下属，被史艳文赞为智勇兼备的战豪。

## 经历
魔世沉沦海大战，修罗国度战败，帝鬼第一次自毁真元，为梁皇无忌所救，签下沉沦海条约。

魔世开启，几日内派遣七先锋及其精锐部队扩大中原控制区域三百里，并在侵略同时派遣人员寻找魔世三件宝物。

被史艳文周旋时，诱劝史艳文投降，遭拒后用邪眼缚神重创史艳文，随后派遣戮世摩罗追杀。

与中苗联军三战：初战偷袭得手，探知封邪之塔地点与幽灵魔刀下落；

二战部署被破，折损两员先锋将，独战中、苗、东瀛五侠挽回败局；

三战依然被默苍离算计，主力魔军即将被三途蛊毒杀，本尊亦于血色琉璃树下面对开启诛魔之利——止戈流的默苍离，不敌止戈流，被戮世摩罗救走。

帝鬼闻默苍离亡，率兵前往封邪之塔，遭史艳文、俏如来阻截。

止戈流再现锋芒，第二次自毁真元，仍无力回天，最终被俏如来所杀。

在之后戮世摩罗与三尊的谈话中，曾多次被提及。

## 帝鬼人物评论

帝鬼是魔世修罗国度第三十三代帝尊，魔世修罗国度的霸主，为了一统人魔两界、满足称霸的野心而不惜兴起战祸，最后战死沙场。任才适用，驭下厉仁兼具，失败时会检讨各方面的失误。其戎马一生，智勇兼具，善于用人，被视为一代枭雄。在武力排名中，帝鬼位列第三档，被描述为智勇双全、战斗技巧高超的强者，实力与撼天阙根基相当，并有畸眼族属性加成和术法优势。史艳文对帝鬼的评价不如苗王狠辣狡猾，但更为通达权变；不如炎魔雄狠勇霸，却更为稳重深沉；若说炎魔是霸王，苗王是枭雄，帝鬼则是智勇兼备的战豪。

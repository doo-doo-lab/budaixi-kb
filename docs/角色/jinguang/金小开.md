# 金小开
(百度百科无对应条目,newton.com.tw 收录)

金小开，霹雳布袋戏中的虚拟人物。一名被武林道上喻为十恶不赦、大逆不道的小魔鬼。因父母离弃及背负祖父叶小钗的盛名，使他以叛逆来表达内心的不满与忌妒；之后经圣母教化而终能改变自己、浪子回头，并赢得佳人自在天女的信赖。

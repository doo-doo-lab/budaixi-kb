# 修罗国度

================================================================================

金光布袋戏虚拟势力修罗国度是金光布袋戏中的魔世三大势力之一，由元邪皇千年前统一魔世时创立。

其组织结构以帝尊为最高统治者，下设策君、灭世三尊及七先锋等职级，核心成员包括公子开明、网中人等。

该势力以破除沉沦海之约、扩张领土为战略目标，根据地设于鬼祭贪魔殿，持有象征王权的鬼玺与幽灵魔刀。

千年间历经三次重大变革：元邪皇首度入侵人世被达摩击退后，魔世分裂为修罗国度、幽暗联盟与凶岳疆朝；

帝鬼时期发动两次灵魔大战，破除封印后遭默苍离设计斩杀，鬼玺被戮世摩罗夺取继位；

元邪皇复活再统魔世败亡后，戮世摩罗重掌鬼玺，联合幽暗联盟对抗凶岳疆朝。

期间梁皇无忌曾短暂执政撤退魔世，公子开明作为策君长期镇守沉沦海维持三方平衡。

该势力贯穿魔世与人界的冲突，其军事行动深刻影响着九界格局。

中文名修罗国度后 果带兵进攻人世特 点后被达摩祖师击退

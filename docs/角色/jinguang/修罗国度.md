# 修罗国度

金光布袋戏虚拟势力修罗国度是金光布袋戏中的魔世三大势力之一，由元邪皇千年前统一魔世时创立。

其组织结构以帝尊为最高统治者，下设策君、灭世三尊及七先锋等职级，核心成员包括公子开明、网中人等。

该势力以破除沉沦海之约、扩张领土为战略目标，根据地设于鬼祭贪魔殿，持有象征王权的鬼玺与幽灵魔刀。

千年间历经三次重大变革：元邪皇首度入侵人世被达摩击退后，魔世分裂为修罗国度、幽暗联盟与凶岳疆朝；

帝鬼时期发动两次灵魔大战，破除封印后遭默苍离设计斩杀，鬼玺被戮世摩罗夺取继位；

元邪皇复活再统魔世败亡后，戮世摩罗重掌鬼玺，联合幽暗联盟对抗凶岳疆朝。

期间梁皇无忌曾短暂执政撤退魔世，公子开明作为策君长期镇守沉沦海维持三方平衡。

该势力贯穿魔世与人界的冲突，其军事行动深刻影响着九界格局。

中文名修罗国度后 果带兵进攻人世特 点后被达摩祖师击退

## 内容简介

千年前元邪皇一统魔世后带兵进攻人世，后被达摩祖师击退。

千年后，帝尊帝鬼对沉沦海之约不满，欲以人世为跳板破除契约，派遣魔之左右手网中人与梁皇无忌率领大军由中魔两界通道进攻中原，但遭到以灵尊为首的灵界众人殊死抵抗最终战败，网中人流落中原，梁皇无忌被灵尊收服，史称第一次灵魔大战。二十多年后网中人在昔日旧将的设计下恢复记忆，再次攻打灵界开启第二次灵魔大战，虽被中苗合力击败但使灵界实力大损为被魔心鉴控制的酆都月潜入灵界打破魔世封印创造了机会，封印破解后因黑水城暗中影响，帝鬼只能率领七先锋先帝国大军降临人世。七先锋先后折损仅余煞魔子，随后帝鬼被默苍离、俏如来布局斩杀，鬼玺被戮世摩罗夺走从而入主修罗国度。

戮世摩罗持鬼玺，号群魔。第一道命令便是一统人世，壮大修罗国度，再度矛头指向中苗。战争最终落败，网中人将帝尊戮世摩罗放入茧内，沉入海底藏身。梁皇无忌继位帝尊，令魔军撤退。之后元邪皇复活，一统魔世各国势力进攻九界，帝尊梁皇无忌外出寻找外援。曼邪音与炽阎天听令元邪皇的同时趁机寻回网中人查找戮世摩罗的下落。元邪皇败亡后，戮世摩罗再现于东瀛，之后和网中人前往妖界接收原酒吞童子的部下再回中原找寻梁皇无忌，取回鬼玺以及寻找能让妖族大军恢复战力的妖界母晶。

最终戮世摩罗重持鬼玺和母晶，再度号令修罗国度，吸收妖族主战派所有战力，现今和幽暗联盟合作，全面攻打凶岳疆朝。

# 白狼（布袋戏《黑白龙狼传》及其衍生作品中的角色）

======================================================================

白狼，又称邪刀恶体‧邪体白狼，是黄立纲配音的男性虚拟角色，登场于《黑白龙狼传》《天地风云录之决战时刻》《天地风云录之九龙变》等布袋戏作品，身份为黑白郎君南宫恨的分身之一。

其肉身源于苗疆王骨狼王爪，持有幽灵魔刀，性格承接黑白郎君的狂傲特质。白狼曾执着于与善体黑龙合体恢复本体，后因担心丧失自我产生排斥。白狼在灵界窃得幽灵魔刀后外逃，曾对上万朔夜并败北，在关键时刻被黑龙所救。

最终，白狼和黑龙合体成为黑白郎君，并以完整姿态对战东瀛魔神炎魔幻十郎。该角色作为黑白郎君恶念化身，其发展轨迹体现从武力至上到重视情感的转变，结局以牺牲个体存在换取他人安危，完成角色叙事闭环。

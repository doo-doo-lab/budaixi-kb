# 东瀛（金光布袋戏虚拟势力）

================================================================================

东瀛，亦称扶桑，是金光布袋戏世界观中的虚构势力，属于中土九龙地界以外的境界，与中原相邻。该势力历史围绕妖界主战派首领酒吞童子的转世展开，织田信长作为首任转世平定东瀛乱世，胧三郎继承力量创立残忍联盟。徐福建立东瀛并隐于幕后，酒吞童子被流放后自命第六天魔王建立政权。西剑流流主炎魔幻十郎获得魔之甲后统一东瀛，但被阴阳师以剧毒击杀。西剑流曾大举入侵中原，最终在军师赤羽信之介运作下部分成员返回日本。中文名东瀛出 处金光布袋戏别 名扶桑

**東瀛**是霹靂布袋戲中的一個國家，影射現實世界中的日本。

==簡介==
東瀛，在中原武林歷史上佔有一大篇幅，從早期的非凡公子出現，歷經三教之子一事的動盪，至魔魁之女身亡。之後，權門宗矩帶領忍者部隊進犯中原，又再度開啟另一波東瀛故事，期間，歷經黑榜、君夫人與莫召奴的出現、東瀛的政權體系也在此時期逐漸揭曉。

而在銷聲匿跡多年後，隨著東瀛隱匿在中原的夜摩市浮上檯面，也讓中原人士察覺東瀛野心其實並未休止……。

==組織==
*神風營-由軍神源武藏所籌組，是當年岩堂幕府擊敗前代鬼祭幕府後建立的武力部隊，直屬於天皇，囊括東瀛武道菁英，實力驚人，全員集合擁有滅國性的力量
*夜摩市-隸屬於岩堂幕府，是由太宰真田龍政所籌組，是東瀛派往中原的潛伏組織，透過黑市交易收集情報、武學和各種奇珍異寶

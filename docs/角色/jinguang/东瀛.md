# 东瀛（金光布袋戏虚拟势力）

东瀛，亦称扶桑，是金光布袋戏世界观中的虚构势力，属于中土九龙地界以外的境界，与中原相邻。该势力历史围绕妖界主战派首领酒吞童子的转世展开，织田信长作为首任转世平定东瀛乱世，胧三郎继承力量创立残忍联盟。徐福建立东瀛并隐于幕后，酒吞童子被流放后自命第六天魔王建立政权。西剑流流主炎魔幻十郎获得魔之甲后统一东瀛，但被阴阳师以剧毒击杀。西剑流曾大举入侵中原，最终在军师赤羽信之介运作下部分成员返回日本。中文名东瀛出 处金光布袋戏别 名扶桑

**东瀛**是霹雳布袋戏中的一个国家，影射现实世界中的日本。

==简介==
东瀛，在中原武林历史上占有一大篇幅，从早期的非凡公子出现，历经三教之子一事的动荡，至魔魁之女身亡。之后，权门宗矩带领忍者部队进犯中原，又再度开启另一波东瀛故事，期间，历经黑榜、君夫人与莫召奴的出现、东瀛的政权体系也在此时期逐渐揭晓。

而在销声匿迹多年后，随着东瀛隐匿在中原的夜摩市浮上台面，也让中原人士察觉东瀛野心其实并未休止……。

==组织==
*神风营-由军神源武藏所筹组，是当年岩堂幕府击败前代鬼祭幕府后建立的武力部队，直属于天皇，囊括东瀛武道菁英，实力惊人，全员集合拥有灭国性的力量
*夜摩市-隶属于岩堂幕府，是由太宰真田龙政所筹组，是东瀛派往中原的潜伏组织，透过黑市交易收集情报、武学和各种奇珍异宝

# 任孤沉

金光布袋戏虚拟人物任孤沉是金光布袋戏系列虚拟人物，初登场于《金光御九界之鬼途奇行录》。作为司马良欢之徒、诸葛穷师弟，身负“无相驭虚指”绝学，因家族五代“白胎”诅咒天生白发，自幼遭歧视并患脑疾，后被司马良欢收养。因师父被害隐居黄昏夹缝，随后被师叔司马魁宗设计加入玄武真道，借彼岸虫克服脑疾，受玄武真神蛊惑成为新任教宗。期间以武力镇压武林，与戮世摩罗合谋铲除异己，却因白胎意识侵蚀性情反复，最终在风云碑决战中被黑白郎君击败导致神力消散。结局因协助对抗靳铅华武功尽废，被天剑慕容府收容。一生历经家族诅咒、师门变故与神力操控，最终挣脱宿命回归本心，与挚友达成和解。

## 角色设定

诗号：谁人不俗尘不染，谁人无惑心无愧。众生皆醉何必醒，任浮任载任孤沉。

## 经历

出生于行禹村任家。

相传很久之前，任家先祖任浮生妻子身患绝症，任浮生跋山涉水，寻遍医治方法，最终找到一名异人，以家族之后每隔五代便出现一名白胎男孩为代价，治好了他的妻子。

历代白胎都存在精神异状，精神极端敏感，会不时伤及他人，甚至自残，因此大多数白胎不出三十岁便会死亡。

所以旁人开始谣传：任浮生和恶魔交易，给家族带来了诅咒。

而任孤沉便是这一代的白胎，从小遭受旁人歧视，最后家族也被屠杀殆尽，成为了一名孤儿。

又因为天生白发，无论到哪里都会被人嫌弃、讨厌，因此得了脑疾，对陌生人怀有极端的惧怕感。

然后，任孤沉被师尊司马良欢收留，和诸葛穷、梅若馨一同长大。

任孤沉和三人情同一家，虽患有脑疾，却唯独对这三人十分亲近。

因为意外捡到前任天下第一指的武学残页，而习得绝世武学“无相驭虚指”，拥有一身不凡修为。

在司马良欢死后，大受打击，对这个江湖十分失望，也对中原领袖俏如来十分仇恨，从此隐居黄昏夹缝中，从不外出。

诸葛穷带着受伤的忆无心来到黄昏夹缝时，任孤沉在屋内和诸葛穷对话，之后忆无心来到黄昏夹缝，任孤沉告知忆无心诸葛穷可能去了银槐鬼市，这期间未曾露面。

风云碑再开，其师叔司马魁宗以任孤沉的名义留名风云碑的天下第一指，又将前往黄昏夹缝的方法告诉黑白郎君，因此，任孤沉被黑白郎君找上。

两人激战中，任孤沉施展无相驭虚指中的无相离火与惊雷破梦，与黑白郎君的一气化九百对抗，无意间离开黄昏夹缝移动至人群密集处，任孤沉的人群恐惧症（脑疾）发作，方寸大乱，最终不战而逃。

再被诸葛穷寻得时，任孤沉正被许多村民殴打。

回到诸葛穷的藏身处后，又被司马魁宗找上，司马魁宗要两人加入玄武真道，而诸葛穷也认为外面不够安全，在一番探查后，诸葛穷通过在食物中下药的方式迷昏任孤沉，将其搬运到玄武真道住所暂歇。

期间，天首（梅若馨）遭遇追杀而受伤，来到玄武真道，任孤沉配合诸葛穷医治天首的内伤。

之后，玄武真道教宗靳铅华试图开导任孤沉，却未见成效。

任孤沉在玄武真道总坛因心魔发作而发狂袭击俏如来，诸葛穷出手暂时将其制服。

接天岚、司马魁宗、沄主、铁骕求衣四人合击任孤沉，被他以‘逍遥汇流·四时孤驰’破解，最终任孤沉袭向教宗靳铅华时被铁骕求衣趁机擒住，并由诸葛穷喂下镇静药物。

被囚期间，任孤沉在与诸葛穷的交谈中，表达了对俏如来不作为的强烈不满与仇恨。

事件发生后，教宗靳铅华为任孤沉作保，表示‘若是他再生事，吾愿负一切责任’，使其得以留在玄武真道。

诸葛穷于是向神蛊温皇借来彼岸虫，让任孤沉服下直面自己的心魔。

任孤沉服下彼岸虫后，在意识空间，见到了‘玄武真神齐天寿甲’，受其蛊惑。

在彼岸虫引发的梦境中，任孤沉见到了幼年的自己，并看到疑似被伪造的、关于父亲过往的日记，幼年形象自称魔考、全知、真理、玄武真神，并逐渐侵蚀控制了任孤沉的意识。

醒来后性格大变，害怕陌生人的脑疾也随即消失，还获得了玄武真神的‘神力’。

而后，任孤沉展开了一连串的行动，先是主动找上接天岚和司马魁宗，要求合作。

再杀死风铃一刀声，取代靳铅华成为玄武真道的新任教宗，并颁布教令，强迫中原武林所有门派归顺玄武真道，不从者皆死于非命，又与戮世摩罗合作，暂时除掉黑白郎君这一隐患。

在天允山地层被俏如来破开时，接收到玄武真神的指令，带领教众来到天允山围杀俏如来等人，并将天允山列为禁地，禁止其他人闯入。

之后，以慕容宁曾协助俏如来破坏天允山地层为由，连番针对天剑慕容府，先生擒慕容宁，又率众在绝死谷杀死慕容烟雨，接着，大举进攻慕容府，但遭诸葛穷与天首阻拦，对战中被诸葛穷所败，随后，任孤沉之意识被体内的白胎完全占据，性情再次产生变化，打伤诸葛穷后，前往绝死谷救下司马魁宗等人，并与慕容府、尚同会合议，约定七天后在风云碑上展开所有天下第一的决战，选出真正的天下第一。

七日之后，众天下第一齐聚天允山，风云碑下，任孤沉一人挑战众天下第一，以一己之力，击败枭岳、忆无心、风逍遥、御兵韬、凰后、六隐神镞，任飘渺，公子开明见状主动投降。

而黑白郎君突然出现，挑战任孤沉。

此时，天允山后山，戮世摩罗等人成功破开地层，找出“玄武真神”的藏身之处，任孤沉的神力加持渐渐消失，并且取代白胎，重新夺回了自己的意识，随后败给黑白郎君，与诸葛穷和天首重归于好。

用残余的叛天族异能协助苗疆三杰击败靳铅华后受异能副作用影响武功尽废，天剑慕容府亦因此放过了任孤沉，但必须终身收容在天剑慕容府直至生命的终点。

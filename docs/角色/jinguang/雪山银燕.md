# 史存孝

金光布袋戏虚拟人物同义词雪山银燕（雪山银燕）一般指史存孝史存孝，别号雪山银燕，是金光布袋戏虚拟角色，由黄俊雄、黄立纲配音。为云州大儒侠史艳文与刘萱姑第三子，归属中原人族，家族属云州史家，生日为11月30日，偶师为萧佟兴，持有天下第一枪称号。幼年因故失散沦为杀手，与家人相认后因二哥小空被牺牲而与父兄决裂。魔世入侵时为护中原再度联手抗敌，对抗元邪皇时断臂并激发第二人格驰突孤燕。最终脱离中原，随小空进入魔世。

## 角色能力

心法神魔一念宫本总司独门心法，通过使修炼者走火入魔，爆发无限潜力，继而掌握入魔威力的心法。

而此心法极意，非在‘魔心开杀’，而在‘神意止杀’，即以强大的意志控制入魔的爆发力，以魔入心，以神出招，一念之间，亦神亦魔。

心法口诀：“无心无我，不思量，不分别，不执著，人无我，法无我，自无我，他无我，一切成空。”境界“神魔一念”初步掌握入魔威力，但尚未达至‘神意止杀’的意境，出手难有余地，一气尽泻而难存容；

早期的雪山银燕为此苦恼，故时常克制自我，以望能达至‘神意止杀’——却也忽略了止杀的前提便是‘魔心开杀’，因而难以激发自身应有的潜力。“神魔非我”赦魔心而获杀神辟易之神力，正神意而定八方止戈之极意，不执著，不分别，心正而气行法度，圆转无碍，来去有理；

意定而势走从容，行云流水，无休无止，由此神魔并具于一念之间，是谓“神魔非我”——达到此境界的雪山银燕，‘力’与‘势’并具一身，啸灵枪轰掣扫荡间，不见暴戾激进，一进一退间尽显浩然，虽为朴实，却最为可贵。

但因银燕的心性易冲，难以把握住两端的平衡，容易从‘非我’再次掉落‘一念’之境，导致实力发挥的大幅度差。“神魔无我”经由彼岸虫完全挖掘潜力，辅增缺舟一帆渡的武学智慧馈赠与元邪皇所遗留的意识魔元，神魔并存，令雪山银燕催生了第二人格：‘驰突孤燕’。

而在这两种强大的经验与潜力完全爆发的前提灌溉下催生的，便是驰突孤燕怪物般的战斗本能与嗜杀渴望，自九界缝隙流浪的期间经历无数厮杀历练，所孕育的便是与创造者宫本总司本人截然不同的道路——‘神魔无我’。

孤燕戟与雷狩交换兵器。

啸灵枪本为前代‘天下第一枪’雷狩之兵，雷狩与雪山银燕一战助其领悟“神魔一念”之境界后，传授爱枪给这位十分欣赏的后辈，而雪山银燕亦相赠孤燕戟防身。

啸灵枪虽名为枪，但其形状更似“三叉戟”，枪头制式繁密，三锋呈‘屮’字形，刃有镂空，中锋镂空处有三枚铜钱状装饰，比一般的枪戟长一寸两分，周身亮银如雪，无缨，枪杆有白绫缠绕，戟张雄武，豪气龙胆。

后废苍生为破坏戮世摩罗的王骨魔之甲，利用与锻神锋互相交换所得之锻家的王骨改造技术，将王骨“始帝鳞”融入啸灵枪重铸，使得啸灵枪拥有破坏王骨的威力，并赋有王骨灵能，此举也使得之后啸灵枪形象大变。

魔世入侵告一段落后，为防止雪山银燕过度使用王骨灵能而消耗真元，继而导致生命力的消耗，废苍生在枪上附着灵能枷锁。

于墨武侠锋第14集启动入灵机制，啸灵枪因而改变造型：——原本三叉戟的形貌变为镞状枪头后更符合其枪名，戟张的两角向后呈火焰线条延伸，适合用于‘刺’、‘穿’杆上纹有焰状朱翳；

比之最先的繁复造型显得更为洗练，一如经历父兄情境、人世历练后的主人。

墨武侠锋第26集，因风华绝代无可匹敌之锋锐，啸灵枪遭玄狐所断。

废苍生继而取出枪中的始帝鳞，重新再造啸灵枪，可说这口枪与其主人一般，跌宕起伏。

臂剑（仙岛之物）持有同心石忆无心所制，两颗同心石能够互相感应对方，与雨音霜各持一颗。

## 角色经历
霹雳城苦海女神龙之霹雳城时期的雪山银燕还不曾取名为此，这时他叫驰突人。

婴儿时被八足原人拐走后养成为杀手，驰突人从不以真面目示人，行至何处都会带来杀戮，曾经还以血丝穿肠击溃黑白郎君。

后来成为霹雳城八部之死部统领，谁知败在卧底的小空剑下险些命归西天，被燕城三母所救后，一直对小空怀恨在心，欲报一剑之仇。

鹰燕龙虎榜鹰燕龙虎榜时期的雪山银燕，表现出来一种无情，无爱，个性单纯刚直，一度被丑孔明所利用，与小空进行手足相残，性格的表现不能说是自信，亦不属于懦弱，对亲情已死心的银燕充分变现出孤单的忧郁，无论是最亲的三母，或是最敬爱的炎，相继离去，使其不能再掩饰内心对亲情的渴望......雪山银燕某夜存孝遭到刺客袭击，三母出手相救而惨遭遇害，存孝认为自己是史艳文之子害死了三母，便因此舍弃姓名，改名“雪山银燕”，并在额上刻下燕疤，表示自己永远都是燕城的人。

黑白龙狼传银燕黑白龙狼传时期的雪山银燕，早期的表现是一种懦弱，一种力不从心，为救兄长小空，不惜一切……然而，得到剑无极等人的激发，雪山银燕的潜能涌现，溘乌斯能量得以发挥，变身成为手拿战戟，身穿银衣的武者，虽然目标依然，但此刻已不是力不从心……决战时刻天地风云录之决战时刻时期的雪山银燕，为了拯救兄长小空而使武力不断攀升，在宫本总司的要求下找到前辈雷狩，得其指点而悟得以魔入心、控制魔性使武力更上一层楼的方法，后与其交换武器，成为忘年之交。

后来雷狩死于邪马台笑之手，从雷狩处继承天下第一枪的雪山银燕毅然在风云碑留下姓名，打败邪马台笑，为中原击退西剑流立下功劳。

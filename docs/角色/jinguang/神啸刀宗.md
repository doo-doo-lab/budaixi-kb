# 神啸刀宗

================================================================================

金光布袋戏虚拟势力神啸刀宗是《金光布袋戏》中虚构的“道域”四大宗门之一，以刀法修行为核心，与仙舞剑宗、紫微星宗、阴阳学宗共同维系道域势力平衡。

其门人擅长刚猛刀招，重视实战与武者精神传承，宗门内部通过武斗选拔晋升，历代宗主以刀法造诣为继承标准。

该宗派源于道教仙人张道陵镇压血神后创立的四大学宗体系，由刀道流派分化演变而来。

作为道域传统势力的代表，其弟子参与“天元抡魁”比武以争夺天师云杖执掌权，该制度成为宗门间权力更迭的核心机制。

在《金光御九界之战血天道》剧情中，神啸刀宗因血神复生危机卷入道域权力斗争，宗主千金少等角色推动主线发展。

中文名神啸刀宗出 处金光布袋戏类 型虚拟势力相关人物千金少，西江横棹，冶云子等

### 镇宗双锋

#### 啸穹刀

神啸刀宗镇宗双器之一，似汉代斩马刀制式，镡长尺余，首为大环，并系有一串驼铃；刀鞘则呈广漠包缠的异域风格，并有数条金缕赭绫飘荡。刀镡为虎首王纹，譬喻刀宗「神啸」之喻；刀身笔直锋锐，玄面金镂，于一寸处有一缺角，乃三十三年前西风横笑于天元抡魁，惨败天之道、遭持之不败所斫。西风横笑由此半生蹉跎，易名弃刀，后由千金少持有，亦成为「笑残锋」名号的由来。

啸穹碎角被千金少托人制成项链，赠与徒弟戚寒雨。

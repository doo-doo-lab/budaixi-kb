# 神啸刀宗

================================================================================

金光布袋戏虚拟势力神啸刀宗是《金光布袋戏》中虚构的“道域”四大宗门之一，以刀法修行为核心，与仙舞剑宗、紫微星宗、阴阳学宗共同维系道域势力平衡。其门人擅长刚猛刀招，重视实战与武者精神传承，宗门内部通过武斗选拔晋升，历代宗主以刀法造诣为继承标准。该宗派源于道教仙人张道陵镇压血神后创立的四大学宗体系，由刀道流派分化演变而来。作为道域传统势力的代表，其弟子参与“天元抡魁”比武以争夺天师云杖执掌权，该制度成为宗门间权力更迭的核心机制。在《金光御九界之战血天道》剧情中，神啸刀宗因血神复生危机卷入道域权力斗争，宗主千金少等角色推动主线发展。中文名神啸刀宗出 处金光布袋戏类 型虚拟势力相关人物千金少，西江横棹，冶云子等

笑殘鋒.千金少神嘯刀宗現任宗主，為人爽朗，個性豁達。當年刀宗身陷道域大戰，前任宗主身亡，存亡之際千金少挺身而出，力挽宗門於狂瀾不倒。重情義，相當重視西江橫棹間的師兄弟感情，與其徒戚寒雨亦有著深厚情誼。武器為神嘯刀宗鎮宗雙器之[嘯穹刀]。夜雨凋楓·戚寒雨西江橫棹之子，也是千金少唯一弟子。個性正直認真，卻因當年天元搶魁父親戰敗，飽受宗門岐視，嘗盡冷嘲熱諷。父子表面關係不睦，但內心仍敬重父親，暗自冀望有朝一日能替父親洗刷當年戰敗恥辱，重奪家門榮耀。武器：調楓刀西江橫棹神嘯刀宗弟子，曾參加天元搶魁但戰敗。戚寒雨的父親。冶雲子神嘯刀宗耆老，宗主千金少的師叔，性格倚老賣老，令多數人感到頭痛。宗門雙鋒四藝鎮宗雙鋒嘯穹刀擬形八法刀宗絕學，要旨在擬形為次，擬神為要，刀要狠惡如狼，方能發揮精隨狼奔萬里馬馳殘陽雁鳴長空龍捲黃沙虎嘯空山猿啼孤月鳳舞狂花魚躍大川小碎刀步刀宗絕學，精義在靠近的人時，利用細碎的步伐，調整身形，製造快速旋身的效果，自意料不到的角度出刀，但絕殺的一刀，是轉向重步的一刀。踏步殺·碎夢掠步殺·疏狂回步殺·蕭索橫步殺·驚鴻極步殺·寂靜縱步殺·虛影金刀三式人兮鬼神辟‧金刀震萬里地兮山河泣‧金刀令千秋醉生夢死刀宗絕學，禁忌之招，運使此招太久，最終會陷入瘋狂失控的狀態，只有百酒丹可壓抑。

# 天满道隆

金光布袋戏虚拟人物天满道隆是金光布袋戏系列剧集《黑白龙狼传》《天地风云录之决战时刻》中的虚拟角色，隶属东瀛西剑流八门中的开门队长，属性为天，初登场于《黑白龙狼传》第11集，退场于《决战时刻》第3集。

作为邪马台笑之徒，其武学以体术与棍法为核心，武器为“棍”，灵属之器“天之霸”配合烈境旋空、断天拳等招式，展现出极强的近战能力。

个性恪守任务准则，厌恶阴谋暗算，在八门中较为正常，会在队长争吵时进行调节，对剑无极与其弟风间始的决斗会觉得不忍心。

曾参与西剑流入侵中原的行动，并与藏镜人正面交锋。

最终在去苗疆调查的路上偷听到藏镜人与千雪孤鸣的对话，欲回报西剑流时被藏镜人拦住，不敌藏镜人被击杀，头颅被割下交还西剑流，其忠耿性格与体术专精的矛盾性为剧情冲突增添转折。

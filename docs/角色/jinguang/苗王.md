# 颢穹孤鸣

================================================================================

同义词苗王（金光布袋戏虚拟人物）一般指颢穹孤鸣颢穹孤鸣是金光布袋戏虚拟人物，苗疆君主，狼主之兄，苍狼之父，由黄立纲配音。

初登场于《天地风云录之决战时刻》第11集，退场于《天地风云录之九龙变》第36集，掌握武学《皇世经天宝典·虚空灭》，招式包含狼王印、霸王殛。

颢穹孤鸣为老苗王次子，因精于城府被立为储君。

三十年前与父合谋诱骗皇兄天阙孤鸣入宫，使其背负刺杀罪名被囚禁于罪海七恶牢，此举导致苗疆内乱。

继位后采取守成之策，经数十年治理恢复苗疆元气，依靠铁军卫震慑内部，派遣藏镜人对抗中原。

因笃信预言猜忌臣属，陷入北竞王设计的九龙天书之局，最终在九脉峰遭藏镜人误杀。

颢穹孤鸣之死引发苗疆分裂，其子苍越孤鸣清除叛贼北竞王后重掌政权，终结动荡局面。

## 角色经历
三十年前与其父共谋，暗害祖苗王，诬陷其兄天阙孤鸣，致使天阙孤鸣被囚禁在罪海七恶牢整整三十年。祖苗王遇害后，由其父继承苗王位，后传位于颢穹孤鸣。希妲为其诞下王子苍越孤鸣，不久后病逝。三十年来，中苗战乱连年，颢穹孤鸣欲扩展版图，侵占中原。遂派苗疆战神藏镜人多次出兵中原，与史艳文交手多年，互有胜负。后迷信大祭司预言，导致苗王颢穹孤鸣猜忌大将，更欲将藏镜人除去，失去理智判断，陷入北竞王的九龙天书之局。岂料藏镜人大难不死，最终在九脉峰一战中，因北竞王·竞日孤鸣的算计，藏镜人错手将颢穹孤鸣杀死。

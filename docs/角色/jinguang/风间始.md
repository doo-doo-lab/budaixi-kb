# 风间始

布袋戏剧《金光布袋戏》中的角色风间始是金光布袋戏虚拟角色，由黄立纲配音，初登场于《黑白龙狼传》第19集。身份为东瀛东剑道二少主、剑无极胞弟，曾任西剑流景门队长及鲁家废字流传人。风间始早年遭西剑流控灵术操控为人形兵器，参与狙杀宫本总司任务时被其解救，被送至梁皇无忌处解除禁制。随后拜入黑水城废苍生门下研习铸造技艺，参与制作四极封与剑匣型思能装置。曾协助解救重伤的苗王之子苍越孤鸣并护送其至龙虎山。东剑道覆灭后安葬父亲风间久护，隐姓埋名流亡积蓄实力。该角色经历从东剑道少主、西剑流傀儡到黑水城铸师三重身份转变，重要关系包括兄长剑无极、师尊废苍生及恋人鲁玉。官方设定其重逢情境曲为《不负韶华》。

## 官方简介

被西剑流祭司改造后以人形兵器登场，在西剑流受挫后，担任八门队长，几番对战剑无极，实际为剑无极幼时已逝的弟弟。——（决战金光：史艳文传奇）西剑流八门之景门队长，剑无极的弟弟，在西剑流与东剑道之战中身亡，实则还活着，却被鬼夜丸用西剑流的术法所操控，是个没有自我意识的傀儡。——（决战时刻：桌布）景门队长，剑无极的弟弟，剑无极原认为其早在西剑流与东剑道之战中身亡，实则被鬼夜丸救起，利用西剑流的术法操控其意志，让他成为一个没有自我意识的傀儡。——（决战时刻：桌布2）剑无极失踪的弟弟，被西剑流意识控制，而后在众人帮助下恢复了意识。——（金光风云录）

## 角色经历
西剑流人形兵器登场，在西剑流实力受损后，担任八门队长之位。

曾几番于剑无极对战。

后来被梁皇无忌解除禁制，恢复自由。

(天地风云录之决战时刻第13集)但此时剑无极疯癫，便承担起照顾兄长的职责。

在剑无极恢复正常后，曾与雨音霜前往救助苍狼。

在魔世开启后，加入对抗魔世的队伍。

在废苍生的破窑里学习铸铁技术，尝试帮助修儒打造医疗工具。

制造出不完美的织命金刀，送给修儒，让其给无情葬月进行开脑手术。

打造出一把匕首送给小玉，并写了好几封情书意图表白，正当牵手之际，被废苍生打断。

被闯入黑水城的鲁缺打断一臂，无法接回，仍坚持打铁，希望成为剑无极、俏如来等人的助力。

进入黑水城生死一线升级（退场）。

回归东瀛。

打造双极封。

用计与锻神锋交流铸术四极封制造剑匣型思能装置风间始剧照

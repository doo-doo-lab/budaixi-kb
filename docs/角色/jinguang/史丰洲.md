# 史豐洲 (史丰洲)
================================================================================

金光布袋戲虛擬人物。史豐洲是明朝大將，曾奉命征討交趾。是雲州大儒俠史艷文與萬惡罪魁藏鏡人的生父。

基本介紹
- **

**中文名**：**: 史豐洲

**配音**：黃俊雄登場作品：金光布袋戲性別：男

**身份**：明朝征交趾將軍種族：人族歸屬：中原組織：明朝家族：雲州史家
 人物介紹,人際關係,師徒親友,對手仇敵,角色經歷, 人物介紹姓名：史豐洲

**身份**：明朝征交趾將軍化身：中國強家族：雲州史家歸屬：中原組織：明朝退場：病逝獄中人際關係師徒親友

**妻子**：水氏（宦門望族之後）兒子：史艷文、藏鏡人（被羅天縱收養，取名羅碧）兒媳：劉萱姑（杭州第一美人）、波娜娜(苦海女神龍）、女暴君（姚明月）孫子：俏如來（史精忠）、小空（史仗義）、雪山銀燕（史存孝）孫女：史菁菁（鷹女）、憶無心對手仇敵對手：羅天縱、紫玄冠角色經歷史豐洲擔任明朝征交趾將軍，與交趾戰神羅天縱交手，並將其頭顱砍去，羅天縱失去頭顱成了無頭將軍。失去頭顱的羅天縱，擄走史豐洲次子，後此男孩被當做羅天縱之子撫養長大，取名為羅碧，即為後來的藏鏡人。後來，史豐洲被羅天縱的大將紫玄冠俘虜，從紫玄冠口中得知，史豐洲最後在交趾的獄中病死。

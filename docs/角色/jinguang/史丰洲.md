# 史丰洲
================================================================================

金光布袋戏虚拟人物。史丰洲是明朝大将，曾奉命征讨交趾。是云州大儒侠史艳文与万恶罪魁藏镜人的生父。

**身份**：明朝征交趾将军化身：中国强家族：云州史家归属：中原组织：明朝退场：病逝狱中人际关系师徒亲友

**妻子**：水氏（宦门望族之后）儿子：史艳文、藏镜人（被罗天纵收养，取名罗碧）儿媳：刘萱姑（杭州第一美人）、波娜娜(苦海女神龙）、女暴君（姚明月）孙子：俏如来（史精忠）、小空（史仗义）、雪山银燕（史存孝）孙女：史菁菁（鹰女）、忆无心对手仇敌对手：罗天纵、紫玄冠角色经历史丰洲担任明朝征交趾将军，与交趾战神罗天纵交手，并将其头颅砍去，罗天纵失去头颅成了无头将军。失去头颅的罗天纵，掳走史丰洲次子，后此男孩被当做罗天纵之子抚养长大，取名为罗碧，即为后来的藏镜人。后来，史丰洲被罗天纵的大将紫玄冠俘虏，从紫玄冠口中得知，史丰洲最后在交趾的狱中病死。

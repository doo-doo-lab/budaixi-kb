# 凤蝶（金光布袋戏人物）

================================================================================

凤蝶是金光布袋戏中登场的虚拟人物，初登场于《黑白龙狼传》第9集。作为苗疆巫教遗孤，自幼被千雪孤鸣所救并收为义女，长期担任神蛊温皇侍女，具有百毒不侵体质及三途蛊宿主身份，后加入还珠楼组织。性格刚烈寡言却心地善良，自幼跟随温皇习得飘渺剑法前九式，曾假扮任飘渺参与布局。她与剑无极历经《九龙变》《剑影魔踪》等多部剧集的情感波折，在《墨武侠锋》中因玄狐事件终成眷属。因温皇布局多次涉险，最终选择照顾成为植物人的温皇退隐还珠楼，暂退隐于《齐神箓》第1集。

## 人物故事

凤蝶自幼便与神蛊温皇隐居于神蛊峰，时间长达十年，平日里主仆相称。

因三途蛊而导致身怀万毒血的她在神蛊温皇的悉心培养下，有了百毒不侵的体质。

凤蝶跟随神蛊温皇涉世后，曾在神蛊温皇诈死于炎魔掌下后假扮任飘渺去见宫本总司和百里潇湘，为温皇与任飘渺之间的身份之谜又增添了一片迷雾。《天地风云录之决战时刻》后期，在黑白郎君决战炎魔时，神蛊温皇为引发三途蛊而重伤凤蝶，凤蝶性命垂危之际，得冥医的帮助，彻底摆脱三途蛊，后又得神蛊温皇的相思蛊（能释放出含有剧毒却能刺激经脉的养分）恢复武功。

因凤蝶与剑无极之间的情愫等其他原因，神蛊温皇化身任飘渺提高剑无极武学之际，也导致了剑无极的疯狂。

其后，神蛊温皇多次试探凤蝶的感情，使得剑蝶情路一波三折。《天地风云录之九龙变》后期，在剑无极与神蛊温皇之间选择了神蛊温皇，最后带走成为活死人的温皇退隐。

无奈多次遭女暴君等人围攻没有真正退隐幕后。

一直在还珠楼照顾温皇。《墨武侠锋》时期，因玄狐之故，剑无极与凤蝶有情人终成眷属。《墨世佛劫》时期，遭受地门无我梵音的影响险被洗去记忆。

幸亏相思蛊起了作用，以凤蝶的安危为引机，及时救治成了活死人的温皇来救回凤蝶。

凤蝶—九

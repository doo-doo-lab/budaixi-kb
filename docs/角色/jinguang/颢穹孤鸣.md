# 颢穹孤鸣

================================================================================

金光布袋戏虚拟人物订阅0有用+10颢穹孤鸣是金光布袋戏虚拟人物，苗疆君主，狼主之兄，苍狼之父，由黄立纲配音。初登场于《天地风云录之决战时刻》第11集，退场于《天地风云录之九龙变》第36集，掌握武学《皇世经天宝典·虚空灭》，招式包含狼王印、霸王殛。颢穹孤鸣为老苗王次子，因精于城府被立为储君。三十年前与父合谋诱骗皇兄天阙孤鸣入宫，使其背负刺杀罪名被囚禁于罪海七恶牢，此举导致苗疆内乱。继位后采取守成之策，经数十年治理恢复苗疆元气，依靠铁军卫震慑内部，派遣藏镜人对抗中原。因笃信预言猜忌臣属，陷入北竞王设计的九龙天书之局，最终在九脉峰遭藏镜人误杀。颢穹孤鸣之死引发苗疆分裂，其子苍越孤鸣清除叛贼北竞王后重掌政权，终结动荡局面。中文名颢穹孤鸣别 名苗王配 音黄立纲性 别男登场作品金光布袋戏身 份苗疆之主种 族人族归 属苗疆组 织苗疆朝堂

## 人际关系

师徒亲友妻子：希妲皇子：苍越孤鸣（苍狼）皇弟：千雪孤鸣（狼主）皇兄：天阙孤鸣（撼天阙）皇叔：竞日孤鸣（北竞王）苗疆朝堂（颢穹孤鸣主政时期）苗王：颢穹孤鸣皇室：竞日孤鸣（北竞王）、千雪孤鸣（狼主）、苍越孤鸣（苍狼）除名皇室：天阙孤鸣（撼天阙）朝堂重臣：藏镜人、女暴君、赫蒙天野、赫蒙少使王族亲卫：冽风涛、岁无偿、叉猡、司空知命、慕云追逸、月荒凉祭司台：大祭司、阳九昊、阴九玄铁军卫：铁骕求衣（军长）、风逍遥（兵长）、白日无迹（尉长）、穷千秋（小尉长）、卫虎城、钩肠夜翎、噬心荒靡、破胆鹰豪其他臣子：刑武忌天、棘凌鹰羽、怒断山、丧魂灭、火流星、貂玉青、铁相对手仇敌对手：天阙孤鸣（撼天阙）

## 角色经历

三十年前与其父共谋，暗害祖苗王，诬陷其兄天阙孤鸣，致使天阙孤鸣被囚禁在罪海七恶牢整整三十年。祖苗王遇害后，由其父继承苗王位，后传位于颢穹孤鸣。希妲为其诞下王子苍越孤鸣，不久后病逝。三十年来，中苗战乱连年，颢穹孤鸣欲扩展版图，侵占中原。遂派苗疆战神藏镜人多次出兵中原，与史艳文交手多年，互有胜负。后迷信大祭司预言，导致苗王颢穹孤鸣猜忌大将，更欲将藏镜人除去，失去理智判断，陷入北竞王的九龙天书之局。岂料藏镜人大难不死，最终在九脉峰一战中，因北竞王·竞日孤鸣的算计，藏镜人错手将颢穹孤鸣杀死。

顥穹孤鳴

金光布袋戲虛擬人物。苗疆之主，狼主之兄，蒼狼之父。為人威嚴霸氣，而又生性多疑。因篤信預言，導致君臣反目，最終因北競王之陰謀，而死在藏鏡人手上。苗疆自此分裂，直至其子蒼狼清除叛賊，成為苗疆新主，皇權方才重歸正統。

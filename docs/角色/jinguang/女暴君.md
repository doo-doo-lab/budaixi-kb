# 姚明月（金光布袋戏中虚拟人物）

================================================================================

同义词女暴君（《金光布袋戏》虚拟人物）一般指姚明月（金光布袋戏中虚拟人物）姚明月，金光布袋戏虚拟人物。姚明月，江湖人称女暴君，藏镜人罗碧之妻，曾为天下第一美人，虽有倾国之貌，却无仁慈之心。昔时与丈夫藏镜人同为苗王颢穹孤鸣效力，随著九龙天书之局展开，才逐渐揭露其为北竞王竞日孤鸣暗桩的真实身份，更反向追杀苗王子苍狼等人，直到苍狼夺回王权、北竞王失势后，女暴君成为首波被清算的目标，与女儿忆无心之间的互动，也开始产生微妙变化。

## 官方简介

甲子名人帖上天下第一鞭，藏镜人之妻，本名姚明月，为人十分注重隐私、冷酷无情，手中握有藏镜人今生最大的秘密。——（决战金光：史艳文传奇）藏镜人之妻，本名姚明月，甲子名人帖上的天下第一鞭，为人十分注重隐私、冷酷无情，手中握有藏镜人今生最大的秘密。——（决战时刻：桌布）藏镜人之妻，本名姚明月，为人十分注重隐私、冷酷无情，性喜强势的男子，以藏镜人的秘密向西剑流及苗王交易，更亲自领兵追杀藏镜人，意图将其比如死地，为毒蝎美人的代表。——（九龙变：宣传简介）藏镜人之妻，也是苗疆女将军，本名“姚明月”外表冷艳娇媚，性格毒辣、难以捉摸、投机主义，且擅长挑逗异性。

夫妻关系极差，并不期待家庭天伦，只重视权势、利益与强大的异性。——（金光群侠传）藏镜人之妻，苗疆战将，名列甲子名人帖‘天下第一鞭’，为人心狠手辣，贪恋权势。

为了巩固地位，先是隐瞒丈夫抛弃女儿忆无心，多年后又在发现忆无心具备利用价值时，利用亲情为饵，制造母女相认，并接连布局陷害藏镜人，使其遭受苗疆围杀。

更令人生惧的是，这一切看似向苗王输诚以求晋升的举动，实际上是为了另一名自己真正效忠的王……——（九龙变：英雄扉页）天下第一鞭，藏镜人之前妻，个性阴险毒辣，为北竞王在苗王身边之暗桩。——（金光风云录）本名姚明月，甲子名人帖天下第一鞭，昔时与丈夫藏镜人同为颢穹孤鸣效力，随着九龙天书之局展开，才逐渐揭露其为北竞王暗桩的真实身份，更反向追杀苍狼等人，直到苍狼夺回王权、北竞王失势后，女暴君成为首波被清算的目标，与女儿忆无心之间的互动，也开始产生微妙变化。——（决战时刻：公司偶）

## 陆长生相关剧情

旧版剧情 姚明月女暴君，本名“姚明月”，原是交趾国王的掌上明珠，许配给争伐中原的大功臣罗碧(即后来之藏镜人)，两人郎才女貌，甚为恩爱。

但交趾第二次兵伐中原却吃下大败仗，罗碧远走中原，姚明月亦灰心丧志，离家出走。

姚明月失意之际，四处晃荡，多情且滥情的她曾先后与风雨断肠人、冷霜子有过感情纠葛，但这些恋情始终无法安抚她受创的心灵，于是便轻易弃情而去，尔后在藏边学得一身武功和邪功，心性大变，对中原的仇恨更激起她近乎变态的复仇大业，于是中原武林再度掀起一股腥风血雨的浩劫。

女暴君最让人丧胆的，首推以吸取男人元阳的邪功，毁在她手下的武林高手不计其数，在她邪功未破之前，可说打遍天下无敌手。

不过，史艳文与女神龙的搭配，隐隐为邪功的克星，于是女暴君设计擒得史艳文，并百般色诱，意欲吸取其元阳，但史艳文凭浩然正气，始终不让女暴君得逞。

不再要风得风、要雨得雨的女暴君，打算投靠南阳城的交趾余孽，却被藏镜人斥为淫妇，欲除之而后快，女暴君无奈，于是色诱南阳城主南海战神，顺利混入城中，再度展开其复仇，最后南阳城被中原群侠攻破，女暴君逃逸无踪，往后仍是黑道大姐大，为祸江湖。

新版剧情 姚明月新金光时期，与藏镜人（罗碧）均为苗疆之人，为苗王效力，两人生有一女忆无心，但因女暴君不想要孩子而丢弃，藏镜人害怕女暴君会抛弃女儿让父女无法相会，而在忆无心身上纹上火焰标记。

之后女暴君果然抛弃忆无心，但扔给予其一根石笛，意图在时机成熟时加以利用。

初登场时，藏镜人质问忆无心是不是两人的女儿，女暴君似乎早已知晓此时，对藏镜人冷嘲热讽。

后藏镜人面容暴露，协助苗王追杀藏镜人，一点也不顾夫妻情面。

九龙变时期，为苗王寻找九龙天书下落，其实早已投靠北竞王，故意泄露消息，让中原介入九龙天书争夺战。

在灵魔大战后，告诉忆无心自己是其亲生母亲，将其带到美人谷训练其特异功能，却未果，于是威胁要杀忆无心，引出藏镜人，并进行追杀，期间被藏镜人打败，又被邪马台笑、天海光流驱逐而逃。

之后和苍狼联手对付任飘渺，但追到还珠楼时，对还珠楼机关有所忌惮不敢前进。

后北竞王篡位成功，女暴君成为北竞王手下大将，在国葬时对战慕云追逸而落下风，之后多次龙虎山与撼天阙部队对抗。

魔戮血战时期，北竞王毒林计划完成，一举杀死慕云追逸。

后撼天阙死亡，被调至铁军卫任副军长，但又由于苍狼登台，与中谷大娘一起被抓走囚禁。

忆无心救出女暴君，为不牵连忆无心而独自一人逃跑，期间被白日无迹以忆无心威胁，又因自身勾结势力皆被铲除，气急败坏找上白日无迹并将其打伤，腿部也因此受伤，一步步爬向忆无心，最后母女相拥，苍狼允许女暴君自尽谢罪，女暴君道谢后，在爱女无心怀中退场。

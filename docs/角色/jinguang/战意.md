# 战意 (战意)

战意(网易旗下冷兵器骑战网游)

《战意》是一款冷兵器骑战网游，是网易游戏“不鸣工作室”2017年创新端游作品，致力打造一个波澜壮阔的古代战争世界。玩家将成为一名武将，统御各式兵马，于世界沙盘中往来杀伐、攻城略地。在《战意》中，玩家可以感受战马嘶鸣的旷野，巨兽眈视的城墙，可以在漫天的流石火羽中与敌人真刀真枪的肉搏，为领土与荣耀而战。

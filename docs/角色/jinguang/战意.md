# 戰意 (战意)
================================================================================

戰意(網易旗下冷兵器騎戰網遊)

《戰意》是一款冷兵器騎戰網遊，是網易遊戲“不鳴工作室”2017年創新端游作品，致力打造一個波瀾壯闊的古代戰爭世界。玩家將成為一名武將，統御各式兵馬，於世界沙盤中往來殺伐、攻城略地。在《戰意》中，玩家可以感受戰馬嘶鳴的曠野，巨獸眈視的城牆，可以在漫天的流石火羽中與敵人真刀真槍的肉搏，為領土與榮耀而戰。

遊戲簡介《戰意》為網易“不鳴工作室”歷時7年傾力打造的一款冷兵器騎戰網遊。製作人王希曾在微軟亞洲研究院與遊戲工作室Bungie工作室先後工作10年，參與製作《命運》和《光環》系列遊戲，有著豐富的遊戲製作經驗與國際級行業視野。基於不鳴團隊自主研發的CHAOS（混沌）引擎研發；《戰意》具有精細畫面與優秀表現力，在北美E3遊戲展參展，以及GDC世界遊戲開發者大會等重要的世界級遊戲展會亮相。遊戲主題《戰意》著眼於波瀾壯闊的古代戰爭，也為玩家提供了統御千軍攻城略地的平台。玩家將成為一名武將，統御各式兵馬，在各種古戰場中與敵人決一雌雄。在戰場上，玩家可以於十餘名隊友攜手對抗與你勒馬對峙的真實玩家，指揮各具特色的兵團，抑或使用古代攻城器械，將敵人一舉擊潰此外，還有望不到邊際的宏大世界沙盤，等待玩家的探索和征服—盤山為盜的山賊，長途跋涉的糧隊，多種多樣的亂世元素，都將在《戰意》的世界中呈現。歷史背景在《戰意》的戰場中，冷兵器與火器並存，多種大型攻城器械、多樣守城器械可以任你操縱。從西方的身著重甲的劍盾騎士、重甲斧手，到東方赫赫有名的長弓神射、關刀猛將，乃至東瀛武士鐘愛的野太刀，都將成為可供玩家成長和搭配的目標，玩家可以自由的搭配武器和裝備，點兵而戰。除了武器、兵團，各類城池與古戰場也有著濃郁的歷史感。從東方的飛檐小橋，到西方的魏巍城堡，都是玩家生活的城市，也都是玩家征服的目標。遊戲角色遊戲武器長弓長弓傷害極高，射程極遠，是戰場上的定點狙殺利器，一位射術精深的長弓武將，將是戰場上最可怕的存在。刀盾刀盾為攻守比較均衡的武器，擅長近身纏鬥，擁有一定的機動能力，是戰場上不可或缺的先鋒。劍盾劍盾身著板甲，持防禦盾牌的劍盾武士具有極強的防禦能力，是極好的陣線保護者，可以勝任各類戰術任務。關刀關刀屬於大範圍傷害的近戰兵器，招式大開大合，打擊面廣，具有強悍的群體輸出，在步戰與騎戰的時候均有不俗的戰力。火銃火銃是明朝火器，填充速度較慢，中距離傷害高爆發，可以亂軍叢中對敵人武將造成震懾性打擊。雙刀雙刀機動性極強，且能隱匿身形。在戰場上或對敵方武將發動一擊必殺的刺殺，或偷襲騷擾敵方據點，牽制敵人的行動。短弓短弓更注重靈活性，雖攻擊距離較短和傷害略低，但射速更快，身法靈活，更傾向在稍近一些的地方不斷進行持續的打擊。太刀太刀打擊面積大，切割傷害強，動作靈活，當其進入敵人的輕甲兵團中，可以發揮其最大的擊殺效率，是輕甲單位的夢魘。戰斧戰斧身披重板甲，防禦效果極強，是戰場最前線的勇士，撕開防線的重型戰士，是戰場上的推進核心。戰矛戰矛是戰場中的動作藝術家，武藝大師，多元化的打擊方式使其在小範圍的戰鬥中擁有其他武將難以比擬的優勢。主要兵種近戰：瑞士榮光長戟、馬爾他步行騎士、鐵衛營塔盾兵、馬爾他堅盾戍衛、青龍營槍兵、虎賁營刀盾兵等。遠程：英國皇家長弓手、白虎營擲矛隊、英國皇家長弓手、英格蘭皇家火槍手、馬爾他神射手、馬爾他精銳投矛手、弗朗機火槍手、羽林神射、精銳神機營火槍兵等。騎兵：哥薩克鷹騎兵、波蘭翼騎兵、朵顏弓騎兵、威武佩刀騎等。器械介紹一窩蜂、烏爾班巨炮、鐵砂炮、燃燒罐投擲器、猛火油罐、康格里夫火箭、佛羅倫斯颶風十字弓、奧斯曼臼炮、箭牌、火藥桶、回回炮、紅衣大炮、攻城塔、投石弩、床弩、法蘭西野戰炮等。遊戲特色沙盒化的武器和裝備搭配，玩家可以選擇遊戲中的任何武器和裝備，不同的搭配能夠產生迥異的戰鬥效能。從東方到西方的幾十種兵團都可以由玩家操控，兵團之間的相生相剋關係使得戰局更具策略感。細膩而有層次感的古代戰場，攻城雲梯、撞車和爬梯等戰爭機器力圖帶來身臨其境的戰爭體驗。呈現了一片宏大的世界沙盤，玩家可以在大世界上攻城略地，和好友建立自己的勢力，為領土而戰。重要事件《戰意》於2015年11月12日G-star展會正式揭開面紗，發布首部玩法視頻，並為玩家們準備了現場試玩。2016年7月22日，首次開放給精選的300名玩家進行試玩體驗。2016年9月19日，“燃夢首測”開啟，幾千名玩家在遊戲中相遇。2017年2月18日，創新進行1.5測，首次創新放出了“世界沙盤及勢力戰”玩法。2017年6月，《戰意》前往北美E3遊戲展，設立的獨立展位，向海外玩家展示中國人自己的遊戲。2017年9月15日，開啟創世終極測試。2018年1月26日，海外測試開啟。2018年4月27日，《戰意》開啟共研服，邀請玩家參與到遊戲的研發過程中。2018年5月，參展「核聚變

# 殷末簫 (殷末箫)
================================================================================

殷末簫

霹靂布袋戲經典虛擬人物。氣態不凡的法門之首，為人剛正、凜然不阿，慎謀且能斷，雖強調法理至上，但猶仍兼顧人情，乃武林懸案紛爭的仲裁者，對於三月浩劫血案尤為關注，一心欲緝查真相與兇手。

**武器**：御法劍人物經歷出場極度尷尬的法門創始人教祖的初登場其實很不是時機。武林是一個野心家輩出的地方。法門重出江湖的契機是武林公法庭的成立，而那正是兩個野心家召集眾人為實現其個人私慾的工具。法無吾給人的印象實在太差，衛無私則幾乎沒幹過什麼好事，於是乎法門也就成了一個藏污納垢的地方。這還不夠，殷芊嫿的出場再次令法門的聲譽打上一折。當然，唯有聶商的出場令法門挽回了一點顏面，這大概也是為了讓殷末簫的出場不至於太過尷尬吧。當然了，這樣的出場難免帶給人很直白的心態，這可能又是一個暗藏陰謀的老狐狸吧。父女師徒法外無情教祖登場之後，本是為了調查三月浩劫，然而也難免出來很多狗血得親情戲份，先是小女兒的無理取鬧自取滅亡，然而法門教祖依法執行，不偏私。而女兒被毘非笑抓走並用來威脅之時，殷末簫又放下教祖

**身份**：孤身前往，這是儘自己身為人父的責任。雖然最終女兒依然是死了，這只能證明天網恢恢疏而不漏，何況天道還是更看中這位優秀的法門教祖的。然而大女兒帶來了無名，一個失憶的殺人機器，雖然教祖也不知情，但是殷殷盼切之心，對無名的重用和關心，更看出一代宗師的風度，雖然前有衛無私，法無吾兩個不成器之徒，但是一個聶商展示出來的點點滴滴，足以掩蓋這二人一生的失誤。況且教祖本人對前二徒也是殷殷教誨，但是所謂江山易改，本性難移，他們始終沒有聽進去這位良師的教誨。這也還是印證了那句天網恢恢疏而不漏的道理。然而教祖在這之間不但得當處理了武林公事，更解決了自己的私事，所謂法情難兩全，可是殷末簫做到了，這是自古以來第一人。鞠躬盡瘁死而後已教祖出場以來，先是三月浩劫，後是協助一頁書屢破魔界詭計，還要處理各方勢力紛爭以及法門內部產生的一些私人情仇。可謂忙得不可開交。然而，每次戰鬥都身先士卒，甚至不惜以自己為餌去布局，彤太君、車車老，這兩人的性格固執而機車，絕不屈從他人，連退場都是自殺。但惟獨面對殷末簫時，他們願意吐露實情。紫宮太一、吞佛童子，這兩人身為兼具智慧與實力的一流高手，也都願意與殷末簫合作。至於莫召奴及弦首，雖與殷末簫來往不密，卻也有所交情。可嘆的是，弦首雖言有朝一日或許與法門並肩作戰，又誠邀教祖一上天波浩渺，但不料這匆匆一面，竟成永別。此間教祖是正道的擎天巨擘，但他為人剛直，性情溫厚，心思縝密，自有一股令人思慕的氣質。武林已經許久不曾出現教祖這樣的人物，溫潤時如涓涓細水，果決時似滔滔洪流。既若春風之溫煦，夾帶萬物生機；又像秋氣之肅殺，掃蕩萬惡無情。法門終戰，英魂震天下法門覆滅之戰，有傷在身的教祖這一次再無回天之力。人死之後，蓋棺論定，唯留聲名，任人評說。當神鷹眼七將法門之戰的結果報告給寂寞侯時，這位立志以紅河血禍重理乾坤的孤獨智者輕嘆一聲，頭一次露出稍許的落寞之感。連長久追隨其左右的眼七亦感奇怪，追問之下，寂寞侯給出了如此評論：“碧血丹心，化做一縷英魂，怎不教人悲噓，拋開立場，殷末簫是寂寞侯敬佩之人。”要知寂寞侯視人命如草芥，所有人，包括六禍蒼龍都只是他布局之中可供利用的棋子罷了。千年一擊成功之後，誰都算準魔界會有瘋狂的反撲，而法門也必然首當其衝，教祖之死恐怕只是時間問題。然而精明如殷末簫卻沒有聽老友的勸說，依然選擇面對魔界大軍，以一人之力，為法門留下點滴生機。寂寞侯能為教祖之死扼腕嘆息，本來已經足夠。但編劇覺得還是少了點，又安排了一個人對殷末簫再次進行了一番評價，這個人是秦假仙。當三人組趕到琉璃仙境，秦假仙是放聲痛哭報告了教祖的噩耗。業途靈頓感怪異道：“大仔，你不是一向對法門的人很感冒？為什麼殷末簫死，你會這么難過？”秦假仙的回應是：“你給我閉嘴，殷末簫不是一個壞人，是一個有風骨，有修養的先天人，他為武林付出這么多，盡心盡力，雖然我跟他見面的次數不多，但是對他的欽佩是一點也不少，啊…素還真，事情怎會演變到這種地步？”業途靈的疑問並不多餘，秦假仙在衛無私手上吃了大虧，以他的為人，如何不會遷怒連坐整個法門。但殷末簫從不曾以武力壓制秦假仙，也不曾對秦假仙有什麼大恩大惠，秦假仙又何以為他之死倍感痛心？以德服人，服君子易，服小人難，服君子般的小人最難。秦假仙就是這樣的人。而他能夠發自內心地敬重殷末簫，亦可見教祖在江湖人心中是何地位。千古功過，只余後人評斷教祖的事跡已經過了很久了，魔界之禍也已經平定，教祖有太多太多，難以抹滅的功績無法一一細說，例如千年一擊，對後來的影響不可謂之不大，比如對無名的教誨，比如甘當配角協助汲無蹤，教祖沒有因為徹查三月浩劫而牽扯無辜，冤有頭債有主，這法家執法的重心，素還真會因為葉小釵而失去理智，也會因為自己力所不及而不願意去面對，慕少艾會因為羽人而犧牲自己有用之軀，會因為傲笑紅塵而與魔界交易，縱然劍子仙跡，佛劍分說，甚至是百世經綸一頁書也會因為某些情理難兩全的情況下而選擇折中方式，然而僅有教祖殷末簫一人，永遠的身先士卒，永遠的明知不可為而盡力為之，即使會給正道帶來損失，也不願意讓別人難過，難道教祖不知道千年一擊之後魔界會全力反撲嗎？難道那時候讓無名退隱對正道是好事嗎？難道在那么個為難之時不能多集中些正道人士來協助抵禦魔界嗎？不是不能，而是力所能及，就全力以赴的心態。殷末簫不藏私，殷末簫不偏私，所謂“為國為民，俠之大者”金庸的小說中我敬佩蕭峰，霹靂的人物中敬重殷末簫，蕭峰尚有因孝抗父罪之舉，而殷末簫比起蕭峰更是高了一籌。英雄之上，已經無詞可形，送上“聖人”一詞估計也難以形容殷末簫之高義。論起殷末簫，只能說望塵莫及，縱然有心學習，世人皆難及，相信即便是霹靂布袋戲這般創造人物，也再難創造出超越殷末簫的人物了，畢竟聖人不是那么容易創造的，但是雖然難及，卻還是要學，法，情可以兩全，當政者該學，當家者更該學，教祖雖然僅留一聲長嘆，但是這聲長嘆也代表了世上還有太多需要渡化之人，教祖一人之力有時而窮，但是英魂永留心間，衝著對這份英靈的感念，即是我們學習的方向。

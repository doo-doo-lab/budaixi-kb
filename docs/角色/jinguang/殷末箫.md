# 殷末箫 (殷末箫)
================================================================================

殷末箫

霹雳布袋戏经典虚拟人物。气态不凡的法门之首，为人刚正、凛然不阿，慎谋且能断，虽强调法理至上，但犹仍兼顾人情，乃武林悬案纷争的仲裁者，对于三月浩劫血案尤为关注，一心欲缉查真相与凶手。

**武器**：御法剑人物经历出场极度尴尬的法门创始人教祖的初登场其实很不是时机。武林是一个野心家辈出的地方。法门重出江湖的契机是武林公法庭的成立，而那正是两个野心家召集众人为实现其个人私欲的工具。法无吾给人的印象实在太差，卫无私则几乎没干过什么好事，于是乎法门也就成了一个藏污纳垢的地方。这还不够，殷芊婳的出场再次令法门的声誉打上一折。当然，唯有聂商的出场令法门挽回了一点颜面，这大概也是为了让殷末箫的出场不至于太过尴尬吧。当然了，这样的出场难免带给人很直白的心态，这可能又是一个暗藏阴谋的老狐狸吧。父女师徒法外无情教祖登场之后，本是为了调查三月浩劫，然而也难免出来很多狗血得亲情戏份，先是小女儿的无理取闹自取灭亡，然而法门教祖依法执行，不偏私。而女儿被毘非笑抓走并用来威胁之时，殷末箫又放下教祖

**身份**：孤身前往，这是尽自己身为人父的责任。虽然最终女儿依然是死了，这只能证明天网恢恢疏而不漏，何况天道还是更看中这位优秀的法门教祖的。然而大女儿带来了无名，一个失忆的杀人机器，虽然教祖也不知情，但是殷殷盼切之心，对无名的重用和关心，更看出一代宗师的风度，虽然前有卫无私，法无吾两个不成器之徒，但是一个聂商展示出来的点点滴滴，足以掩盖这二人一生的失误。况且教祖本人对前二徒也是殷殷教诲，但是所谓江山易改，本性难移，他们始终没有听进去这位良师的教诲。这也还是印证了那句天网恢恢疏而不漏的道理。然而教祖在这之间不但得当处理了武林公事，更解决了自己的私事，所谓法情难两全，可是殷末箫做到了，这是自古以来第一人。鞠躬尽瘁死而后已教祖出场以来，先是三月浩劫，后是协助一页书屡破魔界诡计，还要处理各方势力纷争以及法门内部产生的一些私人情仇。可谓忙得不可开交。然而，每次战斗都身先士卒，甚至不惜以自己为饵去布局，彤太君、车车老，这两人的性格固执而机车，绝不屈从他人，连退场都是自杀。但惟独面对殷末箫时，他们愿意吐露实情。紫宫太一、吞佛童子，这两人身为兼具智慧与实力的一流高手，也都愿意与殷末箫合作。至于莫召奴及弦首，虽与殷末箫来往不密，却也有所交情。可叹的是，弦首虽言有朝一日或许与法门并肩作战，又诚邀教祖一上天波浩渺，但不料这匆匆一面，竟成永别。此间教祖是正道的擎天巨擘，但他为人刚直，性情温厚，心思缜密，自有一股令人思慕的气质。武林已经许久不曾出现教祖这样的人物，温润时如涓涓细水，果决时似滔滔洪流。既若春风之温煦，夹带万物生机；又像秋气之肃杀，扫荡万恶无情。法门终战，英魂震天下法门覆灭之战，有伤在身的教祖这一次再无回天之力。人死之后，盖棺论定，唯留声名，任人评说。当神鹰眼七将法门之战的结果报告给寂寞侯时，这位立志以红河血祸重理乾坤的孤独智者轻叹一声，头一次露出稍许的落寞之感。连长久追随其左右的眼七亦感奇怪，追问之下，寂寞侯给出了如此评论：“碧血丹心，化做一缕英魂，怎不教人悲嘘，抛开立场，殷末箫是寂寞侯敬佩之人。”要知寂寞侯视人命如草芥，所有人，包括六祸苍龙都只是他布局之中可供利用的棋子罢了。千年一击成功之后，谁都算准魔界会有疯狂的反扑，而法门也必然首当其冲，教祖之死恐怕只是时间问题。然而精明如殷末箫却没有听老友的劝说，依然选择面对魔界大军，以一人之力，为法门留下点滴生机。寂寞侯能为教祖之死扼腕叹息，本来已经足够。但编剧觉得还是少了点，又安排了一个人对殷末箫再次进行了一番评价，这个人是秦假仙。当三人组赶到琉璃仙境，秦假仙是放声痛哭报告了教祖的噩耗。业途灵顿感怪异道：“大仔，你不是一向对法门的人很感冒？为什么殷末箫死，你会这么难过？”秦假仙的回应是：“你给我闭嘴，殷末箫不是一个坏人，是一个有风骨，有修养的先天人，他为武林付出这么多，尽心尽力，虽然我跟他见面的次数不多，但是对他的钦佩是一点也不少，啊…素还真，事情怎会演变到这种地步？”业途灵的疑问并不多余，秦假仙在卫无私手上吃了大亏，以他的为人，如何不会迁怒连坐整个法门。但殷末箫从不曾以武力压制秦假仙，也不曾对秦假仙有什么大恩大惠，秦假仙又何以为他之死倍感痛心？以德服人，服君子易，服小人难，服君子般的小人最难。秦假仙就是这样的人。而他能够发自内心地敬重殷末箫，亦可见教祖在江湖人心中是何地位。千古功过，只余后人评断教祖的事迹已经过了很久了，魔界之祸也已经平定，教祖有太多太多，难以抹灭的功绩无法一一细说，例如千年一击，对后来的影响不可谓之不大，比如对无名的教诲，比如甘当配角协助汲无踪，教祖没有因为彻查三月浩劫而牵扯无辜，冤有头债有主，这法家执法的重心，素还真会因为叶小钗而失去理智，也会因为自己力所不及而不愿意去面对，慕少艾会因为羽人而牺牲自己有用之躯，会因为傲笑红尘而与魔界交易，纵然剑子仙迹，佛剑分说，甚至是百世经纶一页书也会因为某些情理难两全的情况下而选择折中方式，然而仅有教祖殷末箫一人，永远的身先士卒，永远的明知不可为而尽力为之，即使会给正道带来损失，也不愿意让别人难过，难道教祖不知道千年一击之后魔界会全力反扑吗？难道那时候让无名退隐对正道是好事吗？难道在那么个为难之时不能多集中些正道人士来协助抵御魔界吗？不是不能，而是力所能及，就全力以赴的心态。殷末箫不藏私，殷末箫不偏私，所谓“为国为民，侠之大者”金庸的小说中我敬佩萧峰，霹雳的人物中敬重殷末箫，萧峰尚有因孝抗父罪之举，而殷末箫比起萧峰更是高了一筹。英雄之上，已经无词可形，送上“圣人”一词估计也难以形容殷末箫之高义。论起殷末箫，只能说望尘莫及，纵然有心学习，世人皆难及，相信即便是霹雳布袋戏这般创造人物，也再难创造出超越殷末箫的人物了，毕竟圣人不是那么容易创造的，但是虽然难及，却还是要学，法，情可以两全，当政者该学，当家者更该学，教祖虽然仅留一声长叹，但是这声长叹也代表了世上还有太多需要渡化之人，教祖一人之力有时而穷，但是英魂永留心间，冲着对这份英灵的感念，即是我们学习的方向。

# 王骨（金光布袋戏用语）

================================================================================

王骨是金光布袋戏世界观中的特殊设定，指由终结乱世或开创盛世的君王、霸主遗骸所化之物，蕴含“王骨灵能”，既是术法珍宝，也是开启伏羲深渊的关键钥匙，具有强化术法、净化邪灵等特性。

九界王骨各具相异功能：始帝鳞可操控水域，狼王爪能克制皇世经天宝典武学，魔之甲赋予无敌防御，幽灵魔刀由元邪皇脊柱骨所铸，紫金钵融入达摩颅骨可镇压邪祟。

其形态涵盖鳞片、兵器、法器等多种类型，多被锻造成专属武器。

该设定最初用于破解魔之甲属性相克，后续发展为修复镇魔龙脉的核心材料。

在《仙古狂涛》剧情中，九项王骨被熔铸为天柱不周山，破碎后形成的四块结晶引发多方势力争夺，成为贯穿剧情的重要线索。

中文名王骨定 义盛世君王、霸主的遗骸形成出 处金光布袋戏

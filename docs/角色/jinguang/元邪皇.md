# 元邪皇

金光布袋戏虚拟人物元邪皇，金光布袋戏虚拟人物横跨一千多年而重生的魔世霸主，玄朝时期率众侵略人界，遭到初祖达摩击杀，分散成各种遗物存世，最终借由酆都月重新汇聚，方穿越千年时空再临。重生后以迅雷不及掩耳的速度统一魔世，并窃取九界地气，准备伺机重返人界，在地门溃败之后，因达摩金光塔能量失衡，导致魔世入口大开，遂借此踏入人界，准备重现千年前的灾劫。

## 角色经历

（以下有微剧透向）
千年前曾一统魔世，野心大开，乘势带大军一攻人界，被佛国初祖达摩和墨家时任矩子皇甫佚名以及鲁家（废字流）等多方势力联合击杀。

死后四项遗物流落人世，分别为枯髓咒怨，幽灵魔刀，魔心鉴以及紫瞳灵睛。

利用流传在人世千年的魔心鉴附身于还珠楼副楼主酆都月的肉身寻找四项遗物，再利用枯髓咒怨的扩散病毒屠杀天门众多僧侣，诈死于玄之玄之手，偷走万化金光佛以及枯髓咒怨，之后紧随于梁皇无忌一起进入魔世。

而后有人盗走幽灵魔刀进而促成了元邪皇的复活，复活之后的元邪皇以惊天动地的威能横扫魔世，修罗国度双尊战败被擒，公子开明得知消息后急忙从沉沦海赶往修罗国度，企料连一个蓝月的时间都未满，修罗军就被元邪皇彻底击溃，在梁皇无忌命危之际，史艳文与暗盟三大剑手之一的鬼飘伶赶来支援救下梁皇无忌，而后梁皇无忌越过沉沦海向其他诸国求援，公子开明则进入人世找寻诛杀元邪皇的办法。

元邪皇再成修罗国度帝尊，随后统领大军覆灭暗盟之一的帝女精国，魔伶公主在大战中下落不明，生死未卜（根据剧中的情况，以及官方的暗示，基本可以确定死亡）。

之后又横击沉沦海彼岸的凶岳疆朝，但凶岳疆朝的领导者应龙师并没有多做抵抗，直接投降。

尔后暗盟为顾全大局，暂降屈身于邪皇之下，实际在暗中谋划反抗元邪皇。

就这样，元邪皇再次一统了魔世，但他没有去稳固人心，随即立马向人界发起战争。

此时人界正于地门大战刚刚结束，元邪皇率魔军攻入人世便开第一战，一败地门大智慧——缺舟一帆渡，但最后一击未能突破萨埵十二恶皆空，气劲反冲之时被钟声干扰受创，随即被缺舟的最强之招——梦幻泡影所反击，带来人世的十数万先锋大军瞬间覆灭，元邪皇亦负伤。

战胜缺舟后，元邪皇以养伤为名留在鬼祭贪魔殿，一边督促应龙师、曼邪音、炽阎天等人备战，一边遣胜弦主作为使者告知中原，若不立即投降，便要挥军将人界变成尸山血海。

胜弦主在与俏如来等人会晤后定下计划，让俏如来假意接受投降，条件是元邪皇独自一人到天允山接受俏如来投降。

元邪皇在佛国境内被狼主与地门前天护逾霄汉发现了自己的重大秘密，在元邪皇察觉到两人后，随即决定斩草除根。

在元邪皇一招杀掉逾霄汉，正准备结果狼主时，因为狼主义女七巧的突然闯入，元邪皇收回了手，但因为狼主攻向邪皇，邪皇反击的一掌把狼主打下了山崖。

七巧爬下悬崖寻找狼主，幸运的是狼主并没有身死，尔后被化名为单夸的竞日孤鸣所救。

元邪皇派遣胜弦主前往万里边城，应龙师前往金雷村，自己则独自一人赴会天允山，应对俏如来的假意投降。

俏如来的目的是用止戈流真阵刺杀元邪皇，而元邪皇也并不认为俏如来是真心想要投降，孤身赴约实则是想要试探中原盟主的实力。

两人不由分说便是开战，但结果，止戈流却无法对元邪皇尽全功，因为眼前的魔皇，并非是魔的躯体，随即，俏如来被元邪皇的一掌反击，陷入了生命危险，在元邪皇想要了结他性命时，被恰好回到人世的史艳文救下，用一枚神秘的信物（和苦海女神龙的发带一模一样，也有可能是道具相同）换得了一次恩情即两人全身而退的权利。

击败俏如来后，元邪皇便开始四处征战，全面树敌。

即便是对自己麾下的势力，元邪皇亦从未给予过信任，只是不停地命令他们出战，仿佛完全没有考虑后果一般。

此时，元邪皇的一切在众人眼中，成为了难以理解的迷雾。

由于应龙师进兵受阻，元邪皇降临金雷村，以不可撼动之能为屠杀了当初修罗国度战败后受佛国和海境庇护的魔兵，杀死鳞族太子北冥觞，重伤鳞王北冥封宇，在入龙涎口时，白练飞踪锦烟霞引爆了龙涎口，欲用龙涎口水流的冲击力结合自身蛟龙御水天赋与一步禅空的功力所使出的萨埵十二恶皆空与元邪皇同归于尽。

绵延百里的超强水流猛冲而出，金雷村的方圆百里，遍地是魔兵的尸骸。

然而元邪皇却如同毫发无伤一般从水中飞出。

八面开战，利用吊魂罪假扮的自己避开了胜弦主的眼线，救下了被四方伏击的应龙师。

毁灭黑水城的一切，准备杀死众人时被化身为天地不容客的藏镜人阻拦。

有两个元邪皇的秘密被苏醒的狼主揭晓。

九龙天书中关于九界地气的记载揭露了元邪皇真正的目的。

元邪皇想要的并不是一统九界，而是让九界合一，令始界回归，让环境可以重新适合烛龙生存，他假借四处征战的名义，暗中破坏六绝禁地，当众人察觉到时候，地脉已经只剩九脉峰与无极山两处。

暗盟反目，胜弦主带玄狐，西经无缺来刺杀元邪皇，但被替身所骗，接中邪皇全力一掌，胜弦主重伤，其余两人情况相同，暗盟因为此次失败，胜弦主与西经无缺四处逃亡，暗盟分裂，但元邪皇亦在此次被玄狐斩武道所伤，上次的伤势也并无恢复，加上几次的磨损与几次破坏九龙地脉的大量的消耗，自身力量在渐渐消失。

邪皇与应龙师完全反目，血战天下。

降临无极山，对战俏如来与玄狐两大绝技合招，最后用先前布好的局（邪皇的力量本体在幽灵魔刀之上）与四元真诀险胜合招，自身也受了不小的损耗，随即毁灭无极山地脉。

用替身与应龙师谈判，让他保持中立不干扰自己的计划，并暴露出自己只剩一月元寿。

应龙师挟持五百名畸眼族族民民威逼邪皇，邪皇动怒。

遇见史艳文之子——雪山银燕史存孝，当时雪山银燕正想要收埋一名名为睛儿的畸眼族男童的尸体，不过那时两人都不知道彼此的真正身份，元邪皇对雪山银燕能不计人魔之别的立场去收埋晴儿尸体的行为表示感谢，记下了恩情。

半途遭遇天地不容客拦截，因不想持久消耗以及对方的地形以及武器都对自己强烈克制，便第一次撤离了战斗，直奔向五百畸眼族所在的无极山。

在无极山遇上了胜弦主，西经无缺，以及暗盟的残余势力。

用假魔刀瞒过了众人的耳目，让西经无缺误以为能有机会完全将元邪皇消灭。

最终暗盟众人牺牲了自己的性命，让西经无缺吸收了足够的灵魂之力，而西经无缺亦将自身灵体的力量全部耗尽，与元邪皇同归于尽。

在众人都以为元邪皇已死而聚集到无极山查看情况的时候，吊魂罪变化为众人最不熟悉的鬼飘零，用调虎离山计遣走的驻守在九脉峰的苍狼，随即用真魔刀的力量轰炸了九脉峰。

六绝禁地开启，元邪皇用睛儿肉体，再次复活。

再次遇到雪山银燕，此时雪山银燕正好被困于彼岸虫的噩梦之中，为报恩情，元邪皇将其救下，带入自己的暂避所中。

之后第三次遭遇天地不容客拦截，强行带雪山银燕撤离了避所，四处求医为偿还恩情，但最终无果，无计可施之下用魔心鉴强行侵入雪山银燕的意识梦境中。

在梦境中遇见史家的所有人，每一个人物都对应着雪山银燕心中的一种情感，而雪山银燕的心魔，以戮世摩罗史仗义的外貌、元邪皇的身份出现。

元邪皇试图引导雪山银燕解开自己的心魔，途中遇到缺舟一帆渡残留在雪山银燕脑中的意识分身，被缺舟指出自己之所以会想帮助雪山银燕，是因为两人之间有着相似的地方，雪山银燕所面对的问题，其实也是元邪皇所面对的问题。

之后两人联手开导雪山银燕，却在即将成功的最后关头，因为元邪皇之前注入雪山银燕体内的魔气让心魔产生了自我意识，最终功亏一篑。

之后带着雪山银燕继续逃命，途中遇见鬼飘怜与公子开明，两人未能围堵住邪皇的脚步，然而紧随其后遭遇墨家九算老五凰后带众军围堵，元邪皇为保护自己背上的雪山银燕而处处受制，就在东门朝日对元邪皇偷袭差点得手之时，雪山银燕心魔所化的第二人格觉醒，斩杀了东门朝日，击退凰后。

吊魂罪为保护元邪皇，去拦阻光门八叶师，引开了佛国光门的追兵。

邪皇再次突围，吊魂罪被众僧围堵，随后自爆牺牲。

两人后躲避于一个无名的洞窟，雪山银燕苏醒，再等待许久之后，元邪皇明白，吊魂罪已经回不来了，将这件事告诉了雪山银燕，并希望雪山银燕能记住这个人。

之后雪山银燕为报恩（此时还不知道邪皇身份），希望能帮助元邪皇恢复体力，在洞窟外面守卫，被雁王发现，两人发生冲突，雪山银燕最开始不敌，再被雁王击倒后，第二人格再次觉醒，单手击碎了雁王的一颗断云石，并称自己为“驰突孤燕”，并击伤雁王。

雁王认为驰突孤燕的出现也许会让局势变的更有意思，于是便收手离开。

之后雪山银燕带元邪皇再找藏身点，来到金雷村的旧址，路过常欣墓前。

在听过常欣的故事之后，元邪皇随即推理出九算的阴谋，但并未道明。

承认与雪山银燕的七日友情，后在中原群侠众围堵金雷村时暴露身份，让雪山银燕大受打击，但因恩情未了，雪山银燕带元邪皇最后一次逃离围堵。

之后彼此都表示，恩情已经两清，下次见面将会是敌非友。

找上还珠楼楼主神蛊温皇，对中原正道愿意收留五百畸眼族的恩情表示感谢，在说明了雪山银燕的心魔和第二人格的问题之后，似乎心知肚明与任飘渺必会一战，之后大败任飘渺。

前往伏羲深渊，途中遇到雪山银燕阻拦，尽管彼此都不愿意出手伤害对方，但为了自身立场两人仍然不得不战。

雪山银燕在矛盾的感情中再次进入了“神魔非我”境界。

元邪皇对雪山银燕的进步表示赞叹的同时，不挡不避的硬挨下了雪山银燕的一击，之后用一根手指将雪山银燕击昏后继续前进。

一路杀上伏羲深渊，元邪皇再无保留的开启全力，先后击退了史艳文、藏镜人两兄弟的联手，风逍遥、鬼飘伶、公子开明、狼主的围攻后，再用邪眼的威能直接令当时台面上所有的高手与中苗联合大军跪伏，但因五百畸眼族与雪山银燕的恩情并没有杀任何人。

在走向最后一步时，俏如来从天边降下，带着融合了玄狐铁精的墨狂挡在元邪皇的面前。

元邪皇与俏如来展开了激战，在最后幽灵魔刀断裂，邪皇拼尽最后一招，打算燃烧魔元与俏如来和伏羲深渊同归于尽自爆，但俏如来被突然赶来的雪山银燕推开，雪山银燕决定与元邪皇同死，但元邪皇因为与雪山银燕的友情，在最后将银燕一掌推了出去，身体的魔元四散开来，轰炸了整个伏羲深渊，雪山银燕在途中也断了一条手臂。

最终因为俏如来在之前保住了黑水城的地气，也保住了整个九界未化为始界，元邪皇以失败告终。

一代皇者，就此陨落。

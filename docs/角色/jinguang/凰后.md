# 凰后（金光布袋戏虚拟人物）

凰后，金光布袋戏虚拟人物。当世九算排行第五，姿态妖娆，风情万种，在收服人心方面甚有天赋。长期蛰伏于尚贤宫，暗中观察局势，并掌握墨家使徒名册，与雁王联手收揽墨家成员，并接连算计玄之玄、铁骕求衣，明面以取得止戈流、继承巨子为目标，实际意图完整墨家，归黑暗，掌握历史，并让自己成为黑暗界的王者。擅长以虚实相参的流言带动风向，操纵舆论，使局面导向自己所想要的状态。

## 经历
因和巨子理念不同，墨家九算九人曾联手对抗巨子默苍离，自身重伤。

结果最终九算四死二重伤惨败，隐于九界。

羽国九羽内乱后，著作《羽国志异》和九算散播，用孛星之说抹黑，意图要引出巨子。

却反被利用作为抹黑墨家的手段，迫使九算无法直接现世，同时让俏如来成为承担墨家巨子传承的因素之一。

一直都隐身于尚贤宫，收集情报，观察时局，并等待合作者雁王的到来。

雁王到达尚贤宫后，浮出台面，与之联手布局。

诱导玄狐来到金雷村攻击龙涎口，想引出欲星移然后借玄狐之手除之。

谁知梦虬孙为保护龙涎口与玄狐交战，龙涎口受到震荡，为护鳞族，鳞王决意孤身迎战玄狐，结果却不幸重伤身亡，成了欲星移的替死鬼。

金雷村外玄之玄欲劝说玄狐再次为自所用，结果落入凰后的陷阱，原来凰后与玄狐早有协议，只要他针对龙涎口并杀掉玄之玄就能让俏如来提前与他决战比剑，玄之玄重伤化身而逃，半路派杀手设伏挡关，最终玄之玄被凰后终结。

魆妖纪篇章结束后，雁王暂时退隐，但凰后本人仍旧留在尚贤宫探听动向。

齐神箓时期与天首梅若馨争夺天下第一兵名额，获胜，留名天下第一兵。

仙古狂涛复出，与铁骕求衣（御兵韬）再会九算老八•卜算子（太叔雨），期间产生冲突，但最后结成统一战线，与俏如来代表墨家共同应对仙岛及最后一名鬼谷四慧。

最终与太叔雨（卜算子）、未珊瑚、烬寒蝉联手获得王骨结晶（紫）。

妖祸天劫复出，与灭帝羽邪产生暧昧关系，期间被铁骕求衣、上官鸿信多次提醒小心引火烧身。

与病子夫（卜算子学生）对战娲龙和密雕，赤手从容接下娲龙数剑，极端时刻灭帝羽邪入局驱赶娲龙，本档结束时与灭帝羽邪牵手迎战殊天九。

## 相关扩展

金光布袋戏，实际通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪(长女)和黄立纲(幼子)共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。

以声音道具等奇关变景吸引观众的表演形态，被称之为“金光戏”，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，后于1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的“金光戏变革”，故把自己旗下的布袋戏事业，称为金光布袋戏。

主要剧集《千禧版云州大儒侠》至《金光御九界之仙古狂涛》。

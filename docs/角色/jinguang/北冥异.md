# 北冥异

金光布袋戏虚拟人物金光布袋戏虚拟人物。太虚海境四皇子，外表温文尔雅，霁月光风，内里谋算阴沉。双亲皆是海境最为高贵的鲲帝血脉，手下多为鲛人，血统极为尊贵，却无高高在上的习气，个性谦和有礼，处事圆滑，因此备受诸多臣属、贤士的推崇，更受鲛人一脉争相辅佐，为鳞王七子中，除了太子北冥觞以外最亮眼的皇子。实为鳞王（北冥封宇）之弟北冥无痕之子，三王之乱后被鳞王收养，纳为四皇子。九岁时被人故意告知自己的身世，挑拨起他对北冥封宇的仇恨。在北冥封宇重伤昏迷之际，献出珍藏的朝元丹，稳定北冥封宇的伤势，使其在夺嫡当中取得先手。

## 经历

【金光御九界之东皇战影】时期在鳞王重伤昏迷时为其积极奔走，献出丹药朝元丹。

表面上性情温和，品学兼优，手下多为鲛人脉的能人异士，双亲又皆是海境最为高贵的鲲帝血脉，出身极为尊贵，是继任太子之位的最佳人选。

实际自己心知并非鳞王之子，而是三王之乱叛逆之一的北冥无痕之子，因杀父之仇记恨鳞王，暗中栽培阎王鬼途的一干死士已久。

在夺嫡过程中毫不留情，并在朝元丹上动了手脚，使得鳞王不能转醒，志在太子之位，甚至预谋直登龙座。

后计划被俏如来破坏，失去筹码，被迫转为与俏如来合作，救醒鳞王。【金光御九界之魆妖纪】时期鳞王醒转，与之深谈，北冥异内心震动，不再失志，为再次争取太子之位而努力。

在北冥华为了救自己而死之后，深受触动，开始变得成熟！

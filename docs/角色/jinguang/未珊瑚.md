# 未珊瑚

金光布袋戏虚拟人物未珊瑚，金光布袋戏虚拟人物，太虚海境清卯宫皇贵妃。出身宝躯未姓一脉，家世不凡，多年前在三王之乱时，作为智囊辅佐鳞王北冥封宇，谋划纵横，不落下风，因此深得鳞王信任，并在北冥封宇重伤后被委以摄政之责，全理海境朝局。实则暗藏野心，水静深流，一手主导了如今的皇子之争，希望借此能使宝躯未姓凌驾鲲帝、鲛人两脉。。

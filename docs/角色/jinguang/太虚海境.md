# 太虚海境

金光布袋戏虚拟势力太虚海境是金光布袋戏中的虚拟势力，为中土九龙地界之一，由鳞族构成，与中原及墨家有深厚渊源。

鳞族内部实行鲲帝、鲛人、宝躯、波臣四级世袭阶级制度。

海境创世于太古三朝前，战朝之前九龙之气汇集鳞族所在之太虚海境。

鳞皇惊觉魔世之现可能会动摇天下，遂派鳞族公主赵姬偷渡中原，嫁于七雄之首，生鳞人混血之子即为战朝始帝，太虚海境倾全族之力资助始帝一统天下。

始帝死后，鳞人形态复现，身躯被运回太虚海境，其身躯一块鳞片成为王骨始帝鳞，能让佩戴者在海中穿梭无阻，更不受太虚海境的无根水影响。

此后海境避世两千年，期间皇族北冥清涟曾化名李太白游历中原，后带杨贵妃回到海境，亲赐未姓归入宝躯一脉引发震动。

鳞人青奚宣发现连接海境的龙涎口隐患。

天地风云录之九龙变时期因始帝鳞失窃与九龙争珠事件，海境重新与外界产生纠葛，藏镜人借史艳文的身份进入太虚海境，并派千雪孤鸣盗取始帝鳞。

魔戮血战时期经师相欲星移推动正式入世抗魔，龙气致使海境地震，始帝陵倒塌，欲星移代表太虚海境与中原签订合约。

墨武侠锋时期彻底打破隔世陈规，欲星移曾回到海境调查百年前的历史。

仙古狂涛时期，皇贵妃未珊瑚在鳞王北冥封宇昏迷期间代为摄政引动海境内乱，后配合俏如来反杀大计。

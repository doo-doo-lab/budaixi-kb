# 梦虬孙

================================================================================

金光布袋戏虚拟人物梦虬孙，金光布袋戏虚拟人物。太虚海境龙子，乃是鲛人、宝躯两脉混血，因而重现上古四龙中之虬龙体质，儿时因血统而饱受鲛人同辈欺凌，十分艰苦，一度流落江湖，乞讨为生，却也意外加入鳍鳞会，结识八纮稣浥。后经由其堂兄欲星移正名，受封“龙子”。儿时的经历造就现在看似随和任性、实则藏有强烈反击因子的叛逆个性。梦虬孙为人豪爽硬气，爽朗洒脱，有智谋却往往被被个人情感左右，在欲星移倒下后，接下沧海珍珑，一肩担起代掌师相的责任，在复杂的宫廷斗争与海境江湖的纠葛中却愈陷愈深。中文名梦虯孙别 名乞罗八景配 音黄立纲性 别男登场作品金光御九界之墨武侠锋金光御九界之墨世佛劫金光御九界之墨邪录金光御九界之东皇战影登场作品金光御九界之魆妖记生 日12月31日（初登场）身 份海境龙子种 族鳞族血 脉虬龙归 属海境组 织海境朝堂、鳍鳞会偶 师萧佟兴

## 人物经历

出身于太虚海境，由于血统等级森严，作为鲛人混血的梦虬孙在童年时期时常收到欺负，而其堂兄欲星移作为鲛人纯血统生来拥有特权，令其感到不平。之后某个时间段，欲星移在一本古籍上发现梦虬孙竟然身负远古四龙之一的虬龙血统，特点便是他生来具有的角，从此梦虬孙地位迅速上升。然而对于幼时欲星移对自己的袖手旁观，梦虬孙一直心有芥蒂。直到亲历了无根水之变，地门之乱，见证了欲星移的种种行为，态度才开始慢慢转变，直至后来接过沧海珍珑，传承了欲星移守护海境的夙愿，成为代掌师相。过去认识了剑无极，因为需要还珠楼的帮忙，所以强行闯入还珠楼，还大曝光剑无极私下讲凤蝶的话，神经感觉非常大条，在剑无极冲动想要冲出还珠楼帮助俏如来对付地门之时，却又冷静阻止。是剑无极的朋友。损友是皇太子北冥觞。在地门之战中，欲星移为逼使玄狐出手布局令巫女常欣遇害于地门之手，梦虬孙为此对欲星移感到极度厌恶。但也对其于地门之战遇害感到极悲伤，并坚信欲星移还有复活的机会。紊劫刀死后，梦虬孙见到其尸身情绪崩溃，冷静下来后与俏如来决裂，成为北冥皇室死敌并且称自己会永远站在雁王和俏如来的对立面，用他们的理念让他们不得安生。

## 势力介绍

太虚海境，金光布袋戏虚拟势力，金光九界之一。且是太古三朝之一，创世已久，境中种族皆为鳞族，与中原以及墨家有着极深的渊源。鳞族创世已久，太古三朝之前，一向与人族交通往来，后来鳞族发生内乱，遂封闭海境通道，自与人绝。一直到人族战朝起七雄争，当时的鳞族却是一统，空前的繁荣。时任鳞王派公主赵姬入中原，为七雄一统奠下基业。赵姬入世之后，鳞族在背后以万金资助始帝相父，使其嫁入七雄之首，生下始帝，继承盛世之国，又得鳞族暗助，墨家鲁家之智巧，遂一统天下。始帝自知承万恶罪名，身为鳞族，恐死后暴露身份，引起两族纷争，又为回归故乡，遂下令建造疑冢，隐藏身份，命其长子公子苏与爱将假意自尽，扶灵回到太虚海境，他死后尸骨尽化，唯留一鳞，就是王骨始帝鳞，两千年来一直供奉在海境。自始朝以来，海境便隐居避世，与其他几界隔绝。由于避世过久，两千年后，不论是海境还是鳞族，于世人眼中已成为传说。鳞族内部等级森严，近乎世袭的种族制度，造就了海境明显的阶级之分。最高贵的为王族鲲帝，之后依次为鲛人、宝躯、波臣。而混血则为最低劣的杂种。天地风云录之九龙变起，随着王骨始帝鳞被苗疆狼主·千雪孤鸣抢夺，鳞族师相欲星移入世，鳞族逐渐卷入纷争中。太虚海境在闭关千年之后，终得以重出九界、再现尘寰。

## 主要剧情

人物事件1.拿走梵海惊鸿的佩剑颠倒梦想，引欲星移前去潜龙崁看他。2.与欲星移交谈后，归还颠倒梦想。在欲星移的支持下为证明心中想所而离开海境，3.前往苗疆参加锋海剑夺。4.被欲星移算计而看守龙涎口。5.魔世之乱斗元邪皇。6.鳞王昏迷，以代理师相身份稳定朝局。7.海境内战，带领鳍鳞会对抗皇室大军。1.与欲星移谈论海境的日常（墨武侠锋第18集）梦虬孙：欢迎，当然欢迎，来，拔剑，别啰嗦。欲星移：没剑。梦虬孙：没带？欲星移：送人了。梦虬孙：（怒）看到鬼！（剑气袭向欲星移，欲星移用坛截挡）将剑送人，你是头壳破洞吗，欲星移？欲星移：我从不知你这麼在意。梦虬孙：谁在意？哼！欲星移：酒。梦虬孙：茶。欲星移：哈！梦虬孙：（接过抛来的坛子）我说茶！欲星移：是茶没错，苦茶。梦虬孙：（开塞，喝一口，喷出）这不是百里闻香。欲星移：加了醉雄黄的百里闻香，这种酒味，只对妖魔有狂乱之效。我知晓你有酒胆没酒品，不会恶意拐你。这种感觉很好，不是吗？梦虬孙：什么感觉？欲星移：家。梦虬孙：看到鬼！鳞族三大血脉，鲲帝，鲛人，宝驱无一容身之处，就连波臣也算不上。家？哈！欲星移：你还是耿耿於怀，堂弟。（接过抛来的坛子，喝一口）不想我这样称呼，或者你希望我直接叫你，乞罗八景梦虬孙。梦虬孙：有很多事情，愈是明白，愈是不能谅解。欲星移：嫉妒，恐惧，排斥，人之常情。梦虬孙：就因为我是鲛人宝驱两脉的混血？欲星移：就因为传闻中那四种龙的资质只出现在两界。（放下坛子）蛟龙、应龙，魔世之属，虬龙、螭龙，鳞族之属。早该湮没的传说，却经由混血而重现，实属难得。所以我曾经用我的职权，让你出海境游历一番，开阔见识，还记得吗？梦虬孙：你要我感激你？欲星移：我只是想告诉你，追求自己想要的就够了。梦虬孙：你推行墨学，也是单纯为了自己的追求，还是为了彰显你的成就以及权力？欲星移：看来你还想证明什麽，那……（将坛子踢起，悬空）就去证明吧。（梦虬孙旋棍前击，两人交手，震碎坛子。）梦虬孙：当然。（转身离开）天涯逆子乞行踪，笑讽王孙畏吉凶，远浦三更弹宝剑，平沙一夕悦虬龙被欲星移算计看守龙涎口（墨武侠锋第24集）欲星移：还有吃的吗？梦虬孙：有喔。（取出面包抛给欲星移）啊！（猛回头）等一下！那是我的！（想抢回面包，欲星移边吃边闪）你……欲星移：我专程从龙涎口游过来看你，向你讨一点东西吃，何必这麼生气？大不了之后赔你便是。梦虬孙：我终於搞清楚你的目的了，臭墨鱼！欲星移：洗耳恭听。梦虬孙：你明知道有人在追查九算，还加速刺激我参加锋海剑夺。就是为了引导最讨厌你的我，去追查九算的事情，然后对你更加不满，进而与你作对，劫囚夺剑，全部都是因为他（一步禅空）你想还情，却又不便亲自出手，所以借我之手让天门脱离尚同会掌握。最后我就会成为代罪羔羊，有家归不得，还要留在这里，替你顾守龙涎口。欲星移：更正，是替海境守住龙涎口，除了一点用词不准确，我必须称赞你……真聪明。现今状况，若我再入人世就会被九算围剿，而你一入海境就会被鳞族围剿，双方既然相见两厌，不如不见。至於海境方面，我已经向王建议，让宝驱一脉进行修建定海堡礁的工程，预防龙涎口的爆发危害，经过百年的镇压，水气已经有消散的状况应可将伤害降至最低。至於这段时间，千万别让任何人去破坏龙涎口。梦虬孙：给我住口！（挥棍袭击欲星移）欲星移：（躲开）哎呀，此地先前经过剧烈变动，地质脆弱，你真要动武？（梦虬孙观视地面裂痕，欲星移趁机跳入水中逃走）梦虬孙：啊！欲星移！你别跑！欲星移：不送了，否则龙困浅滩，可是会被你最讨厌的犬类所欺，我会定期送来百里闻香，让你品尝，再会。梦虬孙：欲星移，你这个臭墨鱼啊！给我回来啊！（喘气）真正有够可恶！等海境度过这次危机，我一定要算一次总帐。（坐下）刚才还吃我的东西！不知道东西是不是还够吃。（倒出袋中物）乾脆去金雷村再分一点好了。（离开）

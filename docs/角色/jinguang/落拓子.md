# 落拓子

================================================================================

金光布袋戏虚拟人物落拓子是金光布袋戏中的虚拟人物，号听雨秀才。

他身背书篓，手持三弦琴，作书生打扮，是一名神秘青年高手。

谈吐诙谐，常把“我有一帖良方”挂在嘴边，有一派江湖闲人的闲散作风，却又知晓诸多武林秘辛。

伴随着天下风云碑再启而现身武林，实为玄机老叟一脉后人，负责对风云碑比武项目以外的天下第一进行考核编列，曾参与天下第一枪的最终争夺战。

书篓中藏有一把组合式的长枪，名唤鸳鸯骨。

他曾受俏如来之托保护靳铅华，前往天允山并查访神迹记载，并与公子开明交战；

也曾与冷秋颜联手激战妖神将。

在《金光御九界之妖祸天劫》中，落拓子曾质问鲁殇未果，并步步进逼猎星与螣九岐，引得戮世摩罗与网中人前来救援。

落拓子武艺精湛，深藏不露。

## 人际关系

## 相关作品

落拓子出场于剧集《齐神箓》（2019年），参与天下第一枪争夺战；落拓子亦在《金光御九界之妖祸天劫》（2022年）第24至27集中出现，涉及质问鲁殇和对战猎星、螣九岐。

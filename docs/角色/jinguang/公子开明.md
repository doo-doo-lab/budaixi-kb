# 公子开明

金光布袋戏虚拟人物，魔世修罗国度策君，沉沦海首智。常年为修罗国度镇守沉沦海，维持三方和平，计谋不凡。看似幽默搞怪，实则奇谋诡谲，杀伐果断，喜怒无常。公子开明身份多变，既是修罗国度策君，又是释墨传人迦谛圣者，便如同传说中的开明兽一般，九首九思，变化万千，难现真颜。曾化身云海过客，周旋各方，在元邪皇之乱中积极奔走，与雁王订立天允山之约，排下重重布局，力抗魔劫，最终重创应龙师。齐神箓时期和戮世摩罗回到中原找寻梁皇无忌取回鬼玺，更意图寻找能让恢复妖族战力的妖界母晶，并在天下风云碑留名天下第一枪。

## 角色能力

### 武器

*   **降妖宝杖**：传闻乃玄奘座下三弟子沙悟净所持兵器，实则为玄奘伏魔法器，鲁家废字流以“镔铁”合以“梭罗仙木”打造，原型即《西游记》中沙悟净的“降妖宝杖”。平常为一尺长短的棍棒便于携身，而当公子开明运使‘九痕杖法’时，便会延伸，显露降妖法器的真身。（编剧说明对妖族并无加成只对魔族有效果，武器的名字叫降妖而已）造型古朴，量重千钧，显露在外的杖身雕镂着梵文云饰，并以晦涩的暗金涂装，体现释教的古雅敦煌风格。玄奘西行魔世时期，化名“迦谛圣者”与火魔儿大战，成功击败并取下其火尖枪头。
*   **火尖枪**：本为火魔儿佩枪，自玄奘打败其后取下其枪头，随之成为释墨传人之法器，释墨传人凭此运使‘三昧真火’，卫道伏魔。一般搜藏于“迦谛圣衣”之中，当释墨传人身披袈裟，口诵真言之时，火尖枪头便会显现于世。将“火尖枪头”装载自降妖宝杖上，使三昧真火沿漫杖身，化为“火尖枪”。因受真焰淬炼而变得深邃猩红的宝杖梵文，仿佛是佛界明王忿怒的象征。火焰形状的枪刃因真火的沸腾而散射炽烈的焰光，使得方寸有如化为业火烬土。枪上的真焰有如红缨一般，随着持有者的挥动燃烧十方，不灭的真火点燃四方，有如红莲盛放，直至邪祟燃烧殆尽，方能使烈火熄灭。

### 物品

*   **木鸢**：公子开明的坐骑，一只体型巨大、翱翔云海的机关鸟。其由来自墨子‘费时三年，以木制木鸢，飞升天空······’，其原型为《西游记》中的“筋斗云”。由鲁家废字流以独门机关术，并以‘不灭火’作为动力来源兴工制造，盛朝年间，玄奘凭此西行魔世，携众多经书自魔世开花授教，传承释、墨双学。
*   **迦谛圣衣**：魔世‘迦谛圣者’、玄奘一脉释墨传人的衣钵象征，也是以《西游记》中“锦襕袈裟”为原型。为墨色并以金漆撰写佛经真言的袈裟，释墨传人身披圣衣，象征此刻化身为‘迦谛圣者’，以“戒心三悟”警示自身，以三昧真火伏魔卫道。
*   **策君令牌**：代表修罗国度策君身份令牌，曾借予帝女精国死亡之组的将领进入人世，并言明持吾令牌者，三尊放行。
*   **龙泉藏剑图**：史艳文给予，龙泉剑所在地的地图，公子开明曾以龙泉剑阻止元邪皇窃取中原地气。

### 武学

*   **九痕杖法**：释墨一脉独传武学，同时也是运使重若千钧的‘降妖宝杖’的必要法门。其招数名称由来俱为《西游记》中的章节名，同时也是《西游记》传说玄奘座下三名弟子，即悟空、悟能、悟净的原型。“九痕”一名可能缘由自玄奘手持的法器“九锡节杖”。
    *   招数：四海千山皆拱伏、九幽十类尽除名、须弥灵吉定风魔、心猿显圣灭诸邪、八戒大战流沙河、九九数完魔灭尽、三三行满道归根、圣僧夜阻通天水
*   **白马行空**：轻功，以快速的步伐兼合多变的身形，有如天马行空一般潇洒自如，以《西游记》中“白龙马”为原型。

## 角色经历

公子开明，金光布袋戏虚拟人物，来自魔世，自称魔世第一智者。修罗国度策君，在帝鬼入侵中原时镇守沉沦海并负责魔世中修罗国度事情。在俏如来被丢入魔世时与俏如来交手（交手结果2：3）。待俏如来回归中原时送玄狐去中原。因元邪皇复生而向帝女精国公主借魍魉栈道入中原，适逢中原遭受地门入侵，遂化身云海过客，襄助中原。

在魔戮血战之时，策君公子开明的大名已浮出水面 ，帝女精国两武士持策君令牌出入鬼祭贪魔殿寻找俏如来的踪影，彼时便有所铺垫。后魔世被达摩金光塔镇压，俏如来会见梁皇无忌时亦有所提及，公子开明在魔世亦是举足轻重之人。恰逢元邪皇复生，与当任帝尊梁皇无忌大战，梁皇无忌败走沉沦海彼岸求援，策君公子开明则借道入中原，寻除元邪皇之法。为快速带止戈流回魔世与俏如来约定，助其攻打地门，在地门终战时负责牵制雁王，更与其立下天允山生死赌约。

公子开明生性洒脱，不同于一般智者沉稳内敛设定，不羁的性格，看似毫无章法的言语，与先前之云海过客形成鲜明对比。在齐神录期间，随戮世魔罗与网中人重回中原，欲寻回梁皇无忌手中的鬼玺与能帮助妖族回复力量的妖界母晶，后为了提醒俏如来而留名天下第一枪，后在与落拓子的对决中胜利，并推断出妖族母晶与天允山有着莫大的关联。

在战血天道时期，被修罗国度帝尊戮世魔罗丢入异象中（即破碎的清圣桥），并被清圣桥传送到羽国。与独眼龙相遇，经过一番交谈后，推断出异乱的根源应与墨家典籍中的——仙岛有关。并打算与独眼龙再次投身异象，将这一消息告诉魔世。要走之际遇到雁王拦路，经过交谈之后，听闻上官鸿信的一句话后十分诧异，两人赶紧离开。

## 扩展阅读

黄俊雄布袋戏又称之金光系列，因为1950至1970时的布袋戏主流。以声音道具等奇关变景吸引观众的表演形态，被称之为“金光戏”，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事。后于1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的“金光戏变革”，故把自己旗下的布袋戏事业，称为金光布袋戏。如今经营公司的是黄立纲的金光多媒体。主要剧集《黑白龙狼传》《天地风云录之决战时刻》开始的新金光布袋戏。

# 竞日孤鸣

================================================================================

金光布袋戏虚拟人物同义词北竞王（北竞王）一般指竞日孤鸣竞日孤鸣是金光布袋戏虚拟人物，别称北竞王，由黄立纲配音。

作为苗疆辈分最高的王族成员（上代苗王幼弟、苍越孤鸣祖王叔），身负苗疆第一智者之名，精通皇世经天宝典·轮回劫武学，初登场于《天地风云录之决战时刻》。

其形象曾被用于BJD娃娃扮演。

竞日孤鸣表面幽默诙谐，常以教养为由捉弄侄孙千雪孤鸣，实则暗藏城府。

为夺取王位隐忍布局三十年，主导九龙天书之局后登基。

在魔戮血战中统一苗疆，最终败于苍越孤鸣并将功力全数传承。

退隐后化名单夸，于地门决战中作为最后智者协助俏如来对抗大智慧。

在元邪皇之乱中解救千雪孤鸣，故意走错道路暗示铁骕求衣识破元邪皇动机，并交出《九龙天书》促成中苗合作，战后隐退江湖。

竞日孤鸣历经从权谋者到传功者的转变，雍容表象下始终伴随着身份认同的虚无感，最终在完成使命后选择远离权力漩涡。

## 角色形象

登场描述金丽华殿，典雅堂皇，干戈武喝中，只见一人轻倚御座，眉眼含笑，举止间尽展勋贵之姿。

北竞王剧照造型内里的衣物则以赤色为底，大幅度地加入了杏黄的花草纹路，袖口滚边以银色打底金丝锈纹镶边，其上零星点缀了几颗橘色的珠宝，外披胭脂色和白色相间的大氅，大氅下摆布满亮金色的细致纹路，亦搭配有刺绣的手套覆其手背，可谓雍容华贵至极，彰显其养尊处优的身份和王者风范，而其服饰是苗疆所有人员之中最为华丽的，亦能体现其平时在生活上对于精致的追求。

貌美俊秀，玉质金相，神采飘逸风流。

一双琥珀色的精致凤眼，眼角微微上挑，羽睫浓密细长，加上眉心一点透明水钻，更显其精致儒雅的智者气质。

北竞王的发饰可谓是极其精美复杂，其浓密的黑色长发之中间或夹杂了几缕棕红色的发丝，长发穿过数颗造型各异的精致金环挽至后方，以嵌有石榴色宝石的叠壳造型金饰细致竖起、固定，而后长发中的几缕又被仔细编织成长辫，下缀金制发环交杂在垂发之中，前有两束长发被环上发带垂在胸前，额上的抹额呈云状，其间亦是缀满各色七彩的贵重珠宝，发饰之中还缀有两条由各色宝珠制成的精美珠串。

大手笔的金饰和珠宝点缀足以彰显北竞王的皇室身份以及其在苗疆的尊贵地位，其中一条珠串之下缀有白色羽饰，搭配其大量复杂而精致的发辫也足以体现苗疆的地域民族风格。

其身份优越却常年缠绵病榻，因而肌肤细白如雪，时常手持玉制的牛角状酒杯，亦能体现其在生活上的奢华。

性格个性风趣幽默，言谈斯文得体，好捉人短处。

待人接物沉稳谦和，气质翩翩，举手投足尽是皇胄风范，但因身体“孱弱”，长时间集中精力极易耗损心力，行走之时偶有气浮虚弱之状。

平日摆出一派沉溺于美酒玩物的闲散王爷的模样，实则城府极深，极擅忍耐和等待，暗伏三十年谋计策划九龙之局，只为夺得最后苗王之位，为了达成自己的目的不择手段，对千雪孤鸣和苍越孤鸣都下过杀手，导致苗王颢穹孤鸣死亡的真正谋划人，然而其对自己亦是同样的残忍。

少时的不幸经历让他在形成自己的性格之前先学会了伪装自己，因而创造了一个无心王位的王爷形象来维护自己的安全，但伪装久了以后也就再也找不回也没机会找回真正的自我，他的内心时常矛盾挣扎，但也非常理智和清醒，在计划之中绝不为私情所动，为了自己的目标会第一时间作出最佳的抉择，从未影响自己的大局和计划，手段果断干脆，极具王者雷霆之风。

宽容大度，能忍能让，顾全大局，伸缩自如，其话术在默苍离面前并不算高明，在同前后两任巨子的交谈之中时常被压在下风，却从未失去其优雅沉稳的气质，仅偶尔感慨自嘲两句，仍显端庄，可谓修养极佳。

在大局方面，北竞王为了苗疆安定费心费神，魔戮血战期间和戮世摩罗、撼天阙和中原方面都多有合作周旋，最后放弃了王位将功力传给了苍越孤鸣，助他成为太祖之后第一个练成三部宝典武学的传人，嘱咐其护卫苗疆之强悍。

即便之后退隐山林化名单夸，仍然关注着苗疆局势，在众人受困于元邪皇之时，主动现身解惑，并交出了《九龙天书》以助中苗一臂之力。

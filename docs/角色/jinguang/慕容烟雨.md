# 慕容烟雨

金光布袋戏虚拟人物慕容烟雨，别名天剑，是金光布袋戏中的虚拟人物，由黄立纲配音。

作为执掌天剑慕容府的百岁剑界传奇，七十年前击败玄枪十三坞与八百刀剑门奠定江湖地位，在李沉渊崛起之前主导中原剑界，后与古岳派李沉渊缔结十年约战传统。

老年得子慕容胜雪，收徒莫离骚与丁凌霜，因家族人丁凋零封剑闭关二十载。

天下风云碑重启后重出江湖，于银槐鬼市强行动武引发冲突，展露无招剑境实力。

与任飘渺展开剑决时，虽以根基优势获胜但仍认可其剑术造诣。

在玄武真道围攻中为救慕容宁耗尽寿元身亡，临终前将府主之位交予慕容宁，木剑斜阳留于慕容府大殿。

其武学以潇湘十三剑各一式为核心，随身携带恩怨名册快意恩仇。

最终战独闯玄武真道绝地，剑意震慑群敌，标志天剑慕容府时代落幕。

武学：潇湘十三剑中的一式（潇湘十三剑为慕容家第六代十三兄弟各创一式之游戏之作）、烟柳画桥、紫微归元法剑境：无招剑境武器：木剑·斜阳【慕容十三器之一】所有物：本子（记录此生所有要解怨报恩之人姓名，还尽恩仇后会将名字画掉）、天山寄忧子、慕容府药酒

## 角色经历
慕容烟雨七十年前公认的天下第一剑，号称天剑烟雨，五十年前天剑慕容府在江湖享誉盛名，后隐世不出。

与古岳派宗师李沉渊为至交好友，二人相约每十年一战，直到第七次十年之约，李沉渊战死于魔世之乱。

三十几年前，再一次打败李沉渊，因心情不好，散心至桃源渡口，遇上被道域仙舞剑宗老宗主秘密送往中原的莫离骚（昔时用名天之道）。

两人互看不顺眼，莫离骚主动挑战，被慕容烟雨带回府中，收为徒弟。

后慕容烟雨老年得子，取名慕容胜雪，慕容胜雪生性叛逆，仅学会家族潇湘十三剑便离家闯荡江湖，更加入反派组织阎王鬼途。

魔世修罗国度入侵时，三尊曾带兵攻打天剑慕容府无果，后因玄之玄从中周旋，使修罗国度大军绕过天剑慕容府的势力范围。

玄之玄的目的是留天剑慕容府成为反制修罗国度的力量。

慕容烟雨封剑二十年闭关，其子慕容胜雪在外惹祸，拜托好友别小楼救下被阎王鬼途追杀的慕容胜雪。

慕容烟雨慕容家十三剑豪只剩下自己以及十三弟慕容宁两人，目前天剑慕容府为慕容宁当家。

天下风云碑重启之后，一剑留名天下第一剑，离开天剑慕容府，闯入银槐鬼市，破坏银槐鬼市不能动武的规矩，意图将离家出走的儿子——慕容胜雪抓回家。

与银槐鬼市发生冲突，对银槐鬼市众人随意说脏话，险些让天剑慕容府与银槐鬼市开战，却也展现了强悍的实力，银槐鬼市的鬼尊破例让动武的他离开。

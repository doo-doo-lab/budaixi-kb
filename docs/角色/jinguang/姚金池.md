# 姚金池

金光布袋戏虚拟人物姚金池是金光布袋戏中的虚拟人物，由黄立纲配音，属苗疆北竞王府成员。初登场于《天地风云录之决战时刻》第19集，后续活跃于《魔戮血战》剧集。作为女暴君姚明月之妹，长期担任北竞王贴身女官，角色厨艺家事超群但无武力智谋。姚金池在北竞王府侍奉期间暗恋千雪孤鸣，面对北竞王求婚试探选择婉拒。北竞王政变夺权时，默苍离为掣肘北竞王派遣大匠师将其带离王府，姚金池发现其病弱伪装，自身情感卷入九龙天书之局，间接导致苗王遇害与千雪重伤失踪。政变失败后隐居黑水城，受托取得九龙天书真迹，并在银娥墓前与千雪释然过往。最终选择追随北竞王离开，角色配乐《岂思故园林》收录于《魔戮血战剧集原声带二》。

## 角色经历
一开始作为北竞王的侍女登场，因为其姐姐女暴君品行问题，被狼主和藏镜人质疑过。但为人善良而无心机，因此被女暴君嘲笑过。在九龙之局进行到最后阶段，与忆无心一起从北竞王府救走去黑水城。之后与北竞王见过面，当北竞王传功苍狼后，搀扶其离开。之后在黑水城劝雨音霜不要离开，但无果。魔祸时期，姚金池在不知情的情况下被温皇委托，前去寻化身单夸的北竞王处取得九龙天书真迹，并对其倾诉自己对北竞王的感情，表示如果北竞王出现，彼时的自已愿意放下一切跟他离开。

## 配乐

## 扩展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

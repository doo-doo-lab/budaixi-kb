# 识龙影

================================================================================

金光布袋戏虚拟人物识龙影是金光布袋戏系列中的虚拟角色，由黄立纲配音，初登场于《天地风云录之九龙变》第15集。

其身份为阎王鬼途十部众之一“神华”，对应泰山王神华宫，同时为中谷大娘非自愿收下的徒弟。

为人八面玲珑，擅长周旋于各大势力之间，个性风流却薄情狠辣。

初登场时以脱俗华丽的穿着和风雅绝代的相貌，持风水轮盘与特殊手帕解救即将被苗疆士兵处刑的风水堪舆家及其爱女。

表面受北冥异指使盗取华佗方巾并潜入还珠楼调查温皇，实际执行阎王鬼途复辟潜伏计划，持有第二本九龙天书。

因误见中谷大娘毁容被强行收徒并遭受虐待，习得无影金梭后杀害紫燕，拒绝回归师门时被中谷大娘依药神指令清除，最终死于《九龙变》第35集。

角色诗号为“初识阴阳真妙理”，相关配乐为《龙吟啸空》。

## 角色背景

识龙影是阎王鬼途为贩卖药物的地下组织，通过一手施毒，一手贩药的手段敛财，用于研究亡命水（长生不老药）。

曾经被幽冥君、鸩罂粟、岳灵休捣毁过一次，如今死灰复燃。

作为新任阎途十部众之一的神华，识龙影秘密潜伏在北冥异的身边，在《九龙变》中甫出场便带出第二本九龙天书，实际上是温皇所派。

曾经误入谷中，撞见中谷大娘被毁容的右脸，因此被强行收为徒弟并被持续虐待，身上遍布伤口并吃虫度日，对中谷大娘恨之入骨。

但也同时学得无影金梭的用法，并用此杀害梅香坞的紫燕。

并非还珠楼直属，仅仅为温皇打工，完成任务便离开，随后被中谷大娘找到，拒绝回到谷中，因此被杀。

后续剧集中得知此乃药神为清除阎王鬼途势力而指使。

是一个可怜可悲，又可恨的角色！

## 扩展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

# 酆都月

================================================================================

金光布袋戏虚拟人物金光布袋戏虚拟人物。

还珠楼副楼主，一心以超越楼主任飘渺（神蛊温皇）为目标，在百里潇湘代任楼主之时，与任飘渺保持奇妙关系，后任飘渺除去百里潇湘，重掌还珠楼，酆都月仍担任副楼主一职。

能担任任飘渺替身开启风云碑、操纵飘渺剑阵，拥有一敌西剑流四天王之一月牙泪数招不落下风之实力。

真正心愿乃是有朝一日能彻底击败楼主，更为此而不惜一切与其赌智慧，赌胆识，可见其城府心机。

其后被从凭金吾处得到的异书影响，心魔渐生。

在被温皇击败之后终于控制不住而走火入魔被剑无极重伤濒死，啃食异书再复出后已失去自我，在九龙天书之局中引发地气突变导致魔世通道开启。

之后搜集邪眼后，进入达摩金光塔。

为夺取枯髓咒怨引发天门危机，后被玄之玄设计击杀而炸死。

于御九界之墨武侠锋第三集趁隙夺取枯髓咒怨后进入魔世后消失，成为元邪皇复生的契机。

## 官方简介

还珠楼副楼主，个性积极，带有文雅书卷味，拥戴还珠楼真正的楼主，为此与百里潇湘多有不合，两人之间总是存着试探。——（决战时刻：桌布）还珠楼副楼主，个性积极，带有文雅书卷味，拥戴还珠楼真正的楼主，为此与百里潇湘多有不合，两人之间总是存着试探。

在原楼主无故失踪后，一直想试着找出原楼主的下落。——（决战时刻：甲子名人帖）还珠楼副楼主，行为举止温文儒雅，一心以超越楼主任飘渺为目标，在百里潇湘担任代楼主时，与任飘渺保持着奇妙的关系。——（史艳文传奇：酆都月）还珠楼副楼主，代替失踪的任飘渺对抗代理楼主百里潇湘之异心，对任飘渺异常执着，渴望得其认同。——（金光风云录）杀手组织“还珠楼”副楼主实力高深，真正心愿乃是有朝一日能彻底击败楼主任飘渺，更为此而不惜一切与其赌智慧，赌胆识，可见其城府心机。——（金光群侠传）期望有朝一日能够彻底击败任飘渺，为此不惜一切，用尽阴沉心机与神蛊温皇赌智慧、赌胆识，最后被击败时竟走火入魔。——（史艳文传奇：魔·酆都月）还珠楼副楼主，具备与西剑流四天王月牙泪一搏的高超实力。

熟悉飘渺绝式，与楼主任飘渺关系耐人寻味，一方面甘愿成为他游戏天下的替身，助其铲除百里潇湘、对付宫本总司，另一方面又彼此勾心斗角、尔虞我诈，一心想彻底击败并超越任飘渺，成为能让他正视的人物。

为此不惜用尽一切，乃至走火入魔……——（九龙变：英雄扉页）

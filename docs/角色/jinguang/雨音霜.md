# 雨音霜

================================================================================

金光布袋戏虚拟人物雨音霜是金光布袋戏中的虚拟人物，

**中文名**：日文名あめね　しも，由黄立纲

**初登场**：于《黑白龙狼传》第2集。她作为东瀛西剑流八门之休门队长，是该

**组织**：八门中唯一的女性成员，持有水属性灵器"水之泣"，擅长冰系

**武学**：。雨音霜原为西剑流效力，因遭丑孔明暗算坠崖被雪山银燕所救，相处中逐渐对银燕产生好感。西剑流败退后自愿留在中原协助正道，期间参与苗疆王子苍越孤鸣复国行动，其果敢性格获得苍狼青睐。她与雪山银燕互生情愫，却因银燕误杀其父八刀痕导致感情破裂。最终雨音霜暂留东瀛协助西剑流复兴，并跟随樱吹雪精进武艺。其角色轨迹贯穿《黑白龙狼传》至《金光御九界之鬼途奇行录》，在梦境、假扮及囚禁情节中多次特殊登场。

## 官方简介

西剑流八门之休门队长，为八门队长中唯一的女性，好胜心极强，个性直爽、泼辣，有话直说毫不掩饰。——（决战金光：史艳文传奇）为西剑流八门中休门的队长，属性为水，其父为原西剑流派到中原夺取魔之甲的分组组长八刀痕，与焱是同父异母的姐妹。——（黑白龙狼传：英雄扉页）西剑流八门之休门队长，八门中唯一女性，对军师赤羽信之介十分仰慕，是双刃剑的攻击暗忍，个性好强不服输。——（决战时刻：桌布）西剑流休门，冷静机智不服输，对赤羽怀有淡淡情愫。——（金光风云录）西剑流休门队长，倔强好胜，原本仰慕赤羽信之介，但遭丑孔明打落山崖、受雪山银燕相救后，渐渐放下对银燕的敌意，暗生好感。

后于西剑流撤出中原时自愿留下。——（九龙变：英雄扉页）原为西剑流八门之休门队长，为八门队长中唯一的女性，对军师赤羽信之介十分仰慕，个性好强不服输，被丑孔明打落山崖后，被雪山银燕意外救起，两人相处一段时间后，对雪山银燕渐生好感，西剑流败亡后，自愿留在中原，成为正派助力，其与雪山银燕之间的发展亦值得关注。——（剑影魔踪：公司偶）【花语绯樱】原为西剑流八门之休门队长，为八门队长中唯一的女性，对军师赤羽信之介十分仰慕，个性好强不服输，被丑孔明打落山崖后，被雪山银燕意外救起，两人相处一段时间后，对雪山银燕渐生好感，西剑流败亡后，自愿留在中原，成为正派助力，其与雪山银燕之间的发展亦值得关注。——（墨武侠锋：桌布）西剑流分组组长八刀痕之次女、云组组长焱的异母妹妹，好胜心极强，个性直爽、泼辣，有话直说毫不掩饰，与风间兄弟、雪山银燕成为朋友。——（金光群侠传）原为西剑流八门之休门队长，为八门队长中唯一的女性，个性好强不服输。

原与中原正道为敌，后在重伤之际被雪山银燕意外救起，经过一段时间相处对其渐生好感。

西剑流败亡后，自愿留在中原成为正派助力。

曾协助苗疆王子苍狼复国，勇敢果断的处事态度获得苍狼青睐，却因惦记雪山银燕婉拒新任苗王爱意，现已回到东瀛，跟随樱吹雪锻炼武艺，协助西剑流复兴。——（金光特展：180228）

## 角色经历
雨音霜个性好强，认为女人的实力绝对在男人之上。

靠著自己的实力，成为西剑流八门中唯一的女性队长。

霜有一位同父异母的姐姐焱(私生女，官方原资料指姐姐是东剑道有误)，而且父亲和姐姐都死于中原。

对她来说，这件事一直是个耻辱。

因此，霜十分无法忍受真田隆三对自己身家背景的冷嘲热讽，好几次两人争端欲起，皆被军师吓令阻止。

在与雪山银燕决斗战败之後，军师肯定与勉励霜身为休门队长的努力作为，使霜对军师由衷敬佩。

在中原人闯入西剑流的「救史行动」中，雨音霜遭受神蛊温皇一击，被赤羽信之介亲自救下。

自此，霜暗自倾心赤羽军师。

与丑孔明二人奉命侦查神蛊峰，却被丑孔明偷袭，击落山崖，被正在神蛊峰底受宫本总司指导的雪山银燕意外救回。

霜虽感念银燕救命之恩，但西剑流与中原仍是敌人，不知如何处理二人关系。

待雨音霜伤好之后，炎魔已死，西剑流已败，霜以报答银燕救命之恩为由自愿留在中原。

霜与银燕在相处中渐生情愫，然而霜个性好强、不愿开口，银燕天性木讷、不善表达，二人关系始终未更近一步。

九龙变之局中，默苍离识破北竞王篡位阴谋，指派雨音霜与风间始二人援救苍狼以挑动苗疆内战。

苍狼被二人救下后，得知父王身亡，叔父狼主下落不明，一直以来对自己呵护关爱备至的祖王叔北竞王竟是幕后黑手，一时之间难以接受。

雨音霜在苍狼低谷时不断鼓励苍狼振作，苍狼在前所未有的困境和霜的鼓励与帮助下，终于抛却了以往的优柔寡断，决心要为父报仇，夺回苗疆。

同时苍狼对在困境中伸出援手的雨音霜心生爱慕，只是心中仇恨难平，未及表达。

霜与银燕在多次磨难中感情弥坚，霜知晓银燕木讷，所以主动向银燕表白，但是银燕却告诉霜，他爱的人是霜的姐姐——雨音焱，更为重要的是，银燕此时方才知晓，霜也是八刀痕的女儿，而八刀痕是死在自己手中。

苍狼成功复国后，便邀请雨音霜来苗疆，并向其求婚。

银燕在得知消息后，在剑无极等人的劝说下，无奈之下和剑无极去苗疆，与剑无极二人大闹苍狼与霜的婚宴，要将霜带走。

然二人使出一剑无悔亦不敌身负三部皇室经天宝典武学的苍狼，但是婚宴实际上霜对银燕的考验，逼银燕正视心中的情感。

银霜二人终于知晓对方心意，霜却在此时获知银燕杀死了自己的父亲八刀痕，心中虽然深爱银燕，最终仍无法接受。

霜不知如何处理心中情感，所以向赤羽和神田提出要与他们返回东瀛。

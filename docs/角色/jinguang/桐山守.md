# 桐山薰（金光布袋戏虚拟人物）

同义词桐山守（桐山守）一般指桐山薰（金光布袋戏虚拟人物）桐山薰，易名为桐山守，是金光布袋戏中的虚拟人物，由黄立纲配音。

作为西剑流祭司，与柳生鬼哭并称西剑流两大百年传奇，因家族传承自幼以男性身份被培养，真实性别为女性。

持有诫灵鞭，配乐为《追昔》，是西剑流实际领导者。

桐山薰为复生炎魔幻十郎，联手推动复活炎魔幻十郎计划，利用史艳文次子小空作为人柱实施禁术。

在中原九星连珠之夜发动天下风云碑之战，期间因炎魔幻十郎死亡触发诅咒，最终与柳生鬼哭在海边共同石化。

曾因误杀柳生鬼哭使用禁术复活对方，导致自身外貌产生异变。

结局承接禁术反噬逻辑，石化象征西剑流之乱终结，其与柳生鬼哭的情感羁绊贯穿权力争夺全过程。

组织残余势力由赤羽信之介代表投降，标志桐山薰统治时代的结束。

诫灵鞭：东瀛奇特灵器，平时只有握柄，当灌入内力甩动后，便会吐出灵鞭，直接造成灵体与灵识的伤害，导致灵力幻散而亡，除柳生鬼哭外尚未有人撑得过四鞭。

## 经历

东瀛西剑流祭司，已经存在了一百多年，与柳生鬼哭并称西剑流两大传奇人物，两人关系匪浅，有着极其深厚的羁绊。

守的母亲在分娩时难产而死，所以她是桐山家唯一血脉单传。

但女儿身的她没有资格成为西剑流之主。

守的父亲桐山猛为了使桐山家得以传承，自小就将守女扮男装，接受最严酷的训练，还要每天喝药让声音变粗。

少年时的守向往普通的人生，却身不由己，唯一的伙伴只有忠诚的柳生鬼哭。

曾怀抱一统东瀛忍派的理想，携柳生鬼哭一起寻觅被埋藏的禁术。

寻得后两人起争执，误杀柳生，启动禁术救其复活，牺牲自我成为“夜叉之相”。

桐山薰原貌其后带领西剑流消灭东瀛各派，入侵中原。

联合藏镜人，捉走了史艳文的次子－小空，并以此逼史艳文现身，决一死战，因中原异人黑白郎君突入战局，导致三人皆失踪。

为使流主炎魔幻十郎复生，擒得史艳文次子小空（史仗义）进行炼化，以供炎魔幻十郎寄体重生。

九星连珠之夜，西剑流流主炎魔幻十郎即将复活重生，在温皇策划下，开启天下风云碑之战。

最后西剑流战败，炎魔伏诛，西剑流之乱平定。

由于她与鬼哭都受到了炎魔的诅咒，炎魔一旦死亡，他们两人就会在三天之内死亡，最后在中原的一个海边一起石化。

# 苍狼

苍狼是金光布袋戏角色苍越孤鸣的别名（亦称苍兔、狼王），为苗疆王子、现任苗王，颢穹孤鸣与希妲之子。详细资料请见 [苍越孤鸣](苍越孤鸣.md)。

## 别名出处

- **苍狼**：北竞王对苍越孤鸣的常用昵称，亦为旁白给予的称呼。"我是苍越孤鸣，这位是叉猡。"（魔戮血战 04 集）
- **苍兔**：北竞王在九龙变 32 集对俏如来的称呼："小王那个好侄孙苍狼应该改名为苍兔，与你相比，他简直温纯无害。"
- **狼王**：旁白称呼。

# 苍狼（2013年王利兴、徐善杰执导的电视剧）

================================================================================

中国大陆36 集订阅0有用+10《苍狼》是由四川广播电视台、四川星空影视文化传媒有限公司、西安梦舟影视文化传播有限责任公司联合出品，王利兴、徐善杰执导，张健、王辉、宋福聚、李卓霖编剧，潘泰名、毛俊杰、章雯淇领衔主演，吴承轩、吴婷、康杰等联合主演的革命战争剧。该剧讲述了以陈天放为首的热血特战队“苍狼”以及一批有志之士与日军斗智斗勇，誓死保卫祖国和人民的传奇经历的故事。该剧于2013年10月30日在湖南广播电视台经视频道首播，12月12日在四川卫视上星播出，播出后收视呈直线上升，稳居csm48+第二名。导演徐善杰、王利兴中文名苍狼外文名Blue Wolf作品类型青春、励志、革命、战争主要演员更多潘泰名毛俊杰章雯淇张永刚图集

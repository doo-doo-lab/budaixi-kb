# 天宫伊织

================================================================================

电视剧《金光布袋戏》及其衍生作品中的角色天宫伊织（别名青龙）是电视剧《金光布袋戏》及其衍生作品中的虚拟角色，由黄立纲配音。作为东瀛西剑流四天王之一，她与宫本总司、赤羽信之介、月牙泪情同手足，术法天赋获祭司桐山守赏识。桐山守在教导过程中将已故恋人桐山薰的特质投射于她，刻意将其培养为温柔娴静的接班人形象。在培养细节上，桐山守不仅看重其术法资质，更通过心理投射塑造其性格，使其成为兼具武力与威望的流主。角色诗号“天命始终有尽期”暗喻其命运转折，终局选择留守东瀛未随军西进。在风雨飘摇中，她既需撑持前线战局，又要平衡内部权力更迭，最终以独特政治智慧完成流主使命。中文名天宫伊织别 名青龙、流主、师娘配 音黄立纲性 别女登场作品金光布袋戏身 份西剑流流主、西剑流四天王之一化 身樱吹雪种 族人族归 属东瀛组 织西剑流

## 人际关系

师徒亲友师父：桐山守（桐山薰）师弟：鬼夜丸师妹：衣川紫好友：宫本总司、赤羽信之介、月牙泪晚辈：月牙诚恋情：宫本总司朋友：金敖（古辰雅久）指导：剑无极、雪山银燕（宫本总司的弟子，只是给予他们一些指导）西剑流（炎魔幻十郎担任流主时期）上司流主：炎魔幻十郎祭司：桐山守（桐山薰）军师：赤羽信之介同级四天王：天宫伊织（青龙）、月牙泪（白虎）、宫本总司（玄武）、赤羽信之介（朱雀）下属六部：神田京一（暗部）、衣川紫（医部）、邪马台笑（兵部）、天海光流（道部）、出云能火（咒部）、夜叉瞳（鬼部）八门：雨音霜（休门）、真田隆三（生门）、丑孔明（伤门）、月牙岚（杜门）、千鸟胜（景门）、柳生鬼哭（死门）、鬼夜丸（惊门）、天满道隆（开门）、风间始（继任景门）四组：雨音焱（云组）、石皮阎罗（破组）、八刀痕（分组）、云十方（森组）其他：真田勇次郎、青木诚归降：天恒君、三清道长、武上君（天宫伊织担任流主时期）流主：天宫伊织军师：赤羽信之介部下：神田京一、衣川紫、出云能火、雨音霜、月牙岚、鬼夜丸

## 角色经历

《黑白龙狼传》至《决战时刻》时期，东瀛西剑流入侵中原，天宫伊织独守东瀛。《魔戮血战》至《墨邪录》时期，天宫伊织继任西剑流流主，带领众人抵抗残忍联盟，并支持赤羽信之介前往中原。

## 人物配乐

◎皓月樱华（天宫伊织角色曲）作曲：李穆　收录于《翠羽珠玑－金光布袋戏藏乐选集》行军曲般的序幕中，樱华乍现，天宫伊织飘然而降，一展术法能为。扬琴乐音与低沉的弦乐交融，是有如其娴静温柔的外表下，有颗坚毅不羁的心。

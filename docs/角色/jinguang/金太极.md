# 金太极 (金太极)
================================================================================

金太极

金太极，霹雳布袋戏虚拟人物。万教之子，霹雳门杀手。与史菁菁、独眼龙有一段复杂难断的感情纠葛。独眼龙与史菁菁相恋，后因缘事故，史菁菁被逼嫁予金太极，并生下儿子紫霹雳。后来独眼龙又重现江湖，并和金太极成生死兄弟，金太极亦改邪归正。

# 金太極 (金太极)
================================================================================

金太極

金太極，霹靂布袋戲虛擬人物。萬教之子，霹靂門殺手。與史菁菁、獨眼龍有一段複雜難斷的感情糾葛。獨眼龍與史菁菁相戀，後因緣事故，史菁菁被逼嫁予金太極，並生下兒子紫霹靂。後來獨眼龍又重現江湖，並和金太極成生死兄弟，金太極亦改邪歸正。

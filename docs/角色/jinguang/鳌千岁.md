# 北冥皇渊

================================================================================

金光布袋戏虚拟人物北冥皇渊，金光布袋戏虚拟人物太虚海境鳌千岁，鳞王北冥封宇之弟。在“三王之乱”中独善其身，因而深得鳞王信赖。居住在边关不远之地的玄玉府。表面上每日锦衣玉食，不理朝政。实则野心勃勃，武功高强，暗中勾结鳍鳞会，借未珊瑚谋逆之局发难，意图篡位。年幼时因鲲帝特有的特性“鲲麟附体”提早到来而被先王北冥宣忌惮，由铅十三鳞看顾长大，对此心有怨恨，亦对鳞王在“三王之乱”后处死众兄弟不能释怀。希望能够借潜藏海境的纵横家之力改朝换代，改变海境固有传统，实现自己的皇途。

## 人物能力

功体珍珑霜焰珍珑髓以水火石炙烧后，经由鳌千岁天生的残缺之躯转化而成的功体真元。

能催生出如霜雪般的煊赫焰火，美伦美央，兼具冰火二性，如霜凛冽难化，如火燎虐雄漫——因为是由水火石炙烧而成，保留了其在无根水下燃烧的特性。

北冥皇渊是鳌千岁独门绝学〖九炼烽火〗的运功根本，平时常将珍珑髓置于香炉烟煴成白烟，再由掌间吸纳，以此温养功体。

鲲鳞战甲鲲鳞覆体完成后的真正形态。

鲲帝一脉雄性在而立之年（三十岁）会觉醒〖鲲鳞覆体〗的特性：周身遍布厚重的青碧色鳞片，由此维持半甲子后，方能收放自如，形成〖鲲鳞战甲〗，鲲鳞战甲成形后会回复原身形貌，鲲鳞则趋渐无形、擐布周身，形成毫无瑕疵的防护，无缝可破。

与一般鲲帝雄性不同，鳌千岁周岁便进入了鲲鳞覆体的阶段，被视为残缺，故在三十岁后形成鲲鳞战甲。

鳌千岁将鲲鳞战甲〖收放自如〗的特性灵活运用，经由<九字诀·斗>演变，衍生出为〖九炼烽火·神罡斗气〗：不仅能通过鲲鳞战甲形成完美防御，通过张开鲲鳞战甲承受攻击形成反震，攻防一体，甚至可操纵鲲鳞由外扩张，形成防御圈，其扩散也能造成一定程度的伤害。

破除鲲鳞战甲的唯一方法，便是以龙力催动以镔铁所造的兵器，如此方能破坏鲲鳞。

武学九炼烽火◎简介：北冥皇渊鳌千岁通过自海境的断简残篇中挖掘出纵横家的九字诀，演变而成的独门绝学（后揭露是由纵横家逍遥游暗手遗谱）。

以九字诀对照自身功体〖珍珑霜焰〗的特性，衍生九式，统称〖九炼烽火〗。

其源流乃纵横家·鬼谷一脉的至高绝学——《纵横九字诀》：以‘临·兵·斗·者·皆·阵·列·前·行’九字心法章要为主，根据修炼者术业所擅以及功体殊异，衍变成同源异径的不同招式，是根据修者特性而产生变化的奇特武学。◎招式：九炼烽火·‘欲海临世、点兵山河、神罡斗气、隐者飘踪、风雨皆谒、明阵封晦、皇天列剑、千川行一、御前诛圣’〖九炼烽火·千川行一〗：‘千川九炼纳己身，烽火行一荡海境’。

双掌催运水火保定，将珍珑霜焰转化成烟丝状遍布四周，蒸腾八方，将范围内所有对手的内力强行吸收，反哺自身炼化，获取海量功力，施展此招后，〖九炼烽火〗九式肆意出招，混无竭象——这一招是以反转武脉为前提，完全忽视自身肉体经脉的承受局限，强行吸纳多人内力，过程中全身经脉会因炼化内力过度而损坏，呈现周身溃血不止的症状，以伤换力，乃弃生忘死、破限逆天之招。

兵器水火保定北冥皇渊一对把玩玉珠，由水火石精炼而成，通体圆润，晶莹剔透，色呈浮翠流丹，实则坚硬无比，可与海皇戟缨锋。 因其水火石材质，能与鳌千岁珍珑霜焰之功体相得益彰，双珠在真元催动下浮动八方，上下颉颃，更能以其水火石特性催化霜焰衍变，忽如银涛波雪，忽如霜华盖天，一展九炼烽火弥天之威。

而将双珠贯入体内，以精炼水火石催化周身珍珑霜焰，可令功力强行提升，却有殃命之危。

所有物镔铁晶矿北冥皇渊与八纮稣浥的定情信物，各有一块。

被鳌千岁搜藏于寝阁，日夜擦拭，分外珍惜。

雁王凭此看出二者非比寻常的关系。

后为拉拢黑白郎君作为交易予之。

一扎书信北冥皇渊写予八纮稣浥，上书‘其雨其雨，杲杲出日。

愿言思伯，甘心首疾。 ’（出自《诗经·卫风·伯兮》），寄寓着北冥皇渊对其的一腔情愫。

骨灰小囊八纮稣浥战死演图关，北冥皇渊以〖九炼烽火·明阵封晦〗焚化其躯，将之骨灰装于其中，自此踏上不归之途，不离不弃。

搜藏珍馐玉粉翠鳌千岁喜爱的甜品，类似药膳。

由衷砚寒清所作、将药味调至服之神怡的玉粉翠。

素心软、金砖裹中原特有的甜品，鳌千岁最为喜爱讲究的点心。

年幼时曾尝过雨相自中原带来的金砖裹，但其酥脆表皮因无根水影响，失去一点风味。

海境年节俏如来携两种甜品拜访玄玉府，一偿鳌千岁幼时遗憾。

八味酥鳌千岁亲自设计的甜品，专为纪念八纮稣浥而设。

酥回醉一种饮品。

## 角色经历
欲夺取海境政权，恢复鳞皇体制（此前为避讳盛朝之时的海境之主北冥清涟之易名太白之名讳，皇字去其白，改鳞皇为鳞王）认为王位有能者居之，暗中勾结鳍鳞会，借未珊瑚谋逆之局发难，强势踏足紫金殿，从此自称“寡人”。将边关至玄玉府作为其腹地，与鳞王北冥封宇展开周旋。在与鳍鳞会合作过程中，遭到鳍鳞会背叛，但最终在鳍鳞会与海境朝堂决战之时，仍然站在鳍鳞会一方。鳍鳞会宗酋八纮稣浥死后，为实现其承诺，拼死踏上海境王座，并耗尽全力，使海境降雨（海境之内是无法下雨的，北冥皇渊曾与八纮稣浥相约至中原江南一观烟雨）。

# 黑水城（金光布袋戏虚拟势力）

================================================================================

黑水城是金光布袋戏中的虚构势力，

**本名**：黑铁之城或机关城，由始帝时期隐居的鲁班、墨家及阴阳家后裔建造。该城实为地下移动堡垒，魔世入侵时启动机关成为正道避难所，后因元邪皇之乱受损，最终被阎王鬼途占领作为基地。黑水城在《天地风云录之九龙变》初次提及，《剑影魔踪》正式登场。魔戮血战期间大匠师启动移动机关抵御戮世摩罗，元邪皇之乱导致不灭火熄灭，后由佛国协助恢复地气。城内存有九界水脉分布图，被阎王鬼途夺取用于传播亡命水，其核心成员包括废苍生、大匠师。

**中文名**：黑水城

**别名**：黑铁之城、机关城

**初登场**：天地风云录之九龙变正式登场天地风云录之剑影魔踪成 员废苍生

# 苗疆朝堂

金光布袋戏中统治苗疆地区的虚拟势力苗疆朝堂是金光布袋戏中统治苗疆地区的虚拟势力，以孤鸣一族为皇室核心。该势力与中原长期对立，历经多次战争后最终签订和平协议。代表人物包括颢穹孤鸣、苍越孤鸣两任苗王。势力拥有苗太祖遗留的王骨“狼王爪”，可克制武学典籍《皇世经天宝典》。组织结构以苗王为最高统治者，通过世袭制维系权力传承。其发展过程贯穿苗疆与中原的冲突、征战与和解，展现了族群政权在虚拟世界观中的政治架构。中文名苗疆朝堂性 质金光布袋戏虚拟势力历任苗王颢穹孤鸣、苍越孤鸣皇 室孤鸣一族

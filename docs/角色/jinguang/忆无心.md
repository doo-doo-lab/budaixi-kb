# 忆无心

金光布袋戏虚拟人物忆无心。绰号“石头仔”，为女暴君姚明月与藏镜人之女，婴儿时期即被女暴君遗弃，机缘下被叹悲欢捡回灵界，心性善良单纯、通情达理，却又带点倔强。身负异能，能与石头进行交流，甚至能操控石头。曾因身世之故，引起若干风波，因与白狼、黑龙的友情，投射在黑白郎君身上，进而产生交集。后加入苗疆祭祀台，在大祭司步天踪死后继任苗疆大祭司一职，是苗疆有史以来最年轻的大祭司。天下风云碑再开之时，留名天下第一术。

## 黑白郎君相关事件

1.被西剑流绑架来迫使藏镜人摘下面罩，让史艳文藏镜人双生子的真相暴露，继而使得两人被中苗逼杀。

2.孤身前往苗疆，为灵界中原寻求帮助。

3.因黑白郎君之死大受打击，异能爆发一举将数万魑鬼大军石封。

4.与女暴君母女相认并执意随其离开，欲感化暴戾的女暴君。

5.因女暴君为建功献计于苗王而遭挟持，欲利用她除掉藏镜人。

6.同飞渊和雪山银燕寻找古燐原晶，并获得初始力量。

7.制作同心石给雨音霜与雪山银燕。

8.在第一次攻打地门时，和燕驼龙一起开启灭却之阵。

9.赶到黑水城用初始力量救回废苍生一家。

10.意图唤回黑白郎君，但失败了。

11.与燕驼龙和废苍生一起发力，使俏如来、欲星移、铁骕求衣和神蛊温皇利用思能装置侵入大智慧脑识。

12.与史艳文、废苍生、大匠师、鲁缺抵抗元邪皇破坏黑水城地气。

13.被妖界异能者所伤，暂时失明。

14.由黑白郎君自海境找到镔铁后经医治已复明。

15.帮助苗疆探查妖染事件（实为阎王鬼途作祟），后加入苗疆祭司台。

16.现任苗疆祭祀台大祭司一职。

17.前往天下风云碑，留名争夺“天下第一术”。

18.同梁皇无忌最后一战最终留名“天下第一术”。

19.天下第一争夺，被风云碑判定败于任孤沉。

## 身世来历

忆无心乃是万恶罪魁藏镜人与女暴君之女，藏镜人对其极其重视，但女暴君却对之不甚在意，甚至认为忆无心只是一个累赘。忆无心还是婴孩时期便被生母女暴君抛弃于战乱后的战场，父亲藏镜人被蒙在鼓里，只以为女儿意外身死，非常痛心。被抛弃的忆无心幸被灵界叹悲欢于石堆之中发现并带回抚养，长大之后一心想得知自己的来历，而手臂上的火焰印记和所持有的石笛就是少数能证明自己身世的线索。忆无心手臂上的火焰印记乃是父亲藏镜人所留，之后巧合之下，藏镜人也是凭此认出自己女儿，而忆无心手上所有石笛则是女暴君所留，同样是留，但父与母分别留下的却是珍惜与利用。一版忆无心二版忆无心

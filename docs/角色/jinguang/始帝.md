# 上古始帝

================================================================================

同义词始帝（金光布袋戏中的始帝）一般指上古始帝上古始帝是金光布袋戏中虚构的鳞族人物，为上古始朝开国皇帝及中原首位帝王。

其身份与海境鳞族密切相关，通过血脉传承与政治谋略推动七雄统一，并建立镇魔龙脉封印魔世通道。

作为鳞族公主赵姬与中原七雄后代，始帝凭借鳞族暗助及墨家、鲁家的智巧一统天下。

为避免死后引发两族争端，其策划假死归葬海境，最终尸骨化鳞形成王骨“始帝鳞”，成为开启伏羲深渊的关键遗物。

曾主导铸造对抗魔世的“诛魔之利”，但因未完成护世之兵留下遗憾。

始帝长子公子苏一脉延续为海境鲛人族，世代担任太虚海境师相。

后裔包括欲星移、梦虬孙等角色，前者作为鳞族帝师推动海境改革，后者因虬龙混血身份历经身份认同困境。

其遗留的始帝鳞与未竟的诛魔之利，持续影响着金光世界观中的人魔两界格局。

## 角色背景

战朝之前，九龙之气汇集于鳞族所在的太虚海境，导致鳞族人才辈出，中原失气战乱频繁，魔世得气魔流横溢，冲击人魔分界。太虚海境鳞皇惊觉魔世现世可能动摇天下，决定在中原建造一条绵延千里的镇魔龙脉（即后来的万里边城），以镇住魔世地气，封印两界通道。鳞皇遂派遣鳞族公主赵姬偷渡中原，嫁于七雄之首，生下鳞人混血之子，即后来的始帝。太虚海境倾全族之力资助始帝统一天下。始帝一统天下后，纠合鲁家、阴阳家合力筑造‘万里边城’这条镇魔龙脉，并纠合鲁家、墨家、阴阳家打造专克魔族的‘诛魔之利’。然魔乱未现世，始朝内部先生事端。

## 经历
始帝将墨、鲁、道、纵横、阴阳诸子百家收入麾下，以纵横家离间六国、墨家收天下之兵、鲁家定度量衡，从而一统天下。

始帝纠合鲁家与阴阳家筑造万里边城作为镇魔龙脉，并纠合鲁家、墨家与阴阳家打造专克魔族的诛魔之利。

诛魔之利由血之禁印、护世之兵、渡世大愿组成，对魔族有特效但对人无杀伤力。

始帝因身为鳞人混血且寿数将尽，其身份被方士徐福知晓，恐引发海境与人族战乱，便借徐福求长生药之机将其逐出中原。

为防止九龙之密泄露以保证诛魔大计，始帝焚书坑儒，仅留存一本真九龙天书交予国师保管。

始帝死后鳞人形态复现，赵高秘不发丧，鳞王命太子扶苏与爱将蒙括假死，将始帝身躯运回太虚海境安葬。

其身躯所化鳞片形成王骨始帝鳞，具有王骨灵能，能让佩戴者在海中穿梭无阻且不受太虚海境无根水影响。

## 遗物

始帝鳞：始帝自知承万恶罪名，身为鳞族，恐死后暴露身份，引起两族纷争，又为回归故乡，遂下令建造疑冢，隐藏身份，命其长子太子扶苏与爱将假意自尽，扶灵回到太虚海境，他死后尸骨尽化，唯留一鳞，就是王骨始帝鳞，两千年来一直供奉在海境。

九龙传说，相传只有三王骨才能打开伏羲深渊。

所谓王骨，是指承天之命，身负王气，终结乱世之人，其身上所留下来的骨骸，开疆辟土，建功立勋的帝王霸主之骨骸亦为王骨，而始帝鳞就是能打开伏羲深渊的三王骨之一。

诛魔之利：上古时期始帝为了阻止魔世祸乱中原，创造诛魔之利以用来对抗未来魔世入侵。

诛魔之利由‘血之禁印’、‘护世之兵’、‘渡世大愿’三种元素组成。

诛魔之利专克魔族，但对人丝毫没有杀伤力。

但始帝一生只完成了渡世大愿、血之禁印的设计，护世之兵一直到始帝去世都没有完成。

## 后裔

鲛人一族，上古始帝的长子公子苏的后代，是海境相族，世代世袭太虚海境的丞相、师相一职，单传一脉，落泪成珠。

鲛人一脉享有外出游历海境的特权。

已知鲛人后裔：青奚宣：锦烟霞的情侣，鳞族师相欲星移和龙子梦虬孙的伯祖父，已经去世。

欲星移欲星移：鳞族师相。

始帝嫡系血脉公子苏的后人，海境单传一脉的鲛族。

曾以少年之姿接替先王身边相位，更身兼帝王师辅佐现任鳞王。

鳞族两朝元老、海境一代帝师。

博学多识、智慧过人，是太虚海境的大局指导者与战略排布者。

渴望打破海境千年成规，引鳞族入世，带领族民走出闭塞沉埋。

身为始帝血统根源之一，他的入世也标志着避世千年之久的鳞族重现九界、再出尘寰。

梦虬孙梦虬孙：鳞族鲛人一脉与宝躯一族的混血，父亲是鲛人，母亲是宝躯。

居住在太虚海境潜龙崁的潇洒剑客，欲星移的堂弟，为人乐天耿直，侠气非常，随身带着百宝袋，装满了各种零食。

传说中，天下间有四种龙的资质，只出现于魔世和鳞族两界，梦虬孙便是鳞族鲛人和宝躯二脉的混血意外而来的虬龙，早该湮灭的传说，却经由混血再现。

梦虬孙头上生有犄角，显示其资质不凡。

早年其因为血统多受人侮辱和嘲笑，后经欲星移正名，始被众人尊称为“龙子”，但梦虬孙心中却一直难以忘怀悲惨的童年经历而心有芥蒂。

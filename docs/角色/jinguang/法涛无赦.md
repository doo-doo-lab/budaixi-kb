# 法涛无赦

================================================================================

金光布袋戏虚拟人物法涛无赦，金光布袋戏虚拟角色，佛国天门萨埵三尊之金刚尊，与菩提尊一步禅空、摩诃尊梵海惊鸿并称。其武学根基为萨埵十二诀中的金刚四正，施展“金刚般若”“怒相行深”两式，兵器为金银双轮，可构筑梵莲圣华之象。作为天门高层，法涛无赦主持达摩金光塔事务，主张对魔世主动出击，曾引荐俏如来加入天门。魔世平定后接掌核心职权，应对梵海惊鸿回归、一步禅空坐化、血纹魔瘟爆发及朽净叛乱等危机，期间遭玄之玄布局，被天门叛徒朽净设计杀害。法涛无赦恪守佛门戒律，以刚正果决著称，其陨落直接导致玄之玄势力渗透天门。中文名法涛无赦别 名金刚尊配 音黄立纲性 别男登场作品天地风云录之魔戮血战登场作品金光御九界之墨武侠锋生 日2014年 5月28日身 份萨埵三尊之一种 族人族归 属佛国组 织天门

法濤無赦

金光布袋戲虛擬角色。天門薩埵三尊之金剛尊，與菩提尊一步禪空、摩訶尊梵海驚鴻齊名。不怒而威，篤實忠厚，於俏如來首次接觸達摩金光塔時，親自考驗並將其引入天門，在針對魔世的戰略上，亦傾向主動出擊。魔世災禍平定之後，因一步禪空為渡魔眾而步出天門，便由自己接掌多數天門事務，其後梵海驚鴻歸來、一步禪空坐化、血紋魔瘟肆虐、朽淨趁勢而起等事件接踵而至，使其行事逐漸支絀。

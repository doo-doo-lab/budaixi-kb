# 法涛无赦

金光布袋戏虚拟人物法涛无赦，金光布袋戏虚拟角色，佛国天门萨埵三尊之金刚尊，与菩提尊一步禅空、摩诃尊梵海惊鸿并称。其武学根基为萨埵十二诀中的金刚四正，施展“金刚般若”“怒相行深”两式，兵器为金银双轮，可构筑梵莲圣华之象。作为天门高层，法涛无赦主持达摩金光塔事务，主张对魔世主动出击，曾引荐俏如来加入天门。魔世平定后接掌核心职权，应对梵海惊鸿回归、一步禅空坐化、血纹魔瘟爆发及朽净叛乱等危机，期间遭玄之玄布局，被天门叛徒朽净设计杀害。法涛无赦恪守佛门戒律，以刚正果决著称，其陨落直接导致玄之玄势力渗透天门。

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

# 緣醉莫求 (缘醉莫求)
================================================================================

緣醉莫求

緣醉莫求，霹靂布袋戲虛擬人物。來歷不明的佛門弟子，攜酒背劍的修行者，喜好吟唱勸世歌，常言“大夢初醒，難得糊塗”，遂以醉為緣法而修行悟禪。因意外撞見梵天之坐騎金翼大鵬鳥身亡而暗中出手協助，與雲鼓雷峰淵源很深。

人物設定緣醉莫求 月刊介紹名稱：緣醉莫求性別：男詩號：大夢癲狂自有憑，浮生泡影醉青燈。江河水月千杯飲，酒海徜徉一劍僧。名言：大夢初醒，難得糊塗代表性配樂：難得糊塗所有物：酒葫蘆人際關係其他：一頁書（亦師亦友的前輩）人物能力武學：醉看秋水不興波兵器：眾生相◎外形特徵：此劍以古銅色為主，飾以藍色琉璃珠。劍柄尾端形為金剛法杖，象徵佛家背景且系有黑色長穗。真實來歷原為龠勝明巒之首蘊果諦魂的兩件法器之一。◎登場劇集：霹靂經武紀之梟皇論戰 第17集人物經歷來歷不明的佛門弟子，攜酒背劍的修行者，喜好吟唱勸世歌，常言“大夢初醒，難得糊塗”，遂以醉為緣法而修行悟禪。因意外撞見梵天之坐騎金翼大鵬鳥身亡而暗中出手協助。實為奉師尊帝如來之命，找尋天佛原鄉的所在地。後來，一頁書在帝如來的指點尋找緣醉莫求。兩人遂結成同伴，一同尋找進入天佛原鄉的方法。實力尤在三聚僧老中的斷業舍妄、拔苦刑招之上。在復活葉小釵途中，為護承裝葉小釵的魔絕天棺，壯烈犧牲。其實在很久前，緣醉莫求被師傅帝如來派遣尋找招提僧，冀望能夠得到毀去滌罪犀角的辦法，因而來到眾相凡窟，意外尋得了天佛原鄉之路的線索。緣醉莫求在眾相凡窟沒有找到招提僧，而是遇到了神妓(巫陽神女)，在一番辯論後，他雖然沒有被神妓誘惑，但也對自己的信仰產生了疑惑。本來在他心裡可以解救眾生的佛法，這時發現也不是萬能，這讓他信仰崩潰，法相盡失，成為了飲酒破戒，另尋緣法的劍僧。帝如來霎時明白，緣醉莫求的佛緣另有其人，而且是一名將會親自踏上尋找天佛原鄉之路的有緣人。後來，一頁書在帝如來的指點找到緣醉莫求，兩人遂結成同伴，一同尋找進入天佛原鄉的方法。緣醉莫求也是在受帝如來之託暗中監視和協助一頁書。兩人在眾相凡窟的種種經歷，使得緣醉莫求一解當時遇到巫陽神女時的內心迷惘，他被梵天堅定的信心和對佛法精湛的理解所打動，重新堅定了對佛法的信仰，從此把梵天當成了自己的另外的一位師尊。緣醉莫求的實力尤在三聚僧老中的斷業舍妄、拔苦刑招之上。後在參與復活葉小釵的護棺之行途中，為護承裝葉小釵的魔絕天棺，在惡陷雨地壯烈犧牲。人物配樂難得糊塗（緣醉莫求之歌）詞：周郎 曲：林久登、楚陽、演唱：林久登 收錄於《難得糊塗》出身明華園歌仔戲團的林久登，以紮實唱功，鮮活演繹戲劇角色笑看人生。澎湃編寫顛覆戲劇呈現，流暢旋律再創武林傳奇。醉劍（緣醉莫求武戲曲）曲/編曲：浩旭 收錄於《霹靂英雄音樂精選32》本曲為浩旭老師所創作，藉由豪爽的國樂琴笛演奏，快意奔放的流暢旋律，結合熱血的搖滾樂元素，互相輝映的氣勢，營造出恣意縱橫、馳騁天地般的俠客武曲，突顯出「緣醉莫求」疏狂不羈的率性風格。

# 缘醉莫求
================================================================================

缘醉莫求

缘醉莫求，霹雳布袋戏虚拟人物。来历不明的佛门弟子，携酒背剑的修行者，喜好吟唱劝世歌，常言“大梦初醒，难得糊涂”，遂以醉为缘法而修行悟禅。因意外撞见梵天之坐骑金翼大鹏鸟身亡而暗中出手协助，与云鼓雷峰渊源很深。

**弟子**：携酒背剑的修行者，喜好吟唱劝世歌，常言“大梦初醒，难得糊涂”，遂以醉为缘法而修行悟禅。因意外撞见梵天之坐骑金翼大鹏鸟身亡而暗中出手协助。实为奉师尊帝如来之命，找寻天佛原乡的所在地。后来，一页书在帝如来的指点寻找缘醉莫求。两人遂结成同伴，一同寻找进入天佛原乡的方法。实力尤在三聚僧老中的断业舍妄、拔苦刑招之上。在复活叶小钗途中，为护承装叶小钗的魔绝天棺，壮烈牺牲。其实在很久前，缘醉莫求被师傅帝如来派遣寻找招提僧，冀望能够得到毁去涤罪犀角的办法，因而来到众相凡窟，意外寻得了天佛原乡之路的线索。缘醉莫求在众相凡窟没有找到招提僧，而是遇到了神妓(巫阳神女)，在一番辩论后，他虽然没有被神妓诱惑，但也对自己的信仰产生了疑惑。本来在他心里可以解救众生的佛法，这时发现也不是万能，这让他信仰崩溃，法相尽失，成为了饮酒破戒，另寻缘法的剑僧。帝如来霎时明白，缘醉莫求的佛缘另有其人，而且是一名将会亲自踏上寻找天佛原乡之路的有缘人。后来，一页书在帝如来的指点找到缘醉莫求，两人遂结成同伴，一同寻找进入天佛原乡的方法。缘醉莫求也是在受帝如来之托暗中监视和协助一页书。两人在众相凡窟的种种经历，使得缘醉莫求一解当时遇到巫阳神女时的内心迷惘，他被梵天坚定的信心和对佛法精湛的理解所打动，重新坚定了对佛法的信仰，从此把梵天当成了自己的另外的一位师尊。缘醉莫求的实力尤在三聚僧老中的断业舍妄、拔苦刑招之上。后在参与复活叶小钗的护棺之行途中，为护承装叶小钗的魔绝天棺，在恶陷雨地壮烈牺牲。人物配乐难得糊涂（缘醉莫求之歌）词：周郎 曲：林久登、楚阳、演唱：林久登 收录于《难得糊涂》

**出身**：明华园歌仔戏团的林久登，以扎实唱功，鲜活演绎戏剧角色笑看人生。澎湃编写颠覆戏剧呈现，流畅旋律再创武林传奇。醉剑（缘醉莫求武戏曲）曲/编曲：浩旭 收录于《霹雳英雄音乐精选32》本曲为浩旭老师所创作，借由豪爽的国乐琴笛演奏，快意奔放的流畅旋律，结合热血的摇滚乐元素，互相辉映的气势，营造出恣意纵横、驰骋天地般的侠客武曲，突显出“缘醉莫求”疏狂不羁的率性风格。

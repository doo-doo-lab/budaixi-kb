# 北冥封宇

================================================================================

金光布袋戏虚拟人物北冥封宇是金光布袋戏中的虚拟人物，称号鳞王、覆海帝鲲，由黄立纲配音。

作为太虚海境之主，其鲲帝血脉使初登场时全身覆盖鱼鳞，后褪鳞化为人形。

2013年首次以鲲鳞形态亮相，2016年展现本真面目，执掌海皇戟并掌握镇海四权武学。

北冥封宇因镇魔龙脉损毁派军联合中原、苗疆、佛国抵御魔世入侵，曾识破九算欲星移身份仍保持信任。

他在龙涎口危机中诈死布局，促成太子北冥觞归朝。

墨邪录时期与元邪皇交锋重伤昏迷，期间未贵妃摄政并提及朝元丹来源及外境势力渗入。

后开启海境改革，下令修建定海堡礁预防龙涎口水气危害。

早年平息三王之乱巩固统治，涉及北冥骄雄、北冥无痕、北冥流君拥兵造反事件。

北冥封宇性格温和而具决断力，重视责任胜于私情。

结局以真容推动政局变革，展现王者魄力与牺牲精神。

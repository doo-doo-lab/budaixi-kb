# 独眼龙（布袋戏《金光布袋戏》中的角色）

================================================================================

独眼龙，《金光布袋戏》与《霹雳布袋戏》共同世界观中的虚拟人物，甲子名人榜上的“天下第一刀”。

诗号为“刀称一流人一流，人称一流刀一流”及“刀无眼，得饶人处且饶人，路难行，风霜何必计前程，进一步，仕途崎岖意难伸，退一步，海阔天空任吾行”。

独眼龙本为市井草莽，无恶不作。

后投身军伍伤了一目，为万象金光佛所救并收为弟子。

万象金光佛传他《达摩金刚榜》，命其将榜上一百零八位恶徒伏法。

独眼龙手持豹眼镶金刀斩奸除恶。

在即将完成使命时，发现最后一名恶徒竟是自己，遂以配刀自残，从此绝迹江湖。

其实他隐于山野，前往灵界帮助灵尊镇压元邪皇遗物，其遮蔽的左眼即为紫极魔瞳。

灵尊死后，独眼龙再次现身，先后协助对抗西剑流与苗疆。

其后魔世入侵中原，独眼龙于网中人手下大难不死，踏上找寻达摩金光塔的旅程。

独眼龙历经从恶徒到侠客的转变，在完成除恶使命后直面自我，最终选择隐退并承担守护之责。

**中文名**：独眼龙

**外文名**：Cyclops

**别名**：荒野金刀

**性别**：男

**登场作品**：忠勇小金刚金光布袋戏

**口头禅**：一流ㄟ擅 长一流刀法

**代表势力**：达摩金刚门、佛国地门

**宝物**：紫睛魔瞳

**武器**：豹眼镶金刀（能伸能缩的一把刀）好 友梁皇无忌、莫前尘对 头万曙天、万朔夜、神田京一

## 角色经历
旧金光系列独眼龙本是坏孩子，年少时无恶不作，欺善怕恶，身陷牢宠后，被判发配充军，后来大明与苗疆作战，他投身军伍，不幸伤了一目，险些死于乱军之中，为天门的万象金光佛所救。

决战时刻海报万象金光佛是佛门得道高僧，将独眼龙从死亡边缘拉回来之后，心知爱徒仍有心结难解，未大彻大悟。

改邪归正的独眼龙在刀法上尤有心得，万象金光佛眼见他武功大成，又一心从善，于是授以“达摩金刚榜”，重出江湖执行任务。“达摩金刚榜”共有一百零八页，每一页均有一位十恶不赦之徒的画像，独眼龙每一次只能翻开一页，将恶棍除去后才能翻开下一页，于是他遵循师命，榜上歹人一一伏法，短短几天能即名扬江湖。

独眼龙可说是“云州大儒侠系列”中最具出场气势的角色，每次登场，随著荒野大镖客配乐的飞扬，“人称一流刀一流，刀称一流人一流”的诗句随口脱出，很快就有坏人血溅当场，然后留下一句“一流ㄟ”扬长而去，当年不知风靡多少电视机前的观众。

就在独眼龙将“达摩金刚榜”翻到最后一页时，他很快就领悟到师父的用心，因为在那一页之上的正是自己的画像，于是以随身配刀穿肠破肚，从此绝迹江湖，生死成谜。

实际上，他并未死去，而是隐于山野。

后曾前往灵界帮助灵尊镇压元邪皇所留下的遗物，其左眼正是用于遮蔽其中的紫极魔瞳。

在黄俊雄的故事中，独眼龙再次出场已经又过了好长一段时间，只是这些故事并没有在电视上播出了。

黄俊雄在1970年之前，已经演了十六年的史艳文，其中的内容大半是没有在萤光幕前出现过的。

新金光系列新金光时期，独眼龙以隐居的天下第一刀的身份登场。

为响应史艳文打败西剑流的计谋，为配合神蛊温皇重启天下风云碑的策略，而再入武林。《天地风云录之决战时刻》中期，独眼龙一招击败西剑流所派争夺天下第一刀的神田京一。

然而西剑流事件结束之后，独眼龙遇上了挑战自己天下第一刀的万朔夜，也揭开了独眼龙隐居封刀的那段伤心往事。

魔戮血战时期曾一度失踪(寻找达摩金光塔)；

在墨武侠锋中再度出现，被地门洗脑。

墨邪录中找回记忆，为救四大天护之一的逾霄汉被应龙师邪术控制，后被俏如来救出，送往道域医治。

## 豹眼镶金刀

黑白龙狼传首次出刀时，开始改为自手上化出。 天地风云录时期又见其将豹头系于腰间。 造型上在黑白龙狼传以后，有别于以往的写实豹头，改为金属质感的几何造型豹头，并追加豹头在战斗中可咬住敌手刀刃的招式设定。

## 扩展阅读

金光布袋戏，实际通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪（长女）和黄立纲（幼子）共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。

以声音道具等奇关变景吸引观众的表演形态，被称之为“金光戏”，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，后于1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的“金光戏变革”，故把自己旗下的布袋戏事业，称为金光布袋戏。

如今经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

金光布袋戏，黑白龙狼传，天地风云录之决战时刻，天地风云录之九龙变，天地风云录之剑影魔踪，天地风云录之魔戮血战，金光御九界之墨武侠锋，金光御九界之墨世佛劫，金光御九界之墨邪录

==金光系列的独眼龙==
在黄俊雄的金光系列布袋戏中，千禧云州大儒侠剧集，为达摩金光塔的组织的一员，龙门世家家族的成员。第一侠苦海女神龙和霹雳城亦有登场，黑白龙狼传中也有登场。

==黑白龙狼传以降的荒野金刀独眼龙==
有别于过去走跳江湖，改以为不世出的高手形象。
过去的独眼龙以杀手之姿行走江湖，暴戾之气甚重；在前作于达摩金光塔大彻大悟之后消失武林。
本剧出现的独眼龙，个性改为沈稳谦逊，行事较为谨慎，但亦因此遇事不若以往快意恩仇，反常见无奈之情。

在本剧的设定中，厌倦武林生涯的独眼龙，隐遁于灵界，担任守卫幽灵魔刀的工作。
由于白狼现世，幽灵魔刀恶灵产生不寻常共鸣，独眼龙应灵尊泣幽冥的邀请，进行调查恶灵的行动，与白狼交手未果。
后来西剑流死门队长柳生鬼哭奉命进攻灵界，独眼龙全力抵挡，但白狼趁乱入侵夺走魔刀并杀害灵尊，致使独眼龙为报灵尊之仇踏出灵界。

于黑白龙狼传末尾，其名见于温皇所交予赤羽的“甲子名人帖”中，揭露其为名人帖上的‘天下第一刀’身份。
（在霹雳系列的剧集，亦有异曲同工的设定，素还真所撰之‘风云录’中，所提及的天下第一刀，乃是荒野金刀独眼龙的师父“帝王刀管千岳”。但此设定与金光系列剧集之剧情并无交会之处，建议视为平行世界。）

==天地风云录以降的荒野金刀独眼龙==
本剧集独眼龙继续进行追捕白狼的行动，但因西剑流炎魔幻十郎现身造成中原祸劫，
唯有黑白郎君重临，方能以一气化九百击破炎魔的魔之甲，
故还珠楼副楼主酆都月居中调停，以天下苍生之福劝说独眼龙暂时放下私仇，独眼龙无奈配合正道的计划，暂时放弃与白狼决斗。

于天允山开启天下风云碑时，以开碑仪式的四位天下第一之一登场。
又应史艳文的邀请，在史藏决战当日进行后方支援，并成功救走史艳文。

后应允史艳文的请托，协助其子俏如来，并参加天下风云碑首战。
以一刀流的刀法对上西剑流暗部飞将神田京一（使用无极剑法的二刀流高手）
以两式刀法与神田的两式无极剑法打成平手，
在神田正欲使出第三式无极剑法之前，
独眼龙掀开眼罩，以紫瞳灵睛使出瞳术，神田未及使出剑法而败于独眼龙之手；独眼龙此战告捷并喝令西剑流人马退出北方，收复失去的领地。
（后于西剑流之主炎魔问罪神田之时，军师赤羽信之介分析神田京一之剑法并不在独眼龙之下，而是因为不料独眼龙一介刀客竟会使用瞳术，才造成对神田京一意外落败的战果。）

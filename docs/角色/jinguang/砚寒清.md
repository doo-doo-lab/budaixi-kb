## 角色经历
鳞族太医令成员，出身鲛人一脉，误芭蕉的表兄，曾被欲星移相中其才，暗中指导，却无意竞逐相位，以加入太医令为首要志向，主要负责膳房食辅的试尝项目，甚至会帮午砗磲处理王侧琐事，因此被其他鲛人视为目光短浅的庸才。

个性温和，意在避世，虽然有极高的才能跟天赋，却完全胸无大志，只想过平淡的日子。

（以下内容涉及剧透）【东皇战影时期】砚寒清原为太虚海境太医令的试膳官，却总是不经意地帮助右文丞午砗磲解决宫中琐事，多次提点梦虬孙、暗中救助修儒、俏如来。

未珊瑚中毒之后，宫中大乱。

有心人操作之下俏如来和梦虬孙的调查陷入瓶颈，砚寒清在自己身上下毒为两人制造调查的突破口。

之后梦虬孙被逼至边关，砚寒清欲救已晚，暗中潜入大牢和俏如来见面，与其合作默契地揪住了幕后者北冥异。

和雁王相遇，言语交锋之后砚寒清担心身在边关的表妹误芭蕉安全，和右文丞一同面见鳌千岁，获得出城准许后一匹沙骑赶往边关，暗中成功救下误芭蕉和北冥缜，北冥缜凭借其丢失的老件找上砚寒清，欲求贤而被婉拒。

带着俏如来制作面见鳌千岁的甜点、写信指点北冥缜回返皇城援助、假扮鳞王北冥封宇帮助俏如来引爆海境暗流，和俏如来共同揭破未珊瑚阴谋，俏如来言其为自己的底牌，砚寒清被逼无奈之下亮出武器对上未珊瑚。【魆妖纪时期】皇城一战鳞王苏醒，鳌千岁叛变与鳍鳞会八纮稣浥合作。

砚寒清打败未珊瑚后声名大作，三位皇子分别前往试膳间以表诚意，鳞王私下对砚寒清言三位皇子谁得你辅佐谁便是下任太子，本人对此相当困扰。

与俏如来再次相遇时本不欲理会，一时心软依旧答应帮忙，和俏如来合作引雁王进局，俏如来和雁王条件交换使雁王退出海境争斗。

鳞王以北冥华私自出兵为由将砚寒清引至前线。

梦虬孙和俏如来正式决裂时，砚寒清现身救助俏如来，劝说梦虬孙无果、被梦虬孙指责其凭什么置身事外。

之后梦虬孙带领鳍鳞会对上定洋军，砚寒清欲带回龙子豁命与虬龙之力相抗，受伤沉重而昏迷。

醒来后态度有所改变，主动与俏如来和鳞王商讨战事。

王，鳍鳞会赢了，海境阶级就真能改变吗？

失去阶级的鲛人、宝躯一脉拥有大批资源，他们仍会揭竿再起，夺回他们失去的阶级。

战争，不会在我们战败之后止息。

要停止伤亡，鳍鳞会只有一种最好的作法——大肆屠杀鲛人、宝躯，直到血脉湮灭。

而在那之前又有几场大战、多少死伤？

而经历这场死伤之后，就真能保证往后的和平？

如果一纸命令就能彻底改变阶级，师相早就做了。

为主者天经地义，为奴者自甘卑贱，阶级，不只存在于制度，更存在于人心。

这也是为何师相所说的，梦中不见枷锁自困。

要脱下的，是人心中的阶级。

这，非数十年不能成功。

鳞王：数十年……漫长的岁月。

砚寒清：所以师相在海境人心中种下了一颗种子。

只要时间……这颗种子，就能萌芽而茁壮。

最后，脱去人心枷锁。

鳞王：什么种子？

砚寒清：不就是海境解除锁国禁制后，王亲自颁下的推行墨学吗。

鳞王：啊……砚寒清：兼爱、平等，只有思想才能彻底改变人民。

鳞王：但这当中，是否又会遭遇阻力，是否又会遭逢反噬，谁又知晓……砚寒清：谁也无法知晓，因为历史无法重来。

也许八紘稣浥有办法迅速解决鲛人与宝躯的反噬，他是这样相信自己，所以才需要……龙子。

鳞王：站在自己阵营的那一方都相信自己走的路是正确的。

砚卿……师相果然没看错你。

经此一谈，本王更器重你几分了。

砚寒清：啊，微臣失言，请王恕罪，王不用抬举微臣。

鳞王：哈。

## 编剧漫谈

三弦再说说海境线吧，海境线则是一个『选』字，每个人都面临着选择，从鳞王、鳌千岁、章鱼、梦虬孙、砚寒清以至于俏如来、狷螭狂、北冥缜，北冥异，每个人都在选，选一条自己认为对的道路，又或者是自己也无这么肯定是对的道路。

砚寒清图片提到海境就不得不提砚寒清这只萌物了。

我喜欢写不同的角色，尤其是具备颠覆性质的角色，写腻了每次高人登场，就是打光气势吹风，自信满满，睥睨天下的模样，于是我就对季电说，这一次，你不如写个低调简约风的角色，他要想尽办法装死，想尽办法不出风头，他的人生最大的志向，就是结婚生小孩，过着平凡的日子，他胸无大志，又怕麻烦，有正义感但是最好不要惹到事，于是砚寒清这个角色就诞生了。

与温皇不同的地方，砚寒清不是懒，甚至说，他其实满勤快的，只是他的抉择从来就不是名利，而是平静，他有在乎的人情义理，但多数时候他都选择不强求，随遇而安，他路见不平，如果事态不严重，也会兴起多一事不如少一事的念头，在俏如来发现了这块『璞玉』之前，砚寒清过着自认为舒适还算惬意的生活。

学文学武，对砚寒清而言只是他排遣寂寞的娱乐罢了。

不同一般装B高人的假低调真张扬，砚寒清这辈子呛人最凶的一句话，大概就是『无根水深，鹅难存活』这句，于是雁王除了鸟王，BB王之外，又入手了新的称号：『鹅王』这样的高人，在布袋戏史上应该是第一个吧。

当然，到了最后，一直想过低调生活的砚寒青，终也是必须选择，严格来说，他大概也是没得选的选了。

话说，由季电设计的海境线，倒是很认真的把我跟他讲的话彻底地实行了。

凡拥有必将失去，凡顺遂必遇挫折，凡信念必遭考验，凡角色必不得好死。

季电不过我可以卖一下总监，其实砚寒清不能算是我的手笔，从原型设计到剧情，乃至人生理念与剧本呈现，基本上都是总监负责的，当初也是因为总监设计了这个角色进入海境线，我才终于把八紘稣浥设计完成，尤其是中心思想。

# 梵海惊鸿

金光布袋戏虚拟人物金光布袋戏虚拟人物佛国天门萨埵三尊之摩诃尊，与菩提尊一步禅空、金刚尊法涛无赦齐名。个性激进刚烈，并有强大的质疑心，会对其他两人所提出的法有所质疑，为了求法另辟蹊径，于多年前出走，从此音讯全无，直到一步禅空将魔众引入天门庇护的事件爆发后，始现踪迹，再现天门时，已背上佛门禁剑‘颠倒梦想’，并对锦烟霞采取一连串行动，其后则因尚同会强势进逼，不惜割袍守护天门。

## 角色经历
摩诃尊梵海惊鸿为寻求其法，出走天门，后因一步禅空护魔而重现，已背上佛门禁剑颠倒梦想。为护天门清圣，追击锦烟霞。543216一步禅空为苍生坐化之后，梵海惊鸿被其所感，后欲阻尚同会，联手锦烟霞共抗玄之玄，最终不敌，伤疲倒地，被法涛无赦与鳞族师相欲星移所救送至海境。在被带回天门时，尚同会欲以方导邑血案处刑之。摩诃尊与锦烟霞合作，一举斩杀朽净及尚同会一伙，重领天门。地门入侵天门，晨钟被毁，摩诃尊遭受重伤，遂封印颠倒梦想交锦烟霞让其带走，为阻地门侵九界，用尽毕生佛力封锁佛国，因不愿与地门为伍散尽修为石化。

## 拓展阅读

编辑台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

# 宫本总司

================================================================================

金光布袋戏虚拟人物宫本总司，金光布袋戏虚拟人物，化名萧无名，由黄立纲配音，2012年6月27日初登场于《天地风云录之决战时刻》。

身份为西剑流四天王之一暨第一剑客，东剑道平定之战时的最强三人之首，也是世上少数可以用来召唤出西剑流最强战神的肉体。

角色名称融合日本剑豪宫本武藏与冲田总司，外形粗犷留有短须，性格温和。

原为西剑流祭司桐山守养子，因不愿再杀戮叛离组织，化名萧无名创立天地双部对抗西剑流。

收史艳文之子俏如来、雪山银燕及东剑道少主剑无极为徒，为剑无极以生死赌约换取飘渺绝式。

最终与任飘渺决战不悔峰身亡，临终前在山壁留招"一剑无悔"，任飘渺在此战中领悟"剑十一·涅槃"。

掌握"神魔一念"心法及"无极剑法"，武功境界达"神魔非我"。

西剑流之乱后主动揭露身份承担罪责，引导俏如来拜师默苍离继承墨家学说。

## 角色能力

神魔一念以魔入心，以神出招，心法极意，不在魔心控杀，而在神意止杀，忘情忘仇，亦神亦魔，神魔非我。宫本总司（官方图汇总)口诀：无心无我，不思量，不分别，不执著，人无我，法无我，自无我，他无我，一切成空。境界：神魔一念、神魔非我附注：宫本总司的神魔非我是无心无我之境界，雪山银燕的则是控制走火入魔后的力量。无极剑法特质：无常无定招式：一剑无极、一剑无尽、一剑无声、一剑无悔附注：总司施展出来的无极剑法和剑无极、神田京一施展出来的无极剑法，有相当的差别（修为、根基、招式等等），不再是类似拔刀术的那种。

## 经历
宫本总司原为西剑流四天王之一，亦是祭司桐山守的养子、西剑流第一剑客，是东剑道平定之战时的最强三人之首，也是世上少数可以用来召唤出西剑流最强战神的肉体，因不愿再杀戮而离开西剑流。他化名萧无名，在西剑流进犯中原时创立天地双部与之对抗，天地双部的原始召集人还是宫本总司。宫本总司收史艳文之子俏如来、雪山银燕及东剑道少主剑无极为徒，也为神田京一之师尊，采取因材施教的教导方式，不惜以生死赌约为剑无极换来更适合他的飘渺绝式。最终与任飘渺决战不悔峰身亡，临终前在山壁留招“一剑无悔”，任飘渺在此战中领悟“剑十一·涅槃”，奠定其备受崇敬的一代宗师形象。

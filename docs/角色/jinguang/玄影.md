# 玄影（电视剧《仙剑四》中夙瑶创造的傀儡角色）

玄影是电视剧《仙剑四》中由夙瑶以元神为代价创造的傀儡角色，作为玄霄的替身，奉夙瑶为主人。他性格善良，因韩菱纱的真诚相待而与其成为朋友，曾多次暗中协助她，包括准备护身仙符、指示她带望舒剑上昆虚琼华等。在剧情中，玄影因重光逼迫交出藻玉而陷入两难，虽不愿背叛夙瑶，却因守护秘密被重光提取记忆，最终为保护韩菱纱挡下致命攻击而魂飞魄散。中文名玄影身 份玄霄替身傀儡创造者夙瑶本 体玄霄（相貌相同）主 人夙瑶结 局魂飞魄散登场时间2025年1月1日（首次提及）

## 角色背景

玄影由琼华派掌门夙瑶耗费元神制造，外貌与玄霄完全相同，主要用途是作为玄霄的替身。夙瑶出于执念用法术创造了玄影，他只是一个没有心跳的假人，作为玄霄的影子存在。其存在被夙瑶刻意隐瞒，直至被虚召意外发现，玄霄得知后欲将其毁灭。玄影为保护夙瑶但求一死。电视剧《仙剑四》中汪铎

## 经历
玄影是夙瑶创造的傀儡，是玄霄的替身，奉夙瑶为主人。

玄影因受雇于韩菱纱而与她产生交集，虽被夙瑶迁怒，仍暗中为其准备护身仙符，并理解她的担忧。

玄影协助韩菱纱打开监狱大门，并威胁黑衣人不得伤害她，要求她带云天河和望舒剑前往琼华派。

玄影后来得知自己只是没有心跳的假人，整日郁郁寡欢，韩菱纱送他的拨浪鼓也坏掉了。

韩菱纱找到玄影后为其修复了拨浪鼓，并告诉他“你和玄霄不一样”，玄影向韩菱纱展示了自己与玄霄相同的容貌，韩菱纱明白他是替代品。

玄影传信给夙瑶，报告望舒剑会反噬灵力且自己无法夺剑，夙瑶下令必须拿到望舒剑并允许对阻拦者格杀勿论。

在弟子大会前，玄影提出以韩菱纱带云天河和望舒剑上昆虚琼华为条件换取丹药（2025年5月2日剧情）。

重光以丹药为筹码逼迫玄影交出藻玉。

玄影起初不愿背叛夙瑶，但重光以丹药为条件，玄影最终同意帮其拿回藻玉。

重光随后用法术提取了玄影的记忆，揭露了夙瑶与玄影的秘密对话。

玄影陷入两难，并希望夙瑶能在自己取回丹药后杀了自己。

重光因记忆被篡改而要杀玄影，韩菱纱挺身相护。

危急关头，玄影为保护韩菱纱挡下攻击。

临消散前，玄影将丹药给了韩菱纱，表示自己不想害人、不想弃主、更不想做影子，只愿做韩菱纱的朋友。

最终玄影消散，只留下拨浪鼓，后来韩菱纱离开琼华时，曾去其墓前道别。

## 人物关系

玄影由夙瑶以元神为代价创造，是夙瑶执念所化的玄霄替身，奉其为主，常被夙瑶迁怒撒气。玄影因韩菱纱的真诚相待而与其成为朋友，多次帮助韩菱纱，并最终为保护她而牺牲；韩菱纱也视其为朋友，曾为其修复拨浪鼓并立墓悼念。玄影是夙瑶按照玄霄样貌创造的傀儡，外貌与玄霄完全相同，是玄霄的影子。重光以丹药为筹码逼迫玄影交出藻玉，并提取其记忆，最终欲杀玄影。云天河曾察觉玄影的杀气；慕容紫英曾公开质问夙瑶关于玄影之事；柳梦璃曾为玄影的死亡以箜篌伴奏悼念。

## 角色结局

玄影曾希望夙瑶在自己取回丹药后杀了自己。在与重光的冲突中，为保护韩菱纱，玄影挡下致命攻击而魂飞魄散。玄影的遗物被韩菱纱埋葬于后山，柳梦璃以箜篌伴奏悼念。消散前，玄影将丹药交给韩菱纱，并说出“不想害人、不想弃主、更不想做影子”的遗言，向主人夙瑶道别‘保重’。其死亡成为揭露夙瑶阴谋的关键线索，慕容紫英曾公开质问夙瑶关于玄影与重光的关系。

## 角色评价

云天河认为玄影本性善良，即便被玄霄视为威胁，仍试图通过交涉获取丹药帮助他人。韩菱纱在玄影死后追忆其善举，称其为"朋友"。

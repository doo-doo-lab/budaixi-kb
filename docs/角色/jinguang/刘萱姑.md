# 劉萱姑 (刘萱姑)
================================================================================

劉萱姑

布袋戲虛擬人物。史艷文正妻。杭州第一美人，品貌端莊、秀中外慧的才女，為人知書達理，十分溫柔善良。

基本介紹
- **中文名**: 劉萱姑配音：黃俊雄登場作品：雲州大儒俠系列性別：女丈夫：史艷文稱號：杭州第一美人長子：史精忠次子：史仗義三子：史存孝
 角色經歷,人際關係, 角色經歷由兄嫂撫養長大，與前來西湖岳飛廟進香，投宿於劉家店的史艷文因一首《滿江紅》結緣，兩情相悅，在史艷文被發配充軍後前往雲州照顧史艷文的母親。（94雲州）94版《新雲州大儒俠》中的劉萱姑被惡人劫走，幸為史艷文所救，而後對史艷文產生好感，在兄長劉三死纏爛打的撮合之下與史艷文結成夫妻，在雲州照顧史艷文之母。（千禧雲州）在史艷文苦海女神龍波娜娜一事後，與幼子離散的劉萱姑心灰意冷，出家帶髮修行，後被波娜娜感動還俗。人際關係霹靂城中的劉萱姑【結合今金光布袋戲】姓名：劉萱姑婆婆：水氏（宦門望族之後）丈夫：史艷文（雲州大儒俠，曾兼任兵部左侍郎、太子少師）【古早設定】70版雲州中劉萱姑的兒女史家長子：史精忠（非俏如來）史家次子：史獻忠（今俏如來原型）史家四子：史仗義（雲州四傑傳登場）史家五女：史菁菁（燈下寂寞人）

# 刘萱姑
================================================================================

刘萱姑

布袋戏虚拟人物。史艳文正妻。杭州第一美人，品貌端庄、秀中外慧的才女，为人知书达理，十分温柔善良。

基本介绍
- **

**中文名**：**: 刘萱姑

**配音**：黄俊雄登场作品：云州大儒侠系列性别：女

**丈夫**：史艳文称号：杭州第一美人长子：史精忠次子：史仗义三子：史存孝
 角色经历,人际关系, 角色经历由兄嫂抚养长大，与前来西湖岳飞庙进香，投宿于刘家店的史艳文因一首《满江红》结缘，两情相悦，在史艳文被发配充军后前往云州照顾史艳文的母亲。（94云州）94版《新云州大儒侠》中的刘萱姑被恶人劫走，幸为史艳文所救，而后对史艳文产生好感，在兄长刘三死缠烂打的撮合之下与史艳文结成夫妻，在云州照顾史艳文之母。（千禧云州）在史艳文苦海女神龙波娜娜一事后，与幼子离散的刘萱姑心灰意冷，出家带发修行，后被波娜娜感动还俗。人际关系霹雳城中的刘萱姑【结合今金光布袋戏】姓名：刘萱姑婆婆：水氏（宦门望族之后）

**丈夫**：史艳文（云州大儒侠，曾兼任兵部左侍郎、太子少师）【古早设定】70版云州中刘萱姑的儿女史家长子：史精忠（非俏如来）史家次子：史献忠（今俏如来原型）史家四子：史仗义（云州四杰传登场）史家五女：史菁菁（灯下寂寞人）

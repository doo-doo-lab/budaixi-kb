# 金光布袋戏

**Jinguang · 黄海岱、黄俊雄、黄立纲家族** · 1970 / 2009 — 至今 · 收录 **180** 位角色

由黄海岱、黄俊雄创立。黄俊雄于 1970 年首次将《云州大儒侠》搬上电视，掀起台湾布袋戏第一次荧幕浪潮。2009 年其子黄立纲重启新金光，从《黑白龙狼传》起，相继推出《天地风云录》《金光御九界》系列，以史艳文、藏镜人、俏如来、神蛊温皇为核心。

# 锻神锋

金光布袋戏虚拟人物锻神锋，金光布袋戏虚拟人物，苗疆锋海之主，苗疆第一铸造名家，属独立势力，亦是铁军卫必然要消灭的对象。

其人佩王骨文帝双剑，诗号“谈风月，评圣愚，抚剑笑公输。

巧夺班门明夜火，锋海照寒躯”尽显狂放气质。

为铸就超越墨狂的天下第一神器，锻神锋与废苍生竞逐多年，其毕生执念在于超越废字流成为天下第一神铸。

曾受北竞王所骗铸造赝品魔之甲，后通过条件交换使锋海自苗疆独立，终摆脱铁军卫威胁。

其铸作涵盖赝品魔之甲等作品，以铸造技术为终极追求。

性格高傲自负，口头禅“锻神锋要失态了”，虽屡遭挫败仍坚守铸造之道。

锻神锋以锋海为根基周旋各方势力，凭借精湛技艺与执念成为布袋戏中独特的匠者象征，其与北竞王的权谋交锋更添人物层次。

## 经历

锻神锋官方图片为北竞王铸造了魔之甲的赝品。与北竞王手下苏厉（丑孔明）交谈，苏厉承诺替其主人完成王骨“狼王爪”一事，就允诺让锋海自苗疆独立，并让铁军卫退出锋海边界。承诺剑无极与雪山银燕，用两坛铁军卫的美酒“风月无边”交易他所 拥有的锋海异铁，达成条件后给予了一两。因抢夺离尘石，与史艳文、废苍生交会，并获得了三分之一。与北竞王达成协议，一战撼天阙。开启锋海剑夺，铸造出天下第一神器九尾风华，为玄狐所得。

## 口白相关

1.丑孔明苏厉找上锻神锋铸造武器（剑影魔踪第10集）2.锻神锋：许久不见了，丑孔明。

（苏厉闻言抚上右脸）你的面具完美无瑕，但当你做出那个动作之时，再怎么完美的面具也都遮掩不了你内心的丑陋。

3.苏厉：为山九仞，功亏一篑。

先生既然已经为主人铸造了魔之甲的赝品，如果抽身不是白费心力吗？

4.锻神锋：你在提醒吾，取你的人头，聊表安慰吗？

5.苏厉：小人的人头，值得几何？

比得上先生牺牲的锋海神铁、三十六种异金、七十二稀木，还有无数的心血吗？

（锻神锋闻言一怒，气劲爆发，苏厉见状急忙后退）6.锻神锋：收敛，收敛，恫吓有失吾高贵的气质，一招取命才是我的本色。

你可以更失态，这样，我才能更失态。

7.苏厉：先生贵为苗疆第一铸手，锋海珍藏无数奇铁，原不该受限于此……啊……（右膝遭袭跪倒）8.锻神锋：吾失态了，抱歉。

9.苏厉：一个魔之甲的赝品就能让中原震荡不安，以先生之能，大可名震天下……（左膝被袭）只要再完成这件事情，锻家必能超越鲁家，成为战朝之后，天下第一铸造名家。

锻神锋：总算有一句中听的话。

10.苏厉：（站起）主人答应你的事情一定会做到，但是主人需要你，……先生放弃主人就等于放弃铸造魔之甲的心血，放弃超越鲁家的机会。

11.锻神锋：怎么超越鲁家？

12.苏厉：数千年以来，鲁家都铸造不出超越墨狂的护世之兵，但是先生却有这项东西。

（取出狼王爪）13.锻神锋：王骨？

14.苏厉：请你替主人完成这件事情，主人一定会完成允诺，让锋海自苗疆独立。

（锻神锋沉默不语）15.为取离尘石，史艳文初会锻神锋与废苍生（剑影魔踪第13集）16.史艳文：艳文斗胆，要取一点离尘石。

17.废苍生：就算我愿意，只怕有人不愿意。

18.锻神锋：珍宝，就要交给能发挥它效用的有能者，无能者得之，只是糟蹋。

19.史艳文：艳文取宝，是为了救爱儿，即便无能，也是非取不可，再说，离尘石散落一地，是无主之物，艳文所需也不多，我们三人又何必争夺呢？

20.锻神锋：纵然是史艳文，也未必懂得如何善用离尘石，珠玉弃如糟糠，锻神锋不忍，也不愿见，甚至可能因此，开杀。

21.史艳文：艳文虽不会使用，但会交给善用之人。

22.锻神锋：谁是善用之人？

23.史艳文：鲁家铸者，废字流。

24.锻神锋：鲁家铸者，（回望废苍生一眼）鲁家避世两千年，想不到你竟知晓鲁家铸者的存在，但就算你知晓鲁家的存在，你又知晓该去哪里找寻吗？

25.史艳文：艳文自有方法可以找到鲁家铸者。

26.废苍生：就算让你找到又如何，鲁家精善机关，但铸造之术却是名过其实，废字流千年不成一器，可笑，可笑。

倒是这位先生，自称名家，我想，应该是锋海传人，苗疆第一铸者，锻神锋。

27.锻神锋：耶，苗疆第一铸者只是暂称，还不足骄傲。

28.废苍生：先生不称苗疆第一，哪个称第一？

29.锻神锋：或者苗疆改为天下，也无不可。

30.废苍生：果然是好自信。

31.锻神锋：可惜，锻神锋虽有此愿，但在超越护世之兵之前，现今的天下第一铸，仍是废字流。

32.史艳文：护世之兵？

是诛魔之利。

33.锻神锋：史君子果然博闻广洽，连诛魔之利这项物件也知晓。

34.废苍生：既然锻神锋有挑战天下第一铸者之能，那史君子将离尘石交他，或者更有好处。

35.史艳文：那先生来此捡取离尘石，又是为何？

36.废苍生：无用之人捡取无用之物，做无用之事，无须介意。

37.史艳文：先生方才所提，废字流千年不成一器，艳文倒是另有想法。

38.废苍生：喔，什么想法？

39.史艳文：艳文认为，正是千锤百炼，岁月洗磨，而后功成，方是真伟业。

世人总以成败论英雄，千年不成，便言是虚掷光阴，若是一朝功成，便说是千古美谈，然则，成与不成根本无关宏旨，也非主题。

真正可贵的，是千年以来锲而不舍的精神。

40.锻神锋：说得很好啊，（回望废苍生）这离尘石，你可得三分之一。

41.废苍生：你不是说，无能者得到宝物只是糟蹋，方才还剑拔弩张，现在却是轻轻放下，莫非，是因为他这番话，说出了你锻家千年来不断追逐废字流的身影，这难堪的心病？

42.锻神锋：如他所言，当锻家超越废字流的那一日，这追逐，便是美谈，成与不成，这份精神，总是会继续传承下去。

43.废苍生：那剩下的三分之二，你要带走了？

44.锻神锋：我带走三分之一，余下的三分之一，就让史贤人转交给废字流的传人，离尘石可以聚化发散灵能，或者帮助废字流，打造出真正的护世之兵，（羽扇轻转，收取部分离尘石）然后吾锻神锋，会将这口护世之兵，击碎！

（离开）45.史艳文：先生需要多少的离尘石请自便，余下的，请让艳文带走。

46.废苍生：你要找废字流的传人？

47.史艳文：是。

48.废苍生：说吧，你找我要做什么？

49.史艳文：先生你是……50.废苍生：鲁家废字流的传人，锈剑废苍生。

## 拓展阅读

金光布袋戏，实际通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪(长女)和黄立纲(幼子)共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白主演和导演及后制动画还有配乐师，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，因为1950至1970时的布袋戏主流。

以声音道具等奇关变景吸引观众的表演形态，被称之为“金光戏”，也就是开始舍弃传统掌中戏偶，而改以较大的戏偶来表演，此一时期的变革给了布袋戏的一个转变契机，后来黄俊雄大师把金光戏的表演型态搬上电视舞台，也就是1970年，云州大儒侠史艳文的故事，后于1994年，黄俊雄大师重新开拍云州大儒侠系列故事时，因为感怀1970年的“金光戏变革”，故把自己旗下的布袋戏事业，称为金光布袋戏。

如今经营公司的是黄立纲的天地多媒体。

秉持着改革传统创新和不断努力创造优秀故事的理念，传统戏剧金光布袋戏拥有了大批的不同年龄段粉丝，而且有着值得粉丝期待的众多经典角色，如史艳文，苦海女神龙，黑白郎君南宫恨，藏镜人等。

2014年，第二十届上海电视节亚洲第七届动画创投会，金光布袋戏获得优秀作品，成为台湾唯一获得优秀的作品。

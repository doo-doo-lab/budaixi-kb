# 月牙岚

================================================================================

电视剧《金光布袋戏》中的角色月牙岚是《金光布袋戏》中的虚拟角色，由黄立纲配音。作为东瀛月牙一族成员，他自幼被视为吊车尾，因兄长月牙泪的盛名而备受西剑流同侪歧视，形成强烈的好胜心与自尊心，渴望成为如兄长般的高强武者。其功体属性为风，惯用武器为龙牙短剑，武学包含岚月灵牙斩、月牙天斩等招式。月牙岚初登场时冷厉尖锐，在爱灵灵与雪山银燕的影响下逐渐敞开心扉，曾为守护灵界叛离组织。其人生贯穿家族桎梏与自我认同的激烈冲突，从冷漠忍者蜕变为为爱献身的战士。与爱灵灵的情感羁绊及悲剧结局，构成角色最具辨识度的叙事核心。

## 官方简介

西剑流八门之杜门队长，因家族、哥哥盛名所累，遭到过高的期待及比较，同时随之而来的歧视，令他背负着沉重的压力。——（决战金光：史艳文传奇）为西剑流八门中杜门的队长，属性为风，从小就被笑称为吊车尾的肉脚，加上其兄长月牙泪的名气，所以一直让西剑流中的人瞧不起，也因此他的好胜心与自尊心也十分强烈，希望有朝一日，也成为像其兄长月牙泪一般，受人尊敬的超强忍者。。——（黑白龙狼传：英雄扉页）西剑流八门之“杜”门队长。

因兄长为四天王之一的月牙泪，从小就活在家族与兄长的盛名下，受到旁人过高的期待，又未能及时以出色的成就回应，而换来同侪各种歧视的沉重压力，一直活在内心的痛苦中。

即使爬上八门队长的位置，压力与欺凌依然如影随形。

直到遇上雪山银燕与爱灵灵，才渐渐打开心防，选择为自己而活，叛离西剑流。

但，最终仍被迫面对亲自前来处决自己这叛徒，也是自己最尊敬的兄长月牙泪……——（决战时刻：英雄扉页）月牙一族，西剑流八门之一的杜门队长，有一名优秀的兄长，两人常被拿来比较，因而时常备感压力，对自我十分要求，在与爱灵灵相识后，其善良本性渐渐被发掘，最后为了保住爱灵灵而违抗西剑流的命令，被下令处死。——（决战时刻：桌布）西剑流八门之一的杜门队长，对兄长月牙泪十分崇拜，一心以月牙泪为目标，却不觉的迷失了自我，最后在与爱灵灵的相处中找回善良本性，却为了爱灵灵违抗西剑流，被月牙泪处决。——（决战时刻：桌布2）西剑流八门之杜门队长，月牙一族，因兄长月牙泪优秀的表现而感到压力，十分要求自己，后来结识爱灵灵后被视为背叛西剑流，被下令处决。——（决战时刻：桌布3）西剑流杜门，月牙泪之弟，本性善良却故作无情，后来为了爱灵灵反叛西剑流而被其兄长所杀。——（金光风云录）西剑流八门之一的杜门队长，在与爱灵灵相识后，其善良本性渐渐被发掘，最后为了保住爱灵灵而违抗西剑流的命令，被下令处死。

后因爱灵灵牺牲自我而被救回，此后便在灵界修习。——（九龙变：宣传简介）

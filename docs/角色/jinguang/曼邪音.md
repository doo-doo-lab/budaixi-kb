# 曼邪音

金光布袋戏虚拟人物金光布袋戏虚拟人物。魔世修罗国度灭世三尊之一，与炽阎天、荡神灭共同镇守沉沦海，因帝鬼之命，三尊同率修罗魔兵进入人世。个性有几分爱记仇，但对同为三尊的炽阎天、荡神灭有着深厚的同袍情感。非常痛恨别人批评自己年纪，对恋红梅有着强烈的敌意。怪癖是四处收集所败者身上的物品等作纪念。

## 扩展阅读

台湾金光布袋戏，通称为黄俊雄布袋戏。

金光布袋戏由黄俊雄，西卿，黄凤仪和黄立纲共同经营；

黄凤仪和西卿负责幕后主唱和行政管理，黄立纲负责口白和导演及后制动画还有配乐师跟演唱，黄凤仪也曾和黄俊雄一起担任金光布袋戏编剧的工作。

黄俊雄布袋戏之又称金光系列，乃因播出新云州大儒侠最后一集，预告接续之戏码为金光系列。

之后推出剧集名称多数有金光二字，如金光霹雳菩萨藏、金光十八龙等，遂成为代表名称。

经营公司的是黄立纲的天地多媒体。

主要剧集《千禧版云州大儒侠》至《金光御九界之墨邪录》。

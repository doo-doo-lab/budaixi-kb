# 鲁缺

================================================================================

金光布袋戏中的虚拟人物订阅0有用+10鲁缺是金光布袋戏中的虚拟人物，废苍生之子，登场于《金光御九界之墨世佛劫》《墨邪录》。其一生围绕铸术传承与家族矛盾展开，性格直率偏激，因不灭火铸造事故导致燕娘身亡，遂离家并怨恨废字流。元邪皇入侵时为护众人舍命启动不灭火，牺牲生命。其铸造技艺关联俏如来脱困地门的关键剧情，临终认可风间始为婿。中文名鲁缺别 名缺阿叔配 音黄立纲性 别男登场作品金光御九界之墨世佛劫金光御九界之墨邪录本尊雕偶师萧佟兴

## 角色经历

初登场：金光御九界之墨世佛劫第13集退场：金光御九界之墨邪录第13集（为了阻止元邪皇，引爆不灭火重伤而亡）废苍生之子，多年前为了证明自己有能力继承废字流与终结废字流的宿命，想利用不灭火打造出护世之兵，结果没想到护世之兵没有打造出来，反而因不灭火喷发而害死自己的爱人燕娘。因燕娘之死恨上自己的父亲废苍生以及废字流的宿命，进而离开黑水城。曾游历至羽国，得到过雁王的帮助，后为其打造裂羽铳。其后因被凰后追杀，与废苍生、小玉相认，消除仇恨，并帮助废苍生打造变灵器对抗地门，期间被雁王以小玉为挟，被洗脑入地门，为其打造增灵器，雁王以鲁玉为人质威胁鲁缺，迫使鲁缺跟随其进入地门。在墨邪录4中，雁王自称上官鸿信。后地门大战时，被剑无极等人救出。元邪皇入侵黑水城时，为掩护众人撤退，不惜舍命开启不灭火，终是伤重身亡。

## 相关配乐

1、静好一朝变 - 风间始惨遇鲁缺寻凶场景　◎作曲：愚人梦想收录于《墨世佛劫原声带下》凶险的开场，昭示危机降临。弦乐紧凑进逼，带着迅猛的打击，写出鲁缺如凶神恶煞步步进逼的霸气。乐曲中段，雄浑的圆号沉沉响起，仿佛宣示一切早已不由分说，尘埃落定，是弱肉强食的武林定律，也是命运捉弄的无情。2、花落枝零空 - 鲁缺与小玉父女逼命危急场景　◎作曲：李穆收录于《墨世佛劫原声带下》甜美温润的钢琴，让全曲开场充满回忆的色彩，抒情风味十足，却徒然遭到电吉他打断，一阵狂野的推弦与泛音，象征原有的美好因为乍逢劫难，自此支离破碎。哀怨的筝声，缓缓诉说劫难之后的凌乱与无奈。笛音与电吉他再次加入乐章的重奏，一如幸存者悲从中来时，痛哭失声的崩溃与不舍。

## 人物影响

鲁缺在元邪皇入侵时，为掩护众人撤退而舍命开启不灭火，最终壮烈捐躯。鲁缺认出了女儿小玉并带走了她，并在因故离开时对小玉做出了尽快回来的承诺。大匠师曾评价“风间始，有鲁缺没有的特质”。

魯缺

金光布袋戲虛擬人物小玉生父，與雁王有合作關係，個性直截了當，魯直豪邁。年輕時受到廢蒼生嚴厲教導，致使心性轉趨偏激，在動用不滅火鑄造時，不慎讓燕娘捲入身亡，無法承受打擊之下離開黑水城，並更加憤世嫉俗，對廢字流充滿怨恨。其後因為一場與廢蒼生的決戰，並遭受凰後追殺、小玉瀕死等事件，終於與廢蒼生盡逝前嫌，回到黑水城，共享天倫。

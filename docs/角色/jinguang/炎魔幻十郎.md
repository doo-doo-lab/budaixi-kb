# 炎魔幻十郎

================================================================================

电视剧《金光布袋戏》中的角色炎魔幻十郎是《金光布袋戏》中由黄立纲配音的反派角色，初登场于《黑白龙狼传》，身份为东瀛西剑流创始者及流主，因实力强横被称为“东瀛魔神”。

其灵魂借史艳文次子小空之体复活，身负赝品魔之甲获得刀枪不入之能，掌握幻魔诀、幻灵诀等秘术，功体为不灭魔身，但存在惧毒弱点。

性格暴虐自负，以游戏心态允诺天下风云碑挑战，复活后独战史艳文与藏镜人，倚仗魔甲横行中原。

曾主导西剑流复兴却引发组织危机，与祭司桐山守合作研究禁术未果。

最终在《九龙变》中因魔甲被黑白郎君击破，遭三途蛊与剑气重创消亡；

后于《魔戮血战》以灵体形态被召唤对抗戮世摩罗。

该角色贯穿多部主线剧情，其禁术传承与灵体重现突显力量延续性，武学招式如“灭绝天地”“轮回之镜”象征毁灭性实力，配乐《魔神乱》通过金属打击与管乐烘托霸者气质。

## 主要剧情

西剑流始祖，因其无可匹敌的实力而被称为东瀛魔神，属于全才型的忍者，能操纵灵力与魔力，修有神秘的忍功，并以自己所学创造出禁术，但唯一弱点为毒，死于敌人的毒杀之下。后祭司以八门炼化之力，在九星连珠之刻，让炎魔幻十郎的灵魂寄体在小空身上重生。

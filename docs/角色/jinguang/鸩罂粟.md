# 鸩罂粟

================================================================================

金光布袋戏虚拟人物鸩罂粟，金光布袋戏虚拟人物，别名药神，扁鹊后人，万济医会首领，初登场于《天地风云录之决战时刻》第15集，正式活跃于《东皇战影》《鬼途奇行录》系列剧集。其先祖被羽国流放赐姓“鸩”，武器为药戥秤，角色配乐《卢医悬秤》由许常山创作。性格疏离却心怀仁术，因夜族灭族案深陷江湖纠葛。最终退隐江湖，与失去记忆的岳灵休相伴。其经历贯穿对抗黑暗势力、救治挚友与履行医责，虽孤僻行事仍以医术守护苍生。

钢琴音低吟而上，二胡低语，恰似风雨过后，涤去满身江湖尘嚣，一片静好。鸩罂粟与岳灵休话别众人，身影逐渐隐入山道中远去。千般俗事已化烟埃，举目远望，又见山辽水阔，碧连青。

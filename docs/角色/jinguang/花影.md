# 花影（动画《秦时明月》系列中的角色）

================================================================================

花影，中国3D武侠动画《秦时明月》系列中的原创女性角色，在手游《秦时明月:沧海》中登场，由杨梦露配音。楚国人，季布孪生姐姐，真实身份为农家神农堂弟子，以醉梦楼花魁及执掌者身份为掩护，管理该神农堂据点。形象出众且擅舞艺，聪慧机敏善应变，多年来游走生死边缘。她曾获王离令牌，以此威慑秦将白屠，在荧惑之石争夺中协助朱家获取情报，并通过至亲之血救治昌平君之女涟心。长期保护楚国公主芈涟（化名涟衣）。后因篡改王离军事地图并向农家传递情报暴露，被王离处决。其遗体最终由高渐离等人夺回，交由神农堂安葬。中文名花影别 名花影姑娘、美人、姐姐配 音杨梦露性 别女登场作品秦时明月籍 贯楚国掩护身份醉梦楼的舞姬、花魁、执掌者真实身份农家神农堂弟子所属阵营反秦联盟管理场所东郡醉梦楼孪生弟弟季布

## 角色设定

花影，楚国人，是季布的同胞姐姐。楚国灭亡后加入农家，成为神农堂弟子，东郡醉梦楼的舞姬、花魁与执掌者。她聪慧机敏，多年来在刀刃中行走，生死之间全凭应变。

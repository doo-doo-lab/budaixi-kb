# 一花香

================================================================================

霹雳布袋戏虚拟人物一花香，霹雳布袋戏虚拟人物。

手持日扬善，扮相斯文秀气，乃魔域进入武林的先锋，能言善道、机灵弄巧，负责离间、分化正道团结的卧底任务。

野心不凡，爱慕虚华，整日妄想自立为王，虽小有智谋，但终究沦为四处投靠、摇摆不定的墙头草。

野心不凡，曾一度欲暗中篡夺合修会统治权！

爱慕虚华，后来背叛了七重冥王，导致其死亡，而后统领了七重冥王手下的人马，并投靠了第二魔界灵魅殿之首血灵魔尊，及至血灵魔尊死于杀手零，又归顺于浑沌风魔、死路冥神两位魔殿之主，共同调查并追杀魔魁及其部下。

但同时又受到魔域非法庭庭主纸面阎罗的暗中委派，调查魔魁之事。

魔魁复活之后，一花香因为有纸面阎罗赐予的飞真丹品证明而免去责罚，成为了魔魁部下，后来被玄都抓获，玄都金魔为了刺杀魔魁，而杀死一花香，并让龙阁梭罗假扮一花香潜入到魔魁身边进行刺杀的计划。

一花香名称：一花香称号：寒山性别：男身份：七重冥王分身、第四魔域司寇、非法庭三品法职诗号：峭寒催换木绵裘，倚仗郊原作逝游，最是秋风管闲事，红他枫叶白人头。初登场：霹雳狂刀 第47集退场：霹雳烽火录 第9集（死于玄都下令斩首）来自：魔界

人物

## 经历
摘自霹雳会月刊第52期——超人气档案·寒山一花香1.拜访菩提学院、合修会，与死卜阴帖、玄德相士合作打响知名度，让菩提学院和合修会死伤惨重。

2.武宗魁误认为他是五儒生中的上官知礼或者司马守义其中之一。

3.在鬼渡河口加以阻止素还真进入魔域，素还真坚持进入。

4.因手中的【日扬扇】而被变成怪物的素还真追着跑。

5.收服了武宗魁和天理老人为自己的部下，趁空劫与合修会众人激战时，投放毒气加害空劫，换来九龙菩提经。

6.抢夺恶狼山寨的蚀石水，破坏风采铃之墓。

7.命武宗魁和天理老人就回被困在菩提学院的金小开，带回魔域再造。

后在和血阳子单挑时受暗伤。

8.引剑君十二恨到魔域杀除一些魔兵试探其实力。

后来又带剑君十二恨到杏黄庐找长桑鬼陀，建立剑君对素还真的误会。

9.向三世道君告密佛教有圣佛眼，可找出三教之子。

设计使得儒道释三教针锋相对。

10.将背叛魔域的千层雪杀死，派人暗杀秋风之刀与落日一笑，避免他们二人与素还真合作。

11.通知归元圣童五阳躲在儒园。

将受伤的神鹤佐木送到圣龙口，避免三世道君对他有疑心。

12.因半生浮向儒教通报普生在道教与其起争执，后为冥王所排解。

带闯完魔域的叶小钗去找长桑鬼陀求医。

13.阻止拒生郎上无人峰，却被秦半式用天地根打成重伤。

14.带魔兵埋伏在有别天地打算解决儒教众人，被圣贤诸逃脱；

指点菩提学院院主等人进入天笔峰找因果来主持佛门大局。

15.为狙杀叶小钗而与灵啸月发生冲突，被打成重伤；

受七重冥王之命到荒龙道探查三教主之生死，为了一根手指骨与云岫君大打出手，败于静天手下。

16.带兵前往云渡山杀蚁天海殇君被灵啸月阻挡，建议七重冥王以撼天秘籍和无字天书的用法，去和三教交换灵啸月。

17.将紫邪草之粉末倒进天河里，欲消灭一页书的元灵。

独吞七重冥王要交给五暴魂的孽生原。

18.和非凡公子商议合作，将七重冥王引往魔魁之墓，七重冥王被非凡公子所杀，一花香宣布接掌魔域。

19.放出紫邪草可解开血烙的风声，设计要让三教主入魔。

后跟黑白郎君抢网中人的茧，被黑白郎君击败。

20.为了反对玉天玑的统治，捉拿金小开来血祭，企图让五暴魂复活，却被玉天玑破坏，转而投靠灵魅殿。

21.以武力压迫地灵手告知东武林神秘山洞的秘密，反遭地灵手困于洞中。

在洞内学得绝世武功，说服地灵手与他同为魔域效力。

设计玉天玑陷入地灵手排布的天地人三才奇斗阵，报了老鼠怨。

22.布局安排诛心、断邪投靠血灵魔尊，险被识破，以自身的伶牙俐齿脱险。

23.纸面阎罗调他到非法庭审问当年魔魁被杀之事，一花香把所有责任都推给七重冥王和三灵魅。

24.到猜心园将非常女的尸体偷到灵魅殿，以便验证魔胎生死。

25.血灵魔尊被盼梦圆杀死后，投靠到邪魅、妖魅两殿主门下。

26.带着焚钟盗录千山樵老的声音，想查明他是不是魔魁，无功而返。

27.死路冥神与浑沌风魔被照影扣魂暗杀后，回头投靠无极殿，被玉天玑在背上贯入金针封锁功力。

28.跟踪非凡公子探望魔魁，被断邪所擒，表示愿意上非法庭为魔魁洗清冤情。

29.在魔魁的逼问下，坦承自己是非法庭的三品法官，为查魔魁被杀一案才成为卧底，魔魁将他背上的金针悉数拔除，转而投靠魔魁。

30.被龙骧擒回玄都，审问金魔真正的死因，龙阁梭罗为接近魔魁，将之斩首，以其面容易容。

# 佾云
================================================================================

佾云

云门八采之一，剑法绝妙。个性极度善良，被称为云门的太阳，但在做事态度方面常因思虑太过、心存善念而流于优柔寡断。习惯以自己的方式，独自承担所有的事项，为避免连累他人而常选择避之不见，在云门中也是令众兄弟挂心的一位。

# 一渡微尘

来历不明，高雅避世的先天高人，自嘲一介闲人，持浮生翩然入世，抚虚籥潇洒渡世，来去悠然无踪，身怀高深武学，性喜洁白干净，极端厌恶污秽肮脏，于异象层出不穷之际意外现身，其背后隐藏身份引人注目……

## 人物经历

雪白天姿，最恶污秽

浮生不染红尘埃，渡世匆忙，是一扰浮生，亦或浮生一扰，皆为一渡微尘独特而偏执想法，惯以悠闲与玩世不恭之态面对世间，更不忘自嘲间人一名，放眼人与人匆匆来往，又何尝将心认真看待，渡微尘本该洗渡世间纷扰，从微小如尘，岂能随心放纵，如今却不欲沾染世俗微尘，此污秽，又有谁能除之。

弦外之音，岂渡微尘

回首君身渡微尘·天下无人识白衣。

轻描淡写的诗号，正诉说其人之志，回首一眼，孰能看得透彻，不识君身是君身，冷淡漠然，神秘莫测，一度微尘身负守护深寰地宇的身份，不欲地宇与苦境有所关联，但其间隐晦说词，似藏难言之秘，行事独来独往，只为目的默默而作，君身白雪姿，是不知其人其事，其身其心，天下间无人得识。

六蚀造祸，非命七念

六蚀玄曜搜集力量破坏地宇封印，七异念飞窜而出各择宿主，并潜移默化影响宿主的所作所为；于剧中解释，非命七异念乃七种由人情感所转化而成的力量。

异念分别为：冷淡、狂妄、悔疚、憎恨、欲望、恐惧，还有一未知意念。

七异念潜伏人之体内，被寄宿者无法察觉自己变化，纵影响判断与行为却不自知，如常初太古云表露苦心并询问是否退隐，凤舞迟因冷淡异念之故而拒绝，又如亲临阙风策逼命，刹紫烟囚恐惧而激发力量···异念因宿主相关情感所激，力量愈盛，反之则受抑，无法尽展功力，随剧情发展，七异念有些再次易主，又将如何引起武林之祸，而最后一个异念下落又在哪里。

回首君身，谁人可识

一渡微尘初现身救援太古云，又因异念之故与凤舞迟意外结识，后助百重泉、玉龙隐士等人，一渡微尘多次为正道化险为夷，武学更是高深莫测，对上狂影不负、阙风策、甚至神荒子，皆泰然自若应对；看似悠游江湖中的闲人，掩藏在厌恶污秽的玩笑之下，是眼神中的绝冷杀意，如若世间不平不公，那便以一，渡微尘。

而一渡微尘不喜自身染尘，随身之物亦然，将浮生或籥飞抛空中是个人兴趣，在一瞬将月分割为二，代表光明与黑暗相生相灭，光之背后是黑，黑之背后是光，本无二分；一渡微麈非是一名慈悲者，若心动杀意便不会有所迟疑，但会因尘土飞扬而停止，曾视眼前污秽。

亦师亦友，忘年之契

初生之犊凤舞迟，遇上一介闲人一度微麈，将擦出何种火花， 云渺不弃凤舞迟，是凤终要高舞飞天，在那日到来以前，凤舞虽迟，谨守分寸，愿尘埃不染他身，纵江湖狡诈，仍抱天真无邪，对任何人留有警诫，是太古云衷心期盼，在知晓凤舞迟结交好友，又能成熟行事，长年牵挂，终于放下。 对一度微尘而言，因异象而起得误会，在过招后，不由感叹小朋友不知轻重，只以满腔热血便想闯荡江湖······是好奇之心，也是故意捉弄，便与凤舞迟结伴而行，却经歴无情风波，凤舞迟父亲太古云、朋友朱弦相继离去，古云庄被灭，曾有得意气风发，如今被消磨得只剩复仇之恨，却是一度微尘不愿见到得画面，太过相像得两人，其实是他，也是他。 不忍凤舞迟受异念影响，一度微尘相约暗号，那是让凤舞迟恢复得关键，属于两人之间得默契。

一渡微尘：「浮生扰扰渡微麈。」

凤舞迟：「百年渺渺凤迟痕。」

暗藏身份，拨云见日

在与神荒子一战中，一招万古乾坤空一洗，被揭破为昔日封印地宇，胤世五烈其一的成名招式，一渡微尘为何会使用，与地宇是何关联，而与凤舞迟这段情谊，随著非命七异念故事的发展又会如何演变，一渡微尘的真实身份以及目的呼之欲出，一切便请戏迷朋友继续关注《霹雳兵烽决之玄象裂变》。

# 槐破梦

霹雳布袋戏虚拟角色。自幼由剑之初所抚养，生性桀傲难驯，自命槐破梦。天阎魔城以医治心悸之由带走，经由愁未央的培植脱胎换骨，更受他化阐提所赠忽雷琴后堂然出现武林，全身散发邪佞气质，个性骄傲皇霸，且富有心机手段。后在天阎魔城兵败后，继承魔城势力，在驺山棋一的协助下，成就胤天皇朝霸业。

## 一泓净角色设计

名号槐破梦一出生，即面临母亲死别，因此对母爱的渴望远超其他，虽期间有父亲剑之初抚养，但槐破梦内心隐隐对剑之初不报仇的态度，感到不满，剑之初为其取名“忘知”，更让槐破梦认为剑之初避事太过，因此在懂事后自名槐破梦，欲借此追本溯源，纪念母亲。

杀戮碎岛之王皆由玉槐树所生，故槐破梦以槐为姓，象征不忘母亲根本，更有光复杀戮碎岛之意，自名破梦，则表示天伦梦碎，今生再无圆梦之时，此恨日夜相随、永伴一生！

槐破梦造型槐破梦槐破梦与殊十二个性迥异，造型上也要有极大分别，槐破梦举止有狂霸之气，应属于阳刚一类，但是编剧又特意设计他以琵琶音波为武器，这样的反差呈现了槐破梦深沉阴柔的一面。

忽雷琴他化阐提得到天工八月泉水弦后，以希音琴木所制，赠与槐破梦。

忽雷琴能与槐破梦承自杀戮碎岛王树的功体相辅相成。

## 角色评价

槐破梦，幼时的自负倨傲，到初出江湖的目空一切，隐藏在急于证明自身能力之后的，是渴求亲人关怀，却别扭说不出口的童蒙内心。对剑之初与殊十二的误解，让槐破梦妄自蹉跎不少天伦相聚的时光，所幸，误会终能冰释，天伦聚首虽是短暂，却已深刻记忆之中。与驺山棋一的相遇极大左右了槐破梦的命运，纵使一路走来曾有不解与怨怼，但槐破梦仍是选择相伴，无所后悔，亦算寻得自身的幸福，不枉红尘一遭。

## 编剧漫谈

槐破梦·忘知那天，双子愁眉苦脸的摊着皇家邀请函，看着已经要过去了的时间，两人却都没有上舞台的准备，衣服在哪儿？

鞋子在哪儿？

怎么一支笔会枯竭成这样？

就在坐困愁城之际，忽来女巫仙杖一点，双子化出一身华丽的装备，开始旋舞在格子舞池上。

原以十二点钟声一响，双子就要因魔咒消失而仓促离开舞台，只留下一抹让世人惊艳的颜色，在心中反复惦念。

谁知道皇家大钟随着睡美人沉眠已久，于是双子舞步从华尔兹到探戈，从探戈到伦巴，今天子夜十二点之前交不出稿子，那就明天午夜十二点之前吧，明天不行那就后天吧。

笔一直钝着，双子的旋舞曲就一直停不了，交稿期限从原本的姑娘，无限延长成折磨人的红舞鞋。

关于十二点之前截稿的限期问题，我睡一觉就全抛诸脑后了。

本来真的不打算废话太多的，但被嘲笑原来对双子的爱，居然堪堪只快逼近2000字，连2000大关都没冲破，于是我只好用废话来冲字数了，然后，我还真的很佩服自己的废话能力，居然能将原本的两行字，废话演绎成五百字（有神，快拜！）不罗嗦，接下来只说关于双子的二、三事。

当初会有双子的戏路出现，其实早在戢武王定为女儿身的时候，就已经开始在酝酿。

到戢武王怀孕的时候，腹中双子一善一恶的路线也已模糊成形。

双子的戏份，对我来说是一种情感上的延续，一种对杀戮碎岛、甚或是整个四魌界的延续。

只是，他们身处苦境，唯一的四魌界延续是来自对母亲的牵念与父亲的纠结情感，然后每次写着写着。

就不免感叹四魌界真的过去了，而双子后续能博得这么大的戏路空间，有大半是来自于戢武王的壮烈殒落，所以双子对母亲的情感，也是人格塑造的一大特点。

杀戮碎岛之人，皆多了一条心脉流转王树之气，双子也不例外。

他俩自母胎便能借由母亲的心绪感知外在世界。

于是应该天真无邪的婴儿，其实在母胎里累积了许多人世想法更深知母亲处世那些抑而不宣的痛苦。

啖魔若果之助，更是加速了双子发育与心性确立。

于是造就了双子，一个性情偏邪与乖戾，一个温和与逆来顺受，然后再借由后天环境的影响，让双子因个性问题而激起戏剧的火花。

槐破梦自小被剑之初带在身边，因缺乏安全感而容易有霸占心理，而偏偏剑之初总是悬心在那个未得下落的念痴身上。

槐破梦为此而对殊十二产生了强烈的敌视感，认为他的出现将夺去自己所拥有的一切，认为既然父亲不够爱他，那么他也不需要父亲，而剑之初为双子的存在，将玉辞心的仇放下，也让槐破梦十分不满。

于是两人的相处模式，紧绷感日渐存在，对父亲的态度，总是张着刺。

看在剑之初眼里，只觉忘知太过叛逆，深怕是受到啖魔若果影响而有渐入魔道的可能，所以剑之初总是较为严厉地管教槐破梦。

这种越来越疏于认识对方心理，让只看见自己以成见所形塑出来的对方，终于让父子关系势同水火。

而被鬼觉神知抢下的殊十二，从小被带离亲人身边，虽受鬼觉神知虐待，但心中总保持着对天伦之情的向往，认为只要能回到父亲与兄弟的身边，现在的种种痛苦，不过也就是种考验，只要熬过去，就会过去了。

因为在远方，还有自己亲人存在，终有一天，他会回到亲人的身边。

相较之下，鬼觉神知却什么也没有，只能借由恐怖与高压手段来彰显自己的存在。

想通看这一点，殊十二在看待鬼觉神知的眼光，便多了几分宽容与怜悯，不再害怕与鬼觉神知相处，甚至随着自己武力的日渐强大，他对鬼觉神知的心理，还多了几丝因养育之恩而来的责任。

殊十二的心理转变，鬼觉神知看在眼里，恨着他如此，但常年失温的心却又为此而暖着，连鬼觉神知也越来越弄不清楚，他到底希望殊十二走上什么路子？

随着双子的交集，这些环境因素加诸在一起，而激起了人性与权力的斗争。

在棋一强势主导而成的胤天皇朝，将领双子走向另一个方向的毁灭。

而双子实际接触后，皆不约而同的调整了自己看待对方的眼光与期待。

殊十二曾经幻灭，却抵不住亲情天性；

槐破梦曾经抗拒，同样抵不住亲情天性。

两人在无情的江湖中，几遭吞没，这才真正体会了母亲双子谣中的意义：双子谣，摇子过大桥，生生世世相伴道。

唯有双子伴道齐心，方能在险峻的江湖中生存。

剧照双子对剑之初的感情，也将随着局势变化而有突破。

槐破梦认为剑之初比较爱他心目中的念痴，而殊十二则认为自己怎么也比不上槐破梦在剑之初心里的位置。

当双子一同到碎云天河，槐破梦与殊十二打赌，赌父亲见到双子同在的时候，谁会是他先叫出口的人。

槐破梦觉得必定是殊十二，岂料父亲一声“忘知”，让他深深震撼，说不出心中百般滋味是什么？

但当他眼角余光瞥见了殊十二，如同局外人的退了一步，看着眼前的父子重逢，他仿佛看见当初的自己，总是疏离在父亲念子的心情之外，一时间突然了悟了很多。

笑着过去的自己，也笑着现在的殊十二。

他忘情的牵起剑之初往殊十二身边，父子三人自此捐弃过去成见，笑谈历来种种……双子戏路里，还有一个很大的关键，是在驺山棋一身上，她撮合了双子，却也为双子铺下了毁灭之路，双子能否逃过她的阴谋算计，便是后续戏路的重点。

而魔子用了极重的笔力，在写着对圣子的纠结，那么也会有相同的笔力完纳这份纠结。

魔子的不成熟，将凝练出这一段双子故事最美的内涵。

敬请期待!曾经想写的圣魔双子，是一对因受啖魔若果影响而天生有着圣魔印记的双子，被世人判定为正与邪的代表。

圣子一出生，便有圣人光环加诸，受到世人的注目与爱戴，对他投以极高的期待，而魔子因有魔性污染，世人对魔子极为唾弃，甚至恶之欲死。

一次因缘际遇之下，魔子失去了下落，众人日渐遗忘之际，流落市集可怜乞讨的少年魔子出现了。

但因为魔子一出生就不受到期许，众人对他的不屑一顾，相对下，养成了他对什么事都能游戏看待过去的乐观心态。

之后少年相遇，一个是天之骄子，一个是市集乞儿，一个手众人寄托了希望而日渐变调的圣子，一个受环境拖磨而豁达人生的魔子，最后因一道人生的选择而体现的自我价值。

这时候，鬼觉神知才揭露，圣与魔只是人心的一种投射，并非啖魔若果能成魔成圣，，是他在玩弄世人的眼光。

不过因为还有剑之初的关系，所以后来两人的个性及戏路便再作过调整。

其最终要表达的，依然是死在对人生的价值体现。

剧照有时情感在心中酝酿的很宏大，写出来的，却不尽理想。

笔力的精进，一直是笔者追求的目标，期盼每位角色的起落，都能带给观众不同的情感感受。

（2012.3.6完）

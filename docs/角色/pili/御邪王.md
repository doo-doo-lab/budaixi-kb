# 暗禘

霹雳布袋戏虚拟人物暗禘，霹雳布袋戏虚拟人物。天邪八部众中的“御邪王”，昔日示流岛战役身亡后，魂魄被地冥施展咒术与寒武纪合一，成为“暗影”，在地冥破除其禁锢封印后恢复。城府深沉，冷血无情，善谋策划，能织罗暗黑吾界克制敌手力量，积极解封八歧邪神的龙首，让厄祸邪神复生。原名犴黥，与胞弟犴黔生处于百妖乱世之时，专门擒抓妖兽出口，以此获利，也缓解境内妖兽躁动的乱象，此举让原本没落的海港，因此成为远近闻名的百妖海市。但犴黥兄弟却也遭妒被陷害，犴黥被流放妖海，后为八歧邪神所救，在犴黔要被问斩前，以御邪王之姿，驾驭屹涛海邪重回海市，虐杀整个海市之人，因而震惊当时。

## 经历
御邪王·暗禘，原名犴黥，来自东瀛，与胞弟犴黔一同生活。

时逢百妖乱世，犴黥兄弟专门去捕捉妖兽幼崽出口买卖，获利同时也减缓境内妖兽作乱，使没落的海港成为闻名遐迩的百妖海市。

但树大招风，犴黥遭官商勾结陷害，受刑并流放妖海，漂流中被八歧邪神所救，被八歧七魂之一的无间常黯皇收编，授予其力量成为御邪王暗禘，在胞弟犴黔要被问斩前，统御妖兽回归并屠杀了整个海市。

一版形象（回忆中）一版形象（回忆中）回忆中形象不久，暗禘接受邪种源计划的任务前往长生树，但因邪功未全遭羽衣狐·花宵朝雾击败，得末邪王·𬸚变迦罗的帮助而完成任务，更在凶巢渊薮布下百婴祭，为未来做下准备。

后来，暗禘和𬸚变迦罗攻打示流岛，在外海的北邪屿建立势力。

入侵示流岛后，八歧邪神又计划入侵中原神州，九天玄尊率领八剑士渡海而来展开示流岛圣战，八歧邪神被九天玄尊击败，暗禘也在战中被锋魔·剑上缺斩杀。

暗禘死后邪魂四处游荡，被地冥施展封印，以殉道之眼将其与寒武纪合一在无人解的肉体中，成为暗影。

后来受𬸚变迦罗引导，为解开禁锢与之联手，在以大漠苍鹰魂识为交易时受地冥解封，暗禘重临人间。

暗禘复生后实力猛增，甫出手便创伤地冥，战中更以暗黑吾界困住玄黄三乘，使三人一时难以施展；

在道武王谷之役中更力拼一页书，被创伤飙血仍不后退，足见其战力与意志的强硬。

后受地冥算计，在西煌佛界外被瑟斯二世以太微垣击杀，因御天者奈落川的计谋而在八歧龙首的邪气力量下复苏，并蜕变出百妖恶相，实力更上一层楼。

暗禘一直专心于解封八歧龙首之事，期间以织骨大法帮助鬼麒主复活；

也配合阻杀孤星泪，将其击落悬崖。

暗禘欲解决跟踪自己的无人榜时，从无限恨处得知，无人榜体内寄宿着胞弟犴黔的魂魄而大为震惊，之后一直欲寻法解开地冥的术法，唤醒胞弟。

而后，暗禘受令以邪葬日月攻击仙门云鲸，对出手阻拦的劫红颜心存疑惑，后得印证，劫红颜便是当年的花宵朝雾。

锋魔·剑上缺寄体重生，与暗禘隔世再战。

心知寄体无法久撑的剑上缺，以地锋太微垣与暗禘最终死战，暗禘虽实力远胜从前，但在坚定决心的剑上缺面前，仍是受到重创，在九婴的帮助下被𬸚变迦罗救走。

正式登场形象暗禘  官方桌布伤愈后继续执行任务的暗禘，感觉到𬸚变迦罗的隐瞒，遂和九婴配合杀死炬风狴小乐，欲解封第八颗龙首。

云徽子赶到现场欲毁龙首，暗禘全力一击却不敌斩魔录心法之威，在要舍身自爆厄力时功亏一篑，不仅龙首被净化，暗禘自身厄力也被突然杀入战场的未知体内的婴灵全数剥夺，邪魂将散之际，与知晓一切后的无人榜短暂再续兄弟之情，以最后力量治愈完无人榜的伤后，便魂断咒散而亡。

在正道开启八龙山战役时，八歧邪神复活天邪八部众，暗禘也以百妖恶相再现。

但犴黥魂魄已散，这个暗禘只是邪神制造的一个拥有相同面容的傀儡。

傀儡暗禘在战中阻挡红尘雪，后来在短暂复活的应无骞的帮助下，红尘雪将其消灭。

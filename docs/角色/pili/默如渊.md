# 默如渊

十三道宁真君的嫡传弟子，承袭刀法绝艺，脱胎而出，实力不亚于昔日的六阳十三道。默如渊个性内敛不露锋芒，沉默少言，认定一个目标便不惜一切达成，对于天道主则全心信任，从不开口多问，只专心完成任务。

# 默如渊

十三道宁真君的嫡传弟子，承袭刀法绝艺，脱胎而出，实力不亚于昔日的六阳十三道。默如渊个性内敛不露锋芒，沉默少言，认定一个目标便不惜一切达成，对于天道主则全心信任，从不开口多问，只专心完成任务。

## 人物经历（来自百度百科）

十三道宁真君的嫡传弟子，多年前师父仙逝，身体上有师兄的刀招，加上师兄失踪。故推断师父被师兄所杀，遂苦心修炼刀招。后追随天道主，为了完成师父的遗愿，视青阳子为仇人，后天道主失败瘫痪，默如渊依旧不离不弃。天道主暗示只有自己恢复才能杀青阳子，遂自杀成全天道主。

# 默如淵 (默如渊)
================================================================================

默如淵

十三道寧真君的嫡傳弟子，承襲刀法絕藝，脫胎而出，實力不亞於昔日的六陽十三道。默如淵個性內斂不露鋒芒，沉默少言，認定一個目標便不惜一切達成，對於天道主則全心信任，從不開口多問，只專心完成任務。

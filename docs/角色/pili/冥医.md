# 冥医（金光布袋戏虚拟人物）

================================================================================

冥医，本名杏花君，是金光布袋戏系列中的虚拟人物，职业医师，师承掌生握死幽冥君。初登场于《天地风云录之决战时刻》第15集（2012年10月3日），在《魔戮血战》第32集（2014年8月6日）为完成医者使命自愿成为徒弟修儒的首名患者后逝世。角色轨迹贯穿《九龙变》《剑影魔踪》等多部作品，遗体化蓝色彩云消散。冥医秉持“生命价值论”按患者价值收费，性格诙谐幽默，与默苍离为至交。魔世入侵后依靠亡命水维持生命，曾将默苍离托付的信件转交俏如来。参与墨家继任事宜，曾攻克失血症并研制阎王低头、阎王借魂等药方，持有织命针、无影金梭等器具。血色琉璃树居所经修缮后增设药室与贵妃榻，被龙宿指出与默苍离均患心病。临终前教导修儒铭记"医者以己之能豁尽全力，也有无能时"的遗志，清平乐继承其名号并引用诗号"杏林迎阻黄泉路，落凤引渡亡魂归"。中文名杏花君别 名冥医职 业医生主要成就攻克失血症、创出阎王低头和阎王借魂药方代表作品天地风云录之九龙变、剑影魔踪、魔戮血战所有物算盘、织命针、阎王低头、万毒血、鬼头菇、养血蛊、无影金梭、葫芦师 承掌生握死幽冥君性 别男

## 官方简介

默苍离好友，万济医会的会员之一，少数真心相信默苍离而跟随其左右之人。医术极为高明，为人爽快风趣，但对医理与原则却相当执着。——（金光群侠传：杏花君）默苍离挚友，将救人视为天职，医术极为高超，靠一手织命针绝技医遍天下，曾在天地风云录时期给俏如来三粒药丸度过难关，是个豪迈风趣的大叔。——（金光群侠传）冥医，以一手绝妙的针术救人无数，在史艳文被中原人士追杀之际出面相救。认为每个人的生命都有一定的价值，因而在救人之余还会依照自己的认定开出相对应的医疗费用。——（九龙变：宣传简介）曾出手搭救史艳文，之后更给俏如来三粒药丸，助其布局定谋，其认定每个人之所以活着，各有其价值，因此救人时会依照自身价值认定，开出不同的诊疗费。个性诙谐幽默，与默苍离为至交，默苍离身亡后，魔世大举进犯，遂以亡命水支撑遭荡神灭重创之躯，苦苦等待再见俏如来，之后为了教导修儒最重要的一课，自愿成为修儒第一名正式患者。——（魔戮血战：桌布）与默苍离为相识好友，由默苍离口中说出全名为「杏花君」。是具有超高技术的神秘医师，性格诙谐幽默而爱财，擅长吐槽。——（决战金光：史艳文传奇）（医术高超亦好财）杏花君，因无法忍受失去病患的良心苛责，一度自暴自弃，而后终于克服心魔，却还是救不了最想救之人…——（金光风云录）

## 人物关系

冥医的师承关系包括师父掌生握死幽冥君、师娘娇姨和师妹中谷大娘（茹琳），并收徒修儒。冥医与默苍离为至交，曾将默苍离托付的信件转交俏如来。仇敌有恋红梅和万朔夜，但仇怨均已化解。冥医曾医治众多角色，如无情葬月、史艳文、藏镜人（罗碧）、俏如来等。

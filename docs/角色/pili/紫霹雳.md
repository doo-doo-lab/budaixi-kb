# 紫霹雳

================================================================================

霹雳布袋戏虚拟人物紫霹雳，霹雳布袋戏虚拟人物。紫霹雳为金太极与史菁菁之子，因先天夭折被弃于葬尸江，后被月云老人救至血树林抚养。其初期以神秘孩童形象登场，曾击退黑白郎君与夜书生，后成长为骁勇善战的武者，多次冒险营救父亲并采药。紫霹雳在翠竹林遭霹雳门围杀身亡，尸体被改造为第五代网中人，经历多次蜕变后与黑白郎君同坠流星岩。后经白骨灵车指引以机器人形态复活，参与天河运棺等战役，最终在琉璃仙境遭解体退场。复活过程需移植百年不死之脑、通灵知性之心等特殊器官。

## 人物设定

身份：金太极与史菁菁之子。

史菁菁为救独眼龙被迫嫁于金太极一年后出生，但一出世便夭折，被二人弃与葬尸江。

而紫霹雳并未死，于江中被神秘十字（月云老人）救走，带至血树林抚养，成为霹雳震灵霄后期只闻其声不见其人的“神秘小孩童”。

初期：初登场便大显神威，击退正在决斗的黑白郎君和夜书生。

其实紫霹雳出初登场时脸的颜色不是紫色而是黑色，且不善言语，亲人就是月云老人。

长大后的紫霹雳骁勇善战，武艺高强。

地狱窗救金太极，千辛万苦为受伤的月云老人采药，又为昏迷不醒的金太极深入危险的云梦沼泽采药，并成为第三个生还于妖龙口中的幸运者。

性格上，紫霹雳与小金刚非常相似，都喜欢打抱不平，其后更与传音儿结拜为兄弟，对父母极为孝顺。

变身网中人：霹雳真象第五集，霹雳魔球缩骨人来到翠竹林要杀死当年霹雳门麾下金流门的叛徒金太极，史菁菁留下独挡，让紫霹雳带着痴呆中的金太极离开，不幸在翠竹斜坡被埋伏的霹雳门众妖道围住。

混战中，金太极坐着轮椅顺着斜坡掉入再生潭，而紫霹雳却不敌群邪，惨死于乱剑之下，其尸体则被路过的秦假仙带给第四代网中人“金蜘蛛”，并在网中人死后继承网中人的衣钵，成为第五代网中人。

成为第五代网中人的紫霹雳初期只有初段蜕变，后期也只达到中段蜕变，然而也打遍天下无敌手，最后却重伤于金太极倒锁之下，托命回到白骨骷髅井，隐匿数日后，蜕变为第六代网中人。

第六代网中人已失去部分紫霹雳原有的容貌，银面白发，声音也变回网中人的声音，但身体仍然是紫霹雳。

蜕变完成不久便遭遇黑白郎君，大战至流星岩边缘，并双双坠入流星岩，消失在烈火中。

金光后：因金太极脱离地狱窗时受到日照伤害需要霹雳门之血肉芽救治，紫霹雳独闯霹雳门，血战通天柱下，惨遭霹雳门守将所杀，受剜眼、断手、取脑、挖心、削足之刑。

后白骨灵车现身指点金太极搜寻五宝和一线生就可以领紫霹雳复活，自此引出了霹雳一代奇人素还真涉足江湖的故事，也将霹雳系列推进到了一个新时期。

紫霹雳以机器人形态复活后曾经横扫武林很长一段时间，紫雷电击之下未有活口。

战斗力测试的能力更是紫霹雳绝招。

直到天河运棺之战后，随着霹雳狂刀剧集的节奏，紫霹雳也终于淡出了霹雳的舞台。

回想紫霹雳作为机器人登场的时代，武功在高科技面前竟是如此不堪一击，叱咤风云的黑白郎君曾经被紫霹雳逼得毫无还手之力。

在这一段时间内，也是霹雳世界从单薄的草莽英雄向神怪、奇谈、奇幻的厚重的全新的世界演进。

注：紫霹雳曾经被命七天以菩萨印第十式莲法灵光照大千击成碎片。

苦、集、灭、道的世界观也是在这一时期开始形成。

退场：霹雳狂刀（在合修会进攻琉璃仙境时以巨型磁石吸住，遭到解体，最后出现是在霹雳烽火录中，一线生的临时实验室中，但是仅存头颅部分。）功能：探测对方战斗力数值、堪透阵法迷雾、刀枪不入、对气功具有防护力、超强灵敏度。

## 武器

## 经历
紫霹雳为金太极与史菁菁之子，因先天夭折被弃于葬尸江，后被月云老人救至血树林抚养，初期以神秘孩童形象登场，曾击退黑白郎君与夜书生。

长大后的紫霹雳骁勇善战，武艺高强，多次冒险营救父亲并采药。

在霹雳眼第18集中，紫霹雳曾杀死两名意图夺取他的江湖客。

紫霹雳在翠竹林遭霹雳门围杀身亡，尸体被改造为第五代网中人。

根据霹雳金光第12集，紫霹雳的尸体最初被三老埋葬在百官机密门。

成为第五代网中人后，紫霹雳经历多次蜕变，最终与黑白郎君同坠流星岩。

为救父亲金太极，紫霹雳前往通天柱采集血肉根，独闯霹雳门，血战通天柱下，惨遭霹雳门守将所杀。

后白骨灵车现身指点金太极，提出复活紫霹雳需找齐五宝和玄子神功的创造者，并意图逼出素还真。

## 相关作品

在《霹雳金光》第12集和第13集中，提及紫霹雳尸体被埋葬于百官机密门，以及白骨灵车提出集齐五宝与玄子神功创造者可使其复活的剧情。在《霹雳眼》第18集中，出现紫霹雳击杀两名欲夺取其的江湖客的情节。在角色扮演游戏《霹雳奇侠传》的攻略及回顾中，提及紫霹雳为金太极与史菁菁之子，并描述其出身背景及为救父前往通天柱采药等冒险情节。在《霹雳英雄榜》剧集相关的问题答案中，紫霹雳被作为谜题答案提及。

## 人物影响

紫霹雳的复活事件由白骨灵车推动，目的是逼出素还真。紫霹雳被设定为能制服三名魔童的关键角色。在游戏《霹雳奇侠传》中，紫霹雳作为金太极与史菁菁之子，为救父亲战死九层天，后白骨灵车再现透露重生之法。在游戏《霹雳英雄榜》中，紫霹雳是关键元素，如“一炮轰开险关道的[炮]是指紫霹雳”。

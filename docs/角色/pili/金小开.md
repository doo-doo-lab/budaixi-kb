# 金小开

霹雳布袋戏虚拟人物金小开，霹雳布袋戏虚拟人物。金小开因父母的离弃及背负祖父叶小钗的盛名形成叛逆性格，无恶不作、为非作歹，因挑衅叶小钗并遭其惩戒。后经圣母教化实现善恶分体，性格转变后与自在天女成婚。曾为获取神剑与刁刀合作，间接导致剑神穷八极之子身亡。

## 角色能力

武学起手一刀、疯魔啸鬼、诛天戮杀、血泣哭灵、蓝蝎虐毒、夜笑狼戾、点落八方、凌虚御风、篷飘萍转、断鹤续凫、走剑行刀、是非圈、旋空杀、一刀起程、形意狂草、草草收尸、先鞭着气、剑走刀行、驾刀御剑、阴风六绝之蛊风、判死剑招地字诀、毁天灭地、血洒天日 、急就行章武器金小开 武器龙骨圣刀：此刀最大特色在于刀身呈骨节状，色泽白灰、布有血纹，护手镶有宝石，刀柄刻有“万俟焉”三字。

慈斌刀：以石为铸，故有着岩石般平实朴素的外表。

善玉剑：无锋之剑，乃一青色玉石所铸成的宝剑。

结草衔环：一柄以草绳织结而成的剑，无锋无刃。

飞驼凌：机械金属合金的现代造型，剑锋异常的短，护手掌翼为一开合匣面，会显示最适合此招的武器，此剑更能拆离为两把武器使用。

红邪：血红色尖刺，尖锐无比，类似腕中剑。

## 角色详解

摘自霹雳会月刊第61期 人物完全写真---金小开金小开表面上总是一副自信满满的金小开，其实潜意识里有着很强的自卑感，太多的挫折打击会击垮他的自尊心。

从小失去父母的疼爱，武林人士又会拿叶小钗的成就来刺激他，是金小开变得更加叛逆的原因之一。

在爱情方面，金小开尽管向来是捏花惹草、不负责任，但当他确定自在天女是自己最爱时，也是毫无保留的付出一切，全心全意的去爱她，不过其中一个原因，也是因为金小开喜欢那种像慈母一般、能给他温馨感觉的女性。

不过他却十分讨厌浓妆艳抹、香气扑鼻、态度暧昧的女人，所以他很不喜欢太阳女。

金小开出道以来，一直给人一种放浪不羁的浪子色彩，也做了很多让人咬牙切齿的事，金小开的叛逆、不孝，以及杀师的罪名，让人对他是又爱又恨。

后来金小开经历照世明灯的辅导，圣母将其善恶分体，原本放浪不羁的个性才有了改变，一生坎坷的金小开终是到了浪子回头，但天道总轮回，好不容易和叶小钗修复关系、与自在天女结婚生子而得到幸福的金小开，报应的死在了穷八极手上，也是令人感叹。

如果说是遗传，那我的祖父也有责任。

金小开：别骗，我都查过了。

最后，我有一段宣言。

素还真：你讲吧。

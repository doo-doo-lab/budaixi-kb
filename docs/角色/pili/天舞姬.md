# 天舞姬 (天舞姬)
================================================================================

天舞姬

艷色傾城，貌美如花的魔息大帝侍妾，平時守於魂棺夏禘內，由魔息大帝招喚時，方會伴隨著音樂而現身，展露舞技。其舞姿出神入化、婀娜動人，同時手持琵琶，一身中東風格衣裳飄動下，手指一邊撥弦彈奏、一邊舞動身軀之景十分動人，為魔息大帝最喜欣賞之娛樂消遣。

# 君奉天

霹雳布袋戏虚拟人物君奉天，霹雳布袋戏虚拟人物。儒门剑客宗师，剑法造诣顶尖，为墨倾池、玉离经等人的前辈，尊号“法儒无私”。身背刚正法剑，手托至衡律典，个性耿直，刚正不阿，不容任何邪恶之事，正气凛然，原则为上。原在德风古道的昊正五道内守关，因单锋罪者一案再掀儒门风波，受玉离经携众请托，现身援助。君奉天出自云海仙门，乃九天玄尊与鬼后魙天下之子，云海仙门的正统继承人。诗号1：正天地所不正，判黑白所不判，犯人鬼所不犯，破日月所不破。儒法、无情，法儒、无私。诗号2：江声岳色，万仞峥嵘剑长歌；青冥浩荡，天涯孤舠尽折蒿，云辟千层巅，还看一山高。

## 角色背景

姓名由来君奉天编剧在设计人物姓名时，取“丹心”两字，以“一片丹心”之意，呈现角色的特质，一以贯之，赤诚天地可证。

而御命，便是代表此人承接天命，而这个天命，便是舍生取义的大道之行。

君奉天，奉天而行，天道之行，君奉天便顺天而为，贯彻正义，对抗所有逆境难关。

（摘自霹雳会刊260期封面人物 2017年4月刊）身份介绍法儒无私：执法者，必须无情无私。

现今在儒门内，要设计一个类似执法者的角色，编剧首先就是想到“法”这个字，法儒无私，带出称号，也带出原则。

法儒是一个称呼，而无私是一个原则。

法儒无私四个字，简单扼要，表明此人所处的立场，必须随时处于无情无私的状态。

编剧设定德风古道的后方，有类似少林寺十八铜人阵的秘密机构。

特别之处，在于昊正五道各自独立，不分上下。

也就是五儒之间，其实各有所长。

其中正气凛然，勇猛果敢的代表人物，便是法儒无私。

（节选摘自霹雳会刊260期封面人物 2017年4月刊）（整理备注：斩魔录45-46集，为救玉离经，君奉天辞去法儒无私一职，离开德风古道。）仙门少主/鬼族皇子：君奉天为九天玄尊与鬼后魙天下所生，为人鬼之子的特殊体质。

同时身负神皇之气与鬼族皇脉之力。

这两种互相冲突的力量使他自小受尽折磨。

后经过九天玄尊的教导与严苛训练，修炼出可以控制力量的阴阳双极体。

角色雏形君奉天从单锋罪者的悬案开始，德风古道便陷入了追查嫌犯，却无计可施的困境。

玉离经身为一方主事，不能轻易动手。

而借着这样的过程中，无疑成了法儒无私登场的最佳时机。

要说编剧总是替角色创造命运，这次却是编剧被角色的气质牵着鼻子走了。

因为这颗偶头太特殊，实在让笔者看到他，就有一种很深刻的感觉，这个人非常的纠结，刚正不阿，故事非常多。

很多心酸都往肚子里吞，原本故事的厚度，都不足以匹配他那充满英气的眼神扫过。

在做造型的过程中，笔者最少去看了十几次，都是在感受聆听，这个角色想要的是什么？

你的故事是什么什么？

你的背景是什么？

你的未来又会是什么？

原本空洞的脑袋，不知道为什么，越来越有影响与想法，而故事也一一浮现出来。

（节选摘自霹雳会刊261期 编剧漫谈2017年5月刊）性格君奉天君奉天不喜喝酒惯喝茶，因为他不想忘记自己所犯的过错，不停的提醒自己的过失。

关于设计君奉天的诗号，为充分呈现出此人的个性与胆识，以“正天地所不正”开头，导正天下歪曲之事，呈现君奉天做事的风格与手腕。

判黑白所不判，代表君奉天刚正不阿的信念，犯人鬼所不犯，呈现的是君奉天的过人胆识。

破日月所不破，则是呈现出君奉天绝对高强的武力，足以使日月动容，一怒震天下。

为了让德风古道能有一个强力的后盾，作为第一先锋的角色，法儒无私的写法跟铺陈当然得塑造出前所未有的绝对强势风格。

以强压性的武力、根基，每次都能强压对战的敌人，无论对手是谁，君奉天都是绝对强悍，第一、不吐血，第二、不后退，第三、不败北。

对于君奉天是否该来几场高规格武戏，编剧的答案很简单，不需要，因为他打架很少动手动脚，简单几招，就能展现他真正的威力。

我只求他举止之间不要失格，帅气、霸气即可。

搭配着个性、气质，塑造出一派顶级武力先天的感觉，刚柔并济，通情达理，英雄侠骨，勇往无惧，具备这四种特质，是编剧最希望观众能感受到的君奉天。

（节选摘自霹雳会刊261期 编剧漫谈2017年5月刊）

## 角色形象

造型法儒版造型：编剧最早看到君奉天的偶头时，印象就非常深刻，当初一看到这张脸，有种脸胖胖，却充满浩然正气的感觉，不苟言笑中带著威严，令人感到一种折服的英气。

于是在人物定案后，编剧就决定选择这颗偶头，而且这张脸非常的纠结，有一种说不出来的苦闷的感觉，似乎让自己处于非常紧绑的情绪下，难以释怀。

编剧希望造型师呈现出君奉天个性上的一丝不苟，还有浩然正气，包括儒门超强先天，白发，不花哨的特点。

### 武器道具

正法剑武器简介：君奉天的武器，曾与神谕同为九天玄尊双剑之一。

充满正气的古铜色泽映照剑格处，剑身能见凌厉锋芒。

平时不轻易出鞘，但一出鞘则代表着执法正义、法儒无私。

设计理念：编剧在与道具组为法儒兵器讨论时，希望呈现出角色的个性与原则，就是希望简单不复杂，因为法儒君奉天是一个一板一眼的人，这把剑的存在，是要衬托他的个性。

编剧只希望一把简单造型的剑，而不用过于精致的设计。

道具组也做出了很棒的正法，背在法儒的身上，衬托出更有威严的气质。

（摘自霹雳会刊260期封面人物道具介绍 2017年4月刊）至衡律典：这本律典有一个很特殊的设计，它代表着法儒无私的地位，也是君奉天固定手持物品。

律典本身，等于接任法儒无私这个称号者，得到的代表物品。

而律典之中，一片空白。

空白的律典，代表律法自在心中。

心无法，法便无用；

心有法，何须律典？

（摘自霹雳会刊260期封面人物道具介绍 2017年4月刊）（整理备注：律典在剧中曾因君奉天卸任法儒一职而交还儒门，继任法儒死后重回君奉天手中，霹雳魔封60集由玉离经正式赠与君奉天作为留念）罪罚：君奉天的武器。

首次出现在被带往阎神殿的君奉天鬼魄身上（霹雳魔封），在后续剧情中，化身为虎魁天虓皇的君奉天也在战斗中使用过这柄剑（霹雳侠峰）。

为对抗太曦神照极招，君奉天豁尽全力抵抗，最终裆下太曦极招，但正法、罪罚双剑难承巨力双双折断。

### 主要人际关系

父亲：九天玄尊博学广识，霸气威严，武学仙术修为已臻顶峰的先天高人，一手创建云海仙门，点育英才无数。

在神州遭逢末日劫难时，挺身而出，召集各方高手前往示流岛，弭平厄祸，而后更钦点天地人玄黄三乘，维护三界和平。

孰料，却意外死于自家门派之中，凶手一直无法追缉归案，然而随著谜团的抽丝剥茧，玄尊之死的真相却越来越扑朔迷离。

女人能的，男人也该能！

魙天下师兄：天迹天地人三乘之一，傲立仙道之巅，实力深不可测的顶先天。

性格风趣巧慧，关键时刻慎谋能断，但大部分时候，作风潇洒随意，不按牌理出牌，常有让人跌破眼镜的表现。

虽隐于仙脚之巅，但仍关心武林事，先遣秦假仙驾风乘云驹入江湖，在天堂之门开启后，天迹也正式入世，与地冥相互制衡。

本名：玉逍遥云海仙门的大师兄，幽默风趣、好笑语，年纪轻轻即出类拔萃，修为已是顶尖，两人合称奉天逍遥，与君奉天追查鬼麒主下落多年，誓要严惩血河战役元凶。

天迹小师弟：迹君-云徽子个性看似迷糊，其实是高深莫测的仙门领导，大智若愚、不轻易显露锋芒。

多年前，云海仙门生变，奉天逍遥先后离开，云徽子在动乱之际，承接领导之位，以迹君为名，维系整个云海仙门的运作，并陆续收受英才教育。

云徽子小师妹（情感）：玉箫出身云海仙门，奉天逍遥的小师妹，温柔婉约、气质不凡，对二师兄君奉天青睐有加。

昔日血河战役，玉箫与师兄一同追查鬼麒主途中，发现尚在襁褓中的玉离经，心怀恻隐而带回抚养。

后来死于鬼麒主惨忍的手段之下，造成奉天逍遥心中莫大伤痛。

玉箫义子：玉离经现今德风古道之主，在应无骞死后被众人推崇接掌儒门，应外和内。

待人较为和顺轻松，但心思缜密，深谋远虑，看待正事则严肃审慎。

云忘归个性潇洒率性，气度不羁小节，行事有自己风格，大气和善，与众人交好。

云忘归二徒弟：邃渊儒门顶尖剑客，法儒君奉天之徒，与妻子席断虹代表儒门，与佛道二教之代表共同看守圣剑“天可明鉴”。

孰料，鬼麒主暗中布施诡计，圣剑被盗、佛道二教之人皆死，唯独邃渊夫妇存活，儒门遂成众矢之的。

最后，为证实自身清白，邃渊选择自尽而亡，遗留妻儿，而三教圣剑被盗一事也成悬案。

邃渊义妹：席断虹剑术高手，曾与斩年合招连破封剑塔九九八十一剑阵，却在即将登顶之际放弃离开，留名“封名录”。

而后加入儒门，被誉为儒门首席女剑客，与邃渊及佛道之人共同看守圣剑“天可明鉴”。

孰料圣剑遭窃，唯独邃渊夫妇存活，最后二人为证清白而选择自尽。

然而，席断虹并未身亡，被西武林神偷金剪刀所救，纳为二房；

后为查金剪刀死因以及洗刷邃家冤屈，再入江湖。

席断虹朋友：净龙云潇接天云关之主、玉琥宫之主的后代，身负净龙玉琥双魄之气。

在一次银宇风暴之后，被九天玄尊所救，为了报恩成为初代龙凤双护，与九天玄尊参与大小战事，共创仙门武典，文武双全。

后来在魔岳圣战之中，击退魔岳剑主，但也使得净龙遭受缔魔剑之伤。

养伤期间，负起照护幼儿君奉天的职责，一直到意外发生，净龙自愿被囚禁在幻海之渊，直到仙海灵兽卷再开。

净龙云潇朋友：灵雀九月虹朱雀灵乡女当主，本为一处不受时空限制的圣地，却被八歧邪神造乱之后，朱雀灵乡伤亡惨重，九月虹逃难途中，被净龙云潇所救，更被九天玄尊收编入云海仙门，成为初代龙凤双护，与云潇一同照护幼儿君奉天。

而当意外发生之后，九月虹自请与云潇一同遭受封印，九天玄尊答应，方使九月虹与云潇被封印至今。

君奉天

儒门剑客宗师，剑法造诣顶尖，为墨倾池、玉离经等人的前辈，尊号“法儒无私”。身背刚正法剑，手托至衡律典，个性耿直，刚正不阿，不容任何邪恶之事，正气凛然，原则为上。原在德风古道的昊正五道内守关，因单锋罪者一案再掀儒门风波，受玉离经携众请托，现身援助。君奉天出自云海仙门，乃九天玄尊与鬼后魙天下之子，云海仙门的正统继承人。

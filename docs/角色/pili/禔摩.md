# 禔摩

================================================================================

《霹雳布袋戏》系列剧中登场人物禔摩是《霹雳布袋戏》系列中登场的虚拟人物，别号“冰爵”，由黄文择配音。作为嗜血族阇皇一脉第二强者，他与西蒙构成生命共同体，效忠于西蒙，善用藏有锐利西洋剑的钻石权杖，剑身冰寒，全身银白装束，性格极端孤傲，行事凌厉决绝。曾因任务失败遭西蒙施以五十鞭刑，刑具特殊材质抑制其血族再生能力，刑后由绣锦娘照料，揭示其失去共同体印记的内心恐惧。

## 经历
冰爵禔摩  官方桌布冰爵禔摩，嗜血者阇城一脉的第二人，个性相当极端、爱憎分明，嗜血者特有的爱憎之心在冰爵禔摩身上表露无遗，只服膺阇皇西蒙一人。

冰爵禔摩本身武艺高强且擅使西洋剑，一旦变脸功力更是骤增，宛若一头疯狂噬人的野兽。

暗夜狩猎的禔摩，半路拦截剑君十二恨和段忍，禔摩以奇特罕见的西洋剑法、步法应对剑君和段忍挥织而成的剑网竟游刃有余，在被剑君的“剑武”打伤后禔摩瞬间变脸、凶性大增，狰狞血腥气息慑服四周，让剑君二人不寒而栗。

段忍首当其冲被杀，剑君五行剑阵奋力回击，无奈惨遭獠牙咬噬。

与疏楼龙宿至极一战，银杖剑挥出神魔斩疾向龙宿，岂料疏楼龙宿故意示弱让禔摩有机可乘，诱惑禔摩变脸以獠牙嗜血，但就在一瞬间，龙宿竟驱使内力使血液倒流，二人遂因此相持不下，禔摩虽察觉情况却早已无法脱身，全身精血遭龙宿反噬吸尽，直到东方日出一刻，禔摩也化为灰烬，造就龙宿不畏日光的嗜血者特性。

# 氐首赨梦

================================================================================

霹雳布袋戏虚拟人物同义词赨梦（《霹雳布袋戏》中的人物）一般指氐首赨梦霹雳布袋戏中的角色。氐首赨梦，红冕之王最忠心不二的部属，在鬼方赤命复活后回归红冕边城势力，誓死效忠赤王，愿为红冕边城霸业除去一切阻碍。手持如梦剑令，武学包含风字诀、冥字诀、魂字诀、残字诀等招式，出招时身法飞快，同时剑上铃铛会发出声响，似警示对手即将步入黄泉。强如森狱大太子玄膑，亦不敌赨梦之速度而败阵。赯子虚澹对其面容有着独特的眷恋，而赨梦的脸与鬼方赤命改换面容前的原本面容颇为相似。

## 角色设定

名称：氐首赨梦性别：男初登场：霹雳开天记之创神篇第12章退场：霹雳开天记之创神篇下阕第7章（死于阎王）根据地：红冕边城身份：红冕七元之一性格：在讨论关键问题时表现出在意与主动性，并曾率先表态。外貌特征：其面容与鬼方赤命改换面容前的原本面容相似，并曾引起赯子虚澹的眷恋。

## 角色能力

- **武器**: 如梦剑令铃剑武学：如梦剑令【风字诀、冥字诀、魂字诀、残字诀】

## 角色经历
红冕七元之一，赤王鬼方赤命最忠心的部属，天生五感残缺。

在鬼方赤命因参与深脑会议而下落不明期间，独自栖身于黑幕琳琅，并日日捉鸟为眼，设法探寻赤王的下落，赤王回归之后，乃以鸟识入魂，替代感官功能，方能正常行动。

而后首要任务便是与绿衣剑者地狱魅影连手对付道真双秀，氐首赨梦手持铃剑，施展如梦剑令，能扰人心神，杀敌于铃音催动之间，令双秀一时受制，不得不知难而退，另寻破解之法。

在《霹雳开天记之创神篇上阕》中，氐首赨梦曾以如梦剑令拦截对手，杀招即出，并与翠萝寒展开激烈交锋。

尽管鬼方赤命失去红冕王戒，然而在氐首赨梦的心目中，赤王才是红冕之主的不二人选，因此对赤王所下达的命令从无二话。

此外，赯子虚澹对氐首赨梦的面容有着独特的眷恋，两人之间存在暧昧情感。

究竟氐首赨梦能否帮助鬼方赤命一路铲除阻碍，成就独霸苦境的伟业呢？

## 角色人际

组织门派：红冕边城上司：鬼方赤命同伙：赯子虚澹（对氐首赨梦面容有独特眷恋，存在暧昧感情）、挽风曲、千玉屑、赮毕钵罗（红冕七元）

## 人物影响

赯子虚澹对氐首赨梦的面容有着独特的眷恋，曾戏言“你的美貌曾让吾戏言，你若为女子，吾必娶之为妻。”此外，赨梦的脸与鬼方赤命改换面容前的原本面容颇为相似。

## 相关作品

歌曲《赨梦》由孙敬凡创作，收录于专辑《霹雳英雄音乐精选五十五: 霹雳谜城之九轮异谱 (电视原声带)》中，该专辑于2015年8月21日发行。

# 近神人一页书

布袋戏剧《霹雳天命之战祸邪神Ⅱ破邪传》中的虚拟人物近神人一页书，男，是霹雳布袋戏《霹雳天命之战祸邪神Ⅱ破邪传》中的虚拟角色，由黄文择配音。该角色为百世经纶一页书在地冥的协助下吸收并融合完整血暗之力后的强化形态，初登场于《霹雳天命之战祸邪神Ⅱ破邪传》第50章，后于《霹雳惊涛》第1章因体力不支恢复原形退场。在与破坏神厄祸决战中，近神人一页书通过武学"祸世七劫曜天华·万念血暗唯一击"摧毁其九成元神。其武器为可化现为三恒瞾世形态的诛邪圣剑。该角色在《霹雳邪章之道劫龙战》第21章留招消灭厄祸后消散，最终退场。主要诗号为"世事如棋，乾坤莫测，笑尽英雄"。

## 出场诗号
世事如棋，乾坤莫测，笑尽英雄。

六道同坠，魔劫万千，引渡如来。(魔化时)

## 相关身份
一页书为佛教高僧，法号梵天。首次出场于〈霹雳异数〉第16集。在剧情中屡次帮助素还真或携手共同弥平武林狼烟、化解危机。

## 风格特色
身为佛门高僧，行事作风果决明快、妒恶如仇，铲奸除恶绝不手软，故有‘邪心魔佛’之称！为正道的精神指标及领导者之一，如一页天书渡化迷航众生，与众不同的百世经纶，半阖眼眸看尽世俗庸人，微扬嘴角笑尽天下英雄。

## 形象
一页书在霹雳布袋戏中始终扮演着非常重要的角色，其智勇双全的能力与以武林兴亡为己任的态度让许多人甘拜下风。

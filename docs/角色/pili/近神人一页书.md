# 近神人一页书

================================================================================

布袋戏剧《霹雳天命之战祸邪神Ⅱ破邪传》中的虚拟人物近神人一页书，男，是霹雳布袋戏《霹雳天命之战祸邪神Ⅱ破邪传》中的虚拟角色，由黄文择配音。该角色为百世经纶一页书在地冥的协助下吸收并融合完整血闇之力后的强化形态，初登场于《霹雳天命之战祸邪神Ⅱ破邪传》第50章，后于《霹雳惊涛》第1章因体力不支恢复原形退场。在与破坏神厄祸决战中，近神人一页书通过武学"祸世七劫曜天华·万念血闇唯一击"摧毁其九成元神。其武器为可化现为三恒瞾世形态的诛邪圣剑。该角色在《霹雳邪章之道劫龙战》第21章留招消灭厄祸后消散，最终退场。主要诗号为"世事如棋，乾坤莫测，笑尽英雄"。

**一頁書**，又稱「**梵天**」，外號「**百世經綸**」、「**邪心魔佛**」，是霹靂布袋戲之中的主要人物，在劇情中與主角素還真同為正道的兩大支柱。

- **檔案**: 一頁書.jpg

==人物介紹==

===出場詩號===
世事如棋，乾坤莫測，笑盡英雄。

六道同墜，魔劫萬千，引渡如來。(魔化時)

===相關身分===
一頁書為佛教高僧，法號梵天。首次出場於〈霹靂異數〉第16集。在劇情中屢次幫助素還真或攜手共同彌平武林狼煙、化解危機。

===風格特色===
身為佛門高僧，行事作風果決明快、妒惡如仇，鏟奸除惡絕不手軟，故有『邪心魔佛』之稱！為正道的精神指標及領導者之一，如一頁天書渡化迷航眾生，與眾不同的百世經綸，半闔眼眸看盡世俗庸人，微揚嘴角笑盡天下英雄。

===形象===
一頁書在霹靂布袋戲中始終扮演著非常重要的角色，其智勇雙全的能力與以武林興亡為己任的態度讓許多人甘拜下風。

===人際關係===
*化身：紫錦囊、宇宙神知、創世狂人、罪惡之身、步懷真、問天敵(偽)
*同修：眾天、輔天 （與梵天合稱「滅境三天」）
*徒弟：靈心異佛、業途靈、截顱(創世狂人時期所收之徒)、小無慾
*隨從：跨限怒佛、悟僧癡迷
*朋友：慈航渡、武皇、霧谷老人、海殤君、素還真、崎路人、葉小釵、歡喜佛、空劫、莫召奴、天魔、劍魔傲神州、醉劍東岳、淨琉璃、佛劍分說、劍子先跡、疏樓龍宿、一步蓮華、蒼、九界佛皇、擎海潮等等
*宿敵：問天敵、佛業雙身
*其他:魔化一頁書(霹靂震寰宇之兵甲龍痕)

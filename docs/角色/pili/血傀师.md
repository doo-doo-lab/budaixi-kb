# 血傀师

================================================================================

霹雳布袋戏虚拟人物血傀师是《霹雳布袋戏》中的虚拟人物，其真实身份为圣魔元史史官鬼觉神知的化身。他于鬼觉神知盖下止战之钥、时空静止之际出现，通晓武林秘辛，并利用众人因圣魔大战记忆被抹除的契机，以“血傀师”之名步入武林，意为制造血泪、操纵傀儡的幕后之人。血傀师策划阴谋，收集混沌五剑融合成春秋剑，挑动佛厉纷争，最终在霹雳侠影之轰动武林序章中被天踦爵所杀。中文名血傀师别 名玄玄配 音黄文择、刘琮（国语版）性 别男生 日2012.06.15（初登场）登场作品霹雳战元史之动机风云、霹雳侠影之轰动武林身 份鬼觉神知根据地辟兽天野、芙蓉山、候风玄窟徒 弟恶骨出场集数56集

## 角色背景

血傀师是鬼觉神知利用圣魔元史的力量蜕变而成。身为圣魔元史史官，鬼觉神知因厌倦职责，动用职权删除圣魔大战相关记忆，并改名血傀师步入武林。“血傀师”之意，乃是制造血泪，操纵傀儡的幕后之人。凭借删除记忆和圣魔元史赋予的“上帝视角”，血傀师对武林中人的底细了如指掌。

## 人物设定

名称：血傀师称号：玄玄诗号：玄玄鸿蒙造天劫，混沌世局操死生，血傀临世三界动，一念翻覆风云涌。初登场：霹雳战元史之动机风云 第7章（利用圣魔元史的力量，由鬼觉神知蜕变而成）退场：霹雳侠影之轰动武林 序章（死于天踦爵）根据地：辟兽天野、芙蓉山、候风玄窟血傀师图片身份：鬼觉神知

## 人物能力

武学：天丝血罗掌、三尸髓枯掌、铁山飘掌、翻掌光明毁·覆手黑暗灭、天罗步、蛛形留弓、阴阳双火、天熔掌、三尸血溶掌、邪衍五尸诀咒术：反色闇术、邪血·破劫、喉神有珠·混吾丹元暗体：蛛形暗体（修炼暗术所形成的暗体，其命门在右肋下三寸处，被野胡禅所破）铸造物：春秋阙所有物：三品长生珠、圣魔元史、半滴至佛佛血、臻武丸、阳火流铁、三机谶（与天踦爵交易而来）

## 主要经历

血傀师原为记载圣魔大战历史的史官鬼觉神知，因不满职责，利用《圣魔元史》之能删除众人相关记忆后，化身血傀师步入武林。血傀师对武林众人的底细了如指掌，拥有上帝视角。他设计针对拥有混沌五剑（太易、太始、太初、太极、太素）的剑客，通过交易与暗示，离间四剑剑客与天之佛的关系，并说服天之佛交出太素之剑，最终集齐五剑。血傀师将五剑融合铸造为天器【春秋】，赠予剑客意琦行，并暗示其斩杀魔头天之厉（邪九世）。意琦行得剑后将其更名为【春秋阙】并成功击杀天之厉。此后，血傀师曝光天之佛破戒生子、以血肉筑墙等过往，引导苍生仇视，导致天之佛被杀。在天之佛、天之厉均亡后，血傀师意图掌控局势，但被天踦爵以“世界讲平衡”之理警告。血傀师自恃拥有三品长生珠，不惧意琦行的红炉点雪和一页书的大梵圣掌，但最终被天踦爵以“轰动武林”之招击败，厉掌加身而亡。天踦爵感叹“一代版本一代神”。血傀师死后，《圣魔元史》本体走向台前。

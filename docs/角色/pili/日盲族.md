# 日盲族

================================================================================

《霹雳布袋戏》剧中登场组织日盲族是《霹雳布袋戏》中登场的夜行战族组织。

该族深居半壁山河底下的阿虚夜殿，以五窍心血传承的圣女祭司为宗教核心，崇拜太阳神并视素还真为偶像，坚信太阳之子将带来光明。

组织以军事行动著称，成员恪守祭司指令，千叶传奇降临后展开积极扩张，通过迁移日罗山对抗死神势力，并治愈族人千年顽疾使其能在日间活动。

曾遭设计几近灭族，后因彻底覆灭，大祭司退隐前向素还真传递关键信息。

作为能透视魖族的特殊种族，日盲族兴衰与千叶传奇命运紧密交织，其权力更迭折射出武林势力博弈的残酷性，既展现夜族传统战力，亦凸显信仰体系与现实冲突的悲剧色彩。

中文名日盲族活跃时期霹雳神州Ⅲ之天罪、霹雳天启、霹雳震寰宇之刀龙传说、霹雳震寰宇之龙战八荒基 地半壁山河、阿虚夜殿、日罗山专 长善于行军打战奇珍异宝圆月无二、寄心虫、五窍心血特 色仅能在黑夜中视物、唯一能看到魖族的种族

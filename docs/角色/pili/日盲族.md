# 日盲族

《霹雳布袋戏》剧中登场组织日盲族是《霹雳布袋戏》中登场的夜行战族组织。

该族深居半壁山河底下的阿虚夜殿，以五窍心血传承的圣女祭司为宗教核心，崇拜太阳神并视素还真为偶像，坚信太阳之子将带来光明。

组织以军事行动著称，成员恪守祭司指令，千叶传奇降临后展开积极扩张，通过迁移日罗山对抗死神势力，并治愈族人千年顽疾使其能在日间活动。

曾遭设计几近灭族，后因彻底覆灭，大祭司退隐前向素还真传递关键信息。

作为能透视魖族的特殊种族，日盲族兴衰与千叶传奇命运紧密交织，其权力更迭折射出武林势力博弈的残酷性，既展现夜族传统战力，亦凸显信仰体系与现实冲突的悲剧色彩。

## 来自百度百科的补充

### 组织背景

日盲族是传说中的夜行战族，深居半壁山河底下的阿虚夜殿，组织充满浓厚的宗教色彩，以五窍心血一脉传承的圣女祭司为尊，崇拜太阳神，视清香白莲素还真为偶像，深信太阳之子将为日盲族带来光明与希望。

该族特色为仅能在黑夜中视物，同时也是唯一能看到魖族的种族。

日盲族虽以骁勇善战著称，但组织资源相对有限，族中顶尖高手数量较少，在武林中通常与正道势力结盟，其目标在于争取在日光下的生存空间。

### 组织特色

族人骁勇善战，机动力强，恪遵祭司指示，不私斗，一切以兴旺日盲族为使命。

在太阳之子千叶传奇诞生后，其根治了日盲族千年以来的不解之症，使族人得以在太阳下生活。为抗衡死神太学主，千叶传奇曾将族中精锐迁移至日罗山。

### 组织架构与成员

日盲族的组织架构以太阳之子为最高领袖，下设祭司、长老、战将、护法、杀手等不同职能的成员。具体成员包括：太阳之子为千叶传奇；祭司包括日盲族大祭司、释女华（圣女）；长老为铁干戈；战将包括万古长空、鹰无眼、燕啼红、银绝、龙彪、虎翼；护法包括罗生夜、虫父卵；杀手包括狼之翳（以刀爪为利器，随身豢养一群兽人，个性阴沉而饕戾，让人不寒而栗。受聘狮子国追杀十二兰灯，出手狠辣，以奇毒和兽人制造混乱，伺机伏袭）、樱尸鬼、簑虫翁；其他成员为不见荷（不见荷昼伏夜出，为了取得药材医治长心，夜间便化身杀手月杀，为玉阳君办事）。

### 组织历史

日盲族曾遭三面长城玉阳君设计，几近灭族。玉阳君为算计圣狮王朝取得息壤等物，并假意欺骗火中雪与释女华之感情，策划了日盲族惨案。

日盲族被灭后，残民戮力密谋复仇，经大祭司测算下找到拯救日盲族的希望，竟是清香白莲素还真的身影；众人前往魔界迎回莲花，孰料取回的却是因魔气所产生的影子…黑莲，黑莲逐渐孕育成形，成为日盲族认定的救世主千叶传奇。在此期间，伏龙先生曾为寻五窍心血来访日盲族，并经历了神殿的考验。

夜族骁勇善战，机动力强，但却不私斗，恪遵祭司所下达之指示，一切以兴旺日盲族为使命；在太阳之子千叶传奇诞临后，积极的作风与手腕，让日盲族势力正式浮上台面，与朱雀殿、学海无涯等武林各大派别一别苗头，然而，日盲族家底薄弱，高手屈指可数。其崛起引起了朱翼皇朝与学海无涯的忌惮，东方羿与玉阳君遂联合计划，意图先吞并日盲族以免碍手碍脚。并且根治了日盲族千年以来的不解之症，让夜族能在太阳底下生活，而后为抗衡死神太学主，千叶传奇更将精锐迁移日罗山，好让外界无法掌握日盲族实力。与此同时，日盲族内部亦生变故。族人不见荷（月杀）为取得药材医治长心，长期为玉阳君办事，最终选择回到朱雀殿，并即将对自己的族人兵戎相见。

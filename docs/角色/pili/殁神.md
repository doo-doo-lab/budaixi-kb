# 歿神 (殁神)
================================================================================

歿神

陰謀家慈海渡者的化身，藏身天鏡台，以六合武冊控制三分縫，試驗其武學新招，造就三強鼎立之局，一旦有人洩露六合武冊秘密，便派天鏡刑者殺之，造成三分縫的恐慌。曾自導自演慈海渡者平定歿神之亂，意圖擾亂歡喜佛等人判斷，好處心積慮陷害一頁書。

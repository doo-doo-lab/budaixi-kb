# 殁神

阴谋家慈海渡者的化身，藏身天镜台，以六合武册控制三分缝，试验其武学新招，造就三强鼎立之局，一旦有人泄露六合武册秘密，便派天镜刑者杀之，造成三分缝的恐慌。曾自导自演慈海渡者平定殁神之乱，意图扰乱欢喜佛等人判断，好处心积虑陷害一页书。

## 来自百度百科的补充

六合武册的创造者即为殁神，曾用“纸人运棺”一招试图获取一页书的尸体。在《霹雳狂刀》剧集中，曾有殁金僵假意悔过及被缉拿的情节。在《霹雳天命》与《霹雳狂刀》的剧情中，慈海渡者（殁神）均被列为反派角色。根据地另包括道境慈梵碇。

### 角色经历

#### 大智慧时期

原本是合修会一员，化名大智慧卧底七彩云天十五年，意图偷取九龙菩提经，事情败露后一直认为是一页书暗中告密，从此视一页书为仇人。由于任务失败，为躲避合修会的追杀，逃往道境修炼，直到能够随意改变自己的外形，化身慈海渡者与孤愁先生、欢喜佛交好。

#### 殁神时期

为报复一页书，殁神在一页书与人决斗时偷偷发请帖叫了许多百姓观战，导致一页书的天龙吼波及无辜，被七彩云天捉去判罪。最终殁神计谋败露被七彩云天收押。

#### 慈海渡者时期

后殁神继续化身慈海渡者行善，以此来干扰欢喜佛等人的判断。最后身份被不知名识破，从此改回慈海渡者的面貌行事。

### 相关作品

殁神（慈海渡者）登场于《霹雳英雄榜》、《霹雳狂刀》和《霹雳天命》等霹雳系列剧集。在《霹雳天命》中，他是反派角色之一。在《霹雳狂刀》中，他也作为反派出现，并出现在剧中情节如“殁神金僵假意悔过”和“缉拿殁神”。

### 人物影响

殁神（慈海渡者）在《霹雳狂刀》和《霹雳天命》等剧中作为反派和阴谋家出现。在《霹雳狂刀》中，殁神的行动如“金僵假意悔过”等情节是推动剧情发展的关键。相关情节增加了戏剧张力，被观众评价为“精彩与刺激络绎不绝”。

殁神的戏偶由著名雕偶师福师雕刻。殁神的戏偶造型风格“阳刚粗犷”，是霹雳布袋戏早期偶戏风格的代表之一，具有时代特色。

# 殁神
================================================================================

殁神

阴谋家慈海渡者的化身，藏身天镜台，以六合武册控制三分缝，试验其武学新招，造就三强鼎立之局，一旦有人泄露六合武册秘密，便派天镜刑者杀之，造成三分缝的恐慌。曾自导自演慈海渡者平定殁神之乱，意图扰乱欢喜佛等人判断，好处心积虑陷害一页书。

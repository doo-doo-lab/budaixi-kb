# 江一柳 (江一柳)
================================================================================

江一柳

聖城武官，劍術高超，乃人族聖皇妲眸姬的下屬。當年與妲眸姬結拜，為黑籠六義之一，是妲眸姬推翻爬族統治時的革命同伴。喜歡當官，是個官迷，從小夢想就是能當個大官，所以無時無刻都穿著官袍，收藏這些為官生涯的種種戰利品，對於官場之道有著自己特別的認知。

# 江一柳

圣城武官，剑术高超，乃人族圣皇妲眸姬的下属。当年与妲眸姬结拜，为黑笼六义之一，是妲眸姬推翻爬族统治时的革命同伴。喜欢当官，是个官迷，从小梦想就是能当个大官，所以无时无刻都穿着官袍，收藏这些为官生涯的种种战利品，对于官场之道有着自己特别的认知。

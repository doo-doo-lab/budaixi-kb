# 鸦魂（霹雳布袋戏虚拟人物）

鸦魂是《霹雳布袋戏》系列中的虚拟角色，由黄文择配音，初登场于《霹雳震寰宇之龙战八荒》第2集，退场于《霹雳经武纪之枭皇论战》第32集。

作为集境残宗副首领，其根据地设于血鸦山并伺机营救残宗领袖雄王，常以肩栖乌鸦为标志性特征，擅长武学包括风卷残木、无杀影及蛾空邪火。

鸦魂原为残宗副首领，曾安排求影十锋潜伏于太君治身边。

后因虓眼军督介入，与万古长空等人归顺破军府，被逐出集境后参与苦集联军。

经历兄弟十锋之死，心灰意冷投靠末世圣传，随后被魔王子强迫收徒修炼蛾空邪火。

在向魔王子复仇时因强行施展该武学遭反噬身亡。

角色性格冷峻低调，以血鸦作为侦查攻击手段，持有鸦魂剑与传命灯等物品。

其命运转折包含卧底失败、兄弟殒命、被迫入魔等节点，最终因执念复仇走向悲剧结局。

## 角色能力

合并图册武学：风卷残木、无杀影、蛾空邪火武器：鸦魂剑◎此剑是把袖里短剑，配合鸦魂急速身法故造型呈箭镞状。护手处有银色羽毛吊饰所有物：传命灯、蛾空邪火秘笈、皆杀者的忘情七绝真元宠物：乌鸦（血鸦、阿鸣）

## 角色配乐

◎鸦魂（鸦魂角色曲）曲/编曲：吴志晖 收录于《霹雳英雄音乐精选二十五》乐曲以“法阵”为创作题材，采用钹、唢呐等中国传统风味的乐器点缀演奏，以渐进感的编曲，浓厚的东方神秘氛围之中，缓缓带出刚劲威严的凛然气势。乐曲选用于鸦魂角色配乐。

## 角色经历
鸦魂求影十锋乃是他安排的潜伏在太君治身边的残宗卧底，但是其卧底行动最终仍然为虓眼军督所察觉，在军督答应以雄王取代圣帝之位后与万古长空、求影十锋一起投降破军府，后又因求影十锋被除名，甘愿与他被逐出集境，其实成为了集境与苦境联军中集境六成员之一。后因小弟之死而心灰意冷，投入了末世圣传。之后因魔王子与剑之初的赌约，被魔王子强收为徒，经过痛苦训练，练成魔王子绝招蛾空邪火，但本身功体只能使用一次，在与啸日猋一战后，试图报十锋之仇向魔王子使出第二次蛾空邪火，被魔火反噬而亡。

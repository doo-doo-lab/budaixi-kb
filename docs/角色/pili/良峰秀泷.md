# 良峰秀泷

================================================================================

霹雳布袋戏虚拟人物良峰秀泷是霹雳布袋戏系列中的虚拟女性角色，由黄文择配音，初登场于《霹雳开疆纪》第31集，身份为东瀛阪良城城主及太政大臣。作为良峰贞义之妹，她在兄长病逝后易容顶替其身份执政，为保护领地放弃与莫召奴的婚约及剑圣柳生剑影传授的武学。良峰秀泷曾收留鬼祭政权遗臣于落日故乡，在岩堂将军与真田龙政的政治斗争中周旋，促成柳生剑影与拳皇的对决，最终取代岩堂将军维持东瀛政局平衡。在莫召奴等人离开东瀛时，以真实样貌前往西海之滨送别。该角色通过伪装身份执政的经历，展现了以政治手段维护和平的决策力，最终退场于《霹雳神州2苍玄泣》第5集。中文名良峰秀泷配 音黄文择性 别女登场作品霹雳开疆纪霹雳神州霹雳神州2苍玄泣身 份阪良城城主、太政大臣来 自东瀛星 座双鱼座人物创作者三弦登 场霹雳开疆纪 31集退 场霹雳神州2苍玄泣 5集化 身良峰贞义（假扮）

## 人物经历

合并图册实际上真正的良峰贞义早已病逝，在剧中所出现者，乃是其妹良峰秀泷在兄长良峰贞义辞世后为保阪良城领地不被鬼祭将军收回而易容顶替。良峰秀泷当年乃是剑圣柳生剑影的得意弟子，被他称赞是绝代奇才，若能坚持剑道成就不限量，但是为继承城主，她不惜放弃习武跟师父翻脸，连跟莫召奴的恋情也放弃。在鬼祭政权被推翻后，后因不忍见鬼祭部属被岩堂政权所灭，接受莫召奴的请托，将鬼祭少主鬼祭宗煌5和遗臣权右将军等人收留于隐密的落日故乡退隐安居。当岩堂将军与真田龙政斗法时，虽然因为岩堂将军利用保全落日故乡之事威胁他投入其麾下，甚至被逼去杀害莫召奴，但良峰贞义仍与真田龙政保持联络，促成柳生剑影、拳皇长曾我部神权的对决，并于岩堂将军被真田龙政用计重创后，取代其地位，跟真田龙政维持东瀛政权的和平。“八山柱武决”后，“军神”源武藏与渊姬、莫召奴要在西海之滨出海时，曾以原样前往送别。

良峰秀瀧

良峰秀瀧是《霹靂布袋戲》虛擬人物。她是良峰貞義小妹，莫召奴的未婚妻，淡掃蛾眉、秀外慧中的才女，性情果敢堅毅，因兄長猝逝，為保護阪良城子民，甘願拋棄愛情與劍道，一肩扛起重任，化充良峰貞義代掌政務，政治手腕圓融，力求安定東瀛政局。

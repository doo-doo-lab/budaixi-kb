# 血刹如来

帝如来与鬼如来的综合体，历经双死双生剧变后，以“血刹如来”自称，能同时操使佛刑禅那与涤罪犀角，不属圣魔任何一方势力。受到种种因缘牵引，不再轻信他人，只以自身最深刻的体悟，劈开自我大道，行事目的与魔皇似有牵连。

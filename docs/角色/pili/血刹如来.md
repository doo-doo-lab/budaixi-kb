# 血刹如来

帝如来与鬼如来的综合体，历经双死双生剧变后，以“血刹如来”自称，能同时操使佛刑禅那与涤罪犀角，不属圣魔任何一方势力。受到种种因缘牵引，不再轻信他人，只以自身最深刻的体悟，劈开自我大道，行事目的与魔皇似有牵连。

## 角色背景

名言

吾非魔非圣，轻蔑三教，斩妖杀厉，
定法名－血刹如来！

## 武器

佛刑禅那、涤罪犀角

## 来自百度百科的补充

### 能力特征

**武学**：初禅三式、鬼禅六断、梵火天击、禅海雷音、孽罪怒佛·鬼嚎令、吾佛照灯印、魔皇武诀

**外形特征**：

佛刑禅那的刀柄处为炎红狮头造型，刀锷轴心镶入白水晶，造型呈火焰状。刀背处扣有六枚梵文状刀环，刀身主色为琥珀金，上刻纹路。前端饰有卍字法轮。

涤罪犀角的刀身蓝红，上镶蓝红钻石，犀角两旁有红色倒钩，刀身头一端有红蓝色尖角与鬼头，另一侧则是两鬼头相接，头顶尖角，刀锷乃是一血红宝石。刀柄亦有鬼头与尖角，红底黑字咒条系于刀柄后。

### 人际关系补充

**所发便当**：大愿普贤、定品、赤梧桐、古潇子、蕴果谛魂、寒山古刹一脉、瀛洲风藏府一脉

### 详细经历

血刹如来是帝如来与鬼如来的佛魔共识之体，在阇魇那迦的奔波策动下复活，历经双死双生的经历而蜕变，以"血刹如来"之态出现的新生体。既是帝如来和鬼如来，也都不是两者，能同时操使佛刑禅那与涤罪犀角，不属圣魔任何一方势力。

血刹如来因身负魔皇武诀，与阇魇那迦合作复活魔皇。而为让正道与厉族相互征战、以模糊众人对魔族的焦点，血刹如来多次介入正道与厉族的战斗中，帮助两方或多或少都得到过好处：血刹如来曾帮素还真杀除厉族的贪秽，后又闯入无尽天峰杀害佛乡的大愿普贤和定品。血刹如来更多次进入过一念之间欲杀鬼觉神知，却被蕴果谛魂阻挡，并受鬼觉神知血蠋所创而退。

后来，血刹如来依照阇魇那迦指示，取得炽心融合朱翼三魂，做好准备复生魔皇。魔皇复生后，巧遇鬼觉神知盖下止战圣印，所有人关于圣魔征战过往的记忆皆被忘却，血刹如来也忘了自己的存在如何而来，为回归自己所谓的"本相"寻找方法，受血傀师故意引导而到处屠戮寺庙，途中更击杀了欲超度自己的蕴果谛魂。在寻得《毁住藏经》修炼时，使善根罪业净化而让恶有机可乘，意识之境中的帝如来意识被鬼如来意识压制并夺得肉身控制权，血刹如来消失，回归鬼如来法相。

# 血剎如來 (血刹如来)
================================================================================

血剎如來

帝如來與鬼如來的綜合體，歷經雙死雙生劇變後，以「血剎如來」自稱，能同時操使佛刑禪那與滌罪犀角，不屬聖魔任何一方勢力。受到種種因緣牽引，不再輕信他人，只以自身最深刻的體悟，劈開自我大道，行事目的與魔皇似有牽連。

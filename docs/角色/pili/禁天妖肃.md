# 禁天妖肃

霹雳布袋戏虚拟人物禁天妖肃是《霹雳震寰宇之龙战八荒》中的邪灵战将，由黄文择配音。作为妖世浮屠十一天禁力量集合孕育的杀戮兵器，其银白战袍配兽角造型突显暴雪般迅猛身法，掌握天禁共创武学极荒邪破·七妖斩等招式。该角色自妖忏池苏醒后，通过吸收十一天禁阵亡者元气强化战力，曾以箭形气功暗袭佛剑分说解救被困佛业双身，参与阻截四龙齐鸣、进攻莫汗走廊等战役。在与火宅佛狱联合作战中，独自对抗破坏者与黯纪仲裁者，协助摧毁对峰壁通道。最终在万里狂沙遭复活的一页书以天龙吼绝招击杀，终结于《龙战八荒》第40集。

## 经历
禁天妖肃，一直沉眠于妖忏池的一具邪灵肉身，每当妖世浮屠精锐兵力十一天禁有人阵亡时，其灵魂元气便会容纳汇贯于这具肉身中，当佛业双身驾乘妖世浮屠和死国两败俱伤遭受枫岫主人、拂樱斋主、三先天等正道人士围剿时，在夜暴双镰、病色哀歌相继阵亡后，十一天禁最后残存者天堂之萼决定自我牺牲，掌盖天灵而亡，成就最终的禁天妖肃出关，解除邪灵危机，将天蚩极业、爱祸女戎救离现场。

在《霹雳震寰宇之龙战八荒》第31集中，为查枫岫神源，禁天妖肃与灭度双宗一同前往寒瑟山房。

禁天妖肃禁天妖肃不但纳有十一天禁力量，更练就天禁共创武学，论战力更胜灭度三宗，数次作为邪灵麾下大将出动，与火宅佛狱配合对正道展开攻击，意图杀上啸龙居摧毁漠刀绝尘、啸日猋与天刀·笑剑钝，但因为拂樱斋主未如火宅佛狱之意行动，四龙顺利齐鸣，而遭击退。

在邪灵和死国已结死仇的前提下，佛业双身企图帮助火宅佛狱开启在对峰壁的通道，禁天妖肃出战对上啸日猋，却无法阻止四龙齐鸣重创妖世浮屠力量。

在爱祸女戎考量火宅佛狱跟死国也有联盟关系，要求黯纪仲裁者一同进攻莫汗走廊，但在莫汗走廊中，佛业双身和禁天妖肃功力被压制七成，悉数战败于死国战神阿修罗，甚至邪说沦语阵亡。

佛业双身认为火宅佛狱在此战中，只有仲裁者一人参战，明显是首鼠两端的举动，因而破除盟约，挥兵攻打地狱口，禁天妖肃只身力战破坏者、仲裁者不落下风，顺利转移佛狱防守力量，上佛业双身摧毁对峰壁的火宅通道口。

随后邪灵回报剑子仙迹等十人已然前往莫汗走廊时，佛业双身决定守株待兔，在外准备趁虚而入，不意在追杀被震出莫汗走廊的剑子仙迹、佛剑分说两人时，被他们引入万里狂沙，复活重生的一页书骑大鹏鸟再现武林，一招天龙吼立时格杀禁天妖肃。

# 芙蓉骨

西南邙者，擅用蛊毒、利爪，形骸恐怖，轻功身法疾速如电，拥有穿墙透壁的特殊能力，与天来眼对翳流怀有很深的仇恨。

## 角色设定

芙蓉骨，是《霹雳布袋戏》中的虚拟角色，男性，由编剧罗陵创作，初登场于《霹雳兵燹之刀戟戡魔录II》第25集。

芙蓉骨为西南邙者，擅用蛊毒、利爪，形骸恐怖，轻功身法疾速如电，拥有穿墙透壁的特殊能力。根据地设于水泷影，与天来眼为同伙，专长使用蛊毒，武学包括芙蓉蚀骨、败魂骨指、化骨芙蓉。北辰元凰曾试图拉拢西南邙者，但芙蓉骨与天来眼对翳流怀有很深的仇恨并处于敌对状态。

芙蓉骨于《霹雳奇象》第12集退场，死于闻人千秋。

## 人物关系

敌对组织：翳流

## 角色能力

武学：芙蓉蚀骨、败魂骨指、化骨芙蓉；轻功：身法疾速如电；特殊能力：穿墙透壁。

专长：蛊毒；技能：擅用利爪。

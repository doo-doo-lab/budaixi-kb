# 鬼智 (鬼智)
================================================================================

鬼智

河圖十智首智，去向飄渺未定，其性深沉難以揣測，一概謙虛文雅姿態慣作嘲諷行為，言談中帶有絕對自信從容；谷嵇文太公為其啟蒙恩師，曾為玉龍隱士、夢鈴心同修，傳聞身亡已久，孰料一日再現形蹤，傾覆武林。

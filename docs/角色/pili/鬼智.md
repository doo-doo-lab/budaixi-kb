# 鬼智
================================================================================

鬼智

河图十智首智，去向飘渺未定，其性深沉难以揣测，一概谦虚文雅姿态惯作嘲讽行为，言谈中带有绝对自信从容；谷嵇文太公为其启蒙恩师，曾为玉龙隐士、梦铃心同修，传闻身亡已久，孰料一日再现形踪，倾覆武林。

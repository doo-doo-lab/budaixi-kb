# 一字鑄骨 (一字铸骨)
================================================================================

一字鑄骨

由鷇音子點名，秦假仙前往找尋的命中貴人，溫文且神秘，因一樁過去而失落了自己全身骨頭，故窮畢生歲月都在找尋自己的骨頭，卻苦無所獲；若有朝一日，當他將自己的骨頭收集完全時，又會發生什麼事？一字鑄骨的神祕，就連鷇音子也難以掌握。

# 一字铸骨

由鷇音子点名，秦假仙前往找寻的命中贵人，温文且神秘，因一桩过去而失落了自己全身骨头，故穷毕生岁月都在找寻自己的骨头，却苦无所获；若有朝一日，当他将自己的骨头收集完全时，又会发生什么事？一字铸骨的神秘，就连鷇音子也难以掌握。

## 来自百度百科的补充

一字铸骨是《霹雳布袋戏》系列中的虚拟角色，"初登场于《霹雳侠影之轰动武林》第22章，退场于《霹雳侠影之轰定干戈》第20章"。其真实身份为"黑海森狱若叶家族的若叶央措"。"他温文神秘，出生即无骨，依靠正法老者所赠的玉符鞋维持生命，并背负竹篓以捡骨埋尸为业"。

"一字铸骨具有清澈气质，特别是那双水蓝色的纯净澄澈的眸子"。"样貌清秀柔和，带有病弱之美"，"肤色苍白，唇色浅淡"，呈现"柔若无骨"的形象。

其真实身份为若叶央措，"因嫉妒说太岁而反叛，被阎王鞭打出全身骨头，临死前许下诅咒"。"以'一字铸骨'之名重生"，终生寻找自己失落的骨头。曾"帮助佛剑分说与裳璎珞破阵"，"成功游说烟都大宗师古陵逝烟"。最终"为救绮罗生与最光阴，命丧于暴雨心奴之手"。

# 玉阳君

霹雳布袋戏虚拟人物玉阳君，狮子国首席军师，擅权术谋略，机心深沉，曾以息壤覆灭贺兰王朝，却在尉迟骄雄兵败之刻抽身。

真实身份为方城子，为练就沙溶神法，迎娶释女华，设计火中雪、正亦邪等，灭日盲族与枉沙城，蛰伏幕后操弄一切。在俊美外表下，暗藏残戾的狼子野心。

## 人物能力

**◎特别介绍**：沙溶神法是一部存于枉沙城的武功秘笈，欲练此一武学须提炼出沙元甘露，组成要件极为复杂，其中的乱心蛊，须用日盲族的寄心虫炼成，方城子娶日盲族圣女释女华获得之，随后要练成乱心蛊的不熄火乃火中雪所有，方城子又花言巧语获其芳心，更利用徒儿正亦邪兄弟之心窍寄养。

诈死后遁往圣狮皇朝，用玉阳君的身份取得国宝息壤，并用息壤跟中原正道换得五窍心血，最后用协助破坏众天转生的条件跟未来之宰换取定元珠，稳固化沙后的身形。

但沙溶神法的唯一破绽就是沙粒中有颗红色细沙，乃是使用者定住元神，居中操控沙爆杀人的关键。

千叶传奇便是攻破这点，使玉阳君元气大伤。

## 人物恩怨

**利用之人**：
- 火中雪：得到不熄火（炼乱心蛊用）、借其妒恨之心与释女华反目而灭日盲族
- 慕非白：灭日盲族、帮助完成一系列阴谋
- 织语长心：使其戴上罗喉戒玺成为武林共主，实际上幕后操控、利用长心
- 不见荷：利用不见荷想治好义妹长心心疾的愿望使其甘愿成为杀手，为自己卖力，得到五窍心血
- 正亦邪、邪亦正：孵出乱心蛊、诈死再改装成玉阳君
- 尉迟骄雄：成为狮子国首席军师玉阳君，得到息壤，见其无称霸天下之心后在狮子国兵败时抽身杀死尉迟骄雄，并用其武器权柄，得到漆雕不朽的遗作铁甲神兵
- 梦花者：监视邪亦正、得到无根花与正道交涉，完成后将其灭口
- 枉沙城：得到沙溶神法秘籍之类的东西
- 日盲族：得到寄心虫（用不熄火炼成乱心蛊），从圣女释女华得到五窍心血

**所害之人**：
- 组织：枉沙城、狮子国（圣狮王朝）、贺兰王朝
- 个人：火中雪、释女华、正亦邪、邪亦正、梦花者、秋水先生、慕非白、尉迟骄雄、雅僧佛公子、不见荷等

**报仇之人**：
- 为火中雪报仇：狂河冰烈、不二做（与太史侯等六人联手，玉阳君败，狂河冰烈伤）
- 为枉沙城报仇：问剑孤鸣、沙克汗（玉阳君伤）
- 为浩然双峰报仇：狂河冰烈、问剑孤鸣（同上）
- 为佛公子报仇：曲怀觞、太史侯、秋水先生（与狂河冰烈等六人联手，玉阳君败，秋水先生亡）
- 为日盲族、释女华报仇：千叶传奇、万古长空（玉阳君亡）
- 为自己以及邪亦正等被玉阳君所害之人报仇：火中雪（火中雪亡）

## 角色经历

三面长城玉阳君，本名方城子，练有赤地之招，擅长剑法、医术以及谋权之道。

其手段残忍毒辣，为达到目的可以牺牲自己的妻女、挚友为筹码，相当自私、虚伪。

玉阳君方城子因觊觎枉沙城绝学沙溶神法而入城屠杀夺宝，并算计替枉沙城伸张正义的浩然双锋仇戴天、岳云乐反目互击两败俱伤。

要练成沙溶神法，需有沙元甘露，而沙元甘露是由乱心蛊以不熄火炼成。

方城子欺骗身怀不熄火的女剑客火中雪的感情，和其结为夫妻以达到目的。

又以帮助日盲族重见天日为条件千方百计迎娶了日盲族圣女释女华，得到寄心虫。

玉阳君伪造丹炉颠覆把乱心蛊投入徒儿正亦邪与邪亦正体内，同时为绝后患，方城子利用司徒偃打造机关城，并利用火中雪对其脚踏两只船的愤恨之情与释女华反目并屠杀日盲族，又安排慕非白、邪亦正、水飘蓬等人为杀手将日盲族杀得血流成河。

事后，方城子借由乱心蛊探知正亦邪对火中雪的不伦爱恋与邪亦正对自己的不满，遂设计正亦邪和火中雪发生关系，逼走火中雪，再用替身被邪亦正杀害，顺势诈死。

又暗地里还用织语长心内疾药物，威胁水飘蓬、女儿不见荷担任杀手月杀为己效力。

因沙元甘露要素之一息壤便在狮子国，方城子诈死后改名玉阳君投入圣狮主尉迟骄雄帐下，位列圣狮皇朝首席军师，趁贺兰王朝内乱，用息壤造桥攻打，并促成徒儿邪亦正为贺兰有思所用，以赤地之招偷袭凤凰鸣，帮助狮子国消灭贺兰王朝，随后引荐一谦师、五方通加入圣狮皇朝，壮大皇朝实力，因而深受圣狮主信赖。

为追杀十二兰灯，玉阳君也透过他对日盲族的了解，用息壤挽救地层崩陷的危机换得日盲族支援，当邪亦正伤及脑门失智后，安排梦花者照料，以便随时再启兄弟互残之局。

在伏龙先生为求息壤而来时，玉阳君于谈判中大占上风，促使其为自己达成十二兰灯投降、杀死邪亦正以及沙元甘露另一要素五窍心血等条件，当伏龙先生顺利说服十二兰灯来后又假意中兰九阳鸿门宴之略，与圣狮主内外呼应大破十二兰灯，并收买月杀除去兰灯排三的慕归心，后弃天帝之祸平息，又与老友慕非白，部署梦花者等人参予武林大会得知三宝之事，玉阳君试图说动圣狮主加入抢夺却不果，后来在花无蝶、不死鸟漂驱使钢铁神兵杀入王殿时刻意抽身，玉阳君还杀死圣狮主后夺取宝剑权柄，为来日控制另外几具钢铁神兵作准备，同时招收身怀九九命格的织语长心为徒。

正当此时，因为凤凰鸣的安排，对弟弟失望至极的正亦邪决心大义灭亲，却正中玉阳君下怀，趁机引动乱心蛊完全成熟，将之吸入体内加以从未来之宰处以相互协助换得定元珠稳住身形，并辣手杀死两名徒弟。

然而邪亦正拖着最后一口气告知火中雪真相后，此人便竟牺牲部属梦花者意图用黑邪毒流施予暗算，此计落空后便亲手以沙溶神法杀死透过慕非白找上自己的火中雪。

无乘载道获取罗喉戒玺后，玉阳君说动情人神母瑶姬，共同拥戴织语长心成为武林共主，建立朱翼皇朝，却未料戒玺上死神之力太强，本想将织语长心置为傀儡的玉阳君当真沦为朱翼皇朝不二之臣，竭尽心思助长心夺得希望号角与巡视各地招募部属。

而日盲族太阳之子千叶传奇降临后，首当其冲也是要对付本族大仇玉阳君，在迫降慕非白后，用他引出玉阳君，并以伏龙先生、太史侯、秋水先生、狂河冰烈、不二做、慕非白六人围攻，可是仍被玉阳君仗着沙溶神法击毙秋水先生与慕非白遁走，但隐在山间的千叶传奇已开始观测沙溶神法之奥妙与缺失。

织语长心未有主见之际，玉阳君尚可任意指挥朱翼皇朝所有势力，甚至和东方羿勾结进攻日盲族，却因千叶传奇安排得当，反破去玉阳君设计的聚阳车而全军溃败。

当织语长心借由希望号角往见死国之神而心性大变后，受戒玺魔力影响的玉阳君依旧尽心尽力为织语长心效劳，先替她洗去希望号角上的魔力，以防后患，后又使用沙溶神法替疏楼龙宿修补神柱，救回佛剑分说与剑子仙迹，然而，虽然还欲安排三先天加入朱翼王朝却因疏楼龙宿早有防备而未成功，奉命刺杀千叶传奇时又被他协同万古长空，利用旋风谷的地形阻住沙溶神法威能而失败，女帝因他屡次未讨得敌方便宜渐生不耐，遂欲杀死释女华予以打击，玉阳君虽因揣测形式持有异议，但终于被罗喉戒玺之能压过答应完成任务。

但在此计收得成效前，千叶传奇已经联合央森、金好牙，在金好牙进贡金锦玉手时，突然发难夺去罗喉戒玺，玉阳君追之不及，在回殿后惨遭织语长心掌掴折辱，甚至安排杀局对付万古长空时，长心也拒绝玉阳君让自己埋伏在最后一线的提议，改用明珠求瑕负责，也未再予其派遣其他助力。

在确认千叶传奇是夺取戒玺主谋后，本欲消灭之，却不料千叶传奇获天不孤相助医治全族日盲之症，将日盲族全数撤离半壁山河，因此才转移目标歼灭学海无涯，结果在第一阵被诱入司徒偃设置的机关中损兵不少，但玉阳君适时用权柄指挥钢铁神兵参阵摧毁机关，逆转劣势逼近学海三里外，但却被东方羿施展威力强大的驭日神箭重创军势，只好缓冲一日再攻。

但在夜里，日盲族及时驰援学海，全军大败，他被千叶传奇看穿沙溶神法破绽重创，狼狈逃回朱雀殿，并安排长心撤往东武殿。

然而织语长心不满地解除他身上罗喉戒玺的禁锢，当玉阳君醒觉自己平白遭到长心利用后，意欲杀她泄愤，不料却被长心暗中收服的东风怒雪、神乞何复求、柳竹公三人横阻，当长心命令三人退开后，又以最后气力运赤地之招要杀织语长心，却被织语长心用死国之神所赠的力量所杀。

# 火文十字

性火如烈，嗜杀如狼，乃六道神兵府三恶道中“地狱道”之主。此道以地狱业火结合枪为特色，火文十字脸戴鬼面具，手持十字火炼枪，招式以火为主。地狱道之炼枪、饿鬼道之鲨戟、徬生道之铁盾，三者能组成攻防兼具之阵术，互补短长、威力无穷。

# 火文十字 (火文十字)

火文十字

性火如烈，嗜殺如狼，乃六道神兵府三惡道中「地獄道」之主。此道以地獄業火結合槍為特色，火文十字臉戴鬼面具，手持十字火鍊槍，招式以火為主。地獄道之鍊槍、餓鬼道之鯊戟、徬生道之鐵盾，三者能組成攻防兼具之陣術，互補短長、威力無窮。

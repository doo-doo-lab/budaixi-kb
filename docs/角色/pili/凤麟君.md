# 凤麟君

七曜定尊会执首，凋亡禁决主持人。以谋求武林和平为诉求，发起凋亡禁决，让台面上众多龙头、组织皆参与其中，竞逐天下共主。为人机警深沈，言谈中善于打太极，转移焦点分化他人对其举办凋亡禁决的用心。

## 来自百度百科的补充

凤麟君，霹雳布袋戏中的角色。

主要经历：凤麟君作为七曜定尊会执首，以谋求武林和平为名，发起并主持凋亡禁决，邀请各方势力参与，以猎杀辟命敌的方式竞逐武林至尊之位，并承诺胜者可获金狮帝国宝藏。在盘龙顶曾遭遇围攻，陷入苦战。后与超轶主会面，告知对方自己并非凋亡禁决的真正主使者，只是受人所托；超轶主则怀疑幕后元凶是东皇戚太祖。

相关人物：超轶主（曾参与凋亡禁决，对其主持凋亡禁决的动机和身份有所质疑）

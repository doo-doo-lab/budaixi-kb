# 鳳麟君 (凤麟君)
================================================================================

鳳麟君

七曜定尊會執首，凋亡禁決主持人。以謀求武林和平為訴求，發起凋亡禁決，讓檯面上眾多龍頭、組織皆參與其中，競逐天下共主。為人機警深沈，言談中善於打太極，轉移焦點分化他人對其舉辦凋亡禁決的用心。

# 凤麟君
================================================================================

凤麟君

七曜定尊会执首，凋亡禁决主持人。以谋求武林和平为诉求，发起凋亡禁决，让台面上众多龙头、组织皆参与其中，竞逐天下共主。为人机警深沈，言谈中善于打太极，转移焦点分化他人对其举办凋亡禁决的用心。

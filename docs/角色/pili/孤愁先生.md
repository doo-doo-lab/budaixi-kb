# 孤愁先生

霹雳布袋戏虚拟人物孤愁先生，霹雳布袋戏虚拟人物。学识丰富，表面上爱好和平，实为合修会在道境之暗椿。身份莫测，曾让素还真为探其底细而与之下棋、斗智。培植杀手一刀起程、利用九龙图与九五至尊之说企图混乱武林。尔后与素还真一场大战中见识到其武学之深不可测后气势大失，终至败亡。

血溶掌分为阴血溶掌、阳血溶掌。

被阴血溶掌击中者，由身体内部开始毁坏，从外表是看不出来。

而阳血溶掌正好相反，被击中之人会由外部开始消溶。【行体流线】道教秘学。

先以丝线绑住敌手，而丝线会慢慢没入体内，最后完全进入体内，中招者会因此全身痛苦不堪。【百川汇宗】远生道最上乘的武学，施展此招时，最大的特点即是头部会隐形不见。【阴阳两极】【翻山倒海】【千层剑法】【破象刀法】【一刀起程】【元神出窍】孤愁先生和素还真对战时所用之武功。

**孤愁先生**是台湾霹雳布袋戏中的人物，在霹雳紫脉线第5集 ，殁于霹雳狂刀第11集 。

==生平==
与欢喜佛、慈海渡者并称为道境三大高人，在玄宗重现之前是道境唯三的居民，名列六圣会之一，曾以行体流线教训盗去行体流线的秦假仙。长年修行于观道院，曾收鬼智灵童为徒，医好叶小钗的双眼。面上爱好和平，实为合修会的暗椿。在一页书天河运棺之役时与素还真下棋、斗智，牵制其前往援救，并且一度元神出窍逼出素还真体内的龙气。

早年在和慈海渡者分送九龙册和九龙图予尘界九龙后，设计安排扒去金小开、小霸王的脸皮，将之培植成杀手一刀起程以杀除九龙，完成无敌战龙现世的必要条件，同时以百川汇宗一招掩去容貌在龙末九身上刺下九龙图最关键的一幅，后利用九龙图与
九图合成九五至尊一说尝试颠覆武林。

尔后，在以血溶掌击伤龙末九后，与前来寻仇的素还真一番大战，被展露多项绝学的素还真重创，并断去一臂，虽被造世明灯所救而保住性命，但自此锐气尽丧、不复旧观。后来得知玄真君可医治金小开的脸，便前往试探，并以百川汇宗击杀玄真君门徒剑胆，被大怒的玄真君以“三分鼎足”射伤遁走。

在获得道教家谱道源时，被循线索追去，正逢同样觊觎道源的慈海渡者，被他以怒佛开膛指击毙。

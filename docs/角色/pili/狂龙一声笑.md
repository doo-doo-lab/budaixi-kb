# 狂龙一声笑

================================================================================

霹雳布袋戏虚拟人物狂龙一声笑是《霹雳布袋戏》系列中的虚拟角色，

**中文名**：源自人物

**本名**：由黄文择

**初登场**：于《霹雳兵燹之刀戟戡魔录》第21集

**身份**：为罪恶坑第一恶首，为练峨眉之弟

**诗号**：为“试问天下谁为狂？唯吾傲视武林空；一笑翻动江湖浪，狂龙出关堪称王”。身为罪恶坑首领，狂龙性格反复无常且残忍狡猾，喜食眼球，曾见邪魅之眼而称“此眼可吃半年”，惯用装疯卖傻掩饰算计，浑身纹身。曾伪装跛脚闯入残林争夺神器天泣，后与异度魔城阎魔旱魃合作，设计以金八珍为诱饵将练峨眉引至罪恶坑。曾现身萍山，以胡言乱语、装疯卖傻之态介入阎魔旱魃与练峨眉之战，实则意图维持双方平衡以利罪恶坑。杀害孤独缺、金八珍、蔺无双等角色，在获得锐感之缨后实力大增，最终被北辰元凰设计围攻，遭鬼梁天下偷袭毙命于《霹雳奇象》第1集。对姐姐练峨眉怀有超越姐弟的情愫，在练峨眉死后意图不轨，练峨眉自爆后更决定吞食其骨灰。该角色具有双重性格特征，既暴虐嗜杀又对练峨眉存在病态依赖。

**退场**：后由凌威接任罪首并保留其雕像

**中文名**：狂龙一声笑

**外文名**：A loud laugh of the dragon

**别名**：罪首

**配音**：黄文择

**性别**：男

**登场作品**：霹雳兵燹之刀戟戡魔录、霹雳奇象人物创作者三弦

## 人际关系

组织门派：罪恶坑姐姐：练峨眉（萍山不落地狂龙不出关）。狂龙对练峨眉怀有复杂扭曲的情感，称其为‘阿姐’、‘唯一的亲人’、‘今生最喜欢的人’，但其情感已异化为乱伦之恋，并最终为得到她而联合异度魔界间接导致其身亡，甚至意图吞食其骨灰。部属：伯藏主、破玄奇、向日斜、封千机、流剑谈月、应江潮、审官、判官、问死官、玄鹤子、火海丑陀、失魂客、金刀狩结义兄弟：阎魔旱魃（狂龙称其为‘最好的朋友’与‘兄弟’）。所发便当：孤独缺、金八珍、明镜秋霜、蔺无双坑死：阎魔旱魃、

练峨眉主要

## 经历
狂龙一声笑初登场于《霹雳兵燹之刀戟戡魔录》第21集，身份为罪恶坑之主，性格反复无常且残忍狡猾，喜食眼球，惯用装疯卖傻掩饰算计。

曾伪装跛脚闯入残林争夺神器天泣，后与异度魔城阎魔旱魃合作，设计以金八珍为诱饵将练峨眉引至罪恶坑。

狂龙一声笑现身萍山，扰乱阎魔旱魃与练峨眉决斗，其插手之战一方面是看出两人实力在伯仲之间，继续战下去一定是两败俱伤的局面，另外一方面也是因为萍山之下中原正道与异度魔界相互对峙，一旦分出胜负，狂龙一声笑所领导的罪恶坑都将会成为下一个被针对的目标，两面游走，四处取利才符合狂龙与罪恶坑的利益。

杀害孤独缺、金八珍、蔺无双等角色，在获得锐感之缨后实力大增，击杀蔺无双。

在阎魔旱魃之后，成为武林最大危机，也再度引动众人联合刀戟屠龙之计。

最终被北辰元凰设计围攻，遭鬼梁天下偷袭毙命于《霹雳奇象》第1集。

退场后由凌威接任罪首并保留其雕像。

## 相关作品

《霹雳奇象》：作为罪恶坑之首，在阎魔旱魃之后成为武林最大危机，引动“刀戟屠龙之计”。

## 人物影响

孤独缺、金八珍、蔺无双俱亡于其手，羽人非獍为报师仇时被其重伤，对抗异度魔界的中流砥柱一代道门先天练峨眉死于魔君之手也与他有直接关系。被分析者评价为具有“反社会变态自恋狂”特质的复杂反派。

# 叶口月人

================================================================================

霹雳布袋戏组织之一叶口月人，霹雳布袋戏中的虚拟组织，是由邪帝创造的特殊蓝血人种，因蓝血、头尖、发少等特征，居住于异幻之境“叶口之间”而得名。该族群以军戎体系立国，阶级地位与种族优越感显著，分为傩叶、氏叶、璚叶、锖叶四部，各部设执首统领及策宦、武冠等辅佐官职，并辖隶御司、兵戎司、𫘨骑司等部司，目标为完成邪帝统一天地人三界的遗愿。中文名叶口月人创始者邪帝辖 区玄空岛、叶口之间专 长高科技发明、工艺机械继任首领九幽结 局残部退回叶口之间

# 叶口月人

霹雳布袋戏组织之一叶口月人，霹雳布袋戏中的虚拟组织，是由邪帝创造的特殊蓝血人种，因蓝血、头尖、发少等特征，居住于异幻之境“叶口之间”而得名。该族群以军戎体系立国，阶级地位与种族优越感显著，分为傩叶、氏叶、璚叶、锖叶四部，各部设执首统领及策宦、武冠等辅佐官职，并辖隶御司、兵戎司、𬴂骑司等部司，目标为完成邪帝统一天地人三界的遗愿。中文名叶口月人创始者邪帝辖 区玄空岛、叶口之间专 长高科技发明、工艺机械继任首领九幽结 局残部退回叶口之间

## 来自百度百科的补充

叶口月人是邪帝所创造出的特殊人种（即外星人）。因蓝血、头尖、发少，居住于异幻之境叶口之间，故名叶口月人。叶口月人由邪帝及其传人领导统驭，辅权则从旁协助，其下共分为四支部族，分别为傩叶、氏叶、璚叶、锖叶，这四部独立自治，以执首为领导，设有策宦和武冠，分别为文武二辅佐官，下有隶御司、兵戎司、騠骑司等各部司寇，兽、虫等其它种族则沦为奴役，充分显现叶口月人以兵马立国的军戎体系，以及强烈的种族优越感，更以完成邪帝遗愿，统一天、地、人三界最终目标。

基地/辖区：玄空岛、叶口之间

交通工具：龙首幽舻、祭月幽舻、拜月幽舻、焚月幽舻、炼月幽舻

奇珍异宝：幻心甲、天霓网、旱地雷、指路针、异形蜘蛛

### 傩叶部

执首：卧江子(前任执首苏扬傩叶)、王隐(执首)、猊戬傩叶(代执首)

其他人员：骈章傩叶、袂雪傩叶、平壤傩叶、鹫羽傩叶等人

代表颜色：蓝色

幽舻：祭月幽舻

叶口月人当中，算是最主要出现的一部，从擒捉夜岸鬼僧开始，就是属于较早与武林接触的一部，而原因无他，就是因为此部的主要领导者苏扬傩叶，当初传出被谬龄儿所杀。也因此傩叶部众人不断的寻找执首及指环的下落。岂料，在阇城血印中，众人始明白，天外南海的奇人卧江子，竟就是叶口月人消失已久的傩叶部执首苏扬傩叶。

傩叶部在苏扬之后，始终没有执首，直到王隐取回指环替代，最后九幽在整顿军备考量下，方才提拔猊戬为新任执首，因此猊戬与另外三名执首之间，较无默契，武功也是相差最为悬殊者。

### 氏叶部

武冠：歧华氏叶

其他人员：骊日氏叶、靡月氏叶、兵戎司下士、四识氏叶、飞渊氏叶、棠真氏叶

代表颜色：银色

幽舻：焚月幽舻

从阇城血印开始，四曲峡道之战以来，对袖权想必不陌生才是，这个状似无敌铁金刚的硬汉，正是氏叶部的执首，不论在四曲峡道一战，二战傲笑红尘，袖权皆表现出执首极为强悍的一面，面对邪能境广目天两人的自我牺牲，袖权挺身为所有士兵挡下冲击力，日常对下属的照顾，都在在的表现出，其实叶口月人中，亦是有谦和、爱民的将领。而绣墨与潇潇之间，虽然最终仍是无言的结局，但也足以在霹雳历史中留下一页，潇潇也因此能在叶口月人大军征讨当中，逃过一劫，只是为难了袖权夹在大公无私的执首与父亲两个角色当中，有诸多的为难，也难怪当最后袖权知道绣墨被杀时，会如此的失常，顶撞九幽不算，甚至不念往日旧情誓杀卧江子，此举也深刻地表现出袖权对爱女的亲情。

### 锖叶部

武冠：端宾锖叶

司寇：凌曲锖叶、盛律锖叶

代表颜色：黑色

幽舻：炼月幽舻

四部之中，最少提到的，大概就属锖叶部了，不过虽是如此，锖叶部的戏却是颇为重要，除了早期大力协助妖后的玄掣锖叶不算，身为四部执首当中的最强者－－洺双锖叶，想必是最受观众喜爱的叶口月人了。除了三十年后的嗜血年纪记载的最强者之外，洺双打败银狐的沈稳、力量，有计划的分析，都让观众对洺双想不注意都难，而从洺双的表现，观众更可以看到，以往执首之间的友情，除了对卧江子的态度之外，暗中掩护绣墨、银狐，对剑君、敌人的赞赏，一举打破了观众对叶口月人极为厌恶的一面。要说洺双是叶口月人当中除了卧江子之外，最受人欢迎的角色，想必不为过。

当初无机原之战，邱霍蛉叶带领的四部执首应战，好在银狐没把指环带着，不然以洺双、袖权的力量，只怕武痴的传说，在该战之后，就只剩下一位侠刀蜀道行。

### 璚叶部

武冠：骁封璚叶

司寇：季焉璚叶、珩瞿璚叶

代表颜色：红色

幽舻：拜月幽舻

比起其他三部，璚叶算是最没有特色的一部了，除了早期出现的青琨，美名慧修罗之外。其馀人员皆只在大场面战斗时出现过，而稽咸也是原本的四大执首中，最缺乏特色之人。个性比起袖权、洺双两人，也较为缺少着墨，这大概就是组织团体当中，较无可避免的一环了。

### 领导体系

叶口月人由邪帝及其传人领导统驭，辅权则从旁协助。邪帝为其创始者。其传人九幽担任幽皇。 其下分为傩叶、氏叶、璚叶、锖叶四部，各部独立自治，具体组织结构详见各部下文。

# 地理司
================================================================================

地理司

紫袍、白发掩面的星象奇人，因锻炼兰若经中“双极心源”，致使相貌巨变、五官尽失。为人心机深沉、工于算计，生性阴险、包藏祸心，手段凶狠毒辣，潜伏于北辰皇朝内，伺机窃取北嵎龙脉之气。

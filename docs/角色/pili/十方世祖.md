# 十方世祖

东方三侠前辈，因白马雕龙的寻仇，让东方三侠点燃万年香求助世祖，结果反被极创机吸取精元复活，缩骨藏身衣袍之中，掌劲奔雷，与流星拳不分上下。后因拾获擎天神剑，意外遭魔域之人所杀。

### 角色经历

十方世祖，东三教东方三侠的前辈，早已坐化多年，但仍留有残余元神在其衣冠冢上。东三教由于当年拒绝并鄙夷白马雕龙而遭到报复，东方三侠为保命而乞求十方世祖庇佑，十方世祖杀死三人并吸收其精元复活，针对白马雕龙采取攻势。一轮激战后，十方世祖提出《侠道追溯》为化解仇恨的条件，但被奇妙大棺王以“点物寄气”的方法赶走。后来，十方世祖在屁龟被鬼王棺杀死时捡漏抢到擎天神剑，耀武扬威时却被魔域人马杀死并夺走神剑。

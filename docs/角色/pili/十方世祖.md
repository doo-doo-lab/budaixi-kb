# 十方世祖 (十方世祖)
================================================================================

十方世祖

東方三俠前輩，因白馬雕龍的尋仇，讓東方三俠點燃萬年香求助世祖，結果反被極創機吸取精元復活，縮骨藏身衣袍之中，掌勁奔雷，與流星拳不分上下。後因拾獲擎天神劍，意外遭魔域之人所殺。

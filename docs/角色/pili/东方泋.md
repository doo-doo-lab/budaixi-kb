# 东方璧

================================================================================

霹雳布袋戏虚拟人物东方璧，霹雳布袋戏中的角色。赫墨族的异数，多年前由逃出族内的穆倾雪，以及大开眼界店主东方印所生，但甫出生便被丢下山崖，尔后幸运残活下来，后被不明之人缝上双眼变成盲虬。在赫墨族复出后，盲虬积极找寻双亲下落，顺利找到已经化名霜叶飞的穆倾雪，最后霜叶飞协请姊妹帮忙，盲虬则在翠萝寒的帮助下解开双眼之封，变回东方璧真身。然而多年来的芥蒂，依旧让东方璧对于赫墨族的一切感到愤恨。

**中文名**：东方璧

**配音**：黄文择（闽南语）

**性别**：男

**登场作品**：霹雳开天记之创神篇霹雳迷城之九轮异谱霹雳靖玄录下阕出 处霹雳布袋戏

## 角色设定

姓名：东方璧诗号：神来一笔，纳天地精灵，蘸风云为墨；绘虎图龙，扫阴谋奸宄，洗同流合污。化身：盲虬初登场：霹雳开天记之创神篇 第8章再登场：霹雳迷城之九轮异谱 第2章霹雳靖玄录下阕 第16章（参加梦丹青举办的丹青宴）退场：霹雳靖玄录下阕 第27章（死于血鲲鯩）

## 角色人际

组织门派：赫墨族父亲：东方印母亲：穆倾雪（霜叶飞）祖父：穆云度舅舅：穆戮徒弟：上官圆缺其他：谬、摩弗罗、飒溘斯、翠萝寒、医天子、素还真、步香尘、梦丹青

## 角色能力

武学：凝气之笔、梦能开引·笔旋天光·一捺挥墨·追本溯源、一捺玄引·封、梦能开引、异瞳开眼、凝气封灵·笔旋天光·一勾引命、凝气引梦·禁忌之笔、异能刀网、神来异笔武器：梦笔三支（收藏于笔囊）、咒邪横斩（布刀）所有物：古曜东方璧

## 角色造型

服饰是关外豪放风，较厚的布料能呈现挺拔英姿。东方璧发色由造型组选择白色，代表纯白画布，再将饰物点缀上去，有如在画布作画。发型呈现出欧式贵族风格。加上了类似羽毛的华丽头饰，表现文艺气息。只装在单边还有独立、自由的暗示。年轻、时尚，瞳孔部分也有特别设计。

## 其他记录

1、犯界者，见识异能之怒！（初登场一对阎王、燹王）2、为何吾不能只是东方璧，既然命运要吾身边的人，一个一个离吾而去，那吾，就顺天之意，做一回复仇之人。3、神来一笔，纳天地精灵，蘸风云为墨；绘虎图龙，扫阴谋奸宄，洗同流合污。（于八岳峰尖对战阎王）4、日出东方，阎王命丧。（于八岳峰尖对战阎王）5、盲虬在玉手九针翠萝寒的协助下，解下了被缝的双眼后，力量大幅提升恢复原本面貌，具有赫墨人血统的东方璧在论剑海外，串连了众异能者之力，一举让阎王、燹王之联军为之退却。（会刊230）

## 角色配乐

◎东方璧（东方璧角色曲）曲/编曲：黄名伟官方桌布收录于《霹雳开天记之创神篇剧集原声带》黄名伟老师二00八年作品，开头铺陈一股东方神秘氛围，接着转为轻快的曲调，就像受翠萝寒帮助而变回原来样貌的东方璧，俊美非常的外貌下，更有着无法测度的赫墨之威。

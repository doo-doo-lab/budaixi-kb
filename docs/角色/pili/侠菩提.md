# 侠菩提

================================================================================

霹雳布袋戏虚拟人物侠菩提，霹雳布袋戏虚拟人物。赮毕钵罗的双胞胎兄长，天性善良、怜悯苍生，从小就有过于常人的成熟及佛缘，自然而然的向佛道而行，因而悟出超凡的圆融智慧，替许多迷惘之人指点迷津。心知赮毕钵罗的存在，故在圆寂得道前以自己的方式留下机缘，即是红色的菩提树，冥冥中牵引着赮毕钵罗走向正确的道路。而赮毕钵罗的一生，也自然以追随兄长的精神与天命而行。

## 角色能力

武器菩提长几，侠菩提灵魂所化。“几”通“机”，乃是对应着机缘、谜底之意。

长几乃是指在时间的长河下，所滔洗出来的答案。

它就在河岸边，等着偶尔休憩的人发觉及醒悟。

菩提长几最特别的地方，是在于剑柄上长出一片菩提叶。

而提供这么好的想法的人，就是周郎了。

当时他形容的眉飞色舞，有种“不用这点子是损失”的感觉，在周郎的坚持下，“菩提长几”就这样定案。

关于这点，周郎表示：这是为了表现出一种生机盎然的意象，从剑鞘上长出枝桠，萌发出菩提叶，也可以当做是帽子一类的头部造型装饰。

确定外型后，再去赋予它故事意义。

## 角色经历
父亲是怪贩妖市“开天皇二世”，自小感到孤独，在亚父/叔父龙戬的透露下，得知自己有位孪生胞弟龙赮，并于千乘骑欲对赮不利时，射出金箭解围。

怪贩妖市宫变后，因心冷于亚父龙戬之死与父皇龙漪之所为，悄然离开妖市，来到苦境游历修行。

（创神下02、03、09）在一次森林大火中，为救被困百姓而砍断一株百年大树，而自愿终生负起其一截树桩（木蒲团）修行，后木蒲团有感，被侠菩提精神影响，因机缘而幻化为人形意方觉，为引导赮毕钵罗接续与侠菩提之缘。

（创神下09）曾一人平定西南二十四寇，力败中原五大武魁，被奉“武神”；

儒道释无一不精，一人舌战三教派流，将武林分歧杂说，定于八大派宗。

开导点化却尘思、缥缈月、鹤白丁的同时，动摇却尘思之心，趁其松手一瞬，抑制外力，三人方能交换灵封，相互制衡，三足天方有现今成就。

（创神下12）与平朔新月城之王论佛时，交予其毕钵罗子，告知日后若遇跟自己长相相似之人便交他，为与赮在阿僧祇园内重逢相认，交接天命留下契机。

（会刊235）在玄同太子于沉剑湖底探寻赮毕钵罗踪迹时，以梵海刹光引动湖底万剑吟啸，阻止玄同破坏既定的天数。

（创神21）侠菩提在赮毕钵罗随心初至沉剑湖，被湖底怨气排斥时现身，解放倍受箝制的剑怨妖影，并指引赮回忆相关过往。

在赮取得菩提长几后，寄在长几上的侠菩提灵识指引其前往妖市开天皇陵，吊祭父皇龙漪，完成久年遗憾之事。

（创神下02、03、07）白骨千丈内，在赮破除了阎王护体的磐甲鳞衣后，兄弟同心祭出菩提剑式，佛缘引动阎王体内天罗子之力，使阎王伏诛。

（创神下12）在阿僧祇园内，接引赮毕钵罗开启与菩提长几未来之天缘，告知其日后须阻止九轮断去时间之流的宿命。

（创神下14）深海主宰与战栗公合作翦除裁罚者后，反被战栗公暗算昏迷，在赮面对妖市大军逼杀，又逢战栗公强势拦阻下，誓死保卫恩师的意志，引动侠菩提之气，兄弟同心共克战栗公，师徒二人得以全身而退。

（创神下22）遗留在天宙之间的佛气帮天迹助大漠苍鹰进入轮回（斩魔录54）侠菩提的残余灵识在天宙之间内，为保护天迹遗体力抗众天邪王，残余灵识终是不敌而消散。

（破邪传17）侠菩提，大漠苍鹰，孤星泪现天堂之门助天迹对抗众天邪王。

（破邪传45）兵锋决楔子，侠菩提与忆秋年、天策真龙作为苦境传奇一起登场（兵锋决01）

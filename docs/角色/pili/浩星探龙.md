# 浩星探龍 (浩星探龙)
================================================================================

浩星探龍

夸幻之父的前身，嗜好探索天下奇秘，身負「佛觀六文」，乃玄黃三乘所言具有「人之最」天命者。曾於賢者之樹受白髮仙者指引，以化消精靈對外戰火，安定人世為自身天命之起點。在精幽戰場畢方山擊敗逆神暘後，前往獸王陵，孰料因此遭逢巨變，浩星探龍被植入精靈三角，反成了迫害精靈的夸幻之父……。

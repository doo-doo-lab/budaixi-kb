# 妖绘天华

================================================================================

霹雳布袋戏虚拟人物霹雳布袋戏虚拟人物。诡异神秘的鬼画师，为奇花八部中的情花部，面容清癯，浑身散发浓浊妖气，甚至因此被黜为奇花八部之末，因而心生不甘，对神、灵两花派怀有敌意。为让情蛮花再世，甘愿放弃双眼，苦心钻研妖绘莳花之术。

**中文名**：妖绘天华

**配音**：黄文择

**性别**：男

**登场作品**：霹雳战元史之动机风云

**出场集数**：29集

## 角色设定

- **名称**: 妖绘天华性别：男诗号：泼墨生妖华，舍眼见未来！初登场：霹雳战元史之动机风云 第10集退场：霹雳战元史之动机风云 第38集（投身情蛮花被吞噬）根据地：留妖山城妖绘天华

## 人际关系

- **组织门派**: 奇花八部朋友：绮罗生、素还真徒弟：狡童

## 角色能力

- **专长**: 妖绘莳花之术所有物：画册、妖花绘、情蛮花、天墨雀丹红、妖绘莳花谱

## 角色配乐

妖绘天华(妖绘天华气势曲)曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十八》丁天牧老师2012年作品，乐曲原创作主题为「堕天使」，以弦乐演奏出危机感的旋律曲调，加上现代感的律动节奏和人声吟唱，营造出邪恶感的紧逼气氛。

乐曲选用为妖绘天华的气势曲，鬼画师奇特的炭绘妖舞之术，搭配诡异的战斗曲风，顿时让人陷入战栗的杀机氛围。

乐曲初次使用于动机风云第10集，妖绘天华气势初登场，之后则常做为妖绘天华武戏或气势呈现之用。

情蛮花(妖绘天华抒情曲)曲/编曲：林薇 收录于《霹雳英雄音乐精选三十八》林薇老师2005年作品，缓缓拨弹的弦音，带点邪气的乐曲旋律，偶之搭衬著迷梦般的女声吟唱，打造出独特的异族风音律，勾勒出一幅绮丽无边的妖冶风采。

妖绘天华配乐共两首，一文一武，此曲为抒情文曲，多半使用于妖绘天华与人交谈时，或其居住地留妖山城之场景配乐。

## 其他纪录

吊妖绘天华之死：(动机38)桶底脱时大地阔，命根断处碧潭清。犹似红炉一点雪，散作人间照夜灯。

妖繪天華是《霹靂戰元史之動機風雲》中的人物。詭異神秘的鬼畫師，為奇花八部中天四部的情花部，面容清癯，渾身散發濃濁妖氣，在久遠前的奇花拔擢會上被黜為奇花八部之末，因而心生不甘，憤出八部斷去一切聯繫。為了傳承情花部一脈，廣收江湖門徒，販夫走卒等，只要對妖繪蒔花術有興趣者，皆不吝傳授情花奇藝。雖表面上對神、靈兩花部懷有敵意，但在神靈兩花部被滅時，除了收留兩花部遺孤之外，更致力於為神靈兩花部討回公道。為讓情蠻花再世，甘願放棄雙眼，苦心鑽研妖繪蒔花之術。後得血傀師指點，突破長久以來妖繪術盲點，終於讓情蠻花現世。

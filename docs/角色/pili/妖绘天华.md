# 妖绘天华

================================================================================

霹雳布袋戏虚拟人物霹雳布袋戏虚拟人物。诡异神秘的鬼画师，为奇花八部中的情花部，面容清癯，浑身散发浓浊妖气，甚至因此被黜为奇花八部之末，因而心生不甘，对神、灵两花派怀有敌意。为让情蛮花再世，甘愿放弃双眼，苦心钻研妖绘莳花之术。

## 角色配乐

- **妖绘天华(妖绘天华气势曲)曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十八》
- **丁天牧老师2012年作品，乐曲原创作主题为“堕天使”，以弦乐演奏出危机感的旋律曲调，加上现代感的律动节奏和人声吟唱，营造出邪恶感的紧逼气氛。

乐曲选用为妖绘天华的气势曲，鬼画师奇特的炭绘妖舞之术，搭配诡异的战斗曲风，顿时让人陷入战栗的杀机氛围。

乐曲初次使用于动机风云第10集，妖绘天华气势初登场，之后则常做为妖绘天华武戏或气势呈现之用。

情蛮花(妖绘天华抒情曲)曲/编曲：林薇** — 《霹雳英雄音乐精选三十八》

林薇老师2005年作品，缓缓拨弹的弦音，带点邪气的乐曲旋律，偶之搭衬着迷梦般的女声吟唱，打造出独特的异族风音律，勾勒出一幅绮丽无边的妖冶风采。

妖绘天华配乐共两首，一文一武，此曲为抒情文曲，多半使用于妖绘天华与人交谈时，或其居住地留妖山城之场景配乐。

# 剑影皓月光

富有正义感的青年，与刀疾流星行情同手足，一起在乱世之中仗义勇为，帮助受难的百姓。在一次运送给难民的粮食时被强盗威胁，此时叶小钗来到将盗匪除去，于是剑影皓月光便与刀疾流星行一同拜叶小钗为师。两人一同习武、成长，并被叶小钗赐名为“剑影皓月光”。之后加入魔吞不动城，承接荒狼宫之代表，化身为剑狼，为了苍生而无悔付出。

## 来自百度百科的补充

霹雳布袋戏虚拟人物

魔吞不动城的荒狼宫代表，孤高骄傲、冷酷少言，酷寒的战栗气息使人退避三分，招起招落飞快无伦，如狼猎物一般的冷静快意。常与刀猿一同出任务，手持狼杀剑，在惊人的出招速度下顺势窥探对手破绽，一举扫荡魔吞不动城的所有阻碍。

武学增加：血狼回杀、刀罗剑网（与刀猿联招）

武器说明：狼杀剑（在苍鹰对战别离禅时，被别离禅内力震断）

# 劍影皓月光 (剑影皓月光)
================================================================================

劍影皓月光

富有正義感的青年，與刀疾流星行情同手足，一起在亂世之中仗義勇為，幫助受難的百姓。在一次運送給難民的糧食時被強盜威脅，此時葉小釵來到將盜匪除去，於是劍影皓月光便與刀疾流星行一同拜葉小釵為師。兩人一同習武、成長，並被葉小釵賜名為「劍影皓月光」。之後加入魔吞不動城，承接荒狼宮之代表，化身為劍狼，為了蒼生而無悔付出。

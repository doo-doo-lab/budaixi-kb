# 剑影皓月光
================================================================================

剑影皓月光

富有正义感的青年，与刀疾流星行情同手足，一起在乱世之中仗义勇为，帮助受难的百姓。在一次运送给难民的粮食时被强盗威胁，此时叶小钗来到将盗匪除去，于是剑影皓月光便与刀疾流星行一同拜叶小钗为师。两人一同习武、成长，并被叶小钗赐名为“剑影皓月光”。之后加入魔吞不动城，承接荒狼宫之代表，化身为剑狼，为了苍生而无悔付出。

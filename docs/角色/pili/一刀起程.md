# 一刀起程

手戴金色手套，脸罩白色人皮，迷离诡残、令人闻风丧胆的杀手，乃孤愁先生为搜集九龙图而培育的金小开，专杀尘界九龙。后被照世明灯带入黑暗道，由小霸王取代，并在释丹凤协助下，混入友情之家卧底。

## 来自百度百科的补充

"一刀起程"是《霹雳布袋戏》中的身份代号，"手戴金色手套，脸罩白色人皮，迷离诡残、令人闻风丧胆的杀手"。该身份由两位14岁左右的少年使用：金小开（原使用者）与小霸王（接替者）。

## 角色能力

**武器：** 屠龙软刀——孤愁先生专为屠杀尘界九龙而设计的软刀，"能直劈横斩、一刀断首"

**武学：** 一刀起程与走剑行刀两式连招。前者为"虚张声势、声东击西"的破绽攻击招式；后者为"快速使用剑气冲破敌人防线的招式"

## 角色经历

金小开被孤愁先生培育成专杀尘界九龙的杀手，为学得绝世武功而"牺牲脸和手指"。他杀死咸通、万烛公、血双鳞等高手，后被慈海渡者打伤。照世明灯安排小霸王接替其身份，而金小开隐于黑暗道。小霸王在释丹凤协助下混入友情之家卧底，最终金小开恢复容貌身份，小霸王身亡。

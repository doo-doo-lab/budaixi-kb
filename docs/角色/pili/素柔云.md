# 素柔雲 (素柔云)
================================================================================

素柔雲

素還真之妹，下嫁霹靂神龍接天道，生有一子獨眼龍，後因霹靂門遭黃山八珠聯所滅，素柔雲雖逃出生天，但就此隱居千霞山，改名素雲流，更對素還真產生誤解，投效歐陽世家。與獨眼龍之間情深緣淺，只能暗中默默關心，始終未能母子相認。

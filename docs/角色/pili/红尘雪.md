# 红尘雪（霹雳布袋戏虚拟人物）

红尘雪，霹雳布袋戏虚拟人物。

倚晴江山楼之主，亦是隐流左单锋之主。

文秀儒雅、貌美如花，善于琴棋书画，学识渊博又天赋异禀，能将知识传授给灵兽。

看似武林少见才女，实有剑中洛神之美誉，其武学脱胎于父亲天剑老人的极单锋，练就自成一格的“翩单锋”，宛若游龙，点化为惊鸿七式。

在历经众天邪王、皇鳞等诸多祸害后，红尘雪等侠女有志一同，组成邀月仙阁。

以女性为主力生力军，团结翠萝寒、巧天工、风霁月、夜飞天、独梦君、剑琅琊等人，协助剑风云，在武林上调查各种神秘。

诗号1：凌波缥缈微步稳，裁云清泠月影深，雪花千转酿香尘。

拼却红颜饮，做芳菲主人。

诗号2：看雪练倾河，十里龙涛，独濯沧浪行云啸；

风光傲，问人间何似，天子逍遥。

诗号3：漱冰濯雪，霞佩云冠，眇视万里一毫端；

寄声玉鉴，摇动星辰，翳凤骖鸾策江山。

霹雳天命之仙魔鏖锋第37章炼洗之命辟夜之光剧中芙蓉铸客巧天工因梦中机缘，由西陵拂晓指点，得到神玉玺宝石，巧天工即以此打造，红尘雪专属神枪——辟夜之光。

由于辟夜之光是红尘雪专属兵器，在制作时，编剧希望能够符合红尘雪本身风格，故道具师以其手持物翩惊鸿及翩惊鸿剑为参考，配色及装饰相似。

枪头部分为双镰枪样式，看起来像个十字，但是左右双镰却又不做成枪尖，而是能活动、旋转的零件，在剧中可自行急速旋转以告知主人危险即将出现。

枪尖的装饰部分也非常的典雅，中央黄色金属线条左右对称交错，是另一处吸引目光的美学设计。

枪身也使用了绿色半透明琉璃质感，整体配合红尘雪服装配色，也因此其原矿神玉玺也以类似质感来制作。

延伸的翠绿飘带为红尘雪武戏演出的一大特色，辟夜之光当然也少不了呈现画面美感的要件，飘带纷飞时，辟夜之光将再现天子之威。

## 经历
红尘雪年少时因资质超越弟弟映云骞，其父天剑老人映朝阳决定将单锋剑传与红尘雪，映云骞因此负气离家出走，投身儒门，化名清怀玉鉴·应无骞，成为儒门正御。

因卧龙隐之死，红尘雪邀请生命练习生至倚晴江山楼，二人由此结识，并彼此心生好感。

应无骞为道剑·剑非道所杀，墨倾池将应无骞尸体带至倚晴江山楼，红尘雪虽得知应无骞之死是咎由自取，但仍无法释怀。

墨倾池求取单锋剑法，但红尘雪并未答应。

于是墨倾池以为应无骞报仇的名义挑战剑非道，落败之际为红尘雪制止。

红尘雪心知墨倾池资质超过映云骞，但心术不正，便写书信将其介绍至任平生处。

猃狁三化复生，凶首恶来为灭单锋剑寻至江山楼，与红尘雪交手期间受到映朝阳思想干扰而退走。

红尘雪从凶首身上感应到父亲的气息，由是对映朝阳的失踪之事充满怀疑。

夸幻之父召开古原争霸，为探寻当年映朝阳失踪谜团，红尘雪持日字玉枢令前往八面玲珑参与古原争霸，并得到三号八纮钥。

后调查天枢世家冤案，证实孤星泪乃天枢世家后人，并告知真相，与孤星泪一起对抗玉梁皇，并将其打败，夺回帝诏。

官方桌布最后在天迹的安排下与生命练习生一同进入幽界阻止原始魔君，正当生命练习生自我牺牲，生命之源全数回归于魔君之身时，红尘雪举枪重伤魔君，扩大了当初寒武纪所留下的伤口，成功阻止魔君完全复苏，而红尘雪被赶来的孤星泪救出幽界，并在仙脚拜别天迹，最后带着存有生命练习生记忆的鸳机石退隐江湖。

八歧邪神为祸武林之际，红尘雪重出，与正道群侠一同对抗邪神厄祸、原始幽界等势力。

险遭悍族劫脉之八凶灵鲪夺躯，翠萝寒为救姐妹自我牺牲与灵鲪同归于尽，经历剑琅琊之死后洛神再尝失娣之痛。

悍族之乱结束后再遇六蚀玄曜为祸，与生命练习生一同遭寰界吞噬，再出时已怀有身孕。

致力与正道人士一同对抗伪太曦神照暴政，遭地冥之化身解璇玑假意杀害，化身黎菲菲养胎并协助地冥暗中救下自尽谢罪的天迹。

腹中孩儿被天迹取名玉晴雨，望其历雨犹晴，笑看人生。

## 红尘雪编剧漫谈

映鸿雪、洛神·红尘雪、天子枪·玉玺重明，比起雨霖铃到巧天工的身份转换，红尘雪身上有更多的身份线，不断抽丝，却也未必能够完全剥茧。

角色形成之初，董事长提出了一个温柔娴雅的女主人形象，拥有琴棋书画等各式才艺，貌若天仙，更身为左单锋创主之一。

红尘雪这样的设定，瞬间将角色拉到一个不食人间烟火的高点，而董事长后续更追加一笔“天子枪”身份，将红尘雪同时放置在剑、枪两界的关键位置，也订定了这个角色的重要性与地位。

不得不说，霹雳史上重要的女性角色们，都相当有自己的脾气与个性。

近年来温柔娴雅的古典女性，反倒成为剧中少见的存在，笔者自己不是什幺正经角色，身边正经角色也不多。

塑造红尘雪之初兢兢业业，确实写得绑手绑脚，也遇到了不少困难。

然而随著角色发展取向日渐明朗，笔者终于为红尘雪写定了形象：表面看来她是一个富贵小姐，典型的风雅闺秀，实质上，她拥有不让须眉的勇气与坚持，一旦换上戎袍，拿起兵器，更化身不逊男子的武中冠冕。

她柔中带刚，细腻而不软弱，更在许多层面展现果决的判断力与行动力。

比起传统定义的贤淑女性，更令红尘雪自在的身份，是在沙场挥洒的时刻。

不为争强斗狠、争权夺利，剑与枪是红尘雪对生命的两种情感、两种追求，更是容许她逃离女人柔弱似水刻板印象，充分展现自我的媒介。

拍板红尘雪的形象后，接下来的工作，便是打造江山楼这个人间胜地。

好山好水，仙鹤灵龟，学艺话文的世外桃源，更依董事长的指示，为这个根据地置入一些弹性大、逗趣而生动的角色─红尘雪的一对侍女。

笔者考量到擅长琴棋书画的才女，实已屡见不鲜，遂设计了教灵兽识艺此一特色，鹦鹉卢小小也为初期红尘雪稍嫌严肃的剧情，添加一些色香味。

初登场时，红尘雪隐洛神剑、天子枪不现，而以代理人身份调查卧龙隐殒命的来龙去脉。

从此不问俗事的倚晴江山楼再入尘寰，随之单锋剑界、枪界的阴谋算计也一一浮现。

洛神红尘雪终于免不了陷身红尘泥淖，却也与今生缘分的题解─生命练习生相知相遇。

爱情之系─生命练习生。

最后笔者要谈的是与红尘雪角色历程紧密相系之人─红尘雪今生无悔的挚爱，生命练习生。

潇洒不羁、落魄江湖的练习生，和成天宅在江山楼、闭门著书的红尘雪，到底是怎么看对眼的呢？

红尘雪相信很多人都对这段情感有所疑问，其实他们两人的相恋就是“一见钟情”，很没道理却又有几分道理。

初次与练习生见面的红尘雪，并不仅仅是红尘雪。

为了暗地调查枪楼血案疑云，她左手隐剑、右手藏枪，将真正的自己掩盖在闺秀的重衣之下，只以儒雅一面示人。

而生命练习生却大方干脆的将自己所知的一切摊在表面，让人看个精光。

对红尘雪而言，练习生是一个直率、简单的人，拥有最纯粹的生命态度，但她自己则为了有所隐瞒、未坦承一切真相而隐隐歉疚。

数日谈话下来，红尘雪无形中对练习生的豪爽直率心生向往，因为这样的生命样态，正是自己自小所渴望的。

然而身为映朝阳之女，她未能以映鸿雪的面容，在武林和江湖四海的人论交，也不便在战场上兵械论争，唯有戴上玉玺重明的面具，以男子身份出现，她才能与江湖豪情沾上边。

而生命练习生相对的，对自己的生命没有任何隐藏，在在呼唤红尘雪对于英雄豪情的认同。

在谈话同时，练习生也为红尘雪风采倾倒，不知不觉地将一颗心献上，为彼此的生命题写答案。

生命本是个不解谜题，罕有人能知己何来，更无人知晓自己从何而去。

生命练习生如此，洛神‧红尘雪亦如此。

半生行走武林，翻滚红尘，世路也惯也倦，而今遇到了相互圆满、解答生命的另一半，是上苍的恩赐，也让彼此的心在汹涌武林风波中，有了栖身之所。

由于红尘雪与练习生各自背负的任务与身份，未来的两人注定走向两端。

为阻止凶首杀戮，并为取得百寒之气，练习生以上邪杀恶来，一枪断去天剑老人生机。

自向红尘雪坦承后，练习生对红尘雪而言，不再是一心相向，更是背负杀亲之仇的冤家。

恩仇、情恨、血亲与挚爱，所有无法割舍的情绪，不能轻定的抉择，谱写两人感情的无解谜题。

而命运冥冥的牵系，将让红尘雪与练习生殊途同归，抑或从此陌路？

就请观众们继续耐心收看了。

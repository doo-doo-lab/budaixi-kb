# 慕容婵

霹雳布袋戏虚拟人物慕容婵是霹雳布袋戏中的虚拟人物，被称为“狂刀爱妻”。她由国语和闽南语配音演员配音。容貌美丽，温婉坚韧，曾为成全姐姐慕容娟主动放弃爱人乱世狂刀，并化名天行奇侠协助父亲大业。她曾重新登场，造型呈现古典美，身穿粉色和服。编剧通过重点片段回顾来呈现她在乱世狂刀心中无可取代的重要性。虽最终与狂刀退隐江湖，却在武林至尊金小开命令下被乱军重伤身亡。她的退场成为一段令人扼腕的传奇。

## 角色设定

慕容婵化身：天行奇侠

根据地：风月幽楼、枫桥、镜花水月台、苦竹篱

## 经历

慕容婵是霹雳布袋戏中的女性角色，曾为成全姐姐慕容娟主动放弃爱人乱世狂刀，并化名天行奇侠协助父亲大业。最终与狂刀退隐江湖，却在武林至尊金小开命令下被乱军重伤身亡。其退场发生在《霹雳00妻》的关键剧情高潮中，为守护爱人与同道而牺牲，化作永恒的传说。在《古原争霸》第四十二章的特别回顾中，慕容婵的形影曾于枫桥重现，与乱世狂刀上演生死重逢一幕。

## 能力设定

慕容婵，外号“狂刀爱妻”。

其能力主要包括武学、武器与所有物。

武学包括排闼直入、风行草偃、土崩瓦解、天地合一、江山易手、一字刀法、回龙逆斩、夜龙一炬、珠凤诀之火凰展翅等。

霹雳会刊 慕容婵相关专题【排闼直入】慕容婵奉命要暗杀藏剑生，两人发生争斗，不一会儿慕容婵便使出狂龙傲天武诀当中的功夫——排闼直入，化出数道气功，但是藏剑生不躲不闪，被气功贯体而过，藏剑生死前要求慕容婵将他的遗体，运到大雪原交给雪狼，事实上这乃是藏剑生退隐的一个障眼法。

（霹雳狂刀第五十二集）【江山易手】慕容婵奉命要杀了非凡公子，两人第一次交手，在非凡公子被副院长抓拿之时，慕容婵使出迷烟，先将七大金身及副院长等人迷昏，慕容婵以为也迷昏了非凡公子，正欲动手杀之，非凡公子突然醒来，两人遂展开了战斗。

慕容婵抢先发动攻势，但皆被非凡公子一一化解，战斗多时，慕容婵使出傲天武诀里面的“风行草偃”，但被非凡公子闪过，非凡公子发现是傲天武诀当中的功夫，也使出七色忍法之绿甲龙卷斩，化成一尾绿龙。

天行奇侠见状，急忙使出“土崩瓦解”，大地被分开两半，非凡公子掉下了地缝之中，随后天行奇侠再使出“天地合一”，让分开的大地合而为一，想夹死非凡公子。

就在天行奇侠以为成功做掉非凡公子之时，突然地下冒出了绿龙的手臂抓住了天行奇侠的双脚，天行奇侠情急之下，双掌合一，使出狂龙八斩法之一的“江山易手”，一道无形的刀气出现，慕容婵用这道刀气试图斩断龙之双手，但绿甲龙卷斩不为所动，随后非凡公子化成的绿龙发出数道闪电，天行奇侠负伤而逃。

（霹雳狂刀第五十五集）【珠凤诀之火凰展翅】在非凡公子离开宇宙神知之后，天行奇侠再度找上非凡公子，这次慕容婵立刻使出狂龙八斩法当中的功夫“回龙逆斩”，但功力不够，再加上非凡公子早已面对过此招，被非凡公子轻易避过。

慕容婵再出“夜龙一炬”，非凡公子则使用”游离八方“迅速破招，慕容婵见状立刻改换功夫，在慕容婵头顶之上，突然冒出了熊熊火焰，煞是惊人，非凡公子见状，大喊一声，啊～！“珠凤诀之火凰展翅”。

正欲准备破招之时，受命保护非凡公子的跨限怒佛跳入阻止战斗，并愿替非凡公子受死，慕容婵无奈，只好离开。

## 新枫桥传说

凄凄枫桥离恨天，十五尘土遍狼烟。

情仇历尽心犹痛，回首无处共婵娟。

古原争霸四十二章收幕，枫桥那端，烟波江上远曳而来的，竟是乱世狂刀梦中伊人形影，这究竟是怎么一回事呢？

为何慕容婵会在枫桥再现？

相信对不少戏迷来说，枫桥背后的凄美爱情故事，是霹雳故事里，最动人的篇章之一。

编剧这回透过特殊加演的方式，重现经典画面，让观众再次回味，乱世狂刀与慕容婵的经典一幕，更挑选了新曲，作为狂刀与慕容婵2016年的纪念音乐。

枫桥再会重新当场的慕容婵，在造型组的精心设计下，也呈现了有别于从前的古典美，一身粉色和服，更添加美感，让整体气质更为出色。

编剧也表示，由于狂刀对慕容婵的情感，早已内化在内心最深处。

所以这次狂刀复出，比较少有特别强调狂刀思念慕容婵的部分，反而是透过重点片段的回顾，如悲龙斩和新枫桥传说，来呈现在狂刀内心里，慕容婵无可取代的重要度，以及两人最深的思念，才会催生出这个桥段。

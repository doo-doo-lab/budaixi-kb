# 千山樵老

在假的素还真出现在翠环山之后，真正的素还真化身为千山樵老悄然的出现。他暗中行事使无极殿与天外方界相互残杀；与忘年之间的结拜更是为人津津乐道，名为结拜，但暗地里却是相互牵制、陷害，但之间还能谈笑风生。个性幽默风趣，也显示出素还真的另外一面。

## 人物经历

青阳子成立新合修会后，武林干戈暂息。素还真表示退隐，实则化身千山樵老。但号世阴令的出现让天下人心惶惶。于是千山樵老派"黑夜奔雷"跟因号世阴令形成的无极殿势力打游击战，送欧阳胜天去无极殿扰乱朝政，后又派荫尸人取代欧阳胜天。

在此期间，千山樵老曾伪装成魔魁的徒弟，欺骗了司徒笑梦。千山樵老的活动也引来了敌人的追杀，血灵魔尊曾亲自率领魔兵鬼族对其进行狙杀，千山樵老与一线生一度面临死厄。

假欧阳胜天劝无极殿的金小开对付乱世狂刀，慕容婵母女因此被大军追杀，千山樵老虽尽力赶到，但依然不能阻止悲剧。后千山樵老和忘年相识结拜，并赠送了一支金叶作为结拜礼物。二人私下相互试探，后二人打赌，忘年拿着樵老送他的金叶子承认自己是素还真。后魔魁借非常女腹中魔胎复活，一页书建议以"佛魔同根双极果"之圣果来杀之。

在后续的互动中，忘年之剑曾在千山樵老手上变化为圆形，并以此帮助脱困。此后，千山樵老还与白云骄霜各有手段展开周旋。

当初，素续缘被万圣佛骨灰及万鬼魔珠之圣气与魔气缠身，导至性情分裂，时善时恶，后来素续缘进入葬尸江，被江中之高人将 这两道气流导出体外，圣魔两气在江中继续同旋争斗，一直到了天河之中，但天河终年冻结，两气不得脱困，在冰下造成急流漩涡，正好 在漩涡之下有一处奇妙的地隙，内中生长一棵奇树，圣魔两气于是被此树吸收，终于生出两果，一树双果，一者魔果，一为圣果，故云佛 魔同根。秦假仙与业途灵受一页书所托前往天河取圣果，双极果在未成熟之前为虚幻之体，待成熟才转为实体，两人并以一页书之圣血测试何为圣果，最后取下圣果时，魔果亦瞬间爆炸，形成一股红色的妖云。

秦假仙身上的圣果后来被千山樵老乐雕缘所骗取，用来医治素续缘所中的创伤。在一页书诛杀魔魁败北后，千山樵老自曝身份，承认自己是素还真。

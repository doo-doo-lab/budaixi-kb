# 香独秀

================================================================================

《霹雳布袋戏》中的经典虚拟人物香独秀是《霹雳布袋戏》系列中的虚拟角色，初登场于2010年2月12日播出的《霹雳震寰宇之龙战八荒》第5集，退隐于2011年4月8日《霹雳兵燹之圣魔战印》第3集。

身份为集境芜园楼主、天府院殿将，持有兵器不群之芳，诗号为“浮名本是身外物，不著方寸也风流”。

角色由黄文择配音，本尊偶头由洪有聪雕刻，配乐由阿轮创作。

香独秀性格自我中心且具洁癖，言行常引发笑料，被称作「剑葩」。

曾参与斩杀阴端佛鬼、协助分离苦集两境等事件，与南风不竞、慕容情产生交集。

因无视规则多次被贬职，最终回归集境退隐。

剧中通过劝诫烨世兵权「争逐天下不如坐拥山林」展现处世哲学。

角色以超凡实力游离于纷争之外，虽被集境众人避之不及，却能凭借剑术与智慧屡次化解危机。

其退隐结局与独特作风形成贯穿剧情的核心脉络。

## 人物形象

性格设计阴端佛鬼在集境搞破坏，变出了三座晶塔，编剧的安排是要让三大高手去破坏晶塔，才能有效的打击妖世浮屠顶端的阴端佛鬼，而这三大高手的人选，其中两人编剧已经处理好了，最后这第三人，编剧希望从集境中再选一人，于是集境的人口「被迫」多加一人，也因为这个的诞生，让全集境对编剧有所怨言。

有些是不说，观众可能不知道，「为什么他不是苦境或灭境人？」这样的耳语似乎悄悄的在三仪三司十二殿中流传。

香独秀要去破坏晶塔，必须是个高手，编剧三弦希望这个高手不只是个高手，而是个非常特别的高手，要有非同凡响的个人特色，这种特色，就是如同观众所看到的，香独秀真的是一个奇葩啊！

没错！

香独秀之所以成为剑葩，不单单是葩在他的剑法上，他的为人处事，才是真正的葩之所在，真是好葩、好葩、好剑葩啊！

香独秀：虚名，一切都是虚名，浮云而已。

能迅速的成为紫微宫御前大统领，身处政权中央，又能急速的降为基层殿将，集境圣帝给予的评语是——「不知悔改」。

名字来源香独秀的命名，主要是来自成语「一枝独秀」，严冬之时，百花枯萎，而松柏挺然独秀，也有超群出众的意思，基本上是个正面的词语，可是用在香独秀的身上嘛……这可语带双关了。

而香独秀的「香」，是代表他的品味高尚，独特的气质像花的芬芳，能扩散、传达给身旁的人，只是用在这角色身上，同样有两面的意思，相信各位观众也是一目了然！

人物造型香独秀由于香独秀糟糕的个性，在集境相当不受欢迎，所以在造型上要很小心，因为一个不受欢迎的人，如果造型又不讨喜，这个角色就彻底完蛋了！

所以三弦挑选了一个斯文、俊秀，让人看了会高兴的偶头，并请造型组特别帮香独秀设计适合的造型，发型与服装都经过了数次的修改，主要是走斯文、高贵的路线，别看香独秀说话惹人嫌，他可是个注重外表的翩翩美公子！

头发颜色选用较明亮，又不失庄重的颜色，发型原本比较简单，但又太过豪迈，最后改成稍微束发，配上漂亮的装饰。

因为香独秀剑法高强，所以衣服要有高手的气势，却又不能过于阳刚、勇猛，厚重硬挺的布料并不合适，于是以轻柔布料、浪漫花色为主，制作出香独秀专属的高雅服装。

## 人物能力

武器：不群之芳外形特征：通体蓝纹流金样式的剑身，简单流线的造型，上有七个圆洞，剑柄镶和阗蓝玉，剑末系棕色长穗。

沿袭香独秀黄色头发和蓝色系外型，其佩剑握柄为蓝色，护手雕琢典雅呈箭镞状，以蓝色琉璃珠点缀，黄铜护手雕琢延伸至剑身之上。

事迹简述：香独秀手持不群之芳，剑出流畅、势走迅捷的无匹剑术闻名于集境。

因其高超剑术而受集境天机院主太君治之托，为共闯妖世浮屠、斩杀阴端佛鬼的人选之一。

妖世浮屠为祸集境，香独秀受天机院主太君治请托帮忙攻打火之晶界。

后因妖世浮屠撞入集境，吸取集境地气能源，而造成集境自然气候异变，香独秀锺爱的雅谷幽兰易受此异变影响而花不开，于是香独秀决定加入求影十锋与万古长空共诛佛鬼。

因剑法高明，被赞为凄绝、冷绝、美绝，在集境素有「剑葩」之称。

## 经历
香独秀集境芜园楼主，身法极快无比而又飘忽不定。曾于当年围剿残宗的时候擒住残宗首领雄王，而名声大噪升为紫微宫御前大统领。与求影十锋、万古长空联手打败阴端佛鬼。之后脱离集境，成为自由之身，居住在薄情馆。表面上是游玩苦境，暗中却仍关心着武林变动，帮助苦境对抗死国与火宅佛狱。后薄情馆被毁，又四处游山玩水，因曾经为救剑子与佛剑前辈而秒杀的异法无天竟然奇迹复活成非尸流状态，寻其报仇，但香楼主因怕鬼而不敢面对。后在灵自灵的帮助下，恢复自信，再度秒杀异法无天。同时又在而后的苦集两境分离中，发出剑气帮助三位祀嬛补充功体，并随之回归集境。

## 人物定位

香独秀在剧中个性的最大特点在于，他对天下武林局势丝毫不在意，看到同属集境的花鸟月围杀千叶，也会做出非常人之反应，帮花鸟月加油！不惹事、不避事，加上无人能揣度的实力，使得集境军督选择避开香独秀，因为军督深知香独秀的个性及实力，若要铲除香独秀，纵使军督亲自出马也非十足把握，与其大费周章招惹一名敌人，最便利的方法便是无视，反正军督无视香独秀，香独秀也无视军督，香独秀就这么的在集境当中安然泡温泉，而这也是香独秀的生活哲学，有需要之时就让香独秀出来搞笑一番。（摘自DVD手札本《芜园耕记》）

香独秀未公开的故事设计芜园耕记香独秀在集境的战略上有着举足轻重的地位，剧中曾简短着墨，香独秀一人独闯残宗大本营，不仅掳走雄王，还视旁人于无物。之前三弦编剧曾暗中设定，其实当年圣帝、雄王两人曾同时到芜园要请出香独秀，不过一人在前门，一人在后门，而香独秀则是依然故我的泡温泉，让两位领导者苦苦等待，最后圣帝比雄王多等了半个时辰而终于等到香独秀泡完澡，因此就注定了圣帝统一集境的命运，所以香独秀才会官拜紫微宫御前大统领，而后连降十七级变成普通殿将，不过这一切当然也不是香独秀会去在意之事啊。（摘自DVD手札本《芜园耕记》）

## 编剧漫谈

香独秀嗯，在正式开始之前，小三子不得不说几句话，在小三子漫长的编剧生涯中，从未有过如此沉重的心情去写一个角色的编剧漫谈。

香独秀，一个让人囧囧有神的人物。

在此，我要为那些戏里戏外，被香独秀欺负的欲哭无泪的人，致上深深的一鞠躬。

照例说主题，嗯，好吧，我终于得承认，我第一次写下了这样一个毫无主题的角色。

香独秀是个奇葩，总是充满着不知道哪来的自信跟朝气。

总是神经粗大到得罪人也无自觉。

总是在最紧要关头跑去忙自己的事。

总是会忘记人家最重要的交代。

好，我们进入下一阶段，对于一个标准乱入型的角色，要如何将之放置于故事当中而又不突兀呢？

首先他必须要有个人的能力，如果不是有过人的能力，只怕早就被身边的人围杀到死，他脱线的风格也不适合参与权力之争，倒是可以如浮云一般飘过，所以先定位了，就是攻打阴端佛鬼的阶段性任务负责人之一。

他必须不属于天机院的麾下，一方面是考虑集境权力斗争的环境问题。

另一方面，客座身份来源能激发出更多的梗来。

且香独秀的性格过于抢眼，如果不将其安置在一个好位置上，喧宾夺主简直是必然之事，集境的故事安排有他的顺序，大家将目光过度集中在他身上时，阶段性任务一过，集境线的故事也将因此失去吸引力，这是绝对要避免发生的。

而香独秀一开始设定的实力就很高，让这个人长久存在于集境当中，一来实力上的平衡问题，对于剧情推动时会有大影响，二来，在阴端佛鬼事件中，香独秀还能保持客座身份的立场，一旦集境的权力斗争正式展开，香独秀持续的搞笑，将会降低这过程中的紧绷感，也因此，可怜的苦境大众在二十三集之后，惨遭香独秀毒手了。

有了这些初步的概念，便可以筹划细节，首先安排他是在天机院对立的天府院登场，一来可以借调请他的过程中，勾勒出两院间的不合之处，再来，也方便之后为香独秀的离开做好伏笔安排，当太君治提出借将的构想时，大殿上众人听到香独秀之名，纷纷摇头叹息，在芜园时，香独秀当即展露了他的过人之处，洗澡洗了一下午，嘴巴说要出去，身体倒是老实的泡着。

这之后香独秀前往天机院询问，也没搞清楚细节，便前往了火灵晶界，胡乱试探一阵之后，又立回到芜园洗澡，完全把回报战情撇到一边去。

面对几位殿主的询问，以他独特的观感把两位殿主气得发昏，战力之强，连十锋也为之胆寒却步。

到这里，观众可以很清楚的知道，他是一个「实力高强」但是「想法独特」的剑客。

离开了龙烟苑之后，香独秀与南风不竞一番鸡同鸭讲，解决了天机院的潜藏危机。

又继续开始他的游山玩水之旅了。

由于一开始香独秀就是个没有主题的角色，所以惯性以主题发想的小三子并未以他为中心设计故事，所以我索性利用到底，利用他带出集境每个角色的性格，例如玉蝶遥星的纯真、战龙纹的暴躁、照路明的沉着、弑道侯的深沉，天机天府两院的矛盾，雄王与圣帝的冲突，连破军府的暗桩也是由他拔除，一来是十锋动手易留下把柄，不利于后面剧情的发展，二来是强调香独秀虚名如浮云的性格。

观众如果细心观察，其实可以发现集境中有不少架构跟冲突，是借由香独秀口中来作铺陈跟陈述的。

当集境的架构以趋完整时，香独秀也放大假离开集境了。

有人说，这个角色最大的特色是洁癖、毒舌跟自我中心，洁癖、自我中心是对的，但是毒舌那未必了，香独秀打从一开始，他的每句话都没有伤人的意图，无论大家相不相信，香独秀其实是个「温和敦厚甚至称得上是善良的烂好人。」香独秀嗯，很没说服力吧，但是实际上就是这样，从他想借战龙纹几本书「增加常识」，且还认真的对万军敌解释「夏虫不可语冰」的典故来看，他非常细心的认为对方可能读书不多，不懂他说的话。

这份「贴心」，并不是每位角色都有的啊。

其实他没有轻视任何人的想法，只不过他眼中的世界就是这样，他也只是如实陈述自己想法而已，草食男、宅男，反正这些词加到他身上，统统可以找到一点影子。

简单说，他就是个宝，不但是个国宝，还是个活宝。

香独秀是个「目中无人」的角色，说他目中无人，不是指他看不起别人，而是香独秀眼中根本就没有别人，别人对他的仇，他不当一回事，别人受不了他，他浑然未觉，别人调侃他，他会说一切都是虚名，浮云而已，就算是婢女吐他槽，他也不会生气。

有求于他，只要合乎（他心目中的）公理正义，他就会去做，做了之后也不认为是施恩。

他是个「自我感觉」不但良好，而且是「非常良好」的角色。

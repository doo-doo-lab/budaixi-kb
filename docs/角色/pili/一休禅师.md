# 一休禪師 (一休禅师)
================================================================================

一休禪師

馳名天下的荒野金刀獨眼龍，沉浮江湖多年，終捨半生塵世情仇，於金山靈佛寺潛心修禪，法號一休。以出世之身行入世佛道，為救治天禍妖狐多方奔走，參與天河運棺之役，最後隱居無雙崖底。

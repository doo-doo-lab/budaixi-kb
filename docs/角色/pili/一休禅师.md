# 一休禅师
================================================================================

一休禅师

驰名天下的荒野金刀独眼龙，沉浮江湖多年，终舍半生尘世情仇，于金山灵佛寺潜心修禅，法号一休。以出世之身行入世佛道，为救治天祸妖狐多方奔走，参与天河运棺之役，最后隐居无双崖底。

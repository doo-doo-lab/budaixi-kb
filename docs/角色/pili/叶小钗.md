# 叶小钗（霹雳布袋戏虚拟人物）

================================================================================

叶小钗，霹雳布袋戏虚拟人物，三大台柱之一（其余二人为素还真、一页书）。耿直专一、守信重诺的侠客，虽为侍童出身，但不屈不挠的个性，丰富的人生阅历，让其成为中原武林不可或缺的一员，享有“刀狂剑痴”之盛名，披肩的白发和脸上的英雄疤，搭配沉默无言的特色，营造出该角色独特的风范。叶小钗一生悲情，命运多舛，亲人、恩人、朋友一个个离他而去，却也因此练就了超绝的禅定功夫。经过半驼废的悉心教导，领悟“只手之声”后断舌证道，在风雨坪之战击败一剑万生与一刀万杀，获得阴凤刀（刀狂）与紫凰剑（剑痴），开启效忠欧阳上智二十年的命运转折。其武学境界突破物我之别，达到以天地无我之心为心的“无心”之境。

**中文名**：叶小钗

**别名**：刀狂剑痴

**配音**：黄文择、林协忠（轰定干戈）

**性别**：男

**初登场**：《霹雳至尊》第1集初

**退场**：霹雳经武纪之枭皇论战第26集（血战千叶传奇后被宿贤卿偷袭致死）

**再登场**：霹雳兵燹之圣魔战印第29集（借助魔绝天棺复活再战江湖）

**生日**：4月29日

**根据地**：二重林、水月两忘轩、雕神古魄、魔吞不动城等名 招般若忏、心剑、探·自谦·必胜

**人物特征**：面上一道伤疤、沉默不言

**星座**：太阳金牛，上升天秤（会刊150期武林地位苦境中原剑圣本尊雕偶师徐炳垣、刘氏、洪有聪、潮州君皇化 身苍鹰（魔吞不动城苍鹰宫代表）身 份佛教传人、古武族太武、魔吞不动城·苍鹰

因叶小钗所持慈光之塔的越限之刀埋有隐患，对战之时叶小钗没能留手，杀死万古长空。

千叶传奇为报仇，率集境大军围攻叶小钗。

被千叶传奇重伤及被宿贤卿伏击偷袭而亡之后，又是素还真、一页书、缘醉莫求、圣弥陀、天情悟剑声等正道众人不放弃任何希望，通力合作完成近乎不可能的众多条件，使得叶小钗重生为古武族太武，断刃重续，钗行无悔。

也是在此时，叶小钗借由元生之玉所凝成的心玉共振之力，短暂地拥有了开口说话的能力（霹雳兵燹之圣魔战印第35集）。“吾之故乡，早是江湖，”也正是这一时期他对自身所担负的重任与天命的体认。

随着素还真的隐匿，叶小钗再入江湖寻访。

指点谜独白刀术，与宫无后留下精彩一战。

魔佛波旬二度降临苦境，叶小钗与正道众人为了再次将之封印而用尽计谋、连番鏖战。

在消灭圣魔元史的战斗中，叶小钗心玉碎裂，再度失声（霹雳侠影之轰定干戈第24章）。

苍鹰展翼苍鹰叶小钗因怜众生苦，不辞尘染身。

持刀断魍魉，抱剑化苍鹰。

在一段隐居二重林，教导悟剑声的短暂休息之后，叶小钗依照素还真的安排，化身苍鹰宫，协助屈世途组建魔吞不动城，以新的身份为守护武林平安而努力，更有了两个徒弟刀猿和剑狼。

刀疾流星行，剑影皓月光，短暂人生路，永铭侠士踪，留下诸多脍炙人口的战例。

上千集霹雳布袋戏中，三大台柱中的另两位都多次有开方便法门、以化身现世的记录，而唯独叶小钗一直是以本来身份行走武林，直到魔吞不动城这一“黑暗中的正义”组织的成立，叶小钗才第一次有了官方确认的化身——苍鹰。

正如2015年10月10日宜兰传艺霹雳活动现场，黄文择先生为叶小钗临时所改的诗号：“爱回红尘心重生，持刀抱剑化苍鹰”，苍鹰这一身份的神秘造型与宗师定位，让叶小钗的形象获得了新的拓展。

在与九轮天这倾界来犯的大敌对抗之时，苍鹰配合卜相机关（屈世途）的计划，联合不动城十二宫之金狮宫、银豹宫、凤凰宫半路拦阻确认已受异识入侵的素还真及唐绝。

对战中苍鹰宫现出叶小钗的真实身份，素还真体内的异识被沾有灵符水的狮头宝刀所斩并封印而陷入昏迷，卜相和齐天变立刻带回琉璃仙境欲铲除附于素还真体内的异识。

苍鹰担心在琉璃仙境的素还真遭受攻击前往守护，果见翠环山下唐绝追杀秦假仙及业途灵，危机之际苍鹰现身凌空而下，褪下苍鹰面具以叶小钗的身份对战唐绝，刀剑齐出再现天道之招，留下又一经典战例，也为一双牺牲的爱徒雪恨。

在九轮天大陆即将坠落苦境之际，叶小钗配合解锋镝安排，和墨倾池、狂刀三人以三教镇教秘招毁去九轮天与苦境之间的通道。

一页书被偷袭而陨，为雪梵天之恨，苍鹰对应无骞武力相向，虽遭重创仍以心剑将对手一剑封喉，却因对手体内金丹化去死劫而反遭重伤，幸得赤龙影相救，并得解锋镝从夸幻之父处取得药物，而逐渐恢复。

阴阳婆请身俱佛门根基的叶小钗前往天涯半窟取回泥犁布牒为一页书抢命。

后得知石之砻的石元可让一页书脱胎重生。

而找寻石之砻需经过北域凶险之地，叶小钗与已失记忆的解锋镝及九龙之一的齐天变一同护棺北行。

此行为一页书重生之路取得了契机，让其灵珠之胎得以凝聚。

此后叶小钗镇守不动城，直至武林态势变化，不动城使命完成正式解散之时。

霹雳惊涛武林危机，邪染天下。

神秘组织邪剑司，把矛头申向二重林，悟剑声失踪。

叶小钗为寻至亲，依线索来到地海孤堡。

在地海孤堡，叶小钗大破邪剑司，也知晓了父母的爱恨情仇，更在不知情的状态下穿越时空，和恩师重逢。

穿越回来的叶小钗，重新背负刀剑，明白凌绝顶一切无恙，救援了风月莫容，更对最终对手——长日锟铻下达战帖，天山剑决最终战，叶小钗一对长日锟铻，坎离双器交锋轩龙绝品。

心剑合双器，无坚不摧之力，斩破长日锟铻恢弘不破之镜！

后叶小钗暂时退隐幕后，他为了捍卫武林正义，刀行无悔、剑诛千邪的故事，仍将继续。

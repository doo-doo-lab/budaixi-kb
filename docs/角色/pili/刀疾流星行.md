# 刀疾流星行

路见不平的有为青年，与剑影皓月光一同行动，在乱世之中行侠仗义、不求回报，无法容忍他人欺负弱者。在一次运送给难民的粮食时被强盗威胁，此时叶小钗来到将盗匪除去，于是刀疾流星行便与剑影皓月光一同拜叶小钗为师。两人一同习武、成长，并被叶小钗赐名为“刀疾流星行”。之后加入魔吞不动城，承接神猿宫之代表，化身为刀猿，提起鬼猿刀，要替武林斩除恶人。

### 主要经历

刀疾流星行本为路见不平的有为青年，与剑影皓月光一同行动，在乱世中行侠仗义、不求回报，无法容忍他人欺负弱者。在一次运送给难民的粮食时被强盗威胁，叶小钗来到将盗匪除去，于是刀疾流星行便与剑影皓月光一同拜叶小钗为师。两人一同习武、成长，并被叶小钗赐名为“刀疾流星行”。

刀疾流星行初登场于《霹雳开天记之创神篇下阕》第27章。之后加入魔吞不动城，承接神猿宫之代表，化身为刀猿，提起鬼猿刀，要替武林斩除恶人。

在《霹雳谜城之九轮异谱》中，刀猿与剑狼联手对战别离禅，施展合招“刀罗剑网”。

刀疾流星行退场于《霹雳谜城之九轮异谱》第14章。

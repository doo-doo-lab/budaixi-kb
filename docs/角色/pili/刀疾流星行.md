# 刀疾流星行 (刀疾流星行)
================================================================================

刀疾流星行

路见不平的有为青年，与剑影皓月光一同行动，在乱世之中行侠仗义、不求回报，无法容忍他人欺负弱者。在一次运送给难民的粮食时被强盗威胁，此时叶小钗来到将盗匪除去，于是刀疾流星行便与剑影皓月光一同拜叶小钗为师。两人一同习武、成长，并被叶小钗赐名为“刀疾流星行”。之后加入魔吞不动城，承接神猿宫之代表，化身为刀猿，提起鬼猿刀，要替武林斩除恶人。

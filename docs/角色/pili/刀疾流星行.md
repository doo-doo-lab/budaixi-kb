# 刀疾流星行 (刀疾流星行)
================================================================================

刀疾流星行

路見不平的有為青年，與劍影皓月光一同行動，在亂世之中行俠仗義、不求回報，無法容忍他人欺負弱者。在一次運送給難民的糧食時被強盜威脅，此時葉小釵來到將盜匪除去，於是刀疾流星行便與劍影皓月光一同拜葉小釵為師。兩人一同習武、成長，並被葉小釵賜名為「刀疾流星行」。之後加入魔吞不動城，承接神猿宮之代表，化身為刀猿，提起鬼猿刀，要替武林斬除惡人。

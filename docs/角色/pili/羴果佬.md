# 羴果佬

个性像个吵着要糖吃的老人，只要懂得顺毛，他就会被治得服服贴贴。本质良善，是传说中的吉祥圣兽。他的另一种型态是生死灵驮，没有人知道他的来历，只知道他一直负责运送的人或灵魂，前往他们要去的各站。

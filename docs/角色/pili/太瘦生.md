# 太瘦生 (太瘦生)
================================================================================

太瘦生

出自鉅鋒里，遊歷武林的一介窮酸書生，知悉不少武林恩怨秘辛，曾告知秦假仙關於半身金人、鄧王爺之事，一心找尋當年圓教村血案的兇手。

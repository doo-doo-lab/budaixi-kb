# 战神猊

霹雳布袋戏虚拟人物战神猊，霹雳布袋戏虚拟人物。虩的真正身份，豪壮雄猛，为精灵天下悍野兽脉之主，过去性格自负而好战，一度遭恨吾峰改造为弃神类虩，以灼世烈眼残杀精灵、镇守封印。在恢复神智之后，因兽脉部下几乎死绝，一改过去性格，开始会谨慎而行，但言谈中仍不减当年风采，深得部下信赖与敬仰。

## 经历

精灵天下·悍野兽脉之王，被尊为兽王，豪壮雄猛，性格自负而好战。

久远前精幽大战时受袭击后失去踪迹，遭恨吾峰所擒，被改造为弃神类·虩，以灼世烈眼残杀精灵、镇守封印。

曾与禁城一脉的天织王女琥珀相爱并定下终身，即使长期被剥夺原有意识、化身为弃神类·虩时，仍对琥珀有深深的执念和温存。

后因在绝迹刀阵受到刺激而使精灵元神破封，意识恢复。

在恢复神智之后，因兽脉部下几乎死绝，反省过去的自己太过好战鲁莽，导致败果，故一改过去性格，开始谨慎而行，但言谈中仍不减当年风采，深得部下信赖与敬仰。

恢复神智后加入狩宇执行灭绝人魔的大计，后因恶魔种子影响使得心性渐趋暴躁，和天织主、殷墟帝少等联手围杀偏离灭绝人魔理念的逆神旸。

在救下险被伪鬼麒主杀死的恨吾峰后得知伪鬼麒主便是当年将自己改造为弃神类之人，劝慰恨吾峰恢复昔日威能、与自己一同报仇，日后更发展为知己朋友。

后因皇旸曜雪和冷飘渺暗中布局，战神猊体内恶魔种子被秋瑟剑消灭，心智恢复理性，并协助两人将精灵同胞从地冥的控制中解脱，在地冥攻击精灵余孽时被地冥擒走。

因身体受冥日之力侵蚀而衰竭，寿命无多，心有觉悟的兽王受地冥指引前往灼世，从烈眼尊枭处取得十三颗灼世烈眼，更获得血暗之力和恨吾峰刀法之助，在转轮谷约战至仇伪鬼麒主。

战中伪鬼麒主一度受到压制，但战神猊在施展恨吾峰刀法时意外解封伪鬼麒主手中的狱龙斩，使得情况急转直下，战神猊身受重创，在恨吾峰和肖流光的掩护下撤离。

战神猊  官方桌布死前被送回兽王陵，在族人和挚爱的幻象簇拥下走向生命的终点，兽王陵也被掩埋。

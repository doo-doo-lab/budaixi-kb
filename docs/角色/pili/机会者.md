# 机会者

霹雳布袋戏虚拟人物机会者，霹雳布袋戏虚拟人物。火宅佛狱第二波进入苦境之人，身罩黑纱袍，宛若祭司般的造型，性格阴冷狡猾，沉着有巧智，擅以言词攻心、分化敌人。主要任务是监督并协助仲裁者打通苦境通道，好让火宅佛狱大举入侵。其副体为手中诡异的人头权杖。

## 角色设定

诗号：命运关键，进乎、退乎；机会抉择，生耶、死耶。初登场：霹雳震寰宇之龙战八荒 第37集退场：霹雳震寰宇之兵甲龙痕 第5集（本体被雷劈死）来自：四魌界根据地：地狱口

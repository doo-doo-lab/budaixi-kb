# 机会者

================================================================================

霹雳布袋戏虚拟人物机会者，霹雳布袋戏虚拟人物。火宅佛狱第二波进入苦境之人，身罩黑纱袍，宛若祭司般的造型，性格阴冷狡猾，沉着有巧智，擅以言词攻心、分化敌人。主要任务是监督并协助仲裁者打通苦境通道，好让火宅佛狱大举入侵。其副体为手中诡异的人头权杖。中文名机会者配 音黄文择性 别男登场作品霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕上 司咒世主组织门派火宅佛狱

## 角色设定

名称：机会者性别：男诗号：命运关键，进乎、退乎；机会抉择，生耶、死耶。初登场：霹雳震寰宇之龙战八荒 第37集退场：霹雳震寰宇之兵甲龙痕 第5集（本体被雷劈死）来自：四魌界根据地：地狱口

## 主要经历

机会者是火宅佛狱第二波进入苦境之人，其主要任务是监督并协助仲裁者打通苦境通道，以便火宅佛狱大举入侵。

## 人际关系

- **组织门派**: 火宅佛狱上司：咒世主同伙：黯纪仲裁者、莎莉罕、寒烟翠、破坏者、替代者副体：投机者

## 角色能力

- **武学**: 无理藏机谋略：擅以言词攻心、分化敌人所有物：人头权杖

## 角色配乐

无理藏机（机会者角色曲）

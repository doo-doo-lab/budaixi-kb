# 随遇（霹雳布袋戏中的人物）

随遇，霹雳布袋戏中的人物。森狱十八皇子玄嚣与天谕鸠神练所生之子，体质殊异生长迅速，但自幼命运多舛，母亲亡故后由舅舅符去病抚养，小小年纪却聪慧懂事，总能安慰焦躁的符去病。稍长后入学堂受廉庄老师教诲，后为躲避尘世暗夜，被送至殊离山上的时间城，陪伴城主和饮岁。随遇之名，乃希望其随遇而安。

## 角色经历

主要剧情随遇与说太岁“随遇对玄嚣而言，又是怎样的存在？

难道真如山龙隐秀所言，玄嚣急着生下后代的原因，是因为要将随遇当成生命的备胎，在遇到重大灾难前，用随遇的命来填补自己的流逝的生命？

我想这个答案，连玄嚣自己也模模糊糊，不如就当成是玄嚣心中的一点秘密，随他消逝而永埋黄土。 ” ————节选自月刊224期编剧漫谈── 玄嚣太子片段。

但是笔者私心认为，不论当时的玄嚣生随遇的目的是什么，但在他死前最后心中的憾恨，亲儿至死不曾享天伦，合眼前最后一句吐念“随遇我儿”，可以深深感受到玄嚣对随遇的思念，那并不仅仅是一个备胎而已。

对话:随遇：饮岁阿叔，城主要我见的人是谁？

饮岁：正确讲来，他应该是你的阿公，但这种关系又太过笼统，我也不先替你定义，你可以在交谈中自由决定对方是你的什么人。

随遇：若他是我的什么人，那随遇还是饮岁阿叔的好朋友吗？

饮岁：哈，当然是，饮岁阿叔的身边一直都没有朋友，有你这样可以谈心的小知己，饮岁阿叔不会放你走的。

随遇：饮岁阿叔这么好，为什么会没有朋友啊？

饮岁：唉，因为我太优秀了！

平凡的人，通常都不喜欢与太优秀的人做朋友，因为我会让他们自形惭秽。

所以，我只能一个人独饮这孤单岁月的滋味。

随遇：原来，要像饮岁阿叔这样，一问三不知的人才是优秀。

饮岁：嗯？

如果不是你的眼神纯正，表情天真，我会以为你这句话中饱含着嘲讽的意味。

随遇：随遇为什么要嘲讽饮岁阿叔？

饮岁：你是乖小孩，不用知道这些属于下等人的无聊游戏。

随遇：哦。

饮岁：走吧，城主应该等得不耐烦了廉庄：首先，你告诉老师，你叫什么名字？

随遇随遇：我叫随遇，我娘希望我随遇而安。

# 随遇（霹雳布袋戏中的人物）

================================================================================

订阅0有用+10随遇，霹雳布袋戏中的人物。森狱十八皇子玄嚣与天谕鸠神练所生之子，体质殊异生长迅速，但自幼命运多舛，母亲亡故后由舅舅符去病抚养，小小年纪却聪慧懂事，总能安慰焦躁的符去病。稍长后入学堂受廉庄老师教诲，后为躲避尘世暗夜，被送至殊离山上的时间城，陪伴城主和饮岁。随遇之名，乃希望其随遇而安。中文名随遇配 音黄文择性 别男登场作品霹雳侠影之轰掣天下生 日2013年12月27日（初登场）

## 角色经历

主要剧情随遇与说太岁“随遇对玄嚣而言，又是怎样的存在？难道真如山龙隐秀所言，玄嚣急着生下后代的原因，是因为要将随遇当成生命的备胎，在遇到重大灾难前，用随遇的命来填补自己的流逝的生命？我想这个答案，连玄嚣自己也模模糊糊，不如就当成是玄嚣心中的一点秘密，随他消逝而永埋黄土。 ” ————节选自月刊224期编剧漫谈── 玄嚣太子片段。但是笔者私心认为，不论当时的玄嚣生随遇的目的是什么，但在他死前最后心中的憾恨，亲儿至死不曾享天伦，合眼前最后一句吐念“随遇我儿”，可以深深感受到玄嚣对随遇的思念，那并不仅仅是一个备胎而已。对话:随遇：饮岁阿叔，城主要我见的人是谁？饮岁：正确讲来，他应该是你的阿公，但这种关系又太过笼统，我也不先替你定义，你可以在交谈中自由决定对方是你的什么人。随遇：若他是我的什么人，那随遇还是饮岁阿叔的好朋友吗？饮岁：哈，当然是，饮岁阿叔的身边一直都没有朋友，有你这样可以谈心的小知己，饮岁阿叔不会放你走的。随遇：饮岁阿叔这么好，为什么会没有朋友啊？饮岁：唉，因为我太优秀了！平凡的人，通常都不喜欢与太优秀的人做朋友，因为我会让他们自形惭秽。所以，我只能一个人独饮这孤单岁月的滋味。随遇：原来，要像饮岁阿叔这样，一问三不知的人才是优秀。饮岁：嗯？如果不是你的眼神纯正，表情天真，我会以为你这句话中饱含著嘲讽的意味。随遇：随遇为什么要嘲讽饮岁阿叔？饮岁：你是乖小孩，不用知道这些属于下等人的无聊游戏。随遇：哦。饮岁：走吧，城主应该等得不耐烦了廉庄：首先，你告诉老师，你叫什么名字？随遇随遇：我叫随遇，我娘希望我随遇而安。

人物設定姓名：隨遇隨遇人際關係主要劇情“隨遇對玄囂而言，又是怎樣的存在？難道真如山龍隱秀所言，玄囂急著生下後代的原因，是因為要將隨遇當成生命的備胎，在遇到重大災難前，用隨遇的命來填補自己的流逝的生命？我想這個答案，連玄囂自己也模模糊糊，不如就當成是玄囂心中的一點秘密，隨他消逝而永埋黃土。 ” ————節選自月刊224期編劇漫談── 玄囂太子 片段。但是筆者私心認為，不論當時的玄囂生隨遇的目的是什麼，但在他死前最後心中的憾恨，親兒至死不曾享天倫，合眼前最後一句吐念“隨遇我兒”，可以深深感受到玄囂對隨遇的思念，那並不僅僅是一個備胎而已。對話:隨遇：飲歲阿叔，城主要我見的人是誰？飲歲：正確講來，他應該是你的阿公，但這種關係又太過籠統，我也不先替你定義，你可以在交談中自由決定對方是你的什麼人。隨遇：若他是我的什麼人，那隨遇還是飲歲阿叔的好朋友嗎？飲歲：哈，當然是，飲歲阿叔的身邊一直都沒有朋友，有你這樣可以談心的小知己，飲歲阿叔不會放你走的。隨遇：飲歲阿叔這么好，為什麼會沒有朋友啊？飲歲：唉，因為我太優秀了！平凡的人，通常都不喜歡與太優秀的人做朋友，因為我會讓他們自形慚穢。所以，我只能一個人獨飲這孤單歲月的滋味。隨遇：原來，要像飲歲阿叔這樣，一問三不知的人才是優秀。飲歲：嗯？如果不是你的眼神純正，表情天真，我會以為你這句話中飽含著嘲諷的意味。隨遇：隨遇為什麼要嘲諷飲歲阿叔？飲歲：你是乖小孩，不用知道這些屬於下等人的無聊遊戲。隨遇：喔。飲歲：走吧，城主應該等得不耐煩了廉莊：首先，你告訴老師，你叫什麼名字？隨遇：我叫隨遇，我娘希望我隨遇而安。

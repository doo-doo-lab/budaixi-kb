# 鹤白丁

霹雳布袋戏虚拟人物鹤白丁是《霹雳布袋戏》系列剧集《霹雳开天记之创神篇下阕》等作品中登场的虚拟角色，属道教组织"三足天"成员，别号"蹈足"，初登场于2015年1月2日。

其腰间配挂紫金葫芦，手持八卦镜，代表经典为《道德经》，诗号"白丁踏千峰，漂泊尽禅空，道海立神足，仙鹤渺苍穹"突显其修者风范。

鹤白丁因挚友却尘思请求重入江湖，参与对抗鬼方赤命、阎王等势力。

在三足天灵封互换事件中为克制异识晶源主动削减功力，后遭罪念芯片附体，假意归顺罪域期间与裁罚者决战，最终携敌共沉深海。

其武学融合醉拳与腿功，配有专属武曲《形意大须弥》。

该角色经历从仗义助友到异识操控的意识转变，最终在《霹雳谜城之九轮异谱》第5章被却尘思亲手终结，完成从正道支柱到悲剧反派的命运闭环。

## 角色背景

预言堂人物第233期 预言堂人物——蹈足鹤白丁（摘自 霹雳月刊 第233期 文/编辑部）三足天之中的道门高人，个性豪迈、直接，外表看似佛门带发修行的行者，腰挂紫金葫芦，手持八卦镜，得知却尘思因白沙书院对上赤王、阎王后，力挺好友而出身相助，并主动前往红冕边城叫阵鬼方赤命。

封面人物（摘自 霹雳月刊 第236期 封面人物）第236期 鹤白丁三足天的登场，原是董事长先提出三人团体的构想，分属儒道释三教，以“足”为共同概念，由于“脚”是个激发想像的点，众编剧纷纷提出新点子，其中“穿高跟鞋”（时尚意味）的高手，这样的想法转变为三足天之中出现女性成员。

鹤白丁豪迈，带点粗犷，与三足天另两人形成强烈对比，与众多正经八百的修道者大为不同，言行直接、带一点市井俗气，陋室铭有云：“往来无白丁”。

很明显的，鹤白丁在个性上要与“谈笑有鸿儒”这些上流社会阶层做一些区别。

鹤是吉祥的动物，与道教文化关系密切，而“蹈”则是“道”的谐音。

鹤白丁惯用拳脚功夫，也有很多腿功的发挥，武学名称也看得出欲与佛门融合。

实际上演出时，配合身上的葫芦，则打出了一段醉拳，编剧希望鹤白丁的武戏上，能有各种类型的拳法表现。

而刀法并不是鹤白丁最强的杀招，那么为什么与鬼方赤命拼战时，刀却是留在最后才拿出来？

这是鹤白丁的个性，他就是那种：“看到对方拿刀出来砍，所以自己也要抄家伙”的类型。

互换灵封的想法，有点类似过去三教怪人互换衣服，强调怪异，不过三足天的互换灵封则另外有设计其背后缘由，经侠菩提指点，三足天互换灵封，削减功力，为却尘思克制邪念，但这邪念考验并非是因本身心魔影响而入魔，而是来自怪贩妖市的恐怖异识。

鹤白丁被异识入侵，但没多久就发现自身异状，心生疑惑与警觉，使鹤白丁决定假意配合罪域，欲调查真相，不料被裁罚者识破，双方于海上激战，事已至此，鹤白丁决意同归于尽，也要将异识葬入大海。

幽暗的海底，鹤白丁已在生死边缘，异识却未受影响，窜出附身！

自海中归来的鹤白丁，神态已变，直接引导鬼方赤命使其被异识所附，可怕的罪念将如何翻转武林局势？

鹤白丁异识上身的情况与却尘思略有不同，他是否已完全被罪念启化？

或者本心仍是暗中抵抗异识，另有对策？

三足天的友情，将会有什么惊人的变化？

霹雳小百科——数字巧组“三之数”（上）（节选自 霹雳月刊 第236期 文/编辑部）三足天时间：创神篇第236期 三之数介绍：在三教顶峰之后，许久未曾出现三教为组合的高人，直到六王现世后，在三足天上再现三教的高人，三人以足为号，并在却尘思涉入武林后，陆续现世，并协助正道对抗赤王鬼方赤命等。

或许是三教顶峰塑造太成功，在长达十几档的时间中，就鲜少再出现三教并立的角色，只有曾经在武林公法庭之时，再加上一人成为四派护法，但声势完全跟三教顶峰没得比，一直到最近的创神篇，终于又再出现值得期待的三教组合，从却尘思临天而降的一脚，三足天正式现身，由于顶峰之名已被用走，之后的组合极难超越，因此三足天以另类的足字来强调三人。

此次三人对比以往的戏路定位，有同有异，相同之处在于同是一激进一平缓一中庸，不过原本最激进的缥缈月，后来才揭晓，原来一切都是为了却尘思着想才会如此难搞，而鹤白丁则是即想即行的行动派，更为了好友却尘思而决定消灭异识晶源，甚至不惜与裁罚者同归于尽，可说是最让人欣赏的行动派了。

## 角色形象

造型虽然剧中称为佛冠，但这顶帽子与真正僧人戴的佛冠形制略有不同。非常有特色的立领，展现鹤白丁豪迈气势。选择深色的亮面布料镶金边来表现，不会过份华丽，也不会太朴素。鹤白丁饮酒，因而佩戴葫芦，编剧透露这是来自自己的嗜好。三足天各自的代表物，道教常见的八卦法器。场景三足天，既名为三足天，修行之地就以脚、腿的外形来设计三根参天巨柱，外观使用看起来历史悠久的石材，并刻有三教的代表经典。鹤白丁的代表经典为道德经。

## 角色能力

武器戒道，参考佛教僧人使用的戒刀，线条简单。刀面上刻有经文，以及八卦图案作简单点缀。刀身选择深色，配合鹤白丁个性，避免太过华丽。武学武学腿法无影踪幻、无影幻击、道海神足、道影纵幻、三昧神火蹴刀法刀式 大千戒道、须弥禅空斩、万昧空灭其他形意大须弥·【芥子纳形、横穿空禅】、踏尽天下 蹈世一足、醉拳所有物紫金葫芦、佛冠（涉足灵封）、道徽（寄于皓足身上的灵封）、罪念芯片、八卦镜

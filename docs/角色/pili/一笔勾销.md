# 一笔勾销
================================================================================

一笔勾销

猪脸书生的打扮，对自己的能力极有自信，为人也重义气，与金剪刀、金絮来为结义三兄弟，合称“神来一笔”三神偷。绝学是以勾销笔在画纸上，画下目标物，画完之后，目标物即被撷取。

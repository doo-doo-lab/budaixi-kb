# 一筆勾銷 (一笔勾销)
================================================================================

一筆勾銷

豬臉書生的打扮，對自己的能力極有自信，為人也重義氣，與金剪刀、金絮來為結義三兄弟，合稱「神來一筆」三神偷。絕學是以勾銷筆在畫紙上，畫下目標物，畫完之後，目標物即被擷取。

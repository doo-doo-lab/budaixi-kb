# 渾沌初王 (浑沌初王)
================================================================================

渾沌初王

古域初代王朝主，佛緣深厚，與君昊為好友，曾往鹿野雲澤阻止九狸夢狐殘害生靈，因而結下不解情緣。在胤世五烈決意以七竅之能，將罪惡禁地盡數擊落異境前，初王留下八正念，也將王朝未來託付於九狸夢狐，望九狸夢狐代其守護。

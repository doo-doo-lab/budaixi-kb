# 元真君

道教十三道之一，与师兄太真君共掌昊光道院，通晓剑阵，收放自如。为躲避合修会迫害，与太真君佯装痴癫，直至师侄鹤冈前来相认，才吐露实情。最后却因九五至尊一事，太真、元真两人双双死于慈海渡者的怒佛开膛指之下。

# 元真君 (元真君)
================================================================================

元真君

道教十三道之一，與師兄太真君共掌昊光道院，通曉劍陣，收放自如。為躲避合修會迫害，與太真君佯裝癡癲，直至師侄鶴岡前來相認，才吐露實情。最後卻因九五至尊一事，太真、元真兩人雙雙死於慈海渡者的怒佛開膛指之下。

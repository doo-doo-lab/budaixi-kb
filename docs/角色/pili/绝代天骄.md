# 绝代天骄（布袋戏剧《霹雳布袋戏》中的人物）

绝代天骄，《霹雳布袋戏》虚拟人物意琦行回到战云界之后，恢复战云界第一战士“绝代天骄”的身份，带领战云双擘对决妖界。但同时体内的天厉意识也逐渐觉醒，进而占据意琦行原本意识，幸三余、凤座察觉有异设下防护措施，最后在与圣婴主交易下，以意识之刃斩杀天之厉，恢复自我。

## 角色设定

- **绝代天骄名称**: 绝代天骄性别：男身份：意琦行身份：战云三骄之一、战云界第一勇士名言：凭吾四字，绝代天骄。初登场：霹雳侠影之轰动武林第6章来自：战云界根据地：战云神宫

## 人际关系

- **挚友**: 绮罗生朋友：绮罗生、一留衣姐姐：朝天骄同伴：朝天骄、御宇天骄(战云三骄)、寰无疆、造烽烟(战云双擘)

## 角色能力

- **武学**: 天殛十式武器：春秋阕

## 角色配乐

战云授阶 (绝代天骄气势回归)曲/编曲：浩旭收录于《霹雳英雄音乐精选四十二》绝代天骄官方桌面浩旭老师2005年作品，磅礴的曲势，稳健的鼓声，呈现一股雄心壮志的气势，营造出战士凯旋而归光荣一幕。乐曲初用于轰动武林第六章，战云神宫，为迎接绝代天骄回归，以战云双擘为首，隆重授阶仪式，步在荣耀之端的意琦行，心知人生最光耀的一刻，绝非过往高高在上之刻，而是从悲叹与绝望后再起挑战意志的此时，战云界第一勇士绝代天骄正式回归。

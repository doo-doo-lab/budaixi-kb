# 方界六弦

中国布袋戏《霹雳布袋戏》角色团体方界六弦是《霹雳布袋戏》中的虚拟角色团体，隶属无忌天子麾下，成员包括傲笑红尘、白云骄霜、不死魔僧、方界老童、愁月仙子及血雨风生。傲笑红尘作为团队核心人物曾斩杀血雨风生，后者仅在其回忆片段中出现。愁月仙子遭六聪天乞杀害，促使无忌天子冒充紫绶一品展开复仇，最终被九锡君反杀。白云骄霜因权力争斗暴露野心，死于傲笑红尘剑下；其麾下的不死魔僧被鬼魂车击杀，方界老童则殒命于龙阁梭罗之手。该团体成员结局均与方界势力斗争直接关联，命运轨迹交织于阴谋对抗与武力冲突之中，最终全员覆灭于不同阵营的博弈过程。

## 角色背景

方界六弦是霹雳布袋戏中的虚拟角色团体。该团体成员包括方界老童、白云骄霜等，其中无忌天子并非其成员。方界老童的六弦兵器为旋箜玉叉，白云骄霜的六弦兵器为一调之弦。为获得一调之弦，白云骄霜曾委托无弦神弩制造此兵器。

## 成员设定

方界六弦隶属无忌天子麾下，成员包括傲笑红尘、愁月仙子、白云骄霜、不死魔僧、方界老童和血雨风生。傲笑红尘是六弦中唯一的不死系主角。血雨风生仅在傲笑红尘回忆中出现，未正式登场，死于傲笑红尘。愁月仙子死于六聪天乞。白云骄霜是战略家，野心巨大，最后死在傲笑红尘之手；其六弦之物为“一调之弦”，为获得此物，白云骄霜曾委托“无弦神弩”铸造兵器。不死魔僧被白云骄霜命令鬼魂车杀死。方界老童死于龙阁梭罗之手，其专属的六弦兵器为“旋箜玉叉”。

## 人物关系

无忌天子并非方界六弦的成员。白云骄霜为了一调之弦，曾委托无弦神弩制造兵器。

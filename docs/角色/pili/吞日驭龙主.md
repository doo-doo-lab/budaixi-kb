# 吞日驭龙主

青阳子体内的龙魂恶气被逼出之后，化成的魔化青阳子，自称“吞日驭龙主”，意味着要吞噬青阳，并能够驾驭无敌战龙之人。驭龙主、青阳子两人犹似一体两面，有相同的思维，相同的龙脑之智，驭龙主更夺下原属青阳子的四道龙魂之力，面对这名最了解自己的对手，将是青阳子平生最艰难的挑战！

## 来自百度百科的补充

吞日驭龙主是霹雳布袋戏中的虚拟人物，由青阳子体内分离的龙魂恶气魔化而成，自称"吞日驭龙主"，与青阳子共享龙脑之智。其通过命魂同源术与青阳子性命相连，强占圣龙口并收服六弑荒魔为部属，更获龙魂之力强化自身。其与青阳子展开龙魂争夺战，一度吸收对方并集齐八条龙魂，最终被三先天、静涛君等人击败，藏匿青阳子体内后遭彻底吸收。作为青阳子的极端分体，驭龙主以霸道手段征伐三教，其存在直接体现人性善恶对立的深层矛盾。虽被消灭，但成为青阳子角色升华的关键镜像。

青阳子收集龙魂过程中，心性日趋极端，故三先天和昔月影配合，用明断之泪分离龙魂恶气。谁知恶气合为一人，正是吞日驭龙主。

驭龙主先以命魂同源之术将自己和青阳子性命相连，后以强硬手段接收圣龙口，带着骊无双收服六弑荒魔，招静涛君为军师，集齐六支万魔锋，以战龙之力封印混沌之扉，更获得部分虚无之力。随后与青阳子展开龙魂争夺战，最终吸收青阳子，收集八条龙魂，开始征战三教，更在静涛君的帮助下彻底集齐九条龙魂，举世无双。

为了对付驭龙主，三先天、静涛君、玄真君齐出。大战过后驭龙主落败，藏于青阳子体内，但被青阳子识破，最终被其接纳吸收。

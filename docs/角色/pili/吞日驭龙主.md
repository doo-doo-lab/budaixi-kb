# 吞日馭龍主 (吞日驭龙主)
================================================================================

吞日馭龍主

青陽子體內的龍魂惡氣被逼出之後，化成的魔化青陽子，自稱「吞日馭龍主」，意味著要吞噬青陽，並能夠駕馭無敵戰龍之人。馭龍主、青陽子兩人猶似一體兩面，有相同的思維，相同的龍腦之智，馭龍主更奪下原屬青陽子的四道龍魂之力，面對這名最了解自己的對手，將是青陽子平生最艱難的挑戰！

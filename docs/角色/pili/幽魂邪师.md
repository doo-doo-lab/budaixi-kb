# 幽魂邪師 (幽魂邪师)
================================================================================

幽魂邪師

隳魔大軍將領之一，因魋山戰事生變，與冥迴劍相前往修羅鬼闕求援。面容半邊青邪，擅長妖法邪術，在聖魔開戰期間，與古武族多次交手，曾纏鬥宿賢卿，最後在綿江一戰中，被無衣師尹所殺。

# 幽魂邪师

隳魔大军将领之一，因魋山战事生变，与冥回剑相前往修罗鬼阙求援。面容半边青邪，擅长妖法邪术，在圣魔开战期间，与古武族多次交手，曾缠斗宿贤卿，最后在绵江一战中，被无衣师尹所杀。

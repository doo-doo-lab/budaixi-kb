# 琴缺风隼

霹雳布袋戏虚拟人物琴缺风隼，参与弦无上宴的琴师，诡异邪魅，以水袖击打悬于竹林半空之琴弦，技惊四座，更怀有一手绝顶琴艺，演奏之琴声如激流奔川海，尽敛一身杀气。自称继承了赑风隼的遗志，其实就是赑风隼本人，在得知鬼方赤名等人重生后，便针对鬼方赤命与之缠斗，两人的恩怨延续多年，依旧难解。

## 基本信息

琴缺风隼作为琴师，在弦无上宴中首位登场，以水袖击打悬于竹林半空之琴弦，技惊四座。

## 人际关系

- **仇敌**: 鬼方赤命（好友反目成仇）
- **其他**: 御清绝（希望能以琴证道，向御清绝取得伏羲神天响之绝学，因心不正被御清绝拒绝）

琴缺风隼（前世为赑风隼）与鬼方赤命原是怪贩妖市的生口，结为生死之交，后因故反目成仇，恩怨延续多年，最终在平朔新月城和魔婆之泪了结。

## 角色经历

琴缺风隼联合众人对付鬼方赤命初次出场：弦琴无上宴初次出场，以水袖击打竹林琴弦，白马三唱技惊四座，面容与鬼方赤命背后的赑风隼脸孔一模一样，目的是为引起红冕边城注意。

似乎于红冕存在某种仇恨围杀红冕之人：以琴音吸引山龙隐秀与商清逸来到居所天水封，告知其红冕边城与怪贩妖市的秘辛（红冕七元用夺舍转生之法，从死地归来，一夕荡平平朔新月城，建立红冕边城，鬼方赤命在这一战中称王）而他继承了赑风隼的精神和血肉，从一本累世相传的琴谱中知晓了过去的一切，赑风隼所追求的琴音便是自己的精神支柱。

为了避免苦境重蹈平朔新月城灭亡覆辙他愿以自身为诱饵引出红冕之人，一举围杀。

找上弦非心，告知其弱水琴姬早被红冕的赦天琴箕夺舍取代，让其找上琴会众人，联合苦境正道，一并对抗红冕边城。

遇见御清绝：与山龙隐秀与商清逸及琴会众人围杀红冕杀手时，因赦天琴箕琴音搅局失败。

琴会主席朝玉京因此身亡。

护送朝玉京尸身回去，遇见御清绝，想向其学习伏羲神天响，因其恨意太深，杀戮之意过重失败。

竹林琴斗：鬼方赤命与阎王合作围杀营救巨王的山龙隐秀与商清逸，半道却遭逢琴缺风隼于竹林中以琴音千里竞杀，琴缺风隼由于赦天琴箕琴音搅局交手落败，山龙隐秀被赤命杀害，琴缺风隼以幻术使赤命不敢确定自己是赑风隼而逃脱死劫。

再次拜访御清绝，直言自己受琴所困，抑郁难解，他对鬼方赤命的恨意已成心魔，可是琴通人心如何能不拘于琴，不拘于恨？

御清绝劝其放下恨意，定可以使琴艺上更高的境界，琴缺风隼说没有了恨，他的生命就没有意义了。

天水封与鬼方赤命对战：天水封中，琴缺风隼被鬼方赤命找上门来，他融合了戏曲与琴艺的剑法仍是不敌鬼方赤命，被抓回红冕边城，在囚禁过程中，在斩龙戏台与鬼方赤命回忆了他们少年时在妖市的听戏的日常，虽有感触，但没有放下恨意。

被阎王救走：向阎王说出了自己的过去，原为鬼方赤命好友赑风隼，平朔新月城大臣，将赤命引荐给新月王，赤命却在一次宴会中故意让其出错，趁机上位，后反目成仇，更因认为赤命割断他们结义之树，决定先下手将鬼方赤命献刑，而因深海异力转生的赤命，归来将其斩杀于魔婆之泪，更是削下他的脸置于脑后，他临死前将恨意寄托于斩龙七段律，越是练习这本琴谱，恨意便越是深入脑髓，最后便会变成他，来进行复仇，鬼方赤命与赑风隼两个人互相嗔恨，都认为是对方先背叛了自己。

退场：赑风隼与阎王一起对付鬼方赤命，因赤命过于熟悉他的性格行为，计划被料中，再次落入赤命手中，不愿向赤命低头最后被赤命凌迟折磨而死，死前诅咒赤命。

结局：一生都被恨意纠缠，不休不止，赤命死后恨意消除，与赤命重新轮回转生。

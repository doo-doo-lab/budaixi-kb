# 玉梁皇

================================================================================

霹雳布袋戏虚拟人物玉梁皇，男性角色，初登场于《霹雳狼烟之古原争霸》第14章。武都玉嵎之主，乃“枪中之皇”，素有千面修罗枪之称，出身北嵎周边外族，年少时便建立武都。不可一世、城府深沉，时而霸气、时而冷酷，在过去北辰皇朝覆灭后，玉梁皇以兵征伐，一统北域四族，成为北嵎新主，建立枪之国度御宇皇朝。诗号1：金车齐首伏六龙，云驾听史御长风。酣觞赋诗槊在手，一朝攀日射苍穹！诗号2：万兵伏首，武道称皇，谈笑定尊。

## 角色背景

玉梁皇出身北嵎周边外族之一，年少时便建立武都，并加入枪楼成为三冠之首，与邪天子、应笑我结识。因不满天子枪传招卧龙隐，玉梁皇于百器神决中挑战天子枪，落败后离开枪楼。玉梁皇巧得神物玉犀角，铸造神兵将军令，以此率领武都之人击败四方部族，统一北嵎，并易帜为武都玉嵎。统一武都后，玉梁皇设一皇、双王、三侯、四相、五军、六门等阶级制度。

## 角色形象

掣风悬武玉梁皇（称号包括“掣风悬武”和“千面修罗枪”），御宇皇朝之主，在古原争霸旷世穷武盛宴的八名参赛者中，列名枪之代表，枪艺超凡，昔日在枪界有“千面修罗枪”之称，过去亦是枪楼三冠之首。

霹雳月刊第253期 P02~03玉梁皇一身金黄战甲，显露王者霸气，其代表颜色以白色、金色和浅褐色为主。

为避免角色过于武将化，所以在一开始的篇幅，编剧强调他性喜听史的一面，武学设计上，也透过御宇八字诀，呈现皇者的武学进境，以及冀望天下归心的王者胸襟。

玉梁皇统御武都，分一皇双王三侯四相五军六门，座下辖有浪云王、凌顶王双王，以及稗史侯、饮命侯、万户侯等三侯为主的阵容，暗地里又与虎冠啸风生合作开城，甚至掌握猎首驰雄、少箕裘、少微等影武者，层出不穷的分身，让人防不胜防。

除此之外，玉梁皇真正的后援，是六道神兵府之主邪天子，与单锋魔派之主单锋剑魔，三人共谋分食山海奇观这块大饼，但暗地里，却又暗藏心机，彼此更是心知肚明。

霹雳会月刊第253期 P04在古原争霸的竞赛中，玉梁皇是最早取得目标八纮钥的参赛者。

这类夺宝大赛，通常最早获得优势的，往往都很难成功，甚至是最早牺牲的。

但在玉梁皇的角色设计上，编剧一反常态，走非典型路线，玉梁皇虽然多有受挫，但总是千方百计，不择手段地设法获得心系之物。

往往以为他快见底之时，他却总是另有新的力量，甚至出现新的发展，带来新的变化。

后来，玉梁皇更是获得玉玺禁章，练就天子枪法。

雄浑的黄金色长兵器，富丽贵气，媲美枪中之皇的美名，使玉梁皇在使用将军令时更显霸气之威。

霹雳会月刊第253期P08~09玉梁皇更以此率领武都之人击败众族，统一北嵎，并易帜为“武都玉嵎”。

在得到《玉玺之命》枪谱后，玉梁皇闭关修炼，让影武者少微扮演自己在台面上行走，将军令也交由少微使用。

后在少微和蝴蝶君的战斗中，被蝴蝶君劈成两半。

伪·冥帝之精：久远前，应笑我将一块妖异天铁（冥霾邪滍的核心）交给雨霖铃铸造成终极冥帝后，剩余的精华，被打造成冥帝之精，可强化任何兵器的威能。

玉梁皇在结识应笑我后，获赠此物，曾在与夔禺疆一战中，用以加强将军令威能，以此一举重创夔禺疆。

实际上真正的冥帝之精一直在巧天工手中。

冥帝枪：邪诡的紫色长枪，由雨霖铃用应笑我取得的妖异天铁打造的神兵，属于终极冥帝的一部分，在邪天子结识应笑我后所得。

## 造型设计

玉梁皇的代表颜色为#ffffff、#fdd525和#d9bb92。

穆天七护：超光神靴、越影神行、腾雾神护、翻羽神甲、挟翼神器、逾辉神冠、绝地神能霹雳会月刊第253期 P06~07穆天七护乃玉梁皇之护身宝甲，是以传说中周穆王所拥有的八匹良驹命名，分别名为【绝地】、【翻羽】、【越影】、【逾辉】、【超光】、【腾雾】、【挟翼】、【奔霄】，其中【奔霄】，编剧原本有意计划是用作玉梁皇坐骑之名。

据编剧透露，穆天七护是特摄组以3D打印技术制作而成，所有细节都不马虎，包括头冠的样式，也是精心设计过。

穆天七护于《霹雳狼烟之古原争霸》第50章被假玉梁皇使用时遭倦收天与原无乡联手击破。

其后玉梁皇用无形神铁重铸穆天七护，并以超光灵珠提升速度，但无形神铁于《霹雳天命之仙魔鏖锋》第14章被生命练习生与红尘雪摧毁。

## 角色经历
玉梁皇大事概要建立武都玉梁皇出身北嵎周边外族之一，依靠冥冥之神（地冥）的指引与恩赐力量，年少便建立武都，然当时国力尚不及北辰皇朝，武都只是天都北嵎外的一族，族中之人，可借着山道进出北嵎皇城。

非命谷之会召开，夸幻之父将古原玉枢令赠与年轻的玉梁皇等人，玉梁皇从而结识天剑老人，并初见映鸿雪，对其一见钟情。

为了玉玺之命枪法，筹划消灭天枢世家，追杀寒武纪、孤星泪父子。

进退枪楼在初代天子枪玄域天枢的血案之后，枪界广征人才，玉梁皇加入枪楼，并在短短期间，便成为三冠之首。

天子宴召开，紫烨疾邪获得冠冕，却因故不受枪界高层承认，乃退出枪楼，另组六道神兵府，并与玉梁皇、单锋剑魔应笑我结识。

多年后，天子宴乃重新遴选天子枪，玉玺重明在天子宴上，击败三生亚父等高手，成为新的天子枪。

玉梁皇百器神决展开，玉梁皇不满天子枪传了卧龙隐一招，让卧龙隐用天子枪的名义，参加百器神决，遂愤而约战天子枪，落败之后，离开枪楼。

建立皇朝北辰皇朝覆灭，四方部族陷入混战，玉梁皇率领武都族人击败众族，统一北嵎，更名为“武都玉嵎”。

后受邀参加旷世穷武盛宴，进行古原争霸。

古原争霸古原争霸需要夺得他人八纮钥和自己玉枢令配合，方能算胜利，获得山海奇观宝藏。

玉梁皇率先抓红尘雪侍女，逼迫其交出八纮钥。

红尘雪交出八纮钥，实际上是祸水东引。

果然，玉梁皇成为众矢之的。

但玉梁皇凭借虚虚实实的替身与冥帝之精，最终派虎冠开启山海奇观，殊不料，夸幻之父背约杀死虎冠。

于是玉梁皇与圆公子等联手，更和邪天子结盟，一同对付天子枪、夸幻之父、解锋镝等人。

最终获得了山海奇观大批宝藏。

积极发展玉梁皇将大批宝物养皇朝龙脉，并算计孤星泪去对付红尘雪，谁知被孤星泪识破击败。

不甘心的玉梁皇不择手段报复孤星泪、红尘雪二人，用手段抓到二人后，羞辱孤星泪，并透露自己早对红尘雪有意思。

关键时刻，天迹入世，救走孤星泪、红尘雪二人。

结局玉梁皇收到红尘雪战书，在北域龙脉之地决战，却不敌被红尘雪，龙脉更是被孤星泪所断，武功尽废，沦落荒野。

神志不清，最终被改造成暗影的寒武纪拦截报仇。

玉梁皇被废去双臂，断掉双膝，毁去面容，在荒野为狼群吞食。

# 羔百年
================================================================================

羔百年

古武族的宗老，沉稳持重、内力深厚的老者，以先知为精神领袖，领导残存于西疆鎏沙地的族人，等待太武降临拯救受困天险的古武族。古武族曾为魔之一方战力，却被冠以背叛之名追杀，如今卷土从来，势将影响未来局势。

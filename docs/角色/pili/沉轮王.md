# 沉轮王

霹雳布袋戏虚拟人物沉轮王，霹雳布袋戏虚拟人物。现今的欲沉轮之主，在过去欲沉轮亡国当下，前任欲沉轮之主海霙在逃亡之时，遭到仇家血歃族二首领将血歃族内特有之血肉精血注入腹中，因而怀胎诞下沉轮王。成人后的沉轮王虽看似憨痴，却拥有着强悍霸道之力及剽悍外貌，甫入苦境便一掌毁灭一际云川，震撼苦境四野。但如此强势作风下，沉轮王也拥有最纯真的赤子之心，对部属极为照顾，因而受到欲沉轮子民爱戴。

## 虚舟浮帆组织介绍

欲沉轮耸立于悬崖之国，拥有九轮天内最坚固的防卫机关术，九轮天童蒙皆知的“纵天神之矛、狱神之火，也无法惊动欲沉轮的睡梦。”即在赞誉欲沉轮的护城术，久远前，欲沉轮由美貌倾国倾城的女皇海霙治理，与血歃族相望，长年受好斗的血歃族侵扰，但凭借着无缝天镔弩，长久以来立于不败，但为彻底解决血歃族的袭击，海霙周游各国寻求他国协助。

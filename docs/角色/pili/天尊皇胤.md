# 天尊皇胤

天尊皇胤为五龙之中的皇者，个性直率、行事风格仁慈，奉行王者之道，是五龙中最受尊敬的兄长。在如此具有王者风范的外在下，内心也极重视兄弟之情，无论发生何事，都会守护所有兄弟，这才是天尊皇胤。

# 汲无踪

霹雳布袋戏虚拟人物汲无踪，霹雳布袋戏虚拟人物。“一夜飞驰，百里猎首”闻名南武林的正义侠客，为人个性洒脱率性，极富正义感，在参与造天计划后发现六祸苍龙阴谋，欲退出计划却被重创，藏身于酒党疗伤，时疯时好、记忆残缺。在莫召奴协助下进行换心，并配合诈死，揭穿六祸苍龙之阴谋野心。

## 角色设定

## 角色经历

以“一夜飞驰，百里猎首”闻名于南武林，并以自创的无踪剑法被称做一代剑侠。

为人个性洒脱率性，嗜好杯中物，极富正义感，因曾为酒党赶走叛徒酹醉成狂‧蒯独渺，而被酒党众人视为恩人。

当初因追查血案而遇上六祸苍龙，两人惺惺相惜，结为好友。

后更受其邀约，加入造天计划，自称为飞，于仙和剑负责剿灭不肯合作与心怀不轨的武林派门。

但在荒城一役，却发现自己所行错误，而与书一同声明退出，却遭六祸苍龙袭击而重伤，时疯时好、记忆残缺，被酒党带回疗养。

酒党灭亡时，与鱼晚儿一同逃出，但因误入蒯独渺的酒窖取酒，而被其追杀，后为莫召奴所收容。

之后，六祸苍龙复出，又被受其指示的毗非笑联合蒯独渺逼杀，在莫召奴与一页书周旋下免难。

而为了揭发六祸苍龙的野心，汲无踪假装在换心手术不幸身亡而诈死，趁其过于骄傲时重伤他。

但后来，因为寂寞侯之计，而被误以为是杀死武联会长老的凶手，受到多方追杀，又被鱼晚儿所救。

然而，因为策马天下想得到无踪剑法，被其与凤无首设计出招。

之后，因听闻禁武令之迫害，为诛杀六祸苍龙再出，又为了鱼晚儿的安危坚持不与其相认。

在法云子与千流影的围杀下跳落悬崖，被鱼晚儿所救，情急之中与其相认。

后因怒于寂寞侯的失信背约，选择再入江湖，与素还真等中原等人共抗六祸苍龙。

而后，邓九五为除掉圣阎罗，而一度被其金封，配合演出，但因嗜杀者出现而失败。

在素还真欲寻回神鹤佐木记忆时，一夫挡关守在定禅天外，面对东瀛进攻，但因为招式早已被透析，而被重创，幸赖恢复记忆的神鹤佐木与素还真及时救援，其后与鱼晚儿退出武林。

后弃天帝降世，伏婴师受命派遣魔将八荒神野捕杀武林高手，为保护祖父新丧的越小枫与妻儿，而与其一战，但因宝剑被夺而不敌，被中途赶到的柳生剑影所救而未死，其后自愿与妻子留于无佛寺中照顾灾民。

## 角色能力

## 人物影响

汲无踪与鱼晚儿的爱情故事在霹雳布袋戏中通过双人曲《情醉无踪》和《伤心酒店》呈现。他们的感情发展从鱼晚儿照顾汲无踪开始，历经诈死、分离，最终相守并退隐。汲无踪的脸型圆，曾引发戏迷调侃，如“天呐! 这世上居然还有比素素的脸还圆的人!!!”。汲无踪与妻女在帮助中原正道后安然退隐。

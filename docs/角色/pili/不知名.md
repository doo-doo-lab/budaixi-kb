# 不知名

素续缘于葬尸江重生，洗净邪气、反璞归真的小沙弥，因追赶龙气意外闯入七彩云天，以过人的智慧和机伶反应，通过三圣佛考验成为七彩云天的第一任住持，领导正道对抗合修会的野心。

### 人物记录

曾经在葬尸江边一声震散一页书、欢喜佛、孤愁先生当时的三大高手。轻松答上了三圣佛的问题。得到圣佛宝裟主动认主。以一片红叶困住鬼王棺。揭开残杀孩童的真正元凶——鬼王棺。一人探非常道。被合修会诬陷，一页书为救他战死黄甫桥。跳下黄甫桥后被曹百哀所救。一人独自挡下天残武祖三招而丝毫无受伤，后服下玩命金丹昏迷，被玄真君等人所救。与青阳子在魔域单挑，因年幼内力不足输于青阳。被血道天宫抓住，受释阳丹而恢复素续缘样貌。

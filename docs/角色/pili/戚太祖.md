# 戚太祖

================================================================================

霹雳布袋戏虚拟人物戚太祖，外文名Qi Tai Zu，别名步武东皇、烈颜不破，是霹雳布袋戏中的虚拟角色，由黄文择（闽南语）、林协忠、江小北、孙诚等配音。2012年12月14日初登场于《霹雳惊鸿之刀剑春秋》，退场于《霹雳侠影之轰动武林》第23章。戚太祖出身东皇玄洲金狮帝国，实为覆灭帝国的末代太子，创立武道七修并开发八品神通理论，著有《六识宝典》。其创建七曜定尊会、葬刀会并主导凋亡禁决，以游戏引发武林动乱。曾与超轶主激战后隐退创出半部灭神之招，最终被七修传人绮罗生击杀。身为五大传奇之“东皇”，戚太祖兼具枭雄野心与深沉谋略，为霸业不择手段，却在维护七修名誉的后辈手中终结霸业，印证因果定数。

## 经历
戚太祖原乃金狮帝国之太子，当初误以为父王欲传位二王子癫不乱，戚太祖一怒之下率兵叛变，帝国老臣凤麟君豁命为他剪除阻碍势力。戚太祖攻破宫闱之时，见先王已自杀殉国，愤而毁灭帝国基业。而戚太祖自立门户，一手创造了定尊会、葬刀会等组织。为了探知金狮币下落，设计凋亡禁决之游戏。为了开启壁窟取出庞大遗产，戚太祖（曾化名烈颜不破）暗中再次策画凋亡禁決，在组织中担任策画者，并在两次禁决中被称为邪魔。而游戏的屠戮渐渐让戚太祖残缺的内心得到满足，后来他将游戏规模扩大，欲造成武林大乱，进而从中得到更多的利益。其后，戚太祖曾于非马梦衢挟持人质逼迫无梦生，最终在与暮成雪的死决中施展七修之招。

## 人物评价

戚太祖，有着枭雄的野心，也有着枭雄的深沉智慧，在算机阴谋之外，更有为完成霸业付出一切在所不惜的决心及气魄，宁可负天下人，不可天下人负我的极端心态，让聪明绝顶的帝国皇子、武学奇才，终是一步步走向自我毁灭的道路。戚太祖是武道七修的创始者，却也讽刺的败亡在维护武道七修名誉的后人之手，让牵扯进无数人命的霸业雄图戛然而止，也印证了天网恢恢，因果轮回的冥冥定数。

## 人物配乐

官方图片步武东皇（戚太祖角色曲）曲/编曲：丁天牧 收录于《刀剑春秋原声贰-精选41》（即《霹雳英雄音乐精选四十一：霹雳惊鸿之刀剑春秋贰 (电视原声带)》）丁天牧老师2011年作品，以「大雅风行」为题创作，中西弦乐演奏出古典优雅的乐曲，东方儒雅的曲风中，散发着潇洒豁达的气息。

乐曲为七修创者「戚太祖」角色曲，初次用于刀剑春秋第16章，步武东皇重获自由回到通天道，轻昂的步伐，搭配节拍落点、以及二胡筝弦之声，潇洒惬意中，展现着一代宗师的风范气度，亘古传承。

该曲在部分专辑曲目列表中亦作“丁天牧、霹雳布袋戏- 步武东皇”或“丁天牧 - 步武东皇”等别名。

最终死决（暮成雪VS戚太祖）曲/编曲：李耀廷 收录于《轰动武林原声带贰-精选44》李耀廷老师二○一三年作品，急促的旋律铮铮作响，跃动的鼓击声，宛如风雨欲来让人焦躁不安，随着节奏激昂迭起，宣告着一场生死决斗就此划开。

乐曲初用于轰动武林第十八章，今生最终之死决，只为死前最后一份欣慰，为情、为义、为报超轶主之仇，暮成雪不惜玉石俱焚，誓杀戚太祖！

坚毅决心，无悔无惧，内心压抑的情绪伴随着激昂乐章尽泄于此役。

乐曲同时也用于别黄昏约战最光阴之桥段。

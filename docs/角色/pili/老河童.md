# 老河童 (老河童)
================================================================================

老河童

自識界裂縫偷渡到人界的老河童，修練成精的龜仙人，本性好色，喜歡偷盜漂亮女子的貼身衣物，曾假借河神之名誘拐少女，成立雜牌妖獸團，騙吃騙喝。因垂涎玉傾歡，而答允正道聯手佈下四象乾坤九星儀。

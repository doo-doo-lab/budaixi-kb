# 識天樞 (识天枢)
================================================================================

識天樞

六一天心垣的上清宗之主。仙風道骨、律己甚嚴的修真道者，性格擇善固執，因而令人感到凜然不可侵犯，不怒而威，致力守護天心垣道規清律，主張不涉下界苦境神州的凡塵俗務，有時令人感到尖銳而不近人情，實則是為了固守自我的堅持。與玉清宗之主別參辰，同為下任天心垣主的有力競爭者，彼此之間互為勁敵，彼此有著強烈的競合關係。

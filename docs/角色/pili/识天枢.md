# 识天枢

六一天心垣的上清宗之主。仙风道骨、律己甚严的修真道者，性格择善固执，因而令人感到凛然不可侵犯，不怒而威，致力守护天心垣道规清律，主张不涉下界苦境神州的凡尘俗务，有时令人感到尖锐而不近人情，实则是为了固守自我的坚持。与玉清宗之主别参辰，同为下任天心垣主的有力竞争者，彼此之间互为劲敌，彼此有着强烈的竞合关系。

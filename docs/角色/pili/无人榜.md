# 无人榜

枪界天子台辅权，从容尔雅，精通术法，乘天选御舆、隐身画轴中，遴选枪界高手而入世。与天枢世家之主寒武纪本为至交，加上不屑枪界主事行径，遂顺理成章转为协助暗影，掌控天子台、并鉴定孤星泪、紫烨疾邪成为暗影左右手，与幽界分庭抗礼。

## 势力关联

通过天子台组织建立战略据点，该组织具备鉴定人才的特殊职能

将孤星泪与紫烨疾邪两位角色认证为暗影势力核心成员，两人分别承担不同战略职责

与幽界的对抗关系构成主要矛盾冲突，形成势力制衡的局面

## 战略布局

在2017年剧情线中，无人榜主导的战略部署包含三个核心层面：

人才遴选机制：通过天子台的鉴定体系筛选优质战力

权力架构建设：确立暗影势力的层级管理体系

地缘政治博弈：针对幽界势力制定系统性抗衡方案

## 人物特质

审时度势：精准判断势力格局变迁趋势

知人善任：成功发掘孤星泪、紫烨疾邪的潜在价值

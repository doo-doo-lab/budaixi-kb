# 南柯补梦

来自西佛国的神秘异能者，个性孤僻、独来独往，拥有编织梦境、吸人入梦的能力，能在梦中杀人于无形。

## 角色背景

名言锦句

诗词

人生何足，欲望难全，既索千金，又求美眷；
富贵兼备，百年寿短，烦恼苦思，唯有梦全。

## 角色能力

专长

补梦大法

## 角色经历

在《霹雳劫之阇城血印》第24集中，南柯补梦设计以梦境与现实两面逼杀对付变裔天邪，变裔天邪亦欲寻找其真身，但南柯补梦在最后一刻体力不支，重回梦境之中。

## 角色配乐

南柯补梦

作曲/编曲：孙敬凡

收录于《阇城血印原声带》

该原声带由无非文化制作，发行于2004年07月30日，为双CD专辑，时长约90分钟，收录了包括“阇城”、“儒门龙首”、“魔龙祭天”、“血琴”、“南柯补梦”、“禔摩”、“苏安”、“流川飘渺”、“玉界尺”、“独夜人”、“宫灯帏”、“邪之子”等曲目，以及阿轮演唱的片尾歌曲《梦中戏》。

此外，“南柯补梦”亦收录于专辑《霹雳布袋戏剧集原声》中，该专辑还收录了“儒门聚首”、“魔龙祭天”、“血琴”、“玉界尺”、“独夜人”、“千秋映江月”等曲目以及阿轮演唱的片尾曲《梦中戏》。

# 剑南天

小说《仗剑初》中的角色剑南天是小说《仗剑初》中的核心角色，天极大陆巨洲地域承影巨洲中的意剑府出身，身负火木双灵根，原为资质平庸之辈。获万古机缘万象祖源后崛起，被极元宗当任宗主定为下任少宗主，后遭神魔双生体算计，业火缠身化出第二人格，被世人冠以“剑魔”恶名长达九千年。其修道历程跌宕：初遇云落笺结为道侣，业力转化为人格分裂。隐匿九千年后携慕青阳复出，于域外入侵中斩尽天族修士，终以“绝天剑帝”之名飞升天尽之穹，成就剑帝、极丹帝师双境巅峰。剑南天以逆道十步四步握源之姿横跨十亿年时空，从卑微府邸弟子至执掌万源宗，其传奇贯穿资质蜕变、正邪交织与终极飞升，世间永铭“绝天剑，名南天”之叹。

## 角色背景

资质下等，火木灵根，原本将于承影巨洲度过平凡一生的命运被丹域帝丹宗核心弟子云落笺为了参加韵尘天域丹云院考核而寻找着“幼丹者”而改变，后于帝丹宗与“诸天戮尽系统”相遇且愿意付出九成精元用以换取万古不出资质与万象祖源，资质与祖源获得了但精元并未消失，后隐藏实力于丹云院考核时一鸣惊人，被丹云院看中万象祖源与万古不出资质收为准圣子，云落笺也被收做内门弟子，时间飞逝，终于在二人相识的第两千七百年整，剑南天表达心意二人结为道侣，后进入九大圣域中的极元宗所在的极元圣域内，被定为极元宗下下任宗主，后三百年云落笺失踪，禁体出世，九上宗被连灭六宗，将云落笺格杀于剑南天面前，禁体使术巫傀儡线将其控制屠戮一域之人，再往后禁体被当任极元宗宗主突破灵道境灭杀，术巫傀儡线禁制消失被无数孽力缠身甚至转化为了业力，五十年业火一降，若非鬼无魄将其孽，业力分成了第二人格，否则剑南天必将陨落，由于第二人格无恶不作的原因导致剑南天后世整整九千年被世人称作剑魔，在极元宗外遇见昏迷的慕青阳将其救回极元宗内。

## 角色形象

一袭陌黑色长袍着身，发丝过肩披于身后，面庞不算俊俏，但也算是有些许出众，嘴角时长挂着一抹淡笑，周身漂浮着一柄剑身为漆黑色的无鞘剑器，约三尺长度，两指宽有余，剑柄则是蓝灰色交错，气质出尘仿佛天外之谪仙。

## 角色能力

境界时间线及位面修道境界剑道境界丹道境界魂道境界天极大陆（十亿年前）半步灵道境剑帝境极丹帝师万象帝师玄元大陆（残魂）成帝境天帝巅峰剑宗地丹四品天魂三品天尽之穹（十亿年后）逆道十步第四步握源未知未知未知灵根五行灵根道品祖源天品仙源金灵根万象祖源天火仙源冰灵根绝寒祖源天冰仙源木灵根-天雷仙源水灵根-天风仙源土灵根-天阳仙源火灵根-天阴仙源体质及血脉寒灵剑体乃是天尽之穹体质榜剑体小榜排名第三与总榜排名一百四十七的体质，对剑道与冰之一道极其亲和，甚至拥有名为冰至幕天的体质形态，可冰封天地。

世吞血脉天极大陆血脉榜排行末尾的体质，只因为并没有特殊的能力，如果真要说有，那便是可配合心法夺取他人灵根，可吞食修者血肉增强修为。

装备绝天（剑）慕青阳在十亿年后的玄元大陆道圣域道圣宗陨山所获，传闻是道圣宗的一位前辈所留，进入十亿年后的天极大陆由剑南天借走，绝天之名乃是世人所取，意为诸绝天族，由不知名材料所铸，坚韧且锋利无比，未饮血前通体漆黑，剑柄蓝灰色交错，约三尺长度，两指宽有余，沾染上血液后剑身红黑相间，若十二个时辰末饮鲜血则变回漆黑，此状态下战力将提升三成左右，飞升前剑南天请来天极大陆仅有的十四位极器帝师铸造此剑之仿品，铸造七七四十九天后成品被剑南天将其命名为绝道，将绝天埋藏在道圣宗陨山下，等待着慕青阳十亿年后取回后，持绝道飞升天尽之穹。

绝道（剑）由天极十四极器帝师按照绝天为原型花费天极整个大陆七成可收集到的云魂铁外加数种宝物且耗时七七四十九天倾力铸造而成，长宽与绝天相似，剑身由纯红与暗红双色组成，剑柄则是呈现漆黑色，极其沉重，举起时只感觉整片天都压在自己手臂上，境界不过圣道不可握，如若不至，轻则被重量碾断手臂，重则七窍流血而亡，剑鞘为天尽之穹一处秘境所获，插进剑鞘后可举重若轻，就算是凡人都能提起。

# 金獅 (金狮)
================================================================================

金獅

魔吞十二宮的金獅宮代表，臉戴金色獅子面具，身著黃金皮甲，雙臂展現健壯體魄，狂傲威武的行事風格下，有著如萬獸之王獅子一般的驚人氣勢。儘管手持布刀，卻能於戰場上所向披靡，一刀劈落、威震天下，剛強霸氣的刀法，使其傲視群雄。

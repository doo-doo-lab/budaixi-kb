# 蝴蝶君
================================================================================

蝴蝶君

北域三大刀剑传说之一，性恶的信奉者，潇洒、自我风格强烈的收银买命杀手。毕生视钱如命、精打细算，最爱黄金与阿月仔。行事干净俐落、绝不拖泥带水，擅于操纵蝴蝶杀人，其刀法造诣之高深，乃北方武林之首。

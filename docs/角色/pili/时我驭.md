# 時我馭 (时我驭)
================================================================================

時我馭

魔息大帝麾下六將排行第五，個性殘酷陰絕，以一口淬有特殊毒性、開八面鋒銳的「毒龍八封」為武器。能與刺槐無生合招，施展燬天之箭。因支持魔息大帝復辟，被九輪天視為棄子，派出泯滅生門的殺手殺之。

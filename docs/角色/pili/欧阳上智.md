# 欧阳上智（霹雳布袋戏虚拟人物）

================================================================================

欧阳上智，霹雳布袋戏虚拟人物，别名号世令主，由黄文择配音，初登场于《霹雳眼》第18集。作为欧阳世家领导者与武林至尊，其凭借过人智谋广纳义子创立霸业，被素还真、谈无欲评为天下第一智，其残忍无情、不择手段的行事风格引发正道人士强烈反感。曾以公开亭逼降素还真、无极殿登基等事件震动武林。欧阳上智多次通过诈死脱困，自导自演死刑岛逃脱事件，化身海上浮尸传授非凡公子破世阴字，又易容铸剑老人忘年联合千山樵老布局武林。先后策动叶小钗退隐、扶持金小开夺权，建立无极殿后暗中操纵武林局势，联合谈无欲在八阵滩围杀素还真，并设计挑拨魔魁与素还真敌对。晚年因魔魁崛起与方界入侵逐渐失势，试图挑拨无忌天子未果，最终在《霹雳狂刀之创世狂人》第2集被射日必杀组成员双龙背击杀，终结其枭雄生涯。中文名欧阳上智别 名号世令主配 音黄文择性 别男登场作品霹雳眼、霹雳至尊、霹雳孔雀令、霹雳剑魂、霹雳异数、霹雳劫、霹雳天阙、霹雳紫脉线、霹雳烽云、霹雳天命、霹雳狂刀、霹雳王朝、霹雳幽灵箭第一部、霹雳幽灵箭第二部、霹雳英雄榜、霹雳烽火录、霹雳风暴、霹雳狂刀之创世狂人身 份欧阳世家领导者、武林至尊根据地无极殿、流亡岛组织门派欧阳世家化 身海上浮尸、忘年本尊雕偶师徐炳垣出场集数465集

## 人物经历

欧阳上智，欧阳世家领导者，智慧超群的武林枭雄，性格多疑狡诈狠毒，以称霸武林为志向。欧阳上智是素还真和谈无欲最头疼的敌人，曾被两人评为天下第一智。欧阳上智广收义子为自己效命，收纳了不少武林知名的人物，欧阳上智也广施恩惠，借此收揽人心，像叶小钗解开“只手之声”，换得叶小钗为己效命二十年。当年，宇文天假扮剑藏玄之师-平天子，在欧阳琳和剑藏玄的婚礼当夜毁灭欧阳山庄，欧阳上智趁机退隐幕后操纵大局，计赚宇文天。欧阳上智给一线生一本假的欧阳世家家谱，在公开亭逼降素还真，后在无极殿登基，成为第一位武林至尊。利用阴月夫人寒雪飘所赠的宝座诈死，借此试探义子们的忠心。重归台上后，曾为欧阳世家霸业，欧阳上智设计萧竹盈和其生父流星君乱伦，使得流星君长跪赎罪岩。在南征南霸天时因手下离心被流放在死刑岛。于是欧阳上智自导自演“真假欧阳上智”之谜，顺利地自死刑岛逃脱，使素还真二度败于其手。后来，素还真、半驼废、谈无欲、百里飞首、千手毒王联合围困指天树，最后死于仇魂怨女之手，但只是诈死，欧阳上智借机隐遁流亡岛。欧阳上智在非凡公子流放海上时，欧阳上智化身海上浮尸救其一命，更传授其破世阴字，交待他回中原策动“号世阴令”重现江湖。后设下至尊擂台将叶小钗逼入无极殿，使得素还真也进入其中。欧阳上智以海上浮尸的身份约谈叶小钗，恩义并使加上抹黑素还真，逼得叶小钗进退两难终退隐江湖，欧阳上智则计策帮助金小开在无极殿杀害冒牌素还真。欧阳上智易容化身为铸剑老人-忘年，以此身份行动，和千山樵老结伴游武林，更在拜天坛十八乞与樵老结义。欧阳上智通过了魔域帝尸缸和焚钟律管的测试，但在和樵老赌约中落败，承认自己是素还真，顺水推舟入主无极殿，后设计金小开诈死，进入天外方界探查秘密。欧阳上智又假扮素还真指派任务给零，使神鹤佐木对素还真产生误会而想杀之。在到天外方界后，欧阳上智向白云骄霜坦承身份，全盘托出与谈无欲合谋杀害无忌天子的真相，后又下令炸毁流亡岛，吩咐六分刀杀分不开，拆毁英雄战场。欧阳上智在铸剑芦和千山樵老摊牌，共同拟定日后的武林大计。欧阳上智告诉玉天玑自己的身份后，假装被驱逐出无极殿，进而将组织化明为暗；联合自己手下和谈无欲的杀手，在八阵滩围杀素还真。天栈峡谷，欧阳上智会谈谈无欲，安排六分刀假扮浮尸来陷害素还真，却被魔魁破坏，便将六分刀毁容瘫痪的过错推给素还真，让双龙背针对素还真。后来，忘年和谈无欲逼迫素还真约战魔魁于荒龙道，自己又偷袭魔魁，使魔魁对素还真更为恼怒。忘年私下又告知一页书樵老用圣果救素续缘的事，想借刀杀人，未果后又与谈无欲合谋绑架素续缘来威胁素还真，后被一页书阻止并救回素续缘。欧阳上智和白云骄霜、谈无欲混战傲笑红尘，不敌而逃往苦行岩陪素还真磨石柱、取神剑。在藏身琉璃仙境时欲杀盼梦圆灭口，但被素还真阻止。为找寻花爵百炼生，欧阳上智被困在耆老迷，后被百炼生救出充当信使。欧阳上智贼心不死，暗中挑拨无忌天子，使无忌天子要求傲笑红尘杀素还真，为愁月仙子报仇。在素还真陪君夫人前往东瀛时野心又起，被射日必杀组锄奸杀死。

## 人物评价

曾经不可一世、曾经独霸天下，武林霸主欧阳上智自流亡岛重新回到中原后，便展开了一系列的复仇活动：召集旧部、瓦解天下万教、攻打游离派门最终建立了无极殿，暗中扶持金小开成为武林盟主，但王朝犹如昙花一现，欧阳上智的上智之智仍然无法对抗外部风云变幻的武林，魔魁兴起、方界入侵，欧阳上智彻底败给了素还真，最后死在了素还真的射日必杀组成员双龙背手中，结束了自己的罪恶而又传奇的一生！

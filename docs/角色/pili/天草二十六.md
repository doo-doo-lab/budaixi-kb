# 天草二十六

================================================================================

霹雳布袋戏虚拟人物天草二十六，霹雳布袋戏虚拟人物。居住在海波浪的天才劍士，有著浪子般的氣息，個性大而化之，常口是心非，越重視的東西越表示討厭疏離。患有心悸，算命的說他二十六歲會死，而他今年正好二十六歲。中文名天草二十六别 名小草配 音黄文择性 别男登场作品霹雳神州登场作品霹雳神州II之苍玄泣角色编剧罗陵本尊雕偶师洪有聪出场集数60集挚 爱如月影

## 角色能力

剧照武学：逆草回影、飞鱼游刃、飞鱼破浪、勾刃破浪封沙尘、海波浪、逐海之浪、奔浪关、飞影残虹、一剑任天真、飞鳞逆江、疾风乱舞、双剑连击·天下无敌（与伊达我流合招）武器：天草剑鞘柄以戽斗状般的开合设计，易于拔剑，而皮革般的剑柄和鞘身，让外观上更添独特风味，剑身护手至剑锷处呈叶形状，逐渐内缩成一尖锋，锋利无比。

## 角色经历

剧照居住在海波浪的天才剑士，与一月三身如月影同时出场。后者其时依宿命只身回到海波浪，直言为天草的性命而回。而异度魔界急于寻找百年无罪之人开启万血邪录，毁灭神州，目标锁定海波浪。天草对如月的宿命论一向很反感，表面上虽与如月影唱反调，但对如月的任何要求都不曾拒绝；虽一直叫嚷如月“神棍、神棍”，但是却一直尽心照顾他，魔界三番两次造访海波浪，天草更是豁命保护如月的安全。然而既定的宿命之刻到来，赭杉军为阻止神州祸乱来到海波浪欲杀如月影，遭到天草的阻止，而此时伏婴师操控时间，加速如月生命的流逝，如月即应天命，伏婴师趁机夺取无罪之人的魂魄，万血邪录应时开启，神州浩劫随之而来。面对如月的离去，天草悲伤不已，但如月的留书让天草相信会有重逢的一天。之后，天草与赭杉布局击杀伏婴师，并和中原正道人士一起保护神州安危，期间遇到东瀛剑圣柳生剑影徒弟伊达我流，两人成为莫逆之交、配合无间。两人受邀入红楼剑阁，伊达娶妻，由于红楼的规矩，遭到剑阁、竞天宗追杀，被剑圣所救。之后，天草便与伊达回到东瀛。天草对如月那句类似告白的话让人感动：“是朋友也好，是什么也好，你活着，无论什么状态，我都会等你到天长地久，你若死，同时赴死，黄泉路上也不孤单”。天草与如月影之间的情令人感动；而与伊达我流的默契，又让人开怀，然而人生的酸甜苦辣，并不曾改变天草乐观的本性，也许这也是如月所期望的结果。

## 角色记录

如月影与天草诀别：（神州30）天草：『这条命运路上，你会等我吗？』如月影：『也许，是你要等我了。』天草：『我知道你在暗示我什麼，但你记著这句话，是朋友也好，是什麼都好，你活著，无论什麼状态，我就会等你到天长地久，你若死，同时赴死，黄泉路上也不孤单。』一年愁病身，一爱喜如生，一语惊世俗，一剑任天真！（神州30，对上赭杉军施展绝招所吟）

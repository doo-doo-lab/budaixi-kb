# 平如蘅

儒门四锋之一，性格温文儒雅、举止高端，处事态度看似随意不羁，却对自己所在意的事物会以极度认真的态度去看待，有着将喜爱之物丢弃的特殊习惯。为名锋“以一贯之”的主人，同时与忧患深为旧识，因白沙书院入学一事而再度会面。

## 来自百度百科的补充

平如蘅是霹雳布袋戏虚拟人物，儒门四锋之一，称号“学门无书”。其性格温文儒雅，行事看似随意却对重视之物极度认真，惯将所爱之物丢弃，持有名锋“以一贯之”，武学融汇儒门经典，招式如“平风一夕雁”“一剑贯中行”皆含中庸之道。出身儒门，曾为忠烈王府匾额留名者，后主事崇圣之光，与忧患深为旧识，因白沙书院入学事件再会。

学门无书平如蘅，儒门中人，忧患深好友。曾是忠烈王府匾额上留名者。因白沙书院诸异见闻开课，暂歇崇圣之光的事务，在忧患深的提议邀请下，提早与他一同离开崇圣之光现世。两人一路游赏至白沙书院。

灭凡超圣——海枯石沉·忧患深（灭凡超圣语出《老子》，招式六凡灭剑，出自《孟子》）

此笔乃以罕世的麒麟毛，谪仙玉所制，世出无二

## 角色经历

平如蘅曾代表儒门天下参加“华山论剑”，在第一轮第一场比试中对战武当派莫邪道长，使用名锋“以一贯之”，先后施展武学“平风一夕雁”、“一剑贯中行”及“剑不移·锋不易·至诚一道”击败对手，此战中仅用了七成功力。

因袭玉佩，而与忧患深结识。

从拂晨手中救下命危的燹王以及哑女尸体，带回白沙书院。

在白沙书院死决中，为护好友忧患深，亡于阎王之手。

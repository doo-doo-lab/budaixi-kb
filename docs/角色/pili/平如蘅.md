# 平如蘅 (平如蘅)
================================================================================

平如蘅

儒門四鋒之一，性格溫文儒雅、舉止高端，處事態度看似隨意不羈，卻對自己所在意的事物會以極度認真的態度去看待，有著將喜愛之物丟棄的特殊習慣。為名鋒「以一貫之」的主人，同時與憂患深為舊識，因白沙書院入學一事而再度會面。

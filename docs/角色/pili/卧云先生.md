# 卧云先生

清香白莲的化身之一，素还真于印心洞术法取出刀剑的同时借机隐身幕后，后以卧云的身份出现。因有着深度的智慧与不凡的武功，在诡谲武林中，领导正道对抗佛魔合体、智破天下第一人的计谋。个性风趣、玩世不恭，温文儒雅气度，使大家耳目一新。

### 武器补充

- **无弦琴**：以古木所制作的典雅古琴，此琴的最大特色是有琴徽而无琴弦
- **大悲三昧弦**：造型极为特殊的圣琴，琴座凝水为冰而成，故澄澈透明，琴座头端则有鹫灵寺三僧般若之颅，琴弦则为血红色的法髓之筋

### 角色经历

1. 卧云先生最初现身于瀑泻古岳之上的云眉栈，并智取秦假仙，得到他的信任和信服。为保护素还真，取走叶小钗身上的刀剑，带秦假仙到印心洞，解释素还真的事情。在相思林弹琴，结识琴魔。
2. 设计前来索取刀剑的晏定邦到黑暗道，让黑暗道中的人感化晏定邦。建议琴魔与白无垢回到魔界并相约每半年在落阳关一会。善劝女乞丐染飞烟别再助其师为恶。在正义坡要叶小钗收起晏定邦给素还真的东西。
3. 轻易打败血眼沙陀，并收他为徒，后派他到天葬协助三小僧到究竟天涯。后以菩萨印第十一式吓退圣法，让其弃暗投明。因刀魔被封印石牵制以及天葬之事，前往圣城找寻圣母。因不想见太阳女，设计圣法缠住卷云和积云。
4. 在印心洞外和风中行者试探印心洞的底细，后要求冷封尘放过残余的风中行者。因封印之事遭封印石针锋相对，遣刀剑双魔来袭。要层云治疗星野残红、处理剑魔之事。
5. 以晏定邦的四只钥匙和封印石交换秦假仙的性命。带假认吾师到印心洞找寻传家宝剑，将云眉栈迁到弃胪潭以便探查西酆残雪的底细。请出傲笑红尘参与制造圣琴，并与琴魔合奏，促成佛魔分离。设连环计抓住蘅佛子，不料被天下第一人中途拦截，后以素还真的智慧之叶换回，并将之带到金佛塔静修。
6. 受圣母之托主导第二次佛魔合体，并与四云辩论佛魔再度合体的优劣，后成功唤回天魔意识。收下蘅佛子交代的五颗恶灵金珠，并送蘅佛子的骨灰到庄严净土的灵骨塔。
7. 暗示一页书明犀火在太阳女身上，排解一页书和太阳女之事，带太阳女前往春海愁国祭拜被杀的天女，利用太阳女身上的明犀火救活其他被变为石像的天女。
8. 开导认吾师以及冷封尘，要秦假仙前往挂日仙乡处理一页书的事。制服剑被抽走的认吾师，替认吾师悬丝诊脉。往挂日仙乡带环儿回云眉栈，并试探大愚先生的实力；之后将环儿交于灯笼客照顾。
9. 在弃胪潭承认自己就是素还真，并使法定住认吾师的剑影，避免与认吾师对战。擒住运功过度的蓝衣人，将蓝衣人送到圣城交由魔界处理。在云渡山拿回刀剑，被逼三天后带环儿到云渡山证明环儿就是素还真。
10. 向一页书讨保太阳女，带到春海愁国监禁，但太阳女吞下明犀火，功体聚变逃脱。前往挂日仙乡带自在天女到云渡山。带认吾师见到环儿，之后在云渡山拔剑验证身份，环儿变为婴儿。约谈认吾师，暗示印心洞的幕后主使者为司马剑秋。
11. 到远浮天请金色人影救蓝衣人，后带认吾师救蓝衣人，揭开印心洞的秘密。安排苗逢春在耆老迷栖身，取得灭元塔机关图。在灭元塔众人面前假装杀死司马剑秋，交予秦假仙处理，原想私下问话，不料司马剑秋被救。
12. 将环儿和刀剑交给韶云，让云门照顾。请金色人影进灭元塔救荫尸人，不料金色人影被困其中，即上云渡山向一页书求救，被护山气墙所伤。
13. 云眉栈上，大愚排布弓箭手欲除卧云，卧云施展一人六化。在卧云使用了浮云掠空这部功夫时，惊动了韶云。韶云及时解救了卧云的危机，进而想证实他的真实身份是否就是佾云。卧云向韶云说出，佾云将浮云掠空这部功夫传授给他的往事
14. 卧云见到叶小钗所持神剑，顿时明白金小开身陷危险。当赶到时，只见金小开的尸体。
15. 云眉栈上，卧云与韶云深谈佾云之事，韶云将佾云的信给他看。卧云赶到近日峰，见叶小钗被钉在山壁之上，卧云口吐鲜血，说道"是你逼卧云怒上邙山"神剑主人穷八极在高峰注视着这一切。
17. 拂水楼前，卧云恢复真身，便是清香白莲·素还真。并逼出"下"字第一人的身份就是寒心·牧剑子。卧云于现场带走环儿与叶小钗。

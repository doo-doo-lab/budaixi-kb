# 卧云先生 (卧云先生)
================================================================================

卧云先生

清香白莲的化身之一，素还真于印心洞术法取出刀剑的同时借机隐身幕后，后以卧云的身份出现。因有着深度的智慧与不凡的武功，在诡谲武林中，领导正道对抗佛魔合体、智破天下第一人的计谋。个性风趣、玩世不恭，温文儒雅气度，使大家耳目一新。

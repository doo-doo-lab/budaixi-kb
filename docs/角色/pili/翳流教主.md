# 翳流教主

身怀龙气的北嵎亡国之君，在慕少艾协助下吞并南宫神翳部分意识，取而代之成为黑派翳流新一任教皇，浴火重生再创颠峰。蜕变之后的北辰元凰，有着过人的政治手腕与心计，更增三分深沈。

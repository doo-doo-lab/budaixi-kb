# 阎王（霹雳布袋戏虚拟人物）

================================================================================

阎王，霹雳布袋戏虚拟人物黑海森狱最高权位象征，过去一直以华丽鬼面遮蔽面容，无人看过真实面貌，城府心机深不可测，除自身高强武功、能操控黑月之外，更可化出“阎王恶相”示警，增添无匹战力和威势；

此外，阎王更拥有副脑“神思”，互相通达，助其谋算天下局势。

久远前在阎王立下四名继任太子人选后，便遭蜕变黑后与千玉屑算计，困于珈罗殿的八镜阵法中，从此不再出现在众皇子面前，但看似受到牵制于人的阎王，却早已布下缜密的计划，不仅已策划好脱困之法，更暗中透过神思悄悄操弄森狱局势，将反动势力一网打尽。

即便连亲生骨肉，皆被视为可牺牲的弃子。

而在阎王吸收一直以来培养的备体“天罗子”后，外在有着惊人蜕变，并且要以自身力量颠覆整个武林，大兴干戈。

诗号：服心不用七擒策，御侮何劳三箭歌；

高枕幽窗无一事，西人不敢牧长河。

### 武器
- **魔罗天章**
  - 初登场：霹雳侠影之轰霆剑海录 第19章
  - 武器特色：金色与红色交错的剑身，营造如魔剑再临的气焰，护手轮廓有大小尖爪状的线条，呈现魔、怪的神秘视觉效果。
  - 当手持魔罗天章时，许多鲜红血管会开始插入持有者手中，让持有者的手臂与血脉与魔罗天章同命相连。
  - 丰功伟业：魔罗天章原本是阎王的专用兵器，阎王以此剑在多年以前砍断苦境与黑海森狱的通道。
  - 而后魔罗天章辗转与玄同元神兽共生，也成为了玄同的佩剑。
  - 后又自燹王手上取得。
  - 而此剑也是传说中唯一能杀死阎王的兵器，更是造成黑海森狱许多纷乱的起因。
- **狱海权锋**
  - 初登场：霹雳开天记之创神篇 第26章
  - 武器特色：阎王向紫宙晶渊所求得之神兵，为一把形似枪的长柄剑，湛蓝色系的设计，并以宝石、金属等元素点缀，除了能引发阎王全身功力外，更像是象征阎王强大的武功与权力。
  - 丰功伟业：魔罗天章失落，阎王为了完成霸业故求得了狱海权锋，此剑在身的阎王宛如重获神兵助力，更可引动体内元神兽功力，阎王更趁商清逸、山龙隐秀援救紫衍神巨时拦路索命，逼得山龙隐秀只能豁命才能抵抗狱海权锋，却也因伤重而性命垂危。
  - 狱海权锋虽强，却仍是难敌阎王本来的兵器魔罗天章。
  - 与燹王的决裂一战中燹王借着魔罗天章施展千魔荡狱之招，阎王以‘阎神毁’抵御，狱海权锋却是当场碎裂，逼得阎王只能趁隙逃离。

## 经历
阎王活跃于霹雳侠影之轰定干戈、霹雳侠影之轰掣天下、霹雳侠影之轰霆剑海录、霹雳开天记之创神篇、霹雳开天记之创神篇下阕等剧集。神思预言碑写下“阎王命中注定得十八子”，其十八子呼应地狱十八层，谁知黑月异象，第十九子天罗子诞生，成了森狱的变数与凶兆。玄嚣太子与玄灭太子等森狱皇子在苦境扩张势力，引发森狱变局，导致黑月进入苦境，开启二阳灭世。素还真斡旋于天疆之中，设法释放古曜之光，造成三阳同天，以避免武林进入末日之局。

## 角色形象

### 造型设计
- 第一造型风格特殊的面具，呈现一种神秘古文明的风格。
- 人物造型黑色的脸颊，说明阎王被困珈罗殿，因时间过久的苍老、衰退感，黑色也增添了阎王的神秘、深沉。
- 深色的长袍，故意做成破损、褴褛的效果，代表阎王被困住太久的落魄感。
- 第二造型阎王正式现身，充满了埃及法老的风格。
- 缤纷色彩的装饰，与之前的萎靡感的造型产生反差，代表生机盎然。
- 肩上的球型代表星球，周围有卫星围绕的轨道，视觉上十足科幻。
- 以长袍来呈现王者风范，这种款式还能呈现神秘的宗教风格。
- 阎王恶相少见的巨大偶头，看起来非常邪气，并不失狂霸感。
- 因为偶头太大，身体也必须跟着调整，全身比一般木偶大上许多。
- 肩头用毛皮修饰，展现出原始、疯狂意象。
- 露出健美身体的男性很多，这里要呈现一种野蛮风格，微凸肚皮成功展现妖异风格。

### 人物关系设计
阎王的计划渊远流长，层层叠叠复杂交织，多少人物成为计划中的棋子， 其中最需要下定决心割舍、绝情断义的，就是自己的亲人。

### 人际关系
- **玄同**：阎王对玄同，是敌视大过一切。
  - 因为玄同的天生剑觉，更因为魔罗天章认玄同为主，让阎王对玄同，是彻头彻尾的无情。
  - 就算几次和颜悦色阐述父子情感，在阎王心中，玄同这名儿子，是他毕生劲敌，是他一向顺遂的王权之变量，他深怕自己的一切，将因为玄同的出现而改写。
  - 所以他为玄同改立四位太子并争皇位。
  - 一来可更加速推快自己的计划，一来可藉其他皇子之手，除掉玄同。
  - 而玄同对阎王，却是有一份求之不可得的孺慕之情，玄同从小便对阎王剑术，有一份向往，每每想亲近阎王，却不得其法。
  - 他只能远远的看着阎王疼爱自己的兄弟，却吝于给自己一丝欢容。
  - 偶尔的一抹笑意，更多的是附加而来的杀机，玄同不懂阎王对自己的敌意是从何而来，只是笑容伴随着的麝香味，让自己耽溺又厌恶。
  - 当众人沉溺在立位太子的欣喜中而不见其他，玄同只看见王位上的父王，眼中噙着锐光看着自己，鼻间隐隐相浮的麝香味，让自己心痛。
  - 也因此养成了玄同事事疏离的态度。
  - 当人生只能托情于剑，这究竟是幸或不幸？
- **玄灭**：阎王欣赏着玄灭的行事作风，总觉得他的绝情与自己最像，连能将元神兽圈养在外的方法，都那么的像。
  - 在玄灭身上看不到过度又泛滥的情感，他总是恰到好处的展现他的情义，可与不同的人交好，不拘于一格。
  - 阎王想看这样的人，能在王位竞争上起了什么波澜，而实际上这样的人，没有绝对的武力，就只能当个被利用的棋子而已。
- **玄膑**：阎王对玄膑，怜悯多于算计。
  - 在玄膑身上，他看见了不向命运低头的坚韧与负重。
  - 他知晓玄膑是为了向世人证明自己，所以才汲汲于王位争夺，但实际上，他只是一个迷失在感情漩涡中的可怜人，他只看见自己所欠缺的，却不知在阎王眼中，他的欠缺，正是他的幸运。
- **玄嚣**：阎王最疼爱的幺儿。
  - 一个真的有下情感在呵护的幼子。
  - 阎王不懂为什么对玄嚣特别的喜爱，他天资聪颖又善解人意，不全然的像自己，却是有一种吸引自己的感觉。
  - 所以理当在“十九子食兄”的预言下，第一个死亡的皇子，阎王却赐以锡杯转命，让他成为自己竞逐苦境的先锋。
  - 而玄嚣的确也不负所望，打下了一片最坚固的基石。
  - 当初神思附身山龙隐秀时，对玄嚣的悼亡，词真情切，是阎王难得的情感流泄，但也更对比出，情感之外的算计，有多么的绝情。
- **繁雪逸冬青**：剧中阎王曾在缅怀逸冬清时，吟诗：“脉脉丝丝难笔墨，只曾凭风说人我，奈何情天被云遮，一点情思几消磨。”阎王是真心喜爱过这名苦境女子，曾想让她平安的回到苦境，赡养天年，但逸冬清却放不下族恨，执意报仇。
  - 所以阎王便顺势将蜕变过的黑后，纳入算计之中。
  - 而已变了容貌、换了个性的她，早已不是阎王心中的逸冬清。
  - 在阎王心目中的逸冬清已死在永寒树中。
  - 这就是阎王提得起、放得下的决绝个性。
  - 因此后蜕变黑后之死，对他并没有造成任何心绪波动。
- **天罗子**：一个由自己血肉所捏生出来的备体，一个在来日危急时，可救其一命的神元之体，对阎王来说，天罗子就是自己。
  - 但天罗子的意识与情感，却与说太岁有着不可分的情谊。
  - 阎王在食下天罗子时，究竟是一并将天罗子的善性及情感食下肚，又或者只是更加的由残忍举动中，将情感驱逐？

### 场景设计
- **珈罗殿**：阎王登场时是处于被困在珈罗殿的情况，所以场景在剧中初现时，偏向阴暗、神秘，呈现一种另类牢笼，但毕竟是阎王专属宫殿，虽然灯光昏暗，在看不到的地方仍然有着很用心的设计。
  - 后来玄膑在葬天关内，也打造了与珈罗殿一样的宫殿。
  - 珈罗殿以竖立的独眼，凝聚神秘感，并制作发光系统，让它在黑暗中，呈现监视的压迫感。
  - 椅背上的多个锥状物展现王者之风，并以尖刺突显阴森、险恶感。
  - 特制的柱子，尺寸宽、厚，并仔细的刻上图纹，增添珈罗殿气势。
  - 柱子中也有灯光设备，在阴暗的殿内，唯有柱子、座椅发出淡淡光芒。
- **惜别峰**：乃久远前，阎王所探知，是森狱大黄地母在苦境的相对应地点。
  - 阎王数次要求来到惜别峰，正是在等待大黄地母的无上魔神之力聚集，穿透空间，来到苦境。
  - 其惜别峰上的父子情感之故事，也恰恰是对阎王与其子嗣们的一种讽刺。
- **大黄地母**：乃森狱最神秘的禁地，早先有地咒为界，鬼吟诗为护界者。
  - 其守护的目的，除了大黄地母深处的大魔像之力，尚有隐藏阎王最深的秘密之地“深髓古河”，内中藏着阎王的元神兽。
  - 元神兽既然是阎王的元神兽，就要有别于其他先出场的皇子们，编剧希望此元神兽必须要是庞然大物，要是多头怪物，经过动画组设计，确定为三头水怪，镇守在深髓古河，登场时要有巨大的震撼感。

## 相关作品

阎王活跃于多个霹雳布袋戏剧集，包括《霹雳侠影之轰定干戈》、《霹雳侠影之轰掣天下》、《霹雳侠影之轰霆剑海录》、《霹雳开天记之创神篇》和《霹雳开天记之创神篇下阕》。在《霹雳侠影之轰霆剑海录》中，玄嚣太子与玄灭太子争夺苦境版图，以图扩张森狱势力并争夺未来阎王继承人之位。在《霹雳开天记之创神篇》中，阎王作为黑海森狱的代表势力之一登场，与中原武林、天疆等各方鼎立，森狱变局导致黑月进入苦境，开启二阳灭世危机。

  - 乐曲初用于轰掣天下第28章，珈罗殿，一个森狱最不可入之地，囚禁着森狱最不可近的“阎王”。
  - 阎王为黑海森狱之主，久远前被蜕变黑后所算计困于珈罗殿中，可阎王早已布好尔后之路，并借神思操弄着黑海森狱的局势。
- **阎王霸途（阎王气势曲）曲/编曲：孙敬凡** — 《轰霆剑海录剧集原声带贰》
  - 孙敬凡老师2013年作品，如鬼王驾临的吆喝声渐渐传至，冷冽的金属乐器声此起彼落，在阵阵肆虐无情的乐声中，刻划森狱最可怕的霸主。
  - 乐曲选用于“阎王气势曲”，阎王乃森狱最高权位象征，却无人看过真实面貌。
  - 阎王育有十九皇子，并册立四位太子竞争王位，表面上鼓励皇子们良性竞争，实则等待皇子自相残杀，面具底下藏着的是黑海森狱最可怕凶残的阴谋。

# 玄同太子

================================================================================

霹雳布袋戏虚拟人物玄同太子，霹雳布袋戏虚拟人物。

诗号：一眼可载几多剑，一手能握几多剑。

一心可爱几多剑，人生到头终为剑，剑剑爱怨憎；

挣得一生痴剑名，挣得一身痴剑形，名形俱坏剑长存，生来死去伴剑行。

黑海森狱阎王第四子，被册立为太子的四人之一，心性傲骨嶙峋，作风特立独行，向来只醉心于剑术之上，爱剑如痴，喜爱听寻剑声，虽然对森狱皇子间的权力斗争漠不在乎，实则重情重义，乃名列黑海森狱三名绝世剑者之一。

在黑海与苦境连通后，玄同太子则改以化名“秋枫暮霞惋红曲”自称，并收紫色余分为随行仆，命其身背飞光剑盒一同游历苦境，并在因缘际会下参与论剑海评剑大会，从此与素还真等人结缘。

玄同身在黑海森狱帝王世家，无情冷酷的环境，唯有单纯的剑声和剑道是完全寄托信赖的对象。

也造成玄同重情也怯于情的个性。

只能以冷淡来伪装自己。

闯荡苦境的问剑旅程，让玄同暂忘了森狱的争权夺利，顺从本心结交朋友。

但紫色余分因自己而亡故的伤痛，和手足的一一逝去，正邪立场的矛盾，亲情与朋友的对立，也让玄同一再陷入困惑的网，选择孤身面对一切。

所幸历经风风雨雨，玄同仍是不曾偏移自己的脚步。

如今黑海森狱已然平静，玄同告别苦境，重整森狱。

## 角色背景

（摘自 霹雳月刊 第225期 封面人物：玄同太子）缘起玄同太子关于这个角色的设计缘由，是一名拥有太子地位，却对权势毫无恋栈，只醉心于剑的特异剑者，在玄同身上要表现出来的，是一种黑海异数。

他一开始出现于关注的讨论中，是在玄嚣太子找上说太岁讲话的那一场戏，那场戏会提到玄同，主要是想借由玄嚣与太岁之间谈话，勾勒出黑海中一个令人期待的太子。

而玄同初现身影，则是在玄幻皇子的丧礼上。

不过那场戏主要要表达的，是森狱众皇子对于一名兄弟死亡的表达。

同时间更有玄膑大太子的现身，以及其他未露脸的皇子一同登场。

在众多新角色齐出的当下，如何让玄同不抢走玄膑主导的地位，又能将玄同独出于众位皇子之中，成了这个角色初登场的重要课题。

于是在此设计了森狱风俗中，人们会对亡者献上一朵白色桔梗。

而玄同则是与众人不同，乃是献上一把纯黑之剑。

一来在人物特色上与其他人所区隔、二来彰显他爱剑的特质，将生命的各种意义与剑结合。

设计起初这个角色的塑造最深的是，玄同的太子殿中，有一处剑窖。

什么是剑窖？

就是类似葡萄酒酒窖，须要控制室温，满满的四面墙上，插满了各式各样的剑，每一把剑都写着他的来历与特性，而玄同最喜欢做的事，就是在剑窖中赏剑。

但因为剑窖要做起来的话，光那满满四面墙的剑，以及壮观的场面，就足以让道具师傅忙翻天，影响效率。

所以折中之下，变成了身负五把剑，而这五把剑，各自有它的来历故事。

然后为了增加太子行走武林的派头，又多设定了一名，因败剑而必须帮玄同背剑的剑侍——紫色余分。

而也借由与这名剑侍互动的过程，将玄同这个角色的特质突显出来。

命名会刊255-玄同太子四位太子之中，“玄同”与“玄灭”乃是由董事长赐名。

其玄同之意，取自《老子》：“塞其兑,闭其门；

挫其锐,解其纷;和其光,同其尘。

是谓玄同”。

也就是所谓“冥默中与道混同为一”。

而玄同行走苦境武林，化名“秋枫暮霞惋红曲”（董事长赐名）秋枫暮霞，皆是很美的景色，但当这种艳丽的红出现时，往往代表了接下来的消逝。

所以在欣赏这样美景时，惋惜这片美景的心绪，便油然而生。

而这某程度的，也侧点出来玄同内心，有其悲观与哀悯的一面，只是在现下还不明显。

这样的人，内心一定都藏有哀戚的秘密。

## 角色形象

造型玄同在诸位皇子中独树一格，在造型设计上也表现与众不同。

比较其他兄弟在头上的用心，来强调自己的地位，玄同更显简单朴素。

造型介绍一版玄同造型肩膀上特殊的突出造型有别于朴素之风。

突出的鲜红，在现今剧中似乎真的是夺人目光。

衣襟、袖边选择对比度高的白色来打出层次。

衣着布料选择颇有质感的厚实风格。

玄同太子一版剧情截图二版玄同造型紫色余分的突然离去，导致悲怒攻心的玄同爆放出元神兽。

元神兽显形，上古神器魔罗天章在手，玄同的造型也为之改变。

玄同二版造型截图元神兽元神兽异形大鹗——为了呈现魔罗天章从玄同身上出现的庞大气势，元神兽的设计比较巨大，带有玄幻和神秘感。

场景玄同在枫叶林玄同只身入苦境，算是一名游人，亦没有固定停留的居住地，要说起相关场景，只有一处“枫叶林”。

这里的美景，让玄同流连忘返，也在此处，有着无尽的剑意产生。

## 角色能力

武学三剑齐天·一气玄同作为黑海森狱三名绝世剑者之一，玄同一人独战天疆三族之长，轻易取胜，而玄离与鳞族之长伐天虹一战，却僵持不下；

为救阎王，秒杀若叶凝雨，一剑取其首级。

而后一人独战剑鬼和若叶知秋，寸伤未负，击退两人并抽身从牧神（未恢复全力状态）掌下带走阎王，由此见玄同实力之强。

白首留仙（孔雀仙者）称玄同之实力不亚于初代阎王。

武器虹霓双剑（以铁霜、热泉母打造而成，对战牧神中折毁）虹剑——为玄同游历到枫叶林，一时剑兴大发，所舞动的剑。

此剑属性阴柔，与霓剑乃是对剑，可单使，也可成对剑使用。

霓剑——属性亦阴柔，与虹剑乃是一对“生死对约的姐妹剑”。

其剑性相随，若其中一口剑有了异动，另一口剑，便会有所感应。

当两把剑同时使时，天际会出现虹霓清象。

蚍蛉剑——“蚍蛉”是一种春天的虫蛾，其属性与蠺相仿，会吐出一种寒萤丝，将自己包覆成茧，其茧质硬，类似金属性质，蚍蛉剑便是用蚍蛉的茧壳打造成剑。

在舞动中，会发出类似虫鸣的声响。

黄离剑——乃是一把材质特殊的重剑，只要一出鞘，剑身所散出的天磁之力，会影响天地重力，乃至失衡。

黄离乃取自易经卦，黄离元吉。

魔罗天章无妄剑——其剑至轻，运行至顶，剑身会变成如蝉翼般的薄透，到最后会变成一把风中的无形剑，剑行无妄。

魔罗天章——元神显形后所执，血脉所封初代阎王之配剑，乃阎王血肉所化。

设计有许多管状物，持剑时会做出刺入手臂与血脉相连的效果，偏向红色色系，轮廓有大小尖爪状的线条，呈现魔、怪的神秘视觉效果，剑身偏向金色，与红色搭配反而呈现一种视觉反差，让应属于魔剑一类的魔罗天章，减少了血腥、肃杀的气氛。

风刃——赩翼苍鸆所用武器，化身挽风曲时使用。

所有物红冕王戒——元神兽显形后喉咙之间，现脱离。

## 人际关系

主要人际关系紫色余分紫色余分玄同看出了紫色余分对剑的天赋，所以将紫色余分收在身边，一来，他想看一名初生之犊能如何生长成绝代剑者，二来，他亦有意为自己培养一名对手，这样有所亦行的剑道，才不会孤单。

紫色余分充满少年性格，但对现实的理解，却是总有落差。

玄同渐渐打消了培养对手的念头，但更多的是，对这名剑侍的情感依赖。

他习惯了身边总要有个人，以着令人发噱的思考，去冲淡森狱内斗带给自己的负面情绪。

紫色余分这个名字是从“紫色蛙声，余分闰位”变化而来，原本要取名紫色蛙声，但是蛙声实在有点过度搞笑了。

而在设计紫色余分这个角色时，就以青蛙（井底之蛙）为原型。

玄同是那只飞鸟，紫色余分是因鸟自头顶飞过，而有幸窥见世界之大的井蛙。

如果有一天，当出了井的青蛙，想回井底时，飞鸟又有何感受。

素还真清香白莲素还真醉心剑道的玄同，甫入苦境武林，便巧遇了溜出时间城“办事”的素还真，初逢时，玄同只在素还真身上，闻得了特殊的剑香，这是一种对剑的敏锐。

而在论剑海评剑会上的相见，才真正让玄同有所留心。

后来在翠环山上的一日之约，才真正奠定了两人的交谊。

不过玄同也知晓自己的身份，将造成两人交情上的障碍，所以一开始，便以“秋枫暮霞惋红曲”对上“清香白莲素还真”之名，来说明两人之间，注定水火不容。

而素还真以泡茶之法巧妙说明，只要用对方式，水与火是相容并济的存在。

阎王黑海森狱阎王一口传说之剑，让阎王对玄同特别的提防，也特别的另眼相待。

而玄同从小便感受到父亲刻意疏离的眼神与偶而热情的双手，玄同会养成淡漠的个性，有大半是来自于看穿了父亲某部分的人格特质。

他无时不警戒着阎王的接近，无法理解自己为何对父亲会是这样的反应，只知道，他对父亲藏着秘密。

玄同说：“我至死也忘不了父亲身上的那股麝香味。”也许来日将这对父子之间的情感薄纱揭去，看清了双方的想法与立场，才能更加清楚这段父子之情的真假。

而玄同的内心的悲观倾向，或许也能得到解答。

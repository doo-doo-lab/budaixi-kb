# 水飘蓬

五短身材，身手矫捷，曾是收钱买命的杀手，历经日盲族血案后，夫妻俩金盆洗手，并收养不见荷与长心，隐居缘荷来境。喜爱钻研药草，曾医治重伤的叶小钗，虽亟欲避世，无奈仍被卷入江湖风波。

## 来自百度百科的补充

水飘蓬，霹雳布袋戏虚拟人物。

五短身材，身手矯捷，曾是收錢買命的殺手，歷經日盲族血案後，夫妻倆金盆洗手，並收養不見荷與長心，隱居緣荷來境。喜愛鑽研藥草，曾醫治重傷的葉小釵，雖亟欲避世，無奈仍被捲入江湖風波。

身份：退隐杀手、朱翼皇朝将领

武器：飘蓬刀

◎外形特征：典型的弧形弯刀，配合水飘蓬的五短身高，刀身较为轻巧短小，刀柄与护手紧密结合，刀刃仅有刀刃开锋，散发慑人的银色光芒。

水飘蓬，与妻子笑菡萏居住在缘荷来境的侏儒医生，性格开朗、不拘小节，略显惧内，和妻子十分恩爱。水飘蓬夫妇曾是训练杀手组织的幕后高人，曾参与玉阳君所策划的日盲族血案，后金盆洗手，与妻子收养了不见荷和织语长心，隐居在缘荷来境。

因不愿退隐生活被干扰，水飘蓬不到生死关头绝不动武，改为钻研草药医学，医术不凡。水飘蓬曾医治织语长心救回的叶小钗后，为此还打退过来犯的异度魔界的伏婴师等人，在叶小钗痊愈后，水飘蓬夫妇便带着义女们一起迁居他处。水飘蓬曾医治燕啼红双亲，但因阎王锁之故导致燕啼红双亲身亡，水飘蓬自责不已。在爱妻笑菡萏身亡后，水飘蓬将不见荷和织语长心的身世道出，并随同长心前往公开亭，被罗喉戒玺影响，臣服于织语长心而成为朱翼皇朝先锋大将。

水飘蓬与日盲族、学海无涯等多番交战，屡屡受伤而回。织语长心因向死神许愿而性情大变，父女俩形同陌路，更因嫉妒心作祟，长心视不见荷为情敌，水飘蓬则沦为弃子牺牲，在战中被千叶传奇重创，不见荷不忍义父痛苦，含泪一掌手刃水飘蓬，结束其悲惨的人生。

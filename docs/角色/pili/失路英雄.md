# 失路英雄

================================================================================

霹雳布袋戏虚拟人物失路英雄是霹雳布袋戏虚拟人物，初登场于《霹雳震寰宇之龙战八荒》第26集。出身天剑峰，行事作风强势，个性严谨而正直，于武林中默默观察局势发展，不断追寻自己的真理，探索正义的真谛。性格沉默寡言，以追寻“正义之道”为核心。其剑术融合兵甲武经“地”字卷与任剑谁剑法，经典战役包括断日峰之战对决夜神。成为霹雳系列中探讨正义本质的典型角色。

**中文名**：失路英雄

**别名**：失路仔（赤子心语）

**配音**：黄文择

**性别**：男

**登场作品**：霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕霹雳经武纪之枭皇论战霹雳兵燹之圣魔战印

**身份**：卫清风

**师父**：任剑谁恩 人火中雪、狂河冰烈、绝凌笙恋 人孔雀（残容悲声）

**兵器**：衡剑（恨铁不成剑）

**本尊雕偶师**：洪剑山人物

**编剧**：八叉

**出场集数**：116集

## 人物设定

名称：失路英雄失路英雄绰号：失路仔（赤子心专用）代表性名言：倾斜的正义来自——失路英雄！性别：男身份：卫清风初登场：霹雳震寰宇之龙战八荒 第26集退隐：霹雳兵燹之圣魔战印 第21集（与孔雀一起退隐）根据地：天剑峰

## 人际关系

- **师父**: 任剑谁恩人：火中雪、狂河冰烈、绝凌笙恋人：孔雀（残容悲声）朋友：素还真、枫岫主人、香独秀、欧阳春羽、赤子心、极道先生、啸日猋、丘伯、少独行前辈：御神风、靖沧浪所发便当：玷芳姬、羽莺

## 人物能力

武学：纵横天地、无憾神威·剑走天行、今生唯恨一剑败、怒发冲冠乱开云、切齿怒目横向天、兵甲武经“地”字卷（空回地斩、地毁千岳、玄绝地毁）武器：衡剑（恨铁不成剑）失路英雄◎以红色为底，金、银色点缀，衡剑握柄为金色，剑身红似血，银色圆形护手。剑鞘上有金黄雕饰，镶有六粒黑曜岩，底端有四根脚，利于衡剑直立于地上，并于剑鞘上端有一天秤并在两端饰以两枚铃铛。所有物：兵甲武经“地”之卷（兵甲龙痕40集被啸日猋所取走）

## 人物生平

在佛业双身逼杀枫岫主人之时突然出现，三招击退天蚩极业将濒死的枫岫主人救走，其剑招诡怪并且沉重非凡，且有令人失去平衡的特效，邪说沦语、爱祸女戎、玷芳姬，包括烨世兵权皆在其剑下因骤失平衡而吃亏。

似有一段离奇过往。

其救人成功率乃霹雳一绝，三招之内对手必定下盘失衡，在龙战八荒与兵甲龙痕中尚未出现三招以外的对手。

失路英雄曾经误杀了一名霓羽族人羽莺，才会一直询问正义之道，经过拣角吃毛的开导，已经认清了自己的正义之道，并开始为自己的过失弥补霓羽族人。

后来认识了霓羽族人孔雀，发生一段爱情。

并在孔雀成为残容悲声后，因她之故承接了御神风的骨气，继续行走在正义之路上。

后在天阎魔城的算计下，失去骨气。

而后在靖沧浪的劝说下，现与孔雀退隐中。

## 人物身份

失路英雄失路英雄的真实身份就是卫清风，证据如下：1.当香独秀来到天剑峰，问“听说这里有个叫任剑谁的修复兵器的侠客……”，失路英雄直接答之“先人已逝，你错差啰！” 带有感情。

这一段的对话和他留恋天剑峰都可以看的出失路英雄的身份。

他的剑法，和他的人，以及他眷恋天剑峰，已经说明一切！

之后香独秀借剑试招，证实此兵器是挂在西门寒照门前的神器，可以随着不同的人变成不同的形态。

（龙战八荒33）2.失路英雄进入薄情馆时，薄情馆的鹦鹉鹂大娘说“卫，卫，帅哥，卫，卫”，说明鹦鹉认得失路英雄就是卫清风。

（龙战八荒40）3.秦假仙和业途灵走在路上，刮来一阵风，业途灵说这阵风“不是狂风暴风龙卷风，而是清风”，然后失路英雄就出现了，这样的暗示非常明显，是编剧暗示失路英雄是卫清风。

（兵甲龙痕24）4.“我不想世上，再有人无辜惨死，不想世上，再有恶徒横行，不想世上，再有魔气肆虐。”（兵甲龙痕34）5.对战啸日猋最后时刻用出了任剑谁的绝学之剑——今生唯恨一剑败。

（兵甲龙痕35）02030405060708096.集境与末世圣传围捕孔雀时，失路英雄对上影，又使出了任剑谁的剑招——怒发冲冠乱开云。

（枭皇论战26）7.被天阎魔城擒去，欲脱出魔城时，再次使出任剑谁的剑招——切齿怒目横向天。

（圣魔战印20）8.在最新剧集（轰定干戈第四集中，谴弥勒为除波旬三化体，而踏上寻找三奇棺之路，其中一棺即为造化金棺，口白中，他说自失路英雄口中得知，造化金棺的最后下落，造化金棺下落的唯一知道人选就只有卫清风而已，除了他所有人都死了，如此可鼎证失路英雄就是当年的卫清风）

# 神鹤佐木

霹雳布袋戏虚拟人物神鹤佐木，霹雳布袋戏虚拟人物，初登场于《霹雳狂刀》第42集。

东瀛忍者黑流派宗师，为抛弃过往情仇出走故国，皈依佛门后法号普生。

曾数度萌生归隐之念，无奈风尘自染人，昔日的恩怨与义女盼梦圆的失踪，让神鹤佐木再度卷入江湖风波，最后为公理正义毅然加入射日必杀组。

多年之后，竟意外现身在瀛幡御龙艇上。

在后续剧情中，神鹤佐木被素还真唤醒，加入中原阵线。

东瀛方面派出神风营发动全面侵略，在六祸苍龙、问天谴、神鹤佐木全面抗衡下，素还真最终顺利逼退东瀛大军，并且拟定和平协议书，呈报东瀛天皇，终止了横跨三档的中日之战。

神鹤佐木从东瀛黑流派宗师转变为中原的修行者与战士，为了心中的正义不惜对抗祖国，并参与终结了东瀛与中原的战事。

## 经历

### 狂刀-创世狂人时期

神鹤佐木本是东瀛忍者【黑流派】宗师，与死对头【伊贺派】长年争斗不休，两派首领更亲自对决，神鹤佐木以自身忍术和鱼龙宝刀力斗七色龙之七色忍法，智取之下反让七色龙死于反向杀法秘招，而神鹤佐木也就此退隐，为求心灵安静不惜远赴中原，最后在菩提学院落发为僧，法号【普生】，而鱼龙宝刀也沉埋于大雪原，代表放弃了东瀛的一切。

或许命中注定鱼龙宝刀不该就此平凡，让雪中狼无意得之，助其成为天残武祖八大将中的翘楚，一直到雪狼萌生退隐之意，鱼龙宝刀也二次尘封于大雪原云波丘，并结识了普生。

无奈风尘染人，雪狼无辜被卷入三教之子的风波，惨遭道教无情逼杀，挚友藏剑生虽及时取出鱼龙宝刀赶往相助，但为时已晚。

日后，因黑流派白月的死谏，让退隐的普生重拾神鹤佐木的身份，取回鱼龙宝刀，一泯昔日恩仇。

但非凡公子三教之子的身份，一统三教建立霹雳王朝，神鹤佐木则在大和居士的安排下加入八德联会，一举推翻霹雳王朝。

更在事后配合灵啸月的破天计划对付魔魁之女，然昔日旧情无法放下故而网开一面，至此之后，神鹤佐木正式退隐。

后来，随着义女盼梦圆的失踪以及东瀛势力再起，神鹤佐木又再度被卷入武林风暴，甚至一度落入对头权门宗矩手中；

获救之后，则加入射日必杀组，与常默衣、风随行、双龙背专门扫除黑榜奸细和中原败类。

却在暗杀九锡君的任务中不行身染剧毒，最后惨遭白云骄霜指使绝离子、义海士所杀，鱼龙宝刀也随之下落不明。

### 铡䶮史-苍玄泣时期

多年后东瀛势力随着夜摩市的曝光再度进入武林视线，当年一度被认为身亡的神鹤佐木再度出现。

其实当年神鹤佐木以虚空壳化出虚体逃过死劫，却也身负重伤并且失忆，被军神源武藏救回东瀛。

销声匿迹多年后，神鹤佐木才意外再现于瀛幡御龙艇上，武器鱼龙宝刀也崭新重铸，在东瀛开疆侵略行动上扮演监军的职位，并协助犬若丸于海防线建造前锋堡垒。

神鹤佐木的出现引起各方关注，素还真一心欲引导其恢复记忆，终在净琉璃、枫神官等人的协助下，唤醒神鹤佐木过去记忆，就此成为中原正道不可缺少的助力。

面对远征军京极鬼彦的强势逼近，神鹤佐木与问天谴结伴闯入天狩浮阁，欲破坏东瀛先锋基地，经过多次试探与牺牲，终于发现机关城破绽，设下铁坪谷之局以磁力吸住天狩浮阁，神鹤佐木为报爱徒冲田鹰司之仇单挑京极鬼彦，终打败狼将，天狩之心也被问天谴破坏，让东瀛侵略大计宣告失败。

随后，在六祸苍龙、问天谴、神鹤佐木的全面抗衡下，素还真顺利逼退东瀛大军，并拟定和平协议书呈报东瀛天皇，终止了横跨三档的中日之战。

日后魔界势力复苏，对中原展开全面进攻，神鹤佐木三度与魔将华颜无道交手，双方对垒各有胜负，最后一战却因伤势未愈而落败，被华颜无道击落断崖，下落不明。

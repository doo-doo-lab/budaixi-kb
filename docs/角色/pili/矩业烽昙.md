# 矩业烽昙

================================================================================

霹雳布袋戏虚拟人物矩业烽昙，霹雳布袋戏虚拟人物。天佛原乡审座，享誉佛界的愤怒尊，握有审核审判等实权，个性刚烈果断、执著坚定，对佛法修为越高者，会采取越严苛的审视准则，执法极少留情。其代表意义为斩恶武神，会为歼灭罪恶而不惜举战，遂有“烽火昙华”之称。

## 经历
炬业烽昙图片炬业烽昙乃天佛原乡审座，素有怒尊的称号，握有审核审判等实权，性格刚烈果断，为歼灭罪恶不惜举战，也有“烽火昙华”之称。

炬业烽昙来自烈武坛，多年前，痕江月打着烈武坛名号夺取盟友方家绝学并流入黑市交易，使得炬业烽昙以为方家有意与其他势力联合反叛而重惩之，后来对方家有所愧疚，便离开烈武坛转往佛乡修行。

传言天之佛造忏罪之墙，兹事重大，矩业烽昙负责调查。

期间中阴界宙王设计推到罪墙，让红潮肆虐苦境，矩业烽昙因此带佛乡杀向中阴界，覆灭其朝臣。

炬业烽昙过去的刀术本无招无式，而中阴界一战中，炬业烽昙以佛乡所记录的佛界三大源流之一的帝如来的初禅三式里的佛途三境、萨三埵融汇刀招之中，配合自身与惑苦终焉的火属性，击败六独天缺，后更重伤宙王，让天王四护自叹不如。

后炬业烽昙因受恶鬼三凶之一的鬼瞳预示将亡于春秋阙剑下，噩梦缠身，对天器春秋阙心有顾忌，曾一度将其得到却在对战邪九世时被击飞而失落(春秋阙择主意琦行)，找回后转赠给意琦行，要求其为苍生杀除帝祸邪九世。

后来意琦行与邪九世大战，双方一死一伤，炬业烽昙心忧鬼瞳预言，心生歹意欲突袭意琦行，却遭意琦行剑者本能反抗，被春秋阙一剑封喉而亡。

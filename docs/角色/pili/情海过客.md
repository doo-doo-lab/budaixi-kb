# 情海过客

情海过客人如其名，因爱慕挚友命随刀的情人病兰花而成为情海中的过客。温文儒雅的书生装扮却暗藏不凡武功，身负蔺家灭门血案，与命随刀结交多年后始知此人竟是灭门仇人，加上为救病兰花而假扮命随刀为其十孔入气，致始病兰花知情后羞而自缢，命随刀为了结一切，约战情海过客，虽情海过客最终获得胜利，却也从此失去挚爱与朋友。

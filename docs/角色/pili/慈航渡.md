# 慈航渡

灭轮儒圣一方的领导者，知天命、顺天时的睿智老者，曾派遣天罡地煞入苦境诛灭邪灵，并以诞登挫骨加速素续缘成长。自知天命将至，担忧其舍利遭邪魔所夺，遂让天祸妖狐取下其头颅，巧妙布下无极炼化阵，让表象意魔惨亏险遭炼化。

## 来自百度百科的补充

慈航渡曾作为侠义之士，为平息武林纷争而奔走奋战。慈航渡曾布下无极炼化阵，困住表象意魔。一页书召开六圣会时，慈航渡并未参加。其结局为被天祸妖狐以招式"分.落.气.离"取下首级，随后今生一剑勉力使出心剑，配合吸雷针切开了慈航渡的头颅。

# 紫锦囊

百世经纶一页书的首位化身，为拯救崎路人壮烈牺牲于八口山的同时，利用佛体离异及吸尘保元，将元灵依附于已死的玉竹风之身，化名天劫紫锦囊行走江湖。结合一页书的根基、素还真的智慧、崎路人的幽默风趣于一身，看似温文儒雅的书生，却每每在谈笑间智破千军，为当时饱受侵略、烽火连天的苦境武林带来一线生机。

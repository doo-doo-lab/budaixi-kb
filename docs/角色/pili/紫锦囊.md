# 紫锦囊

百世经纶一页书的首位化身，为拯救崎路人壮烈牺牲于八口山的同时，利用佛体离异及吸尘保元，将元灵依附于已死的玉竹风之身，化名天劫紫锦囊行走江湖。结合一页书的根基、素还真的智慧、崎路人的幽默风趣于一身，看似温文儒雅的书生，却每每在谈笑间智破千军，为当时饱受侵略、烽火连天的苦境武林带来一线生机。

## 来自百度百科的补充

在一页书认为和半尺剑（灯蝶）之间的赌约已经失控而危害武林时，毅然决定借八口山之劫暂退武林，利用"佛体离异"和"吸尘保元"两种功夫，加之海殇君的"尘沙转命"协助，进入玉竹风的尸身而化身为天劫·紫锦囊。紫锦囊甫入世便解救了崎路人，紫锦囊其神秘的身份，协助崎路人揭穿了灯蝶的伪装，和素还真配合对付鬼王棺与集境高手，并与万俟焉结为好友，得其协助度过不少难关。紫锦囊也曾指点魔域三先知以达到分化魔域，更在云渡山以一气动山河击杀九恶道。紫锦囊的身份引来了绝情师太、天下第一棺和地狱鬼王棺的兴趣，面临集境大军压境的危机，紫锦囊单人进入集境，以大梵圣掌在吸攻石上留下三道掌印，又只身进入魔域与恶魂暴鬼合作。在鬼王棺的邪术和魔域调查下，紫锦囊的玉竹风身份曝光，被鬼王棺和集境高手围剿重创，身中引归杀象的气劲，加上尸体无法恢复伤势，一页书元灵被迫离体，回到释迦树上，紫锦囊也消失武林。

紫锦囊短暂现世扭转战局，其牺牲为一页书回归埋下伏笔，更成为素还真命运转折关键节点。在紫锦囊死后，素还真复出，但接连遭受叶小钗重伤痴傻；风采铃被鬼王棺扣为人质，双臂折断；崎路人死于面前。

# 御清绝

================================================================================

霹雳布袋戏虚拟人物御清绝，是霹雳布袋戏中的虚拟人物。个性坚毅，冷清高绝、爱弦如痴的一代高人，琴艺已至巅峰，以一曲伏羲神天响扬名天下。以琴证道、御琴仗义，御清绝为人正直，为正道难能可贵的助力，并在传授伏羲神天响予赦天琴箕后，了却毕生心愿，最后羽化登仙，进入了天无之境。诗号1：指掀涛澜天下惊，抚筝百载，清绝吾命。挑弦一曲与谁听，昂首万里，江山无人。诗号2：俯瞰世间知音绝，十千沽酒凌烟居。

**性别**：男

## 角色背景

源起御清绝享誉武林的神琴主人，隐居于在水一方凌烟阁，修为超凡入圣，琴艺已臻化境，练有天地双响之一的伏羲神天响，并一心希望神天响有所传承，其友朝玉京知其心愿，便设立弦琴无上宴寻找人才。

然而琴箕杀害瑶琴三调，御清绝愤而约战，伏羲神天响力斗阎王三更响，首现大音希声、大雅无曲的道之极境，后因赮毕钵罗介入下而暂缓。

而御清绝曾解救昏迷之媂君君海棠，对其暗怀情愫，其人却是阴险毒辣之蓝王，一段感情纠葛由此展开。

名号“千霜万雪，受尽寒磨折。

赖是生来瘦硬，浑不怕、角吹彻。

清绝。

影也别。

知心惟有月。

原没春风情性，如何共、海棠说。”选自南宋诗人萧泰来《霜天晓角》，以“清绝”暗喻梅花，表现清霜高洁之意，“清”而至“绝”，可见其超逸出尘的个性，同时也表现了梅花不同流俗的泰然傲气。

## 角色能力

御清绝武器/乐琴：仙品遗音武学/琴曲：清绝五调·【返虚入魂、清绝无响、拨乱反正、惊涛怒拍】、伏羲神天响·【大音希声、大雅无曲、大道无弦】、阎王伏羲（与赦天琴箕合招）阵法：绝弦阵、七绝纵横衍著作：伏羲神天响、玄龙净心阙、梅花引

## 角色经历
弦挑英豪意风发御清绝御清绝早年弦挑天下英豪，并创伏羲神天响（霹雳天命之仙魔鏖锋Ⅱ斩魔录第2章中又言伏羲神天响是九天玄尊赐招，有所矛盾），独身覆灭西城魔域，锱衣十三楼。

孤仞峰之战，无分正邪，群雄惊惧，于是西武林不败神话之名宣扬于武林，后人称其为“琴中伏羲，弦上魔圣”。

然而，初达道时，御清绝已感罪孽难堪，自裁三指以自省，而后于武林中销声匿迹。

并托付好友朝玉京为其定期举办弦琴无上宴，寻觅伏羲神天响之传人。

琴即天下即为道因好友朝玉京之死，商清逸与山龙隐秀一同去在水一方寻上御清绝，希望他能入世帮助正道。

御清绝但御清绝婉拒商清逸之邀，告知他尚未寻得”伏羲神天响“合适的传人，若是入世，恐其成为绝响。

二人离去后，随同而来的琴缺风隼表明想要继承伏羲神天响以证琴道，御清绝称，“道在指间，琴即天下，琴之道，天下道矣。”云手轻拨，并奏大音希声。

一曲毕，御清绝点出其心不正杀戮过重、执念太深，不是他所寻之人。

并指出，如果有朝一日，他能放下心中所恨，便能超越现有境界。

而后，琴缺风隼又因心受琴所困，有所执念，于是二度寻上在水一方。

御清绝直言他受心魔而困，并命瑶琴三调解其心魔，却因琴箕而中断。

随后又规劝琴缺风隼放下魔心，放下仇恨，莫要以魔制魔之法走上歧路。

## 角色关系

主要人际关系主要人际关系朝玉京御清绝部属之一，为弦琴无上宴之主席，曾多次为御清绝开设弦琴无上宴寻觅伏羲神天响后人。

说话平和，语带风趣，虽为部属但实际却视如挚友，感情深厚。

后因死于氐首赨梦之手，御清绝恸感挚友离世，完成其心愿，将他骨灰撒向凌烟阁。

慕梅声御清绝四大琴侍“瑶琴四调”之一，少时为御清绝所救，多年追随下对御清绝有单恋的倾慕之情。

为使君海棠放下对御清绝的仇恨，故寻上云深不知处，却被煅云衣毒杀而身亡。

君海棠六王开天之一，也是六王中唯一的女性。

擅长魅惑之术，手段阴险残毒，却因深脑长议失去意识之时，恰巧被御清绝所救。

清醒后不告而别回到云深不知处，得知御清绝对自己有所痴迷，决心将御清绝收为己用，最终却因心中嫉妒而滥杀无辜。

御清绝感念当初情份，本欲将她导回正途，却因梅声之死使得两人矛盾激化，兵刃相向。

赦天琴箕琴艺无双的绝世才女，个性清冷，其琴声能杀人无无形，在弦琴无上宴中曾多次夺魁。

因琴缺风隼之故破瑶琴四调之琴阵，引起御清绝注意，并在几番试探下最终认定赦天琴箕便是伏羲神天响之传人。

最终，赦天琴箕感其高洁气度，决定传承伏羲神天响。

其他人际关系齐名：纵横子（超神越鬼，天下有双）朋友：天不孤、纵横子部属：怨兰曲、思菊调、悲竹音、慕梅声（瑶琴四调）其他：琴缺风隼（多次寻上凌烟阁，想要继承伏羲神天响）、疏楼龙宿（御清绝退场时说有一面之缘）、弱水琴姬（御清绝原本属意弱水琴姬传承伏羲神天响）、九天玄尊（曾受其指点）

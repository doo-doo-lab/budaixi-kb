# 白城舆

为天外南海傲刀城之第一武训，个性择善固执、谦恭有礼，刚正不阿、富有正义感。身怀不世武功而深藏不露，对于主上傲刀玄龙一直忠心不二…
为调查故人下落与寻找自身异状解法，离开天外南海，因缘际会来至镜界，结识镜界兽族。

# 鬼面伏影 (鬼面伏影)
================================================================================

鬼面伏影

魔界五色妖姬化成的五個鬼面殺手，手提卷鐮長刀，身影飄忽如鬼魅，為強奪造化之鑰而逼殺患劍與素還真。只要本體不死，鬼面殺體便可幻化而出，相當難纏。

# 天子传奇（霹雳布袋戏剧集）

================================================================================

《天子传奇》是改编自黄玉郎同名香港漫画的霹雳布袋戏。该剧以商周政权更迭为背景，融合《封神演义》神怪元素，讲述西伯侯姬昌次子姬发降世时引发天命异象，历经九鼎奇法改命、纣王暴政迫害最终建立周朝的故事。剧情围绕殷商王朝与西岐势力的冲突展开，包含龙龟暴毙、九鼎阴阳挪移大法、灵人炼制等关键事件。剧中戏偶造型融合漫画设定与商周服饰特征，道具仿制编钟、青铜鼎等古器物。作为首部漫改霹雳布袋戏，该剧由杨月卿、李世光担任编剧，制作过程中与香港玉皇朝出版社合作。武戏设计包含马上战斗与完整斗术体系，采用多人闽南语配音阵容。

**中文名**：天子传奇

**别名**：天子传奇——开周记出 自霹雳布袋戏

**配音**：黄文择

**《天子传奇》**是黄玉郎1993年出狱后第5次创业而创作的主打漫画。原本黄氏是打算推出另一部狱中构思作品义勇门来打头炮，但由于首徒祈文杰的劝说，认为《天子》好意头，有利玉皇朝发展，是以改由《天子》作为黄氏的重新创业作。

目前为止，《天子》系列合共六辑，分别有《天子传奇1－开周篇》（周）、《天子传奇2－秦皇篇》（秦）、《天子传奇3－流氓天子》（汉）、《天子传奇4－大唐威龙》（唐）、《天子传奇5－如来神掌》（宋）及《天子传奇6－洪武大帝》（明）共六部。

《天子传奇》的故事剧情由黄易担纲编剧，因此可以算是黄易的作品之一，而黄易担纲的部分约是前三部，第四部开始由邝彬强接手，第五部由黄玉郎及旗下编剧轮流担任，第六部为袁家宝。

===《天子传奇》历代武学介绍===

**天子武学**顾名思义，便是历代天子学习傍身以打天下的武艺，与传统武侠小说中的武功不同之处，在于这些天子武学大多都是**神**所创造的绝学，与君权神授的理念相同。

为了推陈出新，有些天子武学到了下一代还会出现变化，但读者的评价往往是新不胜旧。

本目录中除天子武学外，连反派主角及其他配角的武功也一并收录。

先天乾坤功－姬发、姬昌、姬考、一忧子、燕太子丹、赵匡胤
属于道教武功。黄帝之师广成子所传**广成仙派**的绝学，初期的版本杂乱，中后期开始奠定必杀着为**乾坤七绝**。**第一绝** 乾坤无定/乾坤无量 **第二绝** 震惊百里 **第三绝** 天火燎原 **第四绝** 天道循环 **第五绝** 雷动九天。并出现在龙虎五世中。在天子5中，赵匡胤将其与“混元无极大道”融会贯通、合而为一成‘乾坤无极道’，变为内功。

浑天宝鉴－姬发、嬴政、胡亥、扶苏、成𫊸、飘渺城主、苍龙星君、白虎星君、朱雀星君、娲姐、剑帝、天绝、地绝、皇甫极、朝阳天师、柴荣、五灵子、张彦泽、乔荣
没有教派。

故事中为女娲补天时所遗留下的十枚天晶，与一般武侠小说常用的秘笈经典不同。

可说是创举，共分十层，每一层心法口诀均藏于一枚天晶内。

不同于一般能量属性的设定为其特色。**第一层** 白云烟 （白云剑）**第二层** 玫霞荡 （霞荡剑）**第三层** 土昆仑 （昆仑剑）**第四层** 碧冰雪 （碧雪剑）**第五层** 紫星河 （星河气旋、回转星河、星河暴斩、星河剑 ）**第六层** 玄浑沌 （茧困势、混沌剑）**第七层** 靛沧海 （滔天势、浪卷势、深渊势、鲸吞势、靛海剑）**第八层** 金晨曦 （朝阳耀天、无定飞星、金剑穿云、双芒赶月、五爪金龙、无敌金环、霹雳摧天、金阳破岭、金阳破岳、日月争辉、十阳归一）**第九层** 血苍穹 （穹苍血甲、血海无涯、冰柱擎天、穹苍无涯、血雾迷踪、血阳撕天、穹苍无边、穹苍无悔）**第十层** 玄宇宙（二境:化劫、归真 三变化:大爆炸、天行健、破虚空）

天魔功－纣王、姬考、元始天魔、杨广、李元吉、云师、云宇、云宙
大天魔进攻天界失败后被斩首，因其怨念使其头颅以鲜血在人界石壁上留下的功法。内容千罗万象，有**内功**：阴阳两极魔道、**外功**：天魔神功 **天魔五绝**:天魔极乐,天魔撕天,天魔裂地,天魔金身,天魔怒震、**天魔四蚀**:天魔蚀肉,天魔蚀骨,天魔蚀经,天魔蚀魂 天魔种功、天魔指、天魔拳、天魔锥/天魔金锥、采阴移魂法、天魔刀/天魔金刀/大天魔刀/天魔火刀、天魔斩、天魔乱舞。因为并非针对人类所创的功法，因此若天资不够者修炼，则极易外貌变形、精神失控。

天妖屠神法－天妖、蚩尤、妖帅、李建成、朝阳天师
天妖所创的邪门绝学，天妖屠神法共分九式，配合天妖战甲及屠神妖棒，威力惊人。**第一式** 吸阴式 **第二式** 刁魂破 **第三式** 妖魂冲霄 **第四式** 天魂碎狱/吸天蚀日 **第五式** 千魂屠城 **第六式** 妖锁囚神 **第七式** 幻魅妖球 **第八式** 妖乱天地 **第九式** 妖极灭世。由于天妖和大天魔的仇恨，后世继承天妖屠神法的人会与天魔功的继承者成为宿敌。

如来神掌－龙戈儿、李世民、摩诃叶、魔弥陀、郭荣（柴荣）
佛门武功，共有九式，为佛祖所创。在天子四、五中大放异彩。天子四只出现过头四式神掌，每式皆有法器。天子五中出现过所有神掌，每式都有一把护法佛兵，要结下法印才可使出。练齐头七式神掌，才可修练神掌第八式佛法无边。练齐头八式神掌，兵解头八大佛兵，才可练修终极神掌万佛朝宗，整个天子传奇系列只有佛祖和龙戈儿练就全九式如来神掌。

===《天子传奇》历代剧情介绍===

*开周篇-
**三千年前的商朝末代君王纣王横征暴敛，更修练歹毒的天魔功，使得民不聊生。此时西岐西伯侯姬昌次子姬发历三年怀孕期而降生，负有九九命数，经姬昌以九鼎奇法转移命格成为九五至尊。引发纣王杀机，姬发师承父亲门派－广成仙派，修练先天乾坤功，又经过飘渺城奇遇，巧得女娲绝学－浑天宝鉴，在一连串的奇遇与冒险之中，姬发结识了各路英雄，却也接连失去了长兄姬考与父亲。在姬昌死亡后，姬发继承父亲西伯侯爵位，打正招讨旗帜，历经三年征伐，终在朝歌城与纣王展开惊天神功决战……

***解说-本篇剧本参考封神榜，将哪咤的降生奇遇转至主角姬发身上，也出现了许多封神榜中的要角，但原创的人物仍然占有上风，天子传奇的两大天子武学也在本篇大放异彩。

*秦皇篇-
**战国时代末期，楚国大灵巫－项魁，卜得“秦生子，十二月”预言，得知秦国王孙－历经十二月怀胎诞生的嬴政将会一统天下，使楚国覆亡。嬴政历经连环追杀，全凭生父吕不韦所赠浑天宝鉴自强茁壮。但情敌燕太子丹仍不断物色力士，甚至出兵伐之。回返秦国之后，嬴政又面临与名分兄弟－成𫊸争夺太子权位的兄弟斗争，最终嬴政与身负浑天宝鉴最高境界的成𫊸决战，终登位成秦王。

***解说-本篇为了符合始皇十二岁登位的史实，将秦始皇描写成一个具有成人体格的幼童，撇开此点不论，对于叙述青少年时期的始皇仍可算是精彩。但秦皇登位后，雄霸六国的战争史却轻描淡写带过。

*流氓天子-
**秦王政十一年，沛县一名游手好闲的流氓刘邦，因为积欠债务导致父母连坐，遂打定主意将当时全国通令悬赏的大盗－任横行逮捕以交换赏金，但任横行却在义助刘邦后，将刘邦半拐半带，预备趁秦皇上博浪沙见方士徐福途中，行使刺秦大计。

路途中刘任二人因缘邂逅张良，齐国田单后人田猛，齐志刺秦。

但在秦始皇浑天宝鉴神功之下败死，只得刘邦与张良分散逃脱。

刘邦巧得周武王神兵－天剑，在徐福暗中帮助之下，遁至咸阳，同时结识西楚豪雄－项羽。

两人毫不对盘，但仍在项羽军队协助与张良范增智谋下，成功偷走咸阳城上的十二金(铜)人，以充作项羽反秦兵器来源。

刘邦项羽更于秦始皇出海射鲛时，将秦始皇合力斩杀。

但秦皇死后并未带来和平，而是各地拥兵自重的天下大乱。

在楚怀王下，刘邦与项羽各自拥有兵力，成为一方之主，但项羽在智囊范增与挚爱虞姬先后死亡，行事越见偏急，终于在四面楚歌与十数夜血战之后，于乌江自刎。

***解说-本篇出现了许多不符合史实的生活面貌与文物，故事在任横行刺秦与北海刺秦时达到高峰，之后的楚汉相争剧情却显得无关痛痒，只为了拖延至结局乌江自刎。

*大唐威龙-
**隋文帝仁寿四年，极乐正宗宗主摩诃叶扶持杨广弑父登基，但摩诃叶却选择项羽遗物－雷刀为天子神兵，并积极布下自己成皇的惊天大计。

摩诃叶阴谋将唐国公李渊次子李世民偷龙转凤，李世民（冒充）也随着父命招讨瓦岗寨之下，展开了自己的江湖历练，结识程咬金、虬髯客、李靖等反隋义士，又经过奇遇发掘了自己的佛门“伏魔尊者”天命与成皇之命，练成两式如来神掌，然而自己身世之谜与摩诃叶的权威，却始终无法克服。

隋炀帝意欲发掘秦皇陵中的万世潜龙穴与诸多秘宝，引动各路人马争相入陵，激战连场之下，李元霸死亡，却以自己的血肉之躯，在万世潜龙穴中，为李家定下二十代称皇之天数。

在诛杀隋炀帝后，摩诃叶扶持李渊成皇，是为唐朝。

但李世民的身世揭露，却未能使李家三兄弟真正团结，为求诛灭心腹大患摩诃叶，李家策划玄武门之变，但李建成与李元吉两人各怀鬼胎与妖、魔武功，却要先杀摩诃叶再杀李世民，最终决战里李世民再度诛杀兄弟，成为太子。

却在随后暴起的突厥共主“天可汗”手下，失去挚爱而入魔，在与支配自己半生的摩诃叶决战后，李世民成为万民景仰的唐太宗，却一生仍然活在摩诃叶的阴影里直到死去。

***解说-本篇故事有相当多的原创部分，也创造了许多玉皇朝的经典人物如摩诃叶、再世霸王杨玄感等，同时也因为吸收了许多前几代的原素如武功(天魔功、天妖屠神法)、兵器(天剑雷刀)、以及龙虎五世的资源。堪称为玉皇朝的经典杰作。但为了收拾大魔头摩诃叶，而强加上去的结局“天可汗篇”，却使得这部作品毁誉参半。

*如来神掌-
**唐代灭亡进入五代十国时期，江湖上有一邪宫、双飞堡、三绝观三大势力，为辽国、南唐、后汉所用。

主角龙戈儿因一次机缘由唐代遗孤李无名身上习得三式如来神掌，展开行侠仗义之路。

龙戈儿在夺取雷刀一战会过一邪皇甫极，并结识了赵匡胤，及后又习得如意禅，接受了神掌传人柴荣的功力而令武艺突飞猛进。

在杀胡林一役中，龙戈儿击败了黑巫大神，斩下耶律德光，令一邪谋反大辽的阴谋被毁。

及后天竺恶僧魔弥陀出现，以其强横的神掌先后击败东海一奇、骷髅魔、一悟、双飞项无恨、龙戈儿与一邪皇甫极一众高手，并成为后汉国师。

其后龙戈儿与项无恨练功一年，再战魔弥陀，但联手仍不敌拥有飞龙异血的魔弥陀。

为铲除魔弥陀，护龙大使银铃将玄宇宙晶柱交给皇甫极，皇甫极临阵练成玄宇宙击破魔弥陀的佛法无边，而魔弥陀则在前往天竺途中给龙戈儿分身极恶龙戈儿击杀。

吸收中原的六大佛兵后，龙戈儿与极恶龙戈儿一同前往天竺修练万佛朝宗。

修练完成，龙戈儿再次正邪合一，并兵解九大佛兵。

龙戈儿回到中原后巧遇千岁法王，并因救葆儿而离开中原到了西域，在西域巧遇皇甫极，并在交手的过程将浑天宝鉴玄宇宙最高境界玄宇宙三变化传给皇甫极。

此后龙戈儿、皇甫极一行人进入了吕洞宾的天道仙府，皇甫极一家团圆，心结亦得解除，而龙戈儿就得到由佛兵元素炼成的火云圣衣。

回到中原，龙戈儿与云师及被天魔功控制的项无恨大战，大败后又再因心慈手软败给已练成天子剑法的赵匡胤。

其后，后周世宗柴荣战死，赵匡胤在陈桥兵变取而代之成为皇帝，挥军直指双飞堡支持的南唐。

击杀云师回复清醒并功力大增的项无恨，和太祖皇帝赵匡胤拼过你死我活，龙戈儿纵使扭尽六壬亦无法平息战局，最后改邪归正的皇甫极出山赶到战场，在龙戈儿和皇甫极的联手下终于令项无恨和赵匡胤的大战结束，宋朝最后统一天下。

***解说-本辑天子一共214期，故事一反传统以原创角色龙戈儿做主角，戏份极重的皇甫极和项无恨亦是原创角色，相反历史人物赵匡胤和柴荣则在多个要角中戏份较少和不吃重。由于原创角色位置远超历史人物，使此作角色较难为读者接受，主角龙戈儿立场不明兼且性格温吞，令故事较为松散，但在表达慈悲救世、牺牲小我、完成大我这些主题方面尚算成功。

# 天子传奇（霹雳布袋戏剧集）

================================================================================

《天子传奇》是改编自黄玉郎同名香港漫画的霹雳布袋戏。该剧以商周政权更迭为背景，融合《封神演义》神怪元素，讲述西伯侯姬昌次子姬发降世时引发天命异象，历经九鼎奇法改命、纣王暴政迫害最终建立周朝的故事。剧情围绕殷商王朝与西岐势力的冲突展开，包含龙龟暴毙、九鼎阴阳挪移大法、灵人炼制等关键事件。剧中戏偶造型融合漫画设定与商周服饰特征，道具仿制编钟、青铜鼎等古器物。作为首部漫改霹雳布袋戏，该剧由杨月卿、李世光担任编剧，制作过程中与香港玉皇朝出版社合作。武戏设计包含马上战斗与完整斗术体系，采用多人闽南语配音阵容。

**中文名**：天子传奇

**别名**：天子传奇——开周记出 自霹雳布袋戏

**配音**：黄文择

**《天子传奇》**是黄玉郎1993年出狱后第5次创业而创作的主打漫画。原本黃氏是打算推出另一部獄中構思作品義勇門來打頭炮，但由於首徒祈文傑的勸說，認為《天子》好意頭，有利玉皇朝發展，是以改由《天子》作為黃氏的重新創業作。

目前為止，《天子》系列合共六輯，分別有《天子传奇1－開周篇》（周）、《天子传奇2－秦皇篇》（秦）、《天子传奇3－流氓天子》（汉）、《天子传奇4－大唐威龍》（唐）、《天子传奇5－如来神掌》（宋）及《天子傳奇6－洪武大帝》（明）共六部。

《天子傳奇》的故事劇情由黃易擔綱編劇，因此可以算是黃易的作品之一，而黃易擔綱的部份約是前三部，第四部開始由鄺彬強接手，第五部由黃玉郎及旗下編劇輪流擔任，第六部為袁家寶。

===《天子传奇》歷代武學介紹===

**天子武學**顧名思義，便是歷代天子學習傍身以打天下的武藝，與傳統武俠小說中的武功不同之處，在於這些天子武學大多都是**神**所創造的絕學，與君權神授的理念相同。

為了推陳出新，有些天子武學到了下一代還會出現變化，但讀者的評價往往是新不勝舊。

本目錄中除天子武學外，連反派主角及其他配角的武功也一併收錄。

先天乾坤功－姬發、姬昌、姬考、一憂子、燕太子丹、趙匡胤
屬於道教武功。黃帝之師廣成子所傳**廣成仙派**的絕學，初期的版本雜亂，中後期開始奠定必殺著為**乾坤七絕**。**第一绝** 乾坤无定/乾坤无量 **第二绝** 震驚百里 **第三绝** 天火燎原 **第四绝** 天道循环 **第五绝** 雷动九天。並出現在龍虎五世中。在天子5中，趙匡胤將其與「混元無極大道」融會貫通、合而為一成『乾坤無極道』，變為內功。

渾天寶鑑－姬發、嬴政、胡亥、扶蘇、成蟜、飄渺城主、蒼龍星君、白虎星君、朱雀星君、媧姐、劍帝、天絕、地絕、皇甫極、朝陽天師、柴榮、五靈子、張彥澤、喬榮
沒有教派。

故事中為女媧補天時所遺留下的十枚天晶，與一般武俠小說常用的秘笈經典不同。

可說是創舉，共分十層，每一層心法口訣均藏於一枚天晶內。

不同於一般能量屬性的設定為其特色。**第一層** 白云烟 （白云剑）**第二層** 玫霞荡 （霞荡剑）**第三層** 土昆仑 （昆仑剑）**第四層** 碧冰雪 （碧雪剑）**第五層** 紫星河 （星河气旋、回转星河、星河暴斩、星河剑 ）**第六層** 玄浑沌 （茧困势、混沌剑）**第七層** 靛沧海 （滔天势、浪卷势、深渊势、鲸吞势、靛海剑）**第八層** 金晨曦 （朝阳耀天、无定飞星、金剑穿云、双芒赶月、五爪金龙、无敌金环、霹雳摧天、金阳破岭、金阳破岳、日月争辉、十阳归一）**第九層** 血苍穹 （穹苍血甲、血海无涯、冰柱擎天、穹苍无涯、血雾迷踪、血阳撕天、穹苍无边、穹苍无悔）**第十層** 玄宇宙（二境:化劫、归真 三变化:大爆炸、天行健、破虚空）

天魔功－紂王、姬考、元始天魔、楊廣、李元吉、雲師、雲宇、雲宙
大天魔進攻天界失敗後被斬首，因其怨念使其頭顱以鮮血在人界石壁上留下的功法。內容千羅萬象，有**內功**：陰陽兩極魔道、**外功**：天魔神功 **天魔五絕**:天魔极乐,天魔撕天,天魔裂地,天魔金身,天魔怒震、**天魔四蝕**:天魔蚀肉,天魔蚀骨,天魔蚀经,天魔蚀魂 天魔種功、天魔指、天魔拳、天魔锥/天魔金锥、采阴移魂法、天魔刀/天魔金刀/大天魔刀/天魔火刀、天魔斩、天魔乱舞。因為並非針對人類所創的功法，因此若天資不夠者修煉，則極易外貌變形、精神失控。

天妖屠神法－天妖、蚩尤、妖帥、李建成、朝陽天師

===《天子傳奇》歷代劇情介紹===

*開周篇-
**三千年前的商朝末代君王紂王橫徵暴斂，更修練歹毒的天魔功，使得民不聊生。此時西岐西伯侯姬昌次子姬發歷三年懷孕期而降生，負有九九命數，經姬昌以九鼎奇法轉移命格成為九五至尊。引發紂王殺機，姬發師承父親門派－廣成仙派，修練先天乾坤功，又經過飄渺城奇遇，巧得女媧絕學－渾天寶鑑，在一連串的奇遇與冒險之中，姬發結識了各路英雄，卻也接連失去了長兄姬考與父親。在姬昌死亡後，姬發繼承父親西伯侯爵位，打正招討旗幟，歷經三年征伐，終在朝歌城與紂王展開驚天神功決戰……

***解說-本篇劇本參考封神榜，將哪吒的降生奇遇轉至主角姬發身上，也出現了許多封神榜中的要角，但原創的人物仍然佔有上風，天子傳奇的兩大天子武學也在本篇大放異彩。

*秦皇篇-
**戰國時代末期，楚國大靈巫－項魁，卜得「秦生子，十二月」預言，得知秦國王孫－歷經十二月懷胎誕生的嬴政將會一統天下，使楚國覆亡。嬴政歷經連環追殺，全憑生父呂不韋所贈渾天寶鑑自強茁壯。但情敵燕太子丹仍不斷物色力士，甚至出兵伐之。回返秦國之後，嬴政又面臨與名分兄弟－成蟜爭奪太子權位的兄弟鬥爭，最終嬴政與身負渾天寶鑑最高境界的成蟜決戰，終登位成秦王。

***解說-本篇為了符合始皇十二歲登位的史實，將秦始皇描寫成一個具有成人體格的幼童，撇開此點不論，對於敘述青少年時期的始皇仍可算是精彩。但秦皇登位後，雄霸六國的戰爭史卻輕描淡寫帶過。

*流氓天子-
**秦王政十一年，沛縣一名遊手好閒的流氓劉邦，因為積欠債務導致父母連坐，遂打定主意將當時全國通令懸賞的大盜－任橫行逮捕以交換賞金，但任橫行卻在義助劉邦後，將劉邦半拐半帶，預備趁秦皇上博浪沙見方士徐福途中，行使刺秦大計。

路途中劉任二人因緣邂逅張良，齊國田單後人田猛，齊志刺秦。

但在秦始皇渾天寶鑑神功之下敗死，只得劉邦與張良分散逃脫。

劉邦巧得周武王神兵－天劍，在徐福暗中幫助之下，遁至咸陽，同時結識西楚豪雄－項羽。

兩人毫不對盤，但仍在項羽軍隊協助與張良范增智謀下，成功偷走咸陽城上的十二金(銅)人，以充作項羽反秦兵器來源。

劉邦項羽更於秦始皇出海射鮫時，將秦始皇合力斬殺。

但秦皇死後並未帶來和平，而是各地擁兵自重的天下大亂。

在楚懷王下，劉邦與項羽各自擁有兵力，成為一方之主，但項羽在智囊范增與摯愛虞姬先後死亡，行事越見偏急，終於在四面楚歌與十數夜血戰之後，於烏江自刎。

***解說-本篇出現了許多不符合史實的生活面貌與文物，故事在任橫行刺秦與北海刺秦時達到高峰，之後的楚漢相爭劇情卻顯得無關痛癢，只為了拖延至結局烏江自刎。

*大唐威龍-
**隋文帝仁壽四年，極樂正宗宗主摩訶葉扶持楊廣弒父登基，但摩訶葉卻選擇項羽遺物－雷刀為天子神兵，並積極佈下自己成皇的驚天大計。

摩訶葉陰謀將唐國公李淵次子李世民偷龍轉鳳，李世民（冒充）也隨著父命招討瓦崗寨之下，展開了自己的江湖歷練，結識程咬金、虯髯客、李靖等反隋義士，又經過奇遇發掘了自己的佛門「伏魔尊者」天命與成皇之命，練成兩式如來神掌，然而自己身世之謎與摩訶葉的權威，卻始終無法克服。

隋煬帝意欲發掘秦皇陵中的萬世潛龍穴與諸多秘寶，引動各路人馬爭相入陵，激戰連場之下，李元霸死亡，卻以自己的血肉之軀，在萬世潛龍穴中，為李家定下二十代稱皇之天數。

在誅殺隋煬帝後，摩訶葉扶持李淵成皇，是為唐朝。

但李世民的身世揭露，卻未能使李家三兄弟真正團結，為求誅滅心腹大患摩訶葉，李家策劃玄武門之變，但李建成與李元吉兩人各懷鬼胎與妖、魔武功，卻要先殺摩訶葉再殺李世民，最終決戰裡李世民再度誅殺兄弟，成為太子。

卻在隨後暴起的突厥共主「天可汗」手下，失去摯愛而入魔，在與支配自己半生的摩訶葉決戰後，李世民成為萬民景仰的唐太宗，卻一生仍然活在摩訶葉的陰影裡直到死去。

***解說-本篇故事有相當多的原創部分，也創造了許多玉皇朝的經典人物如摩訶葉、再世霸王楊玄感等，同時也因為吸收了許多前幾代的原素如武功(天魔功、天妖屠神法)、兵器(天劍雷刀)、以及龍虎五世的資源。堪稱為玉皇朝的經典傑作。但為了收拾大魔頭摩訶葉，而強加上去的結局「天可汗篇」，卻使得這部作品毀譽參半。

*如來神掌-
**唐代滅亡進入五代十國時期，江湖上有一邪宮、雙飛堡、三絕觀三大勢力，為遼國、南唐、後漢所用。

主角龍戈兒因一次機緣由唐代遺孤李無名身上習得三式如來神掌，展開行俠仗義之路。

龍戈兒在奪取雷刀一戰會過一邪皇甫極，並結識了趙匡胤，及後又習得如意禪，接受了神掌傳人柴榮的功力而令武藝突飛猛進。

在殺胡林一役中，龍戈兒擊敗了黑巫大神，斬下耶律德光，令一邪謀反大遼的陰謀被毀。

及後天竺惡僧魔彌陀出現，以其強橫的神掌先後擊敗東海一奇、骷髏魔、一悟、雙飛項無恨、龍戈兒與一邪皇甫極一眾高手，並成為後漢國師。

其後龍戈兒與項無恨練功一年，再戰魔彌陀，但聯手仍不敵擁有飛龍異血的魔彌陀。

為鏟除魔彌陀，護龍大使銀鈴將玄宇宙晶柱交給皇甫極，皇甫極臨陣練成玄宇宙擊破魔彌陀的佛法無邊，而魔彌陀則在前往天竺途中給龍戈兒分身極惡龍戈兒擊殺。

吸收中原的六大佛兵後，龍戈兒與極惡龍戈兒一同前往天竺修練萬佛朝宗。

修練完成，龍戈兒再次正邪合一，並兵解九大佛兵。

龍戈兒回到中原後巧遇千歲法王，並因救葆兒而離開中原到了西域，在西域巧遇皇甫極，並在交手的過程將渾天寶鑑玄宇宙最高境界玄宇宙三變化傳給皇甫極。

此後龍戈兒、皇甫極一行人進入了呂洞賓的天道仙府，皇甫極一家團圓，心結亦得解除，而龍戈兒就得到由佛兵元素煉成的火雲聖衣。

回到中原，龍戈兒與雲師及被天魔功控制的項無恨大戰，大敗後又再因心慈手軟敗給已練成天子劍法的趙匡胤。

其後，後周世宗柴榮戰死，趙匡胤在陳橋兵變取而代之成為皇帝，揮軍直指雙飛堡支持的南唐。

擊殺雲師回復清醒並功力大增的項無恨，和太祖皇帝趙匡胤拼過你死我活，龍戈兒縱使扭盡六壬亦無法平息戰局，最後改邪歸正的皇甫極出山趕到戰場，在龍戈兒和皇甫極的聯手下終於令項無恨和趙匡胤的大戰結束，宋朝最後統一天下。

***解說-本輯天子一共214期，故事一反傳統以原創角色龍戈兒做主角，戲份極重的皇甫極和項無恨亦是原創角色，相反歷史人物趙匡胤和柴榮則在多個要角中戲份較少和不吃重。由於原創角色位置遠超歷史人物，使此作角色較難為讀者接受，主角龍戈兒立場不明兼且性格溫吞，令故事較為鬆散，但在表達慈悲救世、犧牲小我、完成大我這些主題方面尚算成功。

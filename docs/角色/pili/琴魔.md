# 琴魔
================================================================================

琴魔

魔界天魔录中琴艺的佼佼者，本身淡泊名利，只对“琴”有极度的偏执狂热。为人知书达礼、重视情义，一生只想结交知音琴友；而卧云即是在相思林中弹起天琴而深获琴魔倾心，二人初见合奏、宛若天籁，为以琴会知音的最佳典范。
如今再现，以英灵型态相助白无垢等人同抗冥河之母。

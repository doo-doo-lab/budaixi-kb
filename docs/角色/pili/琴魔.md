# 琴魔

魔界天魔录中琴艺的佼佼者，本身淡泊名利，只对“琴”有极度的偏执狂热。为人知书达礼、重视情义，一生只想结交知音琴友；而卧云即是在相思林中弹起天琴而深获琴魔倾心，二人初见合奏、宛若天籁，为以琴会知音的最佳典范。
如今再现，以英灵型态相助白无垢等人同抗冥河之母。

## 来自百度百科的补充

琴魔乃天魔录隐世的琴艺高手，本身淡泊名利，对"琴"有极度的偏执狂热，认同天魔的理念而涉世襄助。但正逢天魔实行佛魔合体，实际被蘅佛子控制，因此逐渐生出离去之心。和卧云先生因合奏而产生友情，但是两人的琴音也会让天魔佛魔分体，因此招致天魔逼杀。其后天魔在白无垢的劝说下以无量琴诱使琴魔重归魔界阵营，但实际上这是白无垢的计谋，最后终于达成琴魔、卧云各自以无量琴、大悲三昧弦合奏破解佛魔合体一事。

爱琴成痴的琴魔，在终魇烬土为助天魔出现江湖，看重天魔之才能而帮助天魔，在黑暗道为杀素还真，却反被琴音反弹而现出真身。代替天魔赴素还真的战约之时，被卧云先生的琴艺所吸引，并与卧云结为好友，却违反了天魔的命令，琴魔渐感觉天魔有改而离开屠变之塔。但琴魔与卧云合奏时的琴音曾令佛魔合体产生变化，因此天魔命魔界大军逼杀琴魔，琴魔感到万般无奈。

而后白无垢献计天魔，使天魔渐缓对琴魔的攻势，改为动之以情找来无量琴赠予琴魔，琴魔心存感激。在破佛魔合体之时，琴魔与卧云两人以无量琴、大悲三昧弦突破佛魔合体，让天魔脱离蘅佛子。天魔回归，琴魔也回到魔界协助，与傲神州、星野残红、白无垢同为天魔换血，并协助魔界事务。在天魔命令下，琴魔关注素还真、卧云的动向，找上司马剑秋打听劫走素还真的六道光影去向。后为调查潇潇的底细前往雨风飘摇，却因潇潇多变的个性，措手不及的杀招，让琴魔猝不及防，绝命雨风飘摇。

# 天外南海

================================================================================

霹雳布袋戏虚拟地界天外南海，霹雳布袋戏虚构的独立空间。天外南海位于四境之外，地理构造与苦境相似，包含五域、四族、二城。东域为兽族丛林栖息地，南域虫族擅用毒术，北域翼族占据山岭，西域人族接近苦境平民，中域由冰川刀城（精研铸刀）与傲刀天下（专攻刀法）分治。各族以刀为核心武器，交通依赖雪船及飞行器具。中文名天外南海活跃时期霹雳兵燹、霹雳刀锋等基地/辖区傲刀城、冰川刀城、九耀云峰、沼泽等奇珍异宝九耀芙蓉石、万毒珠、飞行船、邪帝黑虫

**天外南海**是霹靂布袋戲中的一個組織及地點，活躍於霹靂兵燹-霹靂異數之萬里征途。

===基本介紹===
有別於苦集滅道四境之另一空間，山川地理與苦境大同小異，而區域上大致分成五域四族二城。五域是以地理畫分，東域是「獸族」所居之地，獸族之人攻擊強悍、作為野蠻，域內全是又高又密的叢林樹木；南域是「蟲族」之地，地質貧乏、黃土遍佈，而蟲族之人較為狡詐，擅於使毒；北域是「翼族」之地，因為翼族擅於飛翔，所以域內全是奇山峻嶺，行事謹慎、防禦心強；西域是「人族」所居，但是居住者皆是平民階層，外表也最為接近苦境的人；中域各有「冰川刀城」與「傲刀天下」所統轄，冰川刀城世代精研鑄刀之法，傲刀城一脈，與冰川刀城恰巧相反，代代精研刀法，人族的刀法幾乎以他們為首，兩城雖同屬貴族階層，但是不同的派系也可說是兩國並立、各自為政，兩城之間互通聯姻。孰料，多年前冰川刀城為殺手一夕所滅，傲刀天下便掌握了整個天外南海；但四族之間的排他以及皇城內鬥，始終未曾停歇過，直到傲刀青麟揭竿起義，在臥江子與各方勢力協助下，天外南海終告大一統。

==景點==
傲刀城、冰川刀城、九耀雲峰、獸族蟲林、虺域

==交通==
需以雪船或飛行船橫渡冰河天川，或是透過關雲渡隘口由九耀雲峰進入。

==標誌==
「刀」乃天外南海創建標誌，四族幾乎以刀為武器、精於刀法。

==奇珍異寶==
九耀芙蓉石、萬毒珠、飛行船、邪帝黑蟲

==特色==
分為翼獸蟲三族乃「邪帝」所創之物種，在外表和性格上也都具備其種族之特色。

# 天外南海

霹雳布袋戏虚拟地界天外南海，霹雳布袋戏虚构的独立空间。天外南海位于四境之外，地理构造与苦境相似，包含五域、四族、二城。东域为兽族丛林栖息地，南域虫族擅用毒术，北域翼族占据山岭，西域人族接近苦境平民，中域由冰川刀城（精研铸刀）与傲刀天下（专攻刀法）分治。各族以刀为核心武器，交通依赖雪船及飞行器具。中文名天外南海活跃时期霹雳兵燹、霹雳刀锋等基地/辖区傲刀城、冰川刀城、九耀云峰、沼泽等奇珍异宝九耀芙蓉石、万毒珠、飞行船、邪帝黑虫

**天外南海**是霹雳布袋戏中的一个组织及地点，活跃于霹雳兵燹-霹雳异数之万里征途。

## 基本介绍
有别于苦集灭道四境之另一空间，山川地理与苦境大同小异，而区域上大致分成五域四族二城。五域是以地理画分，东域是“兽族”所居之地，兽族之人攻击强悍、作为野蛮，域内全是又高又密的丛林树木；南域是“虫族”之地，地质贫乏、黄土遍布，而虫族之人较为狡诈，擅于使毒；北域是“翼族”之地，因为翼族擅于飞翔，所以域内全是奇山峻岭，行事谨慎、防御心强；西域是“人族”所居，但是居住者皆是平民阶层，外表也最为接近苦境的人；中域各有“冰川刀城”与“傲刀天下”所统辖，冰川刀城世代精研铸刀之法，傲刀城一脉，与冰川刀城恰巧相反，代代精研刀法，人族的刀法几乎以他们为首，两城虽同属贵族阶层，但是不同的派系也可说是两国并立、各自为政，两城之间互通联姻。孰料，多年前冰川刀城为杀手一夕所灭，傲刀天下便掌握了整个天外南海；但四族之间的排他以及皇城内斗，始终未曾停歇过，直到傲刀青麟揭竿起义，在卧江子与各方势力协助下，天外南海终告大一统。

==景点==
傲刀城、冰川刀城、九耀云峰、兽族虫林、虺域

==交通==
需以雪船或飞行船横渡冰河天川，或是透过关云渡隘口由九耀云峰进入。

==标志==
“刀”乃天外南海创建标志，四族几乎以刀为武器、精于刀法。

==奇珍异宝==
九耀芙蓉石、万毒珠、飞行船、邪帝黑虫

==特色==
分为翼兽虫三族乃“邪帝”所创之物种，在外表和性格上也都具备其种族之特色。

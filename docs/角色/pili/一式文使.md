# 一式文使

因碧江孤舟桑道凉之死，由殷末箫所请出的隐世法医，熟知脉理之道和武功招式特征，以精准老练的长针勘验手法，断定双剑一掌伤痕背后的致命之招，悉不知一连串的阴谋却也由此而生...。

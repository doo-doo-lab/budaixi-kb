# 紫星眉

三教时代名闻遐迩的星象家，曾预言七星将毁灭武林，随即消失于武林之中，而预言之事不断扩散，引起众人陷入追杀七星的盲目状态中，自己却隐藏其为七星之主的真实身份。巧言伪善、利益熏心，以吸取七星星灵增加自身功力。

## 角色设定

紫星眉，霹雳布袋戏中的角色，初登场于《霹雳英雄榜之争王记》第7集，退场于《霹雳图腾》第11集。

他是三教时代名闻遐迩的星象家，曾预言七星将毁灭武林，随即消失于武林之中，而预言之事不断扩散，引起众人陷入追杀七星的盲目状态中，自己却隐藏其为七星之主的真实身份。曾以一副可怜的残疾者模样出现，用心计较地取得了素还真的信任。紫星眉一方面和正道众人保持友好关系，另一方面积极地逼杀七星，并设计正道人士，企图吸收七星星灵增加自身功力以夺取上古七星之主秘籍。但其阴谋在云渡山上真相大白，七星之主身份暴露。最终，紫星眉被另一个七星之主设计，因而成了天策真龙的傀儡。

紫星眉巧言伪善、利益薰心，其野心造就了他，也最终毁了他。他在计谋、武学方面高人一等，但未用在正道上，最终尝到了恶果。

性格：权力欲望极重，心思细腻，但待朋友极好，甚至能共享一切。

## 人物经历

紫星眉以一副可怜的残疾者模样出现，用心计较地取得了素还真的信任。初期，在紫星眼的验证下，素还真曾被误认为是七星之主，但此实为误会。为达目的，紫星眉实施奸险之计，步步追杀七星以吸取其星灵之力。

其身份最终在云渡山上被揭露，七星之主正是紫星眉本人，此事令一页书等正道人士怒不可遏。身份暴露后，紫星眉在云渡山与为友复仇的东陵少主、一页书以及病剑叟展开激烈战斗。

## 相关作品

紫星眉登场的主要剧集包括《霹雳英雄榜之争王记》和《霹雳图腾》。在《霹雳英雄榜之争王记》中，紫星眉于第8集、第30集登场，剧中隐藏其七星之主的真实身份，并实施了奸险之计与弑亲阴谋。在《霹雳图腾》中，紫星眉于第5集、第6集登场，剧中其七星之主的身份在云渡山被揭露，并因此与东陵少主、一页书等人爆发激战。

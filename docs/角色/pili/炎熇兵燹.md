# 炎熇兵燹
================================================================================

炎熇兵燹

妖刀诀的创始者，白玉面具下有张俊美如斯的面孔，但个性喜怒无常、嗜血、残毒，让人难以捉摸，沉溺于杀人与痛苦的快感之中，变态的笑声令人印象深刻。毕生所求，乃妖刀的完美极致；至于身世背景，则是异常扑朔迷离…

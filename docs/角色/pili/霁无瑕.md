# 霁无瑕

================================================================================

霹雳布袋戏中的角色霁无瑕，霹雳布袋戏中的角色。霁无瑕是风姿飒爽、直接俐落的豪气女侠客，行走武道仗义不平，天生神力无穷，手持极重的泰若山剑，曾一剑击退巨魔神，罕逢匹敌对手。真实身份为魔佛波旬中的女琊，因遭烽火关键冲撞，导致波旬三体分离，神智受创错乱，方以侠女之姿行走江湖。

## 角色背景

波旬再出，势必惊天动地、无人能敌，武林再度遭劫，必定会有好几个运气不好的被波旬拿来祭旗，不过编剧似乎不打算重走当年弃天帝灭世路线，因此波旬一出场就被铺排已久的烽火关键击散，让三体不但分离，并进行大改造，让当初在霹雳封灵岛中登场、高高在上的波旬，开展不同以往的故事路线。

而女琊则化身成为快雪时晴霁无瑕，行走江湖、快意任侠。

霁无瑕人物塑造来自编剧的取名，快雪时晴取自大书法家王羲之墨宝名帖，内容为王羲之在大雪过后，天气放晴时的愉快心情以及对朋友的问候。

以快雪时晴呈现出的清朗景色，衍伸出人物的豪迈。

而霁也有雪后转晴之意，晴空下的积雪，有如无瑕白玉，人物形态也顺势成为侠女风采。

快雪时晴霁无瑕初现身，攘住佛乡高僧击退巨魔神，保护百姓的举动，料想并非恶徒，然而鷇音子对秦假仙说出，快雪时晴就是女琊时，想必各位观众也都是跟秦假仙一样，“啥？

你讲对啊不对？”受到迷达密咒影响，快雪时晴被一页书打伤，辗转获殊十二援救，带往碎云天河由剑之初照料，期间由于剑之初救了秦假仙，剑之初父子得知了快雪时晴的真实身份，女琊有其波旬天命，待伤愈之后回到武林，也许有一天会回归欲界，因此剑之初常在言谈之中引导，希望改变不可预知的未来。

最终快雪时晴恢复身为女琊时的记忆，但却陷入两难中。

一方面希望与殊十二一起退隐在碎云天河，但另一方面担心自己会为十二带来麻烦，而自己也无法完全放下欲界那些忠心自己的部众以及同修之情。

与阎达定下相助3次之约希望三次之后能远离曾经的自己，做回快雪时晴霁无瑕。

可惜天意弄人，为除魔佛波旬之祸，霁无瑕必须牺牲自己才能完成祸棺祭。

最终为大义牺牲自己，快雪时晴终返侠心。

## 角色形象

造型霁无瑕的造型造型：人物设定一切来自快雪时晴四字，造型也不例外，以水蓝、白色为主，给人一种清冷缥缈的感觉，尤为突出的是一柄黑赤色的宝剑，凸显了清冷的外表下的一颗侠心。与之前女琊的造型有明显差异。披风：与其他角色的披风在设计上的差异是穿脱非常方便。衣物：特殊剪裁，仔细一看，有明显腰身。不过有点窄的衣服会非常挑战操偶师的技术。场景雪晴坊霁无瑕正式登场的场景，天空飘雪，地面积雪，演绎一代女侠豪放风采。

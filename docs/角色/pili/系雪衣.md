# 系雪衣

西儒青年才俊，个性儒雅中带点风趣，玉树临风，仙风道骨。本为庭三帖之后生晚辈、左丘默的学长，却是当年一笔春秋公认的后起之秀，才情出众，人称“八采儒鹤”。当年因故辞退西儒掌门竞拔而去，并离开一笔春秋，天下远游。

## 来自百度百科的补充

系雪衣是霹雳布袋戏《霹雳天命》系列中的虚拟角色。他本是西儒组织“一笔春秋”的后起之秀，才情出众，人称“八采儒鹤”，个性儒雅中带点风趣，玉树临风。曾参与西儒掌门竞拔，但因义妹闻疏梅遭章仇无期侮辱，他为义妹仗义执剑，导致章仇无期死亡、闻疏梅自焚，遂离开一笔春秋天下远游。系雪衣是剑族三大锋芒之一，义父是情不返，重感情，身边有姑苏还剑、公子笑纳等朋友。他承诺为西儒找回传脉之宝泣麟藏颖，最终以生命为代价从鬼族寻回，身受重伤，在子衿亭写下“护”字后去世。

系雪衣的母亲本是剑族三大锋芒之一情不返喜欢之人，却离开情不返并与他人生下孩子，走投无路之际又将幼子托付给情不返。义父情不返对幼年的系雪衣总是沉默不苟言笑，却也以自己的背影庇护系雪衣多年。

系雪衣本是西儒一笔春秋的后起之秀，才情出众，人称八采儒鹤。曾参与一笔春秋主事竞拔，庭主对他别有垂青，寄予厚望。

因一起桃色事件（义妹闻疏梅遭章仇无期酒后侮辱，系雪衣为义妹仗义执剑导致章仇无期死亡，闻疏梅自焚），系雪衣心中失了最深的依恋，辞退掌门竞拔，离开一笔春秋，天下远游。

系雪衣个性儒雅中带点风趣，玉树临风，仙风道骨。他出身儒门，有君子之德，重感情而又感情内敛，然却实则慨而不慷，刚而不折。

系雪衣因义妹闻疏梅遭章仇无期酒后侮辱，为其仗义执剑，在决斗中击断章仇无期宝剑致其死亡；闻疏梅随后自焚，系雪衣因此心灰意冷，遁离儒门，天下远游。章仇无期之友姑苏还剑为友复仇，与系雪衣多次对决，最终二人化解误会成为朋友，并一同查案。

在西煌佛界线，鬼族谋夺万魗荒岩，系雪衣巧施李代桃僵之计保住荒岩，让姑苏还剑带回救人；后因计谋被识破导致荒岩失落，但系雪衣未责怪姑苏还剑。系雪衣追查义父情不返之死真相，证据指向西煌佛界主事释至伽蓝，最终因法畏金刚临终之语而放下仇恨。

系雪衣因重情多次中鬼族之计，包括处理学弟左丘默（实为鬼族暗棋）事件，以及死寂女神假扮闻疏梅的事件。与公子笑纳从存有敌意到成为挚友，公子笑纳牺牲自己的双眼医治系雪衣，使其恢复光明并领悟“怆天若失”剑意，最终反杀八面鬼戎。

系雪衣最终以生命为代价从鬼族寻回西儒传脉之宝“泣麟藏颖”，传承守护之义；在子衿亭写下“护”字后，伤重去世，为剑族线故事落下帷幕。

玉树临风的儒门高士，过去是一笔春秋公认的后起之秀，人称“八采儒鹤”，曾参与掌门竞拔，后因故辞退，离开一笔春秋，天下远游。（月刊265）

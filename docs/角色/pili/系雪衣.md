# 繫雪衣 (系雪衣)
================================================================================

繫雪衣

西儒青年才俊，個性儒雅中帶點風趣，玉樹臨風，仙風道骨。本為庭三帖之後生晚輩、左丘默的學長，卻是當年一筆春秋公認的後起之秀，才情出眾，人稱「八采儒鶴」。當年因故辭退西儒掌門競拔而去，並離開一筆春秋，天下遠遊。

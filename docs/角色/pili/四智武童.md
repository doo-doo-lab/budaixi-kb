# 四智武童 (四智武童)
================================================================================

四智武童

在三余无梦生受到逆时计影响消失后出现的神秘孩童，踩着孔明车，念著喻事的童谣，天真无邪，外表看似约七八岁的孩童，眼神却流露着成熟与睿智，真实身份不言可喻。以佛家四智心品为名，延续三余与鷇音子的斗智竞争，一心杜绝圣魔元史之祸，不让其影响天道的自然运行。

# 誕宗遙 (诞宗遥)
================================================================================

誕宗遙

天佛原鄉師座，統轄三相修羅，因百妖路黑獄妖相前來，遂現身與之談判，表明佛鄉防微杜漸之立場，雙方暗中較勁，結果師座竟意外身亡。死前囑咐三相修羅前往無鏡有境，請出佛鄉客座奇人主持局勢。

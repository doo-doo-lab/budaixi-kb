# 诞宗遥 (诞宗遥)
================================================================================

诞宗遥

天佛原乡师座，统辖三相修罗，因百妖路黑狱妖相前来，遂现身与之谈判，表明佛乡防微杜渐之立场，双方暗中较劲，结果师座竟意外身亡。死前嘱咐三相修罗前往无镜有境，请出佛乡客座奇人主持局势。

# 占云巾

霹雳布袋戏中的人物占云巾，霹雳布袋戏中的人物。南域轩昂五玑之一的玄玑，现为风涛十二楼之代管主事。 头戴鹿冠包巾，身背黄布包道器，其人参悟天命，善卜卦，宛如仙风道骨的神人仙宿，与好友北冥风举有多年交情，素有风云之谊美名。 与琴狐更是多年深交，共同维护南域，不受外力所侵。

## 人物设定

名称：占云巾本名：占帻称号：参天鹿帻、霞峰啸侣（琴狐、占云巾、西窗月合称）、鹿狐双骄（琴狐、占云巾）人物图片1身份：风涛十二楼代管主事、轩昂五玑之玄玑诗号1：笑许云朋霞友，傲看石老梅幽。此生未卜学太周，龙去虎留，明日墟丘。 休休，占得几家风流？算春秋。诗号2：天龙作骑万灵从，独立飞来缥缈峰。怀抱芳馨兰一握，纵横宙合雾千重。眼中战国成争鹿，海内人才孰卧龙。抚剑长号归去也，千山风雨啸青锋。

亲人：香如昔（亲妹）、风云儿（外甥）占云巾同伙：攀玉趾、琴狐、明河影、上官争先（轩昂五玑）朋友：北冥风举、明河影、琴狐、小水仙、恐龙妹、龟忘年同窗：琴狐、西窗月、墨如鸦、江南春信、晏朝歌、不全鹰、鱼雁书、玉微瑕（进修三年）老师：香六牙恋情：西窗月（曾有一段未结果之情）部属：圆缺、败笔写生、枯笔惊泉其他：元守默、桐吟、还音师太、玄裳、凰觉、道锋天扇子、风月主人、刀僧还情、秦假仙饲养：芈麒麟（羊驼，赠予琴狐）仇敌：玉佛爷、鳇影、海宇之主、皇鳞

## 人物能力

功体梅魄转生之体◎介绍：占云巾与北冥风举风、云同修，一身云气功体，浩然飘渺，也因此存在属性火克的弱点。后历经死关，由西窗月以‘梅魄转生之术’，采卜居瑞雪之梅枝为骨，嵩雪水为血，梅瓣鹭羽为肉，皓朱双股为筋，为鹿巾再造肉身，并克服了先前“火克”的弱点。武学占云巾纳化虚空、云翩传鹿鸣、八纮惊赋鹿鸣声、骖驾六龙号岱宗、浩气冲开·谷神滋化·翩然鹄举任长风、吾道超然养胸云、弼世伊周、道咏鹿·号乾坤·一笑平生蕉鹿梦·极、乾坤难负磊落志、日月经天·天道之剑·极、青裾负五岳、一任烟尘古鹿行、白练一抹倾千里鹿狐合招：剑通天地·大道之行、大道谷神玄、蹈乾坤·划阴阳·六合无迹·八纮齐宇贯古今、道灵造·玄神功·名参四大至仰天术法云天六卦、随神往来·并精出入·返、藏形秘法机关阵法五玑之阵·“卦镇”武器咏鹿乾坤◎介绍：一口以黄布卦巾包裹的剑袋，内中所藏即为道家仙器“咏鹿乾坤”。其剑为江南春信之作，镡雕明鹿，七星棱节，与琴狐一战双剑皆断，后经由流形钢再造。包裹剑器的黄布卦巾，乃龟忘年所作，后用于补缺太昊天网。所有物玄玑云图、弥天之土、思亲灯、《拾异经》（西窗月所赠）、咏鹿乾坤（卦巾上绘有十二辟卦，代表十二个月阴阳消长，可推演二十四节气、七十二侯，中间是北斗七星，内书二十八星宿，外书四时，体现古人星象与自然法则）、龟忘年（“龟”指古人大事占卜所用，“忘年”指忘年之交，暗示神龟年资高深）

## 经历

占云巾自小钻研卜算之术，并至汤问梦泽求学，与琴狐、西窗月是同学，学成后回归南域。一天算出妹妹香如昔会遭逢情劫变疯，于是不让妹妹远出，不料却被妹妹误解，终究没有改变命运。香如昔离开后爱上楚郎并怀孕，后楚郎死亡导致她疯癫，占云巾为救她自愿接受朝君九拜等酷刑，牺牲尊严。此事导致占云巾与琴狐产生矛盾，关系一度破裂。后发现自己每用一次卜算，就会折损一名亲人的气运，于是发誓封卦。其后成为南域轩昂五玑之一。曾和琴狐一起击败了企图颠覆南域的皇鳞，却不知皇鳞附身侵占了好友北冥风举的身体。多年后，皇鳞势力再次兴风作浪，召唤火流星、夺取照夜玉狮。鹿巾则在明河影以身入局后与琴狐一战，伤疲之时被罪人岛趁机追杀，虽逃出生天，却不料被潜伏已久的圆缺一刀毙命，后被西窗月所复活。复活后和琴狐同仇敌忾对付皇鳞，在与皇鳞势力的战斗中，占云巾与琴狐联手对抗鳇影与海宇之主，占云巾施展梅魄转生等法术。布下五断绝蕴大阵，破例和风月主人卜卦，意外得知风云儿是妹妹之子，舅侄相认。入天窍修行后大战皇鳞，虽命中其死穴，自己和琴狐也受重伤。琴狐死后占云巾抱其尸身泛舟江上，最终伤重不治。

## 人物影响

占云巾的角色设计蕴含深厚的国学底蕴，其名号、造型与道具均考究地融入了传统文化典故。名号“参天鹿帻”中，“鹿帻”指鹿皮头巾，象征隐士与修真；虽名“云巾”，但造型参考了凤翅幞头而非明代云巾。其道具“咏鹿乾坤”卦巾上绘有代表阴阳消长与古人时间观的十二消息卦（又称十二辟卦），巾内中心为北斗七星，内圈书二十八星宿，外圈书四时，整体体现了古人对星象与自然的归纳法则。随身携带的“龟忘年”则化用“龟卜”与“忘年之交”的典故。这些精心设计共同强化了其“玄玑”身份之“玄”与世外高人的形象。

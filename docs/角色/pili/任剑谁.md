# 任剑谁

天剑峰上的异人，外表粗犷落拓，脾气古怪，周身缠着绕铁链，拖行着一巨大石壁，擅长修补兵刃。曾是千胜不败的顶尖剑客，却因多年前的一场落败，至此自我放逐，弃剑佩刀。

退场原因：霹雳神州II之苍玄泣 第41集（死于曌云裳的岁月轮）

武学列表中补充一项：撕心碎胆吼惊雷

武器外形特征：

虎魄剑：外形特征：犀利笔直的长剑，长度较一般宝剑为长，剑芒银光寒冽，剑器一挥便能发出虎形剑气，护手以虎纹为形，如虎魄剑魂般慑人。登场剧集：霹雳神州II之苍玄泣 第21集

任剑谁之刀：外形特征：朴实简单的一口曲刃勾刀，刀身狭长而尖端锋利，古铜色刀柄缠绕着棉绳，为任剑谁弃剑消沉时所用的武器。在任剑谁弃剑从刀后，封埋佩剑虎魄，改习刀法并以刀为器，刀式走劲刚猛，招式带有强烈的凄厉感，似泣诉着主人难以释怀的过往。

角色经历：

年少时曾经意气风发，挑战高手，连续胜利九百九十八场，剑法有进无退，有攻无守，拔剑有虎魄冲出，威力万钧。后经过苦战，险胜柳生剑影的师傅千败一剑，赢得第九百九十九场胜利。但是因为少年剑圣提前看出了战局，内心踌躇，遂挑战柳生剑影，却因被提前看清剑招，一招击败，又因被恰巧路过的绝凌笙讥讽而恼羞成怒、自暴自弃、弃剑佩刀、自号一败涂地任剑谁，久居天剑锋。

自己是练有铸铁手，能够用神奇的手法修补兵器，融化金属，在天剑锋替人修补兵器，但是会凭自己的观点随意改变求助者的兵器。好友卓东来被圣阎罗追杀时曾上天剑锋寻其保护。神鹤佐木和问天谴缺损兵器便是由他修补，因为其能通过看剑身相面，发觉问天谴有死劫临身，劝其退隐，但问天谴认为心存浩然，死而犹生，后果然为阻银鍠朱武，自爆战死。

后来因为绝凌笙被卫清风感化，向任剑谁道歉，二人遂化解前嫌。后绝凌笙战死异度魔界，自己亦被卫清风的坚韧感动，遂收其为徒，助其报绝凌笙之仇，并在关键时刻出手相救。但因卫清风的功体不适合任剑谁的武功，在经得卫清风同意后破坏其全身骨骼和经脉，将其送入不灭火坑重炼筋骨，后成为失路英雄再出，成为正道的一大助力。

识界乱世，好友卓东来被异虫控制疯狂攻击不二做，不敌被杀，任剑谁重拾佩剑愤然找不二做寻仇，却正巧遇上极封灵地神柱被破，自身跌落地底，意外发现成千上万婴尸，大为震怒，决心为查出真相，为天下除害。因为伏龙先生白忘机（素还真）的周旋，暂时放下对不二做的追杀，并帮助不二做铸剑救治夜愁雨。

时逢红楼剑阁开启，任剑谁被邀请参加红楼锋海盛会，因为红楼剑阁的标记与死去婴儿身上的伤印相似，于是深入剑阁，伺机探查真相。不料柳生剑影与不二做俱在剑阁，三人勉强和平相处。因为长有胡渣有加分，得到红楼四公主霏婴垂青，与其同进同出，游玩嬉戏，但并未与其发生关系。被剑阁下毒，几乎濒死，被绯羽怨姬所救，更加坚信剑阁有内幕。后来暗中与东宫神玺、西门寒照、霏婴联手，查出剑阁的惊人秘密，在步穹青峦发现无数名剑尸身以及出口通向千万婴尸的地底。任剑谁勃然大怒，发誓要为无辜讨回公道，在蒙眼与暂时失明的柳生剑影决斗，完成心愿之后，孤身讨伐剑阁。

任剑谁会见曌云裳，相互嘲讽之后，生死对决，极招对决，任剑谁使出专门为柳生剑影创造的“今生唯恨一剑败”击飞曌云裳的佩剑，将其重创。关键时刻，曌云裳拔出红楼剑阁镇阁神器岁月轮，任剑谁难挡神器之力，怒喝“雪不得，众灵沉冤；恨只能，血诉青天”。剑碎首断，含恨而终。

角色诗词补充：

遗言（胜曌云裳，但却被曌云裳持岁月轮所杀时言）：雪不得，众灵沉冤；恨只能，血诉青天。

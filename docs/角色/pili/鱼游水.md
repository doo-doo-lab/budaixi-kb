# 魚游水 (鱼游水)
================================================================================

魚游水

儒門三監之一，有著讀書人的傲氣，但略顯迂腐，只求獨善其身，對外界莫不關心。魚游水雖自視甚高，卻無相對的實力，以致除惡不成，反慘死於變裔天邪手中。

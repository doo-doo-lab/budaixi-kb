# 朱尊

道武王谷界天塔至高三修之一，仙风道骨，威仪不凡，享有南天第一道之名。在掌门仙逝之后，得到剑子仙迹与多数成员支持，继任掌门，然而在继任大典上，却遭同为界天塔的同志列御子叛变，遭受重创，昏迷近百日方醒。

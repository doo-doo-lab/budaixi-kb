# 剑通慧

霹雳布袋戏虚拟人物剑通慧，霹雳布袋戏虚拟人物。高深精纯的白发佛修者，因自责顾守培孕太极之气的混沌玄母无端气化，导致天竞鏖锋破局，而自愿担起拉扯佛骨天锁的任务。在剑通慧即将圆寂时，巧逢地之厉的灵魂，双方达成交易，让劫尘借剑通慧躯体重生，继续维持天峰巨链之封印；然而，却也布下千年后的宿命之局…。

## 角色设定

诗号：罪恶无门，唯人自伤，一剑通慧，舍己渡人。（剑通慧诗号）退场：霹雳战元史之动机风云第2章（灵识于无尽天峰告知剑布衣一切过往后消弭）

## 人际关系

- **组织门派**: 天佛原乡朋友：传灯无上师同修：尔善多、苇江渡、凡七夜（天王四护）上司：天之佛其他：劫尘(灵魂借体)、剑布衣(转世)

## 角色能力

剑通慧武器：劫尘◎外形特征：平日劫尘将无剑身的剑柄收于腰际间，出剑时以指化出剑身，剑身以淡紫色为主并带出金纹，剑格嵌上如狮身人面像的饰品，剑尾连接三条金属垂饰，配色与地之厉相似。看似轻盈灵动，但剑式刚烈并带有千钧之力。◎登场剧集：霹雳战元史之天竞鏖锋 第21集

## 角色经历

剑通慧多年前天之厉被封印，致使地之厉遭同僚牺牲，劫尘魂体将散之际遇上即将圆寂的剑通慧，双方缔下约定，劫尘得以借剑通慧躯体重生，剑通慧魂体则转世成为剑布衣。在佛骨天锁崩毁后，劫尘得以重见天日。论实力，地之厉仅次于天之厉，因借由剑通慧修者之身份复活，所以成为厉族内能进入天佛原乡的内应。熟料这一切都是剑通慧为了太极之气回归早设下的局，与剑布衣死战时地之厉方知自己早已被剑通慧算计，遭碧血长风贯穿心窝，魂归西天。

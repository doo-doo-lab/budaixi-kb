# 佛劍明王 (佛剑明王)
================================================================================

佛劍明王

佛劍分說融合罪佛赦無心的元罪業力，所形成的「不動明王」狀態，慈悲心不動，無物可改變撼動！功力修為催化至巔峰狀態，佛牒、殺生罪在握，即便九龍戰魂之力也難以匹敵，然而佛劍本身卻也得承受元罪業力反噬，明王狀態無法持久。

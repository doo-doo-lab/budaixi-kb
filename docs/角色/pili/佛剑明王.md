# 佛剑明王 (佛剑明王)
================================================================================

佛剑明王

佛剑分说融合罪佛赦无心的元罪业力，所形成的“不动明王”状态，慈悲心不动，无物可改变撼动！功力修为催化至巅峰状态，佛牒、杀生罪在握，即便九龙战魂之力也难以匹敌，然而佛剑本身却也得承受元罪业力反噬，明王状态无法持久。

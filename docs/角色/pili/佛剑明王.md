# 佛剑明王

佛剑分说融合罪佛赦无心的元罪业力，所形成的“不动明王”状态，慈悲心不动，无物可改变撼动！功力修为催化至巅峰状态，佛牒、杀生罪在握，即便九龙战魂之力也难以匹敌，然而佛剑本身却也得承受元罪业力反噬，明王状态无法持久。

在明王状态下，佛剑分说融合罪佛赦无心的元罪业力，将佛牒与杀生罪双器并运。佛牒、杀生罪在握，即便九龙战魂之力也难以匹敌。佛剑明王武学：不动剑印·【灭天业、斩尘罪、碎地狱、映莲华】、地藏菩萨灭定业真言、悲愿狱空修渡劫·剑忏如来证菩提

在《霹雳魔封》第57、58集中，佛剑明王曾与驭龙主对决，并施展招式“明王裁罚·净业空狱唯一剑”。在《霹雳魔封》第58章决战中，面对九龙战魂合力的生死危机，佛剑分说首次展现「不动明王」形态。该状态下以佛牒、杀生罪在握，即便九龙战魂之力也难以匹敌。战后因元罪业力反噬陷入副作用状态，明王状态无法持久。此外，《霹雳魔封》第59话标题即为“佛剑明王”。该话中，佛剑分说与风僧白云剑也重回佛门，佛剑分说与剑子仙迹、疏楼龙宿再续三教顶峰之会。

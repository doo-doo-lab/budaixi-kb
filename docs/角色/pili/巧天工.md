# 巧天工 (巧天工)
================================================================================

巧天工

巧天工，人稱芙蓉鑄客，愜意居於青埂山。總自稱本芙女，性情刁蠻古怪、伶牙俐齒，最喜閱耽美書籍。為四大名手之一，鑄劍功力堪稱一流，更對劍的特性瞭若指掌，頭上的髮釵拔下後可化為單鋒劍。亂世狂刀與沽命師都曾請求其鑄造單鋒劍，巧天工表面看似刁難狂刀，實則有深意寄託其中，是一介以補天裂鑄術聞名的女高手。

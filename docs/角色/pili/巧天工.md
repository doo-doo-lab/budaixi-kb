# 巧天工

巧天工，人称芙蓉铸客，惬意居于青埂山。总自称本芙女，性情刁蛮古怪、伶牙俐齿，最喜阅耽美书籍。为四大名手之一，铸剑功力堪称一流，更对剑的特性了若指掌，头上的发钗拔下后可化为单锋剑。乱世狂刀与沽命师都曾请求其铸造单锋剑，巧天工表面看似刁难狂刀，实则有深意寄托其中，是一介以补天裂铸术闻名的女高手。

## 来自百度百科的补充

**人物经历**
雨霖铃身份时期
巧天工本名雨霖铃，人称东炼炼青冥，因其兄纵横子贪图荒诞之始的宝物而与夸幻之父打赌，纵横子输了之后，夸幻之父要求娶其妹雨霖铃为妻。雨霖铃将纵横子由夸幻之父身上所取得的十二枚幻甲中的十枚加上两种材料做成了帝弓十二虹，剩余两枚一枚做成单锋剑虎尾春冰。夸幻之父前来迎娶之后雨霖铃提出考虑一段时间，然后请其朋友生命练习生以虎尾春冰杀了夸幻之父，并取得其头上三支角，将其做成格天三锋送给生命练习生。之后以芙蓉铸客巧天工的身份隐居于芙蓉铺。

巧天工身份时期
乱世狂刀为探究刀剑之理请巧天工打造单锋剑，恰遇沽命师也来打造单锋剑。巧天工为看二人相爱相杀，要求二人决斗，胜者可以得到单锋剑。二人不分上下，乱世狂刀主动弃权。巧天工以狂刀用刀之手为要求为沽命师打造单锋剑"三淬要锋"，沽命师以"三淬要锋"斩断狂刀双手经脉，惹得巧天工大怒。巧天工知狂刀真心求单锋剑，便是以其先弃刀方能求剑的原因断其用刀之手的经脉。之后巧天工以绣花重新锻炼狂刀双手，期间为其打造单锋剑、重铸狮头宝刀。巧天工得知夸幻之父卷土重来，遇到解锋镝受夸幻之父所托擒拿巧天工，巧天工败后随解锋镝前往荒诞之始。

**发明创造**
黑白入道：为纵横子打造的黑色剑。
练洗之命·格天三锋：由夸幻之父头上的精灵三角打造的枪头，与枪杆组成【练洗之命】，生命练习生的得力兵器。后为红尘雪保存。
虎尾春冰：配合巧单锋剑法，由夸幻之父的一片幻甲打造而成的单锋剑，巧天工自用武器。
帝弓十二虹：由夸幻之父的十二片幻甲打造的十二支箭簇，每只箭都有不同属性的能力。
三淬要锋：为沽命师打造的单锋剑，以冰火血三淬之法打造。
新·狮头宝刀：以补天裂铸术配合夸幻之父的幻甲为乱世狂刀量身订做的神器。
终极冥帝：一口融合刀、单锋、枪、弓特质却又能单独拆使的神兵，另有冥帝之精可强化兵器。屠戮之恶·冥帝单锋，先由应笑我持有，后为暗影所得；嗜血之罪·冥帝之枪，辗转邪天子、玉梁皇、暗影、寒武纪、红尘雪之手，后回到巧天工手中；背叛之孽·冥帝刀弓由劫红颜持有；伪冥帝之精由应笑我赠予玉梁皇，而真正的怨恨之毒·冥帝之精则一直由巧天工保管。
太虚鬼藏：受控制时替圆公子打造的神鞭，可配合漂浮手的特性。
神思三器：以祌天爻帝的三颗心梦翡翠、玄孔雀、神玉玺打造的三件神兵。

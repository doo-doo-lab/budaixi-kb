# 大悲文殊 (大悲文殊)

大悲文殊

萬聖巖修行者，雪缽五僧排行第二，莊嚴脫俗，為淨化苦境魔化妖氛而出，與異度魔界多方斡旋。參寥靜院一役，由天人文殊牽制赦生童子，大悲文殊與定性聯手對上螣邪郎，結果赦生意外轉變攻勢殺向定性，大悲反應不及，也命喪螣邪郎邪薙之下。

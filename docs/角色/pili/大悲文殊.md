# 大悲文殊

万圣岩修行者，雪钵五僧排行第二，庄严脱俗，为净化苦境魔化妖氛而出，与异度魔界多方斡旋。参寥静院一役，由天人文殊牵制赦生童子，大悲文殊与定性联手对上螣邪郎，结果赦生意外转变攻势杀向定性，大悲反应不及，也命丧螣邪郎邪薙之下。

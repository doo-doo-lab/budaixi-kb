# 鷇音子

霹雳布袋戏虚拟人物鷇音子，霹雳布袋戏虚拟人物。

诗号：玄歌浪蹈，幻中道真，太游方外睨红尘。

当初三余无梦生上时间城借取非关时间，途中历经殊离山魔考一时失魂出神，被圣魔元史点中魂体，向时间树缔命借时而出的素还真第三化身，视三余为竞逐对手。

擅炼玄丹，偏向道家色彩，虽表明立场中立，以烽火天榜将武林各大势力排入榜中，却因此掀起一场未知的武林风暴。

鷇音子本是圣魔元史欲操控天下所化出的棋子，看似正邪难辩的行事准则，让三余无梦生难以全心信任。

但鷇音子本心却始终清明，清楚自己的道路，静默布局，等待适当的时机。

纵使处事手段强硬，但不惜以自身性命换取天下靖平的祈愿，正是如同素还真一路走来的济世信念。

波旬诛，元史灭，当尘世暗夜崩解，一魂虽就此消散天地间，但眼见苍生希望再现，鷇音子亦是欣然接受，不悔尘世一遭，如斯付出，也在武林中人心中留下无法抹灭的一页。

## 角色背景

（摘自 霹雳月刊 第213期 封面人物：鷇音子）源起鷇音子官方桌布当初三余无梦生为替意琦行借非关时间，而再上时间城，因经历殊离山魔考，而一时失魂出神，圣魔元史伺机而作，点中素还真的第三魂体，向时间树缔命借时，而出现的第三化身。

偏道家色彩，炼玄丹是角色个人特色。

居处在“罗浮山裂缺峰，九鼎回环太极台”行事立场中立，颇为高深莫测。

自言与三余无梦生“就如同果实内的两粒种子，在果实裂分时，或受鸟叼啄，或受风吹散，落到不同生长环境，若土沃水甜，自然繁盛，若土焦水短，当是贫瘠，但不管是哪一种状态，本质终究是同一种果实。”名号鷇，乃鸟子欲出卵中而鸣，谓之鷇音也，言亦带壳曰鷇。

最原始纯真的初音，没有偏执，没有是非，最近乎大道的声音。

人物以道家炼丹术士形象设计，古代炼丹术相信炼丹服丹可以养生，汲取老子道德经为思想根本，“抱一”一词出自《道德经》，有“与真理合一”的意思。

目的会刊213期圣魔元史已有自我意识，它屡屡向阅读者显示的内容，有其作乱武林的用意，为了达到这一目标，三余无梦生（或说是素还真）是最大的阻碍，于是圣魔元史这次的目标瞄准素还真，以素制素。

烽火天榜，其中的排名不过是一种引发斗争的手段，将之视为实力高下的准则，就落入了鷇音子的圈套，天榜一出，各方焦点齐聚鷇音子，他就能从中取得拨弄之机，他保持中立，表面上来者不拒，但却让正邪之间互斗更狠。

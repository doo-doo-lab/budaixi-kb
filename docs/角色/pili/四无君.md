# 四无君

================================================================================

霹雳布袋戏虚拟人物四无君，霹雳布袋戏虚拟人物，冥界天岳之首席军师，初登场于霹雳兵燹第37集。他有着过人的智慧与军事手腕，自信狂傲，善于攻心、谋略与谈判；个性深沉却富枭雄之姿，手段强烈极端，可有效地运用身边所有的人力与资源并为达目的而不择手段，喜以华丽的方式登场，为素还真遇过最棘手的敌人之一。他被称为“平风造雨四无君”。四无君最终在霹雳异数之万里征途第31集中，被乐烽烟与一页书击败，退场时留下“巧智终归庸俗，雄谋只余虚话”与“黄泉之下，平风造雨四无君恭候汝等，届时再开新局”的遗言。

## 经历
四无君在忘尘崖附近遭遇牟尼上师、一页书、乐烽烟等人，双方发生冲突。战斗中，四无君化出红色杀体，但仍被乐烽烟重创，打回蓝色本体后身亡。其临终遗言为：“巧智终归庸俗，雄谋只余虚话。四无君此败虽难心服口服，然败即是败，黄泉之下，平风造雨四无君恭候汝等，届时再开新局……”

## 角色漫谈

平风造雨四无君（文|编剧：三弦）这一次要写的角色是冥界天岳的军师，照往例，先想名字，平风造雨四无君，这么好的名字跟诗号，会是谁想的？

当然是我~~~~~~的老板想的。

没错，就是董事长取的名字，响亮又动听。

个人还是满喜欢的啦。

选偶头的过程当中，不免也有一点插曲。

当初我主写刀王跟四无君，一开始先要选的可是刀王的偶头，董事长着令各大雕刻师，极尽创意之能事，又画图又送照片，让大家尽展雕工。

于是又过了几天。

四无君四无君可以说是我进入编剧室后接下的第一个主角，之前虽然接过几个重角，但这样重要的角色，这还是第一次。

这一天，我进入编剧室刚满四个月，之前写过戏份最重的角色是白马纵横跟火龙麒。

怀着忐忑的心，我开始做人物设定。

我的基本雏形大家很难想像，那就是~希特勒。

没错，就是希特勒，纳粹党的首领，二次大战的元凶，杀害无数犹太人的独裁者，来人啊，将四爷抓去抡……呃……当然不是这个意思。

所谓以希特勒为原形，指的是纯粹的种族主义，超凡的个人魅力，指的也是冥界天岳的种族肃清主张，以及属下对四爷的绝对信任与绝无二心。

这一点是我在剧中最大的坚持，冥界天岳不能出现叛徒，更不能出现对军师的怀疑，为了完成任务，即使牺牲生命也在所不惜。

要让部下获得如此的信任跟死忠，除了个人魅力以及能力让人信服外，还需要一个大义名分作为标的，冥界肃清计划正提供一个伟大宏远的目标。

规划完了大概，接下来就是那根……羽毛。

那根每当四爷出场前，必定飘呀飘的，飘到地上来再轰的一声，爆出个四爷的羽毛。

羽毛的意义是个信物，一个传递军师讯息的信物，当初设计这样的代表物，是为了借物转化，让四爷的形象更立体显明。

至于选用羽毛，则是取杜甫诗：“三分割据纡筹策，万古云霄一羽毛”之意。

一来以诸葛亮作为借比，二来强调他功绩卓绝。

至此，四爷的初步人设就算完成了。

在这个过程中，我犯下新手驾驶的大错，在短短两集之中，一口气让四爷念了超过十次的诗号。

据说当时的摄影棚，无我不解……无我之利……那些无我之声此起彼落，何其壮观啊。

接下来，便是剧情的发展了，四爷连环出招，抢得有利先机，为当时冥界天岳开出一片大好光明。

而剧情最重要的转折点也在此处了。

天岳之主，牟尼上师的生死。

在当时编剧组内有一番激烈的讨论，一派的想法是想留下牟尼上师，因为这样更能凸显四爷“军师”的职责，另一种想法则认为该让牟尼身亡，让四无君在高峰时一挫锐气，也平衡一下局势。

接下来的剧情发展，大家都很清楚了。

四无君天岳之主身亡之后，我开始重新定位四爷，他虽然是实质上的领导者，但我更希望能强调他军师这个身份，所以在天岳之中，所有人对四爷一律尊称为军师，军师要有明确的地位，若是强抢领头之位，就归属在枭雄或阴谋家之流了。

正因为强调智者军师的位置，所以我尽量避免四无君以武力解决问题，每一次动武，必然辅以计谋设计，云渡山会一页书，旨在拖延，云尘盦牟尼殒命，旨在救援，破天河冰川，是为除去青阳子海路出击。

包含后来的几场战斗，四爷不见得都以格杀对手为目标，而是将利益放的更高更远。

当然，这样的后遗症，就是他杀体出现的次数大减了，遗憾啊……四无君最明显的个人特质，就是自信、高傲，他的自信是一种绝对，俯瞰全局，泰然自若，成竹在胸，谈笑破敌。

他的高傲是不低首、不屈身，甚至从不用敬语，目空一切，但是对天岳之主却是绝对的服从及尊重。

沉着则是一个合格军师必备的条件，在与素还真过招的几次接触，四无君即使落入颓势，依然保持着沉稳与冷静，谋求扭转的契机。

除此之外，他注重过程，注重结果，不容许有任何变数影响他的计画，所以计算外的东西必须排除。

当明月心取得七月笙前往天外南海。

四无君认为计画可能有变，即刻下令要天之翼将明月心格杀。

四爷对手下的态度一向极端，勇于弃子，却不肯失势，所以四爷泰半的时间都是处于优势，却也因此，势微时无子可救。

四爷化身百朝臣一段，大概是四爷这一生中，最为特殊的经验了。

百朝臣是个无用之人，可以说是天岳最为窝囊的角色，但是在四爷眼里，就算是窝囊的人，也有另类的用法。

命世风流战败后，四无君利用百朝臣无用的身份，在武林中游走。

散播有利于他的消息，最后还成功劫走素还真，累的鬼隐被步怀真秒爆，真个黑狗偷吃，白狗当灾。

当然一定会有人问，以四爷的个性，去伪装百朝臣不会太过委屈了吗？

委屈是大概有一点，不过照四爷的性格看来，只要能成功达到目的，就算委屈点又何妨？

真要摆高姿态，让计画更加难以遂行，更不是四爷所乐见的。

因为百朝臣太过无用，所以武林中人根本也不会将目光放在他的身上，就算露出破绽，几乎也不会被人注意，这招妙手，可不是人人想的到的。

提到四爷，当然也要提他的朋友，云涛梦笔跟王隐了，当初四爷在医院挂号的时候，巧遇了同样罹患静脉曲张的云涛梦笔，两人一见如故，终成好友。

友情这两个字，对于看来冷漠的四爷来讲，是个不简单的议题呢！

大概可以相信，四爷这一生中就只有这两个朋友。

云涛梦笔与他接触甚多，而王隐则少到只有一两幕戏而已。

但四爷肯因为王隐而不对银狐动手，王隐在四爷墓前那一番感叹，可以看出两人深厚的交情。

四爷大部分的时间都在算计武林大事，对于朋友之间的互动，实在是少的可怜了。

好！

提些关于四爷的题外话。

话说当初接下四爷后，我一直没看过四爷的造型，一来是我对造型的兴趣一向不大，只要别太夸张离谱，大概都能接受。

二来当初我是新人，又没资历又没实力，对于造型又懂得少，自己知道没那个本事去挑剔。

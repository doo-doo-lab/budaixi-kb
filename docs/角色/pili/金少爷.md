# 金少爷（霹雳布袋戏中的角色）

================================================================================

金少爷，本名金少一，是霹雳布袋戏中的角色，为一代奇人叶小钗与萧竹盈的独子。从小因故与双亲分离，被血手魔魁满天红夫妇收养并改名金少爷，后因满天红惹来杀身之祸，在外流浪时被欧阳世家吸收成为杀手。初出现时以“天下第一刀”的俐落身手使万教先觉目瞪口呆。在普九年的辅佐下成立无敌太阳盟（又称南霸天），该组织迅速发展，一度成为能与霹雳王朝、北方齐天塔分庭抗礼的势力，并使欧阳世家由盛转衰。在《刀说异数》剧集中，对金少爷的人物性格进行了微调，增加了渴望亲情的特质。最后在崎路人的苦心教诲之下才显示出其善良本性、浪子回头。回归正道后，金少爷为父血战天蝶盟，参与时空圣战。但因爱人八面狼姬亡于天祸妖狐之手，为复仇进入魔域接受六先知深造，最终魂断不归路，死于天祸妖狐的杀招之下。中文名金少爷别 名金少一、少爷刀配 音黄文择性 别男登场作品霹雳眼霹雳至尊登场作品霹雳孔雀令霹雳剑魂霹雳异数霹雳劫霹雳英雄战纪之刀说异数身 份天下第一刀、无敌太阳盟盟主根据地南霸天本尊雕偶师徐炳垣出场集数101集

## 角色经历

为一代奇人叶小钗的独子，本名为金少一，风雨坪上叶小钗离开萧竹盈母子後，被萧竹盈带往祖父血手魔魁满天红身边（两人都不知晓他们之间的血缘关系），请满天红夫妇代为抚养，为避免一剑万生的追杀，萧竹盈以武器金羽毛之首字为其姓，因其早产一个月，再加上双亲少一人，所以取名金少一；後满天红夫妇见其可怜，心生同情便为他改名金少爷，并将之抚养长大；由於满天红曾经为了医治妻子而盗取南霸天十三连锁会的宝物「九天神罩」而无意间得知半月郎君密谋造反的事情，因而惹来杀身之祸，在无情的追杀行动之中，满天红之妻身亡，金少爷也与满天红失散，在外流浪的金少爷便被欧阳世家吸收成为其中之一员。金少爷天资聪颖，但个性顽劣，离经叛道。初出场乃是欧阳上致用毒品所控制的杀手，为让素还真、谈无欲之赌局破局，乃自称少爷刀。个性桀赦不驯，曾违逆欧阳世家的命令，造成毒品来源中断，痛不欲生，毒瘾发作之下侵犯了被剑藏玄砍去双手的风雨残生欧阳翎，致使欧阳翎产下一对龙凤胎金小开(儿)与花非花(女)。金少爷之後被火阳真君毁去面容，整张脸烧得面目全非，万念俱恢的金少爷前往灵隐寺找渡缘和尚，想了结自己的性命，渡缘即是满天红，但金少爷并不知情，而渡缘亦不知道金少爷是自己的亲孙，但仍然非常疼爱他。为使金少爷恢复容貌，渡缘前往南霸天偷取九天神罩，却因不敌半月郎君而无功而返，半月郎君要金少爷杀死血手魔魁满天红来换取九天神罩，金少爷即使已被金羽兰告知抚养了自己二十多年的渡缘即是满天红(当时金羽兰也不知道满天红是金少爷的祖父)，为了恢复容貌仍然狠心杀害了满天红。另外由於其天命所归，金少爷在七色灾主普九年的辅佐下，夺取南霸天，消灭半月郎君的势力，成立无敌太阳盟，以盟主的身份统领太阳盟打败欧阳上智大军，与雨台齐天塔的童颜未老人平分天下；但年轻气盛的他个性傲慢，不愿事事听从他人，也逐渐对普九年感到不满，因此决定出走太阳盟，自己到外面闯天下；普九年无奈之下请求半驼废挫一挫他的锐气而被半驼废狠狠羞辱了一番，为了报仇决定拜一钱一命为师，却被强迫在赎罪岩接受三万鞭的殴打；在赎罪岩接受鞭打期间被流星君萧三瑞认出是强暴欧阳翎的人，但他始终不承认欧阳翎所生的是自己的孩子，由于流星君苦苦纠缠，竟默许一钱一命杀害流星君（此时已经知道流星君是自己外祖父）。金少爷艺成之后为报鞭打之仇，杀师夺剑并急忙去找半驼废报仇，由于半驼废已死于黑白郎君之手，在半驼废的坟墓上撒尿泄愤；大逆不道三番两次挑战其父叶小钗，不断给他找麻烦；羞辱母亲萧竹盈，从不给她好脸色看，直至萧竹盈死亡都未与她相认；对风采铃出言不逊，后来崎路人为阻止他与叶小钗的争斗，把他关在水晶瓶中，并交由秦假仙保管。金少爷假意改过向善，骗得秦假仙信任脱出水晶瓶，并找崎路人报仇却被崎路人所败，替崎路人拖车期间渐渐被教化引导出其善性，回归正道，并为父血战天蝶盟，参与时空圣战，为正道、为父亲尽一分心力。但苍天造化弄人，由於爱人八面狼姬亡命於天祸妖狐之手，为了替爱人复仇，在紫锦囊的帮助之下，进入魔域接受六先知深造，却因六先知先後丧生两名，武艺未学成，又无如意尺之助，终究魂断不归路，死於天祸妖狐的杀招之下。过了很久很久以後，才在刑天师的帮助下，化身神童长河南星，与叶小钗重叙天伦之乐。

**金少爺**為台灣霹靂布袋戲中的人物。霹靂眼第10集出場，霹靂劫第15集退場。為刀狂劍痴葉小釵和玉頸金羽蕭竹盈獨子；自小被父母拋棄的遭遇，造成其狂妄叛逆、爭強好勝的個性，表面上無惡不作、忤逆父母師長，內心其實十分渴望親情；可惜就在其改過向善之後，不久卻魂歸離恨天，令人不勝感慨。

===生平紀要===
為一代劍聖葉小釵唯一的兒子，本名為**金少一**，和蕭竹盈母子在風雨坪被葉小釵拋棄後，遂被帶往祖父血手魔魁滿天紅身邊，請滿天紅夫婦代為撫養，為避免一劍萬生的追殺，蕭竹盈以武器金羽毛之首字為其姓，因其早產一個月，再加上雙親少一人，所以取名**金少一**；後滿天紅夫婦見其可憐，心生同情便為他改名**金少爺**，並將之撫養長大。

金少爺天資聰穎，但個性頑劣，離經叛道。初出場乃是歐陽上致用銷魂菸所控制的殺手，為讓素還真、談無慾之賭局破局，乃自稱少爺刀。個性桀赦不馴，曾違逆歐陽世家的命令，造成毒品來源中斷，痛不欲生，毒癮發作之下侵犯重傷昏迷的風雲殘生歐陽翎，而有子金小開、花非花。之後被火陽真君毀去面容，以其祖父之首級換來九天神罩使面容恢復。

由於其天命所歸，在七色災主普九年的輔佐下成為無敵太陽盟的盟主，統領南霸天打敗歐陽上智大軍，與童顏未老人平分天下；禁不起好勝心的驅使，出走太陽盟挑戰巧龍半駝廢；曾拜一錢一命為師，藝成竟殺師奪劍；大逆不道挑戰其父葉小釵，羞辱母親蕭竹盈，調戲風采鈴，在半駝廢的墳墓上撒尿，後羅網乾坤崎路人為阻止他與葉小釵的爭鬥，把他關在水晶瓶中，並交由秦假仙保管。

金少爺假意改過向善，騙得秦假仙信任脫出水晶瓶，並找崎路人報仇卻被崎路人所敗，替崎路人拖車期間漸漸被教化引導出其善性，回歸正道，並為父血戰天蝶盟，參與時空聖戰，為正道、為父親盡一分心力。但蒼天造化弄人，由於愛人八面狼姬亡命於天禍妖狐之手，為了替愛人復仇，在紫錦囊的幫助之下，進入魔域接受六先知深造，卻因六先知先後喪生兩名，武藝尚未學成，又無絕世兵器如意尺之助，終究魂斷不歸路，死於天禍妖狐的殺招之下。

過了很久很久以後，才在刑天師的幫助下，化身神童長河南星，與葉小釵重敘天倫之樂。

==生平三恨==

金少爺死後，鬼王棺為了要打擊正道，引葉小釵與天禍妖狐決鬥，因此向葉小釵顯現他收集來的金少爺魂魄，金少爺在葉小釵面前道出生平生三恨：

- **第一恨**: 他的父母從小把他拋棄。

- **第二恨**: 學藝不精、命喪仇人之手，不能為愛人八面狼姬報仇。

- **第三恨**: 連死都不能死在親人的懷抱裡。

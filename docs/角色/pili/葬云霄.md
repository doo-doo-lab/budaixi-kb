# 葬云霄

================================================================================

霹雳布袋戏虚拟人物葬云霄是《霹雳布袋戏》系列中的虚拟人物，由黄文择配音，首次登场于《霹雳侠影之轰动武林》。作为无始暗界封印一族成员，自称妖界空间穿行者，曾协助分割荒初禁赦的异空间，并隐居在莫名海奇妙岛。葬云霄性格爽朗但极不信任人类，因与癫不乱换心未果导致妖形虚化。参与上届凋亡禁决时结识痕千古，穿梭于红莲口等妖界空间以推动三王竞斗。其命运转折始于与欹月寒的恋情，被欹月寒（傅月影）下毒后遭步香尘挖心而亡。临终前葬云霄用尽最后气力欲见化名傅月影的欹月寒，最终殒命。

**中文名**：葬云霄

**配音**：黄文择

**性别**：男

**登场作品**：霹靂驚鴻之刀劍春秋霹靂俠影之轟動武林

**本尊雕偶师**：刘氏

## 人物关系

姓名关系介绍欹月寒恋人西疆毒首，统领整个西疆部落释阎摩朋友来自百妖路，称号为亡夜，无始暗界封印一族的鬼才步香尘对手妖界妖凰

葬雲霄

霹靂布袋戲虛擬人物隱居在莫名海奇妙島的神秘大妖，久遠以前與癲不亂換心，卻因對方失信沒再回來，導致失去妖心太久而妖形虛化，必須躲在百妖路。個性爽朗直接，卻極不信任人類，與西疆毒首欹月寒曾有過一段情緣。後因步香塵引誘挑撥，與欹月寒產生誤會，被後者改形易貌之化身傅月影施以劇毒，又遭步香塵挖心而死。可以說是一個悲劇性的人物。

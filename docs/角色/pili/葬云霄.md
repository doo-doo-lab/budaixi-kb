# 葬云霄

================================================================================

霹雳布袋戏虚拟人物葬云霄是《霹雳布袋戏》系列中的虚拟人物，由黄文择配音，首次登场于《霹雳侠影之轰动武林》。作为无始暗界封印一族成员，自称妖界空间穿行者，曾协助分割荒初禁赦的异空间，并隐居在莫名海奇妙岛。葬云霄性格爽朗但极不信任人类，因与癫不乱换心未果导致妖形虚化。参与上届凋亡禁决时结识痕千古，穿梭于红莲口等妖界空间以推动三王竞斗。其命运转折始于与欹月寒的恋情，被欹月寒（傅月影）下毒后遭步香尘挖心而亡。临终前葬云霄用尽最后气力欲见化名傅月影的欹月寒，最终殒命。

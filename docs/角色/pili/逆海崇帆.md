# 逆海崇帆

霹雳布袋戏虚拟组织霹雳布袋戏反派组织。

久远之前，“欲”之一字自原始崇拜脱胎变化，经魔佛波旬吸收佛典变造，而成为宗教组织“欲界第六天”，但在同时，另一个信仰也自其中对应而生，以“潜欲”二字为掩饰，吸收其他宗教的教义，暗中壮大自己，其宗旨为创造一个让人信赖与寄望的信仰，在绝望中找到希望，在逆境中突破难关，修炼过程有如在大海航行，在茫茫大海中找到希望的方向，故名为“逆海崇帆”。

逆海崇帆乃由鸠神练、弁袭君、祸风行三人发起创立，以“圣航者．天谕”及“圣裁者．地擘”为尊，下设“生老病死”四大印，擅长以神迹来吸引信众加入。

殊不知，天谕以扫除信众绝望来凝聚信仰的背后真相，真正的目标是欲将天疆、苦境、地狱，再度回归原初三境一通的世界，届时人神鬼妖，再无分际…中文名逆海崇帆来 自霹雳布袋戏基地/辖区潜欲之门、崇辉圣岸等专 长让信仰者在绝望中通过神迹的显示

# 冲田鹰司

================================================================================

霹雳布袋戏剧中登场人物冲田鹰司是霹雳布袋戏系列中登场的东瀛武士，初登场于《霹雳开疆纪》第28集，退场于《霹雳神州》第13集。作为神鹤佐木嫡传弟子，他天资卓绝，三月精通狂龙八斩法，以武士双刀为兵，曾拒神风营官职。因师尊叛国涉足中原武林，为阻止神鹤佐木危害东瀛，违背师徒情谊决斗，期间与中原侠女荻神官结下情愫，最终为掩护师尊及荻神官断后，力战京极鬼彦而亡。其短暂生涯贯穿忠诚与理想的激烈碰撞，既展现对武学巅峰的追求，亦深陷情感与责任的挣扎。人物轨迹凸显武士道精神与人性矛盾，以生命践行民族大义，悲剧结局折射出侠义抉择的哲学思辨。

## 经历
冲田鹰司为神鹤佐木的嫡传弟子，英俊挺拔的青年，对刀法有过人的资质，在东瀛时和北野真一同接受神鹤佐木的教导，仅以三个月便精通狂龙八斩法的精要，冲田鹰司本为源武藏的神风营大武卫人选，因顾及和北野真的师兄弟情谊而拒绝官职。

对师尊神鹤佐木极为尊敬，以超越神鹤佐木为毕生志向，在得知神鹤佐木叛离东瀛后，不惜以牺牲性命为代价力阻神鹤佐木对付东瀛之人。

在《霹雳神州》剧中，神鹤佐木与问天谴遇险时，冲田鹰司亦曾及时现身救援并对战京极鬼彦。

冲田鹰司在中原时，偶然间救了仙灵地界的荻神官，两人虽打打闹闹，但也结为好友、互生好感，冲田鹰司对中原和东瀛之间的战事毫无兴趣，只希望阻止神鹤佐木杀害东瀛之人，向荻神官询问过神鹤佐木在中原的过往，在情感间挣扎，被荻神官多次呵斥教训，但冲田鹰司仍是坚守原则。

后来，冲田鹰司虽闯入天狩浮阁搭救神鹤佐木，身处怪异空间时，冲田鹰司与神鹤佐木心意相通，以相同招式双刀合并，加乘威力，开出生路一条，但仍不惜以决斗阻止神鹤佐木的行动，甚至想以死让师尊回心转意。

最后为替神鹤佐木和荻神官等人断后，冲田鹰司独对京极鬼彦，不敌身亡。

## 相关作品

冲田鹰司登场于《霹雳开疆纪》和《霹雳神州》。在《霹雳神州》中，冲田鹰司于第5集身处怪异空间寻声急冲，与神鹤佐木配合开出生路；于第12集及时救援神鹤佐木和问天谴，面对京极鬼彦。

# 愁落暗尘

================================================================================

霹雳布袋戏虚拟人物愁落暗尘是《霹雳布袋戏》系列中的虚拟角色，本名鬼梁飞卿，登场于2005年6月17日播出的《霹雳兵燹之刀戟戡魔录》。作为鬼梁兵府大公子兼幽燕征夫顶尖杀手，精通蝉之翼飞斩法，武器包括蝉之翼、无蝉刀，与羽人非獍结为生死之交。自幼被养父鬼梁天下培养为杀手，却渴望与妻子退隐江湖。因异度魔界利用类似蝉之翼的凶器嫁祸，陷入亲友猜忌，后通过击杀暗薄之刃洗刷冤屈。在鬼梁家族变故中得知身世真相，多次为救妻儿重返杀手生涯，最终在与弃天帝的决战中殉道身亡。角色贯穿《刀戟戡魔录》至《天罪》等剧集，以“金风未动蝉先觉”为代表性台词。

## 角色经历

愁落暗尘，原名鬼梁飞卿，是春霖境界鬼梁兵府的大公子。

自幼被父亲鬼梁天下送至杀手组织幽燕征夫训练，为幽燕征夫杀手榜上第一人。

使用武器为蝉之翼，乃数百年前异度魔界与道境玄宗大战时遗落苦境之物。

自创蝉之翼飞斩法，已达无声之境，出手从不落空。

在笑蓬莱初登场的愁落暗尘，早已看淡权势名利，正守护着挚爱倾君怜，静静等待退隐时机。

义弟夜啼鸟为北隅第一杀手蝴蝶君所杀的消息传来，愁落暗尘只是感叹杀手命运无常，悲哀义弟之死，却并未向受伤潜藏在笑蓬莱的蝴蝶君复仇。

异度魔界入侵武林，为逼出当年的萍山练峨眉，以暗薄之刃威胁宫紫玄，虽然金八珍全力戒备，但宫紫玄仍在众人护卫当中，死的不明不白。

由于凶器太过类似于蝉之翼，让金八珍、天险刀藏等人对愁落暗尘产生怀疑，金八珍虽然明白愁落暗尘不可能与魔界勾结，但真相必须查出，于是给了愁落暗尘一个期限，在这段期间，金八珍的女儿女婿金战战、惠比寿却接连惨死，让愁落暗尘更加百口莫辩，加上不定期的诡秘失踪，连倾君怜也怀疑起愁落暗尘，是否藏有她所不知的秘密。

合并图册但事情终于有水落石出的一天，金八珍让羽人非獍以七彩云霓为饵，诱出了暗薄之刃，愁落暗尘抓住一瞬之机，不仅帮了羽人非獍一阵，更以蝉之翼格杀了魔界的杀手，也洗刷了自己的冤屈，在这追查的过程当中，愁落暗尘也因此认识了一名挚友——羽人非獍。

二人告别之时，愁落暗尘首次奏起颈间蝉笛为好友送行，向来沉默内敛的羽人非獍也难得露出笑容，表达对即将退隐的挚友美好祝愿。

之后魔界为了对付愁落暗尘，用重金聘请幽燕征夫的金绣杀手影之无，以连环逼杀的手段重创愁落暗尘，并掳走了倾君怜做为人质。

不顾自己伤体，愁落暗尘带伤赴约，中途得到孤独缺打通血脉之助，以过人的胆识与绝妙的判断，打败幽燕征夫金绣杀手影之无，成功救回倾君怜。

二人前往琉璃仙境求医过程中，再次被幽燕征夫众杀手围杀，幸得天险刀藏解围，随后受药师慕少艾指引前往水晶湖疗伤，倾君怜则在外围黄叶林等候时再次被抓。

伤愈的愁落暗尘走出水晶湖遍寻不得佳人身影，忽然接到幽燕征夫大东家贾命公的手书，原来倾君怜被贾命公所擒。

为救挚爱，愁落暗尘再次踏进幽燕征夫以自己苦心所创《蝉之翼飞斩法秘籍》换取倾君怜自由。

之后让倾君怜前往唯一愿舍等待，自己则前往伏龙壁一见自己另一个雇主——伪装成黑衣人的鬼梁天下。

本以为事情可以就此完结，愁落暗尘也决定完成最后的任务，切断过去的羁绊，与倾君怜安然退隐，但最后的指令，竟是要他对付羽人非獍。

恩、情、义、理，愁落暗尘陷入了困境。

跟羽人非獍相处的日子虽短，但却相知相惜，但不完成任务，终究不能与倾君怜一同退隐，这种复杂的心情，让愁落暗尘难以抉择。

这一战，要是如何了局？

这场无奈之战终究展开，互有保留的两人，假作拼命，却仍留手，愁落暗尘虽败，却得到了他最为渴求的自由。

无奈这种日子，终究不能长久。

羽人非獍在鬼梁兵府少府主的婚宴上突然发狂，杀死鬼梁飞宇后逃逸。

杀弟之仇不能不报，宿命的对决，第二次来临，面对疯狂的羽人，这一次，两人真的不用再留手了，雪地中的对决，错身而过的羽人，更让愁落暗尘体会人生百味。

仇已过，便是恩义，愁落暗尘暗中阻拦鬼梁家众人对羽人非獍的逼杀，帮助了重伤的羽人非獍，而后回到了倾君怜身边。

刀戟堪魔结束之后，愁怜二人的儿子鬼梁埋名也终于平安诞生了。

就在一家三口幸福度日之时，鬼梁天下被翳流之主北辰元凰所杀的消息传来，兵府上下殷切盼望大公子回来领导鬼梁家为故主报仇，此时的愁落暗尘再次陷入了两难。

为探愁落暗尘口风，素还真拜托羽人非獍前往唯一愿舍。

重逢的故人，终于放下过去的恩仇，再次共饮。

羽人非獍为帮助好人燕归人与愁落暗尘，暗布杀局埋伏北辰元凰，中途愁落暗尘与业火红莲出手相助。

终于下定决心复仇的愁落暗尘找回自己以前的战友上官寻命，与凌沧水、燕归人共同围杀北辰元凰。

之后愁落暗尘为收回北辰元凰身上神器不幸中毒，凌沧水多方周旋为愁落暗尘取得解药。

伤愈后的愁落暗尘回到唯一愿舍与亲人共同生活。

其后鬼梁天下阴谋暴露，愁落暗尘也终于得知了自己的身世。

亲生父亲凌沧水被鬼梁天下以五残之招重伤，愁落暗尘为救凌沧水前往凝静雪峰寻找拥有造化之钥的奈落之夜宵，无意间卷入宵与武林公法庭的争斗而延误了救治凌沧水的时间，法门卫无私更因此事判定愁落暗尘有罪，杀害愁落暗尘的舅父雨中砚与其弟凌威并掳走其妻倾君怜与弟妹言倾城作为人质威逼愁落暗尘投罪。

之后愁落暗尘与上官寻命前往无私岩救人，愁落暗尘得贾命公相助救出弟妹言倾城，而挚友上官寻命与爱妻倾君怜则惨死于无私岩。

为复仇，愁落暗尘与幽燕征夫第一斗狗八方横野对决终于重回幽燕征夫成为第一杀手，并获得无蝉刀与无蝉翼。

之后与八方横野合作灭尽无私岩法门弟子，将卫无私斩杀于爱妻墓前。

后与八方横野，尹秋君围攻黑发剑者。

又接受夺取燕归人的孤问枪任务，在与燕归人对决中得胜并带走孤问枪。

之后为还燕归人的情与羽人非獍一起打败昭穆尊并默许羽人非獍带走孤问。

贾命公以愁落暗尘作为交易与天荒不老城城主识能龙交换不老神泉。

恢复年轻面容与巅峰功力的贾命公以刀剑合流之招重创愁落暗尘，危急之时，羽人非獍闯入战局将愁落暗尘救走，并寻找戤戮狂狶治好愁落暗尘之伤。

之后羽愁二人与越小枫共同前往落叶深处等待复仇时机。

获得血断机的情报之后，愁落暗尘以一己之力战胜贾命公并与羽人一同前往倾君怜墓前拜祭。

之后前往春霖境界探望弟妹言倾城探问亲生子的下落。

后从秦假仙处得知埋名已经被紫宫世家收养并改名紫宫昊辰。

愁落暗尘随即暗中前往紫宫世家探视亲儿，为让儿子远离江湖风波平安长大，愁落暗尘最终决定不与昊辰相认，将他留在紫宫世家。

随后与羽人非獍受靛羽风莲之托前往血蛛毒林欲带回被咒术控制的燕归人，对决之中因减速阵法之故羽愁二人纷纷负伤不得已被风莲带离。

二次进入毒林，羽人与风莲负责牵制燕归人，愁落暗尘则与六弦之首苍共同进入毒林内部破阵。

二人配合之下顺利破除阵法，燕归人意识清醒，羽燕愁三人回到天波浩渺养伤。

伤好之后愁落暗尘回到唯一愿舍退隐，长生殿最终武器无名寻仇而至将愁落打成重伤。

幸被及时赶来的殷末箫所救，送往生死边界得到金不换治愈，之后回到唯一愿舍。

神州大地崩毁，愁落暗尘与羽人非獍一同踏上云渡山与众人力抗弃天帝。

愁落暗尘于此役战死。

## 角色编剧漫谈

“金风未动蝉先觉，暗送无常死不知。”“风起了，蝉鸣了，你听见了吗？”杀人前一长串的预告诗，奠定了独特的地位，一身斜披的披风，来去无踪的蝉之翼，冷峻的面孔，只注视着一条倩影，倾君怜。

这就是幽燕征夫顶尖杀手，愁落暗尘。

提到愁落暗尘，首先要提的就是他独门兵器——蝉之翼，蝉之翼是一种很独特的暗器，来去无踪，杀人无形，他最大的特色就是在飞行途中会发出类似蝉鸣的声响，但蝉之翼练至最高境界，对手反而听不见蝉翼鸣叫的声音，当蝉翼经过，人头已落，使人防不胜防。

长居在笑蓬莱，对于权势、名利、金钱，愁落暗尘看的非常之淡，与其他角色不同处，愁落暗尘打从出场开始，仿佛便是经历了无数风雨沧桑，正等待着退隐的时机，但何时是退隐的时机，除了他自己，即便连他至爱的倾君怜也不清楚，因为他身上，背负着许多未还清的人情、恩情。

由于凶器太过类似于蝉之翼，让金八珍对愁落暗尘产生怀疑，金八珍虽然明白愁落暗尘不可能与魔界勾结，但真相必须查出，于是给了愁落暗尘一个期限，在这段期间，金战战、惠比寿却接连惨死，让愁落暗尘更加百口莫辩，加上不定期的诡秘失踪，连倾君怜也怀疑起愁落暗尘，是否藏有她所不知的秘密。

但事情终于有水落石出的一天，金八珍让羽人非獍以七彩云霓为饵，诱出了暗薄之刃，愁落暗尘抓住一瞬之机，不仅帮了羽人非獍一阵，更以蝉之翼格杀了魔界的杀手，也洗刷了自己的冤屈，在这追查的过程当中，愁落暗尘也因此认识了一名挚友——羽人非獍。

为了对付愁落暗尘，魔界用重金聘请幽燕征夫的金绣杀手影之无，以连环逼杀的手段重创了愁落暗尘，并掳走了倾君怜做为人质。

不顾自己伤体，愁落暗尘带伤赴约，中途得到孤独缺打通血脉之助，以过人的胆识与绝妙的判断，打败影之无，成功救回倾君怜。

本以为事情就此完结，愁落暗尘也决定完成最后的任务，切断过去的羁绊，与倾君怜安然退隐，但最后的指令，竟是要他对付羽人非獍。

恩、情、义、理，愁落暗尘陷入了困境。

这一战，要是如何了局？

无奈这种日子，终究不能长久。

一切就在鬼梁飞宇身亡后变调，原来愁落暗尘竟是鬼梁飞宇的兄长，杀弟之仇不能不报，宿命的对决，第二次来临，面对疯狂的羽人，这一次，两人真的不用再留手了，雪地中的对决，错身而过的羽人，更让愁落暗尘体会人生百味。

仇已过，便是恩义，愁落暗尘帮助了重伤的羽人非獍，回到了倾君怜身边。

此刻的他，无牵无挂，一身自在，江湖风波，似已远离，如梦一场。

但，世间事是否真能如他所愿。

愁落暗尘是个重情、重义的好汉，却始终夹在人情与恩情之间两难，对父亲鬼梁天下不能认同，又割舍不下兄弟之情，与羽人非獍肝胆相照，却两次兵刃相对，性格上，他刚毅果断，而际遇上，又让他左右为难。

愁落暗尘武林途是残酷的，一旦踏入，难得回头，杀人人杀的世界，何处是一片净土？

愁落暗尘心中的净土，便是倾君怜，退隐的日子虽然平淡，却幸福，但自己却有太多羁绊，总是难以完全脱身。

这样的愁落暗尘，始终是矛盾的，无所求的人，要求的是最简单却最难以达成的目标。

只要鬼梁天下继续在武林有所作为，他就并非是无牵无挂的一个人，阴谋家鬼梁天下的秘密昭然若揭，愁落暗尘与鬼梁天下之间的关系，又将如何发展？

这一切正牵动着日后愁落暗尘的际遇，即使努力逃避，责任却始终紧跟随他，身为江湖人的无奈，在愁落暗尘身上，尽显无疑。

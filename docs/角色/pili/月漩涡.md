# 月漩涡

================================================================================

霹雳布袋戏中的角色月漩涡是霹雳布袋戏系列中的虚拟角色，初登场于《霹雳谜城》第21集。月漩涡是荒城结义排行第三的成员，曾是收银取命的冷峻杀手，擅使枪铳与剑术，拥有殊异血统，双眼会在发怒时转为艳红血眼。他曾蒙剑师萧振岳之恩久驻荒城，后投靠异度魔界担任月下杀手，与结义兄弟箫中剑（空谷残声）等人产生诸多恩怨纠葛。月漩涡最终为报仇参加了对抗弃天帝的行动。中文名月漩涡别 名夜泷配 音黄文择性 别男生 日2006.09.01（初登场）登场作品霹雳谜城、霹雳神州Ⅲ之天罪根据地荒城萧府、火焰魔城角色编剧罗陵本尊雕偶师潮州君皇出场集数224集

## 角色经历

夜泷月漩涡，半人半鬼的月下杀手，右脸上有巨大伤痕，双眼在发怒时会转为鲜红，擅长枪铳与剑术，喜隐身于月色之下。与忘残年长驻于早已荒凉的荒城中，因曾受城主萧振岳恩惠，为报恩而住下，其间，因与忘残年、箫中剑(当时还叫萧无人)意气相投，而成为结义兄弟，排行老三。月漩涡双城之战时，因注意到墨渊水莲可能是化身的迹象，进而找上门，但无果而返。法门重新审理二十年前三月浩劫惨案，但疑似参与者的飘舟神隐却遇害身亡，在殷末箫大伤脑筋之际，月漩涡现身告知部分真相。而双城之战终结后不久，三月浩劫主谋者六祸苍龙再现，月漩涡与忘残年为报仇而至，彼此三招了结恩仇。不久后，因为毘非笑自认是三月浩劫主谋，月漩涡愤而将其杀死，但由于月漩涡的天生异眼特殊，在袭灭天来策划下，忘残年死于六祸禁式，而月漩涡却为金不换刻意误导方向，找上六祸苍龙，致使惨败重伤，后为袭灭天来带回异度魔界，转交给补剑缺，而得知其为鬼族里的血眼狼族混血儿，与狼主补剑缺同出一脉。在异度魔界，补剑缺帮助月漩涡开发其鬼族血统的能力。魔界前任战神银锽朱武化身朱闻苍日出游之事成为魔界高层的〝机密〞后，在伏婴师的设计下，朱闻苍日与空谷残声为朱闻挽月带回朝露之城，为使不愿恢复真身的朱闻苍日回归，月漩涡被交予朱皇宝血，并将之注入空谷残声体内，造成其陷入魔化。后伏婴师因对月漩涡与补剑缺的关系感到好奇，而以引出赭杉军与墨尘音为由，派其扰乱并杀害玄宗人马，虽成功引出墨尘音，却因实力不足而败阵下来，为补剑缺所救，但未回魔界，即被箫中剑半路拦截，因补剑缺刻意失利，而被带回荒城。最后，在箫中剑决战朱武而死于天渺峰后退隐。弃天帝降世之际，因二次巨大灾变，月漩涡登上云渡山探问原因，却碰到恨长风带回补剑缺尸身，得知其亡于弃天帝。补剑缺因知晓弃天帝秘密而被处死。而因拥有血狼眼，而被苍选为玄罡剑奇阵成员，但因不能静心，在眼见紫宫太一身亡下，怒气攻心地杀向弃天帝，却与紫宫太一一同亡于其手。

**月漩渦**全名**夜瀧月漩渦**為霹靂布袋戲角色，登場於霹靂謎城第21集，後於北越天海上因替補劍缺報仇心切而貿然出手，結果反被棄天帝所殺。(霹靂神州III之天罪第8集)

==生平==

半人半鬼的月下殺手，右臉上有巨大傷痕，雙眼在發怒時會轉為鮮紅，擅長槍銃與劍術，喜隱身於月色之下。與忘殘年長駐於早已荒涼的荒城中，因曾受城主劍師蕭振嶽恩惠，為報恩而住下，其間，因與忘殘年、簫中劍(當時還叫**蕭無人**)意氣相投，而成為結義兄弟，排行老三。

雙城之戰（即天荒不老城與詭齡長生殿的戰事。）時，因注意到墨淵水蓮可能是化身的跡象，進而找上門，但無果而返。法門重新審理二十年前**三月浩劫**慘案，但疑似參與者的飄舟神隱卻遇害身亡（其實是桑道涼，真正的飄舟神隱在二十年前已因自己的同歸於盡之招而死去。），在殷末簫大傷腦筋之際，**月漩渦**現身告知部分真相。

而**雙城之戰**終結後不久，**三月浩劫**主謀者六禍蒼龍再現，月漩渦與忘殘年為報仇而至，彼此三招了結恩仇。不久後，因月漩渦的天生異眼特殊，在襲滅天來策劃下，忘殘年死於**六禍禁式**，而月漩渦卻為金不換刻意誤導方向，找上六禍蒼龍，致使慘敗重傷，後為襲滅天來帶回異度魔界，轉交給補劍缺，而得知其為鬼族裡的**血眼狼族**混血兒，與狼主補劍缺同出一脈。<ref>疑似為補劍缺親子，吞佛童子與補劍缺都曾在〝無意〞中透露。</ref>

**魔界前任戰神**銀鍠朱武化身朱聞蒼日出遊之事成為魔界高層的〝機密〞後，在伏嬰師的設計下，朱聞蒼日與空谷殘聲為朱聞挽月帶回**朝露之城**，為使不願恢復真身的朱聞蒼日回歸，月漩渦被交予**朱皇寶血**<ref>即為朱武之血。</ref>，並將之注入空谷殘聲體內，造成其陷入魔化。

後伏嬰師因對月漩渦與補劍缺的關係感到好奇(？)，而以引出**奇峰道眉**與**撥弦道曲**<ref>奇峰道眉為赭杉軍別稱，而撥弦道曲為墨塵音。</ref>為由，派其擾亂並殺害玄宗人馬，雖成功引出墨塵音，卻因實力不足而敗陣下來，為補劍缺所救，但未回魔界，即被簫中劍半路攔截，因補劍缺刻意失利，而被帶回荒城。最後，在簫中劍決戰朱武而死於天渺峰後退隱。

棄天帝降世之際，因二次巨大災變，**月漩渦**登上雲渡山探問原因，卻碰到恨長風帶回補劍缺屍身，得知其亡於棄天帝。而因擁有**血狼眼**<ref>魔界鬼族中的**血眼狼族**(**補劍缺**和**銀鍠朱武**也有)才有的特異之眼，近似天忌的獸眼，可以看見瞬間細微的動作，而修為高的所有者甚至可以直接看到靈魂。</ref>，而被蒼選為**玄罡劍奇陣**成員，但因不能靜心，在眼見紫宮太一身亡下，怒氣攻心地殺向棄天帝，卻反亡於其手。

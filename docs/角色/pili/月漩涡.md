# 月漩涡

================================================================================

霹雳布袋戏中的角色月漩涡是霹雳布袋戏系列中的虚拟角色，初登场于《霹雳谜城》第21集。月漩涡是荒城结义排行第三的成员，曾是收银取命的冷峻杀手，擅使枪铳与剑术，拥有殊异血统，双眼会在发怒时转为艳红血眼。他曾蒙剑师萧振岳之恩久驻荒城，后投靠异度魔界担任月下杀手，与结义兄弟箫中剑（空谷残声）等人产生诸多恩怨纠葛。月漩涡最终为报仇参加了对抗弃天帝的行动。

## 角色经历
夜泷月漩涡，半人半鬼的月下杀手，右脸上有巨大伤痕，双眼在发怒时会转为鲜红，擅长枪铳与剑术，喜隐身于月色之下。

与忘残年长驻于早已荒凉的荒城中，因曾受城主萧振岳恩惠，为报恩而住下，其间，因与忘残年、箫中剑(当时还叫萧无人)意气相投，而成为结义兄弟，排行老三。

月漩涡双城之战时，因注意到墨渊水莲可能是化身的迹象，进而找上门，但无果而返。

法门重新审理二十年前三月浩劫惨案，但疑似参与者的飘舟神隐却遇害身亡，在殷末箫大伤脑筋之际，月漩涡现身告知部分真相。

而双城之战终结后不久，三月浩劫主谋者六祸苍龙再现，月漩涡与忘残年为报仇而至，彼此三招了结恩仇。

不久后，因为毘非笑自认是三月浩劫主谋，月漩涡愤而将其杀死，但由于月漩涡的天生异眼特殊，在袭灭天来策划下，忘残年死于六祸禁式，而月漩涡却为金不换刻意误导方向，找上六祸苍龙，致使惨败重伤，后为袭灭天来带回异度魔界，转交给补剑缺，而得知其为鬼族里的血眼狼族混血儿，与狼主补剑缺同出一脉。

在异度魔界，补剑缺帮助月漩涡开发其鬼族血统的能力。

魔界前任战神银锽朱武化身朱闻苍日出游之事成为魔界高层的〝机密〞后，在伏婴师的设计下，朱闻苍日与空谷残声为朱闻挽月带回朝露之城，为使不愿恢复真身的朱闻苍日回归，月漩涡被交予朱皇宝血，并将之注入空谷残声体内，造成其陷入魔化。

后伏婴师因对月漩涡与补剑缺的关系感到好奇，而以引出赭杉军与墨尘音为由，派其扰乱并杀害玄宗人马，虽成功引出墨尘音，却因实力不足而败阵下来，为补剑缺所救，但未回魔界，即被箫中剑半路拦截，因补剑缺刻意失利，而被带回荒城。

最后，在箫中剑决战朱武而死于天渺峰后退隐。

弃天帝降世之际，因二次巨大灾变，月漩涡登上云渡山探问原因，却碰到恨长风带回补剑缺尸身，得知其亡于弃天帝。

补剑缺因知晓弃天帝秘密而被处死。

而因拥有血狼眼，而被苍选为玄罡剑奇阵成员，但因不能静心，在眼见紫宫太一身亡下，怒气攻心地杀向弃天帝，却与紫宫太一一同亡于其手。

半人半鬼的月下杀手，右脸上有巨大伤痕，双眼在发怒时会转为鲜红，擅长枪铳与剑术，喜隐身于月色之下。与忘残年长驻于早已荒凉的荒城中，因曾受城主剑师萧振岳恩惠，为报恩而住下，其间，因与忘残年、箫中剑(当时还叫**萧无人**)意气相投，而成为结义兄弟，排行老三。

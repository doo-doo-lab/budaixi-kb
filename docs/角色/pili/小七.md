# 小七 (小七)
================================================================================

小七

意琦行身中仙門禁招「還童返照」，回到七歲時的小天驕狀態，自稱「小七」，機智善良，富有俠義之心，與澡雪、秋水組成小七修，行走武林，行俠仗義。雖是初生之犢，仍不改行俠仗義之心，協助秋水等人對抗造孽的陰謀。

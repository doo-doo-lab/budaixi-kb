# 极道先生

================================================================================

**本名**：尚风悦，是《霹雳布袋戏》系列中的虚拟角色

**性别**：男

**初登场**：于《霹雳震寰宇之刀龙传说》第33集，由黄文择等多位

**配音**：演员演绎。其

**身份**：为啸龙居主人及四魌界上天界悦神圣族的御圣主，因不愿参与王族争斗而逃至苦境，后拜师学得鬼之铸术，建立啸龙居并结识御天五龙之首醉饮黄龙。极道先生性格风雅，对居所洁净度要求苛刻，曾以天外之石、稜晶花提点救治漠刀绝尘与啸日猋，并与死国战神阿修罗联手铸造神兵苍月银狼。在对抗死国势力期间多次介入关键战役，先后经历重伤救治、退隐啸龙居及多次

## 角色经历
诗意天城有两大王族——悦神圣族和御天龙族，历代上天界的王者从这两族派出代表来角逐，优胜者可以成为上天界的领导者，并且得到上天界创世以来的王者神力和号世神剑。悦神圣族派出的代表是御圣主——极道先生，而极道先生不愿参与争斗而出逃到苦境，御天五龙因为追杀降临苦境的前任佛狱之王邪天御武而到苦境。后来御圣主结识了羽天休伊（剧中并未提及，但“休伊”之名存在于官方设定本。直到霹雳天命之仙魔鏖锋Ⅱ斩魔录第22章，天下第一神铸聂寒才提及休伊全名），并拜其为师学得鬼之铸术，化名极道先生，建立啸龙居。醉饮黄龙携天外之石误入啸龙居，由此与其结识。

## 角色关系

# 御神风（《神州传说之上阕》人物角色）

================================================================================

御神风是独笔轩《神州传说之上阕》中的一号男主角，登场于第2集。

性别男，称号天涯浪子、三教高手、中原巨擘，姿容王者气势、文者气质、武者气魄，服饰以蓝白为主。

前世修罗界之王阿修罗，妻子魔姬千寻，女儿相念，徒弟乐逍遥，朋友任云洛、极道先生、任道远、林丹枫、玄杨，居住在半峰雪。

武学剑风不留情、苍龙吼、风扫万里、苍龙破天、苍龙泣、神风凝杀·剑者无情、剑鸣泣血，兵器苍龙剑。

**俠邪御神風**，為台灣霹靂布袋戲的正派角色，嘗於佛愆鬼如來千罪血祭時救下罪惡之都中存有善心的號天窮，然而鬼如來修成眾人景仰的佛首，號天窮因此走上極端，步入惡道。御神風於是召集靖滄浪、淨無幻、擊楫中流、無惑度迷參與聖戰，並請好友蘭翟夫婦以幻金石打造成魔絕天棺，封印號天窮於其內；並隱瞞帝如來曾為鬼如來事實，原諒其斬殺好友玉橫雪之過。然而御神風在聖戰之後遭魔氣滋擾，在被魔染以前自裁靈肉，留下一身骨氣而亡。後被天閻魔城（反派）復活，但未經改造，協助靖滄浪行走江湖對抗反派。

另個身分為**御風樓的老闆爺**。實力高強，足以和未持**滌罪犀角**的號天窮匹敵。最初出場為**霹靂兵燹之聖魔戰印第七集**，**正式出場為霹靂兵燹之聖魔戰印第二十三集**，於霹靂兵燹之聖魔戰印第三十三集為鬼如來所殺。

死前把一點正氣寄在至邪犀角之上，欲以邪養正，遏止犀角之威，並阻止他人修補滌罪犀角，但最終被齊子然以無為而治心法破解。

== 人物個性 ==
幽默風趣，嘲弄揶揄間一派從容瀟灑，快人快事，甚至帶有痞氣。然而行事堅定不容阻擋，在好友靖滄浪口中「凡事首衝陣前」的他也非衝動行事一輩，必是帶有把握而敢從容赴戰。

堅持正道，在罪惡之都中一度欲引導號天窮向善，也願為帝如來隱瞞佛界的不堪記憶；名號中一「邪」字，邪於其行事善於機智應變且莫測。

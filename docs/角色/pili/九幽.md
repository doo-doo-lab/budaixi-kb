# 九幽

为叶口月人新任女领导者，出自黑雾森林，拥有邪帝真传及象征邪帝的指环，是邪帝一脉的正宗传人，武功高强，个性骄矜、倨傲、阴毒，作风果断理智，有睥睨天下的女王风范，统帅叶口月人四部执首，乘驾玄空岛、叶口幽舻浩浩荡荡境压苦境…。

**人物经历**

傲刀缳莺，天外南海傲刀城的小公主，受着三个哥哥的宠爱与保护，个性温和又执着，在一次意外中受傲刀城第一武训白城舆救助而倾心于他，但落花有意，流水无情，因而展开一段曲折离奇、恩怨情仇的故事。

天外南海发生了战乱，傲刀城几度江山易主，傲刀缳莺在阴错阳差间成了敌人的俘虏。黑珠犽挟持傲刀缳莺，欲威逼傲刀青麟集齐九曜芙蓉石，以探知九曜之门的秘密，并在傲刀缳莺毁容期间言语挑唆，间接导致傲刀缳莺心性大变，经历一系列变故后成为邪帝传人——九幽。

九幽凭借邪帝的绝学与信物成为叶口月人新任领袖，以完成邪帝遗愿，统一天地人三界为目标，统帅叶口月人四部执首，乘驾玄空岛、叶口幽舻浩浩荡荡境压苦境。

后来，傲笑红尘血洗玄空岛，九幽势力消散泰半。九幽恐惧红尘禁招，四处求援却毫无所获，无奈之下找邱霍蛉叶为其洗骨增强功体。可惜天不从人愿，洗骨虽然成功，但因为功力增强过剧，九幽细胞急速老化，变成了另一番模样。

因洗骨大法导致容貌衰老的九幽，虽是功体大增，青春年华却已流逝，更丧失了境压苦境的野心，极欲恢复原貌。她化名姜媻嬷嬷行走江湖，得知西佛国佛子法力无边，可以化腐朽为神奇，便乔装改扮混入西佛国鎏法天宫。但她的图谋和真实身份很快就被梵刹伽蓝看穿，小活佛点悟开释后，九幽方才重新正视权势蒙蔽的本心。

可惜好景不长，身怀邪帝绝学的九幽成为了邪之子的目标，在邱霍蛉叶的出卖下，九幽被嗜血者发现。九幽与邪之子决战前将撰写的破解邪帝绝学的秘籍交予佛子，希望有益于正道，说明她已有拼死除邪的决心，真正看破前尘，悔悟过去种种。

决战中，邪之子虽然强悍，但九幽凭借洗骨而得的深厚根基配合邪帝绝学，不落下风。然而邪之子利用从邱霍蛉叶口中得知的九幽功体不能持久的弱点，拖延时间，渐渐压下九幽的攻势，并最终突袭九幽锁骨弱点，将九幽逼下悬崖，如愿得到了邪帝秘籍。九幽从此生死不明，一生起起伏伏的她，曾受到万千宠爱，曾屹立在权力的高点，终究只能在懊悔与悲痛中退场。

# 九幽 (九幽)
================================================================================

九幽

为叶口月人新任女领导者，出自黑雾森林，拥有邪帝真传及象征邪帝的指环，是邪帝一脉的正宗传人，武功高强，个性骄矜、倨傲、阴毒，作风果断理智，有睥睨天下的女王风范，统帅叶口月人四部执首，乘驾玄空岛、叶口幽舻浩浩荡荡境压苦境…。

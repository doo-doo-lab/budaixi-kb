# 九幽 (九幽)
================================================================================

九幽

為葉口月人新任女領導者，出自黑霧森林，擁有邪帝真傳及象徵邪帝的指環，是邪帝一脈的正宗傳人，武功高強，個性驕矜、倨傲、陰毒，作風果斷理智，有睥睨天下的女王風範，統帥葉口月人四部執首，乘駕玄空島、葉口幽艫浩浩蕩蕩境壓苦境…。

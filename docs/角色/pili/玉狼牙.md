# 玉狼牙 (玉狼牙)
================================================================================

玉狼牙

守在雕神古魄的古武族分支领导，个性严厉冷峻、好强争胜不服输，以干戚战魔为信仰，贯彻族人的武学训练，不容一丝松懈。其惯用武器为九节鞭，实力与荡十决旗鼓相当。在叶小钗获战魔像认可后，玉狼牙也率众服膺太武麾下。

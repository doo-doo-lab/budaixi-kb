# 玉狼牙 (玉狼牙)
================================================================================

玉狼牙

守在雕神古魄的古武族分支領導，個性嚴厲冷峻、好強爭勝不服輸，以干戚戰魔為信仰，貫徹族人的武學訓練，不容一絲鬆懈。其慣用武器為九節鞭，實力與蕩十決旗鼓相當。在葉小釵獲戰魔像認可後，玉狼牙也率眾服膺太武麾下。

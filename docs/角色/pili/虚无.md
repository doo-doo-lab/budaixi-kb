# 虚无（汉语词语）

================================================================================

虚无（拼音：xū wú）是汉语哲学概念，原指道家对"道"的本体描述，《庄子·刻意》称"虚无无为，天地之平"，《汉书》载道家"以虚无为本"。

佛学将其解释为"一切事物都没有自性"。

其内涵包含三重维度：本体论层面指道体包容万物的特性；

修养论层面主张清静无欲，如《素问》提出"恬惔虚无，真气从之"；

认识论层面含荒诞无稽或空无所指之意，王符《潜夫论》称其为"乱道之根"。

宋冬在艺术创作中通过镜子探讨空无的临界状态，认为镜像承载着"可视而不可触及"的虚实辩证。

该概念自先秦道家发端，《上林赋》曾延伸其空间维度含义。

近代衍生出历史虚无主义思潮，表现为对历史人物和事件的否定性叙事。

在文学领域，何景明以"缥缈凌虚无"呈现其意境表达。

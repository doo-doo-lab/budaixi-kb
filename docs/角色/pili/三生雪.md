# 三生雪 (三生雪)
================================================================================

三生雪

六世花王的守花三御之一，手持長刀的花凋族戰將，能開啟空間幻境，自黃泉道梅川乘舟而來。金樹族後人，為了恩情誓死追隨六世花王，效忠花凋族。似乎與亡故的九千宵有所關聯。

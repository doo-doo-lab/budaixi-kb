# 收万劫

================================================================================

霹雳布袋戏虚拟人物收万劫，霹雳布袋戏虚拟人物。天邪八部众中的“阿修罗王”，同时也是道皇圣无殛的关门弟子“星宿一奇”，身负正宗道门玄功、以及厄祸邪力，性格冷酷阴柔，酷爱血红之色，浑身上下充满艳红的邪杀之气。与青阳子双双现身道武王谷，一举夺走擘古镜封印的八歧龙首，并崩毁界天塔地脉，震惊在场众人。中文名收万劫别 名阿修罗王、八部之艳、夜魅之魁、星宿一奇、冬月宵配 音黄文择性 别男登场作品霹雳天命之仙魔鏖锋Ⅱ斩魔录登场作品霹雳天命之战祸邪神霹雳天命之战祸邪神Ⅱ破邪传霹雳天越生 日2017年10月20日（初登场）本尊雕偶师潮州君皇人物编剧东山出场集数36集

## 人物设计

摘录自《霹雳会月刊第268期》封面人物——阿修罗王 · 收万劫名称设计阿修罗，即是战火之代名词，前更有死国战神，威名赫赫，收万劫号为阿修罗王，想必是战王之王，因而最初的设计，阿修罗王·收万劫是个斗神，性好战，每遇对手，即张开固有结界“修罗斗场”，强制对手单挑，当看见收万劫的偶头时，妖魅的长耳，邪敛的双眼，亦予人睥睨一切，不可一世之感，及至整体造型完备后，见其妖华外貌，宛若阿修罗众之女，再于收幕一听御天者之点评 ·“八部之艳”，顿时有了绮丽的别想，尤其配合片头片画中，阿修罗王一甩柔顺发丝的片段，于是顺改设定，让阿修罗王的行为处事，不那么极端嗜杀。剧情设计关于撰写收万劫初登场时，编剧室曾出现一有趣的现象，最初的写法是一轮血月浮起，天地涌现万千尸骨，铺成悬桥，收万劫乃自血月而出，踏尸骨悬桥而来，随后选桥会围成一圈，成为修罗斗场。观众想必发现了，关于踏尸骨而出的画面，正与鬼麒主再现时的呈现一样，直到互看初稿时，才发现设计重复了，这等神秘的灵感共鸣无从解释。鉴于天邪八部众皆有过往，其中四人更曾死后再邪魂策王一次，因此拥有多重人生，收万劫也不例外。过去，收万劫名为冬月宵，乃东瀛一酿造清酒之世家，世居冬月藩，因此地涌泉冷冽甘甜，极适合酿酒，以“冬月吟泉”闻名，因冬月宵两位兄长，皆在十三岁时，死于诡异的疾病，其母冬月笙为挽救冬月宵，故与八歧邪神交易，换得冬月宵生机，而冬月笙则化为“寒蝉之音”，灵魂永世禁锢于风铃之内。策王之后的阿修罗王，仍陪伴亲妹冬月泪香长大，并将泪香嫁与竞邪王·驭能天，而后泪香因病逝世，收万劫亦将泪香之魂，收于寒蝉之音内，而后示流岛大战爆发，收万劫战死，邪魂转赴中原，借星宿天之孤儿·星宿一奇而生。收万劫·月刊268期封面人物P2~9因缘际会之下，道皇圣无殛于星宿天扶养一奇，并收为关门弟子。但邪魂影响日剧，纵使道皇亦无法完全遏制，最终只得让星宿一奇沉眠于“时穷丹青湖”中，乃至青阳子凭借《道皇遗册》之记载，将之唤醒，此时星宿一奇已是完整邪魂策王之状态，并与青阳子进一步合作。双方合作，各有谋求，收万劫的目的，与其说是复活八歧邪神，不如说是为了拯救母亲，但死而复生，谈何容易，阿修罗王智非愚昧又岂会轻信，但当遇见郁丹霞这符合命格之人，使泪香复生时，毋宁也加深了收万劫复活母亲的信念。为了表现收万劫对于亲情的执着，与一家团圆的渴望，《战祸邪神》第一章，即带走郁丹霞，一开始或许还有些暧昧，但看到第八章就知道他是为了妹妹冬月泪香；而第二章到第八章的一连串布局，则是要让恨吾峰邪魂策王，为了妹夫竞邪王·驭能天，从两人最初的交谈中，也可察觉收万劫与驭能天之交情不薄；甚至在第三、四章时，圣龙口遭遇剑子仙迹、剑非道、恨吾峰强攻，阿修罗王所想的，却是他还是冬月宵时的回忆，和妹妹相处的点滴，以及病发的状况，再连结到第十章，母亲冬月笙的牺牲奉献，亲情，可说是收万劫的策王的原罪。重情，却不为情所困，是阿修罗王的自我要求，唯有冷静的安排每一步，并让计划如期施行，才能达成最终的目标，故即使他暗地里看见，竞邪王有意冷落泪香，也不出面说破，只轻叹地道：“一家团圆，这条路，吾注定万劫不复”此时，几可看见，阿修罗王脆弱如蝉翼的一面，但也是刹那而已，重情至无情的算计一切，只是一个念头，只消一声铃动。“寒蝉有声，万劫不复”可算是收万劫最常说的一句话，设计这句话时，想到两种含意，第一层意思，可参照御天者曾说的话：“寒蝉之音不息，阿修罗王不收。”寒蝉之音，原本是普通的风铃，但里头寄宿着冬月笙的灵魂，变得意义不凡，每当风铃响起，阿修罗王听见的一声声，都是母亲的叫唤：万劫，即是收万劫，不复，谓永不回头。至于第二层意思，留待日后道破。武学设计武学方面，着眼于收万劫的双重身份，设计他身负两极功体，一是属于天邪八部众的修为，二是来自于道皇传人的道行，甫登场，阿修罗王全凭道门根基应战剑子仙迹，剑子对此的评价是“竟以邪身，练就如此罡正的修为”。而第九章关键一战，初以邪刀对战约七成功力的剑子，在“殊源流”加持下取得上风，等到剑子自古尘中收回完全力量之后，重创收万劫，逼得他刀剑同用，将“殊源流”再次提升，以“奇劫四绝”打断古尘。这段反转再反转的武戏，尤其在剑子恢复完全状态，配合“古尘现世”以及流畅且威能尽展的武打动作，实令人血脉偾张，剑子之败，在于古尘衰损，相信未来还有逆转之机，也期待两人再次对决。阿修罗王·收万劫“殊源流”的设计概念，是一运功法门，收万劫借由自身道门玄功和邪力相互冲击，进而激荡起强大的破坏之能，发挥一加一大于二的威力，如今展现出来的可见有两种阶段：一是持单刀（邪），将道气贯注其中；二是双手分持刀（邪）剑（道），分别将邪气注于剑上、道气注于刀上，威能自也远大于单兵使用。“奇劫四绝”，则是配合“殊源流”使用的四大绝招，已经使用的“千古一式·破碎苍茫”乃是其中的至攻之招，“水月一色·洪荒尽藏”为至守之招，在剧中一一使用。造型设计相比其他八部众内敛稳重、霸气，编剧希望收万劫展现相对年轻的样貌，发型以侧边长浏海、大马尾，呈现少年派日系风格。收万劫·造型编剧指定发色以白红相间的视觉系搭配，较醒目的就是有一点夸张的眼睛与眉毛，与其他八部众更为突出。衣服布料也使用亮片等装饰，再次呈现与其他八部众不同的视觉系效果。

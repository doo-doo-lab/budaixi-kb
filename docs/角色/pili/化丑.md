# 化丑

云州大儒侠史艳文之女，蕙质兰心的名门闺秀，本名史菁菁，与独眼龙、金太极间有段纠葛难断的三角关系，后嫁予金太极生下一子紫霹雳，却避不了坎坷的命运，因此看破红尘落发为尼，无意中被素还真所救，收为徒弟；曾遭魔域鬼帝改造为鬼奴，一度卧底于魔域，最后选择退出江湖，隐居于无双崖底。

## 主要经历

史菁菁（化丑）与独眼龙、金太极间有段纠葛难断的三角关系。她曾遭巫夷五炮追杀，后被韩公所救。巫夷五炮向金太极诬陷史菁菁欲与刀无流私奔，而史菁菁为报杀父之仇寻求刀无流帮助。金太极为复活儿子紫霹雳请教宇文天并收集材料。后在助素还真送一页书至天河医治后，与冷剑白狐、史菁菁一同隐居无双崖底。

## 出场作品

《霹雳金光》。在《霹雳金光》补剧指南中被提及，化丑在该剧集中出现。

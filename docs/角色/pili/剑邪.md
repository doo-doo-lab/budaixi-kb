# 剑邪

一个寻找过去的人。北域两大传奇剑客之一，剑鞘亦为炼邪师所封，守着一口隐藏谜样过去的宝剑，来历背景充满谜团。行事低调、正直良善，好学多问，乐观且安时知命，对自己的过去怀着一种可遇不可求的迷惘。

**武器详细描述**

莲谳：佛门圣器，以“谳”为名，有审判定罪之意，剑身厚实钝重，不用以杀生；

剑鞘造型复杂，镶有多枚宝石点缀，鞘首嵌有两只圆环宝轮，整体造型佛意十足。

朱厌：朱厌有两种型态，虽名为剑，在剑邪手中，剑形似一柄曲刃弯刀，在吞佛童子手中，则变换为长柄长枪，红白二色交错，剑刃及挽手系有日本祭祀纸符，能散发出灼热的炎气，杀意十足。

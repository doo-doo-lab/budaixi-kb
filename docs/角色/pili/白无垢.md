# 白无垢
================================================================================

白无垢

天魔录中的第一智者，淡泊名利，俊秀风雅，昔日应天魔之请而出凉心居，运筹帷幄，主持大局，使魔界立于不败之地。心怀圣母，用情至深，忠于天魔，绝无二心，对待魔界诸友以义气相酬，抱持与中原武林友好的态度，期望人魔双方能有永续和平，而对于侵犯魔界之徒，必予以惩戒，出手绝不留情。

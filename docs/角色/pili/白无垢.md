# 白无垢

天魔录中的第一智者，淡泊名利，俊秀风雅，昔日应天魔之请而出凉心居，运筹帷幄，主持大局，使魔界立于不败之地。心怀圣母，用情至深，忠于天魔，绝无二心，对待魔界诸友以义气相酬，抱持与中原武林友好的态度，期望人魔双方能有永续和平，而对于侵犯魔界之徒，必予以惩戒，出手绝不留情。

### 角色详解

摘自霹雳会月刊第71期完全写真《白无垢 深情忧郁的无私智者》：置身权力名势汹涌翻腾不停的武林，白无垢抱持的态度一直是能躲多远就躲多远，即使有着魔界第一智者的美誉，他从无心涉足魔界的权力斗争，白无垢保持着观望的态度来看待魔界权力斗争及武林势力消长，毕竟，对权力无所求的他想做的只是一个隐世者，魔界由何人掌权与他都没有深切的利益影响，若非有心人士的设计及佳人的请求，白无垢不会踏上红尘路。

白无垢对于爱情认定的执着，可以算得上是洁癖了。虽然圣母一直当他只是朋友，白无垢心底的思慕却不曾断念，更没有因圣母爱上天魔而稍减，他选择在一旁守护，无怨悔地付出以及默默地成全，只要圣母需要帮助，就算会有丧命之忧也毫不考虑地答应，白无垢这样专情又无私的好男人真是难得一见；他唯一的小小私心，就是将圣母葬于凉心居，好让自己日夜陪伴佳人芳魂。

### 诗词记录

有感诗云：万感中年不自由，角声吹彻古梁州。荒苔满地成秋苑，细雨轻寒闭小楼。（江湖血路24，出自文廷式《鹧鸪天·赠友》）

阐释石碑文：白鸟者，乘夫莽眇之鸟，以出六极之外，而游无何有之乡，以处旷浪之野；黄花者，花之末也，故蝶愁蜂怨，乃不可久。

观十分秋悟：不取春夏之繁叶，亦不取寒冬之沉寂，生而杀，杀而休，休则再生，十分秋悟。

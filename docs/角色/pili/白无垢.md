# 白無垢 (白无垢)
================================================================================

白無垢

天魔錄中的第一智者，淡泊名利，俊秀風雅，昔日應天魔之請而出涼心居，運籌帷幄，主持大局，使魔界立於不敗之地。心懷聖母，用情至深，忠於天魔，絕無二心，對待魔界諸友以義氣相酬，抱持與中原武林友好的態度，期望人魔雙方能有永續和平，而對於侵犯魔界之徒，必予以懲戒，出手絕不留情。

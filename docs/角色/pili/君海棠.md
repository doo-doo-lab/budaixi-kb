# 君海棠

开天六王之一，也是六王中唯一的女性，一身蓝色衣裳秀丽脱俗，面貌美艳动人，但心思总让人捉摸不定。擅长魅惑之术，手段阴险残毒，喜爱玩弄人心，为达目的不择手段。却因深脑长议失去意识时，恰巧被御清绝所救，开始了一段特殊的缘分，难分、难舍、亦难解。

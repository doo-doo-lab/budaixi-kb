# 絕日狂圖 (绝日狂图)

絕日狂圖

九輪天「崇罪明邦」之主，昔日席捲怪販妖市的罪念即是絕日狂圖所創。性格嚴謹、威震天下，善於洞察人心，亦擅長談判與利益交換。久遠前將十二個晶源交給創罪者，讓創罪者與裁罰者前往苦境，擴散罪念之力，為九輪天降世先行準備，亦讓崇罪明邦的勢力一點一點侵入苦境。

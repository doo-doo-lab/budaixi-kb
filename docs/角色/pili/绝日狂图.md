# 绝日狂图

九轮天“崇罪明邦”之主，昔日席卷怪贩妖市的罪念即是绝日狂图所创。性格严谨、威震天下，善于洞察人心，亦擅长谈判与利益交换。久远前将十二个晶源交给创罪者，让创罪者与裁罚者前往苦境，扩散罪念之力，为九轮天降世先行准备，亦让崇罪明邦的势力一点一点侵入苦境。

# 绣尉

绣尉（天子传奇）

西岐女将，个性温柔婉约、善体人意，独立坚强、忍辱负重，为女中豪杰，但一生为情所苦。九鼎之役失去情人书尉、断崔魂一手。尽人臣之道，誓死保护姬发。义救一忧子，后重伤被飘渺城少主苍龙所救，苍龙的一往情深让绣尉已冷的心渐渐有了温度！

### 创作背景

在衍生游戏《天子传奇OL》中，绣尉以Q版女宠的形象登场，被描述为“外表柔弱内心坚强”的奇女子；游戏内60级的副本中设有“救出绣尉”的战功，作为玩家可获得的宠物，她在战斗中有不俗表现，展现了力量强大的一面。

### 角色背景

绣尉是《天子传奇开周纪》中西岐阵营的女将，西岐四尉之一，西伯侯的臣子（或称爱将）。绣尉初登场于《天子传奇》第1集，来自西岐，根据地是西伯侯府。

绣尉对西伯侯姬昌及其子姬发忠心耿耿。绣尉的优雅出众的容貌曾令飘渺城主惊艳并意图霸占。

在飘渺城，少城主苍龙星君对绣尉一见倾心并救过她。但因无法违抗父命，最终在苍龙堡强行占有了绣尉，绣尉对此痛恨不已，称其父子“禽兽”。

最终，绣尉因内功不深，在竭力为姬昌疗伤后被苍龙重击，导致体内毒性攻心，香消玉殒。

### 主要经历

绣尉身受重伤，被飘渺城少城主苍龙星君所救并安置在其寝室疗伤，苍龙对绣尉一见倾心并悉心照料。绣尉在昏迷中呼喊“二公子”（即姬发）。

飘渺城主与少城主苍龙均觊觎绣尉美色，城主命令苍龙将绣尉送至其寝宫。苍龙虽有意娶绣尉为妻但被迫服从父命。后苍龙追上绣尉并将其震晕，带至苍龙堡后强行占有了她。绣尉痛斥苍龙父子禽兽不如，感到痛不欲生。

绣尉内功虽不深厚，仍竭力为西伯侯姬昌疗伤。后因被苍龙重击，导致原本暂延的毒性立即发作，毒发攻心，香消玉殒。

### 人物关系

绣尉是西伯侯的臣子。

敌对人物：飘渺城主见绣尉后惊为天人，下令苍龙将其抓回。

情人：苍龙对绣尉一见倾心，但因飘渺城主的命令，在强暴绣尉后导致其最终毒发身亡。

上司：姬昌、姬发。绣尉曾竭力为姬昌疗伤。面对姬发时，绣尉因护驾不力而请罪，后得姬发保护。

### 相关作品

歌曲《霹雳英雄 - 绣尉-风雪情天》收录于专辑《天子传奇开周记 剧集原声带》，由霹雳英雄演唱。

在游戏《天子传奇OL》中，绣尉作为宠物角色出现，玩家可在60级副本中营救她，她在战斗中表现不俗。

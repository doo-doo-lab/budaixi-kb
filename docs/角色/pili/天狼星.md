# 天狼星（霹雳布袋戏虚拟人物）

## 角色评价

对天狼星来说，他没有人类的美丑观念，所以他不在意外在条件，他要看到的是这个人的内在。但是他看着胖女孩儿（白小茶）所表现出来的一切，整个过程中竟是如此的打动他，天狼星终于害怕了，身为恶灵是不可能重视人类，但他却动摇了，天狼星终于把心取回来了、不再是一颗恶灵的心，而是一颗人类的心，这也同样就是死神在人间经历的故事。天狼星

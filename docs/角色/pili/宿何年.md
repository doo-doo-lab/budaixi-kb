# 宿何年

西煌佛界最崇高的精神领袖，四大创道者之一的“尊佛”。满头白发，手持木杖，颈挂佛珠，身披白色绒毛斗蓬，千里跋涉的庄严佛者形象。个性持重慈悲，一生未杀过人，曾封印过鬼狱第三层。生前与阎罗鬼狱之主，有一场横亘百年的赌约......。

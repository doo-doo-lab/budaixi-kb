# 邪影
================================================================================

邪影

武林中传闻的罪恶者，行为诡异莫测，没有人知晓其目的为何，只知道有无数表面无辜的人，惨死在他的剑下。实际上，邪影源自巨锋里，为了伸张正义、制裁犯罪，始隐于暗处，在武林中执行非法正义。

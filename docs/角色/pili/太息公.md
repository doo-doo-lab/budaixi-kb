# 太息公

================================================================================

霹雳布袋戏虚拟人物太息公是《霹雳布袋戏》系列中的虚拟角色，

**别称**：邪玉明妃，由黄文择

**初登场**：于《霹雳震寰宇之兵甲龙痕》第2集。其

**身份**：为四魌界火宅佛狱三公之“公”及第二首领，拥有副体玷芳姬，麾下部署包括莎莉罕等部众。太息公性格刚硬深沉且工于心计，以火宅佛狱利益为最高准则，常与凯旋侯针锋相对。在血暗沉渊开启后主导部署贪邪扶木吸收苦境地能，掌握兵甲武经“裂”之卷、九阴扶邪等

**武学**：以及纳阴邪诀等咒术。副体玷芳姬负责执行深植贪邪扶木的任务，性格直接且厌恶凯旋侯。该角色最终于《霹雳经武纪之枭皇论战》第15集被魔王子击杀，其

**别称**：“邪玉明妃”关联角色配乐，曲风融合人声诵经元素。

**中文名**：太息公

**别名**：邪玉明妃

**配音**：黄文择

**性别**：女

**登场作品**：霹雳震寰宇之兵甲龙痕霹雳经武纪之枭皇论战来 自四魌界

**门派**：火宅佛狱

**身份**：火宅佛狱第二首领副 体玷芳姬

**出场集数**：54集

**本尊雕偶师**：洪有聪

## 角色设定

太息公名称：太息公称号：邪玉明妃身份：火宅佛狱三公之“公”名言1：花颜之所以绝世，不过在于攀折刹那的凄美。一声太息，景殊色衰，不过弹指之间。名言2：太息公，火宅佛狱的最高利益！初登场：霹雳震寰宇之兵甲龙痕 第2集退场：霹雳经武纪之枭皇论战 第15集（死于魔王子）

## 角色能力

- **武学**: 参森刃、参森指、九阴扶邪、九罗盘根、叶雨血潮、鬼哭邪嚎、兵甲武经“裂”之卷：裂宇之玄、裂宇之涛咒术：纳阴邪诀、九罗盘根·贪邪扶木·遮天盖地·速遵吾令所有物：读思虫

## 夺魂者佛狱三公

太息公三公分别代表：火宅佛狱（王）、最高利益（公）、战无不胜（侯）。大意为，三公代表着火宅佛狱的最高利益，进而战无不胜。

## 角色配乐

- **◎邪玉明妃（太息公角色曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选二十七》
- **本曲属于死国、火宅佛狱时期的创作曲，由于要编写的坏同学挺多，所以创作时便以妖僧为发想，加入了人声诵经的元素营造诡异曲风，后来董事长指定此曲给明妃使用，而曲中妖异的诵经声也颇符合此角。◎鬼哭邪嚎（太息公武戏曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选二十八》

010203040506太息公是个有趣的角色，虽名列佛狱三公之中的“公”，却是个不折不扣的邪魅女子，武功高强自然不在话下，但在战斗中却也蛮爱嘶吼鬼叫的，所以孙敬凡老师在编曲时特别加入人声吟唱，且是以女声叠上变频后的男声混音而成，试图营造出有点东方不败的味道，太息公鬼哭邪嚎一起，霎时叫人倍感阴冷且不寒而栗。

**太息公**为台湾霹雳布袋戏中的反派角色。佛狱三公之一，外表娇艳，以组织的利益为优先，当常与凯旋侯发生争执。初登场于霹雳震寰宇之兵甲龙痕第2集，又于霹雳经武纪之枭皇论战第15集，惨遭魔王子拔头。

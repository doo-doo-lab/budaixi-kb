# 时间城主

================================================================================

霹雳布袋戏虚拟人物时间城主，霹雳布袋戏虚拟人物。掌管时序流转的时间城之主，举止总是高贵优雅，却又带有诙谐幽默，对世间万物保持中立且客观的立场，却也会被素还真等正道之人的请托感动，进而给予协助。在尘世暗夜降临时，时间城主为了天三脉的关键而挪动了白虎、天刑、玄武等凶时时序，助正道大破暗夜，尔后更主导修复素还真一魂，以及帮助绮罗生于时间天池疗养复原。尽管对世间之事仍抱持不干涉的态度，但时间城主对正道及苍生的帮助却是功不可没。

## 经历
在尘世暗夜降临时，时间城主为了天三脉的关键而挪动了白虎、天刑、玄武等凶时时序，助正道大破暗夜，尔后更主导修复素还真一魂，以及帮助绮罗生于时间天池疗养复原。此外，时间城主亦曾安排绮罗生回时间城执掌时间，并对其言道：“沉眠的世界，或许有梦。”，此举让绮罗生产生了强烈的归宿感。

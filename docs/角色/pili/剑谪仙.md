# 剑谪仙

仙风道骨，宛如天上谪仙人一般的剑中仙，超然物外，冷傲观世，举手投足充满绝对的自信，却又不会锋芒毕露。曾调查苦境隐藏的数桩神秘灾祸，久远前留下靖玄录计划后，交由月琴老人代为集结天命者——靖玄客，剑谪仙则因故进入涅槃之境，行踪成谜。

# 众天邪王

霹雳布袋戏虚拟人物众天邪王，是霹雳布袋戏中的虚拟人物，天邪八部众之首，以“冥帝”为号，神之罪业“神愆”为名，代表对六天诸神最深的怨恨。其姿态高傲，冰冷无情，睥睨众生，手持咒神天秤。甫出场便击败群侠，拔起仙脚顶端的云汉仙阁，飞入云海之中，开启了沦亡游戏。众天邪王的真身是来自东皇玄洲的祌天爻帝，为战祸双星之祸星，拥有近神修为的近神之躯。其武器为终极冥帝，功体为正邪兼容体质。

## 人物设定

众天邪王·二版造型名称：神愆称号：冥帝、众天邪王、八部之勇、无间之令自称：曌诗号1：三界光明，尽吾赐生，一念黑暗，举世沉沦。诗号2：亘古一邪，神愆唯曌，败尽众天。诗号3：万古祸星千年杀，百代沦亡十方叹。血问天罪，独吾神愆！身份：天邪八部众之首、战祸双星之祸星初登场：霹雳天命之仙魔鏖锋Ⅱ斩魔录 第12章（附身冥霾邪滍）正式登场：霹雳天命之战祸邪神Ⅱ破邪传 第16章（夺舍天迹身躯）退场：霹雳天命之战祸邪神Ⅱ破邪传 第47章（自散灵力而消亡）再登场：霹雳惊涛 第2章（一丝执念化身于生命之林短暂登场）来自：东皇玄洲根据地：云汉仙阁

## 人物能力

武学：六道禁绝、祸星之行‧【天地皆破、三界沦亡】、十方叹、祸天爆功体：正邪兼容体质（夺舍天迹身躯）邪滍之躯（寄体）：冥霾邪滍体质，无形无体，驾雾移形，能进入任何想去的地方，所为甚诡，而邪滍以吞噬黑暗之力为能源，亦能食人妖魔化为能量。

曾神愆在近神之躯受到重创后，得到八歧邪神赐予冥霾邪滍作为暂时的躯体。

为了维持邪力源源不绝，神愆乃将终极冥帝与冥霾邪滍之心合而为一。

终极冥帝需要不断吸收负面能量，而邪滍之心对于终极冥帝那就是世上最好的共给，对于终极冥帝而言世上只要还有负面能量存在，他就永远不灭。

近神之躯（原身）：光明之灵体质，祌天爻帝的本体，乃东皇玄州汇日月星光之精华所聚的三光之灵体，真身拥有近神修为的近神之躯，已达几可登仙之列（只差飞升）。

因叛神一族阴谋失去无垢之心，祌天爻帝因此失去记忆，再由邪毒污染而成为冥帝。

后身中天罚之剑，又经与九天玄尊一场激斗，最终昏迷后漂流海上。

而冥帝在近神之躯受到重创后，得到八歧邪神所救，邪神替其拔出天罚之剑，因此身体需修复而被邪神送入宇宙之牢，后便赐予冥霾邪滍作为其暂时的新躯体，并使其化身为天邪八部众之勇·无间之令·众天邪王。

武器：终极冥帝介绍：集冥帝单锋、冥帝邪枪、冥帝刀弓、冥帝之精，四者为一体的传说魔兵，掀起冥帝之灾的浩劫之源，也是冥帝的由来和神愆的一部分，可以源源不断吸收负面能量，只要生物心中的邪恶、怨恨、痴妄等黑暗的力量长存，就会有无穷无尽的暗能与力量，永远也无法消灭。

形体是以冥帝群锋等比例缩小方式组成，以枪为身，枪头改为单锋，底部为冥帝之精，枪柄处为刀弓且有可折合特质，使整体使用上更具杀伤破坏力。

当玄孔雀之心回归神愆时，愤怒之下首现邪之招唤，使神兵终极冥帝现尘寰，祸星之行，非灾即杀！

终极冥帝事迹介绍：终极冥帝的主人乃是神愆。

最初的终极冥帝本由祌天爻帝的无垢之心中衍生的浩劫之石所化。

而神愆在近神之躯受到重创后，得到八歧邪神赐予冥霾邪滍作为暂时的躯体。

为了维持邪力源源不绝，神愆乃将终极冥帝与冥霾邪滍合而为一。

岂料，云海仙门一战，冥霾邪滍被玉逍遥所杀，邪滍之心化为妖异天铁坠落人间，辗转遗落在毕方山，而为应笑我所得。

应笑我将之交给雨霖铃，雨霖铃意外受到邪滍之心蛊惑，乃重铸终极冥帝，将之还原。

应笑我取走了冥帝单锋、冥帝邪枪、冥帝之精（伪品），雨霖铃则暗中保留了冥帝刀弓与真正的冥帝之精。

背叛之孽－冥帝刀弓形态：可拆解为紫翼双弓刀本为雨霖铃所保留，后委托劫红颜保管，便一直由劫红颜使用。

直到东海之滨一战，被众天邪王以邪之召唤取回。

怨恨之毒－冥帝之精功效：可强化兵器威力原本看似在玉梁皇之手的冥帝之精，实则是雨霖铃仿造的高级品，真品一直在雨霖铃手上。

也是在东海之滨一战，被众天邪王以邪之召唤取回。

屠戮之恶－冥帝单锋最初是为单锋剑魔应笑我所使用，应笑我败于乱世狂刀之手后坠崖，冥帝单锋也随之下落不明。

实则冥帝单锋为暗影取走。

在东海之滨一战，被众天邪王以邪之召唤取回。

嗜血之罪－冥帝邪枪最初是为邪天子所使用，后辗转经过玉梁皇、暗影、寒武纪之手，再由红尘雪保管，在下中阴界之前，转交劫红颜保管。

在东海之滨一战，被众天邪王以邪之召唤取回。

所有物：咒神天秤（可以平衡神愆自身的圣邪两股力量）、神纹烙耀、浩劫之石（是祌天爻帝被邪毒污染后而诞生的恶意之心，后化成终极魔兵——终极冥帝）

## 人物影响

神愆在故事中从被背叛的受害者转变为操纵背叛的加害者，形成了讽刺性的暗喻。部分评论认为，其角色塑造存在“头重脚轻”的问题，背景设定强大但性格转变原因薄弱，用“中毒”带过，导致成为“设定满分，演出扣分”的代表角色之一。神愆的黑暗之心（浩劫之石）的意志通过应龙麟凤传递给了小默云，延续了其影响力。神愆与“战星”御命丹心·君奉天的会面，场景设计可从“战祸双星”与“奉天逍遥”两种人物关系视角进行解读。

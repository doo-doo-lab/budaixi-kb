# 南宮佈仁 (南宫布仁)
================================================================================

南宮佈仁

儒教五儒生之首，能夠模仿任何人的聲音，有「八音才子」之稱。但個性狂妄自大、短視近利，曾變節投靠合修會，且覬覦好友曹百哀所研發的千子彈，不惜滅門奪之，顯露其無情冷血的一面。

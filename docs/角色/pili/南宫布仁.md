# 南宫布仁

儒教五儒生之首，能够模仿任何人的声音，有“八音才子”之称。但个性狂妄自大、短视近利，曾变节投靠合修会，且觊觎好友曹百哀所研发的千子弹，不惜灭门夺之，显露其无情冷血的一面。

## 创作背景

“八音才子”这一称号并非网友杜撰，而是来源于《霹雳狂刀》中五儒生之首南宫布仁的外号。剧中南宫布仁的特长是可以模仿戏中所有人的声音，与现实中配音师黄文择的特点恰巧吻合，因此该称号也被用来指代黄文择。

## 主要经历

在《霹雳狂刀》剧情中，鬼王棺在慈海渡者与南宫布仁的威逼之下，出面指证不知名偷盗九龙菩提经之罪。

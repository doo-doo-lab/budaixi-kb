# 剑君十二恨 (剑君)
(百度百科无对应条目,newton.com.tw 收录)

霹雳布袋戏经典虚拟人物。以剑为名、仗剑天涯，一生追求剑的真意，为人重情重义、极富正义感，自然率真、毫不虚伪，乃剑界中傲骨桀然之独行侠客。初入江湖追求天下第一快剑闻名，因得灵啸月引荐成为儒教传人，使原本冷傲性格渐趋圆融、睿智，在相继拜得名师的指点下、和对剑的领悟与执著，让他不断突破自我、为剑攀越顶峰，达到自己心中的完美、体悟最终的剑意。

## 武器

（摘自霹雳武器事典1~3）
寇心剑：此剑呈银灰色，龙纹环剑首，每逢重阳节剑身会转呈血红色，有如泣血一般。
十二无敌：剑柄长于剑身，剑首粗而宽，护手两翼可折叠，剑锋呈尖锥状，刻有“十二无敌”。
诸凤剑：剑身修长、护手宽大，呈双凤朝天之姿。
玉冰剑：寒光刺骨，外形古典的宝剑。朱红色剑鞘，充分散发着儒门优雅之风格。
巽风剑：黄柄直刃长剑，护柄呈山枕之姿，剑身狭长而锋利，以轻盈、灵动为一大特色。
地凌剑：以金色漆业为护柄、单边歧长，刻有钟鼎文为点缀，笔直狭长的剑身适合凌空飞旋。
武驰剑：翠绿之剑，护手呈菱形、双缘微翘，剑锷刻有锥形雕纹，古意十足，狭长剑身也适合凌空飞旋。
无玹剑：传奇人物“武痴”的佩剑，乃一口上古宝剑，外形以古代宝剑【夫差剑】为蓝图设计。此剑修长锋利，剑身中间有一道突起的棱脊线，两侧微凹、两边留刃，剑刃两面雕双阴线纹，交织成方菱形格纹，由剑尖上端至剑格套嵌处，从小渐大依循雕刻；木质握柄嵌合青铜护手，以钟鼎铭文雕饰，更彰显无玹剑源远流长的历史。

个人诗号
一恨才人无行；二恨红颜薄命；三恨江浪不息；四恨世态炎冷；五恨月台易漏；六恨兰叶多焦；七恨河豚甚毒；八恨架花生刺；九恨夏夜有蚊；十恨薜萝藏虺；十一恨未逢敌手；十二恨天下无敌！

诗号出处：诗号改编自清代文学家张潮所著的随笔体格言小品文集《幽梦影》。原文为：一恨书囊易蛀，二恨夏夜有蚊，三恨月台易漏，四恨菊叶多焦，五恨松多大蚁，六恨竹多落叶，七恨桂荷易谢，八恨薜萝藏虺，九恨架花生刺，十恨河豚多毒……石天外曰：‘予另有二恨：一曰才人无行，二曰佳人薄命’。

1.  拜仇天为师，后司徒无忧杀其师，立志为师复仇。

3.  霹雳狂刀第58集正式登场，杀败荒山三刀。
4.  以第二层剑大破魔域魔阵.。
5.  观风岭上，带头把三教三先天打出原形.。

7.  叶小钗使用心灵剑术，剑君相助，使其灵魂回体。
8.  于是非小径以五行剑阵，助素二人安然离去。
9.  于叶小钗斗剑于无人峰，也是在此时初会灵啸月。
10. 后与灵啸月一战，所背之剑除十二无敌外皆为灵啸月斩断，从此灰心丧志。
11. 无意中发现魔域送毒至海鲸岛阴谋，与干儿共同举发，自信心逐渐恢复。
12. 受神秘女郎之邀，拜圣夫子为师成为儒教传人。
13. 与狂刀，叶小钗共赴西武林拯救不知名。
14. 荒龙道三传人合战入魔的三教主。
15. 以为其弟死于叶小钗之手，两人决战，入魔的夫子闯入死于乱世间手上，此时剑君萌生退隐之意。
16. 帮助百里抱信收复儒家圣地世外书香后，剑君十二恨归还诸凤剑，欲退隐江湖。
17. 得分不开之助，练成“翦云步”，受到分不开煽动，杀骨董，得玉冰剑。
18. 天外方界为除灵山双叹.再度以其弟威胁，命剑君拜灵山大叹为师，习成便挑战大叹。
20. 魔魁大战灵山双叹，双叹一死一伤，之后剑君得知其弟也死于魔魁，立誓报仇。
21. 无忌天子将谈无欲之功力全数灌输给剑君，并安排三传人于海鲸岛大战魔魁。
22. 创世狂人时期，收伏三名易水楼杀手为自己的小跟班，之后救青阳子，败白云骄霜
25. 参与攻破血肉长城。
26. 长乐君成立安乐园，剑君成为天下圆一员，护卫大将。
29. 遭晏君临假扮的西洋女剑客偷袭，丢入伏魔井，并将之洗脑改造，与狂刀沦为晏君临左右护法，但潜意识依然记得三传人的情义。
30. 穷八极卯上晏君临，剑君狂刀遭穷八极击飞，并解除二人洗脑术，再度恢复原有意识。
31. 拜病剑叟为师，得巽风，习得八风剑法。
33. 后帮助天策真龙对抗魔剑道，轻易毁去月鸣孤魂的战车，三传人合杀三阴。
34. 巧遇策衍先座，得武痴配剑-无玹剑及武驰、地凌剑，习得武痴绝学，重新背上剑架再现风采。
36. 抓藏青鸟。
37. 冰河天川边初会银狐。
38. 中四无君之计，困于山洞内，但却参透武痴人字诀的精髓，悟出“剑武”，修为更上一层楼。
39. 与策衍先座定下三剑三约，首杀明月心。
41. 最后在青阳布计之下终于杀除四无君。
42. 落阳湖一役，助青阳子围杀鬼隐。
43. 结识冷非颜，航谷风，助冷非颜洗刷冤屈并收复三槐城。
44. 以巧智说服天章圣阁共同对抗覆天殇。
45. 于九渊之颠秒杀两护法。
46. 补天一役，暗助半君邪，杀败欲界人马。
47. 九渊之颠最后一战，杀败神典但丁。
48. 邪能境叶口之战，与银狐联手毁掉骧铁4代。
49. 四曲狭道之役.与银狐、卧江子联手败叶口一部军队。
50. 叶口之战，杀败执首猊戬傩叶。
52. 杀上玄空岛，十二恨天下无敌震慑叶口月人，败众执首并杀执首稽咸璚叶，叶口月人经此一役，元气大伤。
53. 战死玄空岛之后，被傲笑红尘葬于篙棘居，结束了剑君十二恨天下无敌的一生。

傲笑红尘为剑君十二恨题诗：剑歌未彻角笙散、君子志、裁作新恨、更成云山千叠、才人难得、留待白首人间。
54. 佛剑分说为取回完整力量而再度穿越时空，来到一个平行时空的未来，在这个灭绝希望的未来世界中，剑君十二恨并未战死玄空岛，而是继续贯彻剑道与侠义，跟灭绝希望的嗜血者斗争。
55. 平行时空，剑君十二恨和君奉天为助穿越而来的佛剑分说取回完整力量，一同攻打赎罪塔，剑君十二恨更是在战中诛杀了冰爵禔摩。
56. 暗邪皇虽被消灭，世界也重见天日，但是这个平行时空中仍有嗜血者余孽残留。

在告别了佛剑分说后，剑君十二恨继续为了武林安宁而挥剑战斗，平行时空的故事已告一段落。

## 人物评价

侠义的剑客形象，本姓司马，漂泊江湖，在剑中找到了人生的追求。

心系亲弟惊虹留恨，出生入死无奈江湖无情，此后更加一心求剑，收敛狂傲之心，数访名师，谦虚至诚。

当透彻一代高人武痴的绝学之后，秉承武痴行侠仗义之精神再涉江湖，屡为正道出力。

在变幻莫测的霹雳世界进入嗜血者乱世之时，剑君十二恨选择了他不变的执著——剑，孤身对上另一邪派组织。

问敌只为问剑，沥血化刃，用热血与生命维护了一名剑客的尊严，未曾放弃，依旧谦虚的剑客，达到的是无人可及的人与剑的境界。

退场旁白：一身飘零，十二恨消，毕生追求剑之至理的剑君。

当抛去一切，付出全部心力与生命，换回最后的领悟，最后一剑，是否真是天下无敌，是否是剑君一生愿望的终点。

（一步一沉重，带回是生离两别，来不及换回的遗憾，天地无声，视线胶着处 皆落在星子以冷的温度暗淡；

江湖路，尘世梦，豪情不过一抔黄土覆身，在场者有声声凄厉的悲嚎，有无语默默的沉痛，何足表恨）

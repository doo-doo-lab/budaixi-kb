# 业途灵

霹雳布袋戏虚拟人物业途灵，初登场于《霹雳劫》第9集。

原为灭境三途判之一，与十三邪灵大闹苦境，造成生灵涂炭，但之后被造世七侠炼化，又被表象意魔所擒，侥幸没死反功力大增。

在当时武林各家反派竞抢《九龙菩提经》的争夺战中，终因不敌慈海渡者，菩提经被夺，更被废去武功。

被秦假仙发现后饱以老拳痛打一顿，收为跟班，自此之后业途灵个性变为搞笑、逗趣。

继而一页书化身宇宙神知在梦中渡化其本性并收为徒弟，学得佛家武功。

跟随秦假仙、荫尸人笑闹江湖，屡助正道完成不少事迹。

业途灵曾在《霹雳王朝》中仿一页书吟诗。

亦曾去阴山墓坑窟采阴阳二香菇而被整。

业途灵作为“霹雳三丑”之一，其语言风格插科打诨，风趣幽默。

其角色经历了从反派三途判到被渡化后跟随秦假仙助正道的转变。

## 经历

出身灭境，在数百年前是与鬼王棺、腹中首合称“三途判”的为祸苍生的大魔头，且为不死之身，唯有一页书为其天敌。

业途灵业途灵自从于霹雳劫时期出场后，即与鬼王棺、腹中首、十三邪灵大闹苦境，造成生灵涂炭。

但三途判的弱点——可被七根吸雷针炼化——被知悉后，被造世七侠炼化于七星拱月台，只能借由一口真气借体于侥幸逃出的鬼王棺身上。

这段时间中，并未有太大作为。

之后在霹雳狂刀时期，被十三邪灵中的表象意魔所擒，侥幸没死反而功力大增，但因武林局势变化太快，武力已不敌其他角色。

被秦假仙发现后饱以老拳痛打一顿，收为跟班。

自此之后业途灵个性变为搞笑、逗趣。

此后，在《霹雳天阙》时期，业途灵曾去阴山墓坑窟采阴阳二香菇（阴阳二气菇），被整得身上长满蘑菇，光头上也长角。

跟随秦假仙、荫尸人笑闹江湖，屡助正道完成不少事迹。

## 人物造型

原始造型为光头、蓄胡、戴墨镜（摘掉的话体内魔气会暴涨，性格也会变恶），身穿绣有金丝与红线的黑袍，双手相连（实际上是互相缠绕的两条触手）。之后历有微幅更动，但改变不大。被收为秦假仙小弟之后，身材朝向中广化发展。

## 人物性格

原始个性骄矜自大，好勇斗狠，常与其他角色一言不合就大打出手，在武功被废之前以火龙金魔体称雄武林，但也不是有勇无谋的莽夫。业途灵原为灭境三途判之一，经历被造世七侠炼化、被表象意魔所擒等变故，最终被慈海渡者废去武功，被秦假仙收为跟班，性格也由此发生根本转变。武功被废之后，沦为秦假仙小弟，经常鼻青脸肿、灰头土脸出现，举止诙谐搞笑，例如，他曾去阴山墓坑窟采阴阳二香菇（阴阳二气菇），结果被整得身上长满蘑菇，光头上也长了角状蘑菇；也曾调侃毁容后的玉倾欢，临走时还不忘说一句诗，却又时有惊人之语。现今以诙谐形象活跃于中原武林。

## 业途灵人物影响

业途灵是“霹雳三丑”（秦假仙、业途灵、荫尸人）之一，作为丑角，在黄文择的口白艺术中通过插科打诨和语言交锋体现了风趣幽默、生动活泼的特点。业途灵曾作为灭境三途判之一横行武林，是武林中一大恐怖力量，并参与了埋葬钗头凤遗体等重要事件。转变为秦假仙的跟班后，业途灵在与秦假仙的互动中常进行调侃。

# 鬼帝

坐拥第二魔域的一方霸主，个性骄矜自大、暴躁易怒，且目光短浅，无容人之雅量，不论智慧、气度、手腕皆不足取，纵使手下人才济济、威风一时，仍不免落得众叛亲离的败亡下惨。

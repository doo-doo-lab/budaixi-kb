# 鬼帝

坐拥第二魔域的一方霸主，个性骄矜自大、暴躁易怒，且目光短浅，无容人之雅量，不论智慧、气度、手腕皆不足取，纵使手下人才济济、威风一时，仍不免落得众叛亲离的败亡下惨。

## 角色经历

鬼帝为第二魔域之主，出场前期身体巨大无比，在吸入慈航渡头颅内的舍利后，出现的真身其实只是一个小矮子。性格自大狂傲、暴躁易怒，而且目光短浅，没有上位者的容人雅量，身为枭雄该具有的智慧、气度、手腕都不足取，尽管手下人才济济、威风一时，还和当时为祸武林万魔天指、武皇齐名三大魔头，但仍不免落得下风。

鬼帝统治第二魔域，用一灵三化和慈航渡舍利子助炼的四口灵剑驻守魔域藏经阁，灵剑也曾被用来逼杀欢喜佛，但被欢喜佛用计所毁，但四灵归体反使鬼帝力量增强，练成“魔极”之招。不过亢龙有悔、盈不可久，三大魔头在探查一页书天河复生之谜时，鬼帝被一页书气功击中，元功尽散、一招毙命。死后身上的骨锁被鬼王棺所得，用于开启天地门。

### 组织形象

首领为鬼帝，下有掌管魔脉之殿的地灵鬼母，以及专门培育菁英的魔界学府，此时的第二魔域与灭境邪灵和集境三股恶势力结盟共同对抗正道，魔域的鬼帝、灭境邪灵的万魔天指、集境的武皇号称当时武林三大魔头。

但鬼帝有勇无谋，在军师智多罗死后第二魔域便渐渐式微，后鬼帝为天河复生的一页书所杀，第三魔域的沙虫、青丝前来接收残余兵力，第二魔域就此结束。

另外，第二魔域尚有一据点天地门，由奇妙大棺王看守，将之伪装成阴山墓坑窟。（需要用鬼帝身上的骨锁开门，但是，这个天地门是魔域相关，和后来青阳子的天地门毫无关联，又牵涉龙涎宫遗址的剧情，成为谜团。）

高层人士一开始并未现身，由军师智多罗辅佐阿修罗主宰，率领黑色十字军兵团﹝注：关于黑色十字会组织，比第一层魔域更早现身武林，其成员擅长以控制人心的心灵术，首脑为心海主宰静流君胞弟：黑色十字会之主，在当时的黑色十字会被称为魔教。﹞

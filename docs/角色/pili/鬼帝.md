# 鬼帝 (鬼帝)
================================================================================

鬼帝

坐擁第二魔域的一方霸主，個性驕矜自大、暴躁易怒，且目光短淺，無容人之雅量，不論智慧、氣度、手腕皆不足取，縱使手下人才濟濟、威風一時，仍不免落得眾叛親離的敗亡下慘。

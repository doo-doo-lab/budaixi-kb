# 中书客

儒门天下之人，任职中书令，掌传宣诏命、以及儒门宫藏典籍，乃一饱读诗书、文学名望之秀士，谨言而恪守分寸，与少陵御史地位相当。

## 来自百度百科的补充

霹雳布袋戏虚拟人物。

中书客，初登场于《霹雳兵燹之刀戟戡魔录Ⅱ》第38集。

儒门天下之人，任职中书令，掌传宣诏命、以及儒门宫藏典籍，乃一饱读诗书、文学名望之秀士，谨言而恪守分寸。组织门派为儒门天下，上司为疏楼龙宿。与少陵御史、陆华娥、琨玉商、桐文剑儒、蒙山飞燕、独步寻花等人为同僚。

中书客由编剧罗陵创作。

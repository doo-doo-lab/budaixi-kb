# 纪忘忧

悠然世外、寄情八雅的奇人修道者，幽居于放怀冷韵，雍容自娱，却对天下事了若指掌，信手闲情间，就能搅动江湖风云，善于运用利害关系，让他人无法拒绝要求，而想请他帮助，却是要付出不小的代价。

# 紀忘憂 (纪忘忧)
================================================================================

紀忘憂

悠然世外、寄情八雅的奇人修道者，幽居於放懷冷韻，雍容自娛，卻對天下事瞭若指掌，信手閑情間，就能攪動江湖風雲，善於運用利害關係，讓他人無法拒絕要求，而想請他幫助，卻是要付出不小的代價。

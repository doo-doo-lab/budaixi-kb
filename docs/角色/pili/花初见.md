# 花初见

外表落拓不羁，寡言冷漠，一袭灰衣，流浪于妖漫地狱各地。其人剑法出神入化，神出鬼没，常使无形气波剑气，擅于取人性命于无声无息之间。因自身来历的原因，身负着龙族一脉的血海深仇，曾数次图谋刺杀人族圣皇妲眸姬报仇。

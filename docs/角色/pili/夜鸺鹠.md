# 夜鸮无影

《霹雳神州II之苍玄泣》中的人物夜鸮无影是《霹雳神州II之苍玄泣》中的虚拟角色，由黄文择配音，隶属异度魔界第三殿成员，身高184厘米，体重76.8千克。该角色于第28集初登场，第44集被曌云裳斩首身亡。作为断风尘麾下三魔将之一，夜鸮无影与落雁孤行、落冥孤犬组成行动小组，多次参与夺取红楼剑阁神兵岁月轮的行动。其暗夜鸱枭的造型特征突出隐匿突袭的作战风格，最终在剑阁之主曌云裳剑气下战败退场。该角色在异度魔界第三殿朝露之城整军名单中被明确列为魔将，活动轨迹集中于异度魔界与红楼剑阁的势力争夺。直属上司为断风尘，主要同伙包括若魑离等异度魔界成员，总计出场17集。

## 人物设定

造型特征：其暗夜鸱枭造型，特征突出，体现了隐匿与突袭的作战风格。

## 经历

夜鸮无影初登场于第28集。作为断风尘麾下三魔将之一，与落雁孤行、落冥孤犬组成行动小组，多次参与夺取红楼剑阁神兵岁月轮的行动。在第44集中，被曌云裳斩首身亡。总计出场17集。

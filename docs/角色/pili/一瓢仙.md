# 一瓢仙

酒党成员，品酒为乐的逍遥散仙，相貌滑稽，厚唇阔嘴、爱眨眼，为人逗趣且颇有恻隐心与正义感，举手助人不求回报，曾意外救了墬崖重伤的羽人非獍。

# 金陵寒鴉 (金陵寒鸦)
================================================================================

金陵寒鴉

疏樓龍宿的持劍侍從，寡默無語，性格堅毅，對龍宿十分的忠貞，與穆仙鳳隨侍左右。恪盡職守，相當捍衛龍宿的顏面。金陵寒鴉本是受翳日一脈禁錮之役童，為龍宿所帶出教養，並賜其遮日冠，讓其不畏天陽。

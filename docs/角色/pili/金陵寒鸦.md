# 金陵寒鸦

疏楼龙宿的持剑侍从，寡默无语，性格坚毅，对龙宿十分的忠贞，与穆仙凤随侍左右。恪尽职守，相当捍卫龙宿的颜面。金陵寒鸦本是受翳日一脉禁锢之役童，为龙宿所带出教养，并赐其遮日冠，让其不畏天阳。

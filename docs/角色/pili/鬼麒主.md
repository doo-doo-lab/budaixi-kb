# 鬼麒主

================================================================================

霹雳布袋戏虚拟人物霹雳布袋戏虚拟人物。手持白骨扇，脸罩白面具，散发出冷沉诡邪的气质，内心阴沉难解、颇多算计。久远之前的上古血灾“血河战役”，导致生灵涂炭、人鬼相残，背后策动诸国战役者，即鬼麒主。除了使人界自相残杀，又开启阴界入口，造成群魔乱舞，使得天地人三界大乱。

（月刊258）2. 鬼麒主是幽界之内不能被提起的禁忌之名，也是被九婴传言的创写《释魔录》的神秘智者（《释魔录》原主实为魔始），号称三界第一鬼智，血河战役过后便消失武林，下落不明。

当初鬼麒主离开幽界之前，曾说过鬼麒麟是他的一部分，只要跟着鬼麒麟便能找到他。

鬼麒麟被关在《释魔录》是魔君与鬼麒主的一段约定，鬼麒麟一旦被释放，代表魔君也要放下对鬼麒主的一段恨。

## 备注说明

鬼麒主真正的鬼麒主为天邪八部众之“鬼龙王”，于上古血河战役时，已被君奉天诛杀，魂魄被镇压在天剑名峰。后因君奉天死前毁掉天剑名峰发动向天借剑，使得鬼龙王魂魄自由，在暗禘帮助下复活。仙魔鏖锋时期所出现的鬼麒主，乃人觉获得鬼面具和白骨森罗扇后以一魂双体之术化出越骄子所假扮的伪鬼麒主，并非鬼麒主本人，参见词条“伪鬼麒主”。

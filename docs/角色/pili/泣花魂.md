# 泣花魂

================================================================================

## 经历
泣花魂曾向龙王鱽深情告白，称唯有龙王鱽知她心，两人相知相惜、不离不弃。她表示在芸芸众生中，唯有龙王鱽为她销魂、守候数十年如一日。此情唯天可诉、唯地可知，她感叹真情令苍天嫉妒，导致两人难以团圆。泣花魂誓言此世无君不愿独生，愿上天入地追随吾爱，生同生、死同死。

# 渡末蓮 (渡末莲)

渡末蓮

近月觀音的鬼族真身，本為人族，後加入鬼族，成為鬼獄舞祭。蟄伏西煌佛界多時，身上留著瞞天過海的人血，故而蒙蔽了釋至伽藍等人。與八面鬼戎裡應外合，更在關鍵之刻，以西儒至寶泣麟藏穎破胎藏妙法，聖衡者亡。佛域降血雨，鬼水漫西煌，一朵從血海漫出的末世黑蓮，宣告著鬼獄將禍世而出。

# 渡末莲

近月观音的鬼族真身，本为人族，后加入鬼族，成为鬼狱舞祭。蛰伏西煌佛界多时，身上留着瞒天过海的人血，故而蒙蔽了释至伽蓝等人。与八面鬼戎里应外合，更在关键之刻，以西儒至宝泣麟藏颖破胎藏妙法，圣衡者亡。佛域降血雨，鬼水漫西煌，一朵从血海漫出的末世黑莲，宣告著鬼狱将祸世而出。

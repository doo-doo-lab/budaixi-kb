# 别见黄花落

来自异国，自称穿梦旅行者的奇人，因具有梦牒之能，因而与具有字牒的盗天下有所交集，也因此涉入怪贩妖市之事务。个性古灵精怪，无法忍受别人对自己的忽视，是故在龙戬对别见黄花落下达永不录用妖市之臣的命令时，反而激起别见黄花落的斗志，只要是与龙戬、盗天下，甚至是整个怪贩妖市有关的事物，定要从中插手，证明自己的能力不容忽视。

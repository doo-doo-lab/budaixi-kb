# 破坏者（霹雳布袋戏中的角色）

================================================================================

破坏者，霹雳布袋戏中的角色。火宅佛狱派入苦境的第二波杀手，形貌恶煞丑陋，右臂为一把细长利刃，左臂顶端延绵一条铁链，铁链前端系著一颗人面铁球，是为破坏者的副体。暴力异常，在战斗中会发出如野兽般凄厉嘶吼，给人说不出的颤栗感。中文名破坏者配 音黄文择性 别男登场作品霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕门 派火宅佛狱上 司咒世主

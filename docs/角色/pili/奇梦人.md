# 奇梦人

来历神秘的奇异调香师，能散发异香，更能制造梦境。与兔爵士结伴同行，以梦境激励民心。为寻找消除邪染的方法，奇梦人来到充满悬疑气氛的北海灵洲。

### 相关记录

#### 霹雳超人气───调香师的旅行宝藏

疏影浮生奇梦人，在公开亭技惊四座的神秘新人物，以四界行旅的梦游者、复刻往昔的调香师自居，手持谬思牧杖，悬挂幻羽补梦网，左右常伴咖啡师兔爵士。作风神秘，来历与目的，尽如谜中之梦、梦中之谜，常以令人料想不到的方式解决问题，让人难以抓摸。当此汹涛乱世，将为武林惊起一枕奇梦！

本月超人气，有幸受邀来为奇梦人介绍一身低调华丽的行头，相信大家对这名出场就播放精选CD，聆听奇异耳机，饮用冲泡咖啡，表演奇幻魔术，让人脸上长出猫胡须的神秘新人物，多少感到有点好奇。在此，就利用超人气单元，介绍奇梦人的三样旅行宝藏，让大家先睹为快。

谬思牧杖：

总是一派轻松，泛著谜之微笑的形象背后，藏著不欲人知的苦难过往，所以道具师美乐帝认为，奇梦人必然有著非常人般的钢铁之心，故跳脱了谬思牧杖的名字含意，自由创作，设计了杖中间的雕像，呈现钢铁之心的概念。加上编剧在角色设定中，提到了奇梦人的名字含意，隐喻了在梦境徘徊的设计，所以道具师也藉著牧杖，参考奇幻冒险电影，赋予他在「寻找梦奇地」的希望，一个最后能让他平静的地方。而雕像也代表著这件事，代表著这场梦，一个梦境的体现，两旁的补梦网则象徵著这个梦终将实现。雕像后方有块三角型的图案，代表著成长，表示他经历一切，仍继续往前走。而中间的荷鲁斯之眼使他能看尽万物真实的一切。这三个圆形不仅表示他想守护的事情，也暗示著无限、团结、和谐的意思，并且三个圆形也呼应对应著三角型的三个点，使其所有的一切都能更加团结强大！

不可思议车：

由于编剧坚持奇梦人登场的排场，一定要有车又有杖。所以这次特别委请资深道具师父益诚师父，打造这台复合功能道具车，结合咖啡冲泡、计时、CD播放、打水、调香等多功能，以利呈现出角色的奇幻色彩之外，也用以发挥奇梦人调香师的作用。在师父的妙手巧思之下，将许多废弃的零组件，于此改造、重组后，化腐朽为神奇，成为奇梦人剧中最佳的辅助道具。

幻梦炼香组：

同样由道具师美乐帝打造的炼香组合，精美典雅，十分符合奇梦人的角色特质，乃奇梦人专用的炼香器具。剧中，奇梦人除了炼香等待神秘笔友大驾光临之外，也曾以香氛瓶调配贝斯特的诱惑配方，让渺渺、未萌脸上意外长出猫胡须，从而巧妙化解，双方欲争夺玄脉宝鉴的火花。

另外，关于奇梦人所戴之神秘耳麦，有何来历？未来，奇梦人又会以调香师的本事，解破武林多少迷津？关于奇梦人的故事，以及更多角色设计介绍，就有待后续月刊安排篇幅，再行详细介绍了，请喜欢奇梦人的戏迷朋友们，万勿错过。（月刊276期）

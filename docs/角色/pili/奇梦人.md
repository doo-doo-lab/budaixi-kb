# 奇夢人 (奇梦人)
================================================================================

奇夢人

來歷神秘的奇異調香師，能散發異香，更能製造夢境。與兔爵士結伴同行，以夢境激勵民心。為尋找消除邪染的方法，奇夢人來到充滿懸疑氣氛的北海靈洲。

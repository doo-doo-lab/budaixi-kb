# 辅天

灭轮三天，合创明圣天书，同时也兼具三界者身份，曾于上古灭轮圣战中牵制三途判，让赛迁成功驱逐万魔天指。与地冥至尊素来不睦，反对其女佛莲与燕渡关交往。在邪灵窜出狭道天关时，与慈航渡于还本道口留影九动，吓阻邪灵逃回灭境。

# 楚君儀 (楚君仪)
================================================================================

楚君儀

負責培訓儒門天下的各派之首，指導身為一派之主應有的氣度和格調，地位超然，有「儒門教母」之稱，飽讀詩書、通典曉律，注重禮儀，氣質高雅。

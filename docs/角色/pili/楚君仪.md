# 楚君仪 (楚君仪)
================================================================================

楚君仪

负责培训儒门天下的各派之首，指导身为一派之主应有的气度和格调，地位超然，有“儒门教母”之称，饱读诗书、通典晓律，注重礼仪，气质高雅。

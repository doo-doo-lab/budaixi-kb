# 百里抱信

女扮男装行走江湖的儒门女公子，明礼义、识大体，对素还真怀有倾慕之情。初期受同修蒙骗而加入合修会，曾由爱生恨设局囚禁素还真，但却也因素还真而倒戈背叛，甘愿为其牺牲奉献；更在世外书香逢难时挺身支撑大局，颇具胆识。其真面目则是气质出众、清新脱俗的美人。

### 角色经历

百里抱信为世外书香五儒生之一。当年远生道开会遇到素还真，其气度谈吐令百里抱信心仪不已，但由于素还真已心有所属，导致百里抱信因爱生恨，一出场便女扮男装的阻挠正道，再设计让素还真困于迷情之墓中，后来经过空劫的开导下，百里抱信放下了对素还真的恨，渐渐偏向了中原正道一方。

后来儒教复出，百里抱信回归儒教，经过一连串事件后，世外书香式微，儒教重担落在百里抱信肩头，直到号世阴令再出，世外书香灭亡，百里抱信恢复女装在无极殿卧底，后被玉天玑识破，和万缕丝一同被斩首。

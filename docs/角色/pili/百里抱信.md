# 百里抱信
================================================================================

百里抱信

女扮男装行走江湖的儒门女公子，明礼义、识大体，对素还真怀有倾慕之情。初期受同修蒙骗而加入合修会，曾由爱生恨设局囚禁素还真，但却也因素还真而倒戈背叛，甘愿为其牺牲奉献；更在世外书香逢难时挺身支撑大局，颇具胆识。其真面目则是气质出众、清新脱俗的美人。

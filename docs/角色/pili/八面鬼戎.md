# 八面鬼戎 (八面鬼戎)
================================================================================

八面鬼戎

鬼獄女帝后魃身邊的重臣「殞相」，多年前以「聖懷者」身份滲透西煌佛界，在被師弟釋至伽藍識破擊殺後，順勢竊據靈鷲舍利，化身「靈鷲聖諭」隱於虛空藏內，號令整個佛域。其個性狡猾多詐，善用人性，霸氣沈雄，手持伐罪冥杖，武力高強。

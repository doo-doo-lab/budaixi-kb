# 八面鬼戎

鬼狱女帝后魃身边的重臣“殒相”，多年前以“圣怀者”身份渗透西煌佛界，在被师弟释至伽蓝识破击杀后，顺势窃据灵鹫舍利，化身“灵鹫圣谕”隐于虚空藏内，号令整个佛域。其个性狡猾多诈，善用人性，霸气沈雄，手持伐罪冥杖，武力高强。

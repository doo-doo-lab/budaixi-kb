# 夸幻之父

================================================================================

霹雳布袋戏虚拟人物夸幻之父，霹雳布袋戏虚拟人物。非人非兽、非仙非妖，凌驾于万物的神秘生物，坐拥无数宝藏，善于洞悉人心弱点而加以利诱，阴险狡诈、冷酷残忍。多年前因强娶雨霖铃，结果为生命练习生所杀，头上的精灵三角、和四肢的幻甲，分别被雨霖铃炼制成神兵：格天三锋、帝弓十二虹与虎尾春冰。孰料，坠入炼火深渊的夸幻之父并未身亡，在多年后又开始进行新的计划与报复，利用圆公子设下古原争霸之局，以山海奇观利诱各方霸主竞相争斗。最后遭到圆公子率众反扑，魂体被凝聚成形，现出真身。

## 角色能力

武学夸元警幻、幻世七劫·【狰狞火、饕餮风、混沌殛、獓骃裂、灭蒙雪、殛火双流·双式并合、殛火裂·三式并合、四式并合】幻世七劫原是一种象征人间浩劫的毁灭意识，在夸幻之父脑中生根，以及不断被强化，方衍生出后来的灭世武学。

咒术三线勒魂规、一念之锁、异相大法所有物十二片幻甲（帝弓十二虹、虎尾春冰、变形单锋·狮头宝刀铸造材料）、精灵三角（格天三锋炼制材料）、定情丹（乱世狂刀→巧天工→圆公子服下）、《玉玺之命》（精灵枪法枪谱，赠予天剑老人）、寒澪玉（给予任平生）、赦身镜、戒魅刃、锁魂红索、三恒曌世山海奇观宝物：《登仙录》、《黑死薄》、《冥鸿残章》（只有三页）、《灵鼍十三趾》、《释灵宝鉴》、《圣灵卷》（记载血亲寻灵之法）、逆转轮回丹、硫炎灵萜、续脉石、移心六叶、薰魂灵芝、蟠龙夜光胆、聚神玉髓、九五之盒、曙光之源、日月星三光镜、无缝天丝、无形神铁、超光灵珠、五龙补天石由来：古原之战传说中有万灵源头之称的精灵天下，为阻魔君统领的魔界祸世，由其中数脉主战派领导，于毕方山古原，与魔君决一死战。

绵延九九八十一天的焚世烽火，将战场烧成焦土，一时间血流成河、积骨成山，精与魔双方皆伤亡惨重。

就在天织一族的领导者禁城罂粟与魔君同时倒下那一刻，天降滂沱，大雨如同上苍之泪浇熄了战火，也将精与魔二方的遗骨，并同所有的神兵魔器、奇珍异宝一同埋没洪荒，帝诏之主与阙九重也就此失落，只留下那诸神之缨。

山海奇观与五大秘窟的宝物大部分来自于此，多年以后，夸幻之父以毕方山古原埋葬无数的仙魔异宝，建立了山海奇观，再以他拥有的秘藏，另建五大秘窟。

荒诞之始宝物：孤峭天引、《单锋剑谱》（赠予沽命师）荒芜禁窟宝物：兽妖焚、蒙昧圣卉污山尽头宝物：如意神虹（诸神之缨）驼尸林穴宝物：《搜奇录》、凝晶石花

## 人际关系

人际目录人际关系前身：浩星探龙蜕变：寄昙说仇敌：黄钟、青蚨、冰壶、韫玉、鱼美人、圆公子、巧天工、恶来、天织主、战殟爵、寒武纪、逆神旸部属：钡可汗、荒唐（夸幻异兽，离世洞天守护者）、污山女萝、神行百里（污山尽头守护者）、战殟爵（驼尸林穴守护者）、夕兔、虎姑婆交易：天剑老人、任平生、纵横子、沽命师、解锋镝、鼋无极、君凰雪灵、醉古夫、墨倾池相关：天迹、地冥、人觉、鬼麒主、巧天工、生命练习生、红尘雪、乱世狂刀、忘潇然、赦天琴箕、圣君士、玉梁皇、枯半身、楚天行、剑咫尺所发便当：啸风生、居木雁、倾君罍、夜蜚人际简介生命练习生受芙女所托，生命练习生诛杀夸幻之父，斩下精灵三角，成为夸幻之父的仇敌，也因为遇见了琥珀，人生又重新与夸幻之父连结，然而，红尘雪刺来的那枪，引动出人意料的命运，神魔不许之命格，还会对生命练习生与红尘雪之间，带来什么意外变化。

棋邪·纵横子一时失策入了套局，让胞妹沦为棋下赌注，而引发一连串后续事件的纵横子，本欲营救胞妹，却无端消失，徒留下纵横峰上被削断“让”字的山壁。

究竟被削去的让字，有何蕴含之意。

纵横子的消失，将为未来的武林，带来何等天机。

在局势丕变后的未来武林，纵横子又将如何运筹帷幄。

炼青冥·雨霖铃生活悠哉的雨霖铃，因为大哥的一局败棋，差一点断送一生幸福，也就此与夸幻之父结下不解之仇，经过许多波折，终于平安去到远方，真是可喜可贺，然而芙蓉铸客流传于世的作品，也许仍然会对夸幻之父展开最致命的终极对决。

有生之莲·解锋镝解锋镝与夸幻之父合作，阻止圆公子等人对夸幻之父痛下杀手，看得出来解锋镝的目标是在长远之后。

夸幻之父也知道自己对解锋镝来说还有价值，当这段互相利用的关系，画下句点之时，应该就是真相大白的时候了。

流月亮川·琥珀来自污山尽头下，流月亮川的琥珀石，污山女萝依照光螈计划内容，让琥珀变化成半人半猫。

污山尽头是夸幻之父秘窟之一，莫非光螈计划是夸幻之父安排？

但感觉污山女萝不像外表那样单纯，这其中又有何离奇内幕。

湛卢无方·圆公子闹海凶物鼋无极，在夸幻之父异相大法的施恩下，从原本的丑陋外表，变成潇洒俊美的圆公子，因此配合主持古原争霸，但是夸幻之父的诸多限制、控制，以及阴错阳差下与鱼美人的相恋，致使圆公子起了反扑夸幻之心，双方因此反目成仇。

然与患天常的一场宿命对决，竟使圆公子的命运急转直下，与曼鲤两人感情备受考验。

鱼美人·曼鲤弄假成真，原本对圆公子抱持愤恨之心的鱼美人，心情慢慢改变了，她渴望的幸福即将到来，眼看就要安心的与圆公子建立一个美满家庭，但圆公子的仇敌从来就不会放手，鱼美人还能陪伴圆公子走多久。

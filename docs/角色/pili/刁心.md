# 刁心

魑魔驾前三公之首，最为器重信赖的心腹军师，其人足智多谋，但作风神秘，隐身幕后擘画局势。实乃天魔所派之卧底，曾化身白衣人破坏魑魔行动，后在群侠攻打血肉长城时，临阵倒戈反叛，欲与魑魔同归于尽。

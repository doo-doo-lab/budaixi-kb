# 公孙月

================================================================================

霹雳布袋戏虚拟人物公孙月，霹雳布袋戏虚拟人物。女扮男装的俊美公子，灵气逼人，聪慧超凡、善于审时度势，极擅捕捉人心弱点以占据优势，虽正邪难辨、立场不明，但本性善良。与阴川蝴蝶君关系暧昧、交情颇深。

## 剑随风人物生平

【 霹雳皇朝之龙城圣影 】时期公孙月阴川蝴蝶君爱慕之人，两人为一对欢喜冤家，平常喜爱捉弄蝴蝶君，曾有一段不堪回首的血腥过往，与地理司、邓九五，东方鼎立、章袤君等人为结拜兄弟，退出兄弟之计划后，结识了六丑废人支离疏。

在素还真观看地理司与三教怪人大战之时神秘出现，与素还真打赌地理司与三教怪人一战，双方不分胜负，后随素还真前往琉璃仙境一叙，并向素还真推荐六丑废人，并在琉璃仙境与屈世途下棋解闷。

在素还真回来后，告知公孙月一莲托生品在瀚海原始林的消息，公孙月明白此乃素还真为难六丑废人之举动，遂窃笑离去，并丢下一条写着月字的手巾给素还真，其实是暗示六丑废人便是月才子谈无欲。

公孙月前往神之社告诉六丑废人，素还真告诉自己，一莲托生品在瀚海原始林之中，并说自己会替六丑废人好好宣传这一莲托生品。

之后收到素还真信函，得知蝴蝶君因自己送手巾给素还真而吃醋，便在蝴蝶君准备对素还真动手时现身阻止，更直言若素还真被杀则两人今生无缘，使得蝴蝶君不敢对素还真动手，公孙月更在临走前说蝴蝶君媳妇脸，大大打击到蝴蝶君的自尊心。

在江畔欣赏风景时，秦假仙前来告知不望尘寰之事，明白蝴蝶君正用蝴蝶监看自己的公孙月，便刻意说若有人挺身而出对付不望尘寰连自己都会欣赏他，骗得蝴蝶君急匆匆跑去对付不望尘寰。

与蝴蝶君一同找到不望尘寰，在蝴蝶君出手帮无量佛尊对付不望尘寰时，见不望尘寰似乎要使出金银双绝掌，便连忙出手发出气功冲散战圈，并劝无量佛尊另寻方法帮弟子报仇。

公孙月深怕蝴蝶君因为买卖被自己打坏会不高兴，主动说是怕蝴蝶君有危险才出手帮助，岂料蝴蝶君一听，反而开心公孙月首度关心自己，便兴高采烈离去，留下哭笑不得的公孙月。

由于数度帮助素还真、六丑废人等，被突然出现的五弟章袤君警告，公孙月表明立场，不与兄弟为敌，也不与兄弟合流，而后两人一同回浮光掠影的小屋中谈心、下棋，却意外造成蝴蝶君误会而贸然闯入，公孙月连番追问蝴蝶君之时，也得知了蝴蝶君收到人邪挑战信之事。【 霹雳剑踪 】时期章袤君前来告知大哥地理司被杀，不望尘寰亦亡，要公孙月应帮助兄弟复仇，但公孙月断然拒绝后，遭到章袤君的警告，公孙月怅然若失想到蝴蝶君，便前往蝴蝶谷探望，闲聊一番后回返浮光掠影，就在圣踪被打成金人后，公孙月也被邓九五以金银双绝掌打成金像。

在蝴蝶君请人邪一剑封禅协助后，公孙月的金像被人邪的剑气解封而脱困，从前来探望的章袤君口中得知蝴蝶君与一剑封禅之决斗，眼见无法阻止蝴蝶君的行动，公孙月遂离开蝴蝶谷，让蝴蝶君无心与人邪决斗而阻止了战局。

于武林闲晃时被鬼祚师发现，听鬼祚师之劝返回蝴蝶谷，但因之前蝴蝶君被章袤君捉弄，而公孙月恰巧回来蝴蝶谷，开门之时却让蝴蝶君误以为是再次的捉弄而一拳打出，却阴错阳差的打中公孙月，难以置信的尴尬情况使蝴蝶君赶紧将门关上，公孙月等待许久后生动开门，却见屋内有一大洞，此时蝴蝶君自外而回，刻意装作什么都不知道，还信誓旦旦要帮公孙月报一拳之仇，公孙月眼见蝴蝶君竟装傻至此，又好气又好笑也不再追究。

在蝴蝶君与人邪一剑封禅真正对决之时，眼见两人越杀越狂，非分出生死不可，公孙月遂在最终一招之前跳入战圈，发招打向人邪，致使人邪觉得兴致全失而离去。

之后蝴蝶君信守承诺帮鬼祚师翻译“宁暗血辩”，公孙月闲来翻看“宁暗血辩”译本，却发现此书将会为武林带来红祸，便想藉着与蝴蝶君退隐来阻止蝴蝶君继续翻译，但蝴蝶君却执着要将“宁暗血辩”翻译完成，因此在“宁暗血辩”翻译完成之时，公孙月见剑子仙迹、疏楼龙宿前来，便配合两人之计划·，与剑子仙迹一同带走“宁暗血辩”及翻译本，并留下一信要蝴蝶君立志做大事后便离开了蝴蝶谷。

眼见蝴蝶君被自己刺激到要前去挑战剑邪，公孙月蒙面阻拦蝴蝶君，却再度被蝴蝶君意外打伤，最后蝴蝶君乖乖前来认错，两人又结伴而行，得知素还真被金封后，公孙月再度与秦假仙一搭一唱，刺激蝴蝶君去琉璃仙境领导正道为中原出力，但造成日后章袤君前来问罪，质疑公孙月不该煽动蝴蝶君协助正道，两人争论之时，公孙月听到章袤君提到自己以往的残暴行径，不禁一时动怒，但也随即冷静，更劝章袤君及早退出武林，但章袤君却直言东方鼎立已下最后通牒，双方谈话毫无交集，章袤君更言从此划清界线。

而后得知章袤君之死，公孙月前往吊祭，但再度对地理司、东方鼎立重申退隐之意。

公孙月公孙月与蝴蝶君帮助六丑废人、剑邪闯入黄泉之都救出人邪一剑封禅，并与蝴蝶君带着人邪一剑封禅前往鸿莲寺，并在鸿莲寺中得知人邪、剑邪之过去，岂料人邪突然化成吞佛童子，毁灭整个鸿莲寺，公孙月眼见鸿莲寺被毁，怒而攻向吞佛童子，吞佛童子以声东击西之法离开现场。

公孙月与蝴蝶君前往无欲天拜访复出的谈无欲，将吞佛童子现身之事告知，也得知地理司身亡之事。

回到浮光掠影后，想到结拜兄弟地理司、章袤君相继身亡，公孙月本为阻止兄弟为恶而协助正道，但不仅无法阻止兄弟的行动，更导致地理司等人身亡，公孙月遂陷入深深的自责、愧疚中，此时见到以往与自己有仇的众多杀手寻仇而来，更直呼自己的本名（黄泉赎夜姬），公孙月一时失去理智杀死来犯的所有杀手，更回想起以往杀人的感觉，幸而及时被蝴蝶君喝阻而恢复神智。【 霹雳兵燹之刀戟戡魔录 】时期在东方鼎立前来探望时，公孙月遭蛊皇利用东方鼎立隔空所下的尸蛊所控制，前往忠烈府杀死忠烈王，因此遭到众多仇家追杀，公孙月也因过多的杀戮而逐渐起了杀性，但及时被羽人非獍的二胡声给安抚，被羽人非獍告知蝴蝶君为她挺身担下罪责遭逼杀后，及时赶到解救蝴蝶君。

公孙月带着羽人非獍的六翼风铃信物，与重伤的蝴蝶君前去“笑蓬莱”藏身，并得惠比寿医治取出尸蛊，更假扮成店小二小岳在笑蓬莱服务，也结识了色无极。

在羽人非獍为她及蝴蝶君开脱嫌疑后，与蝴蝶君两人离去，并与喜欢蝴蝶君的色无极成为朋友。

拜访谈无欲，并在色无极的帮助下，寻得谈无欲需要的太古神兽。

因杀死忠烈王而被秋阙主少要求，前往罪恶坑赎罪，寻找应江潮以询问珠遗公主下落，公孙月一口答应，凛然无惧的进入罪恶坑，并通过检验加入罪恶坑组织。

于罪恶坑认识月不全孤独缺，被教导生活在罪恶坑的规则，在见过狂龙一声笑后，提出挑战应江潮的要求，于决斗中打败应江潮，却无法问出珠遗公主下落，史被狂龙逼迫吃下应江潮眼珠，公孙月越来越难以忍受，本欲利用深夜离去，但被孤独缺劝阻而留下（罪恶坑规矩，离开邪恶坑便是死路一条）。

后被孤独缺以执行任务之需带出，并代为传话要秋阙主少前去找孤独缺。

经孤独缺告知消息后，前往平水窟找到珠遗公主遗体，但见燕归人守护在旁，遂答应燕归人要取来凝碧宙，以保存珠遗公主的遗体。

公孙月与蝴蝶君、色无极一同找寻凝碧宙，在金包银的指点下，前往烟霞谷寻找姥无艳，但姥无艳善于用毒，使得公孙月等人无法取得凝碧宙，最后秦假仙请出恨不逢协助顺利取得凝碧宙，公孙月将凝碧宙交给燕归人，但燕归人却突然抱着珠遗公主遗体奔离，让公孙月追赶不及。【 霹雳兵燹之刀戟戡魔录2 】时期公孙月与蝴蝶君追上燕归人后，质疑燕归人毁约，但被蝴蝶君劝离，在别无办法的情况下，答应蝴蝶君的意见，送还祉牙国假的珠遗公主遗体，也算顺利完成当初秋阙主少的请托。

后决定与蝴蝶君、色无极返回蝴蝶君的故乡退隐，岂料在启程前竟见到孤独缺前来杀死色无极，公孙月亦在观看孤独缺与蝴蝶君决战时被孤独缺所杀，但其实孤独缺并没真下杀手，乃刻意误导羽人非獍，最后蝴蝶君安然带着公孙月、色无极回到海外故乡一同退隐。【 霹雳天命之仙魔鏖锋 】时期和阴川蝴蝶君携女儿蝶小月一同回中原游览，前往无欲天探望好友谈无欲，并劝说蝴蝶君接下玄武异谱，后因色无极的书信而先行一步回蝴蝶国。

临行前叮嘱蝴蝶君照看好女儿，否则回家跪算盘。

不料在海上遭遇大雾，漂流至示流岛，随之意识受控，成为邪狱明王的棋子。

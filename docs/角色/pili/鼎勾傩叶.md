# 鼎勾儺葉 (鼎勾傩叶)
================================================================================

鼎勾儺葉

葉口大軍儺葉部司寇，現身於四曲狹道一役，與午咸、揚贊支援執首猊戩，對上臥江子等三人。後於葉口月人與中原對決的比試中出賽，在牢籠內與杜一葦生死搏鬥，結果不敵神秘莫測的杜一葦。

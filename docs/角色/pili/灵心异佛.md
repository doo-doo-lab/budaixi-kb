# 灵心异佛 (灵心异佛)
================================================================================

灵心异佛

百世经纶一页书之徒，将近得到之高僧，心悬苍生，本着救苦救难之心慈悲济世，初期依附在秦假仙之身暗中行事。身负天虎八将宿命，同时也是八卦人头颅人选，最后为救素还真而自愿牺牲。灵心异佛之死也牵动一页书涉入江湖。

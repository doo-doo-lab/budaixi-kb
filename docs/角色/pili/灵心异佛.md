# 灵心异佛

百世经纶一页书之徒，将近得到之高僧，心悬苍生，本着救苦救难之心慈悲济世，初期依附在秦假仙之身暗中行事。身负天虎八将宿命，同时也是八卦人头颅人选，最后为救素还真而自愿牺牲。灵心异佛之死也牵动一页书涉入江湖。

## 来自百度百科的补充

灵心异佛是百世经纶一页书之徒，天虎八将中的最强者，身负天虎八将宿命，带领天虎八将对抗魔龙八奇。灵心异佛初期依附在秦假仙之身暗中行事，寄体在秦假仙身上以让魔龙八奇无目标可循。作为八卦人头颅人选，灵心异佛最后为救素还真而自愿牺牲，成就八卦人头颅。

灵心异佛是一页书之徒，天虎八将中的最强者，性格充满智慧，圆融有礼，心悬苍生。

灵心异佛为一页书之徒，天虎八将中的最强者，为对抗魔龙八奇，初期寄体在武林名人秦假仙身上行动，以此让魔龙八奇无目标可循。后在荫尸人无意提点下，一改作风，主动救援同志。曾出手承受南宫取的雄厚掌力救下八面狼姬，并以佛门秘招“金刚降魔印”击退南宫取。之后更为了不让太黄君知道南宫取的下落，硬受了波幻迷掌而受重伤，不得已离开秦假仙，前往琉璃仙境疗伤。

素还真见状请秦假仙找寻练有菩萨印之人，最终命七天练成了菩萨印第十式。因制作八卦人头颅需要，素还真与灵心异佛互相争着牺牲自己，以用菩萨印第十式打在自愿者身上后散出的余劲来救治对方。最终，命七天将菩萨印第十式打在灵心异佛身上，灵心异佛为救素还真而自愿牺牲，成就八卦人头颅，得大解脱。

灵心异佛的牺牲成就了制作八卦人头颅的条件，推动了后续剧情。其为了苍生大义而舍身成仁的行为，体现了为奉献的精神。死亡对灵心异佛来说是解脱，也是其成就天虎八将天命的最终站。

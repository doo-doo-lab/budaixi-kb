# 厄祸（霹雳布袋戏虚拟人物）

================================================================================

霹雳布袋戏虚拟人物。千古传说的存在，具有神秘莫测的色彩，就连八歧邪神本身都对厄祸存在疑惑。一直到狱婪铤而走险，毁掉自身的躯体，终于让厄祸揭开神秘的面纱。身为诸神噩梦，具有无与伦比空前绝后的无敌破坏力，也使得神州群侠陷入被屠戮的恶梦。身为万恶之初，破坏神的存在，导致三界失衡，哀鸿遍野，也使得古今英豪会聚，开启一场有史以来最壮烈的圣战。中文名厄祸别 名破坏神配 音黄文择、马国骁（台配-破邪传）、图特哈蒙（（普通话-霹雳惊涛））性 别男登场作品霹雳天命之战祸邪神Ⅱ破邪传登场作品霹雳惊涛霹雳天越霹雳邪章之道劫龙战生 日2018年06月08日（初登场）编 剧廖明治

## 邪神冥殿人物设计

千年传说·诸神噩梦破坏神厄祸。凌驾在八歧邪神七条魂魄之上，最神秘的存在。最初七原罪出现之前便已存在的传说，具有永世不朽的力量。对狱婪等七魂来说，厄祸的传说，一直是七人所忌惮的存在，因为破坏神的传说，一直凌驾在七人之上，而且这个存在，似乎一直以虎视眈眈的姿态，看着七条魂魄的厮杀，但却默默与七人共存，却始终没人知道真相为何。一直到狱婪思索出破破坏神存在的真相，以及七人之中隐藏的秘密，才让神秘的破坏神现出真面目。而这样的存在，也是狱婪等七人所怨恨的目标，因为厄祸的存在，万恶方有源泉，其于七魂只是厄祸用来操控玩弄的替代品。也是因为如此，才让狱婪感觉到邪神力量的不完整，因而希望将力量整合为一，凌驾破坏神之上，成为真正完整的八歧邪神。厄祸之始·万恶之初千古传说的厄祸，融合了枭、天回宗、夜诛、欲织心、狱婪，殁王、无间常暗皇七魂所诞生的存在，以破坏神为号，身为诸神恶梦，具有无与伦比、空前绝后的破坏力。甫一登场，便展现超越众人想像的恐怖实力，被称之为真正的八岐邪神。他所拥有的令人畏惧的力量和之前的八岐邪神有天壤之别。实力之强极度恐怖，一招便重创一页书、剑子仙迹、青阳子、莫召奴以及古原八人等，甚至只轻轻接触都能突破帝龙胤的护体龙气造成内伤，实力之强堪称当世无敌。破坏神厄祸远在上古就降临了苦境大地，并留下恐怖的传说。当时破坏神厄祸掀起三次强烈的银宇风暴，席卷整个苦境大地。只是因为，当时银宇风暴后大部分人都已经被厄祸所杀。所以了解真相的人少之又少。而对于破坏神的降临，由厄祸自己所说，乃是被人类呼唤而来。

## 背景来历

厄祸来自虚无，一切的起点与终点。存在于传说，诞生于苦境大地上，神秘莫测的存在。破坏神厄祸在混沌之初，一切还未诞生之前就已经存在，既无性别也无灵魂，连生灵都称不上的它，也因此是相对于永恒的存在。因为厄祸是没有真正的实体和灵魂的存在，本质更像是某种意识的具象化，它这种特殊的存在，也无法在任何方式下被消灭。表面上看，它的力量与狱婪等七人很相似，都是最阴暗的一面所化，但本质上却是天差地别。八恶道尽归一体，七原罪始于黑暗。从混沌初开，光明与黑暗都是共同存在，而破坏神厄祸既是黑暗和灾祸开始在虚无中逐渐理性化才诞生的存在。可以说厄祸既是属于绝对的邪恶，因为厄祸的存在，万恶方有源泉。破坏神厄祸掌握著黑暗世界的法则，既是七原罪的源头，也是世间所有罪恶与灾祸的根源，具有空前节后，无以伦比的无敌破坏力。所以，从这方面来说，破坏神厄祸也是比八岐邪神狱婪等七魂还危险的存在。

## 性格

本来代表了绝对之恶，但并不等于邪恶。从某种意义上可以认为是来自虚无的某种存在，因为存在等同于虚无故而对破坏神厄祸而言，无论神、魔、妖、人，全部都是他足下践踏与双手毁灭破坏的对象。性格相对来说乃是一个没有喜怒哀乐、生死观念的，一个毫无野心的存在；想做什么，就做什么，谁生谁死对它来说是无意义的。

## 人物能力

武学：诛神之光、永世·俱灭、破坏之光、诸神之恶·三界同毁功体正邪不破之躯乃诸神坟场无数绝世遗骨所造，众天邪王·神愆以圣佛白羽洗涤万千绝骨，又以自身邪力引万千魔骸，以自身之能强融正邪双骨，引爆天地至极之力，催生前所未有的毁灭之能，造就正邪不破之躯。融合了历代所有强者的力量。八龙神天护（护体气罩）同时使用八恶道的魂魄，形成绝对防御的形态。特殊能力破坏神厄祸掌握罪恶之源，七大原罪为其最强大的武器。可以通过吸取所有存在的负面怨念，近而转化成自我无穷尽的力量，这也是其所向无敌的原因。武器绝望之心由十万以上万千无辜破碎的心灵与冤魂，所造就的空前绝后的魔兵，可转化邪能，恢复伤势。最终被一页书手持希望之光击破。

## 人物记录

1，正当八歧邪神元神被消灭之际，此时竟见七道邪龙之气，在空中盘旋，随后合而为一，风雷齐动，魔棺现形。（合而为一的邪气进入魔棺）随之，末日再现，就在剑子仙迹青阳子众人惊愕之时，传闻中，诸神噩梦，千年传说中的破坏神厄祸，于焉降临了。（《霹雳天命之战祸邪神2破邪传》第45话旁白）2，第八条魂魄的出现，代表我们一开始，就中了计策，其实我们未料到，其实第八条魂魄尚未诞生，只有七条魂魄皆亡，方能合而为一。（《霹雳天命之战祸邪神2破邪传》第45话莫召奴对话）3.当初近神人一页书与厄祸之战，厄祸表面上虽无大碍，实则元神已被毁去九成，为求自保只能步入丹青地狱图，避免形神俱灭。而后 ，厄祸再度找上太曦寻求合作，解除咒印，而厄祸利用八歧邪神，设下朱雀灵乡之局，欲吸收莫召奴，莫召奴早就让风随行奔赴东瀛，请人（军神）协助脱困。（出自《霹雳兵峰决玄象裂变》第39章太曦对话）4.厄祸毫无弱点。（神愆所评，战祸邪神Ⅱ第47章）5.厄祸来自虚无，一切的起点与终点。乃是诸神噩梦，具有空前绝后、天下无敌的力量。（出自超级霹雳会人物总结）

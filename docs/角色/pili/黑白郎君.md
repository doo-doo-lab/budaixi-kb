# 黑白郎君 (黑白郎君)
================================================================================

黑白郎君

狂傲不羁、极为自负的铮铮铁汉，四处挑战武林中盛名的角色，以别人的失败为快乐，快意恩仇、置生死于度外，有过人的胆识、气魄，乃布袋戏当中最富盛名的角色之一。

马车幽灵影，潇洒一郎君。

别人的失败就是我的快乐！

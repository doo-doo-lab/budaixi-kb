# 黑白郎君 (黑白郎君)
================================================================================

黑白郎君

狂傲不羈、極為自負的錚錚鐵漢，四處挑戰武林中盛名的角色，以別人的失敗為快樂，快意恩仇、置生死於度外，有過人的膽識、氣魄，乃布袋戲當中最富盛名的角色之一。

傲笑天地間，黑白兩不分；
馬車幽靈影，瀟灑一郎君。

名言

別人的失敗就是我的快樂！

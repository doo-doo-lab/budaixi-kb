# 千叶先生

================================================================================

霹雳布袋戏中的角色千叶先生，霹雳布袋戏中的角色，初登场于《霹雳英雄榜之江湖血路》第2集。白发银须、禅定睿智的老者，乃佛门莲佛子诈死所化，师从净瓶尊者。莲佛子曾与蘅佛子、昙佛子并称佛门三个高人。对任何人都抱以宽容之心，贯彻吾不入地狱谁入地狱的胸襟。曾开释傲笑红尘，甚至为感化入魔的蘅佛子而以死相谏。昙佛子遭暗杀后，将秘籍交给莲佛子，莲佛子也掏出一本秘籍交给徒弟后远走高飞。中文名千叶先生配 音黄文择性 别男登场作品霹雳英雄榜之江湖血路来 自佛界身 份莲佛子根据地明台树本尊雕偶师徐柄垣出场集数12集

## 张曼荼罗主要经历

早年经历久远之前，佛门有三位高人，分别为莲佛子、蘅佛子与昙佛子。昙佛子遭暗杀身亡，临死前将一本秘籍交给莲佛子。莲佛子随后亦将自己的一本秘籍交给徒弟，而后远走。莲佛子与昙佛子所持有的秘籍，均源自一位未具名的高人。登场与退场千叶先生初登场于《霹雳英雄榜之江湖血路》第2集。其退场于《霹雳英雄榜之江湖血路》第13集，死于蘅佛子与圣法之手。

千葉(日本城市)

千葉，是日本三大都市圈之一東京都市圈的重要城市，日本本州東南部重要工業港市，千葉縣首府。位於東京灣東北岸。面積269.8平方公里，人口97.5萬(2017年)，2014年人口首次超過北九州市成為日本人口第13多的城市。地處東京灣沿岸平原，都川及其支流葮川流經市區。夏季濕潤高溫，冬季乾燥少雪。12-19世紀中葉是聯繫江戶和東京灣沿岸地區的中轉商業港。1873年為縣政府所在地。1921年設市。

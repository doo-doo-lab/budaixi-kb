# 千叶先生

霹雳布袋戏中的角色，初登场于《霹雳英雄榜之江湖血路》第2集。白发银须、禅定睿智的老者，乃佛门莲佛子诈死所化，师从净瓶尊者。莲佛子曾与蘅佛子、昙佛子并称佛门三个高人。对任何人都抱以宽容之心，贯彻吾不入地狱谁入地狱的胸襟。曾开释傲笑红尘，甚至为感化入魔的蘅佛子而以死相谏。昙佛子遭暗杀后，将秘籍交给莲佛子，莲佛子也掏出一本秘籍交给徒弟后远走高飞。

## 角色经历

早年经历久远之前，佛门有三位高人，分别为莲佛子、蘅佛子与昙佛子。昙佛子遭暗杀身亡，临死前将一本秘籍交给莲佛子。莲佛子随后亦将自己的一本秘籍交给徒弟，而后远走。莲佛子与昙佛子所持有的秘籍，均源自一位未具名的高人。

登场与退场千叶先生初登场于《霹雳英雄榜之江湖血路》第2集。其退场于《霹雳英雄榜之江湖血路》第13集，死于蘅佛子与圣法之手。

**千叶传奇**为霹雳布袋戏中的虚拟人物，登场于霹雳天启，至今仍活跃中。日盲族传唱千年的太阳之子，由黑莲孕化而生，貌似清香白莲素还真，拥有超凡智慧与高深实力，且能过目不忘，学习所有技艺皆能立刻驾轻就熟，手腕圆滑，与各方势力斡旋较劲。千叶传奇的降临，势将改变整个日盲族的历史。

# 色无极

笑蓬莱两大红牌之一，体态轻盈妖娆，娇俏动人，乃一长袖善舞、口齿伶俐的绝代舞伎；虽处在酒色之地，却洁身自爱，对感情专一，为爱情付出一切也不足惜。

## 主要经历

色无极在笑蓬莱做舞姬时，每次凤飘飘出场，她就趴在窗户外头看，看出凤飘飘是男人扮的，并因少女心性活泼好奇，跑去把凤飘飘摸了个遍。

为了让色无极留下，公孙月指点她去抓了一只神龟送给皮鼓师，色无极为证明自己并协助公孙月参与捕获神龟。

色无极触发“罪恶坑”任务，为公孙月奔赴罪恶坑赎罪起到牵线作用；以照顾受伤的蝴蝶君为条件，与公孙月达成协议留下；在照顾蝴蝶君的过程中，对其感情升华，情根深种，并在烟霞谷因误食春药而追逐蝴蝶君。

色无极跟随蝴蝶君与公孙月前往蝴蝶国，陪伴他们走完退隐之路，并见证了公孙月昏死与复苏的关键时刻；最终被蝴蝶君视为公孙月的妹妹，在蝴蝶国寻找自己的归宿。

## 人物关系（补充）

朋友包括公孙月与蝴蝶君。公孙月收色无极为妹妹，色无极是蝶月之恋的陪伴者与见证者。色无极曾单恋蝴蝶君，并一路追随、照顾他，最终被蝴蝶君视为妹妹。色无极是笑蓬莱的舞姬。

## 人物配乐

《无极之舞 -色无极献舞》此首曲子在后来在笑蓬莱赤云染为五色妖姬配乐时用过，当时称名字为《送君一曲相思断》

《武之无极 -色无极武戏曲》

两首配乐均收录于《霹雳兵燹之刀戟戡魔录 剧集原声带》（精选6）。

此外，与色无极相关的场景音乐《蝶舞凤飘》（凤飘飘场景曲）收录于《霹雳兵燹之刀戟戡魔录原声带》。

## 相关作品

色无极是霹雳布袋戏剧集《霹雳兵燹之刀戟戡魔录》中的人物。

## 人物影响

色无极是蝶月之恋的见证者，从笑蓬莱一路跟随至蝴蝶国，陪伴蝶月走完退隐之路。色无极触发了“罪恶坑”任务，为公孙月赎罪起了牵针引线的作用。色无极从对爱情的懵懂向往到深刻理解爱情真意。色无极性格外向、主动、有趣、智慧。

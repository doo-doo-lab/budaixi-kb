# 雅狄王
================================================================================

雅狄王

四魌界武冠传说，杀戮碎岛前任王，雄才大略，武学造诣深不可测，曾蝉联十一届四魌武魁，凝毕身所学写成十一本武典，锋芒毕露，却也对佛狱与慈光之塔造成莫大威胁，联手将之擒禁。雅狄王死前将武经散入虚空之举，也对各境局势投下不可预期的震撼弹。

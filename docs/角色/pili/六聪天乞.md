# 六聪天乞

九大奇人中的乞丐头，外表邋遢不起眼，却天生六耳，可听辩百里外之交谈，然生性贪财畏事，独守丐帮老巢万乞山，但同时也是黑榜七人之一，暗中擒捉盼梦圆、资助大鸿胪东山再起，伺机挑起中原动荡，好让东瀛有机可趁。

## 来自百度百科的补充

在《霹雳英雄榜之风起云涌二》中，百炼生将指示杀除愁月的密函通过忘年转交给六聪天乞，六聪天乞反阴百炼生，导致百炼生被无忌天子委托的傲笑红尘追杀，幸得八趾麒麟及时阻止，百炼生回到必杀组后，将六聪天乞作为第一个任务目标，并向八趾麒麟阐明六聪天乞是黑榜汉奸的事实。

# 六聪天乞 (六聪天乞)
================================================================================

六聪天乞

九大奇人中的乞丐头，外表邋遢不起眼，却天生六耳，可听辩百里外之交谈，然生性贪财畏事，独守丐帮老巢万乞山，但同时也是黑榜七人之一，暗中擒捉盼梦圆、资助大鸿胪东山再起，伺机挑起中原动荡，好让东瀛有机可趁。

# 萍山练峨眉

================================================================================

《霹雳兵燹之刀戟戡魔录II》中的角色萍山练峨眉是《霹雳兵燹之刀戟戡魔录II》中的角色，最接近仙道之高人，别称萍山云人、练云人，女性，长居萍山之巅。体质特异不能忍受凡世浊气。个性刚正不阿、稳重沉静、正邪分明。与弟狂龙一声笑有“萍山不落地，狂龙不出关”的约定。在道境大战中以道留萍踪打出魔君魔心，直到金八珍放出七彩云霓，才重入凡尘，击杀四先知重创魔界，约战魔君使其忌惮。因萍山即将落地，狂龙一声笑准备出关，练峨眉与狂龙一声笑之间的恩怨与萍山落地的关联成为剧情悬念。最终遭魔君和狂龙合击身亡。

**中文名**：萍山练峨眉

**登场作品**：《霹雳兵燹之刀戟戡魔录II》

**别称**：萍山云人、练云人

**性别**：女住 处萍山之巅

## 角色背景

萍山练峨眉是《霹雳兵燹之刀戟戡魔录II》中登场的角色，其角色音乐包括《峨眉萍踪》与《日出峨眉》（武曲）。

她体质特异，不能忍受凡世浊气，故长居萍山之巅。

与其弟狂龙一声笑之间存在深刻恩怨，双方曾立下约束‘萍山不落地，狂龙不出关’。

在剧中，因萍山即将落地，长居罪恶坑的狂龙一声笑遂准备出关。

名称：练峨眉萍山练峨眉诗号：山为萍，云为涛，绝逸红尘任涛涛。

云霞争变，风雨横天，绝逸清坐，一榻沧然。

登场：霹雳兵燹之刀戟戡魔录II第一集退场：霹雳兵燹之刀戟戡魔录II第二十一集(因金八珍被魔界控制偷换慕少艾所留丹药而遭魔君重创，自盖天灵而亡)兄弟：狂龙一声笑（弟）结义：金八珍朋友：号昆仑、蔺无双弟子：宫紫玄、金战战武学：道留萍踪、断萍殇、飞萍泻虹、天越萍踪、天化萍踪、仙者萍踪手持：玉如意脚踏：七彩云霓 萍山峨眉，最接近仙道之高人，以面罩半遮其脸，个性刚正不阿、稳重沉静、正邪分明。

武功高强，却体质特异，不能忍受凡世浊气，故长居萍山之巅，与其弟狂龙曾有约束，『萍山不落地，狂龙不出关』。

曾於道境大战当中，以道留萍踪打出魔君之魔心，直到金八珍放出七彩云霓，才重入凡尘，以一掌击杀四先知，重创魔界；

之後约战魔君，其惊人实力，让魔君深为忌惮；

在正道进攻瀚海时，出手阻挡魔君其众人得以全身而退；

并以惊天一掌直捣魔界心枢；

最後悟出杀魔君之法，积极安排刀戟戡魔一事。 後因狂龙以金八珍为胁而前往罪恶坑，却遭到魔君与狂龙的合击而身亡。

## 衍生作品

在2006年10月20日发行的《霹雳英雄音乐精选柒 刀戟戡魔录 II》音乐专辑中，收录了练峨眉的角色曲《峨眉萍踪》和武曲《日出峨眉》，该专辑由动脉音乐发行，条形码为4719862771107。

## 人际关系

练峨眉的兄弟是狂龙，两人曾有约束『萍山不落地，狂龙不出关』。

==生平==

**道界**一代女先天，修為已臻**登仙之境**，孤高皓潔，穩重沉靜，知天命、識天機，一心求得仙道，透知天理與道界循環。以救世之姿翩然現身，領導正道抗衡**異度魔界**，策劃**刀戟戡魔**之局。

以面罩半遮其臉，因一心修練登仙之境而長居**萍山**。

因緣際會的一次切磋比試下與曾在三境聯合比試中獲勝的**雲飄渺**藺無雙結為好友，明白藺無雙對自己的愛意與其弟狂龍一聲笑的畸戀後，因為被狂龍偷親臉頰，憤而拔起萍山而去，從此消聲匿跡許久。

曾在**聖域天座**與異度魔君閻魔旱魃大戰之中以一招「道流萍蹤」將魔君之魔心打出體外，後來便不見蹤影，從此被魔君視為生平勁敵。

再次踏足塵世時，因不適應凡間濁氣，導致功體無法發揮完全不能久戰，後因慕少艾特製藥丹，助練峨嵋能暫時恢復功體，狂龍以金八珍威脅而前往**罪惡坑**，不料卻遭魔君與狂龍的合擊。

因之前金八珍被魔界控制而把可以恢復功力的丹藥掉包成假貨，所以當練峨嵋氣力不繼服下丹藥時卻毫無功效，功體不全被仙者萍縱反噬重創，以致被魔君連續重創，最後自爆天靈而亡。

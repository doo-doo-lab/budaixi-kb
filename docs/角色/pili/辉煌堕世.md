# 辉煌堕世

霹雳布袋戏中的角色辉煌堕世是霹雳布袋戏中的角色，出自慈光之塔的贫士林，等级略逊于秀士林。一袭黑衣装束带有波斯色彩，能言善道，奉师尹之命与拔刀洗慧、一羽赐命陪同素还真返抵苦境，给予奥援，曾联手施以巧计制住阿修罗。在《霹雳经武纪之枭皇论战》中，为阻挡梵天脚步，辉煌堕世曾与叶小钗、拔刀洗慧以战阵包围一页书；为探查邪氛，与叶小钗进入留蝶梦土见到击珊瑚；还曾与一羽赐命敌对交战。

## 角色设定

- **名称**: 辉煌堕世辉煌堕世性别：男初登场：霹雳震寰宇之兵甲龙痕 第23集退场：霹雳经武纪之枭皇论战 第23集（功体被一羽赐命暂废，欲寻无衣师尹求得解药，被一刀偷袭，死于撒手慈悲）来自：四魌界

## 角色能力

武学：依智不依识·依识入地狱、堕世天火、无咎剑招·【动杀·咎】武器：天坠剑

## 经历

在《霹雳经武纪之枭皇论战》中，为阻挡梵天脚步，辉煌堕世与叶小钗、拔刀洗慧三人以战阵包围一页书，被一页书以如是我斩尽破阵式击败。此后，为探查不明邪氛，辉煌堕世与叶小钗在神秘刀客萧瑟引领下进入留蝶梦土，遇到了留蝶梦土之主飞碧凌渡击珊瑚。后来，为取得无咎剑招解方，辉煌堕世与一羽赐命敌对交战，最终被一羽赐命以七圣箭暂废功体。

## 角色关系

组织门派：慈光之塔上司：无衣师尹同伙：拔刀洗慧；一羽赐命合作：叶小钗相遇：击珊瑚

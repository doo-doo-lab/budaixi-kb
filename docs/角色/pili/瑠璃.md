# 瑠璃 (瑠璃)
================================================================================

瑠璃

琥珀王之長子，辰砂王爵之皇兄。性情傲沉，性喜以飛鷹自喻，對外常以驕傲姿態示人。瑠璃王爵在謀略、武藝、瞳術修為上，都在辰砂之上，故對於琥珀王昔日選擇將胞弟辰砂過繼給迦密王，成為王位繼承人候選一事，一直耿耿於懷，也對辰砂甚得鬼一法眼師厚愛一事，一直抱有醋意。唯獨孔雀公對瑠璃王爵青眼有加，寄予厚望。
在苦境出現不明瞳能之後，瑠璃王爵積極爭取以王輔身份，進入苦境調查，欲建立一番功業。

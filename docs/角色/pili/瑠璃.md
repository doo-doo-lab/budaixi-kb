# 瑠璃
================================================================================

瑠璃

琥珀王之长子，辰砂王爵之皇兄。性情傲沉，性喜以飞鹰自喻，对外常以骄傲姿态示人。瑠璃王爵在谋略、武艺、瞳术修为上，都在辰砂之上，故对于琥珀王昔日选择将胞弟辰砂过继给迦密王，成为王位继承人候选一事，一直耿耿于怀，也对辰砂甚得鬼一法眼师厚爱一事，一直抱有醋意。唯独孔雀公对瑠璃王爵青眼有加，寄予厚望。
在苦境出现不明瞳能之后，瑠璃王爵积极争取以王辅身份，进入苦境调查，欲建立一番功业。

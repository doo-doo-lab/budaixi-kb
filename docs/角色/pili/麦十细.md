# 麦十细
================================================================================

麦十细

外表像是一般的平凡卖货郎，实则深藏不露，身上所扛的杂货柜里面也装有许多神秘的东西。个性开朗风趣、乐观进取、关怀众生，与菩提界沙舟一字师为好友…

男

**退场**

霹雳封灵岛 第16集

**称号**

哗琳琅麦十细、杂细郎

**来自**

欲界第六天

身份

昙摩

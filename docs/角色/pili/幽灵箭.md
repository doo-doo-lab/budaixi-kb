# 潇湘子（霹雳布袋戏虚拟人物）

潇湘子，霹雳布袋戏虚拟人物，别名玉面圣尊，由黄文择配音。

初登场于《霹雳幽灵箭第一部》第25集，退场于《霹雳英雄榜》第5集（死于海殇君）。

身份为血道天宫二宫主、东瀛黑榜之千目王酋，来自西武林，根据地灯花台。

潇湘子白发持灯，擅于分析局势，因反对大宫主山涛君入侵中原策略闭关隐遁。

山涛君亡故后表面维持和平，暗中以无敌战龙图谋中原，最终功败垂成。

掌握武学血光凌霄、四方归元，持有《九龙菩提经》及无敌战龙外壳与龙心。

组织关系涵盖血道天宫、天外方界及东瀛黑榜，同修包括山涛君、劫无行等人，敌对势力涉及玉天玑、海殇君。

该角色在与中原各方势力缠斗中失败，最终被海殇君击杀。

其角色曲《潇湘子》收录于《霹雳英雄榜 剧集原声带》。

幽灵箭

幽灵箭是霹雳布袋戏中的虚拟武器，为一支银色长箭，箭身有螺旋纹路，箭头与箭簇均有皮毛包覆，由亢无后铸造，当前持有者为魔魁之女。该武器因魔魁祸乱武林而铸造，三教挑选三十六名高手精魂投入造骨炉，耗时一百零八天制成八支幽灵箭，后遭魔魁抢夺。铸造者亢无后因自责自废双手并前往大汗之野赎罪。魔魁战死后幽灵箭由其女继承，该箭可通过吸收死者脑波获得生命活性，魔魁之女曾操控其击杀大和居士，最终幽灵箭在完成任务后化为魔魁墓前石俑。

 事迹简述,登场剧集, 事迹简述当年魔魁势力如日中天，武林几无宁日，就连儒道释三教主也无法将他制服，遂下令雕匠亢无后制造一种能完全制魔定邪的武器，经过一番讨论，终于决定由三教各自挑选十二名高手参与造骨炉，搜集他们的精魂来铸造一种无形无影、却能收魂摄魄的“幽灵箭”。

整个炼制过程就在极度保密之下进行，三十六名精英投身造骨炉而牺牲，亢无后身负重任，日夜守着造骨炉，心力交瘁，经过了一百零八天，共铸造出八支幽灵箭，谁知甫出炉即遭魔魁所夺走，亢无后因内咎自责而自动要求到大汗之野赎罪，并且自废双手。

期间，三教主曾不断派人寻觅幽灵箭下落，却一无所获，殊不知失落的幽灵箭竟是落在魔魁之手，直到魔魁战死后便被魔魁之女带走。

幽灵箭之特点能接受魔魁之女的意识去杀人，吸收死者脑波可变成活动有生命的箭。

魔魁之女为顺利卧底齐天殿，首度动用魔魁遗物，以幽灵箭除去障碍大和居士，幽灵箭过穿大和头部却无留下伤痕，只是摄去大和脑波，大和瞬间灰化随风消散，幽灵箭飞入魔魁之墓前，变成一尊石俑。

此后，幽灵箭一度流落至方城之主手中，被其用于挑拨武林各方势力。

铸造者亢无后则隐居在大汗之野，因自责而自残双手，并曾将“无后弯刀”与“天雷罡剑”赠予他人。

为应对幽灵箭的威胁，圣贤诸曾带来能克制此箭的武器。

据亢无后透露，魔魁当年夺走的幽灵箭可能是假货，而真正能克制幽灵箭的秘宝“太极甲”，其制造尚需东岛（隐雾岛）神鹤佐木的“如意宝”。

# 潇湘子（霹雳布袋戏虚拟人物）

================================================================================

潇湘子，霹雳布袋戏虚拟人物，别名玉面圣尊，由黄文择配音。初登场于《霹雳幽灵箭第一部》第25集，退场于《霹雳英雄榜》第5集（死于海殇君）。身份为血道天宫二宫主、东瀛黑榜之千目王酋，来自西武林，根据地灯花台。潇湘子白发持灯，擅于分析局势，因反对大宫主山涛君入侵中原策略闭关隐遁。山涛君亡故后表面维持和平，暗中以无敌战龙图谋中原，最终功败垂成。掌握武学血光凌霄、四方归元，持有《九龙菩提经》及无敌战龙外壳与龙心。组织关系涵盖血道天宫、天外方界及东瀛黑榜，同修包括山涛君、劫无行等人，敌对势力涉及玉天玑、海殇君。该角色在与中原各方势力缠斗中失败，最终被海殇君击杀。其角色曲《潇湘子》收录于《霹雳英雄榜 剧集原声带》。中文名潇湘子别 名玉面圣尊配 音黄文择性 别男登场作品霹雳幽灵箭第一部霹雳外传之叶小钗传奇霹雳幽灵箭第二部登场作品霹雳英雄榜生 日十月廿五身 高178 cm身 份血道天宮二宮主、黑榜之千目王酋根据地灯花台本尊雕偶师徐炳垣人物编剧杨月卿、郑国政、周致忠出场集数32集

## 海殇君人物诗词

芳林新叶催陈木，流水前浪让后波，万古到今同此恨，闻琴泪尽欲如何。（霹雳幽灵箭1，24集，初登场所吟）霹雳会月刊第17期第42页 人物特写档案※注：典出李白《上李邕》：大鹏一日同风起，扶摇直上九万里。假令风歇时下来，犹能簸却沧溟水。世人见我恒殊调，闻余大言皆冷笑。宣父犹能畏后生，丈夫未可轻年少。而原典则是出於《庄子·逍遥游》：北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。鹏之背，不知其几千里也；怒而飞，其翼若垂天之云。是鸟也，海运则将徙於南冥。南冥者，天池也。《齐谐》者，志怪者也。《谐》之言曰：「鹏之徙於南冥也，水击三千里，搏扶摇而上者九万里，去以六月息者也。」（下略）

幽靈箭

幽靈箭是霹靂布袋戲中的虛擬武器，為一支銀色長箭，箭身有螺旋紋路，箭頭與箭簇均有皮毛包覆，由亢無後鑄造，當前持有者為魔魁之女。該武器因魔魁禍亂武林而鑄造，三教挑選三十六名高手精魂投入造骨爐，耗時一百零八天製成八支幽靈箭，後遭魔魁搶奪。鑄造者亢無後因自責自廢雙手並前往大汗之野贖罪。魔魁戰死後幽靈箭由其女繼承，該箭可通過吸收死者腦波獲得生命活性，魔魁之女曾操控其擊殺大和居士，最終幽靈箭在完成任務後化為魔魁墓前石俑。

基本介紹
- **中文名**: 幽靈箭持有者：魔魁之女鑄造者：亢無後出處：霹靂布袋戲類型：虛擬武器
 事跡簡述,登場劇集, 事跡簡述當年魔魁勢力如日中天，武林幾無寧日，就連儒道釋三教主也無法將他制服，遂下令雕匠亢無後製造一種能完全制魔定邪的武器，經過一番討論，終於決定由三教各自挑選十二名高手參與造骨爐，蒐集他們的精魂來鑄造一種無形無影、卻能收魂攝魄的「幽靈箭」。整個煉製過程就在極度保密之下進行，三十六名精英投身造骨爐而犧牲，亢無後身負重任，日夜守著造骨爐，心力交瘁，經過了一百零八天，共鑄造出八支幽靈箭，誰知甫出爐即遭魔魁所奪走，亢無後因內咎自責而自動要求到大汗之野贖罪，並且自廢雙手。期間，三教主曾不斷派人尋覓幽靈箭下落，卻一無所獲，殊不知失落的幽靈箭竟是落在魔魁之手，直到魔魁戰死後便被魔魁之女帶走。幽靈箭之特點能接受魔魁之女的意識去殺人，吸收死者腦波可變成活動有生命的箭。魔魁之女為順利臥底齊天殿，首度動用魔魁遺物，以幽靈箭除去障礙大和居士，幽靈箭過穿大和頭部卻無留下傷痕，只是攝去大和腦波，大和瞬間灰化隨風消散，幽靈箭飛入魔魁之墓前，變成一尊石俑。此後，幽靈箭一度流落至方城之主手中，被其用於挑撥武林各方勢力。鑄造者亢無後則隱居在大汗之野，因自責而自殘雙手，並曾將“無後彎刀”與“天雷罡劍”贈予他人。為應對幽靈箭的威脅，聖賢諸曾帶來能克制此箭的武器。據亢無後透露，魔魁當年奪走的幽靈箭可能是假貨，而真正能克制幽靈箭的秘寶“太極甲”，其製造尚需東島（隱霧島）神鶴佐木的“如意寶”。登場劇集霹靂王朝 第29集

# 武痴 (武痴)
================================================================================

武痴

昂然風骨、身揹無玹劍，一生行俠仗義、醉武成痴的絕世高人，乃正義、光明化身。為力阻邪帝亂世，曾三戰天外南海、苦境兩地，消弭罪惡，昇華俠之道，並留下招式心法，讓後世傳人追尋其武學，發揚以武濟世的精神。

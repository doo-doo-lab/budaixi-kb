# 武痴

昂然风骨、身背无玹剑，一生行侠仗义、醉武成痴的绝世高人，乃正义、光明化身。为力阻邪帝乱世，曾三战天外南海、苦境两地，消弭罪恶，升华侠之道，并留下招式心法，让后世传人追寻其武学，发扬以武济世的精神。

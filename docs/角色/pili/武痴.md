## 来自百度百科的补充

武痴是霹雳布袋戏系列中的虚拟角色，男性，配音为黄文择，初登场于《霹雳九皇座》回忆片段（已故），根据地为归心渊。该角色身负“以义行侠，以侠行义”的武痴精神，口诀为“武承一脉·万武归宗”。为阻止邪帝祸世，武痴与邪帝为生死仇敌，曾三度征战天外南海与苦境，最终将邪帝打死。战后留下招式心法供后世传人研习。其武学体系包含天、地、虚、玄、人五字诀，其中玄字诀赠与好友正一天道天师。人字诀通过归心渊石刻“武”字由不同传人领悟出多样武技。传人分为正统（蜀道行等）与其他支系（剑君十二恨、沐流尘等），部分传人因强行突破武学限制遭反噬，如沐流尘急于求成强行五诀合一，遭武痴预留破绽反噬而被蜀道行击杀。

武痴，昂然风骨、身背无玹剑，一生行侠仗义、醉心武学的武者。为力阻邪帝乱世，曾三战天外南海与苦境两地，消弭罪恶，完善了侠义理念。战后留下招式心法，供后世传人追寻其武学，发扬以武济世的精神。其武学共分天、地、虚、玄、人五诀。武痴曾将玄字诀赠与好友正一天道天师。武痴与邪帝是生死仇敌，两者的对抗是延续千年的宿命，其传人也继承了这份恩怨。

仇敌：邪帝。武痴与邪帝是生死仇敌，其传人延续千年的战斗。对手：银鍠朱武（书本记载和箫中剑回忆），又称朱皇。武痴传人：1.正统传人：莫长铗（蜀道行、沐流尘之师，上一代武流座）、蜀道行武痴传人根据领悟的武学字诀可分为不同支系：天字诀传人包括莫长铗、蜀道行、绢刀、裴千己、柳无色；地字诀传人包括冷非颜、航谷风、极道天权；虚字诀传人包括箫中剑（空谷残声）、蜀道行；玄字诀传人包括阴阳师、天忌、行天师、极道天权；人字诀传人包括策衍先座、金犀武座、白霭灵座、剑君十二恨、沐流尘。其中，人字诀为悟性之招，无固定秘籍；沐流尘曾练有五式绝学但因急于求成而被蜀道行击杀。

| 武学招式 | 使用传人 |
|---|---|
| 天字诀：天外有天、天绝俱灭（原有）；天外回天、天意难违（侠刀自创） | 蜀道行、绢刀、裴千己、柳无色 |
| 地字诀：地一归元、地化星雨 | 冷非颜、航谷风、极道天权 |
| 虚字诀：虚返其实、虚无飘渺、虚藏万象、虚实流转、虚无玄宗、虚转其实 | 箫中剑（空谷残声）、蜀道行 |
| 玄字诀：烙骨大法（天忌改版：剑引风雷）、烙骨催元 | 阴阳师、天忌、行天师、极道天权 |
| 人字诀：剑武、桓武掌、天外刀、武痴剑印 | 策衍先座、金犀武座、白霭灵座、剑君十二恨、沐流尘 |

玄字诀秘诀就是当年武痴与创立正一天道之天师为好友，便将玄字诀赠与天师，也因此烙骨大法本身与正一天道的其它术法有所出入人字诀乃是归心渊当中留下一“武”字，仅仅一字武，其实包含武学万象，化整为零，由浅入深 。因此同一个武字，当年策衍、金犀、白霭三人由於各自专长不同所以领悟出的武功也不同。人字诀为悟性之招并没有秘笈，因此威力大小就看个人悟性而不同，因此剑君和沐流尘也是看武字而自行悟出剑式之招，并且青出于蓝胜于蓝，超越策衍先座的剑武。另：沐流尘练有武痴五式绝学，因为急于求成而以烙骨催元催动五诀合一，殊不知武痴为防有人求速成武痴绝学祸乱武林而留下破绽，最后被蜀道行击杀。

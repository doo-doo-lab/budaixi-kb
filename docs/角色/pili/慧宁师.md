# 慧宁师

================================================================================

霹雳布袋戏虚拟人物慧宁师，霹雳布袋戏虚拟人物。天佛五相之一，象征喜舍念，童稚样貌的佛修者，与会言论采取平铺直叙，不作太多延伸阐述，以乐观欢喜之心看待世界，与素还真甚有渊源。在无尽天峰佛链崩毁后，一会禁锢多时的剑通慧，却也对其性情骤变产生诸多疑点。中文名慧宁师配 音黄文择性 别男登场作品霹雳战元史之天竞鏖锋霹雳战元史之动机风云人物编剧伯风出场集数38集

- **组织门派**: 天佛原乡同修：招提僧、欲明王、恒沙普贤、砗磲佛母（天佛五相）上司：天之佛

## 人物经历

慧宁师，天佛五相之一，代表意义为对治“贪”的“喜舍念”，外貌为一幼童，象征童蒙洁净之心。在鬼觉神知被苍宇医楼擒捉时，慧宁师派奉菩提和谒金刚去医楼交涉。在无尽天峰巨链崩毁后，慧宁师会面禁锢许久的剑通慧，对其性情骤变产生怀疑。后来，慧宁师和招提僧、砗磲佛母、欲明王四相合力攻击皇极七行宫，再配合欲明王、招提僧埋伏于一念之间，与半截王迹等厉族发生冲突。事后，慧宁师和欲明王等追杀天之厉，于异诞之脉开战，慧宁师和招提僧牵制剑通慧，但半截王迹和欲明王同归于尽，慧宁师遂暂撤回天佛原乡坐镇。在半截王迹身亡后，为除厉族后患曾与招提僧合一攻击冰无漪，后因思索到厉元回归的问题而罢手。在天之厉复生后阻拦失败而被天之厉所杀。后为防止天之厉攻击佛乡再被化出阻拦，再度死于天之厉。

# 風雪一路禪 (风雪一路禅)

風雪一路禪

天涯行跡的雲水行腳僧，手持枯木杖，腳踏芒鞋，背後揹著經書架，個性溫文爾雅，講話不疾不徐，善觀察人情百態，語多露禪機雋語，與無故事的人、雲滄海有一段故緣。

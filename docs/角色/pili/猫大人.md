# 猫大人

箫中剑好友，能言人语的猫大人，言行举止如绅士般高雅斯文，有着个性上的洁癖，语调带着浓厚的口音，偶尔会使性子；携佩杖剑，自称乃妖猫族修行五百年以上的大剑士，十足的诙谐逗趣。

## 来自百度百科的补充

猫大人留守在荒城，照顾箫中剑捡回的孤儿金无患。之后，猫大人与金无患在荒城另寻住所，建起一座小庙，金无患当主持，猫大人变为猫和尚，两人为村民占卜谋生。无人打扰时，金无惠会练习箫中剑教授的剑法，猫大人看着他潇洒的剑舞，满足地捋着猫须说：“未来，真令人充满期待。”

| 丰功伟业 | 杖剑剑身细长尖锐，适合挑、刺等西洋剑式，猫大人本身修行老练，剑势磅礴有力，[妖云流]之招犹如邪云飞窜，具有袭击、掩蔽之效果。猫大人剑术不凡，但毕竟身为高雅的绅士，让其甚少动粗动剑，总爱计较言语上的争锋，个性诙谐逗趣，不过一旦挚友箫中剑碰上危险，便可见到猫大人的绝世剑术。在箫中剑面临冷霜城与策马天下，身中剧毒、腹背受敌时，猫大人挺身相救，一招[妖云流]当下震退欲背后偷袭的策马天下，威力之强悍，也让策马天下赞誉有佳，猫大人剑术不凡，由此可知。 |

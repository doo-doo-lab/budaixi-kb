# 鬼奴

化丑为魔域所擒，改造为鬼帝身旁的头号战将，使阴用术变化出奇，与天祸妖狐深得鬼帝器重，曾参与多场重大战役。在清醒后转为卧底魔域，透过千里移影定风珠传递情报，最后与一休禅师等人退隐于无双崖底，不涉尘世。

## 来自百度百科的补充

鬼奴原是素还真之徒·化丑，隐居于紫竹林内，却被魔域所擒，被鬼帝改造为强力战将，和天祸妖狐一同执行杀戮任务。鬼奴能使用变化诡异的阴术，在战场上让敌人捉摸不透。鬼奴后来被解除了洗脑，清醒后和天祸妖狐联手，作为正道潜伏在魔域的卧底。

在鬼帝被一页书所杀后，第二魔域覆灭底定，鬼奴本想顺势混入第三魔域继续内应，却被第三魔域先锋沙虫和青丝拒绝，只好回琉璃仙境报告其师素还真，但让对素还真有强烈占有欲的心弦感到愤怒，甚至教唆龙末九打断了鬼奴的双足，鬼奴双足被断后也下落不明。

后来，秋风之刀到无双崖想请出一休禅师翻译黑卷，鬼奴出现帮秋风之刀传话，可知鬼奴和一休禅师、金太极、天祸妖狐等在无双崖下隐居。

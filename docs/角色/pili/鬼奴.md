# 鬼奴 (鬼奴)
================================================================================

鬼奴

化醜為魔域所擒，改造為鬼帝身旁的頭號戰將，使陰用術變化出奇，與天禍妖狐深得鬼帝器重，曾參與多場重大戰役。在清醒後轉為臥底魔域，透過千里移影定風珠傳遞情報，最後與一休禪師等人退隱於無雙崖底，不涉塵世。

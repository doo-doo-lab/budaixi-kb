# 人邪
================================================================================

人邪

一个追求未来的人。北域传说的两大剑客之一，炼邪师剑鞘所封之人，外冷内热、不拘小节，爱恨分明的性情，对人冷淡，对朋友则至情至性，在豪迈豁达之中，也有对仇恨的强烈偏执，略显矛盾的北域剑客。

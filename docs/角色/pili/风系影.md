# 风系影

天下式为再战天扇子，利用道风天扇与十变魔册的奇能，在死亡三角洲重塑天扇子躯体，功成之际，剑非道以蕴藏天扇子一点灵识的灵珠，使再造之躯体的意识受到天扇子本质的影响，尽管性格及处事态度上略见天扇子的特质，自名为风系影，并坚决否定自己为天扇子。

## 角色介绍

他仅是有他的一部分，绝不是他。

他始终是他自己，一如他始终是他自己。

看起来相当拗口难明的两句话，替换如下的句子，就一目了然：风系影仅是有天扇子的一部分，绝不是天扇子。风系影始终是风系影自己，一如天扇子始终是天扇子自己。

风系影的存在，可谓是阴错阳差又鬼使神差，源自于天下式的一缕执念私心，也多亏于十变魔册的奇效异能，利用道风天扇与死亡三角洲这两个对天扇子意义不凡的物与地，重塑了他的身躯。

关键时刻，剑非道捎来了小秘宝身上的灵珠，其中正蕴含了天扇子在世上的最后一点灵识，千钧一发之际将灵珠融入了那与天扇子有相似外貌的躯壳。

初临世间，随心而为，面临与天扇子多有纠葛的五陵官鬼和旂小雨，杀与救，他并没有太多的两难。正如剑非道所说，就算他不是天扇子，也会做出和天扇子一样的选择，而这样的盘算，则是出自于天马宗一，一个在幕后与天下式博弈的人。

以天马宗一的能为，他当能力阻天下式重塑天扇子这件阴谋，然而他却刻意顺其自然的任由发生，直到最后一刻才让剑非道出手。这麽一来，不仅达成了天下式的渴望，也实现了旂小雨的愿望。从这个角度发想，天马宗一的居心值得揣摩，毕竟这关乎他一生中最重要的两名女性。

风系影拥有与天扇子一样的特质，纯然本真而不解人意，旂小雨将他当作扇主，希望他能寻回记忆，于是携他重游故地，也重温两人温情时光。风系影却不以为意，日中绝迹，指的是已经消亡不存在于世上的人事物，但另一层涵义，却是在消亡之前，乃是绝无仅有的存在。

想来风系影以此自号，带有反驳所有认为、认定、认识他为天扇子的人的意思。

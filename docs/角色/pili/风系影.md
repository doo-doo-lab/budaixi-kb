# 風繫影 (风系影)
================================================================================

風繫影

天下式為再戰天扇子，利用道風天扇與十變魔冊的奇能，在死亡三角洲重塑天扇子軀體，功成之際，劍非道以蘊藏天扇子一點靈識的靈珠，使再造之軀體的意識受到天扇子本質的影響，儘管性格及處事態度上略見天扇子的特質，自名為風繫影，並堅決否定自己為天扇子。

# 武邑率然 (武邑率然)
================================================================================

武邑率然

“武邑”为“云岩武邑”嫡传人所获得的冠名，身为名门正派的代表，个性自负而又自卑，相当注重门派的名誉，却也很在意别人关注、鄙视、嘲笑他的残缺。对师尊巍翼十分敬重，并将他当作生命中的一座高山，值得依靠、仰望，却也在无形中，成为他的关碍。

# 武邑率然 (武邑率然)
================================================================================

武邑率然

「武邑」為「云岩武邑」嫡傳人所獲得的冠名，身為名門正派的代表，個性自負而又自卑，相當注重門派的名譽，卻也很在意別人關注、鄙視、嘲笑他的殘缺。對師尊巍翼十分敬重，並將他當作生命中的一座高山，值得依靠、仰望，卻也在無形中，成為他的關礙。

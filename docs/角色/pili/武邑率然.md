# 武邑率然

“武邑”为“云岩武邑”嫡传人所获得的冠名，身为名门正派的代表，个性自负而又自卑，相当注重门派的名誉，却也很在意别人关注、鄙视、嘲笑他的残缺。对师尊巍翼十分敬重，并将他当作生命中的一座高山，值得依靠、仰望，却也在无形中，成为他的关碍。

## 主要经历

在崇越峰正心台，风月莫容带人一闯破镜祭，武邑率然决心扬威，凝元聚气，以洞心直观与风月莫容对招。为凝聚正道力量共抗八无暇，武邑率然找上入世一步涯的司马骏业请援，反遭为难。

在峡谷之上，祖登龙强势出手，重创武邑率然。在迴廊废墟，游师无方逼命少阳君之际，武邑率然及时来援挡下杀招，但游师无方刀路刁钻，使武邑率然久战之下险象环生，血元流失，筋疲力尽。

在秋声楼，武邑率然与西溟疏狂激战，运使全身功力展开光界，虽根基稍逊但占共感之利，战局僵持；最终西溟疏狂雄啸破招，光界崩碎。

在試鋒岩，香六牙过河拆桥袭击武邑率然，武邑率然以步光宝鉴绝式反击，并得少阳君与西窗月助攻，三方围剿香六牙。

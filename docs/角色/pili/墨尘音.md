# 墨尘音

================================================================================

霹雳布袋戏虚拟人物墨尘音，霹雳布袋戏虚拟人物。玄宗四奇之一，曾在矗理原之战中被魔界四天王之晦王称为“四奇之末”，实则在四奇中实力排行第二。琴剑双修，外表正经，谈吐风趣，虽是先天高人，却显和蔼近人。封云山封印前夕，为找寻赭杉军下落而来到苦境，隐居青埂冷峰深处，并以法阵隐匿行踪、躲避异度魔界的追查。诗号1：凝空心，法常住，道魔消长扰纷纷！百体流形，唯灭动心，十指道弦洗世尘。诗号2：乾坤轻挹墨尘埃，铮铮魔音江流东。

## 角色背景

人物缘起摘自罗陵编剧博客 浅谈关于【六弦四奇】神州写真记得当年在写剑踪时，黄董指示要再写“魔界”，忘记是哪位编剧取名“异度魔界”，又如同剑子跟龙宿一样，忽然异度魔界就这样莫名的落在我头上叫我写了。

那么从道境空降的异度魔界，宿敌便有道境原本就有的道教，苦道两境连联手封魔界...这些得见吞佛童子与夜重生的解说(太久了我快忘光了)依稀记得万圣岩玄宗这个名字好像都不是我取的，只是凑巧写了总收幕。

剑踪那时写到玄宗只余六弦与几名道人，其实当时的设定除了出来那两位，真也只有六弦。

这时奥妙了，四奇呢？

四奇在哪里？

怎么生的？

这个就来自我长年与无非文化和动脉音乐合作，常帮他们写人物介绍，忘记是哪张专辑了，因为一时觉得玄宗只有六弦好单薄，剧情中又不是很有机会写，总是拖着拖着，写著介绍时，一时手痒写了玄宗本有六弦四奇。

音乐CD发片之后，被主编看到，主编便让双桥之主的亲爹‧隽尚编剧创了四奇，但这必须要去符合当时的道佛魔大战之刻，四奇不在，所以，隽尚编剧苦思之后，赭杉军与墨尘音终于诞生。

双桥之主在玄宗的名字：金鎏影与紫荆衣也定名了。

四奇之间的前事纠葛，其实隽尚编剧的设定是令人纠结的，那么隽尚编剧让墨尘音在奔走之下，也重新定位出不一样的双桥与四奇之间的故事。

四奇可以合并，隽尚这位非常认真养小孩的亲爹，真的是花了很大的苦心。

但后来隽尚编剧离职，我被赭杉的亲爹托付了赭杉此角，并协助小墨发型的最后定案。

## 角色形象

性格特征摘自霹雳会刊153期 心相·星相·众生相159-15153-05167-13159-18153-02153-07153-12153-21153-26153-35152-02168-10168-11墨尘音的初次登场，是与多年不见的伯藏主品茗论剑之刻，从言谈中伯藏主道出墨尘音顾左右而言他的惯性，对一般人而言，这是墨尘音风趣幽默的体现，直到赭杉军正式现身，才明白墨尘音这种毛病的根源。

墨尘音是相当重感情的人，从协助赭杉军镇压魔性甚至寻找解咒方式、寻找紫霞之涛、召回金鎏影与紫荆衣魂魄时的真情流露，都有着明显的水象星座情感流动，在对千流影的态度上，也偏向收容、关怀等对待方式，具有强烈的巨蟹座性格。

不喜与人争执的巨蟹座，在团体中通常是良好的调解者，同时受到基本宫的影响，一般而言具有“社会责任” 的概念，两相冲击之下，情感流动通常会偏向消极，为了减轻这种痛苦，进而造成言语上的避重就轻，与射手、水瓶恰好相反，这在墨尘音给与赭杉军的第二道考验中得以展现。

本着巨蟹座的观察本能，墨尘音替赭杉军说出隐藏内心的情感，劝赭杉军放下的同时，自己又何曾将这种重担卸下心头？

总是展现保护者姿态的巨蟹座，其实有着水象本质的深沉脆弱。

角色诗号录自《霹雳人物出场诗选析》12凝空心，法常住，道魔消长扰纷纷！

百体流形，唯灭动心，十指道弦洗世尘。

上片形容墨尘音修行之道，虽处于道魔相争的处境之中，仍坚守以道法为中心，专一而执著，不妄想，不妄念。

下片描述天地阴阳五行所形成之物态万变，墨尘音见俗世红尘纷扰天下苍生之心，决定倾尽一身修为以净化魔氛。“凝空心，惟灭动心”等词源自<太上洞玄灵宝观妙经>，体现墨尘音之意念坚定而专注，拥有过人的仁心善念以及为救苍生的果敢坚毅。

## 武器

### 墨曲琴

- **登场剧集**：霹雳开疆纪 第36集
- **外形特征**：墨曲琴为一口五弦之琴，琴身修长刻有云彩为饰，垂悬羽毛流苏，内部为缕空音箱，墨曲剑平日置入其中，剑锷墨曲二字自镂空处清楚可见。
- **配合招式**：道音十界，道曲十弦，墨尘破魔、道尘十界。
- **丰功伟业**：墨曲琴为道门之物，具有辟邪克魔之能，墨尘音十指拨弄弦音如涛，能形成琴音护罩防护周身。
- **初现绝艺**：对上鬼达魔、冥伞鬼娘时，便以琴音轻松伏邪。
- 随即墨曲剑出，万邪散灵消灭！
- 之后在青埂冷峰与一剪梅交手时，同样也是以墨曲道音配合阵法牵制敌手，消灭怒颜鬼影，“墨尘破魔”之招净化邪物！
- 一旦墨尘音真正要诛魔伏邪时，墨曲剑便会应墨尘音意志飞出，斩妖劈邪不留情！

### 墨曲剑

- **登场剧集**：霹雳开疆记 第39集
- **外形特征**：墨曲剑平日置于墨曲琴中，剑锷墨曲一字镂空处清楚可视，剑身狭长纤细，锋刃处转为尖锐，剑柄以倒戽扳手式的设计，能随意识脱鞘飞出。
- **配合招式**：墨曲一出净世尘、墨尘破威、墨曲斩邪刑无赦、真极烈焰、玄宗秘式-古阳圣威、玄天极。
- **丰功伟业**：墨曲剑乃道门神器，剑身刻有墨曲二字，玄罡正气沛然。
- 平日藏于墨曲琴中，当墨尘音决意开杀时，墨曲剑便会应墨尘音意志而飞出，斩妖辟邪不留情。
- 墨曲剑在玄宗术法加持下，能净化魔气，斩杀妖邪，“墨曲一出净世尘”，“墨曲斩邪刑无赦”便是代表之招，墨尘音在对上嗜生伽罗时，以此两招诛杀魔物，墨曲飞升，剑气疾利，就连东瀛妖灵鬼达磨、冥伞鬼娘也无所遁形，瞬间为墨曲剑斩杀净化。“真极烈焰”乃专克鬼族的至极之招，以墨曲剑灌注道门玄刚内劲，化出消弥世间恶孽的三昧真火，吞佛童子、月旋涡等魔将曾领受过此招之威，墨尘音更能以一代四施展“玄宗四奇阵”，合三位同修之特性同施四色“真极烈焰”，威力倍增，当场将魔晦王炼化！

## 角色经历

### 道魔战，封云乱21

昔日道境封云山一役前夕，异度魔界军师伏婴师与玄宗叛徒金鎏影设计加害玄宗四奇的赭杉军，墨尘音久不见赭杉军归来，于是便四处找寻赭杉军之下落，赫然发现魔气染身的赭杉军。

两人再回封云山之时，魔界已识破封印之谋，大举侵略封云山，大战之中，金鎏影与紫荆衣乘乱离开道境，玄宗众门人为护生灵，以总坛取代被破坏的第四处，强行将魔界封印在异度空间。

在此危急之下，一方面为了保全即将魔化的赭杉军，一方面为躲避异度魔界连番追杀，墨尘音带着赭杉军来到苦境，隐居在青梗冷峰深处，并将赭杉军安置在混沌岩池，以岩池内的仙灵地气延缓赭杉军魔化的速度，并四处找寻消除魔气的方法，以乾坤法阵隐匿赭杉军的行踪。

### 救祸皇，诛邪魔12

鬼夜母獠娜带领八鬼乱世，六祸苍龙一挡獠娜攻势，但也因此被獠娜设计坠入幻之识界，昏迷不醒，千流影为救父亲，上至青埂冷峰跪求高人墨尘音一助。

为防止嗜生伽罗进入青埂冷峰，墨尘音在好友伯藏主的帮助下将千流影带回望天古舍。

虽感念于六祸苍龙与千流影的父子之情，却流露出天命不可违的无奈，不料，赭杉军心生慈悲，出手干预天定之数。

逆天之罪，七七死劫，血亲相见，必亡一人，墨尘音遂将千流影留在青梗冷峰，极力避免千流影与六祸苍龙父子两人见面。

因鬼夜母与东瀛白狐国乃为世仇，白狐国君储伯藏主与胞弟犬若丸排布计画，欲灭鬼夜母及其手下于绿松坑。

墨尘音为助好友铲除邪恶，在绿松坑外牵制鬼夜母手下两护法，劝导不成只好将其诛灭。

之后，墨尘音在绿松坑布法净化残余妖灵，帮助六祸苍龙苏醒。

### 治好友，抗魔祸

为医治同修好友赭杉军，墨尘音四处寻找消除魔气之法，得知蚀光之谷中的暗族，有一部武学能医治赭杉军身上的魔咒，千流影为报恩，自愿一闯蚀光之谷。

墨尘音从赭杉军口中知晓万血邪录后，虽然忧虑此事，但他明白医治赭杉军乃最为迫切之事。

后幸赖千流影请来暗族魔女，在墨尘音布局之下得以顺利吸取赭杉军周身魔源。

期间，一剪梅数度来到青埂冷峰侵犯，墨尘音数度与之周旋，实为防止异度魔界派出更强之魔，最终因非恩之死而怒将其诛杀。

之后，墨尘音前往中原一探万血邪箓与叶小钗之踪迹，途中巧遇正为同样之事欲寻叶小钗的素还真，于是墨尘音便引领素还真一会赭杉军，赭杉军对素还真直言万血邪箓开启将会引动神州血祸。

墨尘音并借此见面之机，对素还真提及叶小钗之事。

为继续探查叶小钗行迹而来到被其屠戮的武林派门，墨尘音遇上前来执行任务的月漩涡，交锋之后将其重创。

### 灭魔火，收双桥

魔火肆虐，中原各处生灵涂炭，在舞先姬、盲夫子的协助下，墨尘音孤身深入魔火深处欲将其灭之，不料伏婴师暗中操控，魔火反噬，墨尘音受伤。

远在混沌岩池的赭杉军心神感应灵识出体赶来相助，合两人之力，玄宗密式再现，焚烧中原多时的魔火终归虚无。

期间，因轩辕不败为达成挑战六祸苍龙的野心，设计让千流影子代父死惨亡于东瀛天狩浮阁大炮之下，墨尘音阻止不及。

为千流影之死感到悲伤之余，想起自己的同修好友金鎏影与紫荆衣。

为两位同修的所作所为向素还真致上迟到的歉意，并从素还真口中得知两人最后的归处，遂前往诡龄长生殿、断魂崖收回两人之魂魄，以尽同修之谊。

### 奇阵开，墨曲终21

为助素还真取回叶小钗意识和赭杉军的紫霞之涛，墨尘音与素还真、赭杉军设下九峦峰之局，三人分工合作。

在九峦峰下的矗理原，墨尘音与盲夫子、舞先姬、守墓人以及地狱岛士兵共同抵挡异度魔界的强大攻势，布下玄宗四奇阵一抗魔威。

墨尘音召唤出双桥之灵，以及赭杉军真气化灵，三奇以真龙妙道三护法宿体而生，以墨尘音真元撑持，组成玄宗四奇阵，一举重挫魔界大军攻势。

但魔界也非泛泛之辈，银锽朱武以赦生童子、螣邪郎、银锽黥武三人的兵器，催动术法召唤出三人之灵，再配合伏婴师所布的阵中阵，由吞佛童子统领组成四魔阵，力拼玄宗四奇阵。

最后的关键，双方各豁尽全力，墨尘音以一代三魂，开启无量周天阵，与四魔阵的天魔锁神关两败俱伤。

熟料，此战异度魔界的最后一张王牌乃魔化叶小钗。

墨尘音过度耗损真气在前，虽然以道曲一时制住叶小钗神识，但叶小钗头上逆五芒星化现猛然解破弦音。

墨尘音察觉魔化叶小钗头上的逆五芒星印仿如赭杉军当年入魔之印，遂催起道印欲替魔钗封印魔咒，不料魔源反噬，墨尘音猝不及防，伤上加伤，受招呕红。

最终被魔化叶小钗断去一臂，加之伏婴师暗处以咒印护住叶小钗，墨尘音剑断人亡。

虽是如此，仍守住最后防卫，让素还真带着叶小钗灵识与紫霞之涛顺利回归。“沉落黄土的尘埃，是宣告这场道魔之战的结束”。“吾死，也不准任何魔人踏入”。“守住最后的承诺，永不放弃的阻魔天命，如今墨曲剑断，墨尘音终究是累了，紧握剑柄，却代表他未曾后悔过的心思，因为他始终明白，在他之身后，仍有一名他最可以信赖的接续者”。

# 認吾師 (认吾师)
================================================================================

認吾師

顱潭劍族純血傳人，對劍領悟力極高，本性剛正不阿、富正義感，與父親司馬劍秋理念不合而出走，戮力尋找至善、傳家之劍，也因而巧遇名劍鑄手金子陵，隨侍在旁學習劍之道，並與劍曲絕鳴子結為莫逆之交。

# 认吾师

颅潭剑族纯血传人，对剑领悟力极高，本性刚正不阿、富正义感，与父亲司马剑秋理念不合而出走，戮力寻找至善、传家之剑，也因而巧遇名剑铸手金子陵，随侍在旁学习剑之道，并与剑曲绝鸣子结为莫逆之交。

## 来自百度百科的补充

认吾师出身颅潭剑族，为族长司马剑秋长子，曾因纯血之故而师从穷八极学艺，后来由于和司马剑秋的阴谋理念不和而离家出走，四处漂浪，也和白马纵横有过切磋之谊。

一心追求至善之剑的认吾师，对剑的领悟力极高，为人也刚正不阿，充满正义感。因出手帮被宇飘风追杀的秦假仙解围、手中剑不敌苍魔刀而断，却也因祸得福地结识了名剑铸手金子陵，并在金子陵的开释指导下修为更上一层楼。认吾师跟随金子陵来到寂山静庐修悟剑道，后来金子陵为铸造足以对抗魔刀的神器而闭关，闭关前特别赠予认吾师一口求心宝剑护身，此剑虽非天下第一，却也是难得一见，和认吾师的特质相得益彰。

认吾师在和金子陵同行时，与绝鸣子结识并成为好友，两人也多次配合克敌，守护铸剑炉、擒捉魔刀非道等等。为对抗鬼阳六斩刈，认吾师协助绝鸣子完成"九天惊虹"最后一道手续，但因天意弄人，加上四无君从中作梗，使得驰援不及，金子陵死前赠送《天剑无双》的剑法秘笈，冀望认吾师能发扬光大。后来，九天惊虹被交托给天忌，天忌以此击败了持有魔刀的炎熇兵燹，算是圆满了金子陵的遗愿，认吾师也和绝鸣子一同退隐修行。

弃天帝为毁灭人间而降临，击毁神州支柱使得神州断裂，认吾师和绝鸣子感到事态严重而重出江湖，与洛子商、舞世态、云中生结为同盟对抗异度魔界，熟料被战兽天戮盯上攻击，五人竭尽办法仍撼不动战兽的钢筋铁骨，绝鸣子和云中生阵亡，认吾师危机之刻被佛剑分说解救，在其掩护下和众人离开。

在霹雳英雄榜之风起云涌一第18集中死亡的认吾师，只是司马剑秋在真的认吾师出走后，以魄书化出的一个替身，目的是为了瞒过剑神穷八极。

风起云涌两部曲剧中多次有点到。在霹雳英雄榜之风起云涌二第24/25集中，司马剑秋曾说过十年培养的替身，讲的很清楚，他对冷封尘说"以我的术法，创造一个人都是容易的，何况改变一个人的记忆"，随后，司马剑秋也特别再补充了一句"十年的父子"，明显的提示死掉的认吾师只是一个替身。

到了霹雳兵燹第27集，三口组为调查凡尘崖而进入千邪洞挑选兵器，业途灵解说所选中兵器时提到情义剑，明确说明之前的是假认吾师。

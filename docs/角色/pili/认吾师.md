# 认吾师

颅潭剑族纯血传人，对剑领悟力极高，本性刚正不阿、富正义感，与父亲司马剑秋理念不合而出走，戮力寻找至善、传家之剑，也因而巧遇名剑铸手金子陵，随侍在旁学习剑之道，并与剑曲绝鸣子结为莫逆之交。

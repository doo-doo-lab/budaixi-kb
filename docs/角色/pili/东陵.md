# 东陵少主

霹雳布袋戏虚拟人物东陵少主，霹雳布袋戏虚拟人物，初登场于《霹雳英雄榜之争王记》第1集，退场于《霹雳图腾》第16集。曾因七星之事与汗青编产生冲突。一贯理性、冷静的态度，甚至从容应付、扭转情势。擅长观测星象，从满天星子中探得丝丝天机。最终在龙颈坡测算到自己死厄，使用延命术，但仍被悦兰芳埋伏杀死。

## 角色设定

诗号：千古谁堪与伯仲，少时落梅殇，今越红尘亦悠悠；一朝白首望平生，不见东风残；只见九州万里行。

## 人际关系

- **妹妹**: 柳依依朋友：佾云、莫召奴、素还真、悦兰芳、经天子师：紫星眉师妹：路光明五方主星：素还真（中麒麟）、东陵少主（东青龙）、莫召奴（南朱雀）、非凡公子（北玄武）、悦兰芳（西白虎）

## 角色经历

东陵少主，怀拥天地七步阶之主，个性沉着冷静，擅长观测天象、推断命哩，人品与武功皆属上流之人士，其来历背景不平凡，为五方星主之一的“东青龙”，另一身份则是拥有七星之主命格的候补人选，登场前期未露面即经佾云与莫召奴介绍了。

初期，对当时武林第一关键七星之事毫无表达更是选择不于理会，而与假悦兰芳（经天子所扮）一同游历江湖，但实际上自己却与真正的悦兰芳谈论天下大事及武林未来动向，更与悦兰芳自身生命一赌七星之主与汗青编御主谁先现身。

到了中期，东陵之前选择不理不睬是为了掩人耳目但私下却营救被追杀的七星，直到路光明出现以及不二刀重伤之后开始在台面上动作，但此举也遭到汗青编的注意而被盯上了。

之后，汗青编开始对东陵少主下手更抓走柳依依要胁东陵交出七星图，东陵少主仍然无动于衷，尔后汗青编采取极端手段杀上怀拥天地七步阶，更杀死七星之一的易星苗逢春，东陵少主忍无可忍之下初现绝技一掌击杀幻化上人打伤寒剑月飘霜、穿云豹等人后逃离现场另外布局，但不幸的是智王星路光明随后被汗青编捉走。

东陵少主争王记后期，汗青编欲在公开庭上将紫星眉刺青公开，东陵少主为了两个师妹安危事先将七星图交予莫召奴保管后一人独自上公开庭处理刺青之事。

公开庭上东陵少主一战汗青编御主，危机之时不二刀义气相助对抗汗青编，后东陵为让悦兰芳生死之谜真相大白而一掌击碎御主华骄，汗青编御主现世但却不是悦兰芳本人而是被亲弟弟经天子谋朝篡位，东陵少主赌约胜出，但经天子不守信用仍要公布刺青图，东陵少主为了其他七星安为下自盖天灵身亡，也让紫星眉与东陵少主师徒关系曝光。

实际上东陵少主诈死化明为暗欲阻止七星之主杀害残余七星。

后来在云渡山上一页书逼出东陵少主，路光明为证明七星之主是紫星眉自杀身亡，紫星眉吸收智王星星灵而阴谋败露，一页书虽联合东陵少主与病剑叟对抗但还是让紫星眉脱逃。

素还真为了对抗七星之主对策联合五方主星到引灵山开启上股七星之主天策真龙陵墓，在天策真龙遗体上紫星眉夺取天策真龙手札却意外被天策真龙借体重生，五方星主掉入陷阱，一页书更被困在天策真龙陵寝里。

五方星主的居住地遭到天策真龙大军所占据后在越剑人指引下一同到落叶知秋与驯刀者一同研讨集合四刀四剑对抗天策真龙。

之后五方主星劫数来临先是非凡公子自爆身亡后来素还真自爆筋脉，东陵少主也遭到悦兰芳算计与莫召奴决裂退出江湖。

东陵少主测算到自己死厄来临而使用延命术，来到龙颈坡上做最后程序但却被悦兰芳埋伏，两人展开一场死战，但因东陵少主身在龙颈坡上真气降低关系无法施出全力而被悦兰芳杀死，首级更被挂在琉璃仙境示威。

## 角色详解

人物写真摘自霹雳会月刊第68期 人物完全写真---东陵少主背负着许多秘密的东陵少主，其许多神秘的行径和谜样的身世，一直被各方人士猜测是七星之主的头号嫌疑人。

可能是个性使然，在东陵少主面对各方压力时，他依旧是保持着一贯冷静理性的态度，不会因此慌了手脚而忘了自己要做什么，也因此魔界、汗青编屡屡针对七星出手，他仍能从容应对甚至扭转局势，他的才能不容忽略。

剧情中，柳依依和东陵少主虽是兄妹，但那种暧昧不明的气氛，可以知道的是柳依依对东陵少主怀着一份极为深厚的感情，并对他若即若离、经常将自己放在一旁的态度感到无奈与伤感。

柳依依会对东陵少主如此牵肠挂肚，到底是男女之情还是只是手足之爱，也只有东陵少主和柳依依自己心中知道了。

# 越织女

================================================================================

霹雳布袋戏中的角色越织女，霹雳布袋戏中的角色。温柔而婉约的气质闺秀，但个性主动、大胆，勇于追求喜欢的人事物，落落大方，与侍女喜鹊居于不渡银河，身怀独特的织造技法而备受瞩目。曾编织三丝之服赠黑衣剑少，因此结识、心仪红流邪少，爱慕之情溢于言表。

**中文名**：越织女

**别名**：烟萝引梦

**配音**：黄文择

**本尊雕偶师**：刘氏

- **越织女名称**: 越织女性别：女其他称号：烟萝引梦初登场：霹雳经武纪之枭皇论战第39集退隐：霹雳战元史之天竞鏖锋第29集（和红流邪少一起退隐）根据地：不渡银河、邪尊道

## 角色能力

发明/创造：三丝之服、触机之服、止战之钥所有物：织梭

## 角色配乐

- **烟萝引梦曲/编曲：浩旭** — 《霹雳英雄音乐精选三十二》
- **这首曲调是越织女角色曲，悠远、平静祥和的曲调，随着轻盈飘渺、婉转流连的旋律，编制出古典柔美的意境情感，仿佛宁静的夜晚，徐徐的清风，水面柔波荡漾的月光，轻轻触及着心灵。乐曲作为烟萝引梦越织女之角色曲。春愁秋梦曲/编曲：孙敬凡** — 《霹雳英雄音乐精选三十七》

这首曲调是越织女抒情曲，乐曲初次使用于圣魔战印36集，越织女虽心仪红流邪少，但面临邪尊道浩势逼亲，也只能无奈妥协，心境之转折与愁绪于乐曲中表露无遗。后亦常使用于越织女与红流邪少分别时，依依不舍的离愁悲思之情境。

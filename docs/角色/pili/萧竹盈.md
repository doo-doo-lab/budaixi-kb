# 蕭竹盈 (萧竹盈)
================================================================================

蕭竹盈

為替走火入魔的母親外出找尋良藥，而遭一連串的變故後喪失記憶，進而結識恩人一劍萬生與其侍童葉小釵。衷情於葉小釵卻遭拆散，傷心欲絕後步入極端，出賣自身製造黑邪書後卻被他人算計。紅顏薄命的她在死前仍低喚著葉小釵的名字，情深已不可言喻。

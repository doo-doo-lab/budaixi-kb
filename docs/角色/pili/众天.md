# 众天

修行于灭轮的老先觉，与梵天、辅天并称灭境三天，合著旷世古今的明圣天书。众天心性慈善，身怀凛然正气，与灭境儒圣、西丘三君交好，更收素续缘为徒，授其不凡圣功，平息邪灵祸世之劫。

## 角色经历

### 天阙时期

修行于灭境的老先天，隐居于九脉界，与梵天、辅天合称灭境三天，三人一同著有明圣天书，个性慈善，正气凛然，与灭境儒圣、西丘三君交好，曾与一页书同游西丘，在山涛君的居所见巫花含苞而悟出明心万象一招，后协助灭境儒圣加入邪灵之战，以佛言枷锁将三途判中的业途灵打入释至明塔囚禁。

霹雳天阙时期，素续缘在灭境儒圣之首慈航渡的指点下拜众天为师，得传不凡圣功等高明武学。后来为防范宇宙至尊棺跟三途判得到雷霆谷内的吸雷针，并困住谷内魔物窜出，遂与好友大圆觉合施五色天网困住雷霆谷的入口，可惜最后仍被鬼王棺打破。

同时在造世七侠破鬼楼后，众天劝说徒弟天下第一现出真身，恢复素续缘的样貌和父亲素还真相认。

后常驻云渡山协助一页书应对武皇、鬼帝等魔头，在一页书殁于邪灵之毒后，参与天河运棺一役，出手牵制入魔已深的素续缘，众天也在此战过后回归灭境，与新任灭境掌轮卧佛一枕眠交好，后功德圆满羽化仙去。

### 神州时期

灭境有一凶恶种族，名唤血犄族，孽角即是此族中最凶恶的邪种，被未来之宰利用，但因其内心尚有一丝善念，众天便欲将其点化。后孽角因内心挣扎痛苦不堪，未来之宰便令他偷盗游仙枕，用其封印了众天羽化后的灵识（众天因修炼入度不转轮，死后会直接重生在转世宿体上，未来之宰让众天提前入灭，故未直接重生），后悔不及的孽角决意痛改前非，便趁机带着游仙枕逃往苦境。

在夜愁雨昏迷之际，众天曾寄体传声说出了"明珠在椟，含光忍辱；还君明珠，苍天不复"关于明圣天书下落的秘密，在机缘巧合之际，游仙枕被玄貘一掌轰开，众天灵识逃入不灭火坑，被火中雪以劫沦瓶封印交予未来之宰，再落魔掌。

众天转世宿体雅僧佛公子，在天启之日欲承接众天灵识的回归。无奈灵识回归被未来之宰、玉阳君、一生悬命、阎王锁破坏，佛公子更是被阎王锁偷袭而死，众天灵识消散，灵识承接失败。

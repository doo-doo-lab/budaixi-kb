# 眾天 (众天)
================================================================================

眾天

修行於滅輪的老先覺，與梵天、輔天並稱滅境三天，合著曠世古今的明聖天書。眾天心性慈善，身懷凜然正氣，與滅境儒聖、西丘三君交好，更收素續緣為徒，授其不凡聖功，平息邪靈禍世之劫。

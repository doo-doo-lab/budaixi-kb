# 一水台

佛门至高清修地无量天之住持，老僧入定，宛若一枝杈枒傲立世间。拥有神物六合灵镜，号称能检测是否遭魔气侵蚀；入世奔波欲鉴定创世者和素还真是否入魔，悉不知六合灵镜竟是阴谋一桩。

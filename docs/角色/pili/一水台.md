# 一水台

佛门至高清修地无量天之住持，老僧入定，宛若一枝杈枒傲立世间。拥有神物六合灵镜，号称能检测是否遭魔气侵蚀；入世奔波欲鉴定创世者和素还真是否入魔，悉不知六合灵镜竟是阴谋一桩。

## 来自百度百科的补充

一水台，霹雳布袋戏虚拟人物。佛门至高清修地无量天之住持。老僧入定，宛若一枝杈桠傲立世间。拥有神物六合灵镜，曾误用其照出素还真入魔太深，入世奔波欲鉴定创世者和素还真是否入魔。后参与大汗之战对抗四飞天，受伤严重命在旦夕。临终前向创世者交代需查明六合灵镜之中所藏的秘密，并嘱托若素还真有倾向魔界的行为，需大义灭亲。一水台最终伤重不治，圆寂后遗体被送回无量天安葬。

# 魑岳

================================================================================

霹雳布袋戏虚拟人物魑岳，霹雳布袋戏虚拟人物。元种八厉中的“山之厉”，曾参与初代圣魔大战，暗助明峦对抗魔城，利用蕴果谛魂退隐养伤时假扮其身份，并引荐泽之厉的化身海蟾尊成为圣方擘画者，实则狼狈为奸，一明一暗共同摆布世局。后借故卸除峦主之位，以真正的身份行事，着手探查天之厉的生死与封印解除。

**中文名**：魑岳

**别名**：葬界刁雄、狮子头（戏称）

**配音**：黄文择

**登场作品**：霹雳兵燹之圣魔战印霹雳兵燹之问鼎天下

**登场作品**：霹雳战元史之天竞鏖锋霹雳战元史之动机风云

**本尊雕偶师**：洪有聪

**角色编剧**：伯风

**出场集数**：91集

## 角色设定

魑岳名称：魑岳称号：葬界刁雄性别：男身份：元种八厉之山之厉化身：无尘、蕴果谛魂、齐子然（假冒顶替）诗号：六煞无生，餍尽江刑岳断，双擎造灭，吞销雷阙风驰。初登场：霹雳兵燹之问鼎天下 第29集（之前以假冒蕴果谛魂和蒙面人的方式出现）退场：霹雳战元史之动机风云 第39集（死于邪九世将其魄元吸收）根据地：黯天峰、阙阗关、皇极七行宫、异诞之脉、赤荒漠

## 人际关系

组织门派：厉族魑岳妻子：后无封义弟：赫连决徒弟：剑布衣仇敌：蕴果谛魂同伙：天之厉、劫尘（地之厉）、贪秽（泽之厉）、魈瑶（风之厉）、克灾孽主（雷之厉）、冰无漪（水之厉）、剡冥（火之厉）其他：齐子然（有过对手戏，之后假冒取代）

## 角色能力

- **武学**: 厉荡千山、地浑朝天·厉煞风云、三罡凶线、五刑吞岳、双擎日月·四阴风雷·六煞平涛启黄泉、五魑运岳·六葬天瀑

## 角色配乐

- **剧截图五刑吞岳（魑岳武戏曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选35》
- **以疾骤的金属乐器声划破开场，伴随而来的是一场生死激战，音乐使用于“山之厉魑岳”的武戏用曲。

黯天峰之会（鳌天vs魑岳）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选43》

孙敬凡老师2010年作品，以“战神武戏”为发想创作，充分发挥弓弦乐器合奏的特色，澎湃激昂且丰富多变，曲风明亮清快又刚劲律动，间奏佐以管乐器和敲击乐器为辅，营造出气势对峙的收幕震撼。

乐曲初用于问鼎天下第十七集，黯天峰，终日乌云罩顶、不见天日的晦暗绝岭，却同时降下两条诡异巍然的身影，一者克灾孽主“鳌天”，一者葬界刁雄“魑岳”，潜伏武林已久的两大厉首终于再度聚首！

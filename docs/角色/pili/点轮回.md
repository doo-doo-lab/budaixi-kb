# 点轮回

================================================================================

霹雳布袋戏虚拟人物点轮回，霹雳布袋戏虚拟人物。为荷叶禅师遁入空门前的身份，曾连得三届评剑会冠座，进入论剑海名人堂。个性较为冷残，手持的血阳残剑，为南海海底渠黎原石的渠玉所打造。久远前照世明灯为诛天疆祸龙，取走了灵性温和的黎石铸造玄解，被迫分离的渠玉，恨意难消，尔后被打造成剑时，影响了持有它的点轮回，入魔的他，残杀无数生命，他的发妻以死为谏，才让点轮回自血阳残剑的邪力中清醒。后来玄同与紫色余分前来问剑，阴错阳差下，荷叶禅师重拾血阳残剑，再度背负起血阳残剑的恨。中文名点轮回别 名六道雪生剑配 音黄文择、马国尧（台湾国语）、李进（普通话）性 别男登场作品霹雳侠影之轰霆剑海录霹雳开天記之创神篇霹雳开天记之创神篇下阕雕偶师何育霖

## 人物经历

六道雪生剑·点轮回，曾连得三届评剑会冠座，为留名于论剑海名人堂的高超剑者。但一口能操纵人心的邪剑，却影响了点轮回的心志，点轮回因血阳残剑而入魔，冷酷嗜杀，不复侠者之道。最终在其发妻牺牲自我之下，终让点轮回挣脱邪剑怨念的束缚。满手血腥，一心忏悔的点轮回也因此皈依佛门，成为荷叶禅师。当天佛原乡为扭转天罗子命数，与阎王展开博奕棋局，荷叶禅师也自天佛原乡踏入武林，担任引导天罗子的任务。久远前，南海之下生有一对阴阳石——渠黎原石，后来照世明灯为诛天疆祸龙，取走了灵性温和的黎石铸造玄解，被迫分离的渠玉，恨意难消，尔后被打造成剑时，影响了持有它的点轮回，入魔的他，残杀无数生命。天疆、苦境、黑海森狱发生大战，点轮回受论剑海教唆阻挡去往增援牧神的剑鬼非人哉，双方由此结下俗世之仇。千年之后，化身荷叶禅师的点轮回为了再次封印血阳残剑却没有成功，反而受到残剑控制，一意对上拥有银骠玄解的原无乡，后在照世明灯点化下，时而清醒，时而沉沦。

# 年几何

黑笼的领导者，也是修关者中的天才，因数次保护着黑笼，被黑笼的居民尊称为“壤父”，个性冷情疏离。因修‘禁道’所以长年眼不开，嘴不张，更是人族圣皇妲眸姬的师尊。更尝试着将已经散佚的灵气寻找回来，为这方生灵寻找生机。

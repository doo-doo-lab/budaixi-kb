# 葉飄零 (叶飘零)
================================================================================

葉飄零

權謀者問奈何的同路人，臉罩面具，具有殺手神秘的孤傲氣質，不問原由，唯命是從。曾暗伏文風谷外，輕易奪取邃無端體內的窮霄辟冥劍，更將正氣凜然的劍意，邪化為魔相千劍。

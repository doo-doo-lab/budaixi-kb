# 克灾孽主

霹雳布袋戏虚拟人物同义词鳌天（《霹雳布袋戏》剧中人物）一般指克灾孽主克灾孽主·鳌天，霹雳布袋戏虚拟人物。元种八厉中的“雷之厉”，有着沉稳霸气的枭雄之姿，城府深沉，工于算计，曾化为鳌天渗透共仰瞻风，娶圣女为妻，目的在于找出真正的死亡预言一书。与忌霞殇一战重伤而销声匿迹，后又伺机返回，先后取代大风鉴与云汉院之身份。

## 人物设定

诗号：天赐灾，吾掌孽，八极蒙祸，九夷肆虐，凶岁立寒烈。初登场：霹雳兵燹之问鼎天下 第24集退场：霹雳战元史之动机风云 第14集（死于天之佛）根据地：阙阗关、皇极七行宫、异诞之脉、祸海鬼渊

## 人物能力

- **武学**: 违天之孽、肆灾天赦孽、灾刑逆破、横道立凶岁、困功锁所有物：赤方镭、死亡预言

## 人际关系

妻子：胜鬘天姬鳌天儿子：刀悬一命、孤竹隐龙（孤狼）同伙：天之厉、劫尘（地之厉）、贪秽（泽之厉）、魈瑶（风之厉）、魑岳（山之厉）、咎殃（水之厉）、剡冥（火之厉）好友：冰无漪仇敌：忌霞殇最崇敬的人：天之厉最讨厌的人：魑岳

## 人物配乐

- **克灾孽主·鳌天克灾孽主（鳌天角色曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选35》
- **黯天峰之会（鳌天vs魑岳）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选43》

孙敬凡老师2010年作品，以战神武戏为发想创作，充分发挥弓弦乐器合奏的特色，澎湃激昂且丰富多变，曲风明亮清快又刚劲律动，间奏佐以管乐器和敲击乐器为辅，营造出气势对峙的收幕震撼。乐曲初用于问鼎天下第十七集，黯天峰，终日乌云罩顶、不见天日的晦暗绝岭，却同时降下两条诡异巍然的身影，一者克灾孽主“鳌天”，一者葬界刁雄“魑岳”，潜伏武林已久的两大厉首终于再度聚首

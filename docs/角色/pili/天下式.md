# 天下式

性格冷漠如深渊冰镜，道通天人，法窥阴阳，精晓道术机关，为达前无古人之境，另辟修道法门，而近乎魔道，强调修道不拘一格，只要能成就一代宗师，并秉持自我，都是可行之道。昔日与天极、地限并列为太上府三府尊，修为犹在两人之上。

# 醉饮黄龙

霹雳布袋戏中的角色。过去曾为上天界诗意天城之领导者“天尊皇胤”，同时亦是御天五龙的领导者，手握神刀龙鳞，英姿飒爽、豪气干云，极为重视袍泽之情。昔日曾与刀无后联手斩杀罗喉，事后却遭出卖而受创隐遁多年，随着刀龙逐一浮上台面，遂以葬龙壁一一试探，并使其领悟自身来历与天命，只希望兄弟能携手一同回归上天界。

## 角色背景

醉饮黄龙本为四魌界中上天界意天城御天五龙之一天尊皇胤之转世。因真身是五爪金龙，因此被称为五龙中的皇者。个性直率、行事风格仁慈，奉行王者之道，是五龙中最受尊敬的兄长。在如此具有王者风范的外在下，内心也极重视兄弟之情。无论发生何事，都会守护所有兄弟。转世到苦境后成为醉饮黄龙。他极为重视袍泽之情，昔日与战友刀无后联手斩杀上古枭雄罗喉，事后却遭出卖受创隐循多年。然而在刀龙们开始踏入江湖后，醉饮黄龙也开始动作，希望能带兄弟们回归上天界。

霹雳震寰宇之刀龙传说章数对手地点战况胜败27罗喉月族战场本场战斗为佛顶冥塔所记录，当年醉黄龙与刀无后在月族圣战时，联手斩杀上古枭雄罗喉。

胜40刀无极天下封刀废墟醉饮黄龙与笑剑钝、漠刀绝尘、笑剑钝共同对上炽焰赤麟刀无极。

漠刀绝尘死于刀无极刀下，醉饮黄龙与啸日猋、笑剑钝败走。

败霹雳震寰宇之龙战八荒章数对手地点战况胜败08枫岫主人荒野醉饮黄龙半途拦截枫岫主人，指其为上天界逃犯楔子，要以武力将其捉拿归案，但因笑剑钝中途阻止而做罢。

平10黄泉荒林刀无极被黄泉偷袭重伤后又遭黄泉追杀，醉饮黄龙来救，带走刀无极。

胜11刀无极傲天武殿以自身龙气为刀无极疗伤，反遭刀无极突袭，危机时黄泉赶到，将醉饮黄龙救走。

败13拂樱斋主拂樱斋为请枫柚主人医治垂危的笑剑钝，醉饮黄龙只好接受枫岫主人提出的杀死拂樱斋主的条件，但却因拂樱斋主没有多加反抗，并质疑枫岫主人的动机与目的而收手。

胜15代行者莎莉罕九天之下醉饮黄龙正欲往九天顶救治重伤的啸日猋，却遭佛狱使者莎莉罕半途截杀，醉饮黄龙轻松击退来犯之敌。

胜19佛业双身、灭度三宗妖世浮屠为了消除漠刀绝尘身上的死神之力，本就真气耗损严重的醉饮黄龙答应佛狱使者的要求前往妖世浮屠取越行石。

但在妖世浮屠，醉饮黄龙先遭夔心吞噬力量，又被佛业双身与灭度三宗联手围攻，本就有伤在身的醉饮黄龙最终含恨惜败。

## 角色评价

黄龙新造型醉饮黄龙，身为御天五龙之首，极重视兄弟情义的个性，让他面对炽焰赤麟的反叛，仍选择一再退让，为护全每一位兄弟尽心尽力，最后，四刀龙再度聚首，尽释前嫌，想必也是醉饮黄龙最大的欣慰。尽兄长之责，燃袍泽之情，天尊皇胤虽死无憾，然可悲者，五龙不复。

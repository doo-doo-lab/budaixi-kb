# 忘尘缘

天佛原乡客座奇人，双目不视、左耳不闻、右臂残疾，无嗅觉、味觉，曾因巨变而使脑部受创，从此丧失某种情绪，但心境却远比健全之人澄明。在审座、师座相继身亡后，受托领导目前的天佛原乡，赐慧座头衔。

诗词

# 佛公子

弃儒从佛的修道高僧，身穿云霓袈裟、手持黄金钵，胸挂七彩霞琅，足踏日月鞋，身背无筝琴，斯文俊雅、贵气逼人。只有超脱七情六欲三毒之人，方能聆听到无筝玄音。

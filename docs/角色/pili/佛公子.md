# 佛公子

弃儒从佛的修道高僧，身穿云霓袈裟、手持黄金钵，胸挂七彩霞琅，足踏日月鞋，身背无筝琴，斯文俊雅、贵气逼人。只有超脱七情六欲三毒之人，方能聆听到无筝玄音。

### 人物生平

曾经求学于学海无涯，并成为学海教统，一人之下万人之上。后来由儒转释，号雅僧佛公子。甫一出场，就极尽神秘，一直致力于帮助武林正道，为人从容淡定，气度飘逸，服饰华美。然其高雅贵气一度被众人曲解为招摇撞骗的妖僧，江湖侠女左手香打抱不平与雅僧理论，却因与佛无缘而始终无法自行进入无佛寺。雅僧之琴音引来剑圣与楼无痕，在雅僧引导下，两人最终体悟了自己所追求的道；后帮助孽角恢复善良本性，帮助神州灾民度过劫厄。学海无涯因武林三宝之争强势介入武林，也让身为学海最高位的雅僧决心卸下教统一职，专心求佛。于是佛公子推荐曲怀觞参选教统一职，却因东方羿之阴谋而出现变化，淡出学海的雅僧为阻止众生抢夺罗喉戒玺给武林带来更大危机，以一人之力击退众豪杰；并化解未来之宰的强势攻击，之后卧佛、大红袍提及众天灵识一事，并借由往圣留迹，雅僧最终明白自己所追求的天命：原来自己乃灭境众天之肉身，在天启之日将承接众天灵识回归。无奈因一生悬命之背叛，打乱了大红袍之布局，使得灵识回归被破坏，功体降至最低的佛公子遭阎王锁杀害，众天灵识消散，灵识承接失败，佛公子也回归凡尘，成全了天命，也成全了自己。

与太史侯、东方羿为多年至交好友，却因东方羿之挑拨，雅僧与太史侯嫌隙暗生，最终互为至交的两人背道而驰，之后学海竞选教统，东方羿之阴谋显露，雅僧与太史侯之宿怨化解，后东方羿欲以驭日神箭射杀雅僧，太史侯出手相助；雅僧回归天命之际，太史侯以箫音告慰好友在天之灵。“大德曰生，菩提愿满；哲人其萎，薤露声寒。”佛公子此生一直追寻着自己的天命，弃儒从佛也只是天命的一部分，灵识回归，是否也是另一个天命的开端亦或终结。也许潇洒而来，飘然而去，不带多余情感追寻着自己的道路。

### 人物配乐

◎雅僧（雅僧佛公子角色曲）曲/编曲：浩旭 收录于《霹雳英雄音乐精选十八》

寒筝匆匆，笛音徐徐，象征沉稳内敛与世无争的绝世高人飘然入世，简洁利落的旋律，抒情文雅的曲调，仿佛陈述着角色的斯文俊雅，让听者不禁余音绕梁印象深刻，是首作者相当经典的武侠风角色代表乐曲。

◎风云雨（佛公子武曲）曲/编曲：阿轮收录于《霹雳英雄音乐精选十九》

紧促的节奏如风似雨，搭配上敲击乐器的铿锵之声，霎那之间暴雨点点、狂风阵阵。一向温文儒雅、无争无求的雅僧佛公子绝学初现，慑人气势撼动山泽，风云变色！浑厚战栗的低音弦乐组和定音鼓节奏营造整曲气势一如排山倒海而来；嘹亮的笛音高亢而优雅，在磅礴紧凑的乐声中显现出无比从容、自信、高贵的先天气质，辉映着佛公子特异不凡的功体与修为。

◎天命回归（佛公子之死）曲/编曲：阿轮 收录于《霹雳英雄音乐精选十九》

柔和的琴声搭配弦乐器匆匆弹奏，正如佛公子儒雅的性格。超脱七情六欲及三毒，无争、无求、无挂碍。一生追寻天命之所归，为武林和平而努力。中段曲调倏尔转强，似在描述众人对一代宗师高人的不忍与不舍！当远方黎明曙光逐渐升起，澎湃的心绪逐渐化为淡然，最黑暗的时刻即将离去，期待天启之时还能够有再见之日。

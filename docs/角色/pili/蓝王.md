# 君海棠

霹雳布袋戏虚拟人物君海棠，霹雳布袋戏虚拟人物，

## 角色设定

- **名称**: 君海棠性别：女称号：媂君身份：开天六王之媂君诗号：自古红颜多薄命，不信此语，还君海棠。根据地：云深不知处

## 角色能力

- **武学**: 碎梦弯·“海棠蚀月、琼台飞雪、倾城一刎”功体：海棠万毒身武器：狐刀碎梦、毁日神弓所有物：半月封、颤声草、绕指柔、龙咽醉、七步绝、镇音双钹

## 角色经历
炼毒制药【半月封】乃媂君独门之毒，专为紫衍炼元极所制，赠予炀君策（创神下05）【绕指柔】乃春毒，原料为颤声草。

混入沉香檀木，可使人成瘾（创神下05）【龙咽醉】特制酒，可暂时压制绕指柔的毒性，专为御清绝备制（创神下05）【毒海七品奁】为巨王所制备，约定与其交换兵器的七项药与毒（创神下17）剧照【七步绝】限煅云衣一个月内夺取深渊玄藏之物，必要时对巨王使用之毒（创神下20）少时经历少年君海棠 创神篇下阕 第21章及笄之年遭养父猥亵，为自保而将养父杀害。

村民不知缘由，议论其弑父逆伦，最毒妇人心。

（创神下21）此两事对其身心造成极大伤害，影响其日后心性及行事作风。

被困于深脑会议出来之后与御清绝相识，最终相爱，然则这只是一个凄楚的爱情故事。

在美貌与功体之间，最终选择了自己的功力，也许是缺少信任，觉得失去容貌便会失去御清绝，这或许是悲剧的最大根源。

话语：属于君海棠的，就是一粒沙，你也别想占有。

## 会刊相关

会刊233月刊232期预言堂人物——媂君君海棠六王之中的唯一女性，秀丽脱俗，美艳不可方物，但心思难测、捉摸不定，且手段狠毒、善魅惑之功，于深脑长议丧失意识之时，恰巧被御清绝所救，清醒后，不告而别回到云深不知处。得知御清绝对自己有所痴迷，决心将御清绝收为己力。

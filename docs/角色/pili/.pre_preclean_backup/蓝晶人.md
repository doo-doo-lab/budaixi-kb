# 蓝晶人

蓝晶人（霹雳英雄战纪）

寄生蓝晶石中的奇人，性格狡猾且粗鲁残暴，甫登场便于玉波池欲以蓝晶毒来一举歼灭素还真，却反被龙气所伤，后与太黄君联手针对天虎八将，并夺炽霹雳将之占为己有。

## 来自百度百科的补充

布袋戏《霹雳英雄战纪之刀说异数》中的人物

蓝晶人性格狡诈残暴，首次现身即以蓝晶毒袭击素还真却遭龙气反噬。该角色初登场于剧集第五章，获得炽霹雳作为寄体后，其行为构成魔龙八奇阵营重要战术支点。蓝晶人曾强迫一线生修炽霹雳并交出使用手册，随后参与太黄君安排的伏击素还真的行动。但在琉璃仙境的战斗中，因一线生设下的陷阱，炽霹雳报废，蓝晶人也被困于其中。其重伤也引出了太黄君与魔域的交易，对未来剧情产生影响。

作为魔龙八奇阵营关键反派，蓝晶人以毒术与寄生能力推动剧情冲突，并通过控制炽霹雳这一角色履行其剧情职能。

## 主要经历

蓝晶人收获炽霹雳后遇到魔域的人，一个雷火弹导致炽霹雳的眼睛损坏，于是强迫外出的一线生修理炽霹雳并索要使用手册。之后应太黄君邀请，蓝晶人在琉璃仙境参与伏击素还真的计划。伏击战中，由于一线生留下的使用手册存在陷阱，蓝晶人未能完全驾驭炽霹雳，导致炽霹雳被搞成报废状态，自身也被困于炽霹雳之中并受重伤。蓝晶人的重伤促成了太黄君后续与魔域的交易，对未来剧情产生重要影响。

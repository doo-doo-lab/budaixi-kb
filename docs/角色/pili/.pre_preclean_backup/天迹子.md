# 天迹子

奇花八部中的怪花，个性较为尖酸刻薄，善作两面人，对于妖绘天华的炭绘情蛮花之术，内心颇不以为然。擅使毒粉，其因习花粉具有麻痹之效，能牵制敌人行动。在步出留妖山城途中，与劫花遭花脸杀手伏袭，双双毙命。

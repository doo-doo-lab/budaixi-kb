# 万俟焉

个性爽快重义气的先觉角色，功力高深，喜欢随自己的意愿做事，为了收金太极为徒不惜舍弃辛苦铸造的龙骨圣刀。因紫锦囊之故而在不知不觉中替正道做了不少的事情，受秦假仙的帮忙寻找其师万烛公，而后为了报杀师之仇而四处追杀一刀起程。

## 来自百度百科的补充

万俟焉是台湾布袋戏剧《霹雳英雄战纪》系列虚拟人物。作为龙骨圣刀铸造者与持有者，他性如烈火，行事端凭自身喜恶，虽小处迷糊却大处精明，秉持大义具侠义心肠。现世后便积极要找回龙骨圣刀的下落，并开出难题给欲取龙骨圣刀的素还真、太黄君二人。其武学以火系绝技为核心，包括火龙腾日、云火转龙变等招式，刀柄刻有姓名。与哀三声形成敌对关系。最终在火龙舌战役中渐趋败势。万俟焉一生纠缠神兵因果，刚烈性格与炽热武学形成鲜明印记。退场旁白以“傲骨垂树”“朗朗气节”暗喻未了亲情，为剧情增添悲壮色彩。

# 虚无（汉语词语）

虚无（拼音：xū wú）是汉语哲学概念，原指道家对"道"的本体描述，《庄子·刻意》称"虚无无为，天地之平"，《汉书》载道家"以虚无为本"。

佛学将其解释为"一切事物都没有自性"。

其内涵包含三重维度：本体论层面指道体包容万物的特性；

修养论层面主张清静无欲，如《素问》提出"恬惔虚无，真气从之"；

认识论层面含荒诞无稽或空无所指之意，王符《潜夫论》称其为"乱道之根"。

宋冬在艺术创作中通过镜子探讨空无的临界状态，认为镜像承载着"可视而不可触及"的虚实辩证。

该概念自先秦道家发端，《上林赋》曾延伸其空间维度含义。

近代衍生出历史虚无主义思潮，表现为对历史人物和事件的否定性叙事。

在文学领域，何景明以"缥缈凌虚无"呈现其意境表达。

中文名虚无拼 音xū wú近义词飘渺 空无 虚空 空虚 反义词实际 真实 存在 释 义荒诞无稽等

## 来自百度百科的补充

虚无，霹雳布袋戏虚拟人物。

从宇宙混沌之中的废气所聚集而成的特殊存在，曾被封在上天界的银河监狱之中，因故逃出后，隐藏在炽炼界深处的混沌之扉当中，运用一切手段要打破混沌之扉，曾现世附身在天道主上，但最终被三光之玉打回混沌之扉。在炼魔塔结合阎神之力协助下，贯通异界通道，化为暗气附体于异葬天道之上，并恢复其本来面貌。

在《霹雳侠峰》剧集中，虚无于炼魔塔寄体降生，开启灭世之行。虚无寄体降生后，虽与计无谞合作，但本身有自己的准则与想法，借力使力、将计就计，最终算计了武神独千秋与之合体，也使得创世神无因此诞生。随着虚无的力量扩散，南域亦受影响。逆神七皇二度集结，众人齐心合力，最终联手对付虚无的野心，开启了一场逆神之战。

### 人物经历

来自宇宙混沌废气的集合物所成，号为万魔之罪，罪中之神，虚无。最早在剧中第一次出现的时候，是只有混沌之扉里面的动画形态，而虚无这两字首度出现，是在破坏神厄祸的口中：神之前，唯有虚无。

为何破坏神厄祸会讲出这样的提示，其实也是代表，世上万物本自虚无而生，更以虚无而终。其中虚无所代表的混沌，同样也是破坏神厄祸所掌握的法准。破坏神厄祸，号为诸神恶梦，在诸神中居于高位，手上所掌握的法准，除了混沌法准、罪衍法准，更有第三个不为人知的柲密，而这个设计，乃因虚无本身与破坏神厄祸、太曦神照的存在息息相关。

虚无从诞生以来，便是接受着太曦神照的计划安排，只是虚无自己并不清楚他与太曦神照的关系，太曦神照创造虚无，主要是让生命为了自己的行为付出代价，这一切的罪恶与废气，其实都是生命运行所造就的结果，而太曦神照赐以生命气息，更趁着破坏神厄祸沉睡之时，让混沌法准与虚无合一，创造了席卷整个武林的恶魔，罪神虚无。

虚无初次降临苦境之时，便遭遇武神独千秋强力的抵抗，因为两人之间有着密不可分的宿命与相遇，独千秋因为虚无的缘故，吸收了好友岳云深的内力，进而蜕变成为武神，却与虚无之间，因此拉开了宿命的战役。最早的一场大战，两人交战的威能，毁灭了整个霓虹村，也种下了未来穆武衡权、寄尘寰两人之间复仇的种子。

虚无因为与武神之战，双双负伤，而本体逃往其他境界的时候，被诗意天城御天龙族拘捕，随后囚禁在银河监狱，藉此继续养伤，而就在许久之后，虚无自己打破了空间禁锢，闯入炽炼界，就在力量即将侵入之时。雨枫族早有预备，建造混沌之扉，守住虚无的出口，也造成后来一连串的悲剧，不停的发生。在《霹雳靖玄录》中，虚无的力量扩散影响了南域等地。

就在霹雳魔封过后，夜雨沧神牺牲自己，却意外中了虚无之计，虚无借用沧神父亲，独孤无行的身体，欺骗了沧神入局，而就在虚无踏出炽炼界时，却遭遇三教人马全力的反扑，使得虚无再度被封印回混沌之扉。

就在霹雳侠峰，炼魔塔上，百炼师等人再度引接空间通道，利用无间阎神之力，再度让虚无寄体降生，随后，虚无在异葬天道体内现出真面目，正式登场。也开启了一段真正的虚无灭世之行，过程中虽与计无谞合作，但虚无本身却有自己的准则与想法，借力使力、将计就计，最终算计了武神独千秋与之合体，也使得创世神无因此诞生。但逆神七皇二度集结，众人齐心合力，最终联手对付虚无的野心，开启了一场逆神之战。

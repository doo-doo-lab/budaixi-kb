# 小七

意琦行身中仙门禁招“还童返照”，回到七岁时的小天骄状态，自称“小七”，机智善良，富有侠义之心，与澡雪、秋水组成小七修，行走武林，行侠仗义。虽是初生之犊，仍不改行侠仗义之心，协助秋水等人对抗造孽的阴谋。

## 人物记录

1、意琦行疑似中了仙门不传禁招，身体、记忆倒退到童年，自称小七，小小年纪，胆识过人，与澡雪、秋水组成小七修，行走武林，对抗阴谋。（群英事纪，月刊278期）

2、少年侠气，推翘勇，矜豪纵，交结论英雄。风云我辈，系取天骄种，肝胆照，死生同。一怒不收锋。（小七所吟，改编自贺铸《六州歌头·少年侠气》）

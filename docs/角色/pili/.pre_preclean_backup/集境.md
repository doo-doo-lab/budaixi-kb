# 集境

霹雳布袋戏术语“集境”是霹雳布袋戏中“苦集灭道”四界之一，也是第一个登场的异度空间，可通过时空裂缝与苦境往来。该境土地贫瘠，因而屡次意图入侵苦境。曾由武皇半尺剑等领导，实行集权制度，划分为“三宫六殿十八楼”，其部分科技水平超越苦境。其人物如时空超越人曾借助“回力盒”等活动于苦境，组织如“太幻楼”拥有将人送入苦境的机器及“细胞分离器”等技术。中文名集境境界特色有完全的集权制度的境界主要组织一皇三宫六殿十八楼、三仪三司十二殿通道路径光明道、挪体超空仪、时空细缝、时空转换台、妖世浮屠定 义霹雳布袋戏中苦集灭道四界之一

## 来自百度百科的补充

### 境界简介

集境的地理环境设计上颇为一致，在花影人出现之时便已说明了，集境整个土地极为贫瘠，因此集境便处心积虑的想入侵苦境，早在武皇统一集境之时，便设下了完全的集权制度，将整个集境划分为一皇三宫六殿十八楼，但武皇被三宫背叛，导致集境群龙无首，直到灯蝶修万年化身花影人统一集境后，方成立十八楼联盟大举进犯苦境，并消灭了魔域第一殿。而后武皇半尺剑自吸功石复出后再度统一集境，虽是表面上与一页书维持友好关系，但暗地里与鬼帝、万魔天指勾结，伺机对付一页书、素还真，最终仍亡于一页书的天龙吼，自此集境便再无任何消息，直到妖世浮屠出现，贯通了集境，带出了全新的集境组织。全新的集境仍是有如武皇统一的情势，只是整个架构改变，改为三仪、三司、十二殿，其中以圣帝为最高领导者，由于妖世浮屠入侵集境，造成了权力斗争的影响，破军府的烨世兵权和等待已久的智者千叶传奇出现，便设下一局，在太君治被诬陷之时，掌控了整个集境权力，并以雄王取代圣帝，烨世兵权可说实际上统一了集境，并藉著佛业双身的妖世浮屠顺势将整个集境降落至苦境大地上。

### 发展历程

集境是霹雳布袋戏中第一个出现的异度空间，由于土地极为贫瘠，因而屡次入侵苦境。最高领导者武皇设下了完全的集权制度，将集境划为三宫六殿十八楼，据《蝶龙之乱》描述，其具体构成为：三宫-贵王宫、朝圣宫、岁皇宫；六殿-普晋殿、国颂殿、风霞殿、玉和殿、紫熙殿、太和殿；十八楼-昭天楼、太幻楼、觉障楼、舍永楼、海芸楼、无常楼、龙华楼、师尹楼、白阳楼、楼中楼、旋元楼、旋真楼、寂身楼、亦如楼、游离楼、逐迷楼、因象楼、心性楼，其部分科技已超越苦境中原。

### 境界特色

境界名称：集境出现时间：霹雳剑魂——霹雳天命、霹雳震寰宇之刀龙传说——霹雳兵燹之圣魔战印（第3集 苦集两境分离）通道路径：光明道——连结集境、道境之间的道路，挪体超空仪便是经由光明道前往道境。挪体超空仪——能自由来去苦集灭三境的宝物。时空细缝——由无常楼三人所开启的时空细缝，可自由来往苦境、集境，更可穿越时空前往过去。时空转换台——集境太幻楼的宝物，可自由来往苦境、集境。妖世浮屠——由佛业双身控制的妖世浮屠，可强行穿破苦集两境空间界限，使两境空间结合。（六出飘霙、素还真等皆是因为妖世浮屠造成空间异变，才能顺势通往集境）境界特色：有完全的集权制度的境界。境界主要组织：一皇三宫六殿十八楼（霹雳剑魂——霹雳天命）：三仪三司十二殿（霹雳震寰宇刀龙传说——霹雳震寰宇之兵甲龙

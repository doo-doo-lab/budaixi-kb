# 雪怜

八歧邪神肆虐下的受害者，丈夫被邪神杀害，将其魂魄化为一口伞。雪僯为报仇，千里迢迢至东瀛远赴魔剑岳，只为求得赤华剑，但却以出卖自身灵魂为代价，至此困守魔剑岳。唯有引渡三千怨魂，方能离开血池孤人桥。

## 主要经历

赤华剑雪怜原是八歧邪神肆虐下的受害者，其丈夫被邪神杀害，魂魄被化为一口伞。为报此仇，她千里迢迢从东瀛远赴魔剑岳，求得赤华剑，但因此出卖自身灵魂，困守魔剑岳。唯有引渡三千怨魂，方能离开血池孤人桥。

# 玄定怒航

天佛原乡洗罪三尊之一，其外显形象皆与黑色相关，行事风格稳健，心计沉着难测，亦为佛乡参加凋亡禁决的代表，与同为追亡狩的战云界、黑狱合纵连横，猎杀辟命敌。

## 来自百度百科的补充

玄定怒航为天佛原乡洗罪三尊之一，代表佛乡参加凋亡禁决，成为追亡狩，并与战云界、黑狱等势力合纵连横，猎杀辟命敌。在《霹雳侠影之轰动武林》第2章初登场后，玄定怒航拦路并联合鬼荒地狱变围攻身怀金钥的辟命敌超轶主。后与战云界的御宇天骄结盟，共同进入鉴兵台捉走吾不留与判死生，并再度尝试拦杀超轶主但失败。期间，玄定怒航与同修赤慧慈航讨论在凋亡禁决中拉拢同盟的策略，并主动寻找战云界洽谈合作。玄定怒航最终于《霹雳侠影之轰动武林》第11章退场。

盟友：在凋亡禁决中，作为追亡狩，曾与战云界、黑狱合纵连横，并与御宇天骄结盟，共同猎杀辟命敌。

敌人：在凋亡禁决中，其辟命敌（主要猎杀目标）为超轶主，曾与鬼荒地狱变联手对其进行围攻。

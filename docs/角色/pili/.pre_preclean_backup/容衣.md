# 容衣

寒月蝉之女，外表看似单纯、没见过世面的女孩，实则授命卧底千飞岛，但其本性善良、体贴人意，因照顾落难天忌而渐生爱慕之心，自愿为天忌失明时的双眼…。

## 来自百度百科的补充

在作品《霹雳天下》中，容衣的形象设计较为素雅，定位为辅助角色，拥有回复技能。

其死亡促使兄长炎熇兵燹慢慢领悟了情感，有了温暖的人性。

容衣的死亡对炎熇兵燹产生了重要影响，使其领悟了情感，有了温暖的人性。此外，角色评析曾见于霹雳会月刊第120期《明月不谙离别苦 流水难忆相思情》与第163期《月下桃花梦佳期：西出关外送别离》。

在衍生作品方面，容衣的形象出现在手游《霹雳天下》中。在游戏中，她定位为辅助角色，形象设计较为素雅。其技能包括具有回复功能的主技能，以及可以恢复我方同伴怒气的技能。

在手游《霹雳天下》中，容衣拥有加怒技能。她定位为辅助奶妈，拥有单体回复和恢复同伴怒气的技能。

## 出场记录

第4集

燕子丹将天忌带回千飞岛后就不怀好意地向天忌挑战，天忌的手被伤，容衣前去包扎。

第5集

与天忌第一次亲密接触。（为天忌送茶，天忌目不能视，误会就此发生）

第6集

燕飞虹回岛，遇上天忌，发生言语冲突，容衣代天忌回话，挨了一巴掌。天忌与醉轻侯一家聚餐，容衣为天忌夹菜。燕飞虹出言嘲笑，天忌到海边散心。容衣前去安慰天忌。（要了解容衣，此集必看。容衣就是在这一集才为人重视。她安慰天忌的一番话包含着她对人生的感悟，很有哲理，天忌应该是此集才对她另眼相看。）

第7集

天忌练剑，容衣端茶擦汗。天忌的剑避开容衣。燕飞虹出言讽刺。燕飞虹欲打容衣，天忌英雄救美。（感情慢慢发展中）

第9集

燕飞虹挑战天忌，被天忌伤右手，容衣受命上前观视，被燕飞虹打了一巴掌，燕子丹上前关心容衣，并出言嘲讽天忌无能保护容衣。（燕子丹来凑热闹了，只要有关天忌，他什么都要掺一脚，比燕飞虹更可恶）

第12集

醉轻侯赠剑天忌，命容衣带天忌离开千飞岛。燕子丹拦路，天忌败燕子丹，带走容衣。

第14集

容衣心系天忌，问天忌是否拖累他，天忌答讨厌一个人就不会与她比肩同行。容衣心中欢喜，问天忌以前可有人与她一般与天忌同行，说话。天忌答有，容衣问此人与容衣相比如何？天忌答母亲无可比拟。

第15集

容衣遇兵燹，救至雪洞。希望宫城城主宿文馗前来救助。容衣回转天忌住处，天忌冒雪在外等候，嘘寒问暖。两心相倾。

第16集

兵燹脱离危险期，天狱毒烟来犯。容衣初次显露武功。

第17集

天忌发现容衣最近一段时间晚归。容衣以摸索路线和采野菜应对。天忌让容衣别想太多，言语关心。容衣看望兵燹，兵燹醒转，问何人救他，言语中逗弄容衣。容衣回到天忌处，告诉天忌要外出买一些东西，天忌与找上大雪原草屋的燕子丹对决。

第18集

燕子丹告诉天忌容衣有秘密，她救了兵燹。天忌表示自己心中有数。容衣探视兵燹，兵燹言语调戏。兵燹得到魔刀焰炽，离开古洞。

第19集

兵燹回到古洞内。容衣到来，兵燹逼问容衣救他的目的。容衣表示有些事是心甘情愿付出，不求回报，并说兵燹是可怜人，没有正常人的七情六欲。兵燹被容衣的话语所感动。容衣走后，天忌现身，两人以性命及容衣相赌搏命。容衣发现天忌不在，急转回兵燹处。

第20集

天忌战败，剑断。容衣现身答应跟兵燹走。半路上兵燹关心容衣，让她在茶棚休息。百邑城在旁监视。

第21集

容衣与兵燹谈话。兵燹言语中似乎对天忌吃醋。秦假仙被苍魔刀追杀。兵燹听到后要容衣先去客栈投宿，自己前往会苍魔刀。

第22集

兵燹杀苍魔刀后来到客栈内。百邑城现身要兵燹去希望宫城见真正的母亲。兵燹不悦。兵燹与容衣到邹纵天处发觉邹纵天不在，后听到秦假仙谈论黄泉刀一事，决定到死亡沼泽一探。半路容衣劝兵燹去希望宫城。

第23集

兵燹见寒月蝉，寒月蝉在酒中下迷药，留宿兵燹，晚上派人偷魔刀，被兵燹所杀，兵燹生气地带容衣离开，前往死亡沼泽等黄泉刀向天借命。

第24集

兵燹在死亡沼泽等向天借命，神秘黑衣人（应该是希望宫城城主宿文馗）引开兵燹。

第25集

兵燹为调查容衣背后的人故意赶走容衣。随后跟踪。

第26集

容衣谨慎而行，兵燹随后跟踪。百邑城与容衣接头后两人分两面三刀路而行。子时，容衣被施以五神血祭，兵燹及时来救，杀死一个百邑城。

第27集

兵燹以一招日毁星沉救下容衣，带容衣到树林后要容衣原地等待，自行返回祭坛，却见祭坛空无一人。再回树林，容衣不见，只在树上留字。兵燹心恼，不知不觉回到大雪原，回想过去与容衣相处的一切，最后决定去希望宫城找答案。

第28集

路上，容衣被两名百邑城包围，危急时候，绝鸣子救下她。

第29集

容衣漫步而行，不知不觉回到千飞岛，恰遇回来祭拜的白马夫妇，看到白马纵横与燕飞虹两人的亲密情形，自伤身世而流泪。

第30集

路上，容衣遇寒月蝉，最终容衣为兵燹决定牺牲自己。容衣向母亲要求见天忌一面。希望宫城外，容衣与天忌重聚，两人互诉别情，表白心意。容衣别过天忌，回到寒月蝉身边，向寒月蝉要求见兵燹一面。寒月蝉不肯。正要将容衣带下，兵燹前来，与寒月蝉动手。容衣趁兵燹不备向其洒下迷药，兵燹悲愤交加狂笑倒下。

第31集

容衣死于五神血祭，天忌欲救不及，抱着尸体回到大雪原，将容衣葬在他俩当初所居的小屋前，并立誓今生誓报两仇——兵燹灭族之仇，容衣被害之仇。

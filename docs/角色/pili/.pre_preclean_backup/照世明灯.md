# 照世明灯

《霹雳布袋戏》中的角色照世明灯，是《霹雳布袋戏》中的虚拟人物，性格仁慈沉稳，常持明灯，有“慈郎”之称。照世明灯是银骠玄解的创造者，为解龙魂之祸而造此器。他曾多次退隐又因苍生需要而重出江湖，在素还真隐遁时承担引领正道之责。在《霹雳封灵岛》剧情后，照世明灯自言责任已了，最终退隐不再出。

## 角色形象

名称：照世明灯照世明灯称号：慈郎性别：男诗号：难定纷纷甲子年，千魔荡荡白阳天/白阳荡荡伏魔天，苍天旨意著书命，诸子虔诚扶道颠；佛灯点亮华光现，一线生机救末年。身份：道教十三道之天真君、天蝶盟第二教主灵蝶化身：寒夜残灯、金色人影初登场：霹雳眼 第11集根据地：万年不灭千灯石、黑暗道、远浮天、腾龙殿嗜好：点灯笼，在黑暗道里和紫阳子、玄真君聊天外貌：面似冠玉，发如银丝（《霹雳眼》中素还真描述）

## 身份解疑

既然官方给出的答案白发照世明灯即是真正的照世明灯，命七天不是，那就讲什么其他理由也没用，编剧的话就注定了他作品的一切。

但如果讲身份由来却是依然清晰的。

命七天并非真正的照世明灯，乃是崎路人为了引出照世明灯而让其假扮，那期间黑发的照世明灯正是命七天，而真正的白发照世明灯隐居幕后一段时间。

关于白发照世明灯为何要拥有九天神罩目的不明，只是说脸部出现溃烂，但是大家要注意，可以肯定的是如果白发照世明灯如果是命七天的话九天神罩可以恢复其真面目，如果他真是命七天他分明是给自己找不自在。

剧情截图中期出现的寒夜残灯照世缘正是之前的白发照世明灯，两者为一人是无疑的。

有一点可以看出崎路人和照世缘的对话提到，崎路人为了引出照世缘才让命七天假扮照世明灯，这里可以看出他对着寒夜残灯说为了引出”他”，但却不是装作“寒夜残灯”而是“照世明灯”，这就说明有可能寒夜残灯曾经就叫照世明灯，但后来因为崎路人的血案牵涉到自己，又出现了假照世明灯，所以为了区分开来所以化名“寒夜残灯”。

还有就是金小开初现江湖时寒夜残灯竟然就知道他是叶小钗的孙子，把他带去交给叶小钗，就更说明寒夜残灯就是当年将幼年时的金小开交给代行姥姥抚养的照世明灯。

而在最后这个问题就可以更准确的看出来，照世明灯被千子弹杀死时有段回忆，是白发照世明灯时为叶小钗抵挡一钱一命一刀，还有是寒夜残灯被天祸妖狐攻击的画面，却完全没有“黑发照世明灯”的任何影像。

这就可以很清楚地说明自始至终，白发照世明灯和寒夜残灯以及后来的出场的照世明灯为一个人，而黑发照世明灯为独立的命七天。

至于寒夜残灯为天蝶盟第二教主的身份有人提出过疑问，但是提出疑问的人不要忘了霹雳里人物的身份本来就错综复杂，所以加入哪个组织不能代表其心性的善恶（比如，史艳文也曾加入欧阳世家，成为欧阳上智的义子），寒夜残灯很可能和灯蝶修万年有其他交情才加入了天蝶盟。

## 经历

在《霹雳眼》时期，照世明灯以“不可无罪受审”为由言退欧阳世家，并迫使欧阳世家先解除素还真的毒患，让他在大众面前证明自己的清白。

在《霹雳狂刀》中，照世明灯再次出场，和玄真君一起辅助素还真对抗合修会，多次帮助叶小钗，教育恶劣的金小开。

在《霹雳幽灵箭1》中，圣贤诸、当世道君和因果来进攻猜心园被非凡公子所擒，照世明灯为保释他们向非凡公子许下三个不违背天理的承诺。

照世明灯数次退隐，之后又数次重出，在《霹雳幽灵箭1》中配合神秘女郎对抗魔魁之女与非凡公子，在《霹雳英雄榜之风起云涌》中重出帮助卧云先生破灭元塔，在《霹雳英雄榜之争王记》中重出对抗天策真龙与魔剑道之祸。

照世明灯因徒弟天道明灯陆慈心对道教失望而欲弃世，被素还真劝慰。

照世明灯为银骠玄解创造者，乃因昔日为解龙魂之祸而造。

后为卸下原无乡双臂的银骠玄解而再出江湖，查找能取下银骠玄解而不伤及原无乡性命的方法，并与倦收天讨论变体银刃促成银骠玄解自然脱落。

## 角色经历

（霹雳官方会刊）照世明灯是一个拥有错综复杂身份与谜团的角色，在照世明灯于早期霹雳剧集登场时，共有三人拥有相同诗号、相仿的外貌，连出场配乐都一样，加上当时欧阳世家扑朔迷离、多重身份的智斗剧情，让观众对照世明灯的身份有着许多猜测。【照世明灯】照世明灯照世明灯在《霹雳眼》时期登场，当时素还真与欧阳上智有一连串精彩斗智斗力的剧情，照世明灯以其智谋及慈悲心肠的行事风格援助素还真、叶小钗，成为令人印象深刻的支援者。

之后对于欧阳上智之事，素还真与照世明灯的处理方法有很大的不同，某次为了争夺欧阳上智，双方产生冲突，素还真联合一钱一命出手，而照世明灯则请叶小钗迎战，面对一钱一命绝招，叶小钗却产生了犹豫，瞬间照世明灯挺身挡刀，因而受了重伤。

在照世明灯受伤之后，由叶小钗背负至山洞休养，这时照世明灯一句“你有二十年的时光是属于我的”，以及随后素还真来探望照世明灯时，在欧阳上智真实身份的议题上，两人的意见有极端的分歧。

加上之前一线生曾说，易容术面具戴太久脸上会溃烂，而照世明灯正好也脸部溃烂，很明显的，这里呈现出照世明灯的真实身份，其实有着相当大的联想空间，特别是经过欧阳世家的各种事件，一人不只一种身份，在当时是很令观众习惯的，当时素还真也对照世明灯身份与欧阳上智作了连结，而照世明灯能够要求叶小钗去杀“当时的”欧阳上智，更是疑点重重。

就在照世明灯受伤、要叶小钗杀欧阳上智后，就此失去行踪。【仇杀千里·命七天】照世明灯因伤消失，但是同时却又出现了另一位“照世明灯”，装扮相同，只是白发的“照世明灯”变成了黑发，他的行事作风与照世明灯相似，也自称是“照世明灯”，但是黑色的头发却又让剧中人物与观众抱着怀疑，剧中却迟迟未揭开真相，各种线索都表现出乃另有其人，而且是欧阳上智的可能性非常大。

终于，当九天神罩一罩上，黑发“照世明灯”在众目睽睽下终于完全被揭露身份，他便是“命七天”，当初在崎路人的安排下，以“照世明灯”的模样行走江湖。

命七天身负血海深仇，年幼时全家被杀，为了寻找灭门凶手，接受崎路人的帮助，苦练菩萨印，誓杀仇人。

练成十式菩萨印者，生命只余七天，在杀死了灭门血案幕后主使金阳圣帝关足天后，大仇得报的命七天利用余生，利用菩萨印协助灵心异佛成就大义，治疗素还真波幻迷掌之伤。

临终前，来到爱人之墓，宁静的结束生命。

照世明灯【寒夜残灯·照世缘】与“照世明灯”的诗号、外表几乎一模一样，其身份是天蝶盟二宫主“灵蝶”，过去曾与崎路人有交情，为人善良，因此与天蝶盟理念背道而驰。

当时“命七天”身份已被揭露，“寒夜残灯·照世缘”初登场时，深不可测的模样也令人以为是照世明灯重出江湖。

为了引出寒夜残灯，崎路人让命七天装扮成照世缘的模样，因为江湖传言，二宫主“灵蝶”早已死于毒瘴林，但崎路人于现场勘查后，发现疑点重重，而且此事牵涉到天蝶盟派风采铃接近素还真的计谋。

寒夜残灯认为风采铃不会毒害素还真，因此并没有将这个计谋揭破。

但寒夜残灯终究不能容于天蝶盟，喝下三杯毒酒，宣示退出天蝶盟的决心后，寒夜残灯遭到追杀，进入了雾谷，并让金小开与叶小钗于雾谷内见面。

后来寒夜残灯出手阻挡魔域行事，愤怒的恶魂暴鬼下令，要天祸妖狐取下寒夜残灯的首级，最后寒夜残灯不敌天祸妖狐绝招而惨亡。

无论是初登场的照世明灯还是残夜残灯，除了外型的特征以外，在行事作风上都有着神秘、善良、智谋等特色，而且兼有正反两种立场。【霹雳道门·天真君】在《霹雳天命》时期，黑暗道出现灯光，与素还真交谈，虽然可猜测为照世明灯，然而当时却只有声音，并没有明显身影，直到《霹雳狂刀》时期，照世明灯再次复出后，明确的建立这个角色的正道地位。

道教曾命令“十三道”攻打“合修会”，而照世明灯即是十三道中的“天真君”，十三道虽然攻破合修会，但死伤惨重，合修会也未被根除去，多年后合修会东山再起，这时照世明灯再出，以道教前辈的身份抵御合修会，瓦解合修会的阴谋，这时的照世明灯较少与对手直接对战，以沉稳、智谋的方式与玄真君一起打击合修会。

但是在乱世狂刀出现后与玄真君有场约战，照世明灯发现玄真君眉间有一股黑气，表示厄运当头，此去大凶，仁慈的照世明灯，使用了厄运转移，替玄真君承受了加倍的厄运，就在照世明灯与欢喜佛押解地藏大如时，遇上了合修会拦截，照世明灯不幸被千子弹击中，重伤濒危。

在《霹雳狂刀》时期，照世明灯现身前，剧中先安排了一位照世明灯的女弟子天道明灯陆慈心现身江湖，同样的配乐，类似的发型，与师父一样善良，蕙质兰心。

天道明灯出场后追查“天地门”的秘密，为了打开天地门，天道明灯与万俟焉一同修练天火九变，成功进入天地门，探查深处宇宙之眼的秘密。

在照世明灯遭千子弹重伤时，天道明灯进入代刑堡星河殿，向盘古开天达愿石许愿，奉献自己保住了照世明灯的生命。【智者复出，扶持正道】海报在智慧之星现身武林出仕魔域时，素还真与一页书出奇策，两人假意失和，此时由照世明灯挑起抵御魔域重任，成为中原正道支柱，配合素还真计划打败玉天玑。

但接着海上浮尸现，无极殿重现武林，照世明灯持续奔波，联系三教，然而无极殿终究一统武林，照世明灯再次退隐于黑暗道，岂料仇家上门，宣誓杀道门中人，玄真君等道教高手不幸身亡，照世明灯亦毁去黑暗道，自此消失行踪。

邪恶组织【天下第一人】阴谋占领武林，在远浮天内“金色人影”现身，照世明灯再次成为幕后助力，配合卧云先生牵制天下第一人，后来卧云恢复素还真身份，金色人影才确定是照世明灯本人。

从金色人影恢复真身的照世明灯，继续替素还真带领中原正道，各处奔波。

后来，七星之谜流传，为了调查七星，照世明灯于寒江再现，并阻止七星星灵回归，然而七星天命已难以扭转，天策真龙的“天策王朝”一统天下，为了武林和平，照世明灯说服群侠加入“天策王朝”，一同抵抗“魔剑道”的侵略。

之后“妖刀界”兵进中原，势力庞大，为了强迫当时消失行踪的素还真等人出面，妖后派兵施压。

妖后旨意来到腾龙殿，强势擒拿照世明灯成为人质用来威胁素还真。

公开亭上素还真现身，妖后依约放人，虽然素还真挽留，但“慈郎责任已了，去意已定”。

随即化为点点金光飘向远方。【归隐黑暗，心系武林】黑海森狱为祸期间，为卸下原无乡双臂的银骠玄解而再出江湖。

于仙魔鏖锋时期应秦假仙之邀再现武林，一探天地门旧址。

因八歧邪神之复活，照世明灯复出，与正道群侠共同对抗邪神，后于《霹雳惊涛》第3集与玄真君一同暂退隐。【南域风波，逆世双鳞】在《霹雳靖玄录下阕》中，为保护介入南域之事的玄真君，照世明灯再次短暂入世，力撼海宇之主，使得玄真君全身而退。

# 木珂雪

出身名门，乃统掌五城矿产的木府大小姐，木衔府掌上明珠，心性单纯善良，对人无防备心，常会对陌生人施以援手。意外解救了负伤昏厥的萧风，将之带回木府养伤，两人因而结下了一段不解之缘...。

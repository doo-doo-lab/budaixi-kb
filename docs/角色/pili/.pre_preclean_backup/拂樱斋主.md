# 拂樱斋主

霹雳布袋戏虚拟人物拂樱斋主，男，霹雳布袋戏虚拟人物。优雅温文的拂樱斋之主，与枫岫主人为多年不见的好友，两人常互相挖苦对方。性格诙谐轻松，谈吐风趣，爱逗弄贴身侍女小免，总是一副天塌下来也不怕的悠闲态度。身份神秘莫测，实力不凡，能与枫岫天外传声。虽表面为武林正道，实为四魌界中火宅佛狱三公之一的凯旋侯，数年来一直卧底于正道，当血暗沉渊开启之后，回归火宅佛狱阵营。后被剑之初废去七成功体，再被魔王子废去剩下三成功体并剥夺声音，押入噬魂囚。由迦陵顶替凯旋侯之位。之后被红狐九尾放出，现行踪不明。

## 角色背景

角色设定来历神秘、行事神秘、说话神秘的枫岫主人，自出场至今，尚无人能一窥其真面目，随着剧情发展，枫岫主人势必不能再神秘下去了，为了揭开枫岫主人神秘的面纱，编剧设计了另一个能制造让枫岫主人“露出马脚”机会的角色，此人名为——拂樱斋主。

文/编辑部即使是刀无极为枫岫主人创立了东品，无上限的供养他，有事前往请教时，还是无法自枫岫主人那得到直接的答案，素还真、千叶传奇，商讨论事时也不能对枫岫主人失礼，少独行虽然常数落枫岫主人，但他的性格与枫岫主人却是格格不入，老是一言不合。

这时编剧需要一个能与枫岫主人平起平坐，行事作风相当的人物，这两人亦敌亦友，旗鼓相当，互相吐槽，互相试探，经过长久岁月，仍纠缠不清，摆脱不了对方，两人注定成为命运的一对、桌历上的一对、写真内页的一对（囧）。

拂樱斋主编剧三弦形容，拂樱斋主这个名字是打翻铅字架而来的，情急之下，又印证了编剧组的名言——“花五天想到的名字，往往没有五秒钟的名字好。”而出场时的编写，其实没有什么特别的涵义，只是单纯形容“这个人很爱樱花”。

而这个人，家里养了一只宠物，一只修行成精化成人形的兔子，既然化为人形，严格来说就不算宠物了，那么是算什么呢？

编剧三弦表示：拂樱斋主是个萝莉控。

（直截了当）于是，这只不像宠物的宠物——小免，就在拂樱斋主的关心爱护中，成为一只萝莉而健康快乐的生活着。

拂樱斋主爱的是小免“将熟未熟”的特质，不过小免有一点让拂樱斋主很头大，常令他受不了，那就是……编剧八叉：小免喜欢枫岫主人。

天啊，这对一个萝莉控来说真是一个天大的打击，这让拂樱斋主更有针对枫岫主人的借口，那么，拂樱斋主与枫岫主人之间，又是怎么一回事呢?简单来说，就是拂樱斋主与枫岫主人互相怀疑对方是“某个人”，他们之间的交情，建立在试探之上，目的是找出对方是“某个人”的有力证据。

原本从不离开寒光一舍的枫岫主人，是为了避开拂樱斋主，而拂樱斋主对于一个隐居之人，也无机可乘，后来枫岫主人因神之子而出门，才引来拂樱斋主的注意。

拂樱斋主的正式登场，是救了昏倒的天狼星，但这并非是拂樱斋主有好生之德，他的目的是要利用此事观察枫岫主人。

之后佛业双身引起的六境之劫，造成武林灾难，拂樱斋主问枫岫主人要如何安排，这也不是为了武林正义，他是为了从中得到更多关于枫岫主人的线索。

但是反过来说，枫岫主人也是利用这些事端，在探查拂樱斋主的真正底细。

拂樱斋主与枫岫主人之间，原本互不相让的平衡，将会在不久的将来出现失衡，关键在第三名角色的出现，这个人周旋在反派之间，拉拢反派合作，揭开了拂樱斋主的最终秘密。

角色造型编剧希望拂樱斋主是个粉红到底的男人，以颜色配合拂樱名号，外型要斯文，但是又不能太过女性化，于是偶头要选择Man一点，眼神阳刚、锐利，编剧另外强调他个性上的粗鲁之处，来与他的服装外型做反衬。

因为那时候佛狱还没有架构完，等到佛狱架构好三公之后我才定好他的身份，那他的设定，一出来比较偏好人的时候，就是当初讲的粉色系，选择的形态方式会偏优雅又带点骚包。

其实你看他跟小免在一起的时候有点骚包，优雅又带点骚包那种感觉。

对照枫岫的感觉，因为不能出一样的东西，如果两个角色的性格太重复的话，会变得很没意思，所以他会偏向话很多，为了让这个角色丰富点，还帮他设计了小免这个角色。

云轩∶所以小免最后是弃我们斋主而去咯？

三弦∶其实就是这样子。

云轩∶唉…下面是我们小草副掌要问的，她问，拂樱龙战这档是出自三弦执笔吗？

三弦∶每一档每个人都有负责的线。

云轩∶龙战是只有部分吗？

三弦∶龙战八荒的话，我是负责集境…好像就只有集境…云轩∶没有写到斋主？

三弦∶有，还是会穿一些场次的，有些场次还是会写的。

云轩∶第18集，枫樱的对话都是三弦编剧写的吗？

三弦∶18集是探牢那一段吗？

云轩∶对的。

三弦∶探牢那一段是八叉跟我……算是八叉跟我一起写的吧。

云轩∶所以是一起写的？

三弦∶嗯。

云轩∶枭皇论战第2集，凯旋侯看到墙上枫岫的留言，究竟心里面的感想是怎样的呢？

三弦∶这部分留给观众去想会比较好。

云轩∶不行啦，我们一定要知道凯旋侯心里面在想什么，因为他讲不出来是不是啦！

三弦∶这不行，应该这样讲吧，有些东西留个白就是希望观众去体会，如果讲到白了…云轩∶可是这样很容易造成戏迷间的争吵。

三弦∶我觉得个人看戏自己的感受就好了，不见得一定要有个公允的，比如哪个对哪个错，类似的问题有一个啊，很多羽人迷一直跑来问我羽人到底爱不爱姥无艳？

（云轩∶喔对，千古奇案！）我被问了五年，我都一直跟他讲说我不知道。

小雷∶其实他爱的是燕归人。

（众人哄堂大笑）云轩∶那我想问，墙上的留言是您设计的吗？

就是枫岫的12个字。

三弦∶这是八叉设计的，因为她是枫岫的原编，所以由她来决定她那些字的意思，至于拂樱的反应，我是决定给他一个留白，因为我觉得这个地方不要想死，让观众在看到这一段的时候，去思考一下侯的心情，自己去体会会比较好一点。

云轩∶好，她们想问为什么你给拂樱一个“战无不胜”的称号？

三弦∶哦…“战无不胜”的称号是整段下来的。

火宅佛狱→最高利益→战无不胜，由王开始，王代表火宅佛狱，代表火宅佛狱的最高利益底下永远战无不胜，是三公的责任（大家欢呼鼓掌），剧情中我解释过一次。

云轩∶所以我理解，王代表火宅佛狱，公是火宅佛狱的最高利益，侯是战无不胜，整个连起来是火宅佛狱，最高利益，战无不胜！

原来如此！

（众人继续欢呼）三弦∶耶，我记得剧情中有解释过一次，只解释一次而已。

云轩∶我们是到现在才知道，所以我们需要月刊。

三弦∶剧情中有直接讲到，在出兵前王的一次精神训话里面有提到。

云轩∶可是我们看的时候都没注意啊…三弦∶就藏在里面。

云轩∶然后太息公为什么讨厌侯？

这是我们大家都想知道的！

三弦∶很简单，因为侯会影响到她的位置。

云轩∶侯不是老三吗？

三弦∶但是早晚会爬到老二啊！

云轩∶他爬上去，太息公说不定就变成太息王了。

三弦∶没有，不见得哦，如果今天侯的功绩…你知道我们火宅这条线只演了40集，如果他今天给我的集数是120 集，如果中间有经过这种内容的话，就和十锋一样，是有可能干掉太息公当凯旋公的哦，那时候他的称号就会变成“最高利益”了！

小雷∶凯旋公？

云轩∶凯旋公的称号叫——最高利益！

（众人笑）三弦∶那个应该不是称号……叫代表词，谁上去了就是那一个。

太息公从初登场就表示出她对凯旋侯很感冒，因为她很担心凯旋侯抢了她的位置。

# 萧竹盈

为替走火入魔的母亲外出找寻良药，而遭一连串的变故后丧失记忆，进而结识恩人一剑万生与其侍童叶小钗。衷情于叶小钗却遭拆散，伤心欲绝后步入极端，出卖自身制造黑邪书后却被他人算计。红颜薄命的她在死前仍低唤著叶小钗的名字，情深已不可言喻。

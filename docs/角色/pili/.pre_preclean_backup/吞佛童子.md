# 吞佛童子
================================================================================

吞佛童子

异度魔界战神，身负开启赦道使命，个性冷酷无情，狡黠聪明，心机深沉难测，为达目的不计手段，深受九祸等人的信赖。曾被一莲托生以圣剑压制魔性，引出潜藏的一剑封禅人格，在解开禁锢后，带出异度魔界兵临苦境。日后，吞佛遭一步莲华所擒，殊不知心识却也被其感化…。

# 既济

浮动山城的珠宝商人，肩负宝石布袋，为别见黄花落梦中出现的神秘人物，虽是市井商贩，但交游广阔，俨然有一方民间势力之气候，深藏不露。于梦境中与箕子臬相遇，解大极宫通缉之危，而后结伴而行，然其目的不明，后更意外让箕子臬为地母之灵所咒。既济之能，就连大极宫司天也难以掌控，且似与穆天教派有所牵连。

### 姓名设计

摘自霹雳会月刊第254期 编剧漫谈《浮动山城》

既济这个名字，如果有看易经的人，对既济这个卦象应该不陌生，代表初吉终乱。因一时环境或人事所影响，而暂时相安无事，但毕竟非长久之象，最终仍会因为冲克而败。这个名字的用意，是对箕子臬而言，不过到了最后，是谁冲克而败，到还难说。

在既济的性格描述里，他是个非常善于揣测人心的人，他很懂得怎么做人，但本心里却疏情太过。有人说过于热情的人，骨子或许都有着冷漠的因子，因为他们的情不入心，感情不会造成他们的心理负担，所以能够毫无忌惮的释放热情。所以遇到太过热情的人，有时必须保持适当的距离。

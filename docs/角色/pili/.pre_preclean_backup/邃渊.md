# 邃渊

儒门顶尖剑客，法儒君奉天之徒，与妻子席断虹代表儒门，与佛道二教之代表共同看守圣剑“天可明鉴”。孰料，鬼麒主暗中布施诡计，圣剑被盗、佛道二教之人皆死，唯独邃渊夫妇存活，儒门遂成众矢之的。最后，为证实自身清白，邃渊选择自尽而亡，遗留妻儿，而三教圣剑被盗一事也成悬案。

# 浑沌初王

古域初代王朝主，佛缘深厚，与君昊为好友，曾往鹿野云泽阻止九狸梦狐残害生灵，因而结下不解情缘。在胤世五烈决意以七窍之能，将罪恶禁地尽数击落异境前，初王留下八正念，也将王朝未来托付于九狸梦狐，望九狸梦狐代其守护。

# 恶骨

幼时遭到抛弃的不良少女，自组恶童党，带着一群小弟四处打劫维生，体验社会现实与人情冷暖，造就强烈的求生意志，以及恶根深植、自私狠毒的性格，却也因此受血傀师的赏识收其为徒，更要其爬上叫唤渊薮取鬼手，脱胎换骨。

## 角色经历

恶骨人物志

一、出身与早期经历

恶骨命途多舛，幼年遭弃，被埋土底，爬了三年才爬出，辗转沦落至毒嬷之手，被其贩卖至青楼。期间遭逢策梦侯凌辱，遂以火焚青楼，并说从此以后不会再有人在这里受到虐待。此段经历奠定其对社会既存秩序之极端不信任，形成以暴制暴的生存法则。

二、江湖轨迹中的关键节点

1. 市井生存

初入江湖，收揽数名流浪孩童为小弟，以盗窃维生却恪守“你们是我收的小弟，你们饱，我就饱“的草莽义气。偶遇失去记忆的克灾孽主，在欺凌克灾孽主时被化名鹤舟的忌霞殇制止，并说“他日必报此仇“，由此可见她睚眦必报的心性。

2. 书院事件

野狐禅以介绍信为交换取得克灾孽主日记后，恶骨携众投奔一叶秋书院。然出身污秽遭学童排斥，更因盗窃馒头之举被小弟背弃。双重背叛催化其焚毁书院之极端行径，此举引起血傀师注目，开启其武道蜕变之路。

三、武道淬炼与人性挣扎

1. 天梯试炼

血傀师指引其攀登叫唤渊薮下的龙脊天梯，虽受武道七修劝阻仍以“大登天“为誓强行突破。攀援过程中手骨折断仍质问天道不公，暴雨中发逆天毒誓，展现其偏执心性。

2. 武学机缘与背叛

绮罗生授以莳花艳身术，暂时给予信任依托。然目睹其与策梦侯交涉即撕毁书籍断然离去，反映其根深蒂固的被害妄想与信任障碍。

四、宿命终局

1. 屠魔事件

受血傀师命斩杀妖魔化的孤城不危，濒死之际爆发生存意志完成反杀，映射其与命运抗争的生存本能。

2. 矛盾本性的最后显现

虽手段狠绝，仍保有底层共情：救济昏迷的明月不夜羽显未泯善念；面对幸存小弟质问放弃抵抗，流露内心孤寂。最终遭绮罗生诛杀，终结其充满对抗与挣扎的悲剧人生。

恶骨同时拥有被害者与施暴者的双重性，其极端行为既是对命运不公的反抗，亦是社会边缘群体生存困境的残酷写照。多重背叛循环造就其扭曲价值观，终难逃武林宿命轮回。

红潮祸（红潮祸·恶骨劫）

曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十八》

丁天牧老师2012年作品，以恢弘的管弦乐编制演奏，演绎创作主题「神族的战争」，乐曲结合西方神话色彩元素与风格，打造出富有史诗气氛的大场面气势曲。初次使用于动机风云第11集收幕，月藏锋与剑布衣一探无向经纬，遭逢红潮来袭时的紧张气氛；之后常使用于恶骨一角的相关桥段，在恶骨放火烧书院、以及攀爬叫唤渊薮时，皆以此曲营造急促紧逼的气氛。

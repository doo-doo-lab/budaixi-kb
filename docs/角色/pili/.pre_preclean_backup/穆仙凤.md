# 穆仙凤

儒门龙首爱徒，聪慧机敏、善解人意的妙龄女子，与默言歆负责看顾疏楼西风，侍主忠贞不二、体贴窝心，甚得龙宿疼爱。

## 来自百度百科的补充

根据地：疏楼西风、西风亭、三分春色、龙烟宛、悠篁里

朋友：霜旒玥珂、黑衣剑少、白衣剑少、穆霜月、穆襄月

武学：仙飘凤羽、柳畔轻烟、柳桥轻絮、絮柳风起

（投诉香独秀）

穆仙凤：（低语）主人，你过来一下。

疏楼龙宿：嗯？

穆仙凤：主人，他还要住多久？

穆仙凤：他来了之后，焚的是千秋香檀木，喝的是百年铁观音，浴的是龙池玉波水，赏的是千娇百艳花。而他本人出更衣，入沐浴，半点没挂心；迎秋风，送明月，一襟涤俗尘。……主人，剑子前辈真的介绍了一只蝗虫，而且是一只很有品位的蝗虫。不出一个月，主人你的珍藏就要用完了。

疏楼龙宿：看来情况比吾所想的更严重。

（出于惊讶）

穆仙凤：楼主要走了吗？可惜，怎么不多住数日呢？

香独秀：仙凤若是不舍，吾可以多留几天无妨。

穆仙凤：啊！我、我不是……

疏楼龙宿：仙凤，别再耽搁楼主的时间。

穆仙凤：是啦是啦。楼主，你慢走。

香独秀：诸位请。浮名本是身外物，不着方寸也风流。

穆仙凤：（捂心口）呼，吓死我了。

疏楼龙宿：仙凤，以后莫轻言客套话。

穆仙凤：我知道了，这次真正吓到我了。

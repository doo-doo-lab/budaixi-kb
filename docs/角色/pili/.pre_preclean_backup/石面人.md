# 石面人

黑暗之间接头人，与驱魔人四分之三似有某种协议，以诛尽天下间的嗜血者为目的，甚至还将矛头伸向茶理王与嗜血化的苏安，惹来四分之三的反扑，遭诛魔银枪所净化消灭。

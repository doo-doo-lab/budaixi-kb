# 偃刀左衡

雕神古魄的古武族分支，个性旷放不羁，一身颓废浪人装扮，虽有一身好刀法，却是镇日好酒好赌，不同于女战神般砥兵砺伍。在叶小钗获得战魔认同后，左衡也重拾偃刀，跟随太武冲锋陷阵杀敌。

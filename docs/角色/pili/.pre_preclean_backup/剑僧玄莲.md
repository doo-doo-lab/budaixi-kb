# 剑僧玄莲

自称乃乡野破戒山僧，言谈之中字字珠玑、禅味十足，为点破剑邪心中疑惑而来，看似闲云野鹤，却是昔日封印异度魔界三名奇人之一，气势非凡的剑僧玄莲。

### 人物经历

剑僧玄莲，神秘不凡的山僧，自号“破戒”，遵循天道伦常之改变，应天时顺命理而为，知晓武林中诸多秘辛，与谈无欲似有故交之情。剑僧玄莲真实身份是昔日协助玄宗封印异度魔界的三名奇人之一的破戒僧，事后隐姓埋名浪迹江湖。

剑僧玄莲在九峰莲潃巧遇剑邪·剑雪无名，在与剑邪言谈中，除了告知当年一莲托生的事迹外，更点悟剑邪除去心中疑惑，让剑雪无名正视与人邪·一剑封禅之间的恩怨，剑僧玄莲更将宝剑莲谳赠予剑邪，取代朱厌，但可惜天数已定，剑雪无名最后仍是难脱死劫。

因局势所致，剑僧玄莲因异度魔界再现而被逼出原来身份，遂复衣挂剑，再度配合耆耋耄和醒恶者施招，虽是顺利扑灭异度魔火，但剑僧玄莲也在封云山封印解开时遭巨大爆炸波及，被巨石重压身亡。

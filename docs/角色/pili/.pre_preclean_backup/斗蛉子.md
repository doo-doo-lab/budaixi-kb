# 斗蛉子

截山三不修之一，个性幽默中带点毒舌，看似是无为的妖修关者，实者是归界外放的质子，有王者血统。在某些时候，规矩特别多。有一份深藏在心的骄傲。与鸣沙流年同为截山高端修关者，称鸣沙流年为师兄，视闪焰为师弟。

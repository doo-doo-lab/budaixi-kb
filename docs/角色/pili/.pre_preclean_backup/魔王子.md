# 魔王子

霹雳布袋戏中的角色魔王子，

**本名**：凝渊，是《霹雳布袋戏》中的虚拟角色

**身份**：为火宅佛狱的新任王。魔王子是咒世主之子，火宅佛狱的禁忌之名，性格反复疯狂，叛逆无可捉摸，绝对的自我中心主义，且带有强烈的黑色幽默。由于当初对火宅佛狱造成重大危害与威胁，而被咒世主封印于蛹眠之间。能驾驭化为魔龙的副体赤睛出征。魔王子于《霹雳兵燹之圣魔战印》第1集中

## 事迹

命丧其手者咒世主：魔王子赐予咒世主的愿望，在咒世主选择解救子民之后，断其手，夺其句芒双剑，而让他死于王座。

太息公：原为魔王子的女人，后因魔王子对其失去兴趣而抛弃，连连战败后，被魔王子虚伪的关心一吻，掐断头颅而亡。

皆杀者：四邪谛之一，因先王之仇欲杀魔王子，被魔王子诱劝但忠诚不减，最终使出“忘情一斩·天地不留”，惨败于魔王子的魔火噬原，被魔王子碾碎头颅。

霓羽族民：一个善良且和平的种族，魔王子借由杀害这村落，以复仇的名义，招惹一页书、慕容情的报复。

炎流村民：安静平祥的村落，不允许任何的反驳，魔王子来此村的目的是为了让其给自己制造代表自己的图腾。

横练金刚(红)：不敌杀世蛾风的强招而亡。

横练金刚(绿)：与光世大如、法丈轮王共同使出的华严三化劫，但却被魔王子的蛾空邪火破除，因而被瞬间斩杀。

光世大如：为救法丈轮王，挺身挡剑，最后释放元灵之力，冰封魔王子而牺牲自我。

风世魃鬼：虽是被啸日猋所杀，但实际原因是由于魔王子故意指点错误导致魃鬼的死亡。

红狐九尾：因为惧怕魔王子而导致精神失常，最后被魔王子欺骗自杀而亡。

鸦魂：被魔王子强授蛾空邪火，因无法承受蛾空邪火的炙热功力，反噬而亡(实为魔王子玩弄至死)。

魔王子之心吾，魔王子，吾从不代表什么。

人心，需要抚慰安定，多数人存有一定的承载底线，每个人内心深处，一定希望不受束缚。【身处火场不自知，火宅不修欲炽烈】，火宅佛狱是佛门流传已久充满邪戾之气的世界，火宅之宅可以说是心宅，火宅有三火即——【欲火，色火，无色火】，这都是心灵上的烦恼。

魔王子之心赤睛说——魔王子，心灵太空虚了是的，异于常人总是寂寞的，这是种可怕到无法想象的心境，魔王子内心有如深渊般空洞，感情及人性都可以拿来玩弄，魔王子是不做梦的人，因为梦是现实的投射，既然不期望，也就无怨无悔，无所谓魔王子初登场，咒世主曾言道【吾儿，为何你失去了心】因为魔王子没有【心】，所以，他没有快乐，悲伤，惆怅及烦恼等情感，魔王子觉得生命如幻，故以残杀生命为乐，寻找自我的毁灭之道，魔王子在炎流村建造的巨大雕像，左胸上巨大的空洞，让这一意义更为明显，空洞的心灵如何填补，人世中的伦理，信仰，欲望等等普世价值，一个人若是没了这些东西，生活将是多么空白魔王子站在他的雕像上说道【这个世界本质是虚无，任何事物的存在都是荒谬】崇尚虚无，轻视世上的所有价值，一个角色，说出一种与众不同的人生观，这世界是因为【人】而腐败，魔王子是一个悲伤的角色，他不是想改变众人的思想，而是想看人的信念能坚持多久。

人看似是世界的主宰，然而在虚空之前，【人】其实什么也不是，想象一下，魔王子站在光谱的一端，而世界在另一端，两者对立着，中间是不可跨越的鸿沟，没有对错，各自所持的只是一种观点而已。【生存】对魔王子来说没有任何意义，他只能四处游荡挖掘一些生存仅存的意义，或是说，魔王子一直期待有人能杀他，这一点让人很是好奇究竟，他是怎么看待自己的死亡连自己的生命都不在乎，更遑论去在乎他人，魔王子觉得整个世界都毫无意义，甚至自己的存在都毫无意义，这样的人，即使死了，也会让人感觉他没死当魔王子从高空坠落，伸张双臂，仰望最后一点光明，这是凝渊心中最为满意的结局吗。

死亡，不是角色的终点，魔王子一步步走向必然的结束，他的出场与消失，一样在颠覆【蛾】的生命短暂而无声，其谐音亦可理解为恶，魔王子的武功属火，代表了欲望焚烧，更是一种净化的意义，所以飞蛾扑火，惨烈一瞬后的飞灰湮灭，算是魔王子一生的注解吧。

## 角色评价

纯邪，同时也是最恐怖的存在被封印于蛹眠之间，四魌界三大传奇之一，火宅佛狱的异数，禁忌的名字——魔王子 凝渊太息公在火宅佛狱危机之际，咒世主解开魔王子封印，引爆最让人不安的存在，羊角的造型，是不贞和兽欲的象征，黑色华丽盔甲造型，出场气氛诡异邪魅，个性冷酷残忍，同时也是破坏与邪恶的代表。

魔王子是个极特殊的角色，在他的意识中，只存在无趣与蔑视，捉摸不定的个性，给剧情带来强大的压迫感，咒世主是个守序的君王，魔王子却是个混乱的煽动者；

咒世主以佛狱最高利益为主，魔王子却是以自身好恶为乐，他说话方式很直接，一针见血的说出想法，不拐弯抹角，也不虚伪做作。

魔王子并不适合做领导人，与咒世主牺牲一切为佛狱相比，他所体现的只是一丝狡智与机灵，宣扬【异端思想】并不能成就一番霸业，魔王子即使嘲笑再多的世人，也改变不了一些既定的价值与信仰。

凯旋侯火宅佛狱是【国家机器】的极致，而魔王子所代表的是【个人主义】，凯旋侯，太息公，迦陵及佛狱众人都有很强的舍身为国的忠诚观念，这些角色所表达的就是贯彻传统的基本观念，往乐观想，这种理念是国家生存的条件，往坏的想，就是限制个人思想的锁链。

魔王子的口舌犀利，对世人鄙夷，在不特定心情中寻找乐趣，更特别的事，魔王子的很多论调都是以另一种观点来讽刺人生，让人不知如何反驳，值得深思玩味。【多数表决，让多数蠢货决定蠢事】，【有权利者众人皆听，无权利者无人过问】，这些理论很现实的说出只有强者才能贯彻个人理念，绝大多数的人都只能服从而已，它真实反映一些被人忽略的真理，也说出社会上另一个隐晦的存在。

人情事故，若看的越细，就会让人越触目惊心，有人认为魔王子是暗喻【人性本恶】，这话有些道理，因为人人都想让他人顺从自己，在平常人心中，多少都会隐藏写怪异观念，甚至是龌龊不堪的想法，问题是我们没有勇气说出来而已。

所谓道德规范，乃是经过教育的产物，魔王子颠覆传统，跳出桎梏，以不受约束的眼光来看世界，只能说魔王子的思想太过于前卫，他的讽刺虽然中肯，实际上，却很难真正实行，这样的人，在社会中是会被视为反动或者疯子的。

魔王子看到的确实是这个社会上存在的缺点，但是，每个制度都有其缺陷，不可能完美无瑕，完全否定制度的存在，则会流于偏激，社会秩序也会崩溃，魔王子说出了缺陷所在，但他没有说出解决之道，《可能正因为魔王子找不到解决之道他才会变得这么扭曲》破坏之后重新开始之路在哪里，这也是必须深思的问题。

还是不存在的虚无大。

但微妙的是，受限于主观思想，我们将存在的东西当作主体，而损坏了存在的东西，就变成破坏。

但究竟是这个洞的虚无破坏、占据、出现在这块地面上，还是地面破坏、占据、出现在整块虚无上。

魔王子那观众或许要问，那他作这些事情的目的为何。 喔，猜猜看王子会怎么回答。

猜到有奖，堕落天堂参观门票一张，保证让你流连忘返，进的去的人通通出不来喔。

至于我为何会下定决心写出王子，起因大概要推到一年多前，我在网路上遇见一位戏迷，他现在可以说是一位我非常珍惜重视的朋友亲人，他博闻广洽，与他聊天是很有趣的经历，我们谈了许多关于政治、哲学、社会、人生观等等各种话题，某次我与他谈到道德问题，提到了关于兄妹**的禁忌原始。

也就是源头问题。

在那场讨论中，我用我微薄的知识，与他针对许多道德、传统的存在原因，以及各种人类情感作剖析，大概这一路的相关话题聊了有几十个小时之久吧。

不到一个礼拜的时间，我就另存MSN的对话新档超过三次。

在讨论当中，我讲了五只猴子的故事，我想很多人都听过，我直接从网路摘录下来： 把五只猴子关在一个笼子里，上头有一串香蕉，实验人员装了一个自动装置，一旦侦查到有猴子去拿香蕉，马上就会有水喷向笼子，而这五只猴子都会一身湿。

首先有只猴子去拿香蕉，当然，结果就是每只猴子都淋湿了。

每只猴子在几次尝试后，达到一个共识：不要去拿香蕉，以免被水喷到。

后来实验人员把其中一只猴子释放，换进去一只新猴子A，这只猴子A看到香蕉，马上想要去拿。

结果，被四只猴子打了一顿。

因为其他四只猴子认为猴子A会害他们被水淋到，所以制止他去拿香蕉。

A尝试了几次，随被打的馒头包，依然没有拿到香蕉。

当然，这五只猴子就没有被水喷到。

后来实验人员再把一只旧猴子释放，换上另外一只新猴子B，这只猴子B看到香蕉，也是迫不及待要去拿。

当然其他四只猴子也把B痛打了一顿，特别的是，那只A猴子打得特别用力（这叫老兵欺负新兵，或是媳妇熬成婆）。

B猴子试了几次总是被打得很惨，只好作罢。

后来慢慢的一只一只的，所有的旧猴子都换成新猴子了，大家都不敢去动那香蕉。

但是他们并不知道为什么，只知道去动香蕉会被扁。

这就是“传统”的由来。

魔王子传统不去反省它，就没有价值。

故事大概就是这样，其他讨论的内容就不详述，我简单用以下的一句话总结。

你确定你所信奉的每个理念，你都能确实找到信奉他的理由吗。

这个问题不需要向任何人解释，只需向自己解释。

于是挑战理念的王子，终于横空出世了。 嗯，由于王子的创作过程非常复杂，所以小三子今天就先聊到这吧，下次编剧漫谈，我们再来继续谈关于王子的其他部分，呃……如果他还有其他部分的话。 啥。

你说我开场不是说，这是小三子最后一次编剧漫谈。

唉，你应该相信的是我这个人，而不是我说的话。

以上，完毕。

摘自：会刊189期文/编剧：三弦上次小三子讲了魔王子的创作源由后，群众纷纷表示听了很感动，因为他们很久没看过这么会骗稿费的人了。

洋洋洒洒讲了一大堆，竟然还没讲到重点。

唉~真是的，大家太不了解小三子的苦心了，别的角色也就算了。

王子这样特别的角色，当然要多花点时间讲解他的出身来历啊。

好吧，我们继续骗稿费……在进入王子的正题之前，先说一下，很多人特别到我的部落格来询问王子跟赤睛的关系，还有赤睛与飞鹭的关系。

赤睛与王子的关系，用戏剧上来说，就好比是希腊神话中的阿波罗（Apollo）跟戴奥尼索斯（Dionysus）一样。

一个代表冷静，沉着，稳定与节制，另一个则是狂乱、善变、虚无与放纵，这样的组合在戏剧中并不少见。

通常除了同伴关系外，还有对立关系，辅助关系等等的各种组合方式，有兴趣的人可以研究一下哪几部小说戏剧电影是这样处理的，小三子就不举例了。

赤睛另外一个很多人问的问题是赤睛与飞鹭的关系，对赤睛而言，飞鹭是他所遇到的一个善良女孩，这是一段插曲。

也让观众了解到赤睛在与魔王子之外的人相处上的另一面。

对赤睛来说，飞鹭或许不会重要到足以动摇他任何理念，但他同样也不愿意看到飞鹭受到伤害，否则也不会企图从王子手上救出他了。

至于赤睛为何从来不在魔王子面前提到飞鹭。

我想赤睛不是棒槌，他比谁都了解王子，提出来后的结果是怎样。

我想观众一定很清楚~谈魔王子就一定要谈到赤睛，赤睛这个吐槽役的发展，是因为王子需要有一个人能跟他对话，王子太过虚无狂乱，我不相信有一个人能跟随他身边太久。

所以只能设定副体赤睛与他对谈，原本赤睛的预想有谋士、军师、圣者等各种形态，后来我决定让他跟随王子身边，作为一个旁观者。

最早的时候，赤睛被咒世主赋予监察王子的责任，但后来赤睛自己决定要看着凝渊如何将自己推入自毁的深渊。

大概在枭皇前期的时候，两人就有过这样的对话，大意是赤睛要看着王子如何被自己吞噬。

不过详细集数跟内容，现已埋藏在前一部电脑里头了（默）。

好吧，我们继续回到王子身上，我写过难以捉摸的假疯子狂龙，外表疯癫却比谁都清醒，也写过喜怒无常的真疯子啸日猋，他是实际定义上的精神异常。

那王子呢。

他是清醒还是疯狂。

他的无定向比啸日猋、狂龙更无定向。

由于王子本身的行动并没有方向性，所以无法按照我以往编剧漫谈的一贯写法，将事情与情感转折作一个统整依序写下，乖乖~这家伙真的是个异数，搞到连作者都无从下手。

嗯，就姑且以各种面向去谈王子这个角色吧，上次提到，写作王子的重点关键：魔王子“你确定你所信奉的每个理念，你都能确实找到信奉他的理由吗。”如果有人想问自己这个问题，第一要件就是诚实面对自己，第二要件要深究自己，然后答案不须向任何人解释，只要自己能回答自己即可。

在剧中，王子不断以言语或者行动，挑衅目标的价值观，例如对寒烟翠的同性爱，迦陵的忠心，太息公对王子的迷恋，啸日猋的自责，剑之初的道德，戢武王对碎岛的付出与最后得到的背叛，军督的自尊与骄傲，对云鼓雷峰的佛理等等。

我尽量挑一些热门且随处可见议题作为目标，但实际上，任何一个议题都足以独立写成一个大长篇或者一部电影、戏剧，如深究学童霸凌与人性黑暗的小说苍蝇王。

复仇与**关系的电影原罪犯，描写政治操弄与威权统治的名作一九八四等等。

王子可没这么多时间把这些议题一一理清，大家都知道的，他的兴趣很短，而对单一目标的深入也非我一开始设计“绝对虚无”的王子所该作的，所以我采用蜻蜓点水式的点入法，让王子用优雅的身影，嘲讽的台词。

去反驳每一个角色自身信奉的信念。

由于桥段太多了，这里不一一拿出来举例，实际上每个议题要讨论到最后，都足以写成一大段的哲学论文了，而会刊太薄且这样的内容太无聊，我们就跳过去吧。

王子期望的世界是什么。

以王子的语气来说：“期望不过是个梦想而已。

以为自己可以改变什么，结果什么都没有改变。”王子是个不作梦的人，不只是意义上的，梦是现实的投射或反射，但现实对王子而言是虚无且不存在的荒谬，王子就算在睡着的时候也不会作梦。

既然不期望，无喜无怒无悲也无怨恨，无所谓对现实的满意与不满意。

那这样的王子也不会有作梦的必要性。

要说王子还保有当下瞬间之外的情感，那大概只有对这个世界的厌恶了。

是的，就是一种厌恶，王子的眼中看过去，这世界满是虚伪与枷锁，但被困住的人却茫然无知。

他也不指望这个世界觉醒，他只想享受末日来临。

某方面来讲，他大概是末日狂欢派的执行者吧。

魔王子不过，王子真的有享受到“快乐”吗。

我想有待商榷，他愉快的时间很短，大概只有在自己巧妙的布置终于完成后的那短短一瞬间。

那之后呢。

剧情中，他不只一次的向赤睛抱怨自己觉得无聊。

正如我一再强调的，王子的内心是空的，无论怎样的情感掉落其中，也只能听到下坠时的轻微声响，而不能填满这个虚无。

某方面来说，王子是EQ最高的人，因为他不会愤怒悲伤疯狂忌妒，他几乎没有负面情绪。

有人注意到吗。

每次王子被打伤时，他总是会笑，伤得越重就笑的越大声，因为疼痛让他感受到自己“存在”。

在那一秒钟的那个瞬间他确实有“感受”。

所以他笑，但这样的疼痛也会消逝，而终于成为不存在，一如他的快乐一般短暂。

有人说王子的乐趣是操弄人心。

这可不然，诚然，王子擅于掌握人性，但也仅只因为他深谙人性。

小三子以前看过一些宗教思辨的书籍，书中的辩论相当精彩，实际上，如果你想当一个真正的反宗教，你就非得深深精研了解教义，同样的，作为反道德枷锁的王子，也深深了解人性的动向，所以他能轻易的玩弄打击迦陵、慕容情、啸日猋他们。

操弄人性只是他的一个手段，但不是目的。

那他的目的是什么。

老话一句，去问他吧。

就算是编剧漫谈也不是每个问题都有答案的（奸笑）。

王子的登场台词：吾，魔王子，吾代表XXXX，这段台词初看之下好似只为了恶搞咒世主，实际上只有第一次登场时，以佛狱代表我那段，是以自身为主，强调王子“自我”的本性。

之后的每次登场，所使用都代表王子当时的心情与环境，这样的设计更也为了凸显王子的善变与捉摸不定。

而他一路走到最后，再与剑之初决战的时，他说了：“吾，魔王子，吾没有代表什么。”是的，既然虚无是本质，最终也是回归虚无，于是他不代表什么。

这是魔王子的结论。

或者也是虚无主义者的结论。

之前写武君罗喉时，我运用了大量的潜台词，而我在王子身上则是用了不少象征图腾，篇幅够的就说说，篇幅不够的，那就留给观众自己去猜吧。

先说几个比较明显的。

蛾的象征意义：蛾是一种害虫，会吸食树液，造成树木的病害。

之前提过火宅佛狱的象征就是树，巨大的扶木、盘根错节的地理环境，还有句芒（木神）等等，王子以蛾的象征出场，开场即暗喻他将会把佛狱吸食殆尽。

而剧情也确实如此发展，王子确实将佛狱作为他玩弄取乐的对象，将佛狱吞噬殆尽。

而选用蛾还有另一个理由，那就是蜕变新型态。

在电影《红龙》（《沉默的羔羊》前传）中蛾所赋予的意义，也是我这样设计的心理意义。

句芒双剑蛹眠之间：延伸蛾的意念，蛹代表的是蜕变，新型态，从蛹中诞生出的是新生。

还是怪物。

而实际上，蛾这种生物在蜕变成型后的生命大多通常很短，可以说，当蛾化之后，虽然蛾的生命得到了完整，却同时也是步入陨灭，套一句羽人说过的话：“羽化不是新生，而是死亡的变形。”堕落天堂：是堕落才会达到天堂，还是天堂中的堕落，还是堕落者的天堂。

还是从天堂堕落。 未完成的羽化，折翼天使像：王子所建造的石像，一只折翼的王子，这座石像是我将我的想法交给场景设计的某人，由她具象化我的概念，再由道具组执行。

原本的设计图当中，王子一边翼臂纠结，残缺不全，上身略弯，另臂前伸掌心向下，食指凸出微向下弯，另四指略内屈，下面是如山的骷髅，而一人攀登尸山，伸手却触碰王子的指头而不得。

嘿~这动作，我突然想起创世纪中的创造亚当了。

这个构图令人击节赞赏，可惜后来因为制作工时不够，所以后面全砍了。

大家幻象一下即可。

至于意义，留给大家猜想。

蛾空邪火出招前的痛苦：正如王子所说的，用自身的痛苦，换取对方得到更大的痛苦。

当然，痛苦也是王子感受自身存在的一种方式。

算是补强我前面的设定。

蛾蛹、折翼天使、蛾空邪火、堕落天使，把这些串联在一起，或者可以看到王子的另一面喔。

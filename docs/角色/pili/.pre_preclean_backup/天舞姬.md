# 天舞姬

艳色倾城，貌美如花的魔息大帝侍妾，平时守于魂棺夏禘内，由魔息大帝招唤时，方会伴随着音乐而现身，展露舞技。其舞姿出神入化、婀娜动人，同时手持琵琶，一身中东风格衣裳飘动下，手指一边拨弦弹奏、一边舞动身躯之景十分动人，为魔息大帝最喜欣赏之娱乐消遣。

## 来自百度百科的补充

魔息在年少时曾被天舞姬所引诱，曾无数次的问道淡风武靖到底有没有天舞姬这个人，淡风武靖说没有。

每在魔息珥图弹指间，天舞姬便会伴乐入景，为魔息珥图献舞。但魔息珥图常常在天舞姬施展唯一能为魔息珥图做的事情时，为自己的春秋大业做想。

天舞姬只有在魔息珥图面前出现。每当有人闯入，天舞姬便被魔息珥图立刻化走。估计没人知道有这么一个人。

# 靛羽风莲

手持莲扇、温文雅逸，其人谈吐幽默风趣，性格外放而兼具温和，正可谓亦侠、亦狂、亦温文；反应敏捷、遇事沉着，总是一派优雅从容，无论处世作风和外貌都偏属儒家风格。

## 来自百度百科的补充

靛羽风莲是素还真以"一人三化"绝学分出的三具化身之一。为消除天之奇象，靛羽风莲来到天荒不老城，被城主赏识并招为军师，城主还将女儿识玲珑许配给他。自此，靛羽风莲被江湖视为不老城一方，参与对抗其宿敌诡龄长生殿。最终在玄机门前，靛羽风莲与业火红莲、墨渊水莲三莲归一，还原为素还真。

**退场**

霹雳谜城40集（和墨渊水莲、业火红莲一起回归素还真本体，于玄机门前，风、火、水三莲并合，最终归一还原为素还真。）

（霹雳皇龙纪中，素还真三识受创之际短暂出现与一页书、汲无踪交手；创神篇中素还真受死亡之海影响，以往化身脱离本体其中包括靛羽风莲）

**武学补充**

- 风神一击

靛羽风莲是素还真通过"一人三化"绝学所化出的三身之一。为消除天之奇象，靛羽风莲前往天荒不老城，被城主赏识并招揽为军师，更将女儿识玲珑许配于他。风莲与识玲珑感情逐渐加深，但不老城与宿敌诡龄长生殿的战争爆发，风莲投身战斗。玄机门前，不老城城主现出六祸苍龙真身，风、火、水三莲归一，还原为素还真。在霹雳谜城中，面对变数，靛羽风莲当机立断发掌，联合水莲、火莲共破紫晶云棺，三莲并合引发生机。

**角色关系补充**

未婚妻：识玲珑（两人后解除婚约，识玲珑认靛羽风莲为义兄）

朋友：识能龙、苍；化身：业火红莲、墨渊水莲（三者均为素还真的化身）

靛羽风莲登场于霹雳布袋戏系列剧集《霹雳谜城》，剧中与水、火二莲合作攻破紫晶云棺，最终三莲并合。

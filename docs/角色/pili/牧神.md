# 牧神 (牧神)
================================================================================

牧神

天疆之主，統御鱗羽痕三族，身披華袍斗篷，手持雪白節杖，仙風道骨的高人之姿，性格沉穩，不怒而威。久遠前被初代閻王與天地蝱算計，重創之下藏身於苦境隱蔽，後在其女凜若梅的尋找救援下，終於恢傷勢回返天疆。然而重出的牧神，因當年遭背叛導致個性轉趨極端，行事一改以往懷柔仁善作風，變的果斷偏激，以天疆利益為優先考量，一心討回當年之恨，向閻王與天地蝱復仇。

其他紀錄

牧神設定緣由：
天疆是一個超然、與世隔絕之地，劇情設計上，居民以古代傳說中的瑞獸、靈獸組成，用動物特徵來與其他是介作出分別，其領袖就以牧羊人、放牧動物的概念來塑造。「牧」字也有冶理的意思，管仲曾著有牧民三章，談到牧養人民的政治思想，因而崇高的天疆之主就以「牧神」來命名，並以「蘇武牧羊」來呈現牧神的造型。

# 牧神 (牧神)
================================================================================

牧神

天疆之主，统御鳞羽痕三族，身披华袍斗篷，手持雪白节杖，仙风道骨的高人之姿，性格沉稳，不怒而威。久远前被初代阎王与天地虻算计，重创之下藏身于苦境隐蔽，后在其女凛若梅的寻找救援下，终于恢伤势回返天疆。然而重出的牧神，因当年遭背叛导致个性转趋极端，行事一改以往怀柔仁善作风，变的果断偏激，以天疆利益为优先考量，一心讨回当年之恨，向阎王与天地虻复仇。

其他纪录

牧神设定缘由：
天疆是一个超然、与世隔绝之地，剧情设计上，居民以古代传说中的瑞兽、灵兽组成，用动物特征来与其他是介作出分别，其领袖就以牧羊人、放牧动物的概念来塑造。“牧”字也有冶理的意思，管仲曾著有牧民三章，谈到牧养人民的政治思想，因而崇高的天疆之主就以“牧神”来命名，并以“苏武牧羊”来呈现牧神的造型。

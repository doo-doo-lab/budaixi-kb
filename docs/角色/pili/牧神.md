# 牧神

天疆之主，统御鳞羽痕三族，身披华袍斗篷，手持雪白节杖，仙风道骨的高人之姿，性格沉稳，不怒而威。久远前被初代阎王与天地虻算计，重创之下藏身于苦境隐蔽，后在其女凛若梅的寻找救援下，终于恢伤势回返天疆。然而重出的牧神，因当年遭背叛导致个性转趋极端，行事一改以往怀柔仁善作风，变的果断偏激，以天疆利益为优先考量，一心讨回当年之恨，向阎王与天地虻复仇。

## 来自百度百科的补充

### 角色雏形

"编剧初始设定天疆牧神曾是一个'善良得令人恶心'的正派人物。结合董事长想做的设定后，则是一个在先前三界大战中，被合作盟友背叛，死过一回，如今重生想以暴制暴、以黑制黑，行事已趋极端的领袖人物"。

### 姓名由来

"天疆是一个超然、与世隔绝之地，剧情设计上，居民以古代传说中的瑞兽、灵兽组成，用动物特徵来与其他世界作出分别，其领袖就以牧羊人、放牧动物的概念来塑造。'牧'字也有冶理的意思，管仲曾著有牧民三章，谈到牧养人民的政治思想。因而崇高的天疆之主就以'牧神'来命名，并以'苏武牧羊'来呈现牧神的造型"。

### 角色形象

"造型编剧指定要以苏武牧羊的形象来设计，以红白两色为主，苏武是外交使者，有明确的特征来做参考依据，而苏武在北海生活困顿落魄，但是牧神为一境之主，身份尊贵，在衣料和剪裁上须有华贵之处，虽然用简单的红白配色，简朴之中仍见尊贵之处。苏武在北海牧羊，环境寒冷恶劣，流传的图画大多有斗篷，披风等共通点，因此牧神也使用类似的衣帽，不过帽子里面好像还有什么东西，让它看起来这么高耸，这小小的变化，营造了牧神尊贵的地位。汉朝对外往来频繁，以手上的节作为代表皇上的信物，悬挂一串节旄，用红色来象征汉室传承的火徳。节杖是苏武最明显的特征，也是牧神造型搭配上的参考。白色代表超然，纯洁，白里透红是冰中透火的极端因子，表示牧神在行事作风上，有其极端的一面"。

### 武器

**牧天九歌**：天疆神器，依牧神元功生辰所铸之武器，故与牧神有护主之灵。在天地蝱与阎王围杀牧神时，在牧神受创、千钧一发之际，牧天九歌化出能量壁，挡下杀招，并将牧神推出战局。然而，牧天九歌事后被阎王带走，插在迦罗殿内。后被玄同太子拔出。外型为一长杵，多以稜角线条，表现其刚强，又似锏类兵器。左右两侧亦是剑柄，可抽出双剑，红白剑身代表牧神服装配色。

### 角色经历

#### 沉眠苏醒

"牧神，统领天疆三族的领导者，因仁慈敦厚而得天疆族名拥戴为王。然而，天疆神物古曜的存在，却让平和安乐的天疆卷入阴谋算计。心善的牧神未处理三阳同天在苦境造成的忧患，离开天疆赴会，熟料却遭遇苦境天地蝱与森狱阎王的背叛，濒死的重创，让牧神只能沉眠无数岁月，隐蔽于苦境等待时机，当森狱黑月再度出现苦境，天疆封印解除"。

"牧神之女凛若梅前往天疆取回牧神留下的神甲香火，顺利让牧神自无尽的噩梦中苏醒。但面对黑海森狱与天地蝱的虎视眈眈，痛定思痛的牧神却将舍弃过往仁慈，走上以黑制黑的极端之路。牧神与挚友剑鬼，暌违多年再续当年友谊，但已戒掉的酒象征重生的牧神已抛却过往仁慈"。

#### 行事丕变

"牧神选择利用森狱内部皇权争斗，诛杀流亡苦境的森狱阎王。西华山战火四起，牧神率天疆众军出征铲除敌手，向森狱阎王一讨血仇。然而就在牧神即将除去心头大患之际，森狱玄同太子竟是杀出战局，成功带走阎王。玄同太子超凡的武学造诣，等同宣告牧神在铲除森狱阎王的路途上，将横生波折"。

"为替天疆铲除敌人，牧神断然布下另一局棋局。牧天九歌回归天疆，圣气浩然撼动天地，但素还真的意外出现，打乱了牧神的盘算，一切付诸东流。牧神明了剑鬼对自己丕变的行事作风难以释怀，对善良本性的厌弃，与不惜化为魔鬼的守护信念，让牧神在这场三境斗争中走向伤人伤己的不归路。在牧神雷厉风行的手腕下，山龙隐秀参与翠华山之战，点燃战火，牧天九歌迎战沧耳刀，非凡神兵交集，划出双方各自立场，战火方兴未艾，熟料，天疆宗女竟是沦为人质，牧神纵使狠心割舍父女亲情，但玄同等援兵的出现，却迫使牧神只能铩羽而归"。

"论剑海外，牧神的奇袭，让天地蝱措手不之间，只能退守永生壁洞。熟料，本是瓮中捉鳖志在必得的胜利，却随着天际响雷而逆转，天地蝱竟是成功蜕变，摆脱虫体，重拾的完整功力带来了天疆的浩劫，天疆局势倾危只能败退而回"。

#### 离心离德

"天疆兵力接连耗损，牧神忧心忡忡，出自黑海森狱机关世家的若叶知秋也因此走入牧神巩固天疆的盘算中，牧神此举虽替天疆换得固若金汤的防卫，却也就此失去了父女亲情，若叶知秋死于牧神剑下，牧神为守护天疆不留情面的铲除任何可能潜在的威胁。背信弃义，甚至牺牲亲生女儿一世幸福的绝情，在在让剑鬼愤怒不已，即将两败俱伤之刻，玉雉衣不顾危险跳入战局，玉雉衣一番为天疆的衷心，也唤醒牧神理智"。

"牧神为防止黑海森狱与天地蝱再度联手，选择先下手为强，利用黑后与魄如霜针对森狱布局，然而山龙隐秀却败于加入森狱的银票当家，让牧神的盘算再度出现变数，与黑海森狱的人质交换，牧神惊天一掌震慑众人。然而螳螂捕蝉黄雀在后，牧神一时大意疏于防范，顿时陷入九死一生的境地。孔雀老者牺牲自己换取牧神活命，然而却也造成众人对牧神的误解"。

"在赫墨异能族的介入下，苍天护佑的机关图被盗，天疆面临两大势力围杀，天疆措手不及之间，转瞬付出极大代价。苍天护佑的毁弃让牧神再次走上极端，牧神杀死玉雉衣放出了咒天三孽，但咒天三孽阳奉阴违的行事手段，造成留白寺血案，接连的悲剧与遗憾，打造了天疆牧神罪无可逭的罪名"。

#### 回归初心

"诸神之巅，本是寻找妻儿消息而往的牧神，却是面临今生最讽刺的一场生死对决，在牧天九歌牺牲护住下，牧神于诸神之巅赢得胜利，然而另一场逼杀却接踵而至，但面对强敌环伺，魂体状态早已损伤过重的剑鬼，却也就此魂飞魄散。今生唯一挚友的殒命，让牧神痛心疾首，一路走来守护的事物一一从掌中逝去，让牧神幡然醒悟"。

"伤重在身的牧神纵使不甘屈服于命运，仍是难以为自己赢得生机，唯有保护女儿脱险的信念，牧神豁命让心所牵挂的爱女脱离战圈，坦然无惧迎接自己生命最终的壮烈一战，散作天地光影消逝"。

# 倚情天

北海灵洲的传说剑者，行剑有若凤舞九天，赤霞冲霄，绝艳当世，故得“剑凤”之美誉。倚情天性情看似冰冷孤傲，除“剑”以外，万事万物均不入眼，不时会流露出潜藏的危险特质，令人不寒而栗。终其一生，为剑、为情、为友，痴狂、痴迷、痴心。

### 人际关系

主要人际关系

爱人

君时雨

劫红颜与魔始之女，天性善良，一开始虽是别有目的接近倚情天，但却不自觉爱上他，最后为救倚情天而牺牲，劫红颜也为此失忆。因术法之能的天赋，死后灵魂被禁锢于薄樱魅影师之躯体，为昊天所控制，利用其能以北海灵洲之生灵蕴生死旸，身不由己……

恩人

昊天

霸气雄才，睥睨风云，统领北海灵洲的不世雄主，以昊天为名，隐喻昊光耀天，号令天下的宏大目标。

其真实身份为魔始众化之一。

朋友

白马纵横

豪迈潇洒、不拘小节、重情重义的川凉剑族奇才，个性幽默风趣，与火龙麒为绝佳搭档，充满过人的自信，一生行侠仗义，连死前亦不改潇洒本性，十足的血性汉子。

曾与倚情天在观沧海比了三天三夜的赣话。

奇梦人

来历神秘的奇异调香师，能散发异香，更能制造梦境。与兔爵士结伴同行，以梦境激励民心。为寻找消除邪染的方法，奇梦人来到充满悬疑气氛的北海灵洲。

与倚情天是相交多年的笔友，其真实身份为地冥。

渺若凡

北海雄主昊天的掌上明珠，貌美不凡，个性独立自主，善体人意，与宫女采风四处采集武林轶事，时常救助城内百姓。

仰慕倚情天，两人之间关系甚笃，但心知倚情天心中早有所属，是以默默守候。

徒弟

白马秋水

白马纵横与燕飞虹之子，本为云海仙门的两童子之一，在云徽子的帮助之下，秋水迅速成长，成为少侠的模样。性格继承了父亲的重情重义，不拘小节，幽默风趣，只是年纪尚轻，心性尚未稳定。

离开仙门后被倚情天收为徒弟并赠其太初之剑。

### 角色经历

登场前

与白马纵横相交成为知己好友。

与君时雨相恋，君时雨赠其魔始右臂化成的魔剑，倚情天与魔剑缔结命契。后因一念动摇被逐出仙门，自尽明志。君时雨以命换命救回倚情天。倚情天在北海灵洲醒来，以昊天为救命恩人，留在北海灵洲。

与奇梦人通过漂流瓶结识，开始通信。

在白马纵横死后（霹雳刀锋时期）辗转打听到其遗孀燕飞虹和幼子白马秋水下落，将其带往北洲城外安置，每年白马纵横的忌日都前来祭拜。

医治重病的秋水并劝说燕飞虹将其送往仙门学习。

在北洲期间时常外出各地寻找君时雨的下落。

曾受仙踪无名指点解破天之秘招。

登场后

甫出场即接下昊天命令，取走失主的终极冥帝，以此开启北海神宫。

再受昊天指令，自云徽子处夺取天书，留下剑招指点意琦行前往北海灵洲。

因渺若凡求其收徒的暗示，将白马秋水收为徒弟，传授其高手心理学与剑法，并将收取的太初之气凝剑赠予秋水。

与奇梦人见面。

路遇太易之气，受其所托将一朵红花送往风漠，拒绝太易之气的跟随。

奇梦人前来浮云栈拜访。

在寰宇斗奇与意琦行对战，意琦行因时间所制而落败。

将离水发病的奇梦人带回浮云栈泡水。

寰宇斗奇第三轮，正要与邃无端对决之时传来昊天死讯，嫌犯为意琦行与奇梦人，倚情天将昊天尸体送往神宫地下安置。

助意琦行击退巨魔神，表示选择用自己双眼找出证据。

撞见兔爵士欲盗取终极冥帝，从他身上截获与奇梦人笔迹相同的书信，因而前往仙门证实。

在仙门外撞见奇梦人，两人释疑，分头对抗祸木。

明白昊天阴谋，约定替昊天完成最后一事。

欲杀仙踪，遭奇梦人换手，误杀薄樱魅影师，发现其真实身份。

与奇梦人断情，后前往造孽处救奇梦人，用己身换回奇梦人和君时雨的尸身，自己被造孽控制改造。

改造过程中，造孽令君时雨说出过往真相，忆起曾与奇梦人通信询问之难题。改造尚未完成时，被造孽带往幽界。

在妖魔之海外围对战秋水，似对秋水的赣话有所感应。

在中阴界花林内压制杀性未果，将自己埋入石堆，被倦收天所救。后在途中遇上幻流星。幻流星给倚情天下药欲助其恢复。

被带上天魔灵车，彻底改造，不存一丝人性。

夺下爻帝之棺，前往绝境长城。

魔始回归，在永夜剧场命令彻底受控的倚情天放血给奇梦人喝。

受控覆灭云海仙门，回到浮云栈后发现毛球君亡，受风霁月（魔始附体）诱导前去找意琦行复仇。

与意琦行决战，魔始受奇梦人幻术所迷，看见意琦行为倚情天所杀，实则倚情天在意琦行的唤回和幻流星所下药息的双重作用下成功清醒。

随意琦行回到指月山瀑，欲让意琦行承接五剑。

与意琦行前往寰宇斗奇，倚情天对上仙踪，展开激战。

仙踪魔魂回归本体，倚情天在意琦行运气相助时将一身功力反向灌注意琦行体内，使五剑合一，自己昏迷。

清醒后阻止风霁月冲动欲助意琦行之举，旁观意琦行与魔始之战。最后同众人一起再将功力输给意琦行。

魔始败亡，救助劫红颜后离去，找寻奇梦人不得，回到浮云栈写信寄情。

回信随水流漂来，倚情天溯源百里找到兔爵士，被告知前因后果。于幻觉中再见奇梦人，而后离开。

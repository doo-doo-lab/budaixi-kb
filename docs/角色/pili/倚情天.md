# 倚情天 (倚情天)
================================================================================

倚情天

北海靈洲的傳說劍者，行劍有若鳳舞九天，赤霞沖霄，絕豔當世，故得「劍鳳」之美譽。倚情天性情看似冰冷孤傲，除「劍」以外，萬事萬物均不入眼，不時會流露出潛藏的危險特質，令人不寒而慄。終其一生，為劍、為情、為友，癡狂、癡迷、癡心。

# 千层雪

儒园之主，才识过人，美貌出众，精通琴棋书画的才女。本为魔域潜派伺机接近素还真、青阳子之人，在与两人结拜后，因爱慕青阳子而逐渐背离魔域。

密锁重关掩绿苔，廊深阁回此徘徊，
先知风起月含晕，尚自露寒花未开；

# 千層雪 (千层雪)
================================================================================

千層雪

儒園之主，才識過人，美貌出眾，精通琴棋書畫的才女。本為魔域潛派伺機接近素還真、青陽子之人，在與兩人結拜後，因愛慕青陽子而逐漸背離魔域。

名言錦句

詩詞

密鎖重關掩綠苔，廊深閣迴此徘徊，
先知風起月含暈，尚自露寒花未開；
蝙拂簾旌終展轉，鼠翻窗網小驚猜，
背燈獨共餘香語，不覺猶歌起夜來。

# 左无咎 (左无咎)
================================================================================

左无咎

凌虚七仙排行第二，凡事以不争为先，愿退其次的大度之人，然而声音雄浑有力，透露著一股威严，一旦决定有所作为，则会坚持到底，呈现出“我不与他人争，不代表他人可以对我予取予求”的心态。自弱水回归后，心知地狱鸟的威胁，重拾过往六崇越“听天阁”之主的身份，心态转为积极应对，协助正道对抗暗劫八无暇。

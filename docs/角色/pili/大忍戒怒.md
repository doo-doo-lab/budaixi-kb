# 大忍戒怒

菩提界修行最高的五莲尊者，大忍戒怒端正刚直，昔日为阻止波旬乱世之祸，赤莲手持法器赤龙杵，配合如来圣器与菩提弓，五莲联手降服魔佛，而后归返须弥山虔心修行。

# 醒惡者 (醒恶者)
================================================================================

醒惡者

居於火山熔岩罪惡深淵的奇人，心思難測、城府深沉，喜怒不露於言表，通曉術法和蠱毒之術，洞悉人心脆弱之處，與西方翳流關係匪淺。

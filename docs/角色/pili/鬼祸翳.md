# 鬼禍翳 (鬼祸翳)
================================================================================

鬼禍翳

戰慄公派去試探赮畢鉢羅的神秘殺手，雙眼罩著咒布，手持拄地鬼杖，身揹哭屍，哭屍乃真正的本體。情緒時而張狂悲憤，陰詭怪異，實則包藏禍心。鬼禍翳不聽警告，硬是尾隨赮畢鉢羅，出言挑釁，就在百步時赮背後的菩提長幾出手，一招直取背後哭屍首級，了結性命。

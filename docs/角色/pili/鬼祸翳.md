# 鬼祸翳

战栗公派去试探赮毕钵罗的神秘杀手，双眼罩着咒布，手持拄地鬼杖，身背哭尸，哭尸乃真正的本体。情绪时而张狂悲愤，阴诡怪异，实则包藏祸心。鬼祸翳不听警告，硬是尾随赮毕钵罗，出言挑衅，就在百步时赮背后的菩提长几出手，一招直取背后哭尸首级，了结性命。

# 朝天骄

================================================================================

霹雳布袋戏虚拟人物朝天骄，霹雳布袋戏虚拟人物。该角色是战云三骄之首，耿直中带有高傲的气息，为人自信，凡事说一是一，温和平稳中带有王者的冷酷风范，遇事则保持一贯的冷漠淡定。由于当初巨魔神攻打妖界时失落阴元，致使朝天骄在内的四大奇观之主受困封印；在阴元回归解封后，正式带领战云界攻打百妖路。

**中文名**：朝天骄

**别名**：凤座

**配音**：黄文择、朱袆（云鹤追）（轰动武林国语版）

**性别**：女

**登场作品**：霹雳侠影之轰动武林角色配乐编曲孙敬凡、浩旭

**本尊雕偶师**：洪剑山

**出场集数**：19集

## 人物设定

- **名称**: 朝天骄身份：战云界三骄之首诗号：胜负由吾不由天，谈笑戎马惯狼烟。争，天地有数；战，败吾不存。初登场：霹雳侠影之轰动武林 第8集退场：霹雳侠影之轰动武林 第26章（死于宫无后）根据地：战云神宫

## 人际关系

- **组织门派**: 战云界亲人：绝代天骄（二弟）、御宇天骄（三弟）心仪：玄冥氏部属：寰无疆（战云双擘之裁令主）、胤苍狼、造烽烟（战云双擘之云师）、星夜穷奇、曦眼苍鹘、银河殛

## 人物能力

武学：连云叠嶂、云天之变、怒马奔澜、飘渺云光、上雷无尽、霸雷三绝·「奔雷势、轰雷掣、奔雷灭」武器：凰刀蝶杀（玄冥氏所造）交通（坐骑）：龙战（朝天骄御用战马）

## 主要剧情

凤座 玄冥氏玄冥氏 【披风为凤座所披】玄冥氏 蝶杀玄冥氏 蝶杀【轰动武林21】朝天骄：就是此地。

玄冥氏：你们所言就是这阵赤色风暴吗？

若是，也毋须进入查探了。

朝天骄：你已有发现？

玄冥氏：这风暴本身并无利度，吾更肯定，当时隐藏风中的人，才是杀人凶手。

朝天骄：现在风中既无人，凶手留下形似一剑风徽的旋风，让人查探，是烟都蓄意误导，或者杜舞雩故弄玄虚？

玄冥氏：你吾皆知，四奇观之间本有相克，雪克风，风克烟，烟克云，云克雪，烟都要模仿风之特性，岂是易事？

一剑风徽能可逆转相克属性，亦需查证。

这些都是我们未来要揪出凶手，必须突破的盲点。

朝天骄：无论此事是谁所为，四奇观连番遇劫，凶手皆指向彼此，此仇更须谨慎为上。

玄冥氏：吾明白。

吾会用证据复仇，让凶手无话可说。

朝天骄：难为你来此已心如刀割，仍要一一查证。

玄冥氏：要平复心情，这段路还很长，再陪吾走一程吧。【轰动武林21.22】朝天骄：不露声色，大宗师还是同样的老狐狸。

玄冥氏：吾相信一剑风徽，此事定与烟都脱不了干系。

连番事故，看来四奇观的风暴将临了。

朝天骄：一同面对吧。【轰动武林23】（无感冷风刺骨，冰楼之主凄望眼前情景，悲从中来。）玄冥氏：冰泓吾弟。

朝天骄：夜冷风寒，你已经不眠不休，在此两天两夜了。[凤座为冰王披衣]朝天骄：错不在你，你该面对的，是人一生皆要正视的三个问题——失去什么会令人恐惧？

什么值得人活下去？

以及什么值得你牺牲性命？

每一个问题的答案都一样，就是爱。

爱不会因为你们不再相见就结束，你们兄弟也是同样。【轰动武林22】霜旒玥珂：皇兄面露忧色，是担心灼焚之日即将来临吗？

玄冥氏：然也。

每年灼焚之日，地心热能暴涨，是雪堡冰雕最脆弱的时候，也是冰楼之人功体最脆弱之刻，若有心人有意动作，必选在此时，咱们不能不防。

霜旒玥珂：皇兄放心，有凤座在此，奸佞难以得逞。

玄冥氏：凤座来是客，怎能如此失礼。

朝天骄：那届时，吾便守在冰楼三里之外，便不算是客了。

玄冥氏：凤座说笑了。

让吾再与冰泓，多聚片刻，咱们再从长计议吧。【轰动武林23】玄冥氏：是杜舞雩约咱们今夜在潇潇暮雨，召开四奇观大会。

朝天骄：选在此地，必为至关紧要之事。

历来只有四方建交与共研生元造化球，才会踏足此地，这回约见谅不单纯。

玄冥氏：上回丧礼已见轻浮，此次约见又显匆忙，一剑风徽之作风，似不若之前沉稳。

朝天骄：非常时期，作法自然不同，这点吾可以理解。

倒是你，在担心别人之前，先关心你自己吧。

霜旒玥珂：凤座何出此言，皇兄有什么事情吗？

朝天骄：抱歉，当初绝代天骄将三成阴元分与雪獒时，几乎皆是雪元被吸收，造成冰王元功恢复不全，此事终是隐忧，须赶紧处理。

霜旒玥珂：呵。

玄冥氏：咳。

多谢凤座关心，但事有轻重缓急，吾认为还是先处理潇潇暮雨之会，回头再处理雪獒之事亦无妨。

朝天骄：你既坚持，吾也不再多言。【轰动武林24】朝天骄：我只是暂时离开，不代表不会再回来。

再说，吾此行离开，除了找凶手，还想探望一个挂念的人。

霜旒玥珂：挂念的人，谁？

玄冥氏：能让凤座挂心者，必是同为天骄之列的绝代天骄。

凤座既然另有要事，路上小心，吾让皇妹陪你一程吧。

霜旒玥珂：当然，我未来的...咳，吾一定会顾好。

朝天骄：请。【轰动武林27】（玄冥氏握起蝶杀）玄冥氏：当初四大奇观建交，吾将你们赠于战云界，并雕下复刻做纪念。

这么多年来，是你助凤座建下彪炳战功，希望此次巨魔神窃案，你也能助她揪出元凶。

镂冰氏：楼主，不好了！

（蝶杀脱手）玄冥氏：啊。

霜旒玥珂：怎会如此？

镂冰氏：生要见人，死要见尸。

尸体在哪里？

秦假仙：尸体已经火化了，详细要问一字铸骨，这件事，是我从他那听来的。

此人行事正派，话不会错。

镂冰氏：此人是何来历？

何处可寻？

秦假仙：他是职业的捡骨师，时常出现在西市的市集附近。

他全天下什么骨头都捡过，里面最特别的，是竟然有水晶骨，玲珑剔透，真正有稀奇。

唉，朝天骄一死，巨魔神就被欲界迷达所用，迷达一定会利用它攻击天佛原乡，届时生灵涂炭，一定非朝天骄所愿见。

楼主若有办法，是否要伸出援手，好告慰凤座在天之灵。

吾言尽于此，你们自己节哀。

玄冥氏：副楼主，赠秦假仙驭寒魄为谢，让他们以后能可自由出入冰楼，不受暴雪侵袭。

秦假仙：多谢，请。

霜旒玥珂：皇兄，你一定要为凤座查出凶手。

玄冥氏：不用你说，吾也会介入此事。

冰楼交你进入戒备，副楼主，你与箭童追霰随吾一寻一字铸骨，查清真相。

（掌心沁血）霜旒玥珂：凤座……【轰动武林27.28】一字铸骨：措身物外谢时名，着眼闲中看世情，人算不如天算巧，机心争似道心平。

玄冥氏：阁下便是一字铸骨？

吾乃朝天骄挚友，请你将发现尸体情形，一一告知。

一字铸骨：事发地点是在一处的荒郊花林，周围花草，除了似曾被风暴扫过之外，并无其他的线索。

镂冰氏：风暴...玄冥氏：死因？

一字铸骨：利刃断头，快、狠、准。

玄冥氏：可有其他特征？

一字铸骨：有，断头处有被烧焦的痕迹。

镂冰氏：焦痕，这不是一剑风徽的剑法。

玄冥氏：是烟都。

你的线索很宝贵，多谢。

一字铸骨：份所当为。

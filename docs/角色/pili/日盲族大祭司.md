# 日盲族大祭司 (日盲族大祭司)
================================================================================

日盲族大祭司

夜族祭司，擁有預知之能，地位崇高，一心盼領夜族回歸正常生活，不受歧視，卻因一場滅族變故，讓大祭司對日族懷有強烈敵意，性情也顯極端執著。為讓日盲族脫離黑暗，積極促成太陽之子的誕生。

# 日盲族大祭司

夜族祭司，拥有预知之能，地位崇高，一心盼领夜族回归正常生活，不受歧视，却因一场灭族变故，让大祭司对日族怀有强烈敌意，性情也显极端执著。为让日盲族脱离黑暗，积极促成太阳之子的诞生。

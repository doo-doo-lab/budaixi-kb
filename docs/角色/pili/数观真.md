# 数观真

================================================================================

霹雳布袋戏虚拟人物数观真，霹雳布袋戏虚拟人物。久远之前被放逐到绝境长城的中阴界国师「点玄机」，后为宙王诈死利用其躯体寄灵前往苦境，化名为「数观真」，精通冰鉴之术，擅以天地生死月品花七种相术，观人百年福祸之数。遇人常以观相之术应对，表面为寻访具帝王之相者辅佐之，实则为打探灵儿下落并搜集苦境情报。

數觀真

數觀真，霹靂布袋戲虛擬人物。久遠之前被放逐到絕境長城的中陰界國師「點玄機」，後為宙王詐死利用其軀體寄靈前往苦境，化名為「數觀真」，精通冰鑒之術，擅以天地生死月品花七種相術，觀人百年福禍之數。遇人常以觀相之術應對，表面為尋訪具帝王之相者輔佐之，實則為打探靈兒下落並蒐集苦境情報。

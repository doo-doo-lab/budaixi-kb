# 秤價仙 (秤价仙)
================================================================================

秤價仙

走闖江湖的赤腳大夫，專治醫男性不舉與性無能。運氣不錯且辯才無礙，認為萬事萬物皆有其價格，他只要抓一把就能秤出價錢，估價十分厲害。

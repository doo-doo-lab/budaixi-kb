# 玄膑太子

================================================================================

## 角色设计

姓名膑是膝盖骨，古代有切去膑骨的刑罚，历史上也有孙膑的故事，孙膑是战国时代的军事家，曾被陷害身受膑刑，但他没有自暴自弃，反而更加坚定意志，完成功业。

编剧以此残疾、忍耐的典故命名，作为玄膑形象上的暗示。

造型玄膑造型选择以深蓝色系呈现，除了稳重高贵、突显与其他皇子色彩设计的不同，也暗示了他的深沉。

以羽毛来点缀出身份高贵，华丽禽鸟的羽毛，在古代向来是身份的象佂。

大排扣，礼服样式，偏向军装的风格。

配合贵族身份制作的龙型头冠，不会过分霸气，也不失斯文。

龙武铁甲玄膑因病导致一足成残，特别设计一只铁脚，以铁甲包覆受伤腿部的概念，配合特写行走时金属撞击地面的效果，让初期看来软弱的玄膑，有更鲜明的形象。

登龙杖为突显玄膑的残疾，特别设计手杖，但手杖同时也是绅士、权贵的象征，外形典雅，以深色强调稳重。

武器龙武战戟初登场：霹雳侠影之轰霆剑海录 第27章武器特色：看似软弱怕事的玄膑太子，实则为森狱皇子中最深沉之存在，特别选用画戟类型的兵器，来展现出驰骋沙场的雄风，紫色系的配色贵气中显现沉稳，画戟的尖锐处锋芒毕露，让总是隐藏自己实力的玄膑太子完全颠覆平常形象。

丰功伟业：虽是贵为森狱大太子，却因脚的旧伤及蜕变黑后的存在，让玄膑太子忍受下别人无法置信的嘲讽与看低，然而在时机成熟后，玄膑太子的动作却是频频让过往轻视之人膛目结舌。

在武学造诣上，玄膑太子克服了旧疾的障碍，龙武战戟在手竟能直接与天疆牧神对峙，更在之后精心布局，单挑阎王恶相也是不落下风，就连阎王亦是相当讶异玄膑功力精进如此。

千玉屑一旁助阵锁功扣，邪木枷锁配合玄膑之招，锁住阎王元功并成功擒抓，让人不得不佩服玄膑太子的智勇双全。

元神兽龙武会刊228玄膑大太子图册编剧选择以类似玄武的龙龟作为玄膑元神兽的外形，礼记有曰：麟凤龙龟，谓之四灵。

龟有保护自己的天性，外表看起来畏缩，但却能因此避免危机，在险恶的环境也能安身立命，等待时机。

以龟来表示玄膑隐藏自己的本性、静待时机的作风，以龙武为名。

后来又让玄武变化为龙，代表从蛰伏到巅峰。

## 角色经历

玄膑，黑海森狱大太子，与玄同、玄灭、玄嚣三兄弟共列太子之位，但玄膑在起点上，可说是集所有劣势于一身。

多年前的一场重病残疾，让他难如玄同般，练就过人武艺。

也不如玄灭，有母系后台高翔族的资源撑腰。

更少与兄弟来往，不得阎王重视，难如玄嚣一般能公开的笼络人才。

但这一切都不代表他不能，他的隐忍，只是因为时机未到。

玄膑的能忍与心计，可说是环境造就下的影帝。

畸形的家庭，斗争的帝王家，让他继承了阎王的深沉，深知过早显露锋芒，只是让自己成为众矢之的。

所以，他能无情的坐视兄弟灭亡，再以仁德之姿，出面收拢人心，如水晶宴上，玄膑对玄同就玄嚣之死一事说道：“天罗子是被玄嚣所杀，黑后虽不准厚葬，不过兄弟一场，玄膑不能坐视兄弟曝尸荒野，为兄已有私下收埋，吾将玄嚣葬在葬天关外二十里处之丘陵，墓碑以麒麟为志，无署名。”简短几句话，让重视兄弟情义的玄同，对其放下戒心，也让其它兄弟，感受出他与黑后的不同。

玄膑虽以仁德为名，然而讽刺的是，剧中玄膑对手足的无情，却是无时不展露。

如同当初从鬼吟诗手中取得王诏，回答阎王所留的问题，就可见端倪。

再从来后坐视原无乡杀了玄黓与玄阙，也可证明他确实是有胆量杀了自己兄弟的。

只是，玄膑的无情，是真无情，抑或环境所逼。

在玄阙败于倦收天手上，身体被带回时，察觉玄阙曾受逆咒反冲，玄膑运动元功，强行吸纳噬体邪劲，所流露出的关心，是否真的只为收买兄弟。

他安排玄造退隐的举动，又是否象征他内心深处，其实有不为人知的一面。

王座的独白玄膑的影帝之路，王座是最佳道具，每每四处无人的时候，王座往往是玄膑显露想法的告白对象。

例如在得知天罗子未死之后，玄膑深知黑后为夺权、护子，手段必定越趋极端。

森狱新一波的宫斗在即，王诏虽早赋予他铲除异己的权力，但无论他再怎样亟欲突破，也不能操之过急。

因为他玄膑要做的，非是下一代阎王，而是历届阎王皆无法完成的创举。

同时，在越是接近目标，玄膑越是会提醒自己，轻易到手的东西，往往也容易失去，该好好利用所有的棋子，为自己拔掉所有的阻碍。

即使距离这王座最近的是他，但不能因为行到阶段目标，就安心回顾来时路。

他的隐忍，让他能不断提醒自己，安于现状是加速自己毁灭的毒药，必须继续前行，才能继续走向无人能及的境地。

劣势中的逆袭玄膑的智慧，每每呈1999年劣势中的逆袭上。

对外上，玄膑在葬龙道扩张黄泉归线时，一句金鳞之躯，岂是下兽可逆。

气势击退天疆之人，却在回葬天关时，故做惶恐，挑起两界战火。

且面对牧神挑拨之语，更是做足了戏，让牧神对玄膑留下无能印象，也埋下两人日后合作的伏笔。

玄膑太子在天罗子回森狱与黑后的一场见面，加深玄膑扳倒黑后的决心，看破一个谎言背后，就有一个真相的他，先是将计就计，让原无乡入主森狱，收拾异己，待时机成熟，更软硬兼施，收服卜相机关与千玉屑后，更与牧神连手，利用魄如霜之仇，让黑后行事越趋极端，加深黑后自我的毁灭。

之后，果不其然，黑后以通敌罪欲除玄膑，但玄膑的反动，却是早已布下。

玄膑先是反其道而行，安排千玉屑刻意向素还真暗示，必须将黑后留住，黑后才有生机。

依素还真才智，必能连想到森狱政局已起变化，但他料不到千玉屑也是反叛黑后的其中一员。

抓准素还真念在战友之情，必会极力说服黑后，不要黑后再回森狱枉送性命。

但素还真终究不如玄膑了解黑后，以黑后醉心于权势的心理，素还真的劝说，只是更加激起黑后的逆反心理，而玄膑要的，就是这个效果。

这场白梅树下杀局，黑后可说是彻底的败了。

只是这场帝王家的悲哀，又真的有所谓的赢家吗。

越接近权力顶峰的玄膑，又是否能维持一贯的韬光养晦，抑或被终于到手的权势冲昏了头。

三界之战，将入尾声，玄膑能否如愿，且待后续分晓。

玄膑的治国策玄膑贵为大皇子，虽被其它皇子视为软弱、畏事，然而在玄嚣死后，玄离前来质问玄膑有何能力继承大位时，玄膑却给了玄离一个出乎意料的答案，森狱需要的是——新的思维。

膑：如同不脱皮的蟒邪，只有死路一条，人也是如此。

若总是披着陈腐思想的皮不放，只会逐渐腐败，不但无法成长，更步入死亡之途。

所以森狱必须有新的思维，进行新陈代谢，才能脱胎换骨。

对玄膑而言，领导者个人的勇武，绝非长治久安之必备。

刚则易断的道理，在玄嚣身上体现无疑。

所以玄膑展露出来的，是一种守柔处弱的，他并非甘处下风，自为人后。

而是一种能忍小愤，伺机而动的度量和韧性，适时柔之，适时刚之。

且提出“仁德治世”做为治国之本，“稳固资源”做为强国之方，国祚才会绵长。

兵权，战力，只时一时的威吓之物，是标非是本的理念，让玄离刮目相看。

## 主要关系

玄膑击败黑后之后，掌握了黑海森狱实权，除阎王之外，境内再无能威胁其地位的反对者。

阎王第二十八代阎王，不按照传统预言方式，指定继任者，而是自行指定四位王储，任其互相争夺，各皇子壁垒分明、派系倾轧消长。

若非如此，玄膑也许不会有斗争野心，与兄弟之间也许更加亲爱。

而这一切，却是阎王计划的一部分，玄膑所为皆在阎王意料之中，虽然玄膑已大权在握，但他能对抗得了阎王吗。

阎王计划逐渐明朗，玄膑能再次演出逆转戏码，或是仍在阎王掌心挣扎。

玄膑太子蜕变黑后为了向阎王报仇，为了自己的亲生孩子，黑后利用玄膑，掌握黑海森狱大权，暗中联合木晶灵伤害玄膑，再假意出面治疗，让玄膑视之为恩人。

黑后不止一次承诺将来必扶玄膑登基，但玄膑真实心机非黑后可测度。

表面上，玄膑事事顺从黑后，无一事敢违逆，黑后也认为玄膑软弱，能力不足为王，但黑后就是如此自以为看透了玄膑，自以为掌控玄膑，因而让玄膑有可乘之机。

# 瑞弗•斐迪 (瑞弗•斐迪)
================================================================================

瑞弗•斐迪（火爆球王）

上將，巨龍號艦長，僅有一名獨子保羅，因過度溺愛致使其倚仗特權無惡不作，獨子被戚風失手打死後，為報復而利用權勢陷害戚風，讓他被判終生監禁；個性遲疑不決，容易喪失先機，智慧平庸但有識才之明，故能立下功勳登上艦長之位，晚年因喪子之痛而不太過問艦隊事務，視漢克為重要左右手，信賴且依賴漢克的分析判斷。

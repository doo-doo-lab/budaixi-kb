# 地之者

================================================================================

霹雳布袋戏虚拟人物地者，初称地之者，是台湾霹雳布袋戏系列中的虚拟角色，死国创世双尊之一。

身披金甲黑绒，性格沉稳，与天者共同构建死国生态体系，以肉身支撑地罪岛并操控精神力实体化作战。

作为死国武魁，地者掌握兵甲武经“灭”之卷，武力凌驾五尊，曾与一页书短暂交锋未分胜负。

在妖世浮屠冲破死国大门时牺牲肉身阻挡灾变，为神之子诞生与阿修罗复生铺路。

其存在始终与天者形成制衡关系，常以务实姿态调和天者的极端决策，在死国内部权力斗争中扮演关键角色。

最终战死于天者引发的冲突，其死亡促使天者重新审视情感与责任。

地者始终忠于天者的创世理想，两人默契跨越族群隔阂，其生命轨迹贯穿死国革命、神权博弈与资源争夺的核心矛盾，成为死国架构中不可或缺的力量支点。

## 人物关系

在略城之战中，地者曾率领九妖翼姬、冷暗邪爵及死国大军行动，九妖翼姬曾赞叹其武力，冷暗邪爵则转述天者对其的评价。此外，地者亦曾阻止邪者的行动，并在迎接冥王神威的仪式中，与阿修罗、尊皇等角色有所互动。

## 相关作品

歌曲《地之者》由孙敬凡演唱，收录于专辑《霹雳英雄音乐精选二十七: 兵甲龙痕 (电视原声带)》，类型为纯音乐。

## 故事来源

死国的故事，其实在架构上式非常庞大的，表面上千军万马，其实分工都分得很细，就如当初的天下封刀一般，东品、西造、南论、北武以及中神刀，加上千刀卫、六刀侯、四大名流、两护法、副主席与主席等等。

笔者设计组织的时候，习惯将每个阶层跟单位分清楚。

所以死国部分也是一样，除了外来的死神与神之子，最高统领阶层天者与地者，管理五大栈道的死国五尊，创造五行资源的六魔女，以及死国战士：魖族、蛔族、貔族等各种族群。

中央的主题领导，便是天者地者两人。

地方上的故事，则是由阿修罗、夜神、天狼星，所带起来的平民革命势力。

当初在设计死国的时候，其实就是想呈现出，一个国家的诞生于延续，过程中需要多少的集权斗争、屠戮战祸、革命反动？

最终，究竟在死国创世的过程中，是该由天者与地者的集权领导是正确的的呢？

或是由阿修罗带动的平民改革才是正确的？

一直以来，过去种种的人类历史或许有了答案，但死国的答案还没有真正出现。

死国的主题故事，其实并非死神，也不是神之子，这两人对死国的意义只在于；

绝对的毁灭与创造的契机。

死神降临死国，正好是阿修罗意外死于走廊之后，当时正是死国反动势力最强的时候，众人都质疑天者害死阿修罗，天者本欲痛下杀手毁灭死国种族，这时死神意外降临了，死神绝对无敌的力量，威赫死国内所有准备向天者革命的族群，而死神对天者的智慧与远见也非常赞赏，所以愿意接受天者的意见，就在死国种族畏惧死神且无依无靠之时，天者见机送走了死神，再度凝聚死国散离的人心。

当初设计好死国的架构，就预订死神只是一个传说，因为他的强度在台面上会非常麻烦。

而太学主，则成为死神在人间的执行者，至于死国真正的秘密，其实全部隐藏在死国年纪其他未公开的章节，笔者当然没有全部说完，就是保留了死国的可能性，当然包含天者的部分，结果枫岫主人帮大家公开了一件事情，那就是最后一个地方，简单来说：就是死神对天者很不爽，要找机会海扁他一顿。

所以要枫岫主人用妖世浮屠拖拉库去撞毁死国大门，引爆死国连环重大车祸，一方面阻止神之子回归。

天者坚持神之子的回归，是天者知道日后死国必定需要神之子的力量，用来成就万妖炉最强的力量，开启死国真正的希望，让死国的生命彻底蜕变。

而神之子本身并不清楚结局，但是当时进入神眠之间，自己就已经受制于天者的力量，虽然提点了阿修罗，但阿修罗却无法对神之子下手，神之子可以预见死国的未来，但他知道天者何阿修罗都是为了死国，最终的毁灭，自己无法阻止，即使倡导和平，也只能扮演一名过客。

死国一切的故事源头，其实都来自于天者的想法。

天者是死国最高领导者，也就是死国创造之神。

就笔者故事的原始设定来说，这部分是不会演出来的，他算是一个草案设计。

故事原案：天者的真实身份来自于天界，一个接近神话的国度，算是笔者的个人想象。

天族传说原案设计：天界之上，有一个非常自负高傲，且具有远见的白天使长，此人虽有卓越的智慧与目光，但因为个人追求完美，作风强硬，屡次为了完成任务而干犯天条，虽然战无不胜但却过度高傲自负，目中无人，最终被太阳神惩戒取走双眼，且留下罪之印记在额头，失去了光明，但最终他挟怨离开天界，而无条件愿意跟着他离开的，是一名一直仰慕他远大目光的黑天使。

故事便由这个故事而开始。

在天族内，天者是个很滥情也很容易受伤的人，但他却总是以非常高傲自负的姿态，去掩饰内心的孤独与伤痛。

这一点，唯有一名黑天使长可以明白，他便是地者，身为将军，地者负责的部分则是武力与平乱。

而天者所负责的则是主导作战，两人合作未曾吞下败仗，地者也只相信天者的战略。

过程中，地者了解天者的个性，那种孤独高傲的脆弱。

天者因为被夺去双眼，不远等到刑法期满，决定舍弃神族资格，独自前往死地再造属于自己的生命。

而在此时，地者毅然决然跟着天者舍弃神族资格，一同进入位于六境十界之外的奇幻空间。

天者最大的安慰来自于地者，因为地者为了挺天者，可以连自己的生命也不要，连自己的亲兄弟也做不到。

天者进入死国后，希望像太阳神证明自己的能力，所以创造了死国制度，开创生命生存的法则。

当初死国是一片混沌荒芜，毫无生命，眼前只有黑白两种颜色的虚幻之地。

后来天者负责领导死国的天命，而地者则是选择以自身扛起整个死国。

天者运用智慧，使用再生魔法，创造魖族、蛔族、貔族、甚至其他各样恶魔生命的种子，并且留下禁断血印。

而地者则是把自己的灵魂跟精神扩散到大地，变成一个巨人扛起地罪岛。

有了生命种子，为了繁衍生命，天者利用魔法搭配神力，创造出六魔女来生产金、木、水、火、土资源，分别是魔女之首鬼薄英(象征嫉妒)、双子魔女灵沙呗(象征贪婪、暴食)、银火魔女葵苓(象征暴怒)、灵火魔女色芳(代表色欲)、丧火魔女白谒(象征懒惰)。

并且建立中央管理制度，死国天都在中央，周围各有五条栈道，连接五个都城，负责掌管五大能源，管理者是死国五尊，其中四尊是天者与地者之血所创造。

共分无界尊皇、银月贪狼、鬼狱邪神、黑暗冷爵、九妖翼姬。

其中尊皇与贪狼是实力最恐怖的强者，而鬼狱邪神对天者与地者绝对忠心。

其中无界尊皇是天者在天族的亲手足，因为天者与地者的离开，不久之后，尊皇遭受庞大的压力与歧视，于是也决定离开天族，追寻天者前来死国，他跟天者的手足关系，其他四尊都不知情，而地者虽然知情，却装傻提天者隐瞒苦心，因为天者虽然希望尊皇领导死国，却不希望其他四尊投以异样的眼光，所以让尊皇与四尊一同平等出现，更让他与其他人一同竞争并管理五都，无界尊皇过人的实力与天赋，是他迅速成为五尊之中的皇者。

但在过程之中，尊皇却爱上了魔女之首鬼薄英，而其他五名魔女也已因此而骄傲起来，因为她们掌握了所有死国生命的粮食源头，后来死国种族开始倒向六魔女，便希望六魔女能成立新的国家，能与天者、地者、五尊平起平坐。

大业未成，天者不允许其他势力的暴动，于是暗中封印了六魔女，用黑暗之章将她们终生禁锢。

自此以后，尊皇与天者渐行渐远，尊皇对天者的厌恶以到达底限，也无法了解当初六魔女存在所带来的危机，天者也不愿多做解释。

尊皇愤恨退出五尊首座之位，天者该推鬼狱邪神成为五尊之首，后来阿修罗意外身亡，尊皇成为死国战士最强的代表，直到死神降临，主动挑战尊皇，并将他打落不毛矿坑。

尊皇也将计就计，为了找寻魔女鬼薄英，让自己接受九酷血惩。

化为全身尖刺透体的恐怖模样，只为找出只爱鬼薄英。

天者虽然善用心计与计谋，其实最不会表达的就是自己。

也因为惯用了手段与智谋，让人无法明白天者的想法。

要他辩论说谎很简单，要他解释自己的真心却很难。

最了解天者的，从头到尾只有地者一个。

因为只要选择相信天者，他就会一直相信下去，所以天者从来不用对地者解释什么。

无论过程中遇到多少事情，地者所负责的，就是提醒天者隐藏的危机。

对地者而言，只要任何对天者有害，他就会阻止，对天者有利，他就会执行。

这也是两人创始至今，一种永远无法切割的默契与感情。

地者明白天者惜才滥情之心，所以放任鬼狱邪神的无礼、阿修罗的夺权、夜神的背叛、尊皇的憎恨、鬼薄英的生机，甚至还让月声逃出死国，地者常常提醒天者，这明明是危机所在，但创造的心情，也只有天者明白，怎么说都是自己创造出来的生命与手足，掌控死国生命的禁断血印，非到最后无奈，天者都不愿下手。

天者希望众人走出死国，利用万妖炉改造自己所创造不完全的生命，并让牺牲的战士复活，他不希望死国生命永远是战争的奴役。

无奈这样的改变需要牺牲无辜，阿修罗便是牺牲无辜生命的反对者。

所以后来地者的死，让天者体会了人类最真挚的感情，那就是伤心的眼泪。

天者害怕失去，但逞强的个性却使他失去的越来越多，终于他宁愿舍弃尊严与面具，把一切留给自己的手足尊皇，并让鬼薄英脱离束缚，保住死国未来再造的生机。

即使未来仍然无人了解，他也无所谓了。

最终于阿修罗的一战，那是一场赌上生命的战役，谁赢谁输？

天者也看开了。

为什么两人总是背道而驰？

阿修罗应该是自己最疼惜的爱将·············也许一开始，天者就不该妄想创造一个国家，因为创造了生命，就有了此生无法割舍的感情。

# 一刀齋 (一刀斋)
================================================================================

一刀齋

棋邪縱橫子身邊的護衛，腳踩木屐，一身東瀛裝扮，性格也如東瀛武士般執著。刀藝精湛，手持歷經千錘百鍊的武士刀「紅雪十握」，平時與縱橫子形影不離，並守護於一旁。若遇江湖人士前來挑戰棋邪，則與棋邪以一文一武之鬥來與來者對弈。而一刀齋真正的目的，則追求有朝一日能真正打敗縱橫子。

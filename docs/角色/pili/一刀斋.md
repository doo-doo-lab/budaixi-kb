# 一刀斋

棋邪纵横子身边的护卫，脚踩木屐，一身东瀛装扮，性格也如东瀛武士般执著。刀艺精湛，手持历经千锤百炼的武士刀“红雪十握”，平时与纵横子形影不离，并守护于一旁。若遇江湖人士前来挑战棋邪，则与棋邪以一文一武之斗来与来者对弈。而一刀斋真正的目的，则追求有朝一日能真正打败纵横子。

## 来自百度百科的补充

一刀斋是霹雳布袋戏系列中的东瀛武士型虚拟人物，"身着东瀛传统服饰，脚踏木屐，以武士刀'红雪十握'为武器"。其性格执着于武道，始终追随纵横子。因以"红叶一先"谜题缔结契约，在长期追随中领悟"败，当然；死，当然"的武学真谛。

一刀斋平日与纵横子形影不离。若遇江湖挑战者，则与棋邪以一文一武之斗协同应对。其终极目标始终追求有朝一日能真正击败纵横子。曾"奉命假扮神机执行危险任务，最终为保护纵横子战死"。死亡场景伴随红叶飘落，诠释红叶一先禅机。

# 一刀斋
================================================================================

一刀斋

棋邪纵横子身边的护卫，脚踩木屐，一身东瀛装扮，性格也如东瀛武士般执著。刀艺精湛，手持历经千锤百炼的武士刀“红雪十握”，平时与纵横子形影不离，并守护于一旁。若遇江湖人士前来挑战棋邪，则与棋邪以一文一武之斗来与来者对弈。而一刀斋真正的目的，则追求有朝一日能真正打败纵横子。

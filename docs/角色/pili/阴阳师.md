# 阴阳师

邪能境之主，曾为争夺机缘图而亡于欲苍穹之手，在瑶琴巧韵与极道天权的帮助下，藉烙骨大法复生；在邪能境拥有崇高尊贵的地位，饱含智谋武略，个性深沉隐重，修练阴阳双册，可以变化男体女体，曾与人形师有一段难解的恩怨情仇恨…

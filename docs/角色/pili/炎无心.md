# 炎無心 (炎无心)
================================================================================

炎無心

當世陽淵火母，擁有孕育聖火之能，被火族視為至高的存在，每一甲子便會進入浴火輪迴，重生之後將失去一切記憶，形同幼兒，由侍火一族養育成人。然而，火母每一年皆須以人為薪、焚人續命，方能維持聖火不滅；豈料，被選中犧牲奉獻的薪人，竟是炎無心青梅竹馬的好友狄子薪…。

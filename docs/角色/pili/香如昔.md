# 香如昔

占云巾胞妹，外表温婉，内心却坚毅逞强，昔日本深爱平明送客楚山孤，并怀有身孕，无奈楚山孤被杀，香如昔诞下死婴，人生遭遇莫大不幸，致使精神异常，被其兄安置在无著静庵内，受还音师太照顾。

## 来自百度百科的补充

她外表温婉，内心坚毅逞强，曾深爱平明送客楚山孤并怀有身孕，后因楚山孤被杀，诞下死婴，遭遇不幸导致精神异常，被其兄安置在无着静庵内受还音师太照顾。在无着静庵，她被花花和尚带走，还音师太为阻止而身亡。最终，她在风涛楼向占云巾询问楚山孤死因后，选择自尽。

香如昔初登场于《霹雳靖玄录》第5章，被其兄占云巾安置在无著静庵，受还音师太照顾。在无著静庵内，花花和尚一艳僧询问香如昔可识胡笳，香如昔昏迷被带走；还音师太试图阻止时被杀害。在风涛楼客房内，香如昔询问占云巾，杀害楚山孤的涤瑕快剑是否就是琴狐。月老庙中，香如昔祈祷夫君与儿子平安归来。无著静庵内，香如昔疯癫寻风云儿，在市集失控，与风云儿鲜血意外融汇。最终，香如昔退场于《霹雳靖玄录》第17章。

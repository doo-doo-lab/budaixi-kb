# 香如昔 (香如昔)
================================================================================

香如昔

占雲巾胞妹，外表溫婉，內心卻堅毅逞強，昔日本深愛平明送客楚山孤，並懷有身孕，無奈楚山孤被殺，香如昔誕下死嬰，人生遭遇莫大不幸，致使精神異常，被其兄安置在無著靜庵內，受還音師太照顧。

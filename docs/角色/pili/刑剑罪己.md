# 刑剑罪己

================================================================================

霹雳布袋戏中的角色刑剑罪己，霹雳布袋戏中的角色。百韬略城的祧师，头梳斜髻，红巾系颈，身披白铠甲袍，腰悬青铜古剑，因看不惯南风不竞为一己好恶而殃及百姓，出面劝阻，却反被南风不竞视为挑战，最后不敌命丧神之卷绝学，刑剑罪己之死，也牵动背后的百韬略城涉足武林。中文名刑剑罪己配 音黄文择性 别男登场作品霹雳震寰宇之兵甲龙痕组织门派百韬略城诗 号瘦马一骑三千里，步至秋风断肠时上 司鬼谷藏龙同 伙劫随、玉权臣、列鸿缺

## 角色设定

名称：刑剑罪己诗号：瘦马一骑三千里，步至秋风断肠时。名言：将狠毒表现在外，生人还有可避之机，但若将狠毒包藏在皮肉之下，那才真是使人防不胜防。初登场：霹雳震寰宇之兵甲龙痕 第2集退场：霹雳震寰宇之兵甲龙痕 第2集（死于南风不竞）

## 角色能力

- **武学**: 凝天地精魄·化一气浩然·芒芒在·剑光寒武器：青铜剑

## 角色关系

- **组织门派**: 百韬略城上司：鬼谷藏龙同伙：劫随、列鸿缺、玉权臣

## 角色经历

虽然身死人手，但不失为热血男儿。算是一位真正的剑客。造型设计虽然很龙套，但是一个令人记忆鲜明又不得不佩服的经典龙套人物。刑剑罪己是一个很强的高手。南风不竞仅仅与其交手数回即大呼过瘾，之前南风不竞面对火宅佛狱代行者莎莉罕与说服着寒烟翠的夹杀，还说打得没意思。刑剑罪己出场虽然短暂，但在片言片语及仅有的一战之中，可以看出他拥有正直自谦的性格以及直逼黯纪仲裁者的实力。拥有这样的资本却是一位龙套角色，不得不说实在可惜。

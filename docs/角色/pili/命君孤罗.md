# 命君孤罗

六蚀玄曜之一，神州北方寰界的创立者，性格幽暗莫测、姿态随兴优雅，游戏人间，曾创立万愿同归、点化魔能悉非等等......却似没有固定的目标与追求，其来历、背景等等，至今依旧成谜......

## 来自百度百科的补充

### 人物设定

诗号：一念天堂地狱，万古人欲，谱非命之命；一睨尘间世外，千秋爱憎，笑无明之明。

正式登场：霹雳玄蒙纪 第1章

退场：霹雳玄蒙纪 第25章（死于谈无欲）

### 人物能力

武学：半夕微尘变、一梦无所命、三幻不尽夜、七魂迷生道·破、九殃坠天华、十绝沦亡·汰、摧命掌、锋刈·瞬一斩、谱命终篇·无绝暗世

咒术：血引封思、凝暗化刃

武器：织命

命君孤罗手上的指爪套，五指皆有，为命君的手饰及武器，强韧无比，可防御任何刀剑威力，更可为爪，以优雅的举止来袭伤对手、玩弄猎物。

### 人际关系

同伙：太曦神照（神谕）、神荒子、太玄封羲、一渡微尘（谛祸）、祇首魈峣→十恶崇黓（六蚀玄曜）；元貘魄尊（噬梦元貘之魄体）

相关：游师无方、神子双竹、魔能悉非、落花朝、亭子玦

部属：映芙蓉、伽楼寻纮（后叛离）、北隍应、击空明（臣服）、宇文鸿心

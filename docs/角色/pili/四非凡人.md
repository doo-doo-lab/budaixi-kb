# 四非凡人
================================================================================

四非凡人

寂寞侯多年知交，自称四非凡人，乃因拥有智慧非凡、见识非凡、阅历非凡、刀艺非凡等四项特质。外型粗犷肃穆，性格潇洒风趣，喜戏谑、不拘小节，实际上是名心思缜密、武中带文的不凡智者。

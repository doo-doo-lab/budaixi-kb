# 四非凡人

寂寞侯多年知交，自称四非凡人，乃因拥有智慧非凡、见识非凡、阅历非凡、刀艺非凡等四项特质。外型粗犷肃穆，性格潇洒风趣，喜戏谑、不拘小节，实际上是名心思缜密、武中带文的不凡智者。

### 角色经历

四非凡人的出场是作为寂寞侯的至交好友，两人以旁观者的角度观看武林局势，四非凡人每次与寂寞侯见面，都会与寂寞侯下一盘“棋”，每次都以失败告终，却依然败而不馁。灵玉的风波，也是四非凡人与寂寞侯交情破损的开端，木姥姥的死讯，四非凡人欲寻六祸苍龙报仇，寂寞侯出言阻拦，两人再下棋争输赢，连下数天，四非凡人胜出，却不想仍被寂寞侯算计，知道寂寞侯要帮六祸苍龙，以建和平无武的天下，在半路拦截中咒术发狂的无名，告之欲寻“他”在哪，便去寻找寂寞侯，再拦找寻风飞沙的侄子三口剑，让其去赶寂寞侯离开冷峰残月，三口剑直言杀掉寂寞侯更省事，不想三口剑和无名两人竟相斗起来，寂寞侯毫发无损，后与一页书、莫召奴、紫宫太一等侠士围住进入冷峰残月的路，欲杀六祸苍龙，不想，计划最终还是失败。

皇朝建起，四非凡人与寂寞侯再无交情可言，四非凡人假扮素还真，救了因千年一击加上烛龙之箭重伤的一页书，不想还是被寂寞侯看破，素还真回归，四非凡人与素还真众人共抗六祸苍龙等人。在铡龑计划中，四非凡人与汲无踪、燕归人一同参与了对六祸苍龙的围攻，并在苍云山围困受伤的六祸苍龙。当地狱岛因问天谴与鬼伶仃离开而出现人事变动时，四非凡人对圣阎罗的安排感到震惊。接着仙灵地界、阿鼻地狱岛依次出现，四非凡人的真实身份也呼之欲出，作为阿鼻地狱岛的三岛主，风趣义气，却不想大哥圣阎罗野心暴露，四弟鬼伶仃戴罪而死，二哥问天谴受计遭金银封体，而自己，也在带素还真与汲无踪到地狱岛赴宴后遭金银封体。

在邓九五的计划下，与枫神官、汲无踪两人合诛圣阎罗，不想仍是失败，邓九五也惨死在圣阎罗手上，后问天谴伤愈回来，两人回到地狱岛，在琉璃仙境与梅神官遭到魔化叶小钗的追杀，梅神官不幸身亡，识界降临后，与屈世途为魔界人质，结识了补剑缺，三人成为了好友，弃天帝的出场，令正道人士死伤惨重，在与弃天帝对战时，身亡命绝。

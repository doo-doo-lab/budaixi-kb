# 赤鬼 (赤鬼)
================================================================================

赤鬼

鬼祭將軍麾下東瀛武士領導者，奉命前來中原索回金龍文詔，展開一場五對五決鬥。赤鬼刀法剛柔並濟、霸氣十足，在影中林之戰大敗舞造論；事後因身染透明之症，再度回轉中原求藥而來。

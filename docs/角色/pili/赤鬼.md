# 赤鬼
================================================================================

赤鬼

鬼祭将军麾下东瀛武士领导者，奉命前来中原索回金龙文诏，展开一场五对五决斗。赤鬼刀法刚柔并济、霸气十足，在影中林之战大败舞造论；事后因身染透明之症，再度回转中原求药而来。

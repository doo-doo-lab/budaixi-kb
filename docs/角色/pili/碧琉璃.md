# 碧琉璃

精灵天下七脉中的神脉之主，超尘脱俗，作风冷静，理性平和，乃当年精幽大战，反对参战而自封的三脉之一，在精灵天下扮演举足轻重的地位，是目前精灵七脉的领导者。后精灵天下频频发生命案，神晖主命玉寰灵捕碧雪妍追查凶手，更与一页书联手试图压制乱神峰龙首的邪恶之气。

### 人物经历

碧琉璃，精灵天下七脉之中·神脉的领导者，多年前曾与浩星探龙商谈过关于精灵族与人族的和平，也是在精幽大战之中，反对参战而选择自封于弃神谷内的三脉之一。碧琉璃和其他两脉之主，在自封多年中，查出地冥和恶魔种子的一些关窍，整顿精灵天下内部和平，使精灵天下内部再度恢复和平。

碧琉璃曾在狩宇族回归精灵天下时出手阻止地冥，帮助回归，后又和寄昙说联手修复精灵天下的防御结界。因八歧龙首风波，天邪八部众之一的蚩罗潜入精灵天下制造多起血案，碧琉璃和一页书联合压制龙首暴动后，又谋划假意怀疑步军殇，引出了真凶蚩罗，最后龙首虽仍是被蚩罗解封，但精灵天下也一度得到短暂的平静。

虽有七脉汇聚使精灵天下重获生机，但外界八歧风波逐渐升级，碧琉璃有感精灵天下危机将至，遂嘱咐碧雪妍加紧练习掌握神斗天宫。但无奈危机终至，八歧邪神攻入精灵天下，精灵死伤惨重，圣宇辰、碧琉璃和天织主等挺身而出但仍是不敌，为掩护众人撤离，碧琉璃和圣宇辰舍身断后，硬接邪神极招，终是重伤而亡。

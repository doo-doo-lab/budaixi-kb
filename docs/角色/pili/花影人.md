# 花影人（霹雳英雄战纪虚拟人物）

花影人，霹雳英雄战纪虚拟人物，集境太幻楼主。花影人有着深谋远虑的智慧与奇诡难防的手段，野心勃勃，一心想要做大为王，一统天下，故而与灯蝶修万年共谋，修建秘密基地，静待袭卷时机。花影人曾与百里泣约谈，一道气功击散花信风身上的金沙，知道图卷非真本后恼火灯蝶算计，吩咐竹虚设法得到真正蓝图。在《霹雳英雄战纪之蝶龙之乱 下阕》中，花影人与天蝶盟等邪恶势力一同侵略中原。

## 经历
花影人与灯蝶修万年共谋，修建秘密基地，静待袭卷时机。灯蝶回到集境后，花影人在集境太幻楼接见了他，识破灯蝶上交的图卷并非真本，恼怒其竟敢算计自己，并立即吩咐下属竹虚设法获取灯蝶身上的真正蓝图。后与百里泣、花信风发生冲突，花影人一道气功便击散了凝结在花信风身上的金沙，导致花信风恢复原状，百里泣见状服输，当场举掌自戕，化为万点金星落地。

## 人际关系

# 弃天帝（霹雳布袋戏虚拟人物）

霹雳史上最强大的魔王，莫过于异度魔界的创始者弃天帝了。

有别以往的魔王，常常在第一次大发神威打败某英雄人物，或歼灭某组织后便休战一阵子。

弃天帝由于行动是要毁灭整个神州，迫使整个中原正道都要阻止这种毁灭的行动，因此可以看见弃天帝从出场到结束，几乎场场置身大战之中，而挑战的对象更是一波强过一波，但弃天帝所展现出来的神级强度，让弃天帝在对决台面上所有的重要角色后，仍旧立于不败之地。

从识界之主玄貘，异度魔界战神银锽朱武，玄宗六弦之首苍，灭境至邪孽角，儒道释三先天，武林第一人一页书，剑界神话风之痕，东瀛剑圣柳生剑影，大有来头的敌手全部都与弃天帝交锋过，而且全数败落。

而为了营造神州毁灭的绝望感，更使得许多英雄人物都葬身在与弃天帝的对战当中，中原正道可说是伤亡惨重。

除此之外，所有与弃天帝对战过的对手，全数非死即伤，无人可以全身而退，这可是项前无古人，后应该也无来者的空前纪录。

叶小钗于激战中，虽即刻判断要断指弃戒，但魔戒却自我保护，让叶小钗无法断指，叶小钗即刻反应，收元化主攻，刀剑同出，也几乎逼近弃天帝心口一寸之处，可惜最后仍功败垂成。

剑奇阵失败，同时也使中原正道损失惨重，月漩涡、紫宫太一殉难，羽人非獍重创、叶小钗落海，更杀害圣兽逆龙，破坏第三根神州支柱。

弃天帝此举动打破了死国空间，使死神传人天狼星和阎王锁来到人间，开启死国乱世序幕。

万里狂沙双天会弃天帝中原正道借由苦行者的遍照寰宇之眼找到神州支柱所在地磐隐神宫位置，同时弃天帝也已从赭杉军尸体取得记忆，故而降临万里狂沙，遭遇妖溺天所控制邪灵欲搬走神柱地层，踏回地层击退妖溺天并轰杀成千上万邪灵。

接受一页书的约战，后弃天帝前往万里狂沙，与当世第一人一页书、剑界神话魔流剑·风之痕一战，此战中风之痕以“剑随风行”之招刺破弃天帝周身护罩，一页书以“破甲尖峰七旋指”伤弃天帝，使弃天帝初次呕红，一页书与风之痕之间的默契配合让弃天帝首度感慨，之后弃天帝虽力挫强敌，但风之痕的“魔流剑风之痕”也使弃天帝腹部大量出血，后一页书为护风之痕安危，使出自绝修为的近神之招“八部龙神火”，宛若八方龙神降临人间之势，梵天圣焰终焚弃天魔障。

弃天帝无人可破的传说，终在佛魔联手中破灭，此战为日后的中原正道开启致胜之机。

磐隐神宫外之战弃天帝在磐隐神宫外，弃天帝受到已经领悟道之极意的东瀛剑圣柳生剑影阻拦。

剑之道，从未现世的败亡之剑，柳生剑影的剑之意志，散于天地之间，化万物天地，纳神鬼妖邪，度宇宙苍穹。

万神劫最终式化剑圣之鲜血遍洒万千利剑，更化为剑圣的道之真意——守护神宫。

虽然柳生剑影只成功击中弃天帝肩部和头部，但弃天帝仍因叹服柳生剑影坚定的证道之心，而停留于磐隐神宫外一日，一日后，弃天帝轻松突破柳生剑影以万神劫及自身之血所成的守护剑阵，进入磐隐神宫。

灵识回归六天之界弃天帝磐隐神宫内，最后的防守阵线，六弦之首苍、魔界战神银锽朱武，曾经的大战死敌，现今的生死战友，为让三先天借神柱圣气，驱逐五浊恶气，共修天极圣光，并汇合灭天之招。

苍启动独门秘式，借神宫地势封锁弃天帝，顿成零的世界，无的空间！

银锽朱武更是会合三魂双体，超越自身极限，誓要重创弃天帝。

弃天帝虽然吸收了以强制破坏三魂两体增进功力的银锽朱武，藉以恢复完整的圣魔元胎，但不知是计，在与三教先天一战时，先遭三先天在磐隐神宫习得的太阳神留下来对付他的神之招“天极圣光”净化，后苍以术法助银锽朱武脱离弃天帝身体，并使其分神之际受三先天突袭被圣器佛牒毁去肉身。

弃天帝因肉身被灭，弃天帝灵识不得已回归六天之界，但于临行前，重击最后的神州支柱，使得剑子仙迹与佛剑分说为护神州支柱而受困于磐隐神宫。

最终，为阻弃天帝再临，银锽朱武自愿死于苍的手中。

最后的圣魔元胎死去，弃天帝从而再也无法降临人间。

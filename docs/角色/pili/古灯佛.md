# 古灯佛

鹿苑一乘灯院，负责处理联外事务，佛教以灯象征智慧，佛子传灯解众生苦难。古灯佛心性慈悲，深明大义，与魑离船大首正邪联手，共同消灭死神太学主，结果全军覆没，古灯佛不幸身染魔气，牺牲捐躯。

## 来自百度百科的补充

古灯佛，霹雳布袋戏虚拟角色，中文名，别名七世传承，由黄文择配音，男性角色，登场于《霹雳天启》。其身份为鹿苑一乘灯院掌灯，驻扎海潮钟楼，负责联外事务，共出场13集。古灯佛心性慈悲，曾为凤凰鸣、玄藏不思议解答尸毒与佛顶冥塔劫案，并借甘露盲佛之眼寻回圣物。后为消灭死神四关，将佛顶冥塔出借央森，却遭太学主夺走。最终联合魑离船正邪率众攻入学海无涯，因错估太学主实力致全军覆没。古灯佛被六铢衣所救后，因身染末日神话魔气，自愿死于破匣求禅，以此捐躯。

## 人物经历

古灯佛古灯佛，驻扎在海潮钟楼的鹿苑一乘掌灯，生性慈悲、深明大义。在凤凰鸣和玄藏不思议先后前来问询关于尸毒和佛顶冥塔劫镖案的情况时，古灯佛不吝言辞地慷慨解答。为寻回圣物佛顶冥塔，古灯佛借甘露盲佛的遍照寰宇之眼探得下落，并让五蕴法刚前往迎回。为消灭死神四关拯救苍生，古灯佛出借佛顶冥塔给央森和黄泉引者交易，让素还真得以消灭四关，熟料冥塔最后被太学主夺走。为对抗死神，古灯佛率鹿苑人马，和魑离船正邪联手，与暗影魑首等黄泉引者联手攻入学海无涯，却错估太学主实力而全军覆没。古灯佛虽被六铢衣所救，但不幸被太学主的末日神话所伤，身染魔气，自愿死于破匣求禅，为正义捐躯。

## 人物配乐

古灯佛（七世传承古灯佛）作曲/编曲：风采轮 收录于《霹雳珍乐典藏原声带 · 精选43》风采轮老师2008年作品，典型的佛教曲风，以钟磬声营造浓浓的禅意，沉缓柔和的旋律让人心平气静，仿如进入物我两忘的禅修境界。佛子传灯，七世光明，广照迷途众生。乐曲选用于鹿苑一乘灯院「古灯佛」一角，初用于霹雳天启第二十集，凤凰鸣及玄藏造访海潮钟楼，传灯院七世传承古灯佛现声一会，协助解尸毒之法以及告知过往鹿苑圣物被劫一案。

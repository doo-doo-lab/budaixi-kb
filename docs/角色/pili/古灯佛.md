# 古燈佛 (古灯佛)
================================================================================

古燈佛

鹿苑一乘燈院，負責處理聯外事務，佛教以燈象徵智慧，佛子傳燈解眾生苦難。古燈佛心性慈悲，深明大義，與魑離船大首正邪聯手，共同消滅死神太學主，結果全軍覆沒，古燈佛不幸身染魔氣，犧牲捐軀。

# 一枝花
================================================================================

一枝花

珠婆婆高足，面戴眼罩、身背剑袋，嘴咬一朵玫瑰花，给人滑稽却又熟悉的感觉，师徒俩互动逗趣十足。蓝侠虽是怪模怪样，却意外获得钢翼飞猿青睐，一见钟情、热烈追求。

# 宇宙神知

一页书自天河复生时元婴离体，在肉身气绝黄甫桥后，元婴则化为宇宙神知，利用梦境渡化业途灵为徒，以罗妖罩困住鬼王棺，预留锦囊暗示三教之子身份和未来局势，却因神力衰退，遭魔域囚禁血池肉林，元灵后为幽灵马车救出，于天河再蕴生机。

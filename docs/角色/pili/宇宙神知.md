# 宇宙神知

一页书自天河复生时元婴离体，在肉身气绝黄甫桥后，元婴则化为宇宙神知，利用梦境渡化业途灵为徒，以罗妖罩困住鬼王棺，预留锦囊暗示三教之子身份和未来局势，却因神力衰退，遭魔域囚禁血池肉林，元灵后为幽灵马车救出，于天河再蕴生机。

## 来自百度百科的补充

宇宙神知原为一页书元婴离体所化。神力衰退后，曾被魔域囚禁于血池肉林，后由素还真与叶小钗等人闯魔域救出。期间，魔域之主七重冥王曾计划用"泣魂珠"来释放其神力。

敌对：七重冥王（曾想用'泣魂珠'释放宇宙神知的神力）

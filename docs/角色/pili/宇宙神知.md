# 宇宙神知 (宇宙神知)
================================================================================

宇宙神知

一頁書自天河復生時元嬰離體，在肉身氣絕黃甫橋後，元嬰則化為宇宙神知，利用夢境渡化業途靈為徒，以羅妖罩困住鬼王棺，預留錦囊暗示三教之子身份和未來局勢，卻因神力衰退，遭魔域囚禁血池肉林，元靈後為幽靈馬車救出，於天河再蘊生機。

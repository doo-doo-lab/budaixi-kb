# 万魔天指

霹雳布袋戏虚拟人物万魔天指是霹雳布袋戏中的反派角色，灭境邪灵首领，由黄文择配音，初登场于《霹雳紫脉线》第13集，退场于《霹雳天命》第1集。

其精血可化育所有邪灵胚胎，掌握《无上魔法》并发明离魂迷图，统领十三邪灵与三途判，长期潜伏于囹圄池操控灭境局势，暗中施计陷害一页书。

万魔天指曾改造素续缘为邪灵化身，联合魔域鬼帝、集境武皇结成三境邪派联盟，多次侵扰灭境与苦境。

在灭境三天与圣翁慈航渡等正道势力围剿下，其势力遭重创并诈死退隐，后复出再掀动乱。

最终因同盟瓦解，被素续缘与鬼王棺联手袭杀，真气被吸尽而亡。

该角色以日本即身佛为原型设计，具备依靠精血复活的特殊能力。

战斗中未使用招式名称的设定使其区别于其他布袋戏角色。

## 人物形象

原始设定万魔天指初登场，日本真言宗的“即身佛”。

为无上魔法的发明者，传说中灭境所有邪灵的源头，其精血为化育所有邪灵的胚胎。

只要一滴精血存在便能不断复活。

十三邪灵为万魔天指麾下大军，持有护元珠(本命元神)、摄业戒集(人口图册)，邪灵护元珠回归摄业戒集后，可以不断再生。

三途判为万魔天指重要干部，持有精血，能够创作出圣羊(犄角族)、妖龙(爬族)等魔物，以邪灵共体为再生手段，三人中只要一人肉体尚存，其他二人便可移转元神于一人之身，他日便得重塑肉身。

脱胎换骨原本形象为一日本“即身佛”(即日本真言宗高僧临死前绝食，留下木乃伊以作护法金身，现已立法禁止此宗教行为。

中国大陆与台湾地区早年亦有此现象。)其被击破虚壳后(其实是使用“金蝉脱壳”，借外力脱胎换骨)，方转为英俊容貌，功体亦大增，但是却也再无战斗场面。

零招魔王虽说“无上魔法”由其发明，在剧中亦有多场战斗场面，但是却没有喊出任何招式名称，在布袋戏中是非常反常的现象。

至死都没有喊出招式名····因此本条目招式只有2招。

## 经历

万魔天指灭境混沌，群邪乱世，万魔天指率领众邪灵，与三途判联手将灭境弄得生灵涂炭，在最后灭境三天（梵天、辅天、众天）出手，三界者（辅天、地冥至尊、宿斗老人）对上三途判，圣翁·慈航渡、大圆觉、教世音与诸儒圣对上十三邪灵，而由英雄赛迁身穿宝衣-圣云战甲，手握神兵-潜龙神戟，对上邪灵之首万魔天指，而由其他灭境英雄负责牵制十三邪灵，方将邪灵击败，万魔天指诈死退居囹圄池，复出之后染指苦境，并与集境武皇、魔域鬼帝结成同盟，共同对付一页书等中原正道。鬼帝丧命后，为素续缘、鬼王棺联手偷袭，被素续缘吸干精气而死。

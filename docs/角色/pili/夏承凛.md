# 夏承凛

霹雳布袋戏虚拟人物夏承凛，霹雳布袋戏虚拟人物。南方文风谷掌门，在玉离经邪染加重后，请其暂代主持大局，重建德风古道，成为儒门领导者。其性清冷肃气，不怒自威，有着一门之主的威严气势。对待同袍、盟友温和谦让，但面对邪魔，则会显现出更多的仇视以及不屑，而少有怜悯。诗号：七弦抚尽，何处觅知音，但向朗月空林。翰墨残迹，谁得千秋理，且听松涛竹意。

## 角色形象

德风古道为儒教重要门派，体系下尚有四方支部据点，分别为“仁宇明圣”、“一笔春秋”、“文风谷”、“奕德熙天”。

夏承凛为文风谷掌门，有别于其他支部之主，夏承凛最晚登场。

在当初儒门尊祖方御衡十甲子忌日之大典，仁宇明圣掌门敬天怀邀请各支部前来参加，此时各部主要人员齐聚一堂，唯独夏承凛因闭关未到，由副掌门莫凭箫代表出席。

而经历八歧邪神动乱后，三教尚待重整秩序，此时夏掌门出关，带领经历战火的德风古道，整合力量，让儒门重新出发。 夏承凛夏承凛个性与其他儒门中成员有所不同，夏承凛之性格严正而不若敬天怀之淡然，圆润而不若玉离经之灵巧，自信而不若慕灵风之率性，言行中多了一分孤傲，相对而言亦有强势风格；

他对待同袍、盟友温和谦让，但面对邪魔，则会显出更多的仇视以及不屑，而少有怜悯。

## 人物关系

主要人际关系主要人际关系人际关系千载明道·玉离经：德风古道主事，统领儒门，包含夏承凛，但因邪染之害，玉离经将德风古道领导之职交予夏承凛。

当初邪染即将夺命之时，夏承凛以过人的能力及时救出玉离经、敬天怀，证明智能双全，堪当大任。

而玉离经退居二线，复兴德风古道，阻止异魔者，与儒门一众继续为武林贡献。

玉儒无瑕：镇守德风古道昊正五道第一关，后来因故离开德风古道，退隐山林，第一关后续才由法儒无私接任。

多年后，与夏承凛一同回到德风古道。

夏承凛接任主事，玉儒尊驾则有前辈地位，外表儒雅贵气，但言词直接、不留情面。

不料玉儒其实早已逝世多年，邪化的穷霄辟冥剑占据玉儒身躯，暗中行使阴谋。

## 角色经历
夏承凛登场之时，玉离经、敬天怀正身受邪染之害，因而暂代儒门领导之位，事出突然，也让云忘归、慕灵风等人感到疑惑。

经过一连串的抽丝剥茧与探查，才发现玉儒无瑕乃是过程中的阴谋者，也经此风波，使得儒门进入真正的团结一统。

霹雳会会刊第238期第4~5页·而面对道门天道主来势汹汹，强势整并的态度，夏承凛挺身而出毫无惧色，过程中面对各方挑衅也不让分毫。

无论是面对异魔者或者道门征战，夏承凛总能凭藉不凡实力化险为夷、扭转局势，个性沉稳，却态度积极，令人难以测试其心思，散发出一种高深莫测的气质，也使得周围的人与他有着距离。

尤其蓝衣蒙面人疑云未解，也使得夏承凛始终脱不了嫌疑。

在攻略妖异魔城的行动中，夏承凛展现超强武学及机智，自恃习得三教极招的六弑荒魔，却不知已经落入了夏承凛的圈套。

六弑荒魔使出夏承凛绝招元圣天锋，却不知此招包含陷阱，进而露出死穴，夏承凛击败六弑荒魔，更以不凡修为破解魔城，让原本势在必得的天道主顿时无功而返。

夏承凛正当虚无出现，混沌之扉即将开启，夏承凛配合武林群侠，全力封印虚无，虽然过程中同袍不幸牺牲，但夏承凛却因此更加坚决，势必歼灭异魔者，也带领着德风古道，全力应战。

行事作风逐渐强硬的夏承凛行事偏离正道，受到众人质疑。

真相竟是夏承凛闭关期间，先祖夏戡玄传下的配剑灵霄烛幽之剑魂侵占夏承凛身体，与玉儒无瑕、问奈何等人合谋，只为实现夏戡玄夙愿。

# 半尺劍 (半尺剑)
================================================================================

半尺劍（霹靂英雄戰紀）

與百世經綸一頁書齊名的高人，武學修為已入無人之境，乃太黃君口中的恩人，結草銜環更是半尺劍對太黃君的恩義代表。能以意識論武，以氣行招，乃凡人無法觸及的高度。在太黃君遭万俟焉大敗後，太黃君找上半尺劍主持公道，要讓素還真、風采鈴付出代價。

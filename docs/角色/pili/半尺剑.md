# 半尺剑

半尺剑（霹雳英雄战纪）

与百世经纶一页书齐名的高人，武学修为已入无人之境，乃太黄君口中的恩人，结草衔环更是半尺剑对太黄君的恩义代表。能以意识论武，以气行招，乃凡人无法触及的高度。在太黄君遭万俟焉大败后，太黄君找上半尺剑主持公道，要让素还真、风采铃付出代价。

## 来自百度百科的补充

半尺剑是《霹雳英雄战纪》系列剧集中的虚拟角色，别称"寰宇武典"，由王希华、刘琮配音，初登场于《霹雳英雄战纪之刀说异数》第18章，居于九层莲峰。在《霹雳英雄战纪之蝶龙之乱》中继续出场，与百世经纶一页书齐名，武学修为臻至化境，能以意识论武、以气行招，曾通过"结草衔环"施恩太黄君。

半尺剑在老剧中原为集境武皇的化身，花影人及灯蝶修万年曾假扮其身份，新剧设定中改为花影人，助太黄君摆脱大宇神宫追杀。在太黄君被万俟焉击败后，半尺剑介入纠纷意图追责素还真与风采铃，并在千石林之战中与一页书关注战局，暗中计划处置太黄君。

其使用圆阳指杀害狄萧引发素还真寻仇，更借秦假仙传递信息引一页书赴约。半尺剑与一页书保持亦敌亦友关系，专属配乐《寰宇武典》收录于《霹雳英雄战纪之刀说异数》原声带。角色布局深远。

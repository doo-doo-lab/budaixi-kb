# 殢无伤

================================================================================

霹雳布袋戏虚拟人物殢无伤，霹雳布袋戏虚拟人物。慈光之塔的孤寂剑者，沧桑冷漠，独居在远无人烟的寂井浮廊，唯与无衣师尹熟识，因此前来苦境。其人性疏质冷，似是凡事漠然，对特定事物却异常偏执，执著于一场虚幻的雪中谜、以及一口渗血的墨剑铁涎。

## 人物设定

殢无伤会刊海报名称：殢无伤称号：永岁飘零其他称号：剑下奴（妖应封光称）、殢大侠（麻我道称）诗号：囚心梦牢侧泉听，回闻涓涓忒流惨。

百年窅冥乎一息，永岁秋风飘零见。

身份：慈光之塔的孤寂剑者、五剑之“太易之剑”初登场：霹雳震寰宇之兵甲龙痕 第21集（以回忆形式出现一个画面）正式登场：霹雳经武纪之枭皇论战 第18集（于寂井浮廊中正式登场）退隐：霹雳战元史之动机风云第20集（中玄玄血傀师的奸计，误向天之佛寻仇，因功体不全 旧伤复发而被天之佛断去一臂，后被多天涯、缉天涯救走，醒后留信离开）根据地：寂井浮廊、深北雪岭·浮廊巘、雪漪谷·雪漪浮廊所有物：沸雪石 、长命锁、香斗（师尹的遗物）、寄心铃（妖应留给无伤的最后一句话）

## 人物能力

武学：终末之境、无咎剑法·一剑无咎◎介绍：殢无伤起招运式，式式皆带天地悲怆终末之气，未及出招，便先夺人之生存意志，是为“终末之境”。武器：墨剑铁涎墨剑铁涎◎乃由慈光之塔最劣质的矿铁，以十年光阴和殢无伤之血养其剑元而成，故玄黑剑身中仍有血红部分，护手中央可有红色三戟之图，恰巧与剑架造型相符。其诞出的铁涎便是无咎剑招的解方。吸纳太易玄气后，成为天佛原乡为圣魔之战点中的应未来之器：先天五剑之太易之剑。最后血傀师为终止佛厉大战而巧施诡计，墨剑连同其他四剑被抽出先天之气铸成神兵春秋阙（后被意琦行所得），墨剑从此退场。

## 人物设计

过往殢无伤·封面人物  月刊第192期慈光之塔的孤寂剑者，乃是慈光之塔擅剑一族后裔，其族天生遗传有怪病，活不过二九之岁，还会传染给别人，因此整个家族被放逐于渎生暗地。

殢无伤在一次因缘之下，从渎生暗地里看见了师尹之妹即鹿。

就此倾心。

而即鹿未遇到雅狄王之前，也总是会在竹花开时，来到渎生暗地的外围，陪殢无伤聊天，她将殢无伤视之为弟，对他推心置腹。

怎料际遇弄人，当殢无伤出了渎生暗地时，竟只见到即鹿尸体焚烧的那一幕，就此，他沉溺在自己筑起的雪中世界，独居在远避人烟的寂井浮廊，唯与无衣师尹熟识，并随之来苦境。

因无衣师尹对他有再造之恩，因此甘心为他所用，但又因即鹿之故，而对师尹有所敌意……曾被无衣师尹诱导出战围攻雅狄王（并未出手，只是威慑，所以火宅佛狱对其不甚注意。

详情见会刊192期），随后殢无伤因为即鹿死因（亦为无衣师尹的诱骗）一怒而杀剑之初的身边友人，进而逼剑之初离开了慈光之塔。

后遇化成人形的妖应封光，并被其所纠缠，最终与之结为佳偶。

其剑招奇异非凡，剑之初言“其剑法之中揉杂异术，却又不是旁门左道”，剑起瞬间四周便会形成终末之境。

外相俊美，脸上有奇特的纹身。

善于观察人之双眼，其人性疏质冷，似是凡事漠然，对特定事物却异常偏执，执著于一场虚幻的雪中谜、以及一口渗血的墨剑铁涎。

起源殢无伤原本编剧会议中，这名角色只是因为剑之初需要一名仇人，仇人不能直接是无衣师尹，所以师尹暗中培养的杀手就此诞生。

他第一幕是出现在兵甲武经的回忆里，当时的他，名字很混乱，故事不明确，但因为偶长得漂亮，造型独树一帜，给人的印象已有加分，所以董事长要我在取名字时，特别的提示了一下，他觉得这个角色有点百年孤寂的味道。

于是，对殢无伤的故事发想，便从[百年孤寂]这个方向着手。

（《百年孤寂》是一本获得诺本尔文学奖的作品，不是忘千岁。）为了替换掉百年孤寂这个词，我不断去搜索脑内资料库，想要取出一个有百年孤寂的味道，但全然不用到这些字眼的词语，想了几天，只先定出[永岁飘零]，然后就是提出角色设定。

先前说了，董事长要的感觉是“百年孤寂”，于是我破天荒的买了一本诺贝尔文学名著《百年孤寂》回家拜读，不是唬人的，我还真是以一种膜拜的心情，撕开了书本的第一页，那当下，我真的有感受到文学光环罩在我头顶，然后，接续在翻了几页、几页.....嗯，我的文学细胞已经滋养够了，不用再看了，于是把书垫在我的枕头下方，就这样沉沉睡去，感觉好像一醒来，那本书就全都在我脑子里了这样，总之的总之，我为殢无伤做的背景设定，仿造了百年孤寂的一些元素，那些恋母情结、被囚禁、家族疾病的等等氛围.....而恋母情结这一项被大家打得很惨，以至于通篇很有文艺气息的设定，就这样被炮轰个不停。

总之就是拿掉恋母情结这一项就是了，然后，一名慈光之塔剑术名家之后的殢无伤，就这样确定下来。

为了要与剑之初年及弱冠便扬名四魌界的设定有个区别，我将殢无伤设定为一名籍籍无名的顶尖剑客，慈光之塔中，无人知晓他的存在，他的剑上才能被无衣师尹刻意隐藏起来，除了师尹，只有辉煌堕世知晓慈光之塔还有这名剑客的存在，而围攻雅狄王那一次，他只是旁观没有出手，所以火宅佛狱亦对他不甚注意。

师尹在得知将逃亡到苦境，便要求殢无伤同行，此两人之关系，看似交好，又有几分不能抹消的冲突。

注：殢字有沉溺、执迷之意。

永岁飘零殢无伤，则是不断的重选这种感觉。--------------------摘自会刊192期（原文）

## 人际关系

人际介绍妻子：妖应封光岳父：齐子然岳母：明霜雪挚友：无衣师尹朋友：素还真、忌霞殇、刀悬一命（在修补墨剑时论剑论艺结交）恋情：即鹿（单恋）、缉天涯（对其有好感）、多天涯（单恋他）其他：剑之初、戢武王、殊十二、槐破梦、楼至韦驮、薄棠、鹤舟先生、麻常道、麻乐道、麻我道、号天穷、端月留生、撒手慈悲、雅狄王、月藏锋、任云踪、击珊瑚、魑岳、剡冥、驺山棋一、孤竹隐龙、鬼觉神知、十两金、阇魇那迦所发便当：一羽赐命、易子娘、砗磲佛母、豫长生（自愿）、深流君主要人际殢无伤主要人际关系妖应封光殢无伤之妻受天宫八月泉希音之琴而自万劫中苏醒，本为上古圣魔大战遗下的太易玄气所蕴出之灵，被风光意外无意间摘得了太易之气所化的红花，自此太易之花吸附着风光的血气为养，后被其母明霜雪移出入土，所化异铁被风光父母铸成名器瑶映，后因为种种意外最终占风光躯体为用，成为妖应封光。

吴侬软语，娇容妖冶无双，但性格极端，因天佛原乡使者十两金刻意之为，欲使瑶映剑灵身上的太易玄气与殢无伤的墨剑并合，是故化成人形的妖应封光与殢无伤多所纠缠，最终结为佳偶。

妖应封光无衣师尹殢无伤亦师亦友慈光之塔主事者，外貌清俊显贵的文雅之士，心思缜密、口才便捷，喜藉焚香取道，涤尽浊世秽气。

曾与火宅佛狱联手擒禁雅狄王，在素还真因灭度三宗漂流异境时出手搭救，并安排星骋助其返抵苦境。

冷眼旁观四魌界局势演变，算记防止任何一方势力坐大威胁。

御下有道，对自己培养的人才十分了解。

心机深沉，手段圆滑，在各方势力之间游刃有余。

无衣师尹即鹿殢无伤初恋对象、无衣师尹之妹即鹿自小体弱，后钟情雅狄王，并生下一子，一时间使无衣师尹在慈光之塔备受质疑。

后来无衣师尹为诱导殢无伤出战围攻雅狄王，以雪中谜作为牵绊，同时告诉殢无伤，即鹿是被剑之初身边友人所逼迫，导致她不堪指责，抑郁而亡。

殢无伤得知此事，愤怒参与无衣师尹袭击雅狄王的计划。

导致雅狄王中计被擒。

随后殢无伤因为即鹿死因（伪）一怒而杀剑之初的身边友人，进而逼剑之初离开了慈光之塔。

实际上即鹿是因为无衣师尹，为使剑之初出战雅狄王，被无衣师尹牺牲而死。

后无衣师尹在交给殢无伤的遗书中，对他亦言明了即鹿真正的死因。

即鹿多天涯神花郡主多天涯女扮男装，以平阳人士重夕公子身份出席七殊园，参与云昙花祭大典，因而初见永岁飘零殢无伤，为其高超的剑艺英姿所吸引，心生爱慕，引发后续一连串的纠缠和事端。

多天涯缉天涯中阴界胡同蜃市鬼掌，处事机敏有度，个性略偏冷傲。

因鬼师缉氏祖规，年过二十必婚配以人，故缉天涯届龄二十后，便设以红銮绣球招亲。

但其父鄙其先祖陋习，不愿女儿受成规束缚，便假外人道，蜃市之主丑陋无比，其性凶恶如夜叉，故缉天涯招亲历年有余，无人敢接绣球以结好。

殢无伤为取风光身上一点太易元灵而前往蜃市交易，无意间接到蜃市招亲绣球，而与缉天涯产生一段纠缠。

为了殢无伤放弃鬼掌之位，利用月藏锋与孤城不危交战之时，通过星河天瀑，由中阴界前往苦境，在欲明王与山之厉魑岳为太易之剑交战时救走殢无伤并解除其毒患。

於神花郡阻止月藏锋与殢无伤之战而正式现身，并在其后结识神花郡郡主多天涯，两人多次打斗嬉闹后渐生情谊。

大定止后，告知殢无伤前来苦境的真正目的，乃为传达一赤魂之最后心音，并将储存该魂心音之寄心铃交给殢无伤。

后又正逢中阴界政局动荡，是以趁势卸去鬼掌之位，来到苦境，欲成全苦境游魂最后的心愿。

缉天涯忌霞殇逸踪大师兄，击楫中流得意高足，身倚卧龙车，左擎轩辕灯，右挂并峰双器，手持御风扇，一袭白袷雪衣，足踏凌波金靴，应霞而出。

个性温文敦厚，智慧豁达而谦冲，甫登场便化解登道岸与逸踪之冲突。

因过往一段战事而负伤不良于行，由高手孤竹隐龙推车而出。

后与殢无伤结识，并由其用墨剑除去心口异物，治愈伤体。

忌霞殇

## 人物配乐
剑者传说（殢无伤角色曲）曲/编曲：黄建秦收录于《霹雳经武纪之枭皇论战剧集原声带》此曲本是黄建秦老师以“守护者”为题材创作的一首优秀乐曲。

在董事长听过之后，决定殢无伤的文戏、武戏皆用同一首乐曲。

而本曲也与殢无伤的文艺风格十分符合。

侠情无悔（殢无伤与无衣师尹）殢无伤刀剑春秋海报曲/编曲：浩旭 收录于《霹雳英雄音乐精选三十四》浩旭老师06年的作品，和缓含蓄的一首侠士抒情曲风，旋律编排犹如诉说故事般，将剧中人的淡然情绪缓缓铺陈。

乐曲使用于“无衣师尹”与“殢无伤”两人前赴魋山时之心念情境，看似淡如水的交情，但不知不觉早已深植两人心中，如涓涓细水般，静静地、淡淡地深远流长。

飘零的雪花（殢无伤和妖应封光）曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十七》丁天牧老师创作，以“归尘”为发想题材，钟磬声声轻响，带来了几许伤感，随著曲调的进行转换，沉重的心情，慢慢转化为随风飞逝的豁然意境……勾勒出妖应封光与殢无伤这对江湖儿女。

执狂的墨剑（殢无伤入狂）曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十七》管弦乐结合高昂的唢呐吹奏，呈现出一股阳刚威武的气焰，伴著阵阵鼓击的催动，情绪也随之沸腾起来。

因为殢无伤个性转为趋狂，故也搭配刚猛狂傲的音乐，突显因痛失爱妻的内心转变。

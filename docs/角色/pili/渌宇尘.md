# 淥宇塵 (渌宇尘)
================================================================================

淥宇塵

為妖漫地獄裡當代第一的製儗師，世代傳承製儗術。製作各種功能儗人，從最早龍族統治時期，就一直是權貴世家，直到人族妲眸姬推翻爬族，淥宇塵靠著製儗術，仍穩居妖漫地獄第一世家。世居於修途夜院。性格陰晴不定，但十分的疼愛女兒，是妖漫地獄中非常有影響力的一號人物。

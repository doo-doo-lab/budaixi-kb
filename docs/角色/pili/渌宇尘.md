# 渌宇尘

为妖漫地狱里当代第一的制儗师，世代传承制儗术。制作各种功能儗人，从最早龙族统治时期，就一直是权贵世家，直到人族妲眸姬推翻爬族，渌宇尘靠着制儗术，仍稳居妖漫地狱第一世家。世居于修途夜院。性格阴晴不定，但十分的疼爱女儿，是妖漫地狱中非常有影响力的一号人物。

# 雲中獸 (云中兽)
================================================================================

雲中獸

魔吞十二宮的雲獸宮代表，於逆三教大軍進犯不動城之時首度現身，一會逆三教之首神機。九天雲變、曙光驚現，在祥雲翻湧之間雲中獸僅僅一掌，便讓神機知難而退。世亂雲變、乾坤失序，不動城豈容邪孽造次？雲中獸身為十二宮的重要支柱，必將撐起屬於不動城黑暗的希望。

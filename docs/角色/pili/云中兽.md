# 云中兽 (云中兽)
================================================================================

云中兽

魔吞十二宫的云兽宫代表，于逆三教大军进犯不动城之时首度现身，一会逆三教之首神机。九天云变、曙光惊现，在祥云翻涌之间云中兽仅仅一掌，便让神机知难而退。世乱云变、乾坤失序，不动城岂容邪孽造次？云中兽身为十二宫的重要支柱，必将撑起属于不动城黑暗的希望。

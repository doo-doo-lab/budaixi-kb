# 楚遗
================================================================================

楚遗

弓弧名家副席，理性斯文、性格严谨，做事条理分明，负责打点弓弧名家的大小事，虽然性格中有傲气，但隐而不显，不会轻易摆架子宛如大伙儿的兄长一般，十分可靠。在玄真君专注处理幽都灾劫与玄凌苍冤案一事时，替主席料理弓弧名家大小事务，让玄真君无后顾之忧。

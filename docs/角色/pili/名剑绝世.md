# 名劍絕世 (名剑绝世)

名劍絕世

白羽忘云僧嫡傳弟子，懷具惻隱俠心，能獨自施展天佛七元相的佛門奇才。劍法絕倫，與皇劍孤臣論劍而交，乃北峰名劍之佼佼者。在天跡與君奉天闖白羽境天道時，現身第三關修羅血海十八重，考驗兩人。

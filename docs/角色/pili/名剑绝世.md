# 名剑绝世
================================================================================

名剑绝世

白羽忘云僧嫡传弟子，怀具恻隐侠心，能独自施展天佛七元相的佛门奇才。剑法绝伦，与皇剑孤臣论剑而交，乃北峰名剑之佼佼者。在天迹与君奉天闯白羽境天道时，现身第三关修罗血海十八重，考验两人。

# 名剑绝世

白羽忘云僧嫡传弟子，怀具恻隐侠心，能独自施展天佛七元相的佛门奇才。剑法绝伦，与皇剑孤臣论剑而交，乃北峰名剑之佼佼者。在天迹与君奉天闯白羽境天道时，现身第三关修罗血海十八重，考验两人。

**人物经历**

鹰族圣女遗腹子，被灵云寺大主持收养，但奇怪的是，大主持一直不让其剃度，让其始终是门外弟子，这使得名剑绝世非常自卑。后名剑绝世练成天佛七元相，成为北境三锋之一，随师父一起守护白羽净天道。当奉天逍遥来到白羽净天道时，名剑绝世凡心蠢动，欲入世行侠。后大主持丧命摩诃孽之手，佛狂、佛圣搅乱佛界，名剑绝世历经磨难后顿悟，成就剑神之姿。最后因皇剑孤辰死亡，自杀殉情。后被死神救活，一番波折后，名剑、皇剑二人一起参与阻止创世神无和缔魔剑之灾，最后携手退隐。

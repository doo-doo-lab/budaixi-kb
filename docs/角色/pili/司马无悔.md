# 司马无悔

当代拳宗第一人，拳劲无双、强悍勇猛，其人杰傲不驯，鹤立鸡群，因认同六祸苍龙天下止武、万世清平之理念，自愿加入紫耀天朝，扫荡不愿归降之派门，好成就祸皇百代霸业。

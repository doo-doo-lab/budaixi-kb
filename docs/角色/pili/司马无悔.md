# 司馬無悔 (司马无悔)
================================================================================

司馬無悔

當代拳宗第一人，拳勁無雙、強悍勇猛，其人傑傲不馴，鶴立雞群，因認同六禍蒼龍天下止武、萬世清平之理念，自願加入紫耀天朝，掃蕩不願歸降之派門，好成就禍皇百代霸業。

# 无界尊皇

霹雳布袋戏虚拟人物无界尊皇，霹雳布袋戏虚拟人物。本是尊贵的死国五尊之首，与天者、地者源出一脉，却因爱上魔女鬼薄英而触怒天者，被天者设计而败于死神之手，遭放逐于不毛矿坑，全身也产生异变，成为插满针刺、龇牙咧嘴的恐怖面貌。

## 角色经历

无界尊皇，死国五尊最强者。

是天者在天族的亲手足，天者胞弟。

因为天者与地者的离开，不久之后，尊皇遭受庞大的压力与歧视，于是也决定离开天族，追寻天者前来死国，他跟天者的手足关系，其他四尊都不知情，而地者虽然知情，却装傻替天者苦心隐瞒，因为天者虽然希望尊皇领导死国，却不希望其他四尊投以异样的眼光，所以让尊皇与四尊一同平等出现，更让他与其他人一同竞争并管理五都，无界尊皇过人的实力与天赋，使他迅速成为五尊中的皇者，赐号“尊皇”。

但在过程之中，尊皇却爱上了魔女之首鬼薄英，而其他五名魔女也已因此而骄傲起来，因为她们掌握了所有死国生命的粮食源头，后来死国种族开始倒向六魔女，便希望六魔女能成立新的国家，能与天者、地者、五尊平起平坐。

大业未成，天者不允许其他势力的暴动，于是暗中封印了六魔女，用黑暗之章将她们终生禁锢。

自此以后，尊皇与天者渐行渐远，尊皇对天者的厌恶已到达底限，也无法了解当初六魔女存在所带来的危机，天者也不愿多做解释。

尊皇愤恨退出五尊首座之位，天者该推鬼狱邪神成为五尊之首，后来阿修罗意外身亡，尊皇成为死国战士最强的代表，直到死神降临。

天者宣传无界尊皇是死国战神，引死国之神对付无界尊皇，死神也主动挑战尊皇，并将他打落不毛矿坑。

尊皇也将计就计，为了找寻魔女鬼薄英，让自己接受万针蚀骨之九酷血惩。

化为全身尖刺透体的恐怖模样，只为找出只爱人鬼薄英，也让无界尊皇得以修炼超越九天之能。

无界尊皇在天者欲奉神之子为主时，鬼狱邪神担起其余四尊的任务时现身。

神之子降临时但在却逢妖世浮屠打破空间入侵，为免死国遭殃，无界尊皇和其他四尊，使出亡炼神击抵御，战后无界尊皇则奉天者命令，在不毛矿坑利用夜神所杀千魖和杀死更多的魖族打造忌血之路。

后在阿修罗修筑的莫汗走廊被四龙齐鸣破坏同时，天者及时转移能量，使死国、火宅佛狱联通苦境，无界尊皇奉命担当守路者的角色，以心针防范外敌入侵。

在鬼薄英拜托笨帝、卢卡带琴奴逃出死国时，看见琴奴身上象征自己赠予鬼薄英的定情之物，出声让银月贪狼放行，事后被愤怒的天者要求用夜神性命来交换鬼薄英、琴奴母女自由，使他陷入两难。

在地者死后，天者解开无界尊皇身上禁锢，并把灭字卷交给他，让他自由释放鬼薄英，原因只在地者死后，天者感怀世上已无人了解自己，不希望同为天族的无界尊皇继续痛苦下去，无界尊皇与天者也冰释前嫌。

天者死后，无界尊皇一家人退隐。

但无界尊皇的退隐生活并不平静，由于女儿琴奴遭天阎魔城所擒，被他化阐提要胁加入六魔禘参与太荒神决，所属天时为子时，在第一战中对上龠胜明峦副峦主奉皇靔时获得胜利。

第二战则对上阿修罗，双方无奈对决，尊皇受天时死克，终究败亡。

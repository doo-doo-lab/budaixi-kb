# 雨知儂 (雨知侬)
================================================================================

雨知儂

塵世九龍之一的水之瀧，因為極為欣賞妲眸姬雷厲風行的作風，故而自願成為麾下，成為聖城統軍，武功高強，善使一把特製的鐵扇，治軍以嚴格聞名，對於聖皇之令都會盡力執行。

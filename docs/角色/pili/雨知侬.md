# 雨知侬

尘世九龙之一的水之泷，因为极为欣赏妲眸姬雷厉风行的作风，故而自愿成为麾下，成为圣城统军，武功高强，善使一把特制的铁扇，治军以严格闻名，对于圣皇之令都会尽力执行。

# 烨世兵权

================================================================================

霹雳布袋戏虚拟人物烨世兵权，霹雳布袋戏系列虚构角色，黄文择配音，初登场于《霹雳震寰宇之龙战八荒》第32集，退场于《霹雳经武纪之枭皇论战》第29集。身为集境破军府军督，手握辉煌军刀修炼独日武典与兵甲武经，通过掌控圣帝傀儡政权主导三仪三司十二殿体系，坐视佛业双身四境合一，始终隐忍不发，一方面扶植圣帝政权为傀儡，另一方面，暗中厚植实力，准备掀起一场腥风血雨。曾联合千叶传奇协助苦境抵御火宅佛狱与死国，意图渔翁得利，并在素还真布局下被迫介入苦境战局。烨世兵权以昊苍玄诀功体化解敌方内力，施展独日武典最上式玄之诀护持集境地脉，却在对抗玉辞心时因废字卷功体克制而不敌。破军府遭天雷摧毁后，受帝如来重创，最终被啸日猋以六武归一之招击杀。其造型融合欧洲贵族服饰与军阀元素，红色三角大领黑袍搭配金色肩甲，马尾卷发突显军人气质。破军府覆灭标志着烨世兵权军国主义扩张路线的终结，但败亡之际仍保留武者傲气。主要兵器辉煌军刀配有圆罩型护手，黑色刀鞘镶嵌金色护柄。中文名烨世兵权别 名虓眼军督配 音黄文择性 别男登场作品霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕霹雳经武纪之枭皇论战身 份集境破军府领导者·军督思想特点极端军国主义根据地破军府、封将台来 自集境组织门派三仪三司十二殿本尊雕偶师洪剑山角色编剧三弦出场集数82集

## 角色能力

武学：独日武典【最上式·玄之诀、九曲黄河万里沙】、兵甲武经裂字卷·裂宇之玄、浩世军威、号令天地、玄掣雷殛、板荡山河、碎破灵空、军武耀日、长驰万军破山河、惊腾万军耀天下功体：昊苍玄诀（可化消对方内力）机关阵法：大周天罗阵武器：辉煌军刀◎外形特征：超长型军刀，刀身上刻纹路。黑色刀柄，尾端镶有金色护柄。单一雕护设计，雕琢如羽，刀鞘以黑色皮革包覆，并设计圆罩型护手，握刀时圆罩会向外打开。◎登场剧集：霹雳震寰宇之龙战八荒 第32集◎事迹简述：烨世兵权以军人身分自傲，以战争为天职，平时惯以左手轻碰辉煌，除了展现军人气势，另一方面则是保持备战状态。战斗时巨大刀护可挡风沙和饰劲，亦可减轻危险，使持刀者再冲锋陷阵。烨世兵权纳千叶传奇为军师，并与苦境正道、杀戮碎岛联手，烨世兵权亲自出马率制咒世主，辉煌军刀在手，所向披靡，造成火宅佛狱大军进军苦境一役大败。能力详介昊苍玄诀烨世兵权最主要的内功，具有在兵器相交、肉身相搏之时不断消耗对方真元之效，在前期近乎靠此招就让不少高手先天苦战，后期则因为台面高手各种应对手段而不再有优势。独日武典最上式“玄之诀”烨世兵权在四境合一时，用此招一掌护住集境地脉，推集境完整降落苦境，霸气绝伦。在围杀“慈光之塔的惊叹”剑之初之时以此招迎击玉辞心，不料却因为废字卷特殊功体之效不敌。角色形象以偏欧洲贵族造型为设计基调，并加入军阀的元素到服装、配件中，发型设计为中古法国贵族的马尾扎法，前额采用大波浪卷发，马尾则为小卷发束，身着红色三角大领的黑色欧式长袍皮衣，内搭白色军式排扣长衣、长裤及军靴，并特别加上金色肩甲及披风，腰间系着长型军刀，处处体现军国主义领导者的风范。

## 角色经历

烨世兵权是集境破军府最高领导人，称号“虓眼军督”。多年前，武皇半尺剑死于一页书之手，连同其下的组织崩解，烨世兵权拥护圣帝统一集境，建立了“三仪三司十二殿”的统治机构，并亲领三司之一的破军府，作为监控集境一切的实际统治者。烨世兵权烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片烨世兵权图片佛业双身之乱，邪灵将魔爪伸向集境，军督趁势扳倒天机院主太君治，并放任佛业双身，在佛业双身发动“四境合一”时，一掌保住集境，使之稳稳降落在苦境大地的北方。凭此展开自己的霸业。火宅佛狱和死国藉血暗沉渊得以进出苦境后，军督更藉策师千叶传奇的计策，表面与凯旋侯以中立换取裂之卷的初式，但私下又以“开除”为由，让战将鸦魂等人协助苦境抵御火宅佛狱与死国，意图渔翁得利。但不久后，素还真自慈光之塔返回，在被其设计下，军督被迫出手，迎战佛狱三公的太息公邪玉明妃，虽然以裂之卷初式破贰式而取胜，但也被迫提早涉入乱世。其后，咒世主以女儿换得杀戮碎岛戢武王协助，并操控入魔的一页书，意图一举攻下苦境。但战争将起时，一页书受到叶小钗和来自慈光之塔的辉煌堕世和拔刀洗慧牵制，让原本在薄情馆等待的咒世主没等到人，反而是军督到场。觑准咒世主运起裂之卷，军督以反制之招击败咒世主，但任由其离开，更下令撤军，意图对素还真釜底抽薪。咒世主和天者死后，佛狱元气大伤，死国则退出苦境，但军督的霸业推展却仍不顺。先是爱将弑道侯亡于玉辞心，因与玉辞心之兵甲武经废字卷功体相克而自废灵字卷功体，武力有所下降。再又受到惜夫人率众刺杀，更逢末世圣传和云鼓雷峰围攻。后来，在素还真的计划下，破军府被天雷所毁，军督则在与云鼓雷峰佛首帝如来的战斗中失利并受伤在身。最后在突围中，已然负伤的烨世兵权遇上习成贯通六卷兵甲武经的啸日猋挑战，被啸日猋以“六武归一”之招重创。最后在破军府前因伤重而亡。

## 角色评价

烨世兵权，积极的军国主义者，有其恢弘的气度与善谋能断的智慧，更懂得运用时势，发挥兵法所长，谋取接连的胜利。烨世兵权纵有成王败寇的豪赌气魄，但以征伐达到富国强兵的目的，终是走向自我毁灭的失败途径，再多的霸业宏图，终在迭起的苦境反抗势力中，烟消云散，徒留下属于军人的傲气与执着不悔。军督陨落图片

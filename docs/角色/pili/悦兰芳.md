# 悦兰芳

霹雳布袋戏虚拟人物悦兰芳，霹雳布袋戏虚拟人物。看似儒雅的悦兰芳，外貌华丽俊美、潇洒不羁、处世严密，专注于自身目标，具有强烈的野心。以高超的枭雄手腕，逆向操作，顺利使御主易位，重登大堂，但城府深沉、游走各方势力之间，直至权谋用尽，后被策谋略化为定风愁行走江湖，被舒石公、素还真等人感化，痛改前非，假扮素还真对抗欲界波旬，终为正义捐躯换得流芳百世之名。

## 角色详解

摘自霹雳会月刊第70期 人物完全写真——悦兰芳霹雳会月刊第70期 人物完全写真被自己的亲弟弟背叛而篡位的汗青编真命天子——御笔丹青悦兰芳，因为忠心手下驭武宫主及其弟子们的牺牲，总算得以光明正大回到汗青编。

一开始，大伙儿还以为整件事是因为经天子的野心，而有阴谋篡位，可是在《霹雳图腾》中，一番与紫星眉的谈话，却暴露出悦兰芳不为人知的一面，原来，有野心、城府深的不只弟弟，总是一派优雅，与世无争模样的哥哥，才是最阴险的大反派。

以退为进，让自己居于幕后掌控大局，悦兰芳不仅手段高明，也够奸诈、阴险，当年的天外方界创始人无忌天子，虽然曾用过以退为进这样的险招，但无忌是为了能与相爱之人厮守，悦兰芳却不是如此单纯，让有野心的弟弟成功篡位，然后再回头以光复汗青编的名义逼走弟弟，又跟预言七星的紫星眉“唱双簧”，他的居心叵测是显而易见的！

一身暗红色的锦服，上面镶着双色的宝石并缀以鸵鸟毛，衬托着悦兰芳天生的领袖气质，同样镶有红宝石的超华丽羽扇，则代表了他乃一介儒士，这也隐喻了其汗青御主的身份。

华丽、亮眼的服装造型，是汗青编御主的重点特色，但一身的暗红，其实很像血液的颜色，汩汩流动的血液，看似平静，实则暗藏着一股蓄势待发的冲力，只要一不小心，便有可能会被反噬、被淹没！

所以可千万别被他俊美斯文的外表所骗喔！

# 妲眸姬
================================================================================

妲眸姬

个性霸气，善于布局，步步盘算。妲眸姬出身底层平民，与结义兄弟在推翻爬族对人族残暴的统治后，被人族尊称为圣皇，成为人族共主，因在妖漫世界漫长的历史中，人族一直都是最低下的存在，任各种族奴役，妲眸姬上位后，便开始斩杀龙族，屠龙务尽，啖龙饮血，政治手腕高超，武学更是深不可测，使得各族与各势力皆不敢撄其锋。

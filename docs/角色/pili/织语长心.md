# 织语长心

================================================================================

霹雳布袋戏虚拟人物织语长心，霹雳布袋戏虚拟人物。天真爛漫，極為率真單純，不經世事的少女，與不見荷在金山海域發現重傷的葉小釵，帶回緣荷來境醫治。天賦異稟，具透視死亡之眼，能準確預見他人死劫。因天生命格不凡，在玉陽君推波助瀾下，戴上羅喉戒璽成為武林共主。

**中文名**：织语长心

**别名**：长心女帝

**配音**：黄文择

**性别**：女

**登场作品**：霹雳神州III之天罪

**登场作品**：霹雳天启霹雳震寰宇之刀龙传说

**角色编剧**：三弦

## 角色经历
少女版织语长心甫出场天真无邪，救助被弃天帝打落北越天海的叶小钗，对叶小钗心存仰慕之情，但努力撮合他和自己的义姐不见荷。

由于命格非凡，被玉阳君操纵戴上罗喉戒玺。

在长心登基后，为治愈先天心疾而借助希望号角之力，与末日神殿的死国之神残影进行交易，不但换得健康，更获得了美貌与武功，不过心性却也完全改变，因美貌而虏获血榜杀手明珠求瑕甘心不计任何代价为长心所用。

因玉阳君的关系，朱翼皇朝与日盲族立场对立，经千叶传奇设计，长心戒玺被夺，后日盲族与学海无涯联手大败朱翼皇朝，长心不满地解除玉阳君身上的戒玺束缚，随后杀死玉阳君，迁往东武殿。

但长心后来与太学主合作，先灭日盲族，后杀不二做，并阻拦素还真前往灭境救凤凰鸣，彻底激怒素还真。

被素还真用天问三誓废掉武功、击断全身筋骨，待在琉璃仙境，琉璃仙境后被太学主摧毁。

太学主伏诛后，长心与义姐不见荷退隐。

## 角色特色

织语长心相貌：美艳绝伦，无瑕可寻，不可方物，震慑人心。气质：少女时的长心像向日葵般的可爱，成为女帝后的她宛若牡丹花一般雍容华贵又如罂粟花一般带着能引领走向毁灭的诱惑。

## 角色配乐

◎神雀女帝（长心女帝角色曲）收录于《霹雳英雄音乐精选二十一》织语长心本曲是首用来描绘宫廷华丽风格的乐曲。大编制的国乐合奏，铺以敲击乐器的协奏，衬托出朱翼皇朝睥睨神州不可一世的浩大声势。中后段轻柔的弦乐搭配缓慢节拍铺陈，让听者如同亲见女帝缓缓步入朱雀殿的庄严景象。◎仙水湾（仙水湾场景曲）收录于《霹雳神州Ⅲ天罪Ⅱ剧集原声带》大提琴音响起，吉他与弦乐协奏让乐曲增添悠远飘扬意境。◎长心女帝（神雀女帝）收录于《霹雳天启剧集原声带》

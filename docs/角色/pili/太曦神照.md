# 太曦神照

霹雳布袋戏虚拟人物，代表七杀星（天枢座）。

未知的异境魔神，久远前诓骗九天玄尊，骗走其天书与魔始的缔魔剑，营造以大地光明之母自居的假象，看似引导苦境众人对抗邪神，实乃阴谋末世圣殇计划。

被天迹揭露真相后，看似暂时隐匿行踪，实则运用神谕身份在武林暗处进行新计划。

以神谕身份加入六蚀玄曜，并与之联手开启神州裂变，造成武林寰界割据，同时引导六蚀玄曜崩裂神州后的寰界巨能传往阴阳裂界，吸纳泰半能量。

太曦统治南境，建立日曜皇城，期间不断恩威并施地扩张领土，并求贤若渴，广纳贤士，向大众宣扬理念。

曾流放天迹（及奉天逍遥）至阴阳裂界，并暗中襄请神荒子，协助鬼一法眼师，取得见龙岛之瞳能，密谋魔三脉。

收玉冰莹（瀛女医）为徒，在其陷入沉眠前将半部宇宙法准授予玉冰莹，令其假扮自己。

在《霹雳天机贰：仙魔决》中，太曦神照算计得逞，以桑源灯收拢民心，登高一呼，其七眼神母之身凝聚万民信力，欲降末世圣熵。

最终与天迹展开决战，面对如日中天的太曦神照，逍遥忘机（天迹）等人试图扭转乾坤。

## 角色形象

从《霹雳魔封》到《霹雳天机》，实际上是有两个太曦神照的。

昔日大地光明之母于西崦闭关之时，将对外要事一律托付予座下首徒——瀛女医玉冰莹主掌，是太曦神照唯一的代言人。

其个性冷慧聪颖，能卜知神鬼之事，曾指点八龙天、碧如斯等无数人解开难题，却在一次变故中，下落不明。【大地光明之母】太曦神照剧中以大地光明之母形象登场，为了对抗破坏神厄祸，曾引导第一代逆神七皇的现世，剧中更借由九天玄尊曾与其对抗的往事，带出太曦神照的传奇性。

然而，就在霹雳天越步入尾响之际，剧情峰回路转，由天迹揭穿太曦神照的真面目，原来太曦神照、八歧邪神等，世人以为的诸神实乃异境魔神。

阴谋败露的太曦神照，在让奉天逍遥坠入魔隧深渊，流落阴阳裂界之后，自身也暂时消声隐迹。

太曦神照太曦神照会刊图南斗六星在战魔策总收档中，剧组带出了六蚀玄曜乃南斗六星，对应靖玄九星代表的北斗九星，象征剧情也将在七大神秘线步入尾声之际，转移至南斗与北斗的玄象之争。

玄象者，星象也，指日月星辰在天所成之象，剧组借指南斗、北斗抗衡之天象，带出一场南斗、北斗之事，已是无可避免。

而太曦神照所代表的，乃是七杀星，剧中亦称天枢座。

真正的神谕神谕剧中乃是太曦神照的化身之一，系其在六蚀玄曜所用之身份。

在六蚀玄曜的聚会中，神谕宣称人三脉之事，意琦行将徒劳无功，后续更接连带出，神谕对玉门世家的陷害，包括设计郁葬香，阻止人三脉集结等等，在在皆可见神谕对天迹相关事情的针对性。

随着身份揭晓，原来神谕竟是太曦神照，一切虽有脉络可循，却也带来更大的疑问，太曦神照与天迹之间，是否另有不为人知的隐情？

以及神谕二字，是否另有所指？【玉门世家的灾星】玉畹芳本为玉门世家的希望，却在神谕、无射联手下，被夺走部分筋脉，更因原罪被贩花郎设计，造成生母落絮夫人悲剧，目睹一切的郁葬香，欲与原难同归于尽不果，忘却一切，在无射设计下，流落见龙岛，成为郁葬香。

太曦神照为何执意将玉畹芳变成灾星？

其利用辟邪一脉与原罪背后，又隐藏什么未知之秘？

太曦神照阴谋六蚀玄曜会刊图六蚀玄曜六人之间，乃平等的合作关系，虽各自进行所属任务，但六人系有明确目标在推动。

在谈无欲与玉龙隐士的对谈闻，就对六蚀玄曜引动七大神秘，短时间内接连现世有所怀疑。

而七大神秘的力量，接连为六蚀玄曜所得，除了开启七窍封印，是否尚有不为人知的秘密？

太曦神照化为神谕，针对人三脉的同时，台面下的诸多运作也随之展开。

如襄请神荒子，在玄象宴上暗中协助鬼一法眼师；

以及与鬼一法眼师合作，取得见龙岛之瞳能，和密谋魔三脉，对抗人三脉等事，皆可见太曦神照短暂的消声隐迹，是为了进行更大的阴谋，意琦行众人能否及时阻止一切？

而流落异境的天迹，又为何要意琦行暂时停止动作，一切且符后续分晓。【造型设计】造型正装以大地光明之母、太阳神为形象法想，整体造型带有浓厚的北欧诸神的色彩，举手投足间，散法高贵典雅的女神之感，搭配天蚀圣杖，降临末世圣殇，为人世带来巨大的浩劫。

七杀星太曦神照乃六蚀玄曜中的七杀星，亦称天枢座，七杀星造型上，以冷酷铁面的形象，展现有别于女神版杀伐果断的气场，也表现七杀星之星性特质，主成败、掌权柄，象征威勇，具有冲锋陷阵，冒险犯难之精神。【道具】天照肩舆手持物“天蚀圣杖”以太阳神为构想，权杖分善恶两面，金色双翼宛如金乌展翅，展现出太曦神照宛如神祇的架势，金色的色系，更搬托出太曦神照整体的尊贵不凡感。

座驾“天照肩舆”神谕登场时，伴随着阴阳桥现世，天照肩舆会从天而降。

据编剧所说，在与道具师讨论时，在轿子的设计上就带有巧思，辖身跟七杀星双肩类似的设计，展现七杀星降世的杀伐气势。

## 经历

久远前，太曦神照诓骗九天玄尊，营造以大地光明之母自居的假象，引导苦境众人对抗邪神，实乃阴谋进行末世圣殇计划。

在被天迹揭露真相后，太曦神照将奉天逍遥打入阴阳裂界，自身暂时消声匿迹。

其后，太曦神照运用“神谕”的身份在武林暗处进行新的计划，并以此身份加入并领导“六蚀玄曜”，为南斗六星中的七杀星（天枢座）。

六蚀玄曜引发神州裂变、寰界割据后，太曦神照获得泰半寰界巨能，统治南境“日曜皇城”，并不断恩威并施地扩张领土。

其引导寰界巨能传往阴阳裂界，开启了另一段故事，并与裂界势力接触，吸纳了原裂界成员作为部下。

在《霹雳天机》中，太曦神照的塑造被部分观众认为存在性格矛盾，时而精明算计，时而在与国师解璇玑互动时表现失当。

太曦神照的真实身份为异境魔神，曾救下玉冰莹（瀛女医）并收其为徒。

在自身即将陷入沉眠前，将半部宇宙法准交给玉冰莹，让其假扮自己。

在《霹雳天机贰：仙魔决》中，太曦神照的计划达到高潮，以桑源灯收拢民心，登高一呼，神秘的七眼神母凝聚万民信力，将降下“末世圣熵”。

## 创作背景

太曦神照的设定可能参考了基督教天使长加百列，太曦为女性神明，掌管设定类比天使的“天族”，其称号“曦”有太阳之意，与炽天使相关。加百列在圣经中被称为“她”，象征智慧和正义，负责宣告神谕，太曦神照给九天玄尊发证书、托梦神毓逍遥的行为与加百列的职责相似。太曦神照的设定也可能融合了日本神话天照大神的元素，其称号“神照”及剧情中君奉天前往“天从灵峰拔剑”的情节暗指素盏鸣尊的故事。但分析认为，整体神战体系仍偏向基督教框架，引入完整日本神系的可能性较低。

## 人物影响

作为《霹雳天机》系列的核心反派，太曦神照的塑造引发了观众讨论，部分观众认为其在剧情中表现存在性格割裂：在谋划全局时精明冷酷，但在与国师解璇玑互动时，却显得轻信甚至“恋爱脑”，削弱了作为最终BOSS的压迫感和格调。太曦神照具有大地光明之母、神谕、七杀星、异境魔神等多重身份，其从诓骗九天玄尊到阴谋末世圣殇计划的漫长布局，构成了霹雳布袋戏“神战”线后期的重要剧情推动力。

## 相关作品

太曦神照在《霹雳天越》中正式登场，以大地光明之母形象出现。在《霹雳天机》中，太曦神照作为角色出现。在《霹雳天机贰：仙魔决》中，太曦神照真身活跃并推动核心计划。

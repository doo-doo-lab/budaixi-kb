# 麒麟星
================================================================================

麒麟星

魔吞十二宫的麒麟宫代表，亦是魔吞不动城之城主，脸戴麒麟面具，身披紫色战服，为人自信、冷静，擅于谋计，更对当今武林局势有着高度了解，乃魔吞不动城的统筹者。手持麒麟双剑，其武学广纳千川，招路更是多变，拥有难以测度的武学根基。雷厉风行的行事手腕，将魔吞不动城的阻碍一一根除，也将为武林局势带来更多的未知数。

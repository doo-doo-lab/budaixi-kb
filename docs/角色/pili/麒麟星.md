# 麒麟星

魔吞十二宫的麒麟宫代表，亦是魔吞不动城之城主，脸戴麒麟面具，身披紫色战服，为人自信、冷静，擅于谋计，更对当今武林局势有着高度了解，乃魔吞不动城的统筹者。手持麒麟双剑，其武学广纳千川，招路更是多变，拥有难以测度的武学根基。雷厉风行的行事手腕，将魔吞不动城的阻碍一一根除，也将为武林局势带来更多的未知数。

## 角色背景

天海·麒麟星，魔吞十二宫的麒麟宫代表，亦是魔吞不动城之主，脸戴麒麟面具，身披紫色战服，为人自信、冷静、擅于谋计，更对当今武林局势有着高度了解，乃魔吞不动城的领导与统筹者。

雷厉风行的行事手腕，不仅为武林局势带来更多的未知数，也让武林不论正邪两派势力，皆对不动城的存在无法忽视。

身为城主，麒麟星担负起与各大势力斡旋的任务，并从中设法将异识晶源引诱而出，进而与伙伴们携手，将其一一消灭。不由得异识在武林中作恶，颠乱是非。

麒麟星手持麒麟双剑，其武学广纳千川，招路更是多变，拥有难以测度的武学根基，更特别习得罪域领导创罪者的独门绝招水风行步，此招更在日后对阵创罪者时，引起对方的极大兴趣，对于麒麟星的真实身份更为好奇。

每一名不动城的伙伴，都必须得到麒麟星的信任，同时也要展现出自己愿意牺牲的决心，麒麟星必须担负起如此重大责任，以确保不动城战将们彼此之间，信念一致。

不动城的巍峨现形，以及所向披靡的气势，素还真自然也要一改圆融态度，戴上麒麟星面具后，不动城城主以不动城的目标——"消灭异识"为最大根除标的。强悍的作风、冷酷的语气，让与麒麟星接触过的人，实在难联想就是过去那名风度翩翩的素还真。

麒麟星如此作风，树立了魔吞不动城不容进犯的气势，就算谈判也是言而有信，不耍小人手段，如此也在武林让不动城的消息以极快速度传播，这也是麒麟星的目的，因为魔吞天下，才能将暗伏的势力一次引出，进而一举歼灭。

麒麟星的真实身份，自然便是武林名人"清香白莲素还真"。在台面上与台面下用两种身份在斡旋各大势力，只要有麒麟星在时素还真就不会出现，而素还真同时也能和不动城的魔将保持着密切关系，这层道理自然能让观众一目了然。在成为解锋镝之后的素还真，将会有何种任务赋予不动城的伙伴，这将是未来可瞩目的重点。

在衍生手机游戏《霹雳江湖》的"魔吞传奇"版本中，麒麟星被设定为辅助型英雄。其基础技能"星痕圣击"可治疗己方全体；进阶后开启的高级技能"水风行步"可攻击敌方并治疗己方。在游戏内，麒麟星与苍鹰、金狮等角色有缘分关联，使用麒麟双剑、天紫战甲等装备。

## 来自百度百科的补充

麒麟星是霹雳布袋戏中的虚拟人物，魔吞不动城城主及麒麟宫代表。其真实身份为素还真（解锋镝），脸戴麒麟面具，身披紫色战服，手持麒麟双剑，武学融合多派精粹并通晓水风行步、星痕圣击等招式。

作为不动城核心统筹者，麒麟星以自信冷静的谋略暗中引导伙伴化解武林危机。他雷厉风行根除组织阻碍，通过强硬手腕周旋于各大势力间建立分散据点，维系组织隐秘性的同时，以消灭异识晶源为目标推动战略布局。在行动中，天海麒麟星曾遭遇多方围杀，亦曾与别离禅等对手交战。

其双重身份与化明为暗的布局深化了魔吞十二宫体系，既为后续任务奠定基础，更因行事果决为武林局势带来诸多未知变数，成为贯穿多部剧集的关键动力。

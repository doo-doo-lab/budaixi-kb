# 崎路人（霹雳布袋戏中的角色）

崎路人，霹雳布袋戏中的角色。原为集境人士，为追杀仇人灯蝶而偷渡至苦境，是一位具有智慧的领袖型人物，个性风趣巧慧，慎谋能断。身为天虎八将之一，与紫锦囊并肩作战、助导金少爷步入正途；于素还真危难时给予最大支持，为人处世有另一种不凡的手腕，主张该牺牲时就必须有所牺牲。

武学介绍：
天绝六式崎路人向六位师傅偷学(后得其谅解)而来的武学，分别为：雷厉风行、星罗棋布、匣剑帷灯、回黄转绿、伏尸遍野、流金铄石。

崎路人轰天雷击崎路人融合天绝六式所创的气功。

一页书曾在锦囊中写道：“半尺剑即灯蝶修万年。

欲诛此凶，需天绝六式合一。

六式如缺其一，败矣。”最后在童道击中灯蝶，再加上紫锦囊和万俟焉的相助，使灯蝶现出原形。

## 角色经历

崎路人出身集境，师父为集境无常楼的六大高手，崎路人由他们那偷得武功宝典，习得了天绝六式的武功，后来为杀灯蝶修万年报杀兄之仇而违反戒律，私自进入苦境（即一般世界）。

在苦境，他选择黑湖为隐居地，沉潜许久搜集与灯蝶有关的资讯。

期间曾拯救遭逢灭门之祸的北域命家庄少主命七天，给予其“菩萨印”与“鬼爪破魂指”秘笈锻炼，也在这段时间由天绝六式创出六式合一的武学“轰天大雷击”。

崎路人的活跃时期在《霹雳剑魂》至《霹雳异数》期间。

他最早的出场，是出现在《霹雳剑魂》时期命七天的回忆里，其后由于剧情推移，正式出场。

在《霹雳剑魂》期间，他曾救助被暗算导致失明的叶小钗，也曾吓退武林中的投机份子毒王毒千手及单锋无尽式百里飞首。

此外，当命七天被北域武林追杀时，崎路人多次出面击退敌手，并曾施展过“乾坤大挪移”的幻术，将一座山装进布袋里，成为早期布袋戏迷津津乐道的话题。

期间，他亦潜入过北域，破坏北域武林反派领导者金阳圣帝的势力，且与金阳圣帝对战过一次，两人气功余劲摧毁了“镜中圆”的虚幻世界。

崎路人在《霹雳异数》期间，是崎路人最活跃的时期。

当时，主角素还真虽从天雷殛顶的灾厄重生，却被灯蝶的邪恶组织“天蝶盟”所牵制，并卷进“天虎八将”及“魔龙八奇”的斗争里。

中原正道支柱不在，崎路人便成为正道的主要领袖，期间曾安抚因师被杀而疯狂失神的叶小钗、指点秦假仙奔走、调查魔龙八奇台面上领导人太黄君的底细，并教化叶小钗顽劣的儿子金少爷、收服魔龙八奇之一的六月飞霜冰锋箭无形。

之后，崎路人借着硬挨武林耆宿万俟焉的气功一击，作为自己心神涣散疯疯癫癫的理由，装疯卖傻自称“骑鹿人”，驾着金少爷拉的人力车，手持大铁锤，以诙谐幽默的风趣方式游走武林，对抗天蝶盟、太黄君等势力，并屡次展现高超的智慧和武功助正道渡过难关。

最著名的事迹就是策划“金丝十七弦风云琴”、“八卦人头颅”、“凤羽半月钟”等三种乐器齐奏合鸣，作为万俟焉提供宝物血角三青秘密与素还真的条件。

但是在此役里，崎路人遭逢“天蝶盟”前锋“彩纹蝶”以毒招“蛾飞蝶舞”逼杀，情势所趋之下动用天绝六式之一的“雷厉风行”击退对手，因而暴露身份，也引发六位师傅从集境赶来苦境追捕。

在此役过后，霹雳布袋戏中的先天角色一页书和半尺剑双双现身，掀起书剑争斗成为另一波剧情主线，麻烦缠身的崎路人耀眼度因而相形降低。

等级下降之余，崎路人也渐渐开始有了失策与情急的表现。

例如为素还真劳碌奔走，还要处理金少爷与黑白郎君的争斗，并应付六位师傅的追捕。

其后，为了化解天虎八将和魔龙八奇的宿命争斗，与金少爷、箭无形共同参与“时空圣战”，却被留在过去。

后经一页书以身犯险，牺牲己身到八口山游魂台投入生命石。

返回当今时空的崎路人，得知半尺剑其实就是灯蝶假扮的冒牌货。

加上灯蝶已于这段期间陆续杀害崎路人六位师傅中的数人，于是终于找上灯蝶算帐，可惜被灯蝶逃脱。

后来经过一页书化身紫锦囊的策划，崎路人在童道埋伏，使出绝招轰天大雷击，将假扮为半尺剑面貌的灯蝶轰出童道，而在童道之外的万俟焉也补上一掌，使灯蝶现出真面目，不过后来仍被其逃脱。

崎路人报仇心切，之后陆续多次追杀，仍无结果，反倒身中暗算，负伤调养了好一阵子。

之后虽康复，却也在为了素还真的情况下，孤身赴千邪洞欲救风采铃，与鬼王棺、业途灵谈判，不幸死于鬼王棺之手。

死后尸体被送入阴山藏万棺（霹雳紫脉线第7集），汗青编感其义气，给予了告评价。

## 角色争议

退场详细经过与争议崎路人在剧情中，亡于《霹雳劫》第二十五集。

崎路人当时气焰正盛的反派魔头鬼王棺与业途灵将素还真之妻子风采铃（崎路人六位师傅之首百里泣的弟子，也算是崎路人的师妹）绑架至千邪洞，并布下“离魂迷图”阵局威胁素还真到千邪洞谈判。

素还真知道进入必死无疑便忍痛置之不理。

崎路人得知后，与素还真讨论，但素还真仍以置之不理的态度冷处理。

痛心不平之下，崎路人丢下一句：‘你不去，我去！我做牺牲，我打头阵！’火速赶往千邪洞。

素还真在好友一线生催促下，省悟情形不妙，才跟着赶赴千邪洞，然而已延误时机，等素还真、一线生赶到时，崎路人已然进洞。

崎路人入洞后，遭逢鬼、业二人以迷阵封阻退路，并被前后夹攻。

混战中，先被业途灵的气功击中，鬼王棺再赞一掌，重伤倒地。

此时素还真在洞外出声，要鬼王棺到洞口谈判，鬼王棺遂拖着奄奄一息的崎路人到洞口，作为与素还真谈判的人质。

双方谈判，鬼王棺开出要求要素还真入洞换人，素还真衡量局势后仍然忍痛不愿进去。

鬼王棺随即道：‘那你就眼睁睁看着崎路人死吧！’崎路人因此为鬼王棺所杀，血溅素还真之面。

崎路人死前最后一句话是：‘素还真，我总算是真正的了解……你。’崎路人之死除了使许多布袋戏迷感到惊愕难过之外，许多人对于主角素还真竟然只顾自己安全而牺牲战友多所批评。

后续素还真和慈航渡谈话时，二人离开时走的是一条琉璃仙境通往千邪洞的地道。

（或许这是素还真为了救风采铃挖的，但素还真不对秦假仙、崎路人坦言也是事实）相关争论还包括：当时素还真为何不对崎路人说明原委或暗示自己的苦心？

为何不拉住崎路人？

一向冷静的崎路人为何在编剧笔下出现如此冲动的作为？

此外，素还真是否有能力战胜鬼王棺与业途灵？

他是真的无能为力，还是隐藏实力？

再者，当时千邪洞内有一颗释迦树，是一页书重生的寄体，素还真是否顾虑到一页书重生阶段的安危才做出如此抉择？

这些都是讨论的议题。

总之，对于崎路人之死，部分戏迷认为素还真是为“顾全大局”，而不得不如此，有些戏迷则对编剧让一向冷静的崎路人作出如此冲动的举动感到不满。

此外，也有不少热爱崎路人的戏迷投书建议崎路人应该找机会复活继续出场。

## 角色特色

崎路人因其冷静的智慧、明快的作风、风趣的举止受到喜爱，崎路人的死亡则引发布袋戏迷的争议。崎路人出身集境，为无常楼风雷六圣的弟子；来到苦境后，被记载为天虎八将之一。装疯卖傻时，曾自称“骑鹿人”。造型特色是长发旁分、身披湛蓝衣衫、左肩斜背一个灰白色大布袋，配乐为缓慢深沉的二胡旋律。他的习惯与嗜好则包括：边走边说话、挖苦旁人、说服他人、捉弄反派、叫人伸手到背后布袋里拿宝物、坐在人力车上拿大铁锤敲金少爷的头、一边骂素还真，一边为其奔走、听到与灯蝶修万年有关的事情后热血冲动……等。

角色经历崎路人出身集境，师父为集境无常楼的六大高手，崎路人由他们那偷得武功宝典，习得了天绝六式的武功，后来为杀灯蝶修万年报杀兄之仇而违反戒律，私自进入苦境（即一般世界）。

在苦境，他选择黑湖为隐居地，沉潜许久搜集与灯蝶有关的资讯。

崎路人的活跃时期在《霹雳剑魂》至《霹雳异数》期间。

在《霹雳剑魂》期间，他曾救助被暗算导致失明的叶小钗，也曾吓退武林中的投机分子毒王毒千手及单锋无尽式百里飞首。

在《霹雳异数》期间，是崎路人最活跃的时期。

崎路人在此役过后，霹雳布袋戏中的先天角色一页书和半尺剑双双现身，掀起书剑争斗成为另一波剧情主线，麻烦缠身的崎路人耀眼度因而相形降低。

等级下降之余，崎路人也渐渐开始有了失策与情急的表现。

后经一页书以身犯险，牺牲己身到八口山游魂台投入生命石。
返回当今时空的崎路人，得知半尺剑其实就是灯蝶假扮的冒牌货。

加上灯蝶已于这段期间陆续杀害崎路人六位师傅中的数人，于是终于找上灯蝶算账，可惜被灯蝶逃脱。

死后尸体被送入阴山藏万棺（霹雳紫脉线第7集）角色争议退场详细经过与争议崎路人在剧情中，亡于《霹雳劫》第二十五集。

当时气焰正盛的反派魔头鬼王棺与业途灵将素还真之妻子风采铃（崎路人六位师傅之首百里泣的弟子，也算是崎路人的师妹）绑架至千邪洞，并布下“离魂迷图”阵局威胁素还真到千邪洞谈判。

素还真知道进入必死无疑便忍痛置之不理。

痛心不平之下，崎路人丢下一句：‘你不去，我去！我做牺牲，我打头阵！’火速赶往千邪洞。

崎路人崎路人入洞后，遭逢鬼、业二人以迷阵封阻退路，并被前后夹攻。

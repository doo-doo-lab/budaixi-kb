# 雪憐 (雪怜)
================================================================================

雪憐

八歧邪神肆虐下的受害者，丈夫被邪神殺害，將其魂魄化為一口傘。雪僯為報仇，千里迢迢至東瀛遠赴魔劍嶽，只為求得赤華劍，但卻以出賣自身靈魂為代價，至此困守魔劍嶽。唯有引渡三千怨魂，方能離開血池孤人橋。

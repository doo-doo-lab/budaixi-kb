# 三青擺龍 (三青摆龙)
================================================================================

三青擺龍

為翥龍之都統率龍族陸海空三軍的軍揆，個性霸氣張揚，曾在苦境與冥海龍靈大戰重創，產下龍蛋後被万俟焉殺死，直至多年以後，才被淥宇塵湊齊龍骨，並在花初見提供的骨氣下復活。

# 不二刀

刀就是刀，何需排名！一生孤独，刀法精湛，喜爱出没在层层山脊间、傲视群伦。为找寻人生目标，隐避在荒凉的枯木求泉，在打铁之中压抑邪性，领悟出刀的真正境界。身为七星之刀王星，在七星之主现世后也再度步上武林的不归路。

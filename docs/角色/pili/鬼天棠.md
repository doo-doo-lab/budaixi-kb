# 鬼天棠 (鬼天棠)
================================================================================

鬼天棠

魔息大帝麾下六將之一，好戰的性格下難掩殺戮成性，卻也為了魔息國度立下不少汗馬功勞，故無法接受魔息大帝叛逃國家一事，因而耿耿於懷。相當尊崇其家族特有的規矩，即在戰場上將敵人的頭顱砍下並製成人頭杯敬酒慶祝，視為一種屬於勝利者的儀式。

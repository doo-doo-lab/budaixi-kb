# 天蚩极业

================================================================================

霹雳布袋戏虚拟人物天蚩极业是《霹雳布袋戏》系列中的反派角色，凶残恶暴、蓝颜怒目的灭境邪灵之首，与爱祸女戎同卵而生并称佛业双身，由黄文择配音。天生与佛对抗的邪灵业障，以打破苦集灭道四境界限、创造六道共处为宗旨，诗号"佛自业障，天蚩极荡"。初登场于《霹雳天启》第47集，退场于《霹雳震寰宇之兵甲龙痕》第1集。曾遭一页书与九界佛皇联手击败，后吸收玄牝之力破茧重生。天蚩极业击杀凤凰鸣、重创罗喉及醉饮黄龙。最终一页书融合十二神天守与八部龙神火余劲，将其与爱祸女戎共同消灭。退场时四境合一宏图随爆炸消散，仅余"灭境邪源，至死方休"之叹。中文名天蚩极业别 名极座、邪灵霸主配 音黄文择性 别男登场作品霹雳天启霹雳震寰宇之刀龙传说霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕组织门派妖世浮屠身 份佛业双身之恶体来 自灭境根据地穷阴迷巢、妖世浮屠种 族邪灵初登场霹雳天启 第47集退 场霹雳震寰宇之兵甲龙痕 第1集角色编剧周郎本尊雕偶师潮州君皇出场集数83集

## 九界佛皇人物战绩

甫登场便击杀灭轮巨擘凤凰鸣；天蚩极业  官方桌布继而逼使九界佛皇自尽结阵困住双身，然在不久之后破阵而出；重创武君罗喉；破黑白双莲合招运出的混沌之力；天雷穹一役轰杀一页书；重创御天五龙之首醉饮黄龙，使后者被妖世浮屠的夔心吸收；利用妖世浮屠几乎将整个死国空间摧毁；败枫岫主人、拂樱斋主；后一页书魂魄入火宅佛狱行以魔锻佛之法提升功力，再假佛皇肉身重生，动用佛皇深修百岁之招“十二神天守”，最后吸收当年抵抗弃天帝所用之八部龙神火在万里狂沙的余劲，再发八部龙神火，两招汇合方破佛业双身。

## 人物配乐

◎妖世灭佛（佛业双身武戏曲）曲/编曲：阿轮天蚩极业收录于《霹雳英雄音乐精选二十三》此曲创作发想源自西洋交响乐曲式。曲中合声唱词分别为：Devastation（蹂躏）、Subversion（覆灭）、Havoc（浩劫）、Death（死亡），以疾走的弦乐组为音乐导引，澎湃定音鼓为主要前奏基础，清脆的三角铁在Death桥段中快速敲击衔接前后情绪，曲中不时出现大钟响主要用来扩充音场的空间感，而人生大合唱则是此曲中最主要的特色。◎妖世浮屠（魔殿场景曲）曲/编曲：吴智晖收录于《霹雳英雄音乐精选二十三》乐曲是由佛教中的“明王”为题材创作，压抑逼迫感的电音与bass衬底，融入肃然气势的东方宗教音乐元素演奏，再加予西方印度民族风的旋律点缀衬托，表现出佛陀的怒化身形。刀龙剧中使用于妖世浮屠的背景音乐。

## 人物结语

多少鸿图大业，多少豪语远望，如今不过两声轻爆，散逝风中。四境合一，六境神劫，飘乱得比漫天血肉更不如，灭境邪源，至死方休。

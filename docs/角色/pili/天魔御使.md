# 天魔御使 (天魔御使)
================================================================================

天魔御使

斬海打破天魔錄封印，於兩界河神祕的異空間內所見到的三名老嫗，魔界玄都始祖之駕前御使，尋天魔血嗣而入江湖，後逢群魔亂世，為護主而先後身亡。

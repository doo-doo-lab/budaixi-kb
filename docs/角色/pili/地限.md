# 地限

道震伏魔崖“太上府”双尊之一，虽外表比师兄天极年长，但相较于天极刚烈心性，地限给人多些温和且怀柔之印象，在太上府内受人敬重，同时也提携后辈不遗余力。明知冲隐无为受异识感染，仍愿多次劝告，给予改过之机会，面对三教的斗争，亦采取以和为贵的作风，不让邪恶势力趁虚而入，颠乱是非。

### 人物经历

前尘

天极与地限乃老君嫡传，是道门之中最不可见的两位前辈，也是实力修为最超凡入圣的两位道仙，开创道镇、建立太上府，威震道界。多年前受云古道渊之主崇玉旨延请镇守伏魔崖，封阻幽都离开冥洞。

天命

尘路终关，为将来开新畴、辟生门，将是其最后之责。天之极、地至限，正是物反道复、齐归大一之时。

入世

冲隐无为受异识感染被发现，遭受围攻之时，降临无上崇真将之带走，并命四衡留守无上崇真。

退场

因封剑主叹希奇谋划伏魔崖封印被破，导致幽都现世，因此不顾功体不全的劣势与天极联手对上叹希奇，遭叹希奇重伤后，不顾伤体仍决意斩邪，与天极联手一招不敌叹希奇剑法自然，重创而死。

主要影响

地限乃是当年开导剑非道之人，对剑非道意义非凡，其之死直接致使剑非道怒然对决叹希奇。

### 人物记录

1、道镇伏魔崖，太上府双尊之一，外表比师兄天极年长，相较于天极刚性心烈，给人温和的印象，明知道道朴受意识感染，仍愿多方劝告，给予改过之机，面临三教门争，亦采取和为贵的方法，不予令九轮天有可乘之机。

2、道经有曰，知人者智，自知者明。胜人者有力，自胜者强。知足者富。强行者有志。不失其所者久。

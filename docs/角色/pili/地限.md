# 地限 (地限)
================================================================================

地限

道震伏魔崖「太上府」雙尊之一，雖外表比師兄天極年長，但相較於天極剛烈心性，地限給人多些溫和且懷柔之印象，在太上府內受人敬重，同時也提攜後輩不遺餘力。明知沖隱無為受異識感染，仍願多次勸告，給予改過之機會，面對三教的鬥爭，亦採取以和為貴的作風，不讓邪惡勢力趁虛而入，顛亂是非。

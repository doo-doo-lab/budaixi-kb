# 万俟焉 (万俟焉)
================================================================================

万俟焉

個性爽快重義氣的先覺角色，功力高深，喜歡隨自己的意願做事，為了收金太極為徒不惜捨棄辛苦鑄造的龍骨聖刀。因紫錦囊之故而在不知不覺中替正道做了不少的事情，受秦假仙的幫忙尋找其師萬燭公，而後為了報殺師之仇而四處追殺一刀起程。

# 任云踪

================================================================================

霹雳布袋戏虚拟人物任云踪，霹雳布袋戏虚拟人物。沉稳飘逸的道门修行者，属于正一天道的分支登道岸，手持无幻笛、身背歧天剑，仙风道骨，气势不怒自威。修行于西山半峰雪，相当照顾灵自灵，并暗中关注天阎魔城的动向，曾出手阻止失路英雄与魔城的交易。其真身为天阎魔城少君“断灭阐提”。

## 五行灵珠人物设计

（摘自霹雳会月刊第190期封面人物——剑真玄影·任云踪）剧情任云踪·封面人物  霹雳会月刊第190期地底魔城的概念是由董事长提出，再由编剧详细设计，魔城现世是一个讯号，代表新一段故事的展开，与魔城有牵连的人物非常多，其中也需要出现与魔城对立的人事物，云鼓雷峰属于佛门，靖沧浪为儒教代表，这时出现一些道教人物也是非常合理的。

天阎魔城所呈现的一种诡异的神怪气氛，正好也可以配合神怪色彩浓厚的正一天道，于是编剧设计分支登道岸，包含一位登道岸中的年轻道长，展开一段道魔交织的仙异灵幻传说。

这位登道岸中的年轻道长，他看起来年轻俊美，辈份虽不高，道术功夫却炉火纯青，十成十的登道岸杰出青年，这样厉害的角色人见人爱，他就是剑真玄影任云踪，不过既然要道魔交织、仙异灵幻，可不是弄弄道法、降妖伏魔就可以皆大欢喜。

要吸引观众目光，就需要冲突与矛盾的事件，以任道长的能力，来对比他背后的故事，最大的冲击点就在于——任云踪其实是魔的化身。

诗号“槐根一梦山河邈，烟雨九原良贱同”。

槐根一梦与南柯一梦同一个典故，某人在槐树下睡着了，梦见自己被槐安国王招为驸马、任南柯郡守，享尽荣华富贵。

九原是墓地的代称，世人无论阶段高低、品格优劣，终将成为烟雨中的坟土。

这两句看起来象是勘破富贵浮云、不做碌碌之人的志气，然而另一层面，则是暗指任云踪与净无幻的关系。

任云踪真身为魔，然而因为与净无幻的感情，让他突破身份藩篱，后来会拜入道门，也是因为担心无幻身后留下的教门危机，于是改头换面加入登道岸，守护这个充满无幻意象的地方。

谁说道魔不两立？

富贵浮云都能看破了，小小的道魔隔阂有何难哉？

人死后终归黄土，是道是魔又有何异？

如此的感情，让任云踪在登道岸待了不知多少年头。

任云踪加入道门内情虽不单纯，但在登道岸面临急难时，任云踪以身犯险，这样的行为不止是基于与无幻的感情，而是与登道岸的同门之谊。

造型任云踪  造型编剧希望任云踪是一位青年才俊，道术高超，以八仙中的韩湘子为参考原型，特征为手持的长笛与飘逸形象。

头冠上这一抹蓝，上有风云刻纹，与任云踪之名相合，为编剧指定设计。

道门人士大多戴冠，从仪容上呈现一种修行规矩、正经的态度。

留一些单独的发丝，吹起风来超帅。

蓝白相间的服装，搭配名字，就是青天高处白云飘之意。

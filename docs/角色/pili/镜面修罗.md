# 镜面修罗

逆海崇帆天谕鸠神练杀手化身，脸戴碎镜面具，手持神兵玄影，专行台面下之暗杀行动，刀艺精湛俐落，更能藉碎镜反射扰人心神，纵使逆海崇帆教内亦鲜有人知。首次现身于永旭之巅，与倦收天小试身手，后配合四令谛夹击，一度让北芳秀腹背受敌。鸠神练天赋聪颖，能借着与对手交手经验，研拟破招克制之法，可惜天生心悸痼疾，注定终败于倦收天名剑之下。

# 鏡面修羅 (镜面修罗)
================================================================================

鏡面修羅

逆海崇帆天諭鳩神練殺手化身，臉戴碎鏡面具，手持神兵玄影，專行檯面下之暗殺行動，刀藝精湛俐落，更能藉碎鏡反射擾人心神，縱使逆海崇帆教內亦鮮有人知。首次現身於永旭之巔，與倦收天小試身手，後配合四令諦夾擊，一度讓北芳秀腹背受敵。鳩神練天賦聰穎，能藉著與對手交手經驗，研擬破招剋制之法，可惜天生心悸痼疾，注定終敗於倦收天名劍之下。

# 武皇

雄才大略的人界枭雄，统辖集境三宫六殿十八楼，心思缜密，具有卓越的领导魅力与政治手腕，与一页书交情匪浅，惟城府深沉、生性多疑且不信任他人，曾大举诛杀昔日功臣以致遭刁七爷与三宫之主秘谋反叛，被困吸功石多年。复出后便开始扫荡叛逆、剪除异己，且怀有极大野心，妄想扩充集境版图、占领苦境武林，却也因为手段残暴无情，以致昔日受害者、甚至好友皆变成对立的敌人…

## 来自百度百科的补充

### 角色经历

寰宇武典半尺剑，乃与百世经纶一页书齐名之高人，囊括世间武学经典于半尺之剑，以此哭遍侠客，故又名'地狱菩萨'。

半尺剑原是集境枭雄武皇于苦境的化身，以武会友而与一页书论交。但当武皇返回集境不久，却遭三宫之主图谋反叛，以毒酒计害偷袭，武皇不得已坐化为吸功石。

期间，玉和殿的灯蝶·修万年，因盗取细胞分离器蓝图遭追缉，遂潜逃至苦境，一手创立天蝶盟，并冒充寰宇武典半尺剑，于一页书平辈论交。

事后，灯蝶潜藏不住终于阴谋浮现，一手策划魔龙八奇于天虎八将之争，连环逼杀素还真、崎路人等正道人士，并暗杀离恶障嫁祸一页书，至此两人关系也正式决裂；直到一页书进入八口山为无形火所杀，化身为天劫·紫锦囊行走江湖，灯蝶之假面具也渐渐暴露，终于在童道为紫锦囊设计，被崎路人以轰天大雷击打出真身，天蝶盟终告瓦解。

后武皇和鬼帝、万魔天指联手攻入苦境，在二重林被一页书以千里碎脑神音（天龙吼）击杀。

### 角色能力补充

◎外形特征：剑身仅有半截，剑柄长度略长于半截剑身，可灌输功力让剑芒无限延伸；玉衡天剑则是一口极为精致的短剑，半驼废所铸，长仅一尺六寸八，护手剑翼如双叉，剑身轻薄短小。

◎登场剧集：霹雳异数第16集（半尺断剑）、霹雳劫第21集（玉衡天剑）

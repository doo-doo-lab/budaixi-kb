# 武皇 (武皇)
================================================================================

武皇

雄才大略的人界枭雄，统辖集境三宫六殿十八楼，心思缜密，具有卓越的领导魅力与政治手腕，与一页书交情匪浅，惟城府深沉、生性多疑且不信任他人，曾大举诛杀昔日功臣以致遭刁七爷与三宫之主秘谋反叛，被困吸功石多年。复出后便开始扫荡叛逆、剪除异己，且怀有极大野心，妄想扩充集境版图、占领苦境武林，却也因为手段残暴无情，以致昔日受害者、甚至好友皆变成对立的敌人…

# 髐易和

霹雳布袋戏虚拟人物髐易和，霹雳布袋戏虚拟人物。苍宇医楼的四名玄医之一，专门骨科学，擅长治疗骨骼之疾，为人狂傲鲁莽、自视甚高，是四医中比较会强出头的人。手持之物名唤巡地斧，平时为医疗用具，亦可为兵器使用。

## 人物能力

- **武器**: 巡地斧武学：龙虎相争削肉剔骨刀式

## 人际关系

- **组织门派**: 苍宇医楼上司：掌悬命同伙：华凤奴、路藏陀、左常坤

## 经历
髐易和为苍宇医楼之人，专供骨科医学，性格狂莽自傲，做事经常强出头，平时手持一把可作为医具也可作为武器的斧头。髐易和跟华凤奴、路藏陀、左常坤四人驻守苍宇医楼，曾研发过克制鬼觉神知的啖魂妖蜂，也曾抓住过鬼觉神知来进行医学手术实验，使鬼觉神知记恨在心。后来，髐易和在医治殊十二时被鬼觉神知抓住，被鬼觉神知报复性杀害。

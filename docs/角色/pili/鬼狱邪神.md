# 鬼狱邪神

================================================================================

霹雳布袋戏中的角色鬼狱邪神，霹雳布袋戏中的角色。鬼狱邪神是死国五尊中的鬼尊，刚猛强悍、霸气十足，是五尊中最忠于天者之人，好战、好斗，性格直爽，也是五尊中唯一与阿修罗关系交好者。他曾在天者欲奉神之子为主时，担起召集其余四方尊者的任务。在阿修罗为换取兵权前去营造万妖炉之际，鬼狱邪神被派去暂代顾守万妖炉，后败于一页书之手，被如是我斩贯穿胸膛，最终投炉身殁。鬼狱邪神是阿修罗在死国唯一能喝酒闲谈的朋友，是败于梵天之手为了保护万妖炉投身祭炉的战士。

## 角色经历
鬼狱邪神鬼狱邪神乃是天者与地者创造死国时，用两人精血凝化的五名尊者之首，奉命镇守于噬血魔道，执掌火之元素，和昔日一统死国三族的阿修罗交情甚笃，当初在死国之神降临时，奉天者命令归降，使他内心对天者十分不满，尤其对毫无战争的日子感觉厌烦，但他仍对天者、地者忠心耿耿，在天者欲奉神之子为主时，担起召集其余四方尊者的任务。

神之子降临时但在却逢妖世浮屠打破空间入侵，鬼狱邪神为免死国遭殃，赶忙招集其他四尊，使出亡炼神击抵御，身受重伤。

正当莫汗走廊即将完工前，鬼狱邪神受天者遣派，和九妖翼姬、黑暗冷爵前往接应，但因为空间变动，使他无法驰援大感焦急，当发觉能量转移至不毛矿坑的忌血之路同样打开死国后，鬼狱邪神为天者玩弄众人，尤其白费阿修罗苦心的措举深表不满。

在阿修罗为换取兵权前去营造万妖炉之际，因为神之子欲招见他，鬼狱邪神被派去暂代他顾守万妖炉，并和阿修罗共饮一番，当阿修罗出发后便用起鬼狱邪火替万妖炉加温，适逢一页书前来欲毁万妖炉，两人之战一触即发，鬼狱邪神败于一页书之手，被如是我斩贯穿胸膛，鬼狱邪神拼上最后尊严投炉身殁。

## 角色关系

组织门派：死国上司：天者、地者朋友：阿修罗鬼狱邪神是死国五尊中唯一与阿修罗关系交好者，也是阿修罗在死国唯一能喝酒闲谈的朋友。同伙：无界尊皇、九妖翼姬、黑暗冷爵、银月贪狼（死国五尊）部署：帝邪天、血魔魑

**鬼獄邪神**為台灣霹靂布袋戲人物，登場於霹靂震寰宇之龍戰八荒第14集，乃天者與地者創造的死國五尊之一，位列五尊之首，為人好戰、好鬥，性格直爽，後在霹靂震寰宇之兵甲龍痕第14集被一頁書擊敗後，投入萬妖爐自絕。

==人物介紹==
鬼獄邪神乃是天者與地者創造死國時，用兩人精血凝化的五名尊者之首，奉命鎮守於噬血魔道，執掌火之元素，和昔日一統死國三族的阿修羅交情甚篤，當初在死國之神降臨時，奉天者命令歸降，使他內心對天者十分不滿，尤其對毫無戰爭的日子感覺厭煩，但他仍對天者、地者忠心耿耿，在天者欲奉神之子為主時，擔起召集其餘四尊的任務。<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI54/14.HTM] 霹靂震寰宇之龍戰八荒第15集</ref>。

神之子降臨時但在卻逢妖世浮屠打破空間入侵，鬼獄邪神為免死國遭殃，趕忙招集其他四尊，使出**亡煉神擊**抵禦，身受重傷。

正當莫汗走廊即將完工前，鬼獄邪神受天者遣派，和九妖翼姬、黑闇冷爵前往接應，但因為空間變動，使他無法馳援大感焦急<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI54/40.HTM] 霹靂震寰宇之龍戰八荒第40集</ref>，當發覺能量轉移至不毛礦坑的忌血之路同樣打開死國後，鬼獄邪神為天者玩弄眾人，尤其白費阿修羅苦心的措舉深表不滿<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/01.HTM] 霹靂震寰宇之兵甲龍痕第1集</ref>。

在阿修羅為換取兵權前去營造萬妖爐之際，因為神之子欲招見他，鬼獄邪神被派去暫代他顧守萬妖爐<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/08.HTM] 霹靂震寰宇之兵甲龍痕第8集</ref>，並和阿修羅共飲一番，當阿修羅出發後便用起鬼獄邪火替萬妖爐加溫，適逢一頁書前來欲毀萬妖爐，兩人之戰一觸即發，鬼獄邪神敗於一頁書之手，被如是我斬貫穿胸膛，鬼獄邪神拼上最後尊嚴投爐身歿。<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/09.HTM] 霹靂震寰宇之兵甲龍痕第9集</ref>。

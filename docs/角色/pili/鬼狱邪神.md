# 鬼狱邪神

霹雳布袋戏中的角色鬼狱邪神，霹雳布袋戏中的角色。鬼狱邪神是死国五尊中的鬼尊，刚猛强悍、霸气十足，是五尊中最忠于天者之人，好战、好斗，性格直爽，也是五尊中唯一与阿修罗关系交好者。他曾在天者欲奉神之子为主时，担起召集其余四方尊者的任务。在阿修罗为换取兵权前去营造万妖炉之际，鬼狱邪神被派去暂代顾守万妖炉，后败于一页书之手，被如是我斩贯穿胸膛，最终投炉身殁。鬼狱邪神是阿修罗在死国唯一能喝酒闲谈的朋友，是败于梵天之手为了保护万妖炉投身祭炉的战士。

## 角色设定

鬼狱邪神名称：鬼狱邪神性别：男身份：死国五尊之一性格：刚猛强悍、霸气十足；好战好斗、性格直爽。是五尊中最忠于天者之人，且是五尊中唯一与阿修罗关系交好者。初登场：霹雳震寰宇之龙战八荒 第14集退场：霹雳震寰宇之兵甲龙痕 第9集（败于一页书后，跳入万妖炉。）来自：死国根据地：噬血魔道

## 角色经历

鬼狱邪神鬼狱邪神乃是天者与地者创造死国时，用两人精血凝化的五名尊者之首，奉命镇守于噬血魔道，执掌火之元素，和昔日一统死国三族的阿修罗交情甚笃，当初在死国之神降临时，奉天者命令归降，使他内心对天者十分不满，尤其对毫无战争的日子感觉厌烦，但他仍对天者、地者忠心耿耿，在天者欲奉神之子为主时，担起召集其余四方尊者的任务。

神之子降临时但在却逢妖世浮屠打破空间入侵，鬼狱邪神为免死国遭殃，赶忙招集其他四尊，使出亡炼神击抵御，身受重伤。

正当莫汗走廊即将完工前，鬼狱邪神受天者遣派，和九妖翼姬、黑暗冷爵前往接应，但因为空间变动，使他无法驰援大感焦急，当发觉能量转移至不毛矿坑的忌血之路同样打开死国后，鬼狱邪神为天者玩弄众人，尤其白费阿修罗苦心的措举深表不满。

在阿修罗为换取兵权前去营造万妖炉之际，因为神之子欲招见他，鬼狱邪神被派去暂代他顾守万妖炉，并和阿修罗共饮一番，当阿修罗出发后便用起鬼狱邪火替万妖炉加温，适逢一页书前来欲毁万妖炉，两人之战一触即发，鬼狱邪神败于一页书之手，被如是我斩贯穿胸膛，鬼狱邪神拼上最后尊严投炉身殁。

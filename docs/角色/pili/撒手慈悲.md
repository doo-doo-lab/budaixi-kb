# 撒手慈悲

================================================================================

霹雳布袋戏虚拟人物撒手慈悲，霹雳布袋戏虚拟人物。来自四魌界慈光之塔内的秀士林，身兼数家之长，精攻刀法与术法，为修练而入苦境执行任务，多番针对枫岫主人。性格混乱矛盾，一方面有着初入江湖的生涩，一方面又具有谋士的深沉，其动向及目的更是让人拿捏不定。

## 经历
撒手慈悲来自四魌界慈光之塔内的秀士林，自称“来自天堂的暴力”，和一羽赐命、拔刀洗慧、辉煌堕世同出自无衣师尹门下。

实力不凡，身兼数家之长，精通刀法和术法。

为追捕楔子---枫岫主人而来到苦境，甫出手便在通往死国的五道玄门内击败少独行，后又夺得枫岫主人之神源，最后积极对付剑之初。

撒手慈悲图册后因无衣师尹来到苦境而转随同驻守濯风山隅，继续执行无衣师尹的策略和命令。

杀符命女、陷害戢武王以及大败魋山魔军等等。

撒手慈悲十分看重老师无衣师尹对他的看法，为此十分敌视一羽赐命，甚至杀害同僚辉煌堕世。

性格傲慢，看不起同出慈光之塔的贫士林中人。

圣魔战争期间，龠胜明峦受六昧童子所惑，圣方军队误入圈套，导致全军覆没。

无衣师尹为救撒手慈悲，断其一臂，更牺牲自己死于槐破梦，方得放生。

在无衣师尹死后，撒手慈悲本受外界影响而蒙尘的淳朴特质复苏，只可惜师尹已经看不到了，可悲可叹。

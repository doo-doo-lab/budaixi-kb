# 隐春秋

================================================================================

霹雳布袋戏虚拟人物隐春秋，霹雳布袋戏虚拟人物。 儒门衔令者，典型的儒教领导性格，孤高冷峻，傲视群伦，一袭玄墨衣著突显身为衔令者的不凡气势，眉宇间散发正气凛然、气度恢弘。隐春秋名字意涵，象征著天下和平时，方是自己隐居之际。因三教本源之争而踏入尘世，对于正义自有坚持，不容邪魔歪道纵恶世间。

**中文名**：隐春秋

**配音**：黄文择（闽南语）、江小北（普通话）

**性别**：男

**登场作品**：霹雳谜城之九轮异谱

**生日**：2015年6月19日

**本尊雕偶师**：刘氏梦凡人物

**编剧**：峤小鹤

**出场集数**：27集

## 经历
很久以前，儒、道、释三个教派的本源都被融汇记载在一本书上，并定期由三教指定的衔令者轮流交替保管。为十佛私吞本源传闻，受冲隐无为邀请，入世调查三教本源之事。

## 人物语录

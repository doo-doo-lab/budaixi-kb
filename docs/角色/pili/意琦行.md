# 绝代天骄（布袋戏剧《霹雳布袋戏》中的人物）

================================================================================

绝代天骄，《霹雳布袋戏》虚拟人物意琦行回到战云界之后，恢复战云界第一战士「绝代天骄」的身份，带领战云双擘对决妖界。但同时体内的天厉意识也逐渐觉醒，进而占据意琦行原本意识，幸三馀、凤座察觉有异设下防护措施，最后在与圣婴主交易下，以意识之刃斩杀天之厉，恢复自我。中文名绝代天骄外文名Tianjiao Marie别 名意琦行，尘外孤标，绝代剑宿，武始通修配 音黄文择、夏治世（台配普通话版）、藤新（普通话：霹雳惊涛）性 别男登场作品霹雳布袋戏武 器澡雪剑、春秋阕化 身意琦行亲 人朝天骄（姐）、御宇天骄（弟）

## 角色设定

- **绝代天骄名称**: 绝代天骄性别：男身份：意琦行身份：战云三骄之一、战云界第一勇士名言：凭吾四字，绝代天骄。初登场：霹雳侠影之轰动武林第6章来自：战云界根据地：战云神宫

## 人际关系

- **挚友**: 绮罗生朋友：绮罗生、一留衣姐姐：朝天骄同伴：朝天骄、御宇天骄(战云三骄)、寰无疆、造烽烟(战云双擘)

## 角色能力

- **武学**: 天殛十式武器：春秋阕

## 角色配乐

战云授阶 (绝代天骄气势回归)曲/编曲：浩旭收录于《霹雳英雄音乐精选四十二》绝代天骄官方桌面浩旭老师2005年作品，磅礴的曲势，稳健的鼓声，呈现一股雄心壮志的气势，营造出战士凯旋而归光荣一幕。乐曲初用于轰动武林第六章，战云神宫，为迎接绝代天骄回归，以战云双擘为首，隆重展开授阶仪式，步在荣耀之端的意琦行，心知人生最光耀的一刻，绝非过往高高在上之刻，而是从悲叹与绝望后再起挑战意志的此时，战云界第一勇士绝代天骄正式回归。

**意琦行**，台灣霹靂布袋戲角色，為武道七修第一人。初登場於霹靂戰元史之動機風雲第24集，尚未退場。

==人物介紹==
**塵外孤標意琦行**，人稱絕代劍宿，乃武道七修第一人，同時也是最強者，性情冷傲脫俗，超然獨處，思想行為不同凡俗的絕代劍宿，在七修中有著「武始通修」之美譽，亦狂亦俠亦超塵。與外聚七修曾在叫喚淵藪之淵頂一戰，該役所使之紅爐點雪劍招，餘勁歷數百年至今未歇，乃意琦行在淵頂所留之警招。

在初次登場時，**意琦行**壓制了被囚禁在通天道中的外七修一人，之後，意琦行前往了叫喚淵藪，救了自淵頂跌落的惡骨，同時對上死後被血傀師控制的尊武封端與沌王非壽，兩人因受邪毒影響，而不識眼前劍宿，而**意琦行**一聲可嘆，同時將兩人爆體，並欲擔下兩人之仇，

後來，**意琦行**遇上了曾闖入淵頂而被紅爐點雪寄招的殘翼之鷹，而當時，血痕將劃成一圈，殘翼也無苟活意念，**意琦行**便讓殘翼在血痕成圈之後，保留全屍；而無故事的人為了殘翼的傷來到叫喚淵藪，卻正逢意琦行返回，兩人瞬間衝突，意境中的對決，**意琦行**澡雪出鞘，讓無故事的人被壓制，而無故事的人將出絕招之時，回到了現實，**意琦行**早已搶先測知對方劍意，立於山壁之上。

動機風雲第二十九集中，為了收回惡鬼三兇之一的鬼手，**意琦行**帶著惡骨來到侯風玄窟，正巧碰見了血傀師，雙方展開決鬥，血傀師策動聖魔之力，使出化身之術對招**意琦行**，同時意境再開，澡雪再出，意境中的劍瞬間重傷血傀師，回到了現實，劍意自血傀師體內衝出，血傀師首度噴血，不甘如此，血傀師瞬間催動五始之劍中的四劍劍氣，重擊**意琦行**，卻見**意琦行**緩緩凝氣，四劍之氣竟爾化散於無，同時血傀師欲逃走之際，紅爐點雪瞬間寄招血傀師身上。

==詩號==
古豈無人，孤標凌雲誰與朋？高塚笑臥，天下澡雪任琦行。

- **其他**: 尊武封端、沌王非壽（二代內七修）

==武學==
紅爐點雪、風雷殘雪、劍意、意殺千里不留行、無心劍

==兵器==

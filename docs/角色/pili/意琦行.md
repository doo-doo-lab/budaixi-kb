# 绝代天骄（布袋戏剧《霹雳布袋戏》中的人物）

绝代天骄，《霹雳布袋戏》虚拟人物意琦行回到战云界之后，恢复战云界第一战士“绝代天骄”的身份，带领战云双擘对决妖界。但同时体内的天厉意识也逐渐觉醒，进而占据意琦行原本意识，幸三余、凤座察觉有异设下防护措施，最后在与圣婴主交易下，以意识之刃斩杀天之厉，恢复自我。

**意琦行**，台湾霹雳布袋戏角色，为武道七修第一人。初登场于霹雳战元史之动机风云第24集，尚未退场。

==人物介绍==
**尘外孤标意琦行**，人称绝代剑宿，乃武道七修第一人，同时也是最强者，性情冷傲脱俗，超然独处，思想行为不同凡俗的绝代剑宿，在七修中有着“武始通修”之美誉，亦狂亦侠亦超尘。与外聚七修曾在叫唤渊薮之渊顶一战，该役所使之红炉点雪剑招，余劲历数百年至今未歇，乃意琦行在渊顶所留之警招。

在初次登场时，**意琦行**压制了被囚禁在通天道中的外七修一人，之后，意琦行前往了叫唤渊薮，救了自渊顶跌落的恶骨，同时对上死后被血傀师控制的尊武封端与沌王非寿，两人因受邪毒影响，而不识眼前剑宿，而**意琦行**一声可叹，同时将两人爆体，并欲担下两人之仇，

后来，**意琦行**遇上了曾闯入渊顶而被红炉点雪寄招的残翼之鹰，而当时，血痕将划成一圈，残翼也无苟活意念，**意琦行**便让残翼在血痕成圈之后，保留全尸；而无故事的人为了残翼的伤来到叫唤渊薮，却正逢意琦行返回，两人瞬间冲突，意境中的对决，**意琦行**澡雪出鞘，让无故事的人被压制，而无故事的人将出绝招之时，回到了现实，**意琦行**早已抢先测知对方剑意，立于山壁之上。

动机风云第二十九集中，为了收回恶鬼三凶之一的鬼手，**意琦行**带着恶骨来到侯风玄窟，正巧碰见了血傀师，双方展开决斗，血傀师策动圣魔之力，使出化身之术对招**意琦行**，同时意境再开，澡雪再出，意境中的剑瞬间重伤血傀师，回到了现实，剑意自血傀师体内冲出，血傀师首度喷血，不甘如此，血傀师瞬间催动五始之剑中的四剑剑气，重击**意琦行**，却见**意琦行**缓缓凝气，四剑之气竟尔化散于无，同时血傀师欲逃走之际，红炉点雪瞬间寄招血傀师身上。

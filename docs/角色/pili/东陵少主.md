# 东陵少主

================================================================================

霹雳布袋戏虚拟人物东陵少主，霹雳布袋戏虚拟人物，初登场于《霹雳英雄榜之争王记》第1集，退场于《霹雳图腾》第16集。曾因七星之事与汗青编产生冲突。一贯理性、冷静的态度，甚至从容应付、扭转情势。擅长观测星象，从满天星子中探得丝丝天机。最终在龙颈坡测算到自己死厄，使用延命术，但仍被悦兰芳埋伏杀死。中文名东陵少主配 音黄文择性 别男登场作品霹雳英雄榜之争王记霹雳图腾星 座双子座身 份五方主星之东青龙根据地梅林、怀拥天地七步阶初登场霹雳英雄榜之争王记 第1集退 场霹雳图腾 第16集角色编剧罗陵本尊雕偶师刘氏出场集数46集

## 角色设定

名称：东陵少主东陵少主性别：男身份：五方主星之东青龙诗号：千古谁堪与伯仲，少时落梅殇，今越红尘亦悠悠；一朝白首望平生，不见东风残；只见九州万里行。初登场：霹雳英雄榜之争王记 第1集退场：霹雳图腾 第16集（死于悦兰芳）根据地：梅林、怀拥天地七步阶

## 角色经历

东陵少主，怀拥天地七步阶之主，个性沉着冷静，擅长观测天象、推断命哩，人品与武功皆属上流之人士，其来历背景不平凡，为五方星主之一的「东青龙」，另一身份则是拥有七星之主命格的候补人选，登场前期未露面即经佾云与莫召奴介绍了。初期，对当时武林第一关键七星之事毫无表达更是选择不于理会，而与假悦兰芳（经天子所扮）一同游历江湖，但实际上自己却与真正的悦兰芳谈论天下大事及武林未来动向，更与悦兰芳自身生命一赌七星之主与汗青编御主谁先现身。到了中期，东陵之前选择不理不睬是为了掩人耳目但私下却营救被追杀的七星，直到路光明出现以及不二刀重伤之后开始在台面上动作，但此举也遭到汗青编的注意而被盯上了。之后，汗青编开始对东陵少主下手更抓走柳依依要胁东陵交出七星图，东陵少主仍然无动于衷，尔后汗青编采取极端手段杀上怀拥天地七步阶，更杀死七星之一的易星苗逢春，东陵少主忍无可忍之下初现绝技一掌击杀幻化上人打伤寒剑月飘霜、穿云豹等人后逃离现场另外布局，但不幸的是智王星路光明随后被汗青编捉走。东陵少主争王记后期，汗青编欲在公开庭上将紫星眉刺青公开，东陵少主为了两个师妹安危事先将七星图交予莫召奴保管后一人独自上公开庭处理刺青之事。公开庭上东陵少主一战汗青编御主，危机之时不二刀义气相助对抗汗青编，后东陵为让悦兰芳生死之谜真相大白而一掌击碎御主华骄，汗青编御主现世但却不是悦兰芳本人而是被亲弟弟经天子谋朝篡位，东陵少主赌约胜出，但经天子不守信用仍要公布刺青图，东陵少主为了其他七星安为下自盖天灵身亡，也让紫星眉与东陵少主师徒关系曝光。实际上东陵少主诈死化明为暗欲阻止七星之主杀害残余七星。后来在云渡山上一页书逼出东陵少主，路光明为证明七星之主是紫星眉自杀身亡，紫星眉吸收智王星星灵而阴谋败露，一页书虽联合东陵少主与病剑叟对抗但还是让紫星眉脱逃。素还真为了对抗七星之主对策联合五方主星到引灵山开启上股七星之主天策真龙陵墓，在天策真龙遗体上紫星眉夺取天策真龙手札却意外被天策真龙借体重生，五方星主掉入陷阱，一页书更被困在天策真龙陵寝里。五方星主的居住地遭到天策真龙大军所占据后在越剑人指引下一同到落叶知秋与驯刀者一同研讨集合四刀四剑对抗天策真龙。之后五方主星劫数来临先是非凡公子自爆身亡后来素还真自爆筋脉，东陵少主也遭到悦兰芳算计与莫召奴决裂退出江湖。东陵少主测算到自己死厄来临而使用延命术，来到龙颈坡上做最后程序但却被悦兰芳埋伏，两人展开一场死战，但因东陵少主身在龙颈坡上真气降低关系无法施出全力而被悦兰芳杀死，首级更被挂在琉璃仙境示威。

## 角色详解

 人物写真摘自霹雳会月刊第68期 人物完全写真---东陵少主背负着许多秘密的东陵少主，其许多神秘的行径和谜样的身世，一直被各方人士猜测是七星之主的头号嫌疑人。可能是个性使然，在东陵少主面对各方压力时，他依旧是保持着一贯冷静理性的态度，不会因此慌了手脚而忘了自己要做什么，也因此魔界、汗青编屡屡针对七星出手，他仍能从容应对甚至扭转局势，他的才能不容忽略。剧情中，柳依依和东陵少主虽是兄妹，但那种暧昧不明的气氛，可以知道的是柳依依对东陵少主怀着一份极为深厚的感情，并对他若即若离、经常将自己放在一旁的态度感到无奈与伤感。柳依依会对东陵少主如此牵肠挂肚，到底是男女之情还是只是手足之爱，也只有东陵少主和柳依依自己心中知道了。

**東陵少主**是台灣霹靂布袋戲的角色，是名外冷內熱的少年隱士，於霹靂英雄榜之爭王記第1集中初次登場，後在霹靂圖騰第16集被御筆丹青悅蘭芳所殺。

==簡介==
懷擁天地七步階之主，個性沉著冷靜，擅長觀測天象、推斷命理，人品與武功皆屬上流之人士，其來歷背景不平凡，為五方星主其中的東青龍；另一身份則是擁有七星之主命格的候補人選，登場前期未露面即經佾雲與莫召奴介紹了。

初期，對當時武林第一關鍵七星之事毫無表達更是選擇不於理會，而與假悅蘭芳(經天子所扮)一同遊歷江湖，但實際上自己卻與真正的悅蘭芳談論天下大事及武林未來動向，更與悅蘭芳自身生命一賭七星之主與汗青編御主誰先現身。

到了中期，東陵之前選擇不理不睬是為了掩人耳目但私下卻營救被追殺的七星，直到路光明出現以及不二刀重傷之後開始在檯面上動作，但此舉也遭到汗青編的注意而被盯上了。

之後，汗青編開始對東陵少主下手更抓走柳依依要脅東陵交出**七星圖**，東陵少主仍然無動於衷，爾後汗青編採取極端手段殺上懷擁天地七步階，更殺死七星之一的易星苗逢春，東陵少主忍無可忍之下初現絕技一掌擊殺幻化上人打傷寒劍月飄霜、穿雲豹等人後逃離現場另外佈局，但不幸的是智王星路光明隨後被汗青編捉走。

爭王記後期，汗青編欲在公開庭上將紫星眉刺青公開，東陵少主為了兩個師妹安危事先將**七星圖**交予莫召奴保管後一人獨自上公開庭處理刺青之事。

公開庭上東陵少主一戰汗青編御主，危機之時不二刀義氣相助對抗汗青編，後東陵為讓悅蘭芳生死之謎真相大白而一掌擊碎御主華轎，汗青編御主現世但卻不是悅蘭芳本人而是被親弟弟經天子謀朝篡位，東陵少主賭約勝出，但經天子不守信用仍要公佈刺青圖，東陵少主為了其他七星安為下自蓋天靈身亡，也讓紫星眉與東陵少主師徒關係曝光。

實際上東陵少主詐死化明為暗欲阻止七星之主殺害殘餘七星。

後來在雲渡山上一頁書逼出東陵少主，路光明為證明七星之主是紫星眉自殺身亡，紫星眉吸收智王星星靈而陰謀敗露，一頁書雖聯合東陵少主與病劍叟對抗但還是讓紫星眉脫逃。

素還真為了對抗七星之主對策聯合五方主星到引靈山開啟上古七星之主天策真龍陵墓，在天策真龍遺體上紫星眉奪取天策真龍手札卻意外被天策真龍借體重生，五方星主掉入陷阱，一頁書更被困在天策真龍陵寢裡。

五方星主的居住地遭到天策真龍大軍所佔據後在越劍人指引下一同到落葉知秋與馴刀者一同研討集合四刀四劍對抗天策真龍。

之後五方主星劫數來臨先是非凡公子自爆身亡、後來是素還真自爆筋脈，而東陵少主遭到悅蘭芳算計與莫召奴決裂退出江湖。

東陵少主測算到自己死厄來臨而使用延命術，來到龍頸坡上做最後程序但卻被悅蘭芳埋伏，兩人展開一場死戰，但因東陵少主身在龍頸坡上真氣降低關係無法施出全力而被悅蘭芳殺死，首級更被掛在琉璃仙境示威。

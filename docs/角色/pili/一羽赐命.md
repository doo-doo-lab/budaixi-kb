# 一羽赐命

================================================================================

霹雳布袋戏中的角色一羽赐命，霹雳布袋戏中的角色，出自慈光之塔秀士林，手持刀弓盗骊，擅长弓射之术。其个性平易谦冲，随和但却不随便，自有一套行事准则与处世圭臬。奉师尹之命与贫士林同伴护送素还真返抵苦境，积极调查剑之初的下落，渴望一竞高下。在后续剧集中，一羽赐命曾于剑之初危难之际引箭相助，后为取得无咎剑招解方而对上昔日同伴辉煌堕世。其经历展现了从执行任务到面临道义抉择的转变。

## 角色设定

- **一羽赐命名称**: 一羽赐命性别：男初登场：霹雳震寰宇之兵甲龙痕第23集退场：霹雳经武纪之枭皇论战第25集（为讨得剑之初的解药而死于𣨼无伤）来自：四魌界出身阶级：慈光之塔·贫士林

## 角色能力

弓箭武学：非天一羽·破神毁战、赦天一羽·破咒动命、忏天一羽·七杀诛灭、玄天一羽·逆天滞时、寥天一羽·黜邪逐生、赩天一羽·万焰同生武器：盗骊弓、七圣箭（非天、赦天、忏天、玄天、寥天、赩天、溯天）◎外形特征：盗骊弓属于长弓，握把以黑布缠绕，上下弓臂各有一独角马头，而尾端皆有锯齿利刃，全弓以紫金色战甲装饰，并镶有紫水晶装饰。七圣箭有各自的颜色：非天为金色箭羽、赦天为紫色箭羽、忏天为白色箭羽、玄天为黑色箭羽、寥天为绿色箭羽、赩天为红色箭羽、溯天未知。除了赦天一羽的箭镞镶金外，其余皆是该箭所属颜色并配上同色水晶。◎登场剧集：霹雳震寰宇之兵甲龙痕 第23集

## 角色经历
一羽赐命出身自慈光之塔的秀士林，手持刀弓盗骊，擅长弓射之术，个性平易谦冲，随和但却不随便，自有一套行事准则与处世圭臬。

奉师尹之命与贫士林同伴护送素还真返抵苦境，积极调查剑之初的下落，渴望一竞高下。

在2011年01月14日的剧集《霹雳经武纪之枭皇论战》之“佛·魔折翼”中，一羽赐命在剑之初危难时引箭上弦介入战局。

在2011年01月28日的剧集《霹雳经武纪之枭皇论战》之“善恶之间”中，一羽赐命为取得无咎剑招解方而对战辉煌堕世，使用七圣箭中的寥天一羽。

后在素还真等人感召下背叛慈光之塔，欲为剑之初寻求解药，最后在向𣨼无伤讨取解药时，先遭墨剑刺心，𣨼无伤给出铁涎，言铁涏可化消伤势，一羽赐命再次横弓，晶箭溯天指向𣨼无伤，𣨼无伤误以为其临死反扑，一剑封喉，不料箭势一转，晶箭溯天将救治的铁涎射往漠沙林方向。

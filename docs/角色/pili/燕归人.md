# 燕归人

霹雳布袋戏虚拟人物燕归人是《霹雳布袋戏》系列中的虚拟人物，初登场于《霹雳兵燹之刀戟戡魔录》，被称为“中原战神”。他力大无穷，是神兵“圣戟神叹”的持有者。曾因痴情长年守护逝去的珠遗公主，后被泊寒波点化，恢复直爽重义的本性，并作为“刀戟”之一，与羽人非獍联手击杀魔头阎魔旱魃。后与断雁西风退隐，在西风死后再度入世，最终在苍云山为阻六祸苍龙而孤身断后，血战后下落不明。是“霹雳F4”中代表夏季的人物。

初期的燕归人长守平水窟，陪伴佳人珠遗公主，殊不知自我精神已陷入痴狂，不愿承认珠遗已死，眼中更无法容下他人骚扰，对一切阻碍者唯有杀，执着痴狂到让人恐惧的地步。

直到泊寒波、断雁西风巧计开导，终于唤回燕归人心志。

恢复本性的燕归人理智且充满正义感，不轻易动武杀人，只求自卫，谈吐更似文质彬彬之君子，一百八十度的转变判若两人，且由于神叹之特性，让燕归人成为刀戟戡魔不二人选。

后因泊寒波之死杠上翳流，甚至击毙军师寰宇奇藏，让翳流元气大伤，事后再与羽人非獍联手诛杀狂龙一声笑，无奈在与鬼梁天下联手斩杀北辰元凰一役，不幸中计被诱入磁心源，圣戟脱手，燕归人重伤被救，得断极悬桥之主尹秋君赠神器“孤问枪”，而圣戟则暗中被阴谋家鬼梁天下所夺，以之和异度魔界女后九祸交易，沦为修补魔界断层之材质。
【丰功伟业】
圣戟神叹乃一组合式兵器，每当燕归人组装圣戟时，会一边吟诵诗号：“飒风沾、问途寒，谁与共饮，谁敢挡关？

燕戟归命人不还！”潇洒霸气之姿，让敌手震撼，也让对手赞叹。

燕归人除了天生神力，战斗中更能冷静分析敌手招数，针对敌手武功特性加以牵制克制，且神叹蕴藏圣气，更是妖魔鬼邪克星，魔族之人一旦被圣戟所伤，沾染圣气，便会造成体内圣、魔二气冲击之苦，无法自行疗愈功体。

此外，就常理而言，持长柄兵器最难防近身速攻，螣邪郎便是抓住此点，以速度和飘忽的身法袭击燕归人，但临敌反应极佳的燕归人却随即转换战术，长柄后滑、往复回旋，“燕复还”一招顿时化守为攻，卯地一击拉开双方距离，再度发挥圣戟一寸长、一寸强之特色。

官方桌布为探圣戟之能，练峨眉也曾亲试圣戟之威，燕归人利用圣戟刚中有韧之特性，七分接、三分化，借力转力巧妙化去练峨眉沛然罡气，然练峨眉掌力浑厚，燕归人圣戟一转，“燕去燕返”竟生双重力量回击，大地为之一动，也让练峨眉刮目相看。

期间，异度魔界曾利用断雁西风性命威胁燕归人，以致圣戟一度落入魔界之手，最后在正道巧设妙局与狂龙一声笑反叛下，顺利促成刀戟戡魔之局。

啸阳谷一役，刀戟首度联手，可说是速度与力量的结合，燕归人神力之悍，刚猛一戟硬生生让魔君陷落地层，在两人极佳的默契配合下，羽人非獍采速攻先行一刀刺中魔君胸口，随后燕归人一戟贯穿魔君心槽，刀戟戡魔遂告功成。

北辰元凰为夺取锐感之缨，谋划刀戟斩龙，继刀戟戡魔后，圣戟神刀再度联手，重创狂龙。

## 人物影响

燕归人被誉为“中原战神”，是“霹雳F4”组合中代表“夏”的成员，拥有“神力再催”的技能，战斗意志无尽，具有遇强则强的特点。其经典台词为“曾经，我找寻活下去的意义，我得到过，我失去过，现在，这已经不重要……”。

## 他人评价

靛羽风莲：“戡魔一役，让燕归人名动江湖，更曾为了救人，孤身深入翳流万军之中，是一名武勇兼备的侠客。他难缠的地方，不止是他对力量的操控自如，尚有他面对敌手的无穷战意。”苍：“面临强敌仍不倒下的意志么？”靛羽风莲：“这一点，翳流曾付出惨痛的代价。”苍：“这样的人物，为何会成为长生殿的助力？”靛羽风莲：“听说他曾经被羽人非獍送入长生殿疗伤，也许遭受了控制。”苍：“一名善用力量的武者，速度与技巧是破解的方式。”靛羽风莲：“长生殿舍去哭麻衣，利用地形和术法，让燕归人把守最后的关卡，可见对他有十足的信心，这份信心，必是来自控制他的术法，而且长生殿也深信，术法与燕归人之间的配合是无懈可击的。”

# 六芒天螭 (六芒天螭)
================================================================================

六芒天螭

六芒天螭為妖漫地獄有史以來唯一一隻有成功越過天地一席的爬族。修為高強能與紫澤分庭抗禮，認為爬族不比龍族弱，昔時遭到紫澤算計封印於斜山五吋天，在黑暗勢力的操作下，以和合轉生再度降臨人間。

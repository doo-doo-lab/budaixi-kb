# 六芒天螭
================================================================================

六芒天螭

六芒天螭为妖漫地狱有史以来唯一一只有成功越过天地一席的爬族。修为高强能与紫泽分庭抗礼，认为爬族不比龙族弱，昔时遭到紫泽算计封印于斜山五吋天，在黑暗势力的操作下，以和合转生再度降临人间。

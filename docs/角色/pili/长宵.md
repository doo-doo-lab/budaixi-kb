# 長宵 (长宵)
================================================================================

長宵

六世花王的守花三御之一，性格沉默少言，金樹族後人，平時為冥界金樹型態，戰鬥時會化為樹人型態，破壞力極強。與妹妹追惜為雙生樹。為了恩情留於花凋族，誓死追隨六世花王。

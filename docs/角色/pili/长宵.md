# 长宵

六世花王的守花三御之一，性格沉默少言，金树族后人，平时为冥界金树型态，战斗时会化为树人型态，破坏力极强。与妹妹追惜为双生树。为了恩情留于花凋族，誓死追随六世花王。

## 来自百度百科的补充

武学：裂缺冥狱击、冥轮轰雷击、裂缺冥狱斩

守花三御为花王座下三大将，三生雪擅长攻击、长宵攻守兼具、兰镶玉笔术法见长以为重要谋士，三人对花王忠心耿耿协力对抗魔界，然因身世来历有了截然不同的命运。

守花三御之一，金树族人，木讷粗犷、沉默不语的强悍战将，一登场就面对魔师傲神州，强大的攻击与防御能力，让傲神州一时也难以取胜。长宵能将树枝化为刺，如飞箭射击，使出的劲拳夹带金雷阵阵，摧山倒岳，盾甲坚硬无匹，傲神州之剑也难伤分毫。

长宵在金树族中，原本为一双生树，即是两株植物相依结合一起生长，看起来像是有两支树干，一为长宵为兄，一为妹妹追惜。曾经，金树族的根据地发生大火，无数金树族人遭逢劫难，全族几乎付之一炬，而兄妹双生树被一神秘高手以兵刃砍成两半，长宵与追惜就此分开。虽然长宵总是沉默，但是思念妹妹的深厚亲情一直藏在心中，这份思念最终化为实体，在长宵变回金树时，当年的幼小妹妹追惜化现，追惜与六世花王末世之艳亲近，甚得花王疼惜。

彪悍的长宵，攻守兼具，唯一的弱点就是火魔半天焱的魔火，克命难解，在是非河，为白无垢之死，魔界与花凋族大战，长宵再次与半天焱对决，长宵事先暗藏三生雪凌霜千仞的寒气，一度避开魔火攻势，击伤半天焱，减低了魔火的杀伤力，但花凋谜境大洪水，为保护族民，长宵化为金树阻挡水流，力战的勇士，在洪水中苦苦支撑，再被星野残红魔刀斩断，兄妹再一次的分离，追惜落水失踪。

被毁的家园、再度失去的亲人，负伤的长宵还会遇到什么样的困境？当年的神秘高手究竟是谁，金树族的大火从何而来？种种谜团如何解开呢？

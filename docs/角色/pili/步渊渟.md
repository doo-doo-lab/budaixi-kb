# 步渊渟

霹雳布袋戏虚拟人物步渊渟，霹雳布袋戏虚拟人物。论剑海主席，沈稳有度，善拢络人心，经营论剑海多年，以评选排名众家剑谱为号召，鼓励剑客精进淬炼，表面立意良善，实则暗藏目的。论剑海之内，也因为每届的评剑会，累积众多名家剑法，步渊渟从中习得各家之长，集剑法之大成。同时也在台面下暗植势力，拉拢曾参与评剑会的不凡剑者，以助永生壁中的双蛹脱困，与天地虻共同策画让三阳同天，造就永生不死的世界。

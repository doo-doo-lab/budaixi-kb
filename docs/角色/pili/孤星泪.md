# 孤星淚 (孤星泪)
================================================================================

孤星淚

槍界中最神秘的百步銀邪槍，有槍中弒神之稱。年幼時曾經歷過極端慘事，以致心性孤寂、離群索居，總是於滿木枯黃的落葉紛飛中現身，沉默不語，散發出蕭瑟、悲愴氣息。幼年時曾為邪天子所救，兩人也因此建立了深厚友情。

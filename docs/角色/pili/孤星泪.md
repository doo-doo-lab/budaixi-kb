# 孤星泪

枪界中最神秘的百步银邪枪，有枪中弑神之称。年幼时曾经历过极端惨事，以致心性孤寂、离群索居，总是于满木枯黄的落叶纷飞中现身，沉默不语，散发出萧瑟、悲怆气息。幼年时曾为邪天子所救，两人也因此建立了深厚友情。

## 人物经历

孤星泪之父寒武纪，原是精灵天下錻锽玄脉之主，世袭錻锽之名，曾在精幽大战之时与天织主联手对抗幽界原始魔君。精幽之战后寒武纪遭遇夸幻之父，重伤之余，诸神之缨、《玉玺之命》枪谱接连失落，落入夸幻之父之手；爱妻灵后为保护孤星泪自我牺牲，引动同归秘法阻止夸幻之父。寒武纪带着孤星泪前往苦境，夸幻之父不知何故中断追踪。寒武纪将帝诏隐藏在问天道，并改换身份，化身玄域天枢，建立天枢世家，称霸枪界，成为初代天子枪。后来，玄域天枢的真实身份引起枪界高层怀疑，天枢世家更接连发生血案，对方的动作越趋极端，为防万一，写下《天枢手记》，并将孤星泪送往隐秘之处，寄望他来日能长大成人，继承帝诏，与之共鸣，使錻锽血脉再续辉煌。孤星泪因年幼时曾历过极端惨事，以致心性孤寂、离群索居，曾为紫烨疾邪（邪天子）所救，两人也因此建立了深厚友情。孤星泪苦练邪枪，并因此身中虹纹天香邪毒，险些丧命，幸得华鹊以续命丹相救，但也导致一身剧毒。后终通过百邪关的考验，获得百步银邪枪。与邪天子交手时将其误伤，致使邪天子性情剧变，成为两人一生的遗憾。总是于满木枯黄的落叶纷飞中现身，沉默不语，散发出萧瑟、悲怆气息。孤星泪 官方桌布邪天子遭玉梁皇算计，向孤星泪送出的信函遭截，使孤星泪并未到达天扇十字峰，导致邪天子死于倦收天与原无乡联手。玉梁皇更以无缝天丝修补邪天子尸身，再以天子枪法（玉玺禁章）创造伤痕，嫁祸红尘雪与生命练习生。孤星泪击败生命练习生后发现兵器有误，察觉有诈。后救出被玉梁皇击伤的红尘雪，更前往武都玉嵎击杀御宇皇朝上万大军，击败玉梁皇，夺回帝诏·阙九重归还红尘雪。在华芷姐弟坟前遇见被地冥复活的紫烨疾邪，两人一起搭档，之后在天证龙战结识锋魔剑上缺之女剑琅琊，帮助邪天子追求剑琅琊并与其成为朋友，寻找剑琅琊父亲当年疯狂的真相，得知剑上缺乃是因为屠龙圣战而受到八歧邪神影响。后来紫烨疾邪为保护孤星泪而力战身亡，孤星泪受故友之托，继续和剑琅琊一起行动并保护对方。剑琅琊被鬼麒主所伤而昏迷不醒，剑上缺又在和鬼麒主谈判中被算计而无法行动，孤星泪为保护剑琅琊独自杀出生路，却被天邪八部众的鸑变迦罗与暗禘合击打落悬崖，剑琅琊亦被九婴派人带走。后来，在天迹联合生命练习生、地冥对上神愆的终战中，从天堂之门内射出帝诏枪劲、鹰隼刀风和菩提剑气攻击神愆，加上天迹所言“我三个冤亲债主终于都到齐了”，由此可见，孤星泪已经以某种形式进入到了天堂之门内。

## 人物配乐

孤星泪（孤星泪角色曲）曲/编曲：吕怡青收录于《霹雳狼烟之古原争霸剧集原声带贰-精选61》吕怡青老师作品。乐曲选用于枪中弑神「孤星泪」一角，于古原争霸第三十九章中初露剪影。孤星泪乃枪界异数，悲剧色彩甚为浓重的角色，出场时伴随着乐曲响起，现场顿时变成枯黄色调，四周落叶纷飞，十足的萧瑟惆怅。枪中弑神（孤星泪武曲）孤星泪曲/编曲：丁天牧收录于《霹雳天命之仙魔鏖锋剧集原声带-精选62》丁天牧老师2016年作品。此曲设定为孤星泪武戏配乐，强调百步银邪的快、狠、准，烘托出孤星泪“枪中弑神”的威名与气势。天泣悲鸣（孤星泪悲壮曲）曲/编曲：张卫帆收录于《霹雳天命之仙魔鏖锋剧集原声带贰-精选63》张卫帆老师2016年作品。乐曲以小号呈现出战士的孤独，军鼓则是刻画出勇往直前每一步的路途艰辛，乐曲中段使用了一小段苏格兰风笛，谱出一种异族武士在天宽地阔的世界中昂然而立的孤傲。曲调诉说着孤星泪一路悲苦的经历，面对无法拯救所珍视的人、只能恨苍天无情的感叹，回荡的凄凉人声和节奏声打入心坎，让人听之能感同身受，无语的悲怆情境。

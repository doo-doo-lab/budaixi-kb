# 魔剑道（《霹雳布袋戏》系列剧中登场组织）

================================================================================

魔剑道是《霹雳布袋戏》系列中源自西漠的魔族政权，由魔皇诛天出走魔界后集结西漠高手创立，以剑术为核心战力，构建起总坛-悲鸣殿-魔阎殿-恶魔岩的四级统治体系。

组织架构包含左右邪剑双护法、三旗六将主力军团、三阴九阳十二祭司操控术法，统率十七万魔魇大军及异法祭司，配属恶灵鬼谷等编外势力，持欲界第六天之波旬剑为镇国神器。

该政权通过灭西疆王朝、夺取神剑崛起，恶魔岩据点司权率先锋部队首开战端，魔阎殿鬼王棺继任后执行剿灭遗孤与渗透中原战略，悲鸣殿七大灵首则正式向天策真龙势力宣战。

魔皇诛天与妖后联姻诞下黑衣剑少，收养白衣剑少传承剑术，同时通过寒月江和约与中原形成短暂对峙。

然内部权力倾轧导致诛天意外身亡，黑衣剑少继位后被迫兼领妖刀界，促成两大组织合并，而幕后黑手策谋略的持续运作最终引发全面内乱。

# 魔剑道（《霹雳布袋戏》系列剧中登场组织）

魔剑道是《霹雳布袋戏》系列中源自西漠的魔族政权，由魔皇诛天出走魔界后集结西漠高手创立，以剑术为核心战力，构建起总坛-悲鸣殿-魔阎殿-恶魔岩的四级统治体系。

组织架构包含左右邪剑双护法、三旗六将主力军团、三阴九阳十二祭司操控术法，统率十七万魔魇大军及异法祭司，配属恶灵鬼谷等编外势力，持欲界第六天之波旬剑为镇国神器。

该政权通过灭西疆王朝、夺取神剑崛起，恶魔岩据点司权率先锋部队首开战端，魔阎殿鬼王棺继任后执行剿灭遗孤与渗透中原战略，悲鸣殿七大灵首则正式向天策真龙势力宣战。

魔皇诛天与妖后联姻诞下黑衣剑少，收养白衣剑少传承剑术，同时通过寒月江和约与中原形成短暂对峙。

然内部权力倾轧导致诛天意外身亡，黑衣剑少继位后被迫兼领妖刀界，促成两大组织合并，而幕后黑手策谋略的持续运作最终引发全面内乱。

## 组织特色

辖区：总坛、首锋殿、恶魔岩、魔阎殿、悲鸣殿、乾坤陵、血骨枯林、太子殿、少子殿

交通：中西交界以圣灵界线为分隔。

专长：以剑为尊，组织之人皆擅长剑术，更有代表诠释兵力的两口魔剑－祭魔剑、波旬剑。

特色：魔剑道成员各个骁勇好战、忠贞不二，视命令为最高宗旨。

## 组织历史

上古时期，魔界混乱，魔界之主天魔为整合魔族而设下天魔录封印，不认同此决定的魔族中人不是纷纷出走就是逐一退隐，诛天与魔流剑风之痕便是其一。

魔流剑风之痕来至西漠一带，延揽聚集当地的用剑高手，以魔剑道命名，诛天也为首领之一（废案设定，正剧中魔剑道的建立与风之痕无关）。诛天遇上两名影响其一生的关键人物，一是毕生劲敌天策真龙，二是助其霸业的策谋略。诛天本就具有皇者雄心，听取策谋略的建言后积极展开霸业，诛天拜托好友魔流剑风之痕取波旬之剑，以为镇教，为魔剑道开疆拓土，收留西漠穷凶恶极之徒，打下魔剑道今日基业，成为西漠一股最强大的力量；后来，为增强自身实力，诛天更拜霸王横千秋为师学习狂魔枪法。

十八年前，诛天与妖刀界的妖后政治联姻，但婚礼上诛天对妖后的好友花姬一见钟情，妖后与之决裂。诛天取得妖后所生之子黑衣剑少十八年的抚养权，后来诛天又得一孤儿，见其为可造之材便将之收养为义子，此儿便是日后的白衣剑少。之后诛天便将年幼的黑白双少送至风之痕处学习剑法，以日后增强组织战力。

在西漠一带，被魔剑道视为眼中钉的不外乎是西疆皇朝，在听闻皇朝拥有强大的“神剑”后，诛天派出左邪剑邪神前往夺之，不过却被西疆皇朝的驸马爷穷八极击退，魔剑道因此沉寂了一段时间。这段时间，诛天除增强战力外，更野心贪婪中原版图，一方面派左邪剑到中原探查，另一方面持续监视西疆皇朝神剑动态。因神剑之故而处变不惊的西疆皇朝却不料神剑后来被西疆皇朝的公主所窃，带离西漠，得知此消息的魔剑道伙同汗青编进攻，西疆皇朝自此成为历史名词，魔剑道也一统西漠。尽管如此，魔剑道先前派出的左邪剑却因消息走漏，遭佾云等十方武者围攻，被封印于近日峰下，毫无消息传回；加上神剑情况不明，使得魔剑道只能延宕计划。

邪神破封后，因为个人复仇而并未立即回转组织，死后身躯被司马剑秋利用，以神剑引发各方争夺战，魔剑道怕神剑威胁魔剑道，故派前线据点恶魔岩负责抢夺神剑。但派出的吾无名铩羽而归，尽管后来再派主将甚至倾全力前往争夺，结果仍是相同，后更招致毒蝎女的攻击，恶魔岩全数被剧毒歼灭，魔剑道也迅速转移任务，交由魔阎殿负责，为首的鬼王棺成功地捉住持有神剑的孤迹苍狼，将神剑扔入恶水坑不见天日。另外，魔剑道总坛针对魔界，派出白衣剑少和黑衣剑少，成功刺杀魔界两位大将魔魁和龙王鱽，使魔界式微。

魔界、西疆皇朝、神剑的事都解决圆满，原本魔剑道欲挥师中原，却不料此时劲敌天策真龙复生，魔剑道便转移战略，助正道对付天策真龙，一面派出黑白双少劫走不二刀阻止七星归一，另一面派另一据点的悲鸣殿促成四刀四剑屠龙。谁知天策真龙竟击败四刀四剑并收服正道人士，打乱了魔剑道的步调，只能先行退兵。

当时武林局势已然是魔剑道和天策大军的对立，天策真龙苦恼于来势汹汹的魔魇大军，诛天也明白日后多苦战而求助风之痕。黑衣剑少曾深入刺杀天策真龙，连累白衣剑少被擒，双方相约在九九登天台交换人质，不过却因诛天的计策而展开大战，天策真龙兵败如山倒，后因部下拼死护主而使天策真龙逃过一劫。后来，天策真龙在万里江一战扳回一城，魔剑道决定以诈败的拔营退兵之计引天策大军入坑，天策真龙果真中计而率军追杀，在天绝峡道死伤惨重，就在诛天要给天策真龙致命一击时却被意外六星入体的天策真龙击退，魔剑道大军也被天策真龙一击击溃，诛天见时机已失只能撤兵。

魔剑道战败而归后，诛天下令重整兵力，并与出关的策谋略商讨对策。策谋略表示六星入体的天策真龙被仁心阻碍，已不具威胁，并指点诛天下一步行动。此时正逢花姬再开琼华宴，诛天受邀，并在会上强调只有风之痕和独孤遗恨能杀自己，而此言自然是先前与策谋略同步的计谋，但并非是为了魔剑道的未来，而是策谋略本身的霸业。

不久，天策真龙主动找诛天谈判并定下和平条约，获得半年的短暂和平。妖后与策谋略一明一暗。策谋略负责消灭沙舟一字师来重新唤醒魔魇，试探除掉忆秋年和风之痕的方法，派一雨愁用佛法消磨天策真龙的斗志，擒下悦兰芳让他以定风愁的身份行走武林，误导众人认为定风愁是素还真化身。妖后方面，让黑衣继承魔剑道大权，妖刀魔剑合一进攻中原，照世明灯和屈世途投降，于是大王朝诞生了，囊括中原、魔界、东西南北武林、北域、西漠等。

当初诛天则伙同策谋略，与妖后商议黑衣剑少抚养权的归属，诛天本以为一切尽在掌握中，却如何也料不到策谋略的野心和妖后意外的一刀，诛天的首级被悬挂在公开亭。而黑衣剑少则不知道父亲死因，策谋略想成就龙图霸业，统治魔界和中原的妖后就成了绊脚石，何况自己的人皮在妖后手中，于是将诛天之死的真相告知黑衣，导致黑衣与妖后翻脸分裂。

## 结局

诛天死于妖后，策谋略死于妖后和权妃，邪神死于正道、魔界、云门、半花容围攻，鬼王棺把魔剑道斩草除根，组织覆灭，黑白双少投身正道。

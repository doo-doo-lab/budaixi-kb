# 爱祸女戎

================================================================================

霹雳布袋戏虚拟人物爱祸女戎是《霹雳布袋戏》系列中的虚拟人物，灭境邪灵，佛业双身女体，初登场于《霹雳天启》第47集，退场于《霹雳震寰宇之兵甲龙痕》第1集。

其诗号为“爱本祸劫，遍地女戎”，主张通过“四境合一”打破境界限制，推行“六道无界”理念，意图建立人妖邪魔共处的世界。

爱祸女戎与天蚩极业共掌邪灵势力，以“爱即祸”邪说创立思想体系，认为人间之爱需通过祸劫淬炼。

曾与九界佛皇论道时施展邪术使其陷入幻境，后与一页书展开佛魔辨法。

在与双佛（一页书、九界佛皇）决战中，爱祸女戎使用“三千爱火盛罗幔”等招式，最终佛业双身并流合招失败遭重创。

角色造型以红色华服搭配高叉裙摆，角色曲《女戎》及武戏曲《祸水吞天》分别收录于《霹雳英雄音乐精选二十三》《霹雳英雄音乐精选二十四》。

- **女戎的独有特色是妩媚、邪气且有着无比的感染力！

其实没啥意思的（羞）……因为编剧有提到她是佛业双身之一，带有点印度神佛的味道，所以在录音当时就想唱个「类似梵文的呢喃」，细毛就这么长出来了，值得一提的是……在唱「细毛」这部分时，请歌手搭个3579度的音层来营造神秘感，也辛苦了歌手说。◎祸水吞天（爱祸女戎武戏曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选二十四》

**愛禍女戎**，霹靂角色。

佛業雙身之女體，來自滅境地下，窮陰迷巢中的巨繭之中，姿態撩人，精通各家學說，扭曲成一套「愛即禍」的偏激言論，說話時會有一股無形的感染力，與天蚩極業兩人以四境合一，人妖魔邪共存的創神大業為目的，血洗中原武林，造成正道死傷無數。

自巨繭破出之後，**愛禍女戎**先行上鹿苑與九界佛皇論道便，論道失利，**女戎**卻是長喝，天蚩極業現身，兩人合攻，佛皇不敵，重傷奔回鹿苑一乘，愛禍女戎與天蚩極業隨之追趕至鹿苑逼殺，破匣求禪、藥如來浪生、答非、所問四人聯手仍被**愛禍女戎**以及天蚩極業重創，就算葉小釵與萬古長空出面幫忙，仍是無法佔上風，雙方決鬥，佛業雙身察覺鹿苑頂端佛光大放，佛業雙身衝入鹿苑最頂端，不料卻是九界佛皇犧牲自我，形成百燈聯戒，將佛業雙身困於其中。

刀龍後期，在問天敵推波助瀾之下，百燈聯戒之局，就要破解，素還真等，利用佛頂冥塔殺除佛業雙身，不料佛業雙身反而吸收佛頂冥塔之力，產生莫大威能，整個鹿苑為之摧毀，佛業雙身以及十一天禁強勢壓境，素還真等陷入頹勢，卻被羅喉所救；之後，愛禍女戎上天都與羅喉談出條件，答應幫助佛業雙身將苦滅兩境合一，在苦滅兩境合一之上，羅喉反遭佛業雙身將壓力全數竄入其身，佛業雙身藉此保留體力，並威壓素還真與千葉傳奇，千葉傳奇更被妖世浮屠之中詭異佛氣所吸收，中原再少助力。為了除去佛業雙身，刀無極向楓岫主人借取影神刀，與羅喉合作欲殺佛業雙身，高崖之上，女戎對上刀無極，渾不在意的纏鬥，最後卻因羅喉重創不了了之。

後女戎更設局讓千葉傳奇與素還真互相殘殺，但千葉傳奇卻是假裝被邪化，雙蓮對上佛業雙身，卻聞百世經綸一頁書重現塵寰，天蚩極業對上一頁書；**愛禍女戎**對上雙蓮，在素還真使出天問三誓，女戎竟讓天蚩分出功力，雙蓮頓時受創，但妖世浮屠重創，佛業雙身即刻喊退。

之後**愛禍女戎**親上雲渡山，與一頁書論道，一頁書開出賭約，滅度三宗、三教頂峰對決，以越行石、如來聖像為賭注，最後卻在一頁書暗助之下，由疏樓龍宿勝出，**女戎**隨即喊殺，創傷一頁書，並讓無執相奪走越行石，但卻是噟品。

元果之力為禍，貫穿妖世浮屠基座，**女戎**以邪靈填補，天蚩極業撐住妖塔，讓其不倒，再由無執相帶回陰月石，妖世浮屠基座恢復。

在此期間，楓岫主人開出以素還真之死換取與雙身合作的機會，**女戎**允准，滅度三宗將素還真逼入葬龍壁中，玉石俱焚，從此消失，雙身大業在少大患。

為阻止元果之力，女戎與十一天禁於九荒野上攔截元果之力，卻因為越行石飛入，打亂僵局，但卻也緩得推進時間，之後女戎與天蚩極業叩關火宅佛獄，將佛獄三名使者放出，而元果之力突破三宗防線，直衝妖世浮屠，兩人本欲聯手抵擋，佛獄使者卻出現將元果之力吸收……。

而之後佛業雙身得知越行石在一頁書身上，佛業雙身會同三宗、四大天禁殺上雲渡山，佛業雙身聯手默契無間，一頁書示弱敗退，將佛業雙身引至天雷穹，欲以越行石吸取天雷之力殺佛業雙身，但越行石是噟品，一頁書反而被重創，爆體身亡。

佛業雙身旋即找上佛獄使者，要其不讓元果之力再衝擊妖塔，使者開出殺楓岫主人的條件，天蚩極業與**女戎**理念首度分歧，最後**女戎**拖延，楓岫主人完成修補妖塔的責任。**女戎**也漸對楓岫產生好感

幾番波折，妖世浮屠終於修補完畢，佛業雙身再度合力，準備讓苦集合一。

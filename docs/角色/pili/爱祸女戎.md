# 爱祸女戎

================================================================================

霹雳布袋戏虚拟人物爱祸女戎是《霹雳布袋戏》系列中的虚拟人物，灭境邪灵，佛业双身女体，初登场于《霹雳天启》第47集，退场于《霹雳震寰宇之兵甲龙痕》第1集。

其诗号为“爱本祸劫，遍地女戎”，主张通过“四境合一”打破境界限制，推行“六道无界”理念，意图建立人妖邪魔共处的世界。

爱祸女戎与天蚩极业共掌邪灵势力，以“爱即祸”邪说创立思想体系，认为人间之爱需通过祸劫淬炼。

曾与九界佛皇论道时施展邪术使其陷入幻境，后与一页书展开佛魔辨法。

在与双佛（一页书、九界佛皇）决战中，爱祸女戎使用“三千爱火盛罗幔”等招式，最终佛业双身并流合招失败遭重创。

角色造型以红色华服搭配高叉裙摆，角色曲《女戎》及武戏曲《祸水吞天》分别收录于《霹雳英雄音乐精选二十三》《霹雳英雄音乐精选二十四》。

- **女戎的独有特色是妩媚、邪气且有着无比的感染力！

其实没啥意思的（羞）……因为编剧有提到她是佛业双身之一，带有点印度神佛的味道，所以在录音当时就想唱个“类似梵文的呢喃”，细毛就这么长出来了，值得一提的是……在唱“细毛”这部分时，请歌手搭个3579度的音层来营造神秘感，也辛苦了歌手说。◎祸水吞天（爱祸女戎武戏曲）曲/编曲：孙敬凡** — 《霹雳英雄音乐精选二十四》

**爱祸女戎**，霹雳角色。

佛业双身之女体，来自灭境地下，穷阴迷巢中的巨茧之中，姿态撩人，精通各家学说，扭曲成一套“爱即祸”的偏激言论，说话时会有一股无形的感染力，与天蚩极业两人以四境合一，人妖魔邪共存的创神大业为目的，血洗中原武林，造成正道死伤无数。

自巨茧破出之后，**爱祸女戎**先行上鹿苑与九界佛皇论道便，论道失利，**女戎**却是长喝，天蚩极业现身，两人合攻，佛皇不敌，重伤奔回鹿苑一乘，爱祸女戎与天蚩极业随之追赶至鹿苑逼杀，破匣求禅、药如来浪生、答非、所问四人联手仍被**爱祸女戎**以及天蚩极业重创，就算叶小钗与万古长空出面帮忙，仍是无法占上风，双方决斗，佛业双身察觉鹿苑顶端佛光大放，佛业双身冲入鹿苑最顶端，不料却是九界佛皇牺牲自我，形成百灯联戒，将佛业双身困于其中。

刀龙后期，在问天敌推波助澜之下，百灯联戒之局，就要破解，素还真等，利用佛顶冥塔杀除佛业双身，不料佛业双身反而吸收佛顶冥塔之力，产生莫大威能，整个鹿苑为之摧毁，佛业双身以及十一天禁强势压境，素还真等陷入颓势，却被罗喉所救；之后，爱祸女戎上天都与罗喉谈出条件，答应帮助佛业双身将苦灭两境合一，在苦灭两境合一之上，罗喉反遭佛业双身将压力全数窜入其身，佛业双身借此保留体力，并威压素还真与千叶传奇，千叶传奇更被妖世浮屠之中诡异佛气所吸收，中原再少助力。为了除去佛业双身，刀无极向枫岫主人借取影神刀，与罗喉合作欲杀佛业双身，高崖之上，女戎对上刀无极，浑不在意的缠斗，最后却因罗喉重创不了了之。

后女戎更设局让千叶传奇与素还真互相残杀，但千叶传奇却是假装被邪化，双莲对上佛业双身，却闻百世经纶一页书重现尘寰，天蚩极业对上一页书；**爱祸女戎**对上双莲，在素还真使出天问三誓，女戎竟让天蚩分出功力，双莲顿时受创，但妖世浮屠重创，佛业双身即刻喊退。

之后**爱祸女戎**亲上云渡山，与一页书论道，一页书开出赌约，灭度三宗、三教顶峰对决，以越行石、如来圣像为赌注，最后却在一页书暗助之下，由疏楼龙宿胜出，**女戎**随即喊杀，创伤一页书，并让无执相夺走越行石，但却是噟品。

元果之力为祸，贯穿妖世浮屠基座，**女戎**以邪灵填补，天蚩极业撑住妖塔，让其不倒，再由无执相带回阴月石，妖世浮屠基座恢复。

在此期间，枫岫主人开出以素还真之死换取与双身合作的机会，**女戎**允准，灭度三宗将素还真逼入葬龙壁中，玉石俱焚，从此消失，双身大业在少大患。

为阻止元果之力，女戎与十一天禁于九荒野上拦截元果之力，却因为越行石飞入，打乱僵局，但却也缓得推进时间，之后女戎与天蚩极业叩关火宅佛狱，将佛狱三名使者放出，而元果之力突破三宗防线，直冲妖世浮屠，两人本欲联手抵挡，佛狱使者却出现将元果之力吸收……。

而之后佛业双身得知越行石在一页书身上，佛业双身会同三宗、四大天禁杀上云渡山，佛业双身联手默契无间，一页书示弱败退，将佛业双身引至天雷穹，欲以越行石吸取天雷之力杀佛业双身，但越行石是噟品，一页书反而被重创，爆体身亡。

佛业双身旋即找上佛狱使者，要其不让元果之力再冲击妖塔，使者开出杀枫岫主人的条件，天蚩极业与**女戎**理念首度分歧，最后**女戎**拖延，枫岫主人完成修补妖塔的责任。**女戎**也渐对枫岫产生好感

几番波折，妖世浮屠终于修补完毕，佛业双身再度合力，准备让苦集合一。

# 江城子
================================================================================

江城子

文诣经纬门生，与同门山亭柳喜爱一起吟诗作赋。正经稳重的性格，遵守儒家礼规，对于外客能以诗词来表达各种意涵。在缥缈月当初前来寻找墨倾池时，与山亭柳一起与对诗来劝退缥缈月，虽说是送客之意，却也显现出文诣经纬门徒的委婉有礼。

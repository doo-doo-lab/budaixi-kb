# 江城子 (江城子)
================================================================================

江城子

文詣經緯門生，與同門山亭柳喜愛一起吟詩作賦。正經穩重的性格，遵守儒家禮規，對於外客能以詩詞來表達各種意涵。在縹緲月當初前來尋找墨傾池時，與山亭柳一起與對詩來勸退縹緲月，雖說是送客之意，卻也顯現出文詣經緯門徒的委婉有禮。

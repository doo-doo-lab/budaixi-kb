# 荫尸人（霹雳布袋戏中的虚拟人物）

荫尸人，霹雳布袋戏虚拟人物。千邪洞之主，擅长使用术法易容，整天梦想当上武林皇帝；本为欧阳世家一分子，被秦假仙收服后跟随身旁，乃霹雳系列的代表甘草人物之一。由于其练有荫尸大法的体质，是唯一能练成菩萨印而不死的奇人。

## 角色形象

名称：荫尸人荫尸人称号：冻液成体性别：男初登场：霹雳眼 第1集退场：霹雳天启 第47集（死于太学主）短暂登场：霹雳惊涛 第28章（平行时空的荫尸人）新剧登场：霹雳英雄战纪之刀说异数 第1集身份：名人榜上天下第一术、黄山八珠联之“绿蟒”、执法无私铁三角之“八分之六”、新三途判之“腹中荫”、紫耀天朝“左仆射”化身：神秘钓魂人、乱世间根据地：魔海死

## 角色记录

荫尸人可能已经正式退场了，事件是发生在霹雳天启47集38分43秒，死神太学主扫荡琉璃仙境，荫尸人被打成碎片，虽然荫尸人有荫尸大法可以碎尸不死，但这次未必可以。

（老剧时期霹雳英雄榜第30集英雄战场上说明，假扮成欧阳胜天的荫尸人穿过帝尸缸时所映射出只有头部骨骼的肉身就是修练荫尸大法而成的，在魔域三魅殿之一的邪魅殿主事眼中荫尸大法属上乘大法，将全身能量汇聚于头部，下身全是肌肉软骨，致命部位全在头部。

所以之后荫尸人无论身首离异还是哪个部位被击碎，只要头颅完好无恙，就算是不死的，这也是荫尸大法的破解所在。）剧集截图另有剧情补充，在刀龙传说第二集中，秦假仙的原话：“这太学主太厉害了，连我的老弟荫尸人也被他收去了”，下边还有一句是“连六铢衣也被他收去了”，此时六铢衣已经阵亡了，所以这里“收去了”应该就是死亡了的意思。

综上所述，荫尸人【退场】：霹雳天启 第47集 （死于太学主） 证言 霹雳震寰宇之刀龙传说（第2集）注：官网的角色介绍并未注释退场说明，但秦假仙说的话表示他已经死了。《霹雳英雄战纪之刀说异数》剧情来自1990年的霹雳剧集《霹雳异数》，这个时间段中荫尸人是活着的。

# 律己秋

================================================================================

霹雳布袋戏中的角色律己秋，霹雳布袋戏中的角色，性别男。初登场于《霹雳战元史之动机风云》第34集，退场于第36集，称号“迎天风”，身份为武道七修之一，武器为风声。他是武道七修内七修第二代成员，习有“袖盈乾坤”，乃是结合暗器和奇门，演绎武学的七修门法之一。律己秋待人和善，自律甚严，对武道七修与奇花八部的排名甚为关心，与妖绘天华不欢而散。父亲为律弹鋏，上司为意琦行。却在回返叫唤渊薮途中，惨遭外聚七修的毒手。其名言诗句为“律己宜带秋气，处事须带春风”。中文名律己秋别 名迎天风性 别男登场作品霹雳战元史之动机风云所 属武道七修

## 角色设定

名称：律己秋称号：迎天风性别：男身份：武道七修之一性格：待人和善，自律甚严。诗号：律己宜带秋气，处事须带春风。武学：袖盈乾坤。武器：风声。人物关系：父：律弹鋏；上司：意琦行（初代内七修）。初登场：霹雳战元史之动机风云 第34集退场：霹雳战元史之动机风云 第36集

## 角色能力

- **武学**: 袖盈乾坤武器：风声

## 角色经历

律己秋为武道七修内七修第二代成员，称号“迎天风”，待人和善，自律甚严，但对武道七修与奇花八部的排名甚为关心。因故与妖绘天华不欢而散，却在回返叫唤渊薮途中，惨遭外聚七修的毒手。他初登场于《霹雳战元史之动机风云》第34集，并于同剧第36集退场。

## 角色关系

组织门派：武道七修父：律弹铗（已殁） 同修：尊武封端，沌王非寿，寄天风，凭风一刀（二代内七修）上司：意琦行（初代内七修）

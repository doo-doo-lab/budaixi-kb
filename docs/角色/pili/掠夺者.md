# 掠夺者

凯旋侯麾下杀将，随拂樱斋主进攻百韬略城，却受困于虚空烈火之中，幸赖拂樱化杀体破阵而出；后随太息公、凯旋侯大军扫荡集境，本以为胜券在握，孰料烨世兵权强不可撼，掠夺者等四将麾众也遭孔雀一人覆灭。

# 掠奪者 (掠夺者)
================================================================================

掠奪者

凱旋侯麾下殺將，隨拂櫻齋主進攻百韜略城，卻受困於虛空烈火之中，幸賴拂櫻化殺體破陣而出；後隨太息公、凱旋侯大軍掃蕩集境，本以為勝券在握，孰料燁世兵權強不可撼，掠奪者等四將麾眾也遭孔雀一人覆滅。

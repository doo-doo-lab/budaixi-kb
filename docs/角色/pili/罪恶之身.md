# 罪惡之身 (罪恶之身)
================================================================================

罪惡之身

神祕高人，以贖罪之身出現於封隱的雲渡山，心性慈悲且睿智。曾以清聖佛法渡化窮八極的殺戮戾氣，並排解半花容、佾雲的心結，促成烈焰谷誅殺邪神之局；而後更在掩光嶺為素還真護航，藏於待罪之身背後的真面目因此曝光…。

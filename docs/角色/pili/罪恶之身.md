# 罪恶之身
================================================================================

罪恶之身

神秘高人，以赎罪之身出现于封隐的云渡山，心性慈悲且睿智。曾以清圣佛法渡化穷八极的杀戮戾气，并排解半花容、佾云的心结，促成烈焰谷诛杀邪神之局；而后更在掩光岭为素还真护航，藏于待罪之身背后的真面目因此曝光…。

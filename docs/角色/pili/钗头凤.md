# 釵頭鳳 (钗头凤)
================================================================================

釵頭鳳

武皇掌上明珠，作風強勢，巾幗不讓鬚眉，個性愛恨分明，鍾慕葉小釵。與今生一劍為調查武皇下落而出現江湖，以武皇令諭解散十八樓組織，威嚇集境三宮，並積極揭穿燈蝶假冒武皇的陰謀。

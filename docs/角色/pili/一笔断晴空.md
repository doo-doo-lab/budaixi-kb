# 一筆斷晴空 (一笔断晴空)
================================================================================

一筆斷晴空

海溝異識的先鋒死將之一，手持長鐵筆，擁有罪念晶源之力加持。與十白浮世諷形影不離，默契非常，甫復生便以異識之力干擾鬼方赤命腦波，使其進入幻境迷陣中，讓赤命受異識所影響。爾後在創罪者復出後，兩人便一同回歸受命於創罪者。最後在進攻魔吞不動城的大戰中，與浮世諷一同對上刀猿、劍狼，因中計而遭劍狼所殺。

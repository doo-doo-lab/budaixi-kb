# 一笔断晴空 (一笔断晴空)
================================================================================

一笔断晴空

海沟异识的先锋死将之一，手持长铁笔，拥有罪念晶源之力加持。与十白浮世讽形影不离，默契非常，甫复生便以异识之力干扰鬼方赤命脑波，使其进入幻境迷阵中，让赤命受异识所影响。尔后在创罪者复出后，两人便一同回归受命于创罪者。最后在进攻魔吞不动城的大战中，与浮世讽一同对上刀猿、剑狼，因中计而遭剑狼所杀。

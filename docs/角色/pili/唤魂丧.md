# 唤魂丧

来自集境无常楼的科学家，乘坐时空转换器来到苦境，缉查崎路人的下落，因此被卷入武林风波，并在时空圣战中帮助天虎对抗魔龙。拿手绝技为光束般的星罗棋布，后因查出半尺剑是灯蝶的真相，遭到灭口。

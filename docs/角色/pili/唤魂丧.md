# 唤魂丧

来自集境无常楼的科学家，乘坐时空转换器来到苦境，缉查崎路人的下落，因此被卷入武林风波，并在时空圣战中帮助天虎对抗魔龙。拿手绝技为光束般的星罗棋布，后因查出半尺剑是灯蝶的真相，遭到灭口。

## 来自百度百科的补充

### 基本信息（来自百度百科）

唤魂丧是霹雳英雄战纪《蝶龙之乱》系列登场的集境武者，隶属无常楼势力，位列"风雷六圣"组合并拥有"星罗棋布"称号。其性格诙谐幽默，在悬空棋盘战役中以"破折号，看你想打几折"等俏皮台词展现独特个性。与同属风雷六圣的傲八方互为挚友，两人持续进行武学切磋以图击败师傅百里泣。在八口山战役中与傲八方联手对抗阿修罗主宰，其拳脚功夫与刀法结合的武打设计成为剧情亮点。

### 角色背景

作为集境"三宫六殿十八楼"体系中无常楼的精锐成员，唤魂丧位列"风雷六圣"组合，其具体称号为"星罗棋布"。无常楼最终因成员遭太幻楼使用变体晶液暗杀而被吞并，该事件由天蝶盟大宫主灯蝶策划。其"风雷六圣"组合成员包括：

雷厉风行傲八方（无常楼主百里泣嫡传弟子）

回黄转绿春意浓

伏尸遍野满江红

匣剑帷灯掩日光

### 人物关系

与傲八方保持深厚战友情谊，两人既是共同修行的伙伴，也是百里泣门下竞争者。作为崎路人成长过程中的六位授业师傅之一，其武学理念对崎路人的战斗风格形成产生直接影响。在无常楼覆灭事件中，与太幻楼缔造者灯蝶构成敌对阵营。

### 剧情经历

#### 悬空棋盘交锋

在阿修罗主宰宣战场景中，以"破折号，看你想打几折"的即兴台词化解紧张气氛，展现出临场应变能力。该战役中其语言风格与武学招式形成鲜明反差，塑造出立体人物形象。

#### 八口山血战

与傲八方组成双人作战单元迎战阿修罗主宰：

中期因对手兵器优势转为防守态势

后期展开"刀对腿、拳"的多维度攻防战役过程被旁白描述为"血战，血战，血战……要让天道回清"，最终因实力差距渐趋下风。

### 武学特点

其修行体系融合三项核心要素：

无常楼传承的集境秘技

风雷六圣组合特训成果

针对百里泣武学弱点的破解研究在实战中擅长利用地形制造战术优势，八口山战役中与傲八方联手对战阿修罗主宰。

### 性格特质

通过三次关键场景展现多面性：

日常修行时保持轻松幽默的交流方式

遭遇强敌时展现武者不屈斗志

战术决策中体现团队协作意识这种"外松内紧"的特质使其在风雷六圣中具有独特辨识度。

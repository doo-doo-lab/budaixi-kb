# 圣踪

一名来自北方的圣者，乃是剑子仙迹多年至交，居住在悬浮奇谷，是位出世的修道人。言谈之中，充满着先天人的风范，具有仙风道骨的气息。实际上却是城府深沉的阴谋家，曾犯下兰若经血案，设计双佛并现，窃夺北嵎龙气、如意法、邪兵卫，暗中操弄一切阴谋诡计。

## 来自百度百科的补充

**退场原因**

因双体合一使龙气和邪兵卫互相冲击，爆体身亡。

**所有物补充**

邪兵卫、兰若经、一莲托生品、北嵎龙气。

**不忘尘寰**

双极邪能、如意法、邪魂爆气、倒行逆施。

**武器描述**

无遗乃圣踪藏匿已久的邪剑，化为手中拂尘掩人耳目，更是昔日《兰若经》血案凶器。此剑轻薄锋利，外形看似端正，实则杀气逼人，剑身较一般利刃窄且细长，刃开双边，一剑封喉毙命。

**角色经历**

圣踪，隐居于悬浮奇谷修行的一代奇人，拔俗出尘，与剑子仙迹为好友，表面上是个不涉红尘、修德养性的世外高人，而真实身份则是包藏祸心的阴谋家、城府深沉的绝代枭雄。圣踪练有双极心源，化出副体地理司，为夺《兰若经》以无遗剑犯下血案，杀害所有护送僧人和高手。

接着，圣踪又到西佛国作案，设计双佛并现的阴谋，更习得藏在佛牒之中的《如意法》，幻化为佛剑分说四处开杀，将正道注意力转向佛剑，趁机吸收佛剑分说体内的邪兵卫，又夺取一莲托生品，并幻化为替身不望尘寰设下连环布局，免除自己与地理司结识的嫌疑。

但来自钜锋里的一步天履·寻锲而不舍地追查，圣踪为维持表面的圣者形象，只好作戏和地理司翻脸，并与正道联合除去地理司和不望尘寰，其实乃布下另一个更加缜密的阴谋。

在让不望尘寰替死后，圣踪又布局自己在豁然之境被邓九五打成金人的假象，化明为暗行动，先让地理司复活，又偷袭素还真，最后一掌将剑子仙迹轰下琉璃仙境山谷，圣踪则出面以圣者形象领导中原群侠，暗中挑拨中原和北嵎的征战。面对人邪的追杀，圣踪决定先针对北嵎，协助皮鼓师擒捉骨箫、治愈红叶夫人，与众兄弟一同毁灭了北辰皇朝。

最后，圣踪的假面具被剑子仙迹揭破，面对剑子仙迹和佛剑分说的围攻，以邪兵卫邪力配合邪剑无遗冲出了包围圈、且战且退，和受日月才子追击而迎面赶来的地理司合体，本以为双体结合而实力大增的圣踪却中了谈无欲的一莲托生品之计，龙气正力和邪兵卫邪力相克相冲，圣踪承受不了体内过于庞大的力量，最终爆体身亡，如同宣判"多行不义必自毙"的下场。

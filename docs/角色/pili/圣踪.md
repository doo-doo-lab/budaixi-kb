# 聖蹤 (圣踪)
================================================================================

聖蹤

一名來自北方的聖者，乃是劍子仙跡多年至交，居住在懸浮奇谷，是位出世的修道人。言談之中，充滿著先天人的風範，具有仙風道骨的氣息。實際上卻是城府深沉的陰謀家，曾犯下蘭若經血案，設計雙佛並現，竊奪北嵎龍氣、如意法、邪兵衛，暗中操弄一切陰謀詭計。

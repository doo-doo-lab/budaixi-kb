# 冲隐无为

================================================================================

霹雳布袋戏虚拟人物冲隐无为，霹雳布袋戏虚拟人物。清静无为、逍遥方外的道门衔令者，人如其名，庄严的眉目，一袭象牙白的雪白衣裳犹如诗号云“不喜轻裘，布衣芒履”平时与道鹂为伴，旁观天下事，淡泊名利、不喜纷争，尽管因三教之源的纷争而入世，却仍秉持着“道常无为而无不为”之中心思想，充分展现出道家的抱朴守真、与世无争。

## 经历
前尘冲隐无为乃道界泰山北斗之人物，本品性超尘。

通过无数艰难考验，百年监察、百年试练、百年悟修，被遴选为衔令者。

后据其多年所查，三教本源蕴藏之密，背后极不单纯，与道界牵连甚大。

为此，冲隐无为想打开本源，一观究竟。

但欲开本源，必须有三名各负三教精纯功体之人，同时运力方成。

而身为道教衔令者，必须练成天下篇这部武功秘诀，让其只能拥有纯粹道元，无法再兼习儒、佛。

直到异识晶源找上，借晶源之助，突破这项限制，而晶源则依附其身，因其功体深厚、意志坚定，异识晶源使用融魂侵识之法，非其死亡，不能离体。

冲隐无为  剧截图入世因无上崇真在鹤白丁的诱导下，逼迫素还真将乱世狂刀请出，以道门镇教之招天地根击毁道之足，使渺云道再现尘寰。

而后在钧天上君与鹤白丁的请求下，冲隐无为再入红尘。

来到寂灭圆槃，一会佛门衔令者询问三教本源之事。

此时已为异识侵染，沦为九轮天在三教的暗桩，协助沉轮加速三教自残。

按天极之言，所犯之错有四：1.鹤白丁为恶，仍任其籍本源之事，挑拨三誓，扩大与佛门之冲突；

2.误导隐春秋，利用其刚烈脾性，加深与不动城、一际云川之敌对；

3.欺瞒先天诸道，擅发诰命，连番无谓征战，致使宗淮烈三人枉死；

4.赮毕钵罗为人正义凛然，私吞本源更属无稽，还要逼其投鼎自尽；

退场在魔吞不动城地牢之中，误以为碎无泪前来相救，毫无防备下被一刀斜划，无可避、无可挡，刀风过处，轻写死亡。

毕生持无为之念，到头来，却因罪念白忙一场。

尘寰碌碌， 毕竟何求，道朴暗问天地，答案，已不重要。

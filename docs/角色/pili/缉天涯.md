# 缉天涯

霹雳布袋戏虚拟人物缉天涯，霹雳布袋戏虚拟人物。胡同蜃市鬼掌，处事机敏有度，个性略偏冷傲。因鬼师缉氏祖规，年过二十必婚配以人，故缉天涯届龄二十后，便设以红鸾绣球招亲。但其父鄙其先祖陋习，不愿女儿受成规束缚，便假外人道，蜃市之主丑陋无比，其性凶恶如夜叉。故缉天涯招亲历年有余，无人敢接绣球以结好。

𣨼无伤为取风光身上一点太易元灵而前往蜃市交易，无意间接到蜃市招亲绣球，而与缉天涯产生一段纠缠。

素还真等人在泥犁森狱斩除驺山棋一阴军之时，偶遇红潮，无处躲藏，危机之时，缉天涯以红轿现身引红潮至无涯之涯。

为了𣨼无伤放弃鬼掌之位，利用月藏锋与孤城不危交战之时，通过星河天瀑，由中阴界前往苦境，在欲明王与山之厉魑岳为太易之剑交战时救走𣨼无伤并解除其毒患。

于神花郡阻止月藏锋与𣨼无伤之战而正式现身，并在其后结识神花郡郡主多天涯，两人多次打斗嬉闹后渐生情谊。

大定止后，告知𣨼无伤前来苦境的真正目的，乃为传达一赤魂之最后心音，并将储存该魂心音之寄心铃交给𣨼无伤。

霹雳会刊223期介绍：缉天涯，出自中阴界控灵家族之一的鬼师缉氏，乃缉仲的女儿，于胡同蜃市担任鬼掌，遵守族规以绣球招亲，但缉仲鄙夷陋习而放出鬼掌丑陋凶悍的谣言，因此多年来无人敢接，但为寻风光的𣨼无伤却意外接到绣球，从此开始了缉天涯对𣨼无伤的穷追不舍。

如玉的面容、自信的姿态，伴随潇洒的歌曲与清脆的铃声，缉天涯现身后多次纠缠𣨼无伤。

后止战之印盖下，缉天涯因魂婢的保护而成为唯一保有记忆的人。

结束与多天涯的闹剧后，缉天涯终于寻上𣨼无伤并带来妖应所托付的话，希望他能想起心中最重要的人。

之后缉仲为中阴界牺牲，缉天涯为了父亲的遗愿而开始寻找母亲九代师，虽然九代师为保护女儿而不肯相认，但在缉天涯的努力与绮罗生的协助下，母女最后终于相认并一同隐居，共享天伦。

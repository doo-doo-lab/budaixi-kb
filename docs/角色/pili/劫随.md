# 劫随

================================================================================

霹雳布袋戏中的角色劫随，霹雳布袋戏中的角色。略城三位祧师之一，个性坚毅而忠诚，恪遵职守，沉稳而寡言，懂得察言观色，颇得城主夫妇器重，负责防护巡守百韬略城。收养一名义子小鬼头，父子俩感情甚笃，对兄弟同袍间也是情义相挺。

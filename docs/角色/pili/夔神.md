# 夔神

血灵魔尊辖下执法三灵魅之首，因魔魁之女开启干中盒，揭开时秘的第二魔界面纱。不满军师玉天玑高压政策、以及血经纬驭下手段，私下小动作不断，甚至求助血道天宫潇湘子，无奈最后仍难逃玉天玑掌控。

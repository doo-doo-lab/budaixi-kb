# 苇江渡

霹雳布袋戏虚构人物苇江渡，霹雳布袋戏虚拟人物，初登场于《霹雳战元史之动机风云》第30集。曾与剑通慧同列“天王四护”的佛修者，因先前判断有误，将“毁住藏经”交给血刹如来，导致佛愆现世，故自请暂退四护之位，并谨慎调查剑通慧身亡之谜。在无向经纬曾与云沧海联手拦杀缎君衡，后又参与天佛原乡对楼至韦驮的追缉行动。其代表色为红色，法器乃缠在手上的“赤龙”。

## 人物能力

赤龙武学：云龙渡海（与云沧海合招）在无向经纬联手拦杀缎君衡时，赤龙急扫配合怒掌威逼，令对手腹背受敌；在天佛原乡追缉楼至韦驮时，与云沧海使出至极合招，两股至圣气漩交织成浑流，化天瀑龙形威撼压下。武器："赤龙"如龙型条般的赤色法器，平日环于苇江渡右手臂上，战斗时能化作炙焰神龙攻击人。

人物

## 经历
苇江渡为“天王四护”修者，曾将“毁住藏经”交给血刹如来，导致佛愆现世，故自请暂退四护之位，并谨慎调查剑通慧身亡之谜。

法器乃在手上的“赤龙”，平日环绕于右手臂上，战斗时能化作炙焰神龙攻击敞人亦能潜入敌人脑内取得灵识，潜入之时，能在人体内扣下无形佛枷，以便追踪该人的行踪。

后绮罗生闯入烈武坛欲取忘巧云戟遭逢天佛原乡、葬刀会埋伏而身中剧毒，苇江渡等人为报血仇围攻而上，毒发之下，江山刀再不留情，血花飞溅间艳刀划过冲上前的苇江渡，苇江渡身首分离，头颅飞至同修凡七夜之手，死法惨绝。

冰无漪与剑布衣来到江山美人亭，苇江渡表明为追杀害剑通慧的凶手而来，欲将剑布衣带回天佛原乡。

剑布衣为证实自己清白愿受灵识探案，故尔善多便拨动妙音，以琴音打开剑布衣的灵识，一旁苇江渡施法让赤龙进入剑布衣脑识，未料，苇江渡竟看见剑布衣前世乃剑通慧之景，使众人惊异费解。

杀人凶手未查出，为防剑布衣潜逃，苇江渡便再施法以赤能于剑布衣体内扣下无形佛枷，以便之后追踪剑布衣之行踪。

在无向经纬之内，苇江渡曾与云沧海联手攻击缎君衡，导致缎君衡受伤。

此外，天佛原乡追缉楼至韦驮时，苇江渡与云沧海率众围攻，施展合招攻击楼至韦驮。

苇江渡的图片后于无向经纬路上，天佛原乡众僧对上宙王，苇江渡与尔善多对上中阴界剑客六独天缺。

赤龙鞭主攻，琴波一旁掩护，双方战得如火如荼，苇江渡的赤龙勾住六独天缺的末日罪赦后，苇江渡再催气劲震伤六独天缺，并将之一举擒回。

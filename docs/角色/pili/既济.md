# 既济
================================================================================

既济

浮动山城的珠宝商人，肩负宝石布袋，为别见黄花落梦中出现的神秘人物，虽是市井商贩，但交游广阔，俨然有一方民间势力之气候，深藏不露。于梦境中与箕子臬相遇，解大极宫通缉之危，而后结伴而行，然其目的不明，后更意外让箕子臬为地母之灵所咒。既济之能，就连大极宫司天也难以掌控，且似与穆天教派有所牵连。

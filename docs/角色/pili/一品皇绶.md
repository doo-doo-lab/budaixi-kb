# 一品皇綬 (一品皇绶)
================================================================================

一品皇綬

六禍蒼龍文武雙化身之一，爾雅溫文中添綴不凡皇龍貴氣，猶如名號般尊爵。為建功博名，曾深入探查黃泉之門虛實，查出朱厭劍靈守關之奧秘；日後更堂而皇之加入武聯會，翦除魔界暗樁，納病梅等勢力為己用。

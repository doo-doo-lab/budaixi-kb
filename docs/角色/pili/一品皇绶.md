# 一品皇绶

六祸苍龙文武双化身之一，尔雅温文中添缀不凡皇龙贵气，犹如名号般尊爵。为建功博名，曾深入探查黄泉之门虚实，查出朱厌剑灵守关之奥秘；日后更堂而皇之加入武联会，翦除魔界暗桩，纳病梅等势力为己用。

## 来自百度百科的补充

一品皇绶是霹雳布袋戏中六祸苍龙以'俱神凝体'化出的文武双分身之一，初登场于《霹雳皇龙纪》第7集，退场于第45集。气质"尔雅温文兼具皇龙贵气"，根据地为武联会。

掌握创世诀武学体系，武学技能包括：皇冠天绶、六溟幻天指、破军流星诀、曜日神威。

- **同伙**：神魁战武（同为六祸苍龙分身）
- **部属**：病梅先生
- **组织**：武联会

一品皇绶入主武联会后，协助逼杀紫宫太一建立功绩，与神魁战武联手牵制袭灭天来。异度魔界进攻时率武联会协助法门抗敌，"在落天桥遭魔界大军围困，为掩护病梅先生突围力战身亡"。其灵气与功力最终回归六祸苍龙本体。

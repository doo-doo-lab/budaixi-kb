# 火邪 (火邪)
================================================================================

火邪

六弒荒魔開啟訞異魔城後的新手下，風火雙邪，負責追查禁忌魔鑰的下落，意外說出現場有兩名「雨楓族」，讓夜雨滄神稍感訝異。雖氣焰囂狂。欲以烈火吞噬眾人，結果卻被夜雨滄神輕鬆解決。

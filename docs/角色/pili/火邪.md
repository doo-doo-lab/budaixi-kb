# 火邪 (火邪)
================================================================================

火邪

六弑荒魔开启𫍚异魔城后的新手下，风火双邪，负责追查禁忌魔钥的下落，意外说出现场有两名“雨枫族”，让夜雨沧神稍感讶异。虽气焰嚣狂。欲以烈火吞噬众人，结果却被夜雨沧神轻松解决。

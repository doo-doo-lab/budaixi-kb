# 渡逢舟 (渡逢舟)
================================================================================

渡逢舟

阳光开朗的大男孩。与师父、师弟一同生活在一衣带水。非常崇拜师父道轩眉，自制轩眉语录，立志背下师尊的每一句话作为名言。剑上轩月是遇事不决，可以博杯请示的利器。不爱在一个地方待着，经常搭著自己的剑舟游玩，跑到上游江上照顾雪狐。

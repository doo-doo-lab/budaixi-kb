# 渡逢舟 (渡逢舟)
================================================================================

渡逢舟

陽光開朗的大男孩。與師父、師弟一同生活在一衣帶水。非常崇拜師父道軒眉，自製軒眉語錄，立志背下師尊的每一句話作為名言。劍上軒月是遇事不決，可以博杯請示的利器。不愛在一個地方待著，經常搭著自己的劍舟遊玩，跑到上游江上照顧雪狐。

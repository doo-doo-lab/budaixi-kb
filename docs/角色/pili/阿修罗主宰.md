# 阿修罗主宰

阿修罗道院的统治者，脸罩修罗鬼面具，智慧、手腕皆属上乘，练有血肉骨三灵分离绝技。造就天祸妖狐，与六先知恶斗胜出，后在魔域遭集境大军攻破时盗走转轮盒，开启第二魔域东山再起。

## 来自百度百科的补充

阿修罗主宰，脸带修罗面具，为魔域高层组织阿修罗道院之主。手下四鼓随从皆带有战鼓随行，以鼓声灭杀敌人。以身为魔界高层为荣，对于同为高层的阴冥皇非常轻视，认为他成事不足、败事有余。阿修罗主宰认为阴冥皇御下无能，放任南宫取和等活天罗在外有辱魔域威名，遂亲自出手，以一招「六爻化象.水雷屯」击败南宫取，并杀了等活天罗（虽然其还会再生）。等活天罗牺牲自己使用移地换景之法让南宫取得以逃脱。

其最大的对手为阴冥皇，两人皆欲夺得魔域盛典【天魔祭】的主祭之位。阴冥皇汲汲营营于天虎八将与魔龙八奇，而阿修罗主宰则放眼于龙灵蜕皮与武林局势。在龙骨圣刀现世时，他曾派遣手下血虎降刺杀素还真，但血虎降被花信风断臂后狼狈逃回，被阿修罗主宰直接处死。

一心想夺龙灵蜕皮成为天魔祭主祭，派出属下鸿爪对上花信风。鸿爪计东西虽战败，但阿修罗主宰仍凭此线索取得了龙灵蜕皮，并一举夺得天魔祭主祭之位。此后，阿修罗主宰与冥海龙灵、太黄君、冥灵道院副道主惊蛰侯、天蝶盟之主灯蝶修万年合作，意图将正道势力与天虎八将一网打尽。行动中，他派出手下玄艳四鼓阻饶素还真，而自己则受冥海龙灵所托，亲身前往火龙舌。欲得初龙，强势压境火龙舌，带来不可预料的暗潮。

蝶龙之乱时期

为夺初龙与万俟焉一战，双方一时不分上下，阿修罗主宰遂祭魔域邪绝天下之神器——魔因神话，魔刀邪气加乘，顿时战事急转直下。就在阿修罗主宰即将劈斩万俟焉之际，花信风到来欲阻，不料冥海龙灵作祟，令衍那魔刀失速，魔因神话横腰一斩，万俟焉近半身躯惨遭劈裂。就在阿修罗主宰追入火龙舌内欲夺初龙之际，花信风冷然挑衅，别开魔刀铿然一战，魔因魔果，于荼毗雪晕之下，婆娑死亡之舞。最终花信风以「八切·雪之刃」一式，完胜阿修罗主宰。

# 月藏锋

================================================================================

霹雳布袋戏虚拟人物月藏锋，霹雳布袋戏虚拟人物。中阴界三大剑客之一，潇洒重诺的文儒剑客，因文才显赫而受宙王器重，但多年前却因一道私人花约触怒圣颜，被贬至藏头冢，自设藏头诗谜困陷其中，直至素还真与欢奭解出十年一觉藏头诗，方重获自由，无奈花期已过，徒留憾事。

## 绝境长城形象设定

书法的表现技巧，在于笔锋的运用，有露锋、藏锋、中锋、回锋、偏锋等，月藏锋为书法名家，取名典故即来自书法。藏锋为浑圆自然、先内收再外送，一如月藏锋温文内敛，但写字不能一味藏锋，须刚柔并济、均匀一致。月藏锋称号“十年一觉”，身份为中阴界殿前御笔侯、太子少傅、绝境长城代理城主，诗号“十裁恨字入诗眼,年冉岁消忘人间,一笔赘墨事三千,觉来日尽已成烟”，初登场于霹雳战元史之天竞鏖锋第21章。

（谜底）6.年年杜鹃犹啼血，艳花入眼不复悲，何人还怜啼血情，可叹今昔万般非。

## 角色配乐

- **十年一觉（月藏锋角色曲）曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十七》
- **丁天牧老师以「茗茶」为题创作之乐章，以西方弦乐搭配中式古琴，演奏东方风格的古典曲调，闲情逸致的曲律中，散发著一股朴实简单，一如月藏锋给人的印象，耿直重诺的外表下，藏著一颗内敛而深情的心。

春江墨雨月锋腾（月藏锋武戏曲）曲/编曲：阿轮** — 《霹雳英雄音乐精选三十八》

角色介绍月藏锋介绍阿轮老师2012年作品，主旋律以古琴为抚，锣钹为响，音色淳和淡雅中藏有高山流水的弦外之音；

嘎然骤起的琴韵，散透出一股刚正沛然的正气、以及坚毅不拔的决心。

乐曲初次使用于动机风云第1集，月藏锋与殢无伤初次交锋，墨剑以敌、觉剑相候，漫天花雨中划开一场惊世剑决；

而后月藏锋独挑阴谋家血傀师时，亦多次使用此古琴武曲来彰显紧逼的气势。

# 列御子 (列御子)
================================================================================

列御子

盛气自负，城府深沉，与朱尊、徐无鬼并列道武王谷至高三修，平时深居简出，潜修数甲子，实力不可度测。内心蕴藏着吞天野望，欲求道界至尊之位，暗中策画叛变谋反，荼害同修与界天塔内道友。平时隐于幕后，指挥崇玉旨、全真子与四烈旗，勾结外力，欲谋夺七仙器中的古剑尊始。

# 列御子 (列御子)
================================================================================

列御子

盛氣自負，城府深沉，與朱尊、徐無鬼並列道武王谷至高三修，平時深居簡出，潛修數甲子，實力不可度測。內心蘊藏著吞天野望，欲求道界至尊之位，暗中策畫叛變謀反，荼害同修與界天塔內道友。平時隱於幕後，指揮崇玉旨、全真子與四烈旗，勾結外力，欲謀奪七仙器中的古劍尊始。

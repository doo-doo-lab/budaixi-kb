# 未来之宰

霹雳布袋戏虚拟人物未来之宰，霹雳布袋戏虚拟人物。灭境邪灵之首，雄才大略，企图以破坏构筑属于自己的未来国度，将儒圣佛道消灭，彻底掌控灭轮。善于算计操弄人心，夺众天灵识，摆布孽角，暗中纠合东方羿，拟定一连串计杀凤凰鸣之行动

## 人物设定

名称：未来之宰未来之宰性别：男身份：灭境邪灵先锋军之主、灭境两大枭雄之一诗号：吾来自未来，毁灭过去，开创现在！初登场：霹雳神州II之苍玄泣 第40集（只出现声音）正式登场：霹雳神州Ⅲ之天罪 第34集退场：霹雳天启 第19集（死于凤凰鸣）来自：灭境根据地：异幻空间、弃龙九脉

## 经历
未来之宰，久远前的灭境邪灵之首，与问天敌分占灭境的半壁江山。

深谋远虑，野心勃勃，武学修为深不可测，主张以破坏带来重建，歼灭儒圣与修行者，开创属于邪灵的康庄大道。

昔年曾在轮回海与蚁天海殇君一战，被海殇君以克邪圣器所杀，卧佛一枕眠念及往日情谊救助未来之宰，使未来之宰元珠修复后再生。

未来之宰也与卧佛定下协议，让邪灵和儒圣一脉休兵，还灭境和平。

角色设定攻略本未来之宰表面虽息事宁人，但老奸巨猾，增强实力的同时隐避自身命门，纵使以克邪圣器也无法将之诛灭，唯有释放出大红袍体内的神秘力量，方能引动未来之宰的死角浮现。

未来之宰沉潜多年，暗中策划使得众天提早坐化，将风暴带入苦境，又培育孽角杀害灭境修道者，在孽角背叛后亲身收拾孽角，正式步入武林。

未来之宰暗中和东方羿串通，派逸君辞卧底学海无涯，另一方面千方百计寻找往圣留迹，要以其中的入度不转轮大法修复元珠。

在得知雅僧佛公子为众天转世宿体后重创对方，后又设计恶海鲛祖，让大红袍误会卧佛，使得天启之日时正道保护佛公子失败，但往圣留迹却也不见踪影。

为对付凤凰鸣并杜绝素还真复活，未来之宰暗中勾结东方羿，以叛天犄黑暗力量制成的箭重创凤凰鸣，后又对曲怀觞、苍等人动手，却在东皋亭被千叶传奇反将一军，对上复出的凤凰鸣。

因大红袍之死，未来之宰死门已现，最后被凤凰鸣以火凤元功融合黑暗力量后用克邪圣器所杀。

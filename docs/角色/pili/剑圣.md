# 裴旻（唐朝将领）

================================================================================

同义词剑圣（唐开元年间将领）一般指裴旻（唐朝将领）裴旻（生卒年不详），唐朝开元时期将领，祖籍河东闻喜（今山西闻喜），出生于东鲁（今山东兖州），后迁居任城（今山东济宁任城区），官至左金吾卫大将军。

唐文宗时，其剑舞与李白诗歌、张旭草书并称“唐代三绝”。

曾任龙华军使镇守北平郡（今河北卢龙），参与对奚人、契丹和吐蕃的战事。

开元年间因母丧请吴道子作壁画时表演剑舞，以“掷剑入云，高数十丈”后精准收鞘的技法激发画师创作。

驻守幽州期间曾一日射杀三十一虎，遇真虎时险遭吞噬而止猎。

王维《赠裴将军》、颜真卿诗句及乔潭《裴将军剑舞赋》记载其事迹。《新唐书》《历代名画记》等史料存其生平记述，唐玄宗曾下诏规范其战功赏罚规则。

别 名剑圣所处时代唐朝民族族群汉族出生地东鲁（今山东兖州）主要成就唐代三绝之一最高官职左金吾卫大将军本 名裴旻祖 籍河东闻喜（今山西闻喜）所属名门河东裴氏

## 人际关系

裴旻作为唐代名将，其剑舞与李白诗歌、张旭草书并称“唐代三绝”，体现了与当时文化名人的广泛联系。

据《翰林学士李公墓碑》记载，李白曾致信裴旻称“如白愿出将军门下”。

后世多认为李白曾从裴旻学剑，但亦有观点认为此事并无确凿实据。

李白亦曾公开推崇裴旻剑术为天下第一。

开元年间，裴旻因母亲去世，请画圣吴道子于天宫寺作壁画以超度亡魂。

吴道子请裴旻先舞剑以启发画思，裴旻遂表演了“走马如飞，左旋右抽”、“掷剑入云”等高超剑技。

吴道子观后受启发，挥毫图壁，绘成“为天下之壮观”的壁画。

裴旻与草圣张旭亦为好友。

据《太平广记》载，吴道子、裴旻、张旭曾相遇，各展其能，“裴剑舞一曲，张书一壁，吴画一壁”，时人赞为“一日之中，获睹三绝”。

唐代著名舞蹈家公孙大娘善舞剑，其代表作《裴将军满堂势》即根据裴旻的剑法改编而成。

诗人王维与书法家颜真卿均为裴旻好友，并曾作诗相赠。

王维在《赠裴旻将军》中赞其“腰间宝剑七星文，臂上雕弓百战勋”；

颜真卿所作《赠裴将军》诗则盛赞裴旻“剑舞若游电”、“威名雄震雷”。

## 成就和影响

唐文宗时，裴旻的剑舞与李白的诗歌、张旭的草书并称“唐代三绝”，世人尊称其为“剑圣”。

据《独异志》记载，裴旻表演剑舞时能“掷剑入云，高数十丈，若电光下射”，并能以剑鞘精准承接落下的剑。

裴旻曾任龙华军使镇守北平郡（今河北卢龙），先后参与对奚人、契丹和吐蕃的战事，官至左金吾大将军。《新唐书》记载，裴旻北伐时被奚人包围，他“舞刀立马上”，来箭“皆迎刀断”，令敌军惊退。

唐玄宗因其在吐蕃战事中的表现而赐书表彰。

裴旻的剑舞艺术对同时代顶尖艺术家产生深刻影响，曾为吴道子作画激发灵感，其剑法被公孙大娘改编为《裴将军满堂势》剑舞。

裴旻与“草圣”张旭、“诗仙”李白交往密切，三人技艺曾于一日内同场展示，获誉“三绝”。

诗人王维、书法家颜真卿均曾作诗相赠。

裴旻被后世与张旭、吴道子、陆羽、杜甫等并称为“三绝五圣”之一。

## 轶事典故

剑画合一开元年间，裴旻因母亲去世，想请大画家吴道子在天宫寺作壁画超度亡魂。

吴道子说：好久没作画了，如果裴将军一定要我画的话，只好先请将军舞一曲“剑舞”好启发一下我的画思。

裴旻当即脱去孝服，持剑起舞，只见他“走马如飞，左旋右抽”，突然间，又“掷剑入云，高数十丈，若电光下射，旻引手执鞘承之，剑透室而入”。

被抛起数十丈高的剑，竟然能用手持的剑鞘接住，使其直入鞘中，真是剑技绝招。

当时，几千名围观者为之震惊，赞叹不已。

吴道子也被那猛厉的剑舞气势感动，画思敏捷，若有神助，于是挥毫图壁，飒然风起，很快一幅“为天下之壮观”的壁画就绘成了。

裴旻射虎裴旻作为龙华军使，驻守在幽州(今北京)。

幽州有很多老虎。

裴旻善于射箭，曾经在一天之内射死过三十一只老虎。

然后他就在山下四处张望，显出自得的样子。

有一位老头走过来对他说：“你射死的这些，都是彪，像虎而不是虎。

你要是遇上真虎，也就无能为力了。”裴旻说：“真虎在哪儿呢？”老头说：“从这往北三十里，常常有虎出没。”裴旻催马向北而往，来到一个草木丛生的地方，果然有一只老虎跳出来。

这只老虎的个头较小，但是气势凶猛，站在那里一吼，山石震裂，裴旻的马吓得倒退，他的弓和箭都掉到地上，差一点儿被虎吞食。

从此他又惭愧又害怕，不再射虎了。

(《唐国史补》)射杀怪蛛裴旻曾射杀过大型蜘蛛。

相传他在深山中行走时，遇到了车轮一样的大蜘蛛，蜘蛛网就像一匹布一样垂下来。

蜘蛛盘丝结网，差点将裴旻缠住。

裴旻“引弓射杀之”，并从蜘蛛网上取下数尺长的丝收藏起来。

当部下受伤的时候，他剪方寸贴之，血立止也。

## 艺术形象

号称剑圣的唐朝将军裴旻，祖籍在河东闻喜，裴旻在电影中只是惊鸿一瞥。裴旻出身河东裴氏，为河东裴氏第31代孙。电影通过艺术化处理，将“三绝”集中到扬州城裴将军府中。“唐代三绝”指李白诗歌、裴旻剑舞、张旭草书。

## 后世纪念

裴旻驻守平州时留下许多脍炙人口的故事，三分剑气也为秦皇岛文脉注入盛唐气象，他是大唐剑圣，“三绝五圣”之一。唐文宗时，称李白的诗、张旭的草书、裴旻的剑舞为“唐代三绝”，世人称“剑圣”。颜真卿曾经写过《赠裴将军》，这里的裴将军就是裴旻；颜真卿在诗里说：“大君制六合，猛将清九垓。战马若龙虎，腾凌何壮哉...”；王维的《赠裴旻将军》指的也是裴旻：“腰间宝剑七星文，臂上雕弓百战勋。见说云中擒黠虏，始知天上有将军。”

天子穆然，诏伶官，斥郑卫。

选色者使觇乎军容，教舞者俾观乎兵势。

激楚结风，发扬蹈厉。

佥谓将军之剑舞，古未之制。

# 无心陀

隔山接脉法的创始人，医术高明，却被徒弟修渡开背叛，囚禁于浮罗教深处水牢多年，因此对外人极为防备。白面具受托医治无念教主一瓢水，让雾谷老人救出无心陀，无奈无心陀已病入膏肓，最后安排由叶小钗承袭隔山接脉法绝技，成为无心陀关门弟子，成功医治好一瓢水，但最后无心陀却也因年老力衰而亡。

### 角色经历

无心陀为隔山接脉法的创始人，医术高超，收修渡开为徒，却被其设计陷害，囚禁于浮罗教后山水牢数十年之久，也因此使得无心陀对任何陌生人都极其防备。白面具·东南秋与无念教的醉贵妃达成协议，要医治无念教主一瓢水，遂让雾谷老人救出无心陀，让其使用隔山接脉。但无心陀由于长年囚禁水牢，湿气侵身，已是时日无多，在东南秋的建议下，无心陀相中叶小钗作为自己的传人，传授其隔山接脉法的绝技，让叶小钗代行医好一瓢水，更让一瓢水也拜入自己门下，无心陀受苦数十年，在临终前却感受到入门不久的弟子的关心，终是含笑九泉。

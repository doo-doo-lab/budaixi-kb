# 無心陀 (无心陀)
================================================================================

無心陀

隔山接脈法的創始人，醫術高明，卻被徒弟修渡開背叛，囚禁於浮羅教深處水牢多年，因此對外人極為防備。白面具受託醫治無念教主一瓢水，讓霧谷老人救出無心陀，無奈無心陀已病入膏肓，最後安排由葉小釵承襲隔山接脈法絕技，成為無心陀關門弟子，成功醫治好一瓢水，但最後無心陀卻也因年老力衰而亡。

# 妖后（霹雳布袋戏虚拟人物）

================================================================================

妖后，霹雳布袋戏虚拟角色。深沉冷静、智勇双全，狠辣强悍且城府极深。对儿子黑衣剑少极为疼爱，曾为救子动用犴妖族禁术而亡；对丈夫诛天采取分权抗衡的决绝态度。统领妖刀界期间，凭借精准局势判断力掌控武林动向，令中原正道人心惶惶，展露逐鹿天下的王者风范。曾被叶口月人围杀后跳崖身亡，后因非尸流复活，最终为护黑衣剑少抵挡海蟾尊的致命攻击而消散。

## 角色经历
妖后是霹雳布袋戏中的一位人妻角色，在剧中身材和相貌较为突出。

性格上兼具优雅与霸气，睿智且具有母性特质，同时也有阴险狠毒的一面。

在霹雳布袋戏的女性角色中，她是一个重要的角色。

她对儿子黑衣剑少表现出强烈的关爱。

妖后COS妖后是霹雳布袋戏中的女王角色，作为妖刀界之主，后与西疆魔剑道之主诛天结婚。

她性格深沉冷静，行事果断，对事情观察入微，且城府极深。

与诛天个性相近，夫妻关系不合，各自统领魔剑道与妖刀界。

作为女性角色，她具有领袖气势，在武林纷争中能洞悉利害得失，寻找有利机会。

她不断锻炼黑衣剑少以提升其武学境界。

为了黑衣剑少，她背叛犴妖族，与冥界天岳合作，谋害丈夫诛天，并与号天穷虚与委蛇，勾结无衣师尹伏击戢武王，导致杀戮碎岛、火宅佛狱被灭等。

妖后具有高深的功力和智谋，在谋求霸业时展现出王者风范。

她布局谋划以阻止孽源的诞生，借由与步怀真的斗争利用佛力拖延孽源诞生，同时保护善体，为日后除去鬼王留下契机。

最终，她为了给儿子黑衣剑少续命而身亡。

**妖后**为台湾霹雳布袋戏中的角色。妖刀界之主，虽在霹雳九皇座时，遭叶口月人围杀，儿子黑衣剑少为护母不幸战死，妖后便带黑衣跳落断崖，就此下落不明，但意外在第二次枭皇论战时介入，并再创势力邪尊道。初登场于霹雳异数之龙图霸业 第8集，于霹雳兵燹之问鼎天下39集，发现自己早已身亡，是借由非尸流事件才得以复活，最后为护儿子黑衣剑少，挺身挡住海蟾尊一剑，在被黑衣救走的途中不幸身亡，消散天地。

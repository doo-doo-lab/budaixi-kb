# 人形師 (人形师)
================================================================================

人形師

擅術法，酷愛人形娃娃，喜愛華麗又帶些神經質的自戀者，行事神秘莫測捉摸難料，自我風格十分強烈，以自我喜好行事，喜獨來獨往，乃為陰陽師畢生死敵。其真實身分，乃不老城主識能龍座前四能之一「太宰」、六禍蒼龍的得力心腹。

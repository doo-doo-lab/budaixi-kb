# 志满天

霹雳布袋戏中的角色志满天是《霹雳布袋戏》中的虚拟角色，初登场于《霹雳震寰宇之龙战八荒》第38集，退场于《霹雳震寰宇之兵甲龙痕》第37集。其真实身份是集境安插到苦境的信息收集者，乔装成游走江湖的术士郎中，满脸黑痣，手执写有“铁口直断，生死无错”的布幡，自称钻研风鉴之术，能借由点痣帮人消灾解厄。其举止言谈带有阴冷诡异感，曾化解南风不竞、少独行的攻击，后常驻于薄情馆并在火宅佛狱进攻时助阵退敌。最终，志满天在薄情馆之战中丧命于太息公之手。

## 角色经历
志满天，乃是集境安插到苦境的信息收集者，乔装成钻研风鉴之术的术士郎中潜入苦境江湖，志满天黑痣满脸，手执布幡替人消灾，能通过点痣帮人化解灾厄。志满天的举止言谈都有种引冷感，曾轻易化解南风不竞、少独行的攻击，在《霹雳震寰宇之刀龙传说》第二十六集中，志满天曾来到并告知啸日猋杀死赤子心。后常驻于薄情馆，在火宅佛狱进攻薄情馆时助阵退敌，但佛狱兵力再加上贪邪扶木，志满天最后丧命于太息公之手。

# 巽非巽
================================================================================

巽非巽

天牟．巽非巽为集仙者与王者的气质于一身之人，其人长相俊美。个性看似亲和且容易相处，实则城府深沉擅长权谋之术。在未进入魔域之前，乃修关者最高话事者，坐‘君位’。战后，以一介外道落魄身加入魔域，在短短一年间，成为掌管第一魔域的最高权威代表。

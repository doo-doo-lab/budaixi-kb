# 巽非巽 (巽非巽)
================================================================================

巽非巽

天牟．巽非巽為集仙者與王者的氣質於一身之人，其人長相俊美。個性看似親和且容易相處，實則城府深沉擅長權謀之術。在未進入魔域之前，乃修關者最高話事者，坐『君位』。戰後，以一介外道落魄身加入魔域，在短短一年間，成為掌管第一魔域的最高權威代表。

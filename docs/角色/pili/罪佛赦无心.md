# 罪佛赦无心

声如洪钟，气似川流，正气无涛，肃穆威严，立身天佛断罪岩，数甲子屹立不摇的佛门高手，专司佛门执法戒律。大乘灵云寺遭逢灭门之劫，天佛断罪岩因此现世，由罪佛赦无心踏入红尘，着手缉凶除恶。

## 来自百度百科的补充

佛门高手，原名段念，因狂禅之乱而苦恼迷茫，受问奈何指点后，自担承受杀生罪过，无私执法。因调查大乘灵云寺案件而正式入世，迅速揪出叛徒、对抗异魔、阻止儒道争斗、调查蓝衣阴谋者、定三教和平协议、攻打往生无相塔。劳苦功高，过去曾为执法而造下无数杀业，后以无尽元罪业力化作佛门圣器长枪"杀生罪"交由三刑天三位罪身尊者看顾。但随着台面局势发生变化，终究让佛者无奈，再度拔起杀生罪，以罪渡杀。

最后被无相塔控制的三尊者偷袭重创，把杀生罪交给佛剑后，灯尽油枯，冬雨不愿承认，背起他前去就医。罪佛在背上嘱咐冬雨："人世，犹如此刻，千变万化，你要守住初心，记住，为天下人而奔！"随后身体便随风消散。

# 狂屠

罗喉右护法，魁武壮硕，手持一口巨刀，如野兽般凶猛狂野，虽不擅言词，但对武君忠心耿耿，平日随侍在侧。为完成主上遗愿，掩护黄泉带离神之子，毫无畏惧只身奋战问天敌，慷慨捐躯。

## 角色经历

在罗喉复活并重建天都后，昔日旧部属也纷纷聚集回归，狂屠便是罗喉的右护令。最为死忠，对罗喉忠心无比，始终伫立于罗喉身后，无任何指令绝不擅自行动，更不会多发表意见。狂屠外表魁梧壮硕，手持一口阔刃大刀，走起路来大开大合，霸道刚猛，加上攻击时发出的嘶吼声，让狂屠如野兽般凶猛疯狂，让人胆寒。

狂屠平时随侍罗喉身边，加上罗喉实力超绝，平时少有表现机会。而后传出罗喉身亡于名刀神坊，狂屠为完成罗喉遗愿，协助黄泉将神之子送到寒光一舍，奋不顾身，与天都叛将和邪灵大军厮杀，最后为掩护黄泉撤离，牺牲断后，死于问天敌。

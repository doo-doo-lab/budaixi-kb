# 赤睛

================================================================================

霹雳布袋戏虚拟人物赤睛，霹雳布袋戏虚拟人物魔王子的副体，佛狱智囊，可化巨大的魔龙，其外表看似年少稚气，但个性却是老成持重，冷眼旁观魔王子的恣意妄为，以不危害佛狱利益为前提。当赤睛为人形时声音温柔，但龙形时却显暴躁凶恶。

## 魔王子人物设计

赤睛赤睛：『在他危害佛狱利益之前，吾永远是观察者。』赤睛这一人物设计除了成为魔王子的副体，还要与魔王子做一个对比，在魔王子大放厥词时，赤睛是一个冷眼的旁观者与吐槽者，因为魔王子的歪理实在是太强大了，所以编剧利用赤睛，来抓一下魔王子的语病，并代替魔王子发出理性的言论，两人一搭一唱，既成一体，又是正反的两面。将赤睛设计成魔龙的原因，一是当做魔王子的交通工具，二是成为威吓敌人的战力，外形为西方的有翼魔龙，在西洋的传说、神话中，这种外形的龙都是邪恶、负面的象征，与东方神龙代表的意义相反，编剧即依此特性，请特摄组设计赤睛的魔龙形态。

人物

## 经历
赤睛，是魔王子的副体“观察者”，可化身巨大魔龙担任座骑，外表看似年少稚气，但个性却老成持重。

赤睛具有两种形态，可化为巨龙以及人形，实力仅次于魔王子。

冷眼观看魔王子的作为，不时会出言吐槽。

最初以不危害佛狱利益为前提，后发现魔王子无人能挡，于是想看他何时自我毁灭。

人形时声音温柔，但化为龙形之时，却是残暴无比。

赤睛  官方桌布赤睛曾经协助咒世主与拖刀者、深流君、红狐九尾、风世魃鬼联手封印被称作“异数”的魔王子，但也因为术法效力一同沉眠，直到魔王子被咒世主放出后，才同时解开封印，随魔王子往赴战场救出太息公、凯旋侯。

赤睛作为观察者，赤睛冷眼旁观魔王子的肆意妄为，并适时提出建言或讥讽，理性进行自己的行动，不随魔王子起舞，但始终是他在战场上的得力臂助，曾在魔王子力斗一页书时，以魔龙姿态和一页书的坐骑大鹏鸟阳翼打得两败俱伤，因而被霓羽族遗孤飞鹭所救。

当魔王子依气息寻来时，赤睛为保飞鹭性命，刻意疏远重新回到魔王子身边，和他去查探神秘的天阎魔城。

在魔王子多番挑衅剑之初后，两方终究对上，尽管魔王子和赤睛使出被誉为佛狱千古最强的联手招“蛾龙天劫”，却不敌剑之初和从天阎魔城借得玄雷的慕容情使出的合招“剑羽飞凰”而落败，双双坠入火山。

## 人物漫谈

赤睛---赤子的眼睛摘自：霹雳会月刊第216期 《侠骨柔情话四魌——火宅佛狱篇》写魔王子，就一定要谈到赤睛，透过赤睛与魔王子的「对杠」，魔王子的话语才不会太过虚无狂乱，赤睛的「吐槽」，让魔王子的形象变得十分诙谐有趣。

人形·赤睛赤睛与魔王子一冷一热，一个逗，一个捧，若说魔王子是说大道理的高手，那么赤睛无疑就是高手中的高手。

武林顶尖高手齐聚一堂展开「枭皇论战」，除了彼此较劲，也各自心怀鬼胎。

魔王子：『有人想在这里当场格杀烨世兵权吗？

没有吗？

明明是众人想除之后快的对象，却又想留下敌人的敌人，为了更大的欲望，所以掩盖现有的欲望。』赤睛：『你的兴趣消失了。』魔王子：『离开吧，替西瓜化妆，都比参加这场会议来的更有意义。』赤睛：『你的比喻不伦不类。』魔王子：『仔细体会，你会了解吾的话是如此贴近真理。』另外，火宅佛狱咒世主之死，寒烟翠对其兄态度质疑而问。

寒烟翠：『难道父王身亡，你一点也不伤心？

父王对你的期待，你一点都不挂心吗？』魔王子：『吾悲伤过。』赤睛：『一秒钟。』赤睛  魔王子魔王子：『差不多。

嫌短吗？

要多久才能表达哀伤，三个月？

三年？

三十年？

每一个人都在怀念死去的先人，道路上就会充斥着满满的哭声，太吵了！

所以我们需要的是诚心的哀悼，只要诚心，一秒钟足够了。』赤睛就像旁观之「眼」，看着魔的反动与机辩，赤睛讲话时，往往能精准接上魔王子的话点，以便提醒我们深层思考，赤睛是一个称职的副体，不突兀，不抢戏，平凡而没有情绪，更是「魔语录」的最佳帮衬者，这两人的相处模式，看的出魔王子很依赖赤睛，赤睛就像是魔王子的另一面，两人之间微妙的对比，形成了一种说不出的感性味道。

赤睛的存在，就像炒菜时放的调味料，很有「提味」的作用，他虽是副体，却是无法不存在的，赤睛的见解，只要他开口，魔王子多少会受其影响，可见得他极了解魔王子的心性。

**赤睛**為台灣霹靂布袋戲人物，登場於霹靂經武紀之梟皇論戰第1集，乃火宅佛獄魔王子的副體，曾助咒世主封印魔王子，在霹雳兵燹之圣魔战印第1集挑戰劍之初、慕容情決戰失敗後，與魔王子失敗後墜落火山。
==人物介紹==
**赤睛**，是魔王子的副體「觀察者」，可化身巨大魔龍擔任座騎，外表看似年少稚氣，但個性卻老成持重，曾經協助咒世主與拖刀者、深流君、紅狐九尾、風世魃鬼聯手封印被稱作「異數」的魔王子，但也因為術法效力一同沉眠，直到魔王子被咒世主放出後，才同時解開封印，隨魔王子往赴戰場救出太息公、凱旋侯。<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI56/01.HTM] 霹靂經武紀之梟皇論戰第1集</ref>。

作為觀察者，赤睛冷眼旁觀魔王子的肆意妄為，並適時提出建言或譏諷，理性進行自己的行動，不隨魔王子起舞，但始終是他在戰場上的得力臂助，曾在魔王子力鬥一頁書時，以魔龍姿態和一頁書的坐騎大鵬鳥陽翼打得兩敗俱傷<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI56/19.HTM] 霹霹靂經武紀之梟皇論戰第19集</ref>，因而被霓羽族遺孤飛鷺所救，當魔王子依氣息尋來時，赤睛為保飛鷺性命，刻意疏遠重新回到魔王子身邊，和他去查探神秘的天閻魔城<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI56/26.HTM] 霹靂經武紀之梟皇論戰第26集</ref>。

在魔王子多番挑釁劍之初後，兩方終究對上，儘管魔王子和赤晴使出被譽為佛獄千古最強的聯手招「蛾龍天劫」，卻仍不敵劍之初和慕容情合力使出的「劍羽飛鴻」而落敗，雙雙墜入火山城<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI57/01.HTM] 霹雳兵燹之圣魔战印第1集</ref>。

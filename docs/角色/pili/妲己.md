# 妲己 (妲己)
================================================================================

妲己（天子傳奇）

紂王寵妃，本為天母門大弟子，極具權謀心機，性殘忍，貌驕媚的女子。自進宮以來，便在其身邊流連忘返，原欲藉控制紂王，進而主導一切，紂王則國政日亦荒廢。但得知龍龜猝亡一事後，發現其位亦危矣，便暗中佈局，以便鞏固自己的地位。施法玩計讓諫臣商容萬磕金垓而亡，假痼疾取忠臣比干「七竅玲瓏心」枉死比干。為保青春美貌汲汲尋找「九天冰蟬」，不惜與紂
王及江湖人士暗中較勁，更是習有「九天聖女功」及「懾魂術」，讓許多男人拜倒其下。

# 帝九重 (帝九重)
================================================================================

帝九重

日夜殊界之主，掌管殊界已歷悠久歲月。待人寬大仁慈，態度和藹親切，卻有著老辣精明的決策眼光，助殊界壯大成地宇一方之霸。深得人心，統御殊界各方菁英，萬眾莫不尊崇。雖軀體衰弱，貌似身無絲毫武學修為，但卻精通無數奇法異術之研究，掌握無比深奧精妙的造軀之術。無論其心其術，都教人難以測度，和藹的面容背後，似乎隱藏著許多更深的秘密…

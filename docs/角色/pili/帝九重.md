# 帝九重

日夜殊界之主，掌管殊界已历悠久岁月。待人宽大仁慈，态度和蔼亲切，却有着老辣精明的决策眼光，助殊界壮大成地宇一方之霸。深得人心，统御殊界各方菁英，万众莫不尊崇。虽躯体衰弱，貌似身无丝毫武学修为，但却精通无数奇法异术之研究，掌握无比深奥精妙的造躯之术。无论其心其术，都教人难以测度，和蔼的面容背后，似乎隐藏着许多更深的秘密…

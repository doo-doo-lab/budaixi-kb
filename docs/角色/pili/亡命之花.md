# 亡命之花

================================================================================

霹雳布袋戏中的角色亡命之花，是《霹雳布袋戏》中的虚拟角色，东瀛“伊贺双华”之一，为伊贺流派高手，初登场于《霹雳狂刀》第36集，退场于《霹雳英雄榜》第9集。亡命之花是非凡公子最为忠心的贴身护卫，一切行动皆以主上命令为依归，曾奉命执行歼灭黑流派、暗杀素还真、对付菩提学院高僧等行动。其口衔红玫瑰，身法飘忽无定，擅长叶杀、珍珠暗器等手法。亡命之花曾有数度复活的记录，最终被不颠和尚强行灌下醉佛总酒，因不听劝告而动用内力导致自焚身亡，化为一只蝙蝠告知主人自己死讯，再无复活。

## 角色经历
亡命之花亡命之花乃东瀛“伊贺双华”之一，为非凡公子最忠心的贴身护卫。

口叼一朵红玫瑰，以珍珠为杀人暗器，一切皆以主人命令为依据，歼灭黑流派、暗杀素还真、对付菩提学院高僧等行动。

在《霹雳狂刀》时期，亡命之花在猜心园废墟与菩提学院的星河、月明大师及众僧发生战斗。

随后在琉璃仙境发现黑流派踪迹，回报非凡公子后，奉命与非凡公子一同截杀黑流派，导致大首领爆体而亡，并追杀余党白月。

亡命之花奉非凡公子之命前往琉璃仙境暗杀素还真，以“花影迷神术”制住紫霹雳后闯入，以手指弹出一球击穿门直接命中素还真。

曾跟踪神雕（不知名），被梵音和木障法干扰，使用“叶杀”攻击无效后离去。

与菩提学院副院主及众僧多次交战，最终旧伤未愈下被副院主以“达摩弹指”震晕七孔流血被擒。

非凡公子为救他被擒，以换得其释放，副院主在释放前废除了他的武功。

此外，秦假仙、业途灵曾将其暗器大珠子放置于破庙，引出了黑流派忍者并致谢。

亡命之花曾有数度复活的记录，第一次是被鬼王棺所擒、欲以之为诱饵擒捉非凡公子，亡命之花为禀告主人不惜自我牺牲，以至高忍术（即‘意识转移法’）化为蝙蝠通知非凡公子，最后在吸收天堂之树洞中所存储的三教抄经者的功力而复活。

第二次则是陪同非凡公子欲返回东瀛之际，在岸边遭夔婴狙杀，亡命之花护主断后不慎被击毙，但却在非凡公子以“号世阴令”重整无极殿势力时再生，成为欧阳世家的一员大将。

直到被不颠和尚强行灌下醉佛总酒，因不听劝告而动用内力导致自焚身亡，化为一只蝙蝠告知主人自己死讯，再无复活。

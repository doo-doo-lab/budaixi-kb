# 史菁菁（霹雳布袋戏虚拟人物）

史菁菁是霹雳布袋戏系列虚拟人物，云州大儒侠史艳文之女。其人生历经多重情感与命运波折：与独眼龙、金太极陷入三角纠葛，被迫成婚金太极后诞下幼子紫霹雳。看破红尘落发为尼之际获素还真搭救并收为徒弟，却遭魔域鬼帝改造为鬼奴卧底魔域。经历情劫魔劫后，史菁菁最终选择退隐江湖，携子栖居无双崖底。这位名门闺秀从江湖纷争到遁世归隐的轨迹，深刻展现了霹雳世界中个体命运与武林沧桑的复杂交织。

## 经历
中原边界的“紧张十字路”，西达苗藏、南通交趾、北抵鞑靼、东至中原。

在这样的交通要道上，出现了“命运青红灯”，好人畅通无阻，歹人却难逃气功袭击、金光散体。

没有多久，一名头戴白帽、身穿时髦劲装、手执长鞭的俊美少年自“紧张十字路” 上踏入江湖，惩奸除恶，找寻亲人的下落，自称“灯下人”。

灯下人的真实身份正是史菁菁，也就是云州大儒侠史艳文的掌上明珠，母亲则是杭州第一才女刘萱姑。

为寻找下落不明的父亲，史菁菁女扮男装，自称灯下人匡金巡，一边寻亲，一边帮助中原群侠，她的武器虽是长鞭，但真正厉害的却是揉合阴阳、刚柔并济的气功。

经常徘徊于紧张十字路，每当歹人来到，便现出命运青红灯，好人能安全通过，坏人则被神秘气功打退。

一度成为中原群侠的保护伞。

史菁菁(金光布袋戏虚拟人物)

史菁菁是金光布袋戏中的虚拟人物。巾帼不让须眉的气势，出场便击杀蟒人，因弄伤史艳文眼睛而被小空打抱不平。善解人意，一身正气，实为云州大儒侠史艳文与苦海女神龙所生的女儿，黑面并非天生，而是自小为避免被史艳文仇家找上而每日用特殊药物洗脸造成，后来谜中迷告知其身世后亦让其恢复天生丽质的面貌。得知身世后担起歼杀恶人责任，同三位兄长一起击败八足原人。虽然之后不再出场，但在《决战时刻》史艳文与宫本总司的谈话里，以及《魔戮血战》戮世摩罗与雪山银燕的对话中，仍有提到四兄妹之间的亲情以及期盼能够再次团聚的愿望。

## 来自百度百科的补充

史菁菁是金光布袋戏中的虚拟人物，"初登场于《第一侠苦海女神龙之鹰燕龙虎榜》第5集"。

在剧情设定中，她因躲避仇家而"每日需以药物涂黑脸部"，直至身世被揭露后才恢复原貌。她拥有三位兄长——俏如来、戮世摩罗、雪山银燕，合称"虎龙燕鹰"四兄妹。

虽然该角色未在后续作品中直接出场，但在《决战时刻》和《魔戮血战》中仍有涉及，"仍有提到四兄妹之间的亲情以及期盼能够再次团聚的愿望"。

# 史菁菁（霹雳布袋戏虚拟人物）

================================================================================

史菁菁是霹雳布袋戏系列虚拟人物，云州大儒侠史艳文之女。其人生历经多重情感与命运波折：与独眼龙、金太极陷入三角纠葛，被迫成婚金太极后诞下幼子紫霹雳。看破红尘落发为尼之际获素还真搭救并收为徒弟，却遭魔域鬼帝改造为鬼奴卧底魔域。经历情劫魔劫后，史菁菁最终选择退隐江湖，携子栖居无双崖底。这位名门闺秀从江湖纷争到遁世归隐的轨迹，深刻展现了霹雳世界中个体命运与武林沧桑的复杂交织。中文名史菁菁别 名灯下人、匡金巡、化丑性 别女登场作品霹雳布袋戏

## 人物经历

中原边界的「紧张十字路」，西达苗藏、南通交趾、北抵鞑靼、东至中原。在这样的交通要道上，出现了「命运青红灯」，好人畅通无阻，歹人却难逃气功袭击、金光散体。没有多久，一名头戴白帽、身穿时髦劲装、手执长鞭的俊美少年自「紧张十字路」 上踏入江湖，惩奸除恶，找寻亲人的下落，自称「灯下人」。灯下人的真实身份正是史菁菁，也就是云州大儒侠史艳文的掌上明珠，母亲则是杭州第一才女刘萱姑。为寻找下落不明的父亲，史菁菁女扮男装，自称灯下人匡金巡，一边寻亲，一边帮助中原群侠，她的武器虽是长鞭，但真正厉害的却是揉合阴阳、刚柔并济的气功。经常徘徊于紧张十字路，每当歹人来到，便现出命运青红灯，好人能安全通过，坏人则被神秘气功打退。一度成为中原群侠的保护伞。

史菁菁(金光布袋戲虛擬人物)

史菁菁是金光布袋戲中的虛擬人物。巾幗不讓鬚眉的氣勢，出場便擊殺蟒人，因弄傷史艷文眼睛而被小空打抱不平。善解人意，一身正氣，實為雲州大儒俠史艷文與苦海女神龍所生的女兒，黑面並非天生，而是自小為避免被史艷文仇家找上而每日用特殊藥物洗臉造成，後來謎中迷告知其身世後亦讓其恢復天生麗質的面貌。得知身世後擔起殲殺惡人責任，同三位兄長一起擊敗八足原人。雖然之後不再出場，但在《決戰時刻》史艷文與宮本總司的談話里，以及《魔戮血戰》戮世摩羅與雪山銀燕的對話中，仍有提到四兄妹之間的親情以及期盼能夠再次團聚的願望。

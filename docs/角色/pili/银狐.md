# 银狐（霹雳布袋戏人物）

银狐，霹雳布袋戏虚拟人物。原为冰河天川时空裂隙中的异生之子，幼年被卧江子救回，身世牵涉叶口月人狐族血脉。与卧江子互为唯一知交，常以心识传音交流，性格外冷内热，行事独来独往却多次助力正道。曾进入中原挑战剑君十二恨、风之痕等高手，并与蜀道行、王隐建立战友情谊。

## 角色设定

名称：银狐身份：天外南海首席刀者银狐其他称号：银色的狐狸（秦假仙、黑衣剑少语）、狐狸兄（步怀真语）、小狐狸（蜀道行发狂时语/道友爱称）、俏狐狸（任飞扬语）性别：男初登场：霹雳刀锋 第10集隐退：霹雳劫之末世录 第14集（霹雳神州22集还有露脸与箫中剑对话）来自：天外南海根据地：飞银苍涧、银勾苍月个性：孤傲冷淡、我行我素、外冷内热嗜好：和卧江子心识传音、挑战绝世高手、追求刺激专长：不负责任的导游&快递、打架抢亲特征：一年四季穿着超厚的白色毛草，戴着纯毛手套身世：在霹雳九皇座第43集与惨绿色一闪而过的碰面，惨绿色说了一句：异生之子，极端的存在。

## 身世原话

霹雳异数之万里征途第21集卧江子：“中原风景真是悠美。”（银狐不语）卧江子：“你来中原树敌不少。”银狐：“讲重点！”卧江子：“你看起来真糟。”银狐：“卧江子！”卧江子：“你越来越没耐性了，真让吾担心。”银狐：“每次垂钓，就是想掩饰或是有隐情！

既然赶来中原，就快解释，别迂回打转！”银狐卧江子：“好吧！

你知道冰河天川与中原苦境为什么一定要以飞船通行吗？

就是因为中间地带有一个时间变异点。”银狐：“意思是时间不同？”卧江子：“除了时间不同，那也是一个扭曲的空隙，可能存在另一个世界！

很久以前，天川偶有飞船忽然失踪的怪事，傲刀城的人查不出原因；

吾听闻风声，也去过天川观察，猜测存有另一个世界的出入口，这个论点也是遇上你之后才完全确定。”银狐：“你从来不提，因为我是自那里来？”卧江子：“尚有其他原因，后来天外南海又发出禁止自由通行之令文，吾难以找寻证据佐证；

而且你兽族的　特征又是天外南海的族群之一；

虽感事有蹊跷，也只能放弃调查。”银狐：“只有我一人吗？

当时的状况？”卧江子：“当时吾行经天川，忽闻气流异变，转头一望便见一名女子自高空的缝隙坠落，吾救起之时已经气绝，她怀中紧抱着你，当时你的身上裹着一件很特殊的白色斗篷，吾便从天川将你救回。”银狐：“她……有何特征？”卧江子：“银发金眼，与你非常相似，也是兽族，但却在颈上有一个特殊的标记，吾猜测是特殊的号码。”银狐：“你为何从来不提？”卧江子：“时机未到，而且吾再回到天川之时，再也寻不得空隙！

因此所以在这个空间出世的人，才是所谓不属于十二时辰内出生的人，因为时间空间皆有所不同！”银狐：“匪夷所思！”卧江子：“意思是由不得你不信吗？”（银狐不语）卧江子：“其他的事路上说吧！”银狐：“去哪里？”卧江子：“随性所至！

来中原这么久，有什么值得留恋之处吗？”银狐：“有啊，正事不做，想要偷闲吗？”卧江子：“还有一点时间！

久未见面，聊聊你的近况再去天地门。”银狐：“麻烦啊～”

## 其他相关

霹雳月刊第95期介绍（节录）银狐之入江湖，理由无关仁义，心境洒落不致无奈，他不理会世间的繁文耨节及人情世故，总是维持着独有的步调，走着专属于自己、殊丽的武学之道。

进入中原武林，遇见真正的王刀之后，银狐的苦境之行才开始有了棋逢敌手的期待感，也使人渐渐感受到银狐桀傲的偶像魅力 。

银狐绝逸非凡的速度，如魅影一般，神出鬼没的瞬动，只留下虚空中的一丝残影，竟令人分不清是幻是真！

时而融于光影草木之中，有如神祇般具有掌控自然万物的能力。

在乎的，或者称之为能使他心湖波荡的，便是探触无涯的武学边际，当然 还有那些曾与他出生入死的友情。

银狐官方桌布银狐与卧江子不仅相知甚深，更难能可贵的是不逾越该有的相互尊重与独立性。

两人灵犀相通而合作无间的互动，彷佛分别象征着出世与入世、明与暗、动与静，正如阴阳两仪双生双合。

若说卧江子如“风”，浑然自成于万物而无所不容，处处显得清越悠然；

银狐就是孤高昭然的“明月”，清辉碧朗，锋芒夺目而从不矫饰。

清风皓月继而构成一幅神韵空零而错落而致的诗画，令人不禁为之赞叹而向往。

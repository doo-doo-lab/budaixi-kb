# 萧雨

乔飞的义弟，心性卑劣，垂涎玉芙蓉美色而陷害乔飞，遭欢喜佛一掌击伤后，为殁神金疆所救，再造成为天镜刑者，专门诛杀与六合武册相关之人，手段凶残，被杀者无不脑浆迸碎，三分缝皆受其害。

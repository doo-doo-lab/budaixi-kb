# 央千澈 (央千澈)
================================================================================

央千澈

道真一脉北宗六扉之冠，人称“道魁”，与南宗式洞机齐名，在当年南北道真武斗事件之后，选择退隐不问世事，而后得知倦收天大战南宗之事，受到精神感召，暗中协助倦收天重新凝聚北芳秀势力，也被公认为如今道真北宗的领导者，为了道真的未来，央千澈与式洞机协议，让银骠当家与倦收天代表南北道真出战，决定日后由哪方统领道真一脉。

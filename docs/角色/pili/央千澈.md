# 央千澈 (央千澈)
================================================================================

央千澈

道真一脈北宗六扉之冠，人稱「道魁」，與南宗式洞機齊名，在當年南北道真武鬥事件之後，選擇退隱不問世事，而後得知倦收天大戰南宗之事，受到精神感召，暗中協助倦收天重新凝聚北芳秀勢力，也被公認為如今道真北宗的領導者，為了道真的未來，央千澈與式洞機協議，讓銀驃當家與倦收天代表南北道真出戰，決定日後由哪方統領道真一脈。

# 天外方界

================================================================================

《霹雳布袋戏》中的门派组织天外方界是《霹雳布袋戏》中的门派组织，由无忌天子不忍苍生陷于苦难，遂联合傲笑红尘、白云骄霜、血雨风生、方界老童、愁月仙子、不死魔僧六位高人共同创立，六人被尊为“方界六弦”，六弦之名乃兵器而来：瑟刃、一调之弦、旋箜玉叉、夜琴刀、半筝剑、野狐禅。

下设血道天宫、云路天宫、无道天宫三处分支，基地包括英雄战场、天外天、琼楼玉宇、拔骨塔、听韵小筑、轮回道关、血道天宫、云路天宫、无道天宫等。

拥有方界六弦、追声骨、通往轮回簸魂车、千里镜、导行磁令、勒马规、顺风鸢等奇珍异宝。

初期作为清净乐土由无忌天子统领，后白云骄霜联合谈无欲发动政变，迫使无忌诈死、傲笑红尘出走。

掌权后天外方界从人间乐土转变为罪恶渊薮，暗中操控易水楼、兵家堡实施侵略武林的阴谋。

天外方界后被标记为邪魔。

天外方界

霹靂布袋戲虛擬組織無忌天子週遊各地，見烽煙四起，不忍蒼生陷於苦難，遂尋得六位高人，靖平狼煙，一同創立的人間樂土。天外方界成立後，無忌被尊奉為「天子」，傲笑紅塵、白雲驕霜、血雨風生、方界老童、愁月仙子、不死魔僧則被尊奉為「六弦」，共同治理，其下還設有「三宮」：血道天宮、雲路天宮、無道天宮。豈料白雲驕霜野心勃勃，夥同談無欲竄謀大權，迫使無忌天子詐死、傲笑紅塵出走，天外方界就此落入白雲驕霜一人獨攬，從清淨樂土轉變為罪惡淵藪，台面下更暗植易水樓、兵家堡等勢力，設計出一連串侵略武林之計畫。

很久很久以前，天下十分混亂，無忌天子周遊列國走遍天涯海角找尋到了六名絕世高人（其實傳說就是這么來的，霹靂幽靈箭II裡面由海殤君和骨董間接介紹說是六名絕世高人，實際上除了傲笑和白雲，哪有能堪稱“絕世”的，尤其不死魔僧就是一個山寨強盜頭目......）建立了一個“清淨”的世界——天外方界。

無忌天子送給他們六人每人一件兵器寶物作禮物，六人一見如故，遂結義，號稱“方界六弦”無忌天子帶著六弦開疆闢土，不久便打下了一片天，威震西武林，後來，無忌天子與愁月仙子私下相愛又苦於傲笑紅塵對愁月仙子的一片真情，於是設下計謀讓血雨風生殺了愁月仙子，挑動傲笑紅塵親手殺了血雨風生，自己則暗中傳位給談無欲，兩人則退隱紅塵......又過了近百年，在談無欲和白雲驕霜的領導下，不甘安逸於天外方界，開始妄想稱霸武林。

設下諸多計謀積極顛覆武林、陷害正義之士。

隨著傲笑紅塵的復出;魔魁崛起，天外方界勢力漸漸衰弱，最後得知談無欲及白雲驕霜陰謀真相的傲笑紅塵怒戰白雲驕霜一眾之人，擊殺談無欲，打暈忘年，逼死白雲驕霜（自殺假死）。

天外方界就此滅亡！

組織歷史及架構1、傲笑紅塵、血雨風生、愁月仙子、方界老童、白雲驕霜和不死魔僧合稱方界六弦，六人結拜為異姓兄弟，所謂“六弦結義，義薄雲天”。

無忌天子送給方界六弦每人一件禮物，白雲驕霜受贈一調之弦，傲笑紅塵受贈半箏劍，血雨風生受贈夜琴刀，愁月仙子受贈瑟刃，方界老童受贈旋箜玉叉，而不死魔僧則受贈野狐禪。

其實從無忌天子所贈之物可以看到：前五件兵器都是和音樂樂器有關，而且都有實用的兵器價值，稱得上是名器寶物，只有不死魔僧的野孤禪僅僅是一把木製的禪杖，無任何用途，不死魔僧也從不隨身攜帶作為武器，他的慣用武器是一條長鎖鏈。

不死魔僧死後，野孤禪被白雲驕霜收於兵家堡內，兵家堡滅亡後不知所蹤......有人說不死魔僧的“野孤禪”不會簡簡單單只是一根木杖那么簡單，一定有妙用，何況白雲驕霜將其收於兵家堡內可見其價值......筆者我也曾試圖分析研究，《霹靂武器事典》裡面對“野孤禪”只有簡單的六個字介紹：一口木製禪杖。“豐功偉業”裡面也沒有什麼實際的內容，最終筆者自己還是認定：這只是一根由無忌天子製作的簡單的木杖，無忌天子深知不死魔僧的山大王思想，殺伐之氣極重，不會給不死魔僧有殺傷力的武器，更何況是名器寶貝，沒給他套上勒馬規已經算是不錯了。

而白雲驕霜生性狡詐多疑，對無忌天子所贈他人的東西都不會放過，畢竟是方界的“鎮界神器”收於兵家堡也是理所應當，無論其是否有實用價值......無忌天子贈予不死魔僧的這根木杖只是一件象徵性的禮物，意在希望不死魔僧能收斂戾氣和殺念，慈悲修佛，不過終其一生也沒有改變不死魔僧的性格和命運，野孤禪對於不死魔僧而言也許只是地位的象徵物，畢竟是“天子”所贈之物，證明了他的地位......2、 其實，整個天外方界的建立就是無忌天子一種不切實際的一廂情願的訴求，就不說不死魔僧滿腦子的“山寨大王”思想，也不談白雲驕霜的陰險深沉、野心重重，現在就談一個人：方界老童！

從劇中介紹也是一個鶴髮童顏的高人，而且貫穿《霹靂英雄榜》整一部戲，方界老童是天外方界各項命令任務的直接執行人，也是方界“最忙”的人，跟蹤忘年、向千山樵老索取無弦神弩、夜闖無極殿、殺秦假仙等等傑作業績，他算是方界最有代表力的中層幹部了吧？

那么他知道這樣做不對嗎？

他清楚以前的無忌天子不應該是這個樣子吧？

他是否產生對方界的懷疑？

沒有！

老童非常賣力的執行著談無欲下達的格殺命令，“因為這才像個組織，這才算有作為”，虧得他早早死在龍閣梭羅的手上，傲笑紅塵在袁冬曲墓前還自責了一番“害了老童”，如果活到了後期傲笑紅塵下戰書約戰白雲驕霜，甚至撐到了東瀛黑榜白雲嬌娘時期，他的立場又會作何呢？

筆者不敢想......3、天外方界自詡為高尚的組織，所以不像合修會或者汗青編，展現出很多雜兵殺手，筆者細細看了《霹靂英雄榜》《霹靂烽火錄》多遍，發現天外方界幾乎沒有雜兵士卒，除了《霹靂烽火錄》17集傲笑紅塵知曉陰謀單挑天外方界，白雲驕霜是率領了一些殺手......但是，也是聘請易水樓的（無忌天子所創立，但是退隱後就中立了，後來成為白雲嬌娘的暗中組織，但不能說這是方界的！）於是，天外方界顯得很少很冷清，六弦剩下三弦，而堂堂弦尊（方界老童）親自跑腿執行各種任務工作，甚至是索要私人物品的雜活兒，到了後期，組織勢力更是捉襟見肘，只得倚靠易水樓聘請殺手......。

4、關於血道天宮大宮主山濤君是否也是天外方界之人的分析。

這個確實沒有明顯的證據證明他是否方界出身，天外方界是在《霹靂英雄榜》第5集瀟湘子被海殤君殺掉後風雪生（雲岫君假扮）私自進入瀟湘子隱居的燈花台發現密室，由裡面的掛著的一幅空白畫軸引出天外方界的關卡：輪迴道關，從而進入方界的，只能證明瀟湘子絕對是方界派來或者培養的人，而山濤君......筆者只能說自己的觀點：應該不是方界直屬出身，類似於“附屬國”的存在，各個天宮和天外方界的關係只是類似門派歸附，山濤君是土生土長的血道天宮大BOSS，可能後來被招安什麼的，《霹靂幽靈箭I》23集，當時山濤君布下五里迷障、十里斷腸崖之戰局，還捉了素續緣，然後跑去琉璃仙境和海殤君聊天，曾經說到“西丘同修數十年，我一直不清楚你的底細，不知你是正是邪？”再看《霹靂英雄榜》第5集瀟湘子被海殤君殺掉時最後慘笑：“哈哈...擎羊嘯天威力不減當年”然後身體就爆了......還有種種之前細節表明瀟湘子很久以前（可能還在天外方界當差沒被外派時）就認識海殤君了，畢竟有愁月仙子這一層的關係，然後被天外方界派到血道天宮“輔佐”（監視）山濤君，不過在與山濤君的宮內政治鬥爭中失勢，於是隱居燈花台，定期通過密室內的空白畫軸向方界傳遞情報。

瀟湘子的六大戰神應該不會是方界的，只是瀟湘子的私人護衛，這個應無問題。

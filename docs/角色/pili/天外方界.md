# 天外方界

《霹雳布袋戏》中的门派组织天外方界是《霹雳布袋戏》中的门派组织，由无忌天子不忍苍生陷于苦难，遂联合傲笑红尘、白云骄霜、血雨风生、方界老童、愁月仙子、不死魔僧六位高人共同创立，六人被尊为“方界六弦”，六弦之名乃兵器而来：瑟刃、一调之弦、旋箜玉叉、夜琴刀、半筝剑、野狐禅。

下设血道天宫、云路天宫、无道天宫三处分支，基地包括英雄战场、天外天、琼楼玉宇、拔骨塔、听韵小筑、轮回道关、血道天宫、云路天宫、无道天宫等。

拥有方界六弦、追声骨、通往轮回簸魂车、千里镜、导行磁令、勒马规、顺风鸢等奇珍异宝。

初期作为清净乐土由无忌天子统领，后白云骄霜联合谈无欲发动政变，迫使无忌诈死、傲笑红尘出走。

掌权后天外方界从人间乐土转变为罪恶渊薮，暗中操控易水楼、兵家堡实施侵略武林的阴谋。

天外方界后被标记为邪魔。

天外方界

霹雳布袋戏虚拟组织无忌天子周游各地，见烽烟四起，不忍苍生陷于苦难，遂寻得六位高人，靖平狼烟，一同创立的人间乐土。天外方界成立后，无忌被尊奉为“天子”，傲笑红尘、白云骄霜、血雨风生、方界老童、愁月仙子、不死魔僧则被尊奉为“六弦”，共同治理，其下还设有“三宫”：血道天宫、云路天宫、无道天宫。岂料白云骄霜野心勃勃，伙同谈无欲窜谋大权，迫使无忌天子诈死、傲笑红尘出走，天外方界就此落入白云骄霜一人独揽，从清净乐土转变为罪恶渊薮，台面下更暗植易水楼、兵家堡等势力，设计出一连串侵略武林之计划。

## 相关历史

天外方界崛起于西武林。

很久很久以前，天下十分混乱，无忌天子周游列国走遍天涯海角找寻到了六名绝世高人（其实传说就是这么来的，霹雳幽灵箭II里面由海殇君和骨董间接介绍说是六名绝世高人，实际上除了傲笑和白云，哪有能堪称“绝世”的，尤其不死魔僧就是一个山寨强盗头目......）建立了一个“清净”的世界——天外方界。

无忌天子送给他们六人每人一件兵器宝物作礼物，六人一见如故，遂结义，号称“方界六弦”无忌天子带着六弦开疆辟土，不久便打下了一片天，威震西武林，后来，无忌天子与愁月仙子私下相爱又苦于傲笑红尘对愁月仙子的一片真情，于是设下计谋让血雨风生杀了愁月仙子，挑动傲笑红尘亲手杀了血雨风生，自己则暗中传位给谈无欲，两人则退隐红尘......又过了近百年，在谈无欲和白云骄霜的领导下，不甘安逸于天外方界，开始妄想称霸武林。

设下诸多计谋积极颠覆武林、陷害正义之士。

随着傲笑红尘的复出;魔魁崛起，天外方界势力渐渐衰弱，最后得知谈无欲及白云骄霜阴谋真相的傲笑红尘怒战白云骄霜一众之人，击杀谈无欲，打晕忘年，逼死白云骄霜（自杀假死）。

天外方界就此灭亡！

## 组织历史及架构

1、傲笑红尘、血雨风生、愁月仙子、方界老童、白云骄霜和不死魔僧合称方界六弦，六人结拜为异姓兄弟，所谓“六弦结义，义薄云天”。

无忌天子送给方界六弦每人一件礼物，白云骄霜受赠一调之弦，傲笑红尘受赠半筝剑，血雨风生受赠夜琴刀，愁月仙子受赠瑟刃，方界老童受赠旋箜玉叉，而不死魔僧则受赠野狐禅。

其实从无忌天子所赠之物可以看到：前五件兵器都是和音乐乐器有关，而且都有实用的兵器价值，称得上是名器宝物，只有不死魔僧的野孤禅仅仅是一把木制的禅杖，无任何用途，不死魔僧也从不随身携带作为武器，他的惯用武器是一条长锁链。

不死魔僧死后，野孤禅被白云骄霜收于兵家堡内，兵家堡灭亡后不知所踪......有人说不死魔僧的“野孤禅”不会简简单单只是一根木杖那么简单，一定有妙用，何况白云骄霜将其收于兵家堡内可见其价值......笔者我也曾试图分析研究，《霹雳武器事典》里面对“野孤禅”只有简单的六个字介绍：一口木制禅杖。“丰功伟业”里面也没有什么实际的内容，最终笔者自己还是认定：这只是一根由无忌天子制作的简单的木杖，无忌天子深知不死魔僧的山大王思想，杀伐之气极重，不会给不死魔僧有杀伤力的武器，更何况是名器宝贝，没给他套上勒马规已经算是不错了。

而白云骄霜生性狡诈多疑，对无忌天子所赠他人的东西都不会放过，毕竟是方界的“镇界神器”收于兵家堡也是理所应当，无论其是否有实用价值......无忌天子赠予不死魔僧的这根木杖只是一件象征性的礼物，意在希望不死魔僧能收敛戾气和杀念，慈悲修佛，不过终其一生也没有改变不死魔僧的性格和命运，野孤禅对于不死魔僧而言也许只是地位的象征物，毕竟是“天子”所赠之物，证明了他的地位......

2、 其实，整个天外方界的建立就是无忌天子一种不切实际的一厢情愿的诉求，就不说不死魔僧满脑子的“山寨大王”思想，也不谈白云骄霜的阴险深沉、野心重重，现在就谈一个人：方界老童！

从剧中介绍也是一个鹤发童颜的高人，而且贯穿《霹雳英雄榜》整一部戏，方界老童是天外方界各项命令任务的直接执行人，也是方界“最忙”的人，跟踪忘年、向千山樵老索取无弦神弩、夜闯无极殿、杀秦假仙等等杰作业绩，他算是方界最有代表力的中层干部了吧？

那么他知道这样做不对吗？

他清楚以前的无忌天子不应该是这个样子吧？

他是否产生对方界的怀疑？

没有！

老童非常卖力的执行着谈无欲下达的格杀命令，“因为这才像个组织，这才算有作为”，亏得他早早死在龙阁梭罗的手上，傲笑红尘在袁冬曲墓前还自责了一番“害了老童”，如果活到了后期傲笑红尘下战书约战白云骄霜，甚至撑到了东瀛黑榜白云娇娘时期，他的立场又会作何呢？

笔者不敢想......

3、天外方界自诩为高尚的组织，所以不像合修会或者汗青编，展现出很多杂兵杀手，笔者细细看了《霹雳英雄榜》《霹雳烽火录》多遍，发现天外方界几乎没有杂兵士卒，除了《霹雳烽火录》17集傲笑红尘知晓阴谋单挑天外方界，白云骄霜是率领了一些杀手......但是，也是聘请易水楼的（无忌天子所创立，但是退隐后就中立了，后来成为白云娇娘的暗中组织，但不能说这是方界的！）于是，天外方界显得很少很冷清，六弦剩下三弦，而堂堂弦尊（方界老童）亲自跑腿执行各种任务工作，甚至是索要私人物品的杂活儿，到了后期，组织势力更是捉襟见肘，只得倚靠易水楼聘请杀手......。

4、关于血道天宫大宫主山涛君是否也是天外方界之人的分析。

这个确实没有明显的证据证明他是否方界出身，天外方界是在《霹雳英雄榜》第5集潇湘子被海殇君杀掉后风雪生（云岫君假扮）私自进入潇湘子隐居的灯花台发现密室，由里面的挂着的一幅空白画轴引出天外方界的关卡：轮回道关，从而进入方界的，只能证明潇湘子绝对是方界派来或者培养的人，而山涛君......笔者只能说自己的观点：应该不是方界直属出身，类似于“附属国”的存在，各个天宫和天外方界的关系只是类似门派归附，山涛君是土生土长的血道天宫大BOSS，可能后来被招安什么的，《霹雳幽灵箭I》23集，当时山涛君布下五里迷障、十里断肠崖之战局，还捉了素续缘，然后跑去琉璃仙境和海殇君聊天，曾经说到“西丘同修数十年，我一直不清楚你的底细，不知你是正是邪？”再看《霹雳英雄榜》第5集潇湘子被海殇君杀掉时最后惨笑：“哈哈...擎羊啸天威力不减当年”然后身体就爆了......还有种种之前细节表明潇湘子很久以前（可能还在天外方界当差没被外派时）就认识海殇君了，毕竟有愁月仙子这一层的关系，然后被天外方界派到血道天宫“辅佐”（监视）山涛君，不过在与山涛君的宫内政治斗争中失势，于是隐居灯花台，定期通过密室内的空白画轴向方界传递情报。

潇湘子的六大战神应该不会是方界的，只是潇湘子的私人护卫，这个应无问题。

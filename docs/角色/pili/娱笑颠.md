# 娱笑颠

神秘的云游仙，一身市井闲人打扮，看似衣衫褴褛，却又贵气逼人，以娱乐世间的态度，笑看人生颠沛流离。身后背着一名婴儿，其哭声似有玄异之力，甫出场便化解忘尘缘杀劫，但言谈中却颇多暗示，与天佛原乡似有渊源。

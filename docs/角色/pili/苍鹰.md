# 蒼鷹 (苍鹰)
================================================================================

蒼鷹

魔吞十二宮的蒼鷹宮代表，頭戴鷹形面具，心如止水、泰然自若，低調不語的性格，更增添神祕難測的氣息。能以劍氣化鷹、翱翔戾天，戰鬥中以高乘的掌法配合指氣凝劍，根基已達武臻化境，並能冷靜判斷與分析當下戰況，適時下達各項指令。

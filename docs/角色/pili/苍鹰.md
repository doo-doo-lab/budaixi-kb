# 苍鹰
================================================================================

苍鹰

魔吞十二宫的苍鹰宫代表，头戴鹰形面具，心如止水、泰然自若，低调不语的性格，更增添神秘难测的气息。能以剑气化鹰、翱翔戾天，战斗中以高乘的掌法配合指气凝剑，根基已达武臻化境，并能冷静判断与分析当下战况，适时下达各项指令。

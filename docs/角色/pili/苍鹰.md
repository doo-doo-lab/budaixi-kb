# 苍鹰

魔吞十二宫的苍鹰宫代表，头戴鹰形面具，心如止水、泰然自若，低调不语的性格，更增添神秘难测的气息。能以剑气化鹰、翱翔戾天，战斗中以高乘的掌法配合指气凝剑，根基已达武臻化境，并能冷静判断与分析当下战况，适时下达各项指令。

## 角色背景

苍鹰自魔吞不动城现身以来，其真实身份一直是热门话题，剧中描写其武学合万千招式、至无招无式，如武林宗师的风范，随着剧情演变，苍鹰身份揭晓，果然是刀狂剑痴叶小钗。

苍鹰

魔吞不动城的计划，素还真很久之前就已构想，素还真曾请秦假仙转交书信给叶小钗，进行秘密任务，后来卜相机关还向秦假仙问起信的内容，秦假仙说是素还真请叶小钗退居幕后，为武林调教一群热血生力军作为栋梁。这里的对话就已向观众透露出讯息了。（创神篇下阙第8章）

战骸回忆过去与战栗公的往事时，思绪混乱，听到村民兄弟的谈话。村民处罚不长进的弟弟，并提到两名戴面具的恩公拔刀相助。也是剧中要透露给观众的，暗示戴面具者行侠仗义。（创神篇下阙第23章）

这两名戴面具的恩公，就是刀猿、剑狼。两人曾挺身阻止恶霸夺取百姓粮食，遇上叶小钗相助，因而加入魔吞不动城，由叶小钗指导武学。

其中，剑狼本名“剑影皓月光”，富有正义感，与刀疾流星行（刀猿）情同手足。在一次运送粮食给难民时被强盗威胁，幸得叶小钗解救，两人便一同拜叶小钗为师，一同习武成长，并被叶小钗赐名为“剑影皓月光”。之后他加入魔吞不动城，承接荒狼宫之代表，化身为剑狼。

假金狮屠灭流书天阙，致使儒门进攻不动城，剑狼意外死于隐春秋之手，之后刀猿为牵制唐绝，也不幸被杀，两位英勇战士之死，叶小钗自是意欲报仇。隐春秋虽杀剑狼，但此乃阴谋者背后操弄，而刀猿之死，目标明确，唐绝自是逃不过。但不动城行事不能泄露身份，苍鹰无法使用叶小钗自身武学，加上沉轮偷袭，报仇未成，之后配合不动城计划，延续唐绝与同伙间的冲突，故暂时按下报仇之事。

## 角色经历

苍鹰（叶小钗）在魔吞不动城期间，训练并带领徒弟刀猿（刀疾流星行）与剑狼（剑影皓月光）。刀猿与剑狼本是富有正义感的青年，情同手足，在乱世中仗义勇为。在一次运送难民粮食时被强盗威胁，得叶小钗相救，两人便一同拜叶小钗为师，后被赐名并加入魔吞不动城。后剑狼与刀猿不幸身亡。

苍鹰（叶小钗）为报徒弟之仇，最终摘下面具，以真身使用太武神器终结唐绝。

场景

魔吞不动城初始设计构想是参考自欧洲巴洛克式教堂建筑，以尖塔为特征，利用西洋风格呈现出神秘感，傲立于险峻山峰，一派独吞天下之势。魔吞不动城城外地界，天上阴阳双月交汇，癸界如同镜子般镜射在眼前，当人一跨入双月地界，便陷入了回阴地，难以脱身。就好像有一道看不见的结界，一直分隔魔吞地界至今。双月乃是神秘机关，可以反射招式，将不动城所受攻击化消，十二宫杀手亦从双月中现身。魔吞不动城大殿以麒麟为主视觉，殿内墙壁上分别绘有麒麟与龙头图案，殿内左右设有十二宫面具台座，肩负任务出城者，面具即不在台座上。

## 来自百度百科的补充

苍鹰，霹雳布袋戏虚拟人物，真实身份为叶小钗，为魔吞不动城魔吞十二宫的苍鹰宫代表。

苍鹰头戴鹰形面具，心如止水、泰然自若，低调不语的性格，更增添神秘难测的气息。佩戴苍鹰面具期间为隐藏身份，多以剑指、刀掌为主要战斗方式，其所持神兵“太武神器”亦常以黑布包裹。能以剑气化鹰、翱翔戾天，战斗中以高乘的掌法配合指气凝剑，根基已达武臻化境，并能冷静判断与分析当下战况，适时下达各项指令。在关键时刻能将剑意提升至巅峰，驱使“无心之痴”化为剑气克敌，罪域创罪者之大将贯天行便亡于此招。

后叶小钗为报徒弟之仇，摘下苍鹰面具，以刀剑在手的太武神器与唐绝决战，终结唐绝，一雪徒弟死仇。

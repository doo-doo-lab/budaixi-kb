# 玉菩提 (玉菩提)
================================================================================

玉菩提

天佛原鄉創立者，亦是創造菩提弓對付波旬之人，在許久之前便已圓寂，在坐化之前遇見山鬼百岫嶙峋，玉菩提刻意被百岫嶙峋刺殺，並讓佛血進入百岫嶙峋體內，使其出現沐靈山的善性人格。之後也藉由神鹿之靈導引，渡化聖邪同體的百岫嶙峋，最終使沐靈山成為天佛原鄉的未來希望。

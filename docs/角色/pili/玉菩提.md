# 玉菩提
================================================================================

玉菩提

天佛原乡创立者，亦是创造菩提弓对付波旬之人，在许久之前便已圆寂，在坐化之前遇见山鬼百岫嶙峋，玉菩提刻意被百岫嶙峋刺杀，并让佛血进入百岫嶙峋体内，使其出现沐灵山的善性人格。之后也借由神鹿之灵导引，渡化圣邪同体的百岫嶙峋，最终使沐灵山成为天佛原乡的未来希望。

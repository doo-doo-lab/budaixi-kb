# 无名（影视剧《霹雳布袋戏》中的角色）

================================================================================

无名是《霹雳布袋戏》系列剧集中的虚拟角色，由黄文择配音，初登场于《霹雳皇龙纪》第1集。其身份为诡龄长生殿集结五大高手肢体制造的人造人，后成为法门教主殷末箫的关门弟子，曾效力于紫耀天朝任荡寇将军。无名诞生于血腥池，因长生殿覆灭提前出世，被殷芊妘救回法门后习得法篁绝式。受咒术控制期间多次袭击正道人士，经一页书点化摆脱操控。后受八津蛮利用效力六祸苍龙，参与紫耀天朝海防战与异度魔界决战。最终为保护黑夷族自废武功，随部族退隐江湖。角色持有赤虺血鞭与御法剑，掌握定心律、五刑御刀术等武学。人际关系网涵盖创造者彝灿天、恩师殷末箫、仇敌一页书等，配乐包含《相伴》《无名之殇》等曲目。中文名无名配 音黄文择性 别男登场作品霹雳皇龙纪霹雳皇朝之铡龑史霹雳神州登场作品霹雳神州II之苍玄泣来 自血腥池根据地明法殿、黃阪坡、紫耀皇殿身 份长生殿人造人、紫耀天朝将军本尊雕偶师潮州君皇角色编剧隽尚出场集数79集

## 人物经历

身为诡龄长生殿的终极武器，聚集五大高手的身体合成，被彝灿天视为杀手锏。可惜未等到出关，彝灿天败亡在一页书手里，诡龄长生殿也随之灭亡，无名亦身负潜在的怨念与仇恨提前出关。出关后流浪江湖，被法门教主的大女儿殷芊妘所救，带回法门。后逐渐展露出超凡的武学天赋，加之单纯的心性，深得法门教主殷末箫的喜爱，并收之为弟子，欲传其毕生修为。无名后逐渐接受法门的任务，并展现出仁勇兼备的素质，深得殷末箫信任，传其法篁绝式，被默认为法门的继承者，与殷芊妘产生了一段朦胧纯真的情感。时值六祸苍龙应运而起，殷末箫为维护公理正义，配合一页书围杀祸龙，在祸龙被汲无踪偷袭重创后，殷末箫、一页书守住两条退路，无名居中策应。在即将斩杀六祸苍龙的时刻，无名因为见到一页书，恢复了身为诡龄长生殿武器的记忆，被术法控制，神智陷入疯狂，出手攻击一页书，从此开始了身为终极武器的复仇之旅。曾经被四非凡人利用，欲逼走寂寞侯，却反遭寂寞侯的算计，间接成为其利用的打手。重创羽人非獍与愁落暗尘，杀戮法门聂商等好友，连翠山行等道门人士亦被杀害。（其后也遭到宇文鹰和燕归人的报复）在于殷末箫的对决之中败于法门绝技劫道无念‧剑狱天穹，神智一度恢复，却跌落悬崖。后被黑夷族文字春、小猴、赫歆所救，并与之结成好友，文字春的琴声也间接帮助无名稳定情绪。可惜在黑夷族的同时也受到八津蛮，神魁战武等人的利用，无名心思越加混乱，最终再次被咒术控制，狂性大发，杀出黑夷族，并且打伤恩师殷末箫，殷末箫也因此被魔界活捉。最终，无名与一页书对决，一页书诈败假死，借此点化无名，使无名彻底摆脱了诡龄长生殿的术法控制，成为了正道的一大助力，并在关键时刻硬接袭灭天来的杀招，伤而不倒，保住了恩师殷末箫。更与殷末箫联手，协助一页书完成千年一击，击杀魔龙，重创异度魔界。但是自认为自己罪大恶极，无颜面再回法门，故告别恩师，意欲前往黑夷族安居，后深得黑夷族民心，渐渐立足。袭灭天来孤军入中原，法门措不及防，殷末箫被寂寞侯算计，失去援助，为保护紫宫太一、眉笑佬与法门弟子独自当关，血战而死。无名得到消息，为了求得黑夷族的援助不得已表示愿意臣服八津蛮，可惜还是晚了一步，恩师战死，无名痛彻心肠，决心完成恩师的遗愿，致力以天下清平。在中原与魔界的决胜战之中，无名力战吞佛童子，吞佛童子为了消灭袭灭天来，战不数合便走，最终导致袭灭天来被无名、千流影、六祸苍龙三人围攻败走。在黑夷族期间，与文字春相处产生了不同于其他人的情感，在守卫海防时，收到文字春的书信，心有所触。紫耀天朝建立，无名因功被封为荡寇将军，成为紫耀天朝的最大战力，但因其功体克制六祸苍龙而被其忌惮。禁武令之下，无名帮助天朝征伐不远归降的帮派，夜摩市案发，无名又帮助铲除东瀛暗桩。地狱岛意欲侵占海防，无名被派往海防线驻扎，多次交战，也逐渐对自己的行为产生怀疑，开始思考自己帮助六祸苍龙是否是恩师的遗愿。最终，紫耀天朝的海防线被攻破，无名力战地狱岛三位岛主，身背受伤的赫歆，周身引动电流之力，所向披靡，最终杀出重围，但却先回黑夷族。后因允爱君为生源槐树不择手段，杀死赫歆与八津蛮，无名怒战允爱君未果。随着寂寞侯出走，无名在天朝之内越发困惑，最终决定退隐黑夷族。六祸苍龙在送别宴会上毒杀无名，幸有体内长生殿与不老城两股力量融合解除毒素。随后与殷末箫英灵再现，御法再出，无名决心为天下除祸龙，血战六祸苍龙，依靠功体相克一度占据优势，却终因寡不敌众败走。六祸苍龙为了斩草除根，先屠杀法门隐居的弟子，再绑架黑夷族众人，无名无奈之下，自废武功，六祸苍龙举手欲杀，被魔龙祭天劝阻。英雄江湖路已到尽头，一身修为还于自然，最后无名随着黑夷族退隐江湖。后遇到神鹤佐木与冲田鹰司，间接点化了冲田鹰司。

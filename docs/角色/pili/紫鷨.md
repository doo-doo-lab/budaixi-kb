# 紫𪉊

霹雳布袋戏中的角色。紫色余分的小妹，个性活泼天真，聪明伶俐，但因痼疾缠身，让她多了几分任性与刁钻。紫家先祖当年因救了初代金晶灵，因而获赠至宝金圣衣，紫家将金圣衣世代供奉，不敢亵渎。但不知为何，从获赠金晶灵开始，紫家历来的女子，皆会有一人被宿疾缠身，不能离开金圣衣太远，直至终老。紫家兄妹感情甚笃，但也因牵扯上玄同太子而遭横祸，被木之琊不信邪以人质要胁，最终紫色余分选择捍卫玄同而亡，然过程中也加深了紫𪉊对玄同的好印象。

## 角色背景

紫色余分的小妹，个性活泼天真，聪明伶俐，但因痼疾缠身，让她多了几分任性与刁钻。

紫家先祖当年因救了初代金晶灵，因而获赠至宝金圣衣，紫家将金圣衣世代供奉，不敢亵渎。

但不知为何，从获赠金圣衣开始，紫家历来的女子，皆会有一人被宿疾缠身，不能离开金圣衣太远，直至终老。

紫家兄妹感情甚笃，但也因牵扯上玄同太子而遭横祸，被木之琊不信邪以人质要胁，最终紫色余分选择捍卫玄同而亡，然过程中也加深了紫𪉊对玄同的好印象。

与玄同因替阎王取药的关系，来到天堂森林，两人命在旦夕时被隐居天堂森林的金晶灵香染衣所救。

紫家与金晶灵族之间的渊源，也牵动了紫𪉊与香染衣之间的交集与命运。

霹雳布袋戏虚拟人物个性活泼的天真少女，乃紫色余分的亲妹，身上有历来紫家女子皆会染上的不治宿疾，使得自身无法离开传家宝金圣衣太远。为照顾妹妹，紫色余分将一铃铛交给她，并交代若身体不适可摇铃通知紫色余分。本无意接受金晶灵之力的紫𪉊，在玄同危急之时，为救玄同在香染衣的协助下完全接受了金晶灵之力，成为金晶灵一族之王。

## 角色经历

为什么紫家的女人，一出生就注定，要被那件破宝甲绑住！

大哥就不用！

如果我们两个对调，不管大哥摇几次铃，紫𪉊都会赶回来的……大哥，今生能与你做兄妹，是𪉊儿最开心的事情，希望来生有缘，再做兄妹……大哥，你不要丢𪉊儿一人在此，若要回去，𪉊儿陪你。

如果𪉊儿只剩几天可活，那也要好好看过这个世界才死啊。

那以后大哥要去哪里，是不是都能带着𪉊儿，不要再抛下我一人了，我怕你们都不要我了……太子？

哈哈，你未免将自己膨胀得太伟大了，看你的颜色，比较像明太子~大哥，你说从今以后，𪉊儿在哪里、你就在哪里，不可以食言喔，𪉊儿会在安全的地方等待你回来。

我以后都不会再乱摇铃了！

大哥，你不要生气，快回来好不好！

呜，大哥——！

我只是平凡的小老百姓，只想拥有平凡的幸福。

如果能可厮守在喜爱的人身边，每天看着他，感受他的喜怒哀乐，分享两人生活的点点滴滴，这样比什么力量，都来得使人有活力啊。

能与心爱的人一起走五十年，比起无穷的生命，更让人觉得珍贵。

反正咱们的感情不对等，一直以来都是我在缠你，现在这样也好，也好……我原本想一直缠你，总有一天，你会将我放在心上，所以不管你是不是有相同的意思存在，这个位置，我一点都不想让开，但现在……你放心，我一定不会将你忘记，我会牢牢将你记在心底，但是不是能请你，悟剑闲暇无聊时，也能想我一下下，这个心口的跳动，有时也能为我变快一些……明太子，𪉊儿来带你回去！

有我在，你不会痛了！

紫𪉊已是过去式，现在我是金晶灵的一员。

有人讲，我只要继承了金晶灵之力，自然能淡忘世间的情爱。

但如果能忘，那我现在心口莫名的颤动是为什么？

见到你未曾醒来，我眉间的忧愁又是为什么？

或许，一切等你醒过来之后，我这悬宕的心，才能有个着落。

玄同啊玄同，我的明太子，我用心在叫唤你，你有听见吗？

曾经，我认为我是被剪去羽翼的鸟儿，被困在金圣衣的牢笼中，无法自由飞翔。

如今，金圣衣成了我的羽翼，我却有了一个不愿再飞的对象，希望能永永远远留在那个人的身边，但那个人却不需要我的陪伴。

你说，这是不是很讽刺？

如果每一个问题，都有它标准的答案，那我现在就不用苦恼了。

可惜没有。

我已继承了金晶灵力量，对于人世的感情已经淡了。

因为金晶灵力量，我一直控制的不够好，施展不全，才使得枯木不能回春，死物无法重生。

只要我能将金晶灵力量全数激发，那些死去的人就能死而复生了。

金晶灵之王没有情感的，我怎会想哭？

我不会哭啊！

我不会哭的！

眼泪流下来就表示我的心，还不够纯粹，修炼还不够，这样我的金晶灵力量会发不出来，我不能哭！

我可以救他们的，只要我再强一点就好了……

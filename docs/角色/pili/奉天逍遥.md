# 奉天逍遥（霹雳布袋戏虚拟角色组合）

================================================================================

奉天逍遥是台湾霹雳布袋戏中的虚拟组合，由神毓逍遥（天迹）和君奉天（法儒无私）组成。两人作为云海仙门玄黄三乘中的“天地”代表，自2017年《仙魔鏖锋》系列登场后成为高人气角色。天迹隐居于仙脚之巅却心系武林，君奉天原是德风古道昊正五道守护者，因单锋罪者事件重入江湖。该组合活跃至《斩魔录》后期因剧情暂时退场，后于《破邪传》中复活参与逆神七皇主线剧情。中文名奉天逍遥组合成员神毓逍遥、君奉天登场时间2017年代表音乐《奉天逍遥（演奏版）》所属专辑《霹雳魔封剧集原声带贰-精选73》相关剧集《仙魔鏖锋》《破邪传》

## 角色背景

神毓逍遥（天迹）居住于仙脚之巅，通过派遣秦假仙干预江湖事务，与地冥形成制衡关系；君奉天（法儒无私）原为德风古道昊正五道守护者，因单锋罪者案件受玉离经之请重出江湖。二人作为云海仙门出身的顶尖存在，自年少起就以"奉天逍遥"为名组合行侠仗义，在江湖上有美名流传。其经典台词“愿苍生不再哭泣，愿邪恶不再猖狂，愿家园得到圆满，愿正义永不消灭”集中体现了二人的侠义精神与守护苍生的信念。

## 剧情发展

在其主场剧集《仙魔鏖锋》与《仙魔鏖锋Ⅱ斩魔录》期间，组合通过"40集友情论"等经典情节展现深厚羁绊。二人经历《破邪传》复活后参与逆神七皇主线。

## 音乐作品

该组合拥有专属音乐《奉天逍遥（演奏版）》，由贾爱国与霹雳布袋戏合作创作。该曲目收录于2019年3月22日发行的原声专辑《霹雳魔封剧集原声带贰-精选73》，2023年相关MV被收录于酷狗音乐平台"两大男团与动漫的碰撞"专题。此外，该组合还拥有角色歌曲《奉天逍遥（天迹&君奉天之歌）》，由廖明治作词，贾爱国作曲并编曲。

## 相关设定

作为霹雳布袋戏角色，继承该系列诗号文化特色——天迹诗号"击冥霄，辟晴曌"与法儒诗号"正天地所不正"广为人知。其木偶造型融合传统偶艺与现代审美，武戏设计延续霹雳系列特色。

# 收萬劫 (收万劫)
================================================================================

收萬劫

天邪八部眾中的「阿修羅王」，同時也是道皇聖無殛的關門弟子「星宿一奇」，身負正宗道門玄功、以及厄禍邪力，性格冷酷陰柔，酷愛血紅之色，渾身上下充滿艷紅的邪殺之氣。與青陽子雙雙現身道武王谷，一舉奪走擘古鏡封印的八歧龍首，並崩毀界天塔地脈，震驚在場眾人。

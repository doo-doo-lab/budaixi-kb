# 天跡子 (天迹子)
================================================================================

天跡子

奇花八部中的怪花，個性較為尖酸刻薄，善作兩面人，對於妖繪天華的炭繪情蠻花之術，內心頗不以為然。擅使毒粉，其因習花粉具有麻痺之效，能牽制敵人行動。在步出留妖山城途中，與劫花遭花臉殺手伏襲，雙雙斃命。

# 鬼谷藏龙

霹雳布袋戏虚拟人物鬼谷藏龙，霹雳布袋戏虚拟人物百韬略城之主，他头戴金冠，身着王袍，手持黑檀笏，雄才大略、成竹在胸，兼通兵家与纵横家之学，善于剖析天下局势，昔日曾与梵天论交通机严，后受一页书之请，带领略城介入苦集两境给盟之事。

## 角色配乐

- **◎鬼谷藏龙（鬼谷藏龙角色曲）曲/编曲：阿轮** — 《霹雳震寰宇之兵甲龙痕剧集原声带》
- **官方桌布运用木琴浑圆清透以及钟琴薄脆清亮的音色，彷如置身在深远辽阔的音场中，将略城之主的王者风范与正派大器表露无遗。

沉稳的节奏、悠扬的旋律，在管弦组以及中西打击乐器的铺陈下，让人倍感尊贵典雅。◎风云自藏龙（鬼谷藏龙武戏曲）曲/编曲：鬼毛浩** — 《霹雳经武纪之枭皇论战剧集原声带》
- **作者以黎明前的破晓为题，以管弦乐编制呈现紧迫逼人却又壮阔的气势，紧凑的弦乐与管乐器的破题协奏，具体呈现风起云涌的波澜壮阔。◎百韬略城（百韬略城情境曲）曲/编曲：孙敬凡** — 《霹雳经武纪之枭皇论战剧集原声带》

这首有着高远意境的场景音乐系由孙敬凡老师创作于2005年底，当时孙老师刚完成首张个人专辑《梦春秋》的发行，对于这类融合东方意象与西方乐器的乐曲十分驾轻就熟，也可由此曲的风格中窥见孙老师个人专辑的风格。

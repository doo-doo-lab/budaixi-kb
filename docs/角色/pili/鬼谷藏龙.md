# 鬼谷藏龙

================================================================================

霹雳布袋戏虚拟人物鬼谷藏龙，霹雳布袋戏虚拟人物百韬略城之主，他头戴金冠，身着王袍，手持黑檀笏，雄才大略、成竹在胸，兼通兵家与纵横家之学，善于剖析天下局势，昔日曾与梵天论交通机严，后受一页书之请，带领略城介入苦集两境给盟之事。中文名鬼谷藏龙配 音黄文择性 别男登场作品霹雳震寰宇之兵甲龙痕本尊雕偶师萧佟兴出场集数27集身 份百韬略城之主

## 角色设定

010203名称：鬼谷藏龙性别：男诗号：笑开八面锋，横槊大江东，胸有平戎策，风云自藏龙。初登场：霹雳震寰宇之兵甲龙痕 第3集退场：霹雳震寰宇之兵甲龙痕 第29集（被魔化一页书重伤，劫随带回百韬略城途中故意延误救治时机而死，死后尸体被妖后操控）再登场：霹雳震寰宇之兵甲龙痕 第38集（行尸化）再退场：霹雳兵燹之圣魔战印 第8集（被一页书净化）根据地：百韬略城、呼尧阙、阴司鬼池

## 角色能力

- **武学**: 八纮四纪天子风、玄元一撤、纳天神藏、六韬印、百年兵凶一式荡、天子定夺笔千秋所有物：九韶遗谱

## 人际关系

组织门派：百韬略城、邪尊道（非尸流）朋友：一页书妻子：惜夫人儿子：赤子心内兄：擎海潮上司：妖后（行尸化）部属：刑剑罪己、玉权臣、劫随、列鸿缺（百韬略城）同伙：红流邪少、虚灵魔官、追魂、犽月、异法无天（行尸）

## 角色配乐

◎鬼谷藏龙（鬼谷藏龙角色曲）曲/编曲：阿轮 收录于《霹雳震寰宇之兵甲龙痕剧集原声带》官方桌布运用木琴浑圆清透以及钟琴薄脆清亮的音色，彷如置身在深远辽阔的音场中，将略城之主的王者风范与正派大器表露无遗。沉稳的节奏、悠扬的旋律，在管弦组以及中西打击乐器的铺陈下，让人倍感尊贵典雅。◎风云自藏龙（鬼谷藏龙武戏曲）曲/编曲：鬼毛浩 收录于《霹雳经武纪之枭皇论战剧集原声带》作者以黎明前的破晓为题，以管弦乐编制呈现紧迫逼人却又壮阔的气势，紧凑的弦乐与管乐器的破题协奏，具体呈现风起云涌的波澜壮阔。◎百韬略城（百韬略城情境曲）曲/编曲：孙敬凡 收录于《霹雳经武纪之枭皇论战剧集原声带》这首有着高远意境的场景音乐系由孙敬凡老师创作于2005年底，当时孙老师刚完成首张个人专辑《梦春秋》的发行，对于这类融合东方意象与西方乐器的乐曲十分驾轻就熟，也可由此曲的风格中窥见孙老师个人专辑的风格。

## 角色记录

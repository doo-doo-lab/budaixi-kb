# 赤子心（霹雳布袋戏虚拟人物）

================================================================================

赤子心，

**本名**：鬼谷晏，是霹雳布袋戏虚拟人物

**称号**：‘豪云侠少’，由黄文择

**配音**：。

**初登场**：于《霹雳震寰宇之兵甲龙痕》第4集

**身份**：为百韬略城少主，常以赤子心为

**化名**：行走江湖，性情天真热情但行事放荡不羁，因不愿受到约束流连于薄情馆。赤子心曾被啸日猋重伤濒死，后又遭劫随暗算而死，后被天者以万妖炉复活却受控于死国势力，性情转为暴戾并杀害亲友。最终被

**母亲**：惜夫人毒毙

**退场**：于《霹雳经武纪之枭皇论战》第2集。其

**武学**：包含《清之卷·群邪清平》

**武器**：为剑，角色关系涵盖父母鬼谷藏龙、惜夫人

**妻子**：艳无双及友人失路英雄等。赤子心之死导致百韬略城失去少主，其父母承受丧子剧痛，略城再无常驻薄情馆抛金纵情的豪少身影。

◎豪云侠少（赤子心角色曲）曲/编曲：阿轮 收录于专辑《霹雳英雄音乐精选二十七:兵甲龙痕》，发行于2010年9月28日。以轻快悠扬的笛音旋律开场，带出游侠的潇洒率真，木吉他、弦乐组则轻弹点缀出游走江湖的潇洒惬意。律动的旋律佐以贝斯、爵士鼓、多情而奔放，将豪少的浪漫情怀表现得丝丝入扣。◎群邪清平（赤子心武戏曲）曲/编曲：阿轮 收录于《霹雳英雄音乐精选二十八》本曲作为赤子心闯荡江湖武戏之用，自然少不了初生之犊的热血激昂，故开头便以极骤重击的快板节奏拉开序端，随着一连串音乐陡升爆发而出的气势，让听者的情绪也跟着热血起伏。

赤子心舅侄曾被啸日猋重伤濒死，后又遭劫随暗算而死，被谱君刑以寄阳珠短暂复活并暗示城主夫妇可求助死国，后被天者以万妖炉妖力复活，但复活后性情大变，被死国控制，先后杀死拣角吃毛、刺杀失路英雄，杀死姨母房虹。后被失路英雄打成重伤，回到百韬略城后被惜夫人用毒毒死。

## 角色评价

鬼谷晏，不，还是叫他赤子心吧！

他的心，如赤子一般，是毫无瑕疵的纯洁，如赤子一般，是未曾污染过的神圣……或许在诡谲多变的江湖中，拥有一颗赤子之心确实是幼稚的，甚至是可笑的，但是胸怀一颗赤子之心的人，何尝不是可敬的？

可爱的呢？

鬼谷晏便是这样的人，心境清澄如水，善待自己，也善待别人。

他对女性的重视不是风流的滥情，而是发自心底的一种尊重，以及对美的赞叹和欣赏！

他对乞丐的施舍不是假装豪气的自我陶醉，而是出于真心的一份善良和真诚。

是的，他是温润的青玉，没有金银的闪耀，却有一股散发着清澈澄明之气的美好，感染着他身边的每个人，从双亲、爱人、朋友、甚至是那些不相干的人……赤子心敞开着自己的一切，包容着除邪恶以外的一切事物，只有未曾污染过的心，才能焕发那份灵动的真诚与可爱，闪耀着令世人赞叹的欣喜！

他总是快乐的，他也总是给别人带来快乐，但绝不是强颜欢笑的隐忍。

也正因为如此，他的死，何其悲哀，又何其有幸呢？

悲哀的是，如此将要旭日东升的骄阳，还未散发他该有热度便如此陨落了，庆幸的是，一颗如此美好的赤子之心，此番轮回没有沾染上世间尘埃，是最为纯净的一枚完璧！

他的洒脱，他的骄傲，他的率真，他的温情，他的聪慧，他的善良，他的一次又一次如顽皮的孩子般的调笑，每一面都是他的本性，每一种美好都是他的气质！

他的一生是一首恬静却又欢快的乐曲，只可惜最后的休止符是是一曲悲情，更是江湖无常，人生跌宕的叹息与写照。

哭吧，为他留下伤悲的泪，叹吧，为他动一次诅咒的粗口，痛吧，为他实在的心痛一次，唱吧，为他唱一曲铭心的挽歌……是啊，不只是我们，他血脉相依的亲人，他曾经生死与共的战友，他心中最牵挂的挚爱，比我们更伤，更痛！

何曾见过刚毅果敢的惜夫人泪流如雨，何曾见过稳重如山的鬼谷藏龙如此的衰微无力……天伦梦断，丧子之剧痛，如何演说？

怎样表达？

再坚强的人也无法承袭这样的痛苦，无情的人也无法面对这样的事实。

这何其美满的一家再无团圆之日，从此略城再无他们鬼精灵般的少主，再无那个总是给他们带无尽麻烦和无尽欢乐的鬼谷晏，薄情馆外再无豪少抛散金银的身影……我们依旧无法改变这个事实，所以我们依旧只能选择铭记，铭记住他的名字，铭记住他的故事，铭记住他给我们带来的欢笑！

别了，赤子心。

**赤子心**为台湾霹雳布袋戏人物，登场于霹雳震寰宇之兵甲龙痕第4集，本名**鬼谷晏**，乃鬼谷藏龙与惜夫人的独子，是为百韬略城少主，为人豪气大方，但江湖经验不足而过度乐观好玩，因而在霹雳震寰宇之兵甲龙痕第26集惨亏于啸日猋掌下，一度被死国救起。

于霹雳经武纪之枭皇论战第二集，因惜夫人得知房虹及拣角吃毛已遭其毒手，在他败给失路英雄之后，愤而将其毒死。
==人物介绍==
**豪云侠少赤子心**，曾获舅父擎海潮传授清字卷上的一招“群邪清平”，初登场时以薄情馆贵客姿态，每逢初一，大赏银两，实则这些钱都是他从家中窃出，擎海潮只教他一招掌法的用意在于磨练他的心志，所以暗中安排好友拣角吃毛照应，拣角吃毛遂以乞丐姿态混迹讨饭人中和赤子心结识<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/04.HTM] 霹雳震寰宇之兵甲龙痕第4集</ref>。

当赤子心在追求薄情馆花魁艳无双时，适逢火宅佛狱遣机会者来擒禳命女，赤子心挺身英雄救美，巧妙利用薄情馆禁武规定，使机会者绝于馆内禁武的条令下，并答应禳命女请托出手去找寒烟翠，意外结识失路英雄，并在开导他正义理念后，成为莫逆<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/05.HTM] 霹雳震寰宇之兵甲龙痕第5集</ref>。

当火宅佛狱续派代替者来抓禳命女时，赤子心再度挺身，击毙代替者，随后和失路英雄为护送禳命女往见枫岫主人，对上集境跟火宅佛狱两方人马，混战中赤子心连毙钩命者、束缚者，并用兵甲武经清字卷的“群邪清平”打死狙击者<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/08.HTM] 霹雳震寰宇之兵甲龙痕第8集</ref>。

并在失路英雄和夜神决战后，拉他一同参加略城寿宴，用从家里偷出的九韶遗谱当贺礼，使鬼谷藏龙哭笑不得<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/11.HTM] 霹雳震寰宇之兵甲龙痕第11集</ref>。

就在赤子心被父母强迫留城之际派劫随跟列鸿缺看管，所幸朋友小鬼头装肚痛帮忙骗走劫随，列鸿缺立即被绑起，赤子心顺利离城。

可是因为寿宴上出现的雅狄王遗书，使赤子心、失路英雄被火宅佛狱跟撒手慈悲围攻，最后是拣角吃毛救走两人，并将两人带往银碗盛雪面见擎海潮，擎海潮也因生出让赤子心成家念头，打算让他娶自己新收的义女忘忧(即失去记忆的玉倾欢)<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/12.HTM] 霹雳震寰宇之兵甲龙痕第12集</ref>。

赤子心用回家告知父母同意婚事的借口离开银碗盛雪，却在路上被蒙面人袭击，在他负伤见红时，拣角吃毛飞身救人并护送赤子心前往百韬略城，断绝赤子心欲往薄情馆快活念头，但答应替他送情书与婚戒去给艳无双。<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/12.HTM] 霹雳震寰宇之兵甲龙痕第15集</ref>。

赤子心回到略城时，正逢剑子仙迹等人为寻得克制玷芳姬方式向略城求助，进入了惜夫人安排的阵法中，漠刀绝尘、求影十锋、情尼孤禅、万古长空、鸦魂、笑剑钝依旧不敌，幸得赤子心和失路英雄驰援方补全攻势破阵<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/16.HTM] 霹雳震寰宇之兵甲龙痕第16集</ref>，因此在获鬼谷藏龙首肯出战后，赤子心按照阵法参加围攻玷芳姬，在群侠围攻下，顺利击毙玷芳姬<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/17.HTM] 霹雳震寰宇之兵甲龙痕第17集</ref>。

当地者来犯略城并轻易击退略城兵阵后，失路英雄及**赤子心**分别使用兵甲武经中地字卷和清字卷的功夫对付地者，地者也回以兵甲武经灭字卷的“寰宇尽灭”以一敌二打平，随后因夜神闯入万妖炉使阿修罗停滞，地者遂收兵回死国<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/19.HTM] 霹雳震寰宇之兵甲龙痕第19集</ref>。

而在面对舅父擎海潮逼婚时，赤子心抢先一步和擎海潮属意的人选玉倾欢结拜兄妹，好杜绝他的主意，同时带玉倾欢去见自己真正钟情的艳无双，表示定要娶艳无双为妻，本纠结于要向薄情馆主慕容情报恩的艳无双获其同意后，终于首肯。<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/23.HTM] 霹雳震寰宇之兵甲龙痕第23集</ref>。而在赤子心回禀父母途中，和玉倾欢遇上失常的啸日猋，玉倾欢因失去记忆没能和啸日猋相认，使啸日猋更加疯狂，并认定赤子心为下个对付目标。

啸日猋离去后，赤子心回城获惜夫人同意和艳无双的婚事，正当欢天喜地的赤子心出城打算帮助失路英雄找寻最轻的刀来破解阿修罗和万妖炉的联系，又遇上为夺清字卷而来的啸日猋，败给他的天字卷“天之挽曲”而遭擒<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/25.HTM] 霹雳震寰宇之兵甲龙痕第25集</ref>。，啸日猋用赤子心性命和鬼谷藏龙交换清字卷，但在释放人质时偷补一掌，使赤子心亡于父母怀中<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/26.HTM] 霹雳震寰宇之兵甲龙痕第26集</ref>。

在死国为解救阿修罗之际，因为略城夫人与死国的交易，使其复活，后来因复活后，成为死国卧底的关系，杀了拣角吃毛，并在失路英雄与啸日猋对决后，暗杀失路英雄未遂。

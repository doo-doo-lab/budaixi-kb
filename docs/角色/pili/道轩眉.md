# 道軒眉 (道轩眉)
================================================================================

道軒眉

身披華服、稀玉為冠，羽扇在握，更襯其仙風道骨、器宇軒昂。因當年一場意外，多年來隱居於一衣帶水深處。年少時與玉逍遙有「逍遙忘機」美名傳世，天跡於他除世族之情，更有救命之恩。個性耿介正直，有不流於世俗的操守氣節，且劍及履及，恩仇必報。羽扇觀世，應時渡世，當仁不讓。

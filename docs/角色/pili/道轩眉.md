# 道轩眉

身披华服、稀玉为冠，羽扇在握，更衬其仙风道骨、器宇轩昂。因当年一场意外，多年来隐居于一衣带水深处。年少时与玉逍遥有“逍遥忘机”美名传世，天迹于他除世族之情，更有救命之恩。个性耿介正直，有不流于世俗的操守气节，且剑及履及，恩仇必报。羽扇观世，应时渡世，当仁不让。

# 傲凌霄

圣龙口位列六色旌旗的旗主，个性较为傲气自信，武力高强，实力不亚于豁青云。武器为浪影枪，算是六位旗主中，较为重要的人物。在炼魔塔攻打圣龙口陷危时，及时驰援解围，逼退昡祭冥司。

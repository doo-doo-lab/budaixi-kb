# 傲因 (傲因)
================================================================================

傲因

原出身于贫民区庸流萍寓，跟随判神殛多年，借由深沉心思而渐渐成为怪贩妖市一人之下、万人之上，仅次于判神殛的妖市第二把交椅。难以度量，且极为自负，无法容忍自己的失败，并有着偌大的侵略野心。在妖市中拥有立法与审判的绝对权力，专司军、刑二务，手握霸疆长刀，傲气狂嚣，对任何违逆妖市者，杀无赦。

# 傲因 (傲因)
================================================================================

傲因

原出身於貧民區庸流萍寓，跟隨判神殛多年，藉由深沉心思而漸漸成為怪販妖市一人之下、萬人之上，僅次於判神殛的妖市第二把交椅。難以度量，且極為自負，無法容忍自己的失敗，並有著偌大的侵略野心。在妖市中擁有立法與審判的絕對權力，專司軍、刑二務，手握霸疆長刀，傲氣狂囂，對任何違逆妖市者，殺無赦。

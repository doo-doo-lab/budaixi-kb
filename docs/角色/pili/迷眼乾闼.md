# 迷眼乾闥 (迷眼乾闼)
================================================================================

迷眼乾闥

外聚七修之首，乃天下間僅存懂得鬼言秘密之人，能以眼睛施展異能，以及在影子間移轉的能力，故有影邪師之稱。因接觸惡鬼三凶，使得原本偏差的心性，更加邪門，進而欲併吞內七修之武學，後為意琦行所敗，囚禁於通天道的禁忌之門內。

# 风月主人

南武林颇负盛名的预言家，出场时，伴随着九天虹桥，自信从天而降。善以推背图预言定吉凶，自言目标是解开推背图真正的排序。其作风神秘，行事游走于正邪之间，令人难以捉摸。
实则，风月主人身份为镜族之影，本协助海宇之主，共成鳞族大业。然而在过程中，风月主人却发现自己乃异天魔族之后，遂兴叛出之意，在海宇之主壮烈牺牲后，陆续取得皇鳞与战鳞等鳞族两大至宝后，以君辅之身份回归，早与之暗中有合作的兵祸血色塔。

人物经历
本为海宇之主的影，二人容貌无别。在外游走期间成为兵祸血色塔君辅，并得南武林预言家之声名。在《霹雳靖玄录》中初登场：于荒野上现身，阻止秦假仙、破玄奇追捕春申昌，伴随着神秘浮泡、神龟负书、玉宇琼楼破海而出等异象，九天虹桥出现，风月主人傲览红尘；随后救下秦假仙，又以推背图为依据，发出轩昂五玑的死亡顺序。为工作需要，多次救助小水仙。后深入死亡三角洲，遇血鲲鯩，得知家族渊源，萌生壮志，吸收异天魔功，与占云巾赌斗预言，在皇鳞死后获得逆世双鳞。在《霹雳兵烽决》中又相继得到逆玺剑、鸦九之力，并得到青玉镜（伪）的指点，不料仍遭天剑非天、剑风云相继击败，双腿被斩，气急而疯，在南域接受小水仙照顾。休养期间神志恢复，又被地冥治好双腿，加入十七特工队，对抗太曦神照势力，最终死战玉冰莹而亡。

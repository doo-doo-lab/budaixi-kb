# 風月主人 (风月主人)
================================================================================

風月主人

南武林頗負盛名的預言家，出場時，伴隨著九天虹橋，自信從天而降。善以推背圖預言定吉凶，自言目標是解開推背圖真正的排序。其作風神秘，行事遊走於正邪之間，令人難以捉摸。
實則，風月主人身份為鏡族之影，本協助海宇之主，共成鱗族大業。然而在過程中，風月主人卻發現自己乃異天魔族之後，遂興叛出之意，在海宇之主壯烈犧牲後，陸續取得皇鱗與戰鱗等鱗族兩大至寶後，以君輔之身分回歸，早與之暗中有合作的兵禍血色塔。

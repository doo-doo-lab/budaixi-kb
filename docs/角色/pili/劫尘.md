# 劫尘（霹雳布袋戏中的角色）

================================================================================

劫尘是《霹雳布袋戏》中的虚拟人物，为元种八厉中的“地之厉”，性格高傲极端，好强争胜。后因天之厉被封，劫尘遭同族魑岳与贪秽设计迫害，魂体将散之际与即将圆寂的剑通慧缔结契约，得以借其躯体重生，但需代替剑通慧守护禁锢天之厉的佛骨天锁。佛骨天锁崩毁后，劫尘重见天日。

**中文名**：劫尘

主要

## 经历
劫尘是元种八厉中的「地之厉」，高傲极端，好强争胜，喜爱向强者挑战，不服输的性格也让其成了仅次于天之厉的存在。

后因天厉被封，厉族内部因对未来的发展方向发生歧义，劫尘遭山之厉魑岳与泽之厉贪秽设计迫害。

魂体将散之际，遇上即将圆寂的佛者剑通慧。

双方达成约定：劫尘得以借剑通慧的躯体重生，但必须替代剑通慧守住禁锢天之厉的佛骨天锁。

劫尘因此以剑通慧的外表示人，在无尽天封守护天锁长达千年。

佛骨天锁崩毁、天之厉解封后，劫尘重见天日。

因外貌变为剑通慧，她无法回归厉族，心中执念未消。

将悲愤发泄于剑布衣，并与之决斗争夺“太极之气”。

决斗中被剑布衣所伤，临死前明白了剑通慧的算计。

劫尘死后，其好友水之厉冰无漪因此与剑布衣绝交。

不久后“止战之印”盖下，关于圣魔大战的记忆被抹去。

## 角色关系

组织门派：厉族同伴：天之厉、冰无漪（水之厉）、剡冥（火之厉）、魈瑶（风之厉）、魑岳（山之厉）、贪秽（泽之厉）、克灾孽主（雷之厉）其他：剑通慧（借其躯体）劫尘与剑通慧存在契约关系，借其躯体重生并承接守护天锁的职责；冰无漪发现劫尘借体重生真相，并在劫尘死后与剑布衣绝交；劫尘因理念不合遭魑岳与贪秽设计迫害，关系敌对；此外，劫尘与剑布衣争夺“太极之气”并决斗，最终被剑布衣杀死。

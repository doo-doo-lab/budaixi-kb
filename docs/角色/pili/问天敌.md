# 问天敌

================================================================================

霹雳布袋戏中的角色问天敌，霹雳布袋戏中的角色。灭轮枭雄，昔日梵天一页书的宿敌，气势嚣狂、不可一世，曾遭一页书击毙于轮回海，凭借着复仇的意志和佛业双身帮助下，重新凝聚邪元复生。在佛业双身受困百灯联戒时，率十一天禁肆虐苦境，欲助佛业双身脱困。中文名问天敌别 名无界主、邪乘配 音黄文择性 别男登场作品霹雳震寰宇之刀龙传说本尊雕偶师刘氏角色编剧三弦、隽尚

## 角色设定

- **问天敌名称**: 问天敌称号：无界主、邪乘性别：男诗号：纵横无界为主，问天可敢为敌。初登场：霹雳震寰宇之刀龙传说 第7集退场：霹雳震寰宇之刀龙传说 第33集（死于罗喉）来自：灭境

## 角色关系

组织门派：十音无界、妖世浮屠仇敌：一页书（梵天）上司：天蚩极业、爱祸女戎（佛业双身）部属：曲指邪怒、夜暴双镰、梦语独断、鬼艳织香、勾首紫蜒、骨讽蓝嚣、玩命丑笑、天堂之萼（十一天禁）、禁种虫父、养骨者、六轮鬼贼、销骨箕伯、九阴魔蝎、叛经恶蠹齐名：未来之宰（以前同为灭境乱世枭雄）

## 角色能力

武学招式：天关双炼·天坠残阳、天关双炼·阴阳雷殛、天火灭佛、夜武一击、夜武天火、无极归一、天关四化·梵天灭介绍：天关双炼乃是同时带有双属性的特异掌法，针对期门、天池两穴入劲。天关四化·梵天灭：引水火风雷四气归一，乃问天敌为杀一页书所创之招。咒术灵诉邪语

## 角色经历

问天敌无界主问天敌，昔日梵天的宿敌，气势嚣狂、不可一世，曾经统领十音无界控制灭境半壁江山，遭梵天击毙于蓬莱天顶，坠入轮回海中，但凭著一股怨气保持元灵不散，后在佛业双身帮助下，重新凝聚邪元复活，因而投入妖世浮屠阵营，被尊称为邪乘，地位在十一天禁之上。在佛业双身被九界佛皇禁入百灯联戒后，代替佛业双身统率十一天禁，攻下百灯联戒，击败破匣求禅，保护佛业双身安全，并与罗喉交涉，意图欲助佛业双身脱困。除了力战来犯百灯联戒的素还真、叶小钗正道高手，并为夺取如来四像击毙鹿苑五大明王之一的持杵明王元初一念。后为夺死神之子，问天敌逼杀罗喉的天都大将黄泉，并在罗喉死后大举进犯天都，二度带兵围攻黄泉，但罗喉因邪天御武的第二滴心血重生，不但救走黄泉，也和问天敌订下战约。在双峡峰决战当日，问天敌虽然使出为对付一页书创出的压箱绝技“天关四化·梵天灭”，却仍不敌罗喉“殒天斩星诀”，为罗喉所杀。

**問天敵**是霹靂布袋戲角色。
== 背景 ==
昔日一頁書的滅境宿敵，自信狂傲、智謀不凡的一方霸主，爪牙橫張，曾吞併整個滅境，成名絕學天關雙煉，乃是同時帶有水火雙屬性的特異掌法。

宿敵之鬥，最後被一頁書以天龍吼擊落輪迴海。

在昭穆尊危急之時出手搭救，更加入長生殿黑道聯盟行列。欲以不老不死之秘加強功體，與百世經綸一頁書再次決戰。

== 局中局 ==

一頁書以問天敵身份作為暗樁，與蒼和悟僧癡迷等人一起大破長生殿陰謀。

更成功誅殺由匃皇·彝燦天所扮的九章伏藏。

**問天敵**是台灣霹靂布袋戲人物，昔日滅境梟雄，曾為一頁書冒充在霹靂謎城時登場，於刀龍傳說中真正的問天敵再度出武林，登場於霹靂震寰宇之刀龍傳說第7集，霹靂震寰宇之刀龍傳說第33集被羅喉所殺。
==人物介紹==
**無界主問天敵**，昔日梵天的宿敵，氣勢囂狂、不可一世，曾經統領十音無界控制滅境半壁江山，後遭一頁書擊斃於蓬萊天頂，墜入輪迴海中，但憑著一股怨氣保持元靈不散，佛業雙身幫助下，重新凝聚邪元復活，因而投入妖世浮屠陣營，被尊稱為邪乘，地位在十一天禁之上。

在佛業雙身被九界佛皇禁入百燈聯戒後，代替佛業雙身統率十一天禁，攻下百燈聯戒，擊敗破匣求禪，保護佛業雙身安全，並與羅喉交涉，意圖欲助佛業雙身脫困。除了力戰來犯百燈聯戒的素還真、葉小釵正道高手，並為奪取如來四像擊斃鹿苑五大明王之一的持杵明王元初一念。

後為奪死神之子，問天敵逼殺羅喉大將黃泉，並在羅喉死後大舉進犯天都，二度帶兵圍攻黃泉，不意羅喉因邪天御武的第二滴心血重生，不但救走黃泉，也和問天敵訂下戰約。決戰當日，問天敵雖然使出為對付一頁書創出的壓箱絕技天關四化‧梵天滅，卻仍不敵羅喉，為羅喉所殺。

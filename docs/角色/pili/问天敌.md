# 问天敌

霹雳布袋戏中的角色问天敌，霹雳布袋戏中的角色。灭轮枭雄，昔日梵天一页书的宿敌，气势嚣狂、不可一世，曾遭一页书击毙于轮回海，凭借着复仇的意志和佛业双身帮助下，重新凝聚邪元复生。在佛业双身受困百灯联戒时，率十一天禁肆虐苦境，欲助佛业双身脱困。

- **问天敌名称**: 问天敌称号：无界主、邪乘性别：男诗号：纵横无界为主，问天可敢为敌。初登场：霹雳震寰宇之刀龙传说 第7集退场：霹雳震寰宇之刀龙传说 第33集（死于罗喉）来自：灭境

## 角色关系

组织门派：十音无界、妖世浮屠仇敌：一页书（梵天）上司：天蚩极业、爱祸女戎（佛业双身）部属：曲指邪怒、夜暴双镰、梦语独断、鬼艳织香、勾首紫蜒、骨讽蓝嚣、玩命丑笑、天堂之萼（十一天禁）、禁种虫父、养骨者、六轮鬼贼、销骨箕伯、九阴魔蝎、叛经恶蠹齐名：未来之宰（以前同为灭境乱世枭雄）

## 角色能力

武学招式：天关双炼·天坠残阳、天关双炼·阴阳雷殛、天火灭佛、夜武一击、夜武天火、无极归一、天关四化·梵天灭介绍：天关双炼乃是同时带有双属性的特异掌法，针对期门、天池两穴入劲。天关四化·梵天灭：引水火风雷四气归一，乃问天敌为杀一页书所创之招。咒术灵诉邪语

## 角色经历

问天敌无界主问天敌，昔日梵天的宿敌，气势嚣狂、不可一世，曾经统领十音无界控制灭境半壁江山，遭梵天击毙于蓬莱天顶，坠入轮回海中，但凭著一股怨气保持元灵不散，后在佛业双身帮助下，重新凝聚邪元复活，因而投入妖世浮屠阵营，被尊称为邪乘，地位在十一天禁之上。

在佛业双身被九界佛皇禁入百灯联戒后，代替佛业双身统率十一天禁，攻下百灯联戒，击败破匣求禅，保护佛业双身安全，并与罗喉交涉，意图欲助佛业双身脱困。

除了力战来犯百灯联戒的素还真、叶小钗正道高手，并为夺取如来四像击毙鹿苑五大明王之一的持杵明王元初一念。

后为夺死神之子，问天敌逼杀罗喉的天都大将黄泉，并在罗喉死后大举进犯天都，二度带兵围攻黄泉，但罗喉因邪天御武的第二滴心血重生，不但救走黄泉，也和问天敌订下战约。

在双峡峰决战当日，问天敌虽然使出为对付一页书创出的压箱绝技“天关四化·梵天灭”，却仍不敌罗喉“殒天斩星诀”，为罗喉所杀。

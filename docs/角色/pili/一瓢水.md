# 一瓢水

六合武册持有者之一，习有能杀能救的佛手水剑，专精换脑手术，奉行无私大爱的小无念教义。死角一战被震断全身经脉，幸得无心陀、叶小钗以隔山接脉治愈；最后却因说出六合武册秘密，而遭天镜刑者杀害。

# 靜濤君 (静涛君)
================================================================================

靜濤君

道門先天高人，術法超絕，身揹寶劍，智計無雙，乃青陽子多年好友。當年曾受邀參加玄天六陽，但因故婉拒並退隱定濤居，後來為青陽子三顧茅廬請出，輔佐其對抗入侵勢力，擅長布局算計敵手。

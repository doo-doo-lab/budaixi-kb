# 天剑非天 (天剑非天)
================================================================================

天剑非天

非圣非魔，天屿剑族的千年神秘传说，非天是一种非神、非鬼、非人，又介于神、鬼、人之间的特殊状态。传闻中，非天“千年只一现，一剑狂千年”，倦收天曾为封住此不为人知的一面，加入道真修行。而今，非天一旦重现，恐将再掀千年混沌。
非天是战斗怪物，天生本能会散发双极非天识，引动强者前来挑战。性喜运使逐日之招，无远弗届的一剑，中招者脑海之中，会缓缓浮现初升旭日的壮观景象。唯有无比的求生意志，越己之限，方能战胜逐日之招。否则，待脑海中的烈阳，日正当中，中招者生命将随之灿烂结束！

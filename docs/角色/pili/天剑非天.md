# 天劍非天 (天剑非天)
================================================================================

天劍非天

非聖非魔，天嶼劍族的千年神秘傳說，非天是一種非神、非鬼、非人，又介於神、鬼、人之間的特殊狀態。傳聞中，非天「千年只一現，一劍狂千年」，倦收天曾為封住此不為人知的一面，加入道真修行。而今，非天一旦重現，恐將再掀千年混沌。
非天是戰鬥怪物，天生本能會散發雙極非天識，引動強者前來挑戰。性喜運使逐日之招，無遠弗屆的一劍，中招者腦海之中，會緩緩浮現初昇旭日的壯觀景象。唯有無比的求生意志，越己之限，方能戰勝逐日之招。否則，待腦海中的烈陽，日正當中，中招者生命將隨之燦爛結束！

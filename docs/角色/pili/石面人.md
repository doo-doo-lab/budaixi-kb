# 石面人 (石面人)
================================================================================

石面人

黑暗之間接頭人，與驅魔人四分之三似有某種協議，以誅盡天下間的嗜血者為目的，甚至還將矛頭伸向茶理王與嗜血化的蘇安，惹來四分之三的反撲，遭誅魔銀槍所淨化消滅。

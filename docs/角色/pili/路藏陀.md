# 路藏陀

霹雳布袋戏虚拟人物路藏陀，霹雳布袋戏虚拟人物。苍宇医楼的四名玄医之一，专长为研究制药配剂的药理学，面容苍白，神态木然，生性胆小怯懦，畏畏缩缩，不太会与人相处，被点到名时会十分慌张，常独自一人窝在二井天旁，喃喃自语。

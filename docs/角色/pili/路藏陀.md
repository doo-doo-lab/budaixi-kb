# 路藏陀

================================================================================

霹雳布袋戏虚拟人物路藏陀，霹雳布袋戏虚拟人物。苍宇医楼的四名玄医之一，专长为研究制药配剂的药理学，面容苍白，神态木然，生性胆小怯懦，畏畏缩缩，不太会与人相处，被点到名时会十分慌张，常独自一人窝在二井天旁，喃喃自语。中文名路藏陀别 名析闻叛命、笨陀螺配 音黄文择性 别男登场作品霹雳兵燹之问鼎天下角色设定名称：路藏陀其他称号：析闻叛命、笨陀螺性别：男初登场：霹雳兵燹之问鼎天下第36集根据地：二井天组织门派：苍宇医楼上司：掌悬命朋友：假中求、醫畸形、朱三聞同伙：华凤奴、左常坤、髐易和(四玄医)武学：龙虎相争削肉剔骨刀式路藏陀

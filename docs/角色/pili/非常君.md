# 人觉

霹雳布袋戏虚拟人物同义词非常君（非常君）一般指人觉人觉·非常君是《霹雳布袋戏》系列中的虚拟角色，天地人玄黄三乘之一，身份为人鬼之子。

初登场于《霹雳天命之仙魔鏖锋》第7章，以一袭黄裳隐者形象持华伞现世，与武林各派略有交情，喜好四方游历与品尝美食，根据地包括觉海迷津、明月不归沉。

退场于《霹雳天命之仙魔鏖锋Ⅱ斩魔录》第60章，后以冽红角身份再退场于《霹雳惊涛》第41章。

非常君表面调和天地争端，过去曾见证天迹与地冥的逆鳞之巅决战，为避免天地争端重演而积极斡旋。

暗中通过一魂双体秘术分化出越骄子与伪鬼麒主双重身份，操控圣剑魔刀计划与神州崩裂事件。

其人鬼共生体质使其分离出习烟儿鬼体，最终在与一页书的天命对决中战败自尽，印证诗号"一将功成万骨枯"。

其冽红角身份曾牺牲鬼元摧毁养魔池，多重身份布局贯穿《仙魔鏖锋》主线，诗号中"醒，亦在人间；

梦，亦在人间"暗喻角色表里反差。

## 厌火天獠角色设计

（摘自霹雳会月刊第263期封面人物——人觉·非常君）

**背景设计**

人觉·非常君  官方桌布在玄黄三乘在剧中登场后，除了要呈现其高深莫测的神秘感，三人的风格特色也要加以区来，“天”与“地”有明显的对立，“人”也要有其立场——就是人觉有如“公道伯”的好好先生，调停天地之争，还有以前辈之姿，对邃无端照顾有加，展现友善，尽量远离人间战火、安适自得，享受美食与生活。

有别于天迹的救世立场、地冥的灭世手段，人觉的存在与定位，似乎显得比较平淡与辅助。

其实在台面上，人觉的存在确实有他明确的目的，他被九天玄尊赋予辅助人之最的使命，要让人中之龙成为苦境的救星。

而对非常君而言，人之最的命格转化，需要时间去酝酿，当下的他只能等待局势的演变，去扮演推手的动作，而无法主动成为目标。

而人觉身负人鬼之子的悲剧与定位，也使得他无法被仙门承认，只能担任持续辅助的角色。

表面上的设计是如此，但过没多久随着剧情转折，又投入一些难以解释的疑点，比如一体双魂、身怀仙门武学等关键线索，开始让人觉与鬼麒主有点莫名牵连，而人觉清白与否，就在有些人相信、有些人怀疑的情况下，以最出人意料的方式，揭开背后一连串的真相。

加上台面上阴谋层出不穷，人觉的存在反而变得格外的扑朔迷离，更因鬼麒主再出江湖，导致局势变得更为诡异莫测。

**剧情设计**

当初九天玄尊钦点玄黄三乘时，人觉已经被玄尊收为门徒，此事也是极为秘密，人觉从不透露、也否认自己身怀仙门武学，但武学会被怀疑，假设人觉设定为反派，这些疑点，也可能是人觉故意泄露的一丝线索。

刚开始，台面上这个人觉常常围绕在邃无端、剑咫尺身边，编剧在当时就已埋下伏笔，按照悬疑片的规则，在焦点人物身边，一定会有魔爪渗透，看似平淡无奇的角色，越有可能暗藏心机。

但同样的，如果人觉只是单纯的好意，而非有所目的，同样也可以解释这样的行为。

而人觉跟鬼麒主之间，其实有着更加复杂的设计。

人觉图片就在一切阴谋指向人觉的时候，意外在剧情中带出了双胞胎兄弟人殊越骄子的存在，也就是另外一个人鬼之姿子，另一个双胞胎的存在。

而台面上一切的阴谋，都成为鬼麒主，也就是越骄子一手策划，就连台面上的人觉，也是他假扮的。

为了推动自己的计谋，越骄子遇到各种状况，都会选择利大于弊的一方，也会混淆视听，做一些看似矛盾的事情，让人难以捉摸，越骄子说出天迹、地冥体内仍有暗伤之事，导致天地两人针对人觉，看似不利，但也因此引发一连串事端，其实一切都在越骄子绵密的布局之中，甚至看似难料的变量，也成为越骄子利用的布局。

庭三帖虽然只有人觉这个朋友，是个不受大众欢迎的人物，但却又独到的观察力，他第一个以不同角度怀疑人觉，当庭三帖说出疑点，同时也开创了一个不同的思考角度，这个人觉不是真正的人觉，而带出了仙魔鏖锋II中段，非常君、越骄子、监牢中废人的多重身份疑点。

当天迹与法儒介入调查，逼使越骄子现身，也使得非常君再度回到了明月不归沉。

鬼麒主不是当年的鬼麒主，人觉也不是大家认识的那个人觉，越骄子的身份正是揭晓，当下越骄子自然成为众矢之的，但越骄子真正的目的达到了吗？

他的计谋尽头会落在何处？

诸多仇怨恶业累积，越骄子是否将受果报？

因越骄子的现身，武林局势有将有何重大变化？

**造型设计**

人觉初现身时，以优雅闲适的形象，配合神秘高人的特色，除了华丽尊贵，还要有一些悠然自得。

帽子参考传统戏曲中常见的王侯帽，加以改造变化，又有一点东洋风，以呈现人觉的贵气。

编剧希望人觉是伴随金雨现身，因此服装也以黄色系来搭配。

人觉于漫天金雨中现身，张开华伞迎向片片金雨，这是编剧早就设想好的画面。

而雨伞非常适切的将人觉华贵之气与悠然闲适做了巧妙的平衡。

**诗字设计**

人觉·非常君这名字，重点全系于一字“觉”。

觉字本身甚妙，一字包含矛盾对立的“眠与醒”两义，甚还包含提炼体认的“觉醒”第三义。

这三种意涵，在非常君人生中，迭现交错，乘了一个复杂而矛盾难解的绝世高人，内在自绝于人世的孤独心灵。

为了凸显觉字的人生主题，编剧取用宋代词人连久道的《清平乐‧渔父》的最后两句“一觉游仙好梦，任它竹冷松寒”，来作人觉诗号的破题，当时读到这两句时，脑中立刻浮现的画面，便是北窗高卧羲皇侣般的隐世高人，把人觉的旷放胸怀、任世沧桑酣然，尽由“任”字，独写风流。

在这两古句后，编剧再顺着自己朗读的声韵铿锵补上：“轩辕事，古今谈，风流河山”，这是把非常君置入历史长河与壮丽山川的恢弘时空中，塑造主角立于这千古宇宙间的大器感。

然这些都仅是身外变化，都是闲来悠游的人间兴替。

而人觉则“沉醉负白首，舒怀成大观”，意即非常君纵情其中时，任凭辜负流年光阴，霜白了鬓发，仍是沉醉无悔。

然一但他敞襟当风，表露心迹时，便是风云瞬变般的雄心壮志，洋洋大观。

当然，这句诗也是为了贴合人觉最后的剧情演变，便是埋下伏笔。

人觉剧照最后收尾，编剧模仿山坡羊的最后曲式，以“醒，亦在人间；

梦，亦在人间”做结，意味无论醒与梦，都在这片人间。

于是在这里的【人间】一词，究竟对非常君而言，是何等意义，便格外耐人寻味。

尤其如果结合仙魔鏖锋中档，寄昙说（人之最）与非常君（人觉）的“禅觉一会”里，他对禅剑一如提出的试验题目：何谓苍生。

乃至斩魔录最后，揭开最大反派面目的非常君与一页书终战论辩的“苍生/人间”主题，就更能感受非常君对这主题的至大执着与体物尤深，亦即他这一路走来，独自领会的“人之最”。

表面上看来，人觉·非常君的诗号，读来给人一种闲世游世的绝代隐士胸怀，然这只是伪装，直到最后人觉展露其内心的阴暗面时，这些美好景象便成了一种反差、讽刺。

因为诗号的前面几句，无论梦或醒，都不过是人觉内心向往的一场大梦，最终还是会被拉回残酷现实，他逃不开这人间，也不想再逃，因为他有更深刻沉痛的“人生觉念”了。

所以觉字的三面意义揉合在代表非常君人生的诗号中，相信初读时，是一番印象，等到看完人觉整个故事，又是另一番感受。

**场景设计**

觉海迷津·明月不归沈“明月不归沈”编剧是取自李白所作诗《哭晁卿衡》。

人觉剧照日本晁卿辞帝都，征帆一片绕蓬壶。

明月不归沉碧海，白云愁色满苍梧。

晁衡是来自日本的遣唐使，与李白结为好友，当晁衡归国后，音讯全无，李白听说晁衡于海上遭遇暴风，以为晁衡遇难，于悲痛中作此七言绝句，思念好友。

但编剧的用意并不是思念好友，明月不归沉碧海只取其字面上悲伤的意思，是以人觉为外貌的越骄子自伤、自怜的暗笔。

在庭三帖提到有人之最却无天之最、地之最，为人觉打抱不平时，编剧利用这段对话，暗示此时的人觉正在压抑自己。

而越骄子的身份揭开，也象征人觉这份压抑之心的爆发。

## 角色剧情

摘录自《霹雳会月刊第268期》编剧漫谈人物——人觉 · 非常君隐黑未曾更改玄黄三乘的正邪定位，对应他们各自对救世和灭世之关键“人之最”的态度，成了仙魔鏖锋最主要角力的修罗场。

一开始，最初设定就是天地逆鳞之战，担任旁观见证人的人觉非常君，在关键一招时下了暗手，致使天迹被锁入天堂之门、地冥重创窜入黄泉三千丈。

后来因原身为浩星探龙的夸幻之父与一页书灵珠的人之最天命依附合一，致使非常君不得不再出手，以《冥鸿残章》记载，与三光之器现世，来迫逼天迹、地冥现身。

而圣剑、魔刀的培养，便是为杀天地两人而准备，所以才有岔出单锋罪者与忉利狱龙斩的刀剑两条戏路剧情。

人觉剧照而最终结局，一开始也有预设：人觉杀了天、地两者，最终由人之最·百世经纶一页书所诛。

虽然地冥后来因个人故事开展而微调了这结果，然大抵上，这结局就是从一有玄黄三乘这组合便定下的里设定。

既然非常君一开始就设定为“伪装的隐黑角色”，那除了他本身的流浪美食家定位，便也得做些好事才叫伪装。

但他把握的原则就是，在可预期结果或他可容许的牺牲限度下，人觉略施小惠，便能维持住他正派形象，而不被众人怀疑，这对他日后行事便是极大的好处。

所以在旁人认为搏命的表现里奋力演出的维妙维肖。

在人觉做好事的心里，是有个秤铊，随时斟酌得失利弊。

天地人的暗中角力不仅如此，因为人觉在意的是人之最的动向，所以从夸幻之父心性渐转之际，他便安排楚天行成了夸幻身边暗桩，借由两者情义加深，步步导引夸幻走向人觉为他布下的灭世之路。

因为他知道固然天地表面承诺，不直接涉入对人之最动向的影响，但私下都各自仍是出招。

从一开始，浩星探龙受贤者之树白发仙者指引，走向人界与精灵的护守和平之路，便是人觉设计让浩星探龙依他安排的超渡僧与精灵天下地图指示，步入兽王陵陷阱的开始。

而为干扰人觉借精灵三角、在夸幻意识中种下的【幻世七劫】恶根，天迹借因缘种下【阿难七梦】的佛根于夸幻脑中；

地冥则顶着如天迹的脸孔，在精灵天下所作之恶行，更有明可利己、暗可嫁祸天迹的效果。

这些他都看在眼底，也深谙彼此间的在意关系，所以人觉以伪鬼麒主行事时，才更能放肆运用。

由于人觉的终极目标，是让人之最在众人心中的美梦幻灭，所以所有建构这传说、支撑这美梦的相关人等，都必须一一铲除，为了达到这目的，他必须有准备，所以圣剑和魔刀他早已预设，只要剑咫尺与恨吾峰帮他把刀剑养好，那拔除天地二人便是指日可待，更遑论其余苦境正道的关系组织。

**单锋罪者与烽烟线索**

人觉·非常君因圣剑所致，斩获与邃无端这对同母异父兄弟的各自悲剧，被人觉满满恶意塑造出来，对斩获一生的极力压榨、鸟尽弓藏，以及对遂无端的假意关怀、虚与委蛇，彻显了非常君对所利用对象，是不会心慈手软、够狠够黑，一切以遂行目标利益为依归。

在这段单锋罪者的戏路中，便不得不提人觉的【烽烟】。

这烽烟从夸幻之父、剑咫尺、夔禺疆，乃至恨吾峰，都有直接剧情连结。

人觉居所明月不归沉后山的白羽松枝，燃烧会有烽烟味，来做为指令下达的媒介。

为了凸显此一线索，再追加了习烟儿素以食人间烟气为生，却偏偏怎么也闻不到白羽松枝的味道，物质燃烧毫无气味，本身就是桩离奇，透过习烟儿屡屡抱怨不想用松枝煮茶，来暗示这其中有鬼：原来，一旦让习烟儿闻到松枝的烽烟味，也无疑暴露了人觉是烽烟连锁案件的最大嫌疑人，所以他控制没让习烟儿闻出这烽烟味，而借游习烟儿翻阅人觉藏书，爆出了他罪证确凿的犯行。

亦因这时，也已是人觉的“嫁祸人殊”计划的关键时刻。

而在烽烟控制他人的事实被正道所广知，如何再翻用成了一大难题。

此时，编剧们将计就计，反用烽烟能害人的既有认知，来切割过往罪行与证明自身清白，人觉与天迹赌：如果天迹够敏锐够机敏，有察觉到狙杀黑洞中人觉时的烽烟，那最后有没有痛下杀手，便成了天迹是否中计的关键征兆。

事实证明，这场谍对谍的心理战，人觉是惊险玩命地赢了一把。

**一魂双体与越骄子**

人觉会反用烽烟为饵，也是因为从云海仙门偷偷习有的独门秘法【一魂双体】，这原本是为了让人觉方便遂行邪恶之事，故设计了让人觉除【人鬼之子】的特殊设定外，还习有可分出另体的秘技，借由副体“人殊·越骄子”的分出，无异他多了个可推锅诿过的对象，也巩固了人觉正派的众人印象。

打从伪鬼麒主与君奉天频频接触，他就知道这鬼面具下的秘密藏不了多久，所以就排设了他有一孪生兄弟的伪计划，再通过烽烟线索，把快要暴露形迹的人觉洗白。

在这里的剧情设计，是故意不在之前人觉的日常对话中提及有胞弟越骄子此人，反而让天迹去猜出这人觉有鬼才显得天迹的智慧。

而人觉·非常君利用人殊·越骄子这身份，不仅刚开始与纵横子合作，颠覆了夔禺疆的幽界政权，后又与地冥竞合关系，互相算计，更乃至于与君奉天死磕，与笼络联系可运用之人力，可说是应付裕如，而这时的人觉还是那个白净善良的闲游美食家，犹如多亏了这假面身份。

**移魂易体和假面梵天**

【移魂易体】这梗，在剧里被揭露时，就达到一种悬疑效果：到底谁偷了？

又要怎么用？

或者已经用了？

在这种草木皆兵的时候，真正首度展现出的，就是最惊悚的的置换一页书。

人觉剧照在这两次移魂易体的大戏后，非常君的东窗事发，终至人觉与梵天，一为人之最，一为人之觉的矛盾终极大对决。

然而战斗不能单纯只是你死我活的绝战了结，必须为这场铺垫多时的最终死战定下一个令人烙下深刻记忆的主题。

于是便以人之最，这座“人之巅”为发想，再回扣档名“天命”来定位这场战役，是一场天命之战，是一场“如何看待苍生”之战。

非常君和一页书，两人不同的经历过往和人生价值观，去激荡深化这场辩道之战，也带出从未被揭开、人觉孤独而幽暗的真实心灵，也是明月不归沉给人的那股莫名哀愁与距离感。

## 角色评价

人觉·非常君人觉作为仙魔鏖锋两档的最大阴谋家，牵涉的人事物太广，他害死的人更是应验那句“一将功成万骨枯”。

对于天地人三者的纠葛，以及与一页书的斗智斗勇，人觉这个这个充满人性忌妒、阴狠、伪装、叛逆等种种幽暗面的反派人物也如此一路走来。

一如戏言，人觉是边缘人，但他是主动地让自己走在人群边缘，冷森森地看着、推动着心中那股腥风血雨，将这人间摧毁殆尽的智慧犯。

这与被动式的被人群隔离的边缘人有根本动机上的截然差异，非常君内心里就不想和这些人掺和在一起，他和善面目的背后，是等着把你们全部铲除的阴狠。

他就像柯南漫画里，那富藏在黑暗的锐利眼睛，盯着局势变化。

人觉剧照图册明月不归沉碧海，白云愁色满苍梧。

人觉故事告一段落，但他身上衍生的一些故事却仍在延伸继续，请记住那道流苏伞下的阴暗深影，回忆虽远去，但总会留下什么，再把回忆拉回。

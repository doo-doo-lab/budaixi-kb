# 皇鳞
================================================================================

皇鳞

以南域为根据地，图在苦境复兴鳞族之皇者，热爱征战、享受武斗，对决中会拥有兴奋愉悦的快感，事后则会以非常缅怀的心情去回味，平常会研究武学和兵法，并以“情”之一字来统摄兵法的要诀，亦善于心计。

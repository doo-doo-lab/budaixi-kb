# 皇鱗 (皇鳞)
================================================================================

皇鱗

以南域為根據地，圖在苦境復興鱗族之皇者，熱愛征戰、享受武鬥，對決中會擁有興奮愉悅的快感，事後則會以非常緬懷的心情去回味，平常會研究武學和兵法，並以「情」之一字來統攝兵法的要訣，亦善於心計。

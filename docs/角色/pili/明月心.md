# 明月心

医术高明的女神医。离世独居、冷漠少言但医术精湛。喜研究与收集各类毒物并找出解毒方法。是解素还真万毒珠之毒的关键人物…

专长

医术、研究毒物

## 来自百度百科的补充

冷言、冷面、冷心的"冷医"明月心，虽名不见经传，但医术却相当高超，尤其对毒更是专精，明月心擅长用针，可救可杀，施针手法精准，暗器手法更是高明。明月心真实身份乃是四无君的暗桩，昔日为了偿还恩情，曾以毒谋害策衍先座，后来更受命取信正道，提出以七月笙吸取素还真体内之毒的办法，让青阳子等人进入黑雾森林内送死，岂知事后竟遭四无君派人灭口，明月心因此觉悟，背叛四无君，四处积极找寻救治素还真的方法，最后因昔日暗杀策衍先座而种下自己的死因，对上为策衍寻仇而来的剑君十二恨。剑君剑出，已经是冷医明月心人生的终点。

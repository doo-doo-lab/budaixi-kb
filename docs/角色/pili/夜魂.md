# 夜魂

出自神秘杀手组织“泯灭生门”，智慧、武功皆为不凡，手持短刀“凛夜”、细剑“冽魂”，年纪轻轻便以得到泯灭生门杀手最高的“鬼华”等级，因而深受罪皇重用与信任，和召临锋同为绝日狂图买回之佣兵。然而在每回任务执行完成的当下，夜魂却也一点一点透露著内心中另外所藏之盘算。

## 来自百度百科的补充

夜魂，霹雳布袋戏虚拟人物，出自神秘杀手组织【泯灭生门】，持短刀【凛夜】与细剑【冽魂】。智慧武功皆属上乘，得到泯灭生门杀手最高的【鬼华】等级，深得罪皇重用信任，却始终暗藏独立谋划。

出自神秘杀手组织「泯灭生门」，智慧、武功皆为不凡，手持短刀「凛夜」、细剑「冽魂」，年纪轻轻便已得到泯灭生门杀手最高的「鬼华」等级，因而深受罪皇重用与信任，和召临锋同为绝日狂图买回之佣兵。然而在每回任务执行完成的当下，夜魂却也一点一点透露着内心中另外所藏之盘算。

在崇罪名邦进军魔吞不动城的攻势中，多次与苍鹰（叶小钗）交手，同样刀剑双修的夜魂与苍鹰战的旗鼓相当，后逐渐被苍鹰所压制。最后在九轮天设局围杀魔息大帝的任务中，被魔息大帝所杀。

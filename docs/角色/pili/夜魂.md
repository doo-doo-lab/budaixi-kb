# 夜魂 (夜魂)
================================================================================

夜魂

出自神秘殺手組織「泯滅生門」，智慧、武功皆為不凡，手持短刀「凜夜」、細劍「冽魂」，年紀輕輕便以得到泯滅生門殺手最高的「鬼華」等級，因而深受罪皇重用與信任，和召臨鋒同為絕日狂圖買回之傭兵。然而在每回任務執行完成的當下，夜魂卻也一點一點透露著內心中另外所藏之盤算。

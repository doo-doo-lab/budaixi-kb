# 月灵公主

为西漠鹫族公主、轻灵秀美。却因内苑斗争而家破人亡。为了生存，她忍痛将爱子送走而苟活于荒林间；为了复仇，她不惜化身为毒蝎女。但最后，面对自己的亲子却不能相认，而是兵刃相向，有的只是对爱子满心的愧疚和再也抓不住的幸福。

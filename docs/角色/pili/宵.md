# 宵

宵

孤守着凝晶奇花，背景来历不明，性情沉默寡言，对人情世故毫无认知，心智单纯如白纸一般，求知欲强烈。因凝晶花之故，卷入武林漩涡，也让宵结识了姥无艳，学习如何当一名真正的“人”。
如今守于傲峰十三巅，看守天火与涅槃剑，结识了剑魔傲神州等人。

### 武器描述

夜刀：繁复华丽的一口紫红短刃，护锷有如利爪镶衔刀身，刀柄缀有羽毛为饰，刀锋轻薄曲狭、尖锐无比，配合宵迅若疾影的身手，伤人无情不留命。夜重生在创造宵之余，除了灌输其武学"夜刀流"，更赋予此口杀人利器，故一旦宵认为受到威胁或侵犯，夜刀便随本能反应而现。登场剧集：霹雳奇象 第9集

涅槃剑：箫中剑以天之焱、天之滟、天人之悯、鬼萤（吸取了六祸苍龙的祸龙之源）四口天之神器，加上冷滟的天铁之身，以黑夷族圣树阴木燃起熊熊阴火，加上月漩涡的血狼之血，宵的冻寒之气催动，以及箫中剑自身修为，在天火炉中锻铸而成。清澈透明的圆形握柄，剑身清澈明晰隐含圣光，佐以梵文刻痕为饰，显示涅槃庄圣气息。此剑先后由箫中剑和银锽朱武使用，朱武死后与其同葬天邈峰，后苍将剑带回傲峰，天火因此在十三巅重燃。为防酿成灾害，苍以涅槃剑镇封天火，并交代退隐傲峰的宵看守。

### 造化之钥描述

风云天地图所记载，埋藏于鬼没河的五大神器之一，外形为以红绳串系的一只水晶坠链，具有释放特殊能量、医治各种伤势病患，让垂死之人再获重生的功效。最终被袭灭天来销毁。

### 人物介绍

"奈落"一词，出自佛经的"那落迦"（naraka），大多指地狱之意，宵这个角色，是夜重生所创造的杀人武器，没有自我意识，唯有听命杀人，但宵对夜重生来说更是一个因果轮回，夜重生是嗜血族创造出的族群，夜重生反噬嗜血族，夜重生却步上轮回，逆天造出宵，造成自己的灭亡。也因宵是夜重生用自己的"半身"所造，完美的外表、完美的力量，如夜之化身，所以单名‧宵。

不料宵初醒时竟双眼失明，让夜重生备受打击，过度期望而失落，怒而舍弃了在他内心明明是最完美，偏偏失败的完美失败品，但夜重生内心无非是抱着一点不舍与期待，他没有毁了宵，却是将宵丢弃在雪地内，任其自生自灭，可是被丢弃的雪地中的宵最不幸的一点，是产生了自我意识，双眼睁开时，他产生了"我是谁？"这样的想法，睁开眼的刹那，看见了雪峰初开的凝晶花。直至遇上了一位对他说："无情者伤人命，伤人者不留命"的人，又遇上了姥无艳，宵学习当人类的道路开始了。

宵：第一眼见到世界时，漫目的雪白之中，我见到一朵破冰而生的花朵，是在一片的空白之中，唯一的生命。
宵：我知道天地万物的词句，我不知道那代表什么意义。"为什么？"，是心中最常出现的一句话。
宵：创造我的人，叫我杀戮的武器。但是他舍弃了我。
宵：漫长的时光中，遇上的第一个人类，他教我一句话，无情者伤人命，伤人者不留命。
宵：不知过了多久，我遇上第二个人，她说，她是一个丑陋的人……
宵：何谓美丽？何谓丑陋？在我的眼中，并没有分别，我只知道，她教我如何当一个人。
宵：我想成为人类，是因为我想了解、明白，但是越想当人类，越不懂人心。

最后，看着姥无艳死去的刹那，宵第一次落下了眼泪。
宵：原来……这就是眼泪。如果当人是如此痛苦，当人……是如此残忍丑陋，那么……我宁愿只当一名杀人武器……不再为人……

# 神愆 (神愆)
================================================================================

神愆

天邪八部眾之首，以「冥帝」為號，神之罪業「神愆」為名，代表對六天諸神最深的怨恨。手持咒神天秤，姿態高傲，冰冷無情，一副高高在上，睥睨眾生。甫出場便擊敗群俠，拔起仙腳頂端的雲漢仙閣，飛入雲海之中，開啟淪亡遊戲。

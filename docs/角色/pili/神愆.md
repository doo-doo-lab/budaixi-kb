# 神愆 (神愆)
================================================================================

神愆

天邪八部众之首，以“冥帝”为号，神之罪业“神愆”为名，代表对六天诸神最深的怨恨。手持咒神天秤，姿态高傲，冰冷无情，一副高高在上，睥睨众生。甫出场便击败群侠，拔起仙脚顶端的云汉仙阁，飞入云海之中，开启沦亡游戏。

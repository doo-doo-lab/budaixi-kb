# 千里不留行

魔域第一战将，率领魔域精锐大军攻杀各地，武力超绝、勇冠三军，剑法高超，万军中取敌首，犹如探囊取物般轻易。

## 武器

枫叶剑

## 来自百度百科的补充

雾谷老人，原本是魔域著名杀手“千里不留行”，因和拜邪公主的感情落空而加入毁灭拜邪教，后叛出魔域，决心为民除害而打回血战是非小径，无意中救了误闯魔域的执戒律。千里不留行在逃出战圈后，被一页书所救，与其结交并隐居雾谷，容貌也被一页书易容，改名为“雾谷老人”。雾谷老人雾谷老人隐居雾谷，躲避着魔域的追缉，但也经常暗中帮助正道人士。在《霹雳劫》时期，雾谷老人曾救助遭受暗算的崎路人，为此寻找秦假仙，并与时空超越人、鬼王棺等人产生交集。雾谷老人曾破坏鬼王棺的阴谋，并从鬼王棺处得知紫锦囊胸前有无双头麒麟刺青的线索，随后安慰了为此事困扰的化丑 。雾谷老人曾布局偷出“三昧光”并交给荫尸人 。在集境进犯苦境时，雾谷老人替一页书驻守云渡山，心知军势敌众我寡不敌而诈降集境，与执戒律结拜，暗中探查灯蝶伪装花影人的秘密，并帮助钗头凤对付十八楼联盟，成功造成集境三宫动乱内斗。 雾谷老人为救其子枯叶而在不归路开杀，公开自己千里不留行的身份，但枯叶回天乏术，雾谷老人从此专注于让枯叶复活，并代替枯叶造世七侠的身份，大破酆都鬼楼、炼化三途判。在白面具东南秋的帮助下，其子枯叶得到复活的机会，雾谷老人感激于心，帮助东南秋做事，捣毁集境大军军营，战中为救东南秋而被诛十七断臂重伤，被天祸妖狐带回魔域后被鬼帝以通骨钢针改造，并赋予“杀人之手”和“百魔杵”，雾谷老人重新变回魔域超级杀手千里不留行。 雾谷老人重回魔域，在天河运棺中杀死今生一剑，就连杀生佛的也敌不过其而被打飞，天河运棺战毕，雾谷老人更击败一休禅师，连挫三名正道高手。不过，后来在原始火烶的帮助下，雾谷老人逐渐恢复本性，并为子报仇，杀死天镜刑者萧雨。为救火龙婴自断杀人之手，和冷剑白狐、化丑、黑白郎君共隐无双崖底。 好景不长，蜕变完成的十九代网中人寻仇而来，雾谷老人代替上阵对敌，用百魔杵攻击网中人，不料网中人竟不惧死灵攻击，被无向飞丝刺穿胸口，雾谷老人被当场阵亡。

千里不留行身为第一魔域第六殿的最强杀手，因任务而前往苗疆拜邪教襄助，结识教中圣女-莫罕儿，进而谱出恋曲，无奈魔域戒律严谨，禁止本家人员与分家结合，千里不留行离开苗疆。莫罕儿对于爱人离去忿恨难平，是时，适逢苗疆勇士进攻拜邪教，莫罕儿因此下嫁被俘虏的勇士首领-枯天豪。得知此事的千里不留行认为爱人变心，于是返回苗疆联合当地土族与枯天豪里应外合，成功消灭拜邪教。圣女莫罕儿毒杀枯天豪后，自杀殉金鳞邪神(注:闵南语中，'蛇'与'邪'字同音，布袋戏传统中，守护神-西秦王爷曾为蛇精所困，因此避讳读'蛇'字，多以'草索'、'溜'或他同音字代替。)圣女侍从-火云姑带着圣女之子枯叶(邪神托世之神子)逃出生天，后千里不留行获悉枯叶非枯天豪之子，而是千里不留行蓝田种玉的结果，悲痛万分，悔不当初，无奈大错已铸成，千里不留行也因此不为魔域所容，留亡天涯。千里不留行众叛亲离，逃亡至云渡山后方的雾谷，偶遇高人-百世经纶一页书，在其帮助下，改头换面为雾谷老人。男主角:千里不留行女主角:莫罕儿便宜老爸:枯天豪最佳化妆:一页书[金鳞蟒邪]:奇异的蛇形剑，剑端蛇眼可射出三道邪光束缚拖曳敌人，在以蛇剑舌尖刺杀。为莫罕儿殉神时，由邪神像化形的邪剑，由于是与枯叶天人感应而生，故内藏枯叶的命脉-八荒脉。[枫叶剑]:枫叶形的剑，是千里不留行与莫罕儿的定情物。

雾谷老人初登场于《霹雳异数》第23集，退场于《霹雳狂刀》第20集。 在《霹雳劫》第20集中，雾谷老人偷出三昧光交给荫尸人。

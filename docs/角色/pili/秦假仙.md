# 秦假仙（霹雳布袋戏虚拟人物）

================================================================================

秦假仙，霹雳布袋戏虚拟人物。名人榜上天下第一辩、霹雳戏中的活宝。急公好义、脑筋灵活、辩才无疑，鬼点子永远用不完，一手包办武林中大小琐事，是正道最重要的情报贩子。个性自私小气、欺善怕恶，出门总带着一群跟班小弟，但却有着超乎常人的好运，加上过人的机智以及不择手段的行事风格，每每于关键时刻小兵立大功，对武林和平的贡献，有着不可磨灭、取代的地位，乃人不可貌相的最佳典范。

## 人际关系

正道盟友：素还真、一页书、叶小钗等所有正道人物家庭名字关系备注秦谷鳖哥哥中原三老之一，秦假仙的兄长。

阿腰侄女于霹雳孔雀令出场，秦假仙用她化妆成莫君愁，诱惑五剑雕郎。

文不通义父出场时是个咬文嚼字的疯子，秦假仙为破东瀛机关城请他制作机关盘，为攀关系愿拜其为师，文不通却因“一日为师，终生为父”干脆收他作义子。

黄金村富氏第一任妻子外号水蜜桃，家财万贯，但因为克夫，无人敢娶。

秦假仙想做富翁，娶了富氏，不料结婚没三天就发生火灾，富氏身亡，财产也被烧尽。

唐七七第二任妻子挑中了秦假仙托付终身，并且意外地琴瑟合鸣。

可惜红颜薄命，秦假仙为替黑白郎君解围使计吓退八大门派遗孤，事后八大门派遗孤不敢直接找秦假仙报复，于是转而擒住唐七七做人质，逼迫秦假仙自废武学。

秦假仙自废武功后八大门派遗孤不守信用，杀害了唐七七。

花非花现任妻子刀狂剑痴叶小钗的孙女，美丽、温柔、大方的漂亮女子，但天生染有怪病，白天是温柔婉约的美女，晚上则变得丑陋不堪，因此衍生出不少坎坷的际遇，之后成为秦假仙的妻子。

华羽火鸡偏房来自天外南海的风尘女郎，气力如牛，曾蝉联数届摔角冠军，个性三八逗趣，总打扮花枝招展，爱慕虚荣、见钱眼开，对打理风月场所相当有一手，乃典型甘草丑角人物。

乌骨鸡偏房天外南海仙姬楼的小姐，人如其名，全身肤色泛黑，聒絮不休，与火鸡共同服侍秦假仙，自从纠缠不放，还随秦假仙回到苦境中原，落脚二重林，与花非花姐妹相称，与火鸡一搭一唱逗趣十足。

## 经历
《霹雳眼》时，素还真命一线生以三阴烈火钢打制刀锁，用以克制金臂会之紫金臂，后送与秦假仙，并配合素还真的“非真刀谱”，秦假仙曾以此风行一时，所向无敌。

但万葬岗上，八大门派遗孤以唐七七的性命威胁秦假仙自废武功，秦假仙在两难选择下，自盖天灵废了功体，昏倒在地。

遗孤们却言而无信，先杀了唐七七，崆峒派之人欲再杀秦假仙，当击中秦假仙时，一股热流传来，崆峒派人全身着火，爆碎而亡。

其余八人吓得面如土色，只见秦假仙起身，异变再生，面容转红，声音威武宏亮，“吾乃是一刀万杀啦！”他由背后刻有“一刀万杀”的刀鞘抽出火红色宝刀，奋力一劈，一人从中分成两半，被火焚烧。

剩下七人立即施放剧毒，但毒粉却被一刀万杀身上发出的烈火蒸散殆尽，一刀万杀将刀插地，火焰刀气袭向七人，八大门派遗孤全数死于烈火怒焰中，一刀万杀转身离开。《霹雳幽灵箭第二部》第三集中被半部禅以血不沾砍下头颅，由十方灵动剑魂赠于叶业灵的银牡丹之叶接回头颅，并送至百棺机密门后被海殇君救活。

之后秦假仙以飞幻公子的身份假冒非凡公子出现在猜心园。

直到霹雳英雄榜第一集非凡公子回到猜心园，秦假仙假冒非凡公子的身份才被揭穿，出现原来面貌（此时的秦假仙是有身无心之体）。

28语清云居士之谜题：明月别枝惊鹊，清风半月鸣蝉，稻花香里说丰年，听取蛙声一片。

七八个星天外，两三点雨山前，旧时茅店社林边，路转溪桥忽见。

29赞花非花：花非花，雾非雾，夜半来，天明去。

来如春梦几多时，去似朝云无觅处。

登天难，求人更难；

黄莲苦，贫穷更苦；

春冰薄，人情更薄；

江湖险，人心更险。

30与欲入悠兰景之胖子对句：两猿断木深山中，小猴子也敢对锯；

一马陷足污泥内，老畜生怎能出题？

31与悠兰景丫环冬梅之对句：吏部堂中，一史不读枉作吏；

悠兰景中，二夫叙情夫为天。

32与柳依依之对句：为名忙，为利忙，忙里偷闲，饮杯茶去；

劳心苦，劳力苦，苦中寻乐，拿壶酒来。

33日月照龙舟，淮南逆水流，扫尽杨花落，天子季无头。

34火龙神探秦厉害重出江湖：半生含恨今终止，一步江湖无尽期。

35吊花非花：卿昔尝爱吾，乃忍舍吾去，今吾欲改娶，不忍别卿墓。

想卿魂寂寞，定怪吾情薄，刻石如吾面，朝夕伴卿乐。

卿见石人如见吾，石人代吾常守节，吾心不似石心坚，石身更比吾身洁，吾身虽去石身留，朝朝暮暮在坟头，坟头不断风和雨，卿魂好共石人语。

呜呼哀哉，别矣。

36扮孔明空城记：上天如圆盖，陆地如棋局，世人黑白分，往来争荣禄；

贫者自安安，富者自乐乐，南阳有隐土，高眠卧不足。

37热剑秦诗号：烘烘之剑震寰宇，冷冷杀人不觉中，武林道内我为尊，江湖路上称帝王；

欲知吾居在哪里，荒山飘浪孤独王，问我何名与何姓，中原热剑一点红。

语权妃：对酒当歌，人生几何，酒入愁肠，更添美人愁。

38回万烛公之打油诗：你别假贤，别臭屁，最有福气是长尾星，长是长迤迤，头墬地，尾翘天，岁寿可与彭祖比，要庆祝，要花钱，提烧酒，办料理，你茫我醉都高兴。

39中原不败歌词：为着正义，出生入死，南征北讨，不曾啰唆，正邪两派，人人啊乐，江湖武林，没我会倒，中原不败，大侠秦厉害，不信试看卖，包你流目屎，中原不败，大侠秦厉害，好胆作你来，包你惨歪歪，风流潇洒，气质不凡，深藏不露智慧好汉，只是英雄，难免怨叹，夜来孤单，为伊一人，花仔啊，我心爱的花仔啊，我可怜的花仔啊，我永远的花仔啊。

40处治世宜方，处乱世宜圆，处叔季之世，当方圆并用；

待善人宜宽，待恶人宜严，待庸众之人，当宽严互存。

国家兴亡自有时，吴人何苦怨西施，西施若解倾吴国，越国亡来又是谁。

41阐释洞神五戒：目不贪五色，耳不贪五声，鼻不贪五气，口不贪五味，身不贪五彩。

42赞非凡公子：举手投足迷倒世间女性，秋波转送疯狂天下裙钗。

43荷尽已无擎两盖，菊残犹有傲霜枝，一年好景君须记，最是灯黄菊绿时。

44万教综合雷公卡：宇宙洪荒，日月无光，天地变色，山河崩碎。

45混元卷螺掌：眨眼变血水，开口吞地球，摇身化成粉，甩头生命休。

46小诸葛赛孔明：飞虫眼前过，计由心上生，大敌十里外。

47卧江子对吟：一生二，二生三，三生万物；

天作棋盘星作子，日月争光。

48秦假仙开导黑衣剑少：初入口中，感觉到的，是苦！

而仔细品尝，就会发现，原来还有那份甘醇甜美。

人生也是一样，刚接触到一件事情时，觉得他不好应付，甚至让你没办法面对，但只要努力地探究下去，常会有意想不到的收获！

49秦玉安出场诗号：城北徐公叹不如，面似凝脂赛潘安。

美如冠玉无人及，英姿飒爽秦玉安。

50悼念素还真：昔日黄山八珠联，威赫万教紫龙天。

今日黄山群雄会，哀思人海葬白莲。

4、许愿仙出场白：生命金不换，一愿梦成真。

一愿梦成真，二愿成真梦，三愿真成梦。

秦假仙5、玄德相士言秦假仙之命格：一卦名凶，二爻位凶，三辞凶，四不得时，五无援，六数逆时，七不得体，八位不当，九违理，十众疾。

另外说明了秦假仙在特殊的时候被人破相（被小金刚割掉鼻子），所以虽然面貌丑陋、厚颜无耻、命格卑贱，却因机缘被毁容，反倒事事逢凶化吉。

6、孤愁先生与秦假仙论缘分：人与人之间就如机器齿轮一般，只有彼此之间相互适应，不断修正彼此的磨擦，到最后才能完全的契合，这样才能保持顺利运行。

所以纵然先天有“缘”，无法密合也不会有后来的“分”，缘分不是相欠债，是再创造。

7、百里抱信对其言：人而无信，不知其可也，失信不立。

8、流浪者评价：外貌俊美者，虽路顺，却是非缠身，纷扰不断，是祸非是福；

其貌不扬者，虽路不平，却事事皆顺，是福非是祸。

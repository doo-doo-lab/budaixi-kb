# 香九霞 (香九霞)
================================================================================

香九霞

香六牙的孿生弟弟，與其兄非常肖似，除了後頸部沒有像其兄的異骨外。為協助斬輪計畫，自願喬裝其兄山座身份，以回報其兄昔日翼護之恩，卻也因此踏上不歸路。

# 一生懸命 (一生悬命)
================================================================================

一生懸命

落魄潦倒的窮酸書生，烏鴉嘴隨口直斷，常常準確命中，愛自嘲搞笑，看似平凡懦弱，實則深藏不露。在磔霞台武林大會後，與大紅袍結伴同行，卻唱反調要阻止三寶現世。

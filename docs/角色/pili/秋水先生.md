# 舞造论

霹雳布袋戏中的角色舞造论，霹雳布袋戏中的角色。风度雍雅，个性仁厚，毕生钻研剑理，剑法与修为同臻化境的剑术名家，不定期召开秋水宴，宴请天下用剑者，穷毕生之力，写三本剑法名著，最后为万民牺牲，为一位可敬的剑界名家。

## 角色设定

- **名称**: 舞造论舞造论称号：秋水先生化身：昔非颜身份：剑盟秋水宴之主初登场：霹雳狂刀之创世狂人 第5集退场：霹雳雷霆 第6集（死于星野残红）根据地：秋水宴

## 角色经历
舞造论，秋水宴创办人，曾创出享誉江湖的解脱剑诀，毕生钻研剑理且不定时召开秋水宴，广邀剑界名人参与，综合百家之长，穷毕生之力撰写“王者之路”、“巨铸录”、“沧海剑理”写三本剑法名著，其中专述剑招的“王者之路”更是当时各家欲夺的至宝，本身也在王者之路上留下随心所欲一招。

舞造论 霹雳官方攻略本为说服独子无不爱继承家业，舞造论曾假死化名昔非颜，但始终化解不了父子隔阂，同时由于当年与寒天放联手放逐掠食者，引来掠食者的报复，不仅收买刀剑两盟的仆从杀害寒天放之女，嫁祸舞造论，使刀剑两盟险些大动干戈，更将无不爱关押在山洞。

为此，舞造论与寒天放再度联手对上掠食者，却不敌他新练成的野性之刀，沦落被放逐的命运。

但舞造论却颇能想开，把三本著作交给莫召奴委他代传剑艺给无不爱，并且帮助叶小钗打造出告心双利。

无奈王者之路引起的动乱太大，寒天放因此被秋末悲歌所杀，舞造论眼见拜弟身亡，痛心而疯，并在面对掠食者二度追杀时，意外使出王者之路四招连贯把他打败。

后来汗青篇派出磊公探测其意识以求王者之路剑法时，意外治愈舞造论的疯病，但舞造论仍然佯疯伪痴躲避野心家的算计，并与素还真、莫召奴及龙眼佛结拜，合作擒下化身无相的野心家帅轻皇。

因为舞造论与素还真等人有结义之情，一度共抗汗青编与魔界武神斩海等强敌，同时应对大汗帝国对王者之路剑客的逼杀，两度迎战银座飙手，且与素还真等人联手制服穷凶极恶的掠食者，后与东瀛五大武士对战中败给赤鬼而灰心丧志，意图投江自尽。

被封印江中的刀魔星野残红所救，为其探查四飞天之事与不透漏恩人身份而再出武林。

后来四魔皇乱世，以水火风疫四种灾祸为祸百姓，舞造论在素还真由天魔处得知刀魔为四人克星后，义无反顾道出其行踪，并亲身去找寻星野残红帮手，因为违反承诺，自愿让星野残红斩杀。

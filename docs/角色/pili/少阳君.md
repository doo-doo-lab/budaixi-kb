# 少阳君 (少阳君)
================================================================================

少阳君

少阳君为号，本名云中陌客．非九容，内心背负着重大罪孽，一心想要弥补赎罪，自带谜团，鲜少人知道他的过去，数月前才现身武林，并帮助日新庄度过一场劫难，之后在应天辉的接纳下，成为日新庄的一员，但其实不被庄主夫人银娘所接纳。身负殊异的三教修为，一心要寻找在墨殇天爆后就消失武林的三教顶峰，并从泥菩萨口中得知，全天下只有他才能找到“未孚”之所在。

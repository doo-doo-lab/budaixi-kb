# 少阳君

少阳君为号，本名云中陌客．非九容，内心背负着重大罪孽，一心想要弥补赎罪，自带谜团，鲜少人知道他的过去，数月前才现身武林，并帮助日新庄度过一场劫难，之后在应天辉的接纳下，成为日新庄的一员，但其实不被庄主夫人银娘所接纳。身负殊异的三教修为，一心要寻找在墨殇天爆后就消失武林的三教顶峰，并从泥菩萨口中得知，全天下只有他才能找到“未孚”之所在。

## 来自百度百科的补充

少阳君的真实身份为墨殇天爆的推手「辰太寻明」。经历墨殇天爆后，其样貌发生变化，遂以「少阳君」之名行走武林。作为玄天六阳·墨阳子之孙，其名中的「阳」字与家族渊源相关。他内心背负着罪孽感，性格呈现复杂性。

**人物经历**

「少阳君」之名横空出世，作为武林新秀，少阳君身负三教顶峰修为而受司马骏业关注。来历成谜的他，背负寻找三教顶峰的使命，加上身上留有的墨气，不慎掉落的玉觿，在进入万愿同归后，少阳君的真实身份也终于揭晓……

过往殷切寻明，今朝以阳重生

墨殇天爆的推手「辰太寻明」，即是现今的少阳君，所以少阳君背负的罪恶感、使命感亦是由此而出。少阳君经历墨殇天爆后大难不死、样貌变化，故决定痛改前非，望能重获新生。因自己是玄天六阳·墨阳子之孙，故以阳为名，象征旭日东升、重启生命，过去寻明、今朝向阳，盼望自己能给这个世间正向力量。而最重要的，是希望能摆脱过去那个充满罪孽、不堪回首的自己……

少阳君的自信中隐藏的是不可告人的自卑，故在日新庄中，为了维持表面的和气，少阳君一直忍受着银娘的冷嘲热讽，除了是报答应天辉的收留外，更多的是认为自己没有资格去争取、争论些什么。而应天辉看出少阳君内心的脆弱，才会提醒少阳君必须要试着抬头挺胸，正视过去的自己后，才有办法面对未来。

赎罪之路颠簸，仍须坦荡前行

魔魇狱火依附在少阳君体内，正孕育着一股可能再度造成世界毁灭的灾难，也是地狱鸟重生的关键。但在那之前，少阳君必须面对的第一件事，便是“赎罪”。了解他拥有三教顶峰修为之人，必然会将其视为关注对象，无论是单纯要找寻三教顶峰下落的司马骏业，或是墨殇天爆受难者的亲属们，这个少阳君不愿意回想的过去，必然成为这一路相识的每个人中，可能会因而变质的复杂情感，将会是赎罪之路上，需不停面对的难题。

在第一次与西窗月见面的短短几分钟，少阳君面对了难以想象的恐惧，他深怕自己身上的墨气，会让西窗月揭晓自己的身份，却仍须故作镇定后赶紧跳上巨灵鸟离去，这一段过程看似从容，却隐藏不住少阳君的些许狼狈。

而今对少阳君而言，这个能重生的自我得来不易，他希望至少能掩盖过去，来让现在的自己好好活着。眼下要找到三教顶峰、向他们致歉外，也要找到杀害应天辉的凶手，为庄主报仇雪恨。等待事情落幕后，欲能在武林行侠仗义，找到现在这个新身份的自我价值，借此抹灭过去的辰太寻明。

恩怨情仇交织，走向真正自我

一路走来，有三人影响少阳君最深，第一位是日新庄主应天辉，因过去少阳君解救了其女柳梢青，应天辉认为少阳君年轻有为，另日必成大器，于是不顾妻子银娘的嫌恶，让少阳君加入了日新庄，甚至欲将其培养成靖玄客贪狼星继任者，这份赏识与信任，对少阳君来说无比温暖。也是因此，应天辉身亡之际，才让少阳君感受到失而复得的幸福，竟是如此短暂。

第二位是武邑率然，第一章中两人不打不相识，少阳君认为率然是志向高远、不因困境影响自我的人，两人相互欣赏，有同袍的患难之情。

第三位即是解芳霏（卯十四），先前为找寻真相，少阳君辗转进入万愿同归，但并不认同靠宗教力量挣脱罪孽的赎罪方式，加上神子实际上是在虐待女性，故决定阻止一切。

未料少阳君却反而落入神子的圈套，导致迷子死伤多数，让其陷入偌大打击中，也渐渐相信万愿同归的信仰，准备把自己的力量都奉献给净思神源时，一段自我的对话中，辰太寻明点醒了少阳君，而三教顶峰更传授“丹海无极妙法”助少阳君一臂之力。最后不但成功瓦解了万愿同归，少阳君体内三教顶峰的修为也能灵活运用，并希望借由此力量，将武林中的罪恶都消灭殆尽。

过住情谊不存，芳霏之怨何解？

虽然解芳霏也在此行动中重获自由，摆脱了万愿同归，然而在神子死之前，对解芳霏说出了少阳君的真实身份。得知造成家破人亡的墨殇天爆，乃少阳君一手造成，解芳霏再会少阳君，给了少阳君难以置信的一刀，冷漠的眼神宣告过去的情谊不存。

在经历了失去恩人、相遇知己、得三教顶峰功力后，少阳君又意外得知武邑率然之死。愤怒的少阳君要去报仇，但裂头人其实是被冤枉的，卯十四挡在前面，少阳君强行收招遭到反噬，剑魔为了让其疗伤，把他送去六崇越圣地，得到惺惺相怼和六崇越全部武学。武功大成出来后参与山座杀除八无暇的计划，最后为救走火入魔的步虚行进入地狱鸟体内，唤醒步虚行，步虚行为赎罪化为灵珠想要引走阴禽地狱鸟，不料步虚行力量不足，因祸得福体质提升的少阳君决定助其一臂之力，一起将地狱鸟引离苦境。

**人物设计**

**造型**

少阳君一身橘红交织金色系的服装，辅以发髻上的头饰有如太阳灿烂，就像是整体散发着强烈的阳光感，白发中挑染着黑丝，即指强光之下必有阴影，也是少阳君必须去克服的自我认同难题。

**道具**

应天辉赠与少阳君的日轮杖，以灿烂天阳为设计重点，其中日轮必要时刻会转动，此物乃应天辉给少阳君的期许，常保光明正向的心态，成为众人的温煦太阳。

**相关作品**

霹雳会刊308期（2025年04月20日发布）详细介绍了少阳君的身份背景（实为墨殇天爆的推手辰太寻明）、心路历程、造型与道具（重轮返照）等信息。

《道劫龙战》第七章精采预告（2025年05月26日发布）中，少阳君宣布回归。

《霹雳朝灵阙》第29、30集（2021年06月08日相关整理）中，少阳君与西窗月、贺楼琼宇联手对抗帝蟒，为吸收晦暗血炉力量进入帝蟒意识，最终与步虚行一同尝试引走地狱鸟。

**人物影响**

少阳君帮助解芳菲和步虚行走出新的人生，影响了他们的人生轨迹；并帮助步虚行克服孤独恐惧，最终一同引走地狱鸟，体现了“火光的传递”。

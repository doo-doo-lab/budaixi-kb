# 少陽君 (少阳君)
================================================================================

少陽君

少陽君為號，本名雲中陌客．非九容，內心背負著重大罪孽，一心想要彌補贖罪，自帶謎團，鮮少人知道他的過去，數月前才現身武林，並幫助日新莊度過一場劫難，之後在應天輝的接納下，成為日新莊的一員，但其實不被莊主夫人銀娘所接納。身負殊異的三教修為，一心要尋找在墨殤天爆後就消失武林的三教頂峰，並從泥菩薩口中得知，全天下只有他才能找到「未孚」之所在。

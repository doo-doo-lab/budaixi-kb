# 策梦侯

奇花八部中，梦花部“瞬之华光”主人，有魏晋雅士之遗风，谈吐极为温文儒雅，举止容态更是慵懒华贵，喜爱抽水烟，与欲花之主关系暧昧。其人处世谨慎，心思细腻，不易为流言所动，对神、灵两花部被灭一案存有疑惑。

## 角色经历

策梦侯，本名清都无我，属于梦花部，表面上以和平的方式处理奇花八部内外纠纷，其实布计已久，目标是收集奇花八部秘传花谱，以练成八品神通，三十年前谋夺兽花天谱未果，故而刻意接近绮罗生，与之攀交，更利用绮罗生的信任，以打猎为由，设计绮罗生杀害击风族鹰后，化身紫衣人，暗中进行活动，并发现了绮罗生从未提起的武道七修身份。策梦侯修炼梦花术，为维持功体而不得不流连风月，欲海成为了痛苦深渊，为了脱离情欲牢笼，策梦侯安排连串毒计，与血傀师合作，却将自己又推向了另一个危险悬崖。

八品神通的执念是策梦侯人生的最高目标，在最后亦不惜赌命之举用自身血肉舍身情蛮花以成就八品神通。（霹雳惊鸿之刀剑春秋第14集）

于步香尘八花神通施展出现。（霹雳侠影之轰动武林第27集）

## 角色配乐

清都无我

曲/编曲：阿轮 收录于《动机风云原声带-精选38》

阿轮老师2012年作品，优美抒情的新世纪曲风，轻亮的琴声辅以弦乐协奏，适时加入的水晶音乐点缀，旋律犹如仙境般婉转流畅，衬托出梦花之主的风采与闲逸。乐曲选用为策梦侯的专属曲，初次使用于动机风云17集，梦花境内月色之下，一人一枕，高卧忘忧，策梦侯卧吸水烟，一副怡然自得的慵懒风雅。

八花奥义（策梦侯之八品神通）

曲/编曲：丁天牧 收录于《刀剑春秋原声带-精选40》

丁天牧老师2011年作品，以「弦涛」为题创作，古琴为主弹奏的气势乐曲，弹指间珠玉错落，轻舞曼妙，时而急弦如涛水，顿挫抑扬，铿锵壮势，营造多变化的层次感。

血色妖花（策梦侯舍命情蛮花）

曲/编曲：徐至正 收录于《刀剑春秋原声贰-精选41》

徐至正老师2009年作品，飘渺、迷梦般的旋律曲调，穿插古琴及二胡孤凉的演奏，融入了一股伤感无奈的气氛，奇特的音乐风格，仿佛一段旖旎梦幻般的奇遇。乐曲原用于妖绘天华之情蛮花抒情曲，后挪用于刀剑春秋第十四章，策梦侯为练就八品神通，移元灵与情蛮花合而为一，在巨大爆炸声响中飞灰烟灭，只余满园萧瑟。

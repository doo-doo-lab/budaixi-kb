# 策夢侯 (策梦侯)
================================================================================

策夢侯

奇花八部中，夢花部「瞬之華光」主人，有魏晉雅士之遺風，談吐極為溫文儒雅，舉止容態更是慵懶華貴，喜愛抽水煙，與慾花之主關係曖昧。其人處世謹慎，心思細膩，不易為流言所動，對神、靈兩花部被滅一案存有疑惑。

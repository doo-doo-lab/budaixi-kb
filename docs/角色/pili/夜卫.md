# 夜卫

鬼祭将军麾下左右手，完全服膺赤鬼领导，以夺回文诏为首要目标，身手诡异如暗夜鸱鸮，在影中林争夺战中，以发簪克制丝线，轻取无情丝。

## 来自百度百科的补充

在《霹雳狂刀之创世狂人》剧集中，夜卫作为鬼祭将军麾下参与了影中林争夺战。于第39集，其与无情丝对战，激战数回合后，夜卫头顶被丝线射中，随后挥刀反击，将丝线回击无情丝，最终击败了无情丝。

# 半驼废（霹雳布袋戏虚拟人物）

================================================================================

半驼废，霹雳布袋戏虚拟人物。一代铸剑名匠及用剑名家，所铸兵器皆为天下名器。韬光养晦、有深沉的修养，与武皇之讲文论武，欧阳上智惊为人中之龙。传授叶小钗剑术、刀法，教育他自谦、内敛，是叶小钗一生的恩师。

## 经历
巧龙半驼废，一代名铸剑师，欧阳上智也赞叹的能人。

年轻时与集境武皇交好，曾赠玉衡天剑给武皇，又受北域孔雀王之托，降服北斗星兽，并用其头角制成七支吸雷针，但也受伤导致终生驼背，年老后在天南山草庐铸剑为生。

因缘际会，半驼废看不惯一剑万生的行为，暗中训练叶小钗，传授其剑术，打败一剑万生和一刀万杀，从此，半驼废之名无人不知无人不晓，但也从此卷入武林是非。

半驼废半驼废曾言，他一生最对不起的两人，一是叶小钗，一是萧竹盈。

因为半驼废为斩断叶小钗的束缚，曾放出风声说叶小钗为造幽灵魔刀而投炉自尽，造成萧竹盈一生的悲剧。

后来，一剑万生和一刀万杀为逼出叶小钗，和半驼废约战风雨坪，半驼废以一敌二与两人打得不相上下，而同时被太原古人用抓风成石变成石像，得普九年之助恢复人形，因此答应普九年教训金少爷，又以擎天神剑测试冷剑白狐，惜与对方无缘，神剑再回其手。

半驼废因驼背因素被卷入欧阳上智身份纠纷中，和百里飞首、仇魂怨女对敌，最后为让叶小钗脱离欧阳上智的控制而帮素还真围杀欧阳上智，却也造成叶小钗的不谅解，视其为寇仇。

半驼废意志消沉、体力逐渐消退，甚至需要擎天神剑才能打退神蠺宫众兵。

半驼废后得崎路人之助照顾叶小钗，苦心孤意之余终让叶小钗彻悟，回心转意，但被魔域控制的黑白郎君南宫恨杀上门，半驼废不敌而亡，使得叶小钗抱憾终生。

# 任东西

任东西（天子传奇）

忠良之后，个性冲动、重情义的少年侠士，为报父仇刺杀纣王失败，得路不平指引，因缘进入无法无天无疆界，却遭飞惊子控制替其执行任务，背天刑之剑闯江湖，被改造后的性格，却也变得冷酷无情。

## 来自百度百科的补充

霹雳布袋戏衍生剧《天子传奇》虚拟人物

# 邪帝 (邪帝)
================================================================================

邪帝

天外南海傳說中的創世之神，為邪惡、黑暗的化身，邪帝智慧絕倫、武功高強，精於生化科技，擅以人為武器，創造出翼、獸、蟲三族，以遂稱霸三界之野心。

**性別**

男

霹靂九皇座 (回憶)

**根據地**

日邪村、血篁嵬坡、黑霧森林、天外南海

## 技能專長

# 天策真龙

================================================================================

霹雳布袋戏虚拟人物天策真龙，霹雳布袋戏虚拟人物。霸气万分，曾统一三教、称霸中原，但后期个性变的嗜血、残暴，而被禁入引灵山陵中、锁气而亡。但早先布下的百年大计使他再度重出江湖。有万夫莫敌之气势、王者之尊与智慧，策军操战面临颓势，为能力挽狂澜的当代王者！中文名天策真龙别 名龙主配 音黄文择性 别男登场作品霹雳图腾霹雳异数之龙图霸业霹雳封灵岛身 份上古七星之主组织门派天策王朝根据地腾龙殿、古圣窟本尊雕偶师潮州君皇角色编剧廖明治星 座白羊座初登场霹雳图腾第11集退 隐霹雳封灵岛第3集（被菩提弓射中散尽星灵之力致使功体尽废，后随沙舟一字师退隐菩提界）

## 人物经历

主要剧情指王星（指爪功夫）、剑王星（剑术）、刀王星（刀法）、智王星（策略）、易星（奇门遁甲）、悟星（洞悉）、化星（化光遁星，万点金星幻化虚体）各有专精，在上古三教式微，武道混乱，妖魔乱世的年代，随家破人亡的天策真龙横空出世，击退上古魔剑道之主·诛天进犯中土。天策真龙在数次血战后，七星凋零天策真龙由於天生体质会吸收星灵，造成功体增加、性格丕变，造成嗜血好杀的性格，因此开始追求极致的武力，开始杀害随他出生入死的七星。在化星入体（获得第6星）后，变成完全的魔王。侥幸未死的上古刀王星·刀无双，寻得神神秘的封灵岛守护者-越剑人、驯刀者之助，组成四刀四剑，以冥道强者-箭翊的银箭射成重伤，天策真龙自知若无法吸收第7星，将爆体而亡，遂与遗世老、竹丑先生、凤栖梧布下千年大计，坐化引灵山，释出五方图腾，静待天时。后世有紫星眉、东陵少主二人拥有七星之主命格，阴错阳差下，本来要借体夺舍的天策真龙，并未如愿进入东陵体中，而以紫星眉之躯重生，然紫星眉天生败相，注定天策此次败亡之因。天龙重生、白莲染血。新的七星传说再度开始!天策真龙吸收星灵（七星阵亡后的功体），但是会造成性格丕变，而且在一定期间内未齐备七星将爆体而亡。所以是在同伴与生命中挣扎，力量与良知中拔河。在吸收化星之后，若至善之人会变成极恶之人；大恶之人会变成慈悲之人。因此在上古时代，上古天策真龙（性善）若吸全七星，将会成为一代明君；而现世之天策由于上古以恶人之姿而死，所以备齐七星将成大魔王。造成龙图霸业最后的悲剧。事迹纪实(1) ## 人物详解

摘自霹雳会月刊第80期 人物哈烧新偶像---天策真龙以征服天下为目标的天策真龙，凭借七星星灵之助席卷中原，连素还真、一页书都败在其手，更一举将照世明灯、叶小钗、乱世狂刀、剑君十二恨等中原武林栋梁纳入麾下，建立一统中原的天策王朝。面对魔剑道和妖刀界势力的威胁，天策真龙在遗世老、屈世途等谋士帮助下打赢了很多胜仗，六星之力入体也具备了更多的本钱，但此时的天策真龙却选择急流勇退，隐居古圣窟研究经文。天策真龙的本质是善是恶，也让人难以捉摸。月刊第80期 天策真龙天策真龙其实也与众多武林人一样，有这一段痛苦的往事，派门争斗，让天策真龙年幼失去双亲，孤苦伶仃的愤恨，让天策真龙励志一统武林，不再有斗争。后来，天策真龙在遗世老等人帮助下越来越接近心中理想，无意间发现自己会因某些特定人物死亡而增强力量，即拥有七星之主的命格，积累的权势让天策真龙逐渐偏离本心，再加上七星化星灵入体的影响，转而追求天下无敌，下令诛灭七星，无论远近亲疏，不从者杀无赦。虽是沉迷于权势的影响中，但可以肯定天策真龙在迷失自我前绝对是有能力、才华和智慧的魅力领导，不然遗世老、步双极等人也不会等待千年，再追随在他身边。上古，在天策真龙成为武林祸端后，许多志士相继而起，最后以四刀四剑屠龙成功，天策真龙则将自己最后一丝灵气封入体内等待复生，在遗世老安排下，等到了紫星眉，利用其躯体复生。化星入体，对天策真龙性格影响巨大，当年天策真龙由仁君变成暴君，今日六星让天策真龙从暴躁刚愎转变为温和仁爱，可见化星影响。藏在狂魔枪中不为人知的秘密，七星、天策真龙和封灵岛的关系，让妖后无意间获得，并设计追杀不二刀使天策真龙七星归身，解除封灵岛封印。七星天策真龙的威力远超各方预料，但也失去理智、见人就杀，连步双极也惨死于其手，连自身性格都无法掌控的王者，也可见其存在是有多么悲凉。

## 人物漫谈

在决定标题的时候犹豫了很久，始终不知道该给天策真龙一个什么样的定位。严格意义上说，天策真龙是取代了紫星眉的灵魂而复活的。因此，他一出场就是一个拥有着五星星灵的强者。可以说，天策真龙的前半生（复生之后）都是由五星天策来演绎的。将一页书封在引灵山，一战打败五方之主，折损正道多人，险些灭了素还真，收服了武林大部分派门，身边不乏忠心耿耿的谋士和武将，且拥有强大的实力。之后更大败四刀四剑，收服三传人、驯刀者、越剑人及照世明灯等正道，巩固了武林共主的地位，并肩负起抵抗魔剑道侵略野心的责任。至此，他的作为都非常符合月下心中对于一代枭雄的认知——行事果断，手段狠辣，知人善用又不失王者之气。对于一个帝王来说，这些因素是必要的。而五星天策的缺点则是冲动莽撞，刚愎自用，这直接造成了他日后惨亏于魔剑道之主诛天手中。遗世老等人因他而死，天策真龙的心痛是显而易见的，麒麟记得战败之后天策一行人垂头丧气的前行，屈世途等人劝慰他不要因一时失败而灰心，天策真龙当时说了一句——“代价太大了。”那一刻麒麟终于发现了长期以来她一直忽视的一点，这个偶的双眉紧锁，除了表现霸气与暴戾之外，更隐含着一股浓浓的悲苦。天策真龙归根结底，天策并不是一个单一化的人物，从上古传说的渲染到他刚出引灵山的狠戾很容易跟人留下一个残暴的反派大BOSS的印象，但后期随着剧情的推进，这个人物的形象在逐渐的改变着，天策真龙作为一个“人”的侧面被逐渐揭示出来。是的，首先他是一个“人”，有着人类共有的七情六欲，然后他才是七星之主天策真龙。因为他是天策真龙，所以他要做天策真龙应该做的事情，而因为他是一个“人”，所以他才以一个活生生的人的角度选择要怎么做。上古传说中的残暴杀人狂究竟是什么样，剧中也承认“或许是在传说的过程中，产生了某些夸大。”事实的究竟已经不可考了，而眼前的这个天策真龙是什么样，我们每个人都能看到。如果他一直是五星天策，那么剧情的走向或许是完全不同的一个样子。而在由于他的又一次错误决定而战至绝境的时刻，六星归位了。剧中对他性格的大反转是以第六星的反向辅佐功能解释的。而我认为，或许在这之外，抱着凤栖梧的天策是真的因为痛苦和悔恨而痛哭失声。因为在那个时候，他正在失去最后一个自上古以来一直陪伴着他的忠心臣子。也许会有人说步双极，从他后期杀了不二刀让天策真龙变回“他心中的龙主”可以看出，在他跟随天策的时候天策真龙就已经是一个残暴滥杀的人了。但遗世老和凤栖梧却知道天策并非一直是这么残暴，甚至上古时期的七星，在开始都是忠心追随天策的臣属。因此可以判断，步双极是后期才加入天策麾下的。从上古七就陪伴着他的臣子们接连战死，在六星归位的那一刻，最后一位也离他而去，这对于一个王者（而且是很恋旧的王者）无疑是个沉重的打击。六星时期的天策对百姓而言是个好皇帝，然而从大局出发，他的行为却显得很没有远见，甚至可以说是有些逃避现实。曾经看过评论说他是个悲哀的王者，自始至终都受到星灵的影响，甚至没有自己的意识。但我觉得，在他人生中的很长一段时间里，他都是属于自己的，他真正悲哀的地方，应该是他自始至终都不明白，自己真正所求的是什么。六星天策的政治做法确实给中原百姓带来了难得的短暂和平，然而世事难测，他一心期待的和平也终归毁在了自己的手里。七星回归引起的力量暴升，让他失去了理智被杀戮控制，之后种种就不做评判了。最后他带着一颗空茫之心进入虚空世界，或许就是对这位曾经的王者最好的归宿。

## 人物评价

腾龙谷之战，凭着一己之力独挫包括三传人、傲笑红尘、剑魔傲神州在内的四刀四剑（四刀：诸葛晚照、乔夫、叶小钗、乱世狂刀；四剑：傲笑红尘、剑魔傲神洲、孤迹苍狼、剑君十二恨）和驯刀者、越剑人十大高手。纵使八卦转九宫、阴阳汇十锋，天策真龙依旧屹立不摇。天策真龙最强王者难以撼动的绝对实力，如融化亘古冰雪般的盛夏骄阳，在烟尘消退，胜负底定那刻，真实的讥讽着那群蚍蜉撼树的失败者的渺小与无力。这样一个睥睨千军的王者，为何笔者却要冠以“身不由己”四字？原因是因为，他的人生主宰权，并非他的自由意志所能操控，而是来自飘渺的上古传说——七星之灵。自上古时期就设下计谋，宁静的引灵山上，天策真龙和遗世老静静的等待到几乎连时光都把他们遗忘。最终风云汇聚，龙啸九天。沉迷与那个古老传说而致力收集七星之力的紫星眉成为天策真龙借体重生的工具，而后囚禁一页书，追杀素还真千里，挫败并招降十大高手建立天策王朝不朽功勋。金碧辉煌的腾龙殿上，一时环伺者，文臣武将，哪个不是当代风流豪杰？这时的天策真龙，即使“文无第一，武无第二”八字评语，也绝对当得起。只可惜，五星时期刚愎自用，对屈世途等人的忠言置若罔闻，最后导致与魔剑道的全面开战中一败涂地。好在此时因为潇潇适时释放星灵之力，使他得以及时吸纳化星之力，顺利扭转战局，并大改往日张狂好战之风，从此干戈不兴，成为一位真正与民休息，爱民如子的仁德之君。最后看淡功名出家将江山托付给屈世途，得知屈世途面对妖刀界入侵直接投降，把他一手创立的大好河山就此奉送他人时，其第一反映不是震怒，甚至没有一丝讶异，只是问明因屈世途和平开城的政策导致没有伤亡产生时衷心庆幸百姓未受战火之苦。六星时期的天策真龙，真的是一位让人心悦诚服，甘心追随的好王者，天策真龙可叹最后七星入体摇身一变，无法压抑杀性而四处屠杀无辜。看着对他忠心耿耿的步双极，曾与他有着论道之交的僧侣不明和尚、不白和尚死在自己手中，想必他心中那个最柔软善良的角落痛得无以复加，却又无法停止这样疯狂的伤人伤己。都说性格主宰命运，而这位天下无敌的一代龙主却连自己的性格都无法主宰。这样的他，除了“身不由己”，笔者真是无法想到更加贴切的评语。当他在听闻诛天死后，走上当年的誓约之地怀念战友，欣喜的伸出手去却只见繁华成空的那刻，那份高处不胜寒的怅然无奈，想来才是这位毕生受到星灵操控的王者最真实的感情流露。

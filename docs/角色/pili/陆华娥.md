# 陸華娥 (陆华娥)
================================================================================

陸華娥

儒門天下文官，居門下侍中一職，外貌娟秀逸雅、持扇而立的才女，與聞朝政，負責傳達王命，並執掌納言雅諫，與少陵御史、中書客合稱三司。

# 弑道侯

霹雳布袋戏虚拟人物弑道侯是《霹雳布袋戏》系列中的虚拟角色，出自《霹雳震寰宇之龙战八荒》《霹雳震寰宇之兵甲龙痕》《霹雳经武纪之枭皇论战》，由黄文择配音。作为集境三仪三司十二殿中的天府院主，下辖三台、龙池、凤阁、八座四殿，为破军府首领烨世兵权的核心幕僚，以阴险权谋著称，号“集境狡狐”，是唯一效忠军督的集境高层。弑道侯曾暗中与逆吾非道勾结，泄漏太阴司祀缳可能为魅族之后的情报，并在剑子仙迹营救途中设下埋伏。也曾领兵支援攻打血鸦山的残宗余部。在集境与苦境的冲突中，弑道侯曾对阵凯旋侯。为围杀“慈光之塔的惊叹”剑之初，弑道侯与烨世兵权、千叶传奇联手追缉玉辞心，最终遭玉辞心以兵甲武经废字卷反击，冰结而亡。

## 经历
弑道侯掌管天府院，被称为集境狡狐，下辖三台、龙池、凤阁、八座四殿，性格阴沈狡猾，在数次六部共议上积极主张对苦境出兵，和太君治长年不睦。

弑道侯 剧截图对剑法过人一等的香独秀深怀戒心，不仅反对香独秀帮助太君治对付阴端佛鬼，还在事成后为防他破坏烨世兵权借口放假将他调离，并为监视新任天机院主求影十锋把心腹三台殿主百里青调派接掌擎羊殿，好监控天机院的一举一动。

后在剑子仙迹与逆吾非道对决时，暗中和逆吾非道勾结，泄漏太阴司祀缳可能为魅族之后的情报，并在剑子仙迹营救途中设下埋伏，而他的真心是希望剑子仙迹与逆吾非道两败俱伤，所以发掌偷袭剑子同时，也驱散逆吾非道布下的大雾。

并且依照继太君治接任天机院主的求影十锋所请，领兵支援攻打血鸦山的残宗余部，结果因为求影十锋本身即是残宗内应，此战失败，更折了百里青性命。

在圣帝强力反驳烨世兵权进攻苦境的意见选择与苦境三先天等结盟后，虓眼军督联合早已谈妥合作的千叶传奇发难，杀死圣帝，用被药物控制住的雄王取代圣帝位置，弑道侯同时奉命杀上太阴司，生擒仙殿望夜、关山聆月、玉蝶遥星三名祀嬛。

却也不禁质疑千叶传奇何以计划留下关山聆月。

同时身为残宗内应的求影十锋向虓眼军督用处斩建议雄王的方式，将残宗引蛇出洞，好营造有利拯救雄王的局面，且由弑道侯奉命监斩，但吊在木架上的雄王竟是由千叶传奇所乔装，烨世兵权也亲身到场，完全压制残宗三人，将他们生擒，而弑道侯也表示他绝不会与军督为敌。

此战过后，烨世兵权完全整合集境台面势力，此时重出江湖的一页书也在剑子仙迹陪同下进入集境范畴，在虓眼军督出面前，弑道侯面对灭境梵天，摆起高姿态，语多挑衅。

此后，在破军府内，弑道侯与烨世兵权、千叶传奇商议苦境局势。

军督烨世兵权下令弑道侯传信给素还真、一页书、擎海潮、火宅佛狱与天者，提议在琉璃仙境一会。

在雪崖，弑道侯与千叶传奇对上老酒虫与言绫。

战斗中，老酒虫盗走军督身上的灵字卷后身亡，弑道侯下令全军追击携带武经逃走的言绫，但被军督制止。

为围杀“慈光之塔的惊叹”剑之初，弑道侯与烨世兵权、千叶传奇联手追缉玉辞心。

就在三人欲出招之际，玉辞心使出至绝之式兵甲武经废字卷。

集境惊觉后撤退，但略城防线开启，三人顿陷危境。

最终，玉辞心以废字卷反击三雄的独日武典与灵字卷联招，弑道侯遭对手冰结而亡。

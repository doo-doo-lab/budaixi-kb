# 花爵百炼生 (花爵百炼生)
================================================================================

花爵百炼生

素还真在海鲸岛一役之后的化身。脚踩珍珠鞋，衣着白银箔，身背黄金袋，手持碧玉杖，提倡要将丐帮企业化经营、帮助三传人突破武学瓶颈。穿梭在魔界、九大奇人与东瀛之间，在幽默风趣的言谈间，成功化解魔界与东瀛夺取中原之野心。

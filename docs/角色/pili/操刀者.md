# 操刀者 (操刀者)
================================================================================

操刀者

性格卑劣、作风霸道，凭恃著刀法高强，强娶娇妻楼沉沉，最后却反被设计而重伤、容貌尽毁，挨过一段茹毛饮血的野人生活；复出之后，便以极端的手段夺回流金岁月，并誓杀梅花岛遗孤报仇。

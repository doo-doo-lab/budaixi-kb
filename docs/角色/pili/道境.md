# 道境（霹雳布袋戏虚拟之境）

================================================================================

道境是《霹雳布袋戏》中苦集灭道四境之一，为最上层、最圣洁且命运最悲惨的神秘境界，现仅存方寸之地但生存条件优越。该境界曾经历上古道魔大战，异度魔界在此近乎毁灭整个道境，导致玄宗等修炼组织遭受重创并销声匿迹。境界内最初仅有欢喜佛、慈海渡者与孤愁先生三名修道者，三人与魔教交战后牺牲，道境自此绝迹。玄宗曾联合苦境万圣岩发动赦天封印，将异度魔界封入异次元，致使道境陷入死寂状态。吞佛童子开启赦道使异度魔界重返苦境，引发阎魔旱魃至弃天帝等势力对中原的持续攻势，最终由苍与银鍠朱武、三教顶峰合力迫使弃天帝回归六天之界，终结异度魔界威胁。道境幸存者苍在经历家园毁灭与同修叛变后，承担起追剿玄宗叛徒与消灭魔道的使命。

**中文名**：道境境界特色只剩方寸之地，但生存条件极为优越主要

**组织**：玄宗、异度魔界、汗青

**所属**：系列霹雳布袋戏

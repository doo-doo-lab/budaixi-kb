# 道境（霹雳布袋戏虚拟之境）

道境是《霹雳布袋戏》中苦集灭道四境之一，为最上层、最圣洁且命运最悲惨的神秘境界，现仅存方寸之地但生存条件优越。该境界曾经历上古道魔大战，异度魔界在此近乎毁灭整个道境，导致玄宗等修炼组织遭受重创并销声匿迹。境界内最初仅有欢喜佛、慈海渡者与孤愁先生三名修道者，三人与魔教交战后牺牲，道境自此绝迹。玄宗曾联合苦境万圣岩发动赦天封印，将异度魔界封入异次元，致使道境陷入死寂状态。吞佛童子开启赦道使异度魔界重返苦境，引发阎魔旱魃至弃天帝等势力对中原的持续攻势，最终由苍与银锽朱武、三教顶峰合力迫使弃天帝回归六天之界，终结异度魔界威胁。道境幸存者苍在经历家园毁灭与同修叛变后，承担起追剿玄宗叛徒与消灭魔道的使命。

## 来自百度百科的补充

## 境界简介

在《霹雳异数》第二十二集中，一页书道：

"宇宙无边，乾坤无垠，天地划分为苦集灭道四境界，苦境乃是我们现在放眼可见的武林，是最下贱，最污秽，最复杂的境界；其次便是集境；再来就是灭境；而最上层、最圣洁便是道境。苦境乃是我们現在放眼可见的武林。"

道境孤愁先生自称发明了挪体超空仪，并在转手之间治愈素还真的伤势，慈海渡者更是化身殁神金疆，创造了六合武典。而慈海渡者、孤愁先生两人乃是合修会之人，密谋设计了一页书，让一页书魂断皇甫桥。

在道境玄宗联合苦境圣域万圣岩以赦天封印将异度魔界封在异次元当中，但玄宗也同时被封印其中，因此整个道境才会呈现出一片死寂。

直到吞佛童子开启赦道，让本来属于道境的异度魔界重新在苦境之中出现，使得恒古以前发生在道境的大战，转而在中原苦境发生，整个异度魔界对中原发动一波波的攻势，由阎魔旱魃到九祸、袭灭天来、银鍠朱武，再到最终的创造者弃天帝，最后结合苍、朱武以及三教顶峰的力量，终于让弃天帝回归六天之界，整个异度魔界的威胁才正式结束。

## 境界特色

境界名称：道境

出现时间：霹雳紫脉线——霹雳狂刀、霹雳剑踪——霹雳神州之天罪

通道路径：黑暗道——由苦境前往道境的通道，有照世明灯把守其中，而后被异度魔界所毁。（但在霹雳侠影之轰掣天下时期再出的照世明灯带上被救的苍以及原无乡在此地疗伤，可想此时的黑暗道应该有所修复了。）

光明道——由集境通往道境的通道，但须籍由挪体超空仪才能由此通过。

超凡道——由灭境通往道境的通道。

地点：封云山*风云舍生道*云阶登天难

## 主要组织

玄宗：宗主、六弦：苍（六弦之首·苍）、翠山行（倚天披瑟）、赤云染（三弦道心）、白雪飘（奉弦归一）、黄商子（伏琴太一）、九方墀（捻筝玄道）；四奇：金鎏影（昭穆尊）、赭杉军（奇峰道眉）、紫荆衣（尹秋君）、墨尘音（拨弦道曲）；其他门人。

异度魔界【高层首脑】异度魔君：阎魔旱魃（魔族主君，异度魔界第一殿魔君）；邪族女王：九祸（鬼族女后，异度魔界第二殿魔君）；鬼族朱皇：银鍠朱武（前任战神，异度魔界第三殿魔君）。

【权贵】长老：补剑缺（鬼族血狼王）、戒神老者（异灵族）、杀身老（鬼族）、封骨衣（鬼族）。王族：朱闻挽月（鬼族公主）、朱武胞弟。

【组织成员】守路者：赦生童子（赦生道）、元祸天荒（天荒道）、别见狂华（神无道）。其他：慧八手（医座）、鬼魅之眼、冷醉（投靠）、爱染嫇娘。魔兵：靛雷龙残、刀诛、剑杀、鬼仆、浑屍、地罗、金色妖邪。

汗青编：四禁道：幻化上人(天心者)、月飘霜(地心者)、养尸子(人心者)、销魂夜媚(兽心者)。执事：钟灵神岳(主事)、九念如来(主事)、廉清君(主帅)、帅轻皇(掌令)。

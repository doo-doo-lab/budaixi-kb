# 玉千寻 (玉千寻)
================================================================================

玉千寻

纤指纨扇轻摇，墨风拂面，蛾眉星眼，霞姿月韵，倚风自笑，顾盼间自有神飞之态。为儒门修者，亦是玉门世家的一员，却鲜少归家，长年隐居木铎席珍。个性谦和有礼，待人处事圆融，实际上并不爱与人打交道。

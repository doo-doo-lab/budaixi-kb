# 云沧海（霹雳布袋戏虚拟人物）

================================================================================

云沧海，霹雳布袋戏虚拟人物。百世经纶一页书与天佛原乡结识的佛修者，受「佛炼铸天术」重塑武骨，佛缘深植，为人孤僻清寡，为调查忏罪之墙学案而离开初禅修界，正式涉足武林。云沧海身披之水蓝色袈裟，看似平凡，实乃佛门法器「云裟」。中文名云沧海别 名浮尘若幻配 音黄文择（闽南语）、郝鹏（国语版）性 别男登场作品霹雳战元史之动机风云登场作品霹雳惊鸿之刀剑春秋根据地初禅修界组织门派天佛原乡角色编剧周郎本尊雕偶师刘氏出场集数21集

## 角色设定

名称：云沧海称号：浮尘若幻云沧海性别：男身份：雨钟三千楼少主诗号：既云天地共歌吟，尘海当如云海深。显密何须分别铸，同根百炼造甘霖。初登场：霹雳战元史之动机风云第26集退场：霹雳惊鸿之刀剑春秋第6章（被耳目失灵的绮罗生封喉误杀）来自：雨钟三千楼根据地：初禅修界

## 角色能力

云裟武学：云沧十破、天裟广化、云龙渡海（与苇江渡合招）、泓影涤千尘咒术：天裟广化·泽披众生所有物：云裟◎云沧海身披之水蓝色袈裟，看似平凡，实乃佛门法器，平时被云沧海披于身后，战斗时能甩出攻击，多变难料的招式，能扰乱对手注意，亦能化为布剑砍伤敌人◎事迹：为报血洗中阴界之仇，宙王与六独天缺、缎君衡、魔皇杀上天佛原乡，尔善多与云沧海对上魔皇质辛，云沧海甩动身后雪裟，手一握，袈裟凝成剑形，与尔善多琵琶琴波一来一往，同时攻向魔皇。蓝裟时而如影似幻，时而坚硬不摧，轻盈之姿来往自如，也让战局走势难料。无奈魔皇实力远超过两人想象，魔皇一掌袭来使两人双双呕红，幸而宙王此时负伤退兵才结束战局。

## 人际关系

云沧海组织门派：天佛原乡父亲：疏雨孟尝义父：十方孤凛（盛华年）朋友：一页书其他：无故事的人、苇江渡、尔善多、风雪一路禅上司：矩业烽昙仇敌：绮罗生

雲滄海

霹靂布袋戲虛擬人物。一頁書於天佛原鄉結識的佛修者，原為雨鐘三千樓少主，受「佛煉鑄天術」之手法重塑武骨，佛緣深植，為人孤僻清寡，為調查懺罪之牆血案而離開初禪修界，正式涉足武林。其身披「雲裟」乃雲滄海專屬的披風狀法器。

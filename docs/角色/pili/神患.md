# 神患 (神患)
================================================================================

神患

文武兼備型的邪靈高手，對滅輪儒聖深懷敵意，強烈捍衛邪靈的生存與地位。曾被臥佛以剋邪珠所制，後為未來之宰解除束縛，至此臣服麾下，助其消滅正道、開創邪靈國度。

# 神患

文武兼备型的邪灵高手，对灭轮儒圣深怀敌意，强烈捍卫邪灵的生存与地位。曾被卧佛以克邪珠所制，后为未来之宰解除束缚，至此臣服麾下，助其消灭正道、开创邪灵国度。

# 枯九泉

为罪念晶源在妖市外的死亡海沟中复活的七人之一，外型如黑白无常般的神秘幽怨，手持一支招魂幡，上头挂着哭魂铃，能以此来招魂唤鬼，而脚则踩着奇特的无常鬼舞，全身散发死亡气息，好似下一秒就要将人拉入阴间。

※备注：此“枯九泉”角色为参考“善恶分明、奖善罚恶-黑白无常”之原型作品制作，其原创者为玖零零原型工作室负责人-许山姆。

## 来自百度百科的补充

角色生前疑为藏魂家成员，因修炼邪功遭处决，行刑前预言赦天琴箕命运。复活后效忠异识，曾游说琴箕与御清绝加入罪域，并预测君海棠命运。其武学包含挪魂律、无常鬼舞等，创神篇下阕第30集与末日之狂对决展现快钩银钩交锋，最终于第31章死于素还真，后以魂识形态再登场。

枯九泉以操控亡者与命运预言贯穿罪域阴谋，其短暂活跃期对妖市势力格局产生多方影响，悲剧结局凸显异识侵蚀与命运无常主题。

个性阴险而善谋，修炼诡异莫测的无常鬼舞，能唤魂操鬼，当年曾与琴箕有两面之缘，更预言了琴箕日后的命运。（会刊256期）

从其外形、武学上来看，似乎生前是属于藏魂家一派，为练成邪门功夫，杀死许多妖市生口，吸食其魂魄而被判献刑，行刑前，预测了琴箕命运，日后也会被亡海献刑且应验。后因罪念晶源附身而被复活，服膺于异识，为罪域奔走。

在战骸因受赦天琴箕勾魂琴声影响被困闇境之时，助其脱困。后找上琴箕，言其阎王三更响与自己的傩舞相合，邀其加入罪域，因早前成功预测出琴箕命运而使琴箕出现动摇。

在露水三千，枯九泉与赦天琴箕发生激战。

预测出君海棠的命运。为晶源入体的缥缈月启罪。在媂君死后游说御清绝加入罪域未遂。

最终于第31章死于素还真。

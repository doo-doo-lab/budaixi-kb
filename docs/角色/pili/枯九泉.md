# 枯九泉
================================================================================

枯九泉

为罪念晶源在妖市外的死亡海沟中复活的七人之一，外型如黑白无常般的神秘幽怨，手持一支招魂幡，上头挂着哭魂铃，能以此来招魂唤鬼，而脚则踩着奇特的无常鬼舞，全身散发死亡气息，好似下一秒就要将人拉入阴间。

※备注：此“枯九泉”角色为参考“善恶分明、奖善罚恶-黑白无常”之原型作品制作，其原创者为玖零零原型工作室负责人-许山姆。

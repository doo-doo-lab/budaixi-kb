# 枯九泉 (枯九泉)
================================================================================

枯九泉

為罪念晶源在妖市外的死亡海溝中復活的七人之一，外型如黑白無常般的神秘幽怨，手持一支招魂幡，上頭掛著哭魂鈴，能以此來招魂喚鬼，而腳則踩著奇特的無常鬼舞，全身散發死亡氣息，好似下一秒就要將人拉入陰間。

※備註：此「枯九泉」角色為參考「善惡分明、獎善罰惡-黑白無常」之原型作品製作，其原創者為玖零零原型工作室負責人-許山姆。

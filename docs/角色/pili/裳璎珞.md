# 裳璎珞

天佛原乡深阙最高指导，佛炼铸天术创造者，人称“佛铸”，行事谦和、明理有度，曾率领深阙对抗洗罪三尊所属的欲界势力，在佛乡解开禁锢、恢复清圣后，担起对抗欲界、重导佛门正法的重责大任。与妖界圣婴主焱无上似结识许久，有一段未知的过程。

## 创作背景

“裳璎珞”之名中，“璎珞”为佛之赘饰，是菩萨摩诃萨才会佩戴的饰物；佛身宝华源于其心，僧人罗汉及佛皆不佩戴璎珞，以“璎珞”为名象征其“非佛”的身份，暗示了其在无佛出世的末法时代的结局，取名初心是“想沾一点佛光华映”。

## 形象设定

其名“璎珞”为佛之赘饰，只有菩萨摩诃萨才会佩戴，象征其“非佛”之定位，亦暗示其结局。裳璎珞称号“年华不染”、“佛铸”，诗号为“愿与年华凋敝罄，尘愆不染佛前灯”，中原正道擎天巨擘。

与妖界圣婴主焱无上似结识许久，有一段未知的尘缘，曾被步香尘擒至妖界。

## 人物经历

裳璎珞

年华不染裳璎珞，天佛原乡佛铸，亦是佛乡深阙的最高指导者。初登场于《霹雳侠影之轰动武林》第22集。明理有度、审时度势，有着兼善天下的弘愿，护守着苦境苍生。在久远前，欲界逐步渗透天佛原乡之际，裳璎珞率领深阙众僧与之抗衡，迫使欲界洗罪三尊只能豁命以玉海九轮盘之力，将深阙连同欲界部从以牵制之法封印。

通过洗罪三尊的谋算，魔佛波旬降世，玉海九轮盘的封印，终也随之瓦解。深阙解开禁锢、恢复佛乡清圣后，担起对抗欲界、重导正法的重责大任。不久，裳璎珞在获悉欲界动向后，率众僧者前往青蒙山阻拦。但本该胜券在握的战局，却因至极的变数而发生异变，魔佛波旬三体之一的智体迷达，竟已回返欲界，重启浩劫。随着迷达重掌大权，手段更加狠戾，裳璎珞肩上负担也更加沉重。

裳璎珞与妖界圣婴主焱无上似结识许久，有一段未知的尘缘。在《轰动武林》时期，曾被步香尘（侯娘）擒至妖界严刑审问。

之后，欲界更以五百僧命相威胁，要求裳璎珞率众人归降欲界。裳璎珞在两相权衡之下，选择相信苍生向善的信念，回应欲界招降，救出五百僧人。但佛乡修者阕声云舵选择默默背负诸般杀生罪业。以牺牲与鲜血铺就的佛乡未来，让裳璎珞痛心不已，更不愿辜负一切，率领众人进军欲界。但就在欲界战况不利之时，巨魔神无端降临，竟是令局势顷刻扭转，所幸阕声云舵与娱笑颠及时来援，协助裳璎珞带离佛乡众人。

在佛乡擒住迷达之后，阎达与步香尘联手进攻佛乡，裳璎珞为护全金棺与深阙诸长老，重伤未愈仍再启佛鍊铸天术，独力断后，却也因此被擒沦为阶下囚。纵使酷刑加身，仍是不曾对欲界透露只字片语。所幸，在四智武童的运筹下，正道答应以迷达换取裳璎珞性命。

纵使甫脱牢狱之灾，伤势沉重的裳璎珞仍是义无反顾再度加入云渡山之战。与一页书、佛剑分说等正道之人联手抗衡魔佛，无奈仍是不敌落败。在正道即将全军覆没之际，裳璎珞再运佛鍊铸天术豁尽生命与功力困锁魔佛，用性命为苍生换取了希望。裳璎珞于《霹雳侠影之轰定干戈》第12集应大火凶劫丧身，最后一次登场于同剧第20集妙胤传心的回忆中。

## 人物评价

裳璎珞，行事谦和，慈悲为怀，不轻言牺牲，在佛乡面临波旬浩劫之际无惧无悔担下沉重责任，于异教邪说窜起的末法时代，引领佛乡众人坚守佛门正法，点燃世间的一线希望。当众人极力挞伐阕声云舵的杀生，裳璎珞却能明瞭阕声云舵为苍生未来无悔堕入无间地狱的悲愿信念，为其护航甚至共担罪业，如斯心思澄明的得道者也不枉其佛乡深阙最高指导之名。

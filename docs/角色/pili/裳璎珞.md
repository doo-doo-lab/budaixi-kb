# 裳瓔珞 (裳璎珞)
================================================================================

裳瓔珞

天佛原鄉深闕最高指導，佛鍊鑄天術創造者，人稱「佛鑄」，行事謙和、明理有度，曾率領深闕對抗洗罪三尊所屬的欲界勢力，在佛鄉解開禁錮、恢復清聖後，擔起對抗欲界、重導佛門正法的重責大任。與妖界聖嬰主焱無上似結識許久，有一段未知的過程。

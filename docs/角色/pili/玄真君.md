# 玄真君

霹雳布袋戏虚拟人物玄真君，霹雳布袋戏虚拟人物。道教十三道之一。箭术无双，医术超绝，为人极为刚正，妒恶如仇；行事果决近乎鲁莽，对自我有极高的要求。道教内斗式微后退隐于离愁谷，因合修会之事再度红尘。万堺纪年时期，玄真君身为弓弧名家首席，为了幽都魔物肆虐之事挺身而出，并率领弓弧名家的部属，一同以百步穿杨的箭技来对抗邪魔，捍卫和平不遗余力。名言：半生闲隐今终止，一步江湖无尽期。诗号：素心常怀静朴理，红尘偏染程子衣。半生惯看风云起，一步江湖无尽期。

## 经历

霹雳狂刀-霹雳英雄榜时期玄真君，乃是道尊座下十三道之一，擅长弓箭射术、医道亦称绝伦，因救过巧手灵工，蒙他将白云骄霜委托制造的无弦神弩相赠，助他无形箭之威更上一层楼。

由于对道尊失踪后的道教内斗感到失望，以及厌倦争名夺利、打打杀杀的生涯，遂对同门不辞而别，退隐于离愁谷数十年，销声匿迹，直到太极道君指点叶小钗、花非花请玄真君协助医治失去脸皮的金小开，方再度被卷入江湖是非。

为阻止玄真君缝合金小开的脸皮，孤愁先生杀了玄真君徒儿剑胆示威，玄真君大怒之下，接连使出无弦神弩十八式中的一泻千里、两尽其妙跟三分鼎足三招重创孤愁。

好友照世明灯登门拜访，玄真君从此再涉武林，并让徒弟剑心退隐。

玄真君不但在治好金小开后将他训斥一顿，还只身杀上合修会据点清理门户，诛杀无极道君、鹤原等道教叛徒。

此后，玄真君积极帮助正道，为保护灭境魔头鬼王棺替一页书作证，玄真君和照世明灯力斗合修会人马，打死西门足，但天残武祖为立威而派来的红彩、蓝带伺机夺走玄真君和照世明灯的惯用兵器，逼迫两人参加武学讲座。

后来武学讲座结束后，本与空劫要往云渡山保护欢喜佛，却又听闻鬼王棺为恶的消息，遂接受目残指点，在风雨坪以三分鼎足一招重创鬼王棺，本以为鬼王棺已毙，不料他暗中移转元气，保住了生命。

其后乱世狂刀受人煽动与玄真君约战，照世明灯发现玄真君眉间有一股黑气，表示厄运当头，此去大凶，遂暗中使用了厄运转移，替玄真君承受了加倍的劫厄，因此身受千子弹，重伤几死。

后来因缘际会下，玄真君与黑流派遗孤白月等人相识，帮助他们抵御非凡公子派来的追杀，英雄气概使白月芳心暗许，同时在他身上施下意形忍法，所以在玄真君找青阳子挑战失败，依诺自尽后仍能保住性命，让白月与黑流派大首领救回，但却疯癫痴呆。

直到魔域派出蛰伏武林中的大夫长桑鬼陀借由高超的医术接近正道时，方被他救醒。

但玄真君也在诊疗期间被他离间，与素还真关系破裂，虽没有接受三世道君的安排射杀非凡公子，却也因圣龙口物是人非，感到迷惘失望，感慨“数十岁月如一梦，此身虽在忆堪惊”，再度归隐离愁谷。

后曾替狂刀接回内脏，而后又于黑暗道与照世明灯一同退隐，却突遇对道教怀恨的盼梦圆寻仇，师侄紫阳子被杀，玄真君和照世明灯现身缉凶时，玄真君不敌盼梦圆，被她拨回无形箭射穿胸膛而死。

复出剧情于《霹雳狼烟之万堺尘涛》回忆录中登场。

玄真君离开万堺之后，得道皇圣无殛指点的太真君告知玄真君其尚有一劫未渡。

玄真君因此借助蒙昧圣卉以副体代死于盼梦圆，之后便一直隐于天地门，勤修无形箭，并将道皇遗册交予青阳子。

八歧邪神祸乱中原时期，玄真君为还道皇提点化劫之情，应照世明灯之邀复出，再现无弦神弩射杀邪狱明王，以帝弓虹摧毁八龙山邪神结界。

邪神一战之后再次与照世明灯一同退隐。

一段时日后再入红尘，参与分离青阳子与吞日驭龙主的行动，此时离愁谷已经重建，且玄真君收得两名弟子剑云、剑雨。

太玄封羲开启寰界时，玄真君亦被纳入其中。

太玄寰界存续期间及消失后，玄真君一直暗中调查道门变化，更试图追踪太玄封羲下落，意外反成锁定对象，被太玄封羲击败。

更加精致化，保留玄真君的特色。

向后梳的头发，戴上红色系头冠，几乎是玄真君注册商标。

明显的颧骨，脸部线条与个性一样刚毅，一直是玄真君的特色。

以前有一段时间布袋戏的服装特色是大垫肩，这次维持相似型态，但尺寸保守。

整体以红白色系简单搭配，古典的花纹维持玄真君的稳重感。

场景设计侯壁峰侯壁峰侯，有箭靶之意。“侯壁”乃一处玄奇山壁，会定期浮现各式星图。

前往侯壁对面的高峰，进行“侯壁射星”的竞技，更成为弓弧名家之人热衷的活动之一。

追羿峰——弓弧名家弓弧名家，乃建立在追羿峰之上，乃取其“追求射艺与传说中的神射手后羿相比”的涵义，场景不求华丽，但务求呈现明亮洁净、阳光晴朗的感觉。

主建筑则希望能有简单而典雅的日式建筑风格。

## 人物评价

霹雳宝典扫图严于律己，在某种程度上也就是对自己极端完美主义要求。

玄真君也是这样一个人。

他对自己的要求是非常严格的。

你可以看到他一直是袍服整齐，头发一丝不苟（神智不清的那段时间除外）。

他要求自己在道德上绝对完美，甚至，不允许自己犯一点差错。

对于他本来有能力去做却最后没有做的事情，他就会耿耿于怀——何况，这件他没有做的事还导致了这样严重的后果：一页书与不知名的惨亡。

于是，他自罚坐钉床三天，就是一件非常顺理成章的事。

但这还不是主要的。

重要的，是这件事对他的思想造成的影响。

自此以后，他认为自己应该采取更迅速的行动，更决断一些，使一切防患于未然；

而一切“邪道”应该尽数消灭。

也就如他称赞一页书的那样“无论局势如何危险，勇敢地挺身而出”。

七彩云天事件是玄真君思想变化的一个转折点，也是以后玄真君遇事缺乏深刻思考的主要原因。

与徒弟玄真君与剑胆、剑心玄真君的两个徒儿，出场的时间并不多——尤其是剑胆，《狂刀》第四集才出场，第七集时便死于孤愁先生之手。

所以，对于他们三人的师徒关系，也就只能作些大胆的推测。

剑胆说话直率，对于外人更是不留情面——甚至达到不通人情的地步。

这从他与花非花的对话中可以知道。

他那种咄咄逼人，连好脾气的花非花也忍耐不住。

相比之下，剑心的性格较为平易，在谨守原则的同时，亦颇具慈悲之心。

以剑胆的性格，即使不命丧于孤愁先生，以后行走江湖，也必然处处碰壁，难以立足；

而剑心虽然也是社会经验不足，但其谦和有礼善解人意的性格，也可以为他建立起不错的人缘——须知在动乱的江湖中，有人帮忙总比孤身一人安全得多。

也难以看出玄真君对这两个徒儿较偏爱哪一个。

不过这里却有一个奇怪的现象：玄真君唤他两个徒儿的时候，总是习惯叫“剑心、剑胆”。

按道理，剑胆居长，应该是先叫剑胆才对。

这里姑且排除口误的情况，那么在玄真君的心目中，第一位的是剑心，其次才是剑胆。

而在与孤愁先生的战斗中，玄真君首先救的也是剑心。

但作为师兄，武功一般情况下是较师弟为好的，所以玄真君先照顾较弱小的一个也是情理之中。

从玄真君那种严于律己、追求完美的个性出发，就可以推想他对两个徒弟的要求必然是相当严格。

而剑胆剑心也有着不错的武功，这点是足以佐证玄真君对他们的严格要求的。

要说明的是，这个所谓的“不错”，是相对于他们的同辈而言的；

一遇上孤愁先生这种道行深厚的高手，他们就很快败下阵来。

值得思考的是，剑胆和剑心用的都是剑（而且都会御剑飞行）；

而玄真君的武器非但不是剑，而且从来没有看见他用过剑招。

道教之中，除了武真君的徒弟鹤原，其他人，比如三世道君和玄天六阳，都是以拳掌功夫见长，从来不曾用过剑。

因此，说“剑”是道教的主流功夫显然说不过去。

鹤原所用的“平阳剑法”，其招式就是祭出飞剑的形式，与剑胆剑心初出场时的御剑颇为类似。

而玄真君曾用嘲讽的口吻对鹤原说：“‘平阳剑法’，道教最下乘的功夫。

你师父只教给你这些吗？”以玄真君自负的个性，他能够对其师弟的徒弟说这种话，就说明他自己徒弟的水平绝对不止如此。

不过，剑胆与剑心的武功与玄真君自己的差距实在是太……太大了！

他们败给孤愁的时间大约就相当于孤愁败给玄真君的时间。

剑胆和剑心看上去也不像是资质甚差之辈，所以也大略可以推断出，他们入门的时间并不长。

爱玩是小孩子的天性。

玄真君的严格要求难免会引起两个徒儿的逆反心理，加上玄真君虽然重视两个徒弟，但以他那种内敛不善于言辞的性格，难免会有误会，从而产生矛盾。

但是两个徒弟对玄真君都是毕恭毕敬的，而且处理事情都以“师父的利益”为首要考量，他们必然是从师父身上看到一些值得他们尊重的东西。

所以，也许这师徒三人平常缺乏言语，缺乏欢笑，但关系却依旧能够和谐稳定。

与朋友（1）玄真君和百里抱信人们在评论玄真君的时候，总是说他黑白分明，不容许有灰色地带。

而在我看来，百里抱信恰恰就是玄真君心中的一片灰色地带。

如果单单从互相了解这个角度看，玄真君和百里抱信确实称得上是好友。

玄真君了解百里抱信的想法。

玄真君，请你记住‘人不染风尘，风尘自染人’这句话！

告辞。————————————————玄真君非常明白，百里抱信表面上是代表儒教联络其余两教，整合三教力量对抗合修会，实质是要为儒教谋求在三教中的统治地位。

尤其是，玄真君对儒教的投机做法十分清楚：当其余两教，尤其是道教，在和合修会拼死拼活时，儒教则袖手旁观；

而当众人皆元气大伤时，儒教才施施然出现，坐收渔利。

于是，可以看到，玄真君对百里抱信的每一句话，均是针锋相对，并且还故意做出安于隐居的姿态，使百里抱信无计可施，惟有抛下狠话灰溜溜地离开。

不过，虽然是针锋相对，但玄真君的每一句话中，除了反驳、诘问之外，也带着规劝。

因为他知道，百里抱信的本性是善良的，她不应该过多地卷入这个旋涡之中。

所以，这就体现了玄真君对百里抱信的“灰色”：既防着她，也想帮助她。

百里抱信也很了解玄真君，不然也就不可能阻止得了玄真君射杀鬼王棺。

她故意提高声调引起在场的人的注意，于是就使爱面子的玄真君不敢有进一步的行动。

而且，玄真君应该感谢她：若不是她及时拉他离开现场，他很可能就是黄甫桥上的另一个冤魂。

百里抱信和玄真君在对人的认识以及价值观上有着非常明显的分歧。

百里抱信主张求名，玄真君淡薄名利；

两人对一页书的看法就是背道而驰的；

玄真君甚至当面对百里抱信是否正道表示怀疑。

这两个人，从一般道理上讲，是不可能走到一起来的。

如果说百里抱信接近玄真君是为了利用他，那么玄真君呢？

他没有利用百里抱信的必要，加上他本人没有说话的爱好，没有故意要找个跟自己观点南辕北辙的人辩论一番的需要。

是什么原因使他一直保持与一个带有某种未知目的接近自己的人的朋友关系呢？

有人说玄真君疾恶如仇，坚决奉行“恶人没有人权”。

我一度十分认同这个观点。

但如今我才发现，其实玄真君的心是极软的。

说玄真君疾恶如仇不留情面的根据，无非是他坚决要射杀金小开一事。

而事实上，玄真君确实有医治好金小开的面皮——秦假仙嘴皮子的作用确实不容忽视，但花非花的真诚恳切更是其中一个重要的原因。

若玄真君真的非杀金小开不可，那么在他一击未中的情况下，他为什么不继续追击逃遁的金小开而是首先去照顾受伤的叶小钗？

他的慈悲之心，隐藏在他表面的杀气之后。

于是同样道理，他与百里保持朋友关系，是因为不忍：不忍心一个本性善良的人被野心和仇恨所蒙蔽。

于是，在玄真君黑与白的世界中有了一层过渡，那就是灰色的百里抱信。

（2）玄真君和照世明灯（天真君）不少人在提到霹雳之中的搭档时，会提到他们两个：说起玄真君，不能不说说照世明灯；

说起照世明灯，也很难不提及玄真君。

这就一直以来造成我的一个错觉：他们两个的关系是亲密无间的知交好友。

而我最近在整理他们两个的剧情时才发现，这似乎是我的一厢情愿。

首先，是从称呼上来看。

玄真君未叫过慈郎一声“师弟”，慈郎未叫过玄真君一声“师兄”；

玄真君更是由始至终都仅仅是以“照世明灯”相称。

虽然说，慈郎一直想掩饰自己道教天真君的身份；

也可以说，玄真君不过是顺着慈郎的心意行事——但是，自从《道源》失落，慈郎再没有隐瞒身份的必要，而此时，玄真君也还是一口一个“照世明灯”，慈郎一口一个“玄真君”。

如果说道教中人都喜欢以道号相称，那么，当他们两个人提到太真君和元真君的时候，为什么一直都是说“大师兄”、“二师兄”，而不是直接叫“太真君”、“元真君”呢？

这是令我怀疑的第一个原因。

其次，他们两人的相知程度似乎并不深。

这里摘录他们两人的一段对话：————————————————天：浮云游子意，落日故人情，挥手自兹去，萧萧斑马鸣。

玄：无限凄凉的感触。

天：十三道永远都无法再共聚一堂了！

不知珍惜现有的一切，是人类的通病，直到你懂得珍惜时，已为时太晚矣！

玄：照世明灯，数日不见，你改变了许多。

天：我是为死去的兄弟悲叹。

十三道之中只剩你，圆真君，明真君，修真君以及我五人。

不幸的是咱五人之中，竟然有人出卖自己的兄弟，背反道教！

玄：你在我面前讲这些话什么意思？

难道你认为我是叛教之徒？

天：当年你有没有进入天地门？

玄：哈哈哈~~~~在青阳子离开道教自创合修会之时，我就看破红尘，深山退隐了。

天地门之内的大激战，玄真君没有参与。

天：迷幻世界，真假难分，请勿见怪。————————————————若慈郎真的了解玄真君，他就不会作这样的猜测，而且最后还说一句“迷幻世界，真假难分，请勿见怪”，客气至极！

一点不像是相交多年的好友。

也许也正如步所说，慈郎一则是因为江湖经验，一则是二人确实是太多年没有见过——中间相隔那么多年，确实可以发生很多事情。

再次，是他们两人说话的态度——实在是太客气了！

两人在昊光道院检查时，当玄真君发现了一条秘道，他对慈郎说：“照世明灯，请过来一下。”若是知交好友，在这种情况下，会用一个“请”字吗？

这只是其中一个例子。

从玄真君与慈郎说话的态度来看，似乎比百里抱信还要来得礼数周到，因此也就显得亲切不够。

虽然如此，玄真君和慈郎的关系，应该还是比和百里来得密切的。

因为，尽管说话说得客气非常，但也说得交心，不像和百里说话时那样时时抱着戒心。

尤其是玄真君和慈郎在剧中初次见面时，玄真君对慈郎说“也许是我的医术不如人”。

这是自负的玄真君第一次在别人面前承认自己“不如人”——尽管前面还是加了个“也许”。

玄真君对慈郎说的一些话，是他在其他人面前所不会说的，尤其是在“道威无极”里的一番对话——那段对话方有点“知己”的味道。

毕竟玄真君到后来是选择和慈郎一道在黑暗道退隐的，这多少也能说明他们两个的关系总不至于太生疏。

（3）玄真君和白月白月登场在玄真君意志最消沉的时期：这时，所有人都怀疑他的能力，包括秦假仙。

他开始知道什么叫失败——却不知如何去面对。

与白月的相识，完全是偶然。

当玄真君看到白月与一众黑流派忍者与亡命之花打得难分难解时，他还似乎蛮有兴致地在一旁看热闹——他认为东瀛忍者自相残杀，对于正道有好处没坏处。

但当他看到亡命之花凝神防御白月的断魂箫之时，却又忍不住偷袭了亡命之花一箭，阴错阳差就救了白月他们一帮人。

可以想象得出白月见到玄真君时激动的心情——处于劣势的黑流派终于可以得到一个强大的助力了！

但由于她不知玄真君的心意如何，所以也只是委婉地提出请他去见黑流派的大首领。

谁知玄真君答应得很爽快。

于是，两人这就算是相识了。

其实，这番初相识，有多少友情的因素实在让人怀疑。

白月不过想为黑流派拉个帮手，而玄真君，很可能也只是想利用黑流派的力量去对抗非凡公子。

各怀心事，互相利用，两边似乎都不吃亏。

但随着交往增多，就不仅仅是“利用”级数的朋友关系了。

玄真君的固执脾气在他拒绝黑流派大首领传授武功的那一刻体现得最为淋漓尽致。

白月尽管有点失望，却也使她单单对玄真君武功的好感上升为对其人格的好感。

发展到后来，白月甚至是不惜牺牲部下的性命来全力配合玄真君的行动——很多次，玄真君的行动可以说是颇为莽撞的。

如果这时还单单是利用，即使玄真君的能力再高，付出的价值未免也太大了。

玄真君尽管心高气傲，尽管每次都口口声声说“不要帮忙”，但他不是瞎子，对于白月的付出他是看得见的，而且还感念在心。

玄真君不善于表达自己的感情，但不等于说他没有感情。

某次白月不辞劳苦到琉璃仙境告诉玄真君一些消息时，玄真君就劝她先休息一下再走，并说“你我是朋友”。

玄真君肯这样说，就代表他这时已经完全把白月当朋友看待了，而不仅仅是利用的关系。

大首领临死前，希望白月去寻找自己的幸福。

白月又何尝不想如此呢？

假如她来到琉璃仙境，见到的不是头上插满花、疯疯癫癫的玄真君，也许她就不会步上死谏之途，也许她会有个平静的下半生。

她带着希望，犹豫着踏入琉璃仙境；

而她所见到的人，她心心念念要见到的人，促使她下了最后的决心。

大雪原上，白练飘扬……与战友关系玄真君应该说，玄真君并不是一开始就加入到正道一方的阵营中，尽管他医治了秦假仙、荫尸人和金小开，替叶小钗找疗养地，还和当时正道的大对头之一孤愁先生打过一仗。

在相当一段时间内，玄真君只是作为一个局外人的身份从旁协助，并没有过多地介入其中。

一则，红尘俗世的纷扰，玄真君自己又不是没有亲身体验过，不必要的麻烦自然是能避则避；

二则，在玄真君看来，自己的身份是前辈，更没有必要加入到正道中任后辈指挥。

于是，在那段时间里，玄真君大部分时间是在离愁谷中泡茶，或者和百里抱信斗斗嘴，或者和慈郎四处闲逛，时不时为正道提供一点协助（多数是医疗方面的）。

所以，此时玄真君与正道的关系还是若即若离。

玄真君完全溶入正道，成为正道实际的一员，并没有什么明显的标志，而是一个渐进的过程。

只是到了某一段时间，我们会看到发生了什么事时，素还真分配任务时玄真君成为了其中一个，就是诸如“某某去哪里干什么，某某某去哪里干什么”之类，玄真君就成了“某某”之一。

开始时一直还是合作愉快相安无事的，但后来问题渐渐就出来了。

玄真君直接的脾性甚不接受素还真那些弯弯绕绕的处理事情方式。

而且《狂刀》时期发生的事情很多，正道这边就好象消防大队，哪里有险情往哪里去，看不出一个很明显的计划，好象就只是一味在补漏。

玄真君加入正道最重要的原因就是寄希望于其最终能够“治世”，但实际的情况却叫他担心。

他忍受不了正道的作风便频频单独行动，用他自己的方式去处理。

很明显，素还真的计划是从来没有向玄真君说起的，更不要说讨论，只是一有任务就去找玄真君帮忙，不但是随叫随到，还占了人家的离愁谷作收容所。

玄真君虽然不是计较之人，只要是有益于正道，他是乐于作出牺牲的；

但日子久了，你能说他一点怨气也没有吗？

不要忘记，玄真君可是一直以前辈高人的身份自居的。

这样下来，他会觉得自己被欺负得上头上脸。

所以，他后来的一些冲动行为，就有一些赌气的成分在了。

某位前辈曾说，玄真君的个性不适合于团体协作。

此话有一定道理。

玄真君的个性太强，使他于团体中人不能很好地相处——除非是他自己处于领导的地位。

可以说，他不是一个好士兵——他不但从心里不服从指挥，而且还根据自己想的“更好的方法”去做了。

所以他后来决心再次隐居，长桑鬼陀的巧舌如簧固然起了很大的作用，但最主要的还是玄真君自己的原因。

虽然不适合于团体，但玄真君对朋友是没话说的。

只要是朋友需要帮助，他二话不说就会去做，决不拖泥带水。

他这种干脆的个性，还是非常欣赏的。

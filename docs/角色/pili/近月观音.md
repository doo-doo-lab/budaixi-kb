# 近月觀音 (近月观音)
================================================================================

近月觀音

西煌佛教四禪天之一，鎮守在佛域南隅的水月臺，人稱「慧者」。手拈一枝垂柳，頭頂寶冠，瓔珞披垂，觀音法相，慈眉善目，說話慢條斯理，通曉事理頗多，給人溫柔智慧的慈祥感。

# 近月观音

西煌佛教四禅天之一，镇守在佛域南隅的水月台，人称“慧者”。手拈一枝垂柳，头顶宝冠，璎珞披垂，观音法相，慈眉善目，说话慢条斯理，通晓事理颇多，给人温柔智慧的慈祥感。

## 来自百度百科的补充

西煌佛界四禅天之一，镇守在佛域南隅的水月台，人称「慧者」。外表为亦男亦女的观音如意相，手拈一枝垂柳，头顶宝冠，璎珞披垂，宛如敦煌佛窟里的菩萨，慈眉善目，说话慢条斯理，通晓事理颇多，给人温柔智慧的慈祥感。

实则乃是鬼族久远前所安排在佛域的潜藏卧底，血海观音·渡末莲。终被尊佛所度化，于双圣一战中与释至伽蓝商议，以泣麟藏颖破去其胎藏妙法，使其最终死于八面鬼戎之手，只为完成尊佛留下的埋葬阎罗鬼狱大计铺开大道舍身成仁。

在双圣一战中，近月观音以背后垂柳所藏之西儒秘宝“泣麟藏颖”破除了圣衡者·释至伽蓝的胎藏妙法，使其功体毁去大半。近月观音揭露自己的真实身份为“血海观音·渡末莲”，并表明自己并非“知心慧者”。最终放下过往，内心不再挂碍，表态与释至伽蓝一同诛魔。

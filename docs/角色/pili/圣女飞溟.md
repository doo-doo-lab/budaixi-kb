# 卑弥呼（新世纪布袋戏人物）

================================================================================

新世纪布袋戏虚拟人物。为圣教之圣女，拥有使用法器为人疗伤治病的异能，不苟言笑，外冷内热。时常体察民情，不取任何代价地为人医治。

**中文名**：卑弥呼

**登场作品**：新世纪布袋戏

**身份**：圣教圣女归属

**门派**：圣教

## 角色设定

卑弥呼姓名：卑弥呼性别：女性格：腹黑（这是认真的）、城府极深身份：圣教圣女诗号：愿祈成真，圣主恩泽。初登场：域界之初第9集所有物：疗灵珠门派：圣教根据地：圣教（中域）武学：昊阳镜、疗天仙法、天降圣裁、悲天之悯、圣赎之霖、圣火神诀、圣天玉痕、圣禄玲珑塔

## 人际关系

- **上司**: 古兰真主修多罗、圣教皇、地魂司铎（冒充圣教皇）同僚：归六尘（圣使）、牧灵司铎、猎魔司铎、鬼宿、参宿合作：御尊、玉世论、墨祸妖龙、韦老其它：葬魂皇、纪无双

人物

## 经历
圣教的圣女，尊古兰真主修多罗为圣主。初登场时带领一群信徒传教，并治病救人，曾使双目失明者重见天日，声称这是“圣主恩泽”，且有时效性，只有特定时间才能发挥功效。之后，鬼万象和鸠魔魂功体被废，也因圣女救治而恢复。时炎凰煞凤遭受内伤，找上卑弥呼，卑弥呼指点其寻找人参灵童吃下疗伤。后语与御尊、玉世论以及与纪无双对战过后的墨祸妖龙结盟，共同谋取六云琴，意图利用神器打开穿界大门，迎接来自空域的圣教皇。

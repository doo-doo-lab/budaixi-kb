# 淨琉璃 (净琉璃)
================================================================================

淨琉璃

為佛門先天高修行成就者，有著菩薩的莊嚴法相，般若智慧與慈悲心，遵行佛理、仗義渡眾，不惜犧牲己身以換取一頁書生機，如春風拂人般的親和，讓人不由敬仰。

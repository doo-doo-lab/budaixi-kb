# 骨董 (骨董)
================================================================================

骨董

五儒生中最為神秘者，昔日因遭同門陷害而出走儒教，以生意人「骨董」身份行走江湖，專門鑑賞、收購神兵名器，練有絕頂輕功翦雲步，並暗中追查摯友長風客、狀元姬血案仇家－歐陽勝天。

# 骨董
================================================================================

骨董

五儒生中最为神秘者，昔日因遭同门陷害而出走儒教，以生意人“骨董”身份行走江湖，专门鉴赏、收购神兵名器，练有绝顶轻功翦云步，并暗中追查挚友长风客、状元姬血案仇家－欧阳胜天。

# 百岫嶙峋
================================================================================

百岫嶙峋

出没于萧山之阿的异人，不谙人情世故，亦无是非善恶观念，性格狂纵狠戾，好以人为鸟兽，追猎杀伐，沉迷落刀时的快意，更以鲜血作为凌驾理性之生命本质。与生俱来神异的回阳之能，但唯有泄杀之后，方能救人，被居民视为“山鬼”。意琦行背后之刀痕，即为久远之前败于山鬼所留。

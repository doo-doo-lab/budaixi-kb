# 百岫嶙峋

出没于萧山之阿的异人，不谙人情世故，亦无是非善恶观念，性格狂纵狠戾，好以人为鸟兽，追猎杀伐，沉迷落刀时的快意，更以鲜血作为凌驾理性之生命本质。与生俱来神异的回阳之能，但唯有泄杀之后，方能救人，被居民视为“山鬼”。意琦行背后之刀痕，即为久远之前败于山鬼所留。

## 角色能力

武器：折桂令【「百岫嶙峋」的武器，同时也是山神「沐灵山」的武器，平时沐灵山手持时为拐杖形态，但在化身成山鬼原身后则转为刀身形态，此刀不似一般刀刃，在刀鞘处延伸出两个锋刃，增添猎杀快感。（摘自轰动武林&轰定干戈剧集典藏书折桂令介绍。）】

## 角色经历

先是于萧山之阿开杀，因缘际会陆续成为焱无上、剑子仙迹等人获救的关键。夺走妙胤传心手中天佛原乡的信物，后杀了妙胤传心，才发现是当年拯救自己的少年，让沐灵山再度被唤醒，之后受玉菩提的指引，灵识焚化归元，真正成为了沐灵山。

## 角色配乐

百岫嶙峋(百岫嶙峋角色曲)

曲.编曲：丁天牧 收录于《轰定干戈剧集原声带贰》

丁天牧老师2013年作品，以「鬼狼」为创作主题，慵懒的萨克斯风与轻灵的吉它，营造出飘渺又带些冷冽孤傲的气息，不时穿插着朦胧般的呢喃声，描绘著穿梭于幽夜中的神秘踪影。乐曲选用于「百岫嶙峋」一角，乃出没萧山之阿的异人，实则为沐灵山的另一道人格。狂纵狠戾，沉迷落刀时的快意，在杀戮中找寻快乐，因而被当地居民称为「山鬼」。

山鬼夜行(百岫嶙峋武戏曲)

曲/编曲：孙敬凡 收录于《轰定干戈剧集原声带贰》

孙敬凡老师2013年作品，强而有力的鼓声阵阵敲打，铜管如闷雷窜动，放肆快意的弦乐让空气中飘满血腥，一道鲜红的战栗身影开始于四周飘移，在血染的景致中绘出死亡之美。乐曲初用于轰定干戈第10章，萧山山阿之内，夜风吹动四垂黑帘，百岫嶙峋手握正闪烁血光的折桂令，在血花绽放时，山鬼开启夜行的杀戮游戏。

如梦初醒(百岫嶙峋情景曲)

曲/编曲：丁天牧 收录于《轰定干戈剧集原声带贰》

丁天牧老师2012年作品，创作题名为「诉愁」，筝声徐缓，蔓延而开，与琵琶合奏抒情的曲韵，幽幽婉转的音符中蕴含著一缕淡淡的愁意，后段曲势加强，更添增了几分慨然。乐曲初用于轰定干戈第22章，事事沉埋，如过往尘埃，大雨滂沱中沐灵山想起自己造下的过错，纵然双手洗净，又要如何说服自己这不是一双染满血腥的手？此曲后也用于迷惘中的百岫嶙峋，展现双重人格对自我认同的困顿。

# 百岫嶙峋 (百岫嶙峋)
================================================================================

百岫嶙峋

出沒於蕭山之阿的異人，不諳人情世故，亦無是非善惡觀念，性格狂縱狠戾，好以人為鳥獸，追獵殺伐，沉迷落刀時的快意，更以鮮血作為凌駕理性之生命本質。與生俱來神異的回陽之能，但唯有洩殺之後，方能救人，被居民視為「山鬼」。意琦行背後之刀痕，即為久遠之前敗於山鬼所留。

# 无梦生
================================================================================

无梦生

手持白羽扇，飘逸如风，隐居在非马梦衢的神秘隐士，性格严肃中带有诙谐幽默，身旁随伺与素还真颇有渊源的四能童子，称其为“鱻生”。身怀暂时计，在天踦爵消失后神秘出现，承担其工作协助正道，以睿智手法周旋各方势力。

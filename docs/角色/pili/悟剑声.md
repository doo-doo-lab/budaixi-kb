# 悟剑声

================================================================================

霹雳布袋戏中的角色悟剑声，霹雳布袋戏中的虚拟角色，伴随着雷雨交加而现的神秘少年剑客，身法奇快、剑法殊异，背着一口具有意识之剑，招式夹带紫电云光。其诗号为“天外情风吹云立，红尘飞雨悟剑声”。在失路英雄遭末世圣传追杀时出手相救，并在天玄谷配合啸日猋与失路英雄，联手计擒宿贤卿。为寻魔绝天棺，悟剑声借由任云踪施法，辗转进入未知境域，遭遇壁上活尸围攻。后在毒雾中中毒，并让易春寒将神意刺向自己的胸口。其谜样的身份和武功属性，格外引人联想。泣龙怨内中藏有文诏，是东瀛军的象征。

## 角色经历
天情悟剑声，师承名家、英姿不凡的少年侠客，真实身份为叶家单传血脉-金小侠，独特的出身境遇，让他拥有不平凡的成长背景，虽自幼双亲皆亡，但悟剑声由傲笑红尘、佾云、潇潇、三名义父抚养成人，天资聪颖尽得真传。随著时光流逝，昔日古灵精怪的小顽童，也逐渐成长成能独当一面的少年侠客，与手中拥有自我意识的神兵-神意，一人一剑有着换帖的过命交情，共同行走江湖。悟剑声悟剑声在失路英雄遭末世圣传追杀时出手相救，并于天玄谷配合啸日猋与失路英雄，联手计擒宿贤卿。此后，为寻魔绝天棺，悟剑声借由任云踪施法辗转进入未知境域，遭遇活尸围攻；在毒邪蜂拥内不慎中毒后，让易春寒将神意刺向自己胸口以解毒。角色

## 武器

悟剑声身负之剑神意，是一口通灵神兵，通人语、会讲话。悟剑声称它为同伙的。不仅如此，它还有治愈伤病的功能。据悟剑声所说，他的失聪就是其治好的。在毒邪蜂拥，悟剑声不慎中了毒雾，便是将神意插入胸口，借助其圣气疗伤。之后也利用此法医治易春寒。此外，神意很怕鬼。经过刀悬一命二次锻造成为“神无之声”。悟剑声称是要神意少啰嗦，无声。现今，神意已经过刀悬一命的第三次锻造，二次升级。外观气势无比。悟剑声·金小侠神意本是刀悬一命与北海隐洞意外拾得的魂铁所铸，而魂铁本身则是靖沧浪的好友、古武族族长冷孤寒，冷孤寒是被端木燹龙以《焚如要术》之“彤烬炽火印”炼魂成铁。已经被克灾孽主以竞豹儿之力炼化成斥方镭

## 角色配乐

- **天情悟剑声曲/编曲：黄名伟** — 《霹雳英雄音乐精选30》

以民族风的鼓打拍子，为乐曲带起了跃动的韵律感，中西乐交错演奏充满侠情豪气的旋律曲调，相砌出具舞动节奏感的侠风武打曲。

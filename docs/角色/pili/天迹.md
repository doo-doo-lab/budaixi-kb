# 天迹（霹雳布袋戏虚拟人物）

================================================================================

天迹，霹雳布袋戏虚拟人物。

天地人三乘之一，傲立仙道之巅，实力深不可测的顶先天。

性格风趣巧慧，关键时刻慎谋能断，但大部分时候，作风潇洒随意，不按牌理出牌，常有让人跌破眼镜的表现。

虽隐于仙脚之巅，但仍关心武林事，先遣秦假仙驾风乘云驹入江湖，在天堂之门开启后，天迹也正式入世，与地冥相互制衡。

后为解开太曦神照之阴谋，天迹预先留下后手，让意琦行找寻人三脉同时，自己则在与太曦神照一战后，孤身流落阴阳裂界，冒险犯难，除了解破太曦神照之企图，更极力避免苦境再受侵略。

玉门世家中，过往与玉逍遥并称“逍遥忘机”的道轩眉，以及当今玉门世家主玉书衡，如何协助神毓逍遥平息狼烟？

昔日天、地、人共修之太穹灵元，又将牵引出何等天机之谜？

顺利觉醒为凤鸣玉鹖皇，与其他逆神七皇大战魔暗。

天迹天越中察觉到代表光明的太曦神照乃是异界魔神，遂在重建仙脚后单独找到意琦行，告知自己欲将云海仙门化明为暗的计划，但因为需要牵制太曦神照而改为请意琦行帮忙寻找人三脉的转世者。

为阻宇外群雄侵略苦境，天迹救下悉毘幽、发功摧毁那迦喉珠后，传出星芒讯息给意琦行，将自己与前来围杀他的裂界大军一同冰封。

苦境神州裂变，传回的六蚀汇能解除了裂界冰封，六蚀巨能却被天迹遣人埋下的三光之镜倍数回返苦境，倍返的能量击碎了寰界，一半被太曦吸收、一半被魔熵吸收，极天关喉珠复原失败，宇外连接苦境的通道未能开启。

天迹被穿越境界而来的人三脉之力所救，数月后通过魔邃深渊回返苦境，擒住邱霍蛉叶，套取了太曦势力盘踞下的苦境当前战况。

之后天迹前往南修真分部，用计骗退前来攻打分部的灭罗血后大军。

灭罗血后将生命练习生首级送予甫回归仙脚的天迹，天迹重伤血后并废去其功体，之后回归玉门世家。

太曦神照前来世家，天迹与太曦当即展开恶战。

天迹、太曦缠斗之时，突生的异象中断了两人战局。

后经查探，原是过去三先贤所封印的太穹魔神再度现世。

天迹与道轩眉合力将魔神暂时封入天堂之门，之后便趁机着手寻找解决魔神之祸的方法，期间天迹与太曦暂时休战。

最终，天迹、地冥、道轩眉以牺牲各自魄元为代价，合力将太穹魔神再度封印。

魔神之祸方歇，往世阎摩携裂族穿越空间来到苦境，领兵围杀大战完功体未复的天迹与道轩眉，太曦在一旁观战。

双方战斗正酣，莫名现世的三足金乌斐斐召出火轮扰乱战局，众人皆被打散。

天迹被悉毘幽所救，得知往世阎摩在其昏迷期间率兵侵略苦境。

赶到一衣带水后，天迹得知玉门世家被往世阎摩攻破、世家主与道轩眉之徒皆被擒作人质，为救人天迹寻求儒门之助。

天迹借伐楼那的关系前往裂族王都，与往世阎摩谈判，裂族之王八龙天苏醒并拿回裂族大权，太曦、裂族、天迹三方势力短暂达成和平，八龙天承诺谁能复燃圣火便与谁结盟。

天迹趁裂族圣火宴期间重新夺回被占据的玉门世家，毁去太曦势力藏在玉门禁地里的桑源灯。

太曦设局诬陷天迹，在一系列阴谋以及斐斐的影响下，天迹精神受创，后为保住陷于太曦手下的人质性命以及灯阵内百姓之命，天迹自愿担下一切罪责于公开庭自尽。

被救的天迹开始探查桑源灯核心之秘，发觉核心中藏有玉门失传术法，利用土龙沟通世家众人，得知新月陀罗与太曦联手毁灭世家的真相，之后更查出台面上太曦神照的真实身份为瀛女医，即玉冰莹。

天迹前去阻止七眼神母灭世，在与杀体太曦一战后，地冥加入战局，天地一同对上了重入战场的太曦神照，最终当场揭穿了面前太曦的真实身份与先前的阴谋。

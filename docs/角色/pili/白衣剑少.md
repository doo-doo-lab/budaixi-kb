# 白衣剑少

霹雳布袋戏虚拟人物。魔界传说剑者风之痕的徒弟，容貌美丽，发如白雪，个性冷静稳重、重情重义，特异的体质不畏一般剧毒。被魔剑道之主诛天所收养，成为魔剑道少主，有着复杂的身世，另一身份为西疆皇朝太子。师承风之痕剑法，其剑法出神入化，于风中快意的冷静，置身在剑速之极意当中，已达自我巅峰。初以魔剑道少子之身份征伐四方，率魔剑道诸将与天策王朝为敌，诛天身死后，决定退出魔剑道，与师尊一起退隐。多次挺身协助正道，对抗魔魇大军、策谋略、万恶鬼楼、九轮天、逆三教、幽界之乱。本与师尊、义弟退隐多时，却因故在异域镜界再现踪迹。

## 人物设定

名称：白衣剑少性别：男身份：西疆皇朝嫡系遗孤、魔剑道少主、魔吞不动城荒狼宫、朱雀宫宫主白衣剑少化身1：魔剑狼（魔吞不动城“新·荒狼宫”代表）化身2：炽风翼（魔吞不动城“朱雀宫”代表，原代表为风之痕，白衣剑少借风之痕魂魄重生后继承风之痕剑意及承接的异谱）诗号：剑上异端，洗越半生秋！

### 武器

- **异端剑**：刃质轻巧、运转灵活，近身使用能长能短，以攻为守，巧妙非常。白色握柄则维持白衣剑少一贯特色。（被鬼刃夕痕所断）
- **祭魔剑**：一口狭长之剑，剑身变化繁复，上段镂空，中段窄缩，尖端为兰锋，剑脊处雕有云染纹饰，整体造型融入西洋兵器设计概念。
- **叱风剑**：由铁十三铸造。延续一剑双分的特色而有所突破，叱风剑拆分时非与绝代之狂一样，变成各保留一半剑锋的形态，而是两个独立的剑身，剑柄部分也是采取双柄的设计，一蓝一红，正代表了风的冷静与魔的狂野，由风之痕交由白衣剑少继承。风之痕复活后回归风之痕之手，在风之痕和夔禺疆的最终对决中被夔禺疆融合圣母九婴之力击碎，但风之痕仍用断剑将夔禺疆重创到无法动弹。
- **绝代之狂**：名剑铸手·金子陵所铸的四大狂剑之一，金子陵专为风之痕量身订做并将其赠予风之痕。以古铜玫瑰金的色调和材质，并以翠绿珠玉为点缀，且同样维持一剑双分之特性，剑脊倏分倏合设计上也跳脱传统的左右对称模式，朱红剑柄两侧各有些微差异。在风之痕复生并再度被夔禺疆控制、夺走叱风剑后，此剑由白衣剑少暂时持有，用以对战风之痕并唤回其剑者本心。在风之痕恢复后再回归风之痕手里。

## 经历

（霹雳官方典藏集）白衣剑少 官方桌布白衣剑少（生平纪要 《霹雳图腾》——《霹雳九皇座》）

【身世】：西疆王一日于打猎时为流寇所困，得鹫族月灵公主所救，两人订下婚约，但西疆王迎娶月灵公主之时，王后与其兄长暗中下毒毒死全鹫族之人，月灵公主侥幸中毒不死，日后产下一子即为白衣剑少，而月灵公主满怀伤悲，仇恨，为免其子受苦，将其置于某户人家门前，后辗转为魔剑道诛天收养，成为魔剑道的皇少主。由于月灵公主身怀剧毒产子，使日后白衣剑少拥有不畏任何剧毒的奇特体质。

霹雳图腾时期白衣剑少，剑法师承魔流剑·风之痕的剑法，甫出场即杀死西疆皇朝国师善藏，又同异端神独闯魔界，与魔魁对决，以快绝的身法，剑招，让魔界战神含恨，震惊全武林，在执行两大任务后，得诛天赞赏，与随从剑理于江湖四处游憩，途中路见不平解救毒蝎女·月灵公主所扮，杀四禁道杀手，又前往凤形山观看风之痕与忆秋年的剑痕，并与洛子商订下战约，隔日于绝尘崖小胜洛子商一招。为救不二刀，与皇弟联手对抗天策真龙，在成功解救不二刀之后抽身而去，又受命狙杀天策真龙，于天策真龙吸化星星灵失败时，再以快绝身法连击天策真龙三剑，为天策所挡，但不屑虫人鬼僧卑劣手法，愤而离去。

龙图霸业时期白衣剑少接下进军中原的帅印，准备率领魔剑道魔魇大军进军中原，但被天策真龙军师屈世途计策所惑，与皇弟黑衣剑少回返魔剑道，途中黑衣剑少离队刺杀天策真龙，为救弟弟黑衣，白衣剑少也急忙随后援救，并帮助黑衣剑少杀出重围，但白衣剑少却遭天策真龙重创，就在昏迷之际被鹫默心所救，在伤势痊愈后回到魔剑道，虽因私自行动而遭受处分，但白衣剑少仍但心黑衣剑少，遂将右护法所送之药材转送黑衣剑少，却反激起黑衣剑少不悦及不甘。得知黑衣再度前往腾龙殿后，白衣再度赶往腾龙殿救援，兄弟两人一同杀出重围，浴血苦战，白衣剑少更以身上之血解除黑衣剑少身上毒患，就在两人杀向中西边界时，被天策真龙及群英围攻，在右护法及时赶来援助，及夜叉鬼，剑理牺牲下，白衣剑少选择断后帮助黑衣剑少离开，就在白衣准备自尽时，被天策真龙所阻而遭到生擒，囚禁在腾龙殿地牢之中。在九九登天台大战中被妖刀界所营救，回归魔剑道后，拔起祭魔剑成为魔剑道主帅，率领大军征讨天策真龙大军的埋伏，三阴巫姥身亡，魔魇大军消失殆尽，白衣剑少与护法解玉龙、白秋水杀出重围，白衣剑少带罪立功，策划星绝峡谷之计大败天策真龙，但因化星星灵回归而功亏一篑，更为救诛天而遭六星天策重创，危急间被风之痕所救，并以琼华玉露将其治愈。回到魔剑道的白衣剑少陪同诛天出度琼华宴，在宴会后随风之痕再行修练剑术，岂料诛天与天策真龙签订和平约半年，后诛天意外传出身亡消息，自己协同剑辰前往寒月江追查凶手独孤遗恨的下落，虽从孤迹苍狼口中得知鹫默心与自己的关系，但仍决心为诛天复仇，后与皇弟联手试探独孤遗恨。在独孤遗恨身亡后，白衣认为仇已毕便选择独自离去悟练剑招，更得风之痕传授魔流剑法，后听从师尊的教诲，为报姬无花救命之恩而前往天坛保护花姬，适逢欲界第六天之魔僧对花姬出手，白衣剑少虽出手杀死众多魔僧，但花姬仍被擒，白衣剑少只得遵照条件指示，寻找沙舟一字师，问出进入浴佛池的方法要解救花姬，但因未达境界而无法开启玉佛池。白衣剑少白衣剑少请风之痕出面向欲界讨人，同时受命前往保护遭到欲界逼杀的黑衣剑少，也同时得知诛天乃妖后所杀，白衣剑少鼓励黑衣剑少振作，两人一同回孤独峰，恰逢妖后与天忌、凯围攻风之痕，白衣剑少对上凯，但双方交战，风之痕剑法似被研究过而遭到凯破解，白衣陷入不利战况，但由于妖后的弃战，使得凯与天忌两人也退去。为了找寻医治风之痕双手伤势的琼华玉露，白衣剑少到天坛求见花姬，但花姬被策谋略透过秦假仙的移花术所伤，至使无法制造琼华玉露，白衣只得回到孤独峰将花姬受伤之事告诉风之痕，两人一同前往天坛保护花姬。并再度对上凯与天忌，最后两人终拖住时间，让沙舟一字师顺利消灭魔魇大军。白衣剑少得到幽灵马车指点前往西漠取得奇黎草要医治风之痕双手。但白衣也同时遭到奇黎草的感染而遭病害，全身剧痛不已，在回程途中，更遭到异端神追杀，白衣忍受全身痛苦血战回到孤独峰，请村人转交奇黎草给风之痕，治愈风之痕双手之伤，但自知无救的白衣默默前往西漠等死，中途逢遇雅瑟风流，但不愿因为忘却亲人记忆的白衣拒绝了雅瑟风流的医治，只让雅瑟风流将自己送到苗疆，最后在苗疆等待死亡的来临。

霹雳封灵岛时期大悲忏慧在白衣剑少临危之时出现，并将白衣剑少身上的疼痛吸收殆尽。白衣于洞穴疗养时，被异兽血变所救，后结识养父诛天的师父横千秋，更被横千秋要求练其霸王枪法，白衣剑少婉拒后借口要偿还他人人情而离开，并探得黑衣剑少消息前往离首峰悬崖下救黑衣剑少，并以其血帮助黑衣剑少恢复面容。白衣剑少白衣与黑衣兄弟两人离开山谷后一同围杀披魂纱，却被披魂纱引至欲界，在大军围攻下不敌而被擒抓，因黑衣剑少拥有阴阳师之力，披魂纱为救黑衣向欲界求情而遵照黑衣意愿放出白衣剑少，白衣前往会见黑衣，但黑衣不愿离开，只请白衣将阴阳师的骨骸交给风之痕研究。而后风之痕将阴阳师的骨骸交出，治愈黑衣剑少的病症后，白衣剑少亦离开风之痕继续出外锻炼剑法。

霹雳兵燹时期白衣剑少经过一段时间的锻炼后，再度回到风之痕身旁，但受到宕月刀控制的黑衣剑少竟向风之痕逼杀而来，在风之痕砍断黑衣剑少一臂后，白衣剑少担心不已，得知妖后进入鬼楼后，白衣想与黑衣一同前去营救妖后，但被黑衣引开，而黑衣剑少已独自一人进入万恶鬼楼之中，白衣剑少唯有与风之痕寻找刑天师协助，但鬼楼有百日一循环的情况，白衣也只能静等时间来到。得到风之痕首肯，白衣剑少进入武林调查南宫笑告知的黑衣剑少有关鬼楼之事的意图。得知南宫笑为冥界天岳之人，与风之痕前往寂山静庐，风之痕出手为金子陵挡下湛江云的刺杀，还金子陵赠剑之情，后在素还真之处，得知黑衣剑少与妖后在鬼楼之中平安无事。在鬼楼之期即将满百天时，得知刑天师身亡，白衣剑少与风之痕找寻天忌协助，就在风之痕进入鬼楼内部探视黑衣剑少与妖后时，风之痕先前的仇人刀鬼猛然来袭，白衣剑少被刀鬼的意外袭击所伤，在得知黑衣剑少与妖后两人平安后，白衣剑少听从风之痕的建议，深山退隐而去。

霹雳九皇座时期白衣剑少解救被叶口月人重伤的黑衣剑少，并一同找寻让妖后石像恢复的方法，在妖后被殷玳叫声解除石化后，白衣剑少与黑衣剑少一同护守在妖后身旁，而后又与黑衣剑少一同对战易伯书与雪飘染，在覆天殇身亡后，后来黑衣剑少与妖后被围杀被迫跳下山崖生死未卜失踪，白衣剑少与风之痕深山退隐，并一同四处寻找黑衣剑少的下落。

九轮异谱-仙魔鏖锋时期白衣剑少清荷纪年，白衣剑少受不动城之邀，承接圣兽异谱，成为新一任的剑狼，即魔剑狼。期间为正道屡立功勋，击败九轮天的鬼天棠、狂墨三十六等人，又击杀黑白使徒、忌迁、风不测、雪无恨等外界侵略者。后与洛子商前往一际云川营救佛门众人，路上遇到鬼刃夕痕的莫名挑衅，白衣剑术造诣虽已臻自我巅峰，但由于根基之差两人联手仍不敌独鬼流剑法，白衣也战死于独孤客之手。后来白衣的师尊风之痕在叹希奇的布局之下与幽都进行交易，以自己的半魂注入白衣体内，从而复生白衣。复生后的白衣剑少继承风之痕的力量，剑意与叱风剑，而魔流剑却被幽都的夺胎消刑棺改造成为无感情牵绊的杀人工具。经历数次磨难魔流剑终于被唤醒，但师徒三人却遭到幽界众人的暗算，夔禺疆以白衣性命为威胁，迫使风之痕独挑魔吞四宫之主，魔流剑为了白衣甘愿死于金狮之手，白衣看到师尊尸体悲痛欲绝，天魔茧将白衣关在动荡心神之地，又用虚假的魔流剑之死来迷惑白衣剑少，让白衣对不动城战友发生了嫌隙，在麒麟星和幽界九婴的帮助下，白衣得知了真相，向战友们致歉后继续为武林和平奔波，期间白衣剑少暗地保护解锋镝安危，两度牵制武都霸主玉梁皇，两度营救夸幻之父，更积极奔走于一页书与风之痕的复活大计。纵横子欲入防幽界，从内部瓦解幽界危机，风之痕因无限之死怒战幽界，先是以叱风剑断刃击败夔禺疆，后击杀蛾魔蝗与刀剑双魂等幽界群魔，正当风之痕要突破幽界之时被棋邪所率领的魔夜听剑与九千秋重伤，实则棋邪等人早已通知蝴蝶君与黑白双少前来救援，故意留手让风之痕被不动城之人救走。后黑白双少请来翠萝寒、天不孤、绯羽怨姬来医治师尊，风之痕得以恢复如初，现师徒三人皆已安全退隐江湖。

破邪传时期，九婴欲请风之痕解开红炉点雪之招，风之痕得知九婴作恶多端不肯替其解招，九婴欲擒白衣剑少威胁风之痕，殊不知白衣剑少境界大越从前，一招风过无痕将其击退，后九婴败退离去，师徒三人继续退隐江湖。

霹雳兵涛时期白衣剑少本与师尊风之痕、义弟黑衣剑少退隐多时，却因故在异域镜界再现踪迹。原来白衣身患离魂异症，魂元流落于外，将有性命之危，原无乡翻遍不动城中的典籍，推测白衣的魂魄应是进入了镜界，众人又从不动城内找到元河天藏，风之痕师徒凭此物得以进入镜界。因缘际会之下，风之痕找上境界翘楚潇湘水云，潇湘水云二话不说，义不容辞选择帮忙，但要白衣彻底恢复，则需要境界能兽身上的血角灵芝。偃武楼众人为帮白衣脱离危险，决定进入狼嚎肉城寻找能兽，怎料肉城能兽威力无匹，众人难撄其锋，就在性命垂危之刻，风之痕再度降临，瞬间救下偃武楼群英，再一剑斩杀肉城能兽，成功带回血角灵芝。

## 人物评价

泰若自如，气宇轩昂！白衣剑少个性冷静稳重，重情重义。被魔皇诛天所收养成为魔剑道少主，有着复杂的身世，另一身份为西疆皇朝太子。师承魔流剑风之痕，其风之痕剑法出神入化。体质特异、不畏一般剧毒。生母月灵公主遭逢巨变之后，一度狠心想扼杀孩子的生命，但终究是自己的骨肉，希望此子能够远离江湖，平安和乐一生，但白衣剑少却被诛天所收养，踏入了魔剑道，踏入另一个人生。诛天的提携、师父风之痕的教诲，使他更加出类拔萃；有位身为太子的手足黑衣剑少，虽有对立之时，但兄弟两感情深厚。魔剑道成为他的家，是他的一切；埋没在滚滚黄沙中，西疆皇朝，是故土，但却茫然不知。当天策真龙大军与魔剑道交战之时，白衣剑少并不知对方将领毒蝎女鹫默心其实就是自己的亲生母亲，将其杀掉。后与师尊风之痕退隐在竹林小屋。后来妖后与黑衣剑少坠崖生死未卜，风之痕带着白衣四处寻找黑衣剑少下落，师徒二人暂隐。天罪时期，风之痕为抗击弃天帝而短暂复出，白衣剑少也随师尊奔走。问鼎天下结尾，当黑衣剑少遭到海蟾尊逼杀之时，风之痕携白衣救走黑衣，并一同退隐江湖。

## 编剧创作心得

编剧罗陵（摘自编剧blog）：魔剑道少子‧白衣剑少：白衣剑少算是我写少年天才的开始，当初受命写他时，出场就是要铲除魔界最强高手，其实我知道写了这个一定会被骂，所以那时思考，以这样的少年，到底要如何才能赢魔魁？内力、掌功，完全是不可能的，白衣会只有惨死的份，所以当时讲求速度，白衣唯有以最快的方式，且唯有那招三式连环才有赌胜的机会，这里，也是日后带出风之痕的剑法超快之原因。而白衣剑少，原来剧本上我写是异端之子。所谓异端，即是特立在一个区域，却非出身于此，格格不入又无法或缺的异端，他就是个矛头，所以白衣的个性沉默认真，不多求也不争夺，就因为“异端”，所以他是少子，而非太子。即因他非诛天之子，但因感念诛天的养育提拔，所以忠诚于魔剑道，从无二心。白衣剑少也因身着白衣以其对自己的要求严苛，特别帮他加诸一个特色，洁癖。白衣性好洁，曾经在一集剑理陪同出门执行任务时，白衣在河边梳发净身的场次，强调他的洁癖，也隐喻他不容许自己失败，以及洁身自爱的个性。而白衣为出生就被弃街头的孤儿，诛天意外捡回白衣，并让好友风之痕授他武学，让左护法教其知识礼仪，所以白衣对风之痕与诛天是当做生父来看待，记得好像是龙图3X集了，有一幕写到风之痕与白衣分别的戏，在讲述人生，那一幕白衣看着风之痕，明明是咫尺近，却已是天涯海角，很喜欢那一段。白衣剑少PS：我最自责的一件事，就是没将打魔魁那场说清楚，可是，有时碍于惯例，以及考虑到气氛，所以新角登场，有时实无法写如此详细……（泣）魔魁大人蒙受秒杀冤屈，是我那时还拿捏不好T_T。第二后悔的是，当初白衣断后，让左护法带他走时，我有写到白衣举刀自刎的画面，我应该让他砍下去喷血的XD　这样效果更好XD（误）

# 战玺主

霹雳布袋戏虚拟人物战玺主，霹雳布袋戏虚拟人物。战玺境界的最高领导，身为九轮天最神秘的一族，拥有无上的优越感，却又不轻易涉世，在九轮天一统时，成为了仅存的核心五国之一。战玺主下御四玺，分别为生、死、灵、幻，一方面协助天议共同为九轮天征战苦境，可战玺主内心所想，却又是另一自我野心。战玺主曾与忆离笙交手，因认识到实力差距巨大而被迫认输。其在与魔息大帝的对战中，被一招抓住两招秒杀，因此得了“战且慢”的外号。战玺主最终被魔息大帝快速击败。其在与忆离笙的冲突中亦因实力不济而认输。

## 经历

战玺主在征战苦境过程中，曾遭遇魔息大帝，被其一招擒住并两招击败，因此得名“战且慢”。后在与神秘高手忆离笙的对峙中，战玺主虽全力出手，但因实力差距悬殊，其攻击被轻易化解，自身亦被冰封。在认识到巨大差距后，为求生存，战玺主最终被迫屈服认输。

## 人物影响

在与忆离笙对峙时，忆离笙平淡的看向了神情有些不自然的战玺主，其直白到不把战玺主放在眼里的回答让战玺主感到被轻视。

统御战玺境界、自诩高贵的战玺主无法忍受有人这么对他说话，于是突然发难，手中印玺迎风而涨当头砸下，同时整个人快速扑向忆离笙。

然而实力的巨大差距让战玺主有苦难言，其覆盖真元的肉掌与忆离笙的冰锥相撞，刺骨寒意瞬间侵入身体并在体表形成冰霜，纵使战玺主使出全身解数也不能阻挡分毫，身体被一节节冻结。

感受到性命威胁，战玺主顾不上高贵和神秘，直接爆发全部实力，汹涌澎湃的真元将体内寒气与体表寒冰震碎。

狼狈挣脱冰封后，认识到两者之间的巨大差距，生存与骨子里的高傲在战玺主内心剧烈斗争，使其眉头紧皱、神色扭曲不定，最后保存生命的思想占据了上风，战玺主认命地表示了妥协。

此外，战玺主也曾被魔息大帝击败。

# 银鍠朱武

================================================================================

霹雳布袋戏虚拟人物银鍠朱武，霹雳布袋戏虚拟人物。异度魔界传说中的战神，英武骁勇，曾以赦天逆乾坤保住鬼族之地，但却也随断层坠落而长眠，后为九祸以残余的魔源唤醒。复活后的朱武因厌倦争斗而自愿放弃王者身份，化身朱闻苍日游历中原，结交空谷残声，但终究别无选择地在伏婴师的策划与九祸的牺牲之下，重掌魔界大权，担下征战中原之重任。更为让爱妻九祸复活，不惜开启万血邪录，牵扯出神州支柱之秘，引发一波中原浩劫。名言：一个叛徒，有可能改变战况；一个强者，却能彻底扭转整个战局。

## 角色背景

角色缘起月刊第149期 第28页月刊第149期 第29页月刊第149期 第30页月刊第149期 第31页封面苍云山铡龑斩龙气，魔界培养魔龙龙气的计划失败，只获得了少部分的龙气。

为了弥补魔界的战力不足，所以女后九祸接受补剑缺的提议，将残余不足的龙气灌注给异度战神·银鍠朱武，并带出鬼族人马，接掌大权领导魔界再战中原。

要说银鍠朱武的设定，就得先承认一件事，其实在刀戟戡魔录第一部，即异度魔界篇章刚开始的时候，原本的设定之中并没有鬼族这一策划，只有魔邪二族，但出于编剧组对于异度魔界这一组织的长期发展战略，剧情必须延伸，便在刀戟戡魔录第二部当中，便出现了螣邪郎等鬼族人马，包括螣邪郎是赦生童子的哥哥、袭灭天来在异度魔界里这些设定。

在此处又将人际关系图再延伸，异度魔界的第三族---鬼族便被设计出来。

之后又设计出银鍠黥武这个角色，除了要来牵引吞佛童子对袭灭天来的反叛外，同时也是要用来牵引出银鍠朱武这个角色。

同为君主，银鍠朱武和阎魔旱魃两者的差异，就在行为处事这一点。

当时设计银鍠朱武时，编剧就经历过冥思苦想，因为银鍠朱武毕竟是反派魔王，而一般魔王的设定便是狂霸凶恶的单挑魔人，就像阎魔旱魃一样。

那这银鍠朱武要怎么写，若是如阎魔旱魃一样就可能带来角色重复的麻烦。

所以，编剧最后决定反其道而行之，设计出一个曾经只为了魔界、甘愿披肝沥胆、抛头颅洒热血，如今却只是一心想追求自由、安享简单平凡的家庭幸福的鬼族战神·银鍠朱武这个异端。

同时为了圆融螣邪郎、赦生童子这两个人的兄弟血缘，整个问题也走入了一套“八点档”。

姓名由来银鍠朱武  官方壁纸鍠，即是“王钟”、“战鼓”的意思，是王者召集军人的象征性兵器。

而朱武这个名字，则是参考了明朝开国皇帝朱元璋的年号“朱洪武”，加之魔界战神都是以鲜红色为主，由此银鍠朱武之名便由此设计出来。

## 角色经历
沉眠过往银鍠朱武写真银鍠朱武，被称为异度魔界最完美的战神，鬼族之主，英武霸气、雄才武略、骁勇善战。

为魔界奉献自我、为鬼族赢得荣誉。

征战、杀戮太久的银鍠朱武，有一日却突然开始自我反思，细想自己想要的到底是什么。

银鍠朱武和邪族女王九祸相爱，本想带着九祸离开魔界浪迹天涯，追求简单的家庭生活。

但是因为九祸对魔界的强烈责任心，两人的价值观冲突，银鍠朱武赌气出走，九祸更是将自己跟朱武的生的孩子（螣邪郎）与同时出生的朱武的弟弟银鍠玄影的儿子（银鍠黥武）调换。

银鍠朱武将黥武视如己出，将其抚养长大。

而后，在异度魔界降临道境的战斗中，银鍠朱武得银鍠玄影之信回归魔界，带领众魔兵征战玄宗，其强悍的战斗力，就连玄宗宗主也惨亏其手。

可在关键时刻却突生变数，异度魔龙意外被天雷巨力击断，鬼族不但被打入断层之下，余者几尽被天灾异变消灭，就在毁灭之刻，银鍠朱武以术法“赦天逆乾坤”保住被击断的鬼族禁地，但也因为消耗太大使得自身陷入漫长的沉睡之中。

苏醒过后银鍠朱武 朱闻苍日异度魔龙象征着异度魔界源源不绝的战力来源，魔龙被杀撼动了整个魔界的根基。

在苍云山借苍龙之气培养魔龙能源的计划被素还真和寂寞侯的铡龑行动破坏后，九祸将一切的希望转移到复活异度魔界最强的战神银鍠朱武上。

遂九祸、补剑缺等人，以残余的魔龙之气灌注银鍠朱武，唤醒昔日的最强战神。

但复活后的银鍠朱武却是无意回归王位，反而化身为朱闻苍日，与武痴传人箫中剑成为好友，两人结伴游历中原。

面对朱闻苍日的迟迟不归，认为“皇者不需要多余的情感”的伏婴师接连布局，要让他回归魔界。

萧中剑在为唤醒加入魔界的三弟月漩涡的过程中而身染魔毒，即将魔化。

为解救好友，朱闻苍日退无可退，自伏婴师手中取得解开咒术的方法，决定重拾银鍠朱武的身份，以朱皇之血换取空谷残声回复意识。

最后一战，朱皇绝学再对武痴之招，朱闻苍日以自身王血破除箫中剑的魔化，但自身也瓦解咒术而恢复成银鍠朱武。

这也象征重拾难以跨越的立场隔阂，这段魔与人之间的友谊终究抱憾收场。

银鍠朱武也回归异度，重掌魔界大权，担下征战中原之重任。

征战神州银鍠朱武 征战银鍠朱武回归并君临魔界后，与九祸再续前缘，并且九祸也再度怀孕。

但因伏婴师和九祸的共同布局下，九祸以自身与双子的魂魄再造并怀上新的圣魔元胎之时又遭遇设计好的朱闻挽月的咒杀，最终难产身亡，被朱武放入天魔池之内。

银鍠朱武为救至爱，在天魔池与弃天帝洽谈好条件，全力开启万血邪录，让弃天帝降临以营救九祸。

一方面，银鍠朱武命伏婴师设下魔火之局，派出魔化的叶小钗，寻找无罪之人，终于开启万血邪录。

另一方面面对恢复正常并意欲唤回好友朱闻苍日的的箫中剑，银鍠朱武与之在天邈峰一战了断。

终究是立场的无奈，但真心无悔。

最终箫中剑牺牲自我以期弥补遗憾，银鍠朱武虽胜犹悔，却也下定了决心。

为经过多次试探后，银鍠朱武确定了吞佛童子的细作身份，为清理门户也是为死去的银鍠黥武安魂，银鍠朱武和吞佛童子两位魔界战神展开决战。

银鍠朱武以自身强大的实力击败吞佛童子，并在其体内留在夺命杀招后放他离开，也为自己对弃天帝的提防留下一个后招。

在这之后的征战中，银鍠朱武为夺得剩余的记载有神州支柱位置的天书以及破坏神柱，与正道发生多次血战。

在狭道天关外为抢夺第三柱神柱的关键而围杀素还真，使得素还真重创奔逃、问天谴英勇就义；

为夺天书，两度与赭杉军激烈对战；

为破坏神州支柱，两次来到极封灵地，先后与柳生剑影、圣兽肥遗交战。

在斩断神州第一支柱后，银鍠朱武在惊叹东武林陆沉的同时，在内心对弃天帝也更加提防。

适逢识界对人界也虎视眈眈，看破弃天帝阴谋的银鍠朱武利用这个机会，在江南雨地与识界大军交战时诈败于识界之主玄貘之手，兵败退回魔界并自爆火焰魔城，随后下落不明。

化身黑羽银鍠朱武 恨长风台面上，银鍠朱武在江南雨地兵败后转入台下。

暗地里，银鍠朱武一边闭关养伤本体，一边化身为黑羽·恨长风帮助中原正道，同时也为了复活九祸而奔走。

在赭杉军被道境内的魔阵所困时将其救下，更与补剑缺、赭杉军、不二做等人进入魔界取走九祸遗体，银鍠朱武本体就是否以素还真尸体换回九祸遗体与弃天帝发生争执，与苍之意识一起被弃天帝关在万年牢中。

恨长风为复活九祸来回奔走，舍命取得无人能得的天穹三鸣。

因雷公胆为复活九祸和医治苍的重要材料，恨长风汇聚朱武之能决战赭杉军，虽获得胜利却也导致元身被弃天帝控制。

回到黑狗养生堂欲救回九祸时，被绯羽怨姬一语道破九祸已死药石罔效的真相。

至恸无泪，哀痛之余恨长风也将雷公胆交予赭杉军，用来救治苍。

逆天自由银鍠朱武在魔界阴谋下，疯狂的曌云裳以岁月轮击断藏青云地神柱，弃天帝挟毁灭之威降临人间，恨长风欲赶往阻止却已经是来迟。

在北越天海和补剑缺联手对战弃天帝保护神柱，却因绝对的实力差而败下阵来，补剑缺也因此阵亡。

弦首苍为能消灭弃天帝，聚集叶小钗等人组成玄罡剑气阵，恨长风相助苍对阵法进行布置。

在剑阵被弃天帝挫败后，因一页书挡下弃天帝的攻击而获救。

为找出圣魔元胎的弱点，恨长风趁伏婴师、弃天帝都不在魔界时，在苍帮助下取出戒神宝典副册，也找回元身恢复为银鍠朱武。

银鍠朱武  音乐精选在磐隐神宫内与弃天帝的最终战中，银鍠朱武和苍联手缠战拖住弃天帝，银鍠朱武在强制融合破坏三魂两体增进功力仍是不敌神威的情况下而被弃天帝所吸收，使得弃天帝恢复完整的圣魔元胎。

但一切都是布局，银鍠朱武在苍的帮助下顺利从被天极圣光净化的弃天帝身体中脱出，使得弃天帝失神一瞬，便被三先天破除肉身，将其灵识返回六天之境。

但因弃天帝在临行前重击磐隐神宫最后一根神柱，欲借银鍠朱武的身体再次降临人间。

身为最后一个圣魔元胎的银鍠朱武，最终，为阻弃天帝再临，自愿死于苍的手中。

最后的圣魔元胎死去，弃天帝再也无法降临人间。

事后，苍将其葬在天邈峰，与九祸、箫中剑比邻，这位一生受立场困缚、不得自由的无奈的魔，终于如愿的走向了自己选择的路。

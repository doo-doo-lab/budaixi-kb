# 一灯禅

来自龠胜明峦的佛修者，手持枯禅轮杵，曾为云鼓雷峰的最高尊者，性好和平，随和但喜多管闲事，与分属儒道二教的靖沧浪、悬壶子为至交，常拖着好友一起下水淌武林事，在云鼓雷峰与登道岸冲突爆发时，出面化解干戈。

## 角色经历

与悬壶子、靖沧浪互动频繁，在佛道两教冲突时出面化解，并多次与二人共同出手协助他人。因"拖人下水"的性格，经常被悬壶子吐槽。

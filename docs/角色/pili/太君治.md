# 太君治

《霹雳布袋戏》剧中人物太君治是《霹雳布袋戏》系列中的虚拟角色，出自《霹雳震寰宇之刀龙传说》《霹雳震寰宇之龙战八荒》《霹雳震寰宇之兵甲龙痕》三部作品，配音由黄文择担任。

其身份为集境三仪三司十二殿中的天机院主，精通阴阳五行数术，统辖擎羊、陀罗、武曲、文华四殿，负责集境内部治安警戒，根据地设于天机院。

太君治性格刚毅公正且精于权谋，曾主导对抗妖世浮屠及阴端佛鬼的战役，先后联合香独秀、鸦魂等人破除佛鬼结界。

因破军府干涉被迫求援残宗势力，最终参与苦集联军对抗火宅佛狱时，遭凯旋侯以裂宇之玄击杀。

作为集境重要势力代表，其政治立场与烨世兵权、弑道侯等形成直接对立，贯穿苦集两境冲突主线，退场于兵甲龙痕第30集的战役中。

## 人物影响

太君治是集境三院中的天机院主，精通阴阳五行数术，性格刚毅公正、心思缜密。太君治刚出场时，能用一幅画来去自如自由穿梭于二三次元的本事昙花一现，开局光鲜有料，但剧情很快急转直下，存在感也就跟着薄弱了。鸦魂评价说太君治性格太过温和不适合当领导者，而万古长空又说这样的人最容易让他人为其卖命。太君治适合当个清平盛世的领导者，遇到乱世或是强硬的对手，那么在别人替他卖命前，他已经失败或是先牺牲了。原以为集境应该也只有这个院主能在谋略号召力上和军督一抗，但实际上等级差太多，还没怎么发挥就直接沦为走剧情的“龙套”角色了。

## 角色经历

无漏玉衡太君治，集境三仪三司十二殿中的天机院主，个性相当温和，被鸦魂称为不适合的领导者，但万古长空却言这种人最容易让他人为其卖命，素来与太阴司交好，统辖十二殿中的擎羊、陀罗、文华、武曲四殿，司职集境治安与警戒。

01020304050607080910在佛业双身利用妖世浮屠冲破集境地层之后，太君治负起消灭妖世浮屠的任务，数次与阴端佛鬼周旋，在关山聆月告知太君治突破妖世浮屠的方法之后，太君治欲找三名高手，分别是香独秀、求影十锋与千叶传奇，但却被内奸知悉太君治找寻外人协助，进而让破军府派出使者野俊飞雄将千叶传奇带回破军府，太君治又进入胶着……万分不得已的情况下，太君治上血鸦山，找残宗副领鸦魂，欲寻其帮忙破妖世浮屠三处结界，在谈论的过程中，牵扯出破军府与天府院欲进攻苦境的野心，太阴司、天机院是阻挡破军府最后的力量，苦苦劝说之下，鸦魂终于答应帮忙；

而后，太君治以及香独秀、求影十锋、鸦魂四人闯入妖世浮屠，三人破除三角结界，关键之处的太君治却意外败于阴端佛鬼，就此功亏一篑。

而太君治商请鸦魂协助的事情竟也被破军府知晓，身受重伤的太君治被使者一路拖行，却在中途被鸦魂所救，处于血鸦山中的秘穴之中。

后经千叶传奇游说，与求影十锋等人与苦境中人共同对抗火宅佛狱与死国，因白尘子的泄密，在与笑剑钝、漠刀绝尘、求影十锋联合闯入火宅佛狱，欲将雅狄王遗书送至杀戮碎岛的行动中，被凯旋侯拂樱斋主以“裂宇之玄”的极招打败，重伤身亡。

# 六昧童子
================================================================================

六昧童子

古武族先知，仙风道骨、去老返少的白发黑颜童子，曾参与过上古圣魔战役，实力莫测。其个性崇尚天命，预知太武的降临将解救古武族，遂一路协助叶小钗复活并带领族人，成为对抗魔的一方战力。

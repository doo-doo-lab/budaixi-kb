# 六昧童子 (六昧童子)
================================================================================

六昧童子

古武族先知，仙風道骨、去老返少的白髮黑顏童子，曾參與過上古聖魔戰役，實力莫測。其個性崇尚天命，預知太武的降臨將解救古武族，遂一路協助葉小釵復活並帶領族人，成為對抗魔的一方戰力。

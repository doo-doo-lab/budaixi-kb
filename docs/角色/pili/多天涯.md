# 多天涯

================================================================================

霹雳布袋戏虚拟人物多天涯，霹雳布袋戏虚拟人物。神花郡郡主，刁蛮任性的千金小姐，自小受郡公多九望宠爱，养成骄纵任性的性格，善使小计，喜爱女扮男装，曾化名重夕公子参加云昙花祭，对殢无伤颇有好感而多所纠缠。在厉族进犯花都时，更布下玄妙的花阵牵制天之厉。

**别名**：天涯郡主、刁蛮郡主(花君子称)、天涯(多九望等人称)

**性别**：女

**登场作品**：霹雳战元史之天竞鏖锋霹雳战元史之动机风云

**编剧**：申呈山

**本尊雕偶师**：洪劍山

多天涯

多天涯是《霹靂布袋戲》中的虛擬人物。神花郡郡主，刁蠻任性的千金小姐，自小受郡公多九望寵愛，養成驕縱任性的性格，善使小計，喜愛女扮男裝，曾化名重夕公子參加雲曇花祭，對殢無傷頗有好感而多所糾纏。在厲族進犯花都時，更布下玄妙的花陣牽制天之厲。與靈花緣之少主海海角訂有婚約，但兩人卻互看不順眼，隨著故事進展，兩人在一連串變故下感情加深……

# 多天涯

================================================================================

霹雳布袋戏虚拟人物多天涯，霹雳布袋戏虚拟人物。神花郡郡主，刁蛮任性的千金小姐，自小受郡公多九望宠爱，养成骄纵任性的性格，善使小计，喜爱女扮男装，曾化名重夕公子参加云昙花祭，对𣨼无伤颇有好感而多所纠缠。在厉族进犯花都时，更布下玄妙的花阵牵制天之厉。

**中文名**：多天涯

**别名**：天涯郡主、刁蛮郡主(花君子称)、天涯(多九望等人称)

**配音**：黄文择

**性别**：女

**登场作品**：霹雳战元史之天竞鏖锋霹雳战元史之动机风云

**编剧**：申呈山

**本尊雕偶师**：洪剑山

## 角色配乐

- **神花郡(神花郡·七殊园)曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十八》
- **丁天牧老师2012年作品，以“幽兰”为题创作，优雅轻扬的琴弦演奏，加上点点轻灵的水晶音乐点缀，编织出一首文雅古朴、幽美的动人曲韵，令人心神向往。

乐曲初次使用于天竞鏖锋第38集，七殊园赏花祭之情境曲，后则使用于神花郡场景，郡公多九望、花君子与紫君花等人出场时，也多使用此曲为代表音乐，衬托出七殊神花的高雅不俗。

天涯郡主(重夕公子·多天涯)曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十八》
- **丁天牧老师2011年作品，神花郡主多天涯之角色代表音乐，以“世外书香”为创作主题，旋律优美轻盈，曲风清新亮丽，笙乐丝竹，远离俗尘的儒雅气息。

乐曲初次使用于天竞鏖锋第40集，多天涯以“重夕公子”男装之姿登场，在七殊云昙花祭中邂逅𣨼无伤，搭衬著轻松悠扬的曲韵，表现出多天涯游戏江湖的潇洒与随性。

天涯海角(多天涯与海海角)曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十九》
- **丁天牧老师2011年作品，乐曲初使用于问鼎天下第十六集，妖应封光造访刀剑铺之场景；

后于动机风云剧中，使用于多天涯与海海角洞房花烛夜，轻松愉快又带点诙谐的味道，搭衬天涯海角的搞笑演出，让人不禁莞尔一笑。

寻梦天涯(多天涯情境曲)曲/编曲：丁天牧** — 《霹雳英雄音乐精选三十九》

丁天牧老师2012年作品，以“情缘”为创作题目，乐曲初使用于动机风云第十八集，多天涯与海海角祭墓凭吊亡父之情景，乐曲同时也使用于后无封与魑岳携手隐遁赤荒漠之情景。

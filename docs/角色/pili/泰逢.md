# 泰逢（《山海经》中的人物）

================================================================================

泰逢，古代神话人物，出自《山海经-中山经》。

泰逢神的形状与人相似，但长着一条虎尾，出入有光，具有变化莫测的法力，可以动天地之气，是能带来祥瑞的吉神，也是黄河上游九条支脉汇集处“作和山”的山神。

泰逢曾使夏朝君主孔甲迷路。

在《山海经》记载的角色中，泰逢被描述为“见之有喜的吉神”。

泰逢的形象在当代文艺作品中亦有出现，其形象于2026年3月18日播出的动画片《山海传奇》第三季中首次登场。

此外，泰逢等皮影神怪图像与明清以来的《山海经图》有直接的亲缘关系。

泰逢(霹雳布袋戏人物)

泰逢，霹雳布袋戏虚拟人物。识界五神之一，天生潇洒率性，允文允武，惯于独来独往，我行我素，是识界中唯一不受玄貘控制之人。手中常把玩一颗小金球，能于战斗中幻化为荧魅剑。对妹妹苏苓有求必应，宠爱有加。

角色经历泰逢是识界幽厉五神之一，更是妙音天女苏苓的大哥。

为免亲妹伤心，阻止释云生对抗玄貘以保住其性命，但终究拗不过释云生，让其牺牲自我，从而使玄貘不能附于人身。

以百里黄泉九转灵心代替素还真之心，为白莲复生留下道路。

参与江南雨地伏击魔界一战，重伤华颜无道。

之后为送还白莲之心与苏苓来到人间，却因邪灵抢夺将心意外丢失。

之后两人拜访伏龙，四处游历，结识游子安与醉仔。

后来得知游子安是须弥如来藏法女萨安，并与其相恋。

千叶传奇为使万古长空不受羁绊，设计不见荷为救义父杀死苏苓，苏苓元灵化为梦界之灵被织语长心用于完善功体吸收。

泰逢在九州一剑知的告知下，惊觉苏苓之死与千叶传奇有关，并将此事告知长空。

后来素还真废去长心功体，并从其体内取出只剩下记忆的苏苓元灵，泰逢催动法咒，使苏苓在熏池青鸟之灵的帮助下从人的梦境中返回识界。

由于须弥如来藏法尊宗喀尔被死神幻影杀害，萨安继任法尊力抗死神。

待太学主元神彻底毁灭后，泰逢与还俗的萨安归隐。

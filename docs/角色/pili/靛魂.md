# 靛魂

东瀛鬼祭将军座下高手，武功居五大武士之冠，刀法精湛、变化莫测，在影中林一招定胜负胜出，夺得金龙文诏。后东瀛内乱、鬼祭流亡，靛魂遭岩堂幕府生擒，最后死于八魂刀下。

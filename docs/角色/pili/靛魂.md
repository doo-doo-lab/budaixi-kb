# 靛魂 (靛魂)
================================================================================

靛魂

東瀛鬼祭將軍座下高手，武功居五大武士之冠，刀法精湛、變化莫測，在影中林一招定勝負勝出，奪得金龍文詔。後東瀛內亂、鬼祭流亡，靛魂遭岩堂幕府生擒，最後死於八魂刀下。

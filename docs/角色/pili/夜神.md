# 倪克斯（希腊神话中的黑夜女神）

================================================================================

订阅0有用+10同义词夜神（希腊神话中的夜神）一般指倪克斯（希腊神话中的黑夜女神）倪克斯（希腊文：Νύξ；英文：Nyx），罗马又称诺克斯（Nox），是希腊神话中的黑夜女神，为原始神之一，是夜的本体与化身，与丈夫和哥哥厄瑞玻斯一同由混沌卡俄斯所生。倪克斯生下了天光、白昼、梦、死亡、睡眠、命运、痛苦、衰老、辛劳等象征意义的神祇。倪克斯与赫卡忒、赫拉克勒斯等为宙斯敬重的神，倪克斯在俄耳甫斯教中是宙斯的养母。中文名倪克斯外文名Νύξ别 名诺克斯拉丁/英语Nox；Nyx双 亲卡俄斯；法涅斯兄 弟厄瑞玻斯配偶/情人厄瑞玻斯；柯罗诺斯（时间）子 女天光、白昼、睡眠、死亡、辛劳等登场作品神谱

## 角色背景

倪克斯（古希腊语：Νύξ；英语：Nyx），最早诞生的神是卡俄斯，代表宇宙出现。随后该亚、塔耳塔洛斯、厄洛斯相继独自诞生。之后卡俄斯独自生下了厄瑞玻斯、倪克斯。倪克斯和她哥哥厄瑞玻斯代表了卡俄斯的黑暗一面。她和厄瑞玻斯生下了埃忒耳、赫墨拉（见赫西俄德《神谱》），也有神话说赫斯珀里得斯、许普诺斯、塔那托斯、摩伊赖、赫卡忒、革剌斯、厄里斯和卡戎（说法见Juvenal 3.267; Eustathius on Homer 1666）也是他们所生。而倪克斯自己也生育了许多千奇百怪的子女——大部分都是不讨人喜欢的恶神。她的子女中，有些加入到了天神的行列，有些则成了冥神。倪克斯一系虽然未能与天神、地/海神、冥神平起平坐，但其势力实在不可小觑，不仅是哈迪斯，就连众神之王宙斯也得掂掂自己的分量。在古典艺术造型中，倪克斯是穿黑色星花纱衣的妇女，怀抱幼年的睡神或死神，在每天傍晚乘黑马拉的车飞上天穹。

## 相关神话

在希腊神话中，倪克斯是位非常古老而强大的神。倪克斯不仅神位崇高，是希腊神话中为数不多在所有神话体系中都拥有强大力量的伟大神明之一，还具有同时制约凡人和众神的强大力量。因其力量与身份，连宙斯都忌惮三分。荷马在《伊利亚特》中提到，唯有“降服一切的”倪克斯让天父宙斯心生敬重（但在《神谱》中说宙斯同样敬重赫卡忒和赫拉克勒斯）。由于赫拉想害死离开特洛亚经海上返回的赫拉克勒斯，为了不让宙斯发现，她让许普诺斯使宙斯睡着了，宙斯醒来后得知赫拉克勒斯被刮至科斯岛，盛怒之下将赫拉用镣铐挂在奥林波斯山上并将许普诺斯扔下奥林波斯上。他还不解气，扬言要将许普诺斯打入塔耳塔洛斯。许普诺斯只得躲进自己母亲倪克斯的袍子里让宙斯找不到，且宙斯由于对倪克斯的敬重，也就此作罢。倪克斯居于冥界，她的住所也是黑气弥漫。每当昏星赫斯珀洛斯（Hesperus）开道，她便离开冥界，驾驶着战车飞上天空，用夜幕笼罩大地，让世界浸入宁静。倪克斯古老而强大，连天帝宙斯（Zeus）也敬她三分。倪克斯与厄瑞玻斯结合，生下高空或天光埃忒耳和白昼女神赫墨拉。她还独自生下了一大批危害世人的恶神。

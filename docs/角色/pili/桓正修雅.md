# 桓正修雅

霹雳布袋戏虚拟人物桓正修雅，霹雳布袋戏虚拟人物。论剑海评剑会主持人，也是论剑海副主席、评剑司司主。气敛丹田、形放诸百骸九窍，有着文人雅士的风雅特质，同时兼具剑之精魄的修养。为人气度恢弘，应对有方，待客有道，剑法修为精湛，腰悬一口碧青断剑，剑下之魂埋藏着一段过往。对评剑会榜上之人礼遇有加，因而派人将失去元功的魄如霜带回安置，但却也坚持论剑海之规矩原则。

## 角色形象

桓正修雅单人图册作为论剑海的副主席，桓正修雅为人气度恢弘，日常事务皆应对有方，谦而不卑，待客有道。虽然极其看重论剑海的规矩与原则，但并不迂腐，反而通情理、知变通。桓正修雅与剑同修，只要剑心不纯，剑也会随之而断。当年桓正修雅被步渊渟的信念所打动，放弃了自己的剑道，倾一身本领全力协助步渊渟管理论剑海，纵使中途有疑惑，亦以执行命令为首要。“国士遇我，国士报之”正是对桓正修雅最贴切的写照。

## 人际关系

人际关系步渊渟论剑海主席，桓正修雅的直属上司。

沉稳有度，善拢络人心，经营论剑海多年，以评选排名众家剑谱为号召，鼓励剑客精进淬炼，表面立意良善，实则暗藏目的。

论剑海之内，也因为每届的评剑会，累积众多名家剑法，步渊渟从中习得各家之长，集剑法之大成。

同时也在台面下暗植势力，拉拢曾参与评剑会的不凡剑者，以助永生壁中的双蛹脱困，与天地虻（王蠸、后夔）共同策划让三阳同天，造就永生不死的世界。

而在天地虻脱困后步渊渟却发现情况已经越走越偏离初衷。

步渊渟暮迟朝论剑海评剑师之一，初登场即为向倦收天通知魄如霜正在论剑海休养一事。

个性温和守礼，尊重他人。

与另一位评剑师枕流君颇有私交。

后因玄同太子断枕流君一臂而前往质问，却意外命丧紫色余分利剑之下。

暮迟朝枕流君论剑海评剑师之一，在魄如霜遭受追杀时现身搭救，踏月而来、一芒千闪，枕流君气势万钧，以新月剑法将敌人全数歼灭，却也因此引起玄同太子的注意而接受挑战，雪中心剑中意，晃眼一瞬剑已决，枕流君不敌遭断一臂。

在玄离皇子一探论剑海时，与儿孙剑锋联手御敌，但却小觑了玄离冰火双剑之威，双双遭封喉而亡。

枕流君儿剑孙锋论剑海评剑师之一，在倦收天欲带非非想进入论剑海医治魄如霜时现身阻拦，个性骄傲气盛，以论剑海为最高荣耀，绝技为月影剑法，能与枕流君的新月剑法搭配剿敌。

在玄离皇子一探论剑海时，与枕流君联手御敌，新月并月影，剑气肆意纵横，但却轻估玄离冰火双剑之威，双双遭封喉而亡。

## 角色经历
初登场论剑海新一届的评剑大会上群英荟萃，前六名剑谱依次摆于剑锋，独有一本《观剑不则声》被放置在剑柄处，且未曾获得排名，主持人桓正修雅对此也并未解释。

桓正修雅主持评剑会评剑会上，秋风暮霞惋红曲（玄同太子）被首先选中一评第六名之剑谱《纵云剑》，惋红曲言此剑谱为下乘之剑不予置评，言语间却对《观剑不则声》颇为推崇。

围观群众因不解剑之道而对他产生质疑，倦收天（本次因《九阳天诀》获评亚座）出言相助。

因挂心魄如霜之事，中途倦收天与原无乡先行离去。

评剑会持续到子夜，获评第四的忘俗贺无怀（葛仙川）指出《九阳天诀》可由其中的五阳之招而速成，甚至将之破解，并亲身演示五阳之招。

此时素还真脚踏莲花自天而降，主动向桓正修雅请求点评第一名的剑谱《松月闲咏》，指出松月剑式以自然之道入剑，与九阳天诀有异曲同工之妙，二者应该并列。

素还真更将贺无怀的见解一一驳斥，言明他已失了剑心。

月下饮谈评剑会结束后，贺无怀对自己仅获第四名而愤懑，更无法接受素还真与桓正修雅所说的“剑心有失”，为此与桓正修雅发生争执，最后拂袖而去。

随后桓正修雅带倦收天入论剑海看望魄如霜，倦收天欲亲自带她求医，被桓正修雅婉拒。

因论剑海有“只接待评剑会前六名”的规矩，为让医者能够顺利看诊，倦收天与桓正修雅约定：如果带来的医者没有把握将魄如霜完全医治，倦收天将被论剑海拔除亚座头衔，连续三届不得参与剑评。

杏花浮瓣，对坐饮谈夜溶光，疏影摇。

杏花天影内，桓正修雅迎来了意料之中的客人——秋风暮霞惋红曲（玄同太子）。

惋红曲指出桓正修雅现在与在论剑海之时的感觉十分不同，桓正修雅顺势破题引话，二人畅谈剑中真义。

惋红曲言桓正修雅给人以剑灵的错觉，并以桓正修雅所佩断剑回答了对方提出的三道议题：“剑上人、剑中理、剑下魂”。

桓正修雅带玄同主仆一观名人堂通过论剑海的试验后，桓正修雅带领惋红曲与紫色余分一观论剑海名人堂。

名人堂上所挂画像皆为曾经蝉联三届评剑会首位的剑者，桓正修雅将诸位剑者的传奇之处娓娓道来，并通过惋红曲的回答再次确认了他对剑之理解确实不同凡响。

惋红曲欲与论剑海主席一会，桓正修雅却言主席早有交待，只要他能胜过名人墙上其中一位，主席便与他见面。

于是惋红曲选定了六道雪生剑点轮回（荷叶禅师），随后离去。

医治之约倦收天几经周折寻来森狱御医非非想，却因非非想身上的森狱气息在论剑海门口被评剑师枕流君、儿剑孙锋拦下。

争执片刻后桓正修雅现身，向倦收天说明了名剑与论剑海的渊源。

虽然医治魄如霜的风险极大，但倦收天履约之心不见动摇，桓正修雅见他心意已决，遂放行。

桓正修雅拔除倦收天剑评亚座之位非非想为魄如霜看诊，验证了桓正修雅先前的猜想。

因魄如霜无法当场被治愈，倦收天所获亚座席位依约被论剑海收回。

倦收天离去后，枕流君欲求情，被桓正修雅拒绝。

魄如霜忧心倦收天，向桓正修雅出言请求不要将他除名，亦被婉拒。

但桓正修雅应下了魄如霜”遣人打探倦收天近况“的请求。

倦收天被森狱视为大敌，为求名剑金锋的破解之法，森狱玄阙皇子领兵欲探论剑海，却逢桓正修雅拦阻。

桓正修雅言论剑海一向以和为贵，为了避免多余的伤亡，不如二人单独一决。

名剑风波玄阙败于桓正修雅夜冷冷，照寒光。

论剑海外玄阙祭起邪之卷，顿时巫气窜天地，邪元开风阵。

桓正修雅甫一抽剑，黑花沛然涌现，剑意瞬弥八荒，断剑挥洒间从容破去玄阙初阵。

玄阙旋指改变阵势，仍是不敌。

桓正修雅问明“为何森狱要针对论剑海”后并未再为难。

数日后，因第二道黄泉归线的启动，论剑海受到强震波及。

桓正修雅担心魄如霜会摔下床而前来探望，魄如霜向他打听倦收天近况，桓正修雅正欲回答，察觉到双秀欲闯论剑海。

论剑海外，亲身挡关的桓正修雅质问倦收天是否想违约背信，原无乡却将责任揽到自己身上。

桓正修雅怒而请剑，战局僵持间倦收天抓住时机，纵步越界。

但因论剑海主席步渊渟插手，倦收天未能找到魄如霜，只得返回中止二人的战斗。

双秀向桓正修雅赔礼致歉，桓正修雅体谅倦收天的心情，言语间颇有宽谅之意。

桓正修雅的“放水”随后倦收天请求与主席亲自商谈魄如霜之事，与原无乡在论剑海外苦等一夜。

但桓正修雅带来的却是步渊渟的拒绝，以及要在三个月后收回名剑的要求（名剑金锋由论剑海所打造，多年前借与葛仙川）。

名剑上嵌有能够让倦收天重新视物的至宝“北斗指引”，收回名剑几乎等于至倦收天于死地。

原无乡因此而感到愤慨，但倦收天却一力应下。

永生壁暗夜沉寂，风透林中，一色秋因黑月之故欲潜入论剑海，桓正修雅横剑挡关。

就在两人极招将发之际，忽来诡异邪波直袭一色秋脑识，一色秋因此撤退，留下对此感到莫名其妙的桓正修雅。

原无乡强势闯入论剑海因之前双秀强闯论剑海之故，桓正修雅将魄如霜转移至杏花天影。

但此时原无乡却在不惊动护界剑阵的情况下进入论剑海，要他交出魄如霜。

激战间桓正修雅发觉对方道心蒙尘，原无乡却突然剑转式变，全无留情，连环三式攻得桓正修雅诧异在心，随后掠走魄如霜。

桓正修雅不明为何银骠当家心性锐变，决意先将此事告知主席因应。

桓正修雅寻步渊渟未果，却在步渊渟房中发现奇异磷光，跟随磷光而行，意外闯入永生壁。 桓正修雅不知论剑海竟有如此暗道，讶异间步渊渟出现，解释此地乃是自己平日深研剑道之处，并命令桓正修雅带等候在外的一色秋参访名人堂。

桓正修雅上报自己保护不利以至于魄如霜被原无乡劫走之事，并未受责。

素还真突然来访，欲拜会论剑海主席。

桓正修雅通报之后步渊渟竟亲自出面迎接。

桓正修雅内心虽觉蹊跷，但本着对主席的信任，不曾多言。

征战天疆宗女凛若梅潜入永生壁，行踪败露后一路疾行而出，半途被桓正修雅挡下。

短暂交手间桓正修雅被逼退，步渊渟随后出手，二人对掌，凛若梅顺势而退。

步渊渟正要以怠忽职守之名降罪，却因素还真的出现而作罢。

桓正修雅对步渊渟提出质疑论倾城重伤，二人回返论剑海魄如霜为二人求情1魄如霜为二人求情2桓正修雅为论倾城疗伤桓正修雅与笔策丹青论倾城遵照主席的指示前往拦阻蜕变黑后，双方激战当下，论倾城被黑后的七绝离恨重创，因魄如霜求情，黑后并未对二人再下杀手。

回到论剑海后，桓正修雅向主席汇报战况并对本次行动提出质疑，但被步渊渟以“武林大义”和“修雅，你的心情浮躁了”为由按下。

随后步渊渟命桓正修雅传令锻剑司，以冰心铜打造纳天镜。

三月之期未到，倦收天携名剑来到论剑海，表明暂时不会归还名剑。

桓正修雅尚未出手，论剑海首席之剑已然出鞘，极战名剑金锋。

步渊渟下通牒后放倦收天离开。

被擒论剑海围杀玄同太子秋水一色剑交光，荒原四野黄尘落。

为杀玄同太子，步渊渟率话偏锋与桓正修雅以剑阵正面对敌，王蠸隐于地底暗中蓄力，后夔则见机附身于桓正修雅。

主攻和辅攻有条不紊。

主锋直捣黄龙，辅攻则乘风助势，主辅默契十足，玄同太子双剑顿时被牢牢牵制，无法运转。

奈何玄同王剑在握，反而一击将话偏锋断首。

众人撤回论剑海之后，桓正修雅独自于论剑海入口处徘徊，对日前与玄同之战充满了疑问。

此时冷别赋前来寻找剑驼异相话偏锋，因话偏锋的住所只有主席知晓，桓正修雅将冷别赋带至沉剑湖引见步渊渟。

桓正修雅被天疆所擒数日后，天地虻尚未恢复人形，天疆牧神却已取回了圣器牧天九歌。

牧神为报仇、为诛恶，率众攻打论剑海。

双虻被迫自我封闭于洞穴，论剑海众人亦不敌神器之威。

在撤退时桓正修雅不慎为玉雉衣所擒。

牧神认定桓正修雅具有很大的价值，命人将他带回天疆。

后天地虻恢复人形，素还真前来论剑海请求借用欧冶神弃，王蠸提出条件，要借欧冶神弃，素还真首先要让天疆释放桓正修雅。

退场翠环山下，论剑海与森狱的大战中途，桓正修雅与欧冶神弃率众驰援。

桓正修雅奉命将打造好的纳天镜由论剑海押送到翠环山，行至中途，葛仙川前来抢夺。

葛仙川收放自如，桓正修雅缠守难破。

眼看战况僵持，葛仙川绝式再出，利用桓正修雅应招的一瞬之隙越过防线取走纳天镜，且留言要求对方以倦收天来交换。

桓正修雅忠魂长逝牧神重伤后，白首留仙与山龙隐秀、剑鬼觑准天地虻外出之机攻打论剑海。

鏖战几转，战已热烈。

步渊渟与剑鬼极招相对，不想在极招催发的当下，步渊渟竟瞬间感到真气逆流，吐出血来。

同一时间，白首留仙与桓正修雅亦战至白热化，仙老一心一意歼灭敌手，桓正修雅的性命已经悬在生死边缘。

剑绝花尽，极天飞艳，为救步渊渟，桓正修雅倾万千剑意全力攻向剑鬼。

剑鬼极招遭到延宕，但桓正修雅却正中仙老招式。

步渊渟顺利脱险离去，剑鬼欲追，却见桓正修雅以将死之躯挡在面前。

剑鬼不忍践踏这样的护主心意，拂袖离去。

气息将尽，桓正修雅眼前只剩初心一幕。

当年他在杏花天影内舞着剑，步渊渟问他“这是我的信念，你能够认同我，助我一臂之力吗？”，当时桓正修雅没有回答，断裂的剑刃却彰显了他的决心。

回忆结束，桓正修雅断剑脱手，断了气息。

后续二人于桓正修雅墓前缅怀新的论剑海建立之后，步渊渟本欲将桓正修雅葬于杏花天影，但因共同的理想终于实现，犹豫后还是将他葬在了新论剑海内。

欧冶神弃与步渊渟在墓前缅怀过去那段三人携手打理论剑海的时光，欧冶神弃更透露当年的桓正修雅总是因为太累而不胜酒力，每每三人办完公事小酌之时他只饮几杯便沉沉睡去，每次还要被抬回房间。

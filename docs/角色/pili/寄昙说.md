# 寄昙说 (寄昙说)
================================================================================

寄昙说

夸幻之父遭旸神极招所灭后，因体内梵天之灵珠而蝉蜕重生，成为佛教修者“禅剑一如寄昙说”，也是梵天寄体重生之新身份。寄昙说身背三光之器“三恒曌世”，功力更胜夸幻之父，以禅行剑，天涯行迹。

# 暴雨心奴

霹雳布袋戏虚拟人物暴雨心奴，霹雳布袋戏虚拟人物。当初设计十八地狱阵一举围杀九千胜与最光阴的邪恶书生，个性阴狠狡诈，因为得不到，所以想一举毁灭，杀人手段十分残虐。习有祆撒教特殊邪法，自许为祆撒大护法，认为自己是天使的眼泪所化，每当下雨时，他就会认为是上天在为他哭泣，哭的是自己还做得不够恶！

## 角色经历
暴雨心奴暴雨心奴，最初出场于黄羽客对最光阴说的故事回忆中。

昔日一个内心充满英雄梦的俊美少年，在入江湖第一战时就败在英俊不凡的刀神九千胜之手（从后来杜舞雩与天华老者的对话回忆中可以看出，暴雨心奴对打败他的九千胜并没有任何不满。

甚至将自己一身功法的来源告诉九千胜）。

在败于九千胜后，暴雨心奴神秘失踪不知去向。

再次出现时暴雨心奴已经成为祆撒教舞司，兵器也从宝剑变成了战镰（在之后的回忆对话中得知，原来暴雨心奴弃剑练刀是源自于九千胜所说他不适合练剑）。

希望能得到九千胜的认同与九千胜共同坐上元字第座，这是暴雨心奴人生第二场梦。

但最光阴的出现再次打碎了他的梦，内心的嫉妒、羡慕、不满已经让他失去理智。

暴雨心奴设下毒计陷害最光阴。

并且摆下十八地狱阵，以最光阴为诱饵引九千胜入阵，愤怒与仇恨已经使暴雨心奴的内心极度扭曲。

为了能得到九千胜的一对心魂，生生扯下九千胜的绮罗双耳。

在九千胜、最光阴被杜舞雩所救之后不久，暴雨心奴被杜舞雩与烟都大宗师古陵逝烟联手囚禁在圈雨井中。

当第一万次天雷响动后，暴雨心奴被古陵逝烟放出。

暴雨心奴的出现使苦境武林又将掀起一场腥风血雨，对绮罗生、最光阴的未来不知产生何种的变数。

## 角色歌

暴雨临世（暴雨心奴角色曲）曲/编曲：孙敬凡 收录于《轰定干戈原声带-精选45》孙敬凡老师2013年作品，以“变局”为题创作，风声刮起，天际顿成一片黑暗，铜管如闷雷阵阵作响，似宣告暴雨将临。黑夜中伫立一道持着镰刀的身影，咯咯笑声传来使人背脊发凉，霎时旋律一转，狂风暴雨随着吆喝声开始肆虐，放声大笑的魔鬼启动了消遣自我的猎杀游戏。乐曲选用于“暴雨心奴”一角，其性阴狠狡诈，有着自己得不到的东西，别人也休想得到的偏差性格。每当下雨时，就会认为是上天正在为他做得不够阴恶才哭泣。

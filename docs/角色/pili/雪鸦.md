# 雪鸦

东武林顶尖杀手，玉天玑最为死忠的贴身护卫，冰冷少言，身手如暗夜鸱鸮，刀落取命于瞬间，贯彻任务绝不留情。在玉天玑落难时依旧誓死追随，甚至为主人前途不惜牺牲自己…

## 武器

破网雪花刀

## 角色设定

雪鸦身手如暗夜鸱鸮，刀落取命于瞬间。

◎外形特征：一口长柄大刀，柄长而刀刃尖细、薄利，轻巧灵敏度十足。配合雪鸦如鬼魅般的身法，更好发挥战力。

◎登场剧集：霹雳幽灵箭第二部 第5集

## 角色经历

神秘的白衣杀手雪鸦，乃是风尘骄子玉天玑所培植的得力战将，也是最忠心的贴身护卫。在玉天玑受聘成为魔界军师时，为了扫荡残余的三教势力而出，一刀取下七彩云天主持空劫的首级、杀圣龙口坐镇的血阳子、伤紫阳子等，雪鸦出刀迅雷不及掩耳，让人避无可避。由于玉天玑手段高压无情，不但无法让手下臣服，更造成魔族连番损兵折将，导致被血灵魔尊翻脸无情逐出魔界，惨遭多方势力围杀，幸亏有忠仆雪鸦护主，才得以逃出生天。

此后，雪鸦奉命救出非常女，却遭遇旧主玉天玑。面对昔日主人，雪鸦手握破网雪花刀刀刀留情；而玉天玑心中有数，珠光如电，招招取命，刻意刁难，令雪鸦渐感难以招架。

日后，欧阳世家复辟，玉天玑也得接天秘法之助重拾智慧之星的风采。欧阳上智要求金小开让玉天玑重回无极殿，但金小开提出的唯一条件是要玉天玑奉上雪鸦的人头。为了让主人有光明的前程，雪鸦选择自刎而死。只是雪鸦之死多多少少有一点是玉天玑设计的结果。

雪鸦曾经将金小开的四肢筋脉打断，玉天玑怎么会不清楚金小开想要什么，在司徒笑梦来告诉玉天玑其重回无极殿的条件时，玉天玑就故意让雪鸦听到，还在雪鸦面前将司徒笑梦打成重伤，司徒笑梦走后，玉天玑更是动不动就在雪鸦面前唉声叹气，甚至假装要自杀，要雪鸦拿着自己的首级去奔赴更好的前程，最后雪鸦为表忠诚在玉天玑面前自刎而死。

可惜的是自认为算无遗策的玉天玑还是算漏了就在他急冲冲的牺牲了雪鸦的时候金小开已经离开了无极殿，而目光短视的他更没算到他心心念念想回的无极殿即将走到尽头。雪鸦的牺牲，他终究还是辜负了。

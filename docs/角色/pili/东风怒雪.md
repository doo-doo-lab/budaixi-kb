# 东风怒雪

拳宗掌门人，老成持重的拳师，拳风刚厉，与神乞、北仙龙三人原是玉阳君准备吸收的武林高手，但暗中被织语长心所招纳，成为取代玉阳君的东武殿新大将。

## 来自百度百科的补充

东风怒雪与神乞何复求、北仙龙柳竹公三人原是玉阳君准备吸收的武林高手，却暗中被织语长心招纳，成为取代玉阳君的东武殿新将领。然而，东风怒雪三人并无太多作为，何复求、柳竹公先后在任务中殉职或遭判罪，仅余东风怒雪一人，也就此成了织语长心的打手。

东风怒雪实力虽是不弱，但非绝顶高手，以致带兵围杀末日骄阳时反遭重创，被一剑毙命。

东风怒雪首攻第一波，拳门宗主力沉招稳，顿足裂地，劲拳开山。

东风怒雪登场于《霹雳天启》，初登场于第18集，并在第38集中有出场，剧情描述为“东风怒雪首攻第一波,拳门宗主力沉招稳,顿足裂地,劲拳开山!”。

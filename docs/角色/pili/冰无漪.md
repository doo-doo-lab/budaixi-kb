# 冰无漪

霹雳布袋戏虚拟人物冰无漪，霹雳布袋戏虚拟人物，元种八厉之“水之厉”，别名咎殃。身负水银功体可穿越无尽天峰，擅使冰系武学与透明冰剑“祸水”，能化水为形伪装，诗号“寂傲沧溟远，睥越天关……”彰显其诙谐高手特质。

## 人物设计

（摘自霹雳会月刊第198期封面人物——祸随剑殃·冰无漪）名号水之厉，祸随剑殃冰无漪，也有一个属于厉族的名字：咎殃。

祸随剑殃与咎殃维持对应厉族特色，而冰无漪代表的是水之厉的不同面貌，冰层表面乍看无甚涟漪，冰层之下却是暗流涌动、深不可测，暗喻水之厉搞笑特质之下，有其不可预知的危险性。

剧情冰无漪·封面人物  霹雳月刊第198期元种八厉的设计，取材于八卦对应的自然现象，天、地、山、泽、雷、风、水、火。

在圣魔大战中，因厉族的从中作手，导致局势出现了巨变，元种八厉之中，泽、风、山、雷四厉，联袂上演了厉族无间，而火、水、天、地则是接着陆续出场的厉族角色，其中水之厉的设计，除了延续厉的一贯风格，编剧在人物性格上另外增加了与其他厉完全不同的特色。

冰无漪对于有损美感的事，是非常在意的，所以他也容不得观众对他如斯冷俊面容，另有质疑。

因此编剧设计在冰无漪初登场时，便让水之厉自己道破这个真相，以免观众寄情之余，会有贪秽创伤症候群，不断联想到水之厉也有不逊于贪秽的真实面貌，那也太不自在了。

为了呼应厉族善于伪装的特质，编剧让水之厉是以液态功体进行伪装，他可以直接变成对方样子，自然能维妙维肖。

只是，既然是水变的，先天上会有其他缺点，不若其他厉的伪装有效又持久。

之前在圣魔战印中提到的古武族叛变事件，真相由水之厉在阙阗关上揭露出来，初次圣魔大战，魔城与古武族内斗，有部分原因是出自厉族的分化，是水之厉伪造假消息，制造两边冲突与不信任。

编剧在设计水之厉时，就定调水之厉独特的反差性，厉披上伪装，我就是不披，厉伪装的目的是变换身份潜伏颠覆，这与冰无漪个性不合，真有需要，他宁愿只用液态功体变身。

身为厉，他也有独到的地方，就如编剧安排水之厉在初次邂逅越织女时，便展现他特殊的能力。

性格冰无漪冰无漪性好亲近女性，对女性有自我独特的审美观，只有与剑布衣相处时，才会流露出歇斯底里的一面。

曾自称爱之厉，是因为对女性、爱情有一种探究的欲望，他想了解，人类的感情到底是怎么一回事，男女之间存在着什么现象，他想寻求这些厉身上所没有的特质。

个性喜欢吐槽的冰无漪，在厉族内则是出了名的病无医，对要紧之事，总是无要无紧，开会老是不见人影，出手也是来去无踪。

这样的态度，一开始是源自他对山之厉势力的不满，因为魑岳派对地之厉的不闻不问，让他老大不爽，所以他刻意出席八厉大会投下反对票，其实是代替地之厉投下神圣一票的（冰无漪自以为），因为就他个人而言，优先讨论的应该是地之厉。

随着厉族会后趋于团结，水之厉对于众人决议的事情，虽无积极参与讨论的意愿，但只要事情到手，他表面上啷当，私底下还是会似有若无，有意无意的把事情完成。

但水之厉对开会这件事，一定都是兴趣缺缺的，这是他的个人特质，因为处在没有异性的空间，他会浑身不自在，很快就会想离开，所以对开会这档事，水之厉是非常、极度不持久的。

冰无漪与传说中的剑布衣也有些交情，但立场应该分明的两人，是否将会发生什么冲突？

冰无漪身为厉族，他残酷的一面是否会表露出来？

祸随剑殃有一天是否会对武林带来巨大灾祸？

造型冰无漪编剧要求冰无漪造型要偏向欧式风格，与其他的厉做区别，并呈现出高贵的美男子形象。

发上装饰品配合冰无漪的水厉特色。

个性活泼的冰无漪，前发刘海特别设计成两边不对称。

偶头的选择经过重重考验，编剧经过二十次的失败，终于找到他的真命偶头。

泡泡袖的设计带有很浓厚的浪漫主义，呈现冰无漪（自以为）的罗曼蒂克。

飘逸洒脱的服装，温文高雅，是否能让冰无漪掳获哪位高雅女士的芳心？

场景冰无漪对斗争没兴趣，对美女比较有兴趣，标准的不爱江山爱美人。

所住的江山美人庭带有水之厉对异性的幻想。

编剧的要求是欧式庭院风格，而且一定要有椅子，这张椅子的功能除了让冰无漪休息，其舒适感还可以让女性贵宾来一起分享，所以这椅子至少要能容得下两人（或以上）。

五行中，黑色代表水，故躺椅也以黑色呈现。

圆拱门是欧式庭园常见的设计，在门中央与地上都有特殊的蓝色装饰以呼应水之厉的属性。

整体设计简单高雅，不只是冰无漪住起来舒服，还要能让受邀前来的女性贵宾感到幸福。

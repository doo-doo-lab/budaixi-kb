# 鬼如来

霹雳布袋戏中的角色鬼如来，霹雳布袋戏中的角色。因涤罪犀角影响，帝如来不受控制而恢复昔日暴虐之形态，头上满布骷髅舍利，全身散发邪妄魔气，行事也偏向极端。在御神风诛灭号天穷时，涤罪犀角也因完成千罪祭血而蜕变，鬼如来重拾至邪之器，再行以杀证道之路。

## 角色背景

因涤罪犀角影响，帝如来不受控制而恢复昔日暴虐之型态，头上满布骷髅舍利，全身散发邪妄魔气，行事也偏向极端。在御神风诛灭号天穷时，涤罪犀角也因完成千罪祭血而蜕变，鬼如来重拾至邪之器，再行以杀证道之路。

御神风死前以一点正气将观心自在寄于犀角之上，欲以邪养正，遏止犀角之威，后犀角与佛刑禅那同断，齐子然为修复犀角而将其析出。

## 角色经历

在佛尊·天佛尊、佛皇·九界佛皇、佛首·帝如来三大源流未现之前，一名僧者莫名得到一柄犀角神兵，冥冥之中，声识传耳，告知此兵刃能涤尽世间罪恶，更能证己大道，过程中，僧者行事愈加极端，甚至杀上传闻中的罪恶之都，进行千罪祭血屠城仪式，传说中的罪恶之都，七天之内，血流成河。
这一切都在天阎魔城的算计中——培养佛愆·鬼如来，这才是涤罪犀角的真正功能。
然而，灭罪执着反噬佛根，僧者濒临形散之际，从善之血以命相殉，破除魔障。
僧者噩梦乍醒，幡然悔悟，然极罪之血千数缺一，罪恶之都最后的血脉免于劫难，却也种下了日后灭神之祸，也就是号天穷的复仇。
僧者的罪愆来自于对“罪”的执着与滥杀，纵使罪恶之都是充满原罪的地方，依照一般佛家观念，仍以慈悲渡世为主，如此罪恶汇集之地，必然受到大家关注，因此僧者的疯狂举动，自然引来各界目光，也成为当时佛门中人“引以为耻”的过去，自然想尽办法重重封锁，经过时代变迁，佛尊、佛皇、佛首三大源流并起，奠定佛门完整体系，如今，对于此事也甚少有人了解，只是没有人知道当年的佛愆便是当今的佛首。
死在犀角之下的，是僧者与御神风共同的朋友—玉横雪。
所谓“从善之血”意即玉横雪从前为恶，而后归入正道，开化他的人，其实就是那名僧者。
因此，玉横雪偿还前恩，御神风也因玉横雪的全然信任，决定帮僧者隐藏过往，因此“帝如来”这个身份可说是在御神风的关注下诞生的。　话说在鬼如来恢复理智后，茫茫无依，此时，一名自称招提的僧侣，给了他一柄拥有充沛灵力、足以抗衡涤罪犀角的空刀，代表了从头开始的抉择，此后，鬼如来逐渐修成帝如来，乃至于创建云鼓雷峰的过程中，也将空刀修成了具有实体形象“佛刑禅那”，因此帝如来化身招提僧，一来是为了赎己罪业，二来是为了回向招提。
精神正处混乱的帝如来在云鼓雷峰覆灭、涤罪犀角正式离开封愆禁地之后，封锁在帝如来内心深处的嗜血渴望，逐渐无法压抑，直到靖沧浪闻风阻杀，精神正处混乱的帝如来，自此隐于台面下，当他再出之时，已是佛愆面目。
这种情况并没有维持多久，当鬼如来成为六魔禘、接受魔皇戮印之后，逆转之力启动，帝如来的意识逐渐恢复，这层变数的起因，源自帝如来消失在台面上的一个月，任谁也没想到，在这关键的一个月，已悄然埋下魔城正式覆灭的原因，原本帝如来所留血书，乃为解说佛愆缘由，并留下对付鬼如来武学之法，却也因为此间变数，帝如来在血书最后，补述了一段耐人寻味的暗示语句。
这一切发展，超乎他化阐提预料，更超乎鬼如来预料，或者该说，是披着佛愆外表的帝如来，在圣魔执着之下选择的道路，已是回返无期。
涤罪犀角与鬼如来一气共生，帝如来不愿入魔，此时自称蕴果谛魂的峦主，设法与帝如来灵识沟通，在提供维持帝如来意识之法的当下，同时交托任务，而帝如来欣然接受的原因有二，一者不愿再返罪恶原路，二者涤罪犀角乃魔城赠予，帝如来更不能纵容此等迷惑人心、破坏戒律的“邪恶”，继续存于世间，危害苍生，于是决定以罪身入道，前往修罗鬼阙卧底，而当他正式回到帝如来意识，早已是太荒神决启战前夕。
帝如来所扮演的，是“天下有罪、无所不杀”的佛愆，因此，他只能以疯狂杀性、玩弄敌手的表象，掩饰不想与黑衣剑少对战的意图；
为了取信魔城，选择针对曾为魔方助力、今为圣方兵源的古武族，于明峦攻防战中杀害岱宗羔百年；
故意激发靖沧浪斗志，使自己能在毫无保留的状态下，顺利导向两败俱伤的战果；
神决最终战，全力以赴赢得胜利，对于阿修罗的生死，只能将希望放在于百年千年后，阿修罗再次苏醒的可能。
这种种的布局，只为了加深他化阐提对自己的信任，让他化阐提相信“以涤罪犀角培养佛愆”是成功的，进而于明峦里应外合，将魔城一步步推向败亡的深渊，甚至配合海蟾尊的计划，使他化阐提判断错误，成功拔除无明法业，同时降低他化阐提的戒心，最终的目标，是在魔城败亡后，迫使他化阐提孤注一掷，前往开启魔皇陵，而那时随侧者，只能有一个人，就是鬼如来。
断灭阐提戮首借命，血战艳凉，他化阐提被海蟾尊连番逼杀，而后鬼如来护驾挡关，顺利将计划推向预设结局，涤罪犀角刺入由饮血邪刃所造成的伤口，瓦解不坏王躯，更顺利摧毁仅有阐提一脉与相关人士知悉正确位置的魔皇陵，岂料鬼如来所作所为，却是将自己甚至苍生的命运，推向另一个深渊，其实，鬼如来从不奢望自己在完成卧底任务之后，能够再次回返正道，遑论以帝如来的身份重新获得世人认可，因为他很清楚，自己的所作所为，与“传闻中的鬼如来”如出一辙，既已堕入阿鼻，便有舍身觉悟，但遗憾的是，从计划一开始，所谓的“正义”早已经走了调，只因委托者不是真正的蕴果谛魂，而是假借名义、潜伏圣方不知过了多少岁月的“葬界刁雄”魑岳，帝如来的弘愿，成为被厉族利用、践踏的垫脚石，所谓真相，让闻者一时愕然。
他化阐提的警告，很快地便由海蟾尊的连番逼杀得到验证，但这还不足以动摇鬼如来，从私下邀约素还真的举动来看，表示鬼如来早有觉悟，只是他的内心仍希望这一切都不是真的，于是在海蟾尊率众前往三教公审之际，鬼如来潜入龠胜明峦，就算最终确认的真相如此不堪，也要亲手毁灭祸源，无奈的是，植入佛脉而保持帝如来意识，已在无形中慢慢消磨佛愆至极毁灭威能，犀角难以认可不完全的鬼如来，同样失去传说的恐怖色彩，导致鬼如来败于魑岳之手，逼命之际，鬼如来催动他化阐提事先寄下的魔皇起手式能量，自刻镜纹图败逃而出。
而后，鬼如来先后遭到刺行杀手、玉清界、竞豹儿、佛门的追杀，正邪两道皆无容身之处，厉族更因鬼如来身系之秘，欲除之而后快，直到在云鼓雷峰一同共事的无惑渡迷，在追杀过程中口出“妖佛”二字，鬼如来终于明白，导致如今局面的，是自己的选择，所有惨亡犀角之下的冤魂，不是为了所谓的苍生大意而牺牲，因为自己的一厢情愿，而让坚持不愿成为佛愆的帝如来，也在无形中成为真正的侩子手，其实，如来已成鬼，其犯行更胜屠杀罪恶之都。
遥忆云鼓雷峰仍盛的时期，帝如来奉法遵行，提倡戒律，便是以曾经杀生破戒的过往为借镜，也因己身曾为佛愆，进而对梵天入魔有着同理心。
帝如来能渡人却无法自渡，只因未曾放下身为佛愆的过往，这份执迷，已在被捣毁的魔皇陵中，由冥冥回响娓娓道出：“帝如来执着于鬼如来，相应而生，鬼如来欲脱帝如来之表象，更形执着，心生极端，两造相斥，如此永困轮回，再难摆脱。”对梵天入魔有着同理心暗夜荒野，逆转识中佛脉的佛愆卸下鬼相，以帝如来的面貌一战甫脱离峦主身份的魑岳，而在身体无法承受体内真气冲突的状态下，浩势挡下魑岳至极一招，终至身形解裂，化作金芒消散无形，也象征着帝如来的执法初心，从此灰飞烟灭，但鬼如来的执杀恶念，却也因此确立于世，只待一人手持佛刑禅那，化身修罗，杀生渡罪，斩断佛愆之路。
涤罪犀角、佛刑禅那齐断，代表鬼如来、帝如来走向了相同的结局，却也开启了另一条大道，这条大道，也许不再有人同行，但对帝如来或者鬼如来而言，一切不过虚妄，是否得到认可，已经不重要了。

## 角色记录

传说“佛皇（九界佛皇）、佛尊（天佛尊）、佛首（帝如来）三大源流未现之前，有一僧者（鬼如来）持上古魔兵——涤罪犀角，进行千罪祭血屠城仪式，传说中的罪恶之都，七日之内，流血漂橹，灭罪执著反噬佛根，僧者面临形散之际，从善之血破除魔障，极罪之血千数缺一。”“极罪之血千数缺一”——故犀角在当时未能练成。
御神风救走号天穷（罪血缺一），玉横雪挡鬼如来杀戮之刀（从善之血破魔障），使鬼如来清醒。
来历涤罪犀角与佛刑禅那随着后来天阎魔城的神秘面纱被逐步揭开，方才知晓犀角是魔城城主他化阐提多年前赠予鬼如来，上古圣魔大战无果，魔城尘封，他化阐提与鬼如来失去联系。
而为玉横雪所挽回的鬼如来陷入迷惘，此时天佛原乡的招提僧出现，赠予他一柄空刀（佛炼铸天术所打造），鬼如来凭借佛乡之刀修成帝如来，并把这空刀修成圣器——佛刑禅那。
鬼如来则变成帝如来。
演变号天穷用邪刀击佛首未完成的邪刀犀角被帝如来用圣器佛刑禅那镇压在佛教总舵云鼓雷峰下，但末世圣传用计攻下雷峰，夺邪刀，并由天君号天穷执掌。
帝如来知道因果报应，遂写下“遗书”（第二段引号里面的内容），并打算跟号天穷决战，让犀角杀死自己。
奈何手持犀角的号天穷、宿贤卿父子合击，且犀角影响帝如来心智，造成佛首负伤，号天穷用邪刀击佛首，佛首圣气已经压制不住鬼如来的邪气，加上邪刀邪气的引动，使得佛首邪气大盛。
在号天穷父子追杀下避入山洞，随即帝如来之心性被原本的鬼如来取代复活。
天君带走邪刀，说58日后如来成鬼。
可是，未到58日，号被算计，临死前却把邪刀插入心脏自尽，使罪血千数完满，犀角练成，鬼如来马上从地下冒出取刀（霹雳兵燹之圣魔战印33集）。
最后于佛剑分说手持的佛刑禅那同断（霹雳战元史之天竞鏖锋第一节） 在涤罪犀角之中有御神风在死前为压制鬼如来将佩剑观心自在打入刀内，希望能唤醒帝如来。
在此之后，在圣魔止战的混沌期，原本已蜕变为血刹如来的鬼如来在失去记忆的情况下通过《毁住藏经》的力量压制住自身帝如来的力量，重拾鬼相。
并受血傀师的挑拨，为使鬼言现世而与当初赠空刀度化自己的天之佛本相约战于如来之巅，虽有魔焰加持但因战斗时间过久魔焰功效渐失，最后在双方皆只有一招之力时，鬼如来的 鬼禅六断·梵鬼同悲（终式）不敌天之佛的 禅天九定·极光净土遍法音 最终被天之佛度化，犀角的万千亡魂亦随之得到解脱，而犀角本身也变回之前未成型的封印形态。

# 蒼龍 (苍龙)
================================================================================

蒼龍（天子傳奇）

胸前佈滿龍紋，心機深沉、穩重而不失大將之風的飄渺城少主，頗得城主單沖的信任，表面上與其父子情深，實際上卻是各懷鬼胎，與白虎之間更是暗自較勁，爭奪繼主之位；情感上則是痴心專情，對繡尉一見鍾情，百般呵護，終於打動佳人芳心...

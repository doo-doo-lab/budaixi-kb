# 魔佛波旬

================================================================================

霹雳布袋戏虚拟人物魔佛波旬，霹雳布袋戏虚拟人物，初登场于《霹雳封灵岛》第13集。欲界之主，由恶体阎达、女体女琊、智体迷达三人合体而成，为三面六臂的魔佛，融合三人无比的力量，三人共有灵佛心，并分别保有三人之意识，可合体也可各自化出，身心魂不死不灭，其信念更是佛中异端，以铲除天下佛门正法为宗旨，一被唤醒便充斥着无尽的杀戮与战乱。波旬曾遭烽火关键击散，一分为三，三体分离后各自有了不同的遭遇。三体分离让后续剧情发展更加诡谲难测，玉海九轮盘的出现，是否代表着魔佛波旬即将再度降临武林，犹未可知。

## 人物剧情

过往剧情波旬为三人共体，不但拥有毁天灭地的威力，身心魂更是不死不灭，菩提界当年虽以菩提弓将波旬之灵佛心射出体外，分灵破其肉身，但是无法消灭灵佛心，魔佛虽一时失败，但其门人仍积极寻找唤回魔佛的方法。

在霹雳封灵岛时，欲界备齐各项要素，终于使波旬再次降临，然而合体波旬尚有菩提弓威胁，平时并不会一直维持合体状态，不过如果长期不合体修炼，功力会衰退。

魔佛波旬波旬复出后，菩提界首当其冲被灭，曾经射出灵佛心的菩提弓也被列入必毁目标。

波旬卷席武林，素还真亦非敌手，看似无敌的波旬，隐患却一一浮现。

鬼隐夺得菩提弓，用来与欲界谈条件，为了未来大计，阎达答应以天籁石交换菩提弓，不过事实上却是要引来鬼隐，直接杀人毁物、双方约在矗天壁，不料此乃鬼隐计谋，一页书等人现身，困战魔佛三体，魔佛落入下风，败象已现，因而再度合体为波旬，瞬间风云变色，魔威再临，此时鬼隐使用掐心术牵制魔佛，一页书等人立即以绝式击中波旬，时机已到，高峰上的菩提弓由霸王横千秋拉开，一道光芒射开天际，将波旬吸入未知空间星云河。

波旬被封印，欲界基地也在之后被攻陷，魔佛之祸终告一段落。

波旬再临妖皇堕神阙攻破天佛原乡外围、陆续取得黑白双玉佛并吸收入体后，佛乡顿现血色异相，洗罪三尊的现世，亦开始带出玉海九轮盘秘辛，欲界第六天的势力，悄然浮现台面，而魔佛波旬再现尘寰的契机，则与金狮秘藏息息相关。

魔佛波旬金狮壁窟内的两座金狮鼓，乃是金狮帝国于久远之前，以圆寂高僧之皮所制成的人皮鼓，此鼓破响三声有裂天之能，受波旬玄异力量选定，透过早已封在佛乡深处的玉海九轮盘，将星云河接轨至双鼓衔口、箍制帝国哀亡怨气的金狮壁窟，只要搜集由深海金元所铸成的四枚金狮币，投入石鼓狮口，便能活络石化的金狮鼓，恢复真正的皮鼓之形，现出开天之路，波旬便能成功破封而再临。

波旬正式破封后，三余无梦生、朝天骄、圣婴主等各路高手正面迎击，难撄其锋，此时一页书驾驭烽火关键而至，以强大的冲击力，将波旬三体强行分离，更将恶体阎达推入星云河，进行一场生死对决，而后两人招行极端，意识双双受创；

迷达则是借着涯十灭重生而布下对策，重创妖界之余，更横扫苦境佛宗，以众多僧侣性命，逼迫佛乡归降，其间虽有阕声云舵负罪杀生，让佛乡无后顾之忧对抗欲界，仍因此引来非议。

玉海九轮盘的背后，也牵扯了一段佛乡与欲界的久违恩怨，昔时欲界潜伏佛乡内部，裳璎珞率领深阙诸佛，与欲界部众一战，魔佛所钦点之秽佛双异不敌身亡，致使洗罪三尊无力回天，只能豁命以玉海九轮盘之力，抗其天铸奇能，方将深阙连同欲界部众，以牵制之法封印。

如今佛乡深阙解放，欲界部众亦脱困而出，面对欲界连番进逼，又要如何愿封？

波旬金身不死，世上真无彻底消减之法？

由于波旬遭烽火关键击散，一分为三，让三体各自有了不同的遭遇，同时也让后续剧情发展，更加诡谲难测，对如今四分五裂的武林局势来说，究竟是福是祸？

犹未可知。

## 相关作品

在《霹雳封灵岛》（2006年）中，魔佛波旬应时重生，欲界第六天肆恶武林。在《霹雳侠影之轰定干戈》（2013年）中，魔佛波旬破天而降再度尘寰，波旬三体分离。在《霹雳侠影之轰动武林》（2026年）中，玉海九轮盘出现，欲界的精神象徵，是否代表着魔佛波旬即将再度武林？

## 人物影响

波旬以魔王之姿，诠释了纯粹的破坏美学。他的逼格来自于一种原始而狂野的破坏欲，统领魔界大军，手持波旬魔刃，每招每式都携带着死神之无间风死的诅咒之力。这种力量如无间风般撕裂灵魂，永无止境地侵蚀敌人的意志。波旬的经典在于他的笑声——那是一种蔑视苍生的狂笑，仿佛世间万物皆为蝼蚁。在霹雳的叙事中，他多次与正派高手对决，却总能以一己之力逆转乾坤，这种魔王不败的设定，让他的逼格直冲云霄。更深层来看，波旬象征着人性中的黑暗面，他的存在提醒我们，面对诱惑时需坚守本心。

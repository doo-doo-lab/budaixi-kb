# 獨孤遺恨 (独孤遗恨)
================================================================================

獨孤遺恨

現身於孤舟之中把酒高歌的神秘劍客。因身繫著魔劍道之主誅天的死因之謎而捲入江湖的是非之中。個性沉默、寡言、重義氣；與川涼劍伕、鋼翼飛猿同為知交好友。

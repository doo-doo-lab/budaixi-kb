# 独孤遗恨

现身于孤舟之中把酒高歌的神秘剑客。因身系着魔剑道之主诛天的死因之谜而卷入江湖的是非之中。个性沉默、寡言、重义气；与川凉剑伕、钢翼飞猿同为知交好友。

### 人物经历

独孤遗恨，魔界传说中的剑客，孤舟漂泊的江上浪人，独孤遗恨幼时曾失手打死玩伴春因，导致后来生性孤独，只有川凉剑夫、钢翼飞猿两位好友。为人重情重义、知恩图报，曾救下被山贼欺辱的妇孺，又散尽自身所有的盘缠接济贫困百姓，足见其侠肝义胆的一面。

为报恩情甘愿受策谋略利用，背起杀害诛天之名，因而卷入武林争斗漩涡，成为众所瞩目的焦点。独孤遗恨独来独往，佩剑也取名【独孤剑】，剑法独步九诀一式九招，收、转、逆、抽、破、挑、扣、抡、扫，一气呵成犀利无比，轻松击杀寻衅而来的影中残、解玉龙，连黑白双少联手都对其无可奈何。

最后，独孤遗恨对上为报挚友诛天之仇而来的风之痕，独孤剑、魔流剑双剑交锋，独孤遗恨的独步九诀相生相变、变化万千招，风之痕左魔流右风痕，双剑分出，狠野疯狂又冷静快意，双方从黄昏激战至黎明，剑势万千令人赞叹。最终，独孤遗恨剑法修为不敌风之痕而命陨江湖。其实，对战过程中风之痕早已发现独孤遗恨并非凶手，独孤遗恨也配合诈死摆脱策谋略的束缚。

无奈，独孤遗恨依旧难逃策谋略杀人灭口的手段，利诱残忍猿冷思路背后暗掌偷袭，让独孤遗恨撒手尘寰，自此剑界少一旷世奇才，后忆秋年与风之痕知其死讯，两人也倍感惋惜。

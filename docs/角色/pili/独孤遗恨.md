# 独孤遗恨 (独孤遗恨)
================================================================================

独孤遗恨

现身于孤舟之中把酒高歌的神秘剑客。因身系着魔剑道之主诛天的死因之谜而卷入江湖的是非之中。个性沉默、寡言、重义气；与川凉剑伕、钢翼飞猿同为知交好友。

# 谜独白

================================================================================

霹雳布袋戏中的角色谜独白，

**本名**：百里冰泓，是霹雳布袋戏系列中的虚拟角色，登场于《霹雳侠影之轰动武林》和《霹雳侠影之轰定干戈》，由黄文择、鹏飞、江志伦

**身份**：为冰楼三王子，来自四奇观·冰楼。作为神秘刀者，谜独白与无梦生有交情，曾暗中救助一页书等人，并协助探索黑狱和阻止圣魔元史被夺

**武学**：为冰锋十破。其真实

**身份**：在剧情中揭晓，最终在《霹雳侠影之轰动武林》第21章死于宫无后，惨死留下白骨与谜刀。

## 角色经历
谜独白谜独白手持一口银白雪亮的谜刀，横摆发出刀气开战，身法极快且不发一语。

曾助三余无梦生深入黑狱一探佛骨凶兵，在妖皇殿阻止暗尊夺取圣魔元史，与绮罗生合力一战葬刀会双公，更从欲界、佛乡众多人马中只身救出凤麟君，实力非凡。

而谜独白真实身份为冰楼三王子【百里冰泓】，多年前由金狮帝国返回冰楼途中遭狙杀被敌人所救，但回至冰楼时冰楼已经因阴阳晶元失落而遭封，后来百里冰泓因被人追杀，只好逆转元功保命进入沉眠，因缘际会被叶小钗所救，结下师徒缘分。

谜刀平时被谜独白背于身后，通常只要右手按压谜刀，旋身即能以锋利刀气重创对手，也因此，谜独白常隐身暗处发招让 敌方措手不及，而顺利完成救人、偷袭等任务。

命天荒与笃常舂乘轿于林间遭逢绮罗生与谜独白拦路。

笃常春对上谜独白，钢丝与谜刀交击时迸出万点金光，笃常春见状不敢大意，以钢丝困锁谜刀，施展「翩燕衔杀」沿著丝线而来。

谜独白见状旋身以巧妙身法挣脱束缚，两人再度陷入狂战之中。

此时绮罗生双刀绝学 「雾月双刀斩」尽现华丽招式，使得命天荒颈部与腰部皆受一刀，身首分离而亡。

见同伴身亡的笃常春一时大意，谜独白趁机 以谜刀划伤笃常春肩部，鲜血直流，使笃常春急忙喊退。

后无梦生欲一探玉海九轮盘，请谜独白护阵并独对风暴之阵，谜刀直冲风阵擦出骇人惊鸿，几秒之间谜独白衣著已多处破裂，但丝毫无惧，纵身冲入风刃之中回身破风，可惜风势转变，战况吃紧。

此时疏楼龙宿来到，一助谜独白挺刀再战，两人配合无间，谜刀锋利刀气与龙首华丽一掌破除阵法，狂风因而消散。

未料百里冰泓恢复记忆后，与疏楼龙宿、朝天骄欲追赶可疑的红色龙卷，百里冰泓冲入风网中，不料数道惊鸿迸出，一声惨叫，百里冰泓惨死，只留下白骨与谜刀。

# 一散仙

性格外放阔达，住在妙极山妙极坪妙极洞天的妙极山人，口头禅为妙极，擅使扇拳，由佛入道，为南修真分脉“妙极宗”宗主，手持济公扇一类蒲扇，自诩逍遥人间一散仙。在黑海深狱的黄泉归线侵略扩张苦境时，与还无道主出面助阵对抗蜕变黑后。

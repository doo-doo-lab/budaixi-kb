# 一散仙 (一散仙)
================================================================================

一散仙

性格外放闊達，住在妙極山妙極坪妙極洞天的妙極山人，口頭禪為妙極，擅使扇拳，由佛入道，為南修真分脈「妙極宗」宗主，手持濟公扇一類蒲扇，自詡逍遙人間一散仙。在黑海深獄的黃泉歸線侵略擴張苦境時，與還無道主出面助陣對抗蛻變黑后。

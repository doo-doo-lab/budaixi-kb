# 宿贤卿

================================================================================

## 角色设计

摘自霹雳会月刊第185期封面人物---宿贤卿背景设计宿贤卿看似正派，实则假宗教之名蛊惑人心，并以天刑审判来掩饰暗植的杀手势力，城府谋算之深，让人不敢恭维。曾偷袭叶小钗并夺取瑟龄卷，后败于啸日猋、失路英雄、悟剑声三人联手，被素还真以封神指封住功体，送至云鼓雷峰囚禁，实则是卧底于云鼓雷峰，助号天穷夺得涤罪犀角。末世圣传瓦解之后，感念复活的叶小钗不计较当日杀身之仇，投效叶小钗麾下。造型设计宿贤卿以宽身大袍代表宿贤卿在末世圣传中的神圣地位，稳重、严肃。头上的冠冕是人间至高的象征，代表宿贤卿在教派中是拥有权力的领袖。稳重的长袍，紫色代表尊贵，白色代表圣洁。有如国王的冠冕，拥有治理的意义，加上毛毛边以增加时尚感。深色头发中夹带着白色挑染，年龄也代表一种地位。配合教主尊爵不凡的衣着品味，造型师特地打造一双雍容时尚的滚毛边靴子搭配。教徽设计教徽设计教徽的设计属于不对称的圆形，表现运转流动之意，日月星三个图案也做大小渐次变化，好比观测天象时，星体也有距离远近之分。中间圆形是以气运太极结合日月星三元素产生，外围圆形代表两种意思，一为时序运转，二为传达信仰。末世圣传崇拜天君但不作神像，信仰的力量在自然界中无所不在，教徽的设计即以自然界中最神秘的星辰为主。宿贤卿的诗号头尾相接，无论从哪一句念，都能相通，如同圆形教徽生生不息，象征自然界的循环。场景设计十真掌天殿场景设计上下颠倒的建筑，底部设计成双手支撑，其含义为“真理即在双掌十指之中”，顶楼为宽阔平台，居高临下，并设立一座钟塔，在剧中以钟声衬托浓厚的宗教气氛。上下颠倒的建筑在霹雳剧集中亦是首次登场。

## 角色配乐

末世圣传（宿贤卿）宿贤卿曲/编曲：黄建秦；收录于《霹雳经武纪之枭皇论战剧集原声带》此曲为黄建秦老师为宿贤卿量身定做的一首乐曲，以大量西洋人声和声搭配神秘音乐，呈现出清圣又带神秘感的精彩乐曲。末世圣传（末世圣传场景曲）曲/编曲：孙敬凡；收录于《【霹雳英雄音乐精选三十】枭皇论战剧集原声带贰》以古典庄严曲风营造宗教信仰的神秘感，在霹雳布袋戏中是较少出现的类型，也因此令人印象深刻。本曲以人声合唱为主角，层层相叠的人声，代表信众的虔诚信仰，包涵各种高低音域。声调在平和中带着坚定，偶尔出现的钟声则像是要敲醒仍在混沌中迷惘的人们。在乐器的配置上，则以管风琴、大键琴、定音鼓、钟声与弦乐，配合慢板的节奏，呈现出叫内平静宁和的气氛。

## 角色评价

宿贤卿，善谋能断，处变不惊，早期为使天君脱离禁锢壮大末世圣传，宿贤卿无所不用其极，但观看其与易春寒和易秋颜的相处，宣天总教亦非铁石心肠之人。虽然苦心经营的末世圣传仍是难逃自取灭亡一途，但在人生的终点之前，宿贤卿仍是倾心而活，不枉江湖一遭。

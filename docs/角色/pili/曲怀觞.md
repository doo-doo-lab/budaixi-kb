# 曲怀觞 (曲怀觞)
================================================================================

曲怀觞

北窗伏龙曲怀觞，蛰伏于碧玄草堂的隐逸高士，仪态优雅、英姿潇洒，具有操控植物之能。因受好友素还真之托，借其魂魄寄体，让素还真得以白忘机名义周旋识界与正道，多方斡旋布局，力阻魔界摧毁神州支柱。神州大地接合后，素还真魂魄离体，始恢复曲怀觞身份。

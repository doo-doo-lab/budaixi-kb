# 忆秋年

================================================================================

霹雳布袋戏虚拟人物忆秋年，霹雳布袋戏虚拟人物。虽有年纪却永保赤子之心的一代剑法宗师。温和斯文、豁达的人生观，对世事采取随遇而安的态度。剑术已达到随心所欲人剑合一的境界，与风之痕因切磋剑法进而成为知己之交；富有侠义之心，对于后辈的提携不遗余力。曾蝉联三届论剑海剑术第一人之冠，亦是封剑塔登顶剑者之首。

**中文名**：忆秋年

**别名**：剑痞、忆老、好友（风之痕称）、老头（洛子商称）、前辈（正道群侠尊称）

**配音**：黄文择、刘若班（普通话）

**性别**：男

**登场作品**：霹雳图腾霹雳异数之龙图霸业霹雳劫之阇城血印霹雳狼烟之万堺尘涛霹雳兵涛

**生日**：2001年

**年龄**：千岁以上

**星座**：双子座

**根据地**：步云崖爱 徒洛子商挚 友风之痕成 就论剑海蝉联冠座、封剑塔登顶剑者

**武器**：金子陵之剑

**初登场**：霹雳图腾 第15集

**退场**：霹雳异数之龙图霸业 第29集

**角色编剧**：黄强华（赐名）、廖明智（原创）、罗陵（接手）

**本尊雕偶师**：苏轩宾

**出场集数**：42集（含回忆、幻象）定 位布袋戏中的剑界标杆角色

## 经历
剑痞·忆秋年，剑界传说级别的宗师，与剑界神话魔流剑·风之痕为知己之交，对爱徒儿洛子商亦师亦父亦友。

平日喜爱逍遥山水、游戏人间，个性洒脱豁达、随遇而安。

时值中原情势危急之际，内有七星祸乱，外有魔剑道虎视眈眈，上古七星之主天策真龙借紫星眉躯体重生，混战之际，一页书意外受困引灵山，中原群侠亦受到重创。

之后素还真遭逼杀逃到引灵山，自爆经脉做出最后反击，随后倒落尘埃。

千钧一发之际，忆秋年出手相助，以高超的速度从天策真龙刀下救走重伤倾危的素还真。

天策真龙震怒，下令贴出皇榜追捕忆秋年。

洛子商恰巧看到皇榜悬赏，便抱着恶作剧的心态，揭下皇榜交给秦假仙，顺便帮忆秋年宣传。

忆秋年为此向洛子商抱怨了一番，但两人言谈中，处处可见师徒间浓厚的情谊。

之后凤形山上，历时漫长的剑痕比试即将得出结果，由忆秋年留下的剑痕率先贯穿试剑石而胜出。

(其后的引灵山之约)忆秋年的目的，实为欲借此救出受困引灵山石壁内的一页书。

另一方面，天策真龙击败四刀四剑，统一武林，于腾龙殿登基为王，并正式向魔剑道宣战。

正道筹备的四刀四剑屠龙失败后，傲笑红尘自责不已，意志消沉之际，来到步云崖会见忆秋年。

忆秋年开导迷惘的傲笑红尘，让他认清自己的缺失之处。

腾龙殿与魔剑道情势紧张，战局一触即发。

仅有五星入体的天策真龙为提升实力，急欲寻找剩余二星的下落。

为保住化星潇潇的性命，又能使星灵回归天策真龙本体，忆秋年指点佾云带潇潇前往十转轮回峰，移转星灵。

万里江畔，腾龙殿与魔剑道会师大战，天策真龙误中诱敌之计，在天绝狭道遭魔剑道大军围困，情况危急，此时化星星灵成功从潇潇身上脱离，吸纳六星之力的天策真龙从颓势中扭转战况。

另一方面，引灵山上，风之痕与忆秋年留下的剑痕，先后切裂石门，使得幽灵马车得以冲破石门，进入山洞救走一页书。

天策真龙因化星影响，个性转变为仁慈，便与魔剑道订立和平条约。

然而此举仅换得六个月短暂的平静，随着诛天的首级被挂在公开亭示众，中原与魔剑道之间纷争再起。

为寻杀害诛天的嫌疑者——独孤遗恨，秦假仙前往吊黄泉拜访独孤遗恨之好友冥河画匠。

秦假仙将见到冥河画匠所绘之图告知洛子商，洛子商好奇心起前往观看，但对于画作预言死亡之说丝毫无动于衷。

离开吊黄泉后，洛子商旋即遭遇策谋略所派出的面具杀手黑鹰拦路截杀，不幸命丧黄泉。

忆秋年回到玉篱园，却见爱徒首级，震惊悲痛不已。

忆秋年忆秋年将徒儿的遗骸一一拼凑拾回，表面上虽平静，内心却已是波涛汹涌。

照世明灯与步双极前来告知凶手的线索。

为换回爱徒的生机，忆秋年以半强迫的手段，委托好友舒石公，以自身根基为代价，让洛子商复活。

此亦埋下了忆秋年日后命丧乾坤陵的近因。

至此，忆秋年已明白有阴谋家在针对自己与风之痕二人，遂提酒找风之痕共饮一解愁闷。

忆秋年亦表达自己追查到底的决心。

为报杀徒之仇，忆秋年一招击败杀手黑鹰，欲追查幕后主使者。

追踪线索途中，忆秋年却遭到气流异变所阻而失败。

之后，诛天尸身已被移入乾坤陵，忆秋年为寻乾坤陵之钥而前往波涛海，却在海中遭遇众多黑衣杀手攻击。

因水压牵制，忆秋年难以发挥绝招，遂以内力引动水流，击杀所有黑衣人。

忆秋年确定波涛海内并无乾坤陵之钥，便回到孤独峰与风之痕商议。

秦假仙等人从冥河画匠之处取得一幅可疑的画像（策谋略），并冠上阴谋家之名大肆宣传。

为揪出幕后主使者，忆秋年与风之痕等人围捕冥河画匠。

此时定风愁现身，揭破此乃策谋略诡计，并带忆秋年、风之痕前往策谋略真正的根据地——恶灵鬼谷。

恶灵鬼谷内，风之痕决杀策谋略，策谋略最终死于风之痕剑下，众人却不知此策谋略仅是分身。

阴谋者伏诛，风浪平息，风之痕萌生退隐之意。

然而忆秋年仍挂心诛天之死的真相，因此暂时告别风之痕，独自前往乾坤陵调查，却不知此举已踏入了策谋略连环杀计中的最后一步。

暗处的策谋略于此时启动术法，将忆秋年困于乾坤陵中，黑衣杀手一涌而出，忆秋年无法发挥速度与剑气，加之牺牲大半功体复活洛子商，顿时受创。

伤重的忆秋年运出绝式，击杀所有黑衣人和鬼神六恶诛。

然而策谋略的杀招紧逼而来，恍然大悟的忆秋年奋力击出最后一剑，尽灭鬼神六恶诛与重创策谋略，终是伤重力尽，遗世而去。

策谋略在忆秋年的尸身上施以咒术，并将尸身送至孤独峰，企图暗算风之痕。

骤见的难以置信与哀恸，化作悲狂的怒吼，震撼了整座孤独峰。

忆秋年用最后一口真气留下乾坤陵内得到的线索，以警示风之痕。

风之痕痛失挚友，再也压抑不住激动的情绪，立誓找出真凶报仇。

忆秋年之逝，留给正道众人无限悲伤与追思，也在戏迷心中刻画下难以磨灭的痕迹。

综观忆秋年一生，为维护武林和平尽心奔走，对提携后辈更是不遗余力，堪称真正的一代剑界宗师。

回顾武林过往云烟，总是会忆起曾有过这一位似高人又似顽童、潇洒不羁、风采翩然的——剑痞·忆秋年。

憶秋年

憶秋年，霹靂布袋戲經典人物。雖有年紀卻永保赤子之心的一代劍法宗師。溫和斯文、豁達的人生觀，對世事採取隨遇而安的態度。劍術已達到隨心所欲人劍合一的境界，與風之痕因切磋劍法進而成為知己之交；富有俠義之心，對於後輩的提攜不遺餘力。曾蟬聯三屆論劍海劍術第一人之冠，亦是封劍塔登頂劍者之首。憶秋年劍術造詣出神入化、無人能及，但從不恃才傲物，對待他人總是真心付出，曾指點傲笑紅塵破除自身心結，在素還真遭逢引靈山大劫時出手相救，為了武林和平盡心盡力，人品亦是受到中原群俠與戲迷們的讚譽與崇拜。

退場：霹靂異數之龍圖霸業 第29集（犧牲自身大半的功體復活洛子商，後中策謀略之詭計，以人海戰術圍殺憶秋年，憶秋年身處真空無法提力，功體不全亡於乾坤陵之內）根據地：步雲崖人際關係所救之人：一頁書（同風之痕二人以劍氣貫穿石壁救出一頁書）、素還真（從天策真龍手下輕鬆救走素還真）、瀟瀟、傲笑紅塵、蔭屍人、夕月村村民（當年夕月村被毀，憶秋年出財資助當地百姓開店）等人物能力武學：隨風點穴、血光旋刃、如臨秋意、一任秋月、劍舞秋風、秋洵薰心、憶·秋思化刃、逍遙秋風劍境：人劍合一（聽得劍聲呼吸，忘我忘念，以念化劍，以劍行意，玄同太子對其劍境的點評）武器：金子陵之劍（名劍鑄手為其量身打造，但並無取名，劇中也從無使用，只在憶秋年的角色寫真「秋聲」中出現）所獲榮譽：苦境劍界代表性人物、劍界雙巔之一人物經歷劍痞·憶秋年，劍界一代傳說宗師，與魔界第一劍者魔流劍·風之痕為知己之交，對愛徒兒洛子商亦師亦父亦友。

平日喜愛逍遙山水、遊戲人間，個性灑脫豁達、隨遇而安。

時值中原情勢危急之際，內有七星禍亂，外有魔劍道虎視眈眈，上古七星之主天策真龍借紫星眉軀體重生，混戰之際，一頁書意外受困引靈山，中原群俠亦受到重創。

之後素還真遭逼殺逃到引靈山，自爆經脈做出最後反擊，隨後倒落塵埃。

千鈞一髮之際，憶秋年出手相助，以高超的速度從天策真龍刀下救走重傷傾危的素還真。

天策真龍震怒，下令貼出皇榜追捕憶秋年。

洛子商恰巧看到皇榜懸賞，便抱著惡作劇的心態，揭下皇榜交給秦假仙，順便幫憶秋年宣傳。

憶秋年為此向洛子商抱怨了一番，但兩人言談中，處處可見師徒間濃厚的情誼。

之後鳳形山上，歷時漫長的劍痕比試即將得出結果，由憶秋年留下的劍痕率先貫穿試劍石而勝出。

(其後的引靈山之約)憶秋年的目的，實為欲藉此救出受困引靈山石壁內的一頁書。

另一方面，天策真龍擊敗四刀四劍，統一武林，於騰龍殿登基為王，並正式向魔劍道宣戰。

四刀四劍屠龍失敗，傲笑紅塵自責不已，意志消沉之際，來到步雲崖會見憶秋年。

憶秋年開導迷惘的傲笑紅塵，讓他認清自己的缺失之處。

騰龍殿與魔劍道情勢緊張，戰局一觸即發。

僅有五星入體的天策真龍為提升實力，急欲尋找剩餘二星的下落。

為保住化星瀟瀟的性命，又能使星靈回歸天策真龍本體，憶秋年指點佾雲帶瀟瀟前往十轉輪迴峰，移轉星靈。

萬里江畔，騰龍殿與魔劍道會師大戰，天策真龍誤中誘敵之計，在天絕狹道遭魔劍道大軍圍困，情況危急，此時化星星靈成功從瀟瀟身上脫離，吸納六星之力的天策真龍從頹勢中扭轉戰況。

另一方面，引靈山上，風之痕與憶秋年留下的劍痕，先後切裂石門，使得幽靈馬車得以衝破石門，進入山洞救走一頁書。

天策真龍因化星影響，個性轉變為仁慈，便與魔劍道訂立和平條約。

然而此舉僅換得六個月短暫的平靜，隨著誅天的首級被掛在公開亭示眾，中原與魔劍道之間紛爭再起。

為尋殺害誅天的嫌疑者——獨孤遺恨，秦假仙前往吊黃泉拜訪獨孤遺恨之好友冥河畫匠。

秦假仙將見到冥河畫匠所繪之圖告知洛子商，洛子商好奇心起前往觀看，但對於畫作預言死亡之說絲毫無動於衷。

離開弔黃泉後，洛子商旋即遭遇策謀略所派出的面具殺手黑鷹攔路截殺，不幸命喪黃泉。

憶秋年回到玉籬園，卻見愛徒首級，震驚悲痛不已。

憶秋年憶秋年將徒兒的遺骸一一拼湊拾回，表面上雖平靜，內心卻已是波濤洶湧。

照世明燈與步雙極前來告知兇手的線索。

為換回愛徒的生機，憶秋年以半強迫的手段，委託好友舒石公，以自身根基為代價，讓洛子商復活。

此亦埋下了憶秋年日後命喪乾坤陵的近因。

至此，憶秋年已明白有陰謀家在針對自己與風之痕二人，遂提酒找風之痕共飲一解愁悶。

憶秋年亦表達自己追查到底的決心。

為報殺徒之仇，憶秋年擊敗殺手黑鷹，欲追查幕後主使者。

追蹤線索途中，憶秋年卻遭到氣流異變所阻而失敗。

之後，誅天屍身已被移入乾坤陵，憶秋年為尋乾坤陵之鑰而前往波濤海，卻在海中遭遇眾多黑衣殺手攻擊。

因水壓牽制，憶秋年難以發揮絕招，遂以內力引動水流，擊殺所有黑衣人。

憶秋年確定波濤海內並無乾坤陵之鑰，便回到孤獨峰與風之痕商議。

秦假仙等人從冥河畫匠之處取得一幅可疑的畫像（策謀略），並冠上陰謀家之名大肆宣傳。

為揪出幕後主使者，憶秋年與風之痕等人圍捕冥河畫匠。

此時定風愁現身，揭破此乃策謀略詭計，並帶憶秋年、風之痕前往策謀略真正的根據地——惡靈鬼谷。

惡靈鬼谷內，風之痕決殺策謀略，策謀略最終死於風之痕劍下，眾人卻不知此策謀略僅是分身。

陰謀者伏誅，風浪平息，風之痕萌生退隱之意。

然而憶秋年仍掛心誅天之死的真相，因此暫時告別風之痕，獨自前往乾坤陵調查，卻不知此舉已踏入了策謀略連環殺計中的最後一步。

暗處的策謀略於此時啟動術法，將憶秋年困於乾坤陵中，黑衣殺手一涌而出，憶秋年無法發揮速度與劍氣，頓時受創。

傷重的憶秋年運出絕式，擊殺所有黑衣人。

然而策謀略的殺著緊逼而來，恍然大悟的憶秋年奮力擊出最後一劍，盡滅鬼神六惡誅與重創策謀略，終是傷重力盡，遺世而去。

策謀略在憶秋年的屍身上施以咒術，並將屍身送至孤獨峰，企圖暗算風之痕。

驟見的難以置信與哀慟，化作悲狂的怒吼，震撼了整座孤獨峰。

憶秋年用最後一口真氣留下乾坤陵內得到的線索，以警示風之痕。

風之痕痛失摯友，再也壓抑不住激動的情緒，立誓找出真兇報仇。
憶秋年之逝，留給正道眾人無限悲傷與追思，也在戲迷心中刻畫下難以磨滅的痕跡。

綜觀憶秋年一生，為維護武林和平盡心奔走，對提攜後輩更是不遺餘力，堪稱真正的一代劍界宗師。

回顧武林過往雲煙，總是會憶起曾有過這一位似高人又似頑童、瀟灑不羈、風采翩然的——劍痞·憶秋年。

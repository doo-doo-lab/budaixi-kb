# 忆秋年

================================================================================

霹雳布袋戏虚拟人物忆秋年，霹雳布袋戏虚拟人物。虽有年纪却永保赤子之心的一代剑法宗师。温和斯文、豁达的人生观，对世事采取随遇而安的态度。剑术已达到随心所欲人剑合一的境界，与风之痕因切磋剑法进而成为知己之交；富有侠义之心，对于后辈的提携不遗余力。曾蝉联三届论剑海剑术第一人之冠，亦是封剑塔登顶剑者之首。

**中文名**：忆秋年

**别名**：剑痞、忆老、好友（风之痕称）、老头（洛子商称）、前辈（正道群侠尊称）

**配音**：黄文择、刘若班（普通话）

**性别**：男

**登场作品**：霹雳图腾霹雳异数之龙图霸业霹雳劫之阇城血印霹雳狼烟之万堺尘涛霹雳兵涛

**生日**：2001年

**年龄**：千岁以上

**星座**：双子座

**根据地**：步云崖爱 徒洛子商挚 友风之痕成 就论剑海蝉联冠座、封剑塔登顶剑者

**武器**：金子陵之剑

**初登场**：霹雳图腾 第15集

**退场**：霹雳异数之龙图霸业 第29集

**角色编剧**：黄强华（赐名）、廖明智（原创）、罗陵（接手）

**本尊雕偶师**：苏轩宾

**出场集数**：42集（含回忆、幻象）定 位布袋戏中的剑界标杆角色

## 经历
剑痞·忆秋年，剑界传说级别的宗师，与剑界神话魔流剑·风之痕为知己之交，对爱徒儿洛子商亦师亦父亦友。

平日喜爱逍遥山水、游戏人间，个性洒脱豁达、随遇而安。

时值中原情势危急之际，内有七星祸乱，外有魔剑道虎视眈眈，上古七星之主天策真龙借紫星眉躯体重生，混战之际，一页书意外受困引灵山，中原群侠亦受到重创。

之后素还真遭逼杀逃到引灵山，自爆经脉做出最后反击，随后倒落尘埃。

千钧一发之际，忆秋年出手相助，以高超的速度从天策真龙刀下救走重伤倾危的素还真。

天策真龙震怒，下令贴出皇榜追捕忆秋年。

洛子商恰巧看到皇榜悬赏，便抱着恶作剧的心态，揭下皇榜交给秦假仙，顺便帮忆秋年宣传。

忆秋年为此向洛子商抱怨了一番，但两人言谈中，处处可见师徒间浓厚的情谊。

之后凤形山上，历时漫长的剑痕比试即将得出结果，由忆秋年留下的剑痕率先贯穿试剑石而胜出。

(其后的引灵山之约)忆秋年的目的，实为欲借此救出受困引灵山石壁内的一页书。

另一方面，天策真龙击败四刀四剑，统一武林，于腾龙殿登基为王，并正式向魔剑道宣战。

正道筹备的四刀四剑屠龙失败后，傲笑红尘自责不已，意志消沉之际，来到步云崖会见忆秋年。

忆秋年开导迷惘的傲笑红尘，让他认清自己的缺失之处。

腾龙殿与魔剑道情势紧张，战局一触即发。

仅有五星入体的天策真龙为提升实力，急欲寻找剩余二星的下落。

为保住化星潇潇的性命，又能使星灵回归天策真龙本体，忆秋年指点佾云带潇潇前往十转轮回峰，移转星灵。

万里江畔，腾龙殿与魔剑道会师大战，天策真龙误中诱敌之计，在天绝狭道遭魔剑道大军围困，情况危急，此时化星星灵成功从潇潇身上脱离，吸纳六星之力的天策真龙从颓势中扭转战况。

另一方面，引灵山上，风之痕与忆秋年留下的剑痕，先后切裂石门，使得幽灵马车得以冲破石门，进入山洞救走一页书。

天策真龙因化星影响，个性转变为仁慈，便与魔剑道订立和平条约。

然而此举仅换得六个月短暂的平静，随着诛天的首级被挂在公开亭示众，中原与魔剑道之间纷争再起。

为寻杀害诛天的嫌疑者——独孤遗恨，秦假仙前往吊黄泉拜访独孤遗恨之好友冥河画匠。

秦假仙将见到冥河画匠所绘之图告知洛子商，洛子商好奇心起前往观看，但对于画作预言死亡之说丝毫无动于衷。

离开吊黄泉后，洛子商旋即遭遇策谋略所派出的面具杀手黑鹰拦路截杀，不幸命丧黄泉。

忆秋年回到玉篱园，却见爱徒首级，震惊悲痛不已。

忆秋年忆秋年将徒儿的遗骸一一拼凑拾回，表面上虽平静，内心却已是波涛汹涌。

照世明灯与步双极前来告知凶手的线索。

为换回爱徒的生机，忆秋年以半强迫的手段，委托好友舒石公，以自身根基为代价，让洛子商复活。

此亦埋下了忆秋年日后命丧乾坤陵的近因。

至此，忆秋年已明白有阴谋家在针对自己与风之痕二人，遂提酒找风之痕共饮一解愁闷。

忆秋年亦表达自己追查到底的决心。

为报杀徒之仇，忆秋年一招击败杀手黑鹰，欲追查幕后主使者。

追踪线索途中，忆秋年却遭到气流异变所阻而失败。

之后，诛天尸身已被移入乾坤陵，忆秋年为寻乾坤陵之钥而前往波涛海，却在海中遭遇众多黑衣杀手攻击。

因水压牵制，忆秋年难以发挥绝招，遂以内力引动水流，击杀所有黑衣人。

忆秋年确定波涛海内并无乾坤陵之钥，便回到孤独峰与风之痕商议。

秦假仙等人从冥河画匠之处取得一幅可疑的画像（策谋略），并冠上阴谋家之名大肆宣传。

为揪出幕后主使者，忆秋年与风之痕等人围捕冥河画匠。

此时定风愁现身，揭破此乃策谋略诡计，并带忆秋年、风之痕前往策谋略真正的根据地——恶灵鬼谷。

恶灵鬼谷内，风之痕决杀策谋略，策谋略最终死于风之痕剑下，众人却不知此策谋略仅是分身。

阴谋者伏诛，风浪平息，风之痕萌生退隐之意。

然而忆秋年仍挂心诛天之死的真相，因此暂时告别风之痕，独自前往乾坤陵调查，却不知此举已踏入了策谋略连环杀计中的最后一步。

暗处的策谋略于此时启动术法，将忆秋年困于乾坤陵中，黑衣杀手一涌而出，忆秋年无法发挥速度与剑气，加之牺牲大半功体复活洛子商，顿时受创。

伤重的忆秋年运出绝式，击杀所有黑衣人和鬼神六恶诛。

然而策谋略的杀招紧逼而来，恍然大悟的忆秋年奋力击出最后一剑，尽灭鬼神六恶诛与重创策谋略，终是伤重力尽，遗世而去。

策谋略在忆秋年的尸身上施以咒术，并将尸身送至孤独峰，企图暗算风之痕。

骤见的难以置信与哀恸，化作悲狂的怒吼，震撼了整座孤独峰。

忆秋年用最后一口真气留下乾坤陵内得到的线索，以警示风之痕。

风之痕痛失挚友，再也压抑不住激动的情绪，立誓找出真凶报仇。

忆秋年之逝，留给正道众人无限悲伤与追思，也在戏迷心中刻画下难以磨灭的痕迹。

综观忆秋年一生，为维护武林和平尽心奔走，对提携后辈更是不遗余力，堪称真正的一代剑界宗师。

回顾武林过往云烟，总是会忆起曾有过这一位似高人又似顽童、潇洒不羁、风采翩然的——剑痞·忆秋年。

退场：霹雳异数之龙图霸业 第29集（牺牲自身大半的功体复活洛子商，后中策谋略之诡计，以人海战术围杀忆秋年，忆秋年身处真空无法提力，功体不全亡于乾坤陵之内）根据地：步云崖人际关系所救之人：一页书（同风之痕二人以剑气贯穿石壁救出一页书）、素还真（从天策真龙手下轻松救走素还真）、潇潇、傲笑红尘、荫尸人、夕月村村民（当年夕月村被毁，忆秋年出财资助当地百姓开店）等人物能力武学：随风点穴、血光旋刃、如临秋意、一任秋月、剑舞秋风、秋洵熏心、忆·秋思化刃、逍遥秋风剑境：人剑合一（听得剑声呼吸，忘我忘念，以念化剑，以剑行意，玄同太子对其剑境的点评）武器：金子陵之剑（名剑铸手为其量身打造，但并无取名，剧中也从无使用，只在忆秋年的角色写真“秋声”中出现）所获荣誉：苦境剑界代表性人物、剑界双巅之一人物经历剑痞·忆秋年，剑界一代传说宗师，与魔界第一剑者魔流剑·风之痕为知己之交，对爱徒儿洛子商亦师亦父亦友。

平日喜爱逍遥山水、游戏人间，个性洒脱豁达、随遇而安。

天策真龙震怒，下令贴出皇榜追捕忆秋年。

四刀四剑屠龙失败，傲笑红尘自责不已，意志消沉之际，来到步云崖会见忆秋年。

忆秋年开导迷惘的傲笑红尘，让他认清自己的缺失之处。

腾龙殿与魔剑道情势紧张，战局一触即发。

仅有五星入体的天策真龙为提升实力，急欲寻找剩余二星的下落。

忆秋年回到玉篱园，却见爱徒首级，震惊悲痛不已。

照世明灯与步双极前来告知凶手的线索。

此亦埋下了忆秋年日后命丧乾坤陵的近因。

忆秋年亦表达自己追查到底的决心。

为报杀徒之仇，忆秋年击败杀手黑鹰，欲追查幕后主使者。

追踪线索途中，忆秋年却遭到气流异变所阻而失败。

为揪出幕后主使者，忆秋年与风之痕等人围捕冥河画匠。

阴谋者伏诛，风浪平息，风之痕萌生退隐之意。

暗处的策谋略于此时启动术法，将忆秋年困于乾坤陵中，黑衣杀手一涌而出，忆秋年无法发挥速度与剑气，顿时受创。

伤重的忆秋年运出绝式，击杀所有黑衣人。

然而策谋略的杀着紧逼而来，恍然大悟的忆秋年奋力击出最后一剑，尽灭鬼神六恶诛与重创策谋略，终是伤重力尽，遗世而去。

骤见的难以置信与哀恸，化作悲狂的怒吼，震撼了整座孤独峰。

忆秋年用最后一口真气留下乾坤陵内得到的线索，以警示风之痕。

风之痕痛失挚友，再也压抑不住激动的情绪，立誓找出真凶报仇。
忆秋年之逝，留给正道众人无限悲伤与追思，也在戏迷心中刻画下难以磨灭的痕迹。

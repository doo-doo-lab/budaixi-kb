# 解天籁
================================================================================

解天籁

道门宗师，乃道真、道玄、道灵之外的道门法宗前主，昔日与佛门法宗、儒门法宗，并为三教审判庭之首，在道门具有崇高的地位。
解天籁为人淡情寡欲，却严守律法，十分有自我原则，言语自信而犀利，往往直破利害所在。历经一巨变后生死不明，人莫知其踪。

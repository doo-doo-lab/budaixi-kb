# 解天籟 (解天籁)
================================================================================

解天籟

道門宗師，乃道真、道玄、道靈之外的道門法宗前主，昔日與佛門法宗、儒門法宗，並為三教審判庭之首，在道門具有崇高的地位。
解天籟為人淡情寡欲，卻嚴守律法，十分有自我原則，言語自信而犀利，往往直破利害所在。歷經一巨變後生死不明，人莫知其蹤。

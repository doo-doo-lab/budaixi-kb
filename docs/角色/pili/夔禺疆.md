# 夔禺疆

霹雳布袋戏虚拟人物夔禺疆，霹雳布袋戏虚拟人物。夔禺疆乃原始魔君与夔后之子，目空一切、阴沉凶险，曾在万魔争锋中力压群雄，遂以枭雄姿态统领幽界，武学根基皆深不可测，又吸收圣母九婴之力使功体突飞猛进，练就九大限魔身，击败白衣剑少、剑非道、任平生等强敌，却在九五之盒的影响下猜忌异己，通过魔渊九熇实施屠城战略，导致与狩宇族、魔吞不动城多方敌对。先被风之痕以叱风剑重创其九大限魔躯，后在纵横子、地茧无限的布局围杀中自尽于天魔殿。

## 人物能力

武学劈神天魔斩、破日贯月·万魔震、魔茧玄熐黩无间、万魔浩劫、魔炼劫世、魔丝天网、祝融魔火、破云贯日、逆魔【无疆劫、寰世诡布、千绝无尽、创邪宇】、吞寰噬宇九大限【幽冥四指·恶邪五爪、焚星禁限、罚月禁限、天地禁限、吞天禁限、灭世禁限、斩日禁限、破天禁限】功体万恶魔身：配合无形魔丝拥有强大的防御力，魔心更能将攻入体内的剑气尽数吸收并化为己用能量。

曾在和剑非道、玉梁皇对战时，被玉梁皇以冥帝之精加成的将军令突袭破解，冥帝紫冥异流入体并一度封锁功力，经过一段时间方得痊愈。

九大限魔躯：吸收九婴黑暗魔能后功力提升修成的至刚至阳之躯，功体威能更远胜万恶魔身，催动功力至极时双手会变化为狰狞魔爪，夔禺疆的九大限威能更胜九大限原主九婴，但弱点则是至阴的冰寒武学。

九大限魔躯被风之痕用叱风剑断刃重招正面击破，留下致命的死门缺口，后只修复了外层伤势，内部仍残留叱风剑劲伤害，被剑非道以冰寒剑招偷袭，成功攻入风之痕所留的缺口，成功破解其九大限魔躯。

咒术魔式融魂、残念茧蛊、降神火·听吾令（召唤魔渊九熇）特殊能力化孕万魔（吸收融合九婴的黑暗力量后获得的能力）、茧丝防御所有物万恶金丝、九五之盒

# 灭境

================================================================================

霹雳布袋戏术语灭境是霹雳布袋戏中的异空间境界，为佛门高僧梵天一页书的起源地，首次出现于《霹雳劫》至《霹雳天命》系列剧集。

其与苦境结构相似，存在儒道释三教体系，以佛门儒圣派系为主导（该派系创作的明圣天书在苦境广为流传），同时盘踞邪灵一族，地域涵盖灭轮、妖世浮屠等区域，可通过狭道天关等路径与苦境、集境互通。

灭境内佛魔斗争贯穿主线，十三邪灵借助狭道天关逃入苦境后，引发三途判集结，导致儒圣势力受创。

万魔天指掌控灭境后，邪灵一度占据主导，后续佛业双身操纵妖世浮屠试图统合四境，虽未成功但引发异空间格局剧变。

灭境历史分为两阶段：初期以慈航渡、灭境三天等佛门人物为核心（明圣天书即出自灭境三天之手），后期随素还真重返灭境，卧佛一枕眠与邪灵未来之宰等新势力登场，佛业双身最终成为贯穿多境危机的核心反派。

中文名灭境来源出处霹雳布袋戏出现时间霹雳劫——霹雳天命 、霹雳神州之苍玄泣——霹雳震寰宇之兵甲龙痕定 义霹雳布袋戏中的异空间境界

## 人物

灭境代表人物名称介绍梵天灭境三天之一，久远前以“佛言枷锁”囚困业途灵，后去苦境化身一页书。众天灭境三天之一，收流落灭境的素续缘为徒，授其不凡圣功，平息邪灵祸世之劫。狡突脸灭境三途判之一，与灭境三天不两立，后逃到苦境化身鬼王棺。凤凰鸣灭境隐世高人，身背天卷，腰悬尺八洞箫，能御卷行天，仙风道骨，与卧佛一枕眠并称灭轮双擘。未来之宰灭境邪灵之首，雄才大略，企图以破坏构筑属于自己的未来国度，将儒圣佛道消灭，久远前被海殇君阻止。佛业双身乃天生与佛对抗的邪灵业障，以四境合一为终极目标，其偏激的理念势将造成无止尽的浩劫。曾遭梵天与九界佛皇联手击败，藏身灭境深处的穷阴迷巢，在吸收玄牝之力后，破茧而出。

_灭境_'是霹雳布袋戏四境的其中一境，四境分别是苦境、灭境、集境、道境四个。

灭境以佛教为主，而反派的方面，苦境的称之为“魔”，灭境的则称之为“邪灵”。

早期邪灵之首为万魔天指，而后被鬼王棺与素续缘所杀，后来邪灵之首为佛业双身，两人分别是“天蚩极业”与“爱祸女戎”，而后被一页书所杀。

早期的有名的邪灵乃是鬼王棺、业途灵、腹中首，合称“灭境三徒判”，其他还有十三邪灵、表象意魔。但现在鬼王棺不知去向、业途灵改邪归正，信仰佛教、腹中首已死，三徒判已无任何威胁。现在的佛业双身手下也有灭度三宗、十一天禁。

灭境早期的超级魔头问天敌也曾出场过，而后被武君罗喉所杀，一页书为了混进诡龄长生殿也曾伪装成问天敌，当初的问天敌是亡于一页书的天龙吼(千里碎脑神音)，而后复活。

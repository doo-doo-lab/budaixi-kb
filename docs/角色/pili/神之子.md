# 神之子（霹雳布袋戏虚拟人物）

================================================================================

神之子，霹雳布袋戏虚拟人物。死神太学主与神女一夕海棠所生之子，被誉为死国等待千年的救赎。初始婴儿状态，于神眠之间由琴奴以琴声照料，透过天者传达指令，却也隐约察觉天者另有所图。在天者的设计下，神之子被万妖炉所吞噬，并与天者融合成为「冥王啻非天」。后在月声的琴声下，唤醒沉眠的神之子，集死国三魖之力终结天者。

**中文名**：神之子

**外文名**：Shen Zhi Zi

**配音**：黄文择（闽南语）

**性别**：男

**登场作品**：霹雳震寰宇之刀龙传说霹雳震寰宇之龙战八荒

**登场作品**：霹雳震寰宇之兵甲龙痕霹雳经武纪之枭皇论战

**生日**：2009年11月20日（初登场）化 身冥王（与天者融合）

**根据地**：神眠之间

**门派**：死国

## 角色设定

- **名称**: 神之子性别：男初登场：霹雳震寰宇之刀龙传说 第21集退场：霹雳经武纪之枭皇论战 第7集（随天者之死而消亡）化身：冥王（与天者融合）根据地：神眠之间

## 角色经历
死神太学主曾与御天荒神六銖衣、天剑之主叶小钗展开末日决战。

为阻止死神之子诞生，天狼星曾试图决杀神之子生母一夕海棠。

神之子是死神太学主和一夕海棠一夜留情后所怀上的神子，在刀无极照料下顺利诞生，曾引起阎王锁、天狼星、问天敌及天者所遣的阎王祖等人争夺，所幸天生具备死国之神流传之神力，使人无法忍心伤害他，最后在罗喉保护下由君曼睩照料，被众人争夺时由黄泉护送罗喉保护躲避，后被枫岫主人决定送回死国，换取暂时关闭死国和苦境的连接，神之子因而被天者、地者捧为死国领导，由琴奴服侍。

被送入死国后，渐生神智的神之子以稚龄之身透过天者传达出各种命令，甚至包含复活阿修罗建造莫汗走廊、约见无界尊皇、银月贪狼、夜神等，似乎隐约察觉天者另存图谋，但这些命令也叫天者巧言转移目标而多未达成，仅有复活阿修罗一事被落实。

于天葬日月降临之时，因妖世浮屠的冲击死国，神之子受到重创老化，而死国也丧失水、土两大元素，透过天者指示夜神夺取无泪之泪、用练之菁制造的死神双镰修补死国元气。

后来经由笑剑钝持刀无极遗书劝说，首肯与苦境和谈，让地者救回枫岫主人性命，并和一页书正式缔约，互换一滴心血，后来终于顺利见到阿修罗后，一开口便要阿修罗杀死自己，但阿修罗却未答应。

而在天者秘密命令阿修罗制造的万妖炉完工后，被天者携之入内炼化，使天者蜕变成冥王啻非天。

神之子与天者在万妖炉合体后，成为死国创世以来极为强大的生命体，其武力与能量在剧中表现突出，曾一举打败死国战神阿修罗。

合体后的冥王啻非天初登场于《霹雳震寰宇之兵甲龙痕》，退场于《霹雳经武纪之枭皇论战》，被阿修罗、夜神和天狼星联手击杀。

**神之子**為台灣霹靂布袋戲人物，乃是太學主利用一夕海棠所留下的血脈，承有前代死國之神的力量，因而被天者、地者稱作死國等待千年的救贖，登場於霹雳震寰宇之刀龙传说第21集，在霹靂震寰宇之兵甲龍痕第13集被天者帶入萬妖爐煉化吸收，最終於霹靂經武紀之梟皇論戰第7集，因為夜神的貫元一槍成功刺殺冥王啻非天，而消逝於人間。

==人物介紹==
神之子是太學主和一夕海棠一夜留情後所懷上的神子，在刀無極照料下順利誕生，曾引起閻羅王鎖、天狼星、問天敵及天者所遣的閻羅王祖等人爭奪，所幸天生具備死國之神流傳之神力，使人無法忍心傷害他，最後在羅喉保護下由君曼祿照料，於躲避至寒光一舎後<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI53/28.HTM] 霹靂震寰宇之刀龍傳說第28集</ref>，被楓岫主人決定送回死國，換取暫時關閉死國和苦境的連接<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/34.HTM] 霹靂震寰宇之兵甲龍痕第34集</ref>，神之子因而被天者、地者奉為死國領導，由琴奴服侍。

被送入死國後，漸生神智的神之子以稚齡之身透過天者傳達出各種命令，甚至包含復活阿修羅建造莫汗走廊、約見無界尊皇、銀月貪狼、夜神等，似乎隱約察覺天者另存圖謀，但這些命令也叫天者巧言轉移目標而多未達成，僅有復活阿修羅一事被落實。

於天葬日月降臨之時，因妖世浮屠的衝擊死國，神之子受到重創老化，而死國也喪失水、土兩大元素，透過天者指示夜神奪取無淚之淚、用練之菁製造的死神雙鐮修補死國元氣。

後來經由笑劍鈍持刀無極遺書勸說，首肯與苦境和談<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/03.HTM] 霹靂震寰宇之兵甲龍痕第3集</ref>，讓地者救回楓岫主人性命，並和一頁書正式締約，互換一滴心血<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/05.HTM] 霹靂震寰宇之兵甲龍痕第5集</ref>，後來終於順利見到阿修羅後，一開口便要阿修羅殺死自己，但阿修羅卻未答應。

而在天者秘密命令阿修羅製造的萬妖爐完工後，被天者攜之入內煉化，使天者蛻變成冥王啻非天<ref>[http://pilicreateworld.myweb.hinet.net/PILI/PILI55/13.HTM] 霹靂震寰宇之兵甲龍痕第13集</ref>。

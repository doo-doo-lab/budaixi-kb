# 圣母

魔界最具威望的女性，面覆红纱，睿智娴熟、识大体、辨是非，与天魔孕育七十三代玄都金魔，享有极为崇高的地位，毕生致力魔界、正道的和平共处，辅佐天魔不遗余力，乃全魔界的精神支柱。

### 其他纪录

其中含义分为两层。第一层：无头之主为【王】字，月旁之辰是【脉】字，巴望穿眼是【已】字，焚鼎是【火皿】、夜书是【聿】，【聿、火、皿】三字加起来是【尽】字，意思是王脉已尽，暗示金魔的败亡。第二层：第一、二句可以获知仍有机会复兴王室，第三句则暗示需要一名虎将，之后裨善则补充，虎将所指有二，一柔一刚，意指裨善与龙王鱽两人。

# 天地主宰
================================================================================

天地主宰

七大神秘之一，源自谷神玄根的天地异数，系由精、气、神三体融合而成，久远之前，由戾祸、初代邪君、异天魔首次融合成天地主宰，在戾祸主导下，联合荒禘，于五巅之岳对决剑谪仙等人，是役天地主宰因力量不全落败，三体拆分，初代邪君被斩杀，戾祸也被囚禁于黄泉三千丈之下。多年之后，戾祸原身解封，积极谋策再次成就天地主宰，在解天籁的协助之下，一切看似功成在望，不料，最后关头，解天籁意外反扑，算计戾祸、月无缺成为备体，融合成为第二代天地主宰，代表降世天谴，将为玄黄天下，带来不可预测的皂识风暴，重塑神州新秩序。

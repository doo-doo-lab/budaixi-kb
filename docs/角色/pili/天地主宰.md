# 天地主宰 (天地主宰)
================================================================================

天地主宰

七大神秘之一，源自谷神玄根的天地異數，係由精、氣、神三體融合而成，久遠之前，由戾禍、初代邪君、異天魔首次融合成天地主宰，在戾禍主導下，聯合荒禘，於五巔之嶽對決劍謫仙等人，是役天地主宰因力量不全落敗，三體拆分，初代邪君被斬殺，戾禍也被囚禁於黃泉三千丈之下。多年之後，戾禍原身解封，積極謀策再次成就天地主宰，在解天籟的協助之下，一切看似功成在望，不料，最後關頭，解天籟意外反撲，算計戾禍、月無缺成為備體，融合成為第二代天地主宰，代表降世天譴，將為玄黃天下，帶來不可預測的皂識風暴，重塑神州新秩序。

# 獨無意 (独无意)
================================================================================

獨無意

儒門天下的約聘鑄劍師，性格瀟灑隨性又隨意，唯有對鑄劍之道極為斤斤計較和專注。平生喜好四處浪蕩江湖，越荒僻的地方越會想去探索，雖有儒門天下的紫綬龍令，卻經常不理會召喚。如今，卻因獨無意不明失蹤，導致儒門護山神龍驚動，影響儒門甚鉅。

# 独无意
================================================================================

独无意

儒门天下的约聘铸剑师，性格潇洒随性又随意，唯有对铸剑之道极为斤斤计较和专注。平生喜好四处浪荡江湖，越荒僻的地方越会想去探索，虽有儒门天下的紫绶龙令，却经常不理会召唤。如今，却因独无意不明失踪，导致儒门护山神龙惊动，影响儒门甚巨。

# 杜舞雩

================================================================================

霹雳布袋戏虚拟人物杜舞雩是《霹雳布袋戏》系列中的虚拟角色，初登场于《霹雳侠影之轰动武林》第30章，闽南语版由黄文择配音。

作为四奇观中的“风”，独居驭风岛，因剑术超卓被鷇音子列名烽火天榜，称号“一剑风徽”，佩剑古风剑蕴含灭徽死印与烈雨剑谱奥义。

器宇轩昂的剑者虽为烟都大宗师最为忌惮之人，却始终未介入四奇观纷争。

角色身负逆海崇帆“灭徽死印”身份，曾化名祸风行隐匿过往。

因暴雨心奴追查潜欲之门秘密导致身份败露，最终在《轰掣天下》第3章被击杀。

武学包含死印三式与烈雨剑式，诗号取材自《论语》“风乎舞雩”意象。

退场后其角色曲《一剑风徽》收录于《轰定干戈原声带》，相关剧情贯穿《轰动武林》《轰定干戈》《轰掣天下》三部作品。

## 人物设定

名称：杜舞雩本名：一剑燎原祸风行称号：一剑风徽性别：男身份：四大奇观之风、逆海崇帆之灭徽死印诗号：追浴沂之风徽，法舞雩之咏叹，心与剑适，雅与道俱，物我浑一，潇洒忘机。追浴沂之风徽，法舞雩之咏叹，雪消云埋，恨生剑启，烟雨衡天，恩泯仇俱。初登场：霹雳侠影之轰动武林 第30章退场：霹雳侠影之轰掣天下 第3章（死于暴雨心奴，轰霆剑海录第3集于阴间和画眉一起迎接弁袭君同入轮回）根据地：驭风岛

## 人物能力

武学死印三式：暗之界限、暗之极、死之终烈雨剑式：江河行地·烈雨横天、日月沉沦·烈雨当空风之剑式：一剑凌尘、卷龙剑式、流风回雪、剑之神域、死灭之风、燎原之风武器古风剑古风剑：听说大宗师心黑、剑也黑，一剑风徽不落人后，指定道具组要呈现出一剑风徽的色泽感，以暗色系呈现出最近很流行的古朴风格。剑上的六颗珠子，其中三颗代表着死印三式，另三颗所代表的则是创教三人灭徽死印：与一剑风徽的过去息息相关，会浮现于一剑风徽的剑法上，这个神秘图腾，又跟暴雨的祅撒图腾有什么关系呢？

## 人物设计

名号设计杜舞雩一剑风徽杜舞雩的角色命名与诗号，编剧取材自宋濂<桃花涧修褉诗序>中“追浴沂之风徽”，以及《论语·先进》篇“风乎舞雩”一语，但会定此名，最大的功臣却是大宗师！

一切要自编剧构想四奇观之间的交往状况说起，当时故事安排四奇观互有交情，彼此相克，但风之大名实处于尚未萌芽阶段，幸托喜欢穿戴冠帽的大宗师之福，编剧脑中突然浮现了“冠者五六人，童子六七人，浴乎沂，风乎舞雩，咏而归”数语，于是灵机一动，遂以舞雩为名，并以“风徽”此一高洁象征，做为角色名号，希望能呈现角色的剑道修为与人生涵养，但在定调一剑风徽的过去之后，诗号追求的潇洒忘机境界，却反成为真实的他，一生遥不可及——梦想。

造型设计一剑风徽的发色、衣服颜色，是编剧请造型组搭配出专属杜舞雩的风的色系。

非常忧郁的表情，编剧特别选择这个超忧郁的偶头，是代表杜舞雩的故事很忧郁？

肩膀部位使用很抢眼的白色层叠设计。

俐落的古装外挂，其实是可以自由穿脱的。

剧情设计风之归宿杜舞雩杜舞雩一身谜团，可说是紧扣灭徽死印、剑法、与风之归宿三元素发挥。

剧中借由谴弥勒一语“风之归宿，潜欲之门”，将线索导向了驭风岛上的杜舞雩，并透过谴弥勒意外撞见，杜舞雩浮现灭徽死印的一幕，和裳璎珞前往试探的一番暗示言论，以及枯朽老人的明白指认，更逐步将线索导向了谜般的潜欲之门。

长久的隐瞒，让化名一剑风徽的他，迟迟不愿动用的灭徽死印，若非暴雨连番恶行，封徽之风，早不愿重拾过往罪恶之名。

因为对杜舞雩来说，那代表着自己过去在潜欲之门内，位极掌死之尊的血腥回忆。

为此，他从此不欲再杀人，即使被迫取人性命，也总会将剑上鲜血甩落在土，回归大地，渡成点点金华。

暴雨：“潜欲之人啊，这个隐藏身份，让你一剑风徽的身价又抬高了不少。

我有潜欲四印之事，要请教你。

第一、我的地狱阵，与潜欲有何关连？

第二、你在潜欲的地位如何？

第三、潜欲到底是何组织？”在暴雨心奴的追查下，一剑风徽的过去逐渐浮上台面，未来，潜欲之人的身份，是否会让杜舞雩，与交好的北狗等人有所冲突？

被封印的潜欲之门，内中又藏有何种惊天之秘？

场景设计杜舞雩驭风岛天光湖影，水天一色，天地浑同为一。

特意以黄昏色调意象，增加角色的浓愁感。

湖中清晰的倒影令人印象深刻。

凉亭岛上仅有的建筑，一剑风徽常伫立在此，在风中迎接即将到来的江湖纠葛。

## 人际关系

人际目录朋友：烈霖、玄冥氏杜舞雩齐名：玄冥氏、古陵逝烟、朝天骄（四大奇观）上司：鸠神练同伙：弁袭君、梦骸生、千夕颜、符去病恋情：画眉（弁袭君之妹）仇敌：暴雨心奴其他：最光阴（北狗）、浑千手、绝望之刀、天华老者、枯朽老者人际介绍古陵逝烟古陵逝烟同为四奇观，大宗师对一剑风徽不只有救命之恩，更曾经联手将暴雨心奴囚禁，后来大宗师野心浮现，斗垮了朝天骄与玄冥氏，还一度假惺惺的要蒙骗一剑风徽，等到终于瞒不住了，才与一剑风徽正式决裂，但同时大宗师也准备好了暴雨心奴这个两面刃来牵住一剑风徽，趁机暗算，但料想不到，古陵逝烟不是被一剑风徽或暴雨所杀，而是死在自己一手栽培的宫无后剑下（假死，后又重新复出，见霹雳侠影之轰定干戈第32章）。

古陵逝烟浑千手浑千手名列天葬十三刀的鬼盗，本名廉知让，因为屡屡窃取文熙载家中宝物失败，却又蒙受文熙载鼓励而将之视为恩人。

在得到奇遇后，浑千手练得偷取魂魄之术，但恩人已遭灭门，凶手就是暴雨心奴，浑千手想帮恩人报仇，曾偷取其魂魄但失败，后来与一剑风徽、古陵逝烟、黄羽客一起将其监禁。

后来暴雨心奴被古陵逝烟释放，化身魔师太卖汤度日的浑千手成为暴雨心奴下手的目标，幸好一剑风徽及时出现阻止了暴雨。

浑千手暴雨心奴暴雨心奴暴雨本名烈霏，小名心奴，幼时为心疾所苦，难以痊愈，父亲烈霖只好与魔鬼交易，以异法为心奴延命，但是心奴性格偏激，在挑战九千胜失败后，就下落不明，多年后再次出现，创立了祅撒教，并对九千胜展开变态复仇手段，由于作风残暴，被一剑风徽等高手囚禁。

如今暴雨再出，也对一剑风徽展开复仇。

但是暴雨有诡异的十八地狱阵以及不死体质，有什么办法破解？

暴雨调查一剑风徽的过去，会造成什么影响？

(囚禁暴雨后，杜舞雩存放着圈雨井的钥匙，或许等待着暴雨心奴能够改邪归正？)暴雨心奴烈霖烈霖一剑风徽的至交，是烈剑宗主人，剑法高强，不过他修练的烈雨剑法若要达到颠峰，需要以病练剑，因此烈霖长年为病痛所苦，他看重一剑风徽的修为以及两人交情，于是将烈雨剑谱赠之，希望一剑风徽能想出办法，帮忙独生子心奴可以不要带著病痛，也能将烈雨剑法练至顶峰。-

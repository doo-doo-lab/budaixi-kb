# 禳命女

================================================================================

霹雳布袋戏虚拟人物禳命女，霹雳布袋戏虚拟人物。来自四魌界的杀戮碎岛，天生具有特殊的灵疗能力，被雅狄王赐「禳命」之号。气质轻灵，性格外柔内刚，与寒烟翠情同姐妹，因仰慕楔子的文采，对楔子情有独钟。为了追求爱情而不惜牺牲一切来到苦境，由于穿越境界的咒法有限，无意中解救走火入魔的南风不竞，而化为石像。卷入了一段恩怨纠缠的爱恨情仇当中，在苦境找到楔子之化身枫岫后，直承内心思慕，毫不遮掩，是一名直接坦白，且勇于追求所爱的聪慧女子，然则面对南风不竞的强力追求，虽深为苦恼却无法摆脱，在寒烟翠告白之后，四角关系越趋复杂。

## 人物设计

名字缘由禳命女禳命女来自四魌界中的一个神秘国度，编剧将此定位一个异国风味浓厚的地方，与中原传统风格差异大，不但外表造型，名字也要非常特别，之后禳命女将会回到祖国，剧中将有更多当地文化的描述。

禳命女职居高位祭司身份不凡，禳有祭祀、消灾之意，而女字更与禳命女祖国一项重要的传统规定有关，是与生俱来的宿命。

感情挣扎禳命女虽出生上层阶级，但受到传统社会层层束缚，逆来顺受，与寒烟翠相比，禳命女比较像处处受到保护的妹妹，寒烟翠则是扮演坚强姐姐的角色，情同姐妹的情意就在楔子出现以后，慢慢起了变化。

楔子出身慈光之塔，游历四魌界，将见闻写成了一本畅销书，许多人成为了他的书迷，禳命女即是其中一位，楔子的著作让禳命女打开了眼界，使专职祭司的她对外面的世界有更多的认识与憧憬，她更想知道楔子是什么样的人，就这样禳命女已经深陷情网不可自拔，用尽管道与楔子见面。

后来楔子突然杳无音讯，为了追寻，她请姐妹寒烟翠使用秘术，让她前往楔子所在的地方，不料却遇到身陷危机的南风不竞，情急之下，善良的她出手救了南风不竞，却违反秘术契约而化成石像，那一瞬间，她感到了不舍、后悔，今生她再也见不到楔子么？

千万种矛盾思绪凝聚在一滴眼泪之中，等待有一天楔子能够出现。

造型设计石化造型禳命女与寒烟翠一样身份高贵，若寒烟翠是江南大小姐，禳命女就是童话中温柔的公主，是第一位在剧中出现的杀戮碎岛人物，外型就代表了当地的特色。

造型组原本让禳命女穿上红色马甲，不过编剧觉得太过彪悍，在经过修改之后，成为现今观众所看到的形象。

在剧中与禳命女有重大关连的道具就属石像了，禳命女也算是首位以石像登场的角色，石像是由道具组蔡师傅所制作，材质主要是保丽龙，保丽龙经切割后难免有棱有角，必须覆上一层纱布再上漆，才能呈现人体浑圆平滑的效果。

由于当时禳命女只有偶头部分完成造型，所以蔡师傅并没有实际的全身造型可供参考，凭借着与编剧的沟通，以大约一周的时间完成石像，与本尊的外形风格相当相近。

## 编剧漫谈

命运的际遇非常奇妙，不管你要或不要，爱或不爱，人与人之前那条线，总会在不经意的时候，早已吐丝结网，纠结难舍。

情之一路，我以为我总是超然，但终究免不了陷入另一个漩涡。

禳命女已在我身后苦苦追求太久，她为我牺牲甚大，付出许多情份，我这一生对她注定亏欠。

但我还是希望，能为她做点什么。

应该说，我必须为她做点什么。

在很久很久以前，枫岫曾对湘灵动心过。

且不论湘灵有什么才能绝学或是高深的智慧，至少这女孩子所具备的气质，是令人安心且温柔，也是他所喜欢的。

在醉花亭共渡三日，彼此互相欣赏，但枫岫并没有表达出来，也没机会表达，因为他被抓去上天界关了。

从那以后，来到苦境过着另一种生活，当初的动心对他来说只是一个小插曲，日子久了早已云淡风轻。

可是偏偏在这时候，他意外得知湘灵竟追寻他到了苦境，更以外地撞见湘灵的石像，当下心情确实受到影响。

一个女孩子竟然有勇气背离杀戮碎岛，只是为了来找他，怎么可能不令人感动？

湘灵解除石封之后，一再地对枫岫表达爱慕之意，也处处帮助、维护枫岫，这段时间相处下来，枫岫不是瞎子聋子，自然也感动点滴在心。

可是，他依旧选择压抑或推拒。

乱世之下的他有很多事情要做，背负着四魌界之谜，成为反派势力逼杀的对象，他没有办法接受湘灵的感情，没有办法表达自己的感情，因为他不想让湘灵碰上任何危机，不希望湘灵跟随着他，却得面临更大更苦的磨难。

于是，枫岫一直坚守着内心的情绪，并且软硬兼施的一次次拒绝了湘灵。

然而他也只有在面对湘灵时，才会那么生硬。

枫岫与湘灵南风不竞曾问枫岫，是不是对禳命女没有情感。

枫岫略有迟疑，才回答“是”。

这个回答，只不过是在说服自己罢了。

当湘灵遇上危机时，枫岫也难再掩饰内心的着急。

第一次湘灵被抓去地狱口，他和天刀马上赶去谈判。

后来南风不竞在不归路挑战天下，即便是最后一天，枫岫其实可以不用去赴战。

去或不去都是一个选择，不去的话，也未必没有转圜。

当时极道先生不明白枫岫为何这么做？

一言以蔽之，答案就是“情债难还”。

枫岫对湘灵的感情有多深，在与南风不竞最后一战可见端倪。

忘了在哪里看过一句话：“我们都只能凭着当时的智慧，选择以为最好的路走。” 然而，一个人心念之强大，却往往可以胜过自己本身。

仅仅只要一个心念，整个人生都可能因此改变。

枫岫面对南风不竞的一章，耳闻鸡鸣之声，重伤的他脑海里也瞬间空白了。

可在那空白的一瞬，却跑出湘灵的身影，那是枫岫深深埋藏在心里的一个秘密。

在这千钧一发时刻，秘密无法再隐藏，湘灵注定是他生命里的一个缺憾。

于是在那瞬间，枫岫的心念便是不再抗拒。

很多人觉得枫岫怪，认为这不像他，他不应该会放弃生命。

可是，枫岫再怎么坚强，他始终是个人，曾受伤会难过，他的心里确实是够坚强，但是再怎么坚强也总有软弱的一刻，而这，就是那时刻，让枫岫彻底放纵了。

文/编剧：八叉——摘自枫岫主人

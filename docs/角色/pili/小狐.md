# 小狐 (小狐)

小狐

寒煙翠的副體，是一隻頗膽小又愛胡思亂想的大眼狐，常常會自言自語碎念不已，少根筋、愛吐槽，又喜歡打小報告，所以常被寒煙翠修理。其實本性不壞，帶點俏皮、容易受騙，與小免之間的敵我互動，叫人好氣又好笑。

# 小狐

寒烟翠的副体，是一只颇胆小又爱胡思乱想的大眼狐，常常会自言自语碎念不已，少根筋、爱吐槽，又喜欢打小报告，所以常被寒烟翠修理。其实本性不坏，带点俏皮、容易受骗，与小免之间的敌我互动，叫人好气又好笑。

## 人物经历

在龙战八荒第三十四集里，小狐因为寒烟翠纠缠禳命女认为禳命女是个狐狸精会带坏小翠，所以，头脑简单的小狐将毒药刷在自己的牙上，想咬禳命女让她中毒而死，没想到自己却先中毒，却又被禳命女所救幻化成人形。

初到苦境的寒烟翠完成带回禳命女的任务，小狐也随主体返回火宅佛狱，奉王命看守邪思台（藏书馆），却被素还真假扮的白尘子所骗，跑回苦境送药，沦为佛狱通缉犯，无法返回佛狱，只身流浪苦境。

恰逢这段时间佛狱发生重大变故，咒世主战败临死放出其子魔王子。魔王子，嗜杀成性，随心所欲，无丝毫善恶观念，竟然杀死亲父咒世主，又逼死亲妹寒烟翠（小狐主体）。小狐流浪苦境无法返回佛狱，大概不知小翠身亡。

小狐因被素还真所骗，一时气不过，自言自语，跑到悬崖边，碎念要连绝世武功，但看悬崖太深，虽然喊着我要跳下去我要跳下去，脚步却一点一点往后缩，不料又绊石踩空，一头摔下悬崖，还无意获取一神秘之物。之后又巧遇道女灵自灵，灵自灵为了通过考试，找小狐做帮手，小狐被勉强学习书中的道法，与笨帝、卢卡上演有趣的魔法大赛等戏份。

在霹雳惊鸿之刀剑春秋，原为小鬼头发起的三能童子天团，成员为小鬼头、小狐、灵儿。三能为能辩、能视、能心，后来奉丹加入，而成四能童子。编剧特别安排四位可爱的小朋友在三馀身边，提升趣味，这四位小朋友说是聪明伶俐，但也不是很可靠，四能的另一个意思就是罢，要这四位小朋友完成大事业，也罢！三馀无梦生会如何调教这四个小捣蛋呢？四能童子能英勇完成任务，还是捅出大纰漏呢？

在三余消失之后，和小鬼头一起随屈世途暂退，后来两名童子又在素还真身边出现。两个小朋友生性不安分，曾瞒着素还真偷偷下山，替秦假仙去找土晶灵，中了缚地灵咒术。小鬼头的左手中咒，小狐则是头部中咒。虽然两人回到翠环山后素还真为他们解开了咒术，但没过多久咒术的效果却再度重现。

在霹雳开天记之创神篇开头，素还真离开翠环山期间三凶来犯，两小童贸然出山迎敌，离开了素还真设下的法印庇护。小狐被一招断首，而小鬼头被斩下了左手，似乎正应了缚地灵咒术之说。小狐真的会因此退场吗？是否还有重生的希望？

最新剧集已经证实在霹雳开天记之创神篇第一集被断首的小狐和被斩手的小鬼头实际上是素还真以异术为两爱徒转劫而放置于翠环山山门前的两朵纸莲花，喜爱小狐和小鬼头的道友可以松口气了。

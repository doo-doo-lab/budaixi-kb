# 天母圣姬

天母圣姬（天子传奇）

奉女娲娘娘为神，以天下女性为尊的理念创立天母门，雍容华贵、身材曼妙多姿，一曲轻歌曼舞风情艳迷倒众生，世间男子无不拜倒其石榴裙下，因弟子妲己涉入纷乱人世，逐渐展露其野心，心悬天剑与天帝之下落。

## 来自百度百科的补充

### 基本信息（来自百度百科）

天母圣姬是布袋戏《天子传奇开周纪》中的虚拟角色，奉女娲为尊创立天母门，主张女性至上的理念，门派位于海外孤岛天母岛。黄玉郎监制其角色造型，以大红飘仙长裙展现丰腴体态与仙气飘逸形象。

三十年前黑煞帮进攻天母岛全军覆没。其大弟子妲己每年回岛探访并携带财宝，曾为助纣王对抗原始天魔求取天母圣水，并提及九天圣女功第九重天可击败强敌。天母圣姬修习拈花手、飞天锦等武学，与天帝存在爱慕之情，和飞惊子保持暧昧关系，有妹妹玄姬及女儿羽凤。原始天魔与魔尊皆对其颇为忌惮。

天母圣姬于《天子传奇》第35集退场，诗号“凡胎俗体红尘爱，英雄美人现世灾”概括其特质。

### 角色形象

诗号：凡胎俗体红尘爱，英雄美人现世灾；九天云里芙蓉苑，世间男子叩门来。

该角色的造型由黄玉郎监制，于2010年11月曝光。其基本造型为身着大红飘仙长裙，身材丰腴，肌肤如雪。在剧中出场时，常浑身散发七色彩霞，飘然而下，恍如飞仙下凡，呈现奇幻景象。

### 角色能力

武学：拈花手、飞天锦

此外，她还修习更高深的武学。其主修功法为“九天圣女功”，曾突破八重天，据称若练成第九重天便可击败元始天魔。她还掌握由“采阳慑魂术”升华而来的“天仙销魂法”，此法分为“回春法”与“慑魂法”。“回春法”可通过与男子交欢，吸纳其精、气、神以回复青春、提升自身功力，但若对方内力更高则有反噬风险，导致施术者经脉断裂而亡。

所有物：天母圣水，此圣水具有特殊效力，可使饮用者必须与女子交欢。

### 主要经历

在《天子传奇开周纪》故事中，妲己提前一个月回天母岛求取天母圣水以对付元始天魔。天母圣姬当时正在极乐塔内修炼九天圣女功，已突破八重天。她应允了请求并提供圣水，同时向妲己传授天仙销魂法，包括回春法和慑魂法。天母圣姬详细讲解心法与风险，如反噬会导致经脉断裂惨死，并要求妲己今后进贡内功高强的男子以供其修炼回春法以保持青春。

### 人际关系

恋情：天帝（爱慕）、飞惊子（暧昧）

姊妹：玄姬（妹）

儿女 羽凤（女）

其中，弟子妲己与天母圣姬关系密切，妲己每年携财宝回岛探访师尊。天母圣姬曾向妲己传授“天仙销魂法”，并提醒其使用该法对付元始天魔的危险性。

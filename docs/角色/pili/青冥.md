# 浩青冥

霹雳布袋戏虚拟人物浩青冥，霹雳布袋戏虚拟人物。昊法修堂首堂四大剑者之一，受君奉天统辖指点，忠于儒门，性情较年轻气盛，在法儒尊驾君奉天令下，以昊天苍雨阵抵抗血暗结界及幽界魔火肆虐，护全德风古道。

## 人物设定

根据地：昊法修堂

## 人物能力

- **武学**: 昊天苍雨阵、昊天鸣雨阵、昊天凌宇阵、昊天极宇阵武器：霜清剑

## 人际关系

组织门派：德风古道上司：君奉天、玉离经同修：楼千影、尚云冠、向天岳（昊法修堂首堂剑者）；碧瑶觞、极万里、阅寒英、晤江清、俦飞云、羽书平（昊法修堂上堂剑者）同门：疏道谴、赋思韵、凤知几、御钧衡、邃渊、席断虹、邃无端、墨倾池

# 笑流霞

古灵精怪的情报商，身怀奇异道具，以搜集情资，判断情势为乐，时常用万里望镜窥探各方，以存音珍笔纪录情报。因命带流霞煞，自名为笑流霞，更刻意沾酒，不畏血煞，笑看注定命劫。
历经多事，脱离叛魔组织后，正式回归魔族。魔族潜伏休养期间，因奇宝纳戒之故，地冥亲自与之一谈，而后笑流霞再入武林，以十七特工队身份执行任务，专司各路情报搜集以及照顾小瑟斯。

# 笑流霞 (笑流霞)
================================================================================

笑流霞

古靈精怪的情報商，身懷奇異道具，以蒐集情資，判斷情勢為樂，時常用萬里望鏡窺探各方，以存音珍筆紀錄情報。因命帶流霞煞，自名為笑流霞，更刻意沾酒，不畏血煞，笑看注定命劫。
歷經多事，脫離叛魔組織後，正式回歸魔族。魔族潛伏休養期間，因奇寶納戒之故，地冥親自與之一談，而後笑流霞再入武林，以十七特工隊身分執行任務，專司各路情報蒐集以及照顧小瑟斯。

# 华凤奴

================================================================================

霹雳布袋戏中的角色华凤奴，霹雳布袋戏中的角色。苍宇医楼的四名玄医之一，专长以阴阳五行为理论基础的中医学，个性活泼外向，小孩子心性，较为撒泼、不讲理，情绪起伏也较为强烈。代表苍宇医楼出席十擘云集，表明只医不战之立场。中文名华凤奴性 别女登场作品霹雳兵燹之问鼎天下所 属苍宇医楼

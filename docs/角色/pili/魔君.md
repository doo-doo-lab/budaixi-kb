# 原始魔君

================================================================================

霹雳布袋戏虚拟人物原始魔君，霹雳布袋戏虚拟人物。原始幽界之主，传说中的预言魔子，怒发冲冠，盛气凌人，拥有最精纯的魔之骨、肉、血、脉。昔日在精幽大战中身亡，残魂与生命之源结合诞生出「生命练习生」，后在地茧奔波下、与九婴策划中复活。因天证龙战赌约落败，自封幽界，魔君更是一度销声匿迹，此时武林中竟出现一位「飘撇浪子」。中文名原始魔君别 名魔君配 音黄文择（闽南语）、陈启刚（普通话）性 别男登场作品霹雳天命之仙魔鏖锋霹雳天命之仙魔鏖锋Ⅱ斩魔录霹雳天命之战祸邪神霹雳天命之战祸邪神Ⅱ破邪传人物编剧太平

## 人物设定

名称：原始魔君原始魔君化身：飘撇浪子身份：幽界之主、预言魔子诗号：天屈膝，地伏首，人间沦亡，不过只手。神无救，圣唯杀，魔翼之前，终究虚话。初登场：霹雳天命之仙魔鏖锋 第36章（生命之源回归）正式登场：霹雳天命之仙魔鏖锋 第48章（吸收朱雀衣后完全苏醒）退场：霹雳天命之战祸邪神Ⅱ破邪传 第23章（化身飘撇浪子被众天邪王重创身亡）根据地：混沌九穹

## 人物能力

武学：惊天三绝·狂魔炼狱·【罪罚之章、天谴之章】、魔之毁、上魔烈熔掌、鬼嚎枪、左手无生·置腹推心、右掌永劫·寸步难行◎介绍：惊天三绝为魔君绝技，左右手双招为两大成名杀招，左手之招能使心腹扭转，痛苦绝伦，随即阴阳两隔，骨肉分离；右手之招是魔能与异术融合之招，中招者会永受鬼躯所制，陷入永劫不复的境地。机关阵法：六祸禁制（兵、旱、涝、灾、风、妖）所有物：《释魔录》、魔君战印、万魔谕令

## 人际关系

- **组织门派**: 幽界妻子：夔后、九婴、寰灵子女：夔禺疆、无限、朱雀衣结义：剑上缺部属：鬼麒主、剑上缺、剑琅琊、千魔幽旨其他：姬无花、天迹、风之痕相关：生命练习生

## 人物经历

原始魔君是幽界原始之主，实力更胜幽都统治者万魔惊座，并且拥有世上最精纯的魔之骨、肉、血、脉，幽界在其统治期间战力空前强盛。久远之前，魔君曾想通过姬无花拉拢剑界不世神话魔流剑，却遭魔流剑拒绝。精幽大战爆发在即，原始魔君前往邀约剑上缺参战，但剑上缺却完全异变，与魔君在十里葬神关大战三天三夜，致使原始魔君负伤参加精幽大战，而锋魔则彻底失控，远走幽界，在发现自身遭受邪魂附体后自尽边城。精幽大战期间，原始魔君带伤在主战场毕方山与寒武纪、天织主、兽王三大霸主对战，虽然重创三人，但自己也因旧伤未愈和寡不敌众身亡，残魂与生命之源结合诞生出生命练习生，后经地茧无限与圣母九婴将生命练习生的生命之源灌入遗体而复活。原始魔君复活后要吸收无限与朱雀衣之血肉以补全功体，在九婴的帮助下吸收朱雀衣后部分恢复。之后与暗影对赌天证龙战落败，因此自封幽界，暗影不死，幽界不出。暗影因邪魂策王转化为暗禘，魔君闻讯准备启动原始幽界，却在行动之前被天迹所留暗招转化为飘撇浪子，失去记忆。飘撇浪子行走江湖期间多次帮助正道，最终为阻止原始魔君意识再次苏醒而挑战神愆，战中压抑魔君意识导致功体不全，被神愆击败，伤重而死。

原始魔君

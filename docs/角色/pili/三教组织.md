# 三教组织

霹雳布袋戏中的虚拟人物团体三教组织是霹雳布袋戏中的虚构团体，由霹雳佛门、道门、儒门构成。

其最早出现在追究一页书使用天龙吼伤人的七彩云天圣佛岩事件，后续传承由三教先祖其他支系发展。

该组织最初由老佛、圣夫子、道尊三位老教主统领，因百八十年前荒龙道之战对抗魔魁导致菁英尽失。

后因假素还真遭无极殿主金小开鸩杀、青阳子逃亡天地门以及百里抱信死亡等事件，导致旧三教体系崩溃。

九大掌教掌权引发内部分裂，合修会改革失败加速三教衰退。

组织高层包含三圣佛、五儒生、十三道等架构，特殊成员有三教授命者素还真、三传人叶小钗等。

三教主因魔魁血咒成为三魔人后，三传人被赋予以三教秘招终结其使命，但多次对抗未果。

中文名三教组织出现于霹雳布袋戏性 质虚拟人物团体，老教主老佛，圣夫子，道尊

## 霹雳狂刀重要职位

三教老教主为了帮助武道万教免于魔域的屠杀，一百八十年前与第四魔域之主－－－魔魁血战，四人在荒龙道之战后失踪，留下菁英俱丧的三教（详见亢无后幽灵箭计画一事），虽然三教主合力消灭魔魁，却也让其他野心勃勃的万教顺势推翻三教秩序，没有了魔教（泛称魔域四大派），武林反而更乱。

而后老教主再现，却因当年荒龙道一役中被魔魁取去血液，用以下血烙魔咒，三教主成为了三魔人，遭到魔魁之女所操纵，反成为武林大患。

九大掌教三教主失踪后，三教随即被八朝元老、九代令公、三世道君所统领，九人各怀鬼胎，让三教步入衰退期，引起三教之中的第三代菁英不满，促使了以道教强人青阳子为首的“合修会”改革，但因为当世道君的跋扈、九代令公的默许、八朝元老的软弱，三教内血腥大清洗，不论是合修会（改革派）或保守派的菁英俱消失殆尽，三教遂淡出武林。

因为三教之子一案出现，再度出现于武林，却又因为当世道君的跋扈、九代令公的默许、八朝元老的软弱而再次成为武林刽子手，对武林弊大于利，成立霹雳王朝后，又加速内耗。

直到魔魁之女出现后，三教意识到必须团结，然而当世道君、圣贤诸怀有异心，老教主再现，反而成为三魔人，被魔魁之女所操纵，三教不论人才、号召力均跌停板，甚至于逐出要杀死三教主的三传人。

由因果来、百里抱信、青阳成为战后新掌教。

面对欧阳世家与无极殿的再兴，外强中干的三教被攻城掠地，败如水银泻地，因果来战败后不知所踪，道教几乎全灭，青阳遁入天地门，忍辱负重卧底的百里抱信被杀，老三教终结。

## 高层领导

三圣佛七彩云天主事，庸碌无能，地藏大如反被合修会渗透，一度造成武林混乱。五儒生南宫布仁、欧阳上智（欧阳胜天冒名）是豺狼之辈，无恶不作。司徒守义（骨董）为友复仇，决定杀死欧阳胜天，因而破门出教。上官知礼，唯一克礼复己的人，但是实力太差。百里抱信，原为投机者，女扮男装，最后因为喜欢素还真而选择为正道而战。十三道有忠有奸，有贤有愚，合修会一战后忠诚者几乎全死，而好人玄真君、照世明灯（明真君）等人又被当世道君所忌。天残武祖在剧中透露，慈海渡者就是十三道之首太真君，可惜无后续剧情发展。玄天六阳十三道的侄辈，反对三世道君的跋扈，引发合修会之乱。后来因为座下菁英俱亡，合修会腐败，被三教联盟再次收编。

## 特殊份子

三教授命者素还真，依三教主所托，压制武道万教群起作乱，以及消灭魔魁之女。三教押差官拒生郎，负责押解三教重犯，惩奸除恶，却被三教遗忘，但是仍旧为武林和平奋斗至死。三教之子非凡公子，魔魁之女利用三教主之血、三教圣地之灵气，配合魔血与魔气所生的圣魔之子。三传人自知无法抵抗魔魁血咒之三教主，委托素还真所找的三人：叶小钗、剑君十二恨、乱世狂刀，希望此三人能够在三教主入魔时，以三教秘招：般若忏、君子风、天地根将其杀死。后来对抗三魔人失败，招致三教罢黜；对抗魔魁亦未尽全功。

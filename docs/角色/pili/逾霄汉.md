# 逾霄汉

================================================================================

台湾布袋戏《金光御九界之墨武侠锋》角色逾霄汉是金光布袋戏《金光御九界之墨武侠锋》中的虚拟人物，地门四大天护之一。别名“云间独步”，佩刀“疏瀹”，诗号“傲视千山，古往今来登霄汉。尘心疏瀹，白衣苍狗尽云间”。原为佛国苦行法门修者，后失踪加入地门。受命夺取紫金钵时遭梵海惊鸿、锦烟霞阻击失败，其身份从佛国守护者沦为地门傀儡天护。虽与独眼龙、留羽、白绮为旧友却因立场对立，最终为对抗元邪皇牺牲，经历折射佛国内部权力斗争与地门扩张野心，成为剧情关键转折点。

## 人际关系

佛国地门上司领袖：大智慧（曾以念荼罗、苍越孤鸣、缺舟一帆渡为肉身）同僚四大天护：藏镜人、千雪孤鸣、独眼龙、逾霄汉、苍越孤鸣（替补藏镜人）部下八关武佐：银娥、真眉、白绮、留羽、牛胜、马衔、方紫、堂朱其他：十法殊胜、十八禅那、三十二具相、幻幽冰剑对手仇敌对手：梵海惊鸿、欲星移仇敌：应龙师

## 角色经历
据停留在天门的地藏师所说，逾霄汉曾是佛国极富名望的高手，原为苦行法门修者，佩刀疏瀹在手无所披靡，后神秘失踪。

在其失踪前，逾霄汉也曾密切关注过天门禁地。

现已加入地门，成为地门四大天护之一，其身份从佛国守护者沦为地门傀儡天护。 大智慧念荼罗在光明殿召集地门四大天护议事时，单独被委派执行夺取紫金钵的任务，但在天门塔林被摩诃尊梵海惊鸿和锦烟霞所阻，导致任务失败。

在地门全面进攻天门之际，再次与梵海惊鸿交手，打伤对方并成功夺取紫金钵。

后与地门群众一同抓拿缺舟一帆渡。

地门降服后，地门全员记忆被恢复，逾霄汉决定与藏镜人四人留下打探元邪皇驻留的魔军情报。

与独眼龙同行遇上了东云武象·应龙师，被其术法所控，独眼龙为解术法答应留下归随应龙师。

会合时与千雪孤鸣碰巧发现了元邪皇的秘密，俩人分逃逾霄汉惨遭杀害，临死前留下了线索，其牺牲旨在揭露地门阴谋。

其经历折射了佛国内部权力斗争与地门扩张野心，成为剧情关键转折点。

# 赤云染

霹雳布袋戏中的角色赤云染，霹雳布袋戏中的角色。玄宗六弦唯一女修道者，雪白束纱、脱俗出众，手持玄妙的三弦之琴，更显气质不凡，为匡助正道对抗异度魔界而现世，配合蔺无双一同抗衡翳流黑派与罪恶坑。

## 角色经历
赤云染  官图图册赤云染，玄宗六弦的女道者，雪白束纱、脱俗出众，手持玄妙的三弦之琴，遂以“三弦道心”自称。

赤云染琴艺高超，三弦之琴奏出动人玄音，既能化肃杀之气消弭无踪，又能操纵音波化为无涛气劲，柔中带刚，一如赤云染给人的印象，婉柔婉约却又显露不凡英气。

随着异度魔界破封再出，道境玄宗、苦境圣域也加入战局，六弦先后步入苦境共抗魔威。

萍山伏魔之战，赤云染初现尘寰，一道破空弦音解佛剑分说和谈无欲之威，而后更与谈无欲着手调查练峨眉之死，并只身进入魔界据点笑蓬莱一探虚实，临机应变、胆识十足。

因练峨眉之仇，请出世外高人蔺无双，对抗狂龙一声笑和翳流，其为人和气度让赤云染钦佩之余也一度心仪，并从旁协助擒捉醒恶者，无奈落花有意、流水无情而告吹。

蔺无双死后，赤云染回归玄宗，直到异度魔界阴谋曝光，为防止魔界修补断层再出，曾奉命擒捉圆儿、抢夺昊天鼎，但依旧无法改变天意。

同一时分，玄宗叛徒昭穆尊和尹秋君将目标锁定六弦，欲设计除之，赤云染不幸身染毒患，苍虽全力奔波救治，但仍难逃脱昭穆尊魔掌，赤云染和白雪飘双双命丧其手。

## 角色特辑

摘自霹雳会月刊第153期 《天波浩渺·三弦道心──赤云染》赤云染，玄宗六弦中仅一位的女性，擅长乐理，随身以三弦琴为武器，雪白的发丝、细致的五官，红白相衬的衣裙发簪，高贵温雅的同时蕴含着一股不凡的气势，有如一抹气质脱俗的白色水仙，颤巍巍地独秀于大地上，让人眼睛为之一亮。

赤云染一登场便化解了佛剑分说和谈无欲之危，再以伏魔三琴从阎魔旱魃手中救下泊寒波，而后又独自一人前往笑蓬莱试探魔界虚实。

月刊153期  赤云染图册赤云染虽是修真的女道姑，但斯文温良的外表下却别有一番刚强气质，在面对蔺无双的隐匿感情，赤云染用一种温柔细心又动人的谈吐，充分显现出她女性婉约的一面。

赤云染对蔺无双的好感，从相见之初到后来的多次并肩，赤云染这份淡淡幽情不停地成长，所谓关心则乱，先是闯入恶人谷对战狂龙一声笑等；

次而领回练峨眉棺椁回归萍山安葬，她眼见蔺无双自然流露出对练峨眉的默默深情，也让赤云染加深对蔺无双的感怀景仰。

然而，蔺无双也是聪慧之人，他察觉赤云染心情，只好委婉地话中带话，点破这不可能成真的思慕之情。

人一旦动了真感情，就容易失去原本持有的境界，赤云染对蔺无双的暗恋，严格来说也只是人与人相处久了自然流露的天性罢了，就算修仙已臻无心无情的练峨眉，面对为非作歹的弟弟狂龙，还有私下倾慕她的蔺无双，练峨眉也难以绝情绝义。

练峨眉衣冠冢前，蔺无双凄然道出一段与练峨眉的尘封往事，并请赤云染替其弹奏一曲时，赤云染豁然开悟的理性涌上心头，她也只是含蓄婉言后不禁流下一滴伤感的泪。

琴音在萍山上悠扬回绕，纯净柔美，一股空灵、简约的气韵，让天地山水之深邃化去沉郁，也顿时凝结往事的沧桑。

赤云染知时而内敛，不嫉妒的爱是世间最难为的事，赤云染身为一个女性，心情起伏充满生动和敏慧，而且存在着真善与无私，她的善良与胸襟足够让她在孤独中找到其他快乐。

在蔺无双死后，赤云染也带着蔺无双的尸身回到白云山浩然居安葬。

人世间的情感，是否都建立在短暂和稍纵即逝的前提下，才是最让人低徊？

仔细看来，其实蔺无双和赤云染两人的心性都极为相近，双方都是含蓄的情感，意境高超，不需多言、不必多说，在将发未发之间若有若无，这种发乎情止乎礼的修养，可说是君子之交淡如水的最高境界。

人生的转折和变化太多，无论是幽情苦、曲中意，三弦道心赤云染，当知云已渺，唯有梦相随。

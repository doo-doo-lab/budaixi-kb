# 乐行词

================================================================================

霹雳布袋戏虚拟人物乐行词，霹雳布袋戏虚拟人物，诗号为“绝域从军计惘然，东南幽恨满词笺。抒怀一曲，撒酒千川，古来圣贤既已饮，勿为醒者传”。原为御风楼驻唱流浪艺人，与刀悬一命师出同门却不习铸造之术，专研乐武技艺，常以戴墨镜、携二胡的形象行走江湖，性格诙谐幽默。乐行词有一首名为《三阳开泰之御风楼-乐行词》的纯音乐贺年曲，收录于2014年发行的数字版贺岁专辑《霹雳贺新春之感谢发财》中。与御神风交好，被龠胜明峦选为六圣护成员，最终死于端木燹龙之手。

## 经历
乐行词原为御风楼驻唱流浪艺人，与刀悬一命师出同门却不习铸造之术，专研乐武技艺。常以戴墨镜、携二胡的形象行走江湖，性格诙谐幽默。与御神风交好，被龠胜明峦选为六圣护成员，最终死于端木燹龙之手。

## 相关作品

歌曲《三阳开泰之御风楼-乐行词》收录于专辑《霹雳贺新春之感谢发财》中。该专辑于2014年1月28日发行，是霹雳布袋戏为迎接甲午年农历春节特别筹划的数字贺岁专辑。专辑以“花开富贵”为主题，共收录十首具有过年氛围的霹雳贺年曲。

## 角色配乐

乐行词◎铸音造声（乐行词角色曲）曲/编曲：孙敬凡、二胡：吴政君 收录于《霹雳英雄音乐精选三十三》乐行词的订制曲，依照编剧所提供的描述，此角是具有乡土气息的长者，但并非诙谐丑角，其角色音乐需带有沉稳且睿智等特质，因此使用二胡为主奏，拉奏出乐行词的个人特质，中段则辅以高胡演奏，拉高音层，让旋律更为清澈明亮，突显角色的鲜明性格。此外，乐行词亦有一首名为《三阳开泰之御风楼-乐行词》的纯音乐贺年曲，收录于2014年发行的数字版贺岁专辑《霹雳贺新春之感谢发财》中。

乐行词

霹雳布袋戏虚拟人物御风楼驻唱的流浪艺人，来历不凡，与刀悬一命师出同门，但却不喜铸造之术，反而钟情于乐武精研，故在艺成下山后以戴墨镜、携二胡的形象浪迹天涯，个性诙谐幽默，和御神风为好友。深藏不露，为龠胜明峦点将的六圣护人选。

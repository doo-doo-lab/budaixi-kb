# 魔魁之女

一代枭雄战神魔魁的掌上明珠，冷若冰霜、气质高贵，其实智慧过人、武功超绝，且城府深沉。昔日因魔域内乱远走东瀛，一心为魔魁平反、夺回大权而重返中原，为瓦解当时武林一统的局面，先以哀兵姿态加入万教联盟，暗中运筹帷幄，分化三教同时又运用三教势力保护自己、对抗七重冥王，其政治手腕之高明，是霹雳史上少见的女强人。

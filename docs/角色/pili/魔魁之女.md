# 魔魁之女

一代枭雄战神魔魁的掌上明珠，冷若冰霜、气质高贵，其实智慧过人、武功超绝，且城府深沉。昔日因魔域内乱远走东瀛，一心为魔魁平反、夺回大权而重返中原，为瓦解当时武林一统的局面，先以哀兵姿态加入万教联盟，暗中运筹帷幄，分化三教同时又运用三教势力保护自己、对抗七重冥王，其政治手腕之高明，是霹雳史上少见的女强人。

### 角色经历

四百年前，魔魁在荒龙道被轮番算计，重伤濒死下回到基地，带给魔魁之女三颗精髓。魔魁之女用三颗精髓，生下来三教之子非凡公子。

魔魁之女随后远渡东瀛，与神鹤佐木发生恋情，但魔魁之女慎重考察，选择更适合的七色龙作为非凡的养父。

后七色龙与神鹤佐木斗法中败亡，神鹤佐木无颜面对魔魁之女，逃往中原。非凡公子、魔魁之女也先后到达中原。

非凡公子因为身世成为三教共主，后又因政策不明被推下台。魔魁之女出面相救，知道普生乃是神鹤佐木后，让神鹤佐木帮她进入齐天殿避祸、让非凡放出被囚禁的三教先天并耗费元气医治、建议将非凡流放到大汗之野，让非凡保住性命的同时收服一批势力。

随后魔魁之女提议万教联盟将老弱妇孺迁往海鲸岛，不久后便将那些老弱杀害。

万教联盟为此对魔魁之女进行审判，结果往世道君被打成重伤，被圣贤诸偷袭杀死。众人正在头痛，一张署名方城之主的帖子飞入，写着三六金言可诛魔女。众人练成三六金言后，果然功成。

而方城之主末情天也现身，他既是诛魔功臣，又有三教授命者的金牌和幽灵箭。一时成为三教领导。而末晴天其实就是魔魁之女化身。

为了统合三教兵力，魔魁之女又找了一个外援血道天宫；在魔域，她进入第二魔界达成共识，获得统治第一魔界的许可，便让非凡公子回归杀掉七重冥王为中原立下大功，三教、魔域瞬间都被被母子俩掌控。

关键时刻，神秘女郎等人布局围攻魔魁之女，魔魁之女察觉幕后黑手，前去加害素还真，结果反被素还真利用修复伤患，甚至还折损了手里王牌幽灵箭。

大势已去的魔魁之女前去投靠第二魔界，结果处处被军师玉天玑打压。

魔魁之女不甘，取得新幽灵箭，准备射杀玉天玑，谁知玉天玑技高一筹，用双颅弓将幽灵箭射回，魔魁之女卒，元神飞出，然后紧接着被老佛和道尊打中，飞灰湮灭。

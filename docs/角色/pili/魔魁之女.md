# 魔魁之女 (魔魁之女)
================================================================================

魔魁之女

一代梟雄戰神魔魁的掌上明珠，冷若冰霜、氣質高貴，其實智慧過人、武功超絶，且城府深沉。昔日因魔域內亂遠走東瀛，一心為魔魁平反、奪回大權而重返中原，為瓦解當時武林一統的局面，先以哀兵姿態加入萬教聯盟，暗中運籌帷幄，分化三教同時又運用三教勢力保護自己、對抗七重冥王，其政治手腕之高明，是霹靂史上少見的女強人。

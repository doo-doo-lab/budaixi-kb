# 正心宗
================================================================================

正心宗

正心六崇越的祖师爷，十六岁就创出了包含步光宝鉴在内的六种武学，并传授给六名弟子，并曾封印六大恶人，认为正邪消长有其平衡，在因缘际会遭遇少阳君后，将能力与责任传给他，而后再次消逝。

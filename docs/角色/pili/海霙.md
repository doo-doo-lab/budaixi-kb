# 海霙

欲沉轮女皇，其美貌远播整个九轮天，冷静的性格下心系着国民，虽看似柔弱，实则具有高明的政治外交手腕，为了国家平安能不顾一切。因血歃族的侵扰已达极端，姤皇便放下身段，先后与金骑帝国、崇罪明邦等国寻求援助，甚至以美色来设计崇罪明邦不得不出兵协防，其心计让人难以估量。

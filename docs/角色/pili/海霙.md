# 海霙 (海霙)
================================================================================

海霙

欲沉輪女皇，其美貌遠播整個九輪天，冷靜的性格下心繫著國民，雖看似柔弱，實則具有高明的政治外交手腕，為了國家平安能不顧一切。因血歃族的侵擾已達極端，姤皇便放下身段，先後與金騎帝國、崇罪明邦等國尋求援助，甚至以美色來設計崇罪明邦不得不出兵協防，其心計讓人難以估量。

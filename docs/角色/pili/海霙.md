# 海霙

欲沉轮女皇，其美貌远播整个九轮天，冷静的性格下心系着国民，虽看似柔弱，实则具有高明的政治外交手腕，为了国家平安能不顾一切。因血歃族的侵扰已达极端，姤皇便放下身段，先后与金骑帝国、崇罪明邦等国寻求援助，甚至以美色来设计崇罪明邦不得不出兵协防，其心计让人难以估量。

## 来自百度百科的补充

1、欲沉轮女皇，外表冷漠，颇有心计及外交手段，具倾国倾城之姿，乃九轮天众所公认，为解决欲沉轮常年遭血歃族侵扰之局面，前往金骑帝国请求天之熙出兵，在月之熙设计下海霙顺势设局，请得崇罪明邦出兵攻打血歃族。（会刊243）

2、欲沉轮女皇，其美貌声名远播，性格冷静，心系国民，因血歃族侵扰，而多向外寻求援助。（会刊242）

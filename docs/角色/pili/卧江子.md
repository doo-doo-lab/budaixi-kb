# 卧江子

================================================================================

霹雳布袋戏虚拟人物卧江子，霹雳布袋戏虚拟人物，初登场于《霹雳刀锋》第13集，退场于《霹雳劫之阇城血印》第19集。本为天外南海的隐世奇人，精通道法术数，能观星改象、扭转天象乾坤，曾口唸密语向天借法，手挥帝尺引动北风，亦曾以火药、地雷瓦解虫族攻势。隐居于洛水无痕秋山谷，兼具满腹经纶谋略与自信风采，言辞犀利幽默，更擅奇门遁甲之术。其武学包括五行磁雷、卧醉霜雪、天罡两仪掌等。此外，亦有以其命名的角色曲《卧江子》及纯音乐《阵法--卧江子第九阵》。中文名卧江子别 名秋山临枫、秋山（化名）、苏扬傩叶（本名）配 音黄文择性 别男星 座巨蟹座登场作品霹雳刀锋、霹雳劫之阇城血印、霹雳神州出场集数120集人物编剧罗陵本尊雕偶师刘氏

## 人物设定

卧江子图册名称：卧江子称号：秋山临枫化名：秋山本名：苏扬傩叶诗号：蛰伏秋山待枫红，青临洛水无云彩；麒麟降世多磨难，江郎愿使尽长才。身份：傲刀城军师、叶口月人傩叶部前任执首、邪帝面授传人初登场：霹雳刀锋 第13集退场：霹雳劫之阇城血印 第19集（被设计喝下毒酒，遭叶口月人围攻，最终死于九幽）短暂登场：霹雳神州 第22集（箫中剑拜访旧友银狐时，卧江子瘫坐于银狐身后）来自：天外南海根据地：洛水无痕秋山谷、傲刀城、叶口之间特征：发色绿白相混，额上有两仪标志，手持叶扇，一身绿衫打扮，以术法掩盖右手拇指残缺。

## 主要经历

卧江子本为天外南海的隐世奇人，精通道法术数，能观星改象、扭转天象乾坤，隐居于洛水无痕秋山谷，兼具满腹经纶谋略与自信风采，言辞犀利幽默，更擅奇门遁甲之术。在《霹雳刀锋》第19集中，卧江子早有准备，使用火药、地雷瓦解虫族第一波攻势，造成虫族死伤惨重。在《霹雳刀锋》第21集中，面对傲刀苍雷弃城而逃的危局，卧江子施展法术，口唸密语、气走周身、向天借法，以帝尺挥动引动北风，将毒云吹回源头。

## 人物记录

1.天外南海不问世事的神秘智者。擅长乾坤法术、奇门遁甲，隐身于秋山谷，终日垂钓占卜的不世高人。因傲刀青麟的诚心而入世，并助其统一天外南海。2.顶着“卧龙”光环登场的卧江子，为天外南海的局势开创了新的契机。淡远从容的神态彷佛可见“谈笑间樯橹灰飞烟灭”的自信怡然。在谈话中表现出来的一点毒舌、一点调侃正是卧江子个性中做令人感到独特而有兴味的地方。与银狐互相调侃的对话中，让人深深感到其中真挚、恬纯温润的情感交流。（霹雳月刊第94期节录）卧江子图册为三城主所作祭文：天唱灵殇，无由魂觞，哀哉吾主，伴芸亭上，血洒一腔，悲哉吾主，修短故天，人岂不伤。南海局势渐明，自信而吟：（刀锋23，前半化自李商隐《安定城楼》）轻挑江湖忘白发，欲回天地入扁舟，乾坤境界归何处？临枫一动百川流。劝白城舆：（刀锋23，化自崔涂《孤雁二首·其二》）几行归塞尽，片影独何之？暮雨相呼失，寒塘欲下迟。渚云低暗渡，关山冷遥随。未必逢矰缴，孤飞自可疑。卧江子退场：（阇城血印19）曾说江湖不使人憔悴，冷眼观望红尘满日潮，一日抛身战火蔓，千古风流人物，莫笑世浪涛花尽英雄，终归天地尘埃，挥袖不复还。一代智者，也脱不过注定的死劫，昔日的潇洒悠然，只能颓逝在无能回天，以报主公恩德的悲泪。回首霎那间，放不下的情感，友情、恩情，终要一笑置之，无声消散天际。

# 竹魂 (竹魂)
================================================================================

竹魂

以竹為名、愛竹成痴的亮節君子，性情孤僻獨居於毒刺林，但本性重情重義、恩怨分明，與葉小釵之間由敵對關係轉為惺惺相惜的生死至交，卻因身懷九龍圖而捲入無情的江湖宿命…

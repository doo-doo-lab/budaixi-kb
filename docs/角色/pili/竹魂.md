# 竹魂 (竹魂)
================================================================================

竹魂

以竹为名、爱竹成痴的亮节君子，性情孤僻独居于毒刺林，但本性重情重义、恩怨分明，与叶小钗之间由敌对关系转为惺惺相惜的生死至交，却因身怀九龙图而卷入无情的江湖宿命…

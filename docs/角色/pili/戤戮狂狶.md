# 戤戮狂狶

万圣岩囚禁的三恶人之一，狡猾残暴，好杀冷酷，单凭一己之好恶而杀人。善使雷电，练有苍雷真殛之招，乃解开血月异象的关键人物。

## 角色能力

苍雷真殛曾于血海之上施展，强烈电球窜入湖中，巨能推挤血海之水，掀启矗天水壁；电流之招曾在天雷穹射出贯脉钉，并能夹带闪电霹雳；狂云疾电曾与五行旗幻化的白虎激烈冲击；刀招如雷刃狂驰、斩雷刀在战斗中有“一刀斩、二掌化”、“狂人刀势烈如电，一劈风走雷云动”等表现。

武器：戤戮刀◎外形特征：此刀造型繁复，宛若多柄刀刃拼凑而成，如野兽般横生突刺利角，野性十足，突显戤戮狂狶的野蛮风格。◎登场剧集：霹雳奇象 第39集主要

## 经历

在《霹雳谜城》中，戤戮狂狶于血海之上施展苍雷真殛，掀起矗天水壁，并与善法天子、贪杯买醉人、紫宫宣夜、车车老、紫宫太一等多次交战。天雷穹事件中，戤戮狂狶挑衅紫宫太一，电流之招爆发，万圣岩随后订下十五天限时调查。在《霹雳奇象》中，戤戮狂狶踏入终年轰雷的天雷穹，引动天雷射出贯脉钉，期间双阳分离、血月生成，并与善法天子再次激战。泪阳奇象未开时，破解血月异象并非必须其苍雷真殛。

## 相关作品

戤戮狂狶初登场于《霹雳奇象》第36集，退场于《霹雳谜城》第31集，在《霹雳奇象》中有出场情节，在《霹雳谜城》中也有出场情节。戤戮狂狶的角色曲《戤戮狂狶》收录于《霹雳英雄音乐精选十：霹雳谜城》电视原声带，发行于2006年10月27日。

## 人物影响

戤戮狂狶最初被观众视为凶神恶煞的反派，但因重视兄弟情义（如对悟僧和弟弟桑道凉的情感）和性格耿直，其死亡引发惋惜。

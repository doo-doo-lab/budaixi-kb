# 劍狼 (剑狼)
================================================================================

劍狼

魔吞不動城的荒狼宮代表，孤高驕傲、冷酷少言，酷寒的戰慄氣息使人退避三分，招起招落飛快無倫，如狼獵物一般的冷靜快意。常與刀猿一同出任務，手持狼殺劍，在驚人的出招速度下順勢窺探對手破綻，一舉掃蕩魔吞不動城的所有阻礙。

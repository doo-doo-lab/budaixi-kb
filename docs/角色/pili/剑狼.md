# 剑狼

魔吞不动城的荒狼宫代表，孤高骄傲、冷酷少言，酷寒的战栗气息使人退避三分，招起招落飞快无伦，如狼猎物一般的冷静快意。常与刀猿一同出任务，手持狼杀剑，在惊人的出招速度下顺势窥探对手破绽，一举扫荡魔吞不动城的所有阻碍。

# 海殇君

================================================================================

## 角色能力

武器羽扇、克邪圣器◎外形特征：羽扇是海殇君随身之物，也作为武器，以柄居中，两边用羽对称。

羽毛大小不一，一扇集十一羽，鎏金扇柄，嵌以白玉珠为饰。

克邪圣器是形似佛门金刚法杵的一口金色圣器，从握柄、护手到杵身共分六节，首尾两端具尖，护手造型如太阳，有六道代表日芒的金色突刺，昔日海殇君便是以此在轮回海击杀灭境邪灵枭雄·未来之宰。

武学◎武学分类：攻击类：黄沙怒音扬、沧海月明映泪痕、至怒玄音综合掌、海纳千川、擎羊啸天、一指泣风动护身类：银波镜含术法类：五行转命术之【奇木转命术、尘沙转命术、心外有身】、陷魔障辅助类：真气传声◎使用介绍：海殇君 写真奇木转命术：五行转命术之一，化解一页书八口山之劫。

银波镜含：蚁天初入苦境，为避免足踏血腥之地所使用的护身之招。

（幽灵箭07）黄沙怒音扬：是非小径一役，海殇君初展绝学，一招将七重冥王打出原形。

（幽灵箭11）沧海月明映泪痕：云渡山之上，仅存二分功力的海殇君，遭受七重冥王的无情攻击而搏命使出，后海殇君诈死，冥王则赢得惊险。

（幽灵箭13）尘沙转命术：五行转命术之一，蚁天借由此术在云渡山诈死成功，退居幕后。

（幽灵箭14）至怒玄音综合掌：七重冥王前往琉璃仙境告知不知名被擒，海殇君盛怒之下发招，将仙境之外的瑟残影击成碎片。

（幽灵箭20）海纳千川：十里断肠崖之战，海殇君以此招吸纳住山涛君和云岫君两人发出的强大气流。

（幽灵箭24）擎羊啸天：海殇君的必杀绝技，先是在五里迷障的入口以此招击毙隐面圣尊劫无行，又在十里断肠崖再以此招击杀山涛君，潇湘子也是死在此招之下。

（幽灵箭22/24，英雄榜05）心外有身：五行转命术合一之术，海殇君以此将自己与秦假仙的本命星的光芒一同封在续命金莲中，以自身的根基道行蕴孕秦假仙的生机，九十九天后秦假仙即可复活。

（英雄榜02）一指泣风动：无尽天涯一战，海殇君以此化解潇湘子四方归元的攻击。

（英雄榜05）所有物忘情剑、黑榜名单

## 角色经历
幽灵箭时期海殇君 剧截图蚁天·海殇君，灭境先天、西武林西丘三君之首、一页书的好友、傲笑红尘的义弟。

眉宇刚毅，不怒而威；

蓝发蓝袍，足蹬锦靴。

手持羽扇，气定神闲，智勇双全，对于敌手仍能保持尊敬，有高手宗师的气度风范。

海殇君昔日修行于灭境西丘，曾练功走火入魔，得一页书三百年金丹之助，为人重情重义的海殇君也感念在心，与一页书相知挚交，也誓为一页书挡下三劫。

为化解一页书八口山之厄，海殇君以奇木转命术协助一页书渡过劫难，正式登场则是青阳子为了枫岩上西丘之时，又交待秦假仙血泪石营救宇宙神知。

当一页书化身宇宙神知犯劫魔域，海殇君毅然踏出武林，以黄沙怒音扬打出七重冥王原身，但仍未救到宇宙神知，因此海殇君坐镇云渡山，诈死与黑白郎君配合，对付魔域和血道天宫，制衡方城之主未情天。

为解救素续缘，海殇君只身闯入灵啸月也无可奈何的十里断肠崖，一举突破五里迷障，力战山涛君和云岫君，终让山涛君伏诛，使一页书复生之后功成退隐。

英雄榜时期退隐到笑情山庄的海殇君，仍关心武林安危，暗中协助一页书、素还真等人，牵制玉天玑、潇湘子，更为护一页书天命而囚禁鬼王棺，拯救巧智之星秦假仙。

海殇君在无尽天涯又大展神威，一举攻破血道天宫，让潇湘子含恨天涯。

天外方界向中原武林伸出魔手，方界老童暗中救出鬼王棺。

海殇君独闯天外方界，终究不敌三强联手而被擒，困于方界。

烽火录时期海殇君被放出后，和素还真寻得其结拜义兄傲笑红尘，再度为武林和平力战东瀛忍者、魔魁等人，曾遭非凡公子所擒，后被素还真等人救出。

最后的海鲸岛一战，海殇君联手素还真、傲笑红尘等人一同攻进，一生诛魔不遗余力的海殇君绝招尽出，奈何早先被天外方界擒住时，被白云骄霜针插风门穴，导致身体每况愈下，气息窒碍、功力消退，被魔魁重创。

海殇君最终重伤不治，一代英豪与世长辞，骨灰被傲笑红尘安放于最高光明界·耶摩天。

天罪时期霹雳神州III之天罪第48集提及，海殇君曾经和梵天合作，欲以九环计诛杀未来之宰与问天敌。

最后，蚁天以地利祭出克邪圣器，刺入未来之宰体内，击碎其肉体与元珠，未来之宰最终消散于无形。

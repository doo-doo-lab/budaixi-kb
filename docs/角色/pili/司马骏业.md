# 司马骏业

性格拘谨严肃，循规蹈矩，不容偏邪的正人君子，遵圣贤，法经典，俨然一代大儒，曾在儒门天下担任大司马一职，将儒门天下管理得有条不紊，而后因故离职，回归原本身份“入世一步涯”主事，乃正心六崇越之一，地位崇高。除了协助正道以外，私下积极想要找寻失踪的三教顶峰。

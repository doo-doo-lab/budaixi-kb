# 命七天（霹雳布袋戏中的角色）

命七天，霹雳布袋戏中的角色。一场因其父亲身怀武林至宝七叶神兰与金龙珠而遭金阳圣帝觊觎所引发的灭门血案改变命七天一生，为报双亲血仇，勤练武功绝学菩萨印。命七天更听从崎路人安排，受其以迭影神变之术化成黑发照世明灯模样行走江湖，并曾说出“不要逼我，不要逼一个想要弃恶从善的人，再度坠入黑暗的深渊”之言。其个性恩怨分明、重情重义，受人点滴则涌泉以报。练成菩萨印第十式的命七天帮素还真解了波幻迷掌后，击败关足天，便离开武林，在爱妻墓边度过残存的日子。

## 角色经历
命七天的一生被一场灭门血案无情改变，其父亲身怀武林至宝七叶神兰与金龙珠，因而遭到北域强人金阳圣帝觊觎，派遣杀手灭门，命七天年幼时亲眼目睹父母俱亡，愤而自号决杀千里。

崎路人助其躲过灭门之灾，并给予鬼爪破魂指秘籍与菩萨印招式，助其成功报仇，命七天因此视崎路人为恩公。

命七天勤练武功绝学菩萨印，只为亲手报双亲血仇。

命七天性格恩怨分明、重情重义，且受人点滴定涌泉以报。

受崎路人之托假扮照世明灯行走江湖。

因其假扮身份，一度被江湖中人误认为是武林魔头欧阳上智。

在一场大混战中，命七天以十成功力的鬼爪破魂指破了素还真与谈无欲的明圣剑法，自身亦受重伤，后身份被九天神罩识破。

之后因素还真中太黄君的波幻迷掌吐血不止，需要菩萨印第十式配合灵心异佛方能治愈。

但菩萨印第十式过于刚猛，会导致习练之人气脉逆冲七天之后毙命。

练成菩萨印第十式的命七天帮素还真解了波幻迷掌后，在碧水岭邂逅秋分，两人互生情愫并结为夫妻，于挽秋居退隐。

击败关足天，便离开武林，期间曾遭遇沙漠五僧的千里追捕，并与回元三圣等强敌交战。

在爱妻墓边度过残存的日子。

## 人物影响

命七天是霹雳布袋戏中的悲剧英雄。其个性恩怨分明、重情重义，受人点滴必涌泉以报。他因幼年目睹家门惨案而立志复仇，在崎路人的帮助下习得武功并成功报仇。后又为报恩假扮“照世明灯”行走江湖。其假扮身份被揭穿时所说的台词“不要逼我，不要逼我，不要逼一个想要弃恶从善的人，再度墬入黑暗的深渊。”成为其名言。命七天从复仇者到退隐者，最终仍被江湖风波缠绕。

## 相关作品

命七天在霹雳布袋戏系列中登场于《霹雳剑魂》（1990年），具体登场于第10、11、13、14、17、18集。

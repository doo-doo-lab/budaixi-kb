# 烈剑宗

================================================================================

霹雳布袋戏虚拟组织烈剑宗是虚拟组织，由烈霖创立。主要成员包括少主烈霏（暴雨心奴）、弟子黄羽客。烈剑宗武学体系包含烈雨剑法（含火、水、冰、剑四属性），其教学体系分三级：烈霖亲授、黄羽客指导、弟子自修。剑雪无名曾担任烈霏的师傅并被聘请为烈剑宗座上宾。烈霖创立烈剑宗后，因修炼烈雨剑法消耗生命力过早病逝。烈霏成为暴雨心奴。中文名烈剑宗出 处霹雳布袋戏成 员烈霖、烈霏（暴雨心奴）、黄羽客

## 人际关系

剑雪无名曾担任烈霏的师傅并被聘请为烈剑宗座上宾。

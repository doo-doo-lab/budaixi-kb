# 凯旋侯

================================================================================

霹雳布袋戏虚拟人物凯旋侯是《霹雳布袋戏》系列中的虚拟角色，

**别称**：“战无不胜”，由黄文择

**配音**：三弦创作设定，洪有聪担任

**本尊雕偶师**：。该角色

**初登场**：于《霹雳震寰宇之龙战八荒》第40集，主要活跃于《霹雳震寰宇之兵甲龙痕》与《霹雳经武纪之枭皇论战》剧集

**身份**：为四魌界火宅佛狱三公之一，象征“战无不胜”的佛狱最高利益。凯旋侯早年

**化名**：拂樱斋主潜伏苦境中原，表面协助正道对抗火宅佛狱与死国，实则联合天者开通血暗沉渊并重创枫岫主人，促成佛狱入侵苦境。其麾下部署包括冲击者、狙击者等战斗团体，拥有无执相与白尘子两名副体。在佛狱与苦境、集境交战中遭剑之初废去七成

**功体**：后因反对魔王子废除三公体制被剥夺剩余三成

**功体**：及声音，囚禁于噬魂囚，并由迦陵顶替凯旋侯之位。角色后被红狐九尾从噬魂囚中救出，最终下落不明，壁上留有枫岫主人“吾不恨你，吾原谅你”字迹，战无不胜的威名随

**功体**：尽废沦为虚妄。官方旁白评述其“机关算尽反误性命”，印证角色命运转折的逻辑闭环。

**中文名**：凯旋侯

**别名**：战无不胜

**配音**：黄文择

**性别**：男

**登场作品**：霹雳震寰宇之兵甲龙痕霹雳经武纪之枭皇论战人物创作者三弦

**本尊雕偶师**：洪有聪

**出场**：活跃43集

## 人物设定

名称：凯旋侯凯旋侯称号：战无不胜名言：凯旋侯所代表的，也不过四字，那区区四字（战无不胜）罢了。性别：男化身：拂樱斋主身份：佛狱三公之一初登场：霹雳震寰宇之龙战八荒 第40集退场：霹雳经武纪之枭皇论战 第22集（实际戏份到枭皇第2集结束，22集借红狐九尾之口说出退隐之事）来自：四魌界佛狱三公：三公分别代表：火宅佛狱（王）、最高利益（公）、战无不胜（侯）。含义为，三公代表着火宅佛狱的最高利益，进而战无不胜。

## 经历
拂樱斋主的杀体，火宅佛狱的三公之一。

为了开通佛狱与苦境的通道，凯旋侯与其副体无执相、白尘子前往苦境。

凯旋侯化身为拂樱斋主，假意从善实则潜伏苦境，除了调查慈光之塔的楔子（枫岫主人）之外，也暗中联合死国与火宅佛狱完成血暗沉渊的开通。

血暗沉渊开启后，旋即重创枫岫主人与极道先生，回归火宅佛狱。

为让贫瘠的火宅佛狱获得资源，开始在苦境进行大规模的进攻。

在火宅佛狱与苦境、集境一战时，因被素还真算计，意外遭逢慈光之塔的惊叹剑之初，凯旋侯、太息公、守护者迦陵三人合攻，凯旋侯遭剑之初散去七成功体，兵败回转佛狱，在魔王子之前建言不能废除佛狱传统的三公体制，而被魔王子废去剩余三成功体以及声音，并卸除侯的身分，打入噬魂囚永久监禁。

后因四邪谛被魔王子解封，由四邪谛之一的红狐九尾将其放出。

## 人物终幕

『火宅佛狱·噬魂囚』凯旋侯噬魂囚内，鬼哭回荡，一条蜷曲的身影卧倒其中。曾是佛狱高枝，今为死牢废奴。凯旋侯一生纵横捭阖，机关算尽，但始料未及的结局，竟是反误性命。枫岫主人：好友拂樱，吾不恨你，吾原谅你。旁白：壁上留字，是最残忍的悲悯，也是最可笑的宽恕。不能言语，怨恨难诉。再多不甘，已是力不从心。战无不胜，终成虚话。

## 人物简评

拂樱斋主，始终忠于火宅佛狱，其卧底苦境所经历的亲情、友情，也许同时也是其内心所重视的感情，但在佛狱面前，纵使有所牵挂，仍是牺牲所有在所不惜。这份忠于家国的心，实为不辱三公之名。角色经典台词自始至终，吾心从未背离佛狱。（龙战八荒40集）未来智计互角，风云变幻，谁有把握一手遮天呢？（兵甲龙痕06集）在佛狱，凯旋侯象征四字——战无不胜（兵甲龙痕07集）我从不低估敌人，也不低估自己。（兵甲龙痕09集）

# 魔魁 (魔魁)
================================================================================

魔魁

個性正直、重諾，頗有智慧，不屑使用權謀陰計，行事直率。為了報答救命之恩，神跡岩論道，成為創世者的第一位信徒；為了救其孫非凡，幾度冒險。其與天魔驚天動地一戰，臣服於天魔，暫代天魔掌理魔界。魔魁是少數魔界擁有雄才大略，有能力睥睨群雄的超絕霸主，也是魔界中少數令正道敬佩的角色之一。

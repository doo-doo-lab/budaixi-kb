# 魔魁

个性正直、重诺，颇有智慧，不屑使用权谋阴计，行事直率。为了报答救命之恩，神迹岩论道，成为创世者的第一位信徒；为了救其孙非凡，几度冒险。其与天魔惊天动地一战，臣服于天魔，暂代天魔掌理魔界。魔魁是少数魔界拥有雄才大略，有能力睥睨群雄的超绝霸主，也是魔界中少数令正道敬佩的角色之一。

## 角色设计

魔胎转生，掣卷武林风暴；人形现世，大败灵山双叹；势力宫内，野心不曾潜藏；肉身初成，白莲战败为奴；即位玄都，统整魔族群心；安乐河畔，天官化敌为友；亢龙顶上，誓为义弟雪命；梭罗复位，一夕化为尘烟；一身傲骨，岂顺命运波涛。

魔界战神魔魁，在三教教主身上设下血烙魔气使三教主入魔，在经由魔胎重生之后，机械化的身躯展现出无人可敌的力量，挫败灵山双叹，打败天外方界和无极殿联军，乃是霹雳第一位打败百世经纶一页书的魔王。

武器

### 武器

撼宇神剑

外形特征：神剑尘封许久，外表如同生锈废铁一般，剑身厚重，剑芒刺眼锋利，剑身处有一凹槽，用以嵌合擎天神剑之用，唯有结合擎天神剑才能发挥撼宇神剑最大威力。

来龙去脉：素还真根据经中所述，上古时期黄帝轩辕氏为除妖平世，特命【天将造化师】铸剑，但搜遍九州精铁十三年仍铸不出神剑，最后造化师之子投炉殉剑才成功。霎时彤云布天、雷霆震世，造化师潸然泪下而叹“神剑现世，满世血腥”，故名“撼宇神剑”。轩辕氏以此平定蚩尤战乱，故将神剑易名【捍宇】。然而此剑杀气弥天，威可摧山撼海，诛仙斩魔。轩辕氏忌惮其威力，将此剑封印于北荒原衡天峰之下。一切都记载于《魔宝大典》之中，被魔界列为最高机密。后在魔魁和龙王鱽的对决中，被金貂刀斩断。

## 角色经历

魔魁，第一魔界之主，被誉为魔界战神。个性耿直重诺，有智慧却不屑于权谋计策，待人处事秉承“以德报德、以直报怨”原则，雄才大略，是个有能力睥睨群雄的霸主。魔魁负责驻守第四魔域，当年和三教主约战荒龙道，不料被欲夺权的七重冥王算计，使得战死荒龙道，但魔魁布下血烙魔气来魔化三教主，死前为复生做好准备，死后元灵留下预言，预言七重冥王将被心腹背叛而亡，这一预言也在后来的一花香身上印证。

数百年后，非常女在祭血魔殿被金小开侮辱后而怀有身孕，魔魁灵气借非常女和胎儿为媒介复生，忠心部署诛心和断邪感应到魔魁重生，也解开石封而现世。魔魁的重生引动各方关注，魔界内部死路冥神和浑沌风魔派人追杀非常女，正道方面一页书等人也为诛杀魔胎而动武，魔魁魔胎危机重重，在猜心园被围攻时受非凡公子保护下逃出。在二度遭受一页书攻击时，魔胎被一页书以十成锻魔真火焚炼，不颠和尚发掌助阵却意外使魔胎逃脱，但非常女却重伤而亡。当初，素续缘被万圣佛骨灰及万鬼魔珠之圣气与魔气缠身，导至性情分裂，时善时恶，后来素续缘进入葬尸江，被江中之高人将这两道气流导出体外，圣魔两气在江中继续同旋争斗，一直到了天河之中，但天河终年冻结，两气不得脱困，在冰下造成急流漩涡，正好在漩涡之下有一处奇妙的地隙，内中生长一棵奇树，圣魔两气于是被此树吸收，终于生出两果，一树双果，一者魔果，一为圣果，故云佛魔同根。秦假仙与业途灵受一页书所托前往天河取圣果，双极果在未成熟之前为虚幻之体，待成熟才转为实体，两人并以一页书之圣血测试何为圣果，最后取下圣果时，魔果亦瞬间爆炸，形成一股红色的妖云。

魔魁魔胎以灵气化石躲过一页书追击后，又被双魅殿主扔到八口山，被自然力量折磨，奄奄一息时吸收妖云之力蜕变为妖兽，能听懂人言却无法说话，只能嚎叫，在魔魁之墓被不知情的诛心断邪赶走，在两魅殿主进攻时相助诛心断邪退敌，后和蠹能人相认，证实自己是魔魁。在和非凡公子相见后，受非凡公子安排，与白云骄霜条件交换，妖兽魔魁吸食了惊虹留恨，蜕变为刀枪不入的机械魔魁。机械魔魁比起妖兽魔魁，获得了更多的语言与思考能力，防御能力达到魔魁所有形态的顶峰，几乎无法伤害，更遑论杀死；但是移动能力大大下降，需要用气功吸引敌人到身前进行战斗。

机械魔魁现世，轻易击败灵山大叹和灵山小叹，占领灵山，并将一页书、不颠和尚、谈无欲、欧阳上智等人的联手打得七零八落，又击败天外方界同傲笑红尘、海殇君的攻势，如此的强大成为当时无人能及的超级魔头，让正道等各方都惶惶不可终日。在消灭势力宫左派后，机械魔魁进入血池中浸泡，欲经过六天再生皮肉，期间正道众人对海鲸岛发动大进攻，欲以撼宇神剑斩杀魔魁。

正道高手云集，素还真、海殇君、傲笑红尘、黑白郎君、已经练成千里神弹的青阳子联手攻上海鲸岛，不料魔魁提前出关，素还真的宝剑被夺，倒在地上。其余人心急如焚。众人围攻魔魁，但却被恢复肉身的魔魁轻易击败，正道损失巨大，海殇君重伤身亡。素还真为解救正道众人而投降成为奴隶，脸上被魔魁刺上毒刺青。

后来，魔魁广发战帖，邀请权门宗矩等东瀛人士、大鸿胪为首的易水楼、以及正道一派与海鲸岛大战，胜者为王。为斩杀魔魁，修炼完成的三传人代表正道出战重新集合于海鲸岛挑战魔魁，却因三人心思各异，成效不佳，反让魔魁获胜。最终魔魁力挫群雄，正面赢下混战，却被一线生安排的大雾阻止不再继续追杀正道人士。武林迎来魔魁天年。

魔魁生肉期间，魔魁外孙非凡公子被东瀛之人下毒重伤，但还不顾自己安排魔魁复活；魔魁找来了名医都无果，便杀掉了他们。

为医治非凡公子，魔魁广寻名医但都不得治，后经花爵百炼生悬丝诊脉，魔魁为非凡吸出喉咙中的杀气，却因心急险被反击杀气所伤。医治非凡后，魔魁灭掉了东瀛人士，忠贞之花阵亡，权门宗矩狼狈逃脱。由于白云娇娘的通风报信，又趁着大鸿胪参加九大奇人聚会，出兵易水楼，一战而灭之，仅剩华琉衣因非凡公子手软得到生机、叔夜衣战败被擒投降成为内应，其余武训生员全部战死。

炼魔狱的火纪天官刺爷爷不服魔魁而发起挑战，首次对决不分上下后，在被死去的忠贞之花附身的非凡公子安排，魔魁和刺爷爷在安乐河两岸再战，却反遭非凡刺伤。由于不熟悉东瀛忍术，魔魁被伪装成孕妇的权门宗矩以尸骨针定位，无法动弹，不得已吐出内丹毁其一臂，又射出双眼击退伺机为大鸿胪报仇的双驼峰，再遭金裨善两掌重袭而重伤昏厥，被创世者以贞烈花、脉生草和胎衣所救。

魔魁和刺爷爷化干戈为玉帛，义结金兰。为报救命之恩，魔魁在神迹岩论道八天，成为创世者的第一位信徒。龙阁梭罗为复辟魔界而率军进攻玄都，但玄都大军被裨善造出迷雾困住不及救援，非凡公子以旱族妇孺作为肉盾，魔魁和非凡因此逃过一劫。事后，魔魁依约放回旱族妇孺，被龙阁梭罗派出虎贲半路拦杀，后化险为夷。花爵百炼生为了魔魁奔走，找来森罗天眼和地心金眼作为魔魁的义眼，让魔魁能恢复实力，应对龙王鱽的挑战。谁料，刺爷爷自愿代替魔魁应战，却不敌被杀。魔魁为替义弟报仇，接受龙王鱽的二度挑战，双方在亢龙顶战的不分轩轾。龙阁梭罗趁机收复了玄都，非凡重伤逃至亢龙顶，却遭叔夜衣围杀，魔魁见状猛催攻力，将近自毁元神，却因和龙王鱽运功过度，导致天动地裂，双双被埋在亢龙顶地下。

龙阁梭罗复辟后，单独逃生的非凡公子被无形魔化身告知魔魁未死，打通亢龙顶地道将魔魁救出。祖孙二人藏身九蟠山。后来三思台软禁老化的龙阁梭罗，派出大军围剿魔魁与非凡公子。非凡公子中毒被擒，魔魁为保命，放弃肉身，退化回妖兽骨架形态。虽然逼退大军，却也不能自行恢复肉身，三思台认为此形态的魔魁已无威胁，宣布退兵。

后来，魔魁被非善类所擒，拘禁在魔界深处。天魔重掌魔界后，为统一魔界实力，延揽非凡公子为军师，更有意延揽魔魁为大将。天魔和魔魁在不归路一战定王侯，魔魁臣服。为应对七星现世，天魔闭关修炼，在此期间由魔魁代掌魔界，对正道和七星采取行动。在此期间，魔魁曾对上来魔界寻傲神州挑战的病剑叟，派出龙王鱽针对乱世狂刀、秦假仙、莫召奴等人等。在司马剑秋的讨情下，魔魁和非凡公子兵进云渡山，魔魁和五方主星归位后力量大增的素还真交手，三掌平局，不分输赢，后因司马剑秋已死，达到目的的非凡公子建议而撤兵。

魔剑道势力崛起，魔界遂成为魔剑道的绊脚石。白衣剑少携两异端神入侵魔界地盘，魔魁出战，一番激斗后陨落。（霹雳图腾07）

死亡分析

一些网友认为，长期以来，魔魁在武林多次战役中尽显霸气，但也树大招风，武学招式皆被研究透析；魔魁重伤难愈尚未复原（如内丹被毁，与龙王鱽大战时的燃烧元神，被龙阁梭罗大军围剿舍弃全身血肉变为妖兽骨架，重塑血肉时的功体下降）；天魔曾言，魔魁武功更加凶悍，说的应该是招式，内功并未复原，在招式早被分析透彻情况下，魔魁受式神压制，大意而亡，可以理解。武林世代更替，一代魔威传说也落下帷幕。

但也有一些人认为，按白衣剑少以后的表现，杀死曾一度击败一页书的魔魁，是没有说服力的。

魔王系列之——魔魁

霹雳王朝之时，儒道释三教教主合作才铲除的魔头——魔魁，曾经制造幽灵箭，又在三教老教主身上下了血烙魔气，最终使三人成为魔人的魔魁，在未现世之前，便经由魔魁之女、三教之间的传言留下了不少的传说，不意在魔胎诞生之后，竟使得魔魁借体重生，成为霹雳史上第一位创造传说的魔王。魔魁在经历魔胎、妖兽等阶段后，终于在吸收了惊虹留恨身上的赤子根之后成为机械魔魁，此乃当时正道有史以来最恐怖的灾难，当魔魁降临灵山之时，庞然的身影，无比的力量，使灵山双叹也无能为力，犹有甚者，更使百世经纶一页书首度现出无能为力的状态。魔魁是霹雳史上第一位力压一页书之人，随后面对天外方界、无极殿、易水楼等势力，魔魁的力量几乎都是摧枯拉朽般的将所有敌人碾压，一直到最后恢复肉身为止，机械魔魁从未露出败象，更遑论受伤，但可惜魔魁长出肉身之后，却失去了无人可破的护甲，甚至还出现了旗鼓相当的对手，逐渐走向败亡的地步，这是美中不足之处。但不论如何，首位给中原正道带来无边绝望者，机械魔魁的强悍，让一页书首度出现不知所措、匆忙奔走的情况，让人十足感觉到，正道是丝毫没有任何方法打的赢机械魔魁的。那种惶惶不知以后希望何在的绝望感，奠定了机械魔魁的超级魔王地位。

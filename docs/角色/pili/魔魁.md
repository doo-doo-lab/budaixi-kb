# 魔魁

个性正直、重诺，颇有智慧，不屑使用权谋阴计，行事直率。为了报答救命之恩，神迹岩论道，成为创世者的第一位信徒；为了救其孙非凡，几度冒险。其与天魔惊天动地一战，臣服于天魔，暂代天魔掌理魔界。魔魁是少数魔界拥有雄才大略，有能力睥睨群雄的超绝霸主，也是魔界中少数令正道敬佩的角色之一。

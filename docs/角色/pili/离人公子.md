# 离人公子

隐居极北之处，浮舟流川尽头，烟航归处的主人。举止高雅，谈吐清冷，喜爱恬静，有着银红眸与月牙耳，不知从何方而来的恶魔。性情孤僻，行事随心而定，对人性洞察透澈，总是一副事不关己，看透尘世的模样。
拥有掌控记忆的奇能，人们为记忆真相前来，凡勾起离人公子的兴趣，并通过考验者，便能一诉祈愿，签订契约，随着秉烛指引，进入心海，探看自身过往经历的事实。
随着剧情演出，揭露其身份为前任沅海玄渊的共主，恶魔真名“零之北溟”，如今寻得故人线索，前往异域镜界。

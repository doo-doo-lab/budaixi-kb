# 離人公子 (离人公子)
================================================================================

離人公子

隱居極北之處，浮舟流川盡頭，煙航歸處的主人。舉止高雅，談吐清冷，喜愛恬靜，有著銀紅眸與月牙耳，不知從何方而來的惡魔。性情孤僻，行事隨心而定，對人性洞察透澈，總是一副事不關己，看透塵世的模樣。
擁有掌控記憶的奇能，人們為記憶真相前來，凡勾起離人公子的興趣，並通過考驗者，便能一訴祈願，簽訂契約，隨著秉燭指引，進入心海，探看自身過往經歷的事實。
隨著劇情演出，揭露其身分為前任沅海玄淵的共主，惡魔真名「零之北溟」，如今尋得故人線索，前往異域鏡界。

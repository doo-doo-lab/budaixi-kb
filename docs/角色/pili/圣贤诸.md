# 圣贤诸

================================================================================

霹雳布袋戏中的角色圣贤诸，霹雳布袋戏中的角色。风度翩翩一表人才的圣贤诸，是儒教九代令公之首，见识武功不凡，却有着称霸武林的雄心。圣贤诸代表儒门出席观风岭，欲逼出三教之子，后担任琉璃镇山大将军，表面保护素还真，实则挑拨当世道君对素还真的偏见。圣贤诸受命铲除魔域分子，杀害半生浮，并擅改黑卷译本，篡改非凡公子的旨意进攻是非小径与别有天地，导致全军覆没。圣贤诸杀害风雅诸之事被百里抱信查出，欲灭口时被非凡公子和秦假仙打断，受审时诬陷非凡公子与魔域勾结。圣贤诸暗中以半魅人身份主动寻求魔魁之女合作，谋诛万教联盟同侪，后又化身半魅人与非凡公子合作，劫持亢无后时被设计现出真身。然因魔魁之女不愿受制同非凡公子合谋，识破其半魅人身份，圣贤诸先遭魔化夫子打伤，坠入非凡公子与神鹤佐木对战之处，而遭两人同时发掌之掌气所杀。中文名圣贤诸配 音黄文择性 别男登场作品霹雳王朝登场作品霹雳幽灵箭第一部本尊雕偶师徐炳垣出场集数49集化 身半魅人身 份儒教九代令公之一

## 角色经历

圣贤诸，儒家世外书香“九代令公”之首，温文儒雅、谈吐不凡，身背一只巨型铁笔，更彰显其儒门人士的身份，铁笔更是天笔锋的缩影。圣贤诸表面上虽然正气凛然，实际上却是个阴谋家，有着称霸武林的雄心大略，暗地里动作频频，进行颠覆三教、谋害万教联盟同僚。圣贤诸代表儒门出席观风岭，欲逼出三教之子，遭落日一笑、秋风之刀等人合力围攻而被打破护身光罩，现出真身。圣贤诸从鬼王棺口中打听到圣佛眼可知何人是三教之子，利用变相追赶当世道君时潜入明吾凡洞打开圣佛眼，却被因果来阻止。后前往菩提学院，圣佛眼却被神鹤佐木打破，圣贤诸助触念来将神鹤佐木击飞。圣贤诸后来担任琉璃镇山大将军，表面上是保护素还真，暗地里则可以挑拨当世道君对素还真的偏见加深，更在青阳子来访时刻意与道君争执，使两方的心结进一步加深。圣贤诸受三教圣主之命和菩提学院副院长领兵行动，铲除在武林中潜伏的魔域分子，在诛杀半生浮时，尽管对方出示普生密报和道君所赠的免死金牌讨情，但圣贤诸仍是杀死了对方。圣贤诸奉命找出一休禅师翻译黑卷而来到无双崖，在得到译本后擅改其中内容，后更篡改非凡公子的旨意，让触念来攻打是非小径，自己带兵攻入别有天地，却遭机关伏击而全军覆没。由于非凡公子早已看过正确的翻译，在圣贤诸回来复命时让其负起救触念来之责，圣贤诸表面答应，实是采取拖延政策，削弱佛教实力。圣贤诸  官方桌布2圣贤诸赞同神鹤佐木引荐魔魁之女进入万教联盟，但不授予任何职权，并要求流放非凡公子。由于武林盛传魔魁之女将成为武林女皇，秦假仙和业途灵频频骚扰魔魁之女，圣贤诸允诺为其辟谣，暗地里化身半魅人和魔魁之女谈判合作。在道佛两教先天围攻魔魁之女时，圣贤诸出手暗伤往世道君致其身亡，又将方城飞帖中三六金言的事告知了魔魁之女。圣贤诸曾暗中跟踪灵啸月，调查其来历，中间发生过拳脚摩擦，但未有结果。圣贤诸将灵啸月身怀儒教秘招的事告知同修广文诸和风雅诸，夜里又趁风雅诸翻阅儒家经典时偷袭对方。在夺得秦假仙身上的大汗之野名单后逼迫亢无后承认身份，却因拒生郎的缘故而未能得逞。圣贤诸答应魔魁之女在荒龙道之战中以至阴至寒之气助力，却被非凡公子怀疑身份而攻击。荒龙道之战风雅诸身负重伤，圣贤诸假治疗实致死的谋害了风雅诸，后同因果来、当世道君前往猜心园，被困在虚幻空间中和魔族交战，在照世明灯的条件交换下方脱险。圣贤诸对神鹤佐木显出真身，解释自己以半魅人身份接近魔魁之女的原因，希望神鹤佐木能接近魔魁之女并毁去其拥有的幽灵箭。经过调查，百里抱信查出风雅诸为圣贤诸所杀，圣贤诸欲杀人灭口，却被非凡公子和秦假仙打断，在受审时诬陷非凡公子和魔域勾结，拖其下水。圣贤诸又化身半魅人和非凡合作，前往三教圣陵劫持亢无后，却被非凡设计而现出真身，双方展开一场恶斗，后被神鹤佐木助其逃脱。圣贤诸甫脱出不久，又遭秦假仙率众围杀，圣贤诸舌灿莲花，群众不再盲目攻击，圣贤诸正觉得自己已经安全时，被受魔化控制的圣夫子一掌打飞往三教圣陵，不偏不倚正好落在非凡公子与神鹤佐木的对战中心，当场被两人同时发出的掌气所击毙。

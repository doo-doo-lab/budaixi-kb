# 求影十锋

================================================================================

霹雳布袋戏虚拟人物求影十锋，霹雳布袋戏虚拟角色，由黄文择配音，登场于《霹雳震寰宇之刀龙传说》《龙战八荒》《兵甲龙痕》。身份为集境擎羊殿殿将，后代理擎羊殿、升任天机院主，持有藏心剑并掌握十方剑原武学，角色音乐包括《求影十锋》《剑影藏心》。求影十锋受天机院主太君治倚重，临危攻打妖世浮屠三角晶界。其真实身份为残宗成员，曾与兄长鸦魂合作营救雄王，后归顺虓眼军督。最终参与护送雅狄王遗书行动时，为掩护战友与血参巫同归于尽。角色以低调寡言著称，曾多次破解阴端佛鬼攻势，最终以牺牲践行忠义信念，遗言“生有何憾，死有何惧，恶山邪路，埋骨忠义”概括其人生准则。

## 角色能力

武学十方剑原武器藏心剑持有者：求影十锋登场剧集：霹雳震寰宇之刀龙传说 第37集配合招式：十方剑原外型特征：藏心剑狭细而尖锐，护手以圈环为概念设计，单侧横嵌著钩刺，便于握剑，平日收执于剑匣中，设计有开槽式机关，能让藏心剑顺势弹出。

事迹简述：集境擎羊殿殿将“求影十锋”佩剑，平日收执于剑匣中，设计有开槽式机关，能让藏心剑顺势弹出，配合十锋的速攻行动。

虽是小小殿将，却拥有高超的剑法，低调寡言不求表现的性格，一如藏心剑般内敛又深藏不露，不过也由于本身超卓的能力，让十锋成为天机院主太君治倚重的对象，更在擎羊殿主刑无错战死后，临危受命代掌擎羊殿，并被指定为攻打妖世浮屠三角晶界的人选，与香独秀、鸦魂三人大破三角晶界。

求影十锋十锋剑艺高强，在素还真闯入妖世浮屠遭受阴端佛鬼偷袭时，及时出手奥援，藏心剑化出犀利的剑气崩毁诛仙轮一角，瞬破阴端佛鬼的幻术结界；

而后在攻打火灵晶界时，面对阴端佛鬼分身以诛仙轮引动的火舌蔓延，十锋匣中剑出鞘，腾空一跃一招“十方剑原”顺势劈落，顿时漫天剑网铺天盖地落下，阴端佛鬼化身当场爆体而亡！

与香独秀、万古长空联手打败阴端佛鬼后，顺利升任天机院主。

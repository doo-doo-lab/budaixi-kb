# 破金眼

继武奎风之后，魑魔派出狙杀龙王鱽夫妇与魔婴的高手，能识破任何命门死角，与吸灵光、引路桀、魔灵手互相搭配，三方牵制、一方主攻，即便骁勇善战的龙王鱽也难以突围，最后被第三势力打乱战局。

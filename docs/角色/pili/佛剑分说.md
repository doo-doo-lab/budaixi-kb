# 三先天

霹雳布袋戏中组合三先天，霹雳布袋戏经典组合，堪称霹雳之中最出名的三教先天组合。三先天，也叫三教顶峰。登场于《霹雳劫之阇城血印》，三人为：剑子仙迹（道）、疏楼龙宿（儒）、佛剑分说（佛）。三人乃生死挚交，早期曾是至交好友亦曾是寇雠死敌，后曾三人合力一同将弃天帝送回六天之界。三先天风雨同路，共进退。

佛剑武戏名为《往生咒》，佛剑分说另有其他配乐，比如角色曲《佛剑分说》，受遮那八部刑时的配乐叫《圣行不悔》，变身修罗佛剑时的配乐《修罗再临》，悲壮曲《佛祭哀歌》，佛剑文戏曲《花妍雅舍》。

剑子武戏为《古尘现世》，对战魔界三将是《踏血》，偶尔也会用《三教先天》就是三先天驾临玄空岛时的配乐。

剑子的出场乐有《剑子仙迹》以及《豁然之境》，还有一段悲曲名为《哀弦》龙宿武戏为《龙吟啸天》，出场乐有《疏楼龙宿》《神龙再现》《紫龙再现》还有最最经典的《宫灯帏》豁然之境一盅茶，余香周旋伴飞花。

棋盘旁边，剑子等待好友的到来——华丽无双的龙宿，或是沉默少言的佛剑。

莫逆之交，不需要钱权，亦能亲密无间，不需要语言，亦能心照不宣，所以剑子在两位挚友的面前总是表现出不同的风格。

龙宿给剑子最多的形容词大概就是“寒酸小气”了，这丝毫不影响剑子的心情，取而代之的是与龙宿没完没了的吐槽。

# 三先天

================================================================================

霹雳布袋戏中组合三先天，霹雳布袋戏经典组合，堪称霹雳之中最出名的三教先天组合。三先天，也叫三教顶峰。登场于《霹雳劫之阇城血印》，三人为：剑子仙迹（道）、疏楼龙宿（儒）、佛剑分说（佛）。三人乃生死挚交，早期曾是至交好友亦曾是寇雠死敌，后曾三人合力一同将弃天帝送回六天之界。三先天风雨同路，共进退。中文名三先天别 名三教顶峰、三教流氓（老秦口中说出）配 音黄文择性 别男登场作品霹雳劫之阇城血印说 明霹雳布袋戏经典组合人物姓名剑子仙迹、疏楼龙宿、佛剑分说人际关系三人乃生死挚交人物创名黄强华人物原创编剧罗陵、三弦 （九皇座时期～天罪时期）后期接手编剧廖明治、周郎、太平、东山、邱继汗、登场周年2004年～2020年

## 人物关系

在雪峰之上，剑子仙迹与佛剑分说会面，讨论《嗜血年纪》记载的未来预言及邪之子降生事件，佛剑分说负责前往西佛国调查。剑子仙迹随后在宫灯帏与疏楼龙宿会面，商讨应对之策并求助查询“古师”信息，疏楼龙宿鼎力支持。

## 诗号

佛见三千破，渡生斩罪（佛剑分说）道见万物灭，杀生始元（剑子仙迹）儒见天下残，覆生归一（疏楼龙宿）杀生为护生、斩业非斩人（佛剑分说）何须剑道争锋？千人指，万人封；可问江湖鼎峰，三尺秋水尘不染，天下无双。（剑子仙迹）华阳初上鸿门红，疏楼更迭，龙麟不减风采；紫金箫，白玉琴，宫灯夜明昙华正盛，共饮逍遥一世悠然。（疏楼龙宿）三先天常常一起登场，代表着佛、道、儒三教顶峰。佛剑武戏名为《往生咒》，佛剑分说另有其他配乐，比如角色曲《佛剑分说》，受遮那八部刑时的配乐叫《圣行不悔》，变身修罗佛剑时的配乐《修罗再临》，悲壮曲《佛祭哀歌》，佛剑文戏曲《花妍雅舍》。剑子武戏为《古尘现世》，对战魔界三将是《踏血》，偶尔也会用《三教先天》就是三先天驾临玄空岛时的配乐。剑子的出场乐有《剑子仙迹》以及《豁然之境》，还有一段悲曲名为《哀弦》龙宿武戏为《龙吟啸天》，出场乐有《疏楼龙宿》《神龙再现》《紫龙再现》还有最最经典的《宫灯帏》豁然之境一盅茶，余香周旋伴飞花。棋盘旁边，剑子等待好友的到来——华丽无双的龙宿，或是沉默少言的佛剑。莫逆之交，不需要钱权，亦能亲密无间，不需要语言，亦能心照不宣，所以剑子在两位挚友的面前总是表现出不同的风格。龙宿给剑子最多的形容词大概就是“寒酸小气”了，这丝毫不影响剑子的心情，取而代之的是与龙宿没完没了的吐槽。宫灯深处紫龙现，华丽无双染天边。一双龙眼的背后，是让人永远猜不透的心思。紫金白玉箫琴奏，醉卧西风共逍然。看似悠闲的隐居，为了挚友再入中原，不惜向织语长心下跪……对于龙宿这样高傲的人来说，我只有两个字——佩服……十指轻挑琴弦起，笑看江湖入天际。华丽容颜的背后，亦是一颗坚毅的救世之心。010203040506雁过长空，影沉寒水，雁无遗踪之意，水无沉影之心。佛剑身负佛碟，杀生斩业，佛者修罗，谁能看得清这大千世界？世事纷纷如闪电，轮回滚滚似云飞。对于佛者来说，红尘得失，人与是非，只不过是人生舞台上旋起旋落的角色而已。而面对灭绝希望的世界，佛剑却愿逆天而为，哪怕是自身遭受再多的天劫……这就是圣行者的境界，任风吹过，任云卷云舒，花开花落……

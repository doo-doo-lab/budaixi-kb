# 如月影

如月一般虚幻不真实的神秘人物，面容数十年如一日，全身皎白如隐世仙人，可与天地万物交谈，能预知部分未来，如同神托者般。疑似魔界急欲找寻的无罪之人，为寻天命而来到海波浪。

## 角色设定

一月三身是指月亮的三种变化，即月体、月光、月影，而如月影恰是如月一般虚幻、神秘。他原是居住在海波浪·水净云天的奇人，面容数十年如一日，全身散发皎洁如月般的光辉。个性温和言谈间透露各种玄机，可以与天地万物交谈，并能看见部分未来之象。

## 角色经历

异度魔界大举进逼苦境，派出魔化叶小钗血洗中原，同时派出落日飘迹找寻万血邪录所记载的百年无罪之人，以开启邪录，破坏神柱，毁灭人间。而此时如月影神秘地回到海波浪，原来早在许多年前，如月影、一步莲华以及苍便预知人类未来的危机：“权利当心、物欲横流的时代，当破坏到极限，眼前的美景不再，人类终要面对毁灭的事实”；“人类总是在最后一刻才后悔，人间更因为七情六欲之魔道，引来天魔劫，也因此才有无罪之人，才有弃天帝下凡间，他既是毁灭也是再生”。无奈既定的命运终究无可逆转，如月影顺从其宿命回到最初的起点，并逐步迈向自己的终点。经常以天机开示天草二十六，但天草始终认为“神棍”的话不可信；亦曾指点过吞佛童子、银鍠朱武、萧中剑等人。后为了尽快开启邪录，伏婴师操纵时间流动之法，让如月影的生命加速流逝。并且趁天草迎战赭杉军之际，利用空间转移之阵夺取如月影之魂魄，万血邪录因吸收无罪之人魂魄而开启，神州血劫成为中原最大危机。

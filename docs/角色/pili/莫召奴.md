# 莫召奴

================================================================================

## 角色形象

名字由来霹雳集团董事长：黄强华先生黄强华：我想霹雳的每一个角色，他的名字都有他的含意，这是我所喜欢的。

譬如说：素还真、一页书、照世明灯、傲笑红尘、圣贤诸、蘅佛子、触念来，他们的名字里面，一定和他本身，所负的责任跟他的个性都是很适当。

那当初呢，因为在这个剧中，我急需要一个从东瀛过来的一个爱国志士，一个隐士。

所以说，我就设定莫召奴这个人物。

因为呢，之所以会用莫召奴这三个字，我想有两个原因：第一个，莫召奴他本身的个性，是认定世界上只有朋友同志，没有所谓的主仆的分别，他认为世间上没有奴才，所以说他才取这个名，他绝对不会说去召唤下人召唤奴才，他把人看作是非常平等的；

第二，就是因为他的造型，说实在的他是有一点女性化，所以说我就把他取个召奴这两个跟他造型比较配的女性化的名字。

那当然他本身是一个非常有个性的，顶天立地的男子汉，这是无庸置疑的。

因为造型和外表不能去决定一个人他的个性。

所以说，我创造莫召奴就是在这种情况之下，把他塑造形成的。

莫召奴人物塑造霹雳集团副总裁：黄文择先生黄文择：嗯，基本上莫召奴这个角色，他是一个很坚强的人。

当然我们刚才有讲过，他是一个多情多义，敢作敢当的一个角色，但是个性上，因为莫召奴经过战火的时代。

所以呢，他一直在找寻真理，在这个武林中，我们所演的武林中，他就是一个认命，认真，所谓认命就是说对这个武林他也很认命，那认真就是他认真在找寻真理的存在，所谓的真理，就是因为经过这些武林的风波。

这些战火，使得武林现局所造成的一种幻觉，就是说到底真假很难分辨。

所以呢，他的内心中一直要找寻他所认知的真理。

那这个角色，当然他是一个外柔内刚，个性上，在外表上，就是看起来好像很温柔。

其实，他是一个很坚强的人，所以在这个声音的部分，当然有比较困难。

当时要录莫召奴这个角色，我考虑很久，想说要怎样去找一个，内心很坚强，但是外表上看起来很温柔，这种角色。

所以用生，用小生的声音以及武生的个性去融合，然后才想到我应该用的莫召奴这种声音。

执行导演：刘金永刘金永：我对莫召奴的看法，他这个人看起来较公子型，不过他很有内涵，像他答应舞造论接下王者之路，对上汗青编这个邪恶的组织。

由此可见，这个人就是讲义气，讲信用。

主演：严宗裕严宗裕：有一场戏是为了文诏的风波，他跟素还真联手合作，故意败给了东瀛武士，让东瀛武士能顺利的取回文诏，这就是他智慧的一面。

戏剧指导：华文骅华文骅：这个莫召奴是属于小生型，和一般的武生喔。

武生的动作就是较大，较有眉角，但是莫召奴不行，很有礼貌，文质彬彬，所以和一般的武生不一样，所以他就是小生型。

造形设计：黄皇霖黄皇霖：刚开始接触到莫召奴这个木偶的时候，也想了好几次，思考了好久，然后开始做动作的时候，也有遇到一些困难，都不是很满意，然后到了快要上演的时候，哟唷，临时脑筋换过一个idea，然后才把他整装出来。

有心无心，心在人间；

多情薄情，情系江湖，莫召奴对自我的江湖路，早已有了深深的体悟，伊的沉浮尚未可知，伊的命运尚无定论。

但是，伊的形象将是霹雳世界的一展光辉，也希望热爱伊的观众，能继续支援伊的信念，你们的拥护，就是角色的生命，也是莫召奴由一尊木偶，化为一颗明星的动力，有梦最美……莫召奴手足情义【手足情义：素还真、莫召奴】俗语说‘兄弟是先天的朋友，朋友是后交的兄弟’，在多变且凶险的江湖路上，同路知心人已是难寻，兄弟手足更是无几，除却先天有血缘关系的亲兄弟、堂兄弟、表兄弟外，武林中不乏有志同道合、意气相投而结拜的金兰兄弟，与同出师门的师兄弟，然而，纵使手足情深、兄弟义重，有时在面临自身利益的考验时，往往都是兄弟阋墙，反目成仇，个中恩怨交织更是所有故事的纠结处。

莫召奴江湖中在缘分的契合下，如有同路知心的战友，有的会结义为异姓金兰手足，如素还真与青阳子便是在缘分的契合下结义为异姓金兰，而素还真与莫召奴则是同路又知心的战友而结义，这三位的金兰情义在霹雳中一直历久弥坚！

昔日，舞造论、龙眼佛、素还真、莫召奴，义结金兰。

除了有其共同的目标，最重要的因素便是互相吸引的气质，当其滚滚尘沙再添两抔黄土，素还真与莫召奴并未因此疏远，反而愈加亲密，这正是因为彼此的人格特性过于相近，莫召奴无法忍受东瀛局势混乱，不惜私自取走文诏并远渡中原，甘愿受故国骂名不断，更甚是背叛家乡，这一切，都是不让东瀛成为权势斗争、人民苦痛的战火深渊，所以怒而出走，怒而反叛。

而这反叛从来都不曾后悔，如同素还真一心只求武林和平，不愿使中原成为兵燹肆虐之地，天下一统何言不可，而是千万不能被野心份子所掌控，一旦有了野心，权力与人命对其便再无分别！

只要安定，管谁来统治天下？

但素还真看的广远，一名智者所考量的绝非当前，而是更长久的未来，在世人都义无反顾的选择了误解、憎恶且厌烦了素还真自以为是的理念时，莫召奴出现了，拥有太过类似的处境，也同样拥有着对天下感到愤怒的一颗心，不仅包含对时势、政权、与那渴求不满的迂腐世间，正是如此，莫召奴为素还真打破‘心筑情巢，夜不留客’的规矩，即便当下仍然迟疑着虚名，直到许久方才肯定素还真的为人，也认定自己并无错看，只因心中的牵挂太过深刻而无法放下，也无能放下，这怒，只对天下涛涛。

面对纷扰的江湖，素还真与莫召奴不约而同的选择了埋藏这份怒，用身外之物来掩饰，克制也抑住了情绪波动，素还真持拂尘，一还反璞归真的初心尽除亟欲滋长的不平之气，并纳白色纯洁的莲花心净挥洒拂尘间，心境渐趋冷静恬淡，惟有清心寡欲不问尘世，方为至真至粹的清香白莲；

莫召奴优雅洒脱独立红尘，习惯寂寞心若止水，文人般的品格德性，手执折扇合开合收，如同莫召奴脾性刚硬果断兼其圆滑通融，行低姿态隐逓俗世，不同于素还真的事事压抑，莫召奴该怒则怒，然，出发点却自始至终建立在自己最深沉的情感皈依，潜世踏尘，这瓣菊沁怀香攸然。

人的一生，由命与运交织而成，勾缠悲欢离合，或有或无的情感缠绵，隐酿的众口之悠，恰似柳欲静而风不止。

莫召奴和素还真都是重情重义之人，莫召奴待亲朋挚友的感情更深入骨，他一生追求情真意切，众生平等，和平相待，又有尊重“人性”的理念，如果他人的感情不纯粹，他情愿舍弃之。

所以能入他心的人寥寥数几，真正入他心者，他所在乎者，他都可以为之不顾一切。

而素还真不同，他心里装着天下人，他也在乎金兰手足情谊，他愿意与手足同生死共患难齐甘苦，但是他的心里始终放不下苦境的那些人，纵使天下人不理解他，他依然不能停止为此奔波，这才是那个江湖人口中的天下第一人，这才是那个人人口中的素贤人，掌握文武半边天的素还真。

初登场的莫召奴，一直维持‘心筑情巢，夜不留客’多年以来的规矩，无人能够打破，即使与莫召奴相交多年的九锡君也不曾受过特殊待遇。

然而，这样的规矩却为一个人破了例，那个人就是素还真。

莫召奴在初见素还真的时候，算不得印象好，因为江湖人口中的素贤人，第一次登上‘心筑情巢’之时就硬闯，甚至没有出声相告。

然而两人在一次次相交之后，莫召奴变得比任何人都理解这位江湖第一人。

理解他的苦心他的无奈他的天下大义，所以，在后来素还真无数次身陷险境的时候，莫召奴一次又一次救助他、帮助他、为他涉入红尘。

在《创世狂人》剧集中，素还真中毒昏迷，莫召奴在他身边悉心照料，并感慨‘素还真，你这一生多灾多难，都是为了天下人，可是又有谁能理解你？

若能换得你的生机，莫召奴甘愿付出自己的性命，素还真，我愿意为你牺牲，不知你是否愿意同样待我？’，而那时二人尚未结拜。《霹雳图腾》时期，莫召奴那句‘素还真还活着就有希望！

我要去找他，我一定要找到他！’更是情谊深重的典型表现，素还真被天策真龙大军追杀逼命，在他身边只有一个莫召奴，兄弟二人同生死共患难。《霹雳皇龙纪》时期，素还真与谈无欲合力斗六祸苍龙，素还真被六祸苍龙所重创飞出一瞬，原本在谈无欲身后的莫召奴瞬间前移第一时接住素还真，接着为救治素还真的伤情各处奔波，并一直陪伴其左右共为武林谋略行事。

后来，素还真为莫召奴去东瀛送行，在海边遥望到抚琴怀念莫召奴，二人金兰情义可见深厚，在莫召奴与军神一行离开中原已久后，莫召奴并没有被遗忘，当素还真初见到极道先生尚风悦时，尚风悦那句‘我不是你四弟莫召奴’又令多少人感慨万千。

## 角色经历
风暴时期：莫召奴以黑榜之人九锡君好友身份出场，劝说九锡君以义理为先，不可再为难素还真，虽身在情巢之中，心系江湖之事，自愿成为中原与东瀛黑榜的沟通桥梁，后因性情相投与舞造论、龙眼佛、素还真三人结为兄弟。

争王记时期：因天象异变，天策真龙将要为祸武林，为助素还真度过死劫，莫召奴在正南方生宫之位重建心筑情巢并成为南朱雀。

曾因指魔之事和非凡公子对上造成两败俱伤，后在毁地气的行动中和非凡公子一起行动，在猜心园被天策真龙拦路，非凡公子自爆猜心园，莫召奴顺利脱出。

天策真龙建立天策王朝，招纳武林人士，莫召奴不愿归降，在照世明灯提示下，去找寻素还真的下落。

皇龙纪时期：因桑道凉嘱托，紫宫太一请莫召奴重出查“三月浩劫”。

在查寻真相途中解救汲无踪，莫召奴查出三月浩劫主谋者为六祸苍龙，并意外在玄机门与素还真、谈无欲对抗六祸苍龙。

莫召奴以十里之围即心筑情巢方圆十里之内，六祸苍龙的人马不能踏入为条件，帮寂寞侯查寻夜摩市的真相。

六祸苍龙建立紫耀天朝之后，下达禁武令，并屠杀反抗者，心筑情巢方圆十里便成为避难所。

夜摩市真相乃是为东瀛进攻神州获取情报的组织，莫召奴为了阻止战祸，返回故土东瀛。

开疆纪时期：由于东瀛先锋营进驻中原，为阻止东瀛对中原用兵，莫召奴返回东瀛寻找鬼祭将军的遗物鬼之瞳，期间与神无月、草一色共同患难结为好友，在一页书与军神八柱山之战后获得鬼之瞳，取得内中的血誓书让各地领主联名上书天皇，终止进攻的行动。

神无月因此被解除军职，莫召奴也被通缉。

莫召奴假死于良峰秀泷的刀，与神无月、渊姬一同退隐海外。

莫召奴天命时期：与神无月等人分离，返回中原的途中被八歧邪神所抓，出现在示流岛，实为奈落川假扮。

其真身被邪神禁锢，后出现在心筑情巢，但仍被邪神控制无法走出心筑情巢，并失去部分记忆，故无法识别奈落川身份。

奈落川以莫召奴的模样在武林作恶，邪神为混淆视听制造与莫召奴相貌一样的黑夜鸣杀，时常偷袭正道，因此莫召奴也一度遭到正道人士的质疑。

最终被众人解救，与正道群侠共同对抗八歧邪神。

## 角色浅谈

有心无心，心在人间；

多情薄情，情系江湖。

有着珠玉般面容的君子，智慧武功气质都不凡的东瀛友人，却一生背负着被族人冠以的“叛国贼”恶名。

莫召奴从封灵岛定风愁的死隐退到造天六人阴谋浮现的复出，寂寞侯点破了他多年藏龙的原因，那来自东瀛的真田龙政。

揭露这一切政治的操控，消除隐藏的危机，是他的使命。

甚至知道夜摩市是个陷阱是个局，也义无返顾纵身其中，因为，君子有所必为。

如舞蹈般的忍术对付自己的家乡人，在绚丽的身影下隐藏的是无奈与痛心。

隐藏的危机日益明显，东瀛的先遣部队已经抵达海岸线，此时的他不得以要直接面对危机的源头，天皇所嫡系的势力。

从十九爷的私欲背叛、草一色、神无月的相交相知，落日故乡对鬼祭宗煌的苦心教导。

他所拯救的，是单单表面上的人命吗？

他本可以很幸福地生活，但是现实的残酷，让他与良峰贞义只能抛却儿女私情，而无可选择地一肩挑起民族大义。

他真是个“叛国贼”吗？

他是一心为中原吗？

不，他是一个真正深爱自己国家，自己故乡的热血男儿。

从不为自己所受的委屈辩解，一生的骂名对他来说早已无关痛痒，可以的话，他宁愿自己背负骂名而换来民族的昌盛平和。

对军神，他深知，唯有他才能将战争的伤害减到最小，所以，他能理解军神的用意，也能了解军神的无奈——有时候，一个人就算天下无敌，也有不能选择的时候。

莫召奴的爱国，是那些成天只会喊“誓死效忠天皇”的愚昧莽夫所能相提并论的吗？

仁者无敌，即便是武功远胜于他的大有人在，可是，他的爱国之心，已经站在了最顶峰。

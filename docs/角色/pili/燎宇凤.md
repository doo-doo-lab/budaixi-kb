# 燎宇鳳 (燎宇凤)
================================================================================

燎宇鳳

魔吞十二宮的鳳凰宮代表，沉默少言，臉戴鳳凰面具，一身赤紅裝扮宛如浴火鳳凰，身後揹著劍袋，登場時伴隨著燃燒的烈焰，並以金色鳳凰開道後現身。常與末日之狂一同行動，以指凝出熾熱雄焰，並將戰場營造出火焚四野、烈焰震宇的氣勢。

# 燎宇凤 (燎宇凤)
================================================================================

燎宇凤

魔吞十二宫的凤凰宫代表，沉默少言，脸戴凤凰面具，一身赤红装扮宛如浴火凤凰，身后背著剑袋，登场时伴随着燃烧的烈焰，并以金色凤凰开道后现身。常与末日之狂一同行动，以指凝出炽热雄焰，并将战场营造出火焚四野、烈焰震宇的气势。

# 关山聆月

================================================================================

霹雳布袋戏虚拟人物关山聆月，霹雳布袋戏虚拟人物，由黄文择配音，初登场于《霹雳震寰宇之龙战八荒》第2集，退隐于《霹雳兵燹之圣魔战印》第3集。身为集境太阴司祀嬛之一，负责祭祀祈祷，性格外柔内刚且聪敏机警，曾破解妖世浮屠奥秘并指导太君治制定作战策略，因解救千叶传奇而对其产生情愫，但因身份限制未果。关山聆月掌握排星移月、六华埋日等武学招式及缩地之术咒法，持有法器缚天紧。其诗词蕴含术法要诀，包含补境裂缝、寻踪定位等咒术应用。作为千叶传奇唯一情感牵绊者，多次使其做出理性让步，成为该角色人格完整化的重要推动力量。中文名关山聆月别 名祀嬛配 音黄文择性 别女登场作品霹雳震寰宇之龙战八荒、霹雳震寰宇之兵甲龙痕、霹雳兵燹之圣魔战印来 自集境根据地太阴司组织门派三仪三司十二殿人物创作者三弦初登场霹靂震寰宇之龙战八荒第二集退 隐霹雳兵燹之圣魔战印第三集本尊雕偶师洪剑山出场集数122集地 位太阴司祀嬛

_關山聆月**為台灣霹靂布袋戲人物，為集境太陰司三祀嬛之一，性格堅毅；雖是心地善良，但在行事作風上有其剛強果敢的一面。因緣際會之下解救了重傷，自時空亂流中漂流至集境的千葉傳奇，兩人互有好感；但在千葉傳奇協助燁世兵權策動集境政變後，**關山聆月**對其感到憤怒且不諒解。刻意的冷語嘲諷惡言相向，使的性格高傲自負，於武林中叱吒風雲的太陽之子，在她面前總是顯露出無奈、困惑、低姿態的窘態；然而每當聽到千葉傳奇身陷危機的消息，卻又會不自主顯露出焦急擔心的樣子。在經過連串動亂後，原本降落苦境大地的集境回到原本的空間，而**關山聆月_'和千葉傳奇也留在集境，暫時的自中原武林中失去蹤影。

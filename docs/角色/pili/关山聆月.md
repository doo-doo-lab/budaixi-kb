# 关山聆月

霹雳布袋戏虚拟人物关山聆月，霹雳布袋戏虚拟人物，由黄文择配音，初登场于《霹雳震寰宇之龙战八荒》第2集，退隐于《霹雳兵燹之圣魔战印》第3集。身为集境太阴司祀嬛之一，负责祭祀祈祷，性格外柔内刚且聪敏机警，曾破解妖世浮屠奥秘并指导太君治制定作战策略，因解救千叶传奇而对其产生情愫，但因身份限制未果。关山聆月掌握排星移月、六华埋日等武学招式及缩地之术咒法，持有法器缚天紧。其诗词蕴含术法要诀，包含补境裂缝、寻踪定位等咒术应用。作为千叶传奇唯一情感牵绊者，多次使其做出理性让步，成为该角色人格完整化的重要推动力量。

_关山聆月**为台湾霹雳布袋戏人物，为集境太阴司三祀嬛之一，性格坚毅；虽是心地善良，但在行事作风上有其刚强果敢的一面。因缘际会之下解救了重伤，自时空乱流中漂流至集境的千叶传奇，两人互有好感；但在千叶传奇协助烨世兵权策动集境政变后，**关山聆月**对其感到愤怒且不谅解。刻意的冷语嘲讽恶言相向，使的性格高傲自负，于武林中叱咤风云的太阳之子，在她面前总是显露出无奈、困惑、低姿态的窘态；然而每当听到千叶传奇身陷危机的消息，却又会不自主显露出焦急担心的样子。在经过连串动乱后，原本降落苦境大地的集境回到原本的空间，而**关山聆月_'和千叶传奇也留在集境，暂时的自中原武林中失去踪影。

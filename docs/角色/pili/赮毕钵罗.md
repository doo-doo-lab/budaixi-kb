# 赮毕钵罗

================================================================================

霹雳布袋戏虚拟人物赮毕钵罗，霹雳布袋戏虚拟人物，登场于《霹雳开天记之创神篇》第21章。赮毕钵罗是红冕七元之一，独来独往、冷漠少言，武学修为极高，超脱世俗之外，一身袈裟行于沙漠之中，有如苦行僧般找寻着红色的菩提树。而毕钵罗三字乃菩提树的别名，也意喻了兄长侠菩提在圆寂前，留给赮毕钵罗冥冥中的指引。在侠菩提的指引下，赮毕钵罗以“菩提斩罪”怒斩阎王，并继承十佛身份等重大天命。

## 角色能力

武器菩提长几，「几」通「机」，乃是对应着机缘、谜底之意。

长几乃是指在时间的长河下，所滔洗出来的答案。

它就在河岸边，等着偶尔休憩的人发觉及醒悟。

菩提长几菩提长几最特别的地方，是在于剑柄上长出一片菩提叶，可为赮毕钵罗遮风避雨。

而提供这么好的想法的人，就是周郎了。

当时他形容的眉飞色舞，有种「不用这点子是损失」的感觉，在周郎的坚持下，「菩提长几」就这样定案。

关于这点，周郎表示：这是为了表现出一种生机盎然的意象，从剑鞘上长出枝桠，萌发出菩提叶，也可以当做是帽子一类的头部造型装饰。

确定外型后，再去赋予它故事意义.武学潜龙排云、菩提一念·渡生之杀、菩提泣、醒圆明·一点证菩提、菩提之证、佛体离异、菩提圣气、圣引天诛万佛怒、转风卸雨、创神篇·【天泣、煅魔焰】、四教汇流·证道天武、初禅·心即剑、菩提灵禁所有物沙钵、随身玉佩、龙戬手札、金箭、毕钵罗子、黑檀佛珠、转经筒、《异识》、《创神篇》、三教本源、定光梭罗（已归还佛乡）

侠菩提赮毕钵罗的双胞胎兄长，天性善良、怜悯苍生，从小就有过于常人的成熟及佛缘，自然而然的向佛道而行，因而悟出超凡的圆融智慧，替许多迷惘之人指点迷津。

心知赮毕钵罗的存在，故在圆寂得道前以自己的方式留下机缘，即是红色的菩提树，冥冥中牵引著赮毕钵罗走向正确的道路。

而赮毕钵罗的一生，也自然以追随兄长的精神与天命而行。

而在红冕七元当中，赮与赦天琴箕最是交好。

赮毕钵罗有自己的道路要走，而赦天琴箕的绝杀琴音中，透出了不为人知的暗藏琴心，赮毕钵罗听出了一段隐藏过往，也因而出面调停赦天琴箕与御清绝之间的冲突。

## 角色经历
与龙戬的三合三离：与胞兄侠菩提为妖市禁忌的孪生子之故，被生父龙漪命龙戬处理掉，因龙戬心生不舍而私下前后托萍寓之主仰义及哑伯照顾，其间因仰义之死而流落乡野，被恶霸欺凌，衣食无着；

后无意间与龙戬重逢，龙戬便命哑伯负责照顾，并收赮为徒，教其读书识字，然好友千乘骑担心龙戬因此获罪而将哑伯毒杀，逼使赮离开龙戬；

再次找回侄儿的龙戬，决定亲自教养，教赮剑术及做人的道理，最后被龙漪以此为由定其叛国罪而处以献刑。

六年后，因昔日九灵泽的出卖，少年赮刺杀龙漪未遂，被当时还是隳宰的判神殛、独楼门主的傲因及迷蝶梦擒捉而判处献刑。

与少年侠菩提的初见：孪生子彼此不知对方的存在，直至少年侠菩提感怀失亲小鹿，龙戬不禁告知其亦有胞弟在这世上。

在千乘骑欲对少年赮不利时，射出金箭解围，后来更现身与之对话，这枚金箭与这番对话，在日后指引赮回想过往，与侠菩提相认，接续过去、未来之缘，开启菩提证道之路有关键作用。

成为红冕七元的「赮毕钵罗」：与八大献刑犯中的七人一同被成为深海主宰的龙戬以皇血复活。

他肉体不灭，更有深海主宰以异力加持，是以回阳后，便以原身复生。「毕钵罗」即为菩提树的别名，似乎也意喻了赮毕钵罗与沉剑湖下，所映照之菩提树有关。	在七元攻下平朔新月城、鬼方赤命成为红冕之王后，赮得平朔王赠名毕钵罗，自此脱离七元独身前往末法广漠浇沃从其心口血花中得来的毕钵罗子，而这颗毕钵罗子，正是侠菩提交予平朔王，接续赮与自己的天缘。

静待菩提枯树开花结子：长久岁月，赮每日以昆仑新成的洩沙浇沃，毕钵罗子渐长成天净沙，素还真身负曾以紫火之力为菩提树驱散邪祟的机缘，遵循天驮狮吼之命，为赮带来天罗子的慈悯之泪，使得菩提发出八片金叶；

素还真、齐天变再接受赮的请托，为其寻来阴冥八盅浇沃于菩提树，终得开花结子，得知了毕钵罗子的由来。

后离开天净沙，随心来至沉剑湖底的红色菩提树，得到菩提长几。

重返妖市的寻根之旅：受长几指引来到开天皇陵，寄于长几之上的侠菩提意识祭拜了龙漪，赮亦心有得偿所愿之感。

离开妖市之际，遭战栗公拦截，在交手过程中，从其武学得知战栗公便是当年偷袭龙戬之人，誓要在诛灭阎王后，一洗恩师之冤屈。

接续侠菩提未竟的天命：意方觉受圣僧侠菩提遗命，在与赮交手时，使长几不受控制，将赮毕钵罗转生入死，使其意识进入阿僧祇园，见到等待良久的侠菩提。

阻止九轮断去时间之流的关键，便是要让菩提种子为赮毕钵罗发缘而长成菩提长几。

过去的菩提长几属于侠菩提，如今再生的菩提长几则属于赮毕钵罗，因此，当长几长成，赮也背负起阻止九轮天的宿命，完成侠菩提未完之事。

三教之劫、幽都之乱：在解决三教内乱时以及逆三教的过程中，赮发现了三教本源的所蕴含的的万堺之秘，于是决意焚毁本源。

九轮天之劫平息，但幽都破封，谛佛主身亡。

三教再起风云，赮在圣众之潮吊唁过后在曙光鎏塔，受谛佛主灵识传授佛解四教汇流之招。

出关后，与中原正道奋力对抗幽都。

重建妖市在众人努力下，幽都之主万魔惊座被魔息大帝以同归于尽的方式消灭。

此役后，赮毕钵罗和师父龙戬回到怪贩妖市，共同经营和守护此地。

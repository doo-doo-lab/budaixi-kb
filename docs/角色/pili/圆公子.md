# 圆公子 (圆公子)
================================================================================

圆公子

八面玲珑之主，具神秘感以及翩翩贵气的美男子。玉树临风中，带有冷利的眼神，看似为人随和海派，却又会瞬间变脸、反复无常。家产雄厚、富甲一方，表面耽溺于宴乐歌舞享受，心里却是最深沉难解，故圆公子底下之美人与奴仆对其格外敬畏，丝毫不敢怠慢。

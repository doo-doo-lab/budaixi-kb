# 刁

刀无极所栽培的傲天武殿大将，个性沉默不语，练有石刀杀式，能以雕刻刀划出杀气袭敌，对刀无极十足的死忠，在其面临黄泉致命的逼杀时，刁挺身护主缠住黄泉，最后不幸为主捐躯。

### 角色经历

刁，刀无极暗中培养的势力，练有石刀刻心的杀式，性格沉默寡言，虽是不语，但对刀无极的忠心是无以言表的真诚，刁不负刀无极所望的完成了修行，替其卖命。在刀无极被黄泉偷袭重伤后，刁飞旋救主，拖延黄泉。为了让刀无极能顺利出逃，刁拼命死战，最终被黄泉所杀。

# 寒武纪

精灵天下錻锽玄脉之主，世袭“錻锽”之名，性情温厚内敛，不怒自威，曾在精幽大战联手天织主、兽王对抗幽界魔君。战后，伤势未愈，因故受夸幻之父逼害，爱妻灵后牺牲断后，錻锽带着爱子前往苦境，将帝诏隐藏在问天道，并改换身份易名“玄域天枢”，以独门枪法称霸枪界，成为初代天子枪，创立天枢世家。

### 角色经历

精灵天下·錻锽玄脉之主，世袭錻锽之名，武冠当世。曾在精幽大战之时与天织主、兽王联手对抗幽界魔君。精幽之战过后，遭遇夸幻之父，重伤之余，诸神之缨、《玉玺之命》枪谱接连失落，落入夸幻之父之手。爱妻灵后为保其子自我牺牲，引动同归秘法阻止夸幻之父。后来夸幻之父不知何故，中断追踪。为隐藏身份，将帝诏隐藏在问天道，并改换身份，化身玄域天枢，称霸枪界，成为初代天子枪，建立天枢世家。后来，其真实身份引起枪界高层怀疑，天枢世家更接连发生血案，对方的动作越趋极端，为防万一，写下《天枢手记》，并将爱子送往隐秘之处，寄望来日能长大成人，继承帝诏，与之共鸣，使錻锽血脉再续辉煌。最终被玉梁皇带人围杀而死，死前为保孤星泪，将其变为哑巴。

### 相关记录

孤星泪之父，原是精灵天下之錻锽玄脉之主，世袭錻锽之名，曾在精幽大战之时与天织主联手对抗幽界魔君。战后因故带着爱子前往苦境，将帝诏隐藏在问天道，并改换身份，成为玄域天枢，称霸枪界，成为初代天子枪。（会刊）

### 其他记录

古原之战：传说中有万灵源头之称的精灵天下，为阻魔君统领的魔界祸世，由其中数脉主战派领导，于毕方山古原，与魔君决一死战。绵延九九八十一天的焚世烽火，将战场烧成焦土，一时间血流成河、积骨成山，精与魔双方皆伤亡惨重。就在天织一族的领导者禁城罂粟与魔君同时倒下那一刻，天降滂沱，大雨如同上苍之泪浇熄了战火，也将精与魔二方的遗骨，并同所有的神兵魔器、奇珍异宝一同埋没洪荒，帝诏之主与阙九重也就此失落，只留下那诸神之缨。

天枢手记：我，玄域天枢，本为精灵天下之錻锽，寒武纪。精幽之战过后，受贼人迫害，辗转流落苦境。重伤之余，诸神之缨、《玉玺之命》枪谱接连失落，落入夸幻之父之手。爱妻亦受迫害，为了保全孩子，自我牺牲。后来夸幻之父不知何故，中断追踪。我为了隐藏身份，便以玄域天枢之名，建立天枢世家，成为初代天子枪。而今，我的真实身份，引起枪界高层怀疑，枪门正统，不容外族之人占据，以此等胸襟，决定枪中天子谁属，不亦悲乎！连日来，天枢世家接连发生血案，连番对战中，我发现其中一名覆面人身藏太阳图腾，对方的动作越趋极端，我身死何妨，但稚子何辜！为防万一，我特立此文，并要在最短时间内将爱子送往隐秘之处，寄望来日此子长大成人，能继承帝诏，与之共鸣，让我錻锽血脉再续辉煌。

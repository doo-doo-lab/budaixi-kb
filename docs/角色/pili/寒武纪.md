# 寒武纪
================================================================================

寒武纪

精灵天下錻锽玄脉之主，世袭“錻锽”之名，性情温厚内敛，不怒自威，曾在精幽大战联手天织主、兽王对抗幽界魔君。战后，伤势未愈，因故受夸幻之父逼害，爱妻灵后牺牲断后，錻锽带着爱子前往苦境，将帝诏隐藏在问天道，并改换身份易名“玄域天枢”，以独门枪法称霸枪界，成为初代天子枪，创立天枢世家。

# 火貓 (火猫)
================================================================================

火貓

原為亨王金甌無缺所飼養的寵物貓妖，卻因性格跋扈調皮而轉由藍燈子管教，天性暴躁好動，容易與人起衝突，故常被藍燈子管教訓斥。而在藍燈子戰鬥時，能招喚出火貓化成神器「紫宸祭劍」展現高超劍藝。

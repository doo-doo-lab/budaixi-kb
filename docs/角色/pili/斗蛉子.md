# 鬪蛉子 (斗蛉子)
================================================================================

鬪蛉子

截山三不修之一，個性幽默中帶點毒舌，看似是無為的妖修關者，實者是歸界外放的質子，有王者血統。在某些時候，規矩特別多。有一份深藏在心的驕傲。與鳴沙流年同為截山高端修關者，稱鳴沙流年為師兄，視閃焰為師弟。

# 悬壶子

================================================================================

霹雳布袋戏中的角色悬壶子，霹雳布袋戏中的角色。道门玉清界三壶的领导者，手持炼壶松拐，个性较为慵懒，不喜多管闲事，对朋友皆抱持君子之交淡如水的态度，但其实嘴硬心软，对好友暗自关切，故常被一灯禅拖下水。悬壶子同时也是重造天道明火的五仙人选之一。

## 角色设定

悬壶子名称：悬壶子称号：风鬙寿岳身份：五仙人选之一诗号：漫劳海内传名字，不论腰间无有悬。深奥自惭称道者，纵行奇想托神仙。初登场：霹雳兵燹之圣魔战印第16集退场：霹雳兵燹之圣魔战印 第36集（被端木燹龙以焚如要术毁容，后死于海蟾尊）来自：玉清界根据地：瀛洲风藏府

## 角色能力

- **武学**: 返璞归真、道源真昧、辟心念化、广览壶天所有物：炼壶松拐

## 角色关系

- **齐名**: 海蟾尊、祖鸿钧（玉清三壶）部署：徐影神翁、四极仙郎师兄：海蟾尊朋友：一灯禅、靖沧浪同伙：徐影神翁、四极仙郎、沐嫦妃、风流斋主

## 角色经历
玉清三壶悬壶子玉清界三壶：蜃海蓬莱·云笈观、瀛洲风藏府、方丈雨卷楼。

其中蓬莱云笈观于霹雳九皇座中登场，是由玄武真主所领导，后以凋零，瀛洲风藏府现今道脉仍盛，而方丈雨卷楼则最是神秘。

阴火绝式悬壶子所修炼的道源真昧为天下三大阴火绝式。

最早出现在在霹雳九皇座中，由段忍口述而出，三大阴火绝式分别是邪火魅指、冷焰血掌、道源真昧，能以人力发出至高阴火，邪火魅指出自易家，冷焰血掌出自墨家，后来疏楼龙宿为了破解冰楼的冰封，曾向墨家的领导墨宗嗣借用了一台能发出类似墨家冷焰血掌阴火的特殊机关。

最终退场一灯禅和悬壶子在壶口烽燧等靖沧浪，正好端木燹龙前来索要魂铁，但他俩并不知道那是什么，一言不合，随即动手。

危机之际，一灯禅为悬壶子挡下端木燹龙杀招，当场毙命。

悬壶子被掳走，用来要挟靖沧浪交换魂铁。

然后燹龙狂虐悬壶子，并毁其容貌，然后扔在靖沧浪面前。

悬壶子知道端木燹龙不会遵守交易，让靖沧浪杀了他，不让端木燹龙奸计得逞，然而却靖沧浪不忍下手，此时海蟾尊擅自做主，一掌击毙悬壶子。

注释：魂铁其实就是悟剑声的佩剑—神意，亦是靖沧浪的好友—冷孤寒。

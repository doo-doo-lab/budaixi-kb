# 驺山棋一

================================================================================

霹雳布袋戏中的角色订阅0有用+10驺山棋一，霹雳布袋戏中的角色，由黄文择配音。驺山棋一是隐居驺山洗棋亭的异人，本名凤隐鳞，天生命格特殊，以筑墓盖命之法，为自己盖命而避开天命轮回。棋一本身命带阴符，擅使阴力，具有特异奇能以及经天纬地之才。在洗棋亭祭告天地后，正式宣示入世，辅佐槐破梦创建胤天皇朝，成就一番霸业。中文名驺山棋一外文名zōu shān qí yī别 名凤隐鳞 配 音黄文择性 别女登场作品霹雳兵燹之问鼎天下霹雳战元史之天竞鏖锋组 织胤天皇朝来 自浮光海市所有物长命灯、天子之尺、折扇、琴根据地驺山洗棋亭、隐鳞苑人物创作者申呈山（素问）本尊雕偶师涂信豪出 场68集身 份海市八奇之一、胤天皇朝亚父

## 角色设计

名号驺山是一座山名，驺山里只住了一名棋者，于是「驺山棋一」就这么出来了。而要玄乎玄的去解释这个名字，其精华就在「一」字，一字有无限解，是棋中之首，亦能作归一、统一之解，更或，一为万象复始之象，从繁化简等等意解。棋一原名凤隐鳞，因一桩恩仇而隐姓埋名，后以盖命之术，为自己隐去主命，改以驺山棋一的面目再现。以驺为命，则是引用传说中的动物驺虞，天性善良的驺虞据说不直接猎食活着的动物，有仁兽之称，古代常被拿来当做至仁象徵来谄媚皇上。洗棋亭棋一命带阴符，天生鬼体，其阳世命格少半，原该一出世便夭折，但得其师尊，以异术为棋一延命，更教她一套特殊修练密法，让她为自己盖命。棋一依据驺山地气，为自己排设奇阵，以一亭一墓做为阵眼，「亭」取意停止、静止，「墓」则有沉眠之意，她以奇门异术，将自己的八字埋入墓中，让自己的命数暂时运转，其间以魂体行走江湖。待槐破梦命格成熟之后，她之本体再破墓而出。常言道：「芭蕉藏鬼，柳树招阴」，洗棋亭里的芭蕉树及柳树，便是养阴之用。造型造型为了强调棋一刚烈性格与柔弱外表的冲突美，造型时为她选用柔软的蓝色毛草以及轻柔的粉红纱作搭配，使得棋一看起来相当具有知性美。长命灯此为棋一之本命灯，上书有特殊符文，加持法力，每当棋一心绪有所浮动时，长命灯便会闪烁不已。长命灯的外型，编剧指定须为如意造型，并垂挂小灯笼。道具组在如意尾部精心设计了一个小机关，能够随风转动，道具组给予的意涵为「转乾坤、动日月」。

## 角色生平

关于棋一的过去风离相版（问鼎36）为借坤舆墨斗与皓眉仙藏言：在寄辛先宗布法中，凤隐鳞原该得享天年六十而命终，谁知她在十六岁那年，因异术修练出差而走火入魔，就此昏迷不醒，醒后，其言行已与过往有异，其玄异能为，亦让人惊诧，先宗细问之下，方知凤隐鳞昏迷的那半年，曾前往一特殊结界之地——中阴界。据棋一透露，此地乃是生与死的中继站，此界之人亦为生人，但其生活方式十分特殊，似是自成一格之地界，其景色也异，为一处生人与活魂共处的空间。传闻浮光海市的高阁上沈睡着一名仙家少女，如今仙家少女醒来，此乃浮光海市之大事。那一日，浮光海市极为沸腾，寄辛先宗为凤隐鳞能醒过来十分高兴。谁知，当棋一步下高阁那时，浮光海市竟无故半壁山河遭到灭顶，浮光海市之人口，竟少了一半。这一日的欢庆，变成了哀恸。海市之人见此无故之灾，皆有联想，但不敢直言宣之。风离相原想此乃巧合之厄，焉能尽怪一人身上。但先宗与凤隐鳞深谈之后，便开始造刀，而且从此以后不再开口与任何人说话，甚至他疼惜若命的凤隐鳞亦是冷漠以对，两人形同陌路。六年后，寄辛先宗与凤隐鳞约战浮光岸，无人知晓战斗过程如何，只知寄辛先宗身负重伤，拖命而回，而凤隐鳞则不知所踪。先宗交予沧耳刀，他说这口刀以五色石铸成，因铸刀火侯有失，乃致刀身有缺，其刀入邪，难以驾驭，须以女娲补天之理，重铸此刀。沧耳取意斩鬼之用，是先宗凝毕生功力所铸，其刀威能，能转天下阴命，专门铸来对付凤隐鳞与背后阴力。但沧耳刀野性难制，其刀尚未认主，若无相应命格之人运使，刀出了鞘，将是另一场灾难的启生。先宗简札记载，棋一与中阴界缔约，中阴界控灵者助棋一运使阴力，而棋一要在得天下后，为他释放黑暗力量。风离相曾立誓，若将凤隐鳞之来历宣之于人，便要死于非命。无计先生版（天竞08）被殢无伤所伤，自知将死，临终前与素还真言：棋一原名凤隐鳞，是寄辛先宗之爱徒。数百年前因弑师之案而被逐出了浮光海市，而逐出之理由除了寄辛先宗之命，还有浮光海市半壁人命。她与中阴界有所缔命，以玄异手段取得阴兵，要除掉棋一除非入中阴界，斩断她阴兵之源。浮光海市有一口沧耳刀，据闻是寄辛先宗特别打造出来针对棋一。薄棠版（天竞11）告知前来询问的素还真：据风离相转述，棋一为了向先宗展示自身阴力有成，是以祭阴法引动海啸，淹没浮光海市半壁土地。先宗原意为她盖下此恶，只要她肯斩断与中阴界之联系。怎料棋一拒绝，于是两人断绝师徒关系。棋一习有阴功，常法或许能伤她，却无法取她性命。听闻当初寄辛先宗与棋一在浮光岸之决战，沧耳刀已入体剖心，但棋一却得到阴力为之护体，拾回一命。是故寄辛先宗交待，要除棋一，须入中阴界斩其阴源。寄辛先宗当初是以五色石铸炼沧耳刀，但因铸刀火候有失，乃致刀身有缺，导致此刀刀煞难抑，须寻七重天火鳞重铸其身。若能让沧耳刀认主，除了刀煞能除之外，其刀神力亦能冲破极限，到达完美境界，届时便能劈开中阴界通道。中阴界版魅生对灵狩言(天竞14)：许久之前，缎君衡借了六只阴魂给那名误闯中阴界的苦境女子。宙王对素还真言(天竞16)：多年前，一条苦境野魂闯进中阴界，让缎君衡收留一段时日，并达成契约。驺山棋一版回忆（天竞18）：云苑中，两人对弈，凤隐鳞胜出，先宗却预言，凤隐鳞将连败十场于他。凤隐鳞疑问，莫非是她大限将至，先宗欲以她之好胜心激起她求生之念？寄辛先宗声称，在他未肯点头放人之前，天不能收她。寄辛先宗与凤隐鳞对战浮光岸，从此师徒情断。凤隐鳞当天立誓，此后将不再使用先宗之法，违者命折其半。回忆（天竞28）：凤隐鳞向寄辛先宗表示，那半壁人命非她所为。但先宗观其身，阴能分明有噬灵余迹，而且怨灵掩元。于是寄辛先宗只要凤隐鳞斩断与中阴界所有联系，便相信她这次，并替她担下这半壁人命。将所知告诉素还真（天竞33）：此长命灯，乃是寄辛先宗为凤隐鳞续命所造，先宗视其为嫡传弟子，将毕生所学尽书在灯内传授于她。当初凤隐鳞为先宗一句话而斗气，最后竟走入如此歧途，这是她始料未及，或许她魂体无意进入中阴界就是一切变调的开始。当初凤隐鳞魂游中阴界，初遇身陷囹圄的缎君衡，他以游戏之态助其定魂，更让她一窥中阴界控灵术之奥妙，凤隐鳞一时鬼迷心窍，便与他缔定灵者之约。在交谈中，他对苦境灵法颇有兴趣，凤隐鳞便告知三教书典(争鸣雪卷、皆空元典、养神丹箓)中，应有他所不知之造灵心得。双方约定，凤隐鳞为他取来三教典籍，缎君衡借六只阴军于她。对阳息已尽的槐破梦言（天竞35）：自小，凤隐鳞便看先宗编缠着头发，那时她问先宗，为何不将头发放下？他说，人的青丝是情丝，心中无人的时候，才可以随风而散。先宗一派，将头发编起，就代表心中有人。驺山棋一·凤隐鳞

## 角色评价

驺山棋一，好胜之心蒙蔽了本该清明的双眼，执着一生，血洗三教，挥兵天下，身负的罪孽已难清偿，所幸，槐破梦的付出，让驺山棋一选择放下执着，也悔悟过往亲手铸下的血腥，泥犁森狱漫漫长途，不悔的旅途，默默延续着另一则执着的故事。

## 角色配乐

告天地曲/编曲/演唱：阿轮、词/何沅谕 收录于《霹雳英雄音乐精选三十四》一首类似歌仔戏乱弹戏曲「阴调」的演唱曲。这类曲风通常是以小行板搭配高亢旋律和激愤凄怨的歌词呈现，且为了合乎需求，阿轮老师特别以歌仔戏乐器声响全程伴奏，强调节奏音律的特色，情绪时而飘忽、时而豪迈，声调时而婉转、时而激昂，让整首歌曲更为戏剧化。歌词：天清呐～地灵啊！巍巍荡荡子魂飘呐！靐填填兮雨冥冥啊！(语出∶《楚辞╱九歌·山鬼》)动时命兮风云啸啊！神兮长在有无间！(语出∶《李贺╱神弦》)山鬼吹烟百姓家，人间底事问牛马。(语出∶《李贺╱示弟》)百年一待浮光影，临照寸心逐天下！天清呐～地灵啊！翻掌千秋定曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十五》丁天牧老师以「神武」为题创作，管弦乐演奏豪迈奔放的旋律，结合重金属元素的强烈节奏，营造出气势磅礴的氛围，犹如天地雄气、千秋凛然的神武风采。驺山凤隐曲/编曲：阿轮 收录于《霹雳英雄音乐精选三十五》以琵琶为主奏的东方新世纪曲风。由于驺山棋一定位是名先天女智者，其举手投足之态势在质量上远超过一般文武旦，因此曲调以徐缓的中慢板行进，并搭配华丽灵巧地轻敲击乐器声来妆点棋一的优美灵犀。琴韵禅音曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十六》丁天牧老师2011年作品，以「琴韵禅音」为题想像创作，乐曲以古筝弹奏禅风曲调，琴音幽缓空灵，静谧飘渺，引领听者进入一种玄奥的冥思时空。乐曲常用于棋一抚琴冥思之意境。情愫曲/编曲：丁天牧 收录于《霹雳英雄音乐精选三十七》情如风、意如烟，琵琶一曲过千年……轻盈的琴声，弹起抒情的旋律，柔美婉转的动人曲调中，蕴藏着淡淡的伤感与柔柔的情怀。槐破梦与驺山棋一，本是君臣关系的两人，却在相处中不知不觉萌生情愫。祸荡天下曲/编曲：浩旭 收录于《霹雳英雄音乐精选三十七》浩旭老师创作，开场以管弦乐雄浑的气势，伴以古乐器「埙」吹奏出浩瀚江湖、壮阔大器的临场感。乐曲常使用于胤天皇朝气势或收幕曲：驺山棋一作法血祭阴军、素还真代无计先生与棋一约战浮光岸等桥段。

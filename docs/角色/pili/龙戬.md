# 龙戬（动画片《超兽武装》及其衍生作品中的角色）

龙戬是动画片《超兽武装》及其衍生作品中的角色。超兽战队的队员之一，身负维持宇宙间平衡的使命，在七大平行宇宙连接的七天内同队友迎战各路强敌，并同欲称霸宇宙的鬼王展开最终决战。七大平行宇宙分开后，龙戬回到属于自己的世界，等待轮回。

## 角色形象

身份背景第二平行宇宙的龙戬是青龙族的族人，青龙族领袖剑龙的徒弟，龙族最强的斗士，能够进入永恒轮回的强者；

超兽战队的队员之一，身负维持宇宙间平衡的使命；

因与冥王的赌约而成为过冥界战士。

第一平行宇宙的龙戬则是一位就读于BlueArc International中学的学生。

相貌衣着龙戬有着青蓝色的长发和眼眸，作为超兽战士身着无袖的连体衣裤为短袖和长裤，色调为蓝白拼色，两边上臂戴有臂环，两边手腕戴有金色手环，武装形态下身上覆盖着青蓝色甲胄，头盔为龙首造型，佩戴上冥王的披风后一度化作黑色的冥界装扮。

第一平行宇宙的中学生龙戬上身穿着黑色内搭，外穿白色的短袖校服，下身是青蓝色的校服裤，两边手腕戴有青蓝色手环。

角色设定龙戬性格特点龙戬是一位冷静、沉着，绝不蛮干的技巧型战士，拥有过人的智慧。

外冷内热，表面冷漠高傲、内心却感情细腻，不轻易表达自己的真实情感、不善于表达自己的内心世界，但是很在乎伙伴。

因剑龙的教导下知晓生命的重要，但认为有一样东西比生命更重要，那就是——信念。

## 角色装备

简介图片异能锁一个激发异能量的装置，青色龙首造型。代表龙族最高荣誉，龙戬成为龙族最强的斗士后获得，沾染蝎毒变异后转赠于龙莹，龙莹死后消散。异能锁龙战武装龙戬专属的武装形态，龙戬战斗时基本身着此套武装。龙战武装龙战闪驰龙戬专属的闪驰武装，交通工具和作战装备。一辆青蓝色的摩托车，车身为青龙造型。有摩托车、飞行器、滑板三种形态。龙战闪驰龙战兽—龙战神龙戬专属的超兽武装，分为龙战兽（兽形）、龙战神（人形）两种形态，能同其他超兽组成合体机甲超兽神。龙战兽—龙战神

## 角色能力

异能量值龙戬初登场时异能量值为0.2个黑洞，冥界大战时至少0.5个黑洞，回到十万年前为0.8个黑洞，大结局为3.5个黑洞。绝招简介图片寒影诀龙族绝学中最高深的技能之一，比寒冰掌更为强大，有着“攻敌三分，自留七分”的口诀。需要先在自身周围制作出冰棱，然后用异能量包裹冰棱破裂后的碎片形成冰针，高速射向敌人。由于冰针的数量多而密集，仿佛是没有子弹限制的机关枪，以寡敌众时尤其有效。寒影诀

## 人际关系

关系简介师父剑龙青龙族领袖，传授龙戬战斗技巧并教导其生命的重要性。师兄战龙与龙戬一同师承于剑龙，于比武大赛上争夺龙族最强斗士时败于龙戬。队友火麟飞、苗条俊、天羽、泰雷、夜凌云、风耀、风影于七大平行宇宙连接的七天内一同组成超兽战队，维持宇宙间的平衡。

## 角色经历
蝎王来袭龙族的比武大赛上，龙戬凭借寒影诀打败了师兄战龙，成为了龙族最强的斗士，获得了代表龙族最高荣誉的异能锁。

玄武号飞船来到第二平行宇宙之后，龙戬奉命离开龙城前去查看情况，因此避过了龙莹对青龙族的屠戮。

同火麟飞交战时，龙戬发现龙城情况不对，赶忙回到龙城，发现留在城内的青龙族都已经被杀死。

天羽为护龙戬而被龙莹使用蝎尾毒刺重伤后，龙戬和火麟飞一起联手对抗龙莹，二者不敌能够召唤超兽的龙莹，想尝试召唤出超兽，但火麟飞一召唤超兽就全是列火焚身，而龙戬则冰冷无比，在危机关头幸好苗条俊驾驶这玄武号救了他们，却忘记了天羽尚且留在城内。

为了救援被困在龙城内的天羽，火麟飞负责前去正面挑战龙莹，龙戬则在后方将天羽救回玄武号飞船。

火麟飞负伤陷入重围时，龙戬赶回救援，与火麟飞一起迎战龙莹，但终究还是不敌，龙戬和火麟飞被双双打败。

重伤倒地的龙戬和火麟飞热血交融，完成了异能量聚变。

苗条俊看出玄机，立即为他们进行异能量配对，令二者成功召唤超兽。

经由玄易子指点，龙戬与火麟飞成功进行超兽神合体与龙莹互相抗衡。

双方两败俱伤之后，龙莹和龙戬的异能量恢复速度较快，两人再次交手。

龙戬不敌，被龙莹强行摘下头盔后，龙莹认出他就是十万年前救过自己的黑衣人。

不明缘由的龙戬趁龙莹惊讶分神之际使出寒影诀打中龙莹胸口的弱点，将其击杀。

蝎王来袭对抗鲸鲨由于龙戬的族人都已经被屠戮殆尽，所以在火麟飞和苗条俊邀请之后，龙戬决定加入超兽战队，共同前去阻止冥王的复活。

来到第三平行宇宙后，为了助泰雷及其族人摆脱鲸鲨族的奴役，龙戬与队友同鲸鲨王展开交战。

龙戬和火麟飞的超兽神二合体渐渐不敌鲸鲨战神时，天羽成功召唤出凤羽兽。

经苗条俊辅助调配异能量在机体里的分配，龙戬、火麟飞、天羽三人成功进入超兽神三合体模式，但超兽神还是不敌鲸鲨战神的黑海深渊。

超兽神就要被吸进黑洞之际，泰雷召唤出雷象兽将鲸鲨战神撞入黑洞。

鲸鲨王从黑洞返回后，龙戬、火麟飞、天羽已因异能量消耗太大而无法进行超兽神合体。

泰雷、苗条俊为龙戬他们争取时间，并在鲸鲨王有意纵容后，龙戬他们得以恢复异能量再度应战。

双方相持不下时，鲸鲨战神被雷象神的奔雷诀击中后背弱点，鲸鲨王也因此被击杀。

对抗鲸鲨团灭云蝠泰雷加入超兽战队，与龙戬、火麟飞、天羽合力消灭云蝠战队后前往第四平行宇宙。

云蝠军团将龙戬等人重重包围后，夜枭子出手欲解决龙戬等人，却被龙戬他们反攻回去。

夜枭子恼羞成怒，下令全军一起上。

但就在这时夜凌云出现喝住了众士兵。

夜凌云遵循公平对决的规则，每一次决斗都是以一对一的形式展开。

龙戬上场后凭借从容的作战境界，夜凌云由于轻敌输了一招。

夜枭子见状，出手偷袭龙戬，并要将他置之死地。

龙戬即将惨死在夜枭子爪下，关键时刻夜凌云及时喝止。

夜枭子于对决中的所作所为令夜凌云实在看不过眼，遂出手救了龙戬他们，还为他们疗伤。

龙戬等人恢复后进行超兽神合体，但不敌受云蝠阵增幅的夜凌云。

夜凌云遭夜枭子背叛后，不得不与龙戬等人合作，毁掉了夜枭子领头的云蝠军团。

团灭云蝠冥王复活收到冥王的命令后，夜凌云带龙戬等人前往冥界。

由于冥界引力的干扰，龙戬、火麟飞、泰雷三人节节败退。

苗条俊将从Baboo家族获得的异能量转移给龙戬三人，令他们突破引力干扰，但依然被冥王阵营死死挡住，没能成功阻止冥王复活。

复活的冥王将龙戬等人封入玄冥黑洞。

冥王复活双强对决天羽于玄冥黑洞不慎陷入危机时，救女心切的冥王不得不将玄冥黑洞中的超兽战队及雪皇阵营放出。

和谈失败的雪皇和冥王展开决斗，二者将要同归于尽时，龙戬、火麟飞、泰雷同夜凌云联手阻止了雪皇和冥王的决斗，却也因此被打入错乱的时光隧道，回到了十万年前。

双强对决赌约初立龙戬被打回到了十万年前的第五平行宇宙，卷入到冥王和雪皇两方阵营的大战中并还救了年轻时的冥王。

龙戬想劝此时的冥王放弃与雪皇的战争，然而二者的理念有所冲突。

冥王为了验证他自己的说法和龙戬打赌，让龙戬以狼族的装扮前往第二平行宇宙见证一下真实的世界。

龙戬答应，穿越时空前往十万年前的第二平行宇宙。

赌约初立龙族内斗龙戬一回到十万年前的第二平行宇宙，立即受到了一条毒龙的袭击，幸好被十万年前的剑龙救了，剑龙还把龙戬带到比武现场，观看他与龙飞的比武。

在比武现场，龙戬亲眼看到了十万年前剑龙和龙飞的那场比武，还知道了导致青龙族和白龙族反目成仇的龙飞死因真相其实是剑龙从巨龙毒爪下救出龙戬时，盔甲上沾染了巨龙的毒，而刚好他的盔甲刮伤了龙飞，导致龙飞中毒身亡。

比武场上青龙族和白龙族大打出手，然而因为同冥王的赌约，龙戬无法出手干涉。

当龙飞的小女儿龙莹也面临杀身之祸时，龙戬终于按耐不住，为了救龙莹而大开杀戒，将在场的青龙族人统统杀死。

当龙戬的异能锁被伴随小女孩的蝎子刺中变异后，龙戬知道了自己所救的小女孩，将是十万年后他亲手杀死的龙莹。

龙戬彻底崩溃、信念全消。

将自己的异能锁送给龙莹并将其送往冥界时，龙戬还叮嘱她在未来遇见自己时务必先出手杀死自己。

龙族内斗赌局落败苗条俊穿越时空于兵荒马乱的第二平行宇宙找到已如行尸走肉的龙戬，试图帮龙戬重拾信念，可是龙戬完全不听，苗条俊在逼不得已之下将龙戬打晕，强行将他带走。

龙戬随苗条俊、泰雷、夜凌云来到第五平行宇宙时，因同冥王的赌约失败而留在冥界加入狼族部队。

赌局落败重拾信念冥王被封入玄冥之棺后，龙戬等人从鬼谷手中抢夺玄冥之匙并让玄易子带走，为冥王留下复活的机会。

发觉自己已经成为冥界战士后，龙戬等人开始分辨不清自己的立场。

苗条俊以玄易子传授的道理开导龙戬等人，令他们明白超兽战队的真正使命是维持宇宙间的平衡而重新振作。

重拾信念最终决战龙戬等人依靠自身的信念将体内的异能量提升十倍，得以随苗条俊返回到十万年后。

龙戬等人同鬼王展开决斗并占据上风，但夜枭子率云蝠军团以云蝠阵为鬼王传输能量后，龙戬等人陷入被动。

苗条俊拼死为龙戬等人拖延时间，令他们得以接收冥王和雪皇的能量再次迎战鬼王。

向鬼王发出最后一击后，七大平行宇宙分开。

超兽战队的所有队员在一瞬间回到了属于自己的世界，等待轮回。

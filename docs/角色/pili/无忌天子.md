# 无忌天子
================================================================================

无忌天子

温柔和善、淡泊名利，是三才子中专研科技的高才生；行走武林结织六弦，创建天外方界，共同为世外净土的理想而努力。与六弦之一的愁月仙子相互倾心，以诈死遁世躲避世俗一切烦忧，本来都是与世无争，但武林似乎总嫉妒有情人，随着愁月的身亡，无忌也积极介入东瀛黑榜之中，藉冒充紫绶一品欲查出幕后主使，最终还是被查觉而殒命。

### 角色经历
无忌天子生于乱世，一生喜好和平，不忍苍生涂炭，于周游列国时结识了六位奇人异士，即傲笑红尘、白云骄霜、血雨风生、愁月仙子、方界老童和不死魔僧，各赠一支兵器，并结为异姓兄弟，共同为理想而努力。无忌天子联合六人之力，共同创建天外方界，自己又创建易水楼、童观，希望建立一个清新无争的世外桃源。

无忌天子和愁月仙子相恋，为断绝愁月仙子和东瀛的关系，无忌天子将年幼的朝子（袁冬曲）带走，交由易水楼的华琉衣照顾。异数时期，无忌天子应素还真之邀，自无欲天救走被金鳞蟒邪所伤的谈无欲，自己也耗损了百年道行。八阵滩祭师，无忌天子遭谈无欲、白云骄霜、欧阳上智等人联手陷害，借机诈死脱离天外方界，和愁月仙子双宿双飞，但方界、易水楼也就此落入谈无欲、白云骄霜等之手，至此方界变色，积极染指中原。

无忌天子在百步阿以师父八趾麒麟之名赠《无声之声》秘笈给灵山小叹后，又以光球困住剑君十二恨，防止其盲目找白云骄霜和魔魁报惊虹留恨之仇。后又从金小开手中救走叶小钗和乱世狂刀，并以勒马规束缚住金小开，欲根除其恶劣本性。集齐三传人后，无忌天子开始训练三人，助其三人日后对付魔魁，但三人心思各异，致使成效不佳。为不使自己和愁月仙子诈死的事情曝光，无忌天子也答应会尽快解决傲笑红尘和方界的问题，因此告知傲笑红尘八阵滩白云骄霜叛变方界及其阴谋，促使傲笑红尘决杀白云骄霜。

谈无欲被傲笑红尘所杀，无忌天子第二次解救谈无欲，但也将谈无欲百年功力吸出，转移给剑君十二恨。在素还真和傲笑红尘为神剑大打出手时，无忌天子出面治疗一页书，化解二人干戈。无忌天子答应素还真照顾盼梦圆，也和权门宗矩打赌救治一页书，若能先解开一页书之毒，则东瀛忍者退出中原，输则任凭宰割。无忌天子以流星靴为交换条件，请愁月仙子代解一页书所中"五凤朝阳"之毒，自己则提供给正道飞行风筝，让正道能顺利进入海鲸岛。无忌天子也将傲笑红尘困在黑暗道，避免诈死之计被他发现。为让愁月仙子交出五凤朝阳解药，无忌天子从易水楼找人顶替朝子。

六聪天乞和七海游僧为带回盼梦圆，答应让无忌天子参加下次的九大奇人聚会。无忌天子劝说一页书将功力捐给乱世狂刀，平衡三传人的力量，以便打败魔魁，为让一页书安心，无忌天子也答应一页书必会铲除三途判。后来功力虽是成功过继，但给却造成了创世者再出。在将三教镇教秘招秘笈交给灵山小叹后，为弥补心中亏欠，无忌天子告知傲笑红尘解开黑榜秘密的方法，即找寻愁月仙子。后来，无忌天子为对付黑榜汉奸，假扮为死海一孤舟，因无"红日轮"证实身份而被忍者所擒，后被傲笑红尘救回。

无忌天子继续调查黑榜之事，期间因愁月仙子身亡而大受刺激，被忘年误导，认为花爵百炼生是黑榜汉奸，使傲笑红尘逼杀花爵百炼生。无忌天子以百炼生留下的红日轮，假扮黑榜汉奸"紫绶一品"，助傲笑红尘破解黑榜之谜。在赶往半斗坪欲救素还真时，被簸魂车擒往童观，将计就计继续假冒紫绶一品，揭穿白云娇娘"吉祥天"的身份，但也被白云娇娘反算计，被傲笑红尘误认为也是黑榜汉奸，无忌天子无奈求助灵山小叹，方躲过傲笑红尘追杀。在九锡君现身之后，无忌天子继续假冒紫绶一品，但不知遇到了正主，不幸亡故，最终于黄土之下和愁月仙子长相厮守。

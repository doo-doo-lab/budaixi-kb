# 閃焰 (闪焰)
================================================================================

閃焰

長得是貓的外型，身穿著人的衣服，有著極高的修為。身份為截山修關者之一，通曉諸多術法，是人族聖皇妲眸姬用重禮迎來的軍師。天生吃素，個性果斷善謀且頗具城府，對於其師兄鬪蛉子當年事件仍是耿耿於懷。

# 云庐剑僧

身背巨剑带发修行的出家人，百年前曾代表佛界出战魔界斩海胜出，却因争取佛界领导地位不受认同，一怒之下出走佛门、四海为家，并留招秋水宴王者之路。

◎登场剧集：霹雳狂刀之创世狂人 第19集

百年前曾代表佛界出战魔界斩海的剑僧，真正身份乃耶摩天高僧摩诃台为以“汇灵卷”化出巨臣剑剑灵，虽于天海斩下斩海首级，其尸体则跌落于身不见底的天海之中；不料斩海却未死亡，云庐剑僧只好将首级带回放入至宝佛手矸意图加以炼化。

实际上，云庐剑僧的成功，乃是其师摩诃台在战前手中化运功力加持巨臣剑之故，所以云庐剑僧回佛界邀功时被指为无功（因师父摩诃台事前在巨臣剑上加持了功力），争取佛界领导地位时亦不受认同，一怒之下出走佛门，并在临行前愤怒地斩下摩诃台头颅。从此云游五岳修行，其人性情外冷内热，脾气刚烈但心地善良，于此时参与秋水宴，留下自创剑法庐山不动一剑痕，被舞造论排为王者之路破绽第二少的剑招，仅在秋末悲歌之下。此剑招传说后来被魔魁之女带入东瀛，神鹤佐木据此创造了刀法版的庐山不动一剑痕。

由于无相意欲利用云庐剑僧牵制素还真，以日月同天屠杀静念禅寺，引得云庐剑僧再入江湖，但此事未有水落石出，即卷入大汗帝国对秋水宴成员的逼杀，云庐剑僧虽然战胜大汗派出的杀手边岁寒，但其后斩海复出，才发现当年师尊摩诃台乃是自愿受死，好与斩海身首互换，加以炼化其魔体。

操控斩海躯体的摩诃台被迫在至阳之时离开天海好借天时地利炼化斩海魔身，云庐剑僧亦回转嵩山替师尊护法，可惜终究不敌斩海，摩诃台圆寂前将毕生功力灌注于岱宗岩传予创世者，战后云庐剑僧打算二度诛魔，但少了摩诃台的功力加持，庐山不动一剑痕完全无法伤及斩海。

尔后，素还真与莫召奴应对东瀛五大武士的挑战时，因有意愿延请斩海参战，所以放弃让云庐剑僧加入，使他颇为心灰意冷，后于静思时忽然发现摩诃台所留下的偈语：“云藏修慧心，庐山一别行，剑挥三途苦，僧证隐和平。”并因巨臣剑映出自己的身影，意外发现自身实为剑灵所化，了解摩诃台最后的计划是让云庐剑僧与创世者合一恢复成一页书。

云庐剑僧本来无法接受此一安排，只打算和创世者培养默契加强联手攻击之威，可惜依然不足与斩海及四飞天等强敌抗衡，最终接受天命，与巨臣剑人剑合一，融入创世者体内，两者合一恢复成百世经纶一页书。

其绝学“庐山不动一剑痕”在霹雳世界外亦有传播，该招式起初为纯剑招，后由魔魁之女将传说带入东瀛，神鹤佐木据此创造了刀法版的庐山不动一剑痕。

为人正直，是个较为乐意奉献，只是外在较冷，是外冷内热型。从他之后为了中原积极要求求战东瀛武士、保护舞造论、大战四飞天等就可看出。尤其是到了后期，即将和创始者合体前，他不介意牺牲自己，但他介意的确是自己实际存在的价值可见在知晓自己只是被炼化成人形的剑灵后，直至最后仍希望能保存自我意识，于是才有了云庐剑僧、素还真、创始者、三传人等困战四飞天，结果却令人感到惋惜，勉强战成平手。

在所有希望都幻化为泡沫后，为了武林大义，毅然决定回归剑身和创始者合体。注意看他即将离去时的眼神，是不是和平常有所不同？他的眼神充满了留恋与不舍，在慢慢消失的瞳孔中看到的是庐山、是摩诃台、是云庐剑僧自己。此时再去i回味云庐剑僧的音乐，更是别有一番风味，在音乐飘飘欲仙的背后，多了一丝对世间的怜悯。

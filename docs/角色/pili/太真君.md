# 太真君 (太真君)
================================================================================

太真君

十三道之首，练有绝技雷霆手，与元真君共掌昊光道院，为躲避合修会的迫害，佯装疯癫保住一命。最后却因九五至尊一事，死于慈海渡者的怒佛开膛指。

# 蕴果谛魂
================================================================================

蕴果谛魂

初代圣魔大战的领导者，久远之前便封身于庄严净土，致使宿敌魑岳李代桃僵潜入龠胜明峦，而今再涉红尘，持续肩负对抗厉族的任务。法相庄严，身披白裟，性情刚毅敦厚，亦为枯禅轮杵及众生相的原持有者。在天佛原乡所代表的形象意义为“地藏王”。

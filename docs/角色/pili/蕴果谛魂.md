# 蘊果諦魂 (蕴果谛魂)
================================================================================

蘊果諦魂

初代聖魔大戰的領導者，久遠之前便封身於莊嚴淨土，致使宿敵魑嶽李代桃僵潛入龠勝明巒，而今再涉紅塵，持續肩負對抗厲族的任務。法相莊嚴，身披白裟，性情剛毅敦厚，亦為枯禪輪杵及眾生相的原持有者。在天佛原鄉所代表的形象意義為「地藏王」。

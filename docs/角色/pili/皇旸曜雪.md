# 皇暘曜雪 (皇旸曜雪)
================================================================================

皇暘曜雪

狩宇皇脈三尊之首「雪爵」，刀法精妙，性格豪爽、不拘小節，但具有智謀，對事物有自己的洞見。一襲素雅白淨、白衣白髮，獨鍾雪景，並以雪為口頭禪。武藝高超，藏刀於雪，變化萬千，為三尊中的鰲首。

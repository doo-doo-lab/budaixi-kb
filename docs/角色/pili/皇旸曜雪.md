# 皇旸曜雪
================================================================================

皇旸曜雪

狩宇皇脉三尊之首“雪爵”，刀法精妙，性格豪爽、不拘小节，但具有智谋，对事物有自己的洞见。一袭素雅白净、白衣白发，独钟雪景，并以雪为口头禅。武艺高超，藏刀于雪，变化万千，为三尊中的鳌首。

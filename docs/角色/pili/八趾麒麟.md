# 八趾麒麟

日月星三才子启蒙恩师，特征为伸缩自如的麒麟大脚，根基修为虽不凡，但却拿徒弟没辙。素还真昔日一句半斗坪外徒渡师，就让八趾麒麟久久不涉足红尘。虽爱与徒弟较劲，但仍会适切暗中关心。

## 角色经历

八趾麒麟是台湾霹雳布袋戏系列中的虚拟角色，由黄文择配音，初登场于《霹雳风暴》第15章，退场于《霹雳狂刀之创世狂人》第14章（死于秋末悲歌）。其身负伸缩自如的麒麟大脚，位列九大奇人第八，与无不爱、双驼峰等八人结义，并担任素还真、谈无欲、无忌天子的启蒙恩师。八趾麒麟作为敌方角色出场。八趾麒麟因素还真“半斗坪外徒渡师”之言长期避居半斗坪，虽暗中关心徒弟却常与之较劲。其独创绝技“九州生气恃风雷”遭素还真习得，武功与智慧亦逊于弟子。他曾在百步阿打败灵山双叹。在《霹雳狂刀之创世狂人》的剧情中，八趾麒麟曾入秋水宴找寻无不爱，面临白云骄霜的威胁，并遭到九锡君与白云骄霜的联手阻击；为营救素续缘，他曾召集武林人士前往琉璃仙境会合。最终殒命于杀人剑音。作为三才子的潜能开发者，八趾麒麟未传授弟子全部学识，但因其启蒙身份仍受徒弟敬重。在后续改编作品中，八趾麒麟的形象与经历另有演绎，曾因徒弟素还真涉入江湖事而要求其回半斗坪，并提出按江湖规矩打败师傅即可出师；后为证明徒弟清白前往寰宇堡并受伤中计，最终不治身亡。

八趾麒麟是素还真、谈无欲、无忌天子之师。为九大奇人之一，曾经斗败灵山双叹（于百步阿）。素还真离开拜师之所半斗坪之後留下“半斗坪内师渡徒，半斗坪外徒渡师”（霹雳风暴第16集9分35秒八趾麒麟亲口说出）再加上识三世所言素还真前三世乃八趾麒麟前三世之师，亦让八趾麒麟感到相当害怕，因此多不离开半斗坪。其武功不传绝技「九州生气恃风雷」却被素还真学走。八趾麒麟为避免与素还真相见，长期躲避在半斗坪，在素还真化身花爵百炼生期间，八趾麒麟才正式步入武林，在《霹雳狂刀之创世狂人》第2集中，八趾麒麟入秋水宴找寻无不爱。在参与九大奇人会议之后，众人决定协助大鸿胪对抗魔魁。期间八趾麒麟多方奔走，助力正道。先后救下谈无欲、无忌天子等人，与素还真合作对付东瀛势力。在九大奇人的老大无不爱因泣花魂事件得罪龙王鱽、九大奇人的老九大鸿胪因投靠东瀛被傲笑红尘所杀、九大奇人的老六六聪天乞因加入黑榜、残害中原武林而被射日必杀组所杀后，八趾麒麟为报兄弟之仇，与剩下的九大奇人先后对上龙王鱽、傲笑红尘、素还真等人。最后八趾麒麟因无不爱决定脱离九大奇人，恢复秋水宴少主身份而心灰意冷，兼之龙王鱽击杀九大奇人的双驼峰、四寸奇迹，导致八趾麒麟心力交瘁决定退隐武林。在素还真远赴东瀛后，白云骄霜、九锡君二人乘机打击中原正道，在《霹雳狂刀之创世狂人》第7集中，八趾麒麟面临白云骄霜，生死关头；第8集中，九锡君与白云骄霜联手阻击八趾麒麟。在中原武林失去顶梁龙头的情况下，秦假仙智激八趾麒麟，使得八趾麒麟重出武林，入住琉璃仙境统领中原正道对抗白云骄霜等人。但八趾麒麟智谋、武功皆远不如素还真，在此期间，中原武林损失惨重，八趾麒麟逐渐陷入身边无将的困境之中。后来白云骄霜、九锡君联手擒拿八趾麒麟，八趾麒麟为保命，投靠白云骄霜，并主动率领中原群侠进入白云骄霜的陷阱中，害死白马雕龙、何三色等正道人士。其后八趾麒麟唯白云骄霜马首是瞻，更绑架素续缘，尽失一代先天高人气概。在素还真回归中原后，白云骄霜、九锡君、八趾麒麟三人在汗青编剑客的协助之下联手对抗素还真，反而被素还真与创世狂人所击败。八趾麒麟落荒逃命之际再遇素还真，在素还真的劝说之下，八趾麒麟决定退隐武林不问世事，然而天理昭彰报应不爽，八趾麒麟在回转半斗坪决定退隐之时，汗青编派秋末悲歌招揽八趾麒麟，在八趾麒麟拒绝后，双方开战，八趾麒麟武学尽展，却伤不了秋末悲歌分毫，随即秋末悲歌腾空一剑，无形杀人剑音将八趾麒麟撕为满天碎片。八趾麒麟就此退场（霹雳狂刀之创世狂人 第14集 死于秋未悲歌）。他只是开发素还真的潜能，并非所有事物都是他教的，虽说如此，但是三才子颇具饮水思源，仍旧尊重启蒙恩师。

八趾麒麟在游戏《霹雳风暴》（PC版）中作为敌方角色于第二十五关“八大奇人的复仇”出场，与六聪天乞、七海游僧等角色一同出现。在剧集《霹雳狂刀之创世狂人》（1998年）中，八趾麒麟出现在第2、7、8、14集，涉及与无不爱、白云骄霜、九锡君等角色的互动和战斗。在衍生作品“素还真大电影”中，八趾麒麟作为素还真的师父出现，剧情包括师徒冲突、八趾麒麟为证明素还真清白而受伤身亡。

观众对八趾麒麟的初步印象是“师父是个有意思的人”，但对其轻易中计的行为与“老江湖”及“素还真、谈无欲之师”的设定不符提出质疑，发出“你这水平到底是怎么教出素还真和谈无欲俩人来的？”的疑问；八趾麒麟为救徒弟素还真而中计身亡，其退场令观众感到震惊。

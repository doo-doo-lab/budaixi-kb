# 八趾麒麟
================================================================================

八趾麒麟

日月星三才子启蒙恩师，特征为伸缩自如的麒麟大脚，根基修为虽不凡，但却拿徒弟没辙。素还真昔日一句半斗坪外徒渡师，就让八趾麒麟久久不涉足红尘。虽爱与徒弟较劲，但仍会适切暗中关心。

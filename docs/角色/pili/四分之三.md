# 四分之三

四分之三，神魔族的后裔，毕生以消灭嗜血族为职志，个性沉默寡言，青年的血气方刚与狂气热情皆隐盖在冷漠外表之下，欲语之言全寄藏在时而孤寂、时而澎湃的小提琴弦音之中；以一双银枪为武器，悠悠弦音，是给予嗜血族的悲怜镇魂曲。

## 来自百度百科的补充

四分之三是霹雳布袋戏中的虚拟人物，初登场于《霹雳九皇座》第44集。

其身具四分之三嗜血者与四分之一人类血统，个性沉默寡言，常以小提琴抒怀。以诛魔银枪为武器，肩负净化嗜血族的使命。曾为对抗嗜血者首领西蒙而吸收嗜血族元灵之力，也曾被西蒙擒获以牵制其父茶理王。后经进化，实力提升，与西蒙决战并将其击败。

在《霹雳劫之阇城血印》中与希恩等多有交战；在《霹雳劫之末世录》中协助佛剑分说。因亲友苏安重伤、半分之间亡故等事件，其人生轨迹再起波澜。

◎外形特征：由黑暗之间铸造，一对组合式的双枪，枪刃造型一者形如尖锥，一者弯若弧刃，双枪合一正如四分之三融合两种血统蜕变为神魔族般，威力更盛。另外，诛魔银枪具有净化嗜血者恶灵之能，凡被银枪刺中者，伤口无法愈合，且随之化为虚无。

四分之三之所以名为【四分之三】，乃因身上流有血堡教父茶理王四分之三的嗜血者血统，以及四分之一的人类血统，二者混杂突变称之为【神魔族】，肩负起净化嗜血者的任务。期间，四分之三曾被西蒙抓走，囚于阇城之内。西蒙此举意在牵制其父茶理王，令其有所顾忌，因此四分之三并无生命危险。四分之三银枪虽利，却无法伤及嗜血者王者西蒙，遂转向探秘西蒙王棺之谜，为求突破，四分之三前往王者之墓，闭气凝神吸收嗜血族元灵之力进行进化。进化成功后，其实力已不逊于西蒙。最终，四分之三以绝招“神魔紫魇”击败西蒙，了结了神魔族与嗜血族的恩怨，成为最强的驱魔人。战后，四分之三从茶理王处惊闻苏安重伤、好友半分之间亡于邪之子手上的噩耗，他强抑复仇怒火，先行前往探望苏安。

然而嗜血者虽被消灭殆尽，但黑暗之间却又出现了另一股野心势力【败血异邪】，也让四分之三将目标转向败血异邪。不过，异邪之首夜重生实力更胜西蒙，且诛魔银枪出自黑暗之间，对夜重生宛如无用之物，茶理王为保全四分之三，避免其冲动寻仇，遂以迷药迷昏四分之三，携其远走海外退隐避祸。

在《霹雳劫之阇城血印》中，四分之三于第10集现身，第15集与希恩战斗，第20集进行伏击，第24集被独夜人拦阻，第25集中计导致体内嗜血族血液被唤醒而狂性大发，第26集丧失心智。在《霹雳劫之末世录》中，四分之三协助身负救世使命的佛剑分说，并于第6集在王者之墓吸收嗜血族元灵之力。

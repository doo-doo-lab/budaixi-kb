# 四分之三 (四分之三)
================================================================================

四分之三

四分之三，神魔族的後裔，畢生以消滅嗜血族為職志，個性沉默寡言，青年的血氣方剛與狂氣熱情皆隱蓋在冷漠外表之下，欲語之言全寄藏在時而孤寂、時而澎湃的小提琴弦音之中；以一雙銀槍為武器，悠悠弦音，是給予嗜血族的悲憐鎮魂曲。

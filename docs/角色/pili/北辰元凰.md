# 北辰元凰
(百度百科无对应条目,newton.com.tw 收录)

霹雳布袋戏虚拟人物。北辰王朝皇太子，外貌斯文俊逸，谈吐恭谦有礼，肩负着皇位继承人的沉重压力，在一场尔虞我诈的宫廷权利游戏中，让原本心性纯良的北辰元凰逐渐改变作风，步上一条充满血腥且孤独的王者之路……皇朝灭亡之后，作为身怀龙气的北嵎亡国之君，在慕少艾协助下吞并南宫神翳部分意识，取而代之成为黑派翳流新一任教皇，浴火重生再创颠峰。蜕变之后的北辰元凰，有着过人的政治手腕与心计，更增三分深沈。

## 角色背景

初登场的北辰元凰爱好和平、善良仁慈，不喜滥杀无辜，与诸多少年玩伴之间真心相交，同时作为一名储君，北辰元凰除了正直，热忱，也表现出才智、能力都能成为一个贤明的君主。岂料在北辰元凰毫无察觉之处，命运的齿轮早已悄悄转动。北辰皇朝世代帝位皆传长子，直到上一代大王爷北辰望让贤，由次子北辰禹继位，此举也引发三王北辰胤的不满，北辰胤文韬武略，堪称北隅皇城第一人，因此暗中秘密谋划，买通宫女秋玲监视当时的长孙皇后。偶然得知自己与皇后同时怀孕，便阴谋下毒使皇后产下死胎，并以狸猫换太子的方式将自己的儿子取而代之。皇后为确保地位，不得已为之，导致日后对北辰胤多有顾忌。在太子北辰元凰出生没多久，在一次贺宴中，北辰胤毒死皇帝北辰禹，北辰胤以为此举万无一失，天衣无缝，哪知北辰禹风流多情，在外与渡香蝶有过一段情，还生下一个儿子北辰凤先，只是凤先为避免暴露，一向以蝶姨称呼渡香蝶，并在外长年游历避开北辰元凰。由于曾给太后诊脉的前御医弄三平的出现，当年北辰胤狸猫换太子的机密渐为人所知，好奇追寻真相的楚华容取来太后之血与北辰元凰滴血验亲，滴血验证的结果却造成北辰元凰心中的创伤。陡然得知自己并非龙子，北辰元凰对自己产生了质疑。事情越闹越大，直至要当庭取先皇胎血滴血验亲。北辰元凰一步一步踏进冰冷辉煌的大殿，只觉所有人的眼光都是那么的冷漠。“到头来还是这滴血最重要！若我不是真太子，立时便有杀身之祸。原来我不比别人尊贵，也不比别人卑贱，太子的身份不过是便于掌控朝政的一颗棋子。”北辰元凰心叹在这皇城之中，除了权利，还有什么是真实的呢？虽然在北辰胤的安排下，滴血验亲有惊无险，北辰元凰顺利登基，但从此心性大为转变，正式步上了无情的王者之路。北辰元凰登基后，为保护自己身份的秘密，表面上维持好人的形象，一方面透露讯息给长孙佑达，但另一方面算准北辰胤的行动，让北辰胤借由逃狱的罪名除去楚华容。原本只想毒死渡江修一人，但看了渡香蝶的画后，北辰元凰知道这个从小看他长大的女人太了解他了，当下改变计划，以欲擒故纵之计，放松渡江修戒心，让其回到渡香蝶身边，再领兵前往一举毒杀两人。至此，北辰元凰无情的帝王手段可见一斑。在内部斗争中，借由与他人的合作，与魔龙祭天配合，做人情给狄，借此引出北辰伯英的阴谋，再一举杀之。对心腹的不信任也体现在枕边人身上，更利用龙宿对假月吟荷的信任，反将一军。之后四族起兵，神武候病逝，北辰胤出兵镇压，得胜而回。由于北辰胤功高震主，又广受大臣巴结，让北辰元凰十分忌惮，为巩固帝位，在逐步得知当年先帝被害真相后，便拍下计谋，先调回北辰胤，以父子情让北辰胤放松。大殿上的一跪，凄声低诉骨肉相认的父子之情，北辰元凰情真意切，令北辰胤差一点就要松口相认。而后前往天锡府呛声之举让其他大臣认清形势，最后算准时机，由长孙佑达揭穿当年血案真相。而这之前，北辰元凰早与长公主、狄等人铲除北辰胤势力，更在路上布置多番截杀，若非北辰胤还有暗藏伏兵，命几乎要断送在亲儿子手里。在所有皇城内部人员当中，唯一知晓所有秘密，又力挺北辰元凰的人唯有太傅玉阶飞。玉阶飞自小看北辰元凰长大，明白北辰元凰是真能为人民谋福祉的明君。事实上，北辰元凰虽在宫廷斗争中十分无情，但却是十分爱民。甫一上台便不忘履行当太子时的诺言，废除活人相斗供贵族游戏的竞技场，连施仁政，颇受百姓爱戴。玉阶飞对其可说是鞠躬尽瘁，死而后已，从一开始太子游历中指点，指点其拜三教罪人为师，拜访素还真等，为北辰元凰铺下后路。而假龙子无法使龙气上升，玉阶飞不惜用乱天混地决自损天命转移龙脉。奈何天命难为，人皮石鼓巧合一击，殷玳发出吼叫，玉阶飞功败垂成。玉阶飞死前还不忘拜访素还真，北辰凤先，为北辰元凰留下后路。乃至身亡，仍嘱咐北辰元凰掩盖死讯不可人前心绪波动，当北辰元凰拿着太傅的遗笔，长叹，“北辰凤先，这张龙椅你坐得起吗。”是对师尊身亡亦不可哀痛的悲哀，也是对帝王无情之途的无奈。之后，因其手段毒辣，北辰凤先入宫行刺，但未成功，转而寻求外援。但在北辰元凰高超的外交手段下，素还真等人无法干涉，有曾协助傲笑红尘助其寻找圣水源解救剑子仙迹。使得日后傲笑红尘不得不帮助北辰元凰，为其布下保命符。自北辰元凰登基后，长孙太后大政归还，被软禁于后宫中。为铲除与当年秘密有关的所有人，北辰元凰假意放太后出宫散心，同时自导自演派人绑架太后，之后利用抢夺之时，派人出手杀之。但正值地理司阴谋夺取龙气，帮助北辰凤先，遇到出宫在外的太后，北辰凤先与太后说明真相，使得太后心灰意冷，留下手书阐明当年事实。长孙祐达将太后手书交给长孙护与大王爷北辰望，北辰望因北辰伯英之死与北辰元凰早有嫌隙，长孙护与长孙祐达更因长孙太后之死彻底背离北辰元凰。而此同时，地理司请蝴蝶君杀掉狄，假月吟荷被鬼笔神匠所杀。北辰元凰众叛亲离，被逐出皇城，北辰凤先登基，龙气翻腾，为地理司所吸收。也许是天命所归，也许是龙气遗失所致，事情再度出现转机，一个让人意想不到的援军出现—北辰胤。或许是父子情深，或许是北辰元凰更胜于自己的帝王谋略。北辰胤不但没有趁机报复，更矢言相助，一路父子扶持，亲情袒露无遗。之后北辰元凰对上北辰凤先，没有一丝的犹豫，最后的胜利促使真正的帝龙诞生，北辰元凰重回帝位，而北辰胤被加封为并肩王，至此北隅皇城的力量归一统。然经过多番斗争，北辰皇朝力量消耗一空，在有心人地理司圣踪的策划下，仍免不了走向覆亡的道路。而北辰元凰也因成为身怀龙气的亡国之君而带来另一份契机。失去皇权的元凰，不再是号令天下的君主，但北辰元凰并没有沉溺在他过往的辉煌，他立刻重新定位了他的身份。先暗算杀害北辰胤的东方鼎立为父报仇，并进入瀚海偷袭皮鼓师，与皮鼓师两败俱伤。随后被蛊皇所救，作为恢复南宫神翳的关键。后来在慕少艾的险棋下，成功取代南宫神翳成为翳流教皇。魔君身亡后，积极介入中原武林，并用计逼出天来眼和芙蓉骨，四方台一会，正式浮出台面，并将焦点集中在鬼没河神器上。随后为了翳流安稳，安排燕归人和寰宇奇藏决斗；为了夺取锐感之缨，安排刀戟斩龙。取得锐感之缨后，先杀鬼梁天下，又将燕归人诱至磁心源，利用特殊地形重创燕归人。击败天来眼后获得不解之护，成为台面上的恐怖角色，却也埋下日后败亡的原因。为夺取撼穹之能，被凌沧水利用日落前阴阳交升的时刻引到影响南宫神翳功体的五爪峰，服用芙蓉骨提炼的药丸，却引发体内真气冲突，最终被燕归人所杀，王者之路就此终结。

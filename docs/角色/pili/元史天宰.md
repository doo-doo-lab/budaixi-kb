# 元史天宰 (元史天宰)
================================================================================

元史天宰

聖魔元史所化出的本體，陰沉而威儀的黑袍老者，在天機讖浮現、與鷇音子交涉破裂之後，正式涉入武林，並化出「倉頡天邪」與「謬思童」兩化體，企圖以聖魔元史無匹力量來干預操控局勢，左右正道與欲界之變數。

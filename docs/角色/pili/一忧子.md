# 一憂子 (一忧子)
================================================================================

一憂子（天子傳奇）

總是隱藏自己的情感，熱心卻表現無情樣，嫉惡如仇，好勝心強但卻心繫眾生、慈悲為懷，為誅殺原始天魔而超越武功極限全身力盡使出天驚地動，後雖被魔君所救，但也被其控制淪為殺人工具。

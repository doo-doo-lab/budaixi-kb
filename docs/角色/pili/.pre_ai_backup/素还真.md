# 素还真（霹雳布袋戏虚拟人物）

================================================================================

素还真，霹雳布袋戏虚拟人物。《霹雳金光》第十三集登场。

2001年-2018年，连续十八年荣获霹雳人气票选排行榜第一名，是当之无愧的霹雳一哥。

霹雳化身最多的首席男主角，温文儒雅、器宇轩昂、超凡脱俗、武学莫测高深、足智多谋、博学多能、谦虚有礼，处世圆融冷静、慈悲亲和、关怀众生；

以武林和平、天下大同为己任，‘谋为天下谋、利为天下利’ - 无我、无为！

为武林风尘默默承受一切，多次以绝顶智慧化解灾厄，置之死地而后生，为天下苍生应现各种精彩玄奇的身份！

幽默风趣的随机教化，难舍能舍、忍辱负重、不计毁谤、无怨无悔，默默付出，不遗余力、不求回报，真乃具足大慈悲与大智慧的凡圣一体，反璞归真‘素还真’。

在这段时期，由于本尊或因病休养、或因本尊身份受制需化明为暗，素还真先后化身千山樵老、花爵百炼生、卧云先生初行雁。

## 根据地
霹雳眼~圣魔战印翠环山、黄山、百棺机密门、九死一生洞、琉璃仙境、六十四个求生站、云尘盦、推松岩轰霆剑海录至创神篇新琉璃仙境：是在翠环山上的琉璃仙境。因为是素还真暌违已久，再度回到琉璃仙境，所以特别的慎重其事，特将场景细分为：翠环山整体外观景、翠环山入口、翠环山山径玉波池、五莲台，然后再上去就是琉璃仙境的主建筑。九轮异谱～仙魔鏖锋魔吞不动城

## 角色形象

设定特色面似冠玉、气宇轩昂、超凡脱俗；

其人博学多闻、足智多谋，文武双全、高深莫测；

待人温文有礼、慈悲亲和、处世圆融。

其思想广涉儒道释三教，上知天文、下通地理，精研琴棋书画，亦晓医术。

允文方面有大智、大慧，不拘泥一时一地，能全盘审慎考量，勘破迷乱的局势；

允武方面亦有大勇，面对强敌不轻易退缩，记忆能力超凡，过目不忘，甚至能所见即所得，将所知所学的一切加以融会贯通、自行运用。

武器素还真武器介绍登场剧集：霹雳至尊 第6集紫虹神剑外型特征：护手为龙首图腾，剑柄色呈紫虹，紫虹剑身蕴藏雷电之威，出鞘则紫气冲云霄。

武器事迹：素还真初出武林所背之宝剑，剑身之中藏有一吸雷针，乃名列巨书岩【古今十八种神器】之一，平日多以剑衣裹于背后。

两百年前，素还真与谈无欲曾败在一剑万生仕童【金童玉女】木剑之下，二人宝剑因此被一剑万生贴上封条，并立下无一剑万生同意不得任意撕下封条之誓言。

然而在素还真诈降欧阳世家，遭遇谈无欲伙同宇文天等人攻打无极殿，仅剩一眼一手的素还真逼不得已，终将背后紫虹宝剑拔出，紫虹剑带闪电，顿时风云变色，雷电交加。

霹雳英雄榜时，白云骄霜更曾言：“唯紫虹宝剑与太古神器相同材质所铸之兵器，方能削断攀天梯。”紫虹宝剑不凡之处由此可见一斑。

就在两人退隐途中，再度遭逢叛徒人法统、地法统围杀，幸得素还真与谈无欲以【挪移大法】解危，郡主为答谢二人，遂赠其孔雀王朝之宝【孔雀剑】一对。

武器事迹：【忘然神器】一词早在影中林中日之战即出现，素还真以一敌四对上赤鬼等人，所使用之宝剑亦称忘然神器，但此剑不论外型或威力，皆和后来对抗天策真龙的神器截然不同，后者知名度也较高。

而后，被天之厉逼杀而逃至霖林，重伤的素还真受林中白丝缠绕成茧，实为受龙蚕之助潜修养伤。

因血傀师以圣魔元史异力，造成时间异常，时间城主派饮岁入世，被时间异力困入异空间陷入不生不灭、永恒静止状态的素还真因此被解救。

以在时间城推动日晷的代价换取借来的时间分别化出天踦爵、三余无梦生（后因逆时计影响化为四智武童）、鷇音子在武林上行走，相继除去血傀师，拉拢妖界，揭露凋亡禁决阴谋，对抗并消灭圣魔元史，终结波旬再出之祸，最后为破逆海崇帆制造的尘世暗夜牺牲一魂。

素还真在时间城养魂之际，苦境正面临黑海森狱作乱，最终，康复后的素还真再度入世，计杀玄嚣，参与论剑海评剑会，解决双阳同天危机，解决天疆森狱苦境之争。

森狱阎王终在素还真的见证下败亡，三阳同天谶言随之被破，更随着娣君、亨王、燹王的纷纷死去，再加上隐藏在怪贩妖市的异识势力与魔息，又牵连出一个全新的异世界——九轮天，为对抗九轮天及异识之祸，素还真召集一页书、叶小钗、乱世狂刀、道真双秀等正道人士组建魔吞不动城，化明为暗。

而素还真也由于异识入体被迫壮士断腕失去心脏，后在葬神之野以黑发年轻样貌复活，但因为新心缘故丧失记忆，但也拥有了四心之力，化身有生之莲·解锋镝，继续奔走于武林。

解锋镝期间，先后与不动城及三教正道人士化解九轮天危机，并且共同对抗幽都君临黑帝。

一页书因中儒道叛徒陷阱而垂危，解锋镝在枯半身帮助下用以胎养命救下一页书，之后受夸幻之父委托前往八面玲珑与圆公子共同主持古原争霸，并为一页书之复活尽心尽力，让夸幻之父服下一页书之灵珠，在狩宇逆神旸出世后挑起狩宇与幽界夔禺疆的霸主之争，为武林争取喘息之机。

在助品愁惶登上仙脚顶峰后，解锋镝行走在云海中，形象也一步步变回素还真。

主要人际关系一页书良师 一页书：和素还真并列霹雳的正道龙头，然而在性格上，洽成极端的对比，素还真柔韧婉转、圆融平和、因时制宜，一页书阳刚率真、有棱有角、一视同仁。

## 角色评价

较之霹雳最新剧集当中，诸多人物造型的炫目华丽，素还真的形貌所能展现的，无疑是简朴而传统的，从木偶、衣饰到配件，这位霹雳布袋戏的灵魂人物，在漫长霹雳史上，所烙印的经典刻痕，极少来自于其外在的形貌，而源于其独特的人格魅力与清冽如水的淡泊。

不需要以表象去吸引目光焦距的素还真，往往仅需要莲冠、素衣、拂尘，作为其身份的表征，再辅以几乎备而不用的佩剑，适度暗示其掌握文武半边天的实力，以及不拘泥于形式的处事风格即可。

这样一个以内涵取胜，收敛平和的角色，自然必须经由时空的沉淀、人性的思考与体验之后，才能够被加以理解与欣赏，再借由逐步上色的彩绘，隐隐撩拨生命悸动的因子，进而穿透戏偶的虚幻，洞悉其不言而言的人生智慧，以及岁月沉淀后的菁华，终至映照出观众内心深处自我的反刍，最后透过性格成色的重重渲染、深层内化，至此，所有隶属于素还真的华采缤纷，亦将自其简朴素净的偶身，无可限量地辐射出绰约的韵致。

靠近素还真，有赖于极高的耐性，不能在第一时间内，要求一个所谓最合理的解释、最合法的动机，先知先觉者，往往会有以静制动的前置布局，来牵扯或导引局势的发展，于是，所有处于无法明言的阶段，一方面是考验对手，另一方面也在考验戏迷；

考验对手的沉稳与实力，同样也考验着观众看戏的功力与其对人生的体悟；

不够沉稳的对手，不值得耗费心神去应对，目光浅薄的群众，亦将丧失与戏偶共舞的感动。

（节选自《品莲观真》前言，作者：冷月白）《品莲观真》写真集素还真，是需要用生命和时间……才能品味的角色……！

其形貌之从容隽雅，虽是江湖中殊绝的风景，却非极致的神髓。

莲开千叶，皓雪莹白，是荧幕内外任何私心、诡谲所无以沾染之圣洁，是任何阴谋、手段所无以操弄之存在，静静地绽放在湖海之一隅，任凭风雨肆虐，犹屹立不摇，任凭世人褒贬评价，仍一往无前，不退缩、不逾矩，香气远扬，逼退世俗尘念，还天地一抹清幽自然，予饱受世情消磨之人心一丝宽慰与谅解。

经不起光阴洗练的角色，成不了典型。

白莲入世，从活泼轻盈的灵魂，为情为义骤成残缺的生命，八方风雨汇聚成素还真静渊一般的莫测高深。

荧幕上，观众目击着“清香白莲”一贯坚持的理念；

荧幕外，素还真则同时参与了所有观众的现实人生。

蓦然回首，在浮光掠影的生活片段里，有一通透的琉璃坐标，隐隐约约地流动着，没有声音，没有影子，却始终留驻，这是素还真之于广大戏迷的存在及意义。

好多戏迷理解“百世经纶”以超凡修为入世，乃源于一份“不忍”之心，不忍苍生为难之慈悲。

故梵天颠覆佛者形象，以非常人之雄浑气魄，为黎民百姓遮风挡雨，唯愿河清海晏，普罗尽欢颜。

然而，“清香白莲”为何涉尘？

却非三言两语所能道尽，端视观者自由心证。

自笔者初识素还真，历经漫长时空之辗转与辩证，极少有过相同的答案。

因为，举凡精彩的文学创作和戏曲，均有伴随聆赏者生命历练不断成长的厚度，以及历经岁月涛濯后愈发熠熠生辉，并且历久而弥新的特质，这是亘古长新的魅力所在，亦是超越时空限制的精神美学。

（节选自《经典不灭，亘古长存》，作者：冷月白）

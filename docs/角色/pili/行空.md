# 行空 (行空)
================================================================================

行空

昔日讓人聞風喪膽的鄧王爺，出手金銀絕學令人聞風色變，卻因紅葉夫人意外猝死，讓鄧九五哀痛欲絕，無語問蒼天，為何自己作惡多端，報應卻是由紅葉承受？為解心中疑惑，鄧九五因此遁入空門，法號行空，雖然日日夜夜唸頌佛經，卻並未真正參透佛法，心中疑惑始終不解。直至問天譴一語道破：「紅葉不需要贖罪，而你需要。」行空至此方才真正頓悟，隨罪劍入地獄島贖罪。

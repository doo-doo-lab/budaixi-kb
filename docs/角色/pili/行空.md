# 行空

昔日让人闻风丧胆的邓王爷，出手金银绝学令人闻风色变，却因红叶夫人意外猝死，让邓九五哀痛欲绝，无语问苍天，为何自己作恶多端，报应却是由红叶承受？为解心中疑惑，邓九五因此遁入空门，法号行空，虽然日日夜夜念颂佛经，却并未真正参透佛法，心中疑惑始终不解。直至问天谴一语道破：“红叶不需要赎罪，而你需要。”行空至此方才真正顿悟，随罪剑入地狱岛赎罪。

## 人物经历

数十年前，在遥远的北武林，存在一个偏僻蛮荒之地，名唤西北十酋。那里曾有一对恋人，斯人从小青梅竹马，两小无猜，感情深厚日复一日，终于是海誓山盟，矢志不渝。无奈，如许多琼瑶戏中狗血的桥段相似，少女的父母嫌弃青年家中贫寒，拒不松口许婚。这个青年是个很有心机与手腕的人，他远走他方，不出数年，再回乡却是锦衣荣归，家资巨富。于是一切问题都不成问题了。

孰能料，平地起波澜。二人大婚前一天，西北十酋的酋王偶然见到了这位少女，为此女的天香国色所倾倒。于是，不需要说明，不需要招呼，直接将少女抢进了王宫。青年自是悲痛欲绝，他散尽家财，雇请无数高手，豁命一搏，却终究无法敌得王宫森严，不仅家产被抄，本人也被打至重伤。再后来，这位青年心如死灰，悲而出走，一走便是十年。

在这十年之中发生过什么，江湖中人莫能知晓，人们知道的，只是十年之后，西北十酋的王宫收到一张印有金银双掌的帖子。再后来，便如北武林传说的那样，腥风血雨，血流成河，西北十酋一夕被灭，十万人口一朝丧尽。从此武林中多了一个名唤“出手金银邓王爷”的魔头，西北十酋，不过是邓王爷传说的起点。

除了月无波，无人知道这十年中那位青年到底经历过何事，唯独伊却是刻骨铭心，乃至于哀肠寸断。青年邓九五伤重出走，被月无波所救，仗着英俊相貌与心计手段，将月无波——当时还叫月无暇——的一片芳心偷取，甚至还学到了其祖上不传之秘，金银双绝掌。月无波一家天资所限，都无法尽练金银双掌，唯有邓九五却竟独享天资异禀，将金银双绝掌修到了化境。邓九五心肠狠辣，颇有决断，利用完的物事对其而言已无价值，因此将月无波半身金封，留其一命，算是多年夫妻顺手之情，自己飘然而去，寻找此生挚爱，当年的倾国少女 ·红叶夫人。若非后蒙剑雪无名所救，月无波绝无生机。

血洗西北十酋后，邓九五与地理司、东方鼎立、公孙月、兰漪章袤君在般若海结义，成为颠覆武林、称霸天下的野心五人组。邓王爷化名楚王孙，潜入北隅皇朝，化身白手套，暗中操控斗技场，后来甚至牺牲亲生女儿楚华容，以护兄弟。

随着正道与般若海联盟的矛盾日益尖锐，邓王爷也大显神通，大肆杀戮正道高手，连三教怪人也死于其掌下，霹雳第一男主角清香白莲素还真也遭其金封，同时圣踪暗计重伤剑子，地理司诡计伤傲笑红尘，正道栋梁一一折落，武林之倾覆已在旦夕之间。

这时，骨箫为引邓九五就范，用迷魂箫声将红叶夫人引成疯癫，红叶疯，邓王爷心急如焚，痛彻心扉，不惜一切要治好红叶，甚至为了好好照顾红叶竟退隐江湖，放弃所有的王图霸业、雄心壮志。其言，红叶在吾心中，是超越一切的存在，有她，邓九五的生命才有意义。甚至红叶夫人痊愈，仍是不愿再出江湖，谓之相欠红叶的已经太多太多，只愿与她携手同隐江湖，度过残生。

一步江湖无尽期，树欲静而风不止，红叶夫人终究是死于皮鼓师之手。红叶丧，邓九五癫痴欲狂，从此江湖上再也没有邓九五此人。

再出，已是身在佛门，法号行空，一个心心念念寻找佛祖的和尚。他要问一问佛祖，为何沾染罪孽的是邓九五，而遭受果报的是红叶，是潜心礼佛、不杀蝼蚁的红叶。最终，地狱岛二岛主罪剑问天谴解开了他的答案，“因为红叶不需要赎罪，而你需要”，一个多么沉痛的答案。

行空于言下有悟，安心随问天谴回地狱岛赎罪。

不料后值圣阎罗野心暴露，行空虚以委蛇，假意投靠，于是出手金银邓王爷重出江湖，却是明里金封汲无踪、柳神官、四非凡人，暗里却是布下除恶之局。孰知天道不昌，一招错而满盘损。就在除恶大计几将功成，圣阎罗几乎落败，半途杀出嗜杀者，柳神官遗恨，行空，不，邓王爷，为了掩护汲无踪与四非凡人撤退，终于血洒地狱岛，死于圣阎罗掌下，一代枭雄，一代魔头，一代忏悔者，不甘而逝。

霹雳神州第7集，罪剑问天谴把红叶夫人的骨灰交给云湘，使二人合葬，圆了邓王爷最后的心愿。

# 行空

昔日让人闻风丧胆的邓王爷，出手金银绝学令人闻风色变，却因红叶夫人意外猝死，让邓九五哀痛欲绝，无语问苍天，为何自己作恶多端，报应却是由红叶承受？为解心中疑惑，邓九五因此遁入空门，法号行空，虽然日日夜夜念颂佛经，却并未真正参透佛法，心中疑惑始终不解。直至问天谴一语道破：“红叶不需要赎罪，而你需要。”行空至此方才真正顿悟，随罪剑入地狱岛赎罪。

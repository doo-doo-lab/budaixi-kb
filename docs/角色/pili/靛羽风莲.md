# 靛羽风莲 (靛羽风莲)
================================================================================

靛羽风莲

手持莲扇、温文雅逸，其人谈吐幽默风趣，性格外放而兼具温和，正可谓亦侠、亦狂、亦温文；反应敏捷、遇事沉着，总是一派优雅从容，无论处世作风和外貌都偏属儒家风格。

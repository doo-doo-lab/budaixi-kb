# 軍神 (军神)
================================================================================

軍神

扶桑無敵神話，享有「一騎當千」美稱，統領東瀛最精銳的神風營，戰無不勝，攻無不克，一日間能連破中原九十九種武學，是殲滅鬼祭大軍和霧隱城的關鍵人物。個性公私分明，休息時間絕不辦公，擅於領導統馭，甚得部屬敬重效尤。

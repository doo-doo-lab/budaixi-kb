# 狼城疑云

黄强华、黄文择执导的舞台剧《狼城疑云》是霹雳布袋戏系列于1998年8月28日至31日在国家戏剧院首演的舞台剧，开创布袋戏首次登陆国家级剧院进行现场实况演出的先河。

该剧以狼城城主在名剑展示宴遭章武宝剑杀害为开端，武林名侦探素还真受邀勘查密室凶案。

调查揭露城主夫人秋痕为报家仇勾结他人弑夫等连环阴谋，并牵出城内权力斗争。

素还真通过智计勘破真相，最终指认主犯为夫人与褓母，但城主之死仅揭开权力争夺序幕。

全剧融合武侠推理与布袋戏表演特色，舞台设计由刘培能操刀结合传统技艺与现代灯光技法，王世信负责灯光设计，黄文择担任口白指导，黄强华、杨月卿等编剧团队打造曲折离奇剧本，呈现新旧表演技法交融的典雅世界。

## 故事大纲

傲笑红尘、剑君等用剑高手，受狼城城主之邀，参与展示名剑的盛宴，不料，在众目睽睽之下，狼城城主竟遭杀害，凶器正是展示在宾客面前的章武宝剑！是谁有这种武功和智慧，能在各方高手注目下，神不知鬼不觉地杀人行凶？案发当时手握宝剑的城主心腹荆师爷，成为最大嫌疑者，被收押大牢，但是，狼城总管金不舍力排众议，坚称荆师爷无罪，并亲身延请人称武林第一智慧者的神人－－清香白莲素还真－－来破解谜团。

素还真亲自来到狼城，便感觉到城内，以金总管、黑教头为首的派系之争，已随着城主之死而浮上台面，双方人马皆有充分的行凶动机。素还真更查出貌美年轻的城主夫人，有一段隐而不宣的过去，带着血海深仇嫁予城主，嫌疑亦难以排除，就在人人有嫌疑，个个没证据的情况下，年幼少主又被刺杀身亡！

素还真以冷静的眼光，察言观色，厘清复杂的重重线索，最后终于锁定最重大的嫌疑者，再加以试探，由秦假仙等人扮成死不瞑目的城主，逼出凶嫌的破绽；再以毒攻毒，顺着嫌犯的心意发展探案方向，终于让凶手自行曝光在众人眼前。素还真点出主犯是夫人及褓母之后，狼城内的争斗反而更加激烈。血案虽破，但人欲难除；狼城内欲置他人于死，欲夺取权位之人，又岂只是杀死城主的凶手？

## 演员介绍

### 狼城成员

黑暗堂：狼城现任城主，好大喜功，得到名器——章武宝剑后，设宴大肆炫耀，不意在大殿上遭人暗杀身亡！

夫人秋痕：前任城主段星石遗孤，策划暗杀黑暗堂的行动，以美色诱惑师爷荆尚智参与暗杀行动。

荆尚智：狼城师爷，因贪恋城主夫人美色，参与暗杀计划，手刃待己亲如兄长的城主。

狼城少主：因具有黑暗堂血统而遭褓母迁怒杀害。

寒彤：城主心腹，因反对黑暗堂与秋痕之婚事而遭驱逐，仍暗中保护城主。

范义：狼城小头目，亦为暗杀成员之一，案发不久之后便遭褓母灭口。

金不舍：提议素还真来破案的狼城总管，案发后急欲为荆师爷洗清嫌疑。

黑护法：狼城总护法，对城主之位充满野心，欲将荆师爷入罪，企图掌握狼城。

狼城褓母：抚养秋痕长大，是位暗器高手，煽动秋痕杀黑暗堂，为父母报仇。

巴比丘：城主黑暗堂之好友，头脑简单，四肢发达。

### 破案成员

素还真：中原武林名人，文韬武略，才智过人，受邀前来破此疑案。

青阳子：素还真之得力助手，偕同素还真破此狼城悬案。

剑君十二恨：协助素还真侦办此案，潜入狼城暗中观察众嫌疑者的行为举止。

傲笑红尘：受邀前来狼城共同鉴赏「章武宝剑」的贵宾，并提供素还真破案线索。

秦假仙：霹雳甘草人物，参与此破案行动，功不可没。

### 其他演员

金小开：不请自来狼城宴会的不速之客，曾被怀疑为凶手。

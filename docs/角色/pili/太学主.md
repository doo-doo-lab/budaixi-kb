# 太学主

================================================================================

霹雳布袋戏虚拟人物太学主，霹雳布袋戏虚拟人物，组织门派包括学海无涯与血榜。学海无涯之主，学识渊博、武功盖世，造就儒门一干英才，却在意外接触死国年纪后，卸下一切教务，离群索居独自解译死国年纪，逐渐继承死神意志与死神的部分力量（六成死神之力），性格也产生异变。作风极端，暗中掌控武林局势，操弄他人命运遂成了其最感兴趣的游戏。死神之祸乱世期间，御天荒神六铢衣踏入尘世，搭配天剑之主叶小钗，两人联手与死神太学主展开一场末日决战。一夕海棠意外遗留太学主之子。中文名太学主配 音黄文择性 别男登场作品霹雳神州Ⅲ之天罪登场作品霹雳天启霹雳震寰宇之刀龙传说人物编剧廖明治本尊雕偶师潮州君皇

## 人物设定

名称：太学主太学主性别：男化身：燕门孤雪（梦境所化）身份：学海无涯最高统领、新任死神、伪权倾天名言：死神之前，无人可以例外！初登场：霹雳神州Ⅲ之天罪 第44集（光球状态）正式登场：霹雳天启 第18集退场：霹雳震寰宇之刀龙传说 第5集（肉身被混沌之力加持的天问三誓第二招击穿，元神被荒神彻底毁灭）根据地：鬼林沼泽、学海无涯所有物：死国年纪

## 人物能力

武学：死神禁断、死神奏杀、死神逆天、死神双极断、死神禁断·五神雷、死神禁绝·五神雷·惊天暴、死神尽绝、横刀辟地、天地尽绝、天地俱丧、天地俱灭、灭世六道·击、心剑末日神话咒术：逆乾坤·造日月·太古双涡武器：末日神话由司徒偃草拟设计图，太学主藉荒神之力取得地心之能，炼化死国地之元素“炼之菁”而成的旷古绝今之作，取名“末日神话”，象征死神降临、天地尽绝的意味。末日神话造型宛如一尾鲜红赤蝎，与阎王（阎王锁武器）的设计概念相同，以层层叠叠的钩刃结合而成，刀刃利钩宛如蝎脚般满布刀身，刀锋划出完美的弧度，有如蝎尾弧翘，给人致命一刺。末日神话刀柄有两根蝎脚，会窜出如血管般的触手，一旦吸取太学主的死神之血，魔力便会瞬间爆发，天地宛如陷入血红炼狱，令人胆颤心寒。曾砍断凤凰鸣的淑世之道。后为天剑、众神之默、创世、影神刀四大神兵合力破坏。戾祸行经天葬山一带时，感受到一股难以消散的怨气，遂赋予重生之机，让末日重现，神话重生，在戾祸以自身戾气灌养之下，末日神话再现昔日威能。

## 人际关系

组织门派：学海无涯、血榜宿敌：六铢衣同伙：天不孤部属：下酆都、刑道者、一生悬命、留万年、司徒偃、阎王锁、夜孽噬影、血断天刑、夜诛神凶、死神四关（眩迷、逆叛、隐欺、邪念）降将：夜行舟、鬼离夜叉、魑魔才子、邪歧其他：一夕海棠（怀有神之子）、死国之神（太学主心性变异源头，给予太学主残留的死神之力）

## 人物经历

死国年纪死国之神所写之书，共计十六章。一日，学海无涯之主太学主听闻邪书问世，造成村落百姓惨亡，太学主亲往救援，眼前竟是死神自传《死国年纪》。来自死国的文字无人可解，但太学主却异于常人，有如被选上的人一般，带走死国年纪，随后更离开学海，隐退在沼泽木屋翻译死国年纪。自从他登场开始，就在一章章地翻阅这本笔记——这是死神重生的笔记，包含了死神一部分能力。于是，太学主就在不断的研读之中有了变化，配乐也从清圣飘渺转为低沉阴暗，直到霹雳天启上册的结尾第十八集，穿上死神服装的太学主终于踏出了闭门半部多戏的大门，一如当年死神踏出死国，新生开始，太学主在人间的游戏也开始了。太学主太学主之死太学主继承死神之能，其败亡并非素还真、千叶传奇、万古长空、叶小钗四人联手那么简单。先是阎王锁、天狼星二人联手破其第一层护身气罩，然后太学主为了证明自己已经超越死神，设计得到了一夕海棠，埋下了神之子，同时也破了自身的第二层护身气罩，最后是六铢衣与叶小钗联手破其第三层护身罡气，随后万古长空与叶小钗联手使用众神之默、创世、影神刀、天剑四大神兵击断其兵器末日神话，接着素还真与千叶传奇联手以混沌之力击破其肉身，游子安等须弥如来藏高僧再使用法阵困住其元识，最后再以被六铢衣舍命保住和以鹿苑一乘众高僧之血重生的荒神之力所彻底毁灭。

## 编剧漫谈

文/编剧：夜雨·十布师山寨来的大王：太学主除了死神、六铢衣、问剑孤鸣、不二做，夜雨近期写过印象最深刻的角色，大概就是太学主了吧。很多人问我说，为什么太学主长的像猴子？竟然还有人说他长的像猪！为什么不找一个帅一点的？也有人说，太学主太老了，为什么不年轻一点？这样把海棠妹妹好怪，幸好海棠外形也有点像欧巴桑。也有人说太学主长的像轩辕不败等等。但对于我来说，其实这就是我心目中的太学主，一个造型简单有型，白发苍苍，眼神睥睨，嘴角微扬，具有相当霸气的骨感轮廓。即使他称不上俊美非凡，但是对于我来说，这是一种我会欣赏的男人帅气。太学主某种程度来说，其实太学主是一个很讨厌的人，因为期待死神的人，会感觉太学主自称死神很讨厌，你明明就是一个山寨版的死神，而且死神还比你帅几百倍。而支持正道群侠的人，也绝对会讨厌太学主，因为他可能随时会害死凤凰鸣、六铢衣、问剑孤鸣、不二做等等。而支持天狼星跟阎王锁的人，对太学主的厌恶就不用说了，凭什么你有这样的能力自称死神？综合以上种种因素，太学主的特质很简单，就是一个我希望坏人该有的特色，就是要惹人厌，因为他真的是个穷凶极恶的反派，是造成武林不停伤亡的魔头，他没有任何立场和无奈，他就是想要玩草菅人命的游戏。我不希望他有英雄气概或者侠义心肠，更不希望他有张俊俏的外表，因为他就是一个不折不扣的反派的大坏蛋，为求目的不择手段的魔头。总是一副老神在在，胸有成竹的模样，当初在鬼林沼泽的时候，太学主就是一个不出门，能掌控天下事情的人。他做任何事情，任何手段，几乎都不需要自己动手，除非是逼不得已，否则他总是观望着所发生的事情，把所有能够利用的手下全部利用，把所有想要铲除的东西全部铲除。包括雅僧佛公子的死、取得天雷杵、玩弄东方羿以及开启血榜，造成武林死伤惨重，这些几乎都是太学主所盘算，却没有亲自动手的案例。当他开始走出沼泽，第一个遇到的就是六铢衣，这是一个他既期待又忌惮的对手，所以他给六铢衣安排的，就是一连串损失神皇之气的考验，借出荒神的时候，就马上遇到死神四关、黄泉引者、不二做、问剑孤鸣、下酆都、绝情书、还有侠肠无医等等众多的难关考验。太学主为什么不亲自上阵？其实夜雨的想法很简单，太学主就是要看你六铢衣能撑到什么时候？如果你连这些关卡都过不了，也不用想成为我的对手。想当初阎王锁连续通过太学主的机关，才终于有机会跟太学主当面一战，六铢衣对太学主来说更加高深莫测，当然所要进行的游戏就更多了。简单来说，太学主在这里展现出来的，就是卑鄙。甫一登场，太学主便调回了死神四关，开始了为祸武林的行动，也直接害死了不少武林人士，也搞得叶小钗、净琉璃菩萨、万古长空等等凄惨落魄。所以才逼出了素还真跟千叶传奇联手，因为太学主明白，当魑离船出现的时候，也带来了白莲生机，四关虽亡，却让太学主一次得到两个秘密，一者素还真浮上台面，二者死神的爱人—一一夕海棠。更让太学主明白自己的敌人有多少，而死神真正的弱点又在何处？非到逼不得已，否则太学主是不可能轻易接受挑战，而当初他找上司徒偃，除了要他制造机关，更是为了手上的末日神话，因为他随时要预防未来的敌人，所以早在一开始，他便做下了这个布局，也一举让凤凰鸣跟六铢衣当场败退。而太学主也是个很会玩弄心机的人，一如夜行舟被煽动，导致黄泉引者分裂，兵力顿失一半。或者先派夜孽噬影去暗杀六铢衣的朋友莫悬灯。又在天剑之战时，分散六铢衣的注意力，导致问剑孤鸣莫名而死。而破匣求禅参加天剑之战时被佛顶冥塔的下落骗走，甚至对上漠刀绝尘。趁着万古长空败北，说出千叶传奇的布局，借此想拉拢长空，成为自己的手下。种种行为，其实都反映着一件事，太学主就是爱玩弄人心，只是跟死神不同的是，死神总是让人自己去找他，而太学主则是主动去玩人。我想，一定会有人说，死神跟太学主之间，究竟谁武功比较高？智慧比较高呢？其实答案就是没有机会证明的。因为死神，就是一个传说，而太学主则是一个相信人定胜天的凡人。当初他能担任学海无涯的太学主，一定有相当的修为、才华跟本事，六艺执令各个身怀绝艺，同时掌控六部的人怎能平凡？也因为这样的条件，才使得死国年纪找上他，而加持了太学主原有的能为。有人希望太学主出现射、无定三绝等等其他的绝技，其实太学主最后得到的答案只有一个，要杀人，简单利落就好，就是用刀，没有多余的花俏型态或者其他兵器样式，就是用刀，单纯的用到来呈现出最强的武力。太学主 剧截图就黄泉引者跟鹿苑一乘同时压境的时候，太学主说了一句话：“就因为我不曾开启杀戮，就让人质疑死神的能为了吗？”这也就代表着太学主怒了，因为爱玩，反而让人以为他是软脚虾，所以直接开杀，毫不留情，毫不手软，有如一个凶狠的刽子手，完全有我希望他存在的形象，杀人如麻，血腥暴力，因为他就是一个噬血的魔头。太学主开启的战役不多，但没有人可以在他手上占到便宜，除了漠刀绝尘，当时太学主第一次感觉到有人刀法如此卓越，并不是说漠刀绝尘在六铢衣之上，而是以漠刀绝尘的年龄，刀法竟然可以到如此程度，让他赞叹，他真正希望的是，漠刀绝尘跟万古长空，能够成为他的左右手，帮助他下棋。无奈这一段最后是无疾而终了，漠刀绝尘反而开启出新的戏路跑去跟御不凡结拜了，因为漠刀绝尘的原作者不希望他成为太学主的手下，为了维持漠刀的格，所以不能让太学主痛扁，结果来了个平手收场。这个作者真够没有人性，虽然说漠刀绝尘的作者，好像也就是我了。死神跟太学主决定性的差异，就来自于他们对于一夕海棠的态度。之前的漫谈有提到死神跟一夕海棠的爱情赌约。太学主跟死神不同的是，这方面太学主的经验要丰富太多了，连下酆都都可以被太学主玩得死去活来，更何况是一夕海棠。而两人最后的结果，便是太学主为自己留下后路，有如当初死神写下死国年纪一般，都是无限的可能。

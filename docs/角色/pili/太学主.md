# 太学主

霹雳布袋戏虚拟人物，学海无涯之主，学识渊博、武功盖世，造就儒门一干英才，却在意外接触死国年纪后，卸下一切教务，离群索居独自解译死国年纪，逐渐继承死神意志与死神的部分力量（六成死神之力），性格也产生异变。作风极端，暗中掌控武林局势，操弄他人命运遂成了其最感兴趣的游戏。死神之祸乱世期间，御天荒神六铢衣踏入尘世，搭配天剑之主叶小钗，两人联手与死神太学主展开一场末日决战。一夕海棠意外遗留太学主之子。

### 武器

**末日神话**

由司徒偃草拟设计图，太学主藉荒神之力取得地心之能，炼化死国地之元素“炼之菁”而成的旷古绝今之作，取名“末日神话”，象征死神降临、天地尽绝的意味。

末日神话造型宛如一尾鲜红赤蝎，与阎王（阎王锁武器）的设计概念相同，以层层叠叠的钩刃结合而成，刀刃利钩宛如蝎脚般满布刀身，刀锋划出完美的弧度，有如蝎尾弧翘，给人致命一刺。

末日神话刀柄有两根蝎脚，会窜出如血管般的触手，一旦吸取太学主的死神之血，魔力便会瞬间爆发，天地宛如陷入血红炼狱，令人胆颤心寒。

曾砍断凤凰鸣的淑世之道。

后为天剑、众神之默、创世、影神刀四大神兵合力破坏。

戾祸行经天葬山一带时，感受到一股难以消散的怨气，遂赋予重生之机，让末日重现，神话重生，在戾祸以自身戾气灌养之下，末日神话再现昔日威能。

末日神话宛如一尾鲜红如血的赤蝎，刀刃利勾如蝎脚般满布刀身，刀锋如蝎尾般上翘且薄利，一旦吸取太学主死神之血，魔力瞬间爆发！

## 人物经历

### 死国年纪

死国之神所写之书，共计十六章。

一日，学海无涯之主太学主听闻邪书问世，造成村落百姓惨亡，太学主亲往救援，眼前竟是死神自传《死国年纪》。

来自死国的文字无人可解，但太学主却异于常人，有如被选上的人一般，带走死国年纪，随后更离开学海，隐退在沼泽木屋翻译死国年纪。

自从他登场开始，就在一章章地翻阅这本笔记——这是死神重生的笔记，包含了死神一部分能力。

于是，太学主就在不断的研读之中有了变化，配乐也从清圣飘渺转为低沉阴暗，直到霹雳天启上册的结尾第十八集，穿上死神服装的太学主终于踏出了闭门半部多戏的大门，一如当年死神踏出死国，新生开始，太学主在人间的游戏也开始了。

### 太学主之死

太学主继承死神之能，其败亡并非素还真、千叶传奇、万古长空、叶小钗四人联手那么简单。

先是阎王锁、天狼星二人联手破其第一层护身气罩，然后太学主为了证明自己已经超越死神，设计得到了一夕海棠，埋下了神之子，同时也破了自身的第二层护身气罩，最后是六铢衣与叶小钗联手破其第三层护身罡气，随后万古长空与叶小钗联手使用众神之默、创世、影神刀、天剑四大神兵击断其兵器末日神话，接着素还真与千叶传奇联手以混沌之力击破其肉身，游子安等须弥如来藏高僧再使用法阵困住其元识，最后再以被六铢衣舍命保住和以鹿苑一乘众高僧之血重生的荒神之力所彻底毁灭。

种种行为，其实都反映着一件事，太学主就是爱玩弄人心，只是跟死神不同的是，死神总是让人自己去找他，而太学主则是主动去玩人。

因为死神，就是一个传说，而太学主则是一个相信人定胜天的凡人。

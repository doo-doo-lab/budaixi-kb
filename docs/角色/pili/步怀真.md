# 步怀真

================================================================================

霹雳布袋戏虚拟人物步怀真，霹雳布袋戏虚拟人物。表面为诙谐幽默的书生形象，实为深藏机锋的智者，以“从心所欲”为号，擅长智谋布局，曾破解东无君阵法。武学修为高深，掌握天罡佛印、大梵圣掌等绝技，多次协助素还真等正道人士化解危机。最终遭冥轮法魁与妖后联手击杀，元神归返本体一页书，完成分身使命。

## 角色设定

步怀真名称：步怀真称号：从心所欲性别：男身份：一页书（冥轮法魁杀掉步怀真后对上真正的一页书后被杀，一页书曾说步怀真是一页书，但一页书不是步怀真，说明只是一部分功体脱离本体形成的真气化体分身，这点跟素还真的分身神秘女郎的形成有些相似。）诗号：路行万里远，明月、流云、远山，故人心思乡；白纸提一字，是非、功过、曲直，千古论英雄。

## 角色经历
01、初登场，阻止业途灵挖坟。

02、帮助银狐破东无君阵法，避开冥界天狱的追杀。

03、捕捉黑虫，阻止九幽从黑虫中获得力量。

04、结识四无君杀体化身百朝臣，并与其游山玩水，实则牵制。

05、遇剑君十二恨，激动下创剑君十二爱诗，剑君听闻后离开。

06、救素还真欲开启鬼楼找邱霍蛉叶。

找先天三座协助，不得其法入，可爱地在外面数花瓣。

07、为救素还真，展现高超武艺，为其拔剑。

08、召集众人布大周天四方镇恶阵，开启鬼楼。

09、鬼楼开，恶鬼飞散。

与叶小钗一同救素还真。

10、上邪能境，一掌击毙鬼隐。

11、和百朝臣摊牌，逼出四无君。

12、与阴阳师对战，促成双方结盟。

13、与妖后大战，被冥轮法魁、妖后合力碎体，元神脱出魂归本体一页书。

14、百世经纶一页书再出。

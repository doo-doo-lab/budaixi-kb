# 歧天人

歧天人原是天屿剑尊半生宿敌，执著于剑，造劫无数，被武林中人称为剑劫。但一次机缘，与天屿剑尊化敌为友，进而结为莫逆，也因此弃恶从善。更在剑谪仙、玉龙隐士的号召下，曾与青玉镜一同参与五巅之战，对抗兵厄剑瘟与异殃悍族。在那之后，歧天人消声匿迹多时，曾暗中训练尚未加入道门的倦收天，乃倦收天亦师亦友的恩人。直到近日，武林上出现一名箫骨剑者，吹奏着白骨箫，并带来腥风血雨。

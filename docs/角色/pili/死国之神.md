# 死国之神

================================================================================

同义词死神（《霹雳布袋戏》死国之神）一般指死国之神死国之神，霹雳布袋戏虚拟人物。诞生于充满杀戮的死境，拥有绝对无敌的能力，主宰生死。死神降临人间，并非杀戮，也非救赎，而是抱持游戏的心态，创造三宝，以此考验人性，从中获得乐趣。直到遇见一夕海棠，意外改变了死神……

**中文名**：死国之神

**别名**：死神、神者（天者称）、术法之神

**配音**：黄文择

**性别**：男

**登场作品**：霹雳神州Ⅲ之天罪霹雳天启

**登场作品**：霹雳震寰宇之刀龙传说霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕霹雳魔封霹雳靖玄录

**登场作品**：霹雳震寰宇之刀龙传说霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕霹雳魔封霹雳靖玄录霹雳侠峰霹雳天越

**本尊雕偶师**：涂宗廷（潮州君皇）、刘梦凡（霹雳天越，君皇不续约后更换偶头）

**角色编剧**：廖明治

## 角色背景

死神图册“忘川，漂流的人生，何者才是真理？

我是死神，降临人间，非是杀戮，也非救赎，我只想完成自己的游戏。” 《霹雳天启》说是一部死神戏并不过分，从那充满了诡异气氛的片头中可以看出，副标题“死国年纪”也强调了这一点，除了作为死神主体的太学主之外，各种线索层出不穷，做足了各种各样的铺垫。

死神的过去，直到霹雳天启最后一集，我们才从《死国年纪》第一章中得以知道，原来死神是突然出现在死国，他具有无可比拟的强大力量，睥睨死国众生，被称为“死神”。 在漫长的岁月中，主宰死国的他感到空虚与厌倦，他不知道什么是失败与挫折，也早就失去了验证自身能为的兴趣。

于是死神创造了招式“死神过境”来打开通往人界的大门。 人界的尽情游戏，死神大概是得到了与众不同的乐趣，留下无数痕迹，但不知为何，他突然回到死国封闭了大门，而后悄然死去……太学主与《死国年纪》死神在死亡之前，写出名叫《死国年纪》的书，共计十六章。

一日，学海无涯之主太学主听闻邪书问世，造成村落百姓惨亡，太学主亲往救援，眼前竟是死神自传《死国年纪》。

来自死国的文字无人可解，但太学主却异于常人，有如被选上的人一般，带走死国年纪，随后更离开学海，隐退在沼泽木屋翻译死国年纪。

自从他登场开始，就在一章章地翻阅这本笔记——这是死神重生的笔记，包含了死神一部分能力。

于是，太学主就在不断的研读之中有了变化，配乐也从清圣飘渺转为低沉阴暗，直到霹雳天启上册的结尾第十八集，穿上死神服装的太学主终于踏出了闭门半部多戏的大门，一如当年死神踏出死国，新生开始，太学主在人间的游戏也开始了。

天狼星与阎王锁死国之神死国魖族出现两名难见的奇才，一者以武力擅长（天狼星），一者善阴谋诡计（阎王锁），但都有着邪恶的心灵，在封闭死国入口的时候，两人率领无数魖族攻击死神，却被他所击败。

死神将他所创造的两把镰刀“阎王”和“孤星”、以及“死神过境”一分为二（死神令和死神泣）交给两人，为今后的游戏做好准备。 在那战出招之前，死神流下了一滴眼泪，这也成为天狼星的口头禅。 “你见过死神的眼泪吗？” 但死神并未就此收手，他夺走了天狼星的心，并将自己的一只眼睛（连同死神三宝之一的不折之花的种子）送给了他。

从此天狼星变成没有感情的行尸走肉，他不能明白死神为什么要这样做，直到被阎王锁杀死后，死神死后残存的灵识才告知他，要天狼星毁灭所有的死神遗产。

无论是三宝，阎王锁或者太学主，都将是天狼星铲除的目标。

初始状态死神最初是一个绝对的权力和控制者，对生死有着绝对的掌控力，无人能反抗死神的决定。

# 南风不竞（霹雳布袋戏中的角色）

================================================================================

南风不竞，霹雳布袋戏中的角色。南风不竞，居住在六出飘霙的不世狂人，性格极端，有着偏执的思维与特立独行的作风，绝不容许旁人染指自己的所有物。因为对禳命女的爱，而欲解开石化，却在恢复后遭到无情拒绝；为得到禳命女的认同，开始了一连串的动作。中文名南风不竞外文名Nán fēng bú jìng别 名不世狂人配 音黄文择性 别男登场作品霹雳震寰宇之龙战八荒霹雳震寰宇之兵甲龙痕生 日2010年03月26日（首次登场日期）退 场2010年08月06日（最后上镜日期）登 场霹雳震寰宇之龙战八荒第17集出场集数39集根据地六出飘霙本尊雕偶师刘氏人物编剧申呈山（素问）

## 角色详解

驰来北马多骄气，歌到南风尽死声。伴随着狂傲的诗号与气势，在三教顶峰与仲裁者等人面前，一名我行我素的不世狂人就此出现，初登场的南风不竞尽显其不凡实力，随手便中断了数名高手的战局，但更为人所惊叹的，则是其对于爱情的执着与自我。南风不竞可说是为爱而生、为爱而活的一名纯粹角色，久远前一次的走火入魔，让南风不竞与禳命女结下了不解之缘，但由于禳命女转瞬化为石像，使得南风不竞在毫无选择以及认清事实的机会下，一味执着于对禳命女的爱情上，也一厢情愿的认为禳命女喜爱着自己。因此，百多年来，南风不竞为了使禳命女恢复，用尽各种方式，在剧情中并未着墨于南风不竞是否在认识禳命女之前便是如此狂妄的个性，或许是百年来以神之卷打遍天下无敌手，又或是百年来无法让禳命女恢复的挫败使然，南风不竞不论在行为上、思想上都极为偏激、极端。就在命定之人——楔子的出现，禳命女终于恢复了自由，但伴随而来的，却是无情的一巴掌，但这巴掌并没有打醒南风不竞，这名不世狂人仍旧执着于自己百年来追寻的爱情上，想来也是应该，百年来的付出，纵是一般人都难以放下了，更何况是南风不竞如此为爱痴狂之人？纵使日后不断地遭禳命女所拒绝，南风不竞的内心也曾出现自作多情的想法，但他仍是一往无悔。最终南风不竞决定在不归路上挑战天下人，虽然自己战得满身伤痕，战得心力交瘁，就在最后的期限之前，眼前再度出现之人，竟是禳命女所钟情的枫岫主人！纵使剧毒在身，南风不竞仍是豁命一战，就在三十天后的日出之时，胜负论定，南风不竞达成了三十天的条件，但此时的枫岫主人竟是束手就戮，此情此景让南风不竞大为讶异，随后禳命女出现，再受打击的南风不竞终于不支倒地，就在生死挣扎的边缘，隐约听见禳命女营救自己后的倾诉之言。经过如此多的事情转折，这一次南风不竞终于体悟及转变了，更在百韬略城寿宴上当众下跪致歉，但紧接而来的却是无情的打击，首度惨败于咒世主之手的南风不竞日后将何去何从？角色

## 诗号

这两句出自明末清初江苏太仓人的吴殳（一名吴乔，字修龄）的诗集《手臂录》里的《雪夜感怀》：酒尽灯残夜二更，打窗风雪映空明。驰来北马多骄气，歌到南风尽死声。海外更无奇事报，国中惟有旅葵生。不知冰冱何时了，一见梅花眼便清。

## 角色诗词

南风不竞伫望石像有感而发：空岁逐世寻无价，千里缁尘鬓双寒。当时陌看春情早，如今无处折烂漫。（龙战八荒17）六出飘霙，南风不竞赏景作画时所吟：煮一壶江山廓落，烟荡日薄；曳一地春华任率，光阴交错；凝一片沧海桑田，转入鎏杯；横一眼秋波即别，仰饮岁月；掠一笔千林妩媚，不世风流；乱一抹微云惊鸟，天涯旧恨。（龙战八荒18）南风不竞对天狼星所吟：四弦寻声马疾蹄，明月桥下走孤星，偷眼曾看千山碧，十里窥江锁烟迷。（龙战八荒23）看到石泪变色所吟：多情敲风一霎来，无情疾雨愁煞怀。几年心上，疑怕梦醒总是哀。（龙战八荒23）石像解封，禳命女离开，失意时旁白：清风三巡不解意，拈来落花笑情多。（龙战八荒25）落花咏怀，翩然直下伤心处；飘风凌乱，吹散多情两三行。（龙战八荒30集）南风不竞感慨所吟：去年今日此门中，人面桃花相映红。人面不知何处去，桃花依旧笑春风。（龙战八荒28）（其实在剧中把“人面不知何处去”改成了“今年不知人何在”，这个错误包括官网，清一色的都CTRL+C，CTRL+V原诗了）独自饮酒时所吟：孤夜独斟酌，一杯浊酒对清风，举也茫，放也茫。（龙战八荒32）向湘灵告白：有心天下，却输一笔多情。我的山水落在你的眉间，你肯入画么？不归路最终战：吾用一生，写一首诗，盲目寻添，只找一字，直至此刻，诗成一字，早已铭心。琴断所吟：情商难理，满山飘叶映斜阳。激亢的琴声中，仿似多年心衷，欲付一曲终了。情弦到此已收声，自此不复弹琴影。如念半兹在心处，便教天风催薄命。（兵甲龙痕12）焚琴断念，了却多少，万般是是与非非，尽化余烟消日薄。为情奔波，来去缁尘，当时错看春情落处，如今繁华无主。血战咒世主旁白：自毁气海，自断生路，因为是抉择，所以一往无悔。同样料不到，是此刻陪在身边的人是知己，是仇敌？人生为何总是这般荒谬？倒落旁白：不能，不愿。却也只能含恨照看，南风不竞此时，只有一股深重的悲哀与不甘，为情奔波，来去缁尘，当时错看春情落处，如今繁华无主，空岁追逐，换得一场徒劳。（兵甲龙痕15）六出飘霙终幕：大雪没身，南风不竞此名，还有谁惦念？

## 角色经历

初登场时气势恢宏，打破火宅三人组和正道三人组僵持的局势，来得快去得也快，叫在场众人莫名其妙。因佛业双身苦集合一计划，使六出飘霙铜柱破空穿过集境，南风不竞误认为集境破坏六出飘霙，而屠杀天机院等集境众人，并要天机院恢复六出飘霙，天机院众人感到莫名奇妙，后南风不竞在牌楼上留下：三五二八时，千里曝屍骸。后因与香独秀交涉作罢。在火宅二人组欲擒回禳命女之时，与仲裁者过招，因败黯纪仲裁者之招「神毁之象」与当年四魌界武冠传说雅狄王所用神之卷相似，因而被怀疑与雅狄王失踪有关。佛狱也开始关注南风不竞。曾闯东阿天悬五锋齐天阵取得稜晶花。因为太过执着于对禳命女的感情，一度走上极端。在不归路以神之卷为饵、一月为限，挑战天下。之后与枫岫主人不归路最终一决，蛛毒爆发。禳命女为其解毒，并告诉南风自己并不爱他。后来禳命女为火宅佛狱所留，为救禳命女，在身体伤势未复之际，闯入火宅佛狱，而后枫岫主人联手对抗咒世主，战况极为惨烈，初显实力的咒世主极为强悍，最终枫岫被咒世主所擒，南风再受重伤，并要求南风一日之内拿神之卷交换，南风急着赶回六出飘霙取神之卷，却被已经变为复仇者的啸日猋所重伤，含恨倒落雪中……

## 角色评价

一名不世狂人为何而愁？一名渺看世事之人为何而狂？一个美丽的入魔划开序幕百年只有等待，也许还有千年，只求无悔而梦会醒，而自己该然。走的再自得还是换得别人的不认同走的再任真还是解得无法再解你的山水我的眉间唯南风、唯自己、唯那轻淡的飘霙之处。命运是注定，一个美丽的脸孔，一场痴迷的追逐记不清是第几次被拒於门外忆不清那千回想像的美丽画面破碎也不足以描述，为何要背叛？越是看不破、越是踏不破红尘一夫挡关，为了情为了爱，最后还是得不到拿不著手一扬，抓不住的爱情手一紧，是自己伤过的心再次起身，是重生，是为了丢弃那可笑的过往只是心底依然期待，期待那小小的芽会开花再聪明也只剩面对情爱的傻白雪染红手一放，是无力的痛漫延著最后一丝的力量，都在回想，这一生是何？到底所求因为爱？还是那坚定的友情……紫色的身影交炽在内心的激动，卷起南风狂澜不己。

# 火中雪

藏身不灭火坑的女剑客，长发及地，性格偏激、冷傲不羁，极端厌恶男性，对冰烈的追求丝毫不假辞色，背后牵扯著与方城子之间的恩怨情仇和日盲族血案。

## 来自百度百科的补充

火中雪，藏身不灭火坑中的女高人，功体属性为火，但个性造型反差却甚大。火中雪外表冷艳绝伦，性格高傲不羁，故赋予冰冷的雪白色调。火中雪一身及地白发，尤当火中雪发怒之时，白发更为瞬间狂张，反应其激烈的情绪。一袭白衣的造型，素雅中不失高贵。常常释放出炽热的炎气和火焰，与全身的雪白相映衬、对比，更凸显出人物的性情，也与名字相衬。火中雪平时甚少使用兵器，却在面对狂河冰烈死缠烂打的追求时，两人为分高下而兵戎相向，最后两败俱伤，火中雪为养伤而藏身不灭火坑。后因神州大地崩断，为借冰火阴阳二气接合断层，在伏龙先生的居中斡旋下，请来风之痕与不死鸟漂协助，促成雪崩与炎流相会，互相拔出对方的兵器。

昔日，火中雪与方城子有过恋情，却遭背叛，一怒之下加入覆灭日盲族的行动中，之后就此退隐。殊不知多年后，竟发现方城子诈死并化身玉阳君，而昔日一切所作所为，皆为练就沙溶神法，让火中雪怒不可遏，欲杀负心汉，但不敌沙溶神法的威能，火中雪血溅当场，香消玉殒。火中雪死后，痴情的狂河冰烈为其立碑安葬于夔木林，并将火之剑插于坟前相伴；而后狂河冰烈代替不二做执行死亡任务之前，生怕一去就此不回，遂将随身冰烈刀插放在火之剑旁，代表永远与火中雪相伴之心。

### 诗词记录
吟诗：平芜春去也，嫦娥自有心。屈指十八日，真假自分明。（意指“无情果”）
解析：这是伏龙先生解出的字谜，第一句芜去掉草字头就是“无”字，第二句指嫦娥是月宫之主，所求不过一个“情”字，即“月”上面写个“主”再加上“心”。第三句指占卜时掐指一算，“日”再加上“十”和“八”就是果字。多日之后，无情花结果，自然可一试真心。

### 角色配乐
◎炎流（火山高人气势曲）
曲/编曲：胡俊溢 收录于《霹雳英雄音乐精选十八》
作者透过现代的电子音乐与重量级的节拍来描述匿居于火山中的冷傲女剑客。打击乐快速的节奏、低缓凝重的低音旋律以及冰冷的管乐与合成音效点缀，形成热情与冰冷的强烈冲突，正若火山高人·火中雪其偏执冷酷的个性一般令人难以捉摸。
◎赤炎烈火（火中雪）
曲/编曲：阿轮 收录于《霹雳神州III之天罪 原声带》
弦乐与沉稳的节奏协奏下，呈现四平八稳却隐含霸气的威猛力道，点缀的魔幻乐音与人声合声，却让人有神秘莫测的想象。
◎发如雪（火中雪情境曲）
曲/编曲：黄建秦 收录于《霹雳神州III之天罪 原声带》
神秘沉静的乐音，低鸣的箫声呜咽，似乎有着不为人知的过往，三味线弹奏着增添飘忽迷离色彩，在一片沉静之下隐藏着意料之外的秘密。

### 角色评价
火中雪的经历是幸福的，也是有些悲惨的。幸福的是她身边有冰烈这样痴情、专一、无怨无悔为她奉献的人在，悲惨的是她挚爱的人——玉阳君欺骗了她，最后还杀了她。

# 火中雪
================================================================================

火中雪

藏身不灭火坑的女剑客，长发及地，性格偏激、冷傲不羁，极端厌恶男性，对冰烈的追求丝毫不假辞色，背后牵扯著与方城子之间的恩怨情仇和日盲族血案。

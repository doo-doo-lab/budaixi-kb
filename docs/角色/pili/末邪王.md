# 𬸚变迦罗

霹雳布袋戏虚拟人物𬸚变迦罗，霹雳布袋戏虚拟人物。大漠苍鹰与地冥一战后并未身亡，为地冥暗中改造为落魄废人，弃之于破庙，后由暗影所带回。几经转折，竟意外被天邪八部众之一的“末邪王”取代，重生蜕变，背生枯骨双翼，手执魔化鹰之隼，杀气腾腾现身于风之谷。

## 人物设定

诗号：末法时代，邪翼掠世地狱海。天地悲哀，战火燎原魔龙灾。名言：𬸚风涌，邪刀鸣，性命停。初登场：霹雳天命之仙魔鏖锋Ⅱ斩魔录 第33章退场：霹雳天命之战祸邪神Ⅱ破邪传 第9章（死于荒漠孤鹰）根据地：示流岛·北邪屿、风之谷、三界塔、末法广漠

## 人物能力

武器：末邪刃武学：神魔同坠·地狱变相、驭神风·邪刀流、操邪曜·聚鬼芒·末法毁天荒、邪刀唯杀、邪刀烍、迦罗狱阇、天罗八相、乱魔·伐天章、迦罗夜变、邪刀葬神荒、𬸚刀流特殊象征：末法邪龙印、枯骨双翼坐骑：金翼鹏龙

## 经历

𬸚变迦罗，本名迦沙，原为风之一族四裔中古𫛟风裔的少主，年幼时外形为一小龙，是其族脉独有特征。

古𫛟风裔血案后，小龙被卖到百妖海市马戏团杂耍。

第一勇士尘远拖命带着血书前往同为四裔的驭风鹰裔求助，荒漠孤鹰接信后化身为死去的尘远的模样追凶，在找到小龙后将事情大致告知，谁知贼人杀至，使两人分散而再无彼此音讯。𬸚变迦罗大难不死，不知多少岁月的颠沛流离后，遇到八歧邪神和古𫛟风裔的风兽祖龙·风𬸦流华，八歧邪神七魂之一的枭赐予其枯骨双翼，并能化为人形，成为八部众之一的末邪王。𬸚变迦罗多次出勤，在邪种源计划任务中击败羽衣狐·花宵朝雾，成功占领长生树培育邪源；

在攻打示流岛时，占领外海北邪屿并和暗禘建立国度势力等等。

后来，八歧邪神计划入侵中原神州，九天玄尊率八剑士展开圣战，八歧邪神失败，𬸚变迦罗也被荒漠孤鹰和尊佛传人杀死。

官网桌布𬸚变迦罗死后，邪魂来到风之谷，利用邪魂策王转生到荒漠孤鹰之子（大漠苍鹰之胞弟）身上，欲探知龙首所在，谁知被地冥的殉道之眼发现，遂血洗风之谷，婴儿也难逃一劫，𬸚变迦罗邪魂只能在风之谷徘徊，再等机会。

数年后，风之谷遗孤大漠苍鹰报复地冥不成反被其改造为无名废人，𬸚变迦罗邪魂暗中影响暗影，让其将无名废人扔入风之谷断崖，成功邪魂策王，重临人间。𬸚变迦罗帮助暗影解开禁锢，复活暗禘，两人合作继续寻找解封龙首。𬸚变迦罗虽占据大漠苍鹰的身躯，但其元神尚未炼化并不断挣扎，尤其在和天迹交手时发作更猛。

后来，地冥化身瑟斯二世，与无限恨合作设计𬸚变迦罗，用夺胎销形棺将邪魂封于千日峰下，救回大漠苍鹰，并让大漠苍鹰假冒𬸚变迦罗伺机而动。

谁知御天者奈落川棋高一着，识破地冥计谋，放出𬸚变迦罗，并将大漠苍鹰魂魄打散。𬸚变迦罗带着即将消散的大漠苍鹰魂识去刺激天迹，欲动手时被天堂之门内的尊佛传人气息吓走。

当年𬸚变迦罗迎娶风兽祖龙后，育有一子小乐。𬸚变迦罗死后，风兽祖龙为报仇杀上风之谷，荒漠孤鹰无奈重伤风兽祖龙，将其置于炬风穴中，风兽祖龙死前生下小兽，怨气也永积古穴，荒漠孤鹰则将掌握龙首秘密的金钥让劫红颜藏在小兽心口。𬸚变迦罗在和寄体重生的剑上缺战中，炬风狴冲入战场，𬸚变迦罗找到小兽，在数日相处中发现此小兽便是当年自己与风兽祖龙所生之子，对荒漠孤鹰更是恨之入骨。

因暗禘对劫红颜身份存疑，𬸚变迦罗在携子前往长生树调查途中结识飘撇浪子和冰少未知，在确认劫红颜便是羽衣狐后，𬸚变迦罗与暗禘欲联手擒捉未知要挟劫红颜，但战中被未知的剑法化消杀气，暂且作罢。

暗禘和剑上缺终战，𬸚变迦罗救下暗禘，言语中被暗禘察觉有事隐瞒。

荒漠孤鹰和九婴不断逼迫𬸚变迦罗杀死亲儿，解封龙首，𬸚变迦罗心有不忍，欲挡下两人送子离开，却被暗禘出手杀死小乐，𬸚变迦罗为自己再度无能守住亲人而悲愤，由此种下了背离之心。

末邪王·𬸚变迦罗德风古道配合战一役未果，加之受鬼麒主言语刺激，𬸚变迦罗的复仇之心日渐加重，以风刀阵阻止蚩罗前往支援鬼麒主的行动，但也被八歧邪神派出奈落川追责，𬸚变迦罗断臂明志，在一行长生树探得新邪源下落后脱离八部众。

前往长生树的工作并不顺利，𬸚变迦罗的邪力遭婴灵附身的未知剥夺，加上被转轮灵童点化，内心迷茫的𬸚变迦罗也不想再追究，在和劫红颜交谈得到复生儿子的办法后离开长生树。

回归风之谷时遭下令处决，在御天者面前被荒漠孤鹰杀死，体内风之一族的灵力转化为生命力，加上劫红颜预先设下的术法，使小乐在失去过往记忆的情况下重生。𬸚变迦罗虽死，但江湖的恩恩怨怨终于结束，此生最大的牵挂小乐，也从遗憾变为了崭新的开始。

在正道开启八龙山战役时，八歧邪神复活天邪八部众，𬸚变迦罗也再次出现。

但𬸚变迦罗本身早已脱离邪神，因此这个𬸚变迦罗非是本人，只是邪神利用邪力制造的一个拥有相同面容的傀儡。

傀儡𬸚变迦罗在战中阻挡邃无端，被邃无端以单锋极致消灭。

# 霹雳布袋戏

**Pili · 黄强华、黄文择家族** · 1984 — 至今 · 收录 **874** 位角色

霹雳布袋戏由黄海岱第三代孙黄强华、黄文择兄弟于 1984 年创立"霹雳"系列，以素还真为核心人物开启庞大的"霹雳"宇宙，跨越四十年。剧目从《霹雳金光》《霹雳眼》起，至《霹雳天命之战》《霹雳魔封》《霹雳惊涛》等数百部连载，已成为台湾布袋戏最具代表性的剧团之一。

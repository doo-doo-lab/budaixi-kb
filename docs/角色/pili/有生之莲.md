# 解锋镝

================================================================================

霹雳布袋戏虚拟人物解锋镝。“有生之莲解锋镝”意指有生之年，皆心系于弭平烽火狼烟。在清香白莲亡心后，被埋入葬神之野九丈地底，开启九轮天的玄天魔能，却意外激荡清香白莲体内的芬陀利华清净无垢体作用，因而修补伤体，让素还真重生成为解锋镝。解锋镝虽失去了原有的记忆，却因天命使然，开始介入九轮天与苦境之战端，从中以智慧斡旋各大势力，守护整个武林。诗号：生有生，大道自有征，死无死，何用百年算。掩筝罢弦听渊默，苍茫天地何解莲。

## 角色背景

解锋镝素还真失心埋于地底时由芬陀利华圣气和魔息魔气所结合产生的特殊角色。

阴阳婆枯半身以通天之能，为失心的素还真，卜策重生之计，更预言素还真将有千日之忘，当此万难时刻，记忆尽失的素还真，将对武林造成什么影响呢？

姓名由来“有生之莲·解锋镝”这个名字是由董事长黄强华亲自定名，意谓着素还真有生之年，皆心系于弭平武林烽烟。

甲骨文与金文中，“解”的写法，像是人以双手紧抱牛角，将牛角从头拔下来的模样，以“解”为姓，要念“懈”的音，但因为有解除战祸的意思，所以这边的“解”，便以“解除”的解为用。

而台语音中，“解”的念法为“懈”，以松懈战事紧张为意，不管是解除烽火或松懈战事之紧张，解锋镝生来，就是要为苦境武林打拼。

角色起源与故事0501030204解锋镝角色的出现，乃因素还真被异识附心，在解除他心口的异识之害时有提到，素还真因先前用火晶灵之力，推送黑月回森狱时，使得体内紫火有损，产生异变，进而成为焚心的变数。

后来浮动山城之主，以梦术为素还真留保一息之存，又逢阴阳婆指点，让齐天变与黄花落将亡心的素还真，葬于葬神之野的九丈地底，借四王之心开启九轮天的玄天魔能，激荡素还真的芬陀利华清净不垢体作用，修补素还真伤体，更自生出一颗新心，让素还真由此死局中，脱胎重生。

但因新生之心，心识尚不稳，故而有了千日之忘，此千日之忘，所指的是素还真（解锋镝）将有未来一千日的记忆空白，他在这一千日中，宛若新生，忘了过去的种种人事记忆，但他内心存有为武林平定烽火狼烟的心志，却是不变，是以忘了一切的素还真，以“有生之莲·解锋镝”为名，奔波于弭平武林众乱。

解锋镝因得天缘，以芬陀利华初生纯净之心，感应到天下九龙元素，受到九轮天降世影响，而显得躁乱不已，所以在他自九丈净土中苏醒的第一要事，便是前往人世九龙异乱之处，一一安抚。

河图为兽之驡，因九轮天入侵，天地冥变，万兽之灵逆反，幸有解锋镝阻止，异咒伏降，柔化招抚了河图。

后更前往四处，解除了金之鑨、水之泷、火之𤇭、阳之陇、月之胧所造成的异变之害。

其中水之泷的水萃，让他心口剥离之症，得到了纾解。

而人之儱齐天变，则因早前修练素还真所赠的棍谱，其武功心法有柔顺转化暴躁之气的作用，故而齐天变不受九轮天的影响。

至于石之砻与木之栊，他们下落为何，又将有何故事？

解锋镝与浮动山城的交集，又有何种后续？

这些都将在素还真的未来剧情，一一展现。

解锋镝以平定九轮天之乱为首要，解锋镝为解救一际云川所做下的安排，将为往后局势造成影响。

天相苍羽凌霄已找上门来，两人的会谈将引出新契机。

武林局势瞬息万变，而他本身的失忆与无意间得到的四心之力，也将为他的未来之路，埋下危劫变数，且看他如何克服难关，恢复成“清香白莲·素还真”。

## 角色形象

造型虽然解锋镝是素还真，但是在造型上还是希望自素还真既有形象跳脱，除了偶头类似，但在其他形象上要有一些变化。以类似莲花花瓣的饰物象征与素还真密不可分的莲花。采用类似琉璃蓝色系的布料，奠定服装主色。配合持扇特色，设计书生发型，不戴头冠，改搭配简约的发饰。以较淡的浅蓝作出不同层次的蓝色调。高雅的蓝色折扇，并手工画上莲花。场景“天月山水”乃解锋镝依天月勾峰的地灵之气，所建筑出来的新居所。清月映山，好风如水，枯崖老松成古趣，尘外云通天地衢，一盏茶、一浮世，对饮人间一场局。

## 角色能力

武器麒麟双剑麒麟是传说中的神兽，雄性名麒，雌性名麟，也能代表阴阳和谐，以此来融合古代的雌雄双剑概念，并搭配麒麟星造型色系，来设计专属武器：剑柄也有麟片图案设计。

以麒麟半身装饰，强调特色；

双剑以此圆珠大小来做分别，较大为雄剑，较小的为雌剑；

镂空设计，有云状麟片，象征麒麟于云端穿梭。

## 人际关系

主要人际关系苍羽凌霄人际关系九轮天相，有不世之才，因天譩认为解锋镝是可以利用的对象，故天相亲入苦境，以司空灵羽之名，在天月山水与解锋镝品茗观局、谈论局势，虽然用了假名，但可看出双方早就对彼此底细心知肚明。

相谈数日后，苍羽凌霄忽然提出以不动城、九轮天之战胜负为赌，拿性命作赌注，两人皆以智谋见长，互相试探下，为未来战局投下了变数。

一线生、秦假仙素还真失忆，一线生与秦假仙这些好友自然是着急的不得了，想方设法要让解锋镝记起素还真之事，多年友情表露无疑。

而解锋镝虽然记不得这些长久以来一起奋斗的伙伴，但是心系武林安危之心是有志一同的，一旦解锋镝安排计策、交代事项，一线生与秦假仙就会很有默契的完美执行。

次要人际关系朋友：业途灵、齐天变、赮毕钵罗、一页书、赦天琴箕、叶小钗、舍脂多（枯半身）、风之痕、乱世狂刀其他：天譩、纵横子、巧天工、叹希奇（二人合作进入山海奇观）、夔禺疆、圆公子、万魔惊座解锋镝天月勾峰之上，解锋镝以一句“天其高，无日月星辰，不成神话；

地其阔，无万物百态，不成人间，吾以素身涉江湖，这一遭，人间再会”，翩然现身，犹如谪仙之姿。

解锋镝甫一登场，便制服河图、解救麒麟星（屈世途所扮），而后前往不动城化解不动城和九轮的对抗，并被邀请到天譩之间。

九轮天内，解锋镝与天譩下一盘竞山棋后，表明各自的立场不同，并婉拒与天譩结盟。

后揭破一刀斋杀起手有回之事，拜见阴阳婆枯半身，以天乙八衍赢了天乙子阳术，得阴阳婆指点获知一际云川被困之事。

解锋镝观察了一际云川的实际情况后，与赮毕钵罗商量救一际云川众人，认为应以不动城的力量引出沉沦王，并让赮毕钵罗联系魔息大帝。

解锋镝在天月勾峰泡茶吟诗“丝弦揉作山河惊，指下风虎斗云龙，促音挥破时世调，别有深机一万重。”，此时九轮天天相前来拜访，并自称司空灵羽，与解锋镝饮茶谈当今局势，而后以一际云川之事打赌，第一局平局，并约定再赌一局，赌一际云川众人是否得救。

纵横子邀请解锋镝去天地碁下棋，两人联手下赢第一关卡，进入第二关卡，第二关卡要求在15天内破掉，否则第一关卡作废。

在破第一关卡中途，解锋镝听闻倦收天受伤之事，离开天地碁，以天相赌局和与纵横子下棋的规则要求，去往九轮天巧妙换得医治倦收天的解药。

然后与天相苍羽凌霄去一际云川证实了一际云川众人得救之事，从而赢得了第二场赌局。

解锋镝白衣剑少和洛子商身受重伤，解锋镝听闻消息后心中情绪受到牵引，回到天月勾峰之后，为恢复记忆，终于答应从一线生手中接过麒麟面具，为武林，为苍生，再次担起不动城之责，最后不动城天命已了，解锋镝在仙脚顶峰重新回归素还真的身份。

# 贺楼琼宇

习武成痴的奇女子，过去因与贺楼世家不合而脱离世家，原本只专注在古风第的梳剑剑艺上，后受前来正心六崇越的香六牙指点，兼修列鼎草庐的武学，并悟出剑鼎合一的剑阵，后为达六武合一的境界而在列鼎草庐持续进修。曾与能剑怪物元八荒，有过一个约定，因此对其相当执著。

### 主要经历

贺楼琼宇出场时，伴随诗号"苍昊云肠照吾心，白玉梳笔剑鸣"，其貌宛若天女落尘，其态则如剑仙入世。

贺楼琼宇与兵灾雪交手，兵灾雪意外收手，并表示"吾没必要，与妳分胜负"，其责任只在八无暇兄弟，贺楼琼宇对此并不认同，认为终会与其一决。

左无咎曾试图请贺楼琼宇出关相助，但见到剑阵后便退缩。因贺楼琼宇对六部武学有所追求且性格孤僻，一度被怀疑与假山座事件有关。

贺楼琼宇与元八荒曾有深厚感情，元八荒曾许诺"我会给你铸一把剑"，贺楼琼宇为此等待漫长岁月，但元八荒后来忘却此约。最终，两人因各自对剑道的极致追求而分开，将彼此视为特别的同道。

贺楼琼宇曾与命萧疏一战，认识到自身差距；后与元八荒比剑，从中获得开悟。她铭记与西窗月的约定，走向属于自己的未来。

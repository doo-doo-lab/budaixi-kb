# 贺楼琼宇

习武成痴的奇女子，过去因与贺楼世家不合而脱离世家，原本只专注在古风第的梳剑剑艺上，后受前来正心六崇越的香六牙指点，兼修列鼎草庐的武学，并悟出剑鼎合一的剑阵，后为达六武合一的境界而在列鼎草庐持续进修。曾与能剑怪物元八荒，有过一个约定，因此对其相当执著。

# 靜如禪 (静如禅)
================================================================================

靜如禪

性格恬淡勤樸，於佛法上有精深造詣的高僧，與淨琉璃菩薩、佛劍分說等人屬於同輩，地位崇高。喜好蒔花植栽，昔日在梵宇是專門傳授佛法的經師，被尊稱為「傳燈上師」。也曾指導過問菩提修習佛法，兩人感情甚篤，亦師亦友。在問菩提離開梵宇後，也跟著一同離開，於淨簷幽居共同隱居修行。

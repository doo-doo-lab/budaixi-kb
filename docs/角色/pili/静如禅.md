# 静如禅

性格恬淡勤朴，于佛法上有精深造诣的高僧，与净琉璃菩萨、佛剑分说等人属于同辈，地位崇高。喜好莳花植栽，昔日在梵宇是专门传授佛法的经师，被尊称为“传灯上师”。也曾指导过问菩提修习佛法，两人感情甚笃，亦师亦友。在问菩提离开梵宇后，也跟着一同离开，于净檐幽居共同隐居修行。

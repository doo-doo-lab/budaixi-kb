# 一步莲华（霹雳布袋戏虚拟人物）

## 角色背景

角色由来霹雳会12年度赠品写真《传奇》内页有一日编剧在街上散步时，忽然看见一间店家门口放着大日如来的法相，瞬间伫足观看，当时只是印象深刻，但没有多加想法，直到后来确定接写大日殿执事，那时编剧的脑海中瞬间浮现了那日在店家门前见到的庄严法相，心来则笔动，写下莲华二字，并题诗：一步一罪化，一步一莲华。

姓名由来一步莲华原名大日莲华，因大日殿执事才让编剧决定取名大日，但怕亵渎了真佛大日如来，所以想了很久，最后决定改名为一步莲华。

因莲华出污泥而不染之特性，故佛教视莲花为清净之意。“一步”带有佛者徒步苦修的艰辛和执着，佛者行步修行除去他人的罪业、消去他人罪孽，再转化为代表重生于圣洁的莲华，体现一步莲华对天下苍生苦难之怜悯，并将一切罪恶净化成善行的决心。

## 角色形象

造型霹雳会12年度赠品写真《传奇》内页大日如来有专属的梵字，而一步莲华额头上的梵字其实却是使用了观世音菩萨，理论上编剧设计一步莲华的构想应该是用大日如来的字，但是因为配乐变成观世音菩萨了。

一步莲华原名大日莲华，因大日殿执事才让编剧决定取名大日，但事关怕亵渎了真佛大日如来，所以想了很久，最后决定改名为一步莲华，决定后，便是音乐，指定七佛灭罪真言，做为一步莲华的曲子，圣尊者的文戏曲，即是莲华部七字心真言，此真言意为：一切莲华部心。

能成一切三世胜法，即正观音咒，又名灭业障咒。

藏经中有观自在菩萨心真言一印念诵法.即系此咒念诵法。

如是秘密法要，精诚修持，一切所为，速得成就。

代表此真言之字，就是圣尊者额上这个梵字，这个字又有此义：一切法、一切谛，不可得故。

造型上与而袭灭天来相反：圣尊者为白，魔之者为黑，额上的反照梵字、脸上的刺青，开眼与闭眼的相反，更是在强调，一步莲华藉以袭灭天来的存在，一同在人间亲身去面对魔道，体会魔道，进而彻底领悟如来之意，最终走过这一遭，拥有双极之体的一步莲华，终究佛魔双体合一，进而成为大日莲华，得证自己之路，化为金色莲华重新渡世。

性格从”人“作为出发点，以肉身渡尘世、救苍生，一步莲华所展现出的，除了因佛门思想所引发的同情心与多愁善感，更有着敏感、仁慈、和善、宽厚等特质，求助戤戮狂狶解除血月异象时的对话，显现出一步莲华不但擅长沟通协调，也懂得察言观色，可以说双鱼座该表现的优点，一步莲华都具备，而且发挥的淋漓尽致，尽现身为水象星座的优势。

就一般而言，双鱼座表面上内向甚至羞怯，但内心往往是复杂而矛盾的，同时存在着善与恶、精神与物质等对立的挣扎，这根一步莲华一心欲消灭自身恶体、撤除魔界之祸的想法，有种莫名又诡异的契合性。

人称双鱼座是”天使与恶魔的综合体“，这在一步莲华身上，似乎可以得到印证。

场景一步莲华场景设计大日殿佛界高层的所在地，万圣岩议事厅堂，由一步莲华所掌理。

立有三尊佛像，左右两侧为光明、无垢尊者，伫立中间之佛像则为万圣岩制高圣者“一步莲华”。

大日殿菩提天池万圣岩之圣地，一步莲华平日修行之处，居于高山石原之上，天池池面广阔，池水平静无波，隐隐散发耀光，池边设有莲华禅座。

天池中的莲华圣露具有修复元功之能，一步莲华于此点悟吞佛童子之善性。

菩提天池莲华之池万圣岩一步莲华修行之处，莲花池中藏有圣气，可帮助疗伤修复功体之用，四周墙壁上写有《摩诃般若波罗蜜多心经》，为一清静庄严的别苑。

莲华之池如来之巅万圣岩最高峰之处，为一断崖，紫宫世家凤麟镜毁，第一颗惑星坠落，直冲万圣岩，圣尊者一步莲华立身如来之巅以莲华圣功当下惑星之势，背后却早吞佛朱厌所伤，以带伤之体强催梵海神击之招竟成功击碎惑星。

## 角色经历
霹雳奇象时期霹雳会刊129期人物预告一步莲华是万圣岩大日殿的最高指导者，在许久之前为修炼如来不毁之身，而逼出自身内恶念而成的恶体袭灭天来。

一步莲华平日鲜少露面，但曾回访万圣岩大日殿为佛剑分说医治伤势，又在佛剑分说因圆儿之事被用刑时，出声为佛剑分说讨保，并暂时收回佛牒，要佛剑再入修罗轮回。

一步莲华与好友六弦之首苍会谈，表示为组织异度魔界结合断层，必要之时采取极端。

在公法庭、日月才子、玄宗、万圣岩共同进攻笑蓬莱、火焰魔城，却落入颓势之时，圣尊者突然出现，以梵海神击重创九祸，迫使火焰魔城转移据点，而一步莲华也将吞佛童子制伏擒回。

为寻回吞佛童子心中深埋的一丝人性，一步莲华带着吞佛童子前往九峰莲潃，要唤起吞佛体内一剑封禅之人格，失败后改施放七佛灭罪真言来消去吞佛童子之罪孽，在一层一层的真言加持下，吞佛童子终于露出痛苦神色，岂料最后吞佛童子竟选择泄尽记忆，终结魔胎宿命，但一步莲华仍决心赐吞佛童子新生，要重新培养吞佛童子。

在魔界断层接合后，天生泪阳的异象，一步莲华前往云渡山与一页书、苍讨论异象，更言万圣岩因此异象分裂为二，以往囚禁于深处的三名罪犯更因此逃出，最后三人决定，一步莲华处理万圣岩三名罪犯之事。

一步莲华回到万圣岩后，收到执戒殿传来之法卷，质疑其恶体袭灭天来协助异度魔界接合断层的罪过，而后善法天子自执戒殿回归，一步莲华负起对抗袭灭天来之事，而万圣岩也交由善法天子指挥。

苍前来菩提天池与一步莲华讨论一页书被困风水禁地以及泪阳血月之事，一步莲华遂暗中传声善法天子，请善法天子不可对戤戮狂狶下杀手，因其招可破血海。

在菩提天池继续教化吞佛童子，却见恶体袭灭天来前来，两人暗中以佛魔之气互冲，不分高下。

在善法天子在善法天子带狂狶前来后，为其解开一根贯脉钉，以此要求狂狶以苍雷真殛之招毁掉血海。

善法天子走后，与袭灭天来正式开启佛魔之辩，最后决定两人以吞佛童子身上之人格为赌。

霹雳谜城时期霹雳谜城剧照一步莲华与袭灭天来再度对战，就在极招冲击之时，天际血月异象解除，一步莲华稍一分心而受伤，就在袭灭天来准备赞掌时，吞佛童子即时打向袭灭天来而救了一步莲华，袭灭天来见状消失现场，一步莲华将吞佛童子带回万圣岩，认为吞佛童子心中善念尚存。

# 蒼月銀血 (苍月银血)
================================================================================

蒼月銀血

月族大將軍，蒼勁挺拔、英武神勇，傲然氣態宛若天神之姿，睥睨群倫。掌管月族的軍國大事，性格冷靜、沉穩，對月王幽溟恭敬忠誠，捍衛月華古都，遏止羅喉復生染指月族。

# 苍月银血

月族大将军，苍劲挺拔、英武神勇，傲然气态宛若天神之姿，睥睨群伦。掌管月族的军国大事，性格冷静、沉稳，对月王幽溟恭敬忠诚，捍卫月华古都，遏止罗喉复生染指月族。

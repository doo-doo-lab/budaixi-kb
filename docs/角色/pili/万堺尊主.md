# 万堺尊主

曾经的武林名人，高瞻远瞩、见识不凡，当年为维护武林和平，倡导万教同修，并力邀儒、道、释三教，以及易天玄脉与其他派门，一同创建了万堺同修会，建立万堺朝城。在万堺同修会的百器论衡上，因神秘一箭而身负重伤，并陷昏迷中，造成万堺同修会群龙无首，局势动荡不安。

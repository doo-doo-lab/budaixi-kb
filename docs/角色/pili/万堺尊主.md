# 万堺尊主

曾经的武林名人，高瞻远瞩、见识不凡，当年为维护武林和平，倡导万教同修，并力邀儒、道、释三教，以及易天玄脉与其他派门，一同创建了万堺同修会，建立万堺朝城。在万堺同修会的百器论衡上，因神秘一箭而身负重伤，并陷昏迷中，造成万堺同修会群龙无首，局势动荡不安。

久远前武林名人，高瞻远瞩、见识不凡，当年为维护武林和平，倡导万教同修，并力邀儒、道、释三教，以及易天玄脉与其他派门，一同创建了万堺同修会，建立万堺朝城，对抗幽都。

经过多方研究之后发现万魔惊座弱点，在怒山大战中凭借环境之利压制万魔惊座，迫使其签订怒山协定，但在此战之后功体尽散，在弓（玄凌苍）、儒（墨倾池）、道（暮长生）、释（谛佛主）、易（意轩邈）激进份子为了让万堺同仇敌忾消灭幽都，以破坏怒山协议为人类争取生存空间而设计将功体已散的万堺尊主杀死。

而万堺尊主之死直接导致万堺同修会倾巢而出大战幽都。

许久前的武林名人，为维护武林和平，倡导万教同修，力邀儒、道、释三教以及易天玄脉与其他派门，一同创建了万堺同修会，建立万堺朝城，对抗幽都邪祟，乃高瞻远瞩、见识不凡之人。（会刊244）

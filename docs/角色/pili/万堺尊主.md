# 万堺尊主 (万堺尊主)
================================================================================

万堺尊主

曾經的武林名人，高瞻遠矚、見識不凡，當年為維護武林和平，倡導萬教同修，並力邀儒、道、釋三教，以及易天玄脈與其他派門，一同創建了万堺同修會，建立万堺朝城。在万堺同修會的百器論衡上，因神祕一箭而身負重傷，並陷昏迷中，造成万堺同修會群龍無首，局勢動盪不安。

# 欲明王

================================================================================

霹雳布袋戏中虚拟人物欲明王，霹雳布袋戏虚拟人物。天之佛五相之一，代表忍辱观，样貌为愤怒明王相，风格稳健而有霸气，老成中带有无比严厉的气质，气势慑人，在会议中常担任决断的一方。曾代表天之佛身份踏入中阴界一会宙王，以掌握魔皇的生死之谜。中文名欲明王配 音黄文择性 别男登场作品霹雳战元史之天竞鏖锋登场作品霹雳战元史之动机风云本尊雕偶师丘山人物编剧伯风出场集数38集

## 人物设定

欲明王名称：欲明王性别：男身份：天佛五相之一诗号：淑世大智慧，悯世大慈悲，救世大无畏，广世大威仪。初登场：霹雳战元史之天竞鏖锋 第4章退场：霹雳战元史之天竞鏖锋 第37章（死于半截王迹）再退场：霹雳战元史之动机风云 第3章（死于天之厉）根据地：韦驮修界

## 人际关系

- **组织门派**: 天佛原乡上司/原身：天之佛同修：招提僧、恒沙普贤、慧宁师、砗磲佛母（天佛五相）

## 人物能力

武学：佛界遗世武册·下卷式·「琉璃炽盛·罗汉开道·如来大悲·究竟涅槃」（与砗磲佛母、慧宁师、招提僧合招）、诸行无常·诸法无我·三学无漏（与恒沙普贤、砗磲佛母合招）、百法无佛相、灭境定·俱解脱·摩诃止观、具足三千戒咒术：地水火风·四大皆空·还诸本相·逆命淬阳（负业法门之逆天神咒）

## 人物配乐

入世明王(欲明王角色曲)欲明王曲/编曲：吴智晖 收录于《霹雳英雄音乐精选三十六》吴智晖老师2009年以「度众生」为题的作品，诠释佛门先天的角度所创作，曲风庄严肃穆，透过唢呐独特的音色演奏，清圣之中散发著一股令人敬畏的威凌气势，正如「欲明王」给人的印象，老成中带有无比严厉的霸气。天佛五相(韦驮修界)曲/编曲：阿轮 收录于《霹雳英雄音乐精选三十六》阿轮老师所擅长的佛教音乐，以钟磬开头敲缀轻点出清圣氛围，笛声悠悠、弦音渺渺，禅韵悠扬的曲调中，营造出佛门圣地的庄严肃穆与神圣不可侵犯。乐曲常用于天佛五相议事之情境桥段。

## 其他记录

欲明王

霹靂布袋戲虛擬人物天佛原鄉最高象徵，至佛“天之佛”的五相化身之一，代表意義為對治「嗔」的「忍辱觀」，樣貌為憤怒明王相，風格穩健而有霸氣，老成中帶有無比嚴厲的氣質，氣勢懾人，在會議中常擔任決斷的一方，以及外出談判的角色。曾代表天之佛身份踏入中陰界一會宙王，以掌握魔皇的生死之謎，其後為了探查天之厲行蹤，數次與厲族正面交鋒，並代表天佛原鄉，參與胤天皇朝誓師大會，全力針對七行宮。

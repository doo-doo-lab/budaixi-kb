# 一刀万杀

一刀万杀（霹雳英雄战纪）

一剑万生的至交，个性强悍鲁莽，拥有异于常人的胆魄与韧性，但个性较为认死理，为了相挺好友，可模糊是非价值。因一剑万生恼怒一刀万杀杀死了萧竹盈，于是将犀角刀带离，致使一刀万杀使用了复制品的犀角刀。冰锋箭无形受太黄君之条件交换前来，一刀万杀一时大意，惨遭无形箭穿心穿脑而亡。

## 角色背景

头戴万胜天冠，身背犀角刀，打遍天下、万夫莫敌的顶尖刀王，脾气刚烈火爆，有着异于常人的胆魄和韧性，人称管命阎王。与一剑万生为至交，常为兄弟奔波在所不辞，是一名重情重义的热血硬汉。

名言

一生持刀不用刀！

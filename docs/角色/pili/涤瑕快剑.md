# 涤瑕快剑

霹雳布袋戏中的人物涤瑕快剑，是霹雳布袋戏中的男性角色，初登场于《霹雳靖玄录》第5章。身为南境神秘剑者，有法外隐锋之名，暗中协助仲裁者攀玉趾，追查昔日罪人岛一干罪犯下落。多年来，更暗中屡屡针对玉面佛爷九千岁，与玉佛爷结下一段不解之仇。涤瑕快剑曾于南域边墙外对抗罪人大军，亦曾与风云儿联手对抗海宇之主。其剑法绝尘七快剑被论为“为救而杀”。诗号：法外之剑，洗恶。埋名之锋，涤罪。

## 人物设定

## 经历

涤瑕快剑作为南境神秘剑者，有法外隐锋之名，暗中协助仲裁者攀玉趾追查昔日罪人岛一干罪犯下落，并屡屡针对玉面佛爷九千岁，与玉佛爷结下不解之仇。涤瑕快剑初登场于《霹雳靖玄录》第5章。在《霹雳靖玄录》第六章中，涤瑕快剑于南域边墙外现身，对抗袭来的罪人大军。此后，在与海宇之主的战斗中，涤瑕快剑首露败相。

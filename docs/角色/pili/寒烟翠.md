# 寒烟翠（电视剧《霹雳布袋戏》及其衍生作品中的角色）

================================================================================

寒烟翠是《霹雳布袋戏》系列中的虚拟角色，

寒烟翠受命追捕枫岫主人，实则暗助单恋对象禳命女完成心愿。她违背佛狱命令保全枫岫性命，以联姻换取其生机。面对兄长魔王子逆伦逼婚，她恳求迦陵将其击杀以维护尊严，最终殒命于《霹雳经武纪之枭皇论战》第13集。该角色因复杂情感线与悲剧结局引发关注，其退场场景以魔王子咒术禁锢、迦陵忍痛执刑的情节收束，遗体由戢武王安葬于杀戮碎岛。

## 人物设定

寒烟翠其实并不只是火宅佛狱来到苦境的使者，她另有高贵身份，编剧希望在造形上有大家闺秀的感觉，发型与发饰不能太过俗气。

寒烟翠身上披的毛皮是富贵的代表，而且编剧希望是一整件的狐皮，雍容高贵，原本的设计上，狐皮就是副体，上面有个狐头能说话，与寒烟翠沟通，不过这样的造型在演出上并不适合，于是保留毛皮装饰，副体另外使用道具呈现。

## 画舫角色设计

副体火宅佛狱有个奇妙的设定，就是人人都有副体，副体会以各种不同形式存在，有的副体外表是人，有的是动物、物品、道具等，各式各样，寒烟翠的副体是个可爱的小动物，因为寒烟翠的故事走沉重感情路线，所以编剧特别设计了一个少根筋、反复不定、爱吐槽寒烟翠的小狐，来点缀感伤的剧情。

寒烟翠受命来到苦境杀楔子，却屡屡违背命令让楔子活命，让小狐接连演出劝谏、告密、担忧等戏码。

寒烟翠绢伞寒烟翠的招牌道具——雨伞，是烟雨蒙胧的江南女子必备道具，为了展现寒烟翠温婉面貌之下的杀气，编剧将脑筋动到了雨伞之上，借由伞面颜色的变化，呈现寒烟翠的不同风貌。

寒烟翠虽然与禳命女出身不同国度，但是却成为了无话不谈的好姐妹，禳命女的烦恼，她都知道，但是她也默默承受，默默隐藏一个难以启齿的秘密，爱，就是成全，即使楔子是那么无情、那么的无心，伤害了最爱他的人。

为了禳命女的心愿，寒烟翠甘愿帮助她去寻找楔子，多年之后，又让楔子为禳命女解除石化，一再的延误组织所交待的任务，无怨的付出，只盼有一天能达成心中愿望，但这段苦恋，真有圆满结束的一天吗？

## 经历

官方百合，单恋禳命女，掩藏自己爱意，并为其幸福默默付出。

在使用阎魔之术送禳命女至苦境后，难忍思念之情，亦来到苦境，名为完成任务，实为寻找湘灵。

但之后亲眼禳命女的情意遭楔子所化身之枫岫主人婉拒，这使湘灵十分痛苦。

寒烟翠不忍爱人内心折磨，终于在龙战八荒第32集向禳命女表白。

禳命女大为震惊，只是跪求寒烟翠放过枫岫，使寒烟翠更为痛心。

后来，枫岫被佛狱所擒，咒世主决定杀死枫岫，而寒烟翠因禳命女恳请，以自己嫁入杀戮碎岛，换得枫岫一命，但枫岫不愿拖累他人，甘愿伤重无治，枫岫死后，寒烟翠与禳命女共往杀戮碎岛。

寒烟翠之兄长魔王子，是火宅佛狱的禁忌，被其父封印，在兵甲龙痕第20集，枫岫送给寒烟翠一句话，说可能是日后魔王子现世的转机。

后来佛狱在无衣师尹的算计下大败，咒世主不得已放出魔王子。

魔王子趁戢武王闭关将寒烟翠抢回佛狱准备娶她为妻，寒烟翠自尽不成被魔王子禁于房内，大婚当日，求迦陵杀死自己。

最后被戢武王带回葬于杀戮碎岛。

【退场】寒烟翠：“迦陵？”迦陵：“快走！”寒烟翠：“没办法，这是他独门的咒术，没与他相等的根基，你解不开。”迦陵：“吾带你走。”寒烟翠：“不行，我不能走，我走了，我不知道他会做出什么恐怖的事情来。

在你送我逃离佛狱之前，他就会追上我们，这仍是相同的结果。

会刊资料寒烟翠的个人出场乐是由阿轮老师制作，是一首精致的东方抒情小品，凄怨柔美的气氛颇浓厚。

文/阿轮寒烟翠的外型非常温柔婉约，但背后却有着不为人知的故事，基本上编剧指定的寒烟翠出场配乐，要能衬托她那美中带著寒意，寒意中又透著神秘的特殊气质。

我对这样的女性角色配乐蛮有兴趣的，写作起来也还算顺手。

这首曲子的旋律、背景都已讲求一种略带凄怨的美感，搭配她乘舟舫独行烟波寒江之上，轻声细语吟咏诗词，整体效果很不错。

寒烟翠我常用自己虚构的想像画面来替代尚未拍摄完成的真正剧情画面，这样的方式对我而言比较能够掌握到角色或剧情配乐所需要的感觉。

常有人问我：灵感从何而来？

当我需要灵感的时候，就让自己静下来，让意识进入冥想空间，当画面出现，那应该就是答案了。

## 人物诗词

（龙战八荒第13集）伫倚危楼风细细，望极春愁，黯黯生天际。

草色烟光残照里，无人会得凭栏意。

拟把疏狂图一醉，对酒当歌，强乐还无味。

衣带渐宽终不悔，为伊消得人憔悴。————宋‧柳永《蝶恋花》文/编辑部寒烟翠剧照蝶恋花，词牌名，这一词调经常用以描写缠绵悱恻的感情或纾发哀愁，因此常用来描写“男女相思”之情。

自宋代以来，就有不少以《蝶恋花》为词牌的优美词章，柳永的这阙词更为历久不衰的绝唱。

词中把漂泊异乡的落魄感受，与怀恋意中人的缠绵情思结合起来，表达了对于爱情至死不悔的执著态度。

上片写春日倚楼盼人引起的相思之苦；

下片写“春愁”的缠绵无法排遣，点明了“愁”的具体内容。

清学者王国维《人间词话》中认为古今成大事者三种境界，其中第二层境界就是引用柳永‧蝶恋花：“衣带渐宽终不悔，为伊消得人憔悴。”因为这两句词概括了一种锲而不舍的坚毅性格和执著态度。

原词是表现作者对爱的艰辛和爱的无悔，然而若以此比喻“成大事业者，必须坚定不移，经过一番辛勤劳动，孜孜以求，直至人瘦带宽也不后悔”亦无不可。

说服者寒烟翠邀请枫岫主人登船游江。

扁舟启程，寒烟翠表示来自火宅佛狱，此行任务即是寻找男女各一，而枫岫神似她欲寻的负心之人。

寒烟翠在江畔舟上吟咏这阙词其实有两层深意，除了强调就算是“衣带渐宽”也不会消磨完成任务的决心意志，第二层意义还是回到这阙词原本要表达的相思愁苦，为“伊”痴心不悔，一心一意的执著与坚毅。

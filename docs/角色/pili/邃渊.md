# 邃淵 (邃渊)
================================================================================

邃淵

儒門頂尖劍客，法儒君奉天之徒，與妻子席斷虹代表儒門，與佛道二教之代表共同看守聖劍「天可明鑑」。孰料，鬼麒主暗中佈施詭計，聖劍被盜、佛道二教之人皆死，唯獨邃淵夫婦存活，儒門遂成眾矢之的。最後，為證實自身清白，邃淵選擇自盡而亡，遺留妻兒，而三教聖劍被盜一事也成懸案。

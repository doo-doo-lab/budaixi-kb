# 背黑的孤儿

手持锋棱，是一个沉默寡言的杀手，自身背负着被灭门的惨剧，因此在背上背着一支黑旗，是特殊的复仇血旗，象征着他的仇恨宛如黑令旗一般，要向当初的凶手索命归阴！

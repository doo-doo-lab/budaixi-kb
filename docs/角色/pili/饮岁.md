# 饮岁

================================================================================

霹雳布袋戏虚拟人物饮岁，霹雳布袋戏虚拟人物。时间城的光阴使者，西洋仕绅造型，出没于时光树，是与守树缔约之人互动最多者，也最为知悉最光阴与绮罗生的过往故事。恪守原则，作风较为强硬，看似不近人情，却又常于话中透露指引。

**中文名**：饮岁

**配音**：黄文择、江志伦(台湾国语)、黑石稔（轰动武林国语版）、马语非（创神篇国语）

**性别**：男

**登场作品**：霹雳侠影之轰动武林

**登场作品**：霹雳侠影之轰定干戈霹雳侠影之轰掣天下霹雳侠影之轰霆剑海录霹雳开天记之创神篇霹雳英雄战纪：刜伐世界人物

**编剧**：申呈山

**本尊雕偶师**：洪剑山

## 角色背景

- **饮岁名称**: 饮岁性别：男身份：时间光使口头禅：饮岁不爽初登场：霹雳侠影之轰动武林 第17章再登场：霹雳英雄战纪：刜伐世界 第21章根据地：时间城

## 人物关系

上司：时间城主官方桌布朋友：最光阴、绮罗生、素还真、随遇、紫

## 火烈信子其他记录

《轰定干戈17》时间城主：饮岁啊饮岁，你将岁月饮干的太久，人都变肥了，运动一下吧。

有益身心健康。

时间城主：饮岁，你焦虑的脚步把时间城地皮踏得隆隆响动了。

饮岁：城主。

时间城主：时间到了，绮罗生来没回来，时间城的规矩荡然无存了。

是你出面与鷇音子缔下的约定，现在是该由你收拾后续？

饮岁：城主，素还真无视你的礼遇失约于时间，我认为该给素还真一点惩罚。

让他知道与时间缔下的约束不能轻忽以待。

时间城主：但时间城向来温婉处世，哪有什么能邢人的处罚呢？

只能让时间自己去处罚素还真的失信了。

你想，素还真的哪一段时间最是能让他警惕守诺的重要性呢？

饮岁：城主的意思是？

时间城主：我要惩罚素还真啊！

至于素还真受罚的这段时间就是由你代他推日晷了。

饮岁：啊！

（推日晷）超级不爽！《轰掣天下01》饮岁：我哪有肥。

时间城主：不要以为你身穿斗篷，吾就看不出，要你运动是为你好。《轰霆剑海录27》时间城主：时间城有你一个饮岁，已倾倒了一半，再将最光阴与绮罗生变成两个重量级的饮岁，时间城怎 会有不坠地的道理？

饮岁：城主，六块肌的人生，不是你能了解，结束这个话题吧。

随遇：饮岁阿叔，城主要我见的人是谁？

饮岁：正确讲来，他应该是你的阿公，但这种关系又太过笼统，我也不先替你定义，你可以在交谈中自由决定对方是你的什么人。

随遇：若他是我的什么人，那随遇还是饮岁阿叔的好朋友吗？

饮岁：哈，当然是，饮岁阿叔的身边一直都没有朋友，有你这样可以谈心的小知己，饮岁阿叔不会放你走的。

随遇：饮岁阿叔这么好，为什么会没有朋友啊？

饮岁：唉，因为我太优秀了！

平凡的人，通常都不喜欢与太优秀的人做朋友，因为我会让他们自形惭秽。

所以，我只能一个人独饮这孤单岁月的滋味。

随遇：原来，要像饮岁阿叔这样，一问三不知的人才是优秀。

饮岁：嗯？

如果不是你的眼神纯正，表情天真，我会以为你这句话中饱含着嘲讽的意味。

随遇：随遇为什么要嘲讽饮岁阿叔？

饮岁：你是乖小孩，不用知道这些属于下等人的无聊游戏。

随遇：哦。

饮岁：走吧，城主应该等得不耐烦了。

饮岁剧照

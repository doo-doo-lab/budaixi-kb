# 饮岁

================================================================================

霹雳布袋戏虚拟人物饮岁，霹雳布袋戏虚拟人物。时间城的光阴使者，西洋仕绅造型，出没于时光树，是与守树缔约之人互动最多者，也最为知悉最光阴与绮罗生的过往故事。恪守原则，作风较为强硬，看似不近人情，却又常于话中透露指引。

**配音**：黄文择、江志伦(台湾国语)、黑石稔（轰动武林国语版）、马语非（创神篇国语）

**性别**：男

**登场作品**：霹雳侠影之轰动武林

**登场作品**：霹雳侠影之轰定干戈霹雳侠影之轰掣天下霹雳侠影之轰霆剑海录霹雳开天记之创神篇霹雳英雄战纪：刜伐世界人物

**编剧**：申呈山

**本尊雕偶师**：洪剑山

饮岁：城主，素还真无视你的礼遇失约于时间，我认为该给素还真一点惩罚。

让他知道与时间缔下的约束不能轻忽以待。

时间城主：但时间城向来温婉处世，哪有什么能邢人的处罚呢？

你想，素还真的哪一段时间最是能让他警惕守诺的重要性呢？

饮岁：城主的意思是？

时间城主：我要惩罚素还真啊！

（推日晷）超级不爽！《轰掣天下01》饮岁：我哪有肥。

饮岁：城主，六块肌的人生，不是你能了解，结束这个话题吧。

随遇：饮岁阿叔，城主要我见的人是谁？

饮岁：正确讲来，他应该是你的阿公，但这种关系又太过笼统，我也不先替你定义，你可以在交谈中自由决定对方是你的什么人。

随遇：若他是我的什么人，那随遇还是饮岁阿叔的好朋友吗？

饮岁：哈，当然是，饮岁阿叔的身边一直都没有朋友，有你这样可以谈心的小知己，饮岁阿叔不会放你走的。

随遇：饮岁阿叔这么好，为什么会没有朋友啊？

饮岁：唉，因为我太优秀了！

平凡的人，通常都不喜欢与太优秀的人做朋友，因为我会让他们自形惭秽。

所以，我只能一个人独饮这孤单岁月的滋味。

随遇：原来，要像饮岁阿叔这样，一问三不知的人才是优秀。

饮岁：嗯？

如果不是你的眼神纯正，表情天真，我会以为你这句话中饱含著嘲讽的意味。

随遇：随遇为什么要嘲讽饮岁阿叔？

饮岁：你是乖小孩，不用知道这些属于下等人的无聊游戏。

随遇：哦。

饮岁：走吧，城主应该等得不耐烦了。

# 金子陵

霹雳布袋戏虚拟人物金子陵，霹雳布袋戏虚拟人物。其个性自在逍遥、潇洒不拘、言辞犀利却幽默风趣，是被封有“名剑铸手”美称的绝代铸剑师，而他的才能不仅止于铸造一把好剑，并能适才锻剑，让剑客的剑法发挥到极致，所铸之剑皆是罕世利器，却有只求知己赠剑、不求代价的胸怀。诗号：铸剑一生赠知音，逍遥一身而忘龄。

## 角色形象

造型去老还少，深藏不露的先天高人。温文儒雅、一副公子哥的打扮，一袭青衫，一身优雅，一派潇洒，折扇轻摇，尽是掩不尽的风采，一生铸剑无数，世人称其为名剑铸手，所铸之剑皆是罕世利器，却有只求知己赠剑，不求代价的胸怀。

霹雳兵燹攻略本下性格金子陵一身温文儒雅的装扮的金子陵，甫登场，不是挥汗如雨的铸剑，而是悠哉的练习书法，完全颠覆传统的刻板印象，高雅不俗的谈吐，风趣不羁的态度，和朋友之间的相处，不难看出金子陵幽默慧黠的一面，谈笑风生却不轻挑，有所坚持却不固执，呈现给人的永远是最自然、最自信与最真诚的金子陵。

场景寂山静庐

## 角色能力

武学名剑无双·绝代双骄、天剑无双·一气震九霄、天剑无双·天理不容武器青泓剑所有物所铸名剑沾血冰蛾名剑铸手金子陵得意之作，此剑平时隐藏剑锋，当剑锋开锋后削铁如泥、斩金断玉且无坚不摧，为当代剑中王者。

凡遭此剑断首者，断首处因瞬间冰封呈现焦黑且留有蛾形标记，其鲜血化为冰蛾漫天飞舞，十分残忍的凄艳，由此得名，可说是至凶至善的兵器。

原赠与仁慈的黄金城主，城主遇害后转手多人：邹纵天、素还真、刑天师、寒月蝉、恶灵龙魁海。

最后为九天惊虹与鬼阳六斩刈所断。

沾血冰蛾九天惊虹为断乱世魔刀与沾血冰蛾杀业，金子陵以“阴阳双铁”铸造至阳圣剑，在极阳之地近日锋引七七四十九道天雷击剑而成。

此剑最后一道手续由绝鸣子完成，并由金子陵命名为“九天惊虹”，意为九天之内最强者。

因无敌不合天理循环而有其时限，犹如惊虹一瞥。

此剑由认吾师转交天忌，砍断凶残的沾血冰蛾与鬼阳六斩刈，不负所托。

最后被打造成锁鬼扣，用以对抗鬼楼恶鬼。

九天惊虹-霹雳武器事典二所铸名剑-绝代之狂-依照风之痕所铸造的名剑，此剑类似魔流剑，可一剑双分，剑柄为朱红色。

赠与风之痕，取代风之痕的魔流剑。

佩剑后经历两次蜕变，是金子陵所铸唯一一把至今活跃于舞台的佩剑。

绝代之狂-风雅之狂-舞墨成狂裔春秋重金请金子陵所铸之名剑，裔春秋以此剑砍断绝鸣子的律音剑，造成绝鸣子对金子陵怨恨不已。

后裔春秋与绝鸣子决斗身亡，绝鸣子将其尸体与风雅之狂送回金子陵以示警告。

王刀异象时，金子陵曾携此剑试探刀王，被刀王杀气所断。

风雅之狂-潇洒之狂-乃一把通身碧绿的宝剑，特别为剑曲绝鸣子打造，而绝鸣子因恨选择非道魔刀，金子陵极度失望，也代表着失去当初铸剑的用意，不惜亲手将费心精制的宝剑摧毁。

潇洒之狂-飘渺之狂-金子陵四大狂剑之一，在与火龙麒立下约定后赠与白马纵横，白马纵横以此剑打败向天借命砍断黄泉刀，但受伤未愈败于刀王之手，飘渺之狂也被王者之刀所断。

飘渺之狂-青泓-为捍卫九天惊虹现世，金子陵以己为饵持此剑与刀王决战不归路，最终为鬼阳六斩刈所断。

青泓-求心-此剑虽然不是第一，但亦是难求的宝剑，名曰“求心”与认吾师的特质刚好符合，金子陵闭关铸剑前赠与认吾师护身之用。

求心-无双-川凉剑帝金苍龙的配剑，乃一对双剑，配合金苍龙的剑法左剑主守、右剑主攻。

但被邹纵天以沾血冰蛾断去左剑。

金子陵以剑名无双评断，剑的命运本该断其中一把。

无双-补缺-金子陵洞察无双命运之先机，为弥补其断剑之一而铸，赠与川凉剑帝金苍龙。

补缺著作天剑无双(传认吾师)名剑(传绝鸣子)三本绝世剑谱（送予论剑海）其他所有物八卦铸天炉龙麒阴铁龙麒阳铁锁马金鞍折扇

## 角色经历
铸剑奇人为补金苍龙的无双被断，已预先铸一宝剑补缺送给川凉剑帝，以书信告之拜访而来的金苍龙● 在素还真拿沾血冰蛾归还时将他送给素还真，并告知素还真魔刀之事，与刀剑的宿命● 到步云崖吊祭忆秋年，将与之同葬之剑的灵气封存长伴故人，并感叹人生命数如此金子陵● 拜访风之痕并要将绝代之狂送与风之痕，但被风之痕所拒● 以绝代之狂与风之痕的魔流剑做赌约● 遇到认吾师并开导他剑理 ，认吾师因此终于寻得他心中认同的理念之师● 前往风之痕住所的路上遇到魔刀非道拦阻选主，怒说非道是贬损金子陵的身份，后来斥色将其震退之● 到风之痕住所，得知绝代之狂胜，并要送给风之痕时再度被拒，后预言魔流剑使命将尽，近期将有断剑一劫● 开导认吾师不但要有武学，更要修心，并教导剑术最基本理念，与最完美的剑理于静庐闲吟赋诗：(兵燹20)荷叶田田青照水，孤舟挽在花阴底，昨夜萧萧疏雨坠，愁不寐，朝来又觉西风起。

于静庐闲吟赋诗：(兵燹20)雨摆风摇金蕊碎，合欢枝上香房翠，莲子与人常厮类，无好意，年年苦在中心里。

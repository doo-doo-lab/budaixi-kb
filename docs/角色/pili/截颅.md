# 截顱 (截颅)
================================================================================

截顱

手無縛雞之力的一介儒生，崇尚孔孟之道，卻被創世狂人強收為徒，隨同行走武林佈道，過程中逐漸認同創世之道理念，甚至挺身為創世者承受一日一刀刑。幸得耶摩天重塑金身而復生，最後為讓創世者恢復一頁書，而選擇自我犧牲。

# 截颅

手无缚鸡之力的一介儒生，崇尚孔孟之道，却被创世狂人强收为徒，随同行走武林布道，过程中逐渐认同创世之道理念，甚至挺身为创世者承受一日一刀刑。幸得耶摩天重塑金身而复生，最后为让创世者恢复一页书，而选择自我牺牲。

## 角色经历

复生后受耶摩天二僧所托，跟随创世者设法让其免受附有奚东城灵魂的怒瀑精英的影响。期间，汗青编挑唆利用截颅，意图让创世者自动送上无名。 之后被东瀛所擒，君夫人在一苇天要挟创世者交出藏有文诏的无名宝刀，创世者问其“你为了什么而生？为了什么而死？”，截颅回答“为真理而生，为正义而死”，甘愿为正义而牺牲，面对要挟，创世者无奈放弃截颅。随后被龙眼佛与凤眉尊者救出，但二人旋即被汗青编乘机杀害。 后被耶摩天二僧将头颅置于佛手矸暂得存活，但是由于根基太浅，无法在短时间内复生。最后为让创世者恢复一页书，而选择自我牺牲，让出佛手矸，躯体化为乌有。一个普通的书生，生平3次舍身取义，令人动容。

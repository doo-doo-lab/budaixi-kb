# 截颅
================================================================================

截颅

手无缚鸡之力的一介儒生，崇尚孔孟之道，却被创世狂人强收为徒，随同行走武林布道，过程中逐渐认同创世之道理念，甚至挺身为创世者承受一日一刀刑。幸得耶摩天重塑金身而复生，最后为让创世者恢复一页书，而选择自我牺牲。

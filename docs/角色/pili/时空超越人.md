# 时空超越人

不受时空约束的奇人，身背回力盒，专门测量他人功力深浅，目的不明，曾提供素还真、紫锦囊等人不少的协助。真实身份乃集境太和殿之人，与驼背老人共同保护戴氏遗孤，躲避武皇毒手。

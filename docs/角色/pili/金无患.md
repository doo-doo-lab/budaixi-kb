# 金无患

金不换之子，天生恶疾，皮肤流脓溃烂，就连其父也束手无策，后在与魔界交易下，取得稀罕药材治愈，始恢复清秀面貌，但离群索居过久，也让金无患孤僻怕生。后为箫中剑收留，跟随在猫大人身边学艺。

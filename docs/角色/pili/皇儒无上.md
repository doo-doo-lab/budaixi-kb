# 皇儒无上
================================================================================

皇儒无上

立身儒门，平乱世而尊皇，与玄尊、道皇、尊佛并列四大创道者的先天人。坐镇昊正无上殿，压制八歧龙首，霸气威武，不容造次。皇儒修为高深莫测，性情虽霸道固执，表面严肃、一丝不苟，其实对儒门所属相当关照，提携后进不余遗力，挺身对抗八歧邪神势力入侵。

"皇儒无上·蔺天刑，既称为皇儒，身份便为儒门之皇，与玄尊等人的追求不同，九天玄尊追求乃登仙境界，而尊佛所求为佛渡众生，道皇寻求者乃稳固道门基业，皇儒无上则直接开创儒门的积极面，对于乱世，皇儒无上直接挺身而出，与一般儒生温文儒雅的气质不同，皇儒无上的气魄是个货真价实的土霸王，勇猛果敢、不拘小节。曾经一人抵御强大的外域敌寇，以及斩杀来自六界的妖魔鬼怪，平乱世而尊皇，被当时拯救的人们敬称为儒门皇帝，也就是皇儒无上的由来"。

"一甲子成名之后，皇儒无上决定将儒门一统。昊正五道的评选，乃是由皇儒无上一人主持，而德风古道成为五儒门中央的司令台，东西南北各自扶持。昊正五道为后盾，成为完整的儒门架构"。

"独自力抗八岐邪神，为掩护儒门众人发动皇天殛元爆并化为圣字天瀑阻拦。天下第一人对抗上古邪神而甘愿牺牲，编剧对皇儒的剧情安排虽然悲壮却不失为真正的英雄"。

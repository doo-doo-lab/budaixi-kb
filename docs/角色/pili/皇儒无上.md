# 皇儒無上 (皇儒无上)
================================================================================

皇儒無上

立身儒門，平亂世而尊皇，與玄尊、道皇、尊佛並列四大創道者的先天人。坐鎮昊正無上殿，壓制八歧龍首，霸氣威武，不容造次。皇儒修為高深莫測，性情雖霸道固執，表面嚴肅、一絲不苟，其實對儒門所屬相當關照，提攜後進不餘遺力，挺身對抗八歧邪神勢力入侵。

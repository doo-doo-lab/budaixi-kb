# 挹天癒 (挹天愈)
================================================================================

挹天癒

深藏一水澈中的神秘高人，以水為治，經水為用，乃玉龍隱士重創時求助的醫者，本身對於人事物極其淡薄，對待患者比對待一般人的態度、語氣上更為耐心、溫柔，但因要事在身再不主動參與醫治患者，而將事情全程轉移荒靡處理；當每日子夜時刻水池呈現鮮紅之態，必不見人。

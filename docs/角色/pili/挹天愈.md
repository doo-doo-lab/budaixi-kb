# 挹天愈
================================================================================

挹天愈

深藏一水澈中的神秘高人，以水为治，经水为用，乃玉龙隐士重创时求助的医者，本身对于人事物极其淡薄，对待患者比对待一般人的态度、语气上更为耐心、温柔，但因要事在身再不主动参与医治患者，而将事情全程转移荒靡处理；当每日子夜时刻水池呈现鲜红之态，必不见人。

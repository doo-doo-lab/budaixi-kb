# 烈眼尊枭

存于终年焚火不灭的灼世之霸者，全身有十三颗烈眼，久远前被鬼麒主砍下一条手臂，夺去手中的两颗烈眼，植入兽王体内，遂成为克制精灵的“灼世烈眼”，烈眼尊枭因此心存怨恨，一直想要报复鬼麒主。

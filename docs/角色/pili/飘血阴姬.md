# 飄血陰姬 (飘血阴姬)
================================================================================

飄血陰姬

示流島「不動明王」座下四大尊者之一的邪幽尊，藝妓裝扮，妖豔性感，卻又冷酷無情的邪魔之女。手持血紅傘，在血雨之中現身，看似嬌弱惹人憐愛，實則殘忍嗜殺、視生命如無物，善用長刀，為深藏不露的高手。

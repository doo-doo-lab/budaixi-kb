# 飘血阴姬

示流岛“不动明王”座下四大尊者之一的邪幽尊，艺妓装扮，妖艳性感，却又冷酷无情的邪魔之女。手持血红伞，在血雨之中现身，看似娇弱惹人怜爱，实则残忍嗜杀、视生命如无物，善用长刀，为深藏不露的高手。

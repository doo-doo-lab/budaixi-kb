# 七重冥王

第一魔界统领者，为谋取地位曾背叛魔魁、积极调查三教之子身份，欲除之而后快。手下能人极多，散布武林各处或造谣或铲除阻碍份子，七重冥王更是屡屡用计创造利己时势，重挫素还真等人声势，被正道人士视为大敌。

### 基本信息（来自百度百科）

七重冥王是台湾霹雳布袋戏系列中的虚拟角色，由黄文择配音，初登场于《霹雳狂刀》第57集，退场于《霹雳幽灵箭第一部》第22集。作为第四魔域之主，其以玄德相士为化身，掌握焚天魔火等武学，统辖寒山一花香等部属，通过三相士、五暴魂等势力分化三教。

七重冥王早年联合三教暗算魔魁，主导儒园结义事件将无字天书与撼天密鉴交予素还真、青阳子，同时积极调查三教之子身份意图铲除，并借三教名录线索引发武林纷争。通过七大化身渗透各方势力，最终被海殇君击破护身气罩，遭魔魁之女与血道天宫围剿，最终被非凡公子以黑翼龙霸式击杀。

第四魔域在其死后由寒山一花香接管，随着第二魔界收编残余势力，第一魔界宣告终结。其七大化身除寒山一花香与玄德相士外，其余身份多为武林推测。

### 人物经历

七重冥王，一开始是以其七大化身游走三教武林，暗中进行分化，待三教之子非凡公子建立霹雳王朝，第四魔域正式和儒释道三教宣战。

另外，当年出走东瀛的魔魁之女自成一派，与三教和七重冥王相抗衡，并开启乾中盒进入第二魔界的灵魅殿，七重冥王势力也在魔魁之女和三教以及新兴组织血道天宫的围剿下渐趋败相，导致最后死于非凡公子之手，第四层魔域也由司寇寒山一花香接掌，不过此时第一魔界气数已尽。待第二魔界正式现世，聘请智慧之星玉天玑任职军师，将第一魔界残余势力收编，第一魔界正式宣告结束。

七重冥王的七大化身应为寒山一花香、一指道灵半生浮、玄德相士、玉槐相士、秤命客、补运仙及长桑鬼佗等，除寒山一花香亲口承认和玄德相士被照出原形外，其余皆是间接推测，七大化身是具有独立人格与思想，分出后与主体无甚牵连。

### 人物经历（详细）

七重冥王，久远前和三教老教主勾结，算计陷害魔界战神魔魁。

为了侵略中原，他先派千层雪卖惨，主导一出儒园结义，好将无字天书、撼天密鉴送给素还真、青阳子，分别告诉两人解开对方物品的方法，这两件物品其实是三教主为让七重冥王出卖魔魁开出的条件，可以用来让三教主做一件事，但如果说不出约定的暗语，三教主必须杀死使用者。

然后又告诉两人三教名录的事，三教名录记载了三教24位名人，若能得到这24人的认可，便能统一武林。三教名录的线索要去找千层雪的妹妹万缕丝，万缕丝说这本书在三教之子身上，有7个人可能是三教之子，分别是乱世狂刀、雪中狼、叶小钗、秋风之刀、剑君十二恨、落日一笑、血剑抗生郎，万缕丝还透出魔魁之女在祭血魔殿的消息，误导想求证的人落入五暴魂的陷阱。

而七重冥王派化身游走武林互相配合施展阴谋，转移各方针对魔域的行动，掌握各势力主要人物的动向，挑动中原自相残杀，引出三教高层，找出三教之子和魔魁之女。

素还真说服三教组织尊三教之子为主，七重冥王便长桑鬼陀组建八德联会吸纳不服非凡和三教的派门，里应外合，终结霹雳王朝。

七重冥王甚至一度抓捕了宇宙神知，吸收其功力，但正是此举引发海殇君入世，一掌击碎七重冥王护身气罩。加上魔魁之女黄雀在后，得到第一魔界支持，七重冥王手下一花香反水，加上血道天宫算计，七重冥王一时势单力薄，最后被非凡公子杀死。

# 七重冥王

第一魔界统领者，为谋取地位曾背叛魔魁、积极调查三教之子身份，欲除之而后快。手下能人极多，散布武林各处或造谣或铲除阻碍份子，七重冥王更是屡屡用计创造利己时势，重挫素还真等人声势，被正道人士视为大敌。

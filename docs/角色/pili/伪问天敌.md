# 伪问天敌
================================================================================

伪问天敌

昔日梵天的灭境宿敌，自信狂傲、智谋不凡的一方霸主，爪牙横张，曾吞并整个灭境，后来被梵天以天龙吼击落轮回海，如今却重现苦境江湖，势将带来不可预知的变数。谜城所出现之问天敌，乃一页书所伪装，用以欺敌耳目。

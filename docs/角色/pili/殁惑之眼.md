# 歿惑之眼 (殁惑之眼)
================================================================================

歿惑之眼

異度魔界的偵蒐先鋒，與邪魅之眼同隸屬六先知鬼座管轄，負責查探聖域位址與魔心下落，多番滋擾迦葉殿，卻在窺探封雲山玄宗本部時，遭突來乍放的金光粉身碎骨。

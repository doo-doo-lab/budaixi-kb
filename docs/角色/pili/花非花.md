# 花非花（唐代白居易诗作）

================================================================================

《花非花》是唐代诗人白居易创作的一首杂言古诗（也可看作是一首词）。此诗表达了对人生如梦幻泡影，如雾亦如电的感慨，表现出一种对于生活中存在过，而又消逝了的美好的人与物的追念、惋惜之情。全诗由一连串的比喻构成，描述隐晦而又真实，朦胧中又有节律整饬与错综之美，是情诗中的佳作。同时，全诗语意双关，雾、春梦、朝云这几个意象都是朦胧缥缈的，意象之间又有意省略了衔接，显现出较大的跳跃性，文字空灵精练，使人咀嚼不尽。后人曾将此诗谱为曲子，广为流传。作品名称花非花出 处《白氏长庆集》作 者白居易创作年代中唐作品体裁杂言古诗

### 主要剧情

#### 第一阶段

- 霹雳劫 第二集：被金小开带出云路天宫遭抛弃，后被绝情师太所救
- 霹雳天阙第二十四集：杀鬼智藏

#### 第二阶段

- 霹雳紫脉线：救金小开，并杀三神秘之一；将金小开禁於银娃之墓前，罚跪一百天。在差点遭到金小开强暴时被叶小钗与今生一剑所救
- 《霹雳烽云时期》：被只手无我声救到二重林长期居住
- 霹雳烽云第六集：错失六十年一度的三光之灵让自己恢复正常
- 霹雳烽火录第十六集：设法唤起秦假仙记忆
- 霹雳风暴第二十集：秦假仙被君夫人所迷，两人分开，君夫人下令东瀛忍者追杀她，在业途灵帮助下被刺爷爷所救，并收她为义女
- 霹雳风暴第三十集：遭魔界大军追杀，被素还真所救
- 霹雳狂刀之创世狂人第九集：以天官密式重创龙王魛，但被泣花魂救走；参与童观之战
- 霹雳英雄榜之江湖血路第四集：参加下天下圆
- 霹雳英雄榜之风起云涌第三集：被秦假仙误会并不爱他

#### 第三阶段

- 跟"许愿仙"许愿，魂魄被夺。为素还真用瀑泉璎珞救活
- 霹雳图腾 第一集：被魔剑道之人重创，为叶小钗、病剑叟所救，後来不药而愈
- 霹雳图腾 第二十集：与秦假仙重逢，长期居住在湘灵宝观
- 霹雳刀锋 第二十六集：在二重林与两位姊妹共同建造花宫，秦假仙在旁做牛做马
- 霹雳剑踪 第六集：听到二重林的婴儿哭声，以为是有弃婴留在二重林，带长孙祐达、箴有力一同寻找。不料秦假仙从阴川回到二重林，在林外听到婴儿哭声，误以为自己与秦假仙收留在二重林的长孙祐达和箴有力两人有染，被无故冤枉后把秦假仙一顿痛骂并要求秦假仙罚跪算盘一夜。

#### 第四阶段

"在《霹雳惊涛》中，双脚已经接好。为了躲避邪染，和易春寒等一同来到地海孤堡。却卷入祖父叶小钗与地海孤堡的恩怨中，一番经历后，众人了解了叶小钗父辈的故事，随后回二重林退隐"。

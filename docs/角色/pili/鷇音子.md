# 鷇音子 (鷇音子)
================================================================================

鷇音子

當初三餘上時間城借取非關時間，途中歷經殊離山魔考一時失魂出神，被聖魔元史點中魂體，向時間樹締命借時而出的素還真第三化身，視三餘為競逐對手。擅煉玄丹，偏向道家色彩，雖表明立場中立，以烽火天榜將武林各大勢力排入榜中，卻因此掀起一場未知的武林風暴。

其他紀錄

與三餘神魂競逐所吟：(轟動19)

- **煉玄丹時所吟**: (轟動21)
虛無生自然，自然生大道，大道生一氣，一氣分陰陽，陰陽為天地，天地生萬物。太虛、太無、太空、太玄，杳杳冥冥，非尺寸可量，浩浩蕩蕩，非涯岸可測。其大無外，其小無內，大包天地，小入毫芒，上無複色，下無複淵，一物圓成，千古顯露。不可得而名者，聖人以心契之，不獲己而名之。

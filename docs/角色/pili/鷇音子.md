# 鷇音子 (鷇音子)
================================================================================

鷇音子

当初三余上时间城借取非关时间，途中历经殊离山魔考一时失魂出神，被圣魔元史点中魂体，向时间树缔命借时而出的素还真第三化身，视三余为竞逐对手。擅炼玄丹，偏向道家色彩，虽表明立场中立，以烽火天榜将武林各大势力排入榜中，却因此掀起一场未知的武林风暴。

- **炼玄丹时所吟**: (轰动21)
虚无生自然，自然生大道，大道生一气，一气分阴阳，阴阳为天地，天地生万物。太虚、太无、太空、太玄，杳杳冥冥，非尺寸可量，浩浩荡荡，非涯岸可测。其大无外，其小无内，大包天地，小入毫芒，上无复色，下无复渊，一物圆成，千古显露。不可得而名者，圣人以心契之，不获己而名之。

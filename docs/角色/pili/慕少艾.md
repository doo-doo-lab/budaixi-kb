# 慕少艾

幽默风趣、风雅隽逸的药师神医，拥有相当高超的医术与修为，早前曾与素还真较劲失利，而潜沉于琉璃仙境之下；后赢得麒麟穴而步入红尘，担起对抗异度魔界之重责，即使遇上艰难逆境也会以轻松态度面对、自我调侃，是正道不可多得的好帮手。

## 角色背景

### 创作背景

创作背景基于编剧王艺婷的设定，西苗被设定为边疆民族，政教分离，类似西藏，阿九一族被视为神兽族，是守护族，成为翳流组织想要消灭的目标。阿九是慕少艾的病人，天生半心，慕少艾为治疗他与阿九父母合作，后者牺牲自己让慕少艾以认萍生名号加入翳流。慕少艾重出江湖主要是为了帮阿九换心，他对江湖并无太认真的想法，甘愿隐居。阿九最终回到迷谷，未来可能成为神医。

### 人物影响

慕少艾的退场情节感人至深，对观众产生强烈情感冲击，有观众因此退坑。角色塑造成功，人气极高，退场原因有换了编剧或剧情需要等说法。角色精神如压力面前的革命乐观主义被观众所称道和学习。慕少艾由编剧王艺婷创作，是她离开霹雳前的最后一个角色。

## 人物特写

第119期 人物特写（摘自 霹雳月刊 第119期 人物特写：药师慕少艾 文/编辑部）一段鲜为人知的比斗过程，剑子一场意外的跌落山崖，带出一位幽默风趣、医术高超的奇人——药师慕少艾。当圣踪致命的一掌，将剑子仙迹轰落琉璃仙境山崖底下时，本该万死无一生的剑子仙迹，却意外被这位居住在岘匿迷谷的新角色所救，慕少艾究竟是何等的奇人，能解救垂危重伤的剑子仙迹？武林三大神医之一药师慕少艾，这位喜好抽着烟斗，习惯呼呼两声，又留着两撮长眉的风趣医生，与神针惠比寿、蛊皇僰医人列名为武林三大神医，蛊皇擅长使用蛊毒，有着不死不医的奇特理念；神针惠比寿擅长用针术治人，而慕少艾名为药师，自然以药物见长，但慕少艾的风趣个性，使得这位药师的治疗方法，比一般的医生多了点玄奇的感觉。当剑子仙迹被轰落山崖时，料想慕少艾应是给予紧急的治疗，但之后为助剑子仙迹的伤势复原，慕少艾请剑子仙迹打了一套拳法，看似平凡无奇的练武过程，蕴含着奇特的治疗过程。当慕少艾与素还真再度比试之时，同为医者的两人，听到一旁妇人的呼唤，两人当下急转而去，慕少艾更亲自吸痰帮助无依的小孩渡过危机，足见慕少艾的医者仁心，另一件较不为人知之事，则是于岘匿迷谷之时，帮助被蠹鱼孙由雪严天带来的叶小钗插上一根针，让叶小钗伤势痊愈的更快。当魔龙祭天找上剑子仙迹寻仇之际，药师慕少艾的出现，无疑又再度的解了剑子一个劫难，信手拨转之间，慕少艾以力化力，将两人的掌气消弭而去，而一眼看出魔龙祭天习练意识能力而造成的旧伤，更确定了药师不凡的眼力，但医得了人，医不了命运，剑子仙迹竟在慕少艾离去不久，伤势复发，加上剑子仙姬的搞不清楚状况，又让剑子仙迹陷入了蛊毒的逼命危机，连番的重创，这下使得凡事缓缓来，不疾不徐的慕少艾也急躁了起来，只见慕少艾与惠比寿打定医治的主意后，四处寻找能与剑子同血型之人，短短一集当中，慕少艾四处奔波，终于找来了各大高手帮剑子分摊蛊毒，对正道而言，慕少艾可说是让众人最无后顾之忧的后援帮手。未知的来历背景虽然慕少艾是新出现于霹雳系列的角色，但其带出的事迹却是不少，其中以麒麟穴的争夺最引人注意，清香白莲素还真定居于琉璃仙境已是许久以前之事，而今突然冒出一位自称是比赛失利才让出麒麟穴之人，根据当初的约定，败者更必须隐居于崖底下，素还真得到第一次的胜利，但第二次在忠烈王的作证下，慕少艾终以一步之差胜出，素还真好不容易重建完成的琉璃仙境，就这么拱手让人啰。出麒麟穴的争夺之外，慕少艾诸多名人留名忠烈王匾额之举，亦逐渐的带出了许多的新人物，其中更与传说中的羽人非獍为好朋友。不仅如此，慕少艾左脸颊处，有一奇特的黥面特征，黥面通常用于罪恶深重之人身上，药师慕少艾本着医者仁心，怎会有着格格不入的黥面？相信亦是观众们急于想知道的一点，由于事关机密，编辑们只能偷偷地透露，这个黥面是在慕少艾曾经化名为「认萍生」时所留下的，并与忠烈王有关喔。沉重的责任慕少艾虽然在二次比试中，赢得朝思暮想的麒麟穴，但也意味着将代替素还真解决眼前的事务，面对着异度魔界的大举入侵，慕少艾首次面对的，即是异度魔界铺天盖地而来，而慕少艾也不负众人的期望，谈笑间便将异度魔火转往山崖底下，顺利解了琉璃仙境被火烧的危机。虽是如此，但异度魔界的威胁才正要展开，一向表现出玩世不恭的药师慕少艾是否能完全代替清香白莲撑起谈无欲以外的半边天？面对着由赦生童子、元祸天荒、别见狂华三大魔将为首的异度魔界，药师能否再谈笑用兵？在此同时，慕少艾过往的恩仇也逐渐被带出，而慕少艾身边的猫少年阿九，是否又有另一段奇特的故事？

### 慕少艾和阿九

摘自慕少艾编剧王艺婷与粉丝的对谈

王：先讲一下我对於西苗的设定基本上西苗是一个比较边疆的民族，我在设定西苗的时候，参杂了比较多幻想跟浪漫的元素。我基本上设定他是比较像是个政教分离的地方，比较类似现在的西藏。那阿九这一族，基本上来讲是被当地的人视为「神兽」的一族，他们是一个守护族。那翳流这个组织，一开始是靠他的政治力在统治这个地区，但因为神兽族的地位在西苗人民心中有牢不可破的地位，所以也变成翳流想要消灭的目标。阿九严格讲起来他其实早期就是慕少艾的病人之一，他的父母是慕少艾的朋友。早期少艾到处去云游看病，在西苗的地方认识阿九的父母，因为阿九是天生半心，慕少艾用了很多办法，但只能维持阿九最基本的生命机能，所以後来是阿九的父母自己提出了一个条件，就是牺牲自己让慕少艾可以利用灭掉神兽族名义顺利用认萍生的名号加入翳流。

月：那阿九到後来到底去哪里了？

王：对！其实少艾对江湖并没有什麼太认真的想法，不然他也不会甘愿隐居在迷谷里面。

慕少艾，又称药师慕少艾。

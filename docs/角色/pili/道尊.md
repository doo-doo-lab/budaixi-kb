# 道尊

道教之主，昔日荒龙道三教主大战魔魁，却也身中血烙魔咒而逐渐魔化，三人因此隐遁。曾藏身神仙图中，造就秦半式、业一招两人，并收乱世狂刀为传人，欲藉传人之手终结魔化之苦。无奈最后彻底魔化，成为中原一大威胁。

## 角色经历

道尊，道教圣龙口之主，与老佛、圣夫子并称三教主，三教主当年透过七重冥王的配合，用计围攻魔魁，使道尊身中魔魁所练的血烙魔气，不仅功力日益消退，更有入魔之忧，因而化做画中仙藏在孝文家中的神仙图中，造就秦假仙、业途灵，使之化身为秦半式、业一招于悬空棋盘上名动一时，后指引家破人亡的孝文，前往悬空棋盘拜秦半式、业一招为师。

经由素还真的协助下，觅得传人乱世狂刀，并且助他将被七重冥王挖出的心肝肠重新修复，但也因此再度沾染魔气，使道尊成为三教主中魔化最快的人，因此在魔魁之女化身末情天冒称三教授命者时，便是由受他控制的道尊出面替魔魁之女作伪证。

道尊造就乱世狂刀，本欲借传人之手终结其魔化之苦，无奈事与愿违，不归路上狂刀不忍下手杀师，道尊在魔魁之女、血灵魔尊先后催动魔咒下，彻底魔化，反成为中原正道一大威胁，成为灵魅殿的杀人武器，多次参与袭杀中原正道如叶小钗、剑君十二恨等人，且曾琉璃仙境攻杀身染邪气的素还真，并与老佛接下魔魁之女射出的幽灵箭，让玉天玑反过来射杀魔魁之女。

后在血灵魔尊逐出玉天玑后，道尊得令回圣龙口利用他本为道门教主的身份斡旋青阳子与魔族的和谈，结果假素还真与紫阳子双双对他发起攻势，道尊于星河殿死在假素还真之手。道尊死前身体内有一股气息飞入盘古开天达愿石之中，不知结果。

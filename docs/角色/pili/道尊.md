# 道尊 (道尊)
================================================================================

道尊

道教之主，昔日荒龍道三教主大戰魔魁，卻也身中血烙魔咒而逐漸魔化，三人因此隱遁。曾藏身神仙圖中，造就秦半式、業一招兩人，並收亂世狂刀為傳人，欲藉傳人之手終結魔化之苦。無奈最後徹底魔化，成為中原一大威脅。

# 道尊

道教之主，昔日荒龙道三教主大战魔魁，却也身中血烙魔咒而逐渐魔化，三人因此隐遁。曾藏身神仙图中，造就秦半式、业一招两人，并收乱世狂刀为传人，欲藉传人之手终结魔化之苦。无奈最后彻底魔化，成为中原一大威胁。

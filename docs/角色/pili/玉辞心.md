# 玉辞心

================================================================================

霹雳布袋戏中的角色玉辞心，霹雳布袋戏中的角色。自称戢武王特遣之令使，为查明剑之初身世而入苦境，脸上妆容有一特殊的蝴蝶纹彩，举止言谈不时流露出一股不凡贵气，实力惊人，在鄙女风气兴盛的杀戮碎岛实属罕见，也为玉辞心身份增添了一丝神秘色彩。

**中文名**：玉辞心

**别名**：一卷冰雪

**配音**：黄文择、郭馨雅（轰定干戈国语）

**性别**：女

**登场作品**：霹雳经武纪之枭皇论战霹雳兵燹之圣魔战印霹雳侠影之轰定干戈

**身份**：戢武王

**门派**：杀戮碎岛人物创作者三弦、申呈山

**本尊雕偶师**：洪剑山

**兵器**：倾雪剑

**丈夫**：剑之初

**出场集数**：50集

## 血魉之羽角色设计

背景自称戢武王特遣之令使，为查明剑之初身世而入苦境，脸上妆容有一特殊的蝴蝶纹彩，似是表征、亦是掩饰。

举止言谈不时流露出一股不凡贵气，实力惊人，在鄙女风气兴盛的杀戮碎岛实属罕见，也为玉辞心身份增添了一丝神秘色彩。

名号玉辞心她的武功有冰雪属性，其人有冰雪特质，戢武王一生，只有为王自觉，对于如何当一个称职的女性并不熟稔，因为想要强调这种感觉，所以在取化名时，便朝着能够呈现她的人格特质与现阶段状态暗示之名字。“一卷冰雪”之命名，其灵感是源自明·张岱的《一卷冰雪文序》，其文以冰雪喻空灵妙境，失则腐臭矣，携一卷行走江湖，暗喻着一卷冰雪玉辞心，为短暂状态。

其玉辞心是为暗合一卷冰雪，是玉辞之心，也是玉，辞了心，一名暂时辞去玉心，暂卸王责的女人。

兵器倾雪剑：乃雅狄王之珍藏，为师尹之妹——即鹿，私下赠与雅狄王的定情物。

## 造型设计

正装版所谓正装，在剧情意思上，也就是戢武王首次能够悉心打扮自己，其脸上蝴蝶纹饰是为了掩饰自己的容貌。散发版玉辞心造型上，唯一的要求就是要跟剑之初随身携带的那张女子图有像到。

## 角色配乐

一卷冰雪(玉辞心角色曲)曲/编曲：孙敬凡 收录于《霹雳英雄音乐精选29》玉辞心本曲为孙敬凡老师所创作，带有浓厚强烈的中国曲风，以独特的中国五声音阶为主旋律，是霹雳配乐中较少出现的种类。以柔中带刚的女性先天人为题材，开场为笛子，钢琴、小提琴为前后主体，搭配弦乐如琵琶、古筝等乐器，以中板节奏带出玉辞心果决明快的气息。

## 其他记录

散发版玉辞心废天地、灭生灵、神裂歇宁清。（霹雳经武纪之枭皇论战第13集，废之卷口诀）

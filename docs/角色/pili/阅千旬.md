# 閱千旬 (阅千旬)
================================================================================

閱千旬

文質彬彬，謙沖有禮，談吐溫雅的文士，對武林事務特別關注，常協助處理紛爭，以公平為原則，而有「裁衡」之名。此回因寄曇說修補地脈失誤，導致神州崩裂，民怨不斷，各方人士要求寄曇說負責，閱千旬因而出面調解，穩住民心。

# 阅千旬

文质彬彬，谦冲有礼，谈吐温雅的文士，对武林事务特别关注，常协助处理纷争，以公平为原则，而有“裁衡”之名。此回因寄昙说修补地脉失误，导致神州崩裂，民怨不断，各方人士要求寄昙说负责，阅千旬因而出面调解，稳住民心。

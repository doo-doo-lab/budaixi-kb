# 一剑万生

一剑万生（霹雳英雄战纪）

一代剑界高人，能御剑飞行，叶小钗过去曾为一剑万生的剑僮，却因与萧竹盈相恋而引来一剑万生的杀机。然而一剑万生两度败于叶小钗之手，脸上更增添刀疤之伤，便藉第二次败阵后诈死并消声匿迹，更带走了一刀万杀的犀角刀。

第一次出场就以驭剑飞行的方式展现其不凡的气势。但与萧竹盈、叶小钗间的三角关系使他为爱蒙蔽理智、约战叶小钗，行事走向极端。风雨坪上的落败使他自尊受损，加上情场的挫折，迫使他采取了玉石俱焚的手段。

## 来自百度百科的补充

"一剑万生是台湾霹雳布袋戏系列虚拟角色"，"由黄文择配音。1989年11月于《霹雳至尊》首次登场"。该角色"包含御剑飞行特性，曾蝉联论剑海三届首冠"。

"其性格偏激执念，因情场失利与武斗败绩屡次采取极端手段"，"经历三次退场与复出轮回"。

**初期经历**：一剑万生原为"剑界的不世高人，驾驭飞剑疾风斩，更以'一世用剑不提剑'闻名"。曾误杀学生马赛凤的父亲，后被对方假意下嫁后欲复仇。

**感情纠葛**：一次"解救了身陷南霸天的玉颈金羽萧竹盈和满天红，更对萧竹盈一见钟情"。后来萧竹盈因故失忆，一剑万生悉心照料寻求医治之方，但"萧竹盈在和叶小钗的朝夕相处下竟萌生爱意"，导致一剑万生欲杀叶小钗，与其定下两年比武之约。

**风雨坪之战**："二年后，风雨坪之战，一世用剑不提剑对上蜕变之后的刀狂剑痴，一剑万生不但败北，脸上还留下了一道疤痕"。

**沉潜与反击**："经过一段时间沉潜的一剑万生，为逼出叶小钗而与半驼废决斗"。与挚友一刀万杀联手对战叶小钗，但最终"遭刀狂剑痴断首"。

**死而复生**：一剑万生"被沧海老鸟以《汇灵卷》化出疾风斩剑灵，让剑灵代替一剑万生死于叶小钗剑下来逃过一劫"。多年后复出，"与叶小钗的心结宿怨，也在天下第一人长乐君的开导下而释怀"。

**最终结局**：最终"被风中行者卧雪刀误认为是叶小钗而截杀于《霹雳英雄榜之江湖血路》第12集"，"一剑万生含恨而终"。

一剑万生"第一次出场就以驭剑飞行的方式展现其不凡的气势"。"与萧竹盈、叶小钗间的三角恋情让他为爱失去理智"，其行为变得"偏激、极端"。"风雨坪上的落败让他的自尊心受到打击，加上情场失意，使得他采取了玉石俱焚的手段"。虽然最终含恨而终，但"他和挚友一刀万杀的友情，如今仍令人津津乐道"。

# 小鬼頭 (小鬼头)
================================================================================

小鬼頭

祧師劫隨的義子，雖是三尺童蒙，卻也熟讀兵法，人小鬼大，個性刁鑽調皮，古靈精怪，喜歡刁難初入略城之訪客，擺排陣法或兵書為考題。愛與少主鬼谷晏嬉戲玩耍，戲稱之為大鬼頭。

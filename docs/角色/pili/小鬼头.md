# 小鬼头

祧师劫随的义子，虽是三尺童蒙，却也熟读兵法，人小鬼大，个性刁钻调皮，古灵精怪，喜欢刁难初入略城之访客，摆排阵法或兵书为考题。爱与少主鬼谷晏嬉戏玩耍，戏称之为大鬼头。

# 恨不逢

================================================================================

霹雳布袋戏中的角色恨不逢，是霹雳布袋戏中的虚拟人物。初登场于《霹雳兵燹之刀戟戡魔录》第19集，留名忠烈王府，组织门派为幽燕征夫。他形象翩翩潇洒、风流倜傥，作风自由随性，常搭乘画舫闲游，追寻世间女子的爱情。曾救下并照料魔界战将别见狂华，后与姥无艳相爱，但因嫌弃姥无艳脸上溃烂的臭味而溜走。恨不逢的性格经历演变，从最初的风流空虚，到暴露冷漠自私，最终成为恶毒阴险之人。在《霹雳奇象》第22集退场，被西风小妹毒杀。

## 经历
恨不逢是留名忠烈王府，翩翩潇洒、风流倜傥的美公子，追寻着世间女子的爱情，作风自由随性，常搭乘画舫闲游。

恨不逢救下魔界战将别见狂华并为其疗伤，但已显露出对感情的漫不经心与疲倦，其内心空虚又寂寞。

恨不逢和姥无艳相爱并自认为找到真爱。

在姥无艳毁容后，恨不逢发现闻到姥无艳溃烂的脸上的臭味时抑制不住想呕吐，认清自己真爱的肤浅。

恨不逢趁姥无艳晕倒时溜走继续寻欢作乐，留下字条称替姥无艳找解药。

此后恨不逢心态恶化，恶毒地诋毁姥无艳和羽人非獍的关系，恶毒地逼迫羽人非獍为自己和姥无艳拉车，将二人逼上绝路。

最终恨不逢被断雁西风毒杀。

恨不逢的塑造有一个从风流到冷漠自私再到恶毒阴险的演变过程。

其故事结局画面于小舟上为姥无艳撑伞，呼应《霹雳奇象》片尾曲“镜中花水中月”的意境。

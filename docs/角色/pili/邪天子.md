# 邪天子 (邪天子)
================================================================================

邪天子

六道神兵府之主，出身草莽绿林，疯癫过人，过去被称为“疯王”，行事总是不按牌理出牌，疯疯癫癫，让人难以抓摸，不时还会拿出镜子照自己。邪天子与玉梁皇、应笑我乃旧识，故六道神兵府除针对天子枪之外，更与玉梁皇合作共谋山海奇观，积极在暗中运作。

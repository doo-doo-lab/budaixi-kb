# 无量佛尊

慈眉善目的入世高僧，掌婆罗寺，笃佛法且知天命，因兰若经出手金银血案，始放下渡世救恶的慈悲心，以武佛斩恶之姿缉拿不望尘寰。

## 来自百度百科的补充

无量佛尊初登场于《霹雳皇朝之龙城圣影》第27集，并于《霹雳剑踪》第9集中被东方鼎立假扮的吞佛童子所杀。

无量佛尊在婆罗寺遭遇袭击，袭击者疑似吞佛童子，不敌时被一位神秘人物以佛光掌力所救，寺中其他僧众尽皆死亡，无量佛尊被救至另一处山头。

# 迷达

================================================================================

霹雳布袋戏虚拟人物迷达是霹雳布袋戏虚拟人物。魔佛波旬智相化体，代表智慧的象征，老成稳健，精于谋略擘画，有着极为敏锐的观察力，擅长于临敌时施展镜射之招，模拟、洞悉对手内心细微处。因遭烽火关键冲撞导致波旬三体分离，迷达一度潜沉，于佛乡和妖界攻打欲界时现身，与狱天玄皇对掌之际吸纳玄皇功力而容貌蜕变，一举扭转劣势。其后亦设局让普世佛门质疑佛乡，更曾让佛剑分说受其洗念异能影响而归顺欲界，然而与傅月影的意外邂逅，又将有了微妙发展。

## 人物形象

新设计过去的智体迷达给予人一种阴沉算计的谋略形象，这次重新登场，亦是算计连连，但是比从前更增暴戾，一扫天下佛宗，擒人为质的恐怖手段令人震撼武林，造成天佛原乡不攻自乱，遭受武林同道非议。在阎达和女琊都不在的情况下，威力与心智皆具备的迷达成为这次欲界风云的主角。新版迷达旧版迷达造型头上的光轮代表尊贵神圣，其上有许多眼睛饰物，意为洞察力、智慧；下唇很奇妙的有一片亮片，造型组特别的创意，非常的能夺取目光。霹雳会刊214期这次新版迷达成为了欲界当家的一哥，露出健美肌肉，宣示自身威能。古印度华服融合欧式风格的服装，尊爵不凡。

## 人物配乐

血印葬天轮（迷达气势曲）曲/编曲：孙敬凡 收录于《轰定干戈剧集原声带 · 精选45》孙敬凡老师2013年作品，以“妖界主宰”为题创作，魑魅般乐声响起，鼓声挟带强逼气势使人感到压迫，一波波人声不停歌颂神的崇高，间奏唢呐声狂妄且波澜，好似魔王只需弹指，障碍则灰飞演灭，展现灭天威能。乐曲选用于魔佛智体·迷达的气势曲，初用于轰动武林第24章，欲界面临天佛原乡、百妖路联手围杀而渐入颓势，此时迷达竟意外现身，吸纳玄皇功力而容貌蜕变，一举扭转欲界劣势，高展魔佛天威。

# 九孽之斬 (九孽之斩)
================================================================================

九孽之斬

九孽之斬為龍族傳說中的刀神。個性冷酷寡言，長居在天地一席的石堺上，不斷精進修行，對刀有著強大的天份，對塵世間的眷戀不大，但見龍族同胞有難，故而出戰驚鱗奔戰役，並用煉顱刀斬下劍尾麒麟的頭顱。

# 九孽之斩

九孽之斩为龙族传说中的刀神。个性冷酷寡言，长居在天地一席的石堺上，不断精进修行，对刀有着强大的天分，对尘世间的眷恋不大，但见龙族同胞有难，故而出战惊鳞奔战役，并用炼颅刀斩下剑尾麒麟的头颅。

## 来自百度百科的补充

九孽之斩是布袋戏剧集《霹雳英雄战纪：刜伐世界》中的角色，是龙族刀神，初登场于第3章，第50章被徐霞客击杀退场。其长居石堺精进修行，性格冷酷寡言，曾参与惊鳞奔战役，以九孽炼颅刀斩落剑尾麒麟头颅。该角色掌握法渡九孽·无锋十二斩等武学，持九孽炼颅刀与五道佚刀，拥有明古征衣。其根据地包括自囚埵府，人际关系网涵盖仇敌巽非巽、徒弟吹刃小子及天河蛟龙等同伙。最终于剧集第50章死亡，角色配乐《龙族刀神》收录于《刜伐世界剧集原声带叁-精选103》。

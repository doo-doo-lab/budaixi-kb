# 醉花阴（昆曲北曲黄钟宫曲牌）

================================================================================

《醉花阴》为昆曲北曲黄钟宫曲牌名。全曲七句，七韵。常做黄钟套数的首曲。2023年4月27日，曲学研究者陈玉成使用乾隆年间刊印的《太古传宗》中元曲《醉花阴》的原谱进行了演唱。该曲牌在《钧天乐·诉庙》、《邯郸梦·云阳》等多部剧目中为不同行当所使用。京剧《荆轲传》的“荆轲舞剑”场景也选用了此曲牌。其名与宋词词牌相同，但字格并不一样。《太古传宗》中收录的诸宫调残曲《双渐赶苏卿》里的《醉花阴》，具备典型的说唱风格。中文名醉花阴类 型昆曲曲牌名属北曲-黄钟宫句 韵七句、七韵

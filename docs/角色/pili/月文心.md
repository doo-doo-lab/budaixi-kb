# 月文心 (月文心)
================================================================================

月文心

出身啟示國度中的月之一族，面容與流蘇晚晴相像，月之一族因聖嬰失蹤，導致家道中落，月文心一心為國，挽回家族名聲。性情急公好義，舉止大方，以啟示國度的子民安全為己任，深受百姓愛戴，直呼其為女聖，後更成為啟示國度的「聖君女」。

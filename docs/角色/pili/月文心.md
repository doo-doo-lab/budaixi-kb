# 月文心 (月文心)
================================================================================

月文心

出身启示国度中的月之一族，面容与流苏晚晴相像，月之一族因圣婴失踪，导致家道中落，月文心一心为国，挽回家族名声。性情急公好义，举止大方，以启示国度的子民安全为己任，深受百姓爱戴，直呼其为女圣，后更成为启示国度的“圣君女”。

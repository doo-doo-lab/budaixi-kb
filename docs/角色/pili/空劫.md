# 空劫

看似幽默逗趣、举止疯癫，法号空劫却自称半僧功的出家人，乃因佛门戒律只守一半、佛法也只修一半，实为大智若愚。在一页书遭逢劫难时，受托主持正道、揭发合修会阴谋暗桩，而后更接掌七彩云天住持之位。

# 经天子

霹雳布袋戏虚拟人物经天子，霹雳布袋戏虚拟人物。原为身居爵位的汗青编辅官，为夺汗青编主权而反叛。在反叛失败后却牵引出背后的坤灵界。身为坤灵界执府，又研习阴阳双册，与鬼隐合谋，掌控邪能境，更在犴妖神死后成为了冥界之主。

## 经历
经天子 悦兰芳曾经在武林中有着举足轻重地位的蚁天·海殇君，在海鲸岛一役之中壮烈牺牲，而海殇君临死前最后的心愿，便是希望自己能名留汗青编，也因此开始让汗青编这个名称在武林中崭露头角，孰料，在众人心目中地位崇高而不可侵犯的汗青编已经变质不复以往，而这全是因为它的主事者，也就是冒牌御主——玉指圣颜·经天子。

以汗青编御主的身份现身武林的经天子，早早便展现出他追求权势名利的野心，由篡夺汗青编，到杀九曲邪君成为邪能境之主，他从来没有放弃对权势名利的追逐，这似乎也注写了经天子的一生。【手足情薄 权位为上】原本身为汗青编辅佐官的经天子，他的职责在于辅佐悦兰芳，但是经天子却因为对于权势的追求，在真正的汗青编御主——御笔丹青悦兰芳离开汗青编之际，取而代之，成为汗青编的领导人。

虽然说，这种篡位夺权的事情在武林中屡见不鲜，但对于汗青编正主悦兰芳来说，这却是桩兄弟阋墙的天伦悲剧。

正因为玉指圣颜与御笔丹青有着血缘之亲，这种事情才让人更觉得无法置信，但是对经天子来说，取得确切的权势比手足亲情更加重要，所以他选择背叛兄长，也从此开启经天子毕生汲汲营营的权位追求之路。【善于借力使力的策谋者】经天子十分了解在当前的武林之中，单凭一己之力很难有所作为，由经天子种种事迹来看，可以发现他鲜少单打独斗，即便是自己已身为组织的领导人，经天子仍然十分擅用他人之力，来减低自身组织的消耗与损失。

在夺取汗青编之时，经天子选择与魔剑道合作，借助魔剑道的人员来建立自己在汗青编各宫的新势力，另外四禁道的销魂夜媚、寒剑·月飘霜等人，便是经天子自坤灵界借调而来的人手。

在预谋夺取邪能境时，经天子更是深谙“射将先射马”的道理，先除去九曲邪君，在众人慌乱之际，再收服邪能境大将，借着灭轮回等大将的臣服，经天子轻轻松松的掌握整个邪能境，如此便可用最省时省力的方法，拿下邪能境的统治权，由此看来，经天子预谋夺取邪能境的领导权，应该早有详细的计划，非是一时间匆促而定的粗略计谋。

而近来经天子与素还真合作演出的戏码，更是出乎众人预料，经天子借着败于素还真手下，消除冥界军师负平生的戒心，更进而摸清天狱，进占天狱。

经天子在处事上确实有其独到的手腕及方法，善用他人所拥有的资源来策谋己身的计划，正是他成功的最大要素。【巧妙布局 隐藏实力】悦兰芳取回汗青编，原本掌握汗青编的经天子自汗青编败出之后，有好一段时间经天子都依附在魔剑道的组织下，更甚而遭受毒蝎女的控制，看似已步入穷途末路的经天子，却早在不为人知时领导另一个组织——坤灵界。

经天子深知想要在武林中有所成就，就不可能将自己的实力完全暴露于敌人面前，尤其在广大的武林中藏着许多不为人知的敌手，要懂得保留实力才能走得长久，因此即使自己已建立了颇有实力的组织，经天子仍然选择暂时寄身于魔剑道，除了可借着魔剑道的能力保护自身的安全，也可利用这段时间休养生息，观测武林各组织的实力及未来的走向。

另外，经天子设计谋杀九曲邪君，谋夺邪能境就更不用说了，若不曾经过巧妙的排布及沙盘演练，邪能境之主岂是如此容易杀害。

当然，经天子也懂得暗中增进实力，只要是可能成为他日后雄霸一方的利器，他都会尽量设法得到手，也是因为如此，有时难免会吃亏，记得当初经天子为了武林上人人争夺的神剑，一路追到怨君崖下，结果被毒蝎女所控制；

也如同他由封灵岛上得到阴阳双册，虽然被驯刀者索回，但是他早就暗中留下了手抄本，当然，他锻炼阴阳双册中的功夫一事，经天子也是尽可能保密咯！【坚持到底的追梦高手】经天子经天子 邪之主形象 官方桌布说到经天子他最大的优点，就是不屈不挠，坚持到底。

不论他为何对于权位如此眷恋，但是他的确是一步步朝着自己想达到的目标迈进，也一次比一次要更为成功，由最初的汗青编，到最终一统冥界，经天子越来越接近他想要的雄霸一方。

在经天子追求权势的过程之中，他曾经挫折，尝到失败的苦果，但他却未曾因此而打了退堂鼓，放弃自我的梦想。

更甚而可以说，经天子便是为了权位而存在，他所做的每一件事都是为了权谋：霸占汗青编、领御坤灵界、私藏阴阳双册，加入魔剑道、谋夺邪能境……他成功的从每次的挫败中成长。

但螳螂捕蝉黄雀在后，经天子打败负平生，却在四无君手中栽了个大跟头，只是，这次他失去了东山再起的机会。【总结】从出场至今，虽然经天子曾经落魄失意，但他的人生一直在他自己的掌握之中，怀有比任何人都要来的多的雄心壮志，一生的经历多彩多姿，即便最后难逃枭雄末路，但经天子华丽的身影想必仍停留在大家的脑海之中，久久不能挥去！

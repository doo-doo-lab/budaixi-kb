# 西窗月

================================================================================

霹雳布袋戏虚拟人物西窗月，霹雳布袋戏虚拟人物。出身道家名宿，学成于仙山洞府，有女卧龙之雅称。甫现身便以梅魄转生术，初展神通，替遭劫鹿巾重塑肉身。其性好僻静，隐居四皓方庭，与山鹭为伴，历经魔笔之险，与天蟒帝蟒之劫后，有了跌宕磅礴的人生际遇。

## 人物能力

武学七十二弦手·十二天罡分拨定、气无终尽·形无不毁·无定霓虹、山星周行、流川不息·凝岳不动·无穷法一定天宿、东风长焰破云空、束龙晶索、霓衣抛锦姑山雪、三月闻韶望乾坤、一戟鸣珂断千泓、桂魄一香引、观乎丽天·珠耀火、镜里移花水非月、一焰空明火琉璃、朗月戟、有龙矫矫动地陷、卧虹千尺冷浸月、如龙负出·是凤衔来·星环日纡飞五云、一江星斗鱼龙寒、日照虹霓灵山秀、周穆八荒行、普贤一剑昭白象术法◎梅魄转生术：记载于《拾异经》的秘术，西窗月采卜居瑞雪之梅枝为骨，嵩雪水为血，梅瓣鹭羽为肉，皓朱双股为筋，为占云巾再造肉身。

华丽晶透，尖端如枪头尖锐锋利，戟柄以山鹭外形打造，并系玉佩与白流苏，十分飘逸的同时也充盈着圣洁净邪的不凡高雅。

西窗月运使秀戟精巧如翩龙翦水，搅动风云万千。

本质并非一般兵器，而是伴随西窗月共胎诞生的伴生灵器，也因此致使其母紫吻难产，以古墓族特有秘法“无坼凌取”隔腹将胎儿与秀戟取出，故无法以寻常金铁修缮。

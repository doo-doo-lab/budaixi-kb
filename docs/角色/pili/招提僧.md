# 招提僧（霹雳布袋戏虚拟人物）

招提僧，霹雳布袋戏虚拟人物，天之佛五相之一“招提法相”。代表因缘法，久远之前曾度化鬼如来，并赠予一口空刀开释，造就后来的雷峰佛首和佛刑禅那。招提僧亦曾于帝如来意识中劝其不要轻易放弃生命。为感念其恩，帝如来亦化身以招提法相于扫禅山门外，洒扫修行；而真正的招提僧，则于一页书顿悟天佛原乡之路时，首度现身迎接。

## 人物能力

- **武学**: 四方招提、佛界遗世武册·下卷式·“琉璃炽盛·罗汉开道·如来大悲·究竟涅槃”（与砗磲佛母、欲明王、慧宁师合招）

## 经历
佛首化身功德回向云鼓雷峰入口处扫禅山门的扫地僧，洒扫修行、处处禅机，曾指点素还真以初心面对勾陈山径之考验，更在山门前以惊天实力挡下暴怒的梵天，并指点庄严殿主放下执著。

如此修为，难掩招提僧不凡身份，正是帝如来所化。

后在光世大如请命下，现身一对烨世兵权。

帝如来化身的招提僧　天佛五相之一许久之前曾入尘世渡化鬼如来，并赐予鬼如来一柄空刀与一股灵气开释，方有日后创建云鼓雷峰的帝如来。

渡化过程中，帝如来曾欲自行了断，招提僧（天之佛化身）在其意识中劝其勿轻言放弃。

随后，招提僧与恢复正常的帝如来相遇，欲将空刀赠予他以护持正法行途，但遭帝如来拒绝。

招提僧遂收回空刀，为众人让开道路。

在一页书通过考验，进入天佛原乡之际，亦担任接引之职，为五相中象征渡化的法相，其后于素还真前往紫竹源再现尘寰，同时也代表延续千年的佛厉之争，即将再掀波澜！

天佛五相的招提僧

## 人物配乐

◎招提僧（无常庵）曲/编曲：林薇 收录于《霹雳英雄音乐精选三十九》林薇老师2005年作品，清亮的梵钟搭衬著清脆的木鱼敲击，一股佛门清圣气息油然而生，三千烦恼瞬间净化于无，让人不自觉平心气定。乐曲初使用于霹雳神州Ⅲ之天罪第8集，楼无痕于无常庵出家修行之情境；后于圣魔战印剧中，挪用为云鼓雷峰扫禅山门的修行僧、同时也是天之佛五相中的“招提”。

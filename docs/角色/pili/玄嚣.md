# 玄嚣太子

霹雳布袋戏虚拟人物。黑海森狱阎王的第十八子，天资聪颖的俊秀少年，具有王者的沉稳霸气，然而楚霸王般的性格，既塑造了其独特的人格魅力，也让他因锋芒毕露而树敌众多，埋下覆灭伏笔。许久前曾与天谕鸠神练有过约定，在鸠神练开启黑海森狱的通道后，答应协助鸠神练（而后不知不觉爱上天谕），并派遣四令缔。本身为黑海森狱立皇的四名人选之一，因此与第九皇子玄灭太子较劲，在得知天罗子复生之后，便开始针对天罗子。诗号：千秋业，万古名，英雄一身血沾尘；疆场沙，争高下，百年气概，胜者吾名。

白麒麟：黑海森狱中，功体高强者，体内皆有元神兽，元神兽离体再回归，则有提升功力的好处，但是元神兽一旦离体，犹如脱缰野马，四处奔驰不知其踪，且离体的元神兽脆弱、不易生存，若被杀将危及本体，风险甚大。

麒麟除了是祥瑞之征，也有麒麟送子、麒麟儿的传说，配合玄嚣白色造型，代表玄嚣杰出的成就。

## 说太岁角色漫谈

月刊224期编剧漫谈── 玄嚣太子
玄嚣太子剧照
以往每个主要角色形成之前，脑袋里都会先转着一套，属于这个角色所要呈现的中心特质，先把棱角都削利出来了，才会知道要怎么打磨，更能呈现出角色的光彩，所以有些戏迷会觉得我笔下的人物，都有种偏执的感觉。

而我个人觉得，其实每个人都会有他显性或隐性的棱角，一般俗称为“癖”，而这种比较贴近人性的癖好（或者说小缺点）设定，可让角色呈现出相对鲜活的生命力，而不是一个面谱化的人物。

而角色活跃的戏剧里，就像上了舞台的演员，大多时候是浓妆艳抹，让舞台效果变得更加醒目。

我在呈现人物的癖好上，也多半会放大书写这不管是好还是坏的个性，因为要的效果，是人物特色的呈现，而不是一个众人眼中然即然矣，一个高大上，完美无缺的角色。

但对于玄嚣太子这个角色，一开始并没有很投注于角色内心思维的设定，但因为身上扛着阶段性反派主角的光环，所以让他有了相对的戏剧空间。

而在书写这个角色时，其实比较多的是在想着，如何把整个森狱的大盘棋端起来，对玄嚣太子的个人情感、喜好、或者说是角色的个人灵魂，就相对浅薄诠释。

这个角色的基调，在于阎王立的四位太子，最小但也最早出头，他十分的爱护手下，面对每一个不同的属下，就会有一套掳获人心的应对方式，说是他天生的热情与敏感也可以，但我觉得比较贴切的形容，是他耽溺于“收买人心”这种情感优越感。

他把自己身为太子这个定位，看得很重，认为森狱以后的王位，必定属于他，所以他与人交陪时，通常不把对方看成是朋友，而是端着太子的身份，用施舍的态度，去经营自己的人际关系。

他有很多忠心的下属，甚至他要好的兄弟，也是以一种上司与下属的模式在相处着，他看似施情很多，也收到了回报，但其实在他的身边，没有一个真正的朋友，一个平起平坐，不是以权势、以地位、以立场相交的朋友，而是一个可以谈心、可以无语并肩的赏星、观海、听雨的知己。

或者正确的说起来，玄嚣太子一生从不知道，朋友相处的感觉是什么。

在他眼中，就只有“太子与众手下们”；

而在夺得大权以后，就是“朕与众功臣们”。

如果说天罗子的世界，是个六亲不认的世界，那么玄嚣的精神世界也差不多。

他的哥哥，不是自己的左右手，就是一个可能要铲除的对象。

阎王或许有其父亲形象，但更多的，是代表权位的阶梯。

或许你们会觉得，玄灭太子不也如此？

其实不然，以先前玄嚣在水晶宴上，宴请与自己交好的玄震与玄幻，对比玄灭在自己的殿上，宴请玄丘、玄穹、玄造，这两场戏，便可说明玄嚣与玄灭的差异。

玄嚣看似与自己兄弟把酒言欢，但实际上，话题都还在自己控场之中进行着，对二位兄弟看似情义深厚，但实际上，玄嚣在谈话间，都会无意的流露出一股“朕的席榻，朕与你共享，跪谢吧！”这种比较高高在上的感觉；

而玄灭与三兄弟的酒宴上，就比较像三个臭皮匠，密谋着该如何进行阴谋，虽然玄灭也是以太子身份自居，但他相对的霸气与棱角就少了许多，无法确切的掌控话题的进展，比如玄造的憨与乱入、比如玄丘的色与自我幻想，他们性格的出槌度，在交谈中，展露无遗。

或者有人会说，这是玄造与玄丘的个人特质，并不是玄灭可以掌控得了。

但以识人、用人的手腕说起来，玄嚣可能就是个相对会掌控，甚至企图改造对方，让他符合自己期许的方向去发展。

而玄灭就比较是种放任态度，然后依其个性或特质去加以遣派运用。

两者用人态度，无分高下，但在掌控度来说，玄嚣比玄灭多了点霸气跟高高在上。

而这也是温翘为什么在两位太子之间，会产生情感的矛盾点。

因为温翘对两位太子笼络人心手段，皆有感触，但玄嚣的掌控度较高，所产生的向心力也比较深。

而神在在最后完全倒戈于玄嚣，也是在于玄嚣的掌控度，较为有力。

霹雳会月刊第224期 编剧漫谈
在一个没有朋友与六亲的玄嚣面前，玄同太子就是个相对较为奇妙的存在。

玄嚣自视甚高，也有点英雄情结作祟，他认为自己站出去，就应该是众星拱月的对象，只有他无视人，没有人可以忽视他！

可偏偏他认为最能成为自己竞争对手的玄同太子，竟然只因为自己不用剑，而完全忽视他的存在。

于此，他更是一把骨气的不去学剑，他就是要玄同从痴剑的眼光中，转投向用枪的玄嚣太子，没有剑，完全不是因为剑的关系，而是因为玄嚣这个人的存在，才让玄同将眼光投注。

可惜玄同不买他的帐。

于是玄嚣更气了，他宣称森狱中，只有玄同才是他真真正正的王位竞争者。

而他要在玄同眼前，夺下王权，甚至是称霸苦境，然后统霸后的第一件事，就是将全天下的剑，全部熔毁，成为一个无剑的世界！

他就不信，在无剑的世界中，玄同的眼睛还能看向哪里！

不过随着他的皇图大梦一醒，他内心这点近乎孩子气的竞争意识，也随之埋没黄土。

而玄同对玄嚣这个弟弟，当真毫无感情吗？

不妨让我们看下去。

再来要说的就是，玄嚣对太岁，究竟是抱持着什么样的观感与情感呢？

其实一开始，玄嚣会注意到太岁的存在，是来自于玄同与太岁的交谊，之后才知道，原来太岁这个玈人，竟然是个能得到阎王赏赐阎王鞭，被阎王喻为贤者的人。

他为了王位，开始想拉拢太岁这个人，但太岁也是个不买他帐的异者。

在这点上，他一直认为是因为太岁先与玄同交好，所以才不愿与他有所交集。

在双重竞争意识下，他觉得如果能把太岁拉到身边，等同于他在与玄同的竞争上，胜了一次。

可惜，太岁真的不买他的帐！

尔后，再加上天罗子的因素，他对太岁产生了一种又爱又恨的心结，想将他一把踩在脚底，又欣赏他那么傲骨无双。

第一次完败了太岁，让太岁屈膝在面前时，其实玄嚣的内心，有一角碎了，虽然称说自己的双手，不屑收下低贱的玈人之命，但实际上，只是在找一个能够饶过太岁一命的理由。

他无法理解为什么看不起自己的太岁，却是用生命在处处维护着天罗子！

玄嚣在太岁身上，从一个玄同的竞争投影，变成了自己内心一个无法理解，却又十分想得到的友情对象。

而最终，或许该庆幸的是，他永远都不知道自己亲手杀死了太岁，这个在他生命留下一道特殊感触的人。

行笔至此，我已经有点佩服自己了，对玄嚣太子这个角色，居然真的可以“漫谈”这么多。

霹雳会月刊第221期 角色特写
这么说吧，玄嚣太子一开始是没有爱情这个区块的设定，我兴致勃勃的想要写出荡气回肠，如史诗般可歌可泣的主上与臣下，但因为整体剧情发展需要“玄嚣太子与天谕”的快餐爱情，就在我的笔下成形了。

七天就要完成终身大事（包括谈恋爱、成亲、生小孩），我真的写得头很大！

总觉得感情再怎么光速发展，这样的七天，也太“惊心动魄”了吧！

然后就想，干脆设定小时候有见过面，有一点点纯纯的交集，为来日的今朝爱情，铺下一点前因后果，才不会显得这么快餐。

可是，森狱未开通之前，两境之人根本不能相通，小时候的玄嚣跟小时候的天谕，要怎么相见过？

鸠神练小时候曾失足跌入海里？

不行，这个梗，逸冬清已经用了，重复显得很没意思，那要怎么办呢？

想了老半天，只有让鸠神练作梦，因梦境关系而进入森狱。

这个设定被接受了，但是小时候两人就见过面的情节，还是太老梗。

于是，后来定案成，鸠神练真的很会做梦，但她小时候进入梦中，见到的那个玄嚣太子，其实是阎王假扮的。

阎王的目的，是要借由鸠神练的天赋之能，为他开通三界交通。

这样就能解释为什么天谕知道黑海森狱的存在，更知道如何进入森狱，开通森狱与苦境的交通，又为什么会认为天、地、人三界打通，她就能得到无上力量，无病无痛，更能赐福于人。

虽然这边的剧情有接顺了，但相对在减轻“玄嚣太子与天谕”的快餐化爱情上，却是于事无补。

也因此，我只好将两人设定为，是因为利益而结合，却在过程中，为对方留下了一点心里位置，而这个位置没有其他人坐过，所以就姑且暂名为“爱情”。

而是不是每一段爱情的样貌都一定是爱得死去活来那种呢？

不一定吧！

玄嚣与天谕的这段感情，可称之为爱的萌芽期，但因为未及茁壮，便被现实摧残，所以留下了一点遗憾，一直在心中反复的搅着，忙的时候，就抛在一旁，不去想它，等空闲的近似寂寞时，再捡起来，贴心的感受一下。

那么随遇呢？

随遇对玄嚣而言，又是怎样的存在？

难道真如山龙隐秀所言，玄嚣急着生下后代的原因，是因为要将随遇当成生命的备胎，在遇到重大灾难前，用随遇的命来填补自己的流逝的生命？

我想这个答案，连玄嚣自己也模模糊糊，不如就当成是玄嚣心中的一点秘密，随他消逝而永埋黄土。

而我迷迷糊糊的，也将玄嚣太子的编剧漫谈写完了，希望这篇漫谈，能够让人更加了解玄嚣这个角色的形成与魅力的所在。

# 千手毒王 (千手毒王)
================================================================================

千手毒王

武林最恐怖的千手毒王，無形劇毒無色無味，讓人聞風喪膽，個性冷血貪婪，多年前曾涉及命家莊血案，與百里飛首、金陽聖帝掛勾，後又參與圍殺歐陽上智計畫，其背景來歷頗不單純。

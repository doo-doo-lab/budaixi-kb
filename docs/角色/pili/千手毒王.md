# 千手毒王

武林最恐怖的千手毒王，无形剧毒无色无味，让人闻风丧胆，个性冷血贪婪，多年前曾涉及命家庄血案，与百里飞首、金阳圣帝挂勾，后又参与围杀欧阳上智计划，其背景来历颇不单纯。

## 主要经历

千手毒王多年前曾涉及命家庄血案，与百里飞首、金阳圣帝挂勾，后又参与围杀欧阳上智计画。金阳圣帝曾找千手毒王与百里飞首参与杀人夺宝事件，事后两人因恐惧不敢出来。

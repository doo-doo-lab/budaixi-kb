# 却尘思

霹雳布袋戏虚拟人物却尘思，霹雳布袋戏虚拟角色，别名涉足、忘尘漪，中文配音为黄文择与正经太郎，2014年12月26日初登场于《霹雳开天记之创神篇》第30章，退隐于《霹雳天命之仙魔鏖锋》第5章。

身为佛门修行者却兼具儒风，性格稳重温和、内敛从容，代表经典为《金刚经》，手持拂尘居三足天，因苍生受难入世却尘思原为易天玄脉玄脉三子之一，与鹤白丁、缥缈月互换灵封共修克制邪念，担任一际云川主事期间对抗鬼方赤命、九轮天等势力。

因异识入侵引发杀戮，经侠菩提点化后逐步压制罪念晶源影响，最终在不动城解散后退隐。

配有佩剑“愆释”及宠物雪儿，武学包含圣华天赦、明佛天皈等招式。

角色历经异识侵蚀、同修背叛等劫难，查明身世后与兄弟离散，退隐江湖时已能自主克制邪念。

主要活跃于《霹雳开天记之创神篇》《霹雳谜城之九轮异谱》等系列剧集，剧中足迹贯穿三足天至留心清域等多重场景。

## 角色设计

预言堂人物——涉足却尘思（摘自 霹雳月刊 第232期 文/编辑部）
外貌年少，修为超凡的佛门修行者，温和内敛，手持拂尘，虽为佛门中人，却饰儒家之风，居于三足天上，未涉尘世。

封面人物（摘自 霹雳月刊 第236期 封面人物）
三足天的登场，原是董事长先提出三人团体的构想，分属儒道释三教，以“足”为共同概念，由于“脚”是个激发想像的点，众编剧纷纷提出新点子，其中“穿高跟鞋”（时尚意味）的高手，这样的想法转变为三足天之中出现女性成员。

第236期 却尘思
涉足却尘思温和、圆融，在点轮回危急之时出手相救，见鬼方赤命侵略，局势动荡，不忍苍生受苦而渡红尘。

温和的却尘思其实也有坚定的一面，除了力邀鹤白丁、缥缈月一同入世，在面对鬼方赤命的威胁下，提出换回灵封，还相当坚持，这点也让人颇为意外。

却尘思的武学设计，也以温和为主，演出时以光芒特效强调佛门的清圣气息，其实却尘思过去曾修练剑法，修为不凡，但剑法越高，越觉“冷锋无情，易将人伤”，因此决定不再轻易用剑。

互换灵封的想法，有点类似过去三教怪人互换衣服，强调怪异，不过三足天的互换灵封则另外有设计其背后缘由，经侠菩提指点，三足天互换灵封，削减功力，为却尘思克制邪念，但这邪念考验并非是因本身心魔影响而入魔，而是来自怪贩妖市的恐怖异识。

异识出自罪域创罪者，也被称为罪念，能无声无息的控制人的精神、行为，发作症状有疑心、暴躁、歪曲本身奉行的理念，身上还会冒烟，更可怕的是居然还会传染！

却尘思曾在古洞中发现疑似祸患，但不及细察，只能暂且封印洞口，不料当下即已被感染，并发生一连串事端，虽然却尘思以功力压制，但因异识影响，不知不觉中隐瞒过往之事而不自觉。

却尘思曾被天佛原乡延揽，有成为“首位”的机会，但是为了调查被邪力感染的村落，放弃了这个被他人视为荣耀的机会。

因剧情需要，故事走向异识之谜，编剧设计却尘思与异识接触的故事，展现却尘思为苍生而舍弃地位的慈悲心肠，也因此事件引发了今生遗憾。

这一去，异识开始作祟，造成不轻易用剑的却尘思出剑杀人。

多年以后，却尘思终于能不依靠灵封，成功克制异识、返回本心，但是异识不止一个，还会自行寻找下一个感染目标，关心却尘思的鹤白丁，也与却尘思一样想毁去异识，但“一位高人终于克服了精神难关，却发现身边的人坏掉了”，这是编剧安排的一个方向，也是却尘思接下来要面对的真正难关，但是异识也不会轻易放弃，却尘思是否还会再度被异识影响？

角色形象造型
却尘思除了温和慈悲，还有儒门之风，气质斯文，是三足天中最为沉稳者。

因为要淡化前辈或超级先天色彩，所以选择深色头发，看起来较年少。

头冠有儒门人士的气质，是佛门角色少见的类型。

浅色系的僧袍，有种朴实感。

以缠绕方式来持念珠，是个人特色，看起来也活泼多了。

三足天各自的代表物，却尘思以拂尘代表佛门。

## 角色经历

久远前却尘思为受异识入侵，渐入魔道，幸好遇侠菩提点化，为压制其体内异识影响，与缥缈月、鹤白丁交换灵封，同在三足天修行。

天佛原乡深层遭鬼方赤命覆灭时，却尘思出手救下并收留重伤的点轮回。

（创神28、30）官方桌布双王大战白沙书院，却尘思以普天众生之力化巨足一助。

（创神29）邀请好友蹈足鹤白丁、皓足缥缈月针对阎王，一抗黑月之祸。

（创神下01）白沙书院终战，却尘思对战阎王副体，在副体释出恶相出现破绽时，抓住时机将其击退，并从赤命手上带走道真双秀。

（创神下02）以身试探阎王本体武学特点，被翠萝寒救走。

（创神下03）却尘思与鹤白丁为再次邀请缥缈月入世，为解决琴决误会，双足拦截赮毕钵罗，鹤白丁与其一战后，与却尘思交换意见，认为赮非缥缈月所形容的无理之人，并隐约感觉其身上似有恩人侠菩提的气息。

（创神下05）三足分别与阎王、赤命、君海棠三王交手，为鹤白丁安危，却尘思要求缥缈月一同解除归返各自灵封。

却尘思归还缥缈月之儒链，鹤白丁归还却尘思之佛冠，缥缈月归还鹤白丁之道徽。

（创神下07、08）却尘思对战阎王，后因阎王祭起黑月阴力而引动体内异识邪力，被缥缈月带走。

（创神下09）因灵封解除，却尘思体内异识邪力渐渐复苏，却尘思以自身意识与之相抗，却遭受被异识启罪的景深湛之逼杀，在邪力影响下，反将其诛灭。

（创神下14、15）却尘思回溯往事，找回初心，以一己之力压制了异识之力，解除了罪念在心性上的影响。

（创神下17）以圣佛之力治愈岱灵思之伤。

（创神下18）与罪念晶源达成协议允其入体。

（创神下21）被罪念晶源入体的鹤白丁联合崇真三誓一起抓回道门，后被狂刀救走。

（九轮异谱03）趁鹤白丁与钧天上君去天外无天寻找道门衔令者之际孤身一人前往无上崇真，提醒广乐上仙、紫宫仙君小心被异识感染的鹤白丁，之后与禄名封发生战斗，因缥缈月插手而停止，随即离开。

（九轮异谱04）为救被罪念晶源侵入意识的鹤白丁，击碎佛之足，后救人失败。

（九轮异谱04、05）和众人一起抵抗九轮天，过程中得知自己还有两个兄弟。

几经辗转，终于明白自己的身世，但父亲、兄弟也纷纷离世。

最后随着不动城的解散而退隐。

（仙魔鏖锋05）

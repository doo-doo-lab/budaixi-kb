# 兵災雪 (兵灾雪)
================================================================================

兵災雪

為暗劫八無暇排行第二的智囊擔當人物，個性優雅中帶邪氣，沉靜中帶深沉謀算，一切只為八兄弟周全，尤其以大哥祖登龍為最先考量，背後似乎暗藏不為人知的幽暗故事。出征殺人前，會先薰香沐浴，作為特殊儀式感。

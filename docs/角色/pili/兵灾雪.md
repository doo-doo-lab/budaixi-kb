# 兵灾雪

### 人物设计

命名来由

兵灾雪之名，透露其人生目标，即以兵戎干戈、掀灾不止，欲以雪浪造成世间的人祸。就如汤问梦泽灭门之时，兵灾雪所吟诗号：“十里风咽，满城兵灾雪。”满城兵灾雪是名词、亦是形容词，而这场雪，不知何时才会落停？

自弃双足，寻水落石出。

多年前，暗劫八无暇之首天蟒·祖登龙，与汤问梦泽山座香六牙，为地狱鸟，在呼魂之巅一战，战后祖登龙下落不明，位列八无暇第二的兵灾雪为了寻兄长的下落，同为掩人耳目，决定自断双腿，化名不全鹰·北云折翼潜入汤问梦泽进修，慢慢取得山座香六牙的信任，成为了众人口中尊敬的大学长，唯一目的，即是为有朝一日能亲自找出祖登龙下落，兄弟团圆。

一名双腿断去之人为了求学来至汤问梦泽，这对香六牙来说，是位使人感动且钦佩的学子，在西窗月、鹿狐双骄等人毕业后，不全鹰虽性格低调甚或孤僻，但仍成为了汤问梦泽中受人尊敬的大学长，这个和平一直到地狱鸟力量再出，导向山座遇害的那日.....

寻回兄长，是唯一使命。

对兵灾雪而言，八无暇的兄弟情凌驾一切，因此找回祖登龙，即是兵灾雪最重要的使命。兵灾雪的性格残忍冷酷，但其实这份无情仅只向外人，兵灾雪对兄弟情的维护可说无微不至，甚至为了兄弟团结，委屈求全亦能牺牲，扮演着团结八无暇的重要人物。

状似同心，却貌合神离。

尽管兵灾雪期望周全八无暇之结义情，然而多年前一段悲剧，造成了兵灾雪与八无暇中的老四愁伞人的对立。当年愁伞人的胞妹算雪，与兵灾雪两人互有情愫，然而一道不可抗拒的秘令，兵灾雪亲手杀了算雪，因而与愁伞人的兄弟情就此变故。直至今日，兵灾雪与愁伞人仍只是因为八无暇的承诺而维持表面和平，而这段悲剧过往，是否会成为未来兵灾雪与八无暇中产生更多的裂痕？

三剑交易，结识傲神州。

霹雳朝灵阙的预告片中，剑魔傲神州与兵灾雪的交锋是否让戏迷朋友尚带有疑惑？乃是当年傲神州寻得刀魔星野残红之后，因故与兵灾雪达成协议。大家熟识的傲神州言出必行，承诺替兵灾雪出三剑交易。这三剑兵灾雪会如何运用？将会是霹雳朝灵阙中的重要关键。

造型

兵灾雪以雪为名，衣着上以雪白与大胆的黑条纹作为色彩冲突，毛绒绒的大领造型强调视觉系风格，呈现出雪季的浪漫，俐落中长发有着干练感，带有智者气质，却是城府深沉。

场景·妖氛之脉

暗劫八无暇的根据地，以石墙为基础，并有着八个炉子，此八炉皆会燃起火焰，当八无暇中有人身亡，即该炉就点不燃火焰，反之只要留有最后一盏火苗，即代表八无暇仍有人生存。

# 兵灾雪

为暗劫八无暇排行第二的智囊担当人物，个性优雅中带邪气，沉静中带深沉谋算，一切只为八兄弟周全，尤其以大哥祖登龙为最先考量，背后似乎暗藏不为人知的幽暗故事。出征杀人前，会先熏香沐浴，作为特殊仪式感。

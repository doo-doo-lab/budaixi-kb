# 八顛 (八颠)
================================================================================

八顛

佛劍入西佛國境內所遇之僧侶，衣著襤褸、橫眉怒目，行徑哭笑瘋癲，似有所欲的阻撓佛劍之路，百般考驗刁難；後方知七笑八顛乃鎏法天宮巡界尊者，顛癡的表象實乃大智若愚。

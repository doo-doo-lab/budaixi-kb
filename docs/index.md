## 怎么用

- **搜索**：顶部搜索栏支持中文全文检索（角色名、招式、配音、剧集等）。
- **浏览**：左侧目录按厂牌分组，按角色名笔画/字母排序。
- **命名**：文件以最常用的称呼命名（如 `史艳文.md` 而非 `云州大儒侠.md`），别名见正文。
- **多源**：每个角色页保留多个数据源用 `===` 分隔条隔开，可对照查看。
- **编辑**：每页右上角"铅笔"图标可直接跳到 GitHub 修改对应 Markdown。

## 数据来源

| 来源 | 用途 |
|---|---|
| [百度百科](https://baike.baidu.com/) | 主要文字内容 |
| [霹雳官网](https://www.pili.com.tw/) | 霹雳角色官方设定 |
| [东离官网](https://www.thunderboltfantasy.com/) | 东离角色官方设定 |
| 维基百科 / 中文百科全书 | 补充资料 |

部分角色文档为多源合并（如 `万雪夜.md` 同时包含百度百科上"万雪夜"与"万朔夜"两个别名词条）。

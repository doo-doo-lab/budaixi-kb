- **维基百科** 中英文版各角色词条

每个角色页均标注了主要内容来源 URL。整理过程中借助 AI 工具（Mimo、Kimi 等大语言模型）辅助合并多源数据。

::: warning 重要提醒

本站内容由 **AI 辅助合并自多个来源**，可能存在以下问题：

- 不同来源信息冲突时的合并错误

## 普通访客如何贡献

发现内容错误、想补充信息？任何登录 GitHub 的访客都可以：

1. 点击页面右上角的 ✏️ **编辑此页** 图标
2. GitHub 会自动 fork 本仓库到你的账号下
3. 直接在浏览器里编辑、提交 Pull Request
4. 维护者审核合并

每次修改都会留下完整的 git 提交记录（谁、什么时间、改了什么），可以在 [仓库 commit 历史](https://github.com/doo-doo-lab/budaixi-kb/commits/main) 查看。

## 本地预览


## 数据清洗说明

原始抓取的百度百科页面带有大量 UI 噪音（导航条、页脚、UI 标签等）。
[`_tools/clean.py`](_tools/clean.py) 通过一组正则规则将其去除，同时保留多源补充段落（如东离官网、维基百科、newton.com.tw 等）的完整内容与原始链接。

每个角色页顶部保留了原始抓取来源 URL，方便溯源。
部分角色（如 `万雪夜.md` 同时含百度百科上"万雪夜"与"万朔夜"两个别名词条）以 `===` 分隔条合并多源资料。
